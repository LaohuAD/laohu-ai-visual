# 图片提示词：《不想长大》

## 阶段说明

本文件承接正式剧本：

`01_作品项目/进行中/2026-06-18_不想长大/02_剧本/文本/2026-06-18_剧本_不想长大.md`

当前阶段目标不是把所有画面都做成资产，而是先建立能支撑后续分镜、视频提示词和生成测试的最小视觉资产体系。

本片是儿童第一人称 POV 的怀旧家庭短片。资产设计的重点是：

- 稳定人物关系和时代生活质感。
- 锁住反复出现的老家空间、木马车、汤圆硬币、丧葬物件。
- 保护 POV 叙事：小安必须先按正常儿童人物资产完整设计，锁定年龄、身高、比例、手部、服装、书包和鞋；后续视频再以手、袖口、书包、背影、低视线和动作反应承载身份，不频繁正脸主角化。
- 保留“主角从小没了妈”的背景刀口，但不做母亲角色资产，不展开母亲支线。

## 资产总览

作品体量：4-6 分钟横屏 16:9 怀旧家庭短片。

生成策略：先做少量高价值图片资产，锁住人物、老家空间和关键道具；一次性村民、亲戚、白布、纸钱、枯叶等进入分镜画面内容或单镜头参考图，不升级为长期资产。

资产唯一性修正：一个图片资产只固定一个确定对象。人物、场景、道具、服装不能混在同一个资产里；如果一个镜头需要多个元素同时稳定，就拆成多个资产，在分镜、视频提示词或第一帧参考图里组合调用。

优先级：

1. 人物资产：小安、父亲、爷爷、奶奶、姐姐，每个人物都输出两套提示词：人物形象资产 + 人物设计资产。
2. 群像人物资产：邻家孩子群像只锁跑龙套孩子群体的年龄层、服装年代、站位密度和生活气，不锁具体单人画像。
3. 场景多角度资产：老家院子、堂屋 / 灶房、放学路 / 村口、小滑坡、小卖部公共电话角落、商场玩具货架区、老家爷爷卧房。场景只锁空间结构、入口、墙面、柜台、固定电话位置、货架陈列、坡道路径、乡路方向、光源和动线。
4. 道具资产：旧木马车、新木马车、包汤圆旧木案桌、元宵完整白汤圆、元宵小面值硬币、药碗、输液瓶、纸扎房子、孝布等。道具只锁单件物品本体，不能把完整汤圆和硬币混成一个资产。
5. 文本资产：重庆老家怀旧写实视觉规则、元宵团圆生活气、丧事仪式视觉规则、儿童 POV 视角规则。

## 风格方向

推荐主风格：90年代老式DV家庭记忆质感 + 重庆老家真人写实风格。

画质介质：全片使用90年代老式DV质感作为记忆外壳，保留轻微频闪噪点、旧录像暖黄偏色和自然光的朴素现场感；资产生成仍保持8K超高清、真人写实、材质和人物细节清楚，不能把DV质感理解成低清、糊、脏或破。

色彩与影调：老家白天是暖黄自然光、土黄木色、旧墙灰白和干净生活色；元宵夜是灶火暖黄、旧灯泡橙黄、糯米白；丧事段是冷灰白布、纸灰、暗木色和微弱火光，但仍保留90年代DV记忆里的暖黄底色；结尾傍晚偏冷，枯叶和木车保留温暖褐色。

风格风险：如果画面太漂亮，会失去生活真实；如果太灰太糊，会变成苦情纪录片或廉价旧录像。主线要保持“生活曾经温暖，后来才刺痛”的层次：怀旧来自暖黄自然光和DV记忆质感，不来自脏破贫困。

选择性忽视风险：普通乡村亲情片容易变成同质化怀旧。轻微跑调点是“儿童 POV 的低视线 + 木马车遗物 + 片名由枯叶拉高引出”，让画面从普通哭戏变成有记忆结构的电影收尾。

## 图片资产提示词

### 人物资产版式说明

本作品的人物资产分为两层：

人物形象资产：单张环境内正面 / 半正面艺术照，用具体场景、光影方向、服装材质、姿态、眼神、构图和叙事瞬间先立住角色第一眼气质。它负责“这个人是什么感觉”。

人物设计资产：白底 / 简洁背景四区参考图，用三视图、面部特写、配色板、局部细节和比例照固定五官、身形、服装和可复用细节。它负责“制作和下游生成如何稳定复用”。

所有主要人物都必须输出两条提示词：一条人物形象资产，一条人物设计资产。不能再用“左侧脸部近景 + 右侧三视图”的旧版混合结构替代两套资产。小安虽然是儿童 POV 主体，也必须先做完整人物形象资产和人物设计资产；只是后续视频阶段不把他当成频繁露脸的正脸主角来拍。

本作品的人物设计资产图优先采用四区结构，便于制作人员快速确认整体造型：

主视觉区（上方）：
正面 + 侧面 + 背面三个核心视角，展示整体身形、服饰搭配和标志性特征。

补充信息区（左侧）：
面部特写 + 配色板，补足脸部正立、颈部垂直、下颌线水平、头顶到下巴在画面垂直中轴上的标准，以及毛发 / 服饰色值。

局部细节区（底部）：
配饰、点缀、关键身份识别元素的小模块拆解。

比例照（右侧）：
上半身或全身比例照，必要时加入比例参考物或身高对比。

人物资产图如果有校服、制服、明显身高要求或腿长要求，可以在提示词里补充：

人物比例和谐，头身比正确，上下身 4:6，长腿，真人写实风格，电影画质，影视级真实材质。

但这些内容仍然服务人物一致性和制作确认，不是做时尚写真。

如果后续实际生成时使用人物参考图 + 服装参考图，提示词要拆开写：人物参考图固定脸、身形、年龄感、体态和气质；服装参考图固定服装版型、层次、颜色和穿法。服装可按内 / 中 / 外 / 腰 / 下 / 足展开。父亲、爷爷、奶奶、姐姐适合按完整四区人物资产图执行；小安也按完整四区儿童人物资产图执行，只是在使用规则里注明视频阶段少正脸，重点调用小手、袖口、书包、背影和低视线高度。
