## 二、核心小样

```text
核心镜头编号：E1-S1-C1
核心镜头时长：12 秒
核心镜头任务：年轻仙人对镜头喊“大人，请登仙界！”，镜头背后的“大人”拂袖打开虫洞式仙界时空裂隙
一个主要动作：第一人称拂袖，仙力冲击波撕开天空
一个信息变化：观众从普通视角变成被仙界恭迎的大人物视角
是否有台词 / 旁白 / 同期声：有台词和仙门开启同期声
```

通过标准：

- [ ] 镜头只做一个主要任务。
- [ ] 观众能看见信息变化。
- [ ] 不靠长解释理解剧情。
- [ ] 能继续拆图片资产和视频提示词。
- [ ] 横屏 16:9 构图成立。
- [ ] 运镜炫酷但不乱，主体没有丢。
- [ ] 第一人称袖口 / 手势 / 仙力波纹能证明“大人”身份。
- [ ] 时空裂隙像仙侠虫洞，不是普通仙门或科幻机械通道。
- [ ] 后续能接恢宏仙界、群仙让路和万仙朝阙。
