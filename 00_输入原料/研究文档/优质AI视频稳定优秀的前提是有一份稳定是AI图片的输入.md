# 优质 AI 视频稳定优秀的前提，是有一份稳定的 AI 图片输入

> 研究时间：2026-06-06  
> 适用方向：AI 图片提示词 / AI 视频参考图 / 影视视觉资产 / 海报封面 / 人物与道具固定  
> 文档定位：这不是一份“好看图片关键词大全”，而是一份把 AI 图片当成后续视频、海报、封面、影视资产上游输入的实战说明书。

## 先说结论

我现在越来越觉得，很多人做 AI 视频不稳定，问题不一定出在视频提示词。

更上游的问题，是图片输入本身就不稳定。

如果你给视频模型的参考图里，人物脸不明确、服装不统一、光影方向混乱、构图没有目的、画面风格一会儿写实一会儿插画，后面再怎么写视频提示词，模型都只能在一堆模糊信息里猜。

它猜得准，你觉得这次运气好。

它猜偏了，你又开始怀疑模型不行。

但真正该先检查的是：你有没有一份稳定的 AI 图片资产。

这里的图片，不只是“生成一张漂亮图”。

它可能是：

- 角色三视图。
- 人物定妆照。
- 道具设定图。
- 场景氛围图。
- 海报主视觉。
- 短视频封面。
- 视频第一帧。
- 后续 Seedance 2、Runway、可灵、即梦等视频模型要吃进去的参考图。

所以 AI 图片提示词的写法，也不能停留在：

```text
一个女孩，电影感，高清，赛博朋克，氛围感。
```

这个写法能出图，但很难做资产。

资产型图片提示词要回答的不是“这张图好不好看”，而是：

```text
这张图后面要干什么？
哪些变量必须固定？
哪些变量可以变化？
它要服务角色、场景、道具、海报、摄影还是封面？
它能不能作为下一步视频生成的稳定输入？
```

这篇文档要解决的就是一个问题：

**怎么写一份能稳定生产 AI 图片资产，并且能继续服务 AI 视频创作的图片提示词。**

## 一、为什么 AI 视频越来越依赖稳定图片输入

我们先把这个背景讲清楚。

Seedance 2.0 官方资料里提到，它支持文本、图像、音频、视频作为输入参考，可以用这些素材控制表演、光影和镜头运动。Seedance 2.0 的论文摘要里也提到，它支持多模态输入，开放平台支持最多 9 张图片、3 段视频和 3 段音频作为参考。

这件事放到创作里，会带来一个很直接的变化：

以前视频提示词主要靠文字描述。

现在视频生成越来越像是“文字说明 + 参考图 + 参考视频 + 音频”的组合生产。

文字负责说清意图。

图片负责锁定视觉。

视频负责提供运动。

音频负责提供声音和节奏。

这里面，图片特别重要。

因为图片通常承担了三个任务：

```text
锁人物
锁风格
锁画面基准
```

如果图片没锁住，视频就很容易飘。

比如你想做一个固定角色连续出镜的视频。第一段是女孩在雨夜街头，第二段是女孩坐进出租车，第三段是女孩回头看镜头。

如果你没有一张足够稳定的角色参考图，模型每一段都可能把她生成成不同的人。

脸变了。

发型变了。

衣服变了。

气质也变了。

最后观众看到的不是一个角色在经历故事，而是三个长得有点像的人分别出现在三个片段里。

这就是 AI 视频创作里最常见的问题：画面看起来都不错，但不能连成作品。

而作品最怕的不是某一帧不够漂亮。

作品最怕的是不连续。

## 二、AI 图片提示词已经从“出图词”变成“资产说明书”

早期大家写 AI 图片提示词，经常是堆词。

```text
电影感，超真实，高级感，柔光，质感，高清，细节丰富。
```

这些词不是完全没用。

但它们大多只能影响画面的平均观感，不能真正控制画面。

OpenAI 的图片生成指南里有一个很朴素但重要的建议：提示词要说清楚图片用途、主体、正在发生什么、发生地点和视觉风格；如果构图、光线或约束很重要，也要写进去。它还提醒，清楚的光线描述会比“漂亮光影”更可靠。

这句话翻译到我们自己的创作里，就是：

```text
不要用感觉代替说明。
```

比如“高级感”是感觉。

“深灰背景，左上方大面积柔光，人物站在画面右侧三分线，脸部保留阴影，服装为无明显品牌的黑色羊毛大衣”才是说明。

真正可控的图片提示词，应该从“形容词堆叠”升级成“视觉资产说明书”。

它至少要写清楚：

- 这张图的用途。
- 画面主体是谁或是什么。
- 主体处在什么场景。
- 景别多近。
- 构图怎么安排。
- 光从哪里来。
- 画面是什么色调。
- 风格是摄影、电影、海报、设定图还是封面。
- 哪些细节必须固定。
- 哪些东西不要出现。
- 如果有文字，文字放在哪里、写什么、是什么字体气质。

你看，这已经不是“写关键词”了。

它更像在给摄影师、美术、造型、灯光和设计师同时发一份小型任务单。

## 三、一份完整 AI 图片提示词的九个模块

我建议以后写 AI 图片提示词，不要一上来就写画面。

先搭结构。

一份稳定的图片提示词，可以拆成九个模块：

```text
用途设定
主体内容
景别
构图
光影氛围
画质与材质
画面风格
画面文字
负面约束
```

这九个模块不一定每次全部写满。

但你脑子里要有这九个位置。

缺哪个，模型就可能在哪个地方乱发挥。

### 1. 用途设定：先告诉模型这张图要干什么

用途是第一层。

很多提示词跑偏，是因为一开始没说用途。

同样是“一个中年男人站在街头”，它可以是：

- 电影角色定妆照。
- 短视频封面。
- 公众号头图。
- 商业海报。
- 纪录片摄影。
- 角色三视图里的正面图。
- 视频生成的第一帧参考图。

用途不同，提示词写法完全不同。

如果是角色定妆照，你要强调人物五官、发型、服装、年龄感、气质和可复用性。

如果是封面，你要强调文字空间、主体识别度、对比度和平台缩略图可读性。

如果是海报，你要强调主视觉、情绪冲突、标题位置和传播感。

如果是视频第一帧，你要强调人物姿态、场景连贯、镜头可延展和运动空间。

所以提示词第一句最好先写：

```text
用途：这是一张用于 AI 视频生成的角色参考图，重点是固定人物外貌、服装和气质，画面不追求复杂背景。
```

或者：

```text
用途：这是一张短视频封面图，重点是第一眼看清人物、标题和主题冲突，画面要适合手机竖屏缩略图。
```

用途写清楚以后，后面的模块才有方向。

### 2. 主体内容：主体不是“一个人”，而是可识别对象

主体内容要回答：

```text
画面里最重要的对象是谁？
他长什么样？
他在做什么？
哪些特征不能变？
```

不要只写：

```text
一个年轻女孩。
```

可以写成：

```text
一个 24 岁左右的年轻女孩，短黑发，眼神克制但敏感，穿深蓝色旧风衣和白色内搭，左肩背一个磨旧的帆布包。她站在雨后的公交站旁，身体略微侧向镜头，像是在等一个迟迟没有出现的人。
```

这段提示词里，人物不是一个标签，而是有可识别特征的角色。

如果是道具，也一样。

不要只写：

```text
一把旧钥匙。
```

可以写成：

```text
一把黄铜旧钥匙，钥匙柄上有细小划痕和暗红色布绳，边缘略微氧化，放在木桌中央。它不是普通钥匙，而像是某个旧房间、旧秘密或家族记忆的线索道具。
```

主体写得越清楚，后面越容易复用。

### 3. 景别：决定观众和主体的距离

景别不是专业词装饰。

景别决定观众离主体有多近。

常用景别可以这样理解：

| 景别 | 适合用途 | 提示词写法重点 |
|---|---|---|
| 远景 | 场景氛围、世界观、城市、自然环境 | 人物可以小，环境要清楚 |
| 全景 | 人物与环境关系、动作姿态 | 身体完整，空间关系清楚 |
| 中景 | 口播封面、人物行动、对话感 | 人物上半身和手部动作清楚 |
| 近景 | 情绪、表情、人物状态 | 脸部、眼神、嘴角和肩颈要清楚 |
| 特写 | 关键道具、微表情、悬念点 | 只保留最重要信息，不要背景抢戏 |

比如你要做角色资产，最好先用中景或半身照，不要上来就大特写。

因为大特写容易锁住脸，但锁不住服装、身形和气质。

如果你要做视频第一帧，也要小心特写。

特写画面后续运动空间少，模型很容易只能做一点点眨眼、转头、推镜。

如果后续要人物走动、拿东西、进入场景，初始图最好给足身体和空间。

### 4. 构图：决定信息怎么被看见

构图要回答：

```text
主体放在哪里？
观众先看哪里？
背景给多少？
文字放哪里？
画面有没有运动空间？
```

常用构图可以先掌握这几类：

| 构图     | 适合用途          | 使用提醒           |
| ------ | ------------- | -------------- |
| 居中构图   | 角色定妆、头像、封面主视觉 | 稳定、直接，但容易呆     |
| 三分线构图  | 电影感画面、人物与环境关系 | 适合留出视线方向和标题空间  |
| 对称构图   | 仪式感、庄重、悬疑、建筑  | 容易有压迫感，也容易过于静态 |
| 前景遮挡构图 | 叙事感、偷窥感、纪实感   | 注意不要挡住主体关键信息   |
| 留白构图   | 海报、封面、标题设计    | 留白必须有目的，不是空    |
| 低角度构图  | 力量感、压迫感、英雄感   | 容易夸张，慎用在真实口播封面 |
| 高角度构图  | 孤独、脆弱、被观察     | 人物会显得弱一些       |

如果是封面图，要特别强调标题空间。

比如：

```text
人物放在画面右侧三分线，左侧保留干净深色留白，用于后期放置中文标题，不要在留白处出现复杂纹理和杂乱物体。
```

如果是视频参考图，要强调运动空间。

比如：

```text
人物站在画面左侧，右侧留出街道延伸空间，方便后续视频中人物向右前方行走，背景透视线指向远处路灯。
```

这类信息很重要。

因为图片不仅是静态图，它还是后续视频的起点。

### 5. 光影氛围：不要写“氛围感”，要写光从哪里来

光影是图片质感的核心。

但“氛围感”这个词太模糊。

更好的写法是把光拆开：

```text
主光从哪里来
光是硬还是软
阴影保留多少
色温偏冷还是偏暖
有没有轮廓光
背景有没有局部光源
```

例如：

```text
左上方一盏柔和窗光照亮人物半边脸，右侧脸部保留自然阴影，背景有暖黄色台灯形成轻微轮廓光，整体低饱和、安静、真实，不要棚拍硬光。
```

这比“高级光影、电影感”稳定得多。

不同用途下，光影方向也不同。

角色资产图最好光线均匀一点，方便后续参考。

海报图可以光影戏剧化一点，强化情绪。

封面图要保证主体和文字清晰，不要为了氛围把脸压得太暗。

摄影感图片要保留真实光线来源，不要所有地方都亮得像广告棚拍。

### 6. 画质与材质：让模型知道哪些细节要可信

画质不是只写“高清”。

高清只是结果要求。

材质才是细节的抓手。

比如：

- 皮肤是自然纹理，还是磨皮广告感。
- 衣服是棉麻、皮革、羊毛、尼龙，还是金属装甲。
- 道具是黄铜、旧木、磨砂玻璃、湿润石板，还是塑料。
- 场景是潮湿、积灰、反光、破旧，还是干净明亮。

提示词可以这样写：

```text
真实摄影质感，皮肤保留自然纹理，衣服为略旧的深色羊毛材质，布料边缘有轻微磨损，雨水在肩部形成细小反光，背景路面潮湿但不夸张。
```

材质写清楚以后，画面会更容易“落地”。

落地感很重要。

观众不一定能说出哪里真实，但他能感觉到这东西像不像真的存在过。

### 7. 画面风格：风格要能执行，不要只写流派名

风格可以写，但不要只堆流派名。

比如：

```text
电影感，港风，日系，复古，赛博朋克。
```

这些词都太大。

你可以继续拆成：

```text
画面像 90 年代香港街头电影的雨夜场景，霓虹灯反射在湿路面上，颜色以青绿色和暗红色为主，人物不是时尚大片姿态，而是有一点疲惫和生活感。
```

这就比“港风电影感”清楚。

风格最好包含四件事：

```text
时代感
媒介感
色彩倾向
真实程度
```

例如：

```text
风格：写实电影剧照，不是插画，不是游戏 CG。整体像现实世界里被摄影机拍下来的一个瞬间，色彩低饱和，轻微胶片颗粒，人物和环境都保留生活痕迹。
```

如果是海报，可以写：

```text
风格：电影海报主视觉，主体清晰，背景有叙事线索，画面有强烈情绪张力，但不要变成炫技概念图。
```

如果是封面，可以写：

```text
风格：短视频封面图，手机端第一眼能看清人物和标题，画面干净、对比明确、不要过度复杂。
```

风格必须服务用途。

不要为了风格牺牲可用性。

### 8. 画面文字：中文标题要短、准、位置明确

图片里出现文字，是封面和海报最容易翻车的地方。

OpenAI 的图片指南里也提醒，图中文字最好非常具体，要说明文字内容、字体风格、大小、颜色和位置，并且文字尽量短。

我们的使用场景大多是中文内容，所以这里直接按中文来写。

比如短视频封面：

```text
画面左侧留白区域放置中文标题“半年跑通一门副业”，标题为粗黑体，白色文字，最多两行，字距正常，边缘清晰。标题下方小一号副标题“从 0 到 1 的完整过程”，不要出现其他文字。
```

海报可以这样写：

```text
画面上方居中放置中文片名“雨夜来信”，字体有电影片名感，白色略带灰度，不要花体，不要英文，不要多余标语。
```

这里要注意一个判断：

如果你对文字准确度要求很高，最好让 AI 图只负责留白和画面，文字后期在设计工具里加。

AI 直接生成文字可以用来做草图。

但正式发布封面，标题最好自己后期排。

尤其是中文标题，少一个字、错一个字、笔画变形，整个封面就废了。

### 9. 负面约束：不是越多越好，而是挡住最容易跑偏的地方

负面约束不是垃圾桶。

不要把所有讨厌的东西都塞进去。

真正有用的负面约束，是针对当前任务最容易跑偏的方向。

比如角色资产：

```text
不要夸张妆容，不要明显品牌标志，不要奇怪手指，不要多余人物，不要过度美颜，不要复杂背景抢主体。
```

比如封面图：

```text
不要小字堆满画面，不要复杂背景，不要让标题遮住人物脸，不要出现无关图标和装饰元素。
```

比如影视剧照：

```text
不要卡通化，不要游戏 UI，不要塑料皮肤，不要过度锐化，不要让角色像摆拍模特。
```

负面约束的目的不是把模型骂清醒。

是提前堵住最影响可用性的错误。

## 四、不同用途下的图片提示词写法

同一套模块，落到不同用途，重点不一样。

这里直接按常见创作场景拆。

### 1. 影视角色资产：先固定人，再让人进入故事

影视角色资产最重要的不是漂亮。

是稳定。

它要让后续模型反复识别：

```text
这是同一个人。
```

角色资产提示词建议包含：

- 年龄段。
- 脸型和五官特征。
- 发型。
- 服装主色和材质。
- 身形和站姿。
- 性格气质。
- 表情基准。
- 光线尽量自然均匀。
- 背景简单，不抢主体。

示例：

```text
用途：用于 AI 视频生成的角色参考图，重点固定人物外貌、服装和气质。

主体：一位 32 岁左右的男性纪录片导演，短发，脸型偏瘦，眼神敏锐但不张扬，轻微胡茬，穿深灰色防水夹克和黑色圆领内搭，肩上挂一台旧相机。人物气质是长期在现场工作的人，安静、观察力强、有一点疲惫，但不颓。

景别：半身中景，人物从头到腰部完整出现，方便保留脸、服装、身形和手部姿态。

构图：人物居中略偏右，背景为简单灰色墙面，左侧保留少量空白，不要复杂环境。

光影：正面偏左的自然柔光，脸部清楚，阴影轻微，整体适合做角色基准参考。

画质与风格：真实摄影质感，皮肤自然，服装有布料纹理，不要广告棚拍，不要过度美颜。

负面约束：不要品牌标志，不要夸张姿势，不要多余人物，不要卡通化，不要奇怪手指。
```

这个提示词的目的不是一次就做出大片。

它的目的，是先把角色定住。

有了稳定角色，再去做场景变化、情绪变化、动作变化。

### 2. 人物三视图：不要追求戏剧性，先追求一致性

三视图适合固定人物形象。

尤其是后续要做多镜头视频、漫画分镜、角色设计、IP 形象时，三视图非常有用。

三视图提示词重点是：

- 正面、侧面、背面同时出现。
- 同一人物、同一服装、同一发型。
- 背景干净。
- 光线均匀。
- 表情中性。
- 不要强烈透视。
- 不要戏剧性姿态。

示例：

```text
用途：角色三视图设定图，用于后续固定人物形象和生成视频参考。

画面内容：同一位 24 岁左右的女性角色，以三视图形式展示，左侧为正面，中间为侧面，右侧为背面。她短黑发，发尾到下巴位置，穿深蓝色旧风衣、白色内搭、黑色长裤和旧帆布鞋，左肩背一个磨旧帆布包。三个人物必须是同一个角色，同一套服装，同一发型，同一身高比例。

景别：全身图，人物从头到脚完整出现。

构图：三个人物等距排列在画面中，背景为干净浅灰色，类似角色设定图，不要复杂场景。

光影：均匀柔光，脸部和服装细节清楚，不要强烈阴影。

风格：写实影视角色设定图，不是动漫设定图，不是游戏立绘。

负面约束：不要不同服装，不要不同脸，不要夸张动作，不要武器，不要背景道具，不要文字。
```

这里的关键是克制。

三视图不是海报。

它是角色资产。

### 3. 道具资产：让道具能承载故事

道具不是摆设。

影视创作里的道具，最好能承担叙事功能。

一把钥匙、一张车票、一台旧录音机、一本破笔记，都可以成为故事线索。

道具提示词要写清：

- 道具是什么。
- 材质和年代感。
- 使用痕迹。
- 与故事的关系。
- 背景尽量简单。
- 是否需要孤立展示。
- 是否需要留给后续特写镜头使用。

示例：

```text
用途：影视短片里的关键道具参考图，后续会作为视频特写参考。

主体：一台 90 年代风格的旧录音机，深灰色塑料外壳，边角有轻微磕碰，按键有磨损痕迹，透明磁带仓里放着一盘手写标签的磁带，标签上写着“1998 年夏天”。

景别：道具特写，录音机占画面主体，背景只保留木桌和少量阴影。

构图：录音机放在画面中央偏下，镜头略微俯拍，右上方有一束窗光落在磁带仓上。

光影氛围：下午自然光，温暖但不明亮，带一点旧回忆感。

画质与材质：真实摄影质感，塑料外壳、灰尘、划痕和标签纸纹理清楚。

负面约束：不要现代数码设备，不要品牌标志，不要多余文字，不要赛博朋克风格，不要过度干净。
```

好道具图的重点，是让人感觉它来自一个故事，而不是来自素材网站。

### 4. 场景氛围图：先确定世界，再安排人物

场景氛围图服务世界观。

它不一定要有明确剧情，但要让后续画面有统一的环境基准。

比如：

- 雨夜街头。
- 小县城音乐教室。
- 废弃商场。
- 未来城市地下通道。
- 老式居民楼走廊。
- 狭小出租屋。

场景氛围图要写清：

- 地点。
- 时间。
- 天气。
- 色调。
- 空间结构。
- 光源位置。
- 可以容纳人物行动的区域。
- 哪些元素是世界观的一部分。

示例：

```text
用途：AI 短片的场景氛围参考图，用于统一后续多个镜头的环境风格。

场景：雨后的老城区公交站，夜晚，路面潮湿反光，远处有便利店和旧楼窗户的暖光，公交站牌略旧但干净，地上有少量积水和落叶。

景别：远景到全景之间，画面能看清公交站、街道延伸方向和人物可站立区域。

构图：公交站位于画面左侧三分线，右侧街道向远处延伸，形成纵深感；画面中央留出人物后续进入的位置。

光影氛围：路灯是冷白色，便利店是暖黄色，冷暖光混合，整体安静、孤独、有等待感。

画质与风格：写实电影剧照风格，低饱和，轻微胶片颗粒，雨水反光自然，不要过度霓虹。

负面约束：不要未来科幻建筑，不要拥挤人群，不要卡通化，不要广告牌文字过多。
```

场景图写好了，后面人物进场才不突兀。

### 5. 海报主视觉：一个画面说清冲突

海报和角色资产不一样。

角色资产求稳定。

海报求传播。

海报主视觉要回答：

```text
这部作品的核心冲突是什么？
观众第一眼应该感受到什么？
标题应该放在哪里？
画面能不能被记住？
```

示例：

```text
用途：AI 短片海报主视觉，用于发布预告和内容封面。

主题：一个年轻女孩在雨夜收到一封来自过去的信，画面要呈现“旧记忆突然回到眼前”的情绪。

主体：女孩站在雨夜公交站下，手里拿着一封被雨水打湿的旧信，低头看信，眼神震动但克制。她穿深蓝色旧风衣，短黑发，身后是模糊的老城区街道。

景别：中景，人物上半身清楚，信件作为关键道具可见。

构图：人物位于画面右侧，左上方留出片名空间。背景路灯和便利店形成纵深，雨水反光引导视线到人物手里的信。

光影氛围：冷色雨夜，局部暖光打在信纸上，信纸成为画面视觉焦点。

画面文字：左上方放置中文片名“雨夜来信”，白色简洁字体，不要英文，不要其他标语。正式发布时文字可后期替换，所以画面要保留干净留白。

风格：写实电影海报，不要游戏海报，不要插画，不要过度奇幻。

负面约束：不要夸张泪水，不要多余人物，不要复杂文字，不要让标题遮住人物脸。
```

海报不是把画面做满。

海报是把冲突压进一个画面里。

### 6. 摄影感图片：别让画面像模型在炫技

摄影感图片最怕两个问题。

一个是过度完美。

一个是没有拍摄逻辑。

真实摄影会有镜头、焦段、光源、空间限制和现场感。

所以摄影感提示词要写：

- 像什么拍摄场景。
- 镜头距离。
- 光源是否真实存在。
- 背景有没有生活痕迹。
- 人物是否像在被拍，而不是在摆拍。
- 质感是否保留不完美。

示例：

```text
用途：纪实摄影风格图片，用于文章配图或视频封面素材。

主体：一个 35 岁左右的男人坐在凌晨的工作室里，桌上有电脑、咖啡杯、手写笔记和几张打印出来的分镜草图。他没有看镜头，而是低头修改纸上的内容，状态专注但疲惫。

景别：中景，人物上半身和桌面工作痕迹都要清楚。

构图：人物位于画面左侧，右侧显示桌面和散落的分镜草图，画面不要太整齐。

光影氛围：电脑屏幕和一盏小台灯作为主要光源，背景较暗，光线真实、低调，不要棚拍感。

画质与风格：纪实摄影，轻微噪点，真实生活质感，皮肤和桌面不要过度修饰。

负面约束：不要商业广告感，不要完美办公桌，不要夸张科技感，不要多余文字。
```

摄影感不是“超真实”。

摄影感是画面像被一个真实的人在真实空间里拍下来。

### 7. 短视频封面：手机端第一眼能看懂

封面图和海报类似，但更功利。

它要在很小的尺寸里被看见。

封面提示词要特别注意：

- 人物脸要大。
- 标题空间要干净。
- 主体和背景对比要强。
- 信息不要太多。
- 一眼能知道主题。
- 不要为了氛围牺牲清晰度。

示例：

```text
用途：短视频竖屏封面图，适合手机端信息流展示，重点是第一眼看清人物和标题。

主体：一个普通创作者站在桌前，桌上放着电脑和一张收益截图打印纸。他表情不是夸张兴奋，而是认真、带一点“我真跑过一遍”的确定感。

景别：近景到中景，人物上半身清楚，脸部识别度高，手里可以拿着打印纸但不要遮住脸。

构图：人物在右侧三分线，左侧保留大面积干净深色空间用于标题。

光影氛围：明亮但不刺眼，人物脸部清楚，背景略暗，主体和文字区域对比明确。

画面文字：左侧放置中文标题“半年跑通一门副业”，粗黑体白字，最多两行，字要大。下方小字“保姆级教程”可选，不要其他文字。

画质与风格：真实口播封面风格，不要浮夸成功学，不要豪车现金，不要夸张表情包。

负面约束：不要复杂背景，不要小字太多，不要金色炫富风，不要标题遮住脸，不要伪造平台收益界面。
```

封面的判断标准很简单：

缩小到手机信息流里，还能不能看懂。

## 五、用于 AI 视频前的图片输入规范

如果一张 AI 图片后续要进入视频模型，它就不能只按静态图标准判断。

还要检查五件事。

### 1. 人物是否稳定

检查：

- 五官是否清楚。
- 发型是否明确。
- 服装是否有稳定特征。
- 身形比例是否自然。
- 表情是否适合作为后续起点。

如果你后续要做多个镜头，最好先生成：

```text
角色基准半身图
角色三视图
角色表情变化图
角色服装细节图
```

不要只靠一张艺术感很强的大头照撑完整视频。

### 2. 构图是否给动作留空间

视频会动。

如果图片构图太满，模型后续运动空间就很少。

比如人物脸贴满画面，后续只能眨眼、转头、微表情。

如果你要人物走路、转身、拿东西、进入房间，图片里就要留出身体和空间。

提示词里可以写：

```text
画面右侧留出人物行走方向的空间，背景有清晰纵深，适合后续生成镜头推进或人物向前移动。
```

### 3. 光影是否能延续

视频片段之间最容易断的一个东西，是光。

第一张图是冷色雨夜。

第二张图变成暖色棚拍。

第三张图又变成阳光下午。

角色再稳定，也会断。

所以同一组视频参考图里，要固定：

- 时间段。
- 色温。
- 主光方向。
- 背景光源。
- 阴影强度。
- 饱和度。

### 4. 风格是否统一

同一作品里，不要一张写实、一张插画、一张游戏 CG、一张广告大片。

除非你本来就要做风格跳变。

否则先确定统一风格：

```text
写实电影剧照
纪实摄影
短剧竖屏
复古胶片
商业海报
角色设定图
```

风格一旦定下来，后续同项目提示词都要沿用同一套风格描述。

### 5. 图片本身是否干净

干净不是简陋。

干净是指模型能清楚识别谁是主体、什么是背景、哪些信息重要。

视频参考图尽量避免：

- 画面里太多人。
- 主体被遮挡。
- 背景全是复杂文字。
- 道具太多，没有主次。
- 角色服装过于复杂且每处都需要保留。
- 光影过于极端，脸部信息丢失。

参考图越干净，视频模型越容易接住。

## 七、常见错误和修正方法

### 错误 1：只写风格词，不写执行细节

问题写法：

```text
高级感电影海报，氛围感，超真实，细节丰富。
```

修正写法：

```text
一张写实电影海报，人物站在雨夜公交站右侧，手里拿着被雨水打湿的旧信。左上方留出片名空间，冷色路灯照亮雨水反光，信纸被一束暖光突出，整体低饱和、安静、有悬念。
```

### 错误 2：没有说明用途

问题写法：

```text
一个中年男人坐在电脑前。
```

修正写法：

```text
这是一张短视频封面图，主题是“普通人如何开始做 AI 视觉创作”。中年男人坐在电脑前，桌上有分镜草图和图片参考图，人物看向镜头，表情认真但不夸张。右侧保留大标题空间。
```

### 错误 3：角色图太戏剧化，反而不适合复用

问题写法：

```text
一个女人站在暴风雨中，头发飞舞，强烈光影，史诗感。
```

修正写法：

```text
用于角色基准参考的半身图。一个 28 岁左右女性，短黑发，深蓝色风衣，白色内搭，表情平静克制。背景简单，光线均匀，脸部和服装细节清楚，方便后续生成不同场景。
```

### 错误 4：封面标题空间没留出来

问题写法：

```text
一个创作者拿着收益截图，背景有很多电脑屏幕和数据图表。
```

修正写法：

```text
短视频封面图。创作者位于画面右侧三分线，手里拿着一张简化的收益截图打印纸，左侧保留干净深色留白，用于后期放置大标题。背景只保留电脑和桌面，不要复杂数据图表。
```

### 错误 5：给视频模型的参考图太满

问题写法：

```text
人物脸部大特写，占满画面。
```

修正写法：

```text
用于 AI 视频第一帧的中景参考图。人物从头到腰部出现，站在走廊左侧，右侧留出行走空间，背景有纵深，适合后续生成推镜和人物向前移动。
```

### 错误 6：想让 AI 直接生成复杂中文排版

问题写法：

```text
生成一张带很多中文说明的知识图谱海报。
```

修正写法：

```text
生成一张知识图谱海报背景图，保留清晰的标题区、三块内容区和底部备注区，不直接生成大量正文文字。正式中文内容后期在设计工具中添加。
```

复杂中文排版，后期做通常更稳。

## 八、我的实战判断

如果你只是玩图，一句提示词也能出效果。

但如果你要做作品，提示词就要开始承担系统功能。

老胡做 AI 视觉创作，不能只追求单张图惊艳。

更重要的是把每张图放进一个连续生产流程里：

```text
剧本
→ 角色设定
→ 场景设定
→ 道具设定
→ 图片资产
→ 视频提示词
→ 视频片段
→ 剪辑成片
→ 发布复盘
```

在这个流程里，AI 图片是中间很关键的一层。

它既接住前面的剧本和设定，又影响后面的视频稳定性。

所以一张合格的 AI 图片，不只是好看。

它至少要做到：

- 角色能复用。
- 场景能延续。
- 道具能被识别。
- 光影能统一。
- 构图能承接视频运动。
- 封面能承接传播。
- 海报能承接情绪。
- 文字空间能承接后期排版。

这才是图片提示词真正应该服务的方向。

我自己的判断是：

```text
图片提示词不是写给模型看的形容词。
图片提示词是写给整个创作流程看的视觉资产说明。
```

这句话如果立住，后面很多问题就会变简单。

你不会再问“怎么让这张图更高级”。

你会开始问：

```text
这张图后面要干什么？
它要固定谁？
它要支撑哪一段视频？
它要给封面留什么位置？
它要作为哪个角色、场景、道具的长期资产？
```

这个问题一变，提示词的质量就会变。

## 九、后续应该沉淀哪些资产

这篇文档不是一次性看的。

它后面应该进入项目系统，变成几个可复用资产。

### 1. 角色资产库

每个角色至少沉淀：

- 角色名称。
- 年龄和身份。
- 外貌特征。
- 发型服装。
- 性格气质。
- 三视图。
- 表情组。
- 常用动作。
- 禁止变化项。
- 可变化项。

### 2. 场景资产库

每个场景至少沉淀：

- 场景名称。
- 时间段。
- 地点特征。
- 光源设定。
- 色彩设定。
- 空间结构。
- 可行动区域。
- 可复用镜头。
- 禁止变化项。

### 3. 道具资产库

每个道具至少沉淀：

- 道具名称。
- 材质。
- 年代感。
- 使用痕迹。
- 故事功能。
- 适合特写的角度。
- 和哪个角色或剧情有关。

### 4. 封面模板库

每种封面至少沉淀：

- 目标平台。
- 标题位置。
- 人物位置。
- 字体气质。
- 背景复杂度。
- 主体与文字对比。
- 已验证的有效案例。
- 老胡否定过的开头或封面问题。

### 5. 风格规则库

每个作品系列都应该有自己的风格规则。

比如：

```text
老胡 AI 视觉短片默认风格：
写实电影剧照，低饱和，真实生活质感，光源有现实依据，人物不过度美颜，场景有可触摸的材质，不要游戏 CG，不要广告棚拍。
```

这类规则越沉淀，后面生成越稳。

不要每次从零开始写。

## 十、最小可用工作流

如果现在就要开做，不要上来追求复杂。

可以先跑一个最小流程。

```text
确定一个短片主题
→ 写一句故事核心
→ 定一个主角
→ 生成主角半身基准图
→ 生成主角三视图
→ 生成一个关键场景氛围图
→ 生成一个关键道具特写图
→ 用这些图写视频提示词
→ 生成 3 个 5 秒片段
→ 剪成一条 15 秒样片
→ 复盘哪里稳定、哪里飘
→ 反向更新提示词规则
```

这个流程看起来慢。

但它比每次随机写一条提示词、随机出一条视频要靠谱。

AI 视觉创作最终拼的不是谁会写更多华丽词。

拼的是谁能把一套角色、场景、风格、镜头和发布反馈反复沉淀下来。

这才会形成复利。
