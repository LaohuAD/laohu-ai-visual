# Seedance 2 引发的未来对于 AI 视频提示词的书写规范思考

> 研究时间：2026-06-06  
> 适用方向：Seedance 2 / AI 视频提示词 / 分镜提示词 / 画面生成规范  
> 文档定位：这不是一份提示词模板合集，而是一份关于“未来 AI 视频提示词应该怎么写”的结构化指导文档。

## 先说结论

我现在越来越觉得，Seedance 2 这类视频模型出来以后，视频提示词从此进入新的篇章。

以前很多人写视频提示词，是这样：

```text
一个机器人在废土城市里奔跑，电影感，超真实，镜头跟拍，氛围紧张。
```

这个写法不是完全没用。

但它太像许愿。

它只告诉模型“我想要什么感觉”，没有告诉模型“这个画面应该怎么被拍出来”。

而 Seedance 2 这类模型真正带来的变化是：它开始让 AI 视频从“生成一个片段”，往“执行一份导演说明书”靠近。

所以未来的视频提示词，应该越来越像这几种东西的混合体：

```text
世界观设定
+ 美术设定
+ 摄影指导
+ 分镜脚本
+ 表演调度
+ 声音说明
+ 后期拼接说明
```

换句话说，提示词不再只是给模型看的“关键词”。

它更像是你给一个小型虚拟剧组下达的制作说明。

这也是为什么一份完整的视频提示词，最好不要只有画面内容，而要分成三层：

```text
基础设定
→ 氛围与画质
→ 画面主体内容
```

其中“画面主体内容”还要继续拆：

```text
镜头编号
→ 时间段
→ 景别
→ 构图
→ 运镜手法
→ 画面内容
→ 声音或后期备注
```

这个结构看起来麻烦。

但它解决的不是“写得专业”的问题，而是“减少模型乱发挥”的问题。

## 一、为什么 Seedance 2 会改变视频提示词的写法

我们先把这个背景讲清楚。

Seedance 2.0 官方资料和论文里，一个很重要的变化是：它不是只吃文本。它强调文本、图像、视频、音频都可以成为输入，模型可以在 4 到 15 秒的视频里处理多模态参考关系。

这件事对创作者意味着什么？

以前你写提示词，像是在给一个画师描述画面。

现在你写提示词，更像是在给导演、摄影、美术、演员、录音和后期同时发通告。

因为模型能理解的不只是“画面里有什么”，还包括：

- 角色长什么样。
- 角色应该怎么动。
- 镜头应该怎么推、拉、摇、移。
- 参考图里的主体应该如何保留。
- 参考视频里的动作节奏能不能迁移。
- 音频或同期声是否需要被保留。
- 这个片段是否要和前后画面拼接。

所以提示词的写法也要升级。

过去是：

```text
描述一个画面。
```

未来更像是：

```text
定义一个视频片段的生产规则。
```

这就是这份文档的核心判断。

**AI 视频提示词正在从“画面描述”，变成“分镜级生产说明书”。**

## 二、一份完整视频提示词的三层结构

我建议以后写 Seedance 2 视频提示词，先不要急着写“画面内容”。

先搭结构。

一份完整提示词可以分成三大块：

```text
【基础设定】
【氛围与画质】
【画面内容】
```

这三块的作用不一样。

### 1. 基础设定：给模型定边界

基础设定不是画面细节。

它是整个视频世界的规则。

它回答的是：

```text
这是一个什么世界？
人物是谁？
角色有什么共同限制？
声音怎么处理？
多个镜头之间要不要统一风格？
后期是否会拼接？
哪些东西不能变？
```

比如你给的图里，基础设定里有机器人、丧尸、场景、声音。

这些不是单个镜头的内容，而是整段视频的共同底座。

如果基础设定没写清楚，模型就很容易出现这些问题：

- 同一个角色每个镜头长得不一样。
- 世界观前后不一致。
- 一会儿电影感，一会儿游戏 CG 感。
- 明明不要配乐，却给你加了夸张音乐。
- 多个画面后期拼接时，色调、镜头语言、角色状态接不上。

所以基础设定的核心价值是：

```text
先把模型能乱发挥的地方圈住。
```

### 2. 氛围与画质：给模型定审美

氛围与画质负责回答：

```text
这个视频看起来像什么？
是纪录片？电影？广告？游戏预告？短剧？MV？
光线、色彩、质感、颗粒、镜头语言应该统一成什么方向？
```

这部分不要只写“电影感、超真实、高清”。

这类词太泛。

更好的写法是写清楚：

- 风格核心。
- 摄影方式。
- 色彩与影调。
- 画面质感。
- 视觉节奏。
- 禁止方向。

比如：

```text
风格核心：废土科幻动作短片，写实电影感，紧张但不浮夸。
摄影方式：手持跟拍，轻微晃动，近距离追随主体，保留现场不稳定感。
色彩与影调：低饱和度，冷灰色主调，局部红色警示光，强对比阴影。
画面质感：真实摄影质感，皮肤、金属、尘土、布料都要有细节，不要塑料感。
视觉节奏：移动速度快，镜头有压迫感，但不要剪辑混乱。
禁止方向：不要卡通化，不要游戏 UI，不要过度锐化，不要干净棚拍感。
```

这比“电影感、超真实”要稳定得多。

### 3. 画面内容：给模型定执行动作

画面内容是真正的分镜区。

它回答的是：

```text
每一个镜头拍什么？
从几秒到几秒？
景别是什么？
镜头怎么运动？
画面里谁在做什么？
声音和后期有什么要求？
```

这部分应该按镜头写。

尤其是你要做多个画面后期拼接的时候，更应该这么写。

因为单条提示词如果塞太多动作，模型很容易平均处理，最后每个动作都不清楚。

分镜的核心不是“写得长”。

而是让每个镜头只完成一个主要任务。

## 三、第一层：基础设定怎么写

基础设定建议包含 6 个模块。

```text
1. 世界观设定
2. 角色设定
3. 场景设定
4. 声音设定
5. 连续性设定
6. 禁止项设定
```

### 1. 世界观设定

世界观设定决定整个视频的底层逻辑。

比如：

```text
世界观：1960 年代复古未来主义废土世界。大战后的城市废墟，街道破败，报纸和玻璃碎片散落在地面，旧广告牌还在闪烁。整体不是现代赛博朋克，而是复古科幻与末日废土混合的世界。
```

这里有几个关键点。

第一，要写时代。

第二，要写风格混合关系。

第三，要写“不是”。

很多提示词只写“复古未来主义”，但不写“不是现代赛博朋克”。模型就可能给你拉到霓虹灯、现代高楼、科技城市。

所以基础设定里，否定方向很重要。

### 2. 角色设定

角色设定要写稳定特征。

比如：

```text
主角：身形修长的人形机器人，面部是老式 LED 屏幕，屏幕显示简单表情，不做动态夸张表情。身体穿着复古西装外套，皮革手套，腰间有工具带。动作敏捷但带有机械停顿感，跑动时关节略微生硬。
```

这里有几个重点：

- 身形。
- 面部。
- 服装。
- 材质。
- 动作方式。
- 表演限制。

角色设定和上一份表情文档里的人物性格设定有点像。

人物性格决定表情边界。

角色设定决定画面边界。

比如你写“机器人有自主意识”，那它可以有选择、犹豫、恐惧、愤怒。

但如果你写“面部 LED 只显示静态表情”，那它的情绪就不能靠脸部肌肉表现，而要靠屏幕图案、头部角度、身体动作、声音来表现。

这就是基础设定的意义。

它不是单纯描述角色，而是在告诉模型：这个角色的表达能力到哪里为止。

### 3. 场景设定

场景设定不是简单写“废墟城市”。

要写环境里的可见物和运动状态。

比如：

```text
场景：破败城市主干道，路面有积水和油污，旧汽车翻倒在路边，墙上有褪色海报，远处有倒塌的高架桥。空气中有灰尘和轻微烟雾，地面反射冷光，远处偶尔有火花闪烁。
```

这里的目的，是给模型提供可执行的画面元素。

“末日感”是抽象词。

“积水、油污、翻倒汽车、褪色海报、倒塌高架桥、灰尘、烟雾、火花”才是画面。

### 4. 声音设定

很多人写视频提示词会忘记声音。

但 Seedance 2 这类模型开始支持音频输入和视频生成关系后，声音设定会越来越重要。

你可以写：

```text
声音：不需要配乐，不要氛围音，仅保留同期声。保留脚步声、金属关节摩擦声、衣物摩擦声、远处风声、碎玻璃被踩碎的声音。声音要像现场录音，不要像后期配乐。
```

为什么要写“不需要配乐”？

因为很多模型会默认帮你“增强氛围”。

但如果你后期要自己配乐，或者你只想要现场感，那配乐反而会干扰。

尤其是多个画面要后期拼接时，声音更要提前控制。

### 5. 连续性设定

如果你要生成多个片段，后面自己剪辑，就一定要写连续性设定。

比如：

```text
连续性：本视频会拆成多个 5-8 秒镜头后期拼接。所有镜头保持同一角色外观、同一服装、同一城市环境、同一色调和同一时间段。每个镜头只完成一个明确动作，不要在单个镜头里加入过多剧情跳转。
```

这个设定很关键。

因为 AI 视频很容易每段都像一个新的世界。

你要提前告诉模型：这些镜头属于同一个视频。

### 6. 禁止项设定

基础设定里也可以放全局禁止项。

比如：

```text
全局禁止：不要卡通化，不要游戏界面，不要出现字幕，不要出现水印，不要角色换脸，不要服装变化，不要突然切到其他时代，不要加入现代汽车，不要出现霓虹赛博城市，不要加入配乐。
```

禁止项不要写得太泛。

要针对你这个视频最容易跑偏的地方写。

## 四、第二层：氛围与画质怎么写

氛围与画质这部分，建议按 5 个维度写。

```text
风格核心
视觉基调
色彩与影调
画面质感
镜头节奏
```

### 1. 风格核心

风格核心要一句话说清楚。

比如：

```text
风格核心：复古未来主义废土动作短片，真实摄影质感，紧张、压迫、粗粝，不要干净科幻感。
```

这里不要写太多方向。

如果你同时写“复古、梦幻、写实、赛博、宫崎骏、广告大片、纪录片”，模型就会混乱。

风格核心最好只保留一个主方向，最多加一个辅助方向。

### 2. 视觉基调

视觉基调是观众第一眼感受到的画面气质。

比如：

```text
视觉基调：画面带有战后废墟的压迫感，镜头贴近主体，背景有尘土和残破建筑，整体像一段从废土动作电影里截出来的追逐戏。
```

视觉基调要服务画面，不要写成抽象感想。

### 3. 色彩与影调

色彩与影调可以写得很具体。

比如：

```text
色彩与影调：低饱和度冷灰色主调，局部红色 LED 光作为视觉焦点。自然光和环境反射光为主，高光不过曝，暗部保留细节。画面有轻微胶片颗粒和旧镜头柔光感。
```

这类描述比“高级感”有用得多。

### 4. 画面质感

画面质感要解决“像不像真实拍摄”的问题。

比如：

```text
画面质感：真实摄影质感，金属表面有磨损和划痕，布料有灰尘和褶皱，皮革手套有旧化纹理，地面积水有真实反射。不要塑料感，不要过度光滑，不要像游戏渲染。
```

材质越具体，画面越不容易飘。

### 5. 镜头节奏

镜头节奏决定视频看起来是稳，还是急。

比如：

```text
镜头节奏：动作镜头节奏紧张，镜头可以轻微晃动，但不能混乱。主体始终清楚可见，运动模糊适度，避免过度晃动导致看不清动作。
```

动作戏尤其要写这个。

如果只写“高速追逐”，模型可能会给你一堆看不清的晃动画面。

## 五、第三层：画面内容怎么写

画面内容建议按分镜写。

每个分镜可以用这个结构：

```text
分镜编号：
时间段：
景别：
构图：
运镜手法：
画面内容：
声音：
后期备注：
```

### 1. 分镜编号

分镜编号不是形式主义。

它让你在后期沟通和修改时更清楚。

比如：

```text
分镜 01：机器人骑乘机械鸵鸟穿过废土街道
分镜 02：机器人上半身近景，机械鸵鸟颠簸
分镜 03：丧尸从街角冲出，机器人拔枪反应
```

后面如果某个镜头失败，你可以说“分镜 02 的颠簸太夸张”，而不是说“第二段好像不太对”。

### 2. 时间段

Seedance 2 这类模型很适合按秒数拆动作。

比如：

```text
时间段：0-7 秒
0-2 秒：机器人从画面下方进入。
2-5 秒：机械鸵鸟沿街道高速奔跑，背景快速后退。
5-7 秒：远处尸潮出现，镜头保持跟随。
```

时间段的作用是控制变化。

视频不是图片。

图片看的是一个瞬间，视频看的是过程。

### 3. 景别

景别决定观众看什么。

常用景别可以这样用：

| 景别 | 适合拍什么 | 提示词写法 |
|---|---|---|
| 大远景 | 世界观、环境规模 | 展示整条废墟街道和远处城市轮廓，人物只占画面很小一部分 |
| 全景 | 人物和环境关系 | 机器人和机械鸵鸟完整入画，能看到街道和追逐方向 |
| 中景 | 动作和身体 | 拍机器人上半身、武器、骑乘动作和身体颠簸 |
| 近景 | 表情、手部、局部动作 | 拍 LED 面部表情、手握武器、衣物和金属细节 |
| 特写 | 关键道具或情绪 | 拍枪口、屏幕表情、眼睛、按钮、血迹、碎玻璃 |
| 极近景 | 微表情或材质 | 拍 LED 屏幕像素、手套纹理、金属划痕 |

不要每个镜头都近景。

也不要每个镜头都大场面。

视频节奏要有呼吸。

### 4. 构图

构图要不要写，取决于这个镜头是否需要强控制。

这点很重要。

有些镜头需要写构图，比如：

- 主体必须在画面左侧。
- 道路作为引导线通向远方。
- 人物背对镜头，远处出现敌人。
- 对称构图制造压迫感。
- 前景遮挡制造偷窥感。

但有些镜头不需要写构图。

如果你把构图写得太死，模型可能会牺牲动作自然度。

比如高速追逐镜头，如果你强行要求“主体始终居中、三分法构图、道路形成完美引导线”，模型可能会为了构图稳定，让动作变得僵硬。

所以构图的使用原则是：

```text
需要稳定关系时写构图。
需要动作自然时少写构图。
```

可以这样写：

```text
构图：主体大致位于画面中心偏左，街道线条引导视线向远处尸潮，不要求严格对称，优先保证奔跑动作自然。
```

这就比“严格三分法构图”更稳。

### 5. 运镜手法

运镜要写清楚，但不要贪多。

常见运镜可以这样用：

| 运镜 | 适合场景 | 提示词写法 |
|---|---|---|
| 固定镜头 | 压迫、观察、稳定信息 | 固定机位，主体从画面远处跑近 |
| 跟拍 | 追逐、奔跑、主体行动 | 镜头跟随机器人向前移动，保持主体清楚 |
| 推镜 | 情绪加强、发现重点 | 镜头缓慢推进到机器人面部 LED 表情 |
| 拉镜 | 揭示环境、扩大空间 | 镜头从人物拉开，露出远处尸潮和废墟城市 |
| 摇镜 | 发现目标、转移注意 | 镜头从机器人摇向街角冲出的丧尸 |
| 移镜 | 横向运动、空间关系 | 镜头沿街道平移，展示机器人和尸潮距离变化 |
| 低角度 | 强化力量感 | 低角度拍机器人从镜头前方冲过 |
| 俯拍 | 展示路线和规模 | 高空俯拍街道，引导线通向远处尸潮 |
| 手持 | 紧张、真实、混乱边缘 | 手持跟拍，轻微晃动但主体保持清楚 |

运镜的核心是服务内容。

不要为了显得专业堆“推拉摇移跟”。

一个镜头最好只写一种主运镜。

### 6. 画面内容

画面内容是最容易写乱的地方。

建议按这个顺序写：

```text
主体在哪里
→ 主体正在做什么
→ 环境发生什么
→ 情绪或氛围是什么
→ 哪些设定要再次强调
→ 哪些东西不要出现
```

比如：

```text
画面内容：机器人骑在机械鸵鸟背上，从画面下方进入废土街道。机械鸵鸟沿着笔直公路高速奔跑，脚步踩过积水和碎玻璃，带起灰尘。机器人左手抓紧缰绳，右手按住牛仔帽防止掉落，面部 LED 屏幕保持红色愤怒表情。远处尸潮缓慢出现，背对镜头涌入街道。画面保持废土危机感，不要出现现代车辆和霓虹灯。
```

这段里，有动作、有环境、有角色状态、有世界观重复、有禁止项。

这样模型就不容易跑偏。

## 七、示例：废土机器人追逐片段

下面用你图里的方向，整理一版更规范的中文提示词。

```text
【基础设定】
世界观：1960 年代复古未来主义废土世界。大战后的城市主干道，街道破败，旧汽车翻倒，墙上有褪色海报，路面积水和油污反射冷光。整体不是现代赛博朋克，而是复古科幻、末日废土和动作片追逐戏的结合。

主角设定：身形修长的人形机器人，拥有自主意识。面部是老式 LED 屏幕，屏幕显示简单静态表情，不做夸张动态表情。穿复古西装外套、黑色皮革手套、腰间工具带。动作敏捷，但关节有轻微机械停顿感。

敌人设定：街道上有行动迟缓的丧尸群，皮肤灰白、衣物破旧、动作不协调。丧尸不需要有复杂表情，主要作为压迫性的环境威胁。

场景设定：废土城市街道，远处有倒塌高架桥、残破路灯、碎玻璃、旧报纸、灰尘和轻微烟雾。空气浑浊，地面有积水和油污。

声音设定：不需要配乐，不要氛围音乐，仅保留同期声。保留机械鸵鸟奔跑声、金属关节摩擦声、碎玻璃被踩碎的声音、远处风声、丧尸低吼声。

连续性设定：本视频会拆成多个镜头后期拼接。所有镜头保持同一主角外观、同一废土街道、同一冷灰色调和同一追逐方向。

全局禁止：不要现代霓虹城市，不要游戏界面，不要字幕，不要水印，不要主角换脸，不要服装变化，不要突然出现现代汽车，不要卡通化。

【氛围与画质】
风格核心：复古未来主义废土动作短片，真实摄影质感，紧张、压迫、粗粝。
视觉基调：画面像一段废土动作电影里的追逐戏，镜头贴近主角，背景残破，远处尸潮逐渐逼近。
色彩与影调：低饱和度冷灰色主调，局部红色 LED 光作为视觉焦点。自然光和环境反射光为主，高光不过曝，暗部保留细节。
画面质感：金属有磨损和划痕，布料有灰尘和褶皱，皮革手套有旧化纹理，地面积水有真实反射。不要塑料感，不要过度光滑，不要像游戏渲染。
镜头节奏：动作紧张，镜头可轻微晃动，但主体始终清楚可见。运动模糊适度，不要晃到看不清动作。

【画面内容】
分镜 01：机器人骑乘机械鸵鸟穿过废土街道
时间段：0-7 秒
景别：全景到中景
构图：主体大致位于画面中心偏左，道路线条引导视线向远处尸潮，不要求严格对称，优先保证奔跑动作自然。
运镜手法：手持跟拍，镜头跟随机器人和机械鸵鸟向前移动，轻微晃动。
画面内容：机器人骑在机械鸵鸟背上，从画面下方进入废土街道。机械鸵鸟沿着笔直公路高速奔跑，脚步踩过积水和碎玻璃，带起灰尘。机器人左手抓紧缰绳，右手按住牛仔帽防止掉落，面部 LED 屏幕保持红色愤怒表情。远处尸潮缓慢出现，背对镜头涌入街道。画面保持废土危机感，不要出现现代车辆和霓虹灯。
声音：只保留机械奔跑声、金属摩擦声、碎玻璃声、远处尸潮低吼声，不要配乐。
后期备注：这一镜头作为开场，结尾保持机器人继续向前冲的运动方向，方便接下一镜。

分镜 02：机器人上半身近景，机械鸵鸟剧烈颠簸
时间段：0-6 秒
景别：中近景
构图：机器人上半身和机械鸵鸟颈部占画面主体，背景街道快速后退。构图不要太死，优先表现颠簸和速度。
运镜手法：固定在主体附近的跟拍镜头，随机械鸵鸟奔跑产生轻微上下颠簸。
画面内容：机械鸵鸟高速奔跑，机器人身体随节奏上下晃动。LED 面部屏幕保持冷酷蓝色表情，但身体动作显得有些狼狈。机器人一只手抓紧缰绳，另一只手压住帽子，肩膀和腰部跟随颠簸起伏。背景中的废土街道快速掠过，带有动态模糊。
声音：机械鸵鸟脚步声更近，金属关节声更明显，保留机器人轻微电子机械音，不要配乐。
后期备注：这一镜头接分镜 01，用近景增强速度感和喜剧反差。

分镜 03：丧尸从街角出现，机器人准备反击
时间段：0-8 秒
景别：中景到近景
构图：前半段机器人在画面右侧，街角在画面左侧；后半段镜头推向机器人面部和右手动作。
运镜手法：先跟拍，再轻微推镜到机器人面部和手部。
画面内容：街角突然冲出几只丧尸，动作笨拙但压迫感强。机器人短暂停顿，LED 屏幕从冷酷表情切换成红色警觉表情。它右手摸向腰间武器，左手仍然控制机械鸵鸟方向。机械鸵鸟没有停下，而是侧身躲开路障。镜头不要切太碎，要让观众看清机器人发现威胁、判断方向、准备反击的过程。
声音：丧尸低吼声靠近，金属关节声和脚步声混在一起，保留现场混乱感，不要配乐。
后期备注：这一镜头作为动作升级点，结尾可以接开枪、闪避或转向镜头。
```

## 八、什么时候不要写太细

提示词不是越长越好。

有些地方写太细，反而会把模型锁死。

### 1. 动作镜头不要过度固定构图

高速运动、追逐、打斗、奔跑，这类镜头最重要的是动作自然。

如果构图要求太硬，模型可能会为了构图牺牲运动。

所以这类镜头可以写：

```text
主体大致保持在画面中心附近，优先保证动作自然和速度感，不要求严格对称构图。
```

### 2. 情绪镜头可以写细一点

人物表情、眼神、手部小动作，可以写得更细。

因为情绪镜头的变化幅度小，模型需要明确知道哪里动。

比如：

```text
眼神先看向对方，随后短暂闪开；嘴角想上扬但被压住；手指轻轻捏紧衣角。
```

### 3. 参考图强时，不要重复写冲突设定

如果你已经上传了角色参考图，就不要在文字里写一堆可能和参考图冲突的外观描述。

更稳的写法是：

```text
主角外观以参考图为准，文字只补充动作、情绪、镜头和场景。
```

### 4. 多镜头不要塞进同一个生成任务

如果一个视频有 6 个镜头，不要全部塞进一个 15 秒生成任务里。

可以先拆成：

```text
每次生成一个镜头
→ 保持基础设定一致
→ 后期拼接
→ 失败镜头单独重跑
```

这比一次性生成完整故事更稳。

## 九、视频提示词自检表

写完提示词以后，可以过一遍这张表。

| 检查项 | 问题 |
|---|---|
| 世界观 | 这个视频发生在什么世界？有没有排除错误风格？ |
| 角色 | 主角外观、材质、动作方式是否稳定？ |
| 场景 | 环境是不是有可见物，而不是只有抽象氛围？ |
| 声音 | 是否说明要不要配乐、是否只保留同期声？ |
| 连续性 | 多个镜头是否保持同一角色、色调、时间段？ |
| 风格 | 氛围与画质是否具体，而不是只写电影感？ |
| 景别 | 每个镜头观众应该看什么？ |
| 构图 | 这个镜头是否真的需要固定构图？ |
| 运镜 | 主运镜是否清楚？有没有堆太多运镜？ |
| 内容 | 主体动作、环境变化、情绪氛围是否写清楚？ |
| 禁止项 | 最容易跑偏的东西有没有提前排除？ |
| 后期 | 是否给后期拼接留下方向、动作或剪辑点？ |

## 十、我的实战判断

Seedance 2 之后，视频提示词最重要的变化不是“词汇变高级”。

而是创作者的位置变了。

你不再只是一个写描述的人。

你更像一个小导演。

你要知道这个世界是什么，角色是谁，镜头怎么拍，声音怎么处理，后期怎么接，哪些地方必须锁住，哪些地方可以让模型自由发挥。

所以未来好的视频提示词，不会只是漂亮。

它应该清楚、可执行、可复用、可修改。

我觉得可以用一句话概括：

```text
一份好的 AI 视频提示词，不是让模型知道你想要什么，而是让模型知道它应该如何拍出来。
```

这就是 Seedance 2 带来的真正变化。

它逼着我们从“提示词玩家”，慢慢变成“AI 视频导演”。

## 十一、后续可以继续沉淀的资产

这篇文档只是第一版。

后面可以继续拆成几份更细的资产：

1. `Seedance 2 分镜提示词模板库`：按动作戏、口播、MV、剧情、产品展示分类。
2. `AI 视频镜头语言词典`：景别、构图、运镜、光线、色彩的中文提示词写法。
3. `AI 视频失败案例库`：每次生成失败后记录“为什么失败”，比如构图太死、动作太多、声音没写清楚。
4. `多镜头后期拼接规范`：统一角色、色调、运动方向、镜头衔接和声音处理。
5. `老胡 AI 音乐 MV 提示词规范`：专门服务 AI 音乐视频，把歌词情绪、画面分镜、人物表演绑定起来。

这件事不是一次写完。

它应该像内容系统一样，越用越准。

以后每次生成一个视频，不要只问“好不好看”。

要问：

```text
它哪里没按设定来？
是世界观没锁住？
是画质氛围太泛？
是镜头目标不清？
是构图写太死？
是运镜太乱？
是声音没说明？
还是后期拼接没有预留？
```

这些问题记录多了，才会变成真正属于你的 AI 视频提示词规范。
