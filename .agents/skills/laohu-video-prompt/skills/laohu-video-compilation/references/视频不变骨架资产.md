## 1. 不变骨架资产

不变骨架资产是 AI 视频提示词成立的固定容器。

### 1.1 三层结构固定槽位

正式视频提示词的固定结构：

```text
【基础设定】
实际资产：
声音总策略：
输出限制：（按需，只写少量抽象边界）

【场景状态与氛围画质】
开拍前场景状态：
全段风格 / 摄影介质 / 宏观色彩：

【画面内容】
【镜头01｜景别｜机位 / 视角｜运镜 / 转场】画面描述。
【VFX】按需。
【环境音】按需。
【动作音】按需。
【音乐 / 节拍】按需。
【台词】角色名（表演）：“原文”。（按需）
```

三层职责必须区分：

```text
基础设定：
实际输入、声音总策略和少量抽象输出限制，不复述当前剧情。

场景状态与氛围画质：
先固定开拍前已经成立的空间、人物、道具、天气、人群和现有破坏，再固定画面风格、摄影介质、色彩影调和全片审美边界。

画面内容：
用连续编号镜头块写本镜发生的动作、表演、光影变化、逐镜声音、环境交互和转场；编号只标顺序，不绑定逐秒时间码。
```

### 1.2 单条独立生成固定槽位

AI 视频平台默认不读取上一条提示词。每条提示词都要自足。

单条生成前要逐项判断下列信息，只有本镜实际需要的内容才进入正文。`确定时长`、实际调用资产和核心变化通常不可缺；其余为条件项：

```text
确定时长
生成画幅
本镜实际调用资产
本镜人物状态
本镜声音状态
景别
机位
运镜
构图落点
动作起点
动作过程
动作结果
光影来源
声音来源
焦点落点
镜头停点
与上一条 / 下一条的片内衔接
```

### 1.3 镜头预演板条件槽位

镜头预演板默认给人确认构图、站位、动线和留白，不默认投喂视频模型，也不强制每条视频提示词配套。只有构图、比例、复杂走位、空间方向或高成本生成风险需要先验证时才制作；简单固定镜头或已有可靠首帧时可以省略。

需要预演板时，从下列槽位选择必要信息：

```text
参考资产
首帧参考
时间点 / 关键帧
线框构图
构图规则
景别 / 机位
空间锚点
引导线 / 动线路径
主体比例与位置
```

预演板只锁人工需要确认的构图、站位、动线、比例和视线，不锁真实脸、服装颜色、材质和最终光影；视频提示词控制真实外观、表演、声音和时间变化。只有明确把干净首帧或构图参考图作为模型输入时，才将其转换成无表格、无箭头、无文字的参考图。

### 1.4 视频质量路径

一条高质量 AI 视频通常按以下路径成立：

```text
第一个画面：
主体、景别、构图、光源和情绪起点立刻清楚。

第一个动作：
人物或镜头有明确起点，动作能在真实空间里排练出来。

第一个变化：
表情、声音、光影、道具或环境触发可见变化。

第一个停点：
在识别、动作、情绪或剪辑任务完成处留下可读状态；只有本镜承担视觉记忆职责时，才把它设计成可截图的审美停点。

下一条起点：
只有本条需要连续拼接时，尾帧才留下足够的姿态、方向、光源、声音或动作锚点供下一条承接；独立素材不强制。
```

视频提示词先服务主观看任务和主情绪，再按需服务生成稳定、表演、声音与剪辑。画面美感、时间变化、动作、停点和光影没有独立完成分，只保留真正承重的部分。

### 1.5 情绪识别与观众代入

主情绪清楚只保证观众看懂人物，不保证观众进入人物。高质量叙事视频要根据段落职责，从以下六条路径中选择真正承重的部分：

```text
目标与代价：人物想得到什么，失败会失去什么，观众为什么替他在乎。
信息对齐：观众与人物同时发现、提前知道还是晚一步理解。
空间对齐：危险、出口、距离、遮挡、视线和动作方向是否可感。
身体对齐：呼吸、重心、受力、速度、触感、声场和环境反馈是否形成身体经验。
时间对齐：等待、逼近、触发、冲击和余波是否被观众亲历。
选择对齐：观众是否跟随人物做决定并看到代价。
```

六条不是逐镜必填。一个段落可以先用客观远景建立空间，再用近主观或声音把观众拉近，在关键动作中共享受力，最后用固定镜头或拉远让后果沉淀。全程 POV、特写、手持、快速剪辑和强音效会造成空间丢失与感官疲劳；距离变化和节奏呼吸也是代入设计。

### 1.6 时间密度诊断尺

视频和图片最大的差别是时间。不同长度承载不同的信息量。

3、5、8、12、15 秒只表示不同预算，不对应固定动作数量或情绪结构。先估算主体识别、动作完成、情绪进入、效果展开和剪辑接口需要多少知觉时间；预算不足就删任务、压缩过程或拆素材，预算充足也不为填满时长添加动作。表情停留由变化幅度、景别、台词、角色克制程度和观众识别速度决定，不统一规定 0.5 秒、1 秒或其他固定值。
