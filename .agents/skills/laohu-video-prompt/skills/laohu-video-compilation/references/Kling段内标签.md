# Kling 段内标签

明确使用可灵/Kling 时读取。只把角色命名、对白区隔和镜头引用装入固定三段式，不改成五层外壳，不把参考项目的 P1—P4 方法编号当成平台参数或项目 P 编号。

## 基础设定中的角色

使用 `[Character A: 名称；本条需要的稳定辨识；参考角色与范围]` 这类简短角色声明；当前 P 后续保持同一别名，不在“红衣女孩/少女/Character B”之间漂移。角色声明是本项目可读约定，不假定它自动创建平台的角色资产或声线绑定。

已有真实角色/元素 ID 时，在操作清单保留实际 ID 和文件对应；正文别名与平台 ID 是两层关系。没有实际素材的文生任务可以定义文字角色，但不能登记成已上传参考。

## 场景与镜头

场景、开拍前状态和全段成像写在第二段；镜头、动作和声音在第三段按 C 方头展开。沿用唯一 C 编号，不并排建立另一套 Shot 1/Shot 2 编号。每镜把景别、主体、动作和结束状态写清，不为满足“必须有运动”破坏有目的的静止观察。

需要入口的 Multi-Shot/Custom Multi-Shot 等模式时，由已核验能力合同记录实际选择和必要镜头参数；提示词里写 C 或硬切，不证明界面/API 已开启该能力。没有核验入口时保留文本方案，不编造模型特定镜头数、时长或已启用状态。

## 对白与画外音

在人物动作中写：`Character A 以已确认的普通话声线对 Character B 说：“原台词。”`。引号只包冻结台词，语言、演法、声线与声源在外；人物继续完成当句触发、听者回应和话后动作。

对白来源、口型是否可见与镜头观看对象分开。需要读唇的正面对白保护嘴部可见；明确的反应镜头、画外对白或声音桥允许不拍嘴，不能把“对白必须永远拍说话人”当成铁律。长画外音优先用适合本场的背面、遮挡、手部、道具或环境观看降低误口型风险，但不机械隐藏所有脸。

## 约束与检视

只写当前任务需要的风险约束；不默认排除动画、3D、非写实风格，不追加一整串反畸形负面词。人物/道具状态、视线、轴线、运动相位和声音归属沿用专业方法。

检视确认角色别名一一回指、冻结台词一致、没有串入 H3 引用标签或 Seedance 音效括号、模式与实际入口一致、所有 C 内容可执行；标签和自然语言版之间的效果差异要通过同输入实验判断。
