# 视频注意力与时间编译

用于把已确认的P内容展开成声画时间因果；通用注意力与必要信息保护由本包已有通用方法共同执行。本文件保留视频特有的时间竞争、图生与文生差异、多主体绑定和可见动作控制。

## 四、视频提示词的注意力编译

### 0. 图片把因果压成一帧，视频把同一因果展开

图片阶段已经验证有效的内核可以进入视频，但不能原样复制静态细节。两者共同回答：唯一任务是什么、观众先看哪里、什么证据证明它、作品怎样成像、哪些信息主动退让。图片把`过去痕迹 / 当前关系响应 / 下一趋势`压进一个事件临界帧；视频把它展开为`可读起点 / 精确触发 / 变化传播 / 决定性结果 / 即时影响 / 余韵停点`。

跨图片与视频的共性按职责迁移：

| 图片中已经成立的能力 | 视频中的等效能力 | 不能误迁移成什么 |
|---|---|---|
| 作品结果图成像合同 | 全段稳定成像基线及合法阶段变体 | 每镜重新选风格、滤镜、导演或调色 |
| 单一第一落点 | 第一落点到决定性落点的注意力迁移 | 人物、摄影机、环境、特效和声音同权运动 |
| 单帧关系与未完成动作 | 人物目的、关系对象、触发后的行动策略 | 让人物只负责跑、转头、微笑或摆姿势 |
| 足以辨认本次变化的承重生命通道（单一通道可以成立） | 触发后异步传播的表演、衣发、道具、环境与声音 | 全身全部部位同时变化 |
| 主构图、主光与景深托举 | 构图重组、焦点迁移、光线变化共同跟随注意力 | 每帧都做壁纸构图或无因动态光 |
| 必须锁定 / 方向引导 / 模型补全 | 稳定锚点、主变化、开放的次级运动分别控制 | 把图片设计全文重新投喂给图生视频 |

视频增加的不是更多字段，而是状态变化和不可换序。先保证时间零点作为画面能够成立，再只改变本段必须改变的部分；决定性时刻可以获得最高构图、表演、光色和声音预算，连接相位允许不完整、遮挡、模糊和普通。所谓“输入决定输出”只在高权重起点、身份、构图和成像方向上成立；输入图不能替视频正文决定人物为什么动、变化何时发生、结果怎样留下。

### 1. 视频比图片多一个时间竞争

视频同时处理每帧的空间身份与跨帧运动。文本不只要回答`是什么`，还要回答`谁在何时为什么变化，变化最后兑现什么`。每个生成单元先只设一个主要兑现，按需最多一个明确从属的次要兑现。动作、摄影机、环境、特效和声音若同时成为主变化源，模型容易丢失身份、运动路径或后半段指令；它们应分别承担铺垫、触发后兑现或结果余韵。

每个镜头先选一个主变化承载者：人物、物体、摄影机、环境、VFX、图形或声音。其余层稳定、延迟响应或只证明结果。多项变化必须形成因果或时间顺序，不能并排要求。

```text
动机 / 起点状态 → 铺垫与早期证据 → 精确触发 → 主变化与阻力 → 主要兑现 → 即时结果 → 余韵 / 稳定停点
```

这条链是时序因果，不是强制逐秒切段。一个镜头可以连续完成相邻两个相位，多个镜头也可以共同铺垫一次兑现；但换序后如果力量不变，就说明时间链没有完成。

### 2. 文生视频与图生视频分开

- 文生视频：提示词同时负责主体、场景、风格、构图和运动，因此先建立简洁空间基线，再写主动作与摄影机。
- 图生视频：输入图已经强力提供主体、构图、色彩、光线和风格；正文主要描述主体动作、环境运动、摄影机运动、速度、方向、时序与结束状态。重复大段静态外观会与动作争夺注意，甚至诱发模型重新解释人物。
- 首尾帧 / 多参考：分别写清每张输入控制身份、结构、状态、构图还是结束目标；同一属性只允许一个主参考。参考图之间冲突时，文字声明未必能完全抵消视觉输入，先修参考组合。

### 3. 多主体按位置和动作分别绑定

不要连续堆叠多人的服装、情绪和动作后统一写“他们”。用屏幕位置、外观短识别词或关系角色逐一绑定：

```text
左侧小师妹先转头看向右后方的大师兄；她说完后仍保持前倾。右后方大师兄只抬眼，擦剑的手在听见最后一个词时停一拍。
```

主体数量越多，单镜头动作越要减少。每增加一个承重人物，都必须有世界位置、屏幕位置、注意对象、动作触发和结束状态；不能满足时拆镜头或使用调度参考。

### 4. 抽象情绪只作为方向，动作承担执行

`悲伤、紧张、强大、轻盈、魅惑`可以概括方向，但必须由可见 / 可听变化执行：眼线、呼吸、嘴角、肩颈、手部、重心、距离、语速、音量和环境响应。视频模型尤其需要物理动词、方向、速度、幅度、参照物和停点；`衣摆迟半拍`必须说明相对身体哪次转身、沿什么方向扫过、何时回落。
