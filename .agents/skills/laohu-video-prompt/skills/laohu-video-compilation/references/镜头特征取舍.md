# 镜头特征取舍

当前 P/C 需要比较“这条提示词靠什么承重、命中哪些特征”时读取。它继承上游已经成立的故事、台词、资产、时长和真实输入，只在开放特征位置做取舍；已有有效取舍直接继承，不重新设计镜头任务，也不在本文件重新决定专业机制、时序编译、模型规则、模板和词汇。取舍结果什么时候算合格按检视包的[镜头特征质量验收](../../../../laohu-inspection/skills/laohu-video-prompt-inspection/references/镜头特征质量验收.md)判断。

## 基本取舍

**骨架强制、特征择优。** 骨架是固定容器：AI 视频提示词天然需要的结构、时长、资产引用、镜头语言、声音、画面内容和故事板关系。特征是开放位置的可选基因：能在视频里被看见、听见、生成、剪辑、拼接和复盘的镜头机制。一条高质量提示词不需要命中全部特征；它更像一组导演基因，承重位置命中少数关键特征，生成结果就会明显脱离平均视频；多个特征在基础设定、氛围画质、画面内容和声音里互相支撑，作品上限才会继续抬高。

**正向导演收束。** 优先描述目标视频已经成立后的可见、可听、可剪辑状态，用镜头距离、人物表演、声音态度、光影变化、时间密度、故事板构图、资产调用和首尾帧衔接共同收束生成范围，而不是罗列要避免的失败。

**承重优先。** 一条视频优先服务一个主镜头任务，辅助特征服从主任务。看脸、展示动作、交代空间、制造转场按主次排列；最多保留一项明确从属的次要结果。

**特征交集。** 每个字段负责一个导演维度，多个维度交叠后形成清楚的生成坐标；交叠用于缩小高质量区域，不是要求所有维度同时出现。特征越细、越具体、越能组合，能圈住的高质量区域就越小，成片越有机会接近真正可生成、可剪辑、可复盘、可发布的影像作品。

## 承重维度

以下五个维度按当前输入条件选择，不是每条提示词都要命中：

```text
生成承重：
独立完整、资产引用准确、时长确定、画面内容可执行。

表演承重：
人物目的、保护策略、触发、承重表演通道、禁止提前反应和结束余韵；复杂节拍内部完成八维判断。本镜没有人物表演时本项不适用，不强求脸部证据。

画面承重：
从构图、点线面、光影、色彩、景深和材质中选择真正传递主情绪或信息的关系，不要求全部出现。

剪辑承重：
连续素材按需选择首尾帧复用、转场锚点、声音桥、动作接力或情绪连续；独立素材不强造上下条关系。

复用承重：
提示词的构图、表情、光影、时长、资产、声音和动作因果都能被下一次创作继续调用。
```

机位与运镜同样按条件成立：固定机位只锁摄影机位置、视轴和构图边界，不因此强求机身运动；运镜只有在改变观看关系、注意力落点或空间结果时才展开为观看意图、物理路径、屏幕变化、情绪倾向和停点。

## 条件组合

以下七组是输入条件下的候选，不是所有风格与情绪的固定配方。命中哪一组由当前主任务、题材、人物情绪和观看位置决定；可以只取其中几项，也可以全部不取而另建组合。

```text
情绪近景：
舒适近景、眼线回到镜头、单一主情绪、脸部证据、声音触发、停住一拍。

崩溃特写：
脸部近景、呼吸断点、眼眶水光、声音哽住、暗部保留肤色层次、尾帧留下泪痕。

失魂远景：
人物缩小、环境变大、高机位或远景、走路无力、风景留白、声音衰减。

热恋期待：
胸部以上中近景、眼神变亮、身体微微前倾、暖白肤色、浅景深、声音亲近。

强撑理解：
舒适近景、礼貌嘴角、眼眶水光、短促吸气、声音放轻、镜头停住读脸。

评论钩子：
人物回到镜头、胸部以上中近景、眼神疲惫但清醒、声音靠前、背景简洁、留白干净。

一镜到底衔接：
首尾同构图、同光源、同姿态、同背景锚点、同声音桥、同情绪余韵；只在任务确实选择首尾帧复用或一镜到底感方案时成立。
```

## 组合语法

维度之间的关系决定它们是共同服务一个时间结果，还是同权堆叠：

```text
镜头任务唯一：
一条提示词优先只有一个主任务。看脸、展示动作、交代空间、制造转场按主次排列。

强位互证：
主情绪与被选中的景别、声音、构图、光影或停点互相证明，不要求所有通道同时承担。

声音触发表情：
如果 VO 是核心，声音曲线和脸部变化必须绑定。

画面服务剪辑：
需要进入同一连续段落的素材才和上下条形成明确接续；独立空镜、可替换素材和单条成片按自身用途设计起止状态。

美感服务剧情：
光影、色彩、留白和运镜让人物处境更清楚、情绪更强。
```
