## 3. 人物表演审美特征资产

### 3.1 通用基底

高质量人物表演要把“开心、伤心、生气、温柔”这类情绪标签展开成触发、起始状态、变化路径、身体证据、声音证据和结束状态。

### 3.2 特征颗粒

```text
主情绪单一：
单条提示词只承担一个主情绪，最多带一个过渡情绪。

触发明确：
表情变化来自一句 VO、一个动作、一个道具、一个眼神或一个空间变化。

脸部证据：
眼神、眼睑、眉心、嘴角、嘴唇、下巴、鼻翼、吞咽、呼吸、眼眶水光。

身体证据：
肩颈松掉、背部僵住、身体后撤、微微前倾、头部偏开、重心不稳。

声音证据：
气口、停顿、音区、响度、咬字、尾音、哭腔、沙哑、电话失真、脑内回响。

结束状态：
本镜最后留下一个可接下一镜的情绪余韵，例如笑意没收住、眼眶红了、身体空掉、视线回到镜头。
```

### 3.3 情绪表演颗粒

人物情绪要写成可见变化路径。

```text
防备：
眼神先停住，眼睑略收，嘴角保持平直，身体微微后撤，肩颈有一点僵。

好奇：
视线重新聚焦，眉心松开，头部轻微前倾，呼吸变浅，眼里出现细小高光。

不屑：
嘴角单侧轻抬，眼神短暂下扫，再回到镜头，表情短促收住。

期待：
眼神变亮，嘴唇轻抿后松开，肩颈微微向前，身体重心靠近镜头。

强撑：
下巴轻抬，嘴角保持礼貌弧度，眼眶有水光，呼吸比表情更先乱。

委屈：
下唇压住，鼻翼轻动，眼眶慢慢发红，短促吸气后低头半秒。

被击穿：
眼神失焦，呼吸断一下，肩颈松掉，泪水从眼眶边缘滑出。

疲惫：
眼皮变沉，嘴角失去支撑，身体重心下坠，视线回到镜头时带着空感。
```

表演颗粒要和镜头距离匹配，但没有固定映射。需要读微表情时可以靠近，也可以用高分辨率中景、镜面反射或遮挡观察；身体崩塌和失魂离开通常需要更多空间，也可以用局部特写表现。选择取决于本镜主情绪与观看关系。

### 3.4 关系距离特征

```text
舒适近景：
当镜头要让观众处在平等、可读但不过度逼近的关系里，可以保留脸、肩颈和少量环境；人物占比由距离感和证据大小倒推。

脸部近景 / 特写：
当局部表情、皮肤、眼泪、嘴唇或信息遮蔽承重时可以使用；亲密、威胁、审讯、喜剧或冷静观察都可能成立。

远景 / 全景：
当空间、距离、群体、路径或人物与环境比例承重时可以使用；它也可以表现自由、秩序、喜悦或事实说明，不固定等于孤独。
```

看清表情不等于怼脸。镜头距离本身就是关系表达。

### 3.5 镜头距离正向资产

```text
胸部以上中近景：
同时需要脸部证据、肩颈动作和少量环境关系时使用。

舒适近景：
需要可读表情且保持不过度逼近的观看关系时使用；不固定人物百分比。

脸部近景：
需要局部表情、身份或质感证据时使用；保留多少脸侧空间由构图与主情绪决定。

眼部 / 唇部特写：
局部本身承担信息、动作或主情绪时使用；时长与停点由可读性和节奏倒推。

半身景：
同时需要身体重心、手部、服装或人物距离时使用；是否保持脸部清晰由主注意力决定。

远景 / 高机位全景：
需要空间结构、路径、群体秩序、尺度或距离关系时使用，不绑定固定情绪。
```

镜头距离要服务观众和人物的关系。对话可以舒适、逼近、疏离或被遮挡；情绪破裂可以贴脸，也可以让环境突然变大；人物离开可以用远景，也可以只留下局部空位。选择由本镜主情绪和证据位置决定。
