# 人物表情与肢体动作词典

本词典是观察入口，不是情绪配方。不能看见“愤怒”就整行照搬，也不能把某个 AU 直接当作情绪。先确定人物目的、保护策略、触发和镜头距离，再从真正承重的部位选择动作。

AU 不是情绪公式。FACS 描述可观察的面部动作，不负责单独判定人物情绪；FACS A-E 强度与 OpenFace 等工具的 0-5 输出不得混写或机械换算。

## 一、观察通道

| 通道 | 可观察内容 | 常见控制问题 |
|---|---|---|
| 眉区 | 内眉 / 外眉抬起，眉间下压、靠拢或放松 | 双眉同时拉满容易符号化；先判断是否对称、是否渐变 |
| 眼睑与眼周 | 上眼睑抬起、眼睑收紧、脸颊抬起、眨眼、眼眶水光 | 眼睛睁大不只属于恐惧，也可能是警觉、惊讶或努力看清 |
| 目光 | 直视、追视、失焦、下落、短暂躲开、重新看回 | 目光必须有对象；不要无原因看向天空、远处或镜外 |
| 鼻翼与鼻部 | 鼻翼张开、鼻部皱起、呼吸带动鼻翼变化 | 适合短促峰值，不宜全程固定 |
| 嘴角与嘴唇 | 嘴角上提 / 下压、单侧变化、压紧、收紧、分开、吸入 | 嘴角和眼周可以不一致，形成礼貌笑、苦笑或强撑 |
| 下巴与下颌 | 下巴绷紧、抬起、轻颤，下颌下落或咬住 | 下颌张开要与发声、喘息或冲击同步，不能无声持续张口 |
| 呼吸与吞咽 | 吸气中断、短促换气、胸口起伏、吞咽、呼气泄掉 | 呼吸变化常是情绪转折的早期证据，比眼泪更自然 |
| 肩颈与躯干 | 肩线抬起 / 下沉、颈部僵住、胸腔前顶 / 塌下、身体旋开 | 身体要服从人物行动，不要与脸部情绪互相抵消 |
| 手与重心 | 攥、压、松、抓、遮、擦，重心前移 / 后撤 / 锁住 | 手部动作要有道具、身体或空间接触对象 |
| 关系距离 | 逼近、退让、停在边界、绕开障碍、背抵墙面 | 距离变化应由关系动作触发，不为“戏剧感”乱走位 |
| 声音 | 音区、响度、语速、咬字、重音、气息、尾音、停顿 | 先写说话态度，再选声学形态；不能只堆参数 |

## 二、常用 FACS 动作单元

| AU | 自然语言动作 | 使用提醒 |
|---|---|---|
| AU1 | 内眉抬起 | 可参与痛苦、担忧、请求等多种状态，不等于悲伤 |
| AU2 | 外眉抬起 | 常与惊讶、强调或警觉有关，结合眼睑和下颌判断 |
| AU4 | 眉毛向下、眉间内收 | 可参与专注、愤怒、痛苦或强光反应，不单独命名情绪 |
| AU5 | 上眼睑抬起 | 增加眼白可见，需区分惊讶、恐惧、警觉和注视用力 |
| AU6 | 脸颊抬起 | 可与真实笑、眯眼或用力有关，结合 AU12 和上下文 |
| AU7 | 眼睑收紧 | 可参与愤怒、疼痛、集中注意或克制 |
| AU9 | 鼻部皱起 | 常见于厌恶或强烈感官刺激，通常短促出现 |
| AU10 | 上唇抬起 | 可参与厌恶、轻蔑或发声动作，结合对称性判断 |
| AU12 | 嘴角向上拉 | 笑的常见动作，但眼周、声音和身体决定笑的性质 |
| AU14 | 嘴角收紧并形成酒窝状 | 可参与轻蔑、忍笑或控制嘴角 |
| AU15 | 嘴角向下 | 可参与悲伤、失望或刻意压住嘴角 |
| AU17 | 下巴抬起、颏部绷紧 | 常用于压住嘴唇、忍哭或咬住反应 |
| AU20 | 嘴角向两侧拉伸 | 可参与恐惧、紧张或某些发音，不等于恐惧 |
| AU23 | 嘴唇收紧 | 常用于压怒、控制发声或集中用力 |
| AU24 | 双唇压紧 | 适合“把话压回去”，与 AU23 需按可见结果区分 |
| AU25 | 双唇分开 | 可能是发声、吸气或反应起点，需要声音和下颌配合 |
| AU26 | 下颌下落 | 可参与说话、惊讶、喘息或爆发发声 |
| AU27 | 嘴部大幅张开 | 强度高，只有明确喊叫、冲击或极端反应时使用 |
| AU28 | 嘴唇向内吸 | 可参与抑制发声、紧张或思考状态 |

AU 的名称只说明可见动作。正式提示词优先写自然语言，AU 放在括号中辅助；通常 1-3 个承重 AU 已足够。

## 三、强度、时序与不对称

```text
强度：轻度可辨 → 中度 → 明显 → 短促峰值 → 接近个体最大。
FACS字母：A 最弱可辨，E 接近个体最大；不与 OpenFace 0-5 工具输出混写。
时序：出现 onset → 增强 → 峰值 apex → 减弱 offset。
不对称：单侧嘴角、单侧眉峰、头部偏转和目光偏离可表达关系态度，但必须有角色与场景原因。
```

不要让所有部位同一帧开始、同一强度到峰值、同一帧恢复。真实表演可以先呼吸停住，再眼睑收紧，最后嘴唇压住；也可以声音先失控，脸部随后重新收住。

## 四、情绪方向的候选证据

以下只提供候选，不提供固定组合：

| 情绪方向 | 可能的脸部证据 | 可能的身体 / 声音证据 | 需要先问 | 可接的动作链通道 |
|---|---|---|---|---|
| 喜悦 | 眼神变亮、嘴角上提、脸颊抬起 | 身体靠近、动作变轻、声音打开 | 是分享、得意、释然、讨好还是忍笑 | 口角、掩饰修复、眼线 |
| 悲伤 | 内眉抬起、嘴角下压、下巴绷紧、眼眶水光 | 呼吸卡住、肩线下降、声音变轻或断掉 | 人物在求助、隐藏、告别还是已经放弃 | 呼吸、吞咽、下颌、余波 |
| 愤怒 | 眉间下压、眼睑收紧、嘴唇压紧、鼻翼变化 | 身体前压、重音变硬、动作缩短或突然停住 | 是争取控制、保护尊严、恐吓还是掩盖受伤 | 下颌、手指、中止动作 |
| 恐惧 | 上眼睑抬起、嘴唇拉伸或分开 | 身体后撤、重心变轻、呼吸变浅、声音失稳 | 人物是否已经看见危险，能否逃，是否必须装镇定 | 眼线、肩背、替代动作 |
| 惊讶 | 眉毛和上眼睑抬起、嘴唇分开 | 身体短暂停住、吸气、话被截断 | 惊讶之后转向喜悦、警觉、恐惧还是怀疑 | 眨眼、眉额 |
| 厌恶 | 鼻部皱起、上唇抬起、眼睑变化 | 头部和躯干撤开、声音排斥 | 是感官刺激、道德判断还是对人的轻蔑 | 距离、掩饰修复 |
| 轻蔑 | 单侧嘴角变化、目光斜过或短暂扫视 | 身体不完全转向对方、尾音轻落 | 人物是掌握优势、故作优势还是用轻蔑防御 | 口角、不对称、头颈 |

## 五、常见复合状态

| 复合状态 | 保护策略 | 可选泄露路径 | 禁止机械处理 | 可接的动作链通道 |
|---|---|---|---|---|
| 克制的开心 | 压住兴奋，避免显得太在意 | 眼睛先亮，嘴角只短暂上提，呼吸变轻 | 不要直接露出完整大笑 | 口角、眼线 |
| 苦笑 | 用笑维持体面或承认无奈 | 嘴角上提但眼周不参与，随后呼气、目光下落 | 不要写成“又哭又笑”同时拉满 | 口角、头颈、余波 |
| 强装镇定 | 保住控制权或不让对方发现害怕 | 声音仍稳，手指先紧，目光追踪出口 | 不要从第一帧全身发抖 | 手指、肩背、眼线 |
| 压抑愤怒 | 避免关系立即破裂或等待时机 | 嘴唇先压住，重音变硬，身体距离暂时不变 | 不要提前咆哮或摔物 | 下颌、手指、中止动作 |
| 礼貌性微笑 | 不认同但暂不撕破脸 | 嘴角参与、眼周不参与，身体保持距离 | 不要套“开心”的身体前倾 | 口角、掩饰修复、距离 |
| 忍住眼泪 | 维持尊严、继续质问或完成告别 | 呼吸先停、下巴绷紧、眼眶湿润，泪暂不落 | 不要一开始就持续流泪 | 呼吸、吞咽、下颌 |
| 愤怒保护悲伤 | 用攻击避免暴露受伤 | 前段直视和硬声，触发后眼眶水光、尾音发颤 | 不要让愤怒和崩溃同步到峰值 | 眼线、呼吸、余波 |

## 六、有触发的动作链与相邻误读

下列为本项目独立练习，不是固定调用清单；各链只用于原文有相容触发和意义的场合：

| 可读通道 | 具体链条 | 使用条件与误读边界 |
|---|---|---|
| 眼线 | 看住对方 → 触发词后视线落到其手上 → 抬回时停在脸侧 | 信息来自手部；不能无故游移 |
| 眨眼 | 反应前维持凝视 → 回答前迟到的一次眨眼 → 目光重新对准 | 延迟接收，不是每句眨眼配额 |
| 眉额 | 眉间短暂收紧 → 主动放平 → 眼线仍避开提问者 | 修复表面，不等于已经放心 |
| 口角 | 礼貌微笑维持 → 触发后嘴角失去支撑 → 闭唇继续听 | 不主动补笑声或快乐 |
| 下颌 | 答复前咬合收紧 → 开口时释放一点 → 最后一个词后再次收住 | 与清楚发声相容，不让全句咬死 |
| 呼吸 | 吸气准备回答 → 听见补充事实后没能接话 → 用较短气息重新开口 | 触发造成中断，不是慢动作 |
| 吞咽 | 话已经到嘴边 → 吞咽一次 → 改为更短但原文已定的回答 | 原文不能被改短；没有该版本则只改演法 |
| 头颈 | 眼先看向门 → 头跟到一半 → 听见叫名后停住 | 外部目标明确，不能凭空加出门决定 |
| 肩背 | 保持挺直 → 话音结束后肩线稍落 → 手仍完成原任务 | 肩落是代价，不自动哭泣 |
| 手指 | 保持递物 → 触发后指端多压一瞬 → 接收者握稳才松开 | 控制权必须连续 |
| 物件 | 原在整理纸页 → 触发后折痕处停顿 → 沿原折痕压平继续 | 物件已有，不能无故新增纸页 |
| 中止动作 | 手伸向对方 → 触发后停在中途 → 改为收回自己一侧 | 改变有原文或已确认表演依据 |
| 替代动作 | 将要起身 → 听见条件后重心回落 → 手改扶椅沿 | 不让起身倾向改写最终留坐事实 |
| 不对称 | 一只手继续稳定持物 → 另一只手短暂用力 → 随后松开 | 生理可行，不把正常不对称判缺陷 |
| 距离 | 身体略靠近 → 对方退半步 → 原地停住而目光仍追随 | 距离反应相互有因 |
| 掩饰修复 | 表情短暂中断 → 重新组织礼貌神态 → 句尾支持仍较弱 | 修复过快可显过度控制，但不能凭脸诊断说谎 |
| 听者 | 听到决定性名词 → 原动作停止 → 对方说完后才回答 | 停止与回答是不同获知阶段 |
| 群体 | 近处人物先看见 → 旁人沿眼线获知 → 再作各自反应 | 获知路径产生先后；合唱/同步动作属于例外 |
| 余波 | 决定已说出口 → 仍未松开的手完成放下 → 视线最后离开 | 话后动作必须有归属，不能假停留 |
| 重置 | 短闭眼或换气 → 恢复原姿态 → 握持或眼线仍有变化 | 重置不抹掉刚发生的压力 |

## 七、使用检查

1. 这项动作是否由人物目的、阻力或触发产生。
2. 镜头景别是否能看清它；看不清就换成身体、声音或空间证据。
3. 它何时出现、何时增强、何时减弱。
4. 哪些反应必须等到后面的触发才能发生。
5. 对手、道具或环境是否接住了这次表演。
6. 台词结束后是否留下可继承的静止反应。
