# 剪辑：专业方法与案例

## 当前专业决策

动作匹配连接同一事件前后相位；省略删除可重建的过程；把手是在最佳切点前后仍有效的素材余量。相似构图不能证明控制权/动作因果连续，切走关键选择会让观众无法重建。

问这一切带来什么新信息→记录出点/入点事件相位→核对视线、方向、控制权与支撑→保护读懂和反应时间→保留可选择把手。适合单元内部切镜与生成素材接口；反例是用快切制造不存在的因果、剪去半句冻结台词、强行改源镜号顺序。

### 同一材料候选比较

候选A：同一纸片交接：前镜尚握纸，后镜已入另一人口袋。

候选B：前镜在纸刚离指后结束，后镜从纸仍下落继续，接住后才抬眼。

取舍：后者连接真实控制权变化，前者省略了可能承重的选择和落点。

适用与反例：源镜号顺序不因剪辑便利重排；缺素材先标风险，不虚构已有可用帧。

### 编译或返修结果示例

“前镜在纸片刚离开他的手指后结束，后镜从纸片仍在下落继续；接纸人的手掌已经处于下方，接住后才抬眼。”前后共同载体是纸片运动相位，不是都出现一张纸。

### 返回合同

返回切点理由、出入相位、匹配载体、素材把手和不可裁切区；指出本次改变哪个决定、原有哪项事实不能动、从哪个状态开始以及下一负责人如何验收。输入缺口影响因果时停止专业深化，带证据返回；不把下游修词当作上游事实已存在。

## 完整专业方法


## 期待驱动节奏

悬念、寻找、误判、揭示、关系反转、倒计时、问题解决或知识解释承担观看牵引时，节奏不能只跟随抽象情绪或动作速度；先继承编剧的`观众问题—答案交接`，再建立内部`观众问题—声画兑现表`：

```text
节拍与当前观众问题：
进入本拍前已经知道 / 暂时相信：
本拍处理：建立 / 加压 / 延迟 / 部分回答 / 回答 / 改写。
新增证据与信息增量：它让观众多知道、改信或改等什么。
声画兑现：由哪个动作、构图、焦点、遮挡、声音或停点交付。
可读等待窗口：证据从何时足以被辨认，到反应或认知更新何时完成。
下一问题：是否由当前答案、代价或后果自然产生；没有则不强造。
```

`期待驱动节奏`不是把全片改成连续提问，`情绪不是唯一节拍器`。没有具体观众问题的氛围、观察、歌舞和克制表演，仍由身体、音乐、空间与材料的可读变化组织节奏。问题承重时，没有新增证据、风险、关系或判断变化的重复动作优先压缩、合并或省略；镜头角度只有改变信息权限、空间关系、人物视点或证据可读性时才新增，不能靠多角度重复同一动作制造紧张。

快慢由信息与表演共同裁决。快用于越过观众已经读懂且不再改变判断的过程；慢用于让关键证据达到辨认阈值、让观众形成预期、读到人物反应或承受答案到来的前一刻。证据尚未可读就切走是抢答；证据、预期和反应都已完成却继续拖延是等待过期。所谓重点不自动获得慢镜头，短促中断、实时动作或突然静音也能成为决定性节拍。以上表格只存在于代码块外的导演判断，正式提示词必须翻译为可见 / 可听事件。


## 剪辑承接合同

每个内部切点在写正文前回答同一份合同；[切镜交接的是事件相位](#3-切镜交接的是事件相位不只是相似画面)里的各类匹配只是这份合同在不同载体上的机制解释，不另立第二份字段表：

```text
A镜末端：已经完成什么，最后可见 / 可听证据是什么；尚在继续的动作、声音或视线还剩什么。
跨切载体：动作相位 / 视线 / 屏幕方向 / 物体 / 形状 / 遮挡 / 声音 / 因果结果。
B镜开端：同一载体的下一相位，以及第一项新增信息。
被省略内容：切点省略了哪段时间或路程——路程、重复动作、等待或非承重时间。
省略期间的例外检查：是否出现新的选择、障碍、人物、物体状态或不可逆结果。
省略依据：观众已经知道的目标、方向、空间和结果。
重建证据：观众凭哪些已见事实可以重建被省略部分。
```

需要省略中间过程时，先过[省略成立门](#4-省略成立门)。

复杂单元的状态链朗读、逐镜复述与断裂修复统一在[逐镜成立、合看断裂的修复](#5-逐镜成立合看断裂的修复)执行。

### 预示线索与动作组

动作镜头之间采用预示性承接：上一块末尾按需同时留下 `本镜结果 + 下一威胁线索 + 摄影机方向`，下一块从同一线索的下一相位开始。线索可以是尚未进入接触的刀尖、地面影子、人物视线、画外脚步 / 链响 / 机关声、旋飞兵器或铺满画面的运动物。遮挡只能隐藏切点，不能让新敌人在遮挡后无预兆出现。

- 内部镜头节点先从主情绪和动作观看方式推导。连续跟拍 / 少量长镜头展示真实时间、空间、完整身法和持续控制；高强度多切展示攻击密度、速度、冲击、失衡和压迫；混合结构可以先建立空间，再快速覆盖爆发动作，最后用结果镜头沉淀。不要预设 15 秒应该有几个镜头。
- 动作组与镜头分层设计。一个动作组可以由一个镜头连续完成，也可以用多个镜头分别看清攻击来路、接触、脚步、受力与结果；每个镜头增加一个新的观看证据，相邻镜头继承同一动作相位和状态，不让动作重新发生。
- 高频动作覆盖不是快闪蒙太奇。前者通过动作匹配、屏幕方向、姿势、武器归属、运动余势和声音连续呈现同一事件；后者用于时间压缩、平行信息、记忆碎片、危机倒计时或卡点并置。

预示线索只在当前动作确实需要交接时留下，不要求每个镜头都埋一条危险线索；动作组与镜头数也不互相换算。

内部校准完成后必须进入正式描述。两镜以上共同完成同一人物选择、道具操作或连续动作时，在`【画面内容】`开头先写一至三句`连续动作主线`：用画内事实说清同一人物、同一物体、不可交换的动作顺序、关键控制权变化和最终状态，再由编号镜头逐步展开。它不是第四个一级区块，不写主题、观众感受和作者解释，也不使用内部字段名；它的作用是让模型先看见整段事件，再理解每个镜头怎样完成事件。

例如不要只把“端盘、台词、夹回、离开”散落到四个镜头里；应先明确：`全段围绕同一盘菜连续发生：母亲先把菜夹入孩子碗中；看见孩子吞咽失败后才端起盘子阻止；孩子说完话从她仍端着的同一盘中夹回一块；母亲把盘子放稳在原餐桌后松手，空手起身走向阳台。` 随后各镜只展开当前相位的机位、表演、接触、声音和停点。总述与逐镜正文有任一状态冲突，整条提示词不得交付。

视频父入口 默认面向当前可用的强生成模型，不替生成模型预先降级。不得因为猜测模型“可能理解不了”，就删掉人物关系、动作因果、镜头调度、物理路径或决定性画面；描述端的责任，是把最佳导演方案写得清楚、完整、无冲突、可执行。平台字符上限只是法度：需要压缩时先删同义解释和低权重装饰，不能压缩承重因果。


## 可剪辑接口

转场不是独立特效，而是两段素材之间的交接合同：前一段交出一项观众能读到的属性，后一段延续、改向或有意反衬它，切点两侧还有足够干净画面和声音供剪辑选择。选择次序固定：先保证主情绪、故事信息和节奏，再保证观众眼睛落点与动作可读性，最后校准空间和图形；不为一个漂亮匹配牺牲更高层目标。

| 接口族 | 交接属性 | 可见 / 可听实现 | 常见风险 |
|---|---|---|---|
| 运动连续 | 动作相位、方向、速度、轨迹、手势、出入画 | 前一镜抬手到动作中段，后一镜从同方向下一相位继续；人物从右侧出画，下一素材从相容边缘进入 | 动作重演、方向反转、切在未完成接触上 |
| 注意力连续 | 观众视点、人物视线、主体落点、焦点 | 人物看向右上方，下一镜在相近屏幕位置出现被看对象；焦点从脸落到杯口，下一素材从同一落点接圆形高光 | 只匹配眼神方向，却没有被看对象或空间依据 |
| 图形连续 | 形状、构图、景别、角度、轮廓、明暗、颜色、纹理 | 圆形杯口接车轮；同一荷兰角延续不安；白色桌面铺满画面接过曝天空 | 只剩形式相似，故事与情绪无关 |
| 遮挡 / 曝光连续 | 满屏遮挡、黑场、白场、闪光、灯光开合 | 人物或车辆完整覆盖画面；关灯后画面稳定变黑；闪电让画面短暂过曝 | 借遮挡瞬移、越轴或重置人物状态 |
| 声音连续 | 声音先行、声音延续、重音、节拍、相似声、对白桥 | 下一空间声音先进入；旧台词跨入新画面；关门重音落在切点 | 声源无方向、声场混乱、台词被截断 |
| 语义连续 | 因果、想法、隐喻、反差、视觉押韵 | 抚摸背部接抚摸琴身；一句提问接下一场动作答案 | 联想牵强、只靠作者解释才能懂 |
| 桥接素材 | 细节、插入、空镜、纹理、极短快闪 | 先切第二场景的产品细节、门把、鞋底、环境纹理，再进入新空间 | 桥接镜头本身抢戏或引入新连续性错误 |
| 后期依赖 | 抠像轮廓、替换平面、蒙版轨迹 | 纸张完整撕开、屏幕平面稳定、手势轮廓清楚、绿幕光照均匀 | 边缘脏、遮挡不完整、运动无法跟踪、后期成本失控 |

跨镜头不需要所有属性同时匹配。通常一条主要属性、一条辅助属性最清楚，例如 `动作方向 + 观众视点`、`形状 + 明暗`、`台词语义 + 声音延续`。相似景别和相似构图可以顺滑，跨景别匹配也可以成立；关键不是“必须跨一个景别”，而是新镜头确实改变了信息尺寸、观看位置或情绪压力，并且观众眼睛知道落在哪里。

除接口族之外，还提供重拍停点、海报式完整构图、满屏色块、轮廓遮满、黑场 / 白场、同形母题、同方向擦除和纯声音桥。声音连续族包含两种拉伸声音的手段：J cut 让下一段音乐、钟声、祷告或机械声提前进入；L cut 让上一段余响拖过新构图。作品标题和角色身份帧不得在尚未稳定时结束。

生成前只记录推荐入点、内部节点、推荐出点和干净把手，不虚构时间码。正式模型正文把接口写成画面 / 声音结果；生成后逐帧确认真实时间码、稳定范围和是否值得使用。


## 跨生成段的尾帧续接

一条成片由多条独立生成视频拼成、并且任务明确选择了首尾帧复用或一镜到底感方案时，才进入本节。通用基底的 `15 秒以内` 是那一类素材当时的方案情境，不是现行模型上限；`A 尾帧要能成为 B 首帧` 只约束主动采用这一输入方式的任务，不升级为所有视频和所有切镜的硬规则。

独立素材、可替换空镜、有意重置场景和非连续剪辑按自身用途设计起止状态，不套同构图、同光源、同姿态的续接；它们之间按[可剪辑接口](#可剪辑接口)选一条主要接口交接即可（组合语法里“画面服务剪辑”的限定同样适用于此）。一旦选择尾帧续接，就要逐项写清继承关系，不写“无缝衔接”：

```text
构图连续：B 条开场沿用 A 条尾帧的人物位置、景别、画幅比例和背景锚点，并接住栏杆、门框、木轮、火盆、病床、海面、树影等稳定视觉锚点。
光源连续：主光方向、动态光源、肤色明度、暗部重量和环境反光保持同一状态。
姿态与表情连续：头部角度、肩颈状态、身体重心、手部位置和服装褶皱承接上一条尾帧；笑意、泪痕、眼神失焦、眼眶水光、嘴角收住或呼吸余韵延续到下一条首帧。
声音连续：VO 尾音、海浪、风声、脚步、门响、电话电流、回响、音乐或静默在剪辑点前后保持同一声场。
动作与情绪连续：上一条未完成的转头、低头、抬眼、走远、停步或落泪，在下一条开头自然完成，下一条在上一条情绪余温上继续推进。
遮挡转场：袖口、门框、火光、纸灰、树影、低头、蒲团纹理或强光满屏可以形成转场点。
```

一镜到底感的关键是剪辑点前后状态一致，让观众感到时间连续；它不要求把每条素材都写成同一种转场。

跨批次的真实参考绑定、有效尾部与终帧的素质门、素材替换以及只支持单图时的运行时重建，由[视频参考与资产绑定](../../laohu-video-references/SKILL.md)的[跨批次连续性参考模式](../../laohu-video-references/references/跨批次连续性参考模式.md)负责；本节只规定“选择了尾帧续接后必须写清哪些状态”，不复制参考绑定教程。


## 3. 切镜交接的是事件相位，不只是相似画面

切点字段统一由[剪辑承接合同](#剪辑承接合同)定义；本节只解释同一份合同在不同匹配载体上的机制，不再另写一份字段表。

动作匹配的核心不是两帧姿势相似，而是切后仍在完成同一件事。视线匹配的核心不是眼睛朝同一方向，而是切后出现人物正在看的对象或其结果。声音桥的核心不是有声音跨过去，而是同一声源或因果声场帮助观众继续追踪事件。门框遮挡只能隐藏机位变化，不能替人物补完尚未决定的行为。

### 景别与观看尺度的切换

切换景别时追求 `有意义的视觉变化`：

1. 同一主体、相近轴线、相近构图和同一动作相位下，从远景只切中远景、从中景只切中近景，变化太小容易像误切或跳切。
2. 此时可以跨过一个景别，例如远景切近景、中景切特写；也可以让机位相对主体改变约 30 度以上；还可以让动作相位、构图或信息目标发生明显变化。
3. `跨一个景别` 和 `30 度` 都是连续性经验，不是硬规则。相邻景别如果新增了明确证据可以使用；跳得很大但没有空间锚点、方向继承或动作匹配，同样会断裂。
4. 每次切换都回答：上一镜为什么此刻结束，下一镜新增什么，人物姿势、道具状态、屏幕方向和动作余势如何继承。

不要每个镜头都特写。连续特写会让空间断裂，也会让后期拼接困难；近景完成证据任务后，按需要重建人物与环境的空间结果。


## 4. 省略成立门

电影可以省掉现实中的每一步，不能省掉理解所需的那一步。满足以下条件时，中间路程或重复动作可以不拍：

1. 人物已经作出决定，动作目标不再未知。
2. 主体、物体和控制权在切点两端能够对上。
3. 运动方向、目的地或下一结果至少有一项被提前建立，另一端明确兑现。
4. 被省略期间没有新的选择、阻力、人物介入、物体易手或不可逆变化。
5. 后镜第一项证据足以让观众恢复人物、空间、时间、因果和目标的当前状态。

若母亲端起盘子只是把它从孩子面前移到厨房台面，可以拍“盘底离桌的近景 → 她朝厨房门洞转身的中景 → 盘底落到具体台面的近景”，省掉几步路；若途中她犹豫、孩子重新夹菜、盘子被抢走或她改变主意，这些都是新的决定或阻力，不能靠跳切抹掉。省略不是少写，而是把可推断的过程交给观众，把不可替代的选择留在画面里。

条件不成立时必须增加连接镜头、声音桥、动作匹配、空间建立或结果特写；所谓“观众会脑补”只能是验收结论，不能代替这些证据。

认知研究为这套判断提供边界：连续性剪辑能让观众跨过低层画面、空间或时间变化，仍感知同一事件；动作连续性一旦断裂，观众更容易把它知觉成新的事件边界。观众会根据当前事件模型预测接下来发生什么，因果、目标、人物、空间、时间或物体交互发生意外变化时，需要更新理解。视觉叙事中的缺口也能触发桥接推断，但缺口过大或缺少桥梁时，推断会转成断裂，而不是自动变成高级留白。参考：The Impact of Continuity Editing in Narrative Film on Event Segmentation（来源：`https://pmc.ncbi.nlm.nih.gov/articles/PMC3208769/`）、Segmentation in Reading and Film Comprehension（来源：`https://pmc.ncbi.nlm.nih.gov/articles/PMC8710938/`）、Bridging a Gap in Coherence（来源：`https://pmc.ncbi.nlm.nih.gov/articles/PMC11417950/`）。这些研究支持“保住行动、目标与因果连续”，不证明任何固定三镜头模板天然正确。


## 5. 逐镜成立、合看断裂的修复

复杂单元再做一次状态链朗读：只读每镜最后一句与下一镜第一句，逐项复述。任何一项无法连续读通，先修状态与剪辑合同，再修华丽镜头。

```text
人物目的是否仍在推进或已经明确改变；
人物与物体各在什么位置，谁控制什么，手中物是否仍然成立；
动作、视线、屏幕方向和声音来源是否进入下一相位；
人物之间的空间位置与关系状态是否还能连续复述；
下一镜新增的内容是否由上一镜结果触发；
观众此刻需要推断什么，证据是否已经给足。
```

任何一项只能靠作者解释补齐，就不是剪辑省略，而是导演因果缺口。先补事件与状态，再选择切法；不能用更多运镜、特效、构图或形容词掩盖。

复杂连续事件还要经过一次从内部判断到模型输入的编译。先在`【画面内容】`开头用一至三句画内事实写出`连续动作主线`：同一人物和同一承重物体怎样依次改变控制权、位置和状态，最终停在哪里；再进入镜头方头展开观看位置。总述不是“本段表现母爱与牺牲”一类主题说明，而是“母亲先递出同一只盘子，看到吞咽失败后端回，孩子再次从盘中取走，盘子落回桌面后母亲空手离开”一类可生成事件。逐镜细节可以增加表演和摄影信息，不能改写这条总线。


## 6. 转场是共同载体的状态继承

相邻独立生成镜头不能只写“无缝衔接”。必须建立共同载体视觉指纹：

```text
载体名称 / 几何轮廓 / 内部结构 / 画面位置与占比
颜色层级 / 材质与纹理 / 光源和反射
运动方向 / 速度 / 动作相位 / 遮挡边界
同步声音 / VFX 阶段 / 下一镜第一变化
```

A 尾部和 B 开头都要独立写出同一指纹。A 以它遮挡或离场，B 从同一轮廓、颜色、材质、位置和运动相位重新开始，再只增加一个新变化。不能用“继续上一镜的圆环”“同一个刀光”代替跨请求的可执行描述。


## 跨批次 连续性把手

独立生成的 A / B 不一定都需要同一种转场。先判断观众需要继承的是空间、表演、动作、艺术母题、因果声音，还是有意重置场景，再设计把手：

```text
空间连续：A 有效尾部或终帧读清人物、锚点、观看侧、临时破坏与运动余势；B 从下一相位继续。
表演连续：继承呼吸、眼线、颈肩、手中物、关系距离、声线余韵和屏幕方向，不强迫近景退成大全景。
动作连续：继承重心、动作相位、运动向量、接触状态和动作声。
艺术转场：继承动作、轮廓、色光、材质或声音的共同载体，不继承错误地点。
因果 / 声音桥：B 先接住 A 的声源或结果，再揭示新的空间和后果。
场景重置：明确终止旧空间状态，只继承长期身份、剧情事实或音乐结构。
```

空间风险高时，A 可在当前动作完成后保留约 1—3 秒能够读清拓扑的中远景、较宽画面或其他有效机位，并把这段标作预计裁剪区。这个经验值不是固定镜长：动作仍未完成就不能为了把手提早拉远，承重文戏也不能为了全景牺牲面部与声音余韵。入口支持视频参考时，优先传入通过真实结果质量门的有效尾部；只支持图片时，使用合格终帧加稳定身份 / 场景资产；两者都不支持时，在 B 的当前批次封闭编译中重建最少充分的 GEO 运行时切片。

把手通过四道门才可引用：只包含一个连续有效机位；人物和承重物没有结构错误；空间、服装、破坏与光影状态属于 A 的真实结果；B 明确只继承哪些属性以及第一项新变化。把计划尾帧、包含两个硬切机位的视频尾部或带畸形的状态帧直接喂给 B，只会把错误变成连续。


## 节奏不是切镜频率

电影节奏由声音、镜头序列和镜内运动的速率与规律共同形成。长镜头可以因人物、摄影机、焦点和空间持续变化而紧张快速；短镜头也可以因内容静止、变化重复而显得迟缓。切得快只能提高画面更换率，不能自动提高戏剧推进率。

每次提速必须至少推进一项：危险更近、关系更紧、力量升级、信息翻转、空间改变、目标接近或情绪保护层破裂。没有状态变化的快切只是视觉噪声。


## 切镜、镜头时长与信息速度


## 切点由事件决定

优先在以下位置切镜：

- 动作意图已读懂、结果尚未出现时，切向目标或反应。
- 动作穿过画面边缘、遮挡面或光色峰值时，借运动完成转场。
- 接触完成点切向结果，让声音瞬态把两镜粘合。
- 人物听到触发词后，不立刻切走，保留最低反应窗口再进入特写。
- 高速段结束时用较长停点，让观众读取代价和新局势。

不能按固定镜头数或固定秒数机械切。镜头持续多久，取决于观众需要多久完成“识别 → 预测 → 等待 → 确认”；一旦本镜任务完成且下一状态已经出现，继续停留才是拖沓。


## 快切的正确用途

快切适合压缩过程、并列证据、制造攻击密度、呈现记忆碎片或在音乐重音上升级状态。每一切至少改变景别证据、受力结果、空间位置、人物策略或信息层级。连续几镜若只换角度而结果不变，删镜比继续提速更有效。

动作片的高速度常用 `可读建立镜 → 短促爆发镜组 → 结果停点`；文戏可用 `稳定对峙 → 触发词后的微反应切近 → 沉默长持`；MG 可用 `连续组装 → 关键数字停住 → 下一关系快速重排`。这些是机制关系，不是固定镜头配额。


## 信息速度不能超过识别速度

画面同时出现新角色、新道具、新字幕、新空间和新动作时，即使每项都清楚，总体仍可能过载。速度设计先保住主观看任务：高速阶段减少新概念，复杂概念阶段减少无关运动。标题、数字、产品卖点和关键表情都需要最低可读停点，不能边高速变形边要求观众完整阅读。


## 期待驱动节奏：问题什么时候到期

剧情、悬念、寻找、误判、揭示、倒计时或知识问题承重时，节奏的基本单位不是镜头秒数，而是观众正在等待的状态何时获得有效更新。先从编剧的观众信息账本接收问题与答案边界，再建立`观众问题—声画兑现表`：

```text
当前问题与提出它的可见 / 可听证据
观众已经知道、暂时相信和仍不知道什么
本拍处理：建立 / 加压 / 延迟 / 部分回答 / 回答 / 改写
信息增量：新增证据改变了哪项判断、风险或下一等待
声画分配：动作、机位、焦点、遮挡、声音与停点各承担什么
可读等待窗口：证据达到辨认阈值 → 观众形成预期 → 反应或答案完成更新
下一问题是否由当前答案、代价或后果产生
```

同一人连续翻找、奔跑、敲门或浏览资料，可以用速度上升证明焦躁或压力，但`重复信息不因多角度获得新价值`。只有新角度改变观察权限、空间范围、人物策略、关系位置或暴露新证据时才保留；否则在同一镜内加速、用动作匹配压缩，或直接省略到下一项有效变化。剪得快不等于故事走得快，镜头没变也不等于节奏慢。

`可读等待窗口`没有固定秒数。开始点是观众已经能够辨认承重对象或异常、足以提出问题；结束点是预期、人物反应或认知更新已成立。结束前切走会让答案没有证据，结束后持续停留却没有新的压力会让等待过期。答案也不必一次给完：部分回答可以把原问题扩大或改写，但新问题必须由当前结果因果地产生，不能靠随机人影、巨响或新秘密替换旧承诺。

`情绪不是唯一节拍器`。情绪是人物处境、信息权限、身体表演、动作速度、声音和观看等待共同形成的结果；它不能单独决定所有重点都慢放、所有焦虑都快切。重点可以用实时速度、短促中断、突然静音或一次硬停成立；低烈度观察、歌舞和氛围段没有具体问题时，继续按身体、音乐、空间和材料的可读变化组织，不强造悬念问答。


## 转场与跨批次 的速度连续性

匹配转场除了几何、颜色和材质，还必须继承运动方向、屏幕速度和动作相位。A 尾与 B 头分别完整复述同一份交接载体指纹：

`轮廓 / 内部结构 / 画面位置与占比 / 材质 / 颜色 / 受光 / 运动方向 / 屏幕速度 / 当前相位 / 拖尾与遮挡边界 / 同步声音 / 稳定把手`

若 A 尾是“圆盘顺时针高速旋转并正在减速”，B 头不能从静止或反向加速开始。B 先恢复共同状态，再新增第一项变化。跨 `批次` 不追求数学上完全相同的速度数值，而要保证观众可感的方向、快慢级别、加减速趋势和相位连续。

转场速度按任务选择：

- 高速擦镜：共同遮挡面快速铺满，适合隐藏空间切换。
- 缓慢形变：共同轮廓逐步重组，适合概念关联和高级感。
- 硬切接惯性：A 出画与 B 入画方向一致，接续运动冲量。
- 突然停住后切：先制造静止标点，再切向新空间，适合强调结果。
- 声音先行：B 的声音提前进入，画面仍在 A 的减速余波中，适合叙事推进。


## 7. B-roll 的时间与剪辑接口

B-roll 的进入点由语义完成、画面证据和声音桥共同决定，不使用“每句切一次”或固定秒数作为默认规则。


## 进入

- 口播先提出问题，画面随后进入回答，适合让观众先听到问题再看到证据。
- 画面先以短暂线索进入，口播随后命名它，适合制造注意力和悬念。
- A-roll 的手势、视线、屏幕方向、物件轮廓、动作声或音乐重音成为 B-roll 的匹配载体。


## 停留

- 先给观众一个可识别的稳定状态，再加入裁切、推进、图形或材质运动。
- 完成点是观众理解本节拍的时刻，不是特效数量达到上限的时刻。
- 同一画面承载多个信息时，先完成主证据，再让辅助细节进入；不要让运动持续遮住证据。


## 退出

- 证据完成后回到 A-roll 的判断 / 限定 / 结论。
- 用同方向运动、主体轮廓、形状、遮挡、光色或声音桥进入下一节拍。
- 转场载体必须吸收、出画或收缩到零；不得留下无职责的色带、玻璃卡、边框、窗口或遮罩线。
- J-cut / L-cut 只作为声音连续手段，不能掩盖画面事实断裂；上一段余音和下一段口播必须知道属于谁、来自哪里。
