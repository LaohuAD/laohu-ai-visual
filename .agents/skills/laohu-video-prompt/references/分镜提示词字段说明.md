# 分镜提示词字段说明

## 字段结构

```text
分镜编号：
时间段：
景别：
观察方位与俯仰机位高度：
取景锚点：
镜头关系：
轴线与视线：
构图：
运镜手法：
画面内容：
首帧状态与结束画面：
声音：
后期备注：
```

原有字段全部保留；新增的三项是把过去混在“机位／角度／高度／距离”里的判断拆成可比对的字段名。旧词仍可读作检索别名：旧“方位／角度／高度／距离”分别对应**观察方位、俯仰与倾斜、机位高度与取景锚点、景别与取景范围**。四件事不能互相顶替：方位回答从哪一侧看，俯仰回答平视还是俯仰，机位高度回答真实观察高度，取景锚点回答这次重点落在哪个可见部位，景别取景范围回答纳入多少环境、哪里被裁切。

`首帧状态与结束画面` 不是逐秒时间轴：写本镜开始时观众看见的主体、位置、光色和构图，再写结束时最后可见与可听的状态，供下一镜继承。计划中的结束状态不等于已经生成的真实尾帧。

各字段的具体覆盖项与镜内必答清单，见[镜内必答项与C方头字段](../skills/laohu-video-compilation/references/镜内必答项与C方头字段.md)；本文件只定义分镜工作表的字段名与填写边界。

## 构图使用原则

需要稳定关系时写构图。

需要动作自然时少写构图。

写构图前先确定镜头关系。镜头关系回答“摄影机站在哪里、观众通过谁看、谁在前景和中景”。常用关系包括主观镜头、客观旁观、近主观、过肩、正反打、反应镜头、插入镜头、视线所见、内打外、外打内和内反打。

正反打和过肩镜头必须写轴线与视线：谁在画面左侧，谁在画面右侧，谁看向画面哪边，谁的肩背或门框形成前景遮挡。只写“正反打”不够，必须让下一步视频提示词能直接转成可见画面。

动作镜头可以写：

```text
主体大致保持在画面中心附近，优先保证动作自然和速度感，不要求严格对称构图。
```

## 运镜使用原则

一个镜头最好只写一种主运镜。

不要为了显得专业堆“推拉摇移跟”。
