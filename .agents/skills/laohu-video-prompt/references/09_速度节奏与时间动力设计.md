# 速度节奏与时间动力设计

> 归属：视频包的速度、时长与镜内时间约束方法负责人。本文件承接《模板_视频提示词_基础设定氛围画面内容》中原有的文本，原文一字未改；模板只保留版式与指针。速度层由本文件决定，镜头内的动作、受力与摄影机路径仍由对应专业负责。

## 一、时长怎样倒推

时长按 `主体识别 + 动作完成 + 情绪建立 + 效果展开 + 停点 / 切换余量` 倒推。简单动作可以短，渐变情绪、复杂受力、天气变化、奇观展开、焦点迁移和多次切镜需要更长；装不下时加时长、删次要效果、减少镜头或拆成多条素材后期剪辑。普通动作不机械使用逐秒时间码；只有高速连锁、亚秒接触、延迟结果、极短反应窗口或停点保持时间无法靠自然语言稳定控制时，才在对应镜头内部加入少量相对时长约束。

#### 开口前、实际发声、话后结果

一条声音事件分为开口前的必要动作/气息、冻结台词实际发声、话后反应或动作结果；三段时间可以与其他事件合理重叠，但同一人物不能在不可兼容的发声、吞咽、剧烈接触或换气状态中被同时安排。功能短句可以几乎无预备，情绪承重句需要可读思考；不强制每句吞咽、吸气或停住。

先建立事件的先后依赖，再分配时间。能同时发生且互不遮蔽理解的动作取覆盖时长；必须等触发完成才开始的反应累加。不能简单取“全部台词总时长”和“全部动作总时长”的最大值，因为局部串行仍会延长整条时间线。

可用估时关系：

```text
事件最早开始 = 所有前置事件完成时刻的最大值
事件结束 = 最早开始 + 该事件自然所需时长
内容最低时长 = 所有事件结束时刻的最大值
请求时长 = 内容时长 + 不能与正片内容重叠的必要素材余量
成片时长 = 最终实际采用片段的时间并集，重叠内容不重复计数
```

独立虚构估算：开口前动作 0.6 秒，台词 3.2 秒，台词结束后放杯 1.1 秒，杯落桌后听者回应 0.9 秒，内容至少 5.8 秒；手已在说话期间伸向杯子时，那段伸手时间不重复相加。若另留头尾余量 0.3 和 0.5 秒，则请求规划 6.6 秒；入口只支持离散时长时另选可行参数，不把多余帧自动算作可剪把手。上述数字仅示例，不是默认配额，也未经过真实读演。

有已确认音频时以真实音频和词句落点为时基；没有音频时可用字符/词数和选定自然速度估计，但必须注明估计，标点、迟疑、气口和动作占时另计。字速不写成演员必须执行的精确数值，不能为了时长删原话、改标点或把关键停顿加速抹掉。

目标时长装不下时，先删无作用的技术复述和装饰，再调整非承重停留/重复建立，仍不可行则把冲突和候选边界 RETURN 分段负责人；视频不能私自把一个 P 改成两个正式 P。声音桥跨 C 不重复合成台词，跨 P 的音频归属沿用分段交接。

默认正文写自然先后与必要相对时间；已锁音频、真实时间码或固定播出点需要精确时基时，按项目既有例外写绝对窗口。采用 H3 标签本身不成为强制逐秒时间轴的理由。

## 二、速度与时间动力（承重时按需）

先区分 `动作速度 / 摄影机速度 / 切镜速度 / 信息速度 / 声音速度`，只选择真正改变本镜观感的一至三层。内部按 `速度意图 → 主速度承载者与参照物 → 起点状态 → 蓄势 / 启动 / 加速 / 峰值 / 接触 / 余波 / 停点 → 摄影机与切镜响应 → 声音完成点` 设计，再把必要因果压入对应镜头；不把这条链另做一级标题，也不机械填满全部相位。

`高速、迅速、激烈、慢动作、快切` 不能独自承担速度。写清谁相对什么加速或减速、背景和前景怎样位移、接触发生在哪里、摄影机何时跟随或制动、结果怎样保持。人物、摄影机、背景、VFX 和切镜不得默认同时加速；先保住方向、接触和结果，再用 `停 → 动、慢 → 快、密 → 空、高速 → 硬停` 产生速度对比。复杂速度任务继续读取本文件及同目录的时间动力模块。

## 三、镜内相对时长约束（按需）

时间约束不取代镜头方头，只能嵌入单个镜头的详细内容。优先选择最接近控制目的的一种写法：

```text
顶镡到刀刃离鞘一掌宽控制在0.2秒内。
刀刃接触后0.1秒内，裂缝先沿接触点扩散，随后才爆开，不得提前爆炸。
完整标题形成后稳定保持至少0.8秒，背景运动同时降到最低。
```

一个复杂镜头通常只保留 `1-3` 个会改变结果的相对时长约束。默认不写 `【本镜0.0-0.2秒】`、`【片内14.2-15.0秒】` 等绝对起止区间；这些区间会把事件绑死在固定片长，无法把同一提示词从 15 秒伸缩到 30 秒。只有明确绑定锁定音频、真实时间码或固定播出点时例外。时间数字只锁动作完成速度、触发后延迟、反应窗口与结果保持，动作路径、接触、受力、屏幕结果、运镜和声音仍要写全。这里是生成前约束，不是生成后真实可用时间码；真实剪辑点由生成复盘回填。

## 四、怎样使用

本文件只回答“这一镜需要多长时间、哪几层速度承重、哪些时间点必须锁住”。动作路径、接触、受力、屏幕结果、运镜和声音的写法回到对应专业。默认不写绝对起止区间；只有绑定锁定音频、真实时间码或固定播出点时才写，并把数字限定在动作完成速度、触发后延迟、反应窗口与结果保持上。
