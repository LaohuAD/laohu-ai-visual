# 题材视觉证据与相邻类型边界

## 用途

这不是风格百科，也不是“输入题材名就复制一套元素”的词库。它用于四件事：

1. 把题材承诺翻译成观众能看见的证据。
2. 区分最容易混淆的相邻类型。
3. 为人物、服装、妆造、场景、道具、光影和运动分配同一方向。
4. 在真实图片 / 视频中判断第一个风格断点。

题材边界会变化、重叠，也受地域、时代、受众和媒介影响。下列分类是生产启发式，不是自然科学分类。使用时先写主类型与辅类型的关系，再选择适合当前故事的证据；不得把目录中的典型元素全部塞入一个作品。

“成熟作品”只能证明某种机制已经被行业广泛使用或被观众认识，不能证明所有颜色、轮廓和元素对任何项目都有效。外部案例拆机制，不复制受保护的标志性表达。

## 一、证据怎样成立

### 1. 从承诺到画面

```text
题材承诺
→ 世界允许什么、禁止什么、相信什么
→ 人物怎样生活、行动和区分身份
→ 形态、色彩、材料、光影、空间与运动关系
→ 观众在没有说明文字时读到的类型
```

一个词如果不能改变人物、物件、空间、光或运动的可见关系，就还没有进入美术设计。例如“仙侠”不是让画面加雾，而是修行世界怎样改变资源、等级、身体、服饰、建筑、材料与物理；“赛博朋克”不是加霓虹，而是高技术、资本 / 权力和低生活之间的冲突怎样进入城市、身体、界面与材料。

### 2. 证据强度

- `一级证据`：只靠题名、字幕、人物职业名、背景捷径或风格形容词；最弱。
- `二级证据`：单个道具、纹样、配色、发光效果或服装装饰；可被相邻类型借用。
- `三级证据`：形态、材料、身份制度、空间或运动中的一组关系；去掉一个元素仍成立。
- `四级证据`：同一世界判断在两个以上承重部门以不同形式重复出现；最稳定。

重要角色或主要场景至少要有一组三级证据；系列整体要追求四级证据。某角色有意伪装成普通人时可以降低个人证据，但必须由同镜环境、道具、他人反应、群像或相邻镜头补偿。

### 3. 五个边界测试

```text
去标签测试：遮掉题名、人物身份、境界、宗门、字幕与说明。
去背景测试：去掉最常见背景捷径，只看人物、服装、妆造和道具。
相邻替换测试：不改画面，是否能直接放进最近的相邻题材。
跨部门一致性：同一视觉判断是否在至少两个承重部门被兑现。
例外补偿测试：有意克制或隐藏时，其他通道是否足以保持类型归属。
```

## 二、通用风格坐标

每次不必全文描述，但必须知道作品落在哪里：

| 坐标 | 一端 | 另一端 | 影响 |
|---|---|---|---|
| 现实规则 | 日常可验证 | 超常世界主导 | 材料、光源、身体能力、空间尺度与运动 |
| 时间来源 | 明确历史时期 | 架空混合 / 未来 | 服制、技术、建筑、文字、工艺证据 |
| 视觉秩序 | 克制、留白、少层级 | 密集、装饰、多层级 | 轮廓、陈设、图形与镜头信息量 |
| 表面状态 | 新、精密、受控 | 旧、磨损、临时、野生 | 材料、身份、制度与生活方式 |
| 情绪温度 | 冷静、疏离、威胁 | 温暖、亲密、明亮 | 色温、距离、表演和空间 |
| 权力尺度 | 个体生活 | 制度 / 文明 / 宇宙 | 构图、建筑、群像和道具系统 |
| 动作物理 | 重力和受力主导 | 仪式、法术或超技术改写 | 衣料、身体、环境反馈与特效 |

坐标不是风格答案。它帮助同一题材形成不同候选，也帮助判断辅类型改写了哪些通道。

## 三、常见题材家族与相邻边界

### A. 中国古代历史 / 古装正剧

`核心承诺`：具体社会制度、时代生活、礼法与物质条件构成人物命运。

`优先证据`：可信服制层级、材料与工艺经济、礼仪和身份距离、历史建造逻辑、生活磨损、现实光源与重力。

`最近相邻`：武侠、仙侠、中国神话。

`误判信号`：只要交领、束发、木构、山水就是历史；时代服制混搭却声称考据；所有人物都像影楼古装。

`边界`：历史题材的超常现象通常不改写整个社会的材料与物理；一旦修行、神灵或法术成为制度和日常资源，应转向仙侠 / 神话或明确混合关系。

### B. 武侠

`核心承诺`：人的技艺、选择、门派伦理与江湖秩序在现实重力和社会世界中被推到极致。

`优先证据`：可行动的服装、真实武器与受力、旅途磨损、门派 / 地域差异、身体训练、客栈山道城镇等人间空间、克制的能力夸张。

`最近相邻`：古装历史、仙侠、动作冒险。

`误判信号`：黑衣、佩剑、山雾、竹林直接等于武侠；所有高手都穿同类深色长袍；只靠慢动作和飞檐走壁。

`边界`：武侠的奇仍以人的身体与技艺为中心；仙侠的异会进一步改变寿命、修行等级、材料、空间、能量和天地规则。

### C. 仙侠 / 修真

`核心承诺`：中国文化语境中的修行宇宙不仅提供奇观，也重新组织人的寿命、身体、门派、资源、伦理、空间和天地关系。

`必要判断`：汉服或古代衣冠只是文化语法，不是仙侠证据；剑、山峰、云雾、长发、低饱和同样可属于武侠或古装。仙侠必须让“修行世界怎样运作”进入可见关系。

`优先证据`：

- 人物与身体：凡人、体修、剑修、丹修、妖修等不是职业标签，而在姿态、运动、照料、身体与环境反馈中有差异。
- 服装妆造：以中国衣冠语法为基础，但由门派制度、修行资源、仪式、行动能力和非凡材料重新组织轮廓、层级、穿法与表面；不是现代紧身衣加古风外壳，也不是统一影楼长袍。
- 场景：山门、洞府、飞舟、药圃、试炼地等由修行制度和超常资源决定尺度、路径、材料、光源与维护，而不是现实古建加云雾。
- 材料与色彩：稀有、透光、轻重异常或能量反应必须有世界来源和阶层分配；色彩可清透、浓烈、幽暗或朴素，关键是与门派、功法、资源和情绪同向，不是统一灰蓝。
- 运动与物理：衣料、风、武器、能量和环境可以有非日常反馈，但必须受修行体系约束；不要求每人发光。

`最近相邻`：武侠、古装历史、中国神话、东方玄幻。

`仙侠归属测试`：

1. 去掉宗门、师兄、境界等称谓，画面是否仍显示修行世界，而非普通古代江湖？
2. 去掉山雾和悬崖，人物服装、材料、道具、动作或空间是否仍有至少一组修行制度证据？
3. 把人物放进现实武侠客栈是否无需修改？若是，个人设计没有承担仙侠；检查是否存在明确的例外补偿。
4. 群像是否只有颜色和武器不同，还是能读出修行路径、门派制度、资源与身体关系？
5. 仙侠的“仙”来自世界秩序与非凡关系，还是只来自柔光、粒子、飘带和白衣？

`常见失败`：为了避免廉价网游感，把所有超常证据一并删掉，结果退化成低饱和武侠；为了强调仙气，让所有人白衣、长摆、薄纱、悬浮、发光，结果失去人物与制度差异。

### D. 中国神话 / 神魔

`核心承诺`：神祇、异兽、祭祀、天命、宇宙谱系与人间秩序相互作用。

`优先证据`：神格 / 族群 / 祭祀身份、象征性身体与器物、宇宙层级、庙宇祭场或神域、仪式色彩与材料、非人尺度和运动。

`最近相邻`：仙侠、历史传奇、民俗奇幻。

`边界`：神话强调神灵谱系、象征与祭祀宇宙；仙侠更强调个体修行、门派和境界路径。敦煌飞天、道教神像、藏传图像等各有具体宗教与历史语境，不能当作万能仙侠装饰包。

### E. 东方玄幻 / 架空奇幻

`核心承诺`：以东方文化资源建立架空世界，规则可跨历史、神话、奇幻与原创文明。

`优先证据`：明确的世界资源、族群、技术 / 法术、制度、形态与材料系统；文化来源经重组后仍有逻辑。

`最近相邻`：仙侠、中国神话、高幻想。

`边界`：如果修行体系和中国宇宙观是主要组织力量，更接近仙侠；若重点是多文明、多族群、架空政治与原创魔法，更接近东方玄幻。

### F. 高幻想 / 史诗奇幻

`核心承诺`：完整的异世界文明、族群、魔法与历史冲突，个体行动连接文明尺度。

`优先证据`：地理与文明差异、族群形态、材料技术、魔法代价、权力建筑、纹章与语言系统、旅行尺度。

`最近相邻`：神话、童话、黑暗奇幻、历史史诗。

`误判信号`：披风、城堡、盔甲、精灵耳和蓝色魔法组成通用游戏皮肤；不同国家只换颜色。

### G. 科幻

`核心承诺`：科学、技术或宇宙条件改变人类生活、伦理和社会结构。

`优先证据`：技术原理与限制、人体 / 机器接口、工程材料、能源与维护、尺度、界面信息、环境适应和技术造成的社会差异。

`最近相邻`：赛博朋克、太空歌剧、近未来惊悚。

`边界`：科幻不等于金属舱、蓝光UI和宇宙；关键是技术怎样改变日常与选择。太空歌剧可更神话化，近未来应更接近日常基础设施。

### H. 赛博朋克 / 科技黑色

`核心承诺`：高技术与低生活、高度网络化与权力失衡同时可见。

`优先证据`：身体商品化、企业 / 平台权力、城市基础设施、临时改装、界面渗透、拥挤垂直空间、人工光与潮湿 / 污染材料对比。

`最近相邻`：一般科幻、黑色电影、反乌托邦。

`误判信号`：紫蓝霓虹、雨夜、汉字招牌和义体就是赛博朋克；人物生活和制度冲突完全不可见。

### I. 黑色电影 / 犯罪惊悚

`核心承诺`：欲望、秘密、危险和道德不确定性通过城市、关系与观看位置逐步收紧。

`优先证据`：遮挡和监视、有限光源、高反差或被污染的色彩、权力空间、人物距离、反射、夜间城市、证据物与不可靠视角。

`最近相邻`：侦探、犯罪现实、心理惊悚、赛博朋克。

`边界`：黑色不只是一套低调光滤镜；如果人物关系、空间权力和心理困境没有进入构图，再黑也只是夜景。

### J. 恐怖 / 民俗恐怖

`核心承诺`：熟悉世界的规则变得不可靠，人物对身体、空间、时间或共同体失去控制。

`优先证据`：被破坏的日常秩序、空间禁区、声音与不可见来源、身体边界、重复 / 缺失、共同体仪式、材料腐败与时间痕迹。

`最近相邻`：惊悚、奇幻、宗教 / 民俗题材。

`边界`：恐怖不等于阴暗、血、娃娃、红衣和跳吓；民俗恐怖必须理解习俗的社会功能与具体语境，不能只借符号制造异域感。

### K. 现实主义 / 家庭 / 都市生活

`核心承诺`：人物的选择受具体生活条件、关系、劳动、资源和社会环境影响。

`优先证据`：准确的职业与阶层物质条件、身体和衣物使用痕迹、空间功能、自然光与实用光、人物距离、日常物件的状态。

`最近相邻`：偶像爱情、轻喜剧、社会议题、犯罪现实。

`边界`：普通不等于平均。真实生活中的选择、照料、磨损、秩序和矛盾依然构成设计。

### L. 爱情 / 偶像 / 女频幻想

`核心承诺`：人物魅力、关系距离、欲望投射与情绪回报被视觉优先组织。

`优先证据`：选角与妆造的吸引力、服装身份幻想、皮肤与发丝质感、关系视线、近景友好光、色彩情绪、空间中的亲密 / 权力距离。

`最近相邻`：都市现实、青春、古偶、仙侠爱情。

`边界`：高颜值、磨皮、大眼、柔光和昂贵服装只能提供表面吸引；人物身份、关系张力和世界归属仍需成立。女频审美也不是所有女性角色同一种白幼瘦和同一种妆。

### M. 喜剧 / 讽刺

`核心承诺`：规则、身份、行为和结果之间的错位被清楚看见。

`优先证据`：信息先后、构图关系、表演节奏、道具因果、空间阻力、预期与结果对比；色彩和造型可辅助但不代替笑点。

`最近相邻`：家庭、浪漫、荒诞、动作喜剧。

`边界`：鲜艳、夸张表情和滑稽服装不自动构成喜剧；如果删掉表面装饰后没有关系错位，就只是卡通化。

### N. 末日 / 废土 / 反乌托邦

`核心承诺`：资源、制度、环境灾难或控制系统改变人的生活组织。

`优先证据`：资源稀缺与分配、维修拼接、防护与负重、基础设施残留、制度标识、环境侵蚀、群体生存策略。

`最近相邻`：一般科幻、战争、恐怖、赛博朋克。

`误判信号`：尘土、破车、防毒面具和橙青调色组成通用废土；人物物资和空间没有使用逻辑。

### O. 动画 / 儿童 / 童话（媒介与受众叠加层）

`核心承诺`：通过清楚形态、节奏、情绪和可理解的世界规则服务特定年龄与观看方式。

`优先证据`：可读剪影、形态对比、颜色层级、表情与动作可读性、威胁强度、材质简化逻辑、重复规则。

`最近相邻`：高幻想、家庭、喜剧、冒险。

`边界`：动画不是统一大眼高饱和；儿童向也不等于幼稚。它是媒介 / 受众层，仍需与主题材合同组合。

## 四、混合题材的处理

不要把两套元素各取一半。写清三件事：

```text
主类型保证什么第一眼承诺：
辅类型改写哪些通道：
冲突时保留什么、舍弃什么：
```

示例：`仙侠 × 轻喜剧`可以由仙侠负责世界、服装、材料与运动物理，由轻喜剧改写人物表演、信息节奏和道具因果；不能因为是喜剧就把世界降级为影楼古装，也不能为了证明仙侠让每个笑点都依赖法术特效。

`仙侠 × 女频爱情`可以由仙侠负责修行制度与世界归属，由爱情类型强化选角、妆造、关系距离、光线和情绪回报；不能只保留柔光美人和飘带，把修行世界删成背景。

## 五、跨媒介等效

真人、2D、3D和AI生成要保留的是视觉关系，不是逐词复制：

- 真人：材料可信、身体受力、妆造与光源、实景 / VFX接口最敏感。
- 2D：轮廓、色块、线条密度、形变与帧间可读性最敏感。
- 3D：模型拓扑、材质响应、毛发衣料、光照与相机尺度最敏感。
- AI生成：显著名词会压过关系，容易落入训练数据平均值；提示词需先给身份与题材视觉合同，再给承重形态、色彩、材料、光影和反例，避免元要求。

跨媒介验证写`固定关系 / 等效实现 / 允许变化 / 失败表现`，不要求所有媒介生成一模一样的表面。

## 六、来源与证据边界

以下来源支撑的是方法，不是具体项目答案：

- 美国电影艺术与科学学院的服装与美术教育材料，把服装、场景、色彩、线条、形态、纹理和光线视为共同讲故事的工具，并强调服装要与场景和灯光协作：<https://www.oscars.org/videos-photos/academy-academy>、<https://www.oscars.org/sites/oscars/files/costumes_and_makeup_activites_guide.pdf>、<https://www.oscars.org/sites/oscars/files/complete_art_direction_activities_guide.pdf>。
- Costume Designers Guild把服装定义为视觉叙事，能够传达身份、时代以及幻想与现实的关系：<https://costumedesignersguild.com/what-is-costume-design/>。
