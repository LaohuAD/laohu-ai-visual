# 模式判定与块级切换

## 一、判定合同

语言模式不是整份文档只能选一次的风格标签。每当接收者、文本块或工作任务改变，就重新形成一次最小判定：

```yaml
current_role: 当前专业角色
work_phase: communicate | create | explain | handoff
artifact_type: 剧本 | 资产规格 | 图片提示词 | 视频提示词 | 声音提示词 | 方案 | 其他
block_type: 当前文本块类型
speaker: 人物姓名 | 制作方 | 系统说明
receiver: 老胡 | 观众 | 演员 | 制作人员 | 下游Skill | 图片模型 | 视频模型 | 声音模型
purpose: 要让接收者理解、感受、表演、决定或执行什么
domain_authority: 拥有内容事实的Skill
fixed_facts: 不得改写的事实、原句、编号、资产和硬约束
allowed_information: 当前发声身份有权使用的信息
forbidden_leakage: 不得混入的作者解释、人物心理、内部规则或模型术语
voice_profile: 人物声音或项目协作声音；无则为空
scene_state: 当前情绪、关系、动作与压力；无则为空
language_mode: 当前唯一主模式
required_references: 当前模式必须读取的权威资料
return_owner: 内容不足或冲突时退回谁
```

先判接收者与任务，再判文本块；最后再叠加人物声音与场景状态。先模仿口吻、再猜文本用途，会把风格当成内容身份。

## 二、模式解析顺序

```text
1. 谁拥有内容事实？
2. 这段文字交给谁？
3. 对方拿到以后要理解、决定、表演还是执行？
4. 当前是整份产物，还是其中一个文本块？
5. 哪些事实、原句和约束不能改？
6. 当前身份没有资格知道或说出什么？
7. 选定一个主模式，再加载必要声音与专业合同。
```

| 接收者与任务 | 模式 |
|---|---|
| 老胡需要理解、比较、决定或知道进度 | `USER_COMMUNICATION` |
| 创作者或制作人员需要理解取舍、范围与交接 | `PRODUCTION_NOTE` |
| 剧本读者需要快速定位镜头 | `SCRIPT_HEADER` |
| 观众将直接看到或听到事件 | `SCRIPT_ACTION` |
| 演员、配音或视频负责人需要知道一句话怎样说 | `PERFORMANCE_CUE` |
| 戏中人物正在对另一个人物或观众做事 | `CHARACTER_DIALOGUE` |
| 生产角色需要知道镜头外的连续性或限制 | `SCRIPT_NOTE` |
| 下游要稳定复现一个对象 | `ASSET_SPEC` |
| 图片模型要生成一个静态时刻 | `IMAGE_PROMPT` |
| 视频模型要生成一段时间因果 | `VIDEO_PROMPT` |
| 声音模型或配音执行者要生成可听结果 | `AUDIO_PROMPT` |

## 三、一个块只能承担一个主要身份

相邻不等于同类。下面这句话把四种身份塞进了一个括号：

```text
Luna（确认他就是故意的，短促冷声宣判，不再接受撤回）：晚了。
```

- “确认他就是故意的”是人物理解，若对后续成立必需，应先在动作正文中给可见触发与反应。
- “短促冷声”属于可听表演。
- “不再接受撤回”是剧情阶段的作者说明，应由前后行动证明，或进入必要的 `SCRIPT_NOTE`。
- “晚了”才是人物原话。

拆块不是把句子写长，而是让每种信息去正确位置：

```text
△ 老胡在画外憋不住，漏出半声笑。Luna 的笑意当场停住，握着遥控器的指节一点点收紧。
Luna（怒意压到爆发前，声音低冷而短，最后一次逼他改口）：晚了。
```

动作正文仍应优先使用直接可见可听的证据。前文事实可以帮助编剧判断人物，但不能变成观众当下看不见、听不到的作者判词。

## 四、混合文档逐块换挡

正式剧本通常按下面的顺序连续切换：

```text
SCRIPT_HEADER
→ SCRIPT_ACTION
→ PERFORMANCE_CUE
→ CHARACTER_DIALOGUE
→ SCRIPT_ACTION 或 SCRIPT_NOTE
```

制作方案可能在 `PRODUCTION_NOTE` 中引用人物台词。引号里的台词仍按 `CHARACTER_DIALOGUE` 检查，外面的解释仍按 `PRODUCTION_NOTE` 检查。引用不会让两种体裁合并。

## 五、失败返回

- **模式不清：** 补齐 `receiver / purpose / block_type`，不使用“自然一点”的通用口吻碰运气。
- **事实不足：** 返回 `domain_authority`。动作缺速度来源就回编剧；资产缺稳定特征就回资产设计；视频缺镜尾就回视频或上游剧本。
- **规则冲突：** 用户锁定事实、内容权威与模型硬约束优先。语言模式只在剩余空间内调整。
- **局部污染：** 只重写受污染文本块，不统一重写整份文档。
- **保护项将被改变：** 停止改写，返回原负责人或请求用户决定。

返回时必须指出缺的内容合同和原负责人，不能只说“需要进一步明确”。
