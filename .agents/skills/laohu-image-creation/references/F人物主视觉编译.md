# 资产规格与编译



人物资产图写法：

```text
F人物主视觉图：使用擅长人物审美与角色塑造的模型，把人物设计正文、服装设计正文和妆造补充正文编译成一张有当下目的、关系对象和未完成状态的角色成图。三段职责必须成立，标题可以显式或融合；正式正文优先保持连续的镜头可执行画面叙述。氛围与画质接入美术风格设计交接包已经确认的名称锚点、可迁移机制与结果图成像合同；画面内容与构图明确人物正在做什么、看向谁、摄影机站在哪里、主证据需要多大、环境怎样参与而不抢人。景别可以是头肩、半身、七分身或全身，不为拆解强制完整身体和裁切安全。它是供人类判断人物是否真正成立的角色主视觉，不是技术规格板。人工确认后，同编号B从F反推可见脸身并用人物正文补齐参数，同编号W从F和服装设计正文反推服装结构，同编号M从F、B、W和妆造补充正文还原最终造型。F不直接进入首帧、封面或视频。

F的编译合同只承接：角色母型与第一眼气质；一个关系瞬间或人物状态；少数脸身、服装、妆发锚点；一个摄影观看方式；一个统一题材先验。服装只锁可识别母型、整体轮廓、主色关系、主要材料行为和一个人物化结构记忆点；脸部只锁稳定身份关系与本次表情方向。不可见背面、内里、鞋履工程、纹样排列和次级配件归入模型补全，或由下游B / W / M结合专业正文处理。

```


- F人物主视觉图：用擅长人物审美的模型，把人物设计正文、服装设计正文和妆造补充正文编译成一张面向观众的角色成图。F先让人物在一个符合长期性格的小目标、关系对象和未完成动作中成立，再让脸身、服装、妆发、空间、色彩和光影共同服务这一瞬间。B从F提取可见脸身证据并用人物正文补足比例；W提取可见服装效果并用服装正文补足背面、内里和鞋履；M提取可见妆发与整体质感，并结合B、W和妆造正文补足侧背面。F不直接进入首帧、封面和视频，也不替代三项正式资产。
