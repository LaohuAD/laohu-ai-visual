# 模板内的表演与情绪方法

> 归属：本主题的唯一负责人。由《模板_视频提示词_基础设定氛围画面内容》按完整主题块拆出；正文信息、表述方式与信息密度未改，编号与标题层级按独立模块重新编排。

## 表演与情绪方法

情绪转折镜头按 `起点情绪 → 可见 / 可听触发 → 表演、摄影、光色和声音变化 → 终点情绪` 写进同一段自然语言。没有触发和变化路径时，拆成两个镜头分别承担情绪，不用“情绪复杂”代替导演调度。

复杂对白、沉默反应、15-30 秒长表演、多人对手戏或模型容易提前泄露结果时，正文前先完成内部演员节拍表：`时间段、人物目的、情绪变化与保护策略、精确触发、面部动作与可选 AU、目光身体与关系距离、声音呼吸与停顿、结束状态与静止反应`。`禁止提前反应` 作为贯穿约束，写明哪一个触发或峰值之前不得落泪、崩溃、吼叫、退缩、微笑、转身或完成后续动作。

八维在内部默认完整判断，正式正文不增加八个标签。功能表演只写态度、可见动作 / 声音和结束状态；单次承重转折把人物目的、保护策略、触发、足以辨认本次变化的承重通道（单一通道可以成立）、禁止提前和结束状态压进一个因果句；复杂长表演按节拍写 `上一状态 → 新触发 → 本次变化 → 新结束状态`，场景、身份、基础声线和已经成立的状态只写一次。某维会改变结果且不能由当前镜头块可靠继承时必须写入；只有不适用或本节拍没有变化时才省略。

正式压缩只删重复，不删承重因果：先删作者解释、理论名称、重复外观和同义情绪词，再合并字段标签、上移全局不变量、后续只写变化量。AU 先用自然语言动作支撑，只在近景且确有校准价值时附 1-3 个；AU 不是情绪公式，FACS A-E 不与工具 0-5 混写。字符仍超限时删非承重效果或拆批，不删人物目的、精确触发、禁止提前反应和结束状态。

写正文前先做情绪入场分流，不新增正式字段：文戏先问 `人物想从关系中得到什么、阻力是什么、第一有效节拍用哪句台词 / 沉默 / 反应 / 距离变化让观众感到它`；武戏先问 `危险从哪来、谁掌握主动、第一有效节拍用哪次预载 / 逼近 / 选择 / 结果让观众身体上感到它`。混合镜头逐节拍确定谁主导，另一类内容只加强主情绪。
