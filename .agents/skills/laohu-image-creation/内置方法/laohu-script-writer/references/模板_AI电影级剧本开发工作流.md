# 模板_AI电影级剧本开发工作流

> 来源：由研究文档《在 AI 时代如何一个人借助 AI 写一个电影级剧本》沉淀。  
> 用途：用于一个人借助 AI 从原始想法推进到短片、长片或 AI 视觉作品剧本。

## 一、完整流程

```text
原始想法
→ 故事种子
→ 主题和类型
→ 人物核心
→ 世界观和规则
→ 故事引擎
→ 节拍表
→ 场景列表
→ 分场大纲
→ 第一版剧本
→ 剧本医生诊断
→ 第二版剧本
→ 视听化拆解
→ 可拍性评估
→ 最终剧本
```

## 二、故事种子模板

```text
一个【具体身份的人】，因为【诱发事件】，必须在【时间或条件限制】内完成【明确目标】，否则他会失去【具体代价】。
```

必须包含：

- 人物
- 目标
- 阻力
- 代价
- 时间压力

## 三、人物模板

每个核心人物至少填写：

```text
人物：
表层目标：
深层需求：
错误信念：
恐惧：
能力：
关系压力：
最后必须做出的选择：
```

## 四、故事引擎模板

```text
目标：
外部阻力：
内部阻力：
规则：
时间压力：
信息差：
代价升级：
不可逆选择：
```

## 五、剧本医生诊断维度

```text
故事核心：
主角目标：
冲突与阻力：
人物弧光：
场景功能：
台词问题：
视听表达：
可拍性：
最大风险：
修改优先级：
```

## 六、老胡项目使用原则

- 优先从 3 分钟到 10 分钟短片跑通闭环。
- 剧本必须能继续拆成图片提示词和视频提示词。
- 不要只写故事，要写可拍、可生成、可剪辑的故事。
- AI 可以当编剧工作室，但老胡必须保留作者判断。
