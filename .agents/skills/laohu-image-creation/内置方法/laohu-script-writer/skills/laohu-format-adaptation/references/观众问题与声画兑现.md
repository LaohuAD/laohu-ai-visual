# 观众问题与声画兑现

> 归属：本主题的唯一负责人。由《模板_视频提示词_基础设定氛围画面内容》按完整主题块拆出；正文信息、表述方式与信息密度未改，编号与标题层级按独立模块重新编排。

## 观众问题—声画兑现

悬念、寻找、误判、揭示、倒计时、问题解决或知识解答承重时，生成前在代码块外补一张内部校准卡，不作为第四段投喂模型：

```text
【观众问题—声画兑现】
当前问题 / 已知与暂时判断 / 本拍处理：建立、加压、延迟、部分回答、回答或改写 / 新增证据与信息增量 / 声画兑现 / 可读等待窗口 / 下一问题怎样由当前结果产生。
```

校准卡只决定哪些动作压缩、哪些证据需要辨认与反应时间、哪个角度真正改变信息权限。正式`【画面内容】`仍只写可见 / 可听事件，不出现“让观众着急、此处揭示答案、故意放慢”等作者解释。没有具体问题的氛围、歌舞和低烈度观察不强制填写。
