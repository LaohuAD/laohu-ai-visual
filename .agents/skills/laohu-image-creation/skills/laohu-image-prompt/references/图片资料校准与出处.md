## 15. 外部资料校准

本次结构参考并校准了以下官方资料，只吸收跨模型成立的原则，不把单个平台参数写成普遍规则：

- Google Cloud Imagen 提示和图片属性指南（来源：`https://cloud.google.com/vertex-ai/generative-ai/docs/image/img-gen-prompt-guide`）：官方基础骨架强调主体、背景 / 环境和风格，并通过摄影位置、光线、材质与迭代增加控制。本项目在此基础上把“时间”升格为光影上游锚点。
- Midjourney Prompt Basics（来源：`https://docs.midjourney.com/hc/en-us/articles/32023408776205-Prompt-Basics`）：官方强调主体、介质、环境、光线、颜色、情绪和构图，同时指出重要细节越少，模型自由度越高。本项目把这些维度组织为开放属性空间，而不是固定清单。
- OpenAI GPT Image Generation Models Prompting Guide（来源：`https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide`）：官方建议保持一致结构，明确场景、主体、关键细节、用途、构图、视角、人物尺度、视线和物体交互；相机规格主要用于高层观感与构图，不假设模型精确模拟物理镜头。

外部资料负责确认共同规律，老胡的实际生成反馈负责决定本项目怎样落地。后续仍要用首测结果校准四锚点的描述密度、模型差异和参考图权重。
