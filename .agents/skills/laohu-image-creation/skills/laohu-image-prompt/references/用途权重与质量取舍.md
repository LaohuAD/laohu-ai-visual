# 用途权重与质量取舍

用途、主次或质量冲突不清楚时读取：同一张图在不同用途下承重特征不同，本文件给出用途权重、特征交集顺序、描述顺序和成图验收与停止条件。适用于叙事成品、制作资产、教程演示等需要取舍的图片任务；已有明确有效结果或已锁定的用途取舍直接继承，不用本文件重开。

## 基本取舍

本文件把高质量图片的特征分成两类：

```text
不变骨架资产：
AI 图片天然需要的画面类型、主体、构图、光影、色彩、材质、风格、参考关系和用途字段。

开放审美特征资产：
高质量图片中反复出现、可识别、可组合、可变体、可增益的视觉质量因子。
```

这里的“特征”不是一句抽象评价，而是一组能在画面里被看见、放大、复现、变体化调用的视觉机制。

一个高质量图片不需要命中全部特征。它更像一组视觉基因：承重位置命中少数关键特征，图片会明显脱离平均生图；多个特征在主体、构图、光影、色彩、材质、风格和用途里互相支撑，图片上限会继续抬高。因此本文件必须按“骨架强制、特征择优”的方式理解。

```text
正向收束：
图片开发优先描述目标画面已经成立后的状态，用清晰主体、准确光影、稳定色彩、真实材质、明确构图、专业妆造和具体镜头语言共同收束生成范围；正向特征越具体、越专业、越能互相限定，模型可进入的画面范围越小，输出越稳定。

特征交集：
每个词负责一个维度，多个维度交叠后形成清楚的审美坐标。

承重优先：
只把最高权重特征放在最重要位置，辅助特征服从主特征。
```

一张图只证明一个唯一承重结果，最多保留一项明确从属的次要结果；从属项不得与主结果争夺第一注意力。

## 图片用途权重

不同用途的承重特征不同。

```text
人物素体形象资产：
脸型、五官、身材、身高、身体比例、基准体态、永久辨识特征和属性说明承重。

人物服装资产：
四区服装结构、版型、层次、材质、颜色、穿戴顺序、活动余量和局部来源关系承重。

人物妆造设计资产：
素体身份、服装上身结果、最终发型、妆容和正背面连续性承重。

人物成品人像：
第一眼气质、脸、体态、服装、光影、情绪和信息留白承重；它不替代三资产。

场景资产：
空间结构、光源、入口、反打、可表演区和尺度承重。

道具资产：
轮廓、材质、比例、状态、使用痕迹和可特写承重。

封面：
主体突出、视觉钩子、标题留白、对比、情绪和缩略图识别承重。

首帧：
视频连续性、人物姿态、光源方向、焦点、动作起点和尾帧可接续承重。

故事板：
构图、景别、机位、主体比例、站位、动线、留白和空间锚点承重。
```

### 用途优先级

图片用途决定特征权重。

```text
人物素体形象资产：
同一人物脸与身体一致性、头部特写可读性、左45度 / 正面 / 背面全身关系和属性准确优先。

人物服装资产：
头部穿戴、上半身、下半身、足部的结构可读性，局部细节来源准确和服装账本统一优先。

人物妆造设计资产：
同一素体与服装的组合一致性、最终发型妆容、配饰位置和三张全身视图连续性优先。

人物成品人像：
脸部吸引力、人物气质、身衣适配、妆容肤色和第一眼记忆点优先。

人物棚拍状态图：
真实人像光影、肤色妆效、表演状态、肩颈胸部以上构图和镜头亲近感优先。

场景资产：
空间结构、光源方向、可表演区、反打视角和动线优先。

道具资产：
轮廓识别、材质触感、比例关系、使用状态和可特写边缘优先。

封面海报：
主体视觉冲击、缩略图可认、情绪钩子、标题空间和颜色对比优先。

视频首帧：
动作起点、主体姿态、光源一致、焦点稳定、尾帧可接续优先。

故事板：
景别、构图、人物站位、镜头方向、空间关系和情绪表演优先。
```

信息密度同样按用途分布：高质量图片的信息不是越多越好，而是围绕用途集中。

```text
高信息区：
脸、手、道具核心、服装关键结构、标题钩子、空间入口、动作起点。

中信息区：
衣料整体、背景主体结构、环境材质、光影层次、辅助道具。

低信息区：
天空、墙面、暗部、虚化背景、海面、雾气、远景和边角。
```

高信息区承载细节，中信息区承载关系，低信息区承载呼吸。三者分开后，画面既丰富又稳定。

## 同一特征在不同用途中的变化

用途改变时，同一条特征的权重、证据和验收标准都会变，这就是上面两张表存在的原因：

- 同一项留白、对比或细节密度，在制作资产里服务结构、比例和一致性可读，在封面里服务缩略图识别与标题空间，在叙事成品里服务主情绪与第一视觉。换用途而不换证据，等于用另一套标准验收。
- 信息密度的落点随用途移动：制作资产的高信息区集中在身份、结构与材质可读处；封面集中在主体与钩子；故事板和首帧集中在构图、站位、动作起点和可接续关系。
- 用途先决定最高目标：叙事成品传递主情绪，制作资产锁身份与一致性，教程演示保证理解与行动。目标不同，同一条特征是否算“做够了”也不同。
- 知识图、数据图和教程图另有边界：不伪造关系、量值与先后，不以审美压过准确性；承载量值的层按[信息设计](../../laohu-art-direction/skills/laohu-information-design/SKILL.md)交确定性制作，不能用模型生成的柱形只贴正确数字冒充正确图表，条件见[专业判断与编译](专业判断与编译.md)。
- 因此本文件不制定万能风格：用途改变时，不适配的特征要退让或删除，而不是把各用途的承重项同时保留。参考图职责、资产组分工和风格继承分别由[参考图职责资产](../../laohu-art-direction/references/参考图职责资产.md)、[风格继承与图片编译](风格继承与图片编译.md)等负责人承担，本文件只决定权重与取舍。

## 六步特征交集法

六步是内部推导顺序，不是交付表格；简单图直接继承已确认取舍，跳过已有结论的环节。每一步都来自本文件的骨架强制、特征择优、正向收束、用途权重与成图验收条件。

```text
第一步 定用途与最高目标：
叙事成品传递主情绪，制作资产锁身份与一致性，教程演示保证理解与行动；用途先决定信息优先级。

第二步 定骨架：
把画面类型、主体、构图、光影、色彩、材质、风格、参考关系和用途字段这些固定槽位填到成立；骨架强制，不用特征词替代结构。

第三步 选承重特征：
从开放审美特征资产里只挑承重位置上的少数关键特征，把最高权重特征放在最重要位置，辅助特征服从主特征。

第四步 多维交集并互相限定：
每个词负责一个维度，用主体、光影、色彩、材质、构图、妆造、镜头和用途把目标状态圈准；正向特征越具体、越能互相限定，模型可进入的画面范围越小。

第五步 按用途调整权重与信息密度：
按用途权重和优先级重新排主次，把细节集中到高信息区，中信息区承载关系，低信息区承载呼吸。

第六步 验收与停止：
逐项核对成图验收条件；已有明确有效结果、已锁定内容或已确认取舍不再重做；未确定条件明确保留，不用推测补成事实。
```

## 单条成品图的交集描述顺序

单条成品图（结果图、封面主体、叙事成品）按下面列出的关系与先后把交集落进正文；已有模板的制作板、图文知识图按各自模板执行，本顺序不覆盖。

```text
用途先决定最高目标：叙事成品传递主情绪，制作资产锁身份与一致性，教程演示保证理解与行动。
主体或主关系有清楚的第一注意力。
构图、光影、时间、场景、色彩、材质和风格按贡献选择，不要求全部出现。
被选中的人物、场景、道具、时间与风格信息形成因果，不互相削弱目标。
图片用途决定信息优先级，而不是所有信息平均铺开。
参考图职责清楚，图片资产组分工明确。
人类抽象词已经翻译成裁切、位置、光源、焦点、姿态和材质等可见事实。
所有分类和示例都作为开放推导入口，不限制 AI 发现新的有效属性。
提示词使用正向、高密度、模型可读的视觉语言。
```

顺序只决定描述的关系与先后，不是新增栏目，也不改变各用途原有模板的一级结构。机制与描述粒度层面的编译顺序（锚点怎样推导、抽象词怎样具象化）见[图片提示词机制与描述粒度](图片提示词机制与描述粒度.md)；本节只管内容权重与优先级。

## 成图验收与停止条件

高质量 AI 图片不是被关键词堆出来的，也不是被高清参数堆出来的。它是在稳定骨架里，让关键开放位置命中足够具体、足够互相支撑的视觉特征，并按用途验收：

- 用途先决定验收标准：叙事成品看主情绪与第一视觉是否成立，制作资产看身份、结构、一致性和下游调用是否成立，教程演示看理解与行动是否成立。
- 不要求命中全部特征；承重位置的关键特征是否真的承重，比特征数量重要。
- 已有明确有效结果、已锁定内容、已确认用途取舍不重开；只重开尚未确认的选择。
- 生成前只验设计与可执行性，生成后按真实图像复验；两种证据分开记录，固定句存在只证明指令已加入，不证明图像已经达到预期。
- 未确定条件明确保留，不用推测补成事实；无法说明结果为什么成立的漂亮，不升级成长期方法。

这份定义的用途不是告诉 AI“按步骤生图”，而是扩大 AI 对高质量图片的可识别特征库：特征越细、越具体、越能组合，生成时能圈住的高质量区域就越小，图片越有机会成为可复用、可剪辑、可发布的视觉资产。
