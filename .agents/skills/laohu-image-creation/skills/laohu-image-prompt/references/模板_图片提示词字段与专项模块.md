# 图片提示词字段与专项模块

> 归属：本文件是 `laohu-image-prompt` 的字段防漏规格，与《风格继承与图片编译》第7节“图片提示词”同属一个负责人。第7节决定结果身份与三段职责，本文件只补“本张图启用后的必要项目有没有答全”。**不新增第二套一级结构**：结果图写真继续用`基础设定 → 氛围与画质 → 画面内容与构图`三段职责，本文件列出的是各段内部的必答覆盖项与按条件启用的专项模块。


> 正文写法同视频镜头正文：**具体描述 ＋ 术语总结**，前段必须有、后段可无；术语是对具体描述的概括，不能取代它。见 `../../../../laohu-video-prompt/skills/laohu-video-compilation/references/镜内必答项与C方头字段.md`。

## 一、字段的三种状态

每个启用后的字段只允许三种状态，不能留第四种：

```text
具体决定：写出本次真正采用的对象、范围、程度和时序。
不适用并给出理由：说明为什么本张图不需要这一项，例如“本镜脸在画外，无需妆发描述”。
草稿阶段的待确定：明确标注为草稿待定，供下一轮补齐。
```

正式可生成稿不能留下未解决的关键项，也不能把未知伪装成“不适用”。“保持固定”“无新增特效”“可见范围内没有配饰”都是决定，可以照写。未看见的服装、不可观察的参考图细节不要为了填空捏造；只依据上游设计或获准的原创范围处理。

## 二、宏观与微观如何分工

**宏观段落负责把单一画面关系写完整**：主体、场景、彼此关系、当前动作状态、主要观看内容和整体气质，用连续自然语言一次讲清。

**微观字段负责可核对的观察位置、清晰范围、光色材料、动作相位**：位置、比例、方向、范围、程度这类需要防止模型随机补全的项目。

两条纪律同时成立：

```text
允许必要关键词重复以明确绑定对象；不把同一整段改换标题重复五遍。
前后矛盾必须在提交前修复；不采用“后面的字段覆盖前面的正文”。
```

## 三、共用的必答覆盖项

适用于结果图写真与叙事成品图。已经进入正文的项不重复写，缺项按第一节的三种状态补齐。

```text
画面用途：这张图的实际用途。它是路由信息，放在可复制正文之外，不替代可见描述，也不在模型正文里写成一长段营销判断。
视觉风格：媒介、表现方式、线条或成像质感；保护已定风格。
画面气质：整体感受，并落到可见关系，不只写几个情绪词。
主体与状态：主次对象、数量、身份及本时刻状态；“主体”可以是人、物、空间、图文或多个对象的组合。
场景与交互：位置、接触、遮挡、道具归属及环境关系。
构图：位置、比例、层次、引导关系、留白和边缘裁切。
色彩：主辅色、明度与饱和度关系、需要保护的颜色。
光影：光源、方向、光质、主辅明暗及与主体的关系。
材质：本次可见的关键材料、纹理尺度和表面状态。
```

摄影模块在本张图确实由摄影机成像时启用；纯二维信息图在完整检查稿写明不适用，正式输出改用第五节模块，但**不能因此把构图、色彩和图形层级也跳过**：

```text
观察方位：相对哪个主体的正面、侧面、背面或斜侧。
俯仰与倾斜：观察的俯仰方向；画框倾斜另说。
机位高度：相对地面、桌面或主体的实际观察高度。
取景锚点：这次重点落在哪个可见部位或物件。
景别与取景范围：保留多少主体和环境，哪里被裁切。
对焦对象：哪一个或哪些对象需要清晰。
景深：哪些前后层次处于可接受清晰范围。
焦外表现：前景、背景哪些失焦，程度及仍需保留的辨认信息。
曝光与成像：重要亮暗信息的保护、必要的运动清晰度与光学痕迹；不凑参数。
```

最后一类为质量与保护：继承身份、结构、文字、已定设计与材质保护要求，并包含本项目原有的**减少假纹理假细节**要求。

### 减少假纹理假细节的原文条件（不得执行成磨皮）

已有完整规则见本专业 `SKILL.md` 的“全部图片的细节质量要求”。这里只强调三条执行边界：不能把它执行成磨皮、模糊、去除天然纹样或抹掉已确认设计；艺术风格本身需要的笔触、颗粒和纹样按已确认用途保留；固定句存在只证明指令已加入，效果必须看真实图像。

## 四、按条件启用的专项模块

先判断本图命中哪些触发条件，启用后使用固定标题回答；未启用的模块不进正文。

| 触发条件 | 应启用的固定专项字段 | 不得做的事 |
|---|---|---|
| 有人物或类人角色 | 人物外观、服饰、配饰、妆发、姿态表情 | 为填字段描述镜外不存在的鞋，或自行更换已定脸型 |
| 主体是产品、道具或设备 | 形体结构、功能部位、比例尺度、操作关系、表面标识 | 只写“精密”，忽略结构或无意新增按钮 |
| 建筑、室内或景观 | 空间层次、尺度参照、路径出入口、结构和陈设、环境状态 | 把实体空间布局与图上构图当同一项 |
| 封面、海报或知识图 | 准确文字、信息层级、图文版式、图形编码、单位与标注、阅读顺序 | 编造数据、错字、同色不同义或只用颜色区分关键内容 |
| 图像编辑 | 修改区域、保护区域、编辑强度、身份结构保护、边缘与光色衔接 | 为修景深重做人物身份或全部画面 |
| 一致性资产 | 身份固定项、当前状态、取景资格、实际参考职责、下游使用条件 | 以普通成品图模板覆盖现有资产编号与校验格式 |

人物类字段与实际画幅必须一致：取景锚点不在脸上时，对焦对象不能又填眼睛；宏观描述没有要求看脸时，妆发不得为了填空强加进画幅。用户把要求改成“眼睛必须清楚”后，要重新协调取景、机位和清晰范围，而不是在末尾再附一句相互竞争的要求。

图形类字段的颜色只作辅助：关键区别同时使用必要的文字、形状或标记，不用颜色作为唯一信息通道。本条按输出用途执行，不把本项目文档审查等同于完整无障碍合规认证。

## 五、二维知识图的等价模块

完全没有模拟空间摄影时，用下列字段替代摄影模块。这不是降低信息量，而是用图文专业字段替代不适用的摄影字段。

```text
视觉风格：二维、手绘、矢量、拼贴或已定表现。
画面气质：整体简洁、严谨、活泼等，并落实到图形组织。
主体与关系：图形、文字、箭头、节点分别表示什么。
构图与版式：网格、对齐、层级、留白和边界。
准确文字：必须逐字呈现的文字。
图形编码：长度、位置、颜色、形状分别承载什么含义。
单位与标注：数据单位、尺度、图例、必要注释；无数据则具体说明。
色彩：颜色职责与对比，不仅靠颜色传达关键区别。
阅读顺序：先看什么，再比较什么，最后得到哪个已确认结论。
清晰与层级：关键图文保持可读；装饰或界面模糊属于合成，不假造光圈。
摄影适用性：没有模拟空间摄影时，机位、焦距、景深不适用。
质量与保护：文字与图形关系正确，减少假纹理假细节，保留已定媒介笔触。
```

二维图仍有位置、层级、遮挡、大小和对比；“不用摄影字段”不等于“无需构图”。内容事实归内容负责人，图形编码归信息设计；本模块只负责把它编译成可生成的可见关系，不在美术阶段补造事实。

## 六、与生成描述的边界

**创作意图与生成描述分开。** 例如“让观众理解她很悲伤”属于制作判断，正式画面写成可见的姿态、动作和现场关系。本项目的微观标题不应被旧规则一概当作作者分析标签；保留旧规则反对无效解释的目的，对新固定字段做准确的适用范围修订，而不是删除全部语言检查。

模型确有不同输入规范时，沿用现有模型适配：保留完整创作母版，把必要决定转入提交版本，记录实际省略和理由。继续沿用现有交付格式，不以“模型喜欢短提示词”为由静默省略用户要求的固定栏目。没有核验的模型长度、时长、帧率、标签功能不能写成通用硬规则。

## 七、提交前检查

```text
宏观段落是否把单一画面关系写完整，没有退化成字段堆砌。
启用后的字段是否都落在三种状态之一，正式稿是否还有未解决项。
摄影模块不适用的二维图，是否真的改用第五节模块，而不是整块留空。
专项模块是否只在实际命中触发条件时启用，字段内容是否与画幅一致。
有没有两组互相抵消的要求被同时写进正文。
代码块外是否写清了说明、跑偏对象和资产边界；代码块内是否只有正向可见结果。
是否明确包含减少假纹理假细节，且没有把它写成磨皮或删设计。
```
