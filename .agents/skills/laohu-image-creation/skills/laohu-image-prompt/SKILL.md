# 老胡图片提示词编译

## 灵魂：本专业怎样取舍

每个词都应改变这张图，而非解释作者。

禁止把专业设计重新概括成电影感、精致、高清；默认输出文本不代表实际生成。

## 筋骨：核心判断与方法路由

读取当前任务目的、已确认事实、可变范围、媒介与上游结果。先判断是否存在“专业判断已完成，需要可复制的图片生成正文”这一缺口；已有有效结论则直接继承。先确定一个任务和一项主证据，再按对象—关系—光材—保护项编译。专业分支、适用条件与反例按Reference执行。

## 血肉：让方法产生差异

本次以“独立可复制正文、参考绑定、画幅与必要保护项”为独立结果，按下方方法将专业控制转成可观察关系。

选择属性绑定、注意力层级、空间关系、参考职责、约束冲突中真正改变本次结果的控制，结合 Reference 中的完整方法、案例与例外形成候选。

只有用户明确授权借鉴视觉风格时，参考图才控制已声明的摄影、色彩、光影或材质表现；上传图片本身不授予全部风格迁移权限。开头用一条精确句说明该图控制与不接管的属性，再写目标对象；不同图分别担任身份、布局、风格或关键帧，不互相覆盖。生产检查图采用便于辨认结构的光线，不能把氛围肖像的强虚化和戏剧光照无条件搬到资产板。

## 表皮：输出与约束

### 全部图片的细节质量要求

本项目每条图片生成及编辑提示词均明确包含「减少假纹理假细节」。这是用户的长期质量要求，适用于人像、场景、静物、制作资产及其他生图用途。编译时同时清理与之竞争的无差别超细节、满屏微纹理或过度锐化要求；按对象保留真实结构、身份辨识、必要文字与有来源的材料特征，使细节随尺度、景深和受光自然变化。不能把减少虚假细节执行成磨皮、模糊、删除已确认设计或抹平所有材料；艺术风格本身需要的笔触、颗粒和纹样仍按已确认用途保留。保留皮肤真实纹理、衣料结构与眼部状态的质量判断；不把中国 / 东亚、哑光、双眼都睁开设成全人物硬规则，受伤、闭眼、正常不对称、其他人群和非写实造型按任务保护。生成后检查重复纹路、无来源刻痕、皮肤噪点和锐化光边，同时复验身份与结构。固定句存在只证明指令已加入，效果必须看真实图像。

返回独立可复制正文、参考绑定、画幅与必要保护项。已锁定的故事、身份、结构、文字和状态按输入保护；模型参数只使用已核验能力。输出专业决定与必要可执行描述，不声称已经生成或实测。图片生成仍须用户授权，不接入参考项目的自动 ComfyUI / 原生生图管线。

## 调用与返回

可由明确点名直接使用，也可由[所属专业入口](../../SKILL.md)按缺口调用。CONSULT返回局部结果，当前作品负责人不转移；缺少上游事实时RETURN最早负责人，不自行改写剧本。需要跨专业判断时只传当前问题和保护项，不重新运行整条生产链。

## 按问题读取

- [专业判断与编译](references/专业判断与编译.md)：执行本专业判断、反例与编译。
- [图片与资产生产合同](references/图片与资产生产合同.md)：当前问题落在正式写图片正文前要确定身份、参考绑定与保护项边界时读取，取得因果描述顺序、注意力合同与选择性编译门。
- [风格继承与图片编译](references/风格继承与图片编译.md)：当前问题落在外观风格已定却编译不出来、或多份材料被拼进同一条正文时读取，取得风格决策与控制对象分流。
- [模板_图片提示词字段与专项模块](references/模板_图片提示词字段与专项模块.md)：结果图写真与叙事成品图编译时读取。字段三种状态、宏观与微观分工、共用必答覆盖项、按条件启用的专项模块、二维知识图等价模块、创作意图与生成描述边界。只补防漏，不新增第二套一级结构。

## 当前文本的语言执行

直接接受局部请求时，也按本包[语言表达](../../references/语言表达.md)先判当前文本块的发声者、接收者与任务。保护原话和专业事实；只补不足的请求不得改变已确认内容。遇到混写或冗余时按该文件选择具体方法，完成后回到本专业验收。

## 按当前缺口读取的补充方法

每条按“未决问题 → 读取 → 返回决定”使用，只进对应主题。

- 本次用途、主次或质量冲突不清：读[用途权重与质量取舍](references/用途权重与质量取舍.md)，返回本图用途权重、骨架与开放特征的取舍、特征交集顺序和成图验收与停止条件。
- 描述该写到多细、四类锚点怎样从开放属性空间推导：读[图片提示词机制与描述粒度](references/图片提示词机制与描述粒度.md)，返回正向提示词密度、主情绪唯一性、主体/场景/时间/风格锚点与目的确定后的执行顺序。
- 审美目标翻不成模型可读的视觉语言：读[模型可读视觉词汇资产](references/模型可读视觉词汇资产.md)，返回摄影、材质与构图三类可用词例。
- 图片由哪些固定槽位构成、哪些问题必须先回答：读[图片不变骨架资产](references/图片不变骨架资产.md)，返回用途层、类型槽位、画面槽位、质量路径与视觉层级。
- 主特征和辅助特征是否互相削弱：读[正向兼容组合关系](references/正向兼容组合关系.md)，返回主风格、辅助特征与局部细节的兼容关系。
- 需要确认哪条规则来自外部资料、哪些只是本项目适配：读[图片资料校准与出处](references/图片资料校准与出处.md)，返回跨模型成立的共同规律与平台专属参数边界。
- 需要判断模型母型、专有词视觉翻译、属性绑定、单帧证据尺寸、摄影参数或多参考职责：读[视觉生成模型注意力与提示词编译参考](references/视觉生成模型注意力与提示词编译参考.md)的对应章节，返回可指认的注意力合同；不把整份候选清单机械填入正文。
- 需要判断排除项走模型负面通道还是人工验收：读[模板_通用负面提示词](references/模板_通用负面提示词.md)的对应章节，返回使用原则与通用质量边界；不把整份候选清单机械填入正文。
