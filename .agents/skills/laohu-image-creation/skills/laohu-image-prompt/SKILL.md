# 老胡图片提示词编译

## 灵魂：本专业怎样取舍

每个词都应改变这张图，而非解释作者。

禁止把专业设计重新概括成电影感、精致、高清；默认输出文本不代表实际生成。

## 筋骨：从问题到专业结果

读取当前任务目的、已确认事实、可变范围、媒介与上游结果。先判断是否存在“专业判断已完成，需要可复制的图片生成正文”这一缺口；已有有效结论则直接继承。先确定一个任务和一项主证据，再按对象—关系—光材—保护项编译。专业分支、适用条件与反例按Reference执行。

## 血肉：让方法产生差异

本次以“独立可复制正文、参考绑定、画幅与必要保护项”为独立结果，按下方方法将专业控制转成可观察关系。

选择属性绑定、注意力层级、空间关系、参考职责、约束冲突中真正改变本次结果的控制，结合 Reference 中的完整方法、案例与例外形成候选。

## 表皮：输出与约束

### 全部图片的细节质量要求

本项目每条图片生成及编辑提示词均明确包含「减少假纹理假细节」。这是用户的长期质量要求，适用于人像、场景、静物、制作资产及其他生图用途。编译时同时清理与之竞争的无差别超细节、满屏微纹理或过度锐化要求；按对象保留真实结构、身份辨识、必要文字与有来源的材料特征，使细节随尺度、景深和受光自然变化。不能把减少虚假细节执行成磨皮、模糊、删除已确认设计或抹平所有材料；艺术风格本身需要的笔触、颗粒和纹样仍按已确认用途保留。生成后检查重复纹路、无来源刻痕、皮肤噪点和锐化光边，同时复验身份与结构。固定句存在只证明指令已加入，效果必须看真实图像。

返回独立可复制正文、参考绑定、画幅与必要保护项。已锁定的故事、身份、结构、文字和状态按输入保护；模型参数只使用已核验能力。输出专业决定与必要可执行描述，不声称已经生成或实测。

## 调用与返回

可由明确点名直接使用，也可由[所属专业入口](../../SKILL.md)按缺口调用。CONSULT返回局部结果，当前作品负责人不转移；缺少上游事实时RETURN最早负责人，不自行改写剧本。需要跨专业判断时只传当前问题和保护项，不重新运行整条生产链。
