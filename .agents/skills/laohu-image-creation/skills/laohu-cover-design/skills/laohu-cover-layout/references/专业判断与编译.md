# 封面版式的判断与编译

## 专业判断

先读具体封面合同，再向共享构图、版式和字体请求缺失判断。默认基线与破格案在同一事实下比较，不因破格更像海报便胜出。

把标题视为画面对象，安排它与眼神、手势、产品或场景承重线的关系；脸、Logo和关键证据不能变成剩余空间。

## 术语怎样进入选择

本专业使用：第一落点、标题—场景轴线、视觉中心、语义保护区。选择术语时必须同时指出它控制的对象、产生的可见差异和失败条件；不能把整组术语并列塞进提示词。

封面专业不重新编造通用构图理论；共享方法不能覆盖封面默认关系。

## 从机制到可执行描述

下例仅在对象和关系已经由输入确认时成立；换题后继承判断方法，不能借用示例中的人物、物品或事件。

> 标题与指向证据的手势共同形成主簇，副标题沿真实桌边退后一级。

先比较这种处理与一项合理替代：如果替代方案更清楚地保护本次主结果，就采用替代，不为展示技法保留原案。只有一个被锁定的有效方案时，比较未锁定变量，不重开用户已确认的设计。

## 验收与修复

逐项检查输出中的对象和因果是否对应权威输入；术语能否变成可观察关系；有没有两个控制相互抵消。发现问题先改产生问题的选择，再改表达。对真实图像的判断必须读取实际结果；只有文本时只验设计与可执行性。

最终返回：版面骨架、保护区、图文轴线、必要重排。附本次采用、舍弃的关键选择及原因；未确定条件明确保留，不用推测补成事实。

## 专项深化与同素材比较

封面负责人决定哪些图文承担承诺，共享版式决定如何组织。链路：继承标题主符号→标眼睛、关键手势/产品结构等语义保护区→默认上方约三分之一完整标题组与中轴主体→选择内容轴线→调用共享版式/字体→同基线比破格案→返回图文关系与一条自适应编译任务。例：同一人物标题，A把字压眼只为海报感；B字在上方、手势导向关键物；若内容本身是身份被遮蔽，遮挡仍需比较手机识别与真实承诺。
