### 第一落点

封面只保留一个第一落点，最多一个辅助中心。一般自媒体封面让标题成为第一文字层级，人物、产品、道具、视线和手势把注意力送过去；人物 IP 或产品识别承重时，主体与标题可以共同第一落点。

内部写清视觉通行：

```text
进入点：第一眼从脸、标题、手、产品、道具还是亮区进入。
加速 / 阻断：什么线条、前景、方向或明暗边界改变视线速度。
决定性落点：观众必须看到的冲突或利益证据。
余韵出口：什么空位、动作、反射或文字关系留下问题。
```

无法写清通行路线，说明画面还是名词拼贴。

### 日常自媒体默认版式

当任务是日常自媒体缩略图，且没有已确认系列模板、平台固定母版或内容事实要求特殊构图时，先使用以下默认版式，再决定是否破格：

```text
标题：作为一个完整横排文字组，水平居中放在画面上方约三分之一；标题组不压底，不塞进人物之外的剩余空隙。
主体：人物或产品的主体视觉中心回到画布纵向中轴附近；近景优先让脸、眼神和辨识性轮廓在中央稳定成立，再安排肩部、手势和背景动势。
边界：标题、脸、眼睛、产品结构与决定性轮廓退出外圈安全边带。日常生成可把画布四周约 6%—10% 视为只供背景出血和非承重装饰使用的缓冲区，实际平台遮挡更大时继续内收。
视角基线：人物近景默认从可信的平视或轻微仰视开始，使用正常透视建立压迫感；不把超广角畸变、斜切半张脸、任意偏心和贴边裁切当成“PV感”或“炫酷”的默认答案。
```

`上方约三分之一`、`中轴附近`和`外圈约 6%—10%`是老胡日常自媒体封面的项目默认关系，不是所有海报的固定坐标。居中指视觉重量围绕中轴平衡，不要求人物姿态、头发和装饰左右镜像。文化海报、剧情压迫、双人对峙、系列母版或平台界面可以改变标题位置与主体重心，但必须写清：内容里的什么关系要求偏离；偏离后标题位置、主体视觉中心、边界距离和缩略图为什么仍比默认基线更强。

### 版面骨架与文字空间

排版不是画面完成后把标题贴进剩余空白，而是把阅读顺序编进空间。内部先形成：

```text
基本阅读方向：观众横向、纵向、向心还是从主视觉向外阅读。
信息组块：哪些文字必须被看成同一组，哪些属于下一阅读阶段。
对齐骨架：文字和图像共同依附哪条真实边界、基线、中心或重复间隔。
密度地图：高密、中密、低密区域分别承担抓取、补充还是停顿。
间距层次：同组关系最强，相关组次强，不同阶段明显分开；关系可以由距离、共同起边、基线、字重或重复节奏建立。
结构例外：哪一个元素有理由越界、错位、放大或改变方向。
```

网格从语义保护区、图像承重线、文字共同起边和多比例重排关系长出来；栏数是结果，不是专业感。删除网格后如果对齐、裁切和重排决定都不变，就不必命名网格。

留白必须承担聚焦、分组、延迟、压力、补完或裁切余量中的至少一项；“高级、日系、呼吸感”不是职责。自媒体缩略图仍只允许一个第一落点；分散、多中心和长阅读版面只在展览、系列身份或艺术海报中有明确增益，并且缩小后没有摧毁主承诺时使用。

纵排、横排和混排先服从语言、语义、图像轴线与阅读成本。只是为了显得东方、日本、展览或先锋时不使用纵排；每增加一种阅读方向，都要说明它造成的必要转向、交叉、阻断或身份区分。

### 标题—场景轴线与语义保护区

标题不是在空白处随便找位置。先从当前画面事实中选择一条`标题—场景轴线`：地平线、道路、建筑边界、人物视线、动作方向、主体轮廓或安静区域；再决定标题与它同向、反向、穿越、夹持还是留空。轴线决定图文怎样共同制造进入、阻断、加速或余韵，不是固定坐标、固定左右布局或每张封面都必须斜排。

日常自媒体默认版式先以画布中轴和上方标题区建立稳定关系，再寻找内容轴线。内容轴线可以加强、轻微偏转或有证据地打破基线，不能反过来把标题推到边界、把主体切出中心，最后再用“轴线通行”解释已经失衡的结果。

排字、裁切和装饰之前，标出`语义保护区`：眼睛、嘴、关键动作、产品结构、Logo、辨识性轮廓，以及当前封面承重的道路、出口、包围、空位或关系证据。保护区来自内容责任，不是统一安全框；某项不承重时不机械保护，真正承重时不能为字更大或版式更潮而牺牲。

允许标题与主体形成少量`有限遮挡`，但同时满足：不破坏语义保护区；缩略图仍能辨认主体和标题；遮挡确实改变空间、关系或阅读节奏；没有夸大正文价值。纯装饰性压脸、压产品、压关键动作，或只为了模仿某张参考版式的遮挡，直接淘汰。无文字封面或没有必要前后关系时，遮挡可以不使用。

### 人物、空间与主符号

人物要处在事件里：有压力、有反应、有带态度的动作或不动作，并留下对手、道具或环境反馈。静止可以成立，但不能像模特等拍照。

摄影机位置要可信，构图从关系压力生长。门框、玻璃、桌面、走廊、空位和反射只有在改变人物关系时使用。受控不工整可以表达疏离、失衡和被监视，但不能遮掉决定性表情、标题和产品结构。

主视觉符号从故事因果里提炼，例如一次被推回的物件、一个不再有人坐的位置、一扇无法关上的门。符号必须参与人物关系或结果，不是找一件漂亮东西放大。

颜色、光线、颗粒、色散、旧纸和耀斑都要有画内来源与传播职责。默认蓝灰、青橙、霓虹、低饱和和胶片颗粒不能替代内容判断。
