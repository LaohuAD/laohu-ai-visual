#### 局部受控编辑合同

局部编辑先建立`变化区 / 保护区`，再写目标结果。默认执行`单一变量编辑`：一次只改变一个主变量，例如徽章、发色、袖长、墙面破损或天空状态；若多个变化互相依赖，拆成可验收步骤，只有必须同时改变才能成立时才合并。

```text
输入图片与验证状态：
编辑目的：
变化区：位置 / 边界 / 旧状态 → 新轮廓 / 材质 / 颜色 / 连接 / 光影响应。
保护区：身份、发型、姿态、服装其他结构、场景、构图、镜头、光线中本次未授权变化的具体项。
输入职责 / 界面参数 / 提示词正文：输入图守整体基准；遮罩或局部选择守像素位置；强度、画幅等由真实界面参数负责；正文只写目标区域的新可见结果和必要的邻接响应。
验收：变化是否发生；保护区是否漂移；是否引入新对象、文字、边缘断裂或光影不一致。
```

保护区是内部与验收合同，不把一长串“不要改变脸、不要换场景”塞进模型正文。正式正文正向描述编辑后的唯一目标及其与邻接衣料、皮肤、墙面或光线的真实连接；没有遮罩能力时，先标记入口控制风险，不能用更长的文字假装拥有像素级定位。
