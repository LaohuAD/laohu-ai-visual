# 室内设计专业方法

## 决定结果的关系

先列功能与相邻需求，按身体尺度布置固定家具、操作面、开合范围、通行和停留；把照明、反射、声学、收纳与维护作为空间条件。制度与生活痕迹可以细化，当前镜头人物站位由剧本拥有。家具不得为每次反打迁位。

## 专业术语如何进入决定

programming（功能需求编排）；adjacency（相邻关系）；circulation（通行）；reach envelope（可达范围）；FF&E（家具设备陈设）。

这些术语用于指出哪项关系要被核验。例如“范围”要有对象和限制，“结构”要有相邻与连接，“状态”要有起因和结束。交付给图片或视频模型时把术语编译为具体可见关系；交给专业制作时保留术语及其条件，不能声称已执行软件、施工、测量或真人试验。

## 代表场景与反例修正

餐桌太宽导致母亲无法收走孩子碗，漂亮餐厅不能交付；比较座位靠近或餐具放在共享可达区域，若剧本已锁距离则返回空间命题。

先复现失败所在的条件，再执行本节修正。如果修正会改写父入口锁定的身份、整体造型、入口或剧情状态，停止局部补丁，携带冲突事实和两个可行返回选项交回负责人。不要因一个反例就把所有同类手法永久禁止。

## 独立结果清单

功能分区、家具固定关系、通行与取用、材料与光声条件、生活证据。

每项都写实际决定，不写“需要清楚、保持高级、加强真实”等未完成要求。可见正文与内部理由分开：正文写对象已经怎样成立，理由写为何胜出及何时重开。只有文本推演时，验收明确记为文字设计检查，真实效果仍待对应生产证据。


## 3. 灯光和声音从空间来源出发

场景设计只确定光声来源与结构条件：

- 日光从哪些开口进入，季节与朝向怎样影响可用时段；
- 实用灯、火源、法术或设备在哪里，谁有权点亮；
- 材料怎样吸光、反射、透光或产生湿润高光；
- 白天 / 夜间状态哪些区域开放，哪些坠入不可见；
- 声音从何处进入、被什么吸收或反射，门窗关闭后如何变化；
- 机械、风、水、人群、钟铃和远处活动是否提供方向证据。

“电影感轮廓光、氛围雾、环境音”不能替代来源。

上游灯光承担叙事时，把这些条件整理成`场景光源账本`：

```text
实景光源 / 异常光源：名称、位置、高度、朝向、相对面积和谁能开启或遮挡。
光路：开口、遮挡、主要照射区、距离与衰减，人物经过哪些区域会改变受光。
环境反射：墙、地、顶、玻璃、金属、水面和织物怎样反射、吸收或染色。
补光与负补光条件：空间本身哪里会抬亮暗部，哪里会吞掉反射；只记条件，不虚构现场灯具。
介质：烟、尘、雾、雨或蒸汽的来源、密度范围和可见光路。
稳定 / 可变：固定光源与白天夜间状态属于母版；人物遮挡、车灯扫过、屏幕亮起和停电属于镜头状态。
```

场景不替逐镜决定顶光、侧光或逆光的情绪。它只证明光从哪里来、为什么能到达人物、空间怎样响应，以及同一地点换机位后哪些物理关系不能跳变。没有合理实景来源但上游已确认梦境、记忆、法术或主观异常时，登记异常规则、触发和恢复条件，不把随机无来源光冒充现实。



## 实际填写示范与判定

以下为虚构练习条件，不冒充当前作品事实。

室内任务：两人用餐且一人能自然收走共享菜盘。餐桌、座椅和收纳台按可达关系布局，菜盘不跨越对方身体；自然光从固定窗进入，反打不能换另一面窗。若视觉资产必须压缩图中距离，仍须保住角色动作关系，不凭看起来舒适验收。

交付前把示范中的对象换成当前已确认对象，再重新推理；不得直接照抄示范形态。成功标准是同一套事实能够解释选择、结构和下一状态，失败时能指出最早需要变化的决定。
