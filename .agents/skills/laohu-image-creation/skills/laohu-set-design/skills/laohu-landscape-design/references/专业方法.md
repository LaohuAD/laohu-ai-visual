# 景观设计专业方法

## 决定结果的关系

先定高程与坡向、水源排水、气候暴露、地表和植被分布，再按使用强度安排路径、停留、视线开合和维护。季节改变可变层，不改地形母版；观赏植物若无维护与水源依据不得随机铺满。历史景观记录人为地貌和土地使用。

## 专业术语如何进入决定

topography（地形）；drainage（排水）；planting structure（植物层次）；viewshed（可视域）；succession（演替）。

这些术语用于指出哪项关系要被核验。例如“范围”要有对象和限制，“结构”要有相邻与连接，“状态”要有起因和结束。交付给图片或视频模型时把术语编译为具体可见关系；交给专业制作时保留术语及其条件，不能声称已执行软件、施工、测量或真人试验。

## 代表场景与反例修正

沙漠庭院无水源却满铺高耗水绿植且自称真实生态，证据不足；补有据的灌溉和维护系统，或改耐旱植被与遮阴策略，保持观众动线。

先复现失败所在的条件，再执行本节修正。如果修正会改写父入口锁定的身份、整体造型、入口或剧情状态，停止局部补丁，携带冲突事实和两个可行返回选项交回负责人。不要因一个反例就把所有同类手法永久禁止。

## 独立结果清单

地形水系关系、路径与节点、植被层级、视廊和遮蔽、季节与维护状态。

每项都写实际决定，不写“需要清楚、保持高级、加强真实”等未完成要求。可见正文与内部理由分开：正文写对象已经怎样成立，理由写为何胜出及何时重开。只有文本推演时，验收明确记为文字设计检查，真实效果仍待对应生产证据。


## 8. 宏大环境

宏大不等于构件无限增加。先固定：世界边界、主地标、进入路径、人尺度证据、区域层级、地貌与建筑语法、普通区域、负空间和异常规则。异常必须改变路线、受力、资源或制度；只增加奇观表面时留在可变风格层。


## 实际填写示范与判定

以下为虚构练习条件，不冒充当前作品事实。

路径卡：入口沿缓坡接近平台，植被在弯处遮住主屋，转折后由地势而非突然出现的树让主屋显露。雨后可改变地表湿度和低洼积水，不新造山丘。雕塑、台阶和树冠关系属于稳定锚点，落叶与开花是季节覆盖。

交付前把示范中的对象换成当前已确认对象，再重新推理；不得直接照抄示范形态。成功标准是同一套事实能够解释选择、结构和下一状态，失败时能指出最早需要变化的决定。
