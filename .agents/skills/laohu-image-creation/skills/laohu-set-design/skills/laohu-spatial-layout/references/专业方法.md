# 空间布局专业方法

## 决定结果的关系

把人物目的写成空间动词，再建立边界、邻接、入口、主备路径、停留、视线和接触面；沿剧本起点到镜尾逐步走戏，验证同时发生的相见/躲藏是否兼容。固定方向与摄影观看侧分开，不能把屏幕左直接当世界西。

## 专业术语如何进入决定

topology（拓扑）；adjacency graph（邻接图）；line of sight（视线）；blocking（场面调度）；axis of action（动作轴）。

这些术语用于指出哪项关系要被核验。例如“范围”要有对象和限制，“结构”要有相邻与连接，“状态”要有起因和结束。交付给图片或视频模型时把术语编译为具体可见关系；交给专业制作时保留术语及其条件，不能声称已执行软件、施工、测量或真人试验。

## 代表场景与反例修正

人物进门立刻看见桌后的人，却要求同一无遮挡桌后者全程藏住，拓扑不能同时成立。明确冲突位置和必要遮挡条件，返回编剧决定发现顺序，不擅自加屏风改戏。

先复现失败所在的条件，再执行本节修正。如果修正会改写父入口锁定的身份、整体造型、入口或剧情状态，停止局部补丁，携带冲突事实和两个可行返回选项交回负责人。不要因一个反例就把所有同类手法永久禁止。

## 独立结果清单

最小拓扑、GEO母版、动作与对话轴、运行时切片字段、冲突返回证据。

每项都写实际决定，不写“需要清楚、保持高级、加强真实”等未完成要求。可见正文与内部理由分开：正文写对象已经怎样成立，理由写为何胜出及何时重开。只有文本推演时，验收明确记为文字设计检查，真实效果仍待对应生产证据。


# 剧本拆解、空间命题与候选竞争

候选遵守核心合约的同约束比较：违规方案不计数，锁定方向只比较剩余自由区；推荐保留有效对手的优势、自身代价与反转条件。

当场景需要从剧本原创、人物关系由空间承重、现有设计漂亮但通用，或需要比较多套真正不同的空间方案时读取。



## 1. 从场次事实提取空间任务

先提取，不先装修：

| 剧本事实 | 要转换的空间问题 |
|---|---|
| 谁先到、谁后来 | 谁控制入口，后来者是否被看见、等待或突入 |
| 谁知道什么 | 信息能否被遮挡、偷听、误认、提前暴露 |
| 谁想接近或逃离 | 距离、路径、门槛和障碍怎样制造代价 |
| 谁拥有这里 | 哪些区域能自然占据，哪些需要获得许可 |
| 必须发生的动作 | 人体、工具、家具、地面和净空是否支持 |
| 场次反转 | 同一空间的哪项旧证据会被重新理解 |
| 下一场压力 | 出口、残留物、破坏或目击关系留下什么 |

输入只写“庭院、书房、宗门大殿”时仍不足。至少补出：本场空间任务、人物关系、必须行动、观众发现顺序、复用范围和不可改事实。



## 2. 人物—空间关系

空间关系不是“角色喜欢什么风格”，而是身体和权力如何被安排。

- 领地：谁能随意移动、触碰、坐下和改变陈设。
- 门槛：谁进入前需要被允许，谁可以越过礼法。
- 距离：亲近、对峙、回避和等级由什么维持。
- 暴露：人物一进门会先被谁看见，秘密在哪里失守。
- 遮挡：屏风、柱、帘、转角、地形和高差隐藏什么。
- 路径：直达代表公开和权力；绕行可能代表礼法、危险或犹豫。
- 高差：不自动等于强弱，要结合谁能上去、谁被迫仰视、谁可退场。
- 占用：哪些痕迹证明长期生活，哪些是临时闯入。

建立最小关系表：

```text
人物A如何进入 / 停留 / 使用 / 离开：
人物B如何进入 / 停留 / 使用 / 离开：
两人最近与最远关系距离：
谁控制视线、出口和关键物：
空间迫使他们做出的选择：
反转后被重新理解的旧证据：
```



## 关系先变成空间动作，再变成装修与陈设

不要把“亲密、压迫、控制、疏离、照顾”直接翻译成色彩和氛围。先选择空间在这段关系里承担的动词：

```text
容许：谁可以不经许可进入、靠近、触碰或改变这里。
逼迫：空间让谁必须靠近、等待、绕行、低头或暴露。
延迟：门槛、距离、路径和操作顺序怎样推迟一次行动。
遮蔽：谁看不见什么，谁能单向观察，秘密怎样暂时成立。
暴露：人物、物件或行动在哪个节点无法继续隐藏。
庇护：空间替谁吸收风险，又把代价转移给谁。
```

再把动词落实到入口、距离、高差、路径、视线、遮挡、承托面和陈设位置。这样设计出来的不是关系的插图，而是会参与剧情的空间。

例如“母亲一边照顾孩子，一边限制他继续吃某种食物”，不能只靠温暖餐厅和丰盛饭菜说明。需要判断：那盘食物最初在谁的可达范围内，母亲从哪里夹取、为什么会先递出又收回，青菜与肉食怎样摆放，移走餐盘需要经过什么承托面和路径，孩子是否能继续触及。食物本体需要原创判断时归道具设计，确认后由道具资产稳定复现；夹取和移走的剧情调度由剧本锁定，视频继承并编译动作；本 Skill负责让餐桌、座位、距离、放置与收纳接口支持这段关系和完整动作。若空间安排迫使人物做出与台词相反的动作，装修再漂亮也不成立。

同一关系至少允许两个合理空间候选。例如控制可以来自物理封闭，也可以来自表面开放但所有路径都经过主人；亲密可以来自距离近，也可以来自人物始终替对方保留一条不被打扰的路径。候选比较的是哪一种空间动作最准确，不把某个空间比喻固化成关系公式。



## 3. 空间叙事命题

合格命题包含四项：人物关系、空间动作、观众认知、结果。

```text
例：大师兄用一座没有正门、人人都能闯入的小院维持散漫假象；真正重要的区域不是被锁住，而是藏在所有人都看得见却不会停留的位置。小师妹每次沿同一路径冲入，观众逐集发现普通陈设都服从精确的修行与防守距离。
```

不合格命题：`清幽仙气、古朴雅致、破败中见高级`。这些只描述结果表面，没有人物和行动。



## 4. 候选差异轴

完整调用先选择本场真正承重的差异轴；开放方向通常比较2—4条轴上的3—5个候选，锁定方向按剩余合法差异比较，不为数量改戏：

- 权力：主人控制 / 访客控制 / 表面开放实际筛选。
- 开放：无门开放 / 多重门槛 / 单入口封闭 / 多路径渗透。
- 距离：强迫靠近 / 保持礼法距离 / 可快速拉开。
- 层级：水平平等 / 垂直压迫 / 高低可反转。
- 视线：全可见 / 逐层揭示 / 单向观察 / 互相误判。
- 动线：直线 / 回环 / 分叉 / 必须经过承重节点。
- 密度：功能紧凑 / 空旷权力 / 生活挤压 / 刻意清空。
- 时间：稳定日常 / 可迅速变成战场 / 状态层逐步暴露。
- 制作：实景借势 / 局部改造 / 完整搭建 / 数字延展改变尺度。

候选卡：

```text
候选编号与关系押注：
主空间关系：
入口、路径、距离、高差、遮挡与视线：
建筑 / 地貌与陈设怎样共同证明：
必须动作如何发生：
观众先看见与后来重读：
位置 / 改景 / 搭建 / 数字延展策略：
主要收益 / 失败风险：
```



## 5. 选择与淘汰

先确定本作品主胜负手，再给候选排序：

1. 是否最强支持人物选择和场次反转。
2. 是否让必须动作自然发生，而不是为镜头临时搬家具。
3. 是否形成不用装饰也成立的空间记忆。
4. 是否能跨场次、状态和媒介稳定复用。
5. 是否在成本、工期、安全和生成稳定性内实现。

淘汰理由必须指向关系与代价。例如：`候选C的封闭单入口强化秘密，但小师妹反复闯入需要每集重做开门节拍，损害系列日常速度，淘汰。`不要只写“不够高级”。



## 6. 平凡与反差

普通人物和普通地点不需要强行奇观，但要有选择。

- 清贫不等于空：物少但每件有多次使用、修补和收纳关系。
- 富贵不等于满：稀缺材质、维护成本、服务空间与留白共同证明权力。
- 散漫不等于乱：混乱可以集中在人物真正不在意的区域，其他区域显出隐性秩序。
- 深不可测不等于发光法阵：距离、磨损、异常净空、错误用途和旁人反应都能证明。

做换人换戏测试和无装饰测试，只检查本场承重关系的空间证据。公共场所的共用结构、行业规范和经济条件允许保持相同；医院走廊可由谁让路、谁能进入病房、谁占据门口表达关系，无需特制装修。只有应当承重的使用关系消失、只剩题材物件清单时，才返回空间命题重做。


## 3. 可行动拓扑

胜出方案至少锁定：

- 空间边界、层级、朝向与相邻关系；
- 主入口、次入口、出口和不能通行处；
- 主锚点与次锚点；
- 主路径、备选路径、停留区、危险区和隐藏区；
- 视线相通与被遮挡关系；
- 固定构件、固定家具和实用光；
- 摄影、动作、声音和VFX需要的净空；
- 母场景与子区关系。

拓扑不是S资产设计板。本 Skill确定设计关系；`laohu-visual-assets`再用鸟瞰、四机位、细节带和锚点指纹证明这些关系能够稳定生成。

候选阶段不必画完整制作板，但必须留下`候选最小拓扑证据`：边界、入口出口、主锚点、主路径、停留区、视线连通 / 遮挡和关键方向距离。没有这份证据，几段空间形容词不能证明候选真的不同。

胜出后为每个主 / 次锚点登记`锚点视觉指纹`：唯一名称、轮廓 / 截面、尺度范围、材料、朝向、连接方式、位置性痕迹和不可镜像项。视觉资产只把它编译成可生成规格，不重新发明这些身份特征。



# 人物调度、摄影灯光与媒介适配

当场景需要支持对白、动作、反打、摄影灯光、声音、VFX、真人实拍、2D、3D、AI生成或虚拟制作时读取。



## 1. 先走戏，再定漂亮机位

对每个承重场景完成走戏检查：

```text
人物从哪里进入，何时看见对方：
第一次停留与关系距离：
接近、回避、绕行或抢占路线：
取物、放物和承托面：
关系变化时距离、高差或遮挡怎样改变：
结束时谁更靠近出口，谁被留下：
```

空间不能靠每镜搬家具维持动作。若走戏不成立，返回拓扑，不先用运镜和剪辑掩盖。



## 2. 人物调度与摄影接口

- 对话轴：不是强制180度，而是先确定观众需要理解的关系方向和越轴代价。
- 反打背景：两侧背景必须分别证明人物位置，不能都生成同一面漂亮墙。
- 景别容量：近景保留身份锚点，中景看见关系距离，全景证明路径与权力。
- 摄影机可达：实景是否有退距、机位、轨道、摇臂和灯光空间；搭景是否需要可拆墙。
- 焦段风险：广角会夸张距离，长焦会压缩层级；选择服务关系，不绑定固定情绪。
- 遮挡：前景不是装饰，需说明隐藏、揭示、窥视或压迫什么。
- 动作净空：兵器、舞蹈、奔跑、坠落、群像和特效需要真实安全区。

本 Skill交付摄影接口，不规定逐镜摄影机运动；具体镜头由`laohu-video-prompt`负责。



## 5. 媒介无关空间母版

先锁不依赖画风的关系：

```text
空间边界和层级；入口出口与相邻关系；人物路径和停留区；主次锚点；距离、高差、遮挡和视线；功能密度；制度、生活和事件证据；状态可变层。
```

再做媒介等效：

| 媒介 | 重点保留 | 允许调整 | 常见失败 |
|---|---|---|---|
| 真人实拍 | 人尺度、接触、可达机位、真实材料与安全 | 局部改景、可拆墙、数字延展 | 场地漂亮但无法走戏或布光 |
| 2D动画 | 轮廓层级、透视基准、反打关系、背景复用 | 简化材质、夸张高差、压缩非承重区域 | 每镜重画成相似但不同地点 |
| 3D动画 | 可行走体积、模块、相邻区、碰撞与镜头 | 模块化、LOD、程序化分布 | 资产丰富但无主次、尺度漂移 |
| AI图片 / 视频 | 少量稳定锚点、清楚拓扑、绝对位置与状态账本 | 降低无关细节、拆母子区、分层参考 | 风格稳定但入口家具镜像漂移 |
| 虚拟制作 | 实体 / 数字分界、视差、互动光和反射 | 预演中快速比较布局 | 把LED当普通背景图 |

等效不是逐件复制。2D可以用更清楚的轮廓替代真实细碎结构，AI可以减少非承重装饰，但人物—空间关系、路径、锚点与状态不能改变。

### GEO母版怎样成为运行时切片源

固定场景反复进入时，把媒介无关关系层组织成一个可检索的GEO母版：区域与相邻关系、入口出口、固定锚点视觉指纹、方向距离、对话 / 动作轴、主备路径、停留与接触区、遮挡与视线、固定光声来源、可变状态槽。它服务设计保真，不等于把完整建筑说明塞进每一镜。

每个镜头从母版裁一份运行时切片，只含：本镜可见区域、决定人物动作的邻区、当前使用入口、会进入构图的锚点、人物可走路径、摄影观看侧、遮挡、当前破坏 / 占用 / 光声状态。切片必须回指母版字段；出现新入口、移动固定家具或改变锚点方向时，先判断这是合法状态覆盖、镜头错误还是母版本身需要重开，不能在视频提示词里悄悄重建设计。

跨媒介结论使用逐项回归矩阵：`母版关系 / 写实实现 / 2D等效 / 3D等效 / AI稳定合同 / 允许变化 / 失败表现 / 实际验证状态 / 返回负责人`。实际验证状态只能从`文字推演`逐级进入`预演通过 / 建模通过 / 真实生成通过`，不能用一句“各媒介均可”代替证据。



## 6. 场景压力测试

至少选择与任务相关的测试：

- 走戏测试：无摄影机时人物行动是否成立。
- 反打测试：两个方向能否证明同一空间。
- 黑白测试：去掉颜色后层级、路径和锚点是否仍清楚。
- 低细节测试：简化到2D或低模后，空间关系是否仍可读。
- 状态测试：白天、夜间、占用、破坏后是否仍是同一母版。
- 空场测试：去掉人物后是否保留功能与生活证据。
- 无装饰测试：去掉纹样、植物、烟雾和粒子后是否仍有设计。
- 生成回归：实际图像或视频是否保持入口、锚点、固定家具和路径。

只有文字和示意时记录“设计压力测试通过”；真实拍摄、预演、建模或生成尚未发生时，不声称生产验证通过。


### 2. 写空间叙事命题与世界地点语法

每个承重场景先写一句`空间叙事命题`：

```text
谁在这里拥有或失去什么空间权力；空间怎样容许、阻止、暴露或误导人物行动；观众应先看见什么、后来重新理解什么。
```

人物关系不能直接兑换成“压迫、温暖、疏离”的氛围词。先把关系写成空间正在执行的动作，再落到拓扑：

```text
人物关系 → 空间要容许、逼迫、延迟、遮蔽或暴露什么 → 入口、距离、高差、路径、视线与陈设 → 人物行动 → 观众理解。
```

同一种关系可以有多种空间答案，候选应竞争哪一种空间动作最能服务本场戏，而不是竞争哪一套装修更漂亮。

多地点作品再建立`世界与地点语法`：地理与气候、建造技术、材料经济、制度等级、公共与私人边界、尺度与密度、维护修补、能源水源与光源、异常世界规则。共同世界不等于每个地点同一种屋檐、同一套材质和同样的蓝紫雾气。

具体拆解与候选方法读取[references / 专业方法](专业方法.md)。



### 3. 让候选在空间关系上竞争

开放方向的完整调用通常生成3—5个真正不同的候选；方向已锁定时按剩余自由区比较，不凑数量。候选遵守核心合约的同约束比较：违规方案不计数，锁定方向只比较剩余自由区；推荐保留有效对手的优势、自身代价与反转条件。至少改变两个承重维度，且至少一个来自入口控制、距离、高差、遮挡、动线、视线、开放度、功能密度、空间层级或制作策略；只换色板、材质、装饰、天气和风格词不算新方向。

每个候选写清：关系押注、主空间关系、入口与门槛、核心行动路径、主要遮挡与暴露、建筑 / 地貌结构、陈设逻辑、状态潜力、制作策略、摄影与媒介风险、主要收益、淘汰风险；并附`候选最小拓扑证据`：边界、入口出口、主锚点、至少一条主路径、停留区、视线连通 / 遮挡和关键方向距离，可以是简图、编号关系表或坐标句，不提前制作完整S板。自动选出当前最佳，保留`淘汰理由`，不把普通专业取舍重新问给老胡。



### 5. 选择制作策略并建立可行动拓扑

按故事收益、场次复用、动作规模、摄影权限、预算、工期和媒介选择`位置 / 改景 / 搭建 / 数字延展`或混合方案。随后锁定：边界、层级、入口出口、相邻空间、固定锚点、主路径、备选路径、人物停留区、视线、遮挡、可拆或可延展部分。

每个主 / 次锚点登记`锚点视觉指纹`：唯一名称、轮廓 / 截面、尺度范围、材料、朝向、连接方式、位置性磨痕 / 缺口 / 色差 / 接缝和不可镜像项。锚点细节属于设计决定，不能留给资产阶段随机发明。

反复调用的固定场景还要把胜出场景母版整理为`GEO 母版`：它不是另一套场景设计，而是供下游裁剪的空间事实层，统一记录边界与相邻区、入口出口、固定锚点及视觉指纹、方向距离、轴线、主备路径、停留与接触区、遮挡 / 视线、固定光声来源、不可镜像项，以及白天、破坏、占用等可变状态槽。

`GEO 母版`同时是`GEO 运行时切片源`。场景设计要标明哪些字段可按区域、场次和镜头抽取，让视频只读取当前会入画或决定动作的子集；例如站台镜头读取站台边界、检票口方向、破窗锚点、人物路径和当前破坏，不必重读地下通道全部陈设。切片可以缩小信息范围，不能改变母版中的入口方向、锚点关系和固定拓扑；一次性人物站位、表演和临时摄影机不写回永久 GEO。

系列固定场景另建`系列复用矩阵`：场次类型、进入方式、第一停点、关系距离、可用对话轴、备选路径、前景遮挡、结束位置、状态覆盖与不可破坏母版。它只证明空间有多种关系用法，不提前替每集写分镜。

先证明人物能行动，再讨论镜头怎样漂亮；先证明功能与结构，再讨论表面风格。地点系统、布景陈设和场景状态读取[laohu-set-decoration / SKILL](../../laohu-set-decoration/SKILL.md) / [laohu-environment-research / SKILL](../../laohu-environment-research/SKILL.md) / [laohu-architecture-design / SKILL](../../laohu-architecture-design/SKILL.md) / [laohu-spatial-layout / SKILL](../SKILL.md) / [laohu-landscape-design / SKILL](../../laohu-landscape-design/SKILL.md)。



### 7. 完成调度、状态与媒介回归

建立`人物调度与摄影接口`：站位容量、对坐 / 对峙轴、进出与绕行、反打背景、摄影机可达区、焦段风险、可拆墙 / 数字延展区、实用光位置、声源与回声、动作和VFX安全区。

上游存在叙事灯光合同时，再建立`场景光源账本`：逐项登记实景光源 / 剧情异常光源的位置与开启权、开口和遮挡、照射区域、距离与衰减条件、墙地顶和关键物的环境反射 / 吸光 / 透光、可形成的补光以及`负补光条件`、白天夜间和占用状态。它只回答空间怎样使这束光成立，不把单镜人物站位、瞬时光态和摄影机曝光写进永久场景母版。

跨场次区分稳定母版和状态覆盖。白天 / 夜间状态、季节、占用、破坏、清理和权力更替只能修改登记的可变层，不能让同一空间重建成另一地点。跨真人、2D、3D和AI先锁`媒介无关空间母版`，再做等效翻译；调度、摄影、灯光和媒介方法读取[laohu-spatial-layout / SKILL](../SKILL.md) / [laohu-interior-design / SKILL](../../laohu-interior-design/SKILL.md) / [laohu-architecture-design / SKILL](../../laohu-architecture-design/SKILL.md)。

跨媒介不得只写“均可复用”。逐项登记`母版关系 / 各媒介等效实现 / 允许变化 / 失败表现 / 实际验证状态 / 返回负责人`；验证状态分为`文字推演 / 预演通过 / 建模通过 / 真实生成通过`，没有真实结果时不得越级。

涉及历史、地域、宗教、公共功能、安全、真实地点或外部案例时读取[references / 专业方法](../../laohu-environment-research/references/专业方法.md)，逐项登记`证据来源 / 证据等级 / 支持范围 / 不得推出 / 当前设计转译`，不把漂亮参考当事实。

文字原创与策略成立只能标记`概念制作策略通过`。只有勘景、关键尺寸与图纸、可拆和实体—数字交界、预算工期、灯光特效、安全及对应专业负责人都完成真实确认，才可标记`生产设计包通过`；本 Skill不得凭文字自行升级完成等级。



## 实际填写示范与判定

以下为虚构练习条件，不冒充当前作品事实。

拓扑卡：南入口→中部停留区→北工作台，西侧柜体固定，东通道连接侧门。A自南入时能见北台但看不到柜体背后；只有经过中部并转向西侧才获得该视线。若剧本锁定入门即见柜后者，当前拓扑失败，不能在下一镜镜像柜体；须返回决定遮挡或发现顺序。

交付前把示范中的对象换成当前已确认对象，再重新推理；不得直接照抄示范形态。成功标准是同一套事实能够解释选择、结构和下一状态，失败时能指出最早需要变化的决定。
