# 建筑设计专业方法

## 决定结果的关系

从地基接触、竖向支撑、跨度、屋盖、开口和排水建立构造逻辑；概念结构只说明可信关系，不替代工程计算。把入口、层级和相邻空间交空间布局核对，材料尺寸与工艺匹配。数字延展要明确实体接触界面，不能靠远景隐藏脚下无承托。

## 专业术语如何进入决定

massing（体量组织）；load path（荷载传递路径）；envelope（围护）；tectonics（建构）；span（跨度）。

这些术语用于指出哪项关系要被核验。例如“范围”要有对象和限制，“结构”要有相邻与连接，“状态”要有起因和结束。交付给图片或视频模型时把术语编译为具体可见关系；交给专业制作时保留术语及其条件，不能声称已执行软件、施工、测量或真人试验。

## 代表场景与反例修正

悬空石殿没有支撑却标现实古建，概念冲突；选择可见柱架与台基或明确已批准异常力学及边界。不是添加雾遮住底部。

先复现失败所在的条件，再执行本节修正。如果修正会改写父入口锁定的身份、整体造型、入口或剧情状态，停止局部补丁，携带冲突事实和两个可行返回选项交回负责人。不要因一个反例就把所有同类手法永久禁止。

## 独立结果清单

体量与构造语法、开口系统、固定锚点、材料连接、制作策略与工程待验证项。

每项都写实际决定，不写“需要清楚、保持高级、加强真实”等未完成要求。可见正文与内部理由分开：正文写对象已经怎样成立，理由写为何胜出及何时重开。只有文本推演时，验收明确记为文字设计检查，真实效果仍待对应生产证据。


## 2. 位置 / 改景 / 搭建 / 数字延展

| 策略 | 适用 | 主要风险 |
|---|---|---|
| 位置实景 | 真实尺度、材料与历史层最有价值，动作与权限可满足 | 摄影权限、噪声、天气、调度和不可拆结构 |
| 实景改造 | 基础结构合适，只需改变年代、制度、身份或局部路径 | 参考污染、恢复成本、改动权限 |
| 完整搭建 | 关系距离、调度、可拆墙、动作与光线需要精确控制 | 预算、工期、尺度缩水、表面假 |
| 局部搭建＋数字延展 | 近景接触需要实体，远景尺度或奇观需要延展 | 实体与数字透视、光色、材质和状态不一致 |
| 完全数字环境 | 2D / 3D / AI、异常世界、危险或不可抵达地点 | 漂浮、无功能、无尺度、镜头间重建 |

“AI生成不用考虑搭建”是错误判断。实体预算会转化为生成稳定性、资产数量、参考容量、镜头自由度和返修成本。



## 4. VFX与虚拟制作接口

区分：实体接触区、可替换背景、数字延展边界、动态特效区、反射与透明材质、互动光、视差和遮挡关系。虚拟勘景或预演要验证：

- 人尺度与摄影机高度；
- 实体搭建到哪里才足以支持脚、手、家具和破坏接触；
- 数字延展是否需要被人物或前景遮挡；
- LED / 数字背景的视角、光色与反射是否与实体一致；
- 特效出现前后空间是否仍是同一拓扑。



## 实际填写示范与判定

以下为虚构练习条件，不冒充当前作品事实。

建筑概念卡：屋盖由明确柱列承托，柱间形成主通行带，次级构件连接到柱架，不从窗洞中途悬起。结构关系在反打中保留。跨距和构件尺寸未工程验算则标概念范围；不因画面风格准确宣称可施工。数字远景仍需和近处台基共享尺度。

交付前把示范中的对象换成当前已确认对象，再重新推理；不得直接照抄示范形态。成功标准是同一套事实能够解释选择、结构和下一状态，失败时能指出最早需要变化的决定。
