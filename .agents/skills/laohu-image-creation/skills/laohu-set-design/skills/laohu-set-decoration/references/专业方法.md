# 布景陈设专业方法

## 决定结果的关系

按固定家具、软装、日用品、消耗物、痕迹与异常分层；每件问谁用、频率、为何放此、谁维护和是否挡动作。对秘密的线索控制首次可见性与复看意义，人物开始操作的物件交道具，布景只保留放置接口。

## 专业术语如何进入决定

set dressing（布景陈设）；patina（岁月表面）；practical（画内实用设施）；hero prop（承重道具）。

这些术语用于指出哪项关系要被核验。例如“范围”要有对象和限制，“结构”要有相邻与连接，“状态”要有起因和结束。交付给图片或视频模型时把术语编译为具体可见关系；交给专业制作时保留术语及其条件，不能声称已执行软件、施工、测量或真人试验。

## 代表场景与反例修正

贫穷房间只是满地垃圾是刻板装饰；可以少物而多次修补、空位保存使用顺序。桌上信件一旦需偷取，不能烘焙成场景不可移动纹理。

先复现失败所在的条件，再执行本节修正。如果修正会改写父入口锁定的身份、整体造型、入口或剧情状态，停止局部补丁，携带冲突事实和两个可行返回选项交回负责人。不要因一个反例就把所有同类手法永久禁止。

## 独立结果清单

陈设层级、制度生活事件证据、摆放与维护、道具拆分、场次覆盖状态。

每项都写实际决定，不写“需要清楚、保持高级、加强真实”等未完成要求。可见正文与内部理由分开：正文写对象已经怎样成立，理由写为何胜出及何时重开。只有文本推演时，验收明确记为文字设计检查，真实效果仍待对应生产证据。


# 场景系统、位置策略与布景陈设

当作品有多个地点、需要实景 / 改景 / 搭建 / 数字延展判断、固定拓扑、布景陈设、生活痕迹、道具分界或跨场次状态时读取。



## 4. 布景陈设层级

按层设计，避免把所有物件平铺成清单：

1. 建筑 / 地貌：墙、地、顶、台地、水体、道路、结构骨架。
2. 固定构件：门窗、楼梯、壁龛、柜体、灶台、管线、固定法器接口。
3. 固定家具与实用灯：桌椅、床榻、货架、工作台、灯具、火源。
4. 软装与制度陈设：帘幕、地毯、挂画、标识、礼仪、荣誉与禁忌物。
5. 日常使用物：餐具、文具、清洁、工具、储藏、儿童或宠物痕迹。
6. 消耗与临时物：食物、燃料、药材、垃圾、来客物、工作中间状态。
7. 生活痕迹：磨损、修补、灰尘、压痕、日晒、潮痕、搬动空位。
8. 缺失与异常：不该空却空、不该新却新、用途错位、被刻意清除。

每项至少回答：谁使用、频率、放置原因、维护者、是否固定、会不会阻挡动作。漂亮但无因果的物件先删除。



## 5. 环境物与关键道具分界

判断不按大小，而按剧情职责：

- 只证明时代、功能、身份、密度和生活方式：留在布景系统。
- 需要人物握持、穿戴、开启、读写、传递、偷取、追踪、破坏或造成状态变化：升级为关键手持道具 / A资产。
- 同一物件可以先是陈设，后成为道具；首次进入操作链时拆出独立本体与状态合同。
- 场景只锁收纳位置、承托面、朝向、发现条件和环境接口，不锁人物手部动作。



## 6. 生活、制度与事件证据

三类证据共同形成可信空间：

| 类型 | 说明 | 例子 |
|---|---|---|
| 制度证据 | 权限、等级、礼法、工作流程 | 门槛宽度、座次、服务入口、封存位置 |
| 生活证据 | 长期使用、经济、照料与习惯 | 修补方式、反复触碰磨损、临时收纳 |
| 事件证据 | 过去或当前事件留下的结果 | 搬动空位、被擦过的灰、临时遮盖、破坏传播 |

陈设不要替剧本泄底。秘密可以有可回看证据，但第一次观看时要与人物认知和观众发现顺序一致。



## 7. 场景状态系统

把场景拆成：

```text
稳定母版：拓扑、固定构件、永久材料、主锚点。
阶段状态：季节、长期占用、权力更替、修缮、废弃、长期破坏。
场次覆盖：白天 / 夜间状态、天气、营业 / 休息、来客、清理、临时陈设。
镜头瞬时：人物站位、移动物、烟尘、水迹、刚发生的破坏与临时光影。
```

白天 / 夜间状态不能只换色温。还要判断使用者、门窗、实用灯、开放区域、声音、可见深度、工作状态和安全路径。镜头瞬时状态交给视频；跨多个镜头持续存在的真实结果再由复盘判断是否升级为状态资产。

反复出现的系列场景再登记`系列复用矩阵`，比较不同场次可用的入口、第一停点、关系距离、轴线、备选路径、前景和结束位置。目的是防止“连续性”退化成每集同一机位、同一站位，不替视频阶段预写镜头。



### 4. 区分有意识的普通与模型默认场景

`有意识的普通`仍有准确功能、社会经济条件、人物使用习惯、维护程度、空间权力和生活节奏；它可以没有奇观。`模型默认场景`只是“职业 / 时代 / 题材 + 常见家具 + 氛围词”。

执行`换人换戏测试`：先核对公共功能、社会经济条件、人物使用方式与本场承重关系，再替换人物或事件，看承重差异是否丢失。医院走廊、车站、教室的标准入口、座位和磨损可以合理共用；只有当前关系本应改变的控制权、距离、动线或使用痕迹仍是通用空壳时才返修。不得为了不可替代性虚构专属装修，或靠灯笼、法器、屏风、卷轴和粒子冒充人物化。



### 6. 用陈设建立生活、制度与事件证据

建立`布景陈设层级`：建筑与地貌、固定构件、固定家具与实用灯、软装与装饰、日常使用物、消耗与临时物、生活痕迹、缺失与异常。每项回答谁使用、为何在此、多久未动、如何维护、是否阻挡行动。

固定陈设属于空间系统；被人物握持、穿戴、传递、开启、破坏、追踪或推动剧情的物件升级为`关键手持道具`，交给道具 / 装备资产设计本体、操作和状态合同。本 Skill只规定它与空间的放置接口、发现条件和收纳关系。



## 实际填写示范与判定

以下为虚构练习条件，不冒充当前作品事实。

陈设卡：工作台上常用工具按取用路径排列，低频物在上层柜；台边只在反复接触区磨亮，背墙不随机同样磨损。缺失工具留下轮廓空位，但首次镜头是否可见由发现顺序决定。若人物拿起工具，它从陈设升级为可操作对象，场景继续保留原收纳位。

交付前把示范中的对象换成当前已确认对象，再重新推理；不得直接照抄示范形态。成功标准是同一套事实能够解释选择、结构和下一状态，失败时能指出最早需要变化的决定。
