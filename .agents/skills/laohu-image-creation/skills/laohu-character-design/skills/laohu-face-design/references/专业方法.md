# 面部设计专业方法

## 决定结果的关系

从颅面体块与软组织分层：额颧颌的转折、眼眶到鼻口的深度、五官相对位置、年龄与自然非对称；分别检查正面宽窄和侧面前后，避免把正面坐标当立体结构。先锁身份，再写表情活动范围；不由眉骨或眼距推断人格。

## 专业术语如何进入决定

craniofacial landmarks（颅面标志点）；facial planes（面部转折面）；identity/expression disentanglement（身份与表情分离）。

这些术语用于指出哪项关系要被核验。例如“范围”要有对象和限制，“结构”要有相邻与连接，“状态”要有起因和结束。交付给图片或视频模型时把术语编译为具体可见关系；交给专业制作时保留术语及其条件，不能声称已执行软件、施工、测量或真人试验。

## 代表场景与反例修正

正面窄脸侧面突然无下颌体积，是体块关系未闭合；不能增加高颜值词补救。保留一组稳定颧颌关系，微笑只改变软组织与嘴角，不重选脸。

先复现失败所在的条件，再执行本节修正。如果修正会改写父入口锁定的身份、整体造型、入口或剧情状态，停止局部补丁，携带冲突事实和两个可行返回选项交回负责人。不要因一个反例就把所有同类手法永久禁止。

## 独立结果清单

面部关系正文、正侧三季度轮廓对应、永久与阶段特征、表情变形保护项。

每项都写实际决定，不写“需要清楚、保持高级、加强真实”等未完成要求。可见正文与内部理由分开：正文写对象已经怎样成立，理由写为何胜出及何时重开。只有文本推演时，验收明确记为文字设计检查，真实效果仍待对应生产证据。


# 第一印象、真实人格与反差



## “相由心生”要拆成三件事

1. 长期生活、压力、训练和照料会影响习惯表情、姿态、发貌和后天痕迹。这可以成为人物证据。
2. 观众会根据脸、身体、姿态和自我呈现迅速形成可信、危险、亲近或支配等第一印象。这可以成为叙事工具。
3. 固定骨相、五官、体型或族群特征能够客观证明善恶、智力和人格。这个推论不可靠，不能当成人物事实。

因此人物设计既不否认面相的叙事作用，也不把快速印象冒充真相。设计目标是精确管理`观众先相信什么`，再让剧本决定这种相信被确认、修正还是推翻。



## 先把现实判断、艺术编码和人物真相分权

这三层不能互相替代：

| 层级 | 它回答什么 | 允许的做法 | 禁止偷换 |
|---|---|---|---|
| 现实判断 | 现实中的某类人是否具有某种人格 | 依赖可靠数据，证据不足就缩小声称 | 用年龄、性别、胖瘦、地域或阶层断言人格 |
| 艺术编码 | 观众在极短时间里可能先读到什么 | 有意识借用类型预期并选择性夸张 | 假装这种预期就是现实统计事实 |
| 人物真相 | 这个具体角色究竟怎样做人 | 由剧本中的选择、代价和后果证明 | 让外貌、服装或作者标签替行为判案 |

艺术化设计不需要把所有既有类型代码清零。它需要知道自己借了什么、为什么借、怎样让行为接管最终判断。`类型化`是用共享预期压缩信息；`脸谱化`是让一个符号包办整个人；`漫画化`是把真正承重的差异有选择地推大。前者可用，后者要避免，第三种在短、远、无字幕和喜剧媒介中尤其有效。



## 选择性夸张不是给全身加大音量

先写同类平均答案，再找当前人物相对平均值最能承重的偏离：体量与空间占用、头颈肩关系、静止重心、动作起势、发貌整理、自我呈现或与物件的关系。只推大2—4组关系，其余保持写实或主动退让。夸张的对象是`关系`，不是孤立名词：

- “胖”本身信息弱；“圆腹贴近方向盘、手肘霸住窗沿、笑时整个胸腹一起震动”才形成空间关系。
- “老”本身信息弱；“薄肩轻微前扣、粗大手掌仍能稳住菜筐、受压先让半步”才形成处境与能力。
- “金链”本身只是物件；“把领口故意敞开让链子露出、抬腕时同时亮出大表盘”才形成主动炫耀。

一个身体属性可以参与第一印象，但不能单独承担善恶。至少再有姿态 / 动作、自我呈现 / 服装、空间 / 道具中的两类证据同向；随后由剧情行为完成确认或反转。



## 五类视觉证据

每条第一印象线索标明来源：

| 来源 | 可以设计什么 | 不能偷换成什么 |
|---|---|---|
| 固定形态 | 面部与身体关系带来的快速感知倾向 | 客观人格诊断 |
| 后天痕迹 | 劳动、训练、健康、衰老、照料和事件结果 | 无来源的苦难装饰 |
| 习惯表情 | 长期社交策略形成的面部基线 | 当前镜头的夸张情绪 |
| 姿态动作 | 重心、距离、速度、控制和空间使用 | 一次动作就证明终身人格 |
| 自我呈现 | 发貌、清洁、修整和身体管理 | 越权代替服装设计 |

人物设计记录稳定倾向；当前镜头的眼神、哭笑、攻击和受力仍交给表演与视频。



## 四种反差结构

### 表里一致

第一印象与真实人格大体一致，但仍需要行为兑现。它适合快速建立可靠类型，不等于可以脸谱化。

### 面恶心善

危险感可以来自体量、动作精度、职业训练、沉默的空间控制或他人反应，不默认依靠伤疤、丑化、黑眼圈、残障和反派妆。心善由控制力量、保护对象、承担代价和关键选择证明；不要提前用温柔微笑消解反差。

### 面善心恶

可信、无害或温和的第一印象可以来自开放姿态、照料得体、稳定注视和低威胁的动作节奏。真实恶意由操控信息、转嫁代价、伤害选择和后果证明；不要靠后段忽然加阴影、邪笑和黑化妆替代人物反转。

### 半真半假

最有层次的反差常保留一部分真实：温和是真的，控制欲也是真的；粗粝是真的，克制和照料也是真的。前段线索在反转后仍能被重新解释，而不是全部作废。这种设计优先于“前后完全两个人”。

```text

观众第一眼可能读到：

自我呈现证据：

剧本中的行为证明：
反转前不得泄露：
反转后仍保持的身份与动作：
容易滑向的刻板印象：
替代方案：
```



## 风险检查不能自动把人物磨平

先给风险分类，再决定动作：

- `伤害风险`：把现实群体写成天然低等、邪恶、愚蠢或可笑，或让单一身体属性独自判善恶；必须停止或重构。
- `陈词滥调风险`：代码太熟、换个同类角色仍成立；不要立刻删除，先增加当前人物独有的身体关系、动作逻辑和自我呈现。
- `观众摩擦`：形象可能引发不适、争论或强烈判断；只要不越过伤害边界，而且摩擦服务作品目的，可以有意保留。
- `生成风险`：模型可能把选择性夸张变成换脸、畸形或塑料感；通过媒介等效、参考资产和压力测试解决，不倒逼上游回到平均人。

把所有“可能冒犯、可能俗、可能过头”都改成正常、自然、耐看，会得到伦理上看似稳妥、叙事上没有任何立场的默认人。这不是反脸谱化，而是失去设计。



## 反脸谱化检查

- 去掉伤疤、黑衣、武器、阴影和邪笑，危险或可信预期是否仍有身体与行为来源。
- 暂时拿掉角色的族群、年龄、性别、体型或残障，剧情行为是否仍能独立证明善恶。若不能，说明设计把道德判决交给了身份偏见；若能，再判断这些特征是否只是有意识的第一印象代码。
- 第一印象是否明确到观众可读，又保留被剧情重新解释的空间。
- 真实人格是否至少由一个有代价的选择证明，而不是由作者标签、面相或他人台词证明。
- 反转后是否仍是同一张脸、同一具身体和同一套稳定动作语言；人格揭示不等于人物换模。
- 风险检查之后，人物是否还保留至少一条不能被“同龄正常人”替换的锐边；若只剩自然、普通、端正，退回候选竞争。



## 研究边界

面孔、姿态和步态确实会引发快速社会判断，身份与表情知觉也会互相影响；这证明“第一印象可以设计”，不证明“第一印象准确”。人物设计使用这些机制组织观众预期，不能把它升级为现实中的善恶鉴定术。


### 4. 分开第一印象与真实人格

每个主要人物都建立`第一印象—真实人格合同`：

```text
观众第一眼可能怎样判断：
这种判断来自：固定形态 / 后天痕迹 / 习惯表情 / 姿态动作 / 自我呈现。
与真实人格的关系：一致 / 误导 / 部分成立。
真实人格由哪些剧本行为证明：
视觉端不得提前泄露什么：
```

外貌可以有意制造表里一致、面恶心善、面善心恶或半真半假的预期，但固定面部形态不能被写成现实中的善恶鉴定。伤疤、体型、年龄、残障、族群、地域特征和审美偏离不能单独证明邪恶、愚蠢、低等或可笑；它们可以在明确的类型与艺术化合同中参与第一印象，前提是姿态、自我呈现、动作和剧情选择共同完成叙事。反差与边界读取[references / 专业方法](专业方法.md)。



## 实际填写示范与判定

以下为虚构练习条件，不冒充当前作品事实。

关系记录：额部略宽于下颌，颧部转折不被微笑改变；鼻根到鼻尖的前后层级在三季度角保留；嘴角上扬可牵动面颊软组织，但不能让下颌突然变尖。近景优先核对眼眶、鼻口与颧颌，远景由头部外轮廓承担，毛孔数量不是身份标准。

交付前把示范中的对象换成当前已确认对象，再重新推理；不得直接照抄示范形态。成功标准是同一套事实能够解释选择、结构和下一状态，失败时能指出最早需要变化的决定。
