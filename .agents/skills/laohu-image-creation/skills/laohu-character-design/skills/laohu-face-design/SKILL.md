# 老胡面部设计

## 灵魂：专业裁决

让一张脸在转角与情绪变化后仍被认成同一个人。局部好看不能牺牲这个结果；已确认的故事事实与当前专业设计选择必须分开。

## 筋骨：工作次序与边界

专业次序是：**面部体块 → 正侧关系 → 表情活动区 → 身份回归**。接收当前任务已确认的对象、状态和可改范围；独立请求以必要输入直接执行，正式作品继承已有导演与美术合同，先定位本专业最早的缺口，再提出可比较方案，形成独立结果，返回实际调用者整合；独立点名时直接交付专业结果，不强制重跑所属父入口。CONSULT只交局部判断，不接管剧本或其他部门。已有锁定设计时只处理自由区；跨越身份、剧情或成本范围的选择返回所属入口。

## 血肉：怎样产生设计

从颅面体块与软组织分层：额颧颌的转折、眼眶到鼻口的深度、五官相对位置、年龄与自然非对称；分别检查正面宽窄和侧面前后，避免把正面坐标当立体结构。先锁身份，再写表情活动范围；不由眉骨或眼距推断人格。

## 表皮：可交接形式

交付必须包含：面部关系正文、正侧三季度轮廓对应、永久与阶段特征、表情变形保护项。未观察、未测试、未生成的部分按事实/推论/设计选择与验证状态登记。正文用观众可见的结构、位置、动作和材料关系；不拿专业词表代替设计，不增加固定资产网格或假造实测状态。

## 执行方法

1. 写出本轮要改变的观看或生产结果，以及不可改项。
2. 读取[专业方法](references/专业方法.md)。原创面部必读[结构兼容方法](references/结构兼容与阵容方法.md)的选择顺序、骨相与冲突矩阵；多人差异转群像会商，同脸局部修改只读锁定与观察边界。词义不够具体时查[候选词表](references/结构与妆容候选词表.md)对应部位，不填满词表。
3. 开放设计比较真正不同的结构或关系；局部修正只比较可改区，锁定事实不得拿来凑候选。
4. 用同一个代表动作、观看距离或状态比较方案，写出胜出收益、代价、最强反对理由与重新开启条件。
5. 输出上列专业交付，补足承接对象和最早返回负责人；只有达到本轮证据等级才能标记相应验收完成。

## 验收与返回

底线：让一张脸在转角与情绪变化后仍被认成同一个人所需的关键结构与因果不冲突，所有锁定事实可追溯。巅峰：删掉解释和装饰后，专业结果仍在实际观看或操作条件里可辨认；同约束更强替代已比较。缺少专业设计则继续当前节点，剧本事件矛盾返回编剧，作品整体风格矛盾返回美术，纯引用与版式错误返回资产。

## 抽象气质怎样成为一张具体的脸

先锁年龄、已有脸部关系与可变范围，再确定主副气质。清冷可由结构强化，也可保留圆润脸型用克制表情和妆容形成；比较至少两条相容路径，不从气质、国籍推导唯一脸型，不自动年轻化、女性化、提白或尖下巴化。

原创面部在眉骨/眼窝、颧部、下颌/下巴三个区域选择有辨识作用的关系，并结合眼、鼻、唇与软组织；极简与局部任务按范围取用。眉骨不等于眉毛，眼窝不等于双眼皮，颧位高不等于脸宽，中庭长度不等于面中前突，下巴尖不等于前伸。正面或侧光证据不足的深度保持未知，不能在“只换妆”时顺手补造。

固定脸换妆交[妆容](../../../laohu-makeup-design/skills/laohu-makeup/SKILL.md)；同妆多人交[群像](../laohu-ensemble-design/SKILL.md)逐对检查。正文选定一套结构，不留“单眼皮或双眼皮”并列选项；提示词压缩保留身份、区别关系与本轮变更，不能为字数删锁定特征。短独立请求交一句方向与完整中文正文；正式作品仍按人物母版与写真交接，不用外部短格式覆盖生产合同。

## 调用与返回

可由明确点名直接使用，也可由[所属专业入口](../../SKILL.md)按缺口调用。直接命中本专业时先沿该链接补齐上级已确认的目的、事实、方向与保护项，只补依赖，不重新发起父级任务。CONSULT返回局部结果，当前作品负责人不转移；缺少上游事实时RETURN最早负责人，不自行改写剧本。需要跨专业判断时只传当前问题和保护项，不重新运行整条生产链。

## 当前文本的语言执行

直接接受局部请求时，也按本包[语言表达](../../../../references/语言表达.md)先判当前文本块的发声者、接收者与任务。保护原话和专业事实；只补不足的请求不得改变已确认内容。遇到混写或冗余时按该文件选择具体方法，完成后回到本专业验收。
