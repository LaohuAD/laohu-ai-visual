# 老胡选角

## 灵魂：专业裁决

选出能承住人物关系和行动的身体，而非按美貌排名。局部好看不能牺牲这个结果；已确认的故事事实与当前专业设计选择必须分开。

## 筋骨：工作次序与边界

专业次序是：**输入角色拆解 → 关系候选 → 同场试演题 → 选角范围定案**。接收当前任务已确认的对象、状态和可改范围；独立请求以必要输入直接执行，正式作品继承已有导演与美术合同，先定位本专业最早的缺口，再提出可比较方案，形成独立结果，返回实际调用者整合；独立点名时直接交付专业结果，不强制重跑所属父入口。CONSULT只交局部判断，不接管剧本或其他部门。已有锁定设计时只处理自由区；跨越身份、剧情或成本范围的选择返回所属入口。

## 血肉：怎样产生设计

把剧本中反复选择与行动分为必须能力、观众第一预期和自由区；比较同样满足事实的亲近型、低估型、压迫型选角关系。先设计两项以上脸身姿动差异，再以同一场压力动作比较，不拿静态精修胜负替代表演潜力。锁定真人只覆盖可见证据，缺少侧背面不能推为真实测量。

## 表皮：可交接形式

交付必须包含：选角范围、三至五个合法关系候选、同场试演题、推荐与淘汰理由、身份锁定边界。未观察、未测试、未生成的部分按事实/推论/设计选择与验证状态登记。正文用观众可见的结构、位置、动作和材料关系；不拿专业词表代替设计，不增加固定资产网格或假造实测状态。

## 执行方法

1. 写出本轮要改变的观看或生产结果，以及不可改项。
2. 读取[专业方法](references/专业方法.md)，按其结构关系展开，不全量调用无关部门。
3. 开放设计比较真正不同的结构或关系；局部修正只比较可改区，锁定事实不得拿来凑候选。
4. 用同一个代表动作、观看距离或状态比较方案，写出胜出收益、代价、最强反对理由与重新开启条件。
5. 输出上列专业交付，补足承接对象和最早返回负责人；只有达到本轮证据等级才能标记相应验收完成。

## 验收与返回

底线：选出能承住人物关系和行动的身体，而非按美貌排名所需的关键结构与因果不冲突，所有锁定事实可追溯。巅峰：删掉解释和装饰后，专业结果仍在实际观看或操作条件里可辨认；同约束更强替代已比较。缺少专业设计则继续当前节点，剧本事件矛盾返回编剧，作品整体风格矛盾返回美术，纯引用与版式错误返回资产。

## 调用与返回

可由明确点名直接使用，也可由[所属专业入口](../../SKILL.md)按缺口调用。直接命中本专业时先沿该链接补齐上级已确认的目的、事实、方向与保护项，只补依赖，不重新发起父级任务。CONSULT返回局部结果，当前作品负责人不转移；缺少上游事实时RETURN最早负责人，不自行改写剧本。需要跨专业判断时只传当前问题和保护项，不重新运行整条生产链。

## 当前文本的语言执行

直接接受局部请求时，也按本包[语言表达](../../../../references/语言表达.md)先判当前文本块的发声者、接收者与任务。保护原话和专业事实；只补不足的请求不得改变已确认内容。遇到混写或冗余时按该文件选择具体方法，完成后回到本专业验收。
