# 群像设计专业方法

## 决定结果的关系

先定义共同世界基线，再将年龄感、体量、头肩、脸部关系、重心、节奏、空间占用放入一张矩阵；主差异围绕关系分工建立，避免每维不同破坏世界。四人以上可比较完整群像系统，但每位未锁定主角必须在各系统里得到真正替代。

## 专业术语如何进入决定

ensemble casting（群像选角）；silhouette readability（剪影可读性）；relational contrast（关系对照）。

这些术语用于指出哪项关系要被核验。例如“范围”要有对象和限制，“结构”要有相邻与连接，“状态”要有起因和结束。交付给图片或视频模型时把术语编译为具体可见关系；交给专业制作时保留术语及其条件，不能声称已执行软件、施工、测量或真人试验。

## 代表场景与反例修正

师兄师姐全是高瘦长发，只换武器仍同质；改成身体组织和关系距离差异，服装保留共同制度。若远景只靠发色识别，应增加轮廓或动作节奏证据。

先复现失败所在的条件，再执行本节修正。如果修正会改写父入口锁定的身份、整体造型、入口或剧情状态，停止局部补丁，携带冲突事实和两个可行返回选项交回负责人。不要因一个反例就把所有同类手法永久禁止。

## 独立结果清单

群像矩阵、共同基线、每人不可重复锚点、成套候选、远中近景和同场动作测试。

每项都写实际决定，不写“需要清楚、保持高级、加强真实”等未完成要求。可见正文与内部理由分开：正文写对象已经怎样成立，理由写为何胜出及何时重开。只有文本推演时，验收明确记为文字设计检查，真实效果仍待对应生产证据。


## 群像先比较关系，再分别做资产

主要角色超过三人时，先在同一矩阵比较：

```text
角色 / 故事功能 / 观众第一印象 / 年龄感 / 身高体量 / 头身颈肩 / 脸部关系 / 重心 / 动作能量 / 空间占用 / 主锚点 / 不得与谁重复。
```

共同世界语法可以统一健康基线、审美习惯或训练体系，但不能把所有人收敛成相同脸部模板、模特身材、站姿和动作节奏。有限关系组校准图只能验收差异，不能替代这一步的设计因果。

开放群像通常有两种探索方式：逐人各做3—5个候选，或为四名以上彼此承重的主角做3—5套完整群像选角系统；已有锁定条件时，数量按剩余可行差异调整，不能用违规方案填满。使用整组方式时，每一套都要让每名未锁定主角获得一个真正不同的脸身姿动方案；同一人物在全部系统里原样不动，说明他没有经过候选竞争。



### 7. 做群像与媒介压力测试

多人项目先建立群像差异矩阵，再完成个人胜出设计：年龄感、身高与体量、头身和颈肩、脸部关系、重心、动作能量、空间占用、第一印象分工、不可重复锚点。共同世界审美不等于同脸、同体型和同动作节奏。

同一人物跨真人写实、2D、3D或AI生成时，先锁`媒介无关身份母版`，再做等效翻译；不能用一份写实提示词追加风格词，也不能让每个媒介重新选角。媒介适配、表情 / 姿态 / 动作压力测试和资产交接读取[laohu-casting / SKILL](../../laohu-casting/SKILL.md) / [laohu-body-design / SKILL](../../laohu-body-design/SKILL.md)。



## 实际填写示范与判定

以下为虚构练习条件，不冒充当前作品事实。

三人关系组：队长窄幅稳停，学徒重心频繁前探，后勤者先留出路径再动作。共同劳动服只保世界一致，不负责唯一识别。若调换动作语言后关系判断没有变化，说明差异仅是身体标签；重新把权责、熟练程度与距离策略写入矩阵。

交付前把示范中的对象换成当前已确认对象，再重新推理；不得直接照抄示范形态。成功标准是同一套事实能够解释选择、结构和下一状态，失败时能指出最早需要变化的决定。
