# 生物设计专业方法

## 决定结果的关系

从栖息地、取食、感知、移动、防护与能量代价建立生存任务；以真实功能关系为参照选择骨架及接触方式，再明确幻想例外。逐项核对关节、肌肉或替代驱动、表皮、呼吸与尺度；不把不同动物器官随意拼成形状目录。

## 专业术语如何进入决定

functional morphology（功能形态学）；convergent evolution（趋同演化）；locomotion（移动方式）；allometry（异速生长）。

这些术语用于指出哪项关系要被核验。例如“范围”要有对象和限制，“结构”要有相邻与连接，“状态”要有起因和结束。交付给图片或视频模型时把术语编译为具体可见关系；交给专业制作时保留术语及其条件，不能声称已执行软件、施工、测量或真人试验。

## 代表场景与反例修正

洞穴伏击者长出巨大展开翼但走道窄，轮廓与栖息地冲突。可改为折叠翼的收拢体积，或删翼而强化伏击感知；要改变运动条件，不能只说魔法解决。

先复现失败所在的条件，再执行本节修正。如果修正会改写父入口锁定的身份、整体造型、入口或剧情状态，停止局部补丁，携带冲突事实和两个可行返回选项交回负责人。不要因一个反例就把所有同类手法永久禁止。

## 独立结果清单

生态与功能假设、体型和轮廓方案、骨架关节逻辑、步态与接触、幻想例外及代价。

每项都写实际决定，不写“需要清楚、保持高级、加强真实”等未完成要求。可见正文与内部理由分开：正文写对象已经怎样成立，理由写为何胜出及何时重开。只有文本推演时，验收明确记为文字设计检查，真实效果仍待对应生产证据。


## 实际填写示范与判定

以下为虚构练习条件，不冒充当前作品事实。

虚构生物卡：水浅而泥软的岸边伏击者，低重心、宽接触脚掌、眼部位于水面附近，推进主要来自后肢。替代案是长腿快速涉水，收益是移动距离，代价是静候时轮廓暴露。若剧情需要长时间隐藏，选低伏案。背上装饰翼不贡献生存或剧情，则删除。

交付前把示范中的对象换成当前已确认对象，再重新推理；不得直接照抄示范形态。成功标准是同一套事实能够解释选择、结构和下一状态，失败时能指出最早需要变化的决定。
