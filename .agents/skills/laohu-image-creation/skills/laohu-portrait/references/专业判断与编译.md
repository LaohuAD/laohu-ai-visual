# 人像摄影的判断与编译

## 专业判断

先写人物此刻要做什么、注意谁和保护什么，再选一项能被看见的动作证据。摄影机的距离、高度与人物知情程度必须能解释照片的观看位置。

在脸、手、重心和环境反馈中选择承重通道，避免每个部位都表演。允许自然不完整，但不能裁掉身份或关键动作；真实皮肤的局部差异不等于全脸粗糙。

## 术语怎样进入选择

本专业使用：环境人像、关系对象、重心、呼吸、微表情、决定性瞬间。选择术语时必须同时指出它控制的对象、产生的可见差异和失败条件；不能把整组术语并列塞进提示词。

B/W/M制作板不能套用现场叙事；歪头微笑不是所有人物的生命感。

## 从机制到可执行描述

下例仅在对象和关系已经由输入确认时成立；换题后继承判断方法，不能借用示例中的人物、物品或事件。

> 来人打断整理衣袖，手停在袖口、目光刚转向门外，身体仍朝着原先工作方向。

先比较这种处理与一项合理替代：如果替代方案更清楚地保护本次主结果，就采用替代，不为展示技法保留原案。只有一个被锁定的有效方案时，比较未锁定变量，不重开用户已确认的设计。

## 验收与修复

逐项检查输出中的对象和因果是否对应权威输入；术语能否变成可观察关系；有没有两个控制相互抵消。发现问题先改产生问题的选择，再改表达。对真实图像的判断必须读取实际结果；只有文本时只验设计与可执行性。

最终返回：单帧因果、人物—摄影机—环境关系、身份保护、静态提示词。附本次采用、舍弃的关键选择及原因；未确定条件明确保留，不用推测补成事实。

## 专项深化与同素材比较

生命感指当前动作由可推断的前因与对象支撑，不等于汗、飞发、张嘴或歪斜。链路：锁人物身份→明确当下目的与关系对象→选动作尚未完成/反应刚出现的时刻→定目光、重心、手部和呼吸的共同方向→选摄影机为何能在这里→环境只提供实际反馈→检查不靠表情词能否读出状态。普通照片升级锁身份、表情、动作、服装与事件，只改允许的摄影变量。例：同一人靠窗看信，A面向摄影机标准微笑割断读信；B目光停在纸下缘、握纸手未放松，与已定事件同向。若用户要证件照，A式中性朝向合法，生命感检查N/A。
