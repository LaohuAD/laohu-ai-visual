# 资产规格与编译



B素体必须逐项继承胜出`人物设计交接包`，按需引用同编号F，只把已确认的脸身关系编译成制作板，不因模板需要重新选角。它把脸部身份与身体校准分开控制，并严格复刻同一套16:9固定三列网格，不允许模型按人物、性别或文字多少重新排版。左栏约占画面宽度36%并贯穿整高，只放正面头部大特写，负责全板唯一清晰人脸以及五官、骨相、肤色、发际线、发质和永久面部特征；中栏约占45%并横向三等分，依次放左前方45度、正面、背面三张同尺度身体，使用同一具完全无头发的无五官校准头模，只负责身体轮廓和参数。三张头模从额顶、颞侧、耳后到枕骨均为连续、同色、哑光校准头模表面，只保留头颅与耳廓体块，不生成真实或模糊五官、头发、发际线、眉毛、睫毛、胡须、眼镜和头饰。三具身体统一穿纯白、不透明、哑光、中等克重校准服：立领前拉链长袖校准上衣、全长校准裤和白袜；领口、肩缝、袖口、前拉链、腰头、侧缝与裤脚必须清楚可见，衣料与肤色有清楚色差，贴合身体但保留2—4cm活动松量，除头颈与双手外不露出皮肤。身体轮廓由服装外轮廓、受力和参数共同证明，不使用肤色紧身衣、身体涂装、无缝人台表皮或近似裸体的表达。右栏约占19%并贯穿整高，是固定文字标注区，标题固定右上，年龄 / 身高 / 体重固定在标题下方，围度与长度按固定纵坐标向下排列，说明固定右下。中栏只允许在正面与背面身体之间出现一个头身比短标；其余参数只能位于右栏，不能改成底部横栏、左下参数栏、分格表格或紧贴人物的自由文字堆。关键围度使用白色圆点落在正面身体的解剖位置，以不交叉的水平细白引线连接右栏对应文字。

B的身体参数标注至少覆盖年龄、身高、体重、头身比、骨性肩宽、胸围、腰围、臀围、颈围、上臂围、大腿围、小腿围、肩点至腕、髋点至地和基础体态；开放设计的原创角色使用人物设计已经胜出的明确设计值，不声称真人测量。锁定真人缺少测量或全身证据时，不能为填满B而虚构数值，应先隔离推定制作信息和高风险缺口。三张身体从头模顶到脚底完整出现，共用同一地面线、头顶线、身体尺度、站姿、校准服、背景、光向和阴影方向。标题、正文、单位、引线、圆点和右下说明使用统一白色无衬线字体与固定字号层级；下游禁止继承注释文字、灰底、校准服和假人头模。

阶段素体资产必须逐项继承B的固定三列网格、36% / 45% / 19%栏宽、整高关系、三身体等分、纯白不透明校准服、右上标题、右栏参数纵坐标、水平引线、右下说明、字体层级和地面线，不能只写“版式与B一致”后让模型自由解释。中栏仍为同一具完全无头发的无五官校准头模所承载的左前方45度、正面、背面身体，头模表面连续、同色、哑光，只保留头颅与耳廓体块；校准服沿用立领前拉链长袖上衣、全长校准裤、白袜、清楚结构缝线和2—4cm活动松量，只允许身体轮廓与阶段数据变化。右栏用同一参数顺序显示当前完整值，完整参数与阶段增量同时保留，一句可见形体变化压缩为右下说明，不新增底栏或左下信息格。所有相邻阶段保持裁切、站姿、头顶线、地面线、光线、背景、字体、注释纵坐标和身体尺度一致，变化只能发生在阶段脸软组织、身体轮廓与对应数字。

左栏阶段脸必须把 `永久身份锚点` 与 `阶段可变区` 分开写，这套分离控制才叫阶段脸受控变化。永久身份只锁眼鼻口耳、发际线及其相互位置，不把整张脸型、脸颊厚度、下颌缘、颏下轮廓或颈部宽度一起锁死；阶段可变区明确列出本次允许改变的颧颊软组织、外侧脸颊轮廓、下颌缘显露度、颏下轮廓与颈部视觉宽度。每个阶段都要有无需上一张图也能执行的 `绝对目标`，再用已真实生成并验收的相邻阶段图强化连续性；`更饱满、进一步柔化、最明显、自然一些` 不能单独承担变化。绝对目标优先使用分级、相对母版的轮廓比例、平面由内收到平直到凸起、下颌缘可见范围、颏下弧线和对应颈围等可观察几何。阶段验收必须做 `剪影级差`：遮住五官后，相邻脸部外轮廓仍能按阶段顺序辨认；若身体变化成立而脸部级差失败，只返修左栏脸部或先生成同裁切的多阶段脸部校准条，不重做已经合格的身体与版式。校准条属于临时比较参考，只有跨任务复用并通过验收后才升级为正式资产。



“根据真实事迹改编”、沿用真实姓名或题材来自新闻，只能证明故事来源，不能自动推出真人相貌复刻。只有老胡明确要求还原具体真人，并且提供了有权使用、足以锁定身份的参考资料时，才建立真人相貌参考链；否则依据剧本职责原创选角，锁年龄、骨相、发型、体态和关系证据，同时避免声称“真人复刻”或“相貌还原”。
