# 群像资产的判断与编译

## 专业判断

先区分需逐人稳定的角色与可替换的群众。群像身份图记录人数等级、轮廓和衣着语法；当场站位、谁遮挡谁和动作由剧本决定。

差异来自职责与资源，不靠随机色衣服。用少量稳定主锚点加可变群众避免复制脸，关键人物仍引用独立身份。

## 术语怎样进入选择

本专业使用：群体分层、轮廓差异、色块分布、身份锚点、重复控制。选择术语时必须同时指出它控制的对象、产生的可见差异和失败条件；不能把整组术语并列塞进提示词。

群像身份板不能覆盖镜头调度；所有人同姿势不等于统一。

## 从机制到可执行描述

下例仅在对象和关系已经由输入确认时成立；换题后继承判断方法，不能借用示例中的人物、物品或事件。

> 班级保留已确认老师与两名主角身份，其余学生在同一校服语法内有身高和姿态差别。

先比较这种处理与一项合理替代：如果替代方案更清楚地保护本次主结果，就采用替代，不为展示技法保留原案。只有一个被锁定的有效方案时，比较未锁定变量，不重开用户已确认的设计。

## 验收与修复

逐项检查输出中的对象和因果是否对应权威输入；术语能否变成可观察关系；有没有两个控制相互抵消。发现问题先改产生问题的选择，再改表达。对真实图像的判断必须读取实际结果；只有文本时只验设计与可执行性。

最终返回：固定角色、可变群众、群体语法、禁止继承的站位。附本次采用、舍弃的关键选择及原因；未确定条件明确保留，不用推测补成事实。
