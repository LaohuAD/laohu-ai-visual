## 群像身份图与叙事调度图分权

群像资产用于锁定同一组人物的成员身份、脸型、发型、身高体型差、年龄差和彼此可辨识性；正面集体合照是身份校准构图，不是正片默认站位。下游镜头若需要前后遮挡、侧后包围、争抢、追逐或多人跨层走位，不能把群像合照同时当作构图参考。

正确链路是：群像资产回答“有哪些人、谁高谁矮、谁是谁”→ 镜头首帧、故事板、简模 / clay render 或验收视频回答“这些人在这一镜具体站在哪里、朝哪里看、怎样移动”→ 视频提示词只描述画面中实际执行的空间和动作。只用文字声明“合照仅参考身份”不足以抵消参考图的强构图暗示；复杂调度必须另有空间参考，或先由群像身份图生成一张镜头专用调度首帧。

验收时做反证：如果把群像合照直接绑定后，模型把冲突人物排成正面横队、集体面向摄影机或保持合影间距，说明身份参考越权为构图参考，必须更换输入合同，不能继续堆动作形容词。



当人物身份、群像、服装状态、人物制作板、角色所属物或跨镜一致性承重时读取。原创主要人物的选角、身体化、第一印象和稳定动作语言先由`laohu-character-design`胜出；本 Reference 只把胜出人物编译成B / 阶段素体 / M / G资产并控制连续性。





群像人物资产不是主角素体资产，但要区分两类职责。开放群众只稳定“这一群人像什么人”：使用场景合照式参考，展示年龄层、服装、发型、密度和表情范围，不为每个人固定姓名、脸和三视图。有限关系组则用于反复出现、人数明确、成员需要分别行动或说话的小组，例如三名同学、四名店员或一家五口；它必须用正面集体校准合照固定每个成员的左右顺序、同一地面线、五官、发型、身高、体型、服装合身度和清楚间距，让差异在同一画面可直接比较。有限关系组仍不替代每名主配角的个人B/W/M，也不把瞬时嘲笑、敲击、奔跑和台词动作固定进资产；这些行为进入分镜与视频提示词。
