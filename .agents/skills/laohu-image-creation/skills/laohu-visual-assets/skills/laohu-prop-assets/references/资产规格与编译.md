# 资产规格与编译



物品先锁主轮廓、比例、材料、功能、接触区、活动件、文字 / Logo 和磨损逻辑。纸张、屏幕、证件、包装和仪表先裁决观众是否必须读取：需要读取就准确设计版式、文字、显示安全区和保持时间；不需要读取就固定无印刷背面、边缘、折痕、纤维、受力和湿痕，印刷面始终背离镜头，不生成半可读伪字。只有跨角度、被操作、进入特写或承担主视觉时才需要多视图；正式道具资产采用中性偏灰摄影棚，按风险展示左前方45度、正面、侧面、背面和功能特写。简单一次性道具写进视频正文。

> 道具一旦被人拿起，就不再只是造型，而是动作因果的一部分。

凡关键物品会被端、拿、递、放、开合、倾倒、破坏或跨镜继承，资产阶段必须向视频阶段交付`道具操作合同`：人物为何选它而不是相邻物、谁拥有或控制它、起点由什么承托、允许怎样接触与发力、活动件怎样运动、经过什么路径、最后落在何处并由什么继续承托。道具的造型资产只固定身份与物性，剧情中的即时位置和控制权由镜头状态承接；不能用一张中性资产图替代动作状态，也不能只写“端走、放下”而省掉离开原承托、控制权变化与新落点。一次性道具可以不建正式资产，但这份操作合同仍必须进入视频提示词。



商业资产还要证明卖点：产品结构、人物用法、场景条件和镜头角度必须共同提供可见证据。只拍高级静物不能证明抓地、防水、轻量、服务效率或使用利益。



物品资产图写法：

```text
同一件物品在中性偏灰摄影棚多角度展示，按风险包含左前方45度、正面、侧面、背面和功能特写，重点固定轮廓、比例、材质、纹理、接触区、活动件、文字 / Logo、磨损、使用方向和可特写细节。
```
