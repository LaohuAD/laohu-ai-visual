## 4. 道具资产拆解

道具必须有故事功能：

```text
道具：
第一次出现：
推动什么信息：
人物为什么选择它，而不是相邻的其他物品：
谁拥有 / 控制 / 争夺它：
开场位置、朝向、容量与支撑面：
允许怎样拿取、递交、移动、放置或破坏：
可信落点与下一状态：
材质和尺寸：
特写需求：
是否影响人物动作：
后续视频用途：
```

道具资产继承道具设计与场景陈设已确认的物件选择，核对物理可信与叙事使用条件。桌上物件的生活组成由场景陈设根据人物数量、家庭或场所条件、时段、用途和生活习惯决定，被操作的承重本体由道具设计负责；资产不得重新决定对象集合；镜头重点操作什么，由人物目的和场次转折决定。家庭饭桌可以有主菜、配菜、汤饭与餐具形成生活可信，但只有真正改变人物选择、身体代价或关系控制权的那一件进入承重近景。不能因为剧情只写一盘肉，就让整桌像尚未开饭；也不能为了“丰盛”平均展示所有菜，冲淡承重道具。

临时剧情道具不必全部升级为稳定资产，但必须给下游可执行的状态合同。凡是被人物拿起、递交、争夺、隐藏、消耗、破坏或跨镜继承的物品，至少交接身份、数量、开场支撑、控制者、可握 / 可托位置、移动净空、可信目的地与结束支撑。道具结构图能证明“它是什么”，不能替视频提示词决定“人物为什么现在碰它、怎样把它从这里移到那里”。

正式道具资产采用中性偏灰摄影棚和稳定基准线，按结构风险展示左前方45度、正面、侧面、背面及必要的顶部、底部、开启、握持、接触或文字特写。多视图固定同一件物品的轮廓、比例、材料、颜色、接缝、活动件、文字 / Logo、磨损和使用方向；特写只能放大主视图已经存在的部位。仅在当前镜头一次出现、不会跨角度或被操作的简单物品继续留在视频正文。

纸张、屏幕、包装、证件和仪表在建资产前先选择唯一可读性分支。若观众必须读取正面，资产和后期共同负责真实版式、准确文字、显示安全区与镜头保持时间；若剧情只需要“这是一份报告/票据”而不让观众读，摄影机只看无印刷背面、边缘、折痕、纤维、受力弯曲和湿痕，印刷面贴桌、朝角色或背离镜头。禁止生成半可读伪字、镜像字、透出的表格块或一张纸同时承担多份不同报告。视频正文必须继承同一分支，不能资产用背面、镜头又突然正面特写。
