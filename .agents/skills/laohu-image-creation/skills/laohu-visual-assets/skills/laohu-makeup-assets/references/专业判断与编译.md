# 妆造资产的判断与编译

## 专业判断

先核对F、B及阶段、W与妆造补充正文来自同一状态。M记录当前头发、妆容、配饰和完整穿着结果，不修改骨架与衣服结构。

受控板式保持上下同列角度、头身中轴、背景和光色一致；眉眼、发缝与发饰位置要具体，不能以“精致妆容”代替。

## 术语怎样进入选择

本专业使用：身份绑定、头身对齐、妆发定位、服装穿着、角度一致。选择术语时必须同时指出它控制的对象、产生的可见差异和失败条件；不能把整组术语并列塞进提示词。

妆发设计缺口返回妆发负责人，不能在M编译时发明方向。

## 从机制到可执行描述

下例仅在对象和关系已经由输入确认时成立；换题后继承判断方法，不能借用示例中的人物、物品或事件。

> 同一发簪在正面与侧面保持插入位置和方向，不能为了美观每格换边。

先比较这种处理与一项合理替代：如果替代方案更清楚地保护本次主结果，就采用替代，不为展示技法保留原案。只有一个被锁定的有效方案时，比较未锁定变量，不重开用户已确认的设计。

## 验收与修复

逐项检查输出中的对象和因果是否对应权威输入；术语能否变成可观察关系；有没有两个控制相互抵消。发现问题先改产生问题的选择，再改表达。对真实图像的判断必须读取实际结果；只有文本时只验设计与可执行性。

最终返回：M正文、同状态引用、妆发定位、穿着与版式验收。附本次采用、舍弃的关键选择及原因；未确定条件明确保留，不用推测补成事实。
