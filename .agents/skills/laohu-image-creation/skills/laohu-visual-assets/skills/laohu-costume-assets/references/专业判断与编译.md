# 服装资产的判断与编译

## 专业判断

接收服装设计包和F，逐项继承轮廓比例、开合方式、层叠与材料；不可见工程信息分为可推定与会改变外观的高风险缺口。

多视图以同一件衣服验证前后与侧部连接；季节和阶段有明确时间戳，不把穿着旧化当新款重设计。

## 术语怎样进入选择

本专业使用：轮廓、结构、层次、穿着顺序、材料分区、活动量。选择术语时必须同时指出它控制的对象、产生的可见差异和失败条件；不能把整组术语并列塞进提示词。

普通衣服进入正式人物资产链也不能跳过W；M不补做服装工程。

## 从机制到可执行描述

下例仅在对象和关系已经由输入确认时成立；换题后继承判断方法，不能借用示例中的人物、物品或事件。

> 外套背面只能延续已确认肩线和接缝，不能因背面参考缺失擅加披风。

先比较这种处理与一项合理替代：如果替代方案更清楚地保护本次主结果，就采用替代，不为展示技法保留原案。只有一个被锁定的有效方案时，比较未锁定变量，不重开用户已确认的设计。

## 验收与修复

逐项检查输出中的对象和因果是否对应权威输入；术语能否变成可观察关系；有没有两个控制相互抵消。发现问题先改产生问题的选择，再改表达。对真实图像的判断必须读取实际结果；只有文本时只验设计与可执行性。

最终返回：W正文、设计锁定清单、工程缺口、材料与穿着合同。附本次采用、舍弃的关键选择及原因；未确定条件明确保留，不用推测补成事实。
