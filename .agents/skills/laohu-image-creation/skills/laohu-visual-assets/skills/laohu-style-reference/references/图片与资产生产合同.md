#### STY风格定调图：强风格动画的共同视觉源

当逐段载体合同把当前段落明确委派为 `AI_VIDEO_FULL`，且作品需要编辑拼贴、纸媒动画、强风格 MG、系列知识动画，或用户明确要求“先看风格选项，再定视觉母板，最后做逐段分镜图和图生视频”时，先建立 `STY风格定调图`。本分支只接收明确委派的 `AI_VIDEO_FULL` 段落；`REMOTION_OVERLAY` 不进入 `STY → VMB → KF`，录屏和证据段也不因共享色彩、字体或纸艺风格而转成全屏生成资产。它和 F 人物主视觉图承担同一种上游作用：先让人类用真实画面判断整体方向是否成立，再让下游拆分；但 STY 只控制作品级视觉语法，不控制人物身份、具体段落内容和逐镜构图。

```text
同一内容基准：选择一条能同时暴露信息层级、媒介、色彩、边缘、构图和运动潜力的代表性关系。
候选竞稿：按美术风格设计交接包真实生成3—5张机制不同的定调图；候选可以沿平面剪贴、浅浮雕、微缩纸景、档案混合媒介等空间机制展开，不能只换色、纸纹、滤镜或镜像。
参考转译：用户给出样图时，先拆出空间深度、纸张结构、边缘与接缝、摄影观看位置、图文层级和可运动部件；候选至少保护其中真正承重的机制，不得把“有纸纹”误当成“像参考”。
人工定案：胜出图登记为STY01；未定案候选保持STY-A / B / C，不进入稳定调用链。
视觉母板：用户选定STY后建立`VMB01`，把胜出图编译成可跨段复用的静态语法与运动语法；未完成VMB时不批量生成KF。
静态语法：锁定媒介、空间深度、色彩角色、形状 / 边缘、纸张厚度与接缝、纹理、信息层级、版式密度、镜头观看位置和安全区。
运动语法：锁定允许的入场、退出、替换、翻页、滑轨、层间视差、纸带推进、停顿与手工定格节奏；同时写清哪些元素必须保持静止、一次只允许几个视觉动作争夺注意力。
标题文字策略：编辑型知识动画不得因担心文字崩坏而默认做成无字画面。`AIGC、快、多个方案、学习规律`这类承担主重心、节拍或概念命名的标题级大字，允许并应当先让图片模型参与定调；完整字幕、解释长句、数值和必须逐字正确的正文仍交给Remotion等确定性工具。正式KF可保留带大字版本；若文字实测崩坏、视频入口容易扭字或后期需要替换，再为同一构图补一张`P0无字底板`，不能反过来用无字底板取消标题设计。
不得继承：候选图的具体主体、文字、Logo、图标、人物、卡片坐标和完整布局。
逐段拆分：按已确认脚本节拍生成KF01—KFn；每张KF须在静止时明确其已委派的知识关系与状态；起始帧、结果帧或构图参考分别登记，不强制把每张都做成最终完成态，再为视频保留相容的动作起点、路径和停点。

KnowledgeVisualContract 空间化：不把脚本里的题材名换成若干图标。先把 `entities → initialState → interaction → stateChanges → resultState`编译成“知识拓扑”，再把这条因果链编译成“空间拓扑”：哪些是语义物件组，谁作用于谁，力、信息或材料沿哪条作用路径移动，哪个状态需要由 KF-A / KF-B 或多关键状态分开承担。`labelPlan`只保留少量中文大标签，就近标明身份、动作、结果或边界；不生成长句、密集小字、随机英文或生产占位符。`cameraPurpose`只能用来显露层级、穿过遮挡、跟随作用路径或完成焦点交接，不得为炫技改变知识关系。正式 KF 必须通过静音理解检查：关掉旁白后，仍能辨认核心对象、作用顺序和结果；若只能看出“这是 AI / 金融 / 医学”而看不出关系，返回重编。

强风格知识动画还要在既有图片提示词栏目内部通过`结构化信息密度与运动可供性门`。信息密度不是随机多塞图标，而是把本段唯一知识关系物理化为有层级的语义对象、过程站、路径、机关和空间结果：主承重装置之外，应按实际复杂度保留足以解释关系的对象组、2—4个不可跳步的状态节点、至少一条可追踪路径，以及门、轨道、转盘、传送带、分类槽或验证关卡中的必要物理因果；前中后景和摄影机通道只在帮助观众看懂同一关系时成立。若KF退化为“稀疏四卡片围中心标签”，只能支持同时飞入或简单汇聚，且没有对象之间的连续作用，必须返回内容设计重构；不得用无职责装饰、随机图标或全体发光漂移冒充高密度。

这里的密度指关系密度、状态密度和可追踪路径密度，不是对象数量。一个对象通过三次可见状态变化完整证明因果，比十个同时漂浮的图标信息更密。

正式编译前可在内部建立`运动可供性判断`，逐一核对真实对象的初态位置、允许动作、路径、作用对象、触发后状态、最终落点和摄影机看见过程的方式；它只用于完善现有风格、画面内容、构图和参考职责，不新增对外交付模板。复杂过程不得让一张完成态图片同时冒充起点和终点：按入口与因果阈值选择单帧、`KF-A起始状态＋KF-B结果状态`或多关键状态，并为每张图片声明起始帧、终点帧或构图参考职责。

#### AI叠层兼容预判

当 `AI_VIDEO_FULL` 后续可能承接 Remotion 的章节进度、证据标签、解释卡、结论大字或桥接提示时，KF 不能只回答“这一镜如何独立好看”，还要预判“后期信息从哪里进入而不破坏知识关系”。这项预判只描述 AI 画面给后期留下的空间与风险，不负责设计 Remotion 组件，也不替最终合成做蒙版决定。

每张承重 KF 在现有交接中补充：

```text
AI叠层兼容预判：可兼容 / 有条件兼容 / 本镜禁止叠加。
视觉锚点：本镜必须完整看见的主体、作用路径、结果装置及其运动轨迹。
稳定负空间：在一段可读时间内，主体、镜头和光线都不会侵入的区域；没有就明确写“无”。
禁入区域：人物脸手、核心标签、主因果路径、结果停点以及镜头即将穿过的区域。
亮度分布：按起始 / 过程 / 结果写暗、亮、混合或快速变化，不能只给全镜平均值。
运动负荷：按阶段写低 / 中 / 高，并指出运动来自摄影机、主体还是前景遮挡。
可交接时刻：哪个知识状态完成后，画面可以把第一注意力让给后期叠层。
```

稳定负空间不是为了把画面做空，也不能牺牲主知识结构去预留“万能右侧空位”。已有深色背景与高亮 Remotion 自然形成足够对比时，可以建议后期不加衬底；背景复杂或明暗快速变化时，只指出风险与可用区域。最终采用无衬底、局部底板、区域压暗还是全幅压暗，必须由后期对真实生成视频逐帧复核，资产层只做预测。

视频交接：图生视频绑定VMB01负责成像世界与动作边界，KF负责本段对象、关系和构图；人物身份、产品结构和场景拓扑仍由各自资产负责，视频正文主要展开运动、触发、镜头、声音与结束状态。
```

风格候选图属于面向人定调的成品图；人工选定后，STY01 先被编译为VMB01，再成为全局参考资产。选中不是把整张图片冻结：下游必须使用`参考职责合同`隔离样本残留，尤其不得复制外部品牌、字体、原文字、Logo 和精确版式。风格图只证明“想选择哪一种观看方式”，视觉母板证明“这种方式如何稳定复用”，逐段 KF 才证明“这一段画什么”；三者不能互相替代。这条分权简称 `STY＋VMB＋KF`：STY负责用户定案，VMB守统一静态与运动语法，KF守当前段落的内容关系与构图。
