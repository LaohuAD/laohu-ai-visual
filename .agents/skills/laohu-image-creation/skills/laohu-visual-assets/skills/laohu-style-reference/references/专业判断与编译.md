# 风格定调资产的判断与编译

## 专业判断

接收美术合同，选择能共同证明形态、色彩、边缘和材质的少量对象。母板的示例内容不是剧情，明确哪些可迁移规则与哪些禁止继承对象。

跨人物和场景测试同一规则是否成立；动画与叠层要检验背景留白、分层边界与运动兼容，不能只看单张漂亮。

## 术语怎样进入选择

本专业使用：形态语言、色材光系统、风格母板、控制职责、样本残留。选择术语时必须同时指出它控制的对象、产生的可见差异和失败条件；不能把整组术语并列塞进提示词。

STY不代替B/W/M/S；参考里的姿势和文字不能偷渡进后续镜头。

## 从机制到可执行描述

下例仅在对象和关系已经由输入确认时成立；换题后继承判断方法，不能借用示例中的人物、物品或事件。

> 母板保护纸片边缘和有限色域，后续不同场景继承形式，不复制同一座房子。

先比较这种处理与一项合理替代：如果替代方案更清楚地保护本次主结果，就采用替代，不为展示技法保留原案。只有一个被锁定的有效方案时，比较未锁定变量，不重开用户已确认的设计。

## 验收与修复

逐项检查输出中的对象和因果是否对应权威输入；术语能否变成可观察关系；有没有两个控制相互抵消。发现问题先改产生问题的选择，再改表达。对真实图像的判断必须读取实际结果；只有文本时只验设计与可执行性。

最终返回：STY正文、可继承系统、禁止继承内容、叠层兼容。附本次采用、舍弃的关键选择及原因；未确定条件明确保留，不用推测补成事实。
