# 版式设计的判断与编译

## 专业判断

先按语义给信息分组，再建立共同起边和阅读方向；网格跟随承重边界，栏数服务复用。留白负责分组、停顿或保护，不能只被叫作高级。

用组内与组间差异建立阅读秩序。重排时保护信息层级与图像证据，不把整张图同比缩小作为所有比例的答案。

## 术语怎样进入选择

本专业使用：网格、基线、对齐、邻近、视觉层级、密度、出血、安全区。选择术语时必须同时指出它控制的对象、产生的可见差异和失败条件；不能把整组术语并列塞进提示词。

日本版式不是竖排红黑加印章；破格须先有可以被察觉的秩序。

## 从机制到可执行描述

下例仅在对象和关系已经由输入确认时成立；换题后继承判断方法，不能借用示例中的人物、物品或事件。

> 标题和行动证据组成第一组，时间地点在共同左边界进入第二组，人物视线方向保留空白。

先比较这种处理与一项合理替代：如果替代方案更清楚地保护本次主结果，就采用替代，不为展示技法保留原案。只有一个被锁定的有效方案时，比较未锁定变量，不重开用户已确认的设计。

## 验收与修复

逐项检查输出中的对象和因果是否对应权威输入；术语能否变成可观察关系；有没有两个控制相互抵消。发现问题先改产生问题的选择，再改表达。对真实图像的判断必须读取实际结果；只有文本时只验设计与可执行性。

最终返回：组块、网格依据、阅读顺序、密度与跨比例重排规则。附本次采用、舍弃的关键选择及原因；未确定条件明确保留，不用推测补成事实。

## 专项深化与同素材比较

**术语与因果**：网格是共享对齐边界和模块关系，不是画几条线；组块把同一阅读阶段的信息联系起来；间距区分组内/组间关系；密度影响局部阅读负担，留白可承担分组、聚焦、延迟或裁切余量。

**方法链**：信息分级与语义分组→确定阅读方向→从标题起边、图像轮廓、保护区生成对齐骨架→布局高/中/低密度→建立组内紧、跨阶段松的关系（必要用共同基线替代紧距）→只给一项有内容理由的越界→最长标题、最复杂主体、不同画幅重排检查。

**条件/反例**：四栏、8px或固定空白比例不是跨任务定律。纵横混排每多一种方向就增加一次阅读转向，只有身份或关系收益足够才用。展览长阅读海报和手机封面不能互换判断。

**同素材比较**：同一标题、杯子、三行参数，A每行等距形成五个孤立物；B标题一组，参数一组，杯子一组，组间留更大间距，阅读顺序更明确。把参数完全删除若破坏购买信息，不是合格精简。
