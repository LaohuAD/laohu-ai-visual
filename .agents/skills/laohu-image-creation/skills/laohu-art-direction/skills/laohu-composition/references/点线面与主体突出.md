# 点线面与主体突出

本方法负责画面内的注意力秩序：点让观众知道第一眼看哪里，线让观众知道视线怎么走，面让画面杂质被压掉，三者共同决定画面是否有秩序；需要纵深、遮挡、空间因果或关系距离时，再由构图层次说明前中后景各承担什么，最后统一过一遍主体可读性。适用于主体与观看目的已经确认，但视觉落点、视线路径、留白压制、遮挡或主体可读性仍不清楚的构图任务；已有有效结论直接继承。本文件只作构图判断：光源因果归光影专业，光学成像归摄影专业，画面里的人、事与状态由上游内容决定。

## 点：视觉落点

点让观众知道第一眼看哪里。它是画面里最先抓住眼睛的对象，可以是一张脸、一双眼睛、一滴泪、一只手、一个道具、一棵树、一束光、一个光点、一道门缝、一件旧物、一个唯一清晰的局部、唯一亮点、发光道具、火苗、泪痕、首饰反光、手部动作或眼神。点在正中间，画面稳定、庄重、确定；点在三分线或边缘，画面更有呼吸感、孤独感或故事空间。

点线面不是美术课概念，而是给观众视线安排秩序的镜头方法。画面越复杂，点越需要被强化：更大、更亮、更鲜艳、更清晰、更高反差、更锐利，或处在运动停点。干扰很多时，主体通过面积、亮度、颜色、清晰度、反差、位置、轮廓光或独特动作被强化。

错误写法：

```text
广场上有很多人，一个女孩回头看镜头。
```

正确写法：

```text
广场人群整体压低饱和度并轻微虚化，画面右侧三分线处只有回头女孩的脸保持清晰，脸部受光比周围人亮半档，眼神直接看向镜头，成为唯一视觉落点。
```

## 线：视觉导引

线在需要安排观看路径时，把视线引向主体或从主体引向别处。主体在线条起点、途中或终点会改变信息顺序、观看顺序和空间方向，但不固定对应存在感、孤独、动作或登场；情绪还取决于人物处境、速度、密度和声音。只有线性节奏承重时才选择位置，并结合人物处境判断情绪。斜线、曲线、S 形、水平线、垂直线和多线汇聚首先改变方向感、节奏和视觉收束程度，不固定对应冲击、舒缓、稳定、庄重或压迫。

常用线条对象：栏杆、道路、桌沿、窗框、门框、桥、光束、阴影、海岸线、人物视线、手臂方向和群体朝向。

写线时必须写清起点、路径和终点：

```text
木栈道从画面左下角斜向右中远处延伸，木板缝和扶手线条汇聚到人物脚边，人物站在线条终点回头。
```

不要只写：

```text
画面有引导线，构图高级。
```

视线落差是线的另一种用法：人物目光、身体朝向、光束方向和构图线条共同指向画面外或画面内的关键区域。

## 面：留白、压制和空间切割

面是大面积的天空、海面、墙面、暗部、雾气、虚化背景、草坡、石墙、门洞阴影或前景色块。面可以是留白，也可以是压制。它的任务不是单纯填背景，而是切割空间、挤压杂质，把主体放到更干净、更有力量的小空间里。背景人物、杂物、纹样和环境细节被压低饱和度、降低清晰度、放进暗部或虚化块面，就是面在承担信息降噪。

留白是面的一种用途：天空、海面、墙面、暗部、门洞、虚化背景或纯色块可以承载安静、压迫、隔绝、字幕或降噪；是否使用取决于主情绪和用途。

正确写法：

```text
画面左侧三分之二被深绿色虚化树影压成干净暗面，只在右侧三分线留出一块柔金亮面承接人物侧脸，暗面压掉杂乱枝叶，亮面托出鼻梁、唇峰和耳坠。
```

使用规则：

```text
主体复杂时，用干净块面承接主体。
背景杂乱时，用暗部、虚化或大面积墙面压掉信息。
情绪孤独时，让人物只占小点，周围大面积天空、海面、雪地、草坡或墙面成为压迫性留白。
人物高级感镜头中，面要干净，边角不要有随机路人、碎道具、强特效或文字。
```

## 构图层次与遮挡

需要纵深、遮挡、空间因果或关系距离时，不要只写“近景”“中景”，应说明必要层次：

```text
前景：若承担遮挡、入口或视点证明，写离镜头最近的手、袖口、门框、桌边、被窝或肩膀。
中景：通常承接核心动作，但平面特写不必硬设中景层。
背景：只保留理解空间、情绪或连续性所需的门、窗、院墙、灶火、遗像桌或道路。
```

深景深群像、正面平光事实镜头、黑白剪影和极简背景都可能没有完整三层。判断标准是主情绪与关键信息是否清楚，不是前中后景是否齐全。

示例：

```text
前景是小安的被窝边缘、浅色睡衣袖口和揉眼的小手；中景是父亲裤腿、外套下摆和递到床边的手；背景是门框、书桌虚影和窗帘缝里的清晨光。
```

这个示例因为需要证明 POV 和室内空间，所以三层都承担职责；它不是所有镜头的固定格式。这样写的作用是把模型注意力固定在本镜真正需要出现的关系上，而不是用一串否定词让模型猜。

遮挡是层次里的局部保留手段：门框、窗帘、发丝、手、前景虚化物、半透明玻璃和阴影切割画面，保留局部信息。神秘局部是遮挡的极端用法：半张脸、唇部、眼睛、手指、侧颈、衣料边缘、首饰微光或背影回头形成想象空间。

## 主体可读性检查

高质量图片首先要给观众眼睛找一个家。画面可以复杂，但第一眼必须知道看哪里。点线面最终必须服务主体突出：不要为了形式把点、线、面都堆满；只要观众第一眼不知道看哪里，就先重写视觉落点。

```text
边角清洁：
画面四角不塞随机文字、路人、半截物体、错位手脚和无关装饰。

远看可认：
缩小到封面尺寸时，仍能认出主体身份、情绪和画面关系。
```

本方法的质量作用是目标而不是已经实测的效果：命中主体突出特征后，图片应从“元素很多”走向“第一眼有主角”，并服务封面点击、资产可用性和视频参考稳定性；点线面让图片不再靠运气好看，它把审美从“元素选择”推进到“视线组织”。是否真的达到，要按真实生成结果复验，不能用文本检查代替。
