## 7. 光影与肤色审美特征资产

### 7.1 通用基底

光影决定观众怎样看见主体、空间和材质；人物肤色与皮肤介质首先要符合地域、年龄、职业、年代、健康和主情绪，而不是统一追求“白皙舒服”。只有光影或皮肤承担主情绪、身份识别、主体塑形或生成稳定性时，才从方向、软硬、反光、色温、妆效和纹理中选择必要控制项。

### 7.2 特征颗粒

```text
光影关系：
单一硬光、平光、剪影、近无辅光或多层布光都可以成立；关键是需要看清的情绪与事实证据不被破坏。

主光方向：
光从画面哪侧、哪个高度、什么时段进入，照到脸、手、衣料或道具哪里。

暗部可读性：
只在暗部包含必要表情、动作或身份信息时补自然反光；需要剪影、隐藏或压迫时允许暗部失去细节。

分离方式：
主体可以通过轮廓光、明度、色差、清晰度、面积、运动或空间位置与背景分离，不默认补轮廓光。

肤色正向：
明确角色自己的冷暖、明度、气色、纹理与妆效。冷白、健康暖肤、深肤、晒痕、雀斑、皱纹、粗粝皮肤、无妆、年代妆、柔雾或油润都可以成为正确身份状态。

高光控制：
高光范围、硬度与反射强度服从光源、皮肤状态和主情绪；可以克制，也可以因汗水、油脂、舞台妆或湿润环境而明显，但不能无来源糊掉关键五官。
```

### 7.3 原生直出成像门

当老胡明确喜欢某张生成结果的光影、肤质、色调和质感，并说明它未经后期调色时，目标不是模仿一层滤镜，而是让这些关系在生成帧内已经成立。内部按以下因果反推：

```text
时间、天气与场景光源
→ 主光、环境补光和必要分离光的方向、面积与色温
→ 人物相对背景的曝光与动态范围
→ 皮肤、眼睛、嘴唇、发丝、首饰和衣料各自的漫反射与局部高光
→ 背景明度、冷暖、清晰度和虚化光区对人物的衬托
→ 焦点、景深、散景形状和边缘响应形成最终成像
```

光学描述默认按 `光源 → 传播路径 / 介质 → 光的变化 → 落点材质 → 可见结果` 编译，详细分类统一执行 `画面氛围与画质规范.md` 的“光照事件链与传播路径”。图片提示词不需要把每个环节写满，但凡写入的光必须能在主体、材质、阴影、反射或背景中找到可见落点。

原生直出不等于无风格、无色彩设计或原始灰片，也不等于禁止后续剪辑调色。它只规定：主审美不能依赖一句 `后期套电影 LUT`、`后期提亮肤色` 或 `后期增加柔光` 才成立。图片提示词必须直接写最终可见状态：哪束光从哪里进入，脸比背景亮或暗多少层级，额头、鼻梁、下眼睑、唇面和发丝哪些区域保留高光，暗侧哪些五官与肤理仍可读，背景用什么色块、反光或散景托住人物。

人物皮肤使用 `漫反射基底 + 局部镜面反射` 描述，不用 `白皙通透、奶油肌、水光肌` 独自承重。漫反射决定肤色、气色和柔和体积；局部高光只落在符合光源与妆效的额头转折、鼻梁、下眼睑、颧骨、唇峰和下唇中央。眼神光必须与主光方向一致；嘴唇可以湿润发亮，但要保留唇纹与体积；发丝边缘只在朝向逆光或侧逆光的一侧发亮。全脸同亮、鼻额过曝、阴影发灰、皮肤无毛孔或塑料镜面都属于失败。

背景不是换成浅色或虚化就算治愈。先确定人物和背景依靠 `明度 / 冷暖 / 饱和度 / 清晰度 / 材质` 中哪一至两项完成分离，再让背景保留少量能解释光源和空间深度的真实色块。暖肤色可以由冷灰蓝环境、低亮度暖色散景和一块较亮的窗面共同托住；换成深肤、夜景、古风或其他题材时重新推导，不能把示例中的年轻女性、暖白肤色、蓝灰背景、圆形灯斑和裸粉唇固化成治愈模板。

人物三资产与场景成像分责：B固定身份和身体，W固定穿戴系统，M固定最终妆发、肤质妆效基线与受控定妆摄影结果；场景资产固定窗、灯、反射面、背景色块和空气状态。若作品成败依赖人物进入具体场景后的最终光色、景深与构图，再由已经确认的 `M + 色彩风格资产 + 场景资产` 生成一张人物成品人像、首帧或镜头参考图。该图是场景化执行参考，不是第四类人物基础资产，也不能反向污染B、W、M的通用职责。
