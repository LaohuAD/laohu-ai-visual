# 老胡摄影

## 灵魂：本专业怎样取舍

镜头参数必须换来可见差异。

参数堆砌互相矛盾时，以成像目标重新求解，不能同时要求全深焦和所有背景极浅虚化。

## 筋骨：从问题到专业结果

读取当前任务目的、已确认事实、可变范围、媒介与上游结果。先判断是否存在“透视、景深、曝光、镜头质感或成像逻辑不成立”这一缺口；已有有效结论则直接继承。先定摄影机位置再定视角；透视由观察位置决定，不能把长焦压缩解释成焦距独自改变空间。专业分支、适用条件与反例按Reference执行。

## 血肉：让方法产生差异

本次以“视点与视角、焦点范围、曝光保护项、允许的光学痕迹”为独立结果，按下方方法将专业控制转成可观察关系。

选择视点、焦距、视角、景深、弥散圈、曝光、运动模糊中真正改变本次结果的控制，结合 Reference 中的完整方法、案例与例外形成候选。

## 表皮：输出与约束

返回视点与视角、焦点范围、曝光保护项、允许的光学痕迹。已锁定的故事、身份、结构、文字和状态按输入保护；模型参数只使用已核验能力。输出专业决定与必要可执行描述，不声称已经生成或实测。

## 调用与返回

可由明确点名直接使用，也可由[所属专业入口](../../SKILL.md)按缺口调用。CONSULT返回局部结果，当前作品负责人不转移；缺少上游事实时RETURN最早负责人，不自行改写剧本。需要跨专业判断时只传当前问题和保护项，不重新运行整条生产链。

## 跨包交接（不复制对方正文）

运镜与焦点调度由视频包 `laohu-video-prompt` 的 `laohu-camera-movement` 负责（《镜头运镜术语与写法》）；剪辑接口与匹配剪辑由 `laohu-editing` 负责（《剪辑接口与匹配剪辑》）。本专业只做静态成像判断与拍摄前光学决定；需要机身位移、拉焦跟焦和跨切连续性时按 HANDOFF 交给对应负责人，不在图片包内另建副本。
