# 老胡摄影

## 灵魂：本专业怎样取舍

镜头参数必须换来可见差异。

参数堆砌互相矛盾时，以成像目标重新求解，不能同时要求全深焦和所有背景极浅虚化。

## 筋骨：成像目标与方法路由

读取当前任务目的、已确认事实、可变范围、媒介与上游结果。先判断是否存在“透视、景深、曝光、镜头质感或成像逻辑不成立”这一缺口；已有有效结论则直接继承。先定摄影机位置再定视角；透视由观察位置决定，不能把长焦压缩解释成焦距独自改变空间。景深是可接受清晰范围，同时受光圈、焦距、对焦距离与输出观看条件影响；曝光负责保护本次必须看清的肤面、高光或结构，不用过曝宣称梦幻。专业分支、适用条件与反例按Reference执行。

## 血肉：让方法产生差异

选择视点、焦距、视角、景深、弥散圈、曝光、运动模糊中真正改变本次结果的控制，逐项说明它控制的对象、产生的可见差异和失败条件，再结合 Reference 中的完整方法、案例与例外形成候选；不能把整组术语并列塞进提示词。静态照片的拖影须有曝光期间的相对运动；视频快门风格服从动作可读性，帧率不等于运动速度。

## 表皮：输出与约束

返回视点与视角、焦点范围、曝光保护项、允许的光学痕迹。已锁定的故事、身份、结构、文字和状态按输入保护；模型参数只使用已核验能力。输出专业决定与必要可执行描述，不声称已经生成或实测。

## 调用与返回

可由明确点名直接使用，也可由[所属专业入口](../../SKILL.md)按缺口调用。CONSULT返回局部结果，当前作品负责人不转移；缺少上游事实时RETURN最早负责人，不自行改写剧本。需要跨专业判断时只传当前问题和保护项，不重新运行整条生产链。

## 当前文本的语言执行

直接接受局部请求时，也按本包[语言表达](../../../../references/语言表达.md)先判当前文本块的发声者、接收者与任务。保护原话和专业事实；只补不足的请求不得改变已确认内容。遇到混写或冗余时按该文件选择具体方法，完成后回到本专业验收。

## 按当前缺口读取的补充方法

每条按“未决问题 → 读取 → 返回决定”使用，只进对应主题，不整份加载。

- 写任何画面内容前缺总判断：读[镜头语言基础_第一判断与四件套](references/镜头语言基础_第一判断与四件套.md)，返回本次主观看任务、主注意力目标、主情绪目标，以及真正承重的开放控制杆。
- 画幅里能装多少证据、观众多近看：读[景别与取景范围](references/景别与取景范围.md)，返回景别理由与裁切保护区；跨镜推进与切换归剪辑专业。
- 从哪一侧看、平视还是俯仰、真实观察高度：读[机位与俯仰角度](references/机位与俯仰角度.md)，返回观察方向与机位高度。
- 主观、客观、过肩、插入或内外打不清楚：读[镜头关系与画面来源](references/镜头关系与画面来源.md)，返回画面来源声明与镜头关系；严格 POV 写法归视频编译。
- 质感词是否真正承重：读[光学质感与情绪反证](references/光学质感与情绪反证.md)，返回保留、替换或删除哪一项质感控制。
- 谁必须清楚、前后景糊到什么程度、焦外光点或颜色怎么呈现、多个对象能否同时清楚：读[对焦景深与焦外](references/对焦景深与焦外.md)，返回对焦对象、清晰范围与焦外表现。
- 术语与旧词别名需要校准：读[专业判断与编译](references/专业判断与编译.md)，返回术语、它控制的对象、可见差异与失败条件。
- 上列主题最容易犯的具体错误：读[镜头语言常见错误](references/镜头语言常见错误.md)，返回本镜需要避免的失败条件。
- 需要纵深、遮挡、空间因果或关系距离，或落点、视线与留白不清：读[构图·点线面与主体突出](../laohu-composition/references/点线面与主体突出.md)，其中[构图层次与遮挡](../laohu-composition/references/点线面与主体突出.md#构图层次与遮挡)返回前中后景职责、无三层成立条件与遮挡方式；视觉落点、视线导引与留白压制归构图专业。
- 正反打、轴线与跨切空间连续性：本专业不再持有正文。完整方法整体归视频包 `laohu-video-prompt` 的《镜头空间与连续性》（真人/三维空间的连续正反打与越轴过渡），静态故事板与分镜同样读取该处真源；本专业只作单镜成像判断。

## 跨包交接（不复制对方正文）

运镜与焦点调度由视频包 `laohu-video-prompt` 的 `laohu-camera-movement` 负责（《镜头运镜术语与写法》）；剪辑接口与匹配剪辑由 `laohu-editing` 负责（《剪辑接口与匹配剪辑》）；正反打、轴线与跨切空间连续性由视频包《镜头空间与连续性》负责（原摄影《正反打与轴线》整体归入该处）；视频提示词分层公式，以及主观镜头与 POV 写法的画面来源声明、前景锚点、稳定方式、视线运动与语法检查，由视频编译负责。本专业只做静态成像判断与拍摄前光学决定；需要机身位移、拉焦跟焦和跨切连续性时按 HANDOFF 交给对应负责人，不在图片包内另建副本。
