# 光学质感与情绪反证

> 景深、光晕、介质等质感词是否真正承重不清楚时读取，返回保留、替换或删除哪一项质感控制，并用替换反证和冲突反证检验。

## 光学质感选择

| 光学 / 质感 | 作用 | 使用规则 |
|---|---|---|
| 浅景深 | 突出主体、虚化背景、情绪亲密 | 写主体清晰、背景柔和虚化，适合表情、手部、道具特写 |
| 深景深 | 空间关系、群像、风景、仪式 | 前景到背景都清楚，适合院子、饭桌、放学路、场景资产一致性 |
| 前景虚化 / 遮挡 | 增加层次、信息差、记忆感 | 写树枝、门框、肩背、被沿、孝布、火光等遮挡在前景什么位置 |
| 镜头光晕 Lens Flare | 逆光、夕阳、怀旧暖意 | 写光源方向和落到哪里，不能无光源硬加光晕 |
| 胶片 / 16mm / 35mm / 老式 DV | 年代、记忆、材质统一 | 《不想长大》优先 90 年代老式 DV 质感、暖黄配色、轻微频闪噪点、自然光 |
| 电影宽幅 | 史诗、庄重、院线感 | 只有需要电影感和宽幅构图时使用；短剧家用 DV 不要无故写 2.39:1 |
| 鱼眼镜头 | 夸张、变形、特殊主观 | 极少用；会强烈改变现实感，生活纪实镜头默认不用 |
| 微距景深 | 极近物件证据 | 硬币划痕、糯米皮纹理、蒲团粗布纤维、火柴火苗可用 |

光学质感必须和故事介质统一。温馨家庭回忆可以有 DV 噪点、自然光、轻微频闪和暖黄；不要突然切成现代广告级高反差商业质感，除非本镜明确是另一种影像层。

上表是检索入口。谁必须清楚、前后景允许糊到什么程度、多个对象能否同时清楚、焦外光点与颜色怎样呈现，以及“虚化”究竟属于离焦、运动模糊、介质朦胧还是后期模糊，按本专业[对焦景深与焦外](对焦景深与焦外.md)执行；该文件只展开焦点与清晰范围，不重复本节的光学质感词表。

## 情绪反推与反证

情绪没有固定镜头套餐。正确方法是先写清人物处境和观众应感到什么，再比较候选手段怎样改变距离、尺度、稳定感、信息量和时间感。例如同样表达紧张，可以用手持追逐让身体失控，也可以用绝对固定的长镜头让危险无法逃离；同样表达治愈，可以慢推靠近，也可以用远景静止让人物终于拥有空间。

选择后做两次反证：

```text
替换反证：把当前运镜、光色或景别换成常见同义方案，主情绪是否几乎不变？如果是，当前手段没有真正承重，可以删减。
冲突反证：当前手段是否同时召回另一种更强的感受，例如浪漫光晕削弱危险、炫技环绕削弱哀悼、漂亮慢动作削弱受力？如果是，降低权重或更换方案。
```

当前案例中，丧事叩首选择固定低视线、下压和冷灰白布，是因为这些关系让人物被仪式空间压住；若故事改成角色主动反抗礼制，同一场景可能需要抬升、逼近或破坏稳定。原则不是“丧事不能环绕”，而是任何镜头都要证明它对这一刻主情绪的贡献。
