# 镜头语言常见错误

> 上列各摄影主题最容易犯的具体错误；写完画面内容后读取，返回本镜需要避免的失败条件。正反打、轴线与越轴过渡的完整规则归视频包《镜头空间与连续性》。

## 常见错误

- 把 `儿童 POV` 写成泛称，没有绑定具体人物资产。
- 只写“第一人称”，但画面内容仍在描述第三人称能看见的脸、背影和全身。
- 写“正反打”但没有轴线、左右关系和视线方向。

- 写“过肩”但没有说明谁的肩在前景、谁在中景、谁看向哪里。
- 写“内打外 / 外打内”但没有先定义门、窗、车门、桌子是哪一侧。
- 只写动作结果，不写动作从哪边开始、哪只手先动、道具如何承重和移动。
- 用否定词堆边界，却没有写出前景、中景、背景应该出现什么。
- 把大全景、浅景深、环绕、镜头光晕等专业词当万能高级词，没有说明它们服务的镜头任务。
- 运镜没有路径、方向、速度和停点，只写 `镜头移动`、`镜头切换`、`氛围感运镜`。
- 光学质感和故事介质冲突，例如温馨 90 年代家用 DV 回忆突然写成现代广告级商业稳定器大片。
