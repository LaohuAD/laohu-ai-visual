# 机位与俯仰角度

> 从哪一侧看、平视还是俯仰、真实观察高度不清楚时读取，返回观察方向、机位高度，以及它怎样改变尺度、遮挡、力量关系和信息范围。

## 机位角度选择

下表描述常见倾向，不是情绪字典。同一平视、俯拍或仰拍可以产生相反感受，必须结合人物处境、镜头距离、空间、稳定方式、表演和声音判断。

| 机位 | 直接改变的知觉关系 | 选择与验证 |
|---|---|---|
| 平视机位 | 观看者与主体高度接近，尺度差较小 | 可用于亲近、对峙、冷漠或客观观察；看人物处境和距离是否把主情绪传准 |
| 轻度俯拍 / 高角度 | 主体面积与高度被压低，周围空间占比增加 | 可显得脆弱，也可显得被观察、秩序清楚或环境占优；写清从哪里俯看、谁变小、空间增加了什么压力或信息 |
| 高空俯拍 / 鸟瞰 | 人物个体缩小，整体路径和群体关系变清楚 | 只在空间关系、行动路线或个体与环境的比例承担任务时使用；不要把它自动等同命运感 |
| 低角度 / 仰拍 | 被摄对象在画面中增高，前景与垂直线被放大 | 可形成威胁、尊敬、陌生、滑稽或英雄感；成立含义取决于距离、焦段、表演和上下文 |
| 45 度斜侧机位 | 同时保留部分正脸、侧脸和空间纵深 | 适合需要兼顾表情与环境关系的镜头；不是“自然高级”的默认人像角度 |
| 正侧机位 | 正向眼神信息减少，轮廓与运动方向更清楚 | 可产生克制、观察、疏离或纯动作可读性；若眼神承重，需确认侧面仍能读到关键证据 |
| 正反打 / 过肩 | 观众在两方之间切换站位，关系距离被具体化 | 对话、试探、冲突或亲密都可使用；先定必要轴线、左右关系、前景肩和视线方向 |
| 门缝 / 窗缝 / 车内机位 | 可见范围被遮挡，空间被分成内外 | 可建立偷看、保护、隔绝或窥见日常；写清遮挡物、空间内外、可见范围和声音来源 |

严格 POV 不是机位高度词，而是画面来源。写 `小安第一人称 POV，画面呈现小安眼前所见` 后，机位角度要落到可见结果，例如儿童低视线看见柜台上沿、成人手从上方进入画面；不要写成 `镜头等同眼睛位置`。

## 角度写法对照表

下表只描述机位首先改变的物理与知觉关系，不规定情绪。实际感受还取决于人物处境、距离、焦段、构图、稳定方式、表演、声音和上下镜头。

| 角度 | 直接改变 | 可用于 |
|---|---|---|
| 平视 | 缩小观看者与主体的高度差 | 亲近、对峙、冷漠、日常或客观观察 |
| 低角度 / 仰拍 | 放大主体高度、垂直线与前景尺度 | 威胁、尊敬、英雄、陌生或滑稽，需由上下文确定 |
| 高角度 / 俯拍 | 缩小主体、增加周围空间与路径信息 | 脆弱、秩序、监视、隔离或空间说明 |
| 贴地低机位 | 放大地面物件和脚步尺度 | 奔跑、门槛、车轮、纸灰或低视线身体经验 |
| 桌面视角 | 把手部、器具和接触关系置于同一平面 | 手工、食物、仪式、证据或动作因果 |
| 门缝 / 窗缝视角 | 限制可见范围并分隔空间内外 | 偷听、保护、隔绝、窥见或画外声空间 |

## 视频分镜的角度倾向

> 来自《短剧短片分镜生成字段规范》（原第六章等），正文未改。

## 七、角度与心理倾向

| 角度 | 首先改变的知觉关系；情绪由上下文决定 |
|---|---|
| 平视 | 缩小观看者与主体的高度差，可用于亲近、对峙、冷漠或观察 |
| 仰拍 | 放大主体高度和垂直线，可用于威胁、尊敬、英雄、陌生或滑稽 |
| 俯拍 | 缩小主体并增加周围空间，可用于脆弱、秩序、监视、隔离或路径说明 |
| 过肩 | 具体化两人距离、遮挡和站位，可用于冲突、亲密、试探或普通交流 |
| 主观视角 | 限制为视点主体所见，可用于代入、误判、平静观察或信息差 |

角度必须服务人物关系和主情绪。表中只提供起点，使用时要写清当前角度怎样改变距离、尺度、信息和力量关系。
