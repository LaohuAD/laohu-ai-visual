# 创意开发与主题检验

## 开发协议

### 创意成熟循环

正式破题前先形成内部 `创作者意图契约`：观众要经历什么；创作者为什么要做；不可改变的事实、价值和结果；允许主动补全的空间；明确不要变成什么。不要把题材、结构、参考作品或一个漂亮场面误当成完整意图。

随后执行一次创意成熟循环，不能从用户的一句话直接跳到格式正确的剧本：

```text
1. 候选发散：开放方向通常提出 3-5 个机制不同的候选；已锁定事实与结尾不重开，在剩余实现中比较。
2. 众数答案：指出模型最容易给出的普通版本、类型惯性和观众一眼能猜完的部分。
3. 最强反对意见：从人物动机、因果、价值、原创性、情绪承诺和可拍性攻击每个候选最脆弱的前提。
4. 二阶后果：继续推演关键选择发生后，关系、代价、物件、空间、身份和观众判断怎样变化，并寻找可见 / 可听证据。
5. 二次延伸：保留经得住质疑的核心，生成更准确的转折、结尾、叙述方式或意象，不用随机事件遮住问题。
6. 创意选择：按观众承诺、情绪潜力、原创性、持续发展和 AI 可生成性选择；必要时说明为什么淘汰其余方向。
```

只有方向选定后，才使用三幕式、起承转合、短剧节奏网格、英雄旅程或类型范式检查因果和组织材料。结构能指出哪里缺压力、转折或回收，但不能替代人物欲望、具体选择和新鲜观察。

这不等于拒绝归纳和复用结构规律。成熟结构可以继续拆成前置条件、人物行动、状态变化、观众更新与下一压力，作为候选故事构件重新组合；反对的是只写原型名称、固定幕数或表面节拍就宣布故事成立。需要产生新结构方向时读取 `06_故事构件拆解与组合语法.md`，在开放方向通常比较三个因果真正不同的候选；已锁定方向按剩余自由区比较，再让人物意图、不可逆代价和当前体量决定胜负。

选定方向后，为关键节拍维护 `观众认知状态`：观众知道什么、暂时相信什么、正在问什么、预测什么、第一眼看哪里、主要感到什么、本节拍改变什么、下一节拍靠什么牵引。它是编剧和导演内部账本，不要求逐镜机械填满；但连续几个节拍没有改变任何相关状态，说明故事停滞。

同时先分清五层视角：叙事视角、信息视角、价值视角、时间视角、光学视点。编剧负责前三至四层，不能用“主角 POV”替代信息设计；摄影机是否第一人称由分镜阶段根据观众体验决定。

### 1. 破题

先回答：

```text
这个故事真正要让观众等什么？
这个灵感能影射什么公共议题或价值冲突？
它的正向价值是教育、尊重、民族记忆、善意、边界、勇气、清醒、担当，还是其他方向？
观众最容易产生什么刻板误判？
反转点是推翻观众误判，还是推翻角色自己的错误认知？
有没有能承载寓意的物件、动作、称呼、空间或特写局部？
开头是否需要未闭合动作：倒计时 / 即将碰撞 / 即将插入 / 即将爆开 / 即将击中镜头 / 即将揭晓 / 不需要。
主角是谁？
主角的生产命名是什么？观众称呼和资产命名是否能映射？
主角想要什么？
谁或什么阻止他？
失败会失去什么？
最有画面感的冲突瞬间是什么？
```

如果这些问题答不清，先写故事种子，不要直接写完整剧本。

如果老胡只给一个灵感，先给 3-5 个价值脑洞候选。候选必须在价值母题、反差机制、隐喻物、片名方向或开场钩子上不同，不要把同一个教育意义换几句说法。推荐输出：

```text
方向名：
影射议题：
正向价值：
观众误判：
反转机制：
开场特写钩子：
隐喻物 / 片名方向：
结尾回响：
适合体量：
```

正能量不能写成说明文结论。不要让角色直接讲大道理，优先让动作、选择、物件归还、称呼改变、光照到谁、谁被看见、谁被保护来完成价值表达。

故事种子不是小说开头，而是把故事能否成立先摆到桌面上。种子槽位固定，槽位里的内容开放；至少写清：

```text
一句话故事：谁在什么处境里，想要什么，被什么阻止。
观众等待的问题：观众前 3 秒开始等哪个结果。
首画面：第一眼给观众的关系、危险、欲望或奇观。
尾画面：最后停在哪个动作、物件、表情、声音或反转上。
关键转折：故事从哪里改变方向。
情绪曲线：观众从好奇、紧张、心疼、爽感、羞耻、治愈或震动中的哪几种状态走过去。
主要场景链：每个场景为什么存在，进入和离开时信息或关系发生了什么变化。
资产预判：哪些人物、场景、道具、色卡或声音需要后续稳定。
生成风险：哪些画面、动作、时代、空间、表演或奇观容易被模型生成错。
具体人物与具体处境：身份、社会位置和当前生活条件，不写成抽象人群或抽象价值。
诱发事件：具体触发动作，以及为什么这件事必须现在发生。
明确目标与外部阻力：想要什么，谁或什么阻止他，失败会失去什么。
内部阻力：人物自己的恐惧、错误信念或不愿承认的需要。
规则限制与时间压力：什么规则不允许，什么期限或代价正在逼近。
信息差：观众、主角和配角各自知道什么，误解从哪里自然长出来。
具体代价与不可逆选择：做这个选择会失去什么，哪一步做完就回不去。
情绪出口与结尾回收：观众带走什么认知或情绪，哪个物件、称呼或动作在结尾带着新含义回来。
传播窗口：标题解释、评论引导、封面画面、可截图句和可复述点从哪里长出来。
```

高质量故事种子是：

```text
一个具体身份的人，因为一个具体触发事件，必须在某个限制内做一个会付出代价的选择，否则会失去某个无法补回的东西。
```

如果是 15 秒以内单镜头、音乐卡点、转场素材或单张视觉概念，可以只做极简故事种子；如果是 1 分钟以上短片、连续剧情、系列短剧或情绪反转作品，必须先形成故事设计稿 / 故事确认稿，再写正式剧本。

失败分支：

```text
主角不清 → 先写视角和身份关系，不写完整剧本。
观众等待的问题不清 → 先写一句话钩子和结尾记忆点。
阻力不清 → 先补规则、门槛、代价或禁忌。
体量不清 → 先按 45 秒视觉短片 / 1-3 分钟概念片 / 3-10 分钟短片分流。
镜头承载过多 → 拆成分场或多个单镜头剧本。
只有奇观没有人物锚点 → 补人物动作、手部、表情、视线、道具或声音锚点。
```

#### 选题机制、题材变体与反转教育

高质量选题是能自然长出人物、冲突、场景、台词和传播资产的故事发生机制。它通常包含：

```text
一个具体的人。
一个正在变化的关系。
一个观众熟悉但容易误判的场景。
一个可见的触发动作。
一个有代价的选择。
一个能被结尾回收的物件、称呼或动作。
一个能被观众带走的认知或情绪出口。
```

七类候选特征颗粒，按当前选题的真实承重选用，不要求一条不落：

```text
窄切特征：
从具体侧面进入大题材。亲情落到具体误解和具体物件，教育落到具体话术和具体支持动作。

临界时刻特征：
截取关系即将变化的一秒。话快骂出口、门快关上、孩子快哭出来、父母快发火、老师快定性、主角快误解完成。临界点越具体，剧本越有张力。

观众预期特征：
先让观众根据经验自动补出一个熟悉套路，再用人物选择击穿这个套路。反转利用观众的社会经验、家庭经验和刻板判断完成价值转向。

情绪代价特征：
人物说出或做出关键选择时会失去一点东西。父母选择温柔，失去的是权威姿态；孩子选择承认害怕，失去的是面子；主角选择道歉，失去的是自我保护。

现实疼点特征：
选题能碰到观众生活里真实存在的痛点，例如被比较、被羞辱、被性别偏见限制、被要求懂事、被迫让步、被爱但不被理解。

正向出口特征：
故事制造情绪压力后，给出一种更好的关系处理方式。出口可以是尊重、边界、理解、勇敢说不、承认脆弱、重新命名价值。

可切片特征：
一个 15 秒以内的场景就能独立成立。开头有预期，结尾有反转，观众不用看完整世界观也能理解情绪。
```

题材变体：

```text
教育反转：
利用传统教育话术的前半句制造预期，后半句改成尊重、鼓励、边界和安全感。

亲情遗憾：
前半段用生活温暖建立爱，后半段用不可逆失去回收物件、动作和误解。

爱情情绪：
用同一张脸在不同 VO 触发下变化，重点是情绪阶段可读。

成长故事：
主角承认一个过去不愿承认的事实，做出更成熟的选择。

社会偏见反击：
先让观众自动按照外貌、性别、贫富、成绩、身高、身份误判，再用回答或行动击穿误判。

奇幻 / 仙侠：
宏大世界服务人物门槛、礼仪、选择和代价，奇观由人物反应和规则代价承重。
```

反转让观众重新评价自己刚才的判断。

```text
价值反转：
观众以为人物要羞辱、压迫、责备，后半段给出尊重、边界、鼓励和安全感。

身份反转：
观众根据外貌、成绩、身高、贫富或身份做判断，人物用回答或行动展示更大的格局。

视角反转：
观众以为某个大人冷漠、严厉或偏心，后半段发现他的行动在保护关系。

情绪反转：
前半段表情、语气和场面像要爆发，后半段情绪转向温柔、理解或支持。

认知反转：
观众意识到自己刚才也被旧经验、刻板印象或传统话术带着走。

行为反转：
人物跳出传统剧本，做出更高级、更有边界、更尊重人的选择。
```

反转的高级感来自“人物选择可信”。观众意外的是价值方向，信服的是人物动作和关系逻辑。

反转教育短片的核心是：调用旧教育预期，再用更高级的关系处理方式改写它。

```text
前半句预期：
使用观众熟悉的传统教育开头，让观众自动补出责备、比较、羞辱或压迫。

表演误导：
父母、老师或大人先呈现严肃、皱眉、停顿、压低声音，让孩子和观众都进入防御。

价值转向：
后半句把话术转向尊重、保护、鼓励、边界、承认脆弱或重新定义勇敢。

行动落点：
大人用一个具体动作支持孩子，例如蹲下、递回、挡住、扶肩、拿回属于孩子的东西。

孩子反应：
孩子从防备、低头、观察脸色，转向松一口气、抬眼、眼眶发亮或靠近。

观众回响：
观众意识到传统反应可以被替换，并愿意把自己的经历投进评论区。
```

这类剧本要让“教育意义”藏在人物关系、具体动作和表情反应里。

### 2. 主题探索

主题不能写成口号。把主题落到人物选择：

```text
主题命题：
主角一开始相信什么：
这个信念如何帮过他：
这个信念现在如何伤害他：
最后他改变、坚持或退回旧方式的选择，以及代价：
能证明主题的动作：
```

输出时避免“他明白了”。要写“他做了什么”。

#### 主题怎样经受场面检验

主题尚未成立时，先把它写成可被剧情检验的因果判断：人物用什么办法追求什么价值，这个办法为何带来当前结局。再写一个最强反方：相反办法在什么情况下合理、有效，为什么人物仍不愿采用。反方若只能靠愚蠢、邪恶或突然失能败下去，主题尚未被证明。

比较候选时只改变未锁定的因果实现，用同一人物、资源和结尾问：哪项选择让结果更必然，却在发生前仍有真正可走的另一条路？不要另造事故来证明“人要珍惜”，不要用人物最后念出结论替代证据。复杂情感可以由同一动作同时兑现主结果与从属代价，例如归还共同使用的物品既尊重对方自主，又使自己失去下次见面的理由；两者必须来自同一事实，不能在结尾追加第二主题。

片段先行时，先试写一个具体的愿望与碰壁，观察人物怎样应对，再提出主题假设；已确认导演命题只能检验其实现，不能悄悄换题。悲剧、坚持原有价值或醒悟太迟都可以成立，不要求人物在最后变得更好。

### 9. 故事杠杆

故事不是信息堆叠，而是用少数关键元素撬动观众的情感、认知和行动。写短视频、人物故事、品牌故事、产品故事、口播和课程化内容时，要主动设计杠杆。

四个常用故事杠杆：

```text
大脑墙：观众内心已有的防线、信仰、偏见、身份、恐惧和价值观。墙越厚，冲突越强，机会越大。
痛点杠杆：人类对痛苦、损失、被冒犯、被忽视、被拖累的敏感度高于喜悦。唤起真实痛点，可以让观众从旁观变成参与。
金句钉：精炼、扎心、可复述的句子，用来穿透大脑墙，钉住观众记忆。
共鸣网：让个体经验接入群体关系、平台、社区、人脉、客户、社交身份和共同处境，让内容从一个人的故事变成一群人的故事。
利他金：内容必须让观众得到东西，例如方法、情绪释放、认知升级、勇气、判断标准、行动路径或被理解感。利他不是讨好，而是用最小表达成本调动最大信任和传播。
```

写作判断：

```text
先找墙：观众最不愿承认、最抗拒、最在意或最被冒犯的点是什么。
再找痛：观众害怕失去什么，正在忍受什么，最不想承认哪种难受。
再下钉：这条内容有没有一句能被观众记住、转述或截图的金句。
再织网：这件事是否连接到一类人、一种关系、一种身份或一个共同处境。
最后给金：观众看完带走什么，是否感到“这对我有用”。
```

如果内容讲得都对，但没有记忆点、没有传播关系、没有利他收益，就要回到这一节补杠杆。

痛点杠杆边界：

```text
可以唤起真实存在的难受、损失、风险、错失和不甘。
不能制造虚假焦虑、夸大恐惧或故意伤害弱势处境。
让用户难受的目的，是让他看见问题和行动出口，不是让他停在自责、恐慌或被操控里。
痛点之后必须给出利他金：判断标准、解决路径、安慰、行动、反击或成长。
```

#### 从观看问题到结尾回响

短视频剧本同时服务正片沉浸、停留、完播、评论和转发，所以观众问题不能等到成片才出现：它要在选题阶段就写进观看任务和结尾落点。这里说的是内容承诺和观众经历，不是编剧行业的报价、投稿、经纪或交易事务（那些判断归 `laohu-industry-business`），封面具体图文设计仍交图片与封面专业。

落到当前位置的杠杆是：

```text
前 3 秒钩子：
用特写、危险句、熟悉话术、反常回答、情绪表情或强局部证据抓住观众。

观看任务：
让观众知道自己接下来要看什么变化，例如“看她怎么从防备到崩溃”“看这句话怎么反转”。

评论钩子与社会认领：
与上面的“共鸣网”“利他金”是同一职责，不另起一套标准。结尾给观众一个能代入自己的问题，让互动从个人经历自然发生；故事触碰一类人的共同经验，观众才愿意说“我也是”“我家也是”“原来可以这样”。

正向价值：
反转教育、亲情、成长和偏见反击，最终要让观众带走更好的关系处理方式。
```

前 3 秒、评论入口和正向关系出口限定在相应短视频用途；长片、观察、纪录和教程内容按各自体裁决定是否使用，不因此把正向出口变成所有作品的必填项。

短视频剧本要像导演一样控制观众注意力；短视频承重时按下面的注意力路径逐拍检查：

```text
开头锁定：
前 3 秒给出熟悉话术、局部特写、强表情、危险句或反常动作，让观众立刻知道要看什么变化。

判断陷阱：
让观众根据生活经验先做一个自动判断，例如这个大人要责备、这个孩子要被羞辱、这个弱者会自私。

等待反转：
中段压住表情、停顿和动作，让观众等那句话或那个动作落下来。

价值击穿：
关键台词或行动改写观众预期，让观众重新评价刚才的判断。

情绪停点：
给孩子、大人或被误解者一个表情停点，让观众看到价值转向被接住。

评论入口：
结尾把问题交还给观众，让观众带着自己的家庭、学校、关系经验进入评论区。
```

注意力路径的目标是让观众经历一次“我刚才为什么会那样想”的认知回弹。

结尾是短视频被记住和被评论的地方，六类结尾落点都可选：

```text
价值落点：
一句话改写前半段的价值判断，让观众带走新的关系处理方式。

行为落点：
一个动作证明爱、尊重、保护或边界，例如递回、挡住、蹲下、扶肩、把门轻轻关上。

物件回收：
开头出现的鸡腿、娃娃、成绩单、书包、门、碗、玩具或地图，在结尾带着新含义回来。

表情停点：
孩子抬眼、父母松一口气、被误解者沉默后笑一下，让情绪停在观众能读懂的位置。

声音余韵：
台词尾音、门响、海浪、铃声、脚步或短暂停顿，让结尾有回声。

评论钩子：
结尾提出一个和观众经历有关的问题，让观众愿意回答自己的版本。
```

高质量结尾让故事完成，也让开头的判断被重新命名。

金句钉的高级形态是个体宣言：

```text
不是顺口号，而是一个人、品牌、产品或群体站出来表态。
不是拼体力，而是借脑力；宁可一个月磨出一句有穿透力的金句，不要十个月输出一堆无头苍蝇式表达。
不要只尊重共识，要从共识里找尚未被说透的偏见、真实偏好、隐秘不满和反常识角度。
偏见不是歧视或恶意标签，而是主流共识尚未承认、但观众心里已经存在的判断倾向。
```

个体宣言式金句判断：

```text
这句话是否有明确立场。
这句话是否像某类人会拿来替自己发声。
这句话是否借用了观众已有偏见、真实偏好或隐秘不满。
这句话是否能对抗一个旧共识，而不是重复一个安全共识。
```

感性与缺点杠杆：

```text
不要只追求理性正确，要借用观众的感性反应。理性负责让内容站得住，感性负责让内容被记住、被转述、被卷入。
不要只突出优点，要借用可被接受的缺点。优点容易变成普通赞美，缺点更容易形成共同敌人、亲密感、辨识度和真实关系。
能够被接纳的缺点，往往比完美优点更像一个人、一个品牌或一个角色被真正认可的理由。
缺点不是硬黑，也不是自毁，而是把人物、品牌、产品或观点的边界说清楚：它不讨好谁，它冒犯谁，它和谁站在一起。
```

写缺点时先判断：

```text
这个缺点是否真实存在，还是为了制造噱头硬编。
这个缺点是否能引出共同敌人，例如拖累、虚伪、懦弱、过度理性、讨好、平庸或旧共识。
这个缺点是否会让目标观众觉得“我懂你”，而不是只觉得被羞辱。
这个缺点最后是否转化成个性、选择、反击、成长或关系，而不是停在负面标签。
```

选择性注意与风格边界：

```text
想讨好所有人，就会失去风格。风格来自选择：选择吸引谁，也选择放弃谁。
人会选择性忽视熟悉、平滑、顺从、平均的刺激。太顺的词、太完整的赞美、太无摩擦的观点，很容易被大脑当成背景噪声。
内容需要一个“轻微跑调点”：一个不顺滑的词、反常识角度、可争议判断、可接受缺点、奇怪但准确的比喻或出人意料的节奏。
跑调点不是乱写，而是让观众在熟悉里突然被刺一下，发现这条内容和别人的不一样。
```

写跑调点时先判断：

```text
这条内容最想抓住哪一类人，愿意放弃哪一类人。
观众已经熟悉到会忽视的说法是什么。
哪里可以故意不那么平滑：词语、句式、观点、人物缺点、节奏、反差或结尾。
跑调点是否服务主张、人物或故事，而不是只为了吸睛。
```

### 材料与关系的不可替代性

材料不以“私人小物件”自动取胜，也不以“宏大意象”自动高级。选择能承担当前关系和主题、又能进入公共经验的材料：它可以是一把钥匙，也可以是一座城；关键不是大小，而是它与人物、处境和结果之间有没有不可替代的关系。

### 商业剧本

商业内容先建立：

```text
转化目标：
目标人群与使用时刻：
原有方案的不满或购买阻力：
一句核心承诺：
支撑卖点与证据：
品牌与行动出口：
事实和声称边界：
```

每个卖点写成 `用户处境 → 问题触发 → 产品介入 → 身体 / 物体 / 环境结果 → 用户利益`。真实参数与疗效没有证据时不编造；画面不能证明的卖点不靠一句广告词硬说。


### 素材进入故事的范围与职责

长篇不能靠一次检索塞入更多候选。先建立 `story` 级承重会话，再按段落、场景和局部动作分别建立 sequence、scene、beat 会话，需要生活质感时才补 texture；电影可以沿着场景链逐段检索和编写，但每段仍须继承全片的人物目标、已发生后果与未来回收。检索页只是本轮可读窗口，不是全片素材配额；一页不足就续页，一个场景结束也不等于丢掉全片状态。

入围原子按 `承重 / 支撑 / 纹理` 标职责：承重原子改变人物选择或主要因果，支撑原子让压力、证据或回收成立，纹理原子增加真实感但不能抢走主动作。短片的信息密度看单位时长内发生了多少次有效状态变化——观众理解、人物关系、行动条件或风险真正改变——而不是看写进多少原子。若新增候选只重复已覆盖机制、不能带来新的因果方向或可见证据，就说明边际增益已经消失，应停止续页或改写查询合同。
