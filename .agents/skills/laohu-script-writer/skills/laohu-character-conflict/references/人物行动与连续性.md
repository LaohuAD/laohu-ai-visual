# 人物行动与连续性

### 3. 冲突构建

需要冲突推进时，从以下三个角度查找压力；它们是诊断视角，不是每个故事必须同时具备的配额：

```text
外部冲突：现实目标和外部阻力。
关系冲突：人物之间的利益、秘密或误解。
内在冲突：Want 和 Need 的拉扯。
```

冲突升级必须是选择带来后果，不是随机事件堆叠。

亲情遗憾、童年成长、怀旧家庭故事要建立与当前关系相符的“情感因果链”。先确认误解来自谁、谁付出回应、什么机会不能重来；不能预设晚辈一定不懂事、长辈一定正确。关系的分离、独立、错过回应和仍在世的人互不理解都可承重。只有离世已属于确认事实、且当前任务涉及离世或遗物回收时，才调用下面的离世型链条；身体预兆和丧葬细则再按已确认病情与具体场景取用。童年追悔本身不触发离世分支，不为使用这些方法新增疾病或死亡。

离世型亲情的候选结构：

```text
误解 / 嫌弃：主角先有一个幼稚但真实的错误信念，例如嫌老家脏、觉得大人管得烦、以为长大就是没人管。
愿望 / 缺口：主角想要某个具体东西或自由，但被拒绝、得不到或不被理解。
亲人记住：亲人没有讲大道理，而是默默把这句话记住。
具体回应：亲人用手艺、食物、礼物、仪式、叮嘱或笨拙行动回应这个愿望。
温馨使用：主角享受这份爱，但不一定真正懂它，甚至会炫耀、任性、占有。
缺点引爆：主角的缺点制造冲突，伤害亲人、关系或关键物件。
后果压近：用弱因果、疾病、离别、沉默、仪式或环境变化，让不可逆后果慢慢靠近。
遗物回收：结尾用物件、旧话、声音回忆或未完成承诺证明：亲人真的爱过，主角懂得太晚。
```

写这类故事时，温馨段不能只负责可爱，也要埋后果证据。例如咳嗽、药碗、递药、手抖、沉默、父亲背过身、旧物损坏、老人把痛苦遮过去。这些证据在前半段不抢戏，后半段才让观众意识到“原来早就有迹象”。

情绪台词不能像完成任务一样突然出现。人物要说遗言、叮嘱、压抑愤怒、忍住眼泪或说不出口的话时，先用生活动作、环境阻力和沉默把情绪托起来，再让台词出来。

常用承接方式：

```text
生活动作：量衣服、改袖口、端药、擦脸、整理孝布、翻衣领、递碗、收拾旧物。
环境阻力：风吹灭火、纸房飘带乱飞、门被风推响、火苗打不着、灯光忽明忽暗、纸钱摩擦。
身体泄露：手指发抖、肩背绷紧、喉咙吞咽、笑到一半压回去、背对孩子、手停在头顶。
物件回忆：袖口针脚、软尺、针线篮、旧玩具、木车轮、药碗、孝布，让台词从物件里回响出来。
```

如果一段对白显得快、莫名其妙、像在交代任务，不要优先加解释性台词。先问：这句话前面有没有生活证据？人物为什么此刻不得不说？有没有一个动作或环境让他 / 她说不出口、说慢一点、绕一下再说？亲情遗憾故事里，很多情绪应该由环境和动作代替人物自我说明。

父亲这类沉默寡言角色尤其不能只靠台词刻画。他的内心可以通过反复打不燃火、手抖、背影挡住火光、握孩子的手太紧、站着不催、肩背绷住等动作被看见。环境也可以承担民俗意味，例如风吹纸房飘带、火几次点不着，既表现人的不平静，也让观众隐约感到逝者不愿离开。

回忆 VO 必须和当前触发物件对位。不要把一句旧话随便放在情绪段里，只因为它好听。先问这句旧话是被什么看见、摸到、听见或闻到的东西触发的：袖口针脚触发“添衣裳”，两辆木车触发“一人一个”和“说话算话”，药碗触发身体不好，纸房火光触发离别和叮嘱。VO 出现时，画面要给出对应证据，让观众知道这句话为什么在此刻响起。

结尾片名要尽量由画面动作托出来，而不是在静态遗物画面后硬贴字幕。先找一个仍在动的轻物、声音或环境变化，让它把观众从近景情绪带到全片空间：木轮转动扫下枯叶 / 纸灰，镜头跟随轻物拉高，院子、人物、遗物和白布完整显露，然后片名出现。这样片名就是最后一幕的情绪命名，不是作者在结尾追加解释。

核心道具必须从“功能物”升级为“情感证据”。它要回答四个问题：

```text
它回应了主角哪个愿望。
谁记住了这个愿望。
对方付出了什么行动或代价。
结尾它如何反过来刺痛主角和观众。
```

对于以“有人记住愿望”为主结果的亲情道具，突然出现礼物却没有前置愿望、回应和后续回收，情绪就缺证据。其他亲情道具可以由共用、维护、争夺、移交或不再使用形成关系；不强制把旧物变成礼物或遗物。

冲突驱动、商业剧情、人物逆袭、品牌起源和创业故事的候选承重机制：

```text
对立面：冲突驱动故事需要明确阻力，可以是反派、制度、禁忌、误解、市场偏见、竞争者、时代压力、内在恐惧或世界规则。
独特个性：主角、品牌、产品或世界观必须有不可中和的个性。个性意味着会吸引一部分人，也会冒犯或排斥另一部分人。
黑暗时刻：需要命运升级时，接近失败、失控、被围攻、被误解、被驱逐或被迫重生可以逼出不可逆选择。
```

当品牌、人物或产品故事选择冲突成长结构时，额外检查：

```text
负面巅峰是否足够强：反派 / 对立面越强，主角或品牌的成长越有说服力。
个性是否有代价：无条件退款、民族情怀、创新洁癖、极致低价、极致审美都不能面面俱到。
黑暗时刻是否改变命运：不是小挫折，而是让主角死过一回、被迫重建认知和打法。
```

不要把对立面写成单纯坏人。真正有力的对立面要能代表一种相反价值、一种强压力或一种观众能理解的合理立场。

#### 对手的独立行动与冲突过渡

出现“反派只是挡路”“一句话就被说服”“人物突然爆发”时，先从对方的生活继续推演，而不是加一句狠话：

1. 主角到来以前，对方已经在办什么事；若主角不出现，他接下来会做什么。
2. 他现在想保住什么；他握有什么确实能使主角付出代价的手段。可以是决定权、时间、掌握的事实、拒绝配合或撤回亲密，不一定是暴力和更高身份。
3. 双方为何不能轻易离开、换人、妥协或绕过问题。亲情、合同、共同目标或稀缺资源只能提供候选理由，还须在当前行动中证明；如果合理退出更符合人物，就允许退出及其后果。
4. 主角采用旧策略，预期对方如何回应；实际回应哪里改变了条件；主角因此换了什么策略、付出什么新增代价。

逐拍诊断三种不同问题：同一请求换词重复而无条件变化，是停滞；新行为需要的人物理由或信息从未出现，是跳跃；眼前尚未冲突但观众已知道不可兼得的目标与临近机会，是有效预示，不能为了“每拍冲突”删掉。

一次突然答应可能是立场改变，也可能一直符合对方的独立计划，或只是观众现在才知道原因。只在第一种情况下补足说服与让步过程；后两种补证据或调整揭示时机，不机械增加阻挠。让步可以留有顾虑，失败可以暂时缓和，升级看可用办法和关系代价是否改变，不看音量与灾难是否越来越大。

例如修理师傅向店主求延期，店主直接答应。先查店主本来就打算次日上午交货，还是确实被新方案说服；若是后者，演出师傅让出哪项便利、店主见到哪项可靠证据后才点头。不要让店主突发善心，也不要为了增强对手擅自添罚款、恶疾或债务。

三维人物资料也只提取有因果作用的事实：身体条件影响能做什么，社会处境影响能调动什么与害怕失去什么，习惯与信念影响怎样选择。没有输入依据的前史是候选，不得把心理学原型当人格诊断，更不能据性别、身体特征或疾病自动分配善恶与结局。

### 4. 人物医生

主角必须具备：

```text
外在目标：
内在需求：
错误信念：
不愿面对的恐惧：
惯常逃避方式：
被迫改变的压力：
最后的不可逆选择：
```

配角不能只负责解释信息。每个重要配角要有自己的欲望、压力和对主角的功能。

#### 4.1 人物连续性圣经

人物设计不能停在外貌、职业、性格形容词和 Want / Need。只要人物跨场次、跨集、跨季、换装或由不同模型反复生成，就建立一份文本型 `人物连续性圣经`：

```text
角色身份与生产编号：
社会角色与公开身份：

一、不可漂移身份
脸部与身体永久锚点：
主识别锚点 / 辅助识别锚点：
发型整体轮廓：
基础声线：
代表性基准体态：
不能误改成什么：

二、人格基线
平时给人的第一印象：
实际稳定倾向：
核心价值 / 外在目标 / 深层需求：
错误信念 / 核心恐惧：
主要防御或逃避方式：
亲密方式：
权力与冲突方式：
羞耻、失败与失控下的反应：

三、条件化行为签名
如果遇到本故事中的关键压力：
人物怎样解释 → 采取什么策略 → 眼神 / 身体 / 声音怎样泄露 → 做出什么选择 → 造成什么后果。

四、关系模式
对每个重要人物想得到什么、怕对方看见什么、公开与私下怎样不同、怎样升级冲突、怎样和解。

五、表演与声音签名
默认目光、表情、语速、停顿、重音、句尾、手势频率、重心、步态、动作幅度、武戏 / 劳动 / 操作语法。

六、初始弧光
初始自我叙事：
旧方式怎样保护过她 / 现在怎样伤害她：
触发改变的事件：
微变化证据：
不可逆选择：
新基线：
仍保留的旧习惯与伤口：

七、逐集连续账本
集 / 场次、事件、知识变化、关系变化、价值判断变化、外貌 / 服装 / 伤势变化、行为与声音基线变化、暂时 / 永久、下集必须继承。
```

短片不机械填满所有字段，只保留真正影响本片选择与表演的项目。系列、续集和长篇必须完整建立，并在每集结束更新；人物圣经是活合同，不是第一集写完后永不变化的档案。

这份记录附属于现有剧本人物资料与连续账本，不另建平行母版。编剧负责人物行动、关系和剧情造成的变化；脸身、服装、音色等已经定案的专业事实只引用对应人物、服装或音频权威资产及其编号。未定案项写叙事需要并交给该负责人，不在此重新设计，也不以本表覆盖下游已经确认的身份事实。

#### 4.2 第一印象、人格事实与预期差

观众会从脸、身体、发型、服装、体态、职业、阶层符号和声线快速形成接近 / 回避、可信 / 危险、柔弱 / 强势等判断，但这类判断快速且未必准确。编剧先定义真实人格，再决定第一印象是顺向表达、暂时遮蔽，还是主动制造 `预期差`；不能让美术从眼型或脸型倒推出人物事实。

预期差的完整结构：

```text
预期建立：观众从哪些可观察线索，具体预期人物怎样说、怎样行动或拥有何种能力。
有意义的违背：哪一种声音、行为、能力、关系方式或道德选择与预期不同。
人物因果：前史、欲望、恐惧、训练、职业、身体条件、处境或保护策略为什么造成这种差异。
剧情后果：反差怎样改变冲突、关系、信息、能力判断、笑点、危险或选择代价。
后续变奏：同一底层差异在不同压力下怎样换一种表现，避免每次重复第一次揭晓。
```

粗犷高大的胡茬男人拥有纤细偏高、拖长尾音的声线，可以迅速违背观众对体格和声音的联想；但这只完成了记忆入口。要成为人物价值，还要说明这种声线与他的自我保护、职业训练、家庭环境、身体条件或关系策略有什么关系，它怎样让别人误判他、怎样在危险或亲密场景中产生后果，以及高潮时他是否用同一声音做出与外形同样有力量的选择。反差若只能重复为一个笑点，就没有形成人物深度。

预期差不自动比一致设计高级。顺向人物可以用极高的一致性获得类型效率，复杂人物也可以通过价值冲突、关系矛盾和选择代价形成深度。只有当前故事需要观众误判、更新印象、重新评价或记住人物时才使用预期差。借用性别、年龄、地域、职业、体型、残障或声线刻板印象时，笑点与冲突必须落在误判、处境和人物反应上，不把群体特征本身当低级、可笑或邪恶。

#### 4.3 人格稳定与人物弧光

人格稳定不是“每次都做同一个动作”，而是在相似触发下呈现可识别的判断与应对模式。人物可以在公共场合克制、在亲密关系里急躁、在权威面前讨好、在保护弱者时突然强硬；只要这些变化能回到同一套价值、恐惧和策略，就比单一性格词更稳定。

人物弧光采用：

```text
初始基线
→ 事件触发
→ 旧方式再次奏效或失效
→ 微小行为偏移
→ 反复、退缩与代价
→ 阈值被跨越
→ 不可逆选择
→ 新基线，同时保留旧习惯残余
```

变化必须在动作、关系、声音和选择中有证据。换服装、换发色、突然会哭、说一句“我明白了”都不能单独证明成长。人物变得勇敢，不等于从此不害怕；更可信的变化是恐惧仍出现，但她在关键阈值做出过去不会做的选择。

#### 4.4 研究校准

- Oosterhof 与 Todorov（2008，DOI `10.1073/pnas.0805664105`）：人会从脸快速形成可信度与支配感判断，但这类判断快速且未必准确，支持“第一印象不是人格事实”。
- Hastie 与 Kumar（1979，DOI `10.1037/0022-3514.37.1.25`）：人格印象会组织对一致与不一致行为的记忆，支持先建立预期再用行为违背促使观众加工人物。
- Mende-Siedlecki、Cai 与 Todorov（2012，DOI `10.1093/scan/nss040`）以及 Mende-Siedlecki 等（2016，DOI `10.1093/scan/nsw058`）：行为不一致会触发人物印象更新，但“有特质意义的变化”与普通的瞬时不一致并不相同，支持把可解释、能改变人物判断的反差与随机怪异分开。
- Mischel 与 Shoda（1995，DOI `10.1037/0033-295X.102.2.246`）：人格可以表现为情境敏感但稳定的 `如果……那么……` 行为签名，支持条件化行为而不是机械招牌动作。
- Schmidt（1991，DOI `10.3758/BF03197149`）：独特性能够影响记忆，但独特刺激必须相对于已有背景被定义，支持“先有清楚预期，差异才可能被记住”。

### 人物选择

重要人物至少建立：

```text
表层目标：眼前想得到什么。
深层需要：真正缺的是什么。
错误信念：他为什么一直用错误办法。
恐惧与代价：什么让他不愿改变。
可见策略：他通常怎样试探、逃避、压制、保护或争取。
阈值选择：什么事件逼他不能再照旧。
选择结果：他做了什么，失去或承担了什么。
```

人物性格要由不同处境下反复出现、但会随压力变化的选择证明。一个口头禅、一个表情或一次换装不能代替人物。
