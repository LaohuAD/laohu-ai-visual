# 结构尺度与高潮设计

#### 结构在不同尺度怎样承重

方向已定后才检查结构。全片的危机是人物面对真正不可兼得的选择，高潮是把选择做出来，结尾是让后果落定；不将三者缩成一句决心，也不要求各占一场。低烈度作品的关键选择可以是没接住一句邀请，结果仍必须留在关系里。

中段乏力时，按因果而非页码重排：每次尝试有没有耗掉一个办法、暴露新的事实或改变风险；看似成功是否让人物误判已经解决，之后的后果能否从该行动生长。假胜利、假失败、倒计时、黑暗时刻只是候选；教学演示、观察、群像和短片不补齐十五节拍。参考长片比例只查节奏失衡，不按比例换算短视频秒数。

主线跨多个场次时，用现有关键场次链检查序列是否完成一个中间任务，并把结果变成下一序列的条件。副线应通过资源、人物选择或同一价值问题的不同处境改变主线；若只是中断主线讲另一个故事，合并、延后或删去，不机械按固定位置插一条副线。剧集再分清本集兑现与跨集余压，不能每集把知识、关系或代价归零。

八种开场、结尾类型或经典幕结构只能帮助生成不同实现。开头建立的类型乐趣应在发展中得到可见兑现；结尾可完成、推翻或重新解释承诺，但不得靠突然换类型、加全新规则制造意外。具体期待与回收继续使用主 Skill 的既有账本，不另建结构表真源。

第一桶金 / 创业起源 / 个人逆袭故事，优先使用三幕英雄之旅：

```text
离开之幕：为什么离开旧世界。写清主角厌倦、反抗或无法忍受什么，例如小城市的碌碌无为、父母控制、小企业内耗、旧行业天花板、旧身份困局。
启动之幕：进入未知世界后遇到什么怪兽。怪兽可以是资金短缺、团队不合、市场不认可、技术失败、投资人撤资、舆论围攻、规则不熟或自身弱点。
归来之幕：第一桶金如何到来。它既可以是成功起点，也可以是坠入深渊的开始；必须写清它改变了主角什么，也埋下了什么新的代价。
```

写第一桶金时，每一幕都要有情感和故事动作：

```text
离开不是换地点，而是切断旧依赖。
启动不是流水账，而是连续打怪和扛住黑暗时刻。
归来不是炫耀赚到钱，而是主角带着新能力、新伤口或新欲望回来。
```

如果第一桶金故事只有“我努力了然后赚到了”，必须退回补对立面、怪兽和黑暗时刻。

### 5. 高潮场设计

高潮不是最大场面，而是最大选择。设计高潮时必须明确：

```text
主角被逼到什么位置：
他最想用旧方式解决什么：
旧方式为什么失效：
当前选择余地怎样收窄（采用黑暗时刻时写其具体作用）：
他付出什么代价做出选择，或再次坚持旧方式：
观众通过哪个动作看见人物变化或不变的代价：
最后一个画面留下什么余味：
```
