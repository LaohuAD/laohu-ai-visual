## 九、四种中文剧本格式的样本（姚扣根）

本节是第三节 3.2 那张对照表的实物补齐。四种格式的出处都是姚扣根《电视剧写作概论》第二章 2.3 节（p0063–0081），姚转引朱白水《怎样编写电视剧》（台视文化公司 1984 年版）的分类，并明确写下"场景内'正文'的格式，**没有统一的标准**"（姚 p0064）。**下面每种格式的样例都按原书版式转写，可照抄；用哪一种取决于这一稿由谁读、读什么。**

四种格式共用同一套场景头规则（姚 p0064，原样）：每个场景正文前要标明 **地点；内景或外景；时间；日景或夜景**；"有的还标出**场景的编号**和**这一场出场的人物**"。

### 9.1 格式 1：影部与声部分离（姚 p0064–0068）

做法（姚 p0064，原样）：**严格将影像部分和声音部分分左右横写**——也有改为上下划分，或排列在一起但对影部声部有明显区分（如影部全用显眼标志标出）——"使导演、演员及工作人员将剧本拿在手上时，**一目了然，不至于混淆不清**"。

**样例 A（姚 p0064–0065，原样转写）**：

```
影部                                  声部
场：5   时：日   景：客厅
·壁钟上的秒针在转动。镜头摇下来，客厅静悄悄，没有人。
·一个女人一边穿扣衣服，一边急忙地出来。      ·紧急的敲门声。
                                            女：谁啊？
·那个女人惊慌地开门，一个男的紧张地冲进来。  男：（画外音）我，快开门！
                                            ·远处传来警笛声、脚步声。
·那个男的抓着那个女人慌慌张张地从侧门逃了出去。
                                            男：糟了，我们的事给警方发现了，快走！
```

姚的分析（p0065）：可视具象（壁钟、紧张逃离的动作）属影部，敲门声、警笛声和人物对白属声部，"**两个部分截然分开，互不干扰**"。

**样例 B：王惠玲编剧《人间四月天》第一集开篇**（中国对外翻译出版公司 2000 年版；姚 p0065–0068）。场景头是独立的三行：

```
场景：硖石村庄后小溪边
人物：村妇，村人
时间：一九八○年夏日清晨

·字幕：一九八○年夏日
·村妇在溪边青石板上洗衣。
村妇：……
```

版式要点（姚 p0065–0068）：影部用"·"领起；对白用"人名："领起；字幕单列成一行（"·字幕：一九八○年夏日"）。

**这一段同时是传记剧 teaser 的范本（姚 p0065–0068）**：5 场完成四重时间跳跃——村妇溪边青石板上洗衣（1980 夏）→ 青石板被翻开，"**石板竟是一块墓碑，碑上写着《诗人徐志摩之墓》**"→ 1898 冬徐家抓周（小孩抓了竹蜻蜓，老太太解为"青云直上，一飞冲天"）→ 1904 夏七岁志摩放风筝滚下草坡，"有了人生的第一个疑惑"→ 1931 秋同样的荒烟蔓草间，搜索队寻到飞机残骸 →"字幕：徐志摩（公元 1897—1931）"。所有跳跃都靠**同一视觉母题（青石板／蔓草／飞）**缝合。

**什么场合用**：声音设计本身承担叙事的剧（音乐、音响、画外音、多层次环境声）；需要把"谁什么时候听到什么"写给录音与后期看的稿；影声关系复杂的传记剧／年代剧开篇。

### 9.2 格式 2：话剧剧本格式（姚 p0069–0071）

做法（姚 p0069，原样）："基本上是由人物对话、旁白和少量提示性词汇组成，**很少对人物肖像、心理活动、环境气氛等作精心描绘**。此类剧本格式，特别适合以对话为主的**室内剧**。"

**样例：桥田寿贺子编剧《阿信的故事》第一集开篇**（春风文艺出版社 1985 年版；姚 p0069–0071）。版式特征：场景名单独一行（"志摩半岛"／"田仓家（早晨）"／"寝室"／"阿信的房间"）；**舞台指示用方括号［ ］整段包住**；对白用"人名：（情绪提示）台词"。

```
志摩半岛

［画外音］昭和五十八年（即 1983 年），春意尚浅的时节。志摩半岛某小镇的田仓家，
祖母阿信突然出走了。阿信已是八十三岁高龄。她的次子田仓仁，已经在周边各镇经营
了十六处大型超级商场，今日又逢第十七个商场开业的良辰。田仓家能有今日的生意兴
隆，完全是阿信惨淡经营的结果。可就是这位阿信，偏偏在象征着田仓家宏图大展的第
十七个商场开业的一天，竟然孤身出走，这是全家人都不敢相信的事。当然，没有一个
人猜得出她出走的原因何在。

田仓家（早晨）

田仓仁：（烦躁地看表）不快些动身，可就来不及啦。
辰则：通知他们，典礼就推迟一小时吧？
田仓仁：不只是自家人，还请来了好多的宾客哪，连市长也光临了，田仓家能做出那种
        丢脸的事吗？
辰则：不过，岳母如果不到场……
田仓仁：这是老太太的脾气。时间一到，她就会突然出现的。……首先，她有什么原因
        非得离开家不可呢？
辰则：对于此次开业，岳母可是从一开始就强烈反对呀……

阿信的房间

阿祯：（沮丧地）妈妈到底还是有计划出走的呀！……妈妈心爱的衣服少了五件、腰带
      两条……而且，我去巴黎给妈妈买的手提包也不见了。
道子：当媳妇的，可真难哪。
```

两处技法（姚 p0069–0071）：① **开场即悬念（为什么出走）＋全剧将用回溯解答**，是纯对白剧的标准起手式；② **用衣柜清点这一具体动作把"临时走失"升级为"有计划出走"**，同时用道子一句牢骚点出婆媳关系——即**用争执交代全部前提**。

**什么场合用**：室内剧、情景喜剧、以对白为主的家庭剧；需要把稿子直接给演员读台词的排练本；无需交代环境气氛（景已固定）的项目。

### 9.3 格式 3：电影剧本格式（姚 p0071–0072）

做法（姚 p0071，原样）："注意影像画面，基本上是**以一个镜头或者一组镜头为句子单位**进行排列。镜头感强，画面跳跃感大，突出视觉造型，描写性词汇较少，**用最简练的文字阐述画面和声音**。"

**样例：《十六岁的花季》第一集开篇**（姚 p0071–0072）。版式特征：场景名用方括号（［野营基地］／"一○一中校门"）；正文短句分行；对白直接写在行内，也可用倒装（"'何大门出列。'潘教官当中点了何大门的名。"）。

```
［野营基地］

队列整齐。

潘教官：“互相看齐了，手必须摆到这个位置，起步走。”

韩小乐：“报告，这样他的屁股就撮起来了。”

同学们吃吃笑。

韩小乐：“那么热的天，都快成烤鸭了。”

笑浪掀起（压抑着的）。

“何大门出列。”潘教官当中点了何大门的名。

韩小乐：“报告，没说什么，是我的肚子叫了一下。”

潘教官：“我们的新兵比你们大不了两岁，每天训练六小时，你们一天才一小时。”

一○一中校门外。家长们聚着，有人递进去一块蛋糕，有人递进去一瓶风油精。
```

结构要点（姚 p0072）：韩小乐连续三次插嘴＝**三次升级、三次"同学们吃吃笑／掀起笑浪（压抑着的）"**，教官最后用数据反击；随即切到校门外家长戏（胃病孙子的蛋糕／风油精），形成"**校内外对位**"。

**什么场合用**：视觉化、强动作、节奏快的剧；青春剧、动作剧、短集数剧；需要让导演一眼看出镜头切分的稿。

### 9.4 格式 4：电视小说格式（姚 p0072–0081）

做法（姚 p0072–0073，原样）："相对比较自由，一面注意电视画面形象的描写，一面取近乎小说的叙述，较为详细地交代场景环境、气氛，在叙述中时常插入对人物心理或剧情发展的说明性文字。在文字描写上，追求文学可读性……**此类格式目前较为广泛采用，不仅为拍摄提供脚本，也同时为电视小说出版打好基础。**"——这句是国产剧本最常见格式的出处说明。

**样例：《新岸》**（知青题材，刘艳华＋高元钢；姚 p0073–0080 长段转写）。姚随后给出全书唯一的技法分析（p0080），可直接当这一格式的写作指令：

- 总评："**挖河泥、牛车进城、探病三个片段，一气呵成，充分调动了画面、声音的种种元素。**"
- **三次"挖河泥"的递进**（重复母题的标准用法）：第一次"两人各怀戒心、互不理睬"；第二次"戒备的目光变为沉静柔和的神态"；第三次"车陷泥塘两人奋力赶车，而后刘艳华来到水塘边在日落霞光中洗刷着两个人的泥鞋"。
- **声音设计**：自然音响、吆喝牲口声、"咯纽纽"的牛车轱辘声、牛脖上的铜铃声。
- **空间＝关系的可视化**：赶牛车一场"两人从一个在车前一个在车后到同坐牛车前，有着第一次对话，然后又是车前车后各一个，**距离的变化暗示了感情的变化**"。
- **道具链**：黄胶鞋出现三次（**脱鞋→垫车→洗鞋**）；窝窝头／白面糖饼对照（高家"给我留点白面……烙几张糖饼"→ 车上递饼被拒 → 探病时看到"粗瓷碗里的干裂的窝头"）。

**什么场合用**：默认选项；同名小说同步出版的项目；需要把心理活动与环境气氛写给制片人／出品人看的送审稿与样本剧本。**注意**：这一格式把心理描写写在纸上，但镜头拍不到心理——所以姚紧接着给出下面这张分镜对照，说明文学本的心理必须由导演换算成镜头。

### 9.5 《新岸》文学本 →10 个分镜头的左右对照（姚 p0080–0081，全书唯一的文学本→分镜对照）

姚在《新岸》长段转写之后，原样列出导演用 **10 个镜头**完成"探病"一场的分镜。左列是电视小说格式里那一段的叙述内容，右列是导演的镜头换算。

| # | 文学本（电视小说格式）写的是 | 导演的分镜（姚 p0080–0081，原样） |
|---|---|---|
| 1 | 高元钢进门，看见炕上的刘艳华 | **中近——全（拉跟）**高元钢急忙进门观看，惊愣了，只见炕上躺着刘艳华。 |
| 2 | 他的担心 | **中近——**高元钢担心地望着。 |
| 3 | 病情（呼吸、嘴唇、昏迷） | **中近——**刘艳华呼吸急促，嘴唇干裂，昏迷不醒。 |
| 4 | 取毛巾、舀水、浸湿、盖额头、坐炕沿注视 | **近——（拉跟）**高元钢忙从绳上取下一条毛巾，从水缸里舀出一瓢水将毛巾浸湿，轻轻地盖在刘艳华额头，坐在炕沿上焦急地注视着。 |
| 5 | 她苏醒 | **中近——**刘艳华苏醒，微睁双眼。 |
| 6 | 他的焦急 | **中近——**高元钢焦急的神色。 |
| 7 | 她"难以言状的感情"与"关闭心门"（文学本写的是心理） | **中近——特写（推）**刘艳华眼睛湿润了，热泪滚动。她怕这种难以言状的感情被高元钢发现，吃力地抬手将毛巾拉在眼睛上，关闭心门。然而那颗泪珠从毛巾下滚到腮边，留下一道泪痕。 |
| 8 | 他克制眼泪、环顾 | **近——**高元钢克制住眼里的泪水，环顾四周。 |
| 9 | 破口黄胶鞋与干裂窝头（文学本写"让人体味到的某种情感"） | **特写——（摇）**炕沿下，那双他熟悉的黄胶鞋破口了；小桌上，粗瓷碗里的窝头干裂着…… |
| 10 | 他心情沉重 | **近——**高元钢心情沉重。（出画） |

姚的解读（p0081，原样要点）：中近景表现"进屋后所见，和两人的关系"；第 7 镜"**从近景推向特写，恰到好处地表现了从毛巾下滚落出来的泪珠及腮上留下的一道泪痕**"；高元钢的心情用"**主观镜头＋特写**"处理（破口黄胶鞋、干裂窝头），"此时仿佛不经意的一瞥，让人们体味到隐藏在主人公内心深处的某种情感"。

→ **给编剧的换算规则**（由上表反推）：① 文学本里每一句"他担心／她焦急／他心情沉重"在分镜里各占一个独立镜头，所以**情绪的每一次变化都要另起一句**，不要揉进长段；② 文学本里**不可拍的心理**（"难以言状的感情""关闭心门"）必须挂在一个可拍的动作上（抬手把毛巾拉到眼睛上）与一个可拍的物证上（从毛巾下滚出的泪珠）；③ 写"他体味到某种情感"时，必须在同一段里给出让他体味的**两件道具**（破胶鞋、干窝头），否则导演无镜头可拍。

## 十、策划文件样本（姚扣根）

本节是第二节那张"六件文件"对照表的实物补齐。出处：姚扣根《电视剧写作概论》第十五章"电视剧策划"（p0328–0348）。姚的策划文件清单（p0329，原样）："一般情况，策划的内容包括：**情节概要、人物设计、主要场景、创意说明**。"

### 10.1 情节概要＝logline：定义与三功能（姚 p0329）

定义（原样，含三种译法）："简洁概述情节（**Logline**），有的译为**高概念**，有的译为'**计程绳**'，指能够概括一个故事的一句话，也可能两句话、三句话，意思尽可能简洁地表述出**剧情假设、题材类型，和主题价值**。"

高概念的三种功能（姚 p0329，原样）："1. 简洁概述故事；2. 类型大体定位；3. **表明具有非同寻常的情节力量，不需要明星参与就有吸引力**。"

### 10.2 六个 logline 原样转写（姚 p0329–0330）

| # | 作品 | logline（原样） |
|---|---|---|
| 1 | 电影**《辛德勒名单》** | "一个看似沉溺于声色犬马的商人，在纳粹的大屠杀中营救了成百上千的犹太人。" |
| 2 | 电影**《史密斯夫妇》** | "夫妻冷战如同间谍竞争，把夫妻的日常冲突和心理治疗演绎成一场敌我双方间谍斗智斗勇的暴力行动。" |
| 3 | 英剧**《安娜·卡列尼娜》** | "淑女名媛们不得不压住自己内心的激情，屈从于上流社会的戒律，而安娜拼死去追求自己的幸福，宁可遭社会唾弃，也要做一个真正的女人。" |
| 4 | 美剧**《越狱》** | "一名结构工程师，光天化日抢劫银行，进监狱帮助受冤枉的哥哥越狱，从而揭开了一个大阴谋。" |
| 5 | 美剧**《绯闻女孩》**（姚注"被称为青春版的《欲望城市》"） | "讲的是纽约一群家境富裕的少男少女，名牌服饰、高级派对等城市时尚的流行元素，以及朋友间的虚伪友谊和钩心斗角。" |
| 6 | 美剧**《绝命毒师》** | "一位高中的化学老师，家里有妻子和一个残废的儿子，被医院诊断为癌症晚期，他决定利用自己擅长的化学知识制造毒品，以保证自己死后可以为家人留下些财产。" |

→ 从六例反推的写法（姚 p0329 的"三要素"在六例中的落点）：**1、4、6 三例是"身份＋反常行动＋代价"三段式**（商人→营救犹太人／工程师→抢银行进监狱／化学老师→制毒）；**2 是"类型错置"式**（把夫妻日常错置成间谍行动）；**3、5 是"群体处境＋一人例外"式**（名媛都屈从，安娜不屈从）。**第 5 例值得注意：它只写了世界与气味，没有写行动，是六例中唯一不含"某人做某事"的——姚把它照样收进来，说明"群像＋元素清单"在剧集里是合法的 logline 形态。**

### 10.3 电视剧的例外：长度限定（姚 p0330）

原样："电视剧有时候也能用一两句话进行概括，**但有的时候由于内容复杂，涉及面广，需要用比较多的篇幅才能阐述清楚**。"随后姚给出 5 份完整"情节概要"，每份约 **200–400 字**——这是本书给"故事梗概"篇幅的实际标准。

### 10.4 五份情节概要样本

**样本 1：《北京人在纽约》（姚 p0330–0331，原样全文转写）**

> 北京某交响乐团的大提琴手王启明和妻子郭燕，到美国纽约寻找自己的艺术梦想。
> 王启明在餐厅打工，遭遇老板阿春的情感纠纷。郭燕进一家毛衣厂，老板大卫喜欢上了她，频频发动了进攻。王启明谋生不顺，准备回国，但在上飞机之前，他决定与妻子离婚，在美国先挣下一笔钱，然后再投身艺术。王启明投入阿春的怀抱，在她的帮助下经营起一家毛衣厂。郭燕与丈夫分手后，和大卫结了婚。**王启明利用郭燕的旧情，套取经济情报，搞垮了大卫的厂子。**
> 王启明成功后，把女儿接到美国。女儿对父母的现状很失望，对阿春极反感，充满反叛性格的她离开了家。
> **众叛亲离的王启明，不顾阿春的提醒，冒失投资房产，在经济萧条中破产。最后，为了挽救彻底的失败，王启明携带着身边唯一的钱去了赌城。**

→ 四段，每段结尾都是一次不可逆的身份／关系变动：抵美 → 离婚并换阵营 → 女儿出走 → 破产赴赌城。**全篇不出现一句主题评语，靠"结局句"把判断交给读者。**

**样本 2：《大长今》（姚 p0331，三段式压缩转写）**

> ① 母亲朴内人在御膳房发现有人利用食物搞阴谋，反被诬陷致死；父亲卷入宫廷斗争惨遭杀害；"**朴内人临终时，希望女儿长今能进宫当上御膳房的最高尚宫，为她报仇**"。
> ② 长今进宫入厨房，"在厨房的职场斗争中一直受到霸占厨房掌门集团的陷害，甚至差点丢了性命，被赶到孤岛"。
> ③ "**苦难，给长今创造了另一个机会**，她开始潜心于医术，并融入宫廷膳食中，再次进宫……成为韩国第一位女御医，被封为大长今。同时，她终于查清真相，为母亲昭雪平反。"

→ **三段＝三种身份（厨人→罪人→医人）**；每段之间的转折都由"被逐"驱动；母亲的遗愿一句话把全剧目标钉死在第一段末。

**样本 3：《白色巨塔》（姚 p0331–0332，原样要点转写）**

> 浪速大学附属医院财前五郎副教授为了实现自己成为第一外科教授的理想，与排挤自己的恩师东教授决裂，并借助岳父财前又一的财力与人脉……展开了激烈的争夺选票的斗争……**就在他志得意满的同时，潜伏的危机却慢慢显现：由于他对待一般病人的草率态度，病人佐佐木庸平因他的误诊死亡。而此时，他正在德国参加学术会议。**……官司初审财前胜诉后，病人佐佐木一家坚持上诉。在正直的关口律师和里见医生的协助下，他们赢得了最终的胜利。**财前虽然获得了又一次选举——学术会议会员选举——的胜利，但是却在官司败诉和病魔缠身的双重打击下倒下了。**

→ **双线咬合的梗概写法**：一条是"选举连胜"，一条是"误诊追责"，两条在同一句里收束（"获得了胜利，但是却……倒下了"）。**"而此时，他正在德国参加学术会议"这一句是把道德判断藏进时间安排的范例。**

**样本 4：《上海往事》（张爱玲传）（姚 p0332，框架转写）**

> 框架：**1955 年到美国 → 母亲去世的箱子打开童年记忆 → 1937 年逃离家庭 → 港大 → 1941 年回上海卖文为生 → 1944 年认识胡兰成 → 1955 年去美国 → 1995 年一个人在美国去世。**
> 关键句："写下婚书，愿'**岁月静好，现世安稳**'"；"张爱玲离开了胡兰成，只能是枯萎了"。

→ **传记梗概＝一串年份＋一个首尾闭合的框架**（1955 年出现两次：一次是开篇的叙述现在时，一次是回到时间线的同一点）。**物件（母亲去世留下的箱子）承担全部回溯的开关。**

**样本 5：《长恨歌》（姚 p0332–0333，三年份分段转写）**

| 年份 | 本段内容 | 本段结束时的不可逆变动 |
|---|---|---|
| **1943** | 16 岁女学生王琦瑶 → 程先生拍照上杂志封面 → 上海小姐候选 | "**被金屋藏娇**" |
| **1958** | 里弄打针为业 → 康明逊 → 康家不同意 → 私下生女薇薇 | 康去香港 |

→ **姚给的可执行格式（p0333）**：**长剧的"情节概要"＝3–5 段，每段一个时间锚点（年份）或一个关系变动；每段结尾必须是一个身份／关系的不可逆改变。**

### 10.5 与这五份梗概配套的两条作者建议（姚 p0337）

- "**编剧的诀窍就是创作出一个个有张力且引人注目的事件，让梗概有灵活性，仿佛它是一个谜，以便今后根据自己的创作实力去修补，去完善，去使它个人化。**"
- "**可以用故事树、流程图来对整个剧情进行分解和缩写，尽可能在梗概阶段完善情节，发酵思想。一旦梗概得到确认，当你坐下来开始写第一页时，你已经不是在创作，而是在打字了。**"

### 10.6 情节流程样本：《亮剑》消灭日军特工队一段（姚 p0336–0337）

姚给"情节流程"的详细版模板（p0335，原样）："**什么时间在什么地方发生了一件什么事，这些事触动了哪些后继事件，他们是怎么联结起来的，人物行动的具体动机是什么，行动的过程如何，结果如何。**"配套的范例是《亮剑》消灭日军特工队一段的流程体写法，关键细节（姚 p0336–0337，原样要点）：

- 山本大佐"留学德国在侵华日军中首创了一支精悍的特种部队"；
- "为革新战法特由 200 名军官组成**战地观摩团**来观摩特种作战"；
- "**李云龙偏不是个墨守成规的指挥员，他相机分兵打伏击，结果无意插柳柳成荫，既全歼了日军的战地观摩团，也解除了山本攻击八路军总部的十万火急**"；
- 楚云飞与李云龙"只带了卫士却将县城日军宪兵队杀得人仰马翻"；"宪兵们已经暗中勾结了独立团中的变节分子"；
- 平安县城之战"双方的交战面积上千平方公里，投入总兵力达 30 万"；
- 结局双写："**李云龙却失去了新婚妻子秀芹，擅自行动又遭八路军领导的严厉批评。**"

→ 对照"情节概要"：**梗概写"发生了什么"，流程写"因为什么所以什么"**。流程体必须出现"偏不是""结果""既……也……""又遭"这一类因果连接词，并在最后一句同时写出**得与失**（歼敌＋丧妻＋受批评）。

#### 姚的总结分析（p0297，原样要点）

- "这 41 个场面，将一系列看似是迷乱繁复的、缺乏关联的段落，**通过相互间的串联和呼应，通过各自矛盾的设置和解决，组成了完整的故事**，表现出各自的性格和情感交流，最终融合成爱的深厚主题。"
- **开场的隐喻设计**："该集的开场，**以护理人员排演《罗密欧与朱丽叶》的兴奋，设立了隐喻**。此之前，有麦尔克医生的夫妻感情遭遇问题；此之后，有病人扯动了苏珊医生的失败恋爱。**这两个医生后来会走到一起，这里侧面提及，为后面的他们俩的感情戏做了铺垫。**"
- **主题的统一（本集即"爱的考验"）**："婚前的恐惧和犹豫；婚后的分离和忍受，**爱情，像一条流淌的河，在每个人的生活中掀起了漩涡和波澜**……**每一个段子似乎没有那么阳光灿烂，反而充满了阴郁，极力在冷风细雨中体现出一丝的温暖**。"逐条对位：哈沙薇"心里真正担忧的是结婚的对象是否是自己的真命天子"；苏珊与妹妹"实际上均是恋爱的失败者"；道格"怀疑自己能否被接纳"；自杀病人的妻子决心离开他；修女"已经有了男友，还是犹豫自己是否要结婚"。
- **结构命名（关键术语）**："精彩的群戏，各个人物的独立的生活片断，在一个'**共时**'空间来来回回地切换，**对同一情绪进行反复渲染**，编织了完美的情节网……**这种多线索、事件交集的散点式结构，具有一种极强的艺术张力。**"
- → **配方（姚 p0297 的可执行版）**：一集＝**5 条跨集连续线＋5 条单集偶然线**；10 条线共用一个抽象主题；由开场的一个"排戏／道具"隐喻点题；**第 1 与第 41 场面用同一家庭场景首尾呼应**。

### 11.2 《北京人在纽约》第 1 集逐场拆解（姚 p0236–0252，本书最完整的国产单集分析）

#### 片段 1：进城狂喜 20 个镜头（姚 p0237–0238，原样转写）

> （1）车子驶向市区。（2）镜头由王启明的特写拉至王启明与郭燕的近景，两人相互对视拥抱微笑。王启明兴奋地抱着郭燕喊，"纽约！曼哈顿！"（3）俯拍纽约城夜景。（4）车子向前。（5）车内，旋律起，王启明随着无声源音乐兴奋起来，挥舞双手作指挥状。郭燕向外张望，目不暇接。（6）纽约夜景，高楼大厦林立。（7）王启明仿佛指挥着一支乐队。（8）纽约街道夜景，灯火辉煌。（9）王启明继续指挥，郭燕兴奋地微笑。（10）纽约街道夜景。（11）王启明大声喊："美国，纽约！"（12）纽约街道夜景，霓虹灯广告牌。（13）王启明高声喊："王启明来了！"郭燕高兴地依着。（14）镜头跟随车子向前推，路边行人的全景移动。（15）王启明向车外招手。（16）**姨妈的后脑勺，她微转头瞧后面，她有点奇怪这对年轻人的大惊小怪。**（17）王启明和郭燕丝毫没有感觉到姨妈的反应，全身心沉浸在兴奋中。（18）仰视纽约夜景。（19）王启明在车里更加起劲地伴着无声源音乐指挥。郭燕仍然自顾自地到处张望。（20）车子向前。

姚的三点评价（p0238）：① **展现异域风光，但景必须与情节有明确关联**——"避免了有些影视剧中，光注意纯粹的异域风光，使风光的展示与故事情节、人物心理存在着两张皮"；② **设置意象音乐**——《新大陆》交响乐"担负了叙事的功能，作为贯穿全剧的听觉形象细节"，后半部重现时"同一旋律已经没有当年的激动和兴奋，只是发出缓慢和悲哀"；③ **变化叙事节奏**——"色彩由单一转向丰富；空间由机场内的封闭，转到街道上的开放"。并明确这段的真实功能（极可执行）："**节奏的变化，由机场的压抑转到街道的高扬，也为后面到贫民窟地下室的进一步压抑作了充足有力的铺垫。叙事技巧上，这一段情节完全是为了衬托着下一场戏。路途上的尽情高扬仅仅是视听感觉，目的地的含蓄沮丧却是实在生活。**"

#### 片段 2：地下室夜谈——姚为"无事件场面"的辩护（p0240–0242）

原样："说一些无关紧要的话，做一些没有联系的事情，表现一种无关紧要的感觉，不是戏剧叙事的关注点。那些零星的碎片，回忆的感受、未来的担忧，一种温柔的失败感，没有明确表达的意念，没有可以察觉的因果联系，不可能推动情节发展……**但是，这种散文式的叙述，流露出的矛盾感情，看似闲笔，却是静止胜动作，走向浪漫、模糊、随意，具有特殊的审美价值。**"

三句话的技法总结（姚 p0242，**可直接做写作指令**）："《北京人在纽约》剧的这场夜谈，**在没有事件的地方写出心理来，在安静的环境中写出心动来，在没有激情的地方写出情绪来**。情绪是心境的一种状态，最会传染于人、感染于人。"

#### 片段 4：见阿春的四个回合（姚 p0244–0250）

为什么必须写足（姚 p0244，原样两条）：① "**重要对手戏的第一场戏**，有着引领全剧的标志性作用……他俩的第一次见面，具有试探和引导的作用。一旦兴趣确立，观众就会有期待。"② "**这一场作为第一集的压轴戏，具有诱惑下一集观赏的功能。电视剧集结构中的最后一个段落，是重要的观赏兴奋点，并起着设置悬念的作用。而通常第一集的结尾，是表示全剧问题的引导，有全剧冲突高潮路程的指向作用。**"

铺垫用反衬法（姚 p0244）："导演给了一个长达一分半时间走过马路的镜头……**这样的剧情，也使观众松懈了观赏的神经，将期待降到了零。**"伏笔道具是**一杯啤酒**（"Frank 拿出一瓶啤酒，王启明点点头"）——"**在这场戏里，这一杯啤酒作为暗藏的由头，串连起一系列精致的对话来**"。

**全集的"首尾两句台词"结构（姚 p0250，本书最漂亮的一条发现，原样）**："本集，主人公听懂的第一句话是：'**美国欢迎你！**'而主人公最后听到的一句话：'**你给我打工！**'从第一句话到最后一句话之间，一集的主要片段形成了几个点，每个点都做在王启明到美国后的感受上。**'欢迎你'词义的真正含意是'给我打工'，当王启明理解了这句潜台词后，立即从自我感觉最为膨胀的顶峰，跌落到自我感觉最受伤害的谷底。**"并补充方法："编剧确立起点和落点，然后一张一弛，从容不迫，形成一个过程……**通过几个地点的转移，把王启明高高抛起，又狠狠摔下。这个过程的最后一点，编剧是无论如何不能轻易放弃，让其顺着时间的自然秩序进行的。本集到了这么一个戏剧之点，戛然而止。**"

**两层"片段需形成复合整体"（姚 p0251，原样）**："一是**片段可以运用各种不同艺术手法，追求电影、散文、戏剧的不同效果**；二是**片段需要服从一个统一的涵义，服从集段的意义，服从全剧的意义**。"

**一条重要许可（姚 p0252）**：王启明的真正目标要等到临上飞机前被阿春轻蔑刺激（阿春名台词："**告诉你，美国既不是地狱，也不是天堂，是战场！**"）才确立——"**可以说，到了王启明被骂了'失败者'这个时候，编剧才给了主人公一个清晰的奋斗目标，要做成功者！**"→ **主角的真正目标可以在第一集之后才确立。**

## 十二、36 种境遇与 36 个喜剧情势清单

两份素材库都在姚扣根《电视剧写作概论》里。**36 种境遇**＝乔治·普尔梯（Polti）的清单，姚在第九章 p0207 给出全表名称，在附录一 p0349–0363 逐条中国化重写并各配 1–3 个剧例。**36 个喜剧情势**＝李天济在 1981 年南京电影剧作讲习会《电影喜剧纵横谈》里的清单，姚在 p0207–0208 原样转写全表。

姚对这两份清单的态度（p0207，原样）：一方面批评"乔治·普尔梯所说人生的滋味尽在这 36 种戏剧境遇里的话，未免有点过头了……**把丰富多彩的人生局限于某些境遇内，实际上扼杀了人类的发现、创造**"；一方面允许借用："但是……这些境遇在今天的生活中还没有完全失去他们的魅力，**还可以借用**。"这与美式方法书强调 originality、忌套路是一处明确分歧。

| 35 | **恐惧** | "**鬼吓人不要紧，人吓人半条命**，恐怖的关键，他人是地狱"；双面性："恐惧可以增强保护自己和躲避危险的能力，**也可以成症，甚至丧失理智和自制力**" | 《沉默的羔羊》恐惧清单（"高智商的食人者和剥人皮的变态狂、遭人绑架、身陷深井、尸体上的巨型昆虫、被看不到的人追赶、失去他人对你的信任，还有门在背后给人关上，黑暗的屋里有一双戴着红外线夜视镜的眼睛"）；《一级恐惧》（"**是一种对恐惧的解构**"）；婚前恐惧的话剧长例（新娘锁在卫生间，父母皆劝不开，"**最后，着急的新郎闯进了房间，什么情况也不问，冲着卫生间大吼一声，转身就走。出乎意料，门开了**"）；《落跑新娘》《粉红女郎》 |
| 36 | **滑稽** | "**实质是一种反常行为和逆反思维。老鼠玩猫很滑稽，人斗不过老鼠很滑稽，大人物被小人物耍了也很滑稽。当人与环境不适合，当人际关系颠倒错乱了，这个世界就会很滑稽。**""**只要能换一个角度去看，或头向下看**，不仅能看到滑稽，而且会产生许多意想不到的效果" | — |

**附录一的结语（姚 p0363，原样）**："现在的电视剧大多采用'**复合原则**'，一个套一个，一个接一个或者数案并发，让主人公处于一种多变的状态中。例如，**被冤枉的警察逃出监狱，在自身被追捕的情况下去调查和追捕真正的罪犯，这一个情节就让主人公处于'误会''捕逃''释谜'等数个境遇中。复合原则允许更多的现实进入电视剧。**"

→ 两种境遇性质（姚 p0207）：① "着重在矛盾冲突中纠缠于人际关系。如'求助'是求助的人与威权者的动作与反动作；'援救'是援救者、不幸的人与威胁者的利益联系；'复仇'有复仇的人与作恶者的斗争"；② "在思想或感情发生变化的过程中而使人物关系发生变化"。**查表时先判这一条属于哪种性质：第一种要配人物，第二种要配时间。**

### 12.3 两份清单的用法差别

| | 36 种境遇 | 36 个喜剧情势 |
|---|---|---|
| 层级 | **人物处境**（一个人被放进什么局面） | **局面的结果形状**（事情最后怎么歪的） |
| 配什么 | 配人物关系（谁对谁）与时间（多久） | 配**落空／错位／反噬**的那一刻 |
| 复合方式 | 姚的"**复合原则**"：一个主人公同时处在数个境遇中（p0363） | 可与境遇叠用：同一境遇换一个情势即由悲转喜（第 32 条"鲁莽"的剧例就同时给了悲剧式张飞与喜剧式李逵，姚 p0362） |
| 查表时机 | 立项与人物关系阶段 | 分集与分场阶段，尤其写情景喜剧与轻喜剧元素时 |
