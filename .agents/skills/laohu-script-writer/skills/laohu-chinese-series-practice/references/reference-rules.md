## 十四、赵彬彬 26 个片段索引表

出处：赵彬彬《影视剧片段改编教程》第四章（6 个详析例，含剧本＋教学说明，p0024–0083）与第五章"实践素材"（20 个片段，p0084–0197）。合计 **26 个片段**。方向与第十三节完全相反：**成片 → 8–20 分钟、3–8 人的舞台片段**（高职高专表演专业的排演素材）。方法条文见 [reference.md](reference.md) 第六节。

### 14.3 配置统计（赵 p0141、p0197 两张统计的合并）

- **角色数 3–7**（最少 3：《十月围城》；最多 9：《刀客家族的女人》《爱情悠悠药草香（二）》）。
- **场景 1 个主场景**（偶有相连的第二区：门外／过道／黑屋）；**唯一的三区布景**是《美丽的大脚》，**唯一的对比式双区**是《半生缘》。
- **题材分布（第五章 20 例）**：民国宅门／年代剧 11；抗战 3；当代家庭 4；农村／年代青春 2；宫斗 1。→ **年代剧占压倒多数**（第 4 份笔记的 10 例中 8 例是年代剧）。
- **取段位置（第五章 20 例）**：第一集 7、第二集 4、第四至七集 5、第二十集以后 2、未标 2。→ "**可独立排演的强冲突场面**"高度集中在**剧集前五集**。
- **由小说二次改编的比例**：20 例中至少 10 例原作是小说（张爱玲 2、严歌苓 2、琼瑶 2、匪我思存、裘山山、流潋紫、董陆明），即**本书大半是"小说→剧→舞台"的三级改编**；每一级都在做压缩——与张巍"小说→长剧＝扩写"正相反。
- **收场规律**：**必须是一个可见的身体事件或一次离场**——跳池／下跪／痛哭／腿软倒地／长辈压场训话／诀别目送／翻窗出逃／全员死亡＋跪台前／背出门／流血晕倒／撞墙／关门锁人。

### 14.4 代表性台词范例（原文转写，做语料用）

#### 范例 1 《倾城之恋》：讨钱的迂回（赵 p0111）——中文"绕着说"的标准范本

```
三嫂：（坐下）也就是妈啊，想清楚了，看明白了，把家里的账交给了我管，我要是不管
      啊，还不知道会出什么事儿呢。哎，六妹，你从婆家回来也有好几天了吧？
白流苏：（不好意思）对的，让三嫂费心了。
三嫂：哎，不费心，（说完，看了看流苏）你说这么大家子吧，开门七件事，柴米油盐酱醋
      茶，哪一件事我照顾不周了，月底都要出篓子的。六妹啊，你是知道的，咱们这个
      家不比从前了，多一个人就多一张嘴，在账上的呢，还好说，不在账上的呢，（笑
      笑）你让我这做嫂嫂，跟你张口要饭钱，实在是难为情啊，可我要是不要吧，要说
      闲话的（指了指门外）
```

→ 技法：**四步迂回**——立权（妈把账交给我）→ 问时长（回来好几天了吧）→ 讲公共难处（开门七件事）→ **把逼债的责任推给不在场的"别人"**（指了指门外）。**最后一刀不用自己说。**

#### 范例 2 《娘》：称呼的战争（赵 p0104–0108）——用一个词完成立场对抗

```
满仓娘：这不是金斗吗，你从日本人那回来了？！
金斗：满仓娘，叫大号！（嚣张跋扈）
满仓娘：哎呀，按辈数，你还得管俺叫婶子吧。
金斗：哼，如今这世道已经变了，没那么多穷讲究。
满仓娘：世道再变，这祖宗不能变吧。
  ……
满仓娘：金斗啊。
金斗：称呼我大号！川山一郎！（叉着腰抬高下巴，趾高气扬）
孟氏：什么一郎二郎的，叫德勇！（惊地转过身，觉得丢脸）
满仓娘：德勇，德勇，你看看，俺一家人还有这个婶子，不就在这儿给你跪着吗
```

→ 技法：一个汉奸的改名被**母亲、邻居、自己**三方争夺，"德勇／金斗／川山一郎"三个名字＝三种身份主张；满仓娘最后喊"德勇"既是屈服也是羞辱。**比任何民族大义的台词都有效。**

#### 范例 3 《铁梨花》：过道盘问（赵 p0121）——把"拖延"写成一场独立的戏

```
大奶奶：你走那么快，哪能看得着我啊！这天儿也晚了，什么事儿啊，这么着急！
张吉安：（支支吾吾）哦，我好几天没见着姑姑了，我记得上次姑姑跟我说，她喜欢吃老孙
        家的核桃酥，（提起东西）我正好路过那儿，就给姑姑买了点儿。
大奶奶：那你怎么走这边儿啊，咱们家常出常入的你，老太太住哪儿你都忘了？
张吉安：（笑了笑）看您说的，嫂子，老太太住哪儿，我哪儿能忘啊！（看了看周围凑近大
        奶奶）我突然有点内急，想上个茅房。
大奶奶：四奶奶、五奶奶都住在那边儿，你想上她们俩谁的院子上茅房啊！？
  ……
大奶奶：对了，我帮你拿着点心。
【张吉安愣了愣】
大奶奶：我正好要去老太太那儿，你总不能拿着点心上茅房吧！
【张吉安转身，下场。大奶奶翻了翻东西，没见猫腻，就离开了】
```

→ 技法：**每一个谎都被对方用日常常识当场拆掉**（走错路线、茅房的位置、拿着点心上厕所），最后用"我帮你拿着"没收物证。这场戏在剧情上只是"迟到的理由"，**在舞台上却是一段完整的攻防**。

#### 范例 4 《马文的战争》：虚词"意思"的七次翻转（赵 p0064–0070）——中文台词的喜剧武器

```
杨欣：我说马文，你说，咱们这么住着有意思吗？
马文：嗯！有意思啊！
  ……
马文：那多没意思啊！我呢，也考虑过了，这样是没什么意思，也显得我这个人特别不够
      意思！不过，住着住着，意思来了！！很有意思！有意思得不得了！
杨欣：有意思是吧！？我会让你觉得更有意思！你前妻绝对够意思！（关门）
```

→ 技法：**抓住一个虚词反复翻转**（"意思"七次），一句之内从"没意思"翻到"够意思"。同片段里还有**自贬反击**："俗！当然俗！**要是不俗，你怎么会和我离婚**？！"和**时间威胁**："她过去是我老婆，现在她是你老婆，但是**将来指不定她又成了谁的老婆，到时候你住哪儿**？"

#### 范例 5 《归来》："组织"三问（赵 p0059）——舞台上最经济的"无法沟通"

```
李主任：冯婉瑜同志，你相不相信组织？
冯婉瑜：相信。
李主任：我是不是代表组织？
【冯婉瑜点头】
李主任：那你是不是应该相信我？
冯婉瑜：相信。
李主任：那好。（将公函放进包里，站起拉过陆焉识）我现在以组织的名义向你保证，站
        在你面前的这个人，就是你的爱人陆焉识同志！
冯婉瑜：我知道他是谁，他姓方，他是方师傅！
```

→ 技法：**三级递进的封闭式提问＋一句全盘否定的回答**。三问每一问都只能答"是"，把对方逼到逻辑上无路可退，然后让她从一个完全不同的层面否定掉全部前提——**对抗不在逻辑里，在认知里。**

### 14.5 交付格式（从 26 个片段的统一体例反推，赵 p0024–0197；格式补充见 p0197）

固定顺序：**剧名＋"根据 X 同名电影／电视剧改编"** → **一段分区布景描述** → **时间／地点／人物**（每人一句小传，可含"人物未来走向"） → **故事简介**（3–6 行；写"片段开演前 2 分钟发生的事"） → **剧情**（`【】`动作提示独立成行，`角色：（括注）台词`） → `参考视频来源：电视剧《X》正片第 N 集` ＋ `注：…改编自<作者>小说《X》` 或 `…编剧<姓名>`。

**不写场号、不写内/外/日/夜、不写任何镜头术语与转场。** 七条体例补充（p0197）：① `【画外音】` 两用——幕后事件（《刀客家族的女人》砸明火）与人物内心独白（《半生缘》）；② `【转场回忆】…【转场】` 舞台闪回；③ `【音乐起】/【音乐渐起】/【音乐渐弱】/【音乐渐强】`——本书唯一的节奏标记，固定出现在开场、情感峰值前、收场三处，**20 个片段几乎全部以"【音乐起】/【音乐渐起】"收尾**；④ 外语台词＝原文＋括号中文直译；⑤ 允许打破第四面墙（`【从台下往台上逃跑】`、`【大幕渐渐拉开】`、`（对着台下一观众）`）解决配角不足；⑥ 群众角色编号（`女学生甲/乙/丙/丁`、`丫鬟甲/乙`）；⑦ 多人混战写一条总调度提示。

⚠️ 与 `laohu-format-adaptation` 的两处冲突已在 [reference.md](reference.md) 第六节末标明（"必须用镜头去描述故事"vs"永远不提摄影机"；人物表带小传在片段／国产行业稿里是必备项，在英美 spec 里是明令禁止项）。另一处：《唐山大地震》教学说明第 5 条（p0054）鼓励"可以用带有唐山口音的方言说台词"——**但本书 26 个剧本无一处方言音译**，所以两者其实一致：**方言属于表演层，不进剧本文本。**

### 15.11 配套条款：第六条、第七条、第八条（2015-12-31 版）

- **第六条 必须聘请专家把关的三类细节（2015-12-31 版，p0294，原样）**："严肃认真对待摄制中的细节，涉及下列内容的，**要聘请相关专家进行把关**：（一）涉及**少数民族语言文字、革命先驱及其他重要人物形象、特定符号与标识使用以及图形、图表**等；（二）剧情内容表现**人民军队、武装警察、国安、公安、司法人员、医生、律师等特定职业、群体，以及社会组织、团体**的；（三）涉及**特定历史时期、职业群体的服装、布景道具**等。"
  → ★ **编剧写到以上任一项，剧本就会进入"专家顾问审读"环节**，进度表里要留修改时间；这笔钱在预算里就是"剧本讨论费及咨询费用"（张明智 p0145–0146）。涉法内容还要过剧组法律顾问（张明智 p0280）。
- **第七条 文字规范（2015-12-31 版，p0294，原样）**："电视剧制作机构应按照**国家语言文字规范标准**对电视剧的文字质量进行检查，以确保用字用语正确、规范。电视剧字幕**除书法题写的片名及相关文字外，应为规范汉字**。剧中有歌词的歌曲，外语标题、台词、有特定含义的词汇及标识等，**应加中文字幕**。"
- **第八条 罚则（2015-12-31 版，p0294）**：违反通则产生不良影响的，协会视情节"给予批评、警告、向全行业及社会公众通报的处分，情节恶劣的，**将取消会员资格，并报告主管部门，请予依法依规查处**"。

### 15.12 第三条 倡导的八项（2015-12-31 版，p0291）——反面清单之外的正向卖点清单

坚持"二为"方向和"双百"方针，制作"**思想性、艺术性、观赏性有机统一**"的优秀作品：（一）"坚持以人民为中心的创作导向，把人民作为表现的主体，反映人民心声"；（二）"坚持以社会主义核心价值观为引领……引导人民树立和坚持**正确的历史观、民族观、国家观、文化观**"；（三）★**"坚持以现实题材为主，贴近实际、贴近生活、贴近群众，记录时代发展和社会进步。"**；（四）"大力弘扬中国优秀传统文化。以史为鉴、传承文明"；（五）"弘扬真善美，传播正能量……引导人们增强道德判断力和道德荣誉感"；（六）"努力讲好中国故事，弘扬中国精神，凝聚中国力量"；（七）"坚持把社会效益放在首位……社会效益和经济效益相统一"；（八）"牢固树立精品意识……努力制作**思想精深、艺术精湛、制作精良**的优秀作品"。

### 15.13 用法：把这张表当读稿清单

1. **立项前**先过 15.1（1-5、1-8）、15.4、15.6（6-2、6-3）、15.8（8-2）——这五项决定**选题能不能做**，改不了的要换题。
2. **大纲期**过 15.5（5-5）与 15.8（8-3）——这两项决定**主题标尺与原著内核**，对应第十三节 13.5 的"主题表达环境三要素"（张巍 p0232–0233）。
3. **分集期**过 15.5（5-1/5-2/5-3/5-8）、15.6（6-1/6-4/6-5）、15.9——这些是**场面级**的问题，多半可以用[reference.md](reference.md) 第 7.5 节的规避手法改掉，或用赵彬彬的"幕后＋可见后果"四步（见第十四节 #2）转化。
4. **定稿前**过 15.11 第六条三类——列出本稿触发专家把关的全部条目，连同 15.10（10-3）的标识、呼号、称谓清单一起交制片。
5. **每次引用都写年份**：本表全部条文为 **2015-12-31 版**；现行文件须另行核对。
