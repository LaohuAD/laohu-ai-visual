# 故事与剧本的独立使用与交接

本文件是包内执行合同。单独上传本文件夹即可读取本包方法，项目AGENTS、其他包和本地共享资料不作为执行前提。作品本身的事实仍需提供，未知内容不得伪造。

## 必要输入与任务选择

输入：灵感或任务目的；修改任务的已有正文与锁定事实；分段任务的完整剧本。

先区分素材保存、故事开发、局部返工和定稿后分段。故事原子提供可用机制，不替代角色选择与故事因果；完整剧本验收后才能分段，视频不能倒改P。

已有目的和事实足够的局部请求直接执行，不强制先重跑总导演或整部作品。当前任务事实不足时只追问会改变结果的缺项；别的包未安装不能成为跳过本包应有方法的理由。

## 输出与完成

交付：完整E-S剧本；需要时继续生成E-S-P原文映射、讲戏、估时、资产需求和接续。

按当前任务读取专业入口及其中的方法；先保护锁定事实，再完成本轮独占判断。候选比较只重开未确认选择。初稿完成后反向审稿：因果是否成立、示例是否换题、对象关系是否清楚、陌生读者能否独立理解、内部规则是否泄漏进正文。图片与视频未真实生成时只标设计或提示词通过，不登记已验收素材。

本包默认交付文本。用户明确要求具体生成工具才执行该工具；发生费用、发布或使用真实账号时遵守实际授权。通用输出写入使用者指定位置；在老胡本地项目仍遵守外接工作盘、私有作品和Markdown生产/HTML交付规则。仓库根 `scripts/render_delivery_html.py` 可渲染作品主Markdown（从仓库根运行，六个包不各存实现）；无文件写入环境时交付完整正文，不声称已创建文件。

## 跨阶段协作

HANDOFF交出当前结果、来源映射、保护项、输入缺口和下一负责人；RETURN附具体冲突和最早能修根因的人。独立使用时把这些信息交给使用者，不声称实际调用了包外能力。本包所需方法从本包专业与 references/ 读取；跨包共用方法按可解析的相对路径读取唯一正文，不在包内另存运行副本；真源不可达时如实报告依赖缺口，不以链接文字代替专业执行。

## 本地可选增强

案例、品牌素材、风格资产及使用结果由使用者按任务提供。有这些资料时先检验是否适配、获准且有证据；没有时仍执行包内完整通用方法。未知模型参数不靠记忆补写；用户要求新事实或平台发生变化时再核验。

## 语言与来源

动作写可见可听事件，台词由人物身份与当场目的产生，讲戏解释行动与回应但不得改写所引原文。制作说明、对白、动作和括注分别处理。

外部网址保留为来源证据，不是日常必读前置。执行用本地方法、条件和案例；来源无法核验时保留未知，不把作者意图当实测。许可证与原作者身份不得抹除。
