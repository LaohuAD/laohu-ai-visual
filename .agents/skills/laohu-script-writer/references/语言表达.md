# 故事与剧本的语言表达

动作写可见可听事件，台词由人物身份与当场目的产生，讲戏解释行动与回应但不得改写所引原文。制作说明、对白、动作和括注分别处理。

## 执行顺序

先逐块识别发声者、接收者、文本任务和锁定信息；内容由当前专业决定，表达不能倒改事实。先检查句群是否完整传达因果，再决定句子如何合并或删除。必要信息、原话、动作和硬约束先保护，不能为短而短。

## 何时使用完整方法

- 身份、文本类型或详略不清：读[模式判定](语言模式/01_模式判定与块级切换.md)，确定一个主要接收者与任务。
- 对老胡说明方案、判断、修改或交接：读[沟通与制作说明](语言模式/02_用户沟通与制作说明.md)，用结论、依据和现实用途承接理解。
- 含对白、动作、括注或讲戏：读[剧本文本块](语言模式/03_剧本文本块语言.md)，保护原文，分清谁在说话。
- 含资产、图片、视频或声音指令：读[专业正文桥接](语言模式/04_资产图片视频与声音提示词桥接.md)，把作者解释移出模型正文，保留可执行控制。
- 冗长、口号化或压缩后丢信息：读[必要信息与冗余](语言模式/05_有效信息与冗余裁决.md)，逐块决定保留、合并、迁移、删除或返回。

完整方法已经在本包，不能以未安装语言模式包为由跳过。整稿返工检查实际出现的每种文本块，交付审过并改过的正文。只要求补充的任务沿原句补足，不另起画面、例子或剧情。
