# 剪辑接口与匹配剪辑

> 本方法原属摄影《镜头语言词典》第十二章，本轮按完整方法块归位到剪辑专业；正文信息、表述方式与信息密度未改，编号与标题层级按独立模块重新编排。转场是两段素材的交接合同，先服务主情绪与信息，再校准空间图形。

## 剪辑接口与匹配剪辑

转场不是独立特效，而是两段素材之间的交接合同：前一段交出一项观众能读到的属性，后一段延续、改向或有意反衬它，切点两侧还有足够干净画面和声音供剪辑选择。先保证主情绪、故事信息和节奏，再保证观众眼睛落点与动作可读性，最后校准空间和图形；不为一个漂亮匹配牺牲更高层目标。

| 接口族 | 交接属性 | 可见 / 可听实现 | 常见风险 |
|---|---|---|---|
| 运动连续 | 动作相位、方向、速度、轨迹、手势、出入画 | 前一镜抬手到动作中段，后一镜从同方向下一相位继续；人物从右侧出画，下一素材从相容边缘进入 | 动作重演、方向反转、切在未完成接触上 |
| 注意力连续 | 观众视点、人物视线、主体落点、焦点 | 人物看向右上方，下一镜在相近屏幕位置出现被看对象；焦点从脸落到杯口，下一素材从同一落点接圆形高光 | 只匹配眼神方向，却没有被看对象或空间依据 |
| 图形连续 | 形状、构图、景别、角度、轮廓、明暗、颜色、纹理 | 圆形杯口接车轮；同一荷兰角延续不安；白色桌面铺满画面接过曝天空 | 只剩形式相似，故事与情绪无关 |
| 遮挡 / 曝光连续 | 满屏遮挡、黑场、白场、闪光、灯光开合 | 人物或车辆完整覆盖画面；关灯后画面稳定变黑；闪电让画面短暂过曝 | 借遮挡瞬移、越轴或重置人物状态 |
| 声音连续 | 声音先行、声音延续、重音、节拍、相似声、对白桥 | 下一空间声音先进入；旧台词跨入新画面；关门重音落在切点 | 声源无方向、声场混乱、台词被截断 |
| 语义连续 | 因果、想法、隐喻、反差、视觉押韵 | 抚摸背部接抚摸琴身；一句提问接下一场动作答案 | 联想牵强、只靠作者解释才能懂 |
| 桥接素材 | 细节、插入、空镜、纹理、极短快闪 | 先切第二场景的产品细节、门把、鞋底、环境纹理，再进入新空间 | 桥接镜头本身抢戏或引入新连续性错误 |
| 后期依赖 | 抠像轮廓、替换平面、蒙版轨迹 | 纸张完整撕开、屏幕平面稳定、手势轮廓清楚、绿幕光照均匀 | 边缘脏、遮挡不完整、运动无法跟踪、后期成本失控 |

跨镜头不需要所有属性同时匹配。通常一条主要属性、一条辅助属性最清楚，例如 `动作方向 + 观众视点`、`形状 + 明暗`、`台词语义 + 声音延续`。相似景别和相似构图可以顺滑，跨景别匹配也可以成立；关键不是“必须跨一个景别”，而是新镜头确实改变了信息尺寸、观看位置或情绪压力，并且观众眼睛知道落在哪里。

生成前只记录推荐入点、内部节点、推荐出点和干净把手，不虚构时间码。正式模型正文把接口写成画面 / 声音结果；生成后逐帧确认真实时间码、稳定范围和是否值得使用。
