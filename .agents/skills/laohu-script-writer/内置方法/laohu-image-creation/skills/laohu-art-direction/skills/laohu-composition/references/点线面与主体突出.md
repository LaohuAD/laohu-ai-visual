## 点线面与主体突出

点线面不是美术课概念，而是给观众视线安排秩序的镜头方法。点让观众知道第一眼看哪里，线让观众知道视线怎么走，面让画面杂质被压掉。

### 点：视觉落点

点是画面里最先抓住眼睛的对象，可以是一张脸、一双眼睛、一滴泪、一只手、一个道具、一棵树、一束光或一个唯一清晰的局部。点在正中间，画面稳定、庄重、确定；点在三分线或边缘，画面更有呼吸感、孤独感或故事空间。画面越复杂，点越需要被强化：更大、更亮、更鲜艳、更清晰、更高反差、更锐利，或处在运动停点。

错误写法：

```text
广场上有很多人，一个女孩回头看镜头。
```

正确写法：

```text
广场人群整体压低饱和度并轻微虚化，画面右侧三分线处只有回头女孩的脸保持清晰，脸部受光比周围人亮半档，眼神直接看向镜头，成为唯一视觉落点。
```

### 线：视觉导引

线在需要安排观看路径时，把视线引向主体或从主体引向别处。主体在线条起点、途中或终点会改变信息顺序，但不固定对应存在感、孤独或动作；情绪还取决于人物处境、速度、密度和声音。

写线时必须写清起点、路径和终点：

```text
木栈道从画面左下角斜向右中远处延伸，木板缝和扶手线条汇聚到人物脚边，人物站在线条终点回头。
```

不要只写：

```text
画面有引导线，构图高级。
```

斜线、曲线、S 形、水平线、垂直线和多线汇聚首先改变方向感、节奏和视觉收束程度，不固定对应冲击、舒缓、稳定、庄重或压迫。

### 面：留白、压制和空间切割

面是大面积的天空、海面、墙面、暗部、雾气、虚化背景、草坡、石墙、门洞阴影或前景色块。面可以是留白，也可以是压制。它的任务不是单纯填背景，而是切割空间、挤压杂质，把主体放到更干净、更有力量的小空间里。

正确写法：

```text
画面左侧三分之二被深绿色虚化树影压成干净暗面，只在右侧三分线留出一块柔金亮面承接人物侧脸，暗面压掉杂乱枝叶，亮面托出鼻梁、唇峰和耳坠。
```

使用规则：

```text
主体复杂时，用干净块面承接主体。
背景杂乱时，用暗部、虚化或大面积墙面压掉信息。
情绪孤独时，让人物只占小点，周围大面积天空、海面、雪地、草坡或墙面成为压迫性留白。
人物高级感镜头中，面要干净，边角不要有随机路人、碎道具、强特效或文字。
```

点线面最终必须服务主体突出。不要为了形式把点、线、面都堆满；只要观众第一眼不知道看哪里，就先重写视觉落点。

## 2. 主体突出审美特征资产

### 2.1 通用基底

高质量图片首先要给观众眼睛找一个家。画面可以复杂，但第一眼必须知道看哪里。

### 2.2 特征颗粒

```text
视觉落点：
脸、眼睛、泪、手、道具、树、光点、门缝、火苗、旧物或唯一清晰局部成为第一注意力。

主体加满：
当干扰很多时，主体通过面积、亮度、颜色、清晰度、反差、位置、轮廓光或独特动作被强化。

信息降噪：
背景人物、杂物、纹样和环境细节被压低饱和度、降低清晰度、放进暗部或虚化块面。

边角清洁：
画面四角不塞随机文字、路人、半截物体、错位手脚和无关装饰。

远看可认：
缩小到封面尺寸时，仍能认出主体身份、情绪和画面关系。
```

### 2.3 质量增益

命中主体突出特征后，图片会从“元素很多”升级为“第一眼有主角”。这会直接提高封面点击、资产可用性和视频参考稳定性。

## 3. 点线面构图审美特征资产

### 3.1 通用基底

点让观众锁定，线让视线移动，面让空间安静。三者共同决定画面是否有秩序。

### 3.2 特征颗粒

```text
点：
唯一亮点、清晰脸部、眼神、手部动作、发光道具、火苗、泪痕、首饰反光。

线：
栏杆、道路、桌沿、窗框、门框、桥、光束、阴影、海岸线、人物视线、手臂方向、群体朝向。

面：
天空、海面、墙面、暗部、虚化背景、雾气、草坡、石墙、门洞阴影、前景色块。

线条位置：
主体在线条起点、途中或终点会改变观看顺序和空间方向，但不固定对应登场、孤独或动作。只有线性节奏承重时才选择位置，并结合人物处境判断情绪。

留白：
天空、海面、墙面、暗部、门洞、虚化背景或纯色块可以承载安静、压迫、隔绝、字幕或降噪；是否使用取决于主情绪和用途。

遮挡：
门框、窗帘、发丝、手、前景虚化物、半透明玻璃和阴影切割画面，保留局部信息。

神秘局部：
半张脸、唇部、眼睛、手指、侧颈、衣料边缘、首饰微光或背影回头形成想象空间。

视线落差：
人物目光、身体朝向、光束方向和构图线条共同指向画面外或画面内的关键区域。
```

### 3.3 质量增益

点线面让图片不再靠运气好看。它把审美从“元素选择”推进到“视线组织”。
