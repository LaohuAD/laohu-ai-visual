# 语言模式的独立使用与交接

本文件是包内执行合同。单独上传本文件夹即可读取本包方法，项目AGENTS、其他包和本地共享资料不作为执行前提。作品本身的事实仍需提供，未知内容不得伪造。

## 必要输入与任务选择

输入：待处理文本、接收者、任务、锁定事实与允许变化。

独立调整表达时直接处理，不要求完整作品流程；跨领域规则由本包维护，领域写作仍由对应负责人执行。业务包内嵌规则可直接用，不要求另装本包。

已有目的和事实足够的局部请求直接执行，不强制先重跑总导演或整部作品。当前任务事实不足时只追问会改变结果的缺项；别的包未安装不能成为跳过本包应有方法的理由。

## 输出与完成

交付：修订后的文本及必要的块级处理说明；内容缺失时的具体返回。

按当前任务读取专业入口及其中的方法；先保护锁定事实，再完成本轮独占判断。候选比较只重开未确认选择。初稿完成后反向审稿：因果是否成立、示例是否换题、对象关系是否清楚、陌生读者能否独立理解、内部规则是否泄漏进正文。图片与视频未真实生成时只标设计或提示词通过，不登记已验收素材。

本包默认交付文本。用户明确要求具体生成工具才执行该工具；发生费用、发布或使用真实账号时遵守实际授权。通用输出写入使用者指定位置；在老胡本地项目仍遵守外接工作盘、私有作品和Markdown生产/HTML交付规则。包内scripts/render_delivery_html.py可渲染作品主Markdown；无文件写入环境时交付完整正文，不声称已创建文件。

## 跨阶段协作

HANDOFF交出当前结果、来源映射、保护项、输入缺口和下一负责人；RETURN附具体冲突和最早能修根因的人。独立使用时把这些信息交给使用者，不声称实际调用了包外能力。本包所需方法从包内专业与内置方法读取，不能拿一个外部链接代替专业执行。

## 本地可选增强

案例、品牌素材、风格资产及使用结果由使用者按任务提供。有这些资料时先检验是否适配、获准且有证据；没有时仍执行包内完整通用方法。未知模型参数不靠记忆补写；用户要求新事实或平台发生变化时再核验。

## 语言与来源

先判发声者、接收者、阶段和文本块，再确定详略、语序与表达形式。语言修复不改事实、锁定台词、身份与专业约束。先保必要信息再去冗余，整稿审查覆盖全部实际出现的文本类别。

外部网址保留为来源证据，不是日常必读前置。执行用本地方法、条件和案例；来源无法核验时保留未知，不把作者意图当实测。许可证与原作者身份不得抹除。
