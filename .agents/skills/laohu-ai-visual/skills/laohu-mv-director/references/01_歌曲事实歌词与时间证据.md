# 歌曲事实、歌词与时间证据

## 一、先决定什么可以相信

歌曲进入 MV 后，不能把不同材料当成同一种证据：

| 材料 | 能负责什么 | 不能自动负责什么 |
|---|---|---|
| 最终音频 | 实际总长、人声、律动、旋律、配器、音色、动态、停顿 | 谁在唱、人物关系和创作背景 |
| 锁定歌词 | 唱词、重复、语义、说话对象和文字包装原文 | 精确起止时间、实际唱法和配器事件 |
| 人工 LRC / SRT / DAW 标记 | 歌词或段落的时间边界 | 自动证明文字无误或边界适合视觉切换 |
| ASR / 自动对齐 | 发现候选入点、出点和置信度 | 改写锁定歌词、证明低置信度音节准确 |
| 创作背景 | 发声者、对象、关系、动机和主题边界 | 证明音频中一定发生了某种声音 |
| 音乐生成提示词 | 原始审美意图、曲风、乐器和演唱设想 | 覆盖最终成曲与提示词不一致的结果 |

冲突时先保护可确认事实：最终音频决定听觉发生了什么，锁定歌词决定唱了什么，人工确认决定人物和创作事实。自动分析只能补充，不能悄悄替换。

## 二、输入充分度

### 可执行时间线

至少需要最终音频，以及能够对应人声的锁定歌词；纯器乐不需要歌词。有人工时间戳时优先使用，并检查是否覆盖目标版本、是否越界、是否漏句和是否把一句词拆断。

### 可做导演方向、不可做精确时间线

只有歌词、创作背景、曲风、谱曲方案或音乐提示词时，可以完成：

- 发声关系与主题判断。
- 叙事 / 表演 / 概念 / 氛围候选。
- 相对段落与母题发展。
- 需要哪些人物、空间和美术方向。

但每个时间字段都写`相对位置`或`待音频校准`，不得按照常见歌长、歌词字数、Verse / Chorus模板伪造秒数。

### 只有音频、缺少歌词

- 纯器乐：按声音事件、能量、配器、音色与结构设计，不补唱词和口型。
- 有人声但没有锁定歌词：可以判断人声出现、强度和表演类型；不能写精确唱词、歌词字效或逐字口型。先请求或等待歌词，自动识别只能形成待确认文本。

## 四、时间证据使用

歌曲事实允许保留毫秒或帧精度；生产单元是否必须为整数、最短和最长多少，完全由目标模型能力合同决定。

边界候选按优先级检查：

1. 不切词、音节、重要呼吸、长音收束和未完成表演。
2. 尽量落在歌词句末、乐句、小节、停顿、配器或动态变化。
3. 能把上一视觉任务交完，并给下一任务留下清楚入口。
4. 满足目标模型与实际工作流的硬上限。

没有完全干净的模型边界时，不改写歌曲事实：可以跨段保留声音桥、把人物暂时移出清晰口型位置、调整视觉动作相位，或标记需要人工确认；不能静默删掉尾音、重复音频、拉伸声音或伪造停顿。

## 五、歌词语义不能变成逐句插图

先判断歌词句在歌曲中的功能：建立事实、改变对象、重复宣言、推进压力、产生反转、留下歧义或只提供声音质感。只有承重句才需要直接的视觉回应。

逐字画出歌词名词容易得到插图集。优先寻找：

- 同一关系怎样在不同段落变化。
- 一个母题怎样因重复获得新意义。
- 画面何时平行歌词，何时对位，何时留白。
- 哪一句适合人物正面跟唱，哪一句应让环境或动作接管。

## 六、失败检查

- 根据曲风提示词写出音频里没有的乐器、速度和 Drop。
- ASR 识别错词后直接改写锁定歌词。
- 没有音频却输出精确秒数。
- 看到 Chorus 名称就给每次副歌相同画面。
- 为了适配模型切断一个词、一个呼吸或未完成的长音。
- 纯器乐段仍让人物持续演唱。
