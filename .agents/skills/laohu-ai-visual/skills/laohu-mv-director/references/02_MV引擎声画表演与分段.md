# MV 引擎、声画、表演与分段

## 一、四类引擎解决不同观看问题

### 叙事引擎

观众等待人物会怎样选择，歌曲通过事件、关系和代价变得可见。适合歌词有角色、对象、行动与变化，或者创作背景包含不可替代的关系事件。

叙事不等于逐句重演歌词。先让一条人物压力在整首歌中推进；完整人物选择、高潮和结尾交给编剧建立，再由 MV 导演决定哪些歌曲段落承担故事事实、哪些留给表演和声音。

### 表演引擎

观众通过歌手或角色的身体、目光、呼吸、嘴型、舞蹈和摄影机关系进入歌曲。适合人声、唱法、Hook、艺人身份或身体律动本身是记忆中心。

表演必须发展：对象、距离、姿态、控制能力、摄影机亲疏或空间压力至少有一项随歌曲变化。全曲站在同一处对嘴，不会因为换景和换灯就形成推进。

### 概念引擎

观众逐渐看懂一个视觉规则怎样建立、变体、失效和回收。适合强隐喻、重复命题、符号、材料或世界法则。

概念不是意象堆叠。必须能写出`初始规则 → 第一次变化 → 代价或反例 → 高潮改写 → 结尾回收`，并让同一母题跨状态仍可辨认。

### 氛围引擎

观众先经历温度、空间、时间、材质和情绪，而不是理解事件。适合歌词开放、重复、声音重音色与空间，或歌曲需要克制观看。

氛围不等于没有结构。空间距离、光色、天气、颗粒、主体可见度、运动密度或声音留白必须出现可感变化。

## 二、候选竞争

至少比较三条真正不同路线。例如同一首失恋歌可以是：

- 人物在一个不可逆行动中结束关系。
- 歌手直接面对镜头，从压抑演唱发展到失控又恢复克制。
- 两个人共享的空间逐段删除物件，最后只剩声音。

三者改变的是观众关系、引擎和结果，不是换滤镜。候选记录主胜负手、最强段落、不可替代母题、主动放弃与淘汰理由；胜出方案最多保留一个辅助引擎。

## 三、五种声画关系

| 关系 | 作用 | 失败信号 |
|---|---|---|
| 同步 | 让动作、嘴型、构图完成或母题变化与关键声音同时落点 | 每拍都切、所有元素一起动 |
| 平行 | 画面与音乐同向推进情绪或能量 | 只有情绪形容词，没有可见变化 |
| 对位 | 画面与歌词或声音形成有目的的反差，产生第三层意义 | 为高级而反着拍，关系无法解释 |
| 留白 | 让画面或声音一方暂时退让，放大缺席、呼吸和等待 | 单纯没设计、信息断裂 |
| 声音桥接 | 同一人声、呼吸、乐器或环境声穿过切点，连接两个空间或状态 | 声音只是背景，没有承接对象 |

每个歌曲段落只设一项主要关系，必要时增加一项辅助关系。拍点设计写`拍前准备 → 同步完成 → 拍后余波`；卡点看事件何时完成，不看切镜数量。

## 四、表演与口型分流

### 精确跟唱

同时满足才启用：真实人声正在发生；人物嘴部清晰可见；该人物与人声身份相符；直接演唱能加强当前段落。记录唱词、对象、气口、重音、下颌与嘴型幅度、目光、身体支撑和句后停点。

### 情绪表演

人物不逐字跟唱，但呼吸、控制能力、距离和动作策略与唱法同向或有意对位。适合无法可靠对齐、人物并非歌者或画面承担关系反应。

### 舞蹈 / 动作表演

动作短语、重心、方向和完成姿势服从音乐结构。重拍承担完成点，细分拍承担连续小运动；不能让人物、摄影机、背景和特效同时抢拍。

### 纯视觉

器乐、远景、背影、空镜、插入、概念与留白段不强制嘴型。人物进入画面不等于必须演唱；看不见嘴也不能假装已经完成口型控制。

## 五、从歌曲段落到生产单元

### 先有创作段落

边界来自歌词对象、信息、旋律、律动、配器、音色、动态、停顿、表演阈值和情绪变化，可以长短不一、精度不同。

### 再装入生成单元

目标模型能力合同至少记录：

```text
生成方式：文生 / 图生 / 首尾帧 / 多参考。
单次最短、最长与时间精度：
图片输入职责：
是否支持内部多镜头：
口型 / 音频参考能力：
字符与参考数量边界：
当前未知：
```

模型限制只改变怎样装箱，不改变歌曲为什么转段。没有能力合同时提供模型中立的自然边界和备选拆点，不默认任何固定时长或整数规则。

### 生成单元与剪辑镜头分权

- 生成单元：一次模型请求要完成的完整素材任务。
- 内部镜头：生成单元内部的观看位置与切换。
- 成片镜头：真实生成后从素材中选出的可用区间。

三者可以不同。一段较长素材可以只取中间几秒；一个连续表演也可以在一个生成单元内包含多个内部机位。导演阶段只规划任务和接口，不用虚构的生成后时间码冒充真实剪辑结果。

## 六、动态分镜资产模式

### 单帧

适合稳定身份、演唱近景、情绪姿态、氛围起点和一次明确动作。图片必须包含开始时真正存在的主体、关系、构图和状态，不把未来结果提前画进首帧。

### 首尾帧

适合从明确起点收敛到明确结果：姿态变化、物件状态改变、空间重构或概念变形。两端必须属于同一事件，不能用两个无因海报逼模型补完整故事。

### 多关键状态

适合多个不可合并的叙事阈值、复杂调度或分阶段概念变化。每个状态写清功能和前后继承；状态数量由变化决定，不固定版式、不固定宫格数，也不要求把多图合成一张上传板。

## 七、重复、高潮与结尾

- 第一次重复建立规律，第二次重复改变关系、规模、表演、空间或含义。
- 高潮不是特效最多，而是歌曲最重要的声音与全片最重要的视觉判断终于相遇。
- 结尾可以回收人物、母题、空间或一句唱词，也可以保留准确缺席；不能只因音频结束让画面随意淡出。
