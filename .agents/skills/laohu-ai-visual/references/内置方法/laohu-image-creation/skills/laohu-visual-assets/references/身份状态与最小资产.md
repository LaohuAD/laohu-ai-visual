# 资产规格与编译



需要多镜头复用时，先按“复用次数、身份承重、结构易漂移、失真代价”判断最小必要资产，不统一建立三件套：



- 表情组、动作起点参考图或角色一致性网格图只能作为辅助或临时参考，不能替代已经选定的正式资产职责。

生成顺序按依赖关系执行：人物设计正文、服装设计正文和妆造补充正文先组成`F人物主视觉图`；人工确认F后，同编号B从可见证据反推脸身并使用人物正文补足身体参数，同编号W反推可见服装并使用服装正文补足拆解；最后M组合F、当前B / 阶段素体、W和妆造补充正文。F只服务资产生产，不直接进入视频；M不得绕过W直接发明服装。未被资产化的一次性背景群众仍可由群像或视频正文统一描述，不为每个路人建立个人资产。
