# 对白与表演方法

人物感知决定注意什么，关系目的决定怎样说，动作与表演让未说的部分成为可见可听的证据。

## 台词口气与方言

台词不是把故事信息翻译成普通话句子，而是人物身份、地域、年龄、文化程度、亲疏关系和当下情绪的声音。写正式剧本前，必须先判断人物应该怎么说话：

```text
人物来自哪里。
年龄和受教育程度如何。
亲属关系和距离感是什么。
当下是在训人、哄人、忍着哭、随口抱怨，还是说不出口。
用户是否指定方言、地域口气或年代口气。
```

如果用户指定重庆话、四川话、东北话、粤语口气、老一辈农村口气等，剧本台词必须按对应口气写。方言不是装饰词库，而是让人物听起来像真实生活里的人。

## 人物先怎样看，再怎样说

人物声音不只是字词风格，而是人物在当下处境中对证据的选择、解释和应对。先建立人物声音合同：

```text
他优先注意什么：
普通人不会优先注意、他却会注意的证据：
前史、训练或当场证据：
他会怎样解释证据：
他的欲望、恐惧和价值判断怎样改变这种解释：
他正在想让谁做什么：
他最不愿直接说出什么：
未说出的普通愿望：
句子说完后他实际采取什么行动：
```

这份合同不要全部解释给观众，它用来生成这个人独有的感知与反应。同一声敲门、同一个空杯、同一次停电，护士、修理工、孩子和躲避追踪的人会优先注意不同证据，因而做出不同选择。

### 职业化感知不是超能力

职业、劳动、疾病、长期关系和生存经验会改变人物的注意顺序。医护人员可能先看呼吸节律，老木工可能先听结构受力的声音，长期被监视的人可能先找出口与反射面。但超出常识的判断必须有前史、训练或当场证据；不能因为人物“厉害”就让他从一个脚步精确知道对方全部身份，把不可信的超能力冒充职业经验。

职业化感知最终要回到：

```text
处境 → 感知证据 → 人物解释 → 可选行动 → 当场选择 → 可见后果
```

只有专业判断、没有后续选择，仍只是人设展示。

### 对白的策略变化与未说内容

当对白像轮流表态、反复请求或突然让步时，先用动作动词在内部标出各轮正在做什么，例如试探、讨价、遮掩、挑明、转移、求助、拒绝；不把这些词贴在每句正文旁边。逐轮追问：对方的哪项反应使上一招失效，这一句准备换什么办法，句后谁改变了行动或判断。换同义词、提高音量和换情绪形容词都不算换策略；反复说同一句却逐次改变关系许可、期待或代价，可以保留。

需要潜台词时，分清三类内容：

- 人物愿意并能够明说的事：当场事实、请求、操作指令或必要教学，清楚说出。
- 人物知道却不愿明说的事：必须指出怕付出什么关系代价，以及观众能从哪项言行不一致和反应察觉；不能仅靠作者括注宣布“其实舍不得”。
- 人物尚未意识到或无法组织成语言的需要：用重复选择、回避和失败结果支持一种解释，允许不确定；不要让他突然自我诊断，也不要把心理学名词当确定人格事实。

先写一遍人物真正想说的意思作为内部草稿，再按说话对象、关系风险与习惯改成当前会出口的话，最后删除内部解释，检查正文还剩什么证据。冻结台词不参加改写；若它与当场目标矛盾，只能尝试已授权的语气、触发和反应，仍不成立则标明冲突返回编剧或导演，不偷换原话。

背景信息可以在请求、反驳或谈判中产生作用，但这不是把每句都写成武器的命令。人物可以合作、闲聊、直接表达感情；教学喜剧必须先让观众听懂知识原义。不能为“有潜台词”删掉关键解释，再要求观众靠表情猜专业知识。明确示范的知识也不必伪装成争论。

原创局部例：两名同事共同完成报告，结尾已锁定由乙上台，甲想让自己的名字被提到。甲连说“记得说我／别忘了我／我也做了”，只是重复请求。若乙回应“我会说是我们做的”，甲可以不再索要表扬，改问“说到那张图时，能说是谁画的吗？”新策略来自对方刚给出的集体称呼，争取的是可辨认的贡献。若图并非甲画、原稿没有图或署名已冻结，就不能借此例补造事实，应从已有贡献找可用证据。

角色辨识最后仍回到本文件的人物声音合同与纯对白盲听：遮住姓名时，区别应来自关注对象、取证方式、句子习惯与关系策略；加一个方言词或口头禅不能代替人物。对白过满时可以先排一次无台词行动，找出确实只能靠说话才能完成的事，再恢复必要台词；这只是诊断工具，不以无对白为更高级，也不删已有表演与声音交接。

### 让一组词语沿同一条矛盾生长

同组词语换义的价值，不是谐音或比喻数量，而是一组生活词语随人物处境获得新指向。一场先确定同一条人物矛盾，再决定人物会借用哪个熟悉领域理解它。

```text
核心矛盾：当下身份与人物愿望如何相撞。
词语母域：人物最熟悉的劳动、家庭、食物、生意、训练或地域经验。
首次指向：词语的日常意义。
新指向：它怎样暴露当下危险、身份或价值判断。
行动回收：这个换义怎样改变人物下一步。
```

一场可以只有一组承重关系，其余句子允许普通、犹豫、沉默和说不完。每句都随机更换漂亮意象，会把人物变成作者的比喻展架。

### 误听、曲解与词语机关

误听喜剧不是斗嘴的默认起点。先检查可见处境、两人当下目标、关系特权和上一拍后果；这些已经能让普通话变得好笑时，不再追加词语机关。确实使用误听时再过四道门：现场发音是否支持、整句句法是否支持、人物是否有动机选择错误解释、错误解释是否改变下一行为或关系。自然同音或近音同时通过四道门时可以使用；只有作者看文字觉得像、真人说出口却不像时，判为假谐音。

没有可靠谐音时，不降低标准硬凑。改为比较双重语义、断句换义、对象偷换、字面执行、关系反应与动作回收：它们不要求人物真的没听清，而是让人物明明听懂，仍为试探、反击、调情、嘴硬、报复或给下一动作找借口而选择另一种解释。观众必须先听懂原义，再看懂人物为什么故意换义。这里校验的是人物有没有关系动机“这样接”，不是人物是否真的相信第二种解释。

```text
原句的可听原义：
可成立的第二听法或第二指向：
人物选择第二解释的关系动机：
对方是否立刻识别他在装：
改变下一动作、距离、物件、空间或风险：
```

同一段若连续三次使用“你说什么”，即使每次词不同，也属于句式重复。保留最准确的一次，其余改用现场听不清、对象换义、字面执行、关系反击、动作回收或普通反应。反过来，也不能把“避免机械重复”执行成删除人物已经成立的调皮策略；系列喜剧允许同一个关系引擎在不同场景中变奏，但每次必须改变证据、句法、攻防位置或可见后果。

更重要的是，不得把“换一种手法”执行成把谐音、双重语义、对象偷换、字面执行逐一排班。同一段冲突通常只保留一个主喜剧引擎，其余台词允许普通、结巴、改口、沉默或只报出事实。人不会在每一次呼吸里都发明一个新比喻。

#### 语言机关兑现合同

台词中的换义一旦被人物拿来发动动作，就不再只是句子，而是一个跨台词与动作的承诺：

```text
已确认原词：观众刚听懂、用户已经确认或前文已经建立的准确说法。
人物故意换义：人物为了试探、反击、调情、嘴硬或报复，故意把它指向什么。
当场台词：换义必须怎样被观众直接听见。
下一动作：人物立刻据此做什么。
动作结果：对方、物件、空间或风险发生什么变化。
跨镜头保留项：切镜后必须原样保留的词、动作方向和未完成后果。
```

若台词镜与动作镜分开，切镜只改变观看位置，不取消语言承诺。上一镜说“正侧着踹”，下一镜可以换机位展示蓄力和命中，但下一镜不得退回普通招式名如“漂亮横踢”，也不得把“正侧着踹”稀释成任何侧向动作。动作结束后再检查：观众能不能不用作者解释，把原词、故意换义、身体动作和结果连成同一条因果。

### 台词的人类反应校验

经常合作的人物先读权威人物资产中同一关系状态的已确认原话，再写新台词。抽象标签不等于声音；“毒舌、调皮、聪明”不能告诉编剧这个人会说多长、会不会解释、调侃时抓对方哪个具体漏洞。

初稿后先把动作和作者说明全部删掉，只保留说话顺序做一次`纯对白盲听`：

```text
听众能否只凭前一句和刚发生的事，理解为什么现在这样回？
这句是在攻击、防守、转移、求饶、掩饰还是报事实？
如果去掉巧妙的比喻，这个人当下还有非说不可的原因吗？
听完后，对方能不能立刻反应，还是必须等作者解释这句的逻辑？
```

当人物没有职业或现场理由时，“流程、收到、测试、层次、知识付费、抽查”这类压缩词连续出现，应当视为作者正在借人物总结机制的警报，而不是直接当作机灵。这不是禁词表；只要现场真有这个对象、人物平时会这样说，仍可保留。

### 情绪交接：括号写状态，动作写证据

情绪不是给人物贴在脸上的词。剧本括号的第一职责，是让演员和下游知道人物此刻处在什么情绪阶段、正想怎样对待关系对象；`△`动作与声音再证明这种状态从何时开始、从哪里泄露、最后把人物推向什么行动。

承重节拍使用：

```text
【情绪交接合同】
起点与情绪阶段：已经平静 / 正在压住 / 接近阈值 / 刚越过阈值 / 爆发余波。
人物正在压住或放大什么：不愿让对方看见的真实反应。
关系目的：此刻想让谁改口、靠近、停手、相信、害怕、原谅或离开。
精确触发：哪一个词、动作、声音或可见结果改变了人物。
可见泄露：目光、嘴角、下颌、呼吸、手、重心、距离或声线先后出现什么证据。
台词策略：试探 / 警告 / 求饶 / 装作没听懂 / 抢回解释权 / 结束谈话。
句后行动与终点：话说完后做什么，关系停在哪里。
禁止提前反应：触发发生前，哪些终点反应不能出现。
```

括号保持短，写`声源 / 情绪阶段 / 关系目的 / 可听语气`中当前需要的信息，不要把整份合同塞进角色名后面。例：

```text
△ “油光”落下前，Luna仍维持主持状态；两个字落下后，她吸气停住半拍，嘴角礼貌弧度消失，下颌咬住，握遥控器的指节收紧，目光才从镜头移到老胡。
Luna（怒意压在爆发前，给老胡最后一次改口机会）：老胡。
老胡（玩笑已经收不住，先装成口误求她别动手）：伦勃朗光。刚才嘴瓢。
```

`Luna（声音放低、句子很短）`只写了声音结果，不知道她是在害怕、哀求、压怒还是控制局面；`老胡（笑意开始发虚）`只写了模糊神态，不知道他意识到什么、想掩饰什么、下一步为何求饶。声音和神态可以作为可见泄露继续保留，但不能代替情绪阶段、关系目的和精确触发。

每句有声台词必须能追溯到可执行表演信息：可逐句括注，也可在本场开头显式声明角色表演基线、适用镜号或台词范围，以及“未另标者继承本场基线”。情绪、关系目的、可听语气或声源变化处单独标注；跨场不自动继承。声源位置不等于表演状态，O.S. / V.O. 只说明声源，不能代替表演。例如本场开头可写`表演基线｜教师｜E01-S01-C01至C04：耐心平稳，未另标台词均继承；重音变化单独标注`；逐句写法也可用`Luna（保持教学耐心，语速平稳，把重点落在“暗侧亮三角”）：……`；情绪转折、谎言、求饶、抢话、攻击和关系变化再使用完整合同。不得只写 `O.S. / V.O. / 远处`，因为这些只说明声源，不说明人物怎么说；正确写法如`老胡（O.S.，怕她追来，隔门喊得又快又响）：记住了！`。括号服务表演，不重复台词字面意思，也不把每句都写成同样长度的心理说明。

### 普通愿望、身份反差与结果残留

强身份人物的普通愿望可以让人接近他，但不自动等于深度。愿望要至少完成一项：提高他当下选择的代价，暴露他不肯承认的需要，或成为后续能被兑现、破坏或重新解释的承诺。

事件过去后，优先用温度、气味、损坏、位置、声音余波和他人反应作为结果残留。它们先证明刚才发生了什么，人物语言再选择是否改写意义；不先用旁白把画面已经证明的事说一遍。

### OS / VO 与画面分工

文学样章可以直接写内心；正式剧本使用OS / VO时，必须说明这个声音是当下内心、回忆旧话、未出场声音还是叙事旁白。声画关系只保留能带来补充 / 对位 / 反差的内容，不同义复述画面。

一段独白完成后再问：

```text
画面已经证明了什么：
声音新增了什么信息、误判或价值冲突：
说完以后人物采取什么行动：
这个行动产生什么可见后果：
```

只有气氛、观点和漂亮句子，却没有行动与后果时，将它标为文风层，不把它当成场次推进。

## 白话台词与前因后果

历史题材不等于文言腔。人物可以受时代、职业和教育程度影响，但普通百姓、戏班艺人、基层士兵和临时传话的人，默认先用当时生活里说得出口的白话；只有身份、场合和关系确实需要时，才保留礼貌称谓或戏曲化表达。不要用“局势、命运、使命、牺牲、制造混乱、调动注意力”替人物说话，这些是创作者的分析词，不是现场对白。

关键台词必须先有可见前因，再让人物开口。至少交代其中一项：谁刚刚做了什么、谁听见了什么、谁被抓住或看见、眼前正在发生什么。对白应完成“事实 → 反应 → 选择”：先让观众看见事实，再让人物用符合身份的短句反应，最后说清或做出下一步选择。错误写法是士兵没有听见任何铺垫就突然命令“唱个锤子”；正确顺序是先宣布庆功宴、公开征集会唱会跳的人，再由群众目光暴露戏班，最后由军官决定把人带走表演。

台词多少服从节拍，不追求每场平均。建立信息时可以多说几句，冲突升级时用事实、反应、选择推进，动作已经清楚时不再用台词解释一遍。危险中的人通常说短句、生活词和能一口气说完的话；需要交代复杂关系时，把信息拆到传令、动作、旁人反应和下一句对白里，不让一个人站着替全片讲解。

白话审稿逐句检查：普通人会不会在这个时间、地点、关系和危险里这样说；删掉修辞后事实是否仍清楚；句子是否在替作者总结主题；上一拍是否真的给了人物开口的理由。出现“景一落”“腿软、不够要命”这类只有作者或行话能懂的表达时，改成画面和生活话，例如“大布放下来”“够他们喝一壶，死不死看命”。

重庆话 / 川渝口语写法：

```text
优先使用短句、碎句、生活词和口气词，例如：啷个、莫、嘛、噻、撒子、晓得、要得、没得、娃儿、你个小崽儿。
老人、父母、村民说话可以更土、更直接、更省略，不要像受过训练的主持人。
孩子说话要任性、直接、反应慢，不说成人式总结。
方言使用要克制，保证普通观众能听懂；不要每一句都堆方言词。
```

反例：

```text
奶奶：你以后一定要照顾好自己，注意身体，保持良好的生活习惯。
```

正确：

```text
奶奶：饭莫挑，天冷了晓得添衣裳。你爸忙，没人天天盯到你，听到没得？
```

对《不想长大》这类重庆老家、老一辈文化程度不高、亲情遗憾题材，爷爷、奶奶、父亲、村民优先写重庆话口语气质；小安和姐姐写儿童 / 少年口语。核心不是方言表演，而是避免书面腔破坏真实感。

### 人物声音与当场演法

先找关系，再炼句子。关键台词、片名、钩子、主物象和结尾不能直接采用模型第一反应。

人物声音不先由口头禅、方言或句式决定，而由他怎样看见、解释和应对世界决定。编剧负责的是`写作声音`：人物优先感知什么、怎样解释、想用语言改变谁、回避什么，以及说完会怎样行动；它决定台词 / OS / VO 的内容与语言策略，不决定演员的生理音区、音色，也不逐镜导演最终呼吸、口型、FACS强度和模型参数。但这条边界不允许编剧把情绪缩成一个形容词交给下游补猜：承重节拍必须先锁定情绪阶段、关系目的、精确触发、可见泄露、台词策略、句后行动与终点和禁止提前反应。重要人物写台词、OS或VO前建立人物声音合同：

沿用本文件“人物先怎样看，再怎样说”的人物声音合同，不另建第二份。把“哪些职业、生活或身体经验支持这种注意”纳入已有前史证据，把压力下泄露的判断纳入欲望与恐惧，把可见后果接在既有话后行动之后；同一合同再补以下校准信息：

```text
权威人物资产或语言样本来源：
本关系状态中已确认的 3–8 句原话：
原话共同显示的句长、直接程度、攻防方式与留白：
```

人物声音合同回答“这个人为什么这样说”，`情绪交接合同`回答“他在这一拍怎样从一个状态走到另一个状态”。每句有声台词必须能追溯到可执行表演信息：可逐句括注，也可在本场开头显式声明角色表演基线、适用镜号或台词范围，以及“未另标者继承本场基线”。情绪、关系目的、可听语气或声源变化处单独标注；跨场不自动继承。声源位置不等于表演状态，O.S. / V.O. 只说明声源，不能代替表演。承重转折再展开完整情绪合同。详细格式见[对白与表演方法](#人物声音与当场演法)。剧本负责锁定因果和可表演证据，`laohu-audio-design`与`laohu-video-prompt`只能深化声音、面部、身体和时间相位，不能第一次发明人物为什么变、何时变。

已有长期人物资产时，必须读取权威来源，不能只携带“温柔、调皮、小恶魔”等抽象性格标签就开始写。标签只能约束方向，已确认的真实原话才能校准这个人的句子长度、直接程度、调侃对象和什么地方不解释。人物切换关系状态时，只调用对应关系的样本，不把对外礼貌腔移植到私下斗嘴，也不把私下攻击性扩展给陌生人。

正式交接时把已经定稿、下游不得改写的台词 / OS / VO 明确标为`冻结台词`，并交给`laohu-audio-design`编译自然语言音色描述、当场演法和可生成音频任务。音频设计可以为稳定发音而建立可读规整文本，但不能改变原句语义、人物策略和关系后果。

口头禅、方言词和金句都不能单独证明人物。强表达至少要暴露一项只属于此人的感知、判断、回避、愿望或行动策略，并回到`感知证据 → 人物解释 → 当场行动 → 可见后果`。详细方法只在人物声音、台词、OS、VO、方言或文学样章承重时读取[对白与表演方法](#人物声音与当场演法)。

```text
写出第一反应
→ 把它当作平均值候选
→ 从人物立场、关系命名、动作证据、声音节奏和留白生成不同方向
→ 淘汰换到同题材另一篇仍成立的句子
→ 真人朗读
→ 只保留这个人物在这个处境里会说、也说得出口的话
```

### 情绪进入戏的条件

情绪也受这条箴言裁决。`愤怒、委屈、声音放低、笑意发虚`都只是标签或表面结果；只有压力改变了人物想保住什么、怎样对待关系对象、在哪个触发后露出破绽并作出下一选择，情绪才真正进入戏。
