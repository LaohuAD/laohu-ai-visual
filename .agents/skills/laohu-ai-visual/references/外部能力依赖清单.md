# 外部能力依赖清单

本文件登记项目运行时直接调用的外部 Skill，以及它进入本地流程后的适配关系。外部资料、GitHub 案例和专业理论如果只被提炼成知识，不属于运行时依赖，由对应 Reference 记录来源与吸收边界。

## 依赖箴言

### 外来的能力要留来路，本地的判断要有归处

外部原文负责保留方法原貌，本地适配负责决定何时调用、保护什么、怎样进入当前生产链。二者必须清楚区分，也不能只留下简称让后续模型猜测。完整原文快照保持不变；经老胡明确要求进行保真整理的适配稿，可以在同一入口保留可独立校验的原文块并标明本地说明，不能将改写内容冒充原文。

## 依赖类型

| 类型 | 含义 | 项目要求 |
|---|---|---|
| 外部运行时 Skill | 当前流程会直接读取并使用其原始方法 | 必须登记原始名称、包内原文、本地适配层、调用者、返回负责人和失效处理 |
| 外部知识来源 | 只吸收机制、事实、案例或校准视角 | 在对应 Reference 记录仓库、提交、证据边界和反复制边界，不作为独立 Skill 调用 |
| 本地模板与脚本 | 本项目自己维护的执行资产 | 由唯一负责 Skill 路由，并通过路径或机械测试验证 |

不得把外部知识来源误写成运行时 Skill，也不得把外部运行时 Skill 悄悄改写成本项目原创能力。

## EXT-SKILL-001：vibe-creating-prompt

### 身份

- 外部原始名称：vibe-creating-prompt。
- 项目简称：VC，即 Vibe Creating。
- 依赖类型：外部运行时 Skill。
- 原作者与公开来源地址：当前项目历史没有保存，暂记“来源信息缺失”，不得自行补写或猜测。
- 首次进入当前仓库：Git 提交 2a8139c，日期 2026-06-22。

### 文件职责

视频包持有唯一维护的[外部完整原文](内置方法/laohu-video-prompt/skills/laohu-vibe-creating-prompt/references/01_外部Vibe_Creating原文.md)和[本地适配方法](内置方法/laohu-video-prompt/skills/laohu-vibe-creating-prompt/专业方法.md)。这里的链接指向总控包内实际保存的受控方法，供独立总控理解及复验；日常维护仍由视频专业负责，同轮同步正文。视频包自己就带有完整原文，本地与上传后读取同一份，不再要求另外寻找共享目录的原文或与自己比较。

本地适配层负责调用条件、拒收门、硬接口和回填；`laohu-video-prompt`负责首稿基线与VC返回后的最终复验。总控的副本只支持局部会商和复验，不另造一份正式视频提示词。

### 调用链

    laohu-video-prompt 完成可直接生成的首稿
    → laohu-vibe-creating-prompt 必须读取包内外部原文并执行 VC
    → 判断提纯、改写、零改动放行或退回
    → 本地适配层保护三段式、台词、资产、状态、字符和剪辑接口
    → VC 结果返回 laohu-video-prompt
    → laohu-video-prompt 复验并写入正式作品文件

调用者只调用本地适配层，不直接调用外部原文。外部原文给方法，本地适配层给权限和边界，视频 Skill 对最终可用性负责。

### 失效处理

出现下列任一情况，停止 VC，不得凭记忆模拟外部 Skill：

- 包内外部原文缺失、损坏或无法读取。
- 受控副本与维护者已确认的方法版本不一致。
- 本地适配层没有写清调用条件或返回负责人。
- 外部更新改变了方法，但尚未完成本项目兼容性验证。

停止 VC 后保留已经通过基线的视频提示词原稿作为排障与恢复材料，并返回 laohu-video-prompt 标记“VC 链路失败”。基础稿不能丢，但未实际完成 VC 的稿件不得冒充正式提示词或进入付费生成。

### 更新方式

外部版本确实更新时：

1. 先记录新来源、版本或提交证据。
2. 更新视频包内外部原文，保留可核验的来源与版本证据。
3. 更新使用该方法的包内受控副本。
4. 检查本地适配层是否仍能保护项目硬接口。
5. 运行外部依赖、行为场景、字符与五个包的独立性校验。
6. 验证通过后再允许 VC 进入正式生产。

## 当前审计结论

当前登记包含VC与下述编剧专业能力。VC保留完整原文并经本地适配，编剧专业按来源快照保留正文与本地前言。

未列为运行时能力的其他外部 GitHub 仓库、导演方法、摄影理论、提示词案例和研究文档属于“外部知识来源”：它们已经按机制吸收到具体 Reference，不在运行时以独立 Skill 身份调用。以后新增外部运行时 Skill，必须先登记本清单，再进入任何调用链。
