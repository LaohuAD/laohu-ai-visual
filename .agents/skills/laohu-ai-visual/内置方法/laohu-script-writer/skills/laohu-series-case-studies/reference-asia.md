## 九、坂元裕二《花束般的恋爱》：场次统计表与五年时间线

> **媒介注明：这是一部电影剧本**（2021 年 1 月 29 日上映，导演土井裕泰，主演菅田将晖、有村架纯；蕾克译，广西师大出版社·一頁 folio 2022 年 12 月版，正文 35 千字）。**没有集、没有幕、没有 act out**，不能当剧集结构范本。放进本库的理由是作者是日本最重要的电视连续剧编剧之一（《东京爱情故事》《Mother》《最高の離婚》《カルテット》《大豆田とわ子と三人の元夫》《anone》《初恋的恶魔》），而这是他"对话驱动关系剧"最浓缩可拆的样本。下文的"隐形三幕"是**按篇幅反推的推断**。

体例：场号（1–159）＋场景标题（地点／时间／"回想"）＋动作描写＋对白。年份用"字幕 '2015'（手写文字）"分章，共 7 张字幕场：1、3、76、92、112、140、153。独白写作 `绢（独白）`／`麦（独白）`（voice-over）。`*` 是场内分节符。

### 9.1 总量与长场排行

**总量**：159 场，正文有效行（含动作描写与台词，不含空行）**1822 行**，字数 35 千字，成片约 124 分钟——**平均每场 11.5 行**。**短场为主体：72 场（45%）正文 ≤5 行**；全片只有 2 场超过 100 行。

| 场 | 地点 | 行数 | 作用 |
|---|---|---|---|
| 147 | 家庭餐馆内 | **162** | 分手戏（全片 9%） |

| 121 | 四月，二人的房间（夜晚） | 71 | 大吵＋怒中求婚 |
| 52 | 连锁家庭餐馆店内（夜晚） | 54 | 告白 |

### 9.5 范例（中文译文）

**范例 1（场 2）平行对白——两桌人合说一段话**

```
麦 恋爱不能一人一半。
绢 恋爱是一人一个。
麦 一人一个。那两个人真是不懂，要不然我过去教他们一下。
　麦和绢同时站了起来。
　两人察觉到对方，四目相对，终究还是坐回了原位。
朱音 别管人家了。小麦，昨天晚上我是不是把耳环忘在你那儿了？说不定在你床上。
麦 我没看到……（有些心不在焉）
知辉 小绢，我爸妈特别烦，总想让我把你带过去介绍给他们，你说怎么办？
绢 嗯，是啊，我想……（有些心不在焉）
　绢和麦各自坐在同伴对面，心却都飞到了别处。
```

中文说明：两个人物用对方的句子接龙；新伴侣的台词全是"现实事务"（耳环、见父母），反衬这两人的"文化事务"。

**范例 2（场 47–52 摘编）交替倒计时的双独白**

```
麦（独白） 有人说，如果一起吃过三次饭还没有告白，就只能做普通朋友了。
绢（独白） 我开始焦虑了。
……
绢（独白） 离末班车时间还有八小时。
麦（独白） 从现在开始要改变气氛了。
……
绢（独白） 为什么话题越说越远？
麦（独白） 离末班车还有三小时。
……
麦（独白） 不行不行！越扯越远了。
绢（独白） 还剩两小时。
```

中文说明：两条独白轨共用一个时钟；悬念来自"双方都在倒数，互不知道"。

**范例 3（场 28）名词清单作为心跳**

```
　各自从背包口袋里拿出文库本，腼腆地互相交换。
绢 （打开麦的文库本）穗村弘的书我基本都看了。
麦 （打开绢的文库本）长岛有的书我基本上也都看了。因为没钱，都是等出了文库本才看。
绢 我也是，或者从图书馆借。
麦 作家里你还喜欢谁？
绢 我看的都很普通噢。石井慎二、堀江敏幸、柴崎友香、小山田浩子、今村夏子、圆城塔。
   当然还有小川洋子、多和田叶子、舞城王太郎、佐藤亚纪。
　麦一边听，一边赞同。忽然察觉到绢的文库本里夹着一张用过的电影票根，
　电影是《自由之丘》。
麦 啊，八谷桑你……
　绢发现的电影票根是《穿裘皮的维纳斯》。
绢 山音桑，你也是电影票书签党啊。
麦 嗯，我是电影票书签党。
```

中文说明：剧本不解释任何名字；"我看的都很普通噢"后面跟十个作家，是自嘲也是自我定位；最后落在一个物件（票根）上，比清单更有力。

**范例 4（场 13 → 31 → 150）同一句话，三个年份，三种意义**

```
［2015 一月，场 13］
麦（独白） 石头赢剪子，剪子赢布，这两步我懂。布赢石头，为什么？布包石头明明会破掉。
［同月，场 31］
绢 布怎么可能赢过石头呢？明明会破的。
麦（独白） 现在我知道有一个人，也有同样想法。
麦 （心里美滋滋）说的也对噢！
［2019 五月，分手后，场 150］
　绢和麦玩石头剪子布。绢出拳头，麦出布。
绢 你怎么出布啊！
麦 （微笑着说）因为我是成熟的大人。
```

中文说明：第一次是孤独，第二次是合拍，第三次是"我接受了规则"——不用任何解释，观众自己完成意义。同类手法还有"原句奉还"：2015 场 65 麦替绢骂面试官说"就算他职位高，这种人吧，就算看完今村夏子的《野餐》，内心也不会起波澜"；2018 场 121 这句由绢原样说回给麦，而麦只能答"我已经毫无感觉了"。

**范例 5（场 147）分手的辩论核心——"降低下限"**

```
绢 因为今天是开心的一天，所以你才会这么想。马上就会恢复原状的。
麦 恢复原状也没关系。
　绢摇头。
麦 世上的夫妇不就是这么回事吗，就算恋爱的感觉消失了……（意识到说错话）
绢 ……
麦 （却接着说下去）很多人依然维持着婚姻，对吧？……我和小绢也能……
绢 你还要降低下限？
麦 ……
绢 不断降低着感情的下限，一起过日子，认为一切就那么回事，你觉得这真的好吗？
麦 好。
绢 真的吗？
麦 如果我的感情冷却了，不正说明我已经做好了准备，能进入一段平稳的婚姻生活了吗？
```

中文说明：全片最长的一场（162 行）的论点只有一句话——要不要降低感情的下限；两人谁都没有道歉，也没有和解场面。同场用邻桌 21 岁情侣（凛与亘）的对白做镜像打断："我们终于见面了。／终于见面了。"——"对面的绢和麦，注视着已经回不去的往昔。"

**范例 6（场 11 → 149）盖棺语由对方补完**

```
［2015 一月，场 11，绢独白］
绢（独白） 2014 年的世界杯，东道主巴西队输给德国队，被灌了七个球……
　　　　　我再怎么惨，也比那会儿的巴西人强吧。嗯，我幸福多了，幸福多了。
［2019 二月，分手当夜，场 149］
绢 我总是想，我再惨，也惨不过那时的巴西队。
麦 啊……输球之后，巴西队队长儒利奥·塞萨尔接受采访时说了什么，你知道吗？
绢 啊，不知道。
麦 史无前例的惨败之后，塞萨尔接受采访时说："我们至今为止的征途无比美好，只差了最后一步。"
　两人回味着这句话，重新迈出步伐，脸上露出沉静的笑容。
```

中文说明：女主角的私人安慰句在四年后由男主角接出下半句；全片对这段关系的评价由一句引文代劳，人物不自己说。

**范例 7（场 155、159）结尾——看不见的同步**

```
［场 155 咖啡店外］
　走出店门的绢和知辉。麦和朱音。分别走向相反的方向。
　绢悄悄举起手，背到背后，挥手。
　麦悄悄举起手，背到背后，挥手。
```

### 10.5 家庭冲突网

配置法一句话：**给每个家庭成员一个与"母亲的病"完全无关的、已经在燃烧的麻烦；然后让病同时烧到这六处。**

开场时六个人各有独立困境，**没有一个是因为妈妈的病产生的**：父亲与年轻院长不和、即将退休（p0013）；妍秀与有妇之夫复合（p0020）；正秀三次复读后等放榜（p0012）；根德赌光买车钱、打妻子（p0033、p0056）；奶奶老年痴呆＋中风（p0011）；妈妈自己只想赶在入冬前搬进日山（p0019）。**病的功能不是制造冲突，而是把每条既有冲突推到必须解决的程度**：父亲被辞（p0141）、妍秀分手（p0168）、正秀许下不可能的愿（p0163）、根德开起出租（p0217）、奶奶被钉在房里又被闷（p0206、p0212）、妈妈从被照顾者变成主持者（p0176–p0188）。

### 10.6 「告别」的分配法（第七章，p0216–p0239）

| 顺序 | 对象 | 形式 | 长度 | 核心动作／道具 |
|---|---|---|---|---|
| 1 | **奶奶**（提前到第六章末，p0216–p0218） | 洗澡间内，锁门，家人在外敲门 | 长 | 亲手洗婆婆的身体、换新衣；"妈，我先走一步，您也快点来。" |
| 2 | 奶奶（再一次，p0225–p0226） | 出门前牵手，几乎无台词 | 极短 | "我，走了。""嗯……去吧。"——两个女人对视，"30 年的恩怨情仇像肥皂泡一样慢慢消失" |
| 3 | 弟妹（p0228） | 门口，交托 | 极短 | 核桃酥的袋子；"好好照顾老太太。" |
| 4 | **正秀**（p0230–p0231） | 车里，后座 | 中 | 戒指；"即使忘了妈妈的长相……也不要忘了是妈妈生了你。" |
| 5 | **妍秀**（p0232） | 车里，从背后抱住驾驶座 | 中 | 亲脸颊；"你……就是我，妈妈就是妍秀。" |

| 7 | **丈夫**（p0233–p0238） | 新家一夜：粥→洗澡→床上 | **最长** | 金箔咖啡杯；"你会想我吧？""全部。"的清单；"要是觉得我漂亮就亲我一下吧"；"仁熙啊，真的谢谢你" |

分配法的五条规律：① **最长的一场给最疏远的人**（30 年没被照顾过的妻子与不会照顾人的丈夫）；② **最短的一场给最亲的人**（奶奶的"我，走了""嗯……去吧"只有两句）；③ **有一个人必须缺席**（根德），缺席的那一场反而是最大的一次哭；④ **每场都必须交出一件东西**：戒指（儿子）、吻（女儿）、新衣（婆婆）、托嘱（弟妹）、核桃酥（弟弟，反向交付）、一句"谢谢你"（丈夫）；⑤ **最后一句不是遗言，是道谢，而且是丈夫说给妻子**（"仁熙啊，真的谢谢你"，p0238）——临终的台词权交给留下的人，不是走的人。死亡本身只有五行（p0239）。

中文说明：分手的理由是一个发现，不是一次伤害——母亲的衣柜与情妇处境重合（几天前她在情人家看见的是同样的便笺、同样叠成手掌大小的内衣、同样打好圆结的七条领带，p0084–p0087）；分手台词是四个排比的"你能吗"＋一份未来的具体幻想清单；走位本身是情绪（并肩看江，不对坐）。

**范例 5（p0230–p0232）车里，逐一告别子女**

```
"正秀啊，我是谁？"
"妈妈。"
"再叫我一次。"
"妈——妈。"
"正秀啊，你……即使忘了我，忘了妈妈的长相，忘了妈妈的笑容……
 也不要忘了是妈妈生了你。"
（妈妈摘下戴在手上的戒指，交给儿子）"这个你以后……给你老婆。"
"我是怕你忘了我才给你的。再怎么找，我能给你的也只有这个了，对不起。"
（正秀下车）
"妍秀啊，妈妈好像马上就要失去意识了，总是迷迷糊糊的。"
"妈妈很爱你，知道吧？"
"是，我也……很爱……妈妈。"
"嗯，我爱你，非常非常爱你。"
"你……就是我，妈妈就是妍秀。"
（妈妈从后面环抱住妍秀的脖子）"我善良的女儿……"
（用被泪水打湿的嘴唇亲了亲妍秀的脸颊）
```

中文说明：两场告别在同一辆车里背靠背完成，走位极其经济——儿子在后座面对面，女儿在驾驶座**背对着**（全程不用拍她的脸）；给儿子的是物（戒指）＋否定句式的遗言，给女儿的是吻＋同一性的断言；儿子的台词被压缩成一个词的重复，**最强的情绪给最少的词**。

**范例 6（p0237–p0239）日山的一夜：最后的对话与死**

```
"你……没有我也没关系吗？"……"没人再唠叨你，很好吧？"
"会想我吧？"
（父亲无法再直视妈妈，他只是点了点头）
"在什么时候？怎样的情况下？"
"全部。"
"全部是什么时候？"
"早上上班前打领带的时候。""还有呢？""喝不好喝的大酱汤的时候。"
"还有呢？""喝好喝的大酱汤的时候。""还有呢？"
"喝酒的时候，醒酒的时候，睡觉的时候，想听唠叨的时候，母亲犯糊涂的时候，
 妍秀嫁人的时候，正秀上大学的时候、毕业的时候，春节煎煎饼的时候，
 中秋节做松饼的时候，生病的时候，孤独的时候……"
"你快点来找我，不要让我一个人无聊。"
"老公，要是觉得我漂亮就亲我一下吧。"
（父亲用双手捧起妈妈的脸颊深深地吻了下去）
"仁熙啊，真的谢谢你……"
—— 次日清晨 —— "老婆。"（抱着妈妈的右臂已经感受不到任何温度）
"老婆……""仁熙啊！"
```

中文说明：用"会想我吧"→"全部"→四次"还有呢"的问答循环，把告白从一个词逼成一份十二项清单，**每一项都是家务或节气，没有一项是抽象的爱**；"喝不好喝的大酱汤的时候／喝好喝的大酱汤的时候"一句玩笑式的重复替全剧的酱缸线收束；最后的话不是"我爱你"而是"谢谢你"，且由留下的人说；死亡只用"右臂已经感受不到任何温度"一句——没有呼吸、没有心跳、没有医生、没有哭喊。全书最后一个意象是"陷入深深睡眠之中的妈妈眼角也凝结着冰冷的水汽"（p0239）：**不写死，写温度与湿度**。

后记里作为创作法则的四条原话（均出自作者后记，p0240–p0253）：

- **法则 A**：两位老人都因癌症过世，"死亡并不是可怕的事情，而是获得美丽的最后机会"。
- **法则 B**：母亲临终"没有微笑，也没有痛苦的挣扎，非常平静地离开了"；"**我们的分别不美好，也不悲伤。**"；"我并不感激您在临终前说爱我，因为我'一直'都知道您有多么爱您的小女儿熙京。"
- **法则 C**："母亲去世前，我从未想过她会成为我的遗憾。那时，我是她的遗憾。"
- **法则 E**：作者把母亲讲的"出生故事"写进后记，随后大姐告诉她那不是真的；结论是"**我们只是不能完全理解对方的心思**"——这直接解释了剧中全家人互相隐瞒的写法。
