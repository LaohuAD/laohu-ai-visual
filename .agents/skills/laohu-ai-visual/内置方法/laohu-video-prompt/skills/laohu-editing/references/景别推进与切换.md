# 景别推进与切换

> 归属：视频包剪辑专业。本模块由《《短剧短片分镜生成字段规范》（原第六章等）》按完整主题块拆出，正文信息、表述方式与信息密度未改，编号与标题层级按独立模块重新编排。

## None

切换景别时追求 `有意义的视觉变化`：

1. 同一主体、相近轴线、相近构图和同一动作相位下，从远景只切中远景、从中景只切中近景，变化太小容易像误切或跳切。
2. 此时可以跨过一个景别，例如远景切近景、中景切特写；也可以让机位相对主体改变约 30 度以上；还可以让动作相位、构图或信息目标发生明显变化。
3. `跨一个景别` 和 `30 度` 都是连续性经验，不是硬规则。相邻景别如果新增了明确证据可以使用；跳得很大但没有空间锚点、方向继承或动作匹配，同样会断裂。
4. 每次切换都回答：上一镜为什么此刻结束，下一镜新增什么，人物姿势、道具状态、屏幕方向和动作余势如何继承。

不要每个镜头都特写。连续特写会让空间断裂，也会让后期拼接困难；近景完成证据任务后，按需要重建人物与环境的空间结果。
