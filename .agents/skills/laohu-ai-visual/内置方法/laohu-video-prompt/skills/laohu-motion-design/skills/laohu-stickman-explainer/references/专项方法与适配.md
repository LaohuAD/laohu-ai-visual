# 火柴人讲解：专业方法与本地适配

来源为kaomei/stickman-video-director（来源：`https://github.com/kaomei/stickman-video-director`），提交`6d7f8c83a16c594c23bb73da832c8864ccd2aeb5`，MIT；[原始方法](upstream/原始方法.md)、完整提案、提示词合同及案例原文随本能力保存。以下为本地转译，不冒充原作者原文。

## 从一句知识到一个动画事件

1. 提取本段要让观众理解的关系及事实边界；把人、对象、变量、规则、结果一一对应。比喻映射失真时更换载体，不能补旁白为错误画面辩护。
2. 选择叙述结构：科普可用现象→条件→机制→结果→应用；励志可用困境→尝试→重新理解→行动；商业解释只采用已有证据的功能与收益。结构服务原文，不每次都插CTA。
3. 先规定初态，再设计导致理解变化的触发和结果。用角色表演、环境转换、符号、对比、路径或形变组合，所有从属动效指向同一命题。
4. 让终态有可读时间。动作密度看每次变化贡献的新信息；不按“每两秒必须变”“至少四种效果”配额塞动效。需要等待、辨认或对比的地方允许静止。
5. 结束保留下一P要继承的动作方向、对象、形状、姿势或构图锚点；发生物理空间变化仍另起P。全片视觉接续不能反向改写分段内容范围。

## 形象与画幅

默认候选为浅底深线或深底浅线，选定后锁全片。浅色纯平面方案明确均匀纯白、不带纸纹、灰底、渐变、环境投影与三维背景；纸纹或微缩纸景属于另一个已选风格，不能暗中混入。强调色默认少量（上游至多三色），每色负责稳定含义，跨段不把同一色从风险改成收益。颜色写常见词，避免技术代码被生成成画面文字。

无脸空心圆头、线条身体时用头的朝向、躯干倾斜、四肢支撑、动作停顿表达；锁定线宽和比例。穿透、肢体脱节、角色填色、突生脸部或3D渲染是此方案的偏离，非所有动画的禁令。

16:9适合横向并列、侧移和关系展开；9:16可上下分层、纵向追踪与前后遮挡，但平面图层纵深不等于强制写实3D背景；1:1缩短路径、集中主关系。换画幅时重新规划对象位置、移动路径、转场几何与后期文字安全区，不能只改比例标签。

## 旁白、文字和声音

旁白是音频，与可见文字分别设计；冻结语句逐字保留，不让模型重复念、改写或自动转成字幕。图标适合无需精确文字的通知和概念卡；公式、刻度、专名及数据有阅读任务时，保留后期文字层需求与时间、位置，不能为“无字风格”删除。独立生成时继承相同音色参考；持续旁白与音乐可在剪辑中统一铺设，不能承诺单靠重复音色描述就一致。SFX只跟可见接触、转换或强调同步，音乐不盖知识。

## 上游配置怎样进入本项目

| 上游约定 | 本地执行 |
|---|---|
| 一分钟、六段十秒、每段三个绝对时间拍 | 作为完整示例保留；内容与自然演法决定P，遵守当前4—30秒制作范围并核验实际入口 |
| 130—150词英文、默认美式女声 | 用户语言、冻结文案和音色资产优先，不自动翻译或换声 |
| 每段四种视觉手段、两三秒一次变化 | 取其避免空洞静画的目的；按解释贡献安排变化，不机械配额 |
| Omni Flash、720p、24FPS、同步音频 | 原库配置，不是本项目核验事实；目标模型按实际入口能力确定 |
| 先确认全新六幕提案 | 已授权且已定的剧本/风格直接继承；只有新的真实取舍才进入人工确认 |
| 每条重复关键锁定 | 保留独立可用性；嵌入父级三段式，不另建平行提示词格式 |

## 同构比较：瓶颈

已定命题：“其他条件不变，出口更窄会限制同时通过的人数。”候选A是小人在旁摆手、出口不断闪光；候选B保持人数、方向、行走速度不变，只缩窄出口，形成排队并在通过处短暂停留。选择B，因为画面直接隔离变量；不额外表现小人变懒或人数减少，否则会引入第二原因。若原文要求说明流体而非人流，须核对比喻适用范围，不把排队图当流体定律证据。

完整原案例含短文扩展、长文压缩、画幅转换及商业段落；仅在遇到对应问题时读[案例](upstream/references/examples.md)，以结构和关系迁移，不复制独有旁白。
