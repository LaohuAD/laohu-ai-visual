## 6. 光影画质审美特征资产

### 6.1 通用基底

高质量视频提示词的画质由风格、光影、色彩、景深、材质和运动稳定共同形成影像系统。

### 6.2 特征颗粒

```text
风格交集：
主风格母体 + 辅助风格 + 胶片 / 滤镜分级 + 明度对比 + 光影方式 + 肤色妆效 + 场景环境色。

光影分离：
亮面、半暗面、暗部细节、轮廓光、反光和背景层级分开。

动态光源：
风吹树影、火光跳动、车灯扫过、水面反光、霓虹雨地反射，有来源、有方向、有稳定运动节奏。

色彩主次：
1 个主色 + 1 个辅助色 + 1 个小面积点缀色，肤色被保护。

景深层次：
前景虚化遮挡、中景清晰主体、远景朦胧环境，焦点落点明确。

材质细节：
皮肤、发丝、衣料、木纹、金属、玻璃、纸灰、水汽和旧墙纹理可读。

运动停点：
每个情绪段或动作组只选择一至两个承重英雄帧；文戏从关系变化或表演结果中形成，武戏从蓄势、决定性接触或控场结果中形成。连接帧允许遮挡、甩镜、失衡、局部出画和方向性模糊，不能为了截图让人物一招一停。
```

### 6.3 氛围画质词汇资产

视频的氛围与画质要用中文专业词形成稳定风格交集。

```text
风格母体：
日系治愈短片、电影剧照感、纪实人像短片、青春短剧、低照度情绪片、商业人像影像。

摄影介质：
全画幅人像摄影、35mm 胶片颗粒、阿莱电影质感、手持纪实质感、长焦压缩空间。

光影方式：
窗边自然光、侧逆光、树影动态光、黄昏漫射光、海面反光、低照度局部光。

色彩影调：
清新透亮、低饱和、暖白肤色、冷灰暗部、柔和高光、明暗有层次。

空气状态：
海风水汽、窗边浮尘、雨后湿润、夜晚低照度颗粒、黄昏空气透亮。

人物材质：
白皙清透肤色、半哑光柔雾底妆、真实发丝、衣料垂坠、首饰细碎柔光、唇色纹理。
```

这些词共同决定视频的清透度、耐看度和人物情绪承载力。

### 6.4 动态光源资产

```text
树影动态光：
风吹树叶，侧逆光形成细碎树影，缓慢扫过脸侧、肩线和背景墙。

窗光变化：
窗边自然光稳定进入，薄纱窗帘轻动，亮部柔和移动，暗部保留皮肤层次。

海面反光：
海面细碎反光在脸侧或栏杆上轻轻跳动，画面保持清新透亮。

火光跳动：
火光在脸、手、墙面和道具边缘形成暖色微变化，背景暗部有层次。

车灯扫过：
远处车灯从背景掠过，短暂拉出轮廓光，随后回到低照度环境。
```

动态光源要有来源、方向、速度和作用对象。它的职责是让画面拥有稳定时间感。

### 6.5 原生直出影像链

当参考视频或关键帧未经后期调色却已经具备明确的光影、色调、肤质和镜头质感时，把它视为生成阶段完成的影像系统，不把效果归因于某个 LUT 或一句“电影感”。正式视频提示词先建立以下关系：

```text
场景与时间光源
→ 主光 / 环境光 / 分离光的方向、面积、色温与稳定性
→ 人物相对背景的曝光、对比和高光衰减
→ 皮肤、眼睛、嘴唇、发丝、衣料和首饰的局部反射
→ 背景冷暖、明度、清晰度和散景对主体的托举
→ 摄影机运动、焦点变化和人物运动中的光色连续
```

正式编译默认按 `光源 → 传播路径 / 介质 → 光的变化 → 落点材质 → 镜头可见结果` 的线性因果顺序；视频中的动态光再补充进入、移动、峰值、离开和恢复基线。详细光学机制统一执行 `画面氛围与画质规范.md` 的“光照事件链与传播路径”。只写来源而不写亮面、阴影、反射、透射、散射或色彩变化的屏幕结果，视为不完整；只写结果却无法解释来源、方向和受光对象，视为随机光效。

`【场景状态与氛围画质】` 负责写全段不变的光源基线、肤色基线、背景层次、成像介质和动态范围；`【画面内容】` 只写运动造成的变化，例如人物转头后眼神光怎样移到虹膜、发丝边缘怎样短暂变亮、背景暖色散景怎样产生视差、窗光怎样扫过衣料，以及镜头停点时哪些局部重新稳定。不要在每个镜头重复整套肤色和光影，也不能把变化交给模型自行猜。

视频验收至少检查五项：

```text
光源方向没有无因切换；
人物肤色没有随背景或镜头移动突然漂白、发灰或偏色；
眼神光、高光和阴影随头部 / 摄影机位置产生合理变化；
背景虚化、散景和反射有来源且不抢过眼睛与嘴唇；
需要截图的英雄帧中，主体边缘、眼睛、唇面和关键材质清楚稳定。
```

如果只写 `清透、柔和、治愈、电影感、原生直出`，却没有写光源、曝光、材质反射、背景分离和运动连续性，视为未完成的画质描述。
