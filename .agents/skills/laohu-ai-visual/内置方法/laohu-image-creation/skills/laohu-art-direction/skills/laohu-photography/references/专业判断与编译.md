# 摄影的判断与编译

## 专业判断

先定摄影机位置再定视角；透视由观察位置决定，不能把长焦压缩解释成焦距独自改变空间。景深同时受光圈、焦距、对焦距离与输出观看条件影响；提示词只保留能改变所需结果的控制。

曝光保护关键肤面或高光，不用过曝宣称梦幻。静态照片的拖影须有曝光期间的相对运动；视频快门风格须服从动作可读性，帧率不等于运动速度。

## 术语怎样进入选择

本专业使用：视点、焦距、视角、景深、弥散圈、曝光、运动模糊。选择术语时必须同时指出它控制的对象、产生的可见差异和失败条件；不能把整组术语并列塞进提示词。

参数堆砌互相矛盾时，以成像目标重新求解，不能同时要求全深焦和所有背景极浅虚化。

## 术语校准与旧词别名

旧稿把若干不同控制合并在一个口语词里，读到时先拆开再落决定。校准后的正式说法在前，括号内保留旧词作为检索别名，输入中仍会出现这些旧说法，不因为改名而拒读：

```text
方位 → 观察方位（旧称“方位”）：相对哪个主体的正面、侧面、背面或斜侧观看。
角度 → 俯仰与倾斜（旧称“角度”）：观察方向是平视、俯视还是仰视；画框是否倾斜需要单独说明，不合并进“角度”。
高度 → 机位高度与取景锚点（旧称“高度”）：机位高度是相对地面、桌面或主体的真实观察高度；取景锚点指本次重点落在头、手、脚、衣摆、道具等哪个可见部位。两者是两件事，不能互相顶替。
距离 → 景别与取景范围（旧称“距离”）：指主体与环境的纳入范围、哪里被裁切；真实物距与焦距按需要另写，不用“距离”一词同时表达三者。
对准、聚焦 → 观察与取景 / 光学对焦 / 语义重点：按语境分别归入构图、本专业与应用目的。
虚化 → 光学离焦 / 运动模糊 / 介质朦胧 / 后期模糊：四种机制分开写，见[对焦景深与焦外](对焦景深与焦外.md)。
景深、散景 → 清晰范围 / 焦外质感：景深是可接受清晰范围；散景只是焦外表现中的一种，不是全部“模糊”的总名。
柔光、柔焦 → 光源软硬 / 成像处理：柔光属光影；柔焦是成像或后期处理，不等同柔光。
高调、过曝 → 明调组织 / 曝光信息风险：高调是明暗组织方式，过曝是信息损失风险，两者不同。
```

光影与构图继续独立：摄影只负责光学成像与拍摄前的位置、清晰度和曝光决定，不把光源因果并入本专业，也不代替构图判断视觉落点与引导关系。这些术语变更必须与图片提示词模板、本专业入口和包内受控副本同轮更新，不留同名异义；旧词只作检索别名，不再作为正式字段名。

## 从机制到可执行描述

下例仅在对象和关系已经由输入确认时成立；换题后继承判断方法，不能借用示例中的人物、物品或事件。

> 摄影机靠近桌面，让前景杯沿明确变大；焦点落在杯后人物的眼睛，背景标牌退为不可读色块。

先比较这种处理与一项合理替代：如果替代方案更清楚地保护本次主结果，就采用替代，不为展示技法保留原案。只有一个被锁定的有效方案时，比较未锁定变量，不重开用户已确认的设计。

## 验收与修复

逐项检查输出中的对象和因果是否对应权威输入；术语能否变成可观察关系；有没有两个控制相互抵消。发现问题先改产生问题的选择，再改表达。对真实图像的判断必须读取实际结果；只有文本时只验设计与可执行性。

最终返回：视点与视角、焦点范围、曝光保护项、允许的光学痕迹。附本次采用、舍弃的关键选择及原因；未确定条件明确保留，不用推测补成事实。

## 专项深化与同素材比较

**术语与因果**：景别是对象在画框中的规模；机位决定观看位置；焦距/视场角决定纳入范围；透视主要由摄影机与对象相对位置决定，不能简写成长焦自己压缩空间。景深是可接受清晰范围，受光圈、焦距、对焦距离和观看条件等影响。曝光关系决定哪些信息落在可辨范围，焦点决定当前清晰优先对象。

**方法链**：写观看身份与必须看清的证据→定机位高度、方向与距离→选能纳入对象的视场角→定焦点及背景需要清晰到何种程度→选曝光保护项与运动清晰度→检查脸手近大远小、垂直线、空间锚点、前景遮挡→返回可见成像结果，必要才附近似焦段，不让参数取代画面描述。

**条件/反例**：浅景深适合隔离对象，不适合必须读出后景门牌、两人关系或产品前后结构的任务。缺少感光器规格时不要把焦距数字当作唯一画幅答案。

**同素材比较**：同一桌杯子和人物，A近距离广视角让杯子异常巨大；B退后、收窄视场并维持人物尺度，杯脸比例可信。若故事要求杯子在前景构成威胁，A反而有意义。
