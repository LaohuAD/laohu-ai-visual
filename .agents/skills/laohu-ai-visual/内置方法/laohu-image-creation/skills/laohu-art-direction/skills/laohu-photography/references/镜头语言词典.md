# 镜头语言词典（导航）

本词典不再是长文，只做**主题导航**：每个主题都是独立模块，图片、视频与剪辑按当前缺口进入对应模块，不整份加载。

## 基础模块（被多处调用）

- [镜头语言基础_第一判断与四件套](镜头语言基础_第一判断与四件套.md)：写任何画面内容前的总判断与四类控制杆。图片、视频与剪辑都从这里开始。
- [景别与取景范围](景别与取景范围.md)：画幅里能装多少证据、观众多近看。跨镜的推进与切换不在这里，见剪辑专业。
- [机位与俯仰角度](机位与俯仰角度.md)：从哪一侧看、平视还是俯仰、真实观察高度。
- [镜头关系与画面来源](镜头关系与画面来源.md)：主观、客观、过肩、正反打、插入、内外打的用途与写法；画面来源怎么声明。主观镜头的完整写法见视频编译。
- [光学质感与情绪反证](光学质感与情绪反证.md)：景深、光晕、介质等质感词与使用规则；用替换反证和冲突反证检验镜头手段是否真正承重。
- [构图层次](构图层次.md)：需要纵深、遮挡或关系距离时，前中后景各承担什么。
- [正反打与轴线](正反打与轴线.md)：空间连续规则与越轴过渡；跨切连续性的完整方法由视频包《镜头空间与连续性》负责。
- [镜头语言常见错误](镜头语言常见错误.md)：上列各主题最容易犯的具体错误。

## 应用模块

- 主观镜头与POV写法（视频包 `laohu-video-prompt` 的 `laohu-video-compilation`《主观镜头与POV写法》）：严格 POV 的画面来源声明、前景锚点、稳定方式、视线运动与语法检查。观看位置的判断在摄影《镜头关系与画面来源》。
