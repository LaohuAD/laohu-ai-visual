# 景别与取景范围

> 本模块由《镜头语言词典》按完整主题拆出，正文信息、表述方式与信息密度未改，编号与标题层级按独立模块重新编排。层级：**基础模块**。职责：画幅里能装多少证据、观众多近看。跨镜的推进与切换不在这里，见剪辑专业。

## 景别选择：先看画幅里要装多少证据

| 景别 | 适合任务 | 正向写法 |
|---|---|---|
| 大全景 / 远景 | 建立环境、孤独感、规模、空间方向 | 大全景完整展示整片场景，环境占画面大部分，人物只占小比例，观众先看懂位置关系 |
| 全景 | 展示全身动作、走位、跪拜、奔跑、摔倒 | 全景里主体从头到脚完整入镜，能看清动作起点、路径和落点 |
| 中全景 | 展示膝盖以上动作，兼顾少量环境 | 中全景保留人物腿部方向和上身动作，背景给出门框、桌边或路口位置 |
| 中景 | 对话、递物、推拉、家庭生活动作 | 中景聚焦腰部以上和手部动作，能看清人物距离和物件交互 |
| 中近景 | 对话和轻微表情、肩膀和手部反应 | 中近景拍胸口以上，眼神、嘴角、下颌、肩膀和手部局部都清楚 |
| 近景 | 表情证据、手部证据、关键道具 | 近景让脸、手、碗、外套、木轮、硬币等关键细节成为画面中心 |
| 特写 / 极致特写 | 情绪爆点、局部物证、动作触发点 | 特写只保留眼睛、嘴角、指尖、针脚、火苗、硬币、布纹等单一重点 |
| 微距 / 大特写 | 材质纹路、金属划痕、水珠、纤维 | 微距让纹理和反光成为画面信息，背景大幅虚化，只服务强证据或强情绪 |

景别要和时长匹配。远景需要时间让观众看懂空间；特写需要时间让观众看清细节和情绪。一个镜头如果同时要空间、动作、表情和转场，通常要拆镜头或用清晰的景别变化，不要把所有任务塞进一个模糊中景。

## 特写进与注意力控制

特写不是“把东西拍大”这么简单，而是导演强制观众先看某个局部。它的核心作用是控制信息量：先不给全局，只给眼睛、嘴角、手指、汗珠、刀尖、门锁、纸灰、手机震动、杯沿裂纹、硬币反光、药瓶标签、合同签名、红灯倒影等局部证据，让观众产生“这是什么、谁在场、接下来会发生什么”的期待。

全景开场擅长交代空间，但风险是观众一眼看完人物关系和场面规模，悬念提前死掉，画面像监控录像。短剧、悬疑、审问、背叛、冲突、恐怖、情绪爆点、关系反转和开场钩子，不能默认用全景开局；要先判断是否需要“特写进”。

```text
特写进判断：
1. 本场是否需要在 1-3 秒内抓住注意力？
2. 全景是否会过早暴露剧情答案、角色关系或下一步动作？
3. 是否有一个局部证据能代表危险、欲望、秘密、压力或情绪？
4. 特写之后是否有明确的揭示路径：局部特写 → 反应脸 / 关键动作 → 空间揭示？
```

常用特写进结构：

```text
局部证据特写：先拍门锁转动、手指颤抖、杯沿裂纹、合同签名、血迹边缘、手机来电、药瓶标签。
情绪证据特写：先拍眼睑压住、瞳孔停住、嘴角抽动、下巴发颤、泪水在下眼睑积起。
物件威胁特写：先拍刀尖、绳结、录音笔红点、审讯灯反光、烟灰落下、文件袋封口。
身体压力特写：先拍指节发白、喉结吞咽、后颈汗、鞋尖停住、手背青筋、呼吸把衣领轻轻顶起。
环境异常特写：先拍灯管频闪、窗帘缝隙、门缝冷光、地面积水波纹、火苗突然压低。
```

特写进要和“揭示”绑定，不能只是漂亮局部。正确写法是让观众从局部推测全局，再逐步揭示场面：

```text
0-1.5秒：极近特写，审讯灯反光落在一滴汗上，汗珠沿脸侧慢慢滑下。
1.5-3秒：镜头轻微拉开到嘴角和下巴，角色咬紧牙，呼吸短促。
3-5秒：镜头继续拉到中近景，桌对面的黑影、录音笔红点和压在桌上的文件袋进入画面。
```

错误写法：

```text
全景展示审讯室，背叛者坐在椅子上，审讯者站在对面，气氛紧张。
```

这种写法虽然信息完整，但太早把“谁在哪干什么”交代完，观众没有猜测空间。正确写法是先把注意力钉在局部证据上：

```text
镜头从极近特写开始，录音笔红点在黑暗桌面上一闪一闪，旁边一只手的指节慢慢攥白；头顶审讯灯只照亮半张下巴和不断吞咽的喉结。第 3 秒镜头缓慢后拉，桌面文件袋、椅背轮廓和对面站着的人影才逐步进入画面。
```

## 特写作为蒙太奇连接器

特写还能当剪辑连接器。它的价值不是解释时间，而是用局部状态变化让观众自己感到时间过去了、事情变坏了或心理被吞掉了。

相似转场特写蒙太奇适合压缩时间。用同类物件的连续变化代替“过了很久”的说明：

```text
咖啡杯液面从满到空 → 杯沿咖啡渍变深 → 桌上便利贴越来越密 → 键盘缝隙落满碎屑 → 台灯从暖亮变成冷白闪烁。
```

正式提示词写法：

```text
一组 6 秒特写蒙太奇：第一格是干净桌面上满杯咖啡的俯拍特写；第二格匹配到同一位置的空杯，杯沿留下深色咖啡渍；第三格同样构图里便利贴贴满桌角；第四格键盘缝隙出现面包屑和纸团；第五格台灯冷白光轻微频闪，人物手背伏在桌面边缘不动。每个特写用相似构图和同一桌面边线连接，不需要字幕说明时间。
```

联想蒙太奇特写适合心理暗示。用抽象物理过程替代直白心理台词，例如吞噬、震荡、溶解、挤压、断裂、污染、失控、坠落、烧尽。它不是乱插意象，而是让意象和人物处境有共同结构：

```text
资本做局：墨水扩散吞掉白纸边缘、玻璃杯里的水旋成漩涡、棋子被阴影盖住、合同页角被手指压皱。
愧疚恐慌：水面细纹震荡、灰尘在强光里剧烈翻涌、灯丝忽明忽暗、玻璃反射里脸被撕成碎片。
关系崩塌：海面反光被树影切碎、项链吊坠在胸口快速晃停、唇色变淡、泪痕把柔雾底妆划开一道细线。
```

联想蒙太奇必须写清现实层和意象层的关系，不要把意象写成无来源的高级感装饰。正确顺序是：

```text
现实触发 → 抽象特写意象 → 回到人物反应 / 当前物件结果。
```

例如：

```text
男声说完“滚”后，镜头不立刻全景解释，先切到脸侧泪痕极近特写，柔金树影在泪痕上断成几段；下一瞬匹配切到远处海面反光被树影切碎，海风声短暂放大；再切回林栀眼神彻底失焦的近景。海面不是空镜装饰，而是她内心被切碎的视觉回声。
```

## 信息留白、局部遮蔽与观众补完

留白不只有画面空白。空间留白是画面里空出来的天空、海面、墙面、暗部、雾气、窗外虚景和负空间；信息留白是关键内容没有一次给满，例如只露半张侧脸、嘴唇和下颌、手指和戒指、耳坠和锁骨、发丝遮住一只眼、门缝里只露局部、背影只回头一点点。

信息留白的核心不是少拍，而是让观众补完。完整脸部让观众确认人物长相；半张脸、侧脸轮廓、唇峰、鼻梁、耳坠、手部和发丝遮挡，会让观众主动想象完整人物、关系和情绪。它适合人物第一眼、开场钩子、封面、暧昧、危险、身份悬念、不可接近感和高级氛围。

使用信息留白前先判断镜头任务：

```text
适合：神秘、诱惑、危险、身份未揭示、人物第一眼、封面壁纸、心理暗示、关系暧昧、观众需要继续猜。
不适合：情绪高潮、落泪、争吵、台词反应、关键表情证据、道具操作、动作因果、身份必须确认。
```

正式写法必须说明四件事：

```text
遮住哪里：发丝、树影、门框、窗帘、暗部、烟雾、玻璃反光遮住脸的哪一侧或哪个局部。
露出哪里：眼睛、嘴角、唇峰、鼻梁、下颌线、耳坠、项链、锁骨、手指或道具边缘。
光勾哪里：侧逆光、轮廓光、窗光或水面反光勾出哪条轮廓。
留白在哪：天空、海面、墙面、暗部或负空间占画面哪一侧，服务视线方向和情绪。
```

错误写法：

```text
美女很神秘，画面留白多，有高级感。
```

正确写法：

```text
胸部以上近景，人物位于左侧三分线，只露右半张侧脸；前景发丝和树影遮住左眼区域，金色侧逆光勾出鼻梁、唇峰、耳坠和下颌线。右侧海面负空间占画面约 45%，背景散景柔和，观众只能通过嘴角和耳坠轻晃判断她的情绪。
```

边界：信息留白不能偷掉表演。如果镜头任务是被击穿、落泪、愤怒、争吵或台词反应，遮蔽只能短暂出现，关键停点必须让眼神、眼眶、嘴角、下巴和呼吸清楚。

## 景别写法对照表

| 类型 | 用途 | 中文提示词写法 |
|---|---|---|
| 大远景 | 展示世界观和环境规模 | 展示整条街道、院子全貌或远处城市轮廓，人物只占画面很小一部分 |
| 远景 | 建立空间和人物位置 | 人物完整入画，能看清人物和院门、桌子、床、灶台的位置关系 |
| 全景 | 展示人物全身动作 | 主体完整入画，能看到走位、推拉、坐下、跪拜、奔跑方向 |
| 中景 | 展示身体动作和关系 | 拍人物腰部以上、手部动作、递物、阻拦、父子距离 |
| 中近景 | 对话和轻表情 | 拍胸口以上，能看到眼神、嘴角、手部局部和身体距离 |
| 近景 | 展示表情和局部动作 | 拍面部、手部、袖口、碗、外套、木轮、硬币等关键细节 |
| 特写 | 强化道具或情绪证据 | 拍眼睛、嘴角、针脚、硬币、药碗、打火机、木轮 |
| 大特写 | 极强情绪或物件触发 | 只拍眼眶水光、指尖发抖、火苗被风吹灭、硬币被汤圆皮包住 |

## 视频分镜的景别证据容量与协作

> 来自《短剧短片分镜生成字段规范》（原第六章等），正文未改。

## 六、景别推进原则

景别首先控制观众能同时读到多少证据，不是给情绪贴固定标签：

| 景别 | 优先承载的可见证据 |
|---|---|
| 远景 / 大全景 | 环境尺度、群体阵形、危险来路、出口、位移范围、破坏规模 |
| 全景 / 中远景 | 完整身体力学、步法、武器轨迹、双方距离、受力位移、环境反馈 |
| 中景 / 中近景 | 人物关系、攻防关系、重心变化、上半身动作与较明显表情 |
| 近景 / 特写 | 手部承重、兵器接触、呼吸、眼神、面部控制、关键道具状态 |
| 大特写 / 极端特写 | 一个决定性局部，例如指节失力、剑身弯曲、瞳孔反应或机关启动 |

这些只是证据容量，不是固定情绪映射。远景可以通过人物被空间吞没制造孤独，也可以通过出口打开制造释放；特写可以压迫，也可以平静。先问本镜需要观众看清什么，再由人物处境、观看距离、焦点、运动、声音和主情绪决定具体效果。

多人合击、力量反转和大型破坏通常需要景别协作：先用较远景别建立攻击几何与力量来路，再用较近景别提清接触点、支撑、手部或表情，最后回到较远景别展示压退、震开、脱困、倒塌或冲击范围。不是每段都必须三镜，但如果只用中远景从头拍到尾，常会既看不清接触细节，也感受不到完整结果。

## 动作与合击中的景别证据尺寸

> 来自《模板_视频提示词_基础设定氛围画面内容》，正文未改。

景别按证据尺寸选择：远景 / 大全景交代环境尺度、群体阵形、危险来路和结果范围；全景 / 中远景展示完整身体、步法、兵器轨迹和位移；中景 / 中近景展示攻防关系、重心与上半身表演；近景 / 特写展示接触点、手部、呼吸、眼神和表情；大特写只承载单一关键细节。多人合击可按 `较远景别建立几何 → 较近景别提清接触 / 支撑 / 表情 → 较远景别兑现位移与结果` 组织。切同一主体时，相邻景别若轴线、构图和动作相位近似，优先跨过一个景别或改变约 30 度机位；这只是连续性经验，有明确动作、信息或构图变化时可使用相邻景别。
