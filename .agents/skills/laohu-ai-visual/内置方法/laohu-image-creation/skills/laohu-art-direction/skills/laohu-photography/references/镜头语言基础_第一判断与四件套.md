# 镜头语言基础_第一判断与四件套

> 本模块由《镜头语言词典》按完整主题拆出，正文信息、表述方式与信息密度未改，编号与标题层级按独立模块重新编排。层级：**基础模块**。职责：写任何画面内容前的总判断与四类控制杆。图片、视频与剪辑都从这里开始。

## 第一判断：写画面内容前先定三件事

写 `【画面内容】` 前，先确定 `主观看任务 + 主注意力目标 + 主情绪目标`，再从下列控制杆中选择真正承重的部分。复杂空间、多人互动或连续动作可以多选；简单特写、空镜和功能镜头只写足生成与理解所需信息，不为完整而补齐所有项：

```text
画面来源：画面来自某个人眼前所见、旁观者、贴近某人肩后、桌面 / 物件视角，还是被某个动作带着走。
观众站位 / 空间侧：画面从门内还是门外成立，从人物左侧还是右侧成立，从桌子哪一边成立，从车内前后排哪个位置成立。
镜头关系：主观镜头 / 客观镜头 / 过肩镜头 / 正反打 / 反应镜头 / 插入镜头 / 内打外 / 外打内。
画面层次：需要空间因果或纵深时，前景、中景、背景分别承担什么；不需要时可以平面化、无前景或只保留一个背景块面。
视觉落点：观众第一眼被哪个点锁住；主体靠面积、亮度、颜色、清晰度、反差、位置还是运动成为第一注意力。
视觉导引：有没有栏杆、道路、桌沿、窗框、光束、阴影、人物视线、手臂方向或群体朝向把视线带到主体。
空间块面：天空、海面、墙面、暗部、虚化背景、雾气、草坡、石墙或门洞阴影如何切割空间、压住杂质和形成留白。
视线与轴线：谁看谁，谁在画面左边或右边，动作从哪边往哪边走。
可见证据：观众凭什么知道这是这个人的视角、这个空间、这个情绪。
```

被选中的控制杆必须具体到屏幕结果。真正需要避免的不是“字段没填满”，而是承担镜头任务的信息仍交给模型随机补全，例如 POV 没有画面来源、交互动作没有位置关系、切镜没有新注意力目标。没有承担职责的控制杆可以省略。

## 四件套总纲：四类开放控制杆

镜头语言不是把专业词堆到提示词里。景别、机位、运镜和光学质感是四类开放控制杆，不是每镜四项必填；先用下面的问题判断哪一类真正改变观众感受：

```text
景别：画面需要容纳多少信息，是空间关系、完整动作、人物互动、表情，还是局部证据？
机位：观众站在什么高度和方向看，这会怎样改变尺度、距离、遮挡、力量关系和信息范围？
运镜：镜头是否移动，移动从哪里开始、朝哪里去、经过什么、停在哪里？
光学质感：景深、焦段、前景虚化、光晕、胶片 / DV 质感如何服务情绪？
```

写正式视频提示词时，先完成四类判断，但只把被选中的控制杆落进正文。固定机位不必硬写运镜，清楚的自然景深不必硬写焦段，简单脸部特写不必补完整空间层次。不要把 `大全景、低角度、环绕、浅景深、镜头光晕` 当成万能高级词；如果解释不出它解决什么观看问题、怎样加强主情绪，就不要写。
