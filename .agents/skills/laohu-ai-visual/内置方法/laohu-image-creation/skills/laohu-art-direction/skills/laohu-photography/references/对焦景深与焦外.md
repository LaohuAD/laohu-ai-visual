# 对焦、景深与焦外

> 归属：本文件是对焦对象、清晰范围与焦外表现的专业负责人，供图片摄影、静物、人像、视觉资产与视频首帧共同读取。`专业判断与编译.md` 保留综合判断与同素材比较，本文件只把其中“焦点—清晰范围—焦外”这一组决定展开到可执行程度。不重复构图的位置、比例与遮挡判断。

## 一、三项决定必须分开

同一个“虚化”口令下面压着四个不同机制，写提示词前先分辨是哪一种，否则模型会把它们合成同一种模糊：

```text
光学离焦：对焦对象之外的东西落在可接受清晰范围以外，是镜头成像结果。
运动模糊：曝光期间被摄对象或摄影机相对移动造成，与是否对焦无关。
介质朦胧：雾、烟、水汽、雨、扬尘、玻璃反光把光散开，远山朦胧不等于离焦。
后期模糊：图层模糊、高斯模糊、降噪磨皮，是后期处理结果，不产生真实焦外结构。
```

四项可以共存，但必须分别说明原因。把雾写成“背景虚化”、把运动拖影写成“失焦”、把界面高斯模糊写成“浅景深”，都属于把不同机制挤进同一个词；反过来，“虚化”单独出现时，不构成可执行指令。

## 二、对焦对象与清晰优先级

先回答“观众这一刻必须看清哪一个对象、哪一处证据”，再决定焦点落在哪里。

```text
唯一主对焦对象：只有一处最重要的证据时，把焦点写死在它上面，并写清它相对摄影机的深度位置。
主次双对象：主对象保持清楚、次对象允许退到可辨认或轮廓程度时，写明各自允许的清晰等级。
冲突对象：两个都在不同深度且都要求完全清楚时，先判断故事是否真的同时需要；不成立就返回构图或应用目的，重新分配取景。
```

“对准、聚焦”在本项目分三种含义，读到时先归位：

```text
观察与取景（构图）：观众第一眼被安排看哪里，属于位置、面积、亮度与遮挡，不是光学对焦。
光学对焦（本专业）：哪一层落在可接受清晰范围内。
语义重点（应用目的）：卖点、主角、证据需要被强调；它可以用光学对焦实现，也可以用构图、光影、色彩或信息设计实现。
```

对应关系：语义重点不等于光学对焦。用户说“聚焦卖点”时，默认先按语义重点处理，只有在确实需要光学手段时才落到本专业的对焦对象。把“聚焦”一律翻译成“眼睛对焦”或“主体对焦”，是常见误判。

对焦对象必须落到可见部位或物件，而不是笼统的“主体”：眼睛、指尖与杯柄的接触处、门锁、铭牌、针脚、屏幕文字、产品结构接缝都可以；写“人物清楚”在多人或前后景同框时不足以执行。

## 三、景深与清晰范围

景深是可接受清晰范围，不是“背景糊不糊”的开关。它同时受对焦距离、视场角（焦距）与成像条件影响；缺少真实感光器规格时不写毫米数，只写范围结果。

```text
浅景深：只有一层清楚。适合把主证据从环境中隔离出来，例如表情、手部、单一物件特写。
深景深：前景到背景都可读。适合空间关系、群像、多人关系、产品前后结构、场景资产一致性、铭牌与门牌必须读出的任务。
选择性对焦：同框内指定某一侧或某一层清楚，其余退出清晰范围；常与前景遮挡配合。
前后都清楚：同一画面里前后多个对象都需要辨认时，写明方位、大致深度和必须可辨的信息量。
```

写清楚范围至少要能回答三件事：哪一个对象必须完全清楚；哪些层允许退到可辨认；哪些层可以完全成为色块或纹理。

同一区域不能同时要求极强失焦和完全清楚。出现这种要求时，先判断是不是把两组不同深度的对象错误地压在同一个取景里；成立就返回构图或应用目的重新分配，不把两个矛盾条件一起写进正文。

## 四、前景虚化与背景虚化

前景虚化和背景虚化是两种不同用途，不能互相顶替。

```text
前景虚化 / 前景遮挡：制造层次、观看位置证明或视线框。前景物的选择与位置由构图决定，本专业只决定它失焦到什么程度、是否仍能辨认材质或颜色。
背景虚化：把主对象从环境中拉出来。必须同时说明背景里哪些信息仍然要可辨，例如门牌、招牌、人群数量、战场残局、天气、房间陈设。
```

前景虚化不是“自动加一层树叶”。前景必须是本次画面真正需要的遮挡物或视点证据；把无关物件塞进前景只降低可读性。

**反例（必须保留）**：浅景深适合隔离对象，但不适合必须读出后景门牌、两人关系或产品前后结构的任务。把“用浅景深突出主体”当作通用规则，并在后景放了必须可读的铭牌、价格、路牌或说明文字，是把两组要求写成了互相抵消的条件。

## 五、焦外表现

焦外表现描述清晰范围之外的呈现方式，不等于“模糊”这个总名。散景（焦外质感）只是焦外表现中的一种，指失焦点光源、高光边缘与色彩呈现出来的形状和质感。

需要写焦外时，至少写清三件事：

```text
哪些层退出清晰范围：前景、背景，还是两者。
退出的程度：仍可辨认轮廓 / 只能读出颜色块 / 完全不承载信息。
焦外的呈现特征：光点是否成柔和圆点、有无边缘亮度、是否出现方向性拉伸、颜色是否互相渗透、是否保留材质轮廓。
```

焦外不能被用来消除本来必须交代的信息。背景里有支持剧情理解的对象时，先用景深和构图保证它可辨，再调整焦外质感。

夜间或逆光场景中，焦外光点的形状会被光圈结构影响；没有真实镜头条件时不写具体叶片数与形状名称，只写观众看到的呈现结果。

## 六、不归本专业的相邻情况

出现以下需求时，先判归属，不要在本专业补一个不存在的机制：

| 需求 | 主责 |
|---|---|
| 杯子清楚转到眼睛清楚 | 视频——拉焦（对焦对象随时间变化，不必移动摄影机） |
| 主体移动但一直清楚 | 视频——跟焦（与跟拍分开，跟拍是摄影机位移） |
| 快速动作拖影 | 运动成像——曝光期间的相对运动，不是离焦 |
| 雾中的远山朦胧 | 场景与光影——大气介质，可与景深共存 |
| 界面背景高斯模糊 | 合成与图像编辑——图层模糊，不强加实体镜头参数 |
| 聚焦某个卖点 | 应用目的＋构图＋信息设计——是注意力分配，不是光学对焦 |
| 光源看起来柔 | 光影——光源软硬；柔光不等于柔焦 |
| 画面整体偏亮 | 光影与曝光——明调组织与曝光信息风险分开，高调不等于过曝 |

## 七、验收与返回

提交前逐项检查：

```text
对焦对象是否落到可见部位或物件，而不是“主体”一类笼统说法。
清晰范围是否写明三层状态：必须清楚 / 允许可辨 / 可以完全退出。
焦外是否只描述呈现，没有偷偷承担必须交代的信息。
是否把离焦、运动模糊、介质朦胧、后期模糊写成了同一件事。
是否同时要求了互相抵消的两个清晰条件。
缺少感光器规格时是否避开了毫米数。
```

发现问题先改产生问题的选择（取景、深度分配、对焦对象），再改表达。对真实图片的判断必须读取实际结果；只有文本时只验设计与可执行性。

最终返回：对焦对象、清晰范围、焦外表现三项决定，附本次采用与舍弃的关键选择及原因；未确定条件明确保留，不用推测补成事实。
