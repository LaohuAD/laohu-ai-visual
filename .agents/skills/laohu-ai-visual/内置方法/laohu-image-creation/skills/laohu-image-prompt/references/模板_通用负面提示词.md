# 模板：通用质量边界

> 本文件不再作为正式提示词的默认负面提示词模板。正式模型正文优先写正向目标结果：画面里出现什么、动作如何发生、光影如何塑形、声音如何进入、停点是什么。
>
> 本文件只在平台确实提供负面提示词栏、且需要补充抽象质量边界时使用。不要在负面栏里写当前画面不该出现的具体视觉对象，避免模型把它们当成候选元素。

## 使用原则

```text
正向正文负责生成目标。
质量边界只负责抽象技术稳定。
剧情风险、混用风险和不该继承的具体对象，写在代码块外的验收标准 / 不能继承 / 复盘说明里。
```

## 视频通用质量边界

```text
身份稳定，服装稳定，时代稳定，动作自然，构图清楚，主体不漂移，镜头停点稳定，无随机字幕，无水印，无比例畸形，无身份漂移，无动作逻辑混乱。
```

## 人物表演质量边界

```text
五官稳定，眼神有焦点，表情符合当前关系和台词，眨眼自然，脸部不变形，情绪强度不过度夸张，声音和表情状态一致。
```

## 动作镜头质量边界

```text
动作的力量来源、路径、接触点和结果清楚；主体可见度、运动模糊、镜头晃动与停帧只按本镜动作任务控制。
```

## 画面质感质量边界

```text
材质真实，边缘清楚，光源方向稳定，暗部保留细节，色彩主次稳定，画面干净，无随机文字，无压缩糊块，无塑料质感。
```
