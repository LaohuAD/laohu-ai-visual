# 文化素材事实与视觉基因转译

当任务涉及传统图像、建筑、服饰、器物、纹样、非遗材料、文化摄影、商业文化再设计、展览海报、文化品牌 KV、出版物封面或用户提供版式参考时读取。普通短视频封面、纯原创剧情海报和没有文化来源的产品主视觉不调用；只有颜色、材质或年代感变化而没有文化事实与来源判断时，也不强行调用。

本 Reference 解决的是“文化如何成为现代视觉系统”，不是规定藏地、东方、黑金、巨型汉字或 3:4 版式。它与封面主体的分工是：`laohu-cover-design` 负责点击承诺、标题、主视觉和比例自适应；本 Reference 负责文化事实、来源风险、转译机制、视觉基因、版式方法和文字可信度。

## 一、底层转译链

文化海报不能从“某某文化风格”直接跳到提示词。先执行：

```text
材料导入
→ 来源与角色分层
→ 可观察事实记录
→ 敏感元素隔离
→ 二创 / 版式方法拆解
→ 视觉基因提取
→ 任务与受众路由
→ 主视觉与字体系统设计
→ 素材职责绑定
→ 紧凑提示词编译
→ 来源、文字和原创边界复核
```

底层原则是：文化负责提供内在依据，当代视觉负责最终表达。合格结果应让观众感到“它来自某种真实材料与生活经验”，但不能看出在复制某一张源图、某一套商业海报或某个宗教对象。

## 二、材料分层与事实卡

同一文件夹里的图不能默认属于同一种证据。内部至少分成：

| 类型 | 能证明什么 | 不能证明什么 |
|---|---|---|
| `RAW` 原始现实资料 | 现实中的建筑、人物、材料、器物和环境外观 | 不能自动证明文化含义或商用授权 |
| `TRD` 传统 / 历史资料 | 可观察的传统造型、工艺、图像和材料关系 | 不能把未知符号解释成吉祥寓意 |
| `SEC` 当代二创资料 | 当代重排、抽象、品牌化和视觉加工方法 | 不能当作传统事实 |
| `COM` 商业案例 | 品牌语气、版式、产品摄影和转化方法 | 不能复制品牌识别或当作文化来源 |
| `LAY` 版式参考 | 分区、裁切、文字密度、视觉层级和阅读路径 | 不能照搬坐标、文案和独特组合 |
| `UNC` 来源不明 | 只能作为待核实的形式参考 | 不得当作事实或自动进入商业交付 |

核心素材先写事实卡，只记录镜头或图片可以直接观察的内容：

```text
编号：
来源类型：RAW / TRD / SEC / COM / LAY / UNC
对象：人物 / 建筑 / 器物 / 材料 / 文字 / 图像 / 版式
可观察事实：形状、比例、颜色、光线、材料、结构、位置、重复和缺口
可提取关系：连续 / 间断、重 / 轻、密 / 疏、实 / 虚、开 / 合、粗 / 细、冷 / 暖
视觉角色：主视觉 / 局部细节 / 背景 / 色彩 / 肌理 / 构图 / 字体 / 方法参考 / 排除
风险等级：L1 可自由转译 / L2 先抽象 / L3 先核实 / L4 不自动使用
可信度与来源备注：
```

事实卡与审美判断分开。`红褐色大墙面、深窗洞、白色水平分层、粗粝表面` 是事实；`神秘、自由、治愈、高级` 是解释或营销判断，不能代替事实。事实不足时降低断言，不要让模型替材料编造历史、民族、宗教或地域含义。

素材数量达到 10 张以上时建立文字索引再选择；达到 30 张以上时额外区分核心、辅助、来源不确定和敏感 / 排除材料。当前项目默认文本交付，索引可以是结果文件中的表格，不为了模仿外部工具强建联系表图片、CSV 或新作品目录。原始文件名、路径和用户提供的编号必须保留，系统编号只为交接服务。

## 三、敏感元素隔离

默认单独隔离下列内容：未知经文、咒语、整段宗教文字、完整神像或唐卡、宗教核心符号、完整法器、未知图腾、仪式动作和无法确认用途的圣物。风险等级只决定处理方式，不替人工核验作结论：

```text
L1：可用于构图、色彩、材质和空间关系。
L2：只提取比例、结构、节奏、肌理或负空间，不复制完整原形。
L3：先确认含义、语境、使用权限和商用边界，再决定是否出现。
L4：不自动进入商业海报、品牌 KV、封面或广告。
```

未知文字不能因为字形漂亮就当作装饰纹样。需要文化层时，优先用已确认的短文本、空白、边注或结构化图形；没有准确原文就不让模型随机生成经文、藏文、古文字、日期、地点和品牌口号。文化真实性与文字准确性是两道不同的门，不能用“看起来像”互相替代。

商业任务还要检查来源授权、人物肖像、第三方品牌、宗教使用、民族身份表达和可能的刻板化。只改名称不等于原创；人物服饰、构图组合、标志性器物、字体轮廓和广告语的独特组合也需要重新设计。

## 四、视觉基因而非文化符号

视觉基因必须能从具体材料中追溯出来，同时可以被替换到另一种人物、产品、地域或题材而不依赖原符号。提取时至少从六个维度中选择真正承重的部分：

```text
构图：大面与小焦点、偏心、上重下空、窗口嵌套、局部放大、图文分界。
图形：环带、切片、串联、垂落、断边、模块堆叠、重复节奏、边界收分。
色彩：对象色、材料色、光源色、暗部关系、局部强调和颜色面积，不固定色板。
字体：字重对比、字面比例、横竖方向、断行节奏、标题与图像的前后关系。
图像：人物与环境尺度、建筑局部、器物细节、手与材料、传统图像的局部裁切。
材料：墙面粗粝、金属氧化、织物经纬、纸张纤维、旧印刷网点、矿物颜料、手工边缘。
```

文化不是把某个图腾贴到背景上。观察材料的结构如何决定阅读路径，再把结构转译成当代设计：刺绣可以提供线密度、缝线方向或局部织物细节；木版印刷可以提供墨边、套色偏差和大色块；建筑工艺可以提供构件模块、尺度关系和结构线；园林与奇石可以提供框景、孔洞、虚实和负空间。它们只是“从材料观察到视觉机制”的例子，不是不同文化可以互相替换的固定寓意。

每个项目只选 2-4 个视觉基因作为主机制，其他材料退到辅助层。若把颜色、纹样、建筑、人物、宗教文字、器物、纹理和五种版式同时放进主视觉，结果通常不是信息丰富，而是文化事实、商业叙事和装饰层互相争抢。

## 五、版式参考转译

版式参考只提供方法，不提供内容、事实或坐标。读取参考图时先提取：画幅造成的空间预算、图像占比、分区关系、标题层级、文字密度、裁切逻辑、留白、图文前后关系、装饰职责、阅读路径和主视觉到底是图还是字。然后重新分配主体、标题、色块和空白，重做裁切与文字层级。

版式相似不等于坐标相同。`左边巨字、右边物件、底部英文` 只是表面；真正需要继承的可能是“文字形成垂直重量，物件作为唯一明亮焦点，空白承担高级感”。每次优先借一个主维度，最多再加一个辅助维度；借了构图，就重新做字体、材质和文化对象，不能同时把版式、字体、颜色、图像组合和文案都照搬。

视觉路由按功能选择，不按文化标签机械选择：摄影主视觉、编辑拼贴、上图下字、传统艺术再编辑、先锋实验、器物解构、极简收藏、研究标本 / 档案系统、时装 / 生活方式材料广告都可以成立。名称只是入口，胜负由观众任务、主体证据、信息层级和素材物理决定。

每张海报只保留一个主要视觉判断：一个主视觉符号、一个第一落点、一个标题任务和一个阅读出口。文化细节集中在局部，其他区域允许纯色、暗部、纸面、普通纹理或留白。满版传统边框、平均五色、景点堆叠、三至五张剧照平均拼贴和“所有素材都要出现”都属于结构失控，不是文化完整。

## 六、字体与文字系统

字体是视觉资产，不是最后贴上去的说明文字。先判断文字以什么力度说话：制度、展览、档案、亲密、先锋、史诗、产品或社媒点击，再从字重、字面、方向、间距、断行、位置和与图像的前后关系构成系统。可以使用巨型裁切标题、边缘竖排、英文斜体穿图、窄体信息栏、编号、坐标、材料标签、图像窗口和研究图表，但每个动作都要服务信息层级。

真实出现的中文标题、英文、副标题、藏文、日期、地点、品牌名和互动文案继续使用项目既有的中文双引号逐项锁定；没有原文就不要让模型随机加字。模型可以负责版式草案与少量短字，但正式交付必须逐字检查。陌生文字、长段文字和任何需要语义准确的文化文本，优先考虑后期精确排版，不把错误字形包装成“氛围”。

文化文字至少要有三项明确职责：主标题命名作品或点击承诺，副标题补充对象 / 时间 / 功能，文化层文字提供已确认的短信息或边注。未知文字不能作为满版底纹，藏文、少数民族文字或宗教文字不能只因视觉好看就降格成装饰。

## 七、文化品牌与商业 KV

商业视觉把文化当作材料智能，而不是装饰贴图。每个卖点或品牌判断都要经过：

```text
文化事实 / 材料特性
→ 被转译成什么图形、结构、肌理或行为
→ 为什么符合产品 / 品牌功能
→ 观众看见什么证据
→ 标题和产品怎样完成记忆与行动
```

人物优先使用局部身体、衣料、手、影子、对象和环境尺度，不默认让演员穿历史戏服站在景点前。传统材料和现代产品并置时，产品结构、使用方式、Logo 和品牌文字仍要保持清楚，文化层不能吞掉转化证据。高级感来自比例、层级、材料真实性、留白和对主视觉的取舍，不等于黑金、烫金、低饱和或昂贵词汇。

## 八、提示词编译

内部先完成事实、风险、视觉基因、版式方法和文字权限判断，正式模型正文只保留当前图像真正需要的内容：

```text
用途 / 观众任务
→ 主视觉主体
→ 文化事实与明确引用职责
→ 2-4 个视觉基因
→ 一个版式主动作
→ 标题和文字层级
→ 对象色、材料和光线来源
→ 留白、裁切、主次与安全区
→ 必要的排除边界
```

不要把索引表、来源解释、风险分析、完整文化历史和 11 项内部字段全部投喂模型。默认输出应是一条紧凑、可复制、带字的提示词；分析和来源追踪留在执行单或扩展说明中。模型正文必须正向描述要出现什么，不能用大量敏感名词建立反向联想；排除项只保留真正会导致误读的少数边界。

## 九、失败修复

| 失败表现 | 根因 | 修复 |
|---|---|---|
| 像旅游纪念品或国潮模板 | 文化符号直接堆叠，缺少主视觉判断 | 回到事实卡，只选 2-4 个结构 / 材质基因，增加留白与局部集中 |
| 画面好看但无法说出文化依据 | 只写黑金、东方、高级、氛围 | 把颜色、比例、材质、构件、工艺或空间关系落回来源 |
| 把商业海报当成传统事实 | 来源类型混淆 | 将 `COM / SEC / LAY` 单独标记，只吸收方法，不吸收文化含义 |
| 版式像参考图换了图片 | 同时复制坐标、字体、图像比例和文案 | 只保留一个主版式机制，重新分配标题、主体、裁切和空白 |
| 所有文字像乱码或伪文字 | 让模型凭空生成未知文字 | 删除不必要文字，锁定已确认短文本，正式字后期校正 |
| 文化文本被当作装饰背景 | 没有文字语义门 | 先核实含义与用途；不能核实就不用，不改成无意义纹理 |
| 高级感变成空洞黑金 | 把色彩当审美结论 | 用比例、材料反射、层级、留白和功能关系替代贵重色词 |
| 画面过满、信息互相争抢 | 素材数量等于文化完整 | 只留一个主视觉和一个标题任务，其他素材退为辅助或排除 |
| 文化身份被刻板化 | 用服饰、肤色、景点和固定姿势代替真实依据 | 以环境、材料、工艺、生活尺度和已确认事实表达，不做角色扮演式民族化 |

## 十、迁移测试与反复制边界

以下任务应都能使用这套机制，但不应被强制使用同一种版式或色板：

| 任务 | 应迁移的底层能力 | 不应固化 |
|---|---|---|
| 非遗织物品牌 KV | 事实卡、织物结构、局部材料特写、产品证据 | 满版纹样、固定金色、历史戏服 |
| 博物馆展览海报 | 来源追踪、标题层级、图像窗口、留白与信息准确 | 先锋巨字、商业 CTA、伪古文字 |
| 传统建筑出版物封面 | 构件比例、尺度关系、摄影与版式分工 | 固定红墙、雪山、黑金 |
| 现代饰品广告 | 器物形态转译、产品结构、局部材质和品牌文字 | 完整宗教法器、旅游场景、文化符号堆叠 |
| 社媒文化短视频封面 | 内容承诺、单一主符号、标题缩略图可读性 | 复杂研究索引、过密小字、长段文化说明 |

如果规则换掉人物、地域、材料、产品和用途后仍然只剩“黑底巨字加金色文化元素”，说明没有完成抽象，必须退回重写。

外部项目的样片、标题、品牌、人物、固定色板、默认比例、示例文案和具体版式组合都不是本项目模板。只吸收可追溯事实、来源分层、敏感隔离、视觉基因、版式方法和文字校准机制。
