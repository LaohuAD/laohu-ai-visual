# MV 文本完成门

本文件是 MV 导演文本产物的**生成前检视判据**：歌曲任务合同、歌曲事实卡、导演命题、歌曲—视觉结构图、生产时间线、分镜导演卡、视觉资产图片任务交接和视频提示词交接已经写成 Markdown 文本，尚没有真实图片、视频或音频时，用本判据判断它是否达到已写明的条款，再决定放行到下一步或打回重做。判据从[MV 导演交接](../../laohu-ai-visual/skills/laohu-mv-director/references/03_MV导演交接.md)的完成门提取，源文件继续负责各层字段与交接写法。

判据由[laohu-inspection](../SKILL.md)执行。它只判断是否达到已写明条款、给出条款出处、分类和归口，不重写产物。每个未通过项附三项结论：

```text
① 未满足什么        具体条款，以及在哪个文件里写着
② 属于哪一类        输出问题（产物本身没写对）／规则问题（规则没覆盖或表述不清）
③ 归哪个顶层负责人   输出问题 → 对应生产包的专业；规则问题 → 该规则的唯一负责人
```

三项结论对应的路由结果：

```text
规则没覆盖这条                        → 规则问题 → 归该规则负责人 → 补规则
规则覆盖了、检视官查出来了、产物照旧错  → 输出问题 → 归生产端专业 → 改产物或补该专业表述
产物错、检视官没查出来                → 检视问题 → 归检视官 → 补检视判据
```

归口的完整判断方法、责任链和归口检查清单见[责任划分与路由](责任划分与路由.md)，本文件只承接 MV 文本这一种产物的判据。生成前检视判断的是可执行性，不用「还没生成、无法判断」当作通过。

## 结构底线

以下 6 条任一条不通过，文本不得进入下一阶段。三层指歌曲创作段落（C段）、生成单元（E-S-P 批次）和单元内部镜头（B），三者编号与权威不得混用。

1. 三层结构完整且权威没有混淆。
2. 每个创作段落有声音依据和主要声画关系。
3. 每个生产单元有唯一任务、完整状态变化和相邻接口。
4. 跟唱段写清人声、唱词、对象与可见嘴部；非跟唱段没有被强迫开口。
5. 图片任务明确采用单帧、首尾帧或多关键状态，并说明原因。
6. 全部结果保持文本状态，不出现伪媒体结果。

## 作品巅峰

结构底线通过只说明文本可用。以下 5 条判断它是否达到当前已知范围内的最好，未通过时继续比较候选或回到上游重做，不直接宣布交付完成。

1. 胜出方向经过真正不同的候选竞争。
2. 主视觉引擎和母题能够从开头发展到结尾，而不是段段换概念。
3. 重复段落的意义改变可见，高潮完成全片最重要的声画相遇。
4. 最强画面来自这首歌的关系、声音和结构，换一首同曲风歌曲不能直接套用。
5. 图片和视频下游可以在不依赖创建聊天的情况下继续工作。
