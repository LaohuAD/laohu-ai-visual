# 图片候选分级与三道门

本文件是**已有真实候选并明确进入资产验收**时的判据：真实图片已经生成并回传，本轮任务明确要求把它们判成可用等级、决定哪些能进入视频参考。判据从图包[图片生成执行与封面交接](../../../../../../laohu-image-creation/references/图片生成执行与封面交接.md)的验收段落提取后整合，图包整体职责与生产链见[laohu-image-creation](../../../../../../laohu-image-creation/SKILL.md)。

判据由[laohu-image-review](../SKILL.md)执行并返回：每张候选的等级、两道门与现场生命感门的逐项证据、第一个断点、保护项与返修负责人。

## A/B/C/D 质量等级

已有真实候选并明确进入资产验收时，按 A/B/C/D 质量等级验收。这里的 A/B/C/D 是**结果等级**，不是要求额外生成四组候选，也不是 A/B 实验：

```text
A：可直接进入视频参考。
B：小修可用。
C：只保留为参考，不进入视频。
D：失败，进入失败复盘。
```

## 两道门

验收同时看两件不同的事：好看，和一致性。候选图必须**同时通过两道门**才算成立：

| 门 | 检查什么 |
|---|---|
| `审美门` | 类型与受众适配、第一眼吸引、设计语言、视觉记忆、作品归属 |
| `制作门` | 身份、结构、比例、材质、多角度一致性、可运动性、参考污染 |

任一道不通过都不能进入 A 级视频参考。以下三种情况回到资产设计，由视频提示词补救不成立：

```text
结构稳定但普通        → 制作门通过、审美门未通过 → 回资产设计
好看但换角度崩坏      → 审美门通过、制作门未通过 → 回资产设计
单独漂亮但不属于同一世界 → 作品归属未通过        → 回资产设计
```

## 现场生命感门

观众成品人像、人物形象图、封面主体、叙事首帧和生活方式 B-roll 英雄帧再过 `现场生命感门`，逐项判断：

```text
人物状态能否推断前后瞬间
摄影机是否有可信观看关系
环境是否回应人物
皮肤、发丝、衣料、湿润和局部光学效果是否按来源与材质成立
```

## 普通照片升级的身份与事件硬锁

普通照片升级另查身份与事件硬锁。出现以下任一项时，即使成图更漂亮也不能评 A：

```text
换脸
换年龄
换表情
换主要动作
换服装
换关键道具
另编场景
```

## N/A 的适用边界

中性设计板、证件式校准和纯结构拆解记 `N/A`，按结构、比例、材质与多角度一致性验收，不强行制造抓拍感。
