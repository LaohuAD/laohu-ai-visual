# 综合验收与体裁边界

剧本检视在判断骨架与开放位置是否成立、或需要按体裁边界作反向逐项检查时读取本文件。本文件承接原属剧本包的综合验收条款；生产端的基本取舍、描述粒度、特征交集、承重选择与审美组合语法仍由[剧本质量取舍](../../../../laohu-script-writer/references/剧本质量取舍.md)负责，其中「正向兼容组合关系」一节是本文件第三组体裁检查所指的六组组合。

高质量 AI 剧本来自稳定骨架和具体叙事特征的组合。

它是在稳定骨架里，让关键开放位置命中足够具体、足够互相支撑的叙事特征：

```text
选题有具体人物、临界时刻、观众预期和情绪代价。
人物有欲望、缺口、错误信念、防御动作和最终选择。
需要冲突的故事，其对立面、信息差、阻力、代价或不可逆变化中至少有一个真正推动人物；不需要冲突的体裁也要有清楚的观看推进。
场景按需承担压力、动作因果、道具、声音、观察或情绪空间；不强制可截图停点。
台词有人物声口、潜台词、动作性和声音状态。
结尾能回收开头的物件、动作、称呼或价值判断。
```

这条验收从体裁边界开始判断，而不是先套统一戏剧配方：

```text
商业剧情、悬疑和强叙事内容：
从对立面、信息差、阻力递增、不可逆节点和黑暗时刻中选择承重机制。

文艺、观察、氛围、纪录和教程内容：
允许由关系距离、时间流逝、发现、节奏或认知变化推进。

反转教育、亲情遗憾、爱情情绪、成长选择、奇观邀请：
按“正向兼容组合关系”检查承重特征是否互相支撑，不要求每部作品把六组组合全部命中。
```

反向逐项检查时，同样按体裁和真实作用验收：不需要冲突的体裁有清楚的观看推进即可成立；长片比例不线性套用到短片；结尾回收、黑暗时刻、递增阻力和可截图停点都是**候选**，不是时长或体裁自动触发的必填项。只有在题材、观众经历与主情绪都要求时才成为验收项。

综合验收与生产端质量取舍共同的核心用途是扩大 AI 对高质量剧本的可识别特征库。特征越细、越具体、越能组合，生成时能圈住的高质量区域就越小，剧本越有机会接近真正可拍、可生成、可剪辑、可传播的影视作品。
