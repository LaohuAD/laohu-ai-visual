# 视频提示词生成前验收判据

本文件是视频提示词投喂生成之前的两道门逐条判据。底线门判首稿是否可执行，巅峰门判这条正式提示词是否值得生成。条款原先写在视频包的交接与验收合同里，现由检视官在本位置维护；生产端按同一份判据自检并返修。

底线门未通过时，问题留在 `laohu-video-prompt` 修复，不进 VC、不进付费生成。

## 一、底线门：首稿可执行

### 上游成立与镜头原子

- 上游镜头是否已经成立，提示词没有承担第一次发明故事。
- 每镜是否只有一个主观看任务和一个主情绪。
- 是否逐镜通过镜头原子检查：一镜一事、一个主要画面内容、一项主变化和一条连续摄影机路径；真实切镜是否已经新开编号；连续拉焦、揭示和反应是否仍保留连续镜头身份。
- 首稿无论采用完整母稿法还是关键场面→专业补全法，是否都完成同一导演母稿合同；是否因为“已经有镜头编号 / 台词 / 音效”而在强度仅1—2级时提前停止。

### 因果闭合与状态连续

- 起点状态、触发、路径、屏幕变化、结果和结束状态是否闭合。
- 人物动机、台词、动作与道具选择是否共享同一条因果；表面矛盾是否有意且有可见证据，否则是否退回上游。
- 承重道具是否通过状态账本锁定起点、接触、承重、路径、落点、支撑和下一镜状态，没有悬空、瞬移、易手或数量漂移。
- 每个切点是否有剪辑承接合同；省略是否通过省略成立门，而不是靠“自然衔接”或观众替作者补因果。
- 两镜以上共同完成同一动作时，连续动作主线是否已经进入正式`【画面内容】`，并与逐镜状态逐项一致。
- 直接连续时，A与B必须继承的状态是否相容，B是否从下一相位开始；同场重建、艺术转场或场景重置是否按已确认的继承与重置范围核对，没有把全部屏幕状态相等强加给所有切点。

- 原文范围内不能丢失的非对白信息、物品状态变化和揭示顺序，是否在正式正文或已明确交接的后期载体中有具体落点，而不是只留在说明或资产表中。
- 反向核对后，正文是否没有由旧提示词、相邻场次或参考中的偶然内容引入未经确认的承重剧情事实；合法摄影和表演深化是否仍保留本专业判断空间。

### 摄影机与声画来源

- 摄影机物理路径是否真的产生正文所写屏幕变化。
- 动作、表演、VFX 和声音是否有画内来源与正确时点。

### 注意力、表演与台词

- 期待承重时，是否继承观众问题—答案交接并完成声画兑现表；每次快慢、切角、遮挡和停点是否改变信息、风险、关系或判断，且内部作者解释没有进入模型代码块。
- 冻结台词是否嵌入镜头正文，并同时写清开口前动作、说话对象、重音 / 气口 / 口型、说话中的身体变化、听者准确反应与说完后的停点；是否完全没有独立 `【台词】` 轨。
- 直接对镜时是否写清`镜头关系对象合同`；人物的称呼、礼貌程度、攻击性、眼线、距离和动作强度是否服从戏内对象，而非笼统服从公开观众；无害边界是否落在道具、接触、停手和结果上，而没有削弱冻结台词。
- 每个承重节拍的主要兑现、决定性视觉落点和结果停点是否达到3级主导；构图、焦点、光色、动作、声音或VFX是否以足够可辨认的证据证明主结果，单一机制可以成立，竞争信息是否退让。
- 所谓重点是否通过当前观众问题与信息增量证明；是否既没有在证据可读前抢答，也没有在预期和反应完成后继续拖成等待过期。
- 承重句是否具备实际基准、变化维度、方向 / 幅度 / 路径和可见 / 可听终态；不可变项是否吞掉了可变项。
- 具体排除是否已经改写为正向唯一结果；真实时间状态是否被正确保留。

### 控制密度与资产绑定

- 复杂单元是否通过最低充分控制密度检查；是否仍有承重人物、空间、表演、摄影机、环境或后半段状态需要模型猜测。
- 实际绑定资产是否真实存在，本镜未用资产是否删除。
- 图生、首尾帧和多参考任务是否已打开真实图片并完成真实参考图调用合同；路径、入口模式、真实可见对象、固定对象、可动对象、禁止新生对象、首个变化与最终结果是否齐全。
- 参考图是否通过语义一致性门；文件名与真实像素不一致、草图未验收或内部编号 / 临时占位泄漏时，是否已经拒绝绑定并返回视觉资产。

- 使用真实多模态输入时，当前P的操作清单、实际可核实的提交位置、文件版本、角色或属性范围与正文引用是否一致；待准备和计划绑定是否没有冒充已上传或已验收。无额外输入的合法文生任务不因没有空表而失败。
- 音色参考、原声复用与配乐选择是否分别成立；是否没有把参考文件中的旧话、音乐或杂音带入未授权的目标声音。

### 正文纯净与机械边界

- 代码块是否只有模型需要的内容，没有作者意图和后期解释。
- 字符、格式、时长和命名是否通过机械检查。
- 需要多版本时，人读说明与实际可复制／导出的正文是否共享同一事实、冻结台词、引用关系和声音策略；没有相关需求时是否没有强制增加双语或机器版。
- 本轮只做了文档、结构或引用检查时，是否如实区分尚未生成、尚未观察与实际成片已验收。

首稿未通过，留在 `laohu-video-prompt` 修复，不能交给 VC 收拾基础错误。

## 二、巅峰门：正式提示词值得生成

底线门与 VC 都完成后，视频 Skill 仍对最终作品效果负责，不能只复查格式。正式写入前检查：

```text
主胜负手：本段最不可替代的情绪、关系、视觉、声音或卖点结果是什么。
候选比较：决定性瞬间、观看位置、构图、运镜、表演、声画和停点中，哪些方向被比较并淘汰。
序列推进：每个镜头 / 批次新增什么，换序或删除后是否明显失去力量。
导演连续性：人物目的怎样穿过镜头，道具状态怎样交接，省略怎样被观众无负担地重建；是否仍有逐镜成立、合看断裂之处。
峰值兑现：前面的蓄压是否在可见 / 可听结果中真正到顶，而不是靠形容词宣布高潮。
专业协同：构图、运镜、表演、动作、VFX、光色、音乐和环境声是否共同托住主胜负手；不承重的维度是否主动退让。
质量强度：主胜负手是否达到3级主导；不是统计规则有没有，而是判断它是否足够强、有效信息占比是否足够高、删掉任何承重句是否会明显削弱结果。
Reference 生效：调用回执能否指出机制改变了哪个决定并落到哪处成品。
VC 生效：有改动时为什么更强；零改动时为什么原稿已经优于可行改法。
已知上限：是否仍存在一个具体、可实施且预计明显更强的方案没有处理。
```

最后一项为是，返回对应的导演选择、镜头编译或 VC 环节继续改；不能以字符已满、三段齐全或时间已花费为理由停止。极致不要求每个维度最大：承重的是静止、留白、沉默或固定机位时，强行增加运动和特效反而判为降级。
