# 镜头特征质量验收

本文件是镜头特征的验收判据，取舍方法由[镜头特征取舍](../../../../laohu-video-prompt/skills/laohu-video-compilation/references/镜头特征取舍.md)负责。

一条高质量提示词来自稳定骨架和具体镜头特征的组合：在稳定骨架里，让关键开放位置命中足够具体、足够互相支撑的镜头特征。以下检查按当前实际用途执行：

```text
基础设定自足，资产引用准确。
氛围画质有风格交集、光影分离、色彩主次和材质细节。
画面内容四核形成因果：主体与注意力目标明确，动作与表演可见，效果系统有来源和结果，节奏与时长足够感受。
画面内容有确定时长、景别构图、运镜路径、动作因果和镜头停点。
运镜已经从术语展开为观看意图、摄影机物理路径、屏幕变化、情绪倾向和停点。
焦点、环境、光色、速度和声音共同指向同一注意力目标，画外声音能建立不可见空间。
人物表演有触发、变化路径、脸部证据、身体证据和声音证据。
声音先写情绪态度，再写参数和空间。
图生视频、文生视频和资产输入采用与输入信息相匹配的描述预算。
连续镜头有首尾帧、声音桥、视觉锚点和情绪余韵。
正式模型正文集中书写可见 / 可听结果。
```

权重与检查项的适用条件同时成立，以下限定来自同组骨架资产的明确例外，不是新加的宽容：

- 本镜没有人物表演时，不强求脸部证据、身体证据和声音证据，由镜头、空间、材料、图形或产品承担主结果；反过来也不能因为“没有脸”就放弃可辨认的变化证据。
- 固定机位时不强求机身运动：动的是人物、焦点、光影、画外声音或画内物体；但也不能用“固定机位”掩盖观看关系没有建立。
- 独立素材、可替换空镜、单条成片和非连续剪辑不强求上下条接续，不为不存在的前后片段造同构图、同尾首帧。
- 单条生成前逐项判断的信息只有本镜实际需要的内容才进入正文；确定时长、实际调用资产和核心变化通常不可缺，其余为条件项。
- 以上是设计端检查。静态检查通过只证明设计成立，不证明媒体效果已经达成；真实生成结果仍按真实结果验收。

字段、冻结台词、已确认资产、段落范围与 VC 执行不在本文件放宽：正文仍使用既定三段式，已锁定内容不改，候选特征不得被写成逐条必填的硬字段。
