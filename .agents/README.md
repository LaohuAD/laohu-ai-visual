# 项目技能实体与发现

真实技能位于 `.agents/skills/`，包含项目总控、故事与剧本、图片与视觉资产、视频制作与提示词、语言模式、检视官六个实体文件夹；内部专业保留名称和方法，没有指向根目录skills的符号链接，也不保留反向兼容链接。目录是递归语法：每层有自己的 `SKILL.md`、按需的 `references/`，以及确有下层能力时才建立的 `skills/`。

目录与使用说明见[Skills README](skills/README.md)。上传时直接选择对应完整文件夹。包内Reference、领域语言写法和必要方法都是实际文件；共用方法全项目只维护一份正文，消费位置按相对路径读取，不需要先导出或运行维护工具。

维护者修改公共方法时改唯一负责人的文件并复验，不再靠复制同步；`scripts/sync_skill_packages.py` 在迁移工具切换后承担副本审计与依赖检查，不再是运行时索引，也不再生产新副本。入口数量是六个，不保证宿主只显示六项：本地宿主若递归发现，会同时显示内部专业。磁盘嵌套与默认自动加载不是同一保证，父链继承由显式相对链接和执行约定保障，需实测确认；磁盘可用与当前会话刷新也是两件事。

运行 `python3 scripts/validate_skill_packages.py` 检查六包实体、元数据、文件链接与跨包依赖；旧历史迁移证据由五包迁移清单记录可逆变化，不为保持老路径制造链接。
