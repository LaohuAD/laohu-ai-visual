# 模板_视频生成质量检查清单

> 用途：生成前检查提示词，生成后诊断结果。重点不是“好不好看”，而是是否服务作品。

## 一、生成前检查

### 基础设定

- 作品体量是否清楚。
- 是否说明单镜头还是多镜头。
- 角色外观、服装、场景是否统一。
- 是否说明是否后期拼接。
- 是否说明声音策略：同期声、配乐、旁白、台词或无声。
- 会出声的人物是否在资产行或资产表中写了基础声线；同一人物跨镜头是否保持同一音色锚点。
- 是否列出全局禁止项。

### 氛围与画质

- 风格不是只写“电影感”。
- 色彩和影调具体。
- 光线方向具体。
- 画面质感具体。
- 镜头节奏具体。
- 禁止风格冲突：卡通化、游戏 UI、塑料感、棚拍感、过度锐化等。

### 画面内容

- 每个镜头有编号。
- 每个镜头有时间段。
- 每个镜头只有一个主要动作。
- 景别和构图服务动作。
- 运镜不超过镜头承载能力。
- 表演有时间轴，而不是一个情绪词。
- 每个镜头是否设计了壁纸帧 / 审美停点：至少一个暂停后仍然成立的画面瞬间，具备清楚主体轮廓、前景 / 中景 / 背景层次、视觉中心、留白、主次色彩、方向性光影、材质细节和镜头停稳点。
- 审美停点是否从剧情动作里长出来，而不是无关漂亮空镜、滤镜词或只写“电影感”。
- 审美停点是否有明确构图逻辑：三分构图、黄金分割构图、中心对称构图、框架式构图、引导线构图、对角线构图、留白构图、前景框构图或三角稳定构图至少选择一种，并写清主体落点。
- 是否写清留白方向和画面平衡：大面积干净留白、上方留白、侧边留白、极简留白或负空间是否明确；视觉重心是否稳定，主体是否位于画面 1/3 处、黄金分割点、中心轴或明确框架内，边角是否干净无杂物。
- 动态镜头是否有稳定停点：推拉摇移后是否回到可截图构图，而不是主体全程漂移；画幅比例是否服务用途，例如 16:9 标准壁纸、21:9 宽幅电影画幅、3:4 竖幅人像壁纸比例或方形文艺画幅。
- 光影体系是否具体：是否写清时段光线、主光方向、弱辅光、轮廓光 / 反光、阴影层次、材质反应和动态稳定，而不是只写 `自然光`。
- 是否选择了明确时段定向光线：黄金一小时逆光、日出柔光、蓝调时刻冷光、傍晚漫射光、雨后柔和天光，或室内的柔和窗光、门缝冷光、灶火暖光、旧灯泡暖光、屋檐下漫反射。
- 阴影和反光是否可控：是否有柔和虚化阴影、低对比度阴影、细腻层次阴影、长投影、镜面反光、水面反光或透光纱质柔光；是否避免生硬死黑阴影、无来源高亮和动态光源乱闪。
- 色彩体系是否具体：是否写清主色调、辅助色、点缀色、饱和度策略、明度 / 对比、环境色反光、色彩过渡和统一滤镜 / 分级，而不是只写 `高级调色` 或 `复古滤镜`。
- 色彩主次是否稳定：是否控制在 1 个主色 + 1 个辅助色 + 1 个小面积点缀色，通常不超过 2 种主色；是否避免多种高饱和红、蓝、绿、黄同时抢画面。
- 色彩是否和故事、年代、空间、光源统一：莫兰迪低饱和、青橙电影色调、冷调蓝灰、复古胶片棕调、奶油温柔、暗调黑金、黑白灰单色、褪色老照片、山城雾灰绿等是否按本镜需要选择，而不是机械套用；富士胶片色调、柯达金 200、电影 LUT、轻微暗角或低对比色彩分级是否服务统一。
- 景深与空间层次是否具体：是否写清前景虚化遮挡、中景清晰主体、远景朦胧环境、焦段选择、焦点落点、虚实过渡和空气透视 / 散景，而不是只写 `浅景深`。
- 焦段是否按任务选择：85mm 人像定焦、50mm 标准人文镜头、35mm 人文广角、135mm 长焦或其他焦段是否服务人物情绪、POV、空间关系、距离压缩、道具特写或仪式群像。
- 景深是否匹配信息量：情绪 / 手部 / 遗物 / 材质特写是否主体清晰、背景柔化；群像 / 仪式 / 空间因果 / 动作受力是否保留中等或深景深，没有把关键信息虚掉。
- 前景虚化遮挡是否服务层次和信息差：门框、窗沿、树叶、纱帘、薄雾、纸灰、火光、柜台边、桌沿、肩背、手部或道具边缘是否形成入口；是否没有遮住关键动作。
- 动态镜头焦点是否稳定：推镜、拉镜、摇镜、升镜、POV 转头或跟随轻物升高时，焦点是否写清从哪里转到哪里，停点是否锁住主体，远景朦胧是否受控。
- 画质与材质质感是否具体：是否写清分辨率清晰度、主体边缘锐度、材质质感细分、微细节锚点、运动模糊控制、画面洁净度和介质颗粒边界，而不是只写 `8K 高清`。
- 材质是否绑定具体物件：哑光柔和质感、磨砂低反光、丝绒柔和肌理、金属细腻拉丝、水雾朦胧质感、细腻胶片颗粒或受控老式 DV 噪点是否落到旧墙、衣料、硬币、木轮、蒲团、旧瓷、玻璃、火光、纸灰等具体表面。
- 截图停点是否清楚：审美停点是否极低运动模糊，主体边缘、手部、道具和材质纹理是否清晰；是否避免大面积动态拖影、多余虚影、AI 扭曲瑕疵、边缘崩坏、脏杂点、随机文字、水印和压缩糊块。
- 氛围环境元素是否具体：是否写清天气 / 时间基底、空气媒介、漂浮微粒、光学点缀、环境运动、密度控制和题材适配，而不是只写 `氛围感`。
- 氛围元素是否有来源和方向：薄雾、水汽、烟气、窗边落尘、纸灰、落叶、细雨水雾、光斑、水面波光、漫射柔光粒子是否来自真实光源、天气、动作或环境，并写清位置、方向和密度。
- 氛围元素是否克制并符合题材：家庭纪实、丧事病床、放学路、浪漫 MV 或强风格化镜头是否使用不同元素；是否避免无来源花瓣、过浓雾、舞台特效感和遮挡关键动作。
- 镜头运动约束是否具体：是否写清机位稳定策略、运镜速度、抖动强度、变焦 / 旋转控制、构图保持、可定格停留和运动模糊边界，而不是只写 `动感运镜`。
- 是否使用适合截图的运动方式：固定机位长镜头、极缓慢微动运镜、轻微呼吸手持、低抖动稳定画面、缓慢推拉和低幅度摇移是否优先用于家庭纪实、病床、遗像、饭桌、门口对话、遗物和仪式。
- 动态镜头是否有可定格停点：关键动作后是否停住 1-2 秒，主体、留白、光影、景深和材质是否稳定；是否避免全程快速推拉、连续旋转、快速变焦、甩镜、大幅颠簸、过度航拍和主体漂移导致抽帧不可用。
- 声音和后期备注写清楚；病弱、哭腔、压低声音、隔门闷声、电话失真、VO 回响等是否作为当前镜头状态写入画面内容。

### 参考素材

- 参考图负责锁定什么已写清。
- 参考视频负责参考什么已写清。
- 参考音频负责控制什么已写清。
- 哪些内容不能被参考素材带偏已写清。

### 低保真故事板

- 是否已经把故事板提示词和视频提示词分开：故事板提示词单独存在 `04_分镜/文本/`，视频提示词单独存在 `05_视频/文本/`，两者都能独立复制。
- 同一个 `VID` 的故事板提示词和视频提示词是否使用同一组微分镜编号；如果 `VID-01` 用 `S1-C1-01` 到 `S1-C1-03`，故事板和视频提示词都不能擅自增减或错位。
- 故事板是否是低保真 2.5D 线框表格图：黑白 / 灰阶、火柴人 / 简化剪影、几何块、空间文字标签、构图线、前景框、引导线、箭头、虚线和运动路径线是否明确。
- 故事板是否只锁构图、景别、机位、主体比例、站位、道具数量、空间锚点、引导线、动线路径和留白；是否没有锁真实五官、具体服装、颜色、材质、最终光影和电影质感。
- 故事板提示词是否没有调用具体资产图、没有写 `【@资产名】`、没有把角色 / 场景 / 道具资产的真实外观画进故事板；若需要锁真实外观，是否已回到图片资产或第一帧参考图流程。
- 故事板表格列是否完整：时间点 / 微分镜编号、2.5D 线框构图图、构图规则、景别 / 机位、空间锚点、引导线 / 动线路径、主体比例与位置、参考强度。
- 参考强度是否写清：强锁构图、站位、比例、道具数量、动线和留白；弱锁外观、颜色、材质、表情和最终光影。
- 如果使用锚点重叠，上一条 `VID` 的最后一个微分镜和下一条 `VID` 的第一个微分镜是否在故事板和视频提示词里保持同一构图、空间锚点和动作状态；如果是硬切、时间跳切、换场或闪回，是否没有机械重叠。

## 二、生成后评分

每项 0-2 分：

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 角色一致性 | 明显变脸或变装 | 局部不稳 | 基本统一 |
| 镜头任务 | 看不出任务 | 大致完成 | 清楚完成 |
| 动作自然度 | 扭曲或跳变 | 有小问题 | 自然可信 |
| 表演控制 | 情绪不对或过度 | 基本接近 | 准确有层次 |
| 构图可用性 | 影响观看或后期 | 勉强可用 | 清楚稳定 |
| 壁纸帧 / 审美停点 | 没有任何值得截图的稳定帧 | 有可用帧但主体、层次、留白或光影不足 | 至少一帧可作封面候选、壁纸或段落记忆点 |
| 构图逻辑 | 只堆元素，没有构图结构、主体落点和留白 | 有构图词但停点不稳、边角杂乱或主体漂移 | 构图结构明确，主体落点、留白、引导线 / 框架和边角清洁都稳定 |
| 光影体系 | 只写自然光或光源乱闪，画面平灰 | 有时段或光型，但主辅轮廓、阴影或反光不完整 | 时段、主光、弱辅光、轮廓 / 反光、阴影层次和动态稳定都清楚 |
| 色彩体系 | 高饱和撞色、无主次、无统一色调 | 有色调但主辅点缀、过渡或分级不稳 | 主色、辅助色、点缀色、环境色反光、过渡和统一分级清楚 |
| 景深与空间层次 | 画面扁平，前景 / 中景 / 远景不分，焦点随机 | 有前后景或浅景深词，但焦段、焦点或虚实关系不稳 | 前景虚化、中景主体、远景朦胧、焦段选择和焦点落点都服务剧情 |
| 画质与材质质感 | 截图发糊、边缘崩坏、材质像塑料或画面脏 | 有高清或材质词，但细节锚点、模糊控制或颗粒边界不稳 | 主体边缘锐利，材质纹理可放大，运动模糊受控，画面干净 |
| 氛围环境元素 | 画面死板或元素无来源、乱飘、遮主体 | 有雾、光斑或微粒，但来源、方向、密度或题材适配不稳 | 天气基底、空气媒介、微粒光斑和轻微环境运动都服务情绪 |
| 镜头运动约束 | 全程快速推拉、旋转、变焦或抖动，抽帧不可用 | 有停点但运动速度、抖动、变焦 / 旋转或模糊边界不稳 | 固定 / 微动 / 慢推拉 / 低抖动策略清楚，关键动作后停住成可截图构图 |
| 光影风格 | 跑偏 | 局部跑偏 | 统一 |
| 声音适配 | 同一人物换音色、声音冲突或多余 | 声音基本可接受但声线锚点不够稳定 | 基础声线稳定，本镜声音状态服务画面 |
| 拼接可用性 | 接不上 | 需要剪辑补救 | 可直接拼接 |
| 故事板参考有效性 | 故事板和视频内容错位，或故事板锁死真实外观导致视频僵硬 | 构图 / 动线有参考价值，但微分镜、锚点或参考强度不够清楚 | 故事板准确锁住构图、景别、空间、动线和留白，同时不限制资产外观和最终美术发挥 |

## 三、常见失败对应修正

| 失败现象 | 常见原因 | 修正方式 |
|---|---|---|
| 角色变脸 | 参考图不稳定，基础设定不够 | 先做角色定妆图和三视图，视频提示词减少外貌变化 |
| 动作乱 | 单镜头动作过多 | 每镜头只保留一个主要动作 |
| 运镜晕 | 运镜叠加过多 | 保留一种运镜，或改为固定镜头 |
| 表情夸张 | 情绪词太泛 | 写表情强度、性格边界和时间轴 |
| 风格冲突 | 风格词互相打架 | 只保留一个风格核心，删除矛盾词 |
| 拼接断裂 | 各镜头没有统一规则 | 增加全局基础设定和后期衔接备注 |
| 声音抢戏 | 声音策略不清 | 明确只保留同期声、无配乐或指定配乐功能 |
| 人物跨镜头换声 | 人物资产未写基础声线，或每条提示词随意改音色 | 在人物资产行补基础声线；当前镜头的病弱、哭腔、电话失真、隔门闷声只写进画面内容 |
