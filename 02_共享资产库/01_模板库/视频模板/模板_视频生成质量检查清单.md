# 模板_视频生成质量检查清单

> 用途：生成前检查提示词，生成后诊断结果。重点不是“好不好看”，而是是否服务作品。

## 一、生成前检查

### 基础设定

- 是否只列本条实际上传或绑定的人物、场景、道具、色卡、动作 / 音色和首帧参考。
- 是否删除了只为提醒作者、但本镜不出镜也不参与声音 / 动作 / 空间的资产。
- 参考图容易误导或本镜临时状态变化时，是否只补了一句必要约束，而不是重复整份资产说明。
- 是否明确只生成对白、同期动作音效和环境声，默认不生成 BGM。
- 会出声的人物是否保持同一音色锚点；本镜声音变化是否跟随表演写进对应镜头。

### 氛围与画质

- 是否只保留 1-3 句跨全部镜头成立的主风格、摄影介质和宏观色彩基线。
- 主风格是否从“电影感”收窄到明确影像母体与真实程度。
- 全局画幅、颗粒、稳定度和色彩关系是否统一。
- 局部焦段、光源、材质、雾气和对象 HEX 是否已经移入对应镜头。
- 删除任何一句后，如果只影响某一镜，是否已把它移出全局段。

### 画面内容

- 是否完成四核：主体与注意力目标、动作与表演、效果系统、节奏与时长是否形成同一条观看因果链。
- 每镜是否只有一个主注意力目标；景别、焦点、运动、明暗色彩、导引线和声音是否共同指向它；注意力迁移是否有视线、动作、焦点、声音或切镜触发。
- 每个情绪节拍是否只有一个主情绪目标；是否分别回答注意力目标、观看任务和情绪目标；表演、运镜、光色、声音和停点是否共同指向它，没有让多个情绪以同等权重竞争。
- 是否区分情绪识别和观众代入：观众除了看懂人物情绪，是否知道人物为什么在乎、会失去什么，并通过本段真正承重的信息、空间、身体、时间或选择路径与人物共同经历。
- 段落是否按需要完成进入处境、与人物对齐、共同经历和拉开沉淀；是否避免把全程 POV、贴脸特写、手持抖动、快速切镜和强音效误当成唯一代入方法。
- 情绪转折镜头是否有明确起点情绪、可见 / 可听触发、变化路径和终点情绪；没有变化因果时是否拆镜头处理。
- 每个专业字段是否真正增强主情绪：构图、光影、时间、姿态、场景、色彩、材质、运镜和声音中，无关字段是否删除，削弱、稀释或转移情绪的内容是否改写或降权。
- 动作与表演是否从起始状态、触发、路径速度、接触受力、可见结果、反应走到结束状态；情绪是否有台词态度、表情、呼吸、肢体、距离或声音证据。
- 复杂人体动作是否有姿势相位：起始轮廓、约束解除、支撑点转换、肩胸骨盆与关节链、重心 / 旋转轴、四肢净空、首次落地、缓冲卸力和结束轮廓；是否仍停留在 `翻身 / 跳下 / 旋转 / 摔倒` 等动作名称。
- 多主体运动是否逐一锁定世界坐标、屏幕坐标、朝向、速度 / 加减速、景深层、路径、外力、相对顺序、终点和出画顺序；共同运动体分离后是否保留惯性；摄影机跟随速度与轴线是否和对象世界运动分开描述。
- 是否存在没有因果的反向、超越、瞬移、停住、换层或出画顺序颠倒；人物、坐骑、车辆、群像、投射物、关键碎片和摄影机的相对关系是否能被连续排演。
- 重大位移或遮挡切换后是否重新建立主体、攻击来源、地面 / 道路边界和摄影机观看侧；局部手腕、暗器或碰撞点是否有清楚空间来路。
- 承重动作是否有帅点捕捉：危险逼近、提前占位、短路径处理、接触瞬间短暂清晰、结果继续高速运动和余势停点是否连成一体；停点是否由动作结果产生而非摆拍。
- 主要交战者是否有可辨认的角色动作语法：距离、起势、攻击几何、防守 / 借位、场景利用、回收方式和能力边界是否符合身份；是否避免所有角色共享同一套通用连招。
- 群战是否让上一招的遮挡、失衡、空位、掉落物或反作用力成为下一招条件；是否避免每名攻击者依次走到正面、人物恢复默认站姿后重新开打。
- 本段是否选出一个真正承重的决定性瞬间；摄影机是否让危险线、人物轮廓和结果证据同时可读；特效、拖影、火花、水花和碎片是否证明物理与情绪，而没有淹没主体。
- 爆炸、坍塌、炮击、撞击或能量事件是否有来源、命中点、传播方向、承力结构、材料失效顺序、碎片分组 / 飞散锥、二次碰撞、烟火压力、遮挡、声音、摄影机响应和永久终态，而不是只有结果词。
- 效果系统是否按需要选择焦点、运镜稳定、环境天气、光色、速度、声音和转场；每个效果是否有来源、变化过程、可见 / 可听结果和情绪职责。
- 运镜具象化是否完成：是否按观看意图、摄影机物理路径、屏幕变化、情绪倾向和停点写清机身 / 镜头运动、方向轨迹、速度稳定度、主体 / 背景 / 地平线变化和最终构图。
- 运镜是否只作为情绪倾向而非固定字典；推、拉、摇、移、FPV、横滚、机械臂或希区柯克变焦是否结合当前主体、起终景别、焦点、速度、声音和上下文选择。
- 时长是否覆盖主体识别、动作完成、情绪建立、效果展开和停点 / 切换余量；内容过载是否通过加时长、删效果、减镜头或拆素材解决。
- 是否按图生视频 / 文生视频 / 实际资产输入调整描述预算：输入已固定的外观少重复，未资产化主体和场景写足。
- 首尾帧双端锚定模式是否同时引用首帧和尾帧；是否完成端点兼容性分析，写清不变量、变化量、共同桥梁和最大断裂点。
- 中间变换链是否有触发、有因果、有连续状态；摄影机路径是否服务主变换；尾帧元素是否提前召回，结尾是否减速校正主体比例、位置、景别、透视、地平线和焦点后再落帧。
- 分镜表和预演板可以保留镜头编号供人工管理；正式视频模型正文是否已经去掉 `镜头01 / 镜头02 / 镜头N` 标签，避免把连续画面写成互不相干的独立任务。
- 正文每次切换是否写清前一画面的动作、遮挡、视线、焦点、声音、光色峰值或运动方向怎样触发摄影机变化；切换后的画面是否继承人物姿势、道具状态、动作余势、空间方向和声场。
- 镜头数量是否由观看任务决定：长镜头服务连续时间 / 空间 / 情绪累积，少量切镜服务反应 / 揭示 / 景别递进，快闪蒙太奇服务时间压缩 / 并置信息 / 记忆碎片 / 危机 / 动作卡点。
- 每增加一个镜头，是否增加了新的信息、情绪、空间关系、动作阶段、视觉证据或节奏压力。
- 精确多切、逐镜构图和大量重要画面是否已经拆成多条素材后期剪辑，而不是全部塞进单条 15 秒生成。
- 总时长是否在 Seedance 平台参数中设置；首测是否默认 720p。
- 每个镜头只有一个主观看任务；发生动作链时，链内动作共享同一注意力和情绪方向，并写清实际发生的起点、触发、路径、结果或停点，不要求五项齐全。
- 是否完成承重字段审计：主情绪证据和生成必需信息已经写清；景别、机位、运镜、光影、HEX、材质、环境、同期声、切换和停点只保留本镜真正使用的部分，没有机械全填。
- 是否已经判断本镜类型：文戏、武戏、转场、空镜、表演、动作、信息揭示或审美停点。
- 节奏密度是否匹配体量：15 秒、30 秒、60 秒或 1-3 分钟内容是否有对应的信息推进、冲突推进、情绪推进或动作爆点；慢节奏是否有情绪压力，快节奏是否看得清动作因果。
- 文戏关键台词是否有关系目的并造成可读后果；潜台词、表情、停顿、关系距离和反应镜头是否按主情绪选择，未机械全填。
- 武戏 / 动作是否先让力量来源、路径、接触点和结果可读；起势、发力、受力、反应、爆点和停帧是否只出现在承担对应职责的节拍。
- 镜头切换是否有任务：为什么现在切，切掉了什么信息，切进来增加了什么压力，观众情绪被加速、压住、误导还是释放。
- 景别和构图服务动作。
- 运镜不超过镜头承载能力。
- 表演有清楚起点、触发、变化和停点，而不是一个情绪词。
- 面向观众且承担视觉记忆的镜头是否有审美停点 / 情绪停点；功能型镜头是否只保持任务完成和可剪辑，不强制壁纸帧；停点是否只使用加强主情绪的承重元素。
- 审美停点是否从剧情动作里长出来，而不是无关漂亮空镜、滤镜词或只写“电影感”。
- 观众第一眼是否有明确视觉落点：脸、眼睛、泪、手、道具、树、光点或唯一清晰局部。
- 主体是否通过面积、亮度、颜色、清晰度、反差、位置或运动被突出；画面复杂时主体是否被“加满”。
- 先做承重字段判断：本镜为主情绪、主注意力、动作因果和连续性真正需要哪些构图、光影、色彩、空间、材质、氛围或停点手段；未被选择的项目标记 `N/A`，不因字段少扣分。
- 构图承重时，检查视觉落点是否明确；导引线、空间块面、留白、三分法、对称、框架或黄金分割只选择实际加强落点和主情绪的方式，不要求至少一种经典构图。
- 光影承重时，从时段与真实光源反推方向、软硬、明暗和材质反应；平光、剪影、单一硬光或大片暗部都可以成立。使用动态光时，必须有来源、方向和稳定的运动因果。
- 色彩承重时，检查对象落点、权重和连续性；不固定为 `1 主色 + 1 辅助色 + 1 点缀色`，黑白、单色、自然综合色和有意高饱和冲突均可得满分。
- 空间与焦点承重时，从前景、中景、背景、焦段、焦点、虚实过渡和空气透视中选择必要项；不强制前中后景齐全，不把人像、POV、疏离或群像固定到某个焦段与景深。
- 焦点发生迁移时，检查触发、转移路径和最终落点；固定深焦、全程失焦、方向性运动模糊或主体全程移动也可以是有意结果，不统一要求焦点稳定。
- 材质承重时，只检查与身份、状态、物理因果或主情绪有关的具体表面；不要求每镜同时写分辨率、锐度、微细节、运动模糊、颗粒和洁净度。
- 氛围元素承重时，检查天气、空气、微粒、光斑或环境运动是否有来源和密度；干净空气、静止背景和无微粒同样可以成立。
- 只有承担人物第一眼、情绪峰值、封面候选或传播视觉职责的镜头检查审美停点；功能型镜头不强制壁纸帧，速度冲击和运动连接镜头也不强制可截图。
- 氛围元素是否克制并符合题材：家庭纪实、丧事病床、放学路、浪漫 MV 或强风格化镜头是否使用不同元素；是否避免无来源花瓣、过浓雾、舞台特效感和遮挡关键动作。
- 镜头运动约束是否具体：是否写清机位稳定策略、运镜速度、抖动强度、变焦 / 旋转控制、构图保持、可定格停留和运动模糊边界，而不是只写 `动感运镜`。
- 是否使用适合截图的运动方式：固定机位长镜头、极缓慢微动运镜、轻微呼吸手持、低抖动稳定画面、缓慢推拉和低幅度摇移是否优先用于家庭纪实、病床、遗像、饭桌、门口对话、遗物和仪式。
- 需要读表情、事实证据、动作结果或剪辑接口时，动态镜头是否给足可读停留；停留时长是否由内容倒推。持续运动、旋转、颠簸或模糊是否有明确情绪职责，还是无意破坏了关键因果。
- 病弱、哭腔、压低声音、隔门闷声、电话失真、VO 回响等是否作为当前镜头状态写入画面内容；正式模型正文是否没有后期备注。

### 参考素材

- 参考图负责锁定什么已写清。
- 参考视频负责参考什么已写清。
- 参考音频负责控制什么已写清。
- 哪些内容不能被参考素材带偏已写清。

### 镜头预演板

- 本轮是否真的需要预演板；老胡只要视频提示词或构图已经验证时，是否避免强制生成。
- 预演板是否明确给图片模型和人审，而不是默认作为 Seedance 输入。
- 同一个 `VID` 的预演板和视频提示词是否使用同一组关键画面节点；预演板可以用格号或镜头编号人工对齐，正式视频正文是否改用连续动作节点和切换桥梁，没有逐秒时间码和项目内部代号。
- 预演板是否是黑白 / 灰阶低保真构图骨架，只锁构图、景别、机位、主体比例、空间关系、视线、动线、切换点和留白。
- 是否没有锁真实人物脸、服装颜色、最终材质、最终光影和完整电影美术。
- 需要模型参考构图时，是否另行生成或挑选无表格、无箭头、无文字、无多格拼图的干净首帧 / 构图参考图。
- 如果使用首尾帧接续，上一条停点和下一条开场是否保持同一构图、空间锚点、光源方向和动作余势。
- 如果使用同次生成的首尾帧模式，是否把它与跨片段接续区分；双端参考、端点兼容性、中间状态链、尾帧召回和落帧验收是否完整。

## 二、生成后评分

每项 0-2 分：

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 角色一致性 | 明显变脸或变装 | 局部不稳 | 基本统一 |
| 首尾帧落准 | 首帧漂移、过程跳变或尾帧未落准 | 两端大致接近但比例、透视、光色或姿态仍跳 | 首帧稳定，中间因果连续，尾帧提前召回并准确收束 |
| 镜头任务 | 看不出任务 | 大致完成 | 清楚完成 |
| 观众代入强度 | 只能从外部认出人物情绪，不知道目标代价，也未共享信息、空间、身体、时间或选择 | 部分对齐成立，但进入角色的过程断裂或过快 | 本段用必要的目标、信息、空间、身体、时间或选择路径让观众共同经历，并留下余波 |
| 主情绪目标 | 多个情绪同等并列，观众不知道该感到什么 | 主情绪大致可辨，但部分表演、光色或声音信号冲突 | 一个节拍一个主情绪，转折有起点、触发、变化和终点，多镜形成情绪曲线 |
| 节奏密度 | 中段空转或切换无任务 | 有推进但信息点 / 冲突点 / 情绪点间隔不稳 | 信息、冲突、情绪或动作爆点匹配体量 |
| 动作自然度 | 扭曲或跳变 | 有小问题 | 自然可信 |
| 文戏表演 | 台词像主题总结，没有关系动作 | 台词目的可辨，但后果或承重表演证据不足 | 关键台词有关系目的和可读后果，潜台词、表情、停顿、距离或反应按需准确 |
| 武戏受力 | 动作飘乱，只剩炫酷词 | 力量来源、路径、接触或结果仍有缺口 | 动作因果清楚，承重节拍再准确使用起势、受力、反应、爆点或停帧 |
| 表演控制 | 情绪不对或过度 | 基本接近 | 准确有层次 |
| 构图可用性 | 影响观看或后期 | 勉强可用 | 清楚稳定 |
| 壁纸帧 / 审美停点 | 承担视觉记忆却没有稳定落点 | 有落点但与主情绪冲突或证据不清 | 承重镜头形成准确记忆点；功能镜头标记 N/A |
| 构图逻辑 | 主体落点与主情绪互相冲突 | 落点可读但部分关系抢戏 | 被选中的裁切、位置、线、块面或留白共同服务主情绪；不承重项标记 N/A |
| 光影体系 | 只写自然光或光源乱闪，画面平灰 | 有时段或光型，但主辅轮廓、阴影或反光不完整 | 时段、主光、弱辅光、轮廓 / 反光、阴影层次和动态稳定都清楚 |
| 色彩体系 | 高饱和撞色、无主次、无统一色调 | 有色调但主辅点缀、过渡或分级不稳 | 主色、辅助色、点缀色、环境色反光、过渡和统一分级清楚 |

## 三、常见失败对应修正

| 失败现象 | 常见原因 | 修正方式 |
|---|---|---|
| 角色变脸 | 参考图不稳定，基础设定不够 | 先做角色定妆图和三视图，视频提示词减少外貌变化 |
| 动作乱 | 单镜头存在多条互不相干的动作或注意力链 | 保留一个主观看任务，把相关动作组织成一条因果链；其余任务删减或拆镜头 |
| 运镜晕 | 运镜叠加过多 | 保留一种运镜，或改为固定镜头 |
| 表情夸张 | 情绪词太泛 | 写表情强度、性格边界和时间轴 |
| 风格冲突 | 风格词互相打架 | 只保留一个风格核心，删除矛盾词 |
| 拼接断裂 | 各镜头没有统一规则 | 增加全局基础设定和后期衔接备注 |
| 声音抢戏 | 声音策略不清 | 明确只保留同期声、无配乐或指定配乐功能 |
| 人物跨镜头换声 | 人物资产未写基础声线，或每条提示词随意改音色 | 在人物资产行补基础声线；当前镜头的病弱、哭腔、电话失真、隔门闷声只写进画面内容 |
