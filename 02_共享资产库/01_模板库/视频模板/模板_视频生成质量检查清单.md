# 模板_视频生成质量检查清单

> 用途：生成前检查提示词，生成后诊断结果。重点不是“好不好看”，而是是否服务作品。

## 一、生成前检查

### 商业转化链（仅电商 / TVC / 品牌 / 获客作品）

- 是否先写清转化目标、目标人群、使用场景和真实购买矛盾，没有把“拍得高级”当成商业目标。
- 是否只有一个核心承诺，2-4 个支撑卖点是否都为同一购买结论服务，没有念完所有参数。
- 每个卖点是否都有用户处境、问题触发、产品结构 / 功能参与、接触 / 受力、可见 / 可听结果和用户利益，没有用 VFX、参数浮层或口号代替证据。
- 老胡未给文案时，是否已判断文案是否对转化承重；承重时是否已主动设计钩子句、卖点句和品牌 / 行动句。
- 文案是否与当下画面证据同向，是否没有编造真实产品的性能数字、成分、疗效、认证、绝对化词或竞品对比。
- 结尾是否让观众知道这是什么产品、属于谁、下一步做什么；不需要强行“立即购买”，但必须有符合本条转化目标的行动出口。

### 基础设定

- 是否先确定模型路由，并在最终一次正文修改后运行 `skills/laohu-video-prompt/scripts/count_video_prompt_chars.sh` 实测单个正式 `text` 代码块字符数：Seedance 2.0 `≤4000`，Seedance 2.5 本项目配置 `≤10000`，模型未明确或跨版本共用 `≤4000`；是否没有把项目配置冒充平台公开官方硬上限，也没有人工估算、沿用旧数字或把完整文件、资产提示词、故事板和验收表误算进上限。
- 是否只列本条实际上传或绑定的人物、场景、道具、色卡、动作 / 音色和首帧参考。
- 是否删除了只为提醒作者、但本镜不出镜也不参与声音 / 动作 / 空间的资产。
- 参考图容易误导或本镜临时状态变化时，是否只补了一句必要约束，而不是重复整份资产说明。
- 是否明确只生成对白、同期动作音效和环境声，默认不生成 BGM。
- 输出限制是否只保留无字幕、无水印、身份一致、基本物理逻辑等少量抽象边界，没有堆当前案例的具体错误对象。
- 会出声的人物是否保持同一音色锚点；本镜声音变化是否跟随表演写进对应镜头。

### 场景状态与氛围画质

- 是否先写清视频开始前已经成立的空间边界、人物与道具初始位置、天气、人群活动和现有破坏。
- 是否把开场以后才发生的入场、玻璃破碎、天气突变、环境破坏和局部光色变化留在对应镜头块，而不是提前写成初始状态。
- 是否只保留 1-3 句跨全部镜头成立的主风格、摄影介质和宏观色彩基线。
- 主风格是否从“电影感”收窄到明确影像母体与真实程度。
- 全局画幅、颗粒、稳定度和色彩关系是否统一。
- 局部焦段、光源、材质、雾气和对象 HEX 是否已经移入对应镜头。
- 删除任何一句后，如果只影响某一镜，是否已把它移出全局段。

### 画面内容

- 是否在正式代码块外建立素材剪辑接口卡：素材主任务、推荐入点、内部可切节点、推荐出点、主要 / 辅助匹配属性、干净把手、不建议裁切点和后期依赖是否齐全。
- 每个接口是否形成 `出镜证据 → 可读边界 → 入镜证据`，并优先守住主情绪、故事信息与节奏；是否避免为了匹配形状、黑白场或甩镜牺牲动作因果和人物表演。
- 正式三段正文是否把接口编译成动作、屏幕方向、观众视点、视线 / 焦点、图形、遮挡、明暗、声音或停点的可见 / 可听结果，没有出现 `入点、出点、剪这里、J-cut、L-cut、后期抠像` 等作者说明。
- 接口数量是否服从内容：一镜到底表演没有被切碎；动作、舞蹈、MV 和广告的内部节点确实对应新动作相位、节拍、卖点证据或品牌停点；没有固定要求每条素材使用几种转场。
- 后期依赖型接口是否提前提供干净轮廓、完整遮挡、稳定替换平面或可跟踪运动，并在代码块外标记所需抠像、蒙版、绿幕、屏幕替换、变速、叠化或关键帧。

- 是否通过屏幕可观察性检查：每个实义句都能在成片里被直接看见、听见，或通过景别、构图、屏幕方向、焦点、透视、地平线、遮挡和镜头运动直接感到。
- 角色意图、内心判断、力学解释、胜负总结和情绪结论是否已经翻译成身体、兵器、环境、材质、声音与画面变化；是否没有让模型补小说因果。
- 正式正文是否使用 `镜头 + 屏幕结果`，没有用机身、轨道、摄影设备到达某点等幕后设备叙事代替主体大小、位置、背景视差、焦点和最终构图。
- 画外事件是否只通过画外声、光影、影子、反射、飞入物、遮挡变化或画内人物反应进入；是否没有直接讲述观众既看不见也听不见的画外动作。
- 是否完成四核：主体与注意力目标、动作与表演、效果系统、节奏与时长是否形成同一条观看因果链。
- 每个独立镜头是否以 `[景别][运镜 / 转场]` 头部开始；同一镜头是否只保留一个头部并写完整连续路径；机位不连续时是否在第二个括号明确硬切、遮挡转场、甩镜转场或匹配剪辑。
- `【画面内容】` 内每个镜头是否以 `【镜头01｜景别｜机位 / 视角｜运镜 / 转场】` 独立分块并连续编号；是否按需在本镜描述后附 `【VFX】`、`【环境音】`、`【动作音】`和`【音乐 / 节拍】`；冻结台词是否直接嵌入当前镜头正文并连接表演、听者反应和摄影机，而不是另列`【台词】/【对白】`；没有内容时是否直接省略，而不是机械填写匿名“无”。
- 环境音是否写当前空间持续声场，动作音是否写当前接触或运动的同步声音；是否没有只在全段末尾列一张无法对齐镜头的声音清单。
- 普通功能台词是否在人物动作中简短嵌入；情绪承重台词是否同时展开开口前动作、说话对象、重音 / 气口 / 口型、眼神、面部、呼吸、姿态、身体距离、听者准确反应和句后停点。
- 是否通过最低充分控制密度：复杂单元仍有承重人物、空间坐标、触发、表演、摄影机、声光环境、结束状态或后半段需要模型猜测时，是否继续补足；是否既没有为接近字符上限同义反复，也没有把“不凑上限”当成一两千字符提前停止的理由。
- 复杂对白、沉默反应、长表演或多人对手戏是否先完成八维内部排演：时间段、人物目的、情绪变化与保护策略、精确触发、面部动作与可选 AU、目光身体与关系距离、声音呼吸与停顿、结束状态与静止反应；是否没有把八维机械显示成正式正文八个标题。
- 人物目的是否写成要让对方做什么、相信什么、停止什么或想掩盖什么，而不是 `想要尊严、很委屈、很愤怒` 等心理概括。
- 触发是否精确到台词、重词、动作、声音、视线或信息；反应是否确实晚于刺激；是否明确触发前不得提前出现的眼泪、崩溃、吼叫、退缩、转身或道具动作。
- 脸、目光、身体、声音、呼吸和距离是否按人物控制能力先后泄露，而不是同一帧同时拉满；台词结束后是否保留静止反应和下一节拍入口。
- 正式正文是否按复杂度编译：功能表演简写，单次转折保留承重因果，复杂长表演全局写一次不变量、后续只写变化量；压缩是否删重复而没有删掉目的、触发、禁止提前反应和结束状态。
- 使用 FACS / AU 时是否先写自然语言，只在近景、脸部清楚且动作承重时附少量 AU；是否避免情绪公式、编码堆叠和 A-E / 0-5 混写。
- 每镜是否只有一个主注意力目标；景别、焦点、运动、明暗色彩、导引线和声音是否共同指向它；注意力迁移是否有视线、动作、焦点、声音或切镜触发。
- 每个情绪节拍是否只有一个主情绪目标；是否分别回答注意力目标、观看任务和情绪目标；表演、运镜、光色、声音和停点是否共同指向它，没有让多个情绪以同等权重竞争。
- 是否区分情绪识别和观众代入：观众除了看懂人物情绪，是否知道人物为什么在乎、会失去什么，并通过本段真正承重的信息、空间、身体、时间或选择路径与人物共同经历。
- 段落是否按需要完成进入处境、与人物对齐、共同经历和拉开沉淀；是否避免把全程 POV、贴脸特写、手持抖动、快速切镜和强音效误当成唯一代入方法。
- 情绪转折镜头是否有明确起点情绪、可见 / 可听触发、变化路径和终点情绪；没有变化因果时是否拆镜头处理。
- 每个专业字段是否真正增强主情绪：构图、光影、时间、姿态、场景、色彩、材质、运镜和声音中，无关字段是否删除，削弱、稀释或转移情绪的内容是否改写或降权。
- 是否先完成 `主情绪 → 观众 / 主角感知关系 → 动作 / 表演 → 摄影机 / 运镜 → 技术校准` 的顺序；是否没有先填空间、材质、射界和状态，再把情绪作为补充说明。
- 运镜是否让观众共同经历主角的距离、速度、方向、失衡、压迫、反击、震撼或余悸；是否明确摄影机站在谁的感知位置，而不是只写“炫酷、快速、电影感”；每个镜头头部是否只有一个主要情绪功能。
- 动作导演是否先设计情绪承重的危险、选择、发力、受力和结果；穿模、道具、站位、切镜、材质和生成稳定性是否只是保护这条情绪路径，没有反过来削弱它。
- 动作与表演是否从起始状态、触发、路径速度、接触受力、可见结果、反应走到结束状态；情绪是否有台词态度、表情、呼吸、肢体、距离或声音证据。
- 复杂人体动作是否有姿势相位：起始轮廓、约束解除、支撑点转换、肩胸骨盆与关节链、重心 / 旋转轴、四肢净空、首次落地、缓冲卸力和结束轮廓；是否仍停留在 `翻身 / 跳下 / 旋转 / 摔倒` 等动作名称。
- 多主体运动是否逐一锁定世界坐标、屏幕坐标、朝向、速度 / 加减速、景深层、路径、外力、相对顺序、终点和出画顺序；共同运动体分离后是否保留惯性；摄影机跟随速度与轴线是否和对象世界运动分开描述。
- 是否存在没有因果的反向、超越、瞬移、停住、换层或出画顺序颠倒；人物、坐骑、车辆、群像、投射物、关键碎片和摄影机的相对关系是否能被连续排演。
- 重大位移或遮挡切换后是否重新建立主体、攻击来源、地面 / 道路边界和摄影机观看侧；局部手腕、暗器或碰撞点是否有清楚空间来路。
- 承重动作是否有帅点捕捉：危险逼近、提前占位、短路径处理、接触瞬间短暂清晰、结果继续高速运动和余势停点是否连成一体；停点是否由动作结果产生而非摆拍。
- 目标为炫酷高速群战时，是否建立主角、近战敌群、远程投射物、摄影机和环境五层速度；攻击是否按扇区和距离半拍错位、重叠进入，而不是每名敌人轮流出招。
- 高速武戏是否按动作组组织，而不是按单招流水账组织；每组是否有压力建立、连续变化、决定性反转 / 升级和可见桥接，桥接动作是否同时成为下一组的真实起点。
- 多人压力是否做到威胁并发、力量关系可读；决定性接触可以串行或一对多，但同一节拍是否只有主角震开、敌方压退或技术卸力中的一个明确结果。
- 一对多同时接触是否写清各攻击来源、不同接触位置、主角支撑点、合力方向、位移 / 形变、胜负和情绪结果；轻灵技巧型角色是否只短暂架力并迅速改角、卸力或换位。
- 势均力敌、中度占优、压倒性碾压和弱势求生是否采用相符的交换次数、动作规模和解决方式；是否避免绝对碾压却长时间缠斗，或中度占优却提前范围清场。
- 摄影机是否与动作组一起设计，完成攻击几何建立、沿力线追击、爆点提清和余势出组；是否没有在动作写完后只补一句 `快速环绕 / 炫酷运镜`。
- 景别是否承担正确尺寸的证据：较远景别交代阵形、方向和结果尺度，全景 / 中远景展示完整动作与位移，中景 / 中近景展示攻防关系，近景 / 特写展示接触、手部与表情；多人合击是否按需完成 `几何 → 接触 → 结果`。
- 同一主体连续切换时，若轴线、构图和动作相位近似，是否跨过一个景别、改变约 30 度机位，或用明确动作 / 信息 / 构图变化避免误切；是否没有把该经验机械化。
- 真实性规则是否在保留主动破局、速度、运镜和环境奇观的前提下校准攻击通道；是否没有把提示词写成谁等待、谁补位、谁让射界的战术说明书。
- 大量敌人是否拥有真实交战面容量和不同人员状态；当前接触人数是否受空间宽度、武器射程、友军遮挡、挥舞净空与误伤约束，避免对称圆阵、长兵器辐条和所有人同时命中一点。
- 被围主角是否通过移动破坏包围几何并建立可信生存路径；远程组是否拥有不穿过近战友军的安全射界。
- 每次兵器相撞、武器命中人物或落空破坏环境时，是否写清材质、接触点、力量方向、声音、形变 / 破坏、人物受力和环境余波，而不是统一火星、闷响和随机爆炸。
- 提示词是否在同一呼吸内组织多条攻击线，上一招的改向、遮挡、失衡、飞散物和空位是否立刻触发下一招；人物是否没有频繁停稳、回正和重新起势。
- 接触点清晰是否通过高快门感、跟踪对焦、方向反差和材料反馈完成；`摄影机停止、缓慢推近、慢动作、定格、稳定停住` 是否只在真正承重的少数瞬间出现，没有把整段节奏压慢。
- 主要交战者是否有可辨认的角色动作语法：距离、起势、攻击几何、防守 / 借位、场景利用、回收方式和能力边界是否符合身份；是否避免所有角色共享同一套通用连招。
- 群战是否让上一招的遮挡、失衡、空位、掉落物或反作用力成为下一招条件；是否避免每名攻击者依次走到正面、人物恢复默认站姿后重新开打。
- 本段是否选出一个真正承重的决定性瞬间；摄影机是否让危险线、人物轮廓和结果证据同时可读；特效、拖影、火花、水花和碎片是否证明物理与情绪，而没有淹没主体。
- 爆炸、坍塌、炮击、撞击或能量事件是否有来源、命中点、传播方向、承力结构、材料失效顺序、碎片分组 / 飞散锥、二次碰撞、烟火压力、遮挡、声音、摄影机响应和永久终态，而不是只有结果词。
- 效果系统是否按需要选择焦点、运镜稳定、环境天气、光色、速度、声音和转场；每个效果是否有来源、变化过程、可见 / 可听结果和情绪职责。
- 运镜具象化是否完成：内部是否按观看意图、摄影机物理路径、屏幕变化、情绪倾向和停点推导；正式正文是否写清镜头方向轨迹、速度稳定度、主体 / 背景 / 焦点 / 地平线变化和最终构图，没有暴露观众看不见的设备过程。
- 运镜是否只作为情绪倾向而非固定字典；推、拉、摇、移、FPV、横滚、机械臂或希区柯克变焦是否结合当前主体、起终景别、焦点、速度、声音和上下文选择。
- 时长是否覆盖主体识别、动作完成、情绪建立、效果展开和停点 / 切换余量；内容过载是否通过加时长、删效果、减镜头或拆素材解决。
- 复杂内容是否先提高控制精度，而不是默认降级为单人、单招、少道具或固定镜头；场景链、摄影机链、人物链、道具链和事件链是否在每个关键接触点指向同一时空状态。
- 场地边界、通行净空和环境锚点是否从开场持续继承，没有为了接住兵器、人物或镜头临时长出竹子、墙、车辆、建筑或其他障碍物。
- 遮挡、甩镜、水幕、烟尘或主体掠镜是否只覆盖摄影机已经建立的连续运动；掠开后是否仍能根据前一位置、方向和距离推导当前机位，没有借遮挡瞬移、跨轴、人物重置或换景。
- 每名人物的结束姿势是否直接成为下一动作起点；每件关键道具是否保持唯一归属、数量、方向、握持 / 脱手 / 损坏 / 落点和后续状态，没有复制、恢复、换手省略或穿过身体。
- 是否按图生视频 / 文生视频 / 实际资产输入调整描述预算：输入已固定的外观少重复，未资产化主体和场景写足。
- 首尾帧双端锚定模式是否同时引用首帧和尾帧；是否完成端点兼容性分析，写清不变量、变化量、共同桥梁和最大断裂点。
- 中间变换链是否有触发、有因果、有连续状态；摄影机路径是否服务主变换；尾帧元素是否提前召回，结尾是否减速校正主体比例、位置、景别、透视、地平线和焦点后再落帧。
- 多个 `VID` 是否先区分直接连续、同场重建和关系重置；是否只在直接连续时优先使用上游尾部视频，同场重建改用终帧 / 构图参考，关系重置不机械调用上一条。
- 直接连续的参考片段是否来自 A 最后一次切镜之后的单一机位；是否没有把硬切前后两个构图、强遮挡、严重失焦、错误人物状态或反向运动一起投喂；不合格时是否缩短或退化为终帧。
- A 的交接点是否完成当前动作结果并提前出现下一压力；是否避免未完成兵器接触、未知落点、飞行中投射物和未兑现爆炸，也没有为了交接增加无剧情职责的空镜。
- 交接卡是否分开记录世界状态与屏幕投影；人物相对场景锚点、朝向、持物、伤势和永久破坏是否硬继承，画面左右、景别与观看侧是否只在重新建立空间后改变。
- B 是否在基础设定引用实际上传的连续性参考并写清职责，在场景状态重建自足事实，在画面内容直接进入新动作；是否没有复演 A 或只写 `承接上一段`。
- 分镜表、预演板和正式视频模型正文是否都使用能够互相对齐的连续镜头编号；正式正文是否保留 `【镜头01｜景别｜机位 / 视角｜运镜 / 转场】` 方头来声明真实机位边界，同时去掉项目内部节点名、格号和 `0—2秒 / 2—5秒` 绝对起止区间。镜头方头只标顺序，镜间连续性仍由动作、遮挡、视线、焦点、声音或运动方向承担。
- 正文每次切换是否写清前一画面的动作、遮挡、视线、焦点、声音、光色峰值或运动方向怎样触发摄影机变化；切换后的画面是否继承人物姿势、道具状态、动作余势、空间方向和声场。
- 每个承重人物是否完成`人物动机—行动校准`：台词、即时目的、选择的动作和道具是同向、有因相反还是无意冲突；有意相反是否被迟疑、改手、撤回、眼线、对手反应或后续选择证明。
- 被拿取、递交、争夺、隐藏、消耗、破坏或跨镜继承的物品是否有`道具状态账本`；镜前支撑、接触与控制权、受力路径、镜后支撑和下一镜状态是否闭合，是否没有悬空、瞬移、易手、数量漂移或无因消失。
- 每个切点是否有`剪辑承接合同`：A镜完成结果、共同载体、B镜第一证据和新增信息能否连续复述；切掉的只是路程 / 重复 / 等待，还是误删了新的选择、障碍、物体状态或关系转折。
- `省略成立门`是否通过：动作目标已经确定，主体与控制权连续，方向 / 目的地 / 结果至少有明确桥梁，后镜兑现结果；是否没有用`观众会脑补、自然衔接、转场过去`替代证据。
- 两镜以上共同完成同一人物选择、道具操作或连续动作时，正式`【画面内容】`是否先有一至三句连续动作主线；它是否用画内事实锁定同一人物 / 物体、动作顺序、控制权变化和最终状态，并与全部逐镜正文一致。
- 动作镜头尾部是否在结果落下时提前露出下一威胁的刀尖、影子、视线、脚步、链响、机关声或运动物，并把摄影机方向交给它；下一镜是否从同一线索的下一相位开始，使观众在切换前已经预判趋势。
- 两个独立机位之间是否出现新的方括号镜头头部；硬切或软切机制是否进入第二个括号；是否避免用换行、`随后画面出现` 或无物理路径的运镜让模型猜切换。
- 如果没有新的镜头头部，摄影机是否确实拥有从起点连续到达新景别 / 新机位的真实路径、速度和观看侧变化；否则退回重写。
- 镜头数量是否由目标体验决定：连续跟拍 / 少量长镜头是否真正强化了真实时间、空间、完整身法或持续控制；高强度多切是否真正强化了攻击密度、速度、冲击、失衡或压迫；混合结构是否在空间建立、爆发覆盖和结果沉淀之间形成清楚节奏。
- 是否没有用固定镜头数或平均镜长倒推内容；15 秒使用约 10 个快速镜头时，是否每个镜头都增加新的动作相位、视角证据或情绪压力；使用少量镜头时，镜头内部是否有足够丰富而连续的动作与摄影变化。
- 完整动作单元是否闭合；若一个动作单元跨多个短镜头，各镜是否分别承担来路、接触、脚步、受力、反应或空间结果，并在切换后进入下一相位，而不是重新起招。
- 高频动作覆盖是否与快闪蒙太奇区分：前者保持人物姿势、动作手、武器归属、屏幕方向、运动余势和声音连续，后者才用于时间压缩或并置信息。
- 每增加一个镜头，是否增加新的信息、情绪、空间关系、动作阶段、视觉证据或节奏压力；只有没有观看价值的重复角度才合并，只有总时长无法兑现核心结果时才删减或拆条。
- 总时长是否在 Seedance 平台参数中设置；首测是否默认 720p。
- 每个镜头只有一个主观看任务；发生动作链时，链内动作共享同一注意力和情绪方向，并写清实际发生的起点、触发、路径、结果或停点，不要求五项齐全。
- 是否完成承重字段审计：主情绪证据和生成必需信息已经写清；景别、机位、运镜、光影、HEX、材质、环境、同期声、切换和停点只保留本镜真正使用的部分，没有机械全填。
- 是否已经判断本镜类型：文戏、武戏、转场、空镜、表演、动作、信息揭示或审美停点。
- 是否完成文戏 / 武戏情绪入场分流：第一有效节拍是否已经让观众感到关系压力或力量压力；所谓“尽快带入”是否避免被误写成所有题材统一快剪。
- 节奏密度是否匹配体量：15 秒、30 秒、60 秒或 1-3 分钟内容是否有对应的信息推进、冲突推进、情绪推进或动作爆点；慢节奏是否有情绪压力，快节奏是否看得清动作因果。
- 文戏关键台词是否有关系目的并造成可读后果；潜台词、表情、停顿、关系距离和反应镜头是否按主情绪选择，未机械全填。
- 文戏开场是否尽快建立 `人物想得到什么 + 对方 / 处境为何不给`；平静、停顿和长镜头是否持续增加关系压力，而不是空转。
- 武戏 / 动作是否先让力量来源、路径、接触点和结果可读；起势、发力、受力、反应、爆点和停帧是否只出现在承担对应职责的节拍。
- 高武、机甲、枪战、追逐、超能力或爆炸是否建立 `预载 / 蓄力 → 瞬时释放 → 高速位移或力量传播 → 极短接触 → 明确结果 → 余势继续`；不同题材是否换了发力介质，而不是只替换武器名。
- 高速是否至少有位移、发力、环境、摄影 / 声音中的两类可感证据；瞬移观感是否仍有发力点、落点和介质反馈。
- 角色能力等级是否通过预动作大小、有效路径长度、接触时长、结果规模和控制精度拉开；高手是否没有被写成普通动作加速或慢动作摆招。
- 镜头切换是否有任务：为什么现在切，切掉了什么信息，切进来增加了什么压力，观众情绪被加速、压住、误导还是释放。
- 景别和构图服务动作。
- 运镜不超过镜头承载能力。
- 表演有清楚起点、触发、变化和停点，而不是一个情绪词。
- 面向观众且承担视觉记忆的镜头是否有审美停点 / 情绪停点；功能型镜头是否只保持任务完成和可剪辑，不强制壁纸帧；停点是否只使用加强主情绪的承重元素。
- 每个文戏情绪段或武戏动作组是否只选择一至两个承重英雄帧；连接帧是否允许遮挡、甩镜、失衡、局部出画和方向性模糊，避免“帧帧壁纸”导致一招一停。
- 审美停点是否从剧情动作里长出来，而不是无关漂亮空镜、滤镜词或只写“电影感”。
- 观众第一眼是否有明确视觉落点：脸、眼睛、泪、手、道具、树、光点或唯一清晰局部。
- 主体是否通过面积、亮度、颜色、清晰度、反差、位置或运动被突出；画面复杂时主体是否被“加满”。
- 先做承重字段判断：本镜为主情绪、主注意力、动作因果和连续性真正需要哪些构图、光影、色彩、空间、材质、氛围或停点手段；未被选择的项目标记 `N/A`，不因字段少扣分。
- 构图承重时，检查视觉落点是否明确；导引线、空间块面、留白、三分法、对称、框架或黄金分割只选择实际加强落点和主情绪的方式，不要求至少一种经典构图。
- 光影承重时，从时段与真实光源反推方向、软硬、明暗和材质反应；平光、剪影、单一硬光或大片暗部都可以成立。使用动态光时，必须有来源、方向和稳定的运动因果。
- 色彩承重时，检查对象落点、权重和连续性；不固定为 `1 主色 + 1 辅助色 + 1 点缀色`，黑白、单色、自然综合色和有意高饱和冲突均可得满分。
- 空间与焦点承重时，从前景、中景、背景、焦段、焦点、虚实过渡和空气透视中选择必要项；不强制前中后景齐全，不把人像、POV、疏离或群像固定到某个焦段与景深。
- 焦点发生迁移时，检查触发、转移路径和最终落点；固定深焦、全程失焦、方向性运动模糊或主体全程移动也可以是有意结果，不统一要求焦点稳定。
- 材质承重时，只检查与身份、状态、物理因果或主情绪有关的具体表面；不要求每镜同时写分辨率、锐度、微细节、运动模糊、颗粒和洁净度。
- 氛围元素承重时，检查天气、空气、微粒、光斑或环境运动是否有来源和密度；干净空气、静止背景和无微粒同样可以成立。
- 只有承担人物第一眼、情绪峰值、封面候选或传播视觉职责的镜头检查审美停点；功能型镜头不强制壁纸帧，速度冲击和运动连接镜头也不强制可截图。
- 氛围元素是否克制并符合题材：家庭纪实、丧事病床、放学路、浪漫 MV 或强风格化镜头是否使用不同元素；是否避免无来源花瓣、过浓雾、舞台特效感和遮挡关键动作。
- 镜头运动约束是否具体：是否写清机位稳定策略、运镜速度、抖动强度、变焦 / 旋转控制、构图保持、可定格停留和运动模糊边界，而不是只写 `动感运镜`。
- 是否使用适合截图的运动方式：固定机位长镜头、极缓慢微动运镜、轻微呼吸手持、低抖动稳定画面、缓慢推拉和低幅度摇移是否优先用于家庭纪实、病床、遗像、饭桌、门口对话、遗物和仪式。
- 需要读表情、事实证据、动作结果或剪辑接口时，动态镜头是否给足可读停留；停留时长是否由内容倒推。持续运动、旋转、颠簸或模糊是否有明确情绪职责，还是无意破坏了关键因果。
- 病弱、哭腔、压低声音、隔门闷声、电话失真、VO 回响等是否作为当前镜头状态写入画面内容；正式模型正文是否没有后期备注。

- 如果使用跨 `VID` 直接连续，上一条最后有效机位和下一条开场是否保持同一世界状态、屏幕方向、空间锚点、光源方向和动作余势；若属于同场重建，是否保留世界状态但明确重新建立构图。
- 如果使用同次生成的首尾帧模式，是否把它与跨片段接续区分；双端参考、端点兼容性、中间状态链、尾帧召回和落帧验收是否完整。

## 二、生成后评分

每项 0-2 分：

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 角色一致性 | 明显变脸或变装 | 局部不稳 | 基本统一 |
| 首尾帧落准 | 首帧漂移、过程跳变或尾帧未落准 | 两端大致接近但比例、透视、光色或姿态仍跳 | 首帧稳定，中间因果连续，尾帧提前召回并准确收束 |
| 镜头任务 | 看不出任务 | 大致完成 | 清楚完成 |
| 观众代入强度 | 只能从外部认出人物情绪，不知道目标代价，也未共享信息、空间、身体、时间或选择 | 部分对齐成立，但进入角色的过程断裂或过快 | 本段用必要的目标、信息、空间、身体、时间或选择路径让观众共同经历，并留下余波 |
| 主情绪目标 | 多个情绪同等并列，观众不知道该感到什么 | 主情绪大致可辨，但部分表演、光色或声音信号冲突 | 一个节拍一个主情绪，转折有起点、触发、变化和终点，多镜形成情绪曲线 |
| 节奏密度 | 中段空转或切换无任务 | 有推进但信息点 / 冲突点 / 情绪点间隔不稳 | 信息、冲突、情绪或动作爆点匹配体量 |
| 动作自然度 | 扭曲或跳变 | 有小问题 | 自然可信 |
| 文戏表演 | 台词像主题总结，没有关系动作 | 台词目的可辨，但后果或承重表演证据不足 | 关键台词有关系目的和可读后果，潜台词、表情、停顿、距离或反应按需准确 |
| 武戏受力 | 动作飘乱，只剩炫酷词 | 力量来源、路径、接触或结果仍有缺口 | 动作因果清楚，承重节拍再准确使用起势、受力、反应、爆点或停帧 |

## 三、常见失败对应修正

| 失败现象 | 常见原因 | 修正方式 |
|---|---|---|
| 角色变脸 | 参考图不稳定，基础设定不够 | 先做角色定妆图和三视图，视频提示词减少外貌变化 |
| 动作乱 | 单镜头存在多条互不相干的动作或注意力链 | 保留一个主观看任务，把相关动作组织成一条因果链；其余任务删减或拆镜头 |
| 运镜晕 | 运镜叠加过多 | 保留一种运镜，或改为固定镜头 |
| 表情夸张 | 只有情绪词，没有人物目的、保护策略、精确触发和禁止提前反应 | 先补演员节拍因果，再选择承重脸部 / 身体 / 声音通道；近景需要时用少量 AU 辅助，不套情绪公式 |
| 风格冲突 | 风格词互相打架 | 只保留一个风格核心，删除矛盾词 |
| 拼接断裂 | 只有连续性要求，没有可识别的剪辑接口或实际把手 | 先设计出镜证据、可读边界和入镜证据；在代码块外填接口卡，正文写成可见 / 可听结果，生成后回填真实时间码 |
| 声音抢戏 | 声音策略不清 | 明确只保留同期声、无配乐或指定配乐功能 |
| 人物跨镜头换声 | 人物资产未写基础声线，或每条提示词随意改音色 | 在人物资产行补基础声线；当前镜头的病弱、哭腔、电话失真、隔门闷声只写进画面内容 |
