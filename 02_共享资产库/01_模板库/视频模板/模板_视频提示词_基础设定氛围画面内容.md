# 模板：视频提示词_基础设定氛围画面内容

正式提示词代码块前先填写供老胡剪辑使用的接口卡；它不投喂视频模型：

画幅作为生成参数和内部导演判断处理。老胡未指定时按 `16:9` 设计主体占比、留白、运动路线、人物距离和文字安全区；实际比例由生成平台设置。正式视频提示词代码块只写这些判断造成的屏幕结果，不写比例数字、横屏、竖屏、横版或竖版。老胡指定其他比例时必须重新设计构图，不能只换数字；只有明确要求正文携带比例或平台没有独立比例设置时例外。

第二段先写开拍前事实，再写全段风格。开场以后才发生的入场、玻璃破碎、天气突变、环境破坏和局部光色变化必须放进对应镜头块，不能提前写成场景初始状态。

商业广告在代入本模板前，代码块外先填最小商业简报，不新增第四个模型正文字段：

```text
转化目标：
目标人群与使用场景：
购买矛盾：
核心承诺：
支撑卖点（2-4 个）：
每个卖点的画面证据：
钩子句 / 卖点句 / 品牌与行动句：
声称边界：
```

商业 `【画面内容】` 中每个承重卖点都必须完成 `用户处境 → 问题触发 → 产品结构 / 功能参与 → 可见 / 可听结果 → 用户利益`。台词或旁白跟随证据所在镜头命名好处；当文案对理解和转化承重时，不得因用户未提供就默认删除口播 / 旁白，也不得让文案宣称画面没有证明的卖点。

每个新镜头块都以中文方头 `【镜头01｜景别 / 信息尺度｜机位、视窗或构图焦点｜观察路径 / 转场】` 开始，并按实际顺序连续编号；它本身就是镜头边界，不在自然语言正文里重复写独立的 `切镜` 二字。真人、三维动画和空间合成使用实体或虚拟摄影机；二维动画、MG、UI 和字幕动效使用视窗、图层、遮罩、版式重排与焦点迁移；固定机位写明构图不动以及画内发生的变化，不为高级感强造运镜。同一镜头的一镜到底只保留一个头部，可写 `【镜头01｜中景推至近景｜平视正面｜连续手持后退转侧移】`。如果观察位置不连续，头部最后一栏必须明确硬切或软切机制，不能只换行。镜头编号只标顺序，不默认绑定逐秒时间码。

动作镜头之间采用预示性承接：上一块末尾按需同时留下 `本镜结果 + 下一威胁线索 + 摄影机方向`，下一块从同一线索的下一相位开始。线索可以是尚未进入接触的刀尖、地面影子、人物视线、画外脚步 / 链响 / 机关声、旋飞兵器或铺满画面的运动物。遮挡只能隐藏切点，不能让新敌人在遮挡后无预兆出现。

每个镜头头部只有一个主要情绪功能。先确定摄影机站在谁的感知位置、观众需要共同经历什么，再选择景别、观看侧、距离、速度、方向、稳定性、焦点和停点。同一推镜可以表达亲近、发现或压迫；运镜与情绪的一一对应是本镜功能对应，不是固定情绪词典。

VFX 放在画面描述之后，只补充正文已经触发的视觉事件及其可见结果，不重复主体动作，也不能独自新增特效。环境音写正文已经出现的空间声场事件，动作音写与当前接触、运动或破坏同步的声音；音乐承重时增加 `【音乐-X】`，说明正文中的同步事件与重拍、切分、高潮或静音的关系。建议用事件 ID 绑定正文和补充轨；每个标签必须有正文触发点，不能出现孤儿标签、时序漂移或改变主体状态的补充。所有声画字段按镜头分别写，不能只在全段末尾列一张清单。没有内容时省略，不写匿名“无”。

普通功能台词用简短准确的表演词，例如 `【台词】男孩（惊讶、小声）：“妈妈，这个是神吗？”`。情绪承重台词按需展开眼神、面部、呼吸、视线、姿态、身体距离和发声变化，例如 `【台词】男孩（仍缩在母亲怀里，眼睛越过她肩头盯住白羊，呼吸尚乱，声音发轻，惊恐中第一次出现敬畏）：“妈妈，这个是神吗？”`。表演密度由本镜情绪职责决定。

`【画面内容】` 的内部判断是 `主体与注意力目标 + 动作与表演 + 效果系统 + 节奏与时长`。效果系统按本镜实际需要从焦点、运镜、稳定、环境、天气、光色、速度、声音和转场中选择，不要求每个镜头机械填满全部效果。每个短语都要描述屏幕或声音里的真实变化。

每个承重控制句在写入正文前内部补齐 `控制对象 → 本次实际基准 / 起点 → 变化维度 → 方向、幅度或路径 → 可见 / 可听终态`，正式三段式不增加五个标签。比较级、最高级和`继续 / 进一步`只有在本次真实绑定参考或当前镜头起点已写明时才成立，并且仍要给出当前终态的绝对描述。不可变身份 / 结构 / 空间锚点与可变表情 / 软组织 / 动作 / 破坏 / 光色分开；不得用大范围的`保持一致`吞掉本镜变化。`轻微、自然、缓慢、明显、高级、流畅`不能独自承担控制，要落到对象、屏幕参照、变化路径和结束结果。

具体排除对象使用正向唯一结果：声音轨写唯一声源组成，画面写唯一人物与物件，单镜写完整连续路径，文字交给后期时写画面保持纯影像与可替换安全区。真实时间状态中的`尚未落泪、手仍未伸出、门没有打开`可以保留；它们限定当前状态，不是负向生成黑名单。

正式正文采用 `观众屏幕视点`。内部可以先算角色意图、力量关系、摄影设备路径和情绪目的，落笔时只写三类内容：画面内可见的对象与变化；成片可听的声音；景别、构图、屏幕方向、焦点、透视、地平线、遮挡和镜头运动造成的直接观看结果。错误：`她确认对手失衡后借拉力脱困，机身沿弧线靠近`。正确：`对手右膝滑向坡下，双手中的链条随之松弛；她抬脚从链线内侧穿过。镜头保持在交战轴线右侧，沿她右前方弧线靠近，人物由全身扩大到胸部以上，背景逐渐虚化。`

写每个内部镜头节点前先做三问，三问用于内部导演判断，不新增正式字段：`主注意力目标：看哪里；主观看任务：发生什么；本镜主情绪：主要让观众感到什么。` 正式正文将这些节点合并成连续镜头叙事，不显示节点编号。本镜主情绪必须来自一句具体情绪命题，并由表演、景别、运镜、光色、声音和停点共同证明。复杂余味退到第二层，不把多个情绪同等并列。

情绪转折镜头按 `起点情绪 → 可见 / 可听触发 → 表演、摄影、光色和声音变化 → 终点情绪` 写进同一段自然语言。没有触发和变化路径时，拆成两个镜头分别承担情绪，不用“情绪复杂”代替导演调度。

复杂对白、沉默反应、15-30 秒长表演、多人对手戏或模型容易提前泄露结果时，正文前先完成内部演员节拍表：`时间段、人物目的、情绪变化与保护策略、精确触发、面部动作与可选 AU、目光身体与关系距离、声音呼吸与停顿、结束状态与静止反应`。`禁止提前反应` 作为贯穿约束，写明哪一个触发或峰值之前不得落泪、崩溃、吼叫、退缩、微笑、转身或完成后续动作。

八维在内部默认完整判断，正式正文不增加八个标签。功能表演只写态度、可见动作 / 声音和结束状态；单次承重转折把人物目的、保护策略、触发、2-4 个承重通道、禁止提前和结束状态压进一个因果句；复杂长表演按节拍写 `上一状态 → 新触发 → 本次变化 → 新结束状态`，场景、身份、基础声线和已经成立的状态只写一次。某维会改变结果且不能由当前镜头块可靠继承时必须写入；只有不适用或本节拍没有变化时才省略。

正式压缩只删重复，不删承重因果：先删作者解释、理论名称、重复外观和同义情绪词，再合并字段标签、上移全局不变量、后续只写变化量。AU 先用自然语言动作支撑，只在近景且确有校准价值时附 1-3 个；AU 不是情绪公式，FACS A-E 不与工具 0-5 混写。字符仍超限时删非承重效果或拆 VID，不删人物目的、精确触发、禁止提前反应和结束状态。

写正文前先做情绪入场分流，不新增正式字段：文戏先问 `人物想从关系中得到什么、阻力是什么、第一有效节拍用哪句台词 / 沉默 / 反应 / 距离变化让观众感到它`；武戏先问 `危险从哪来、谁掌握主动、第一有效节拍用哪次预载 / 逼近 / 选择 / 结果让观众身体上感到它`。混合镜头逐节拍确定谁主导，另一类内容只加强主情绪。

高能动作按开放链条组织，不照抄题材示例：`预载 / 蓄力 → 瞬时释放 → 高速位移或力量传播 → 极短接触 → 明确结果 → 余势进入下一动作`。武侠可用脚底、腰胯和兵器，机甲可用关节锁止、伺服与推进器，枪战可用预瞄、扳机与后坐，爆炸 / 科幻可用能量积聚、结构应力和冲击波；其他题材按同一因果推导。高速必须留下发力点、起终位置、环境反向响应、惯性 / 拖曳、声音时差和结果，不写无来源瞬移。

多人武戏使用 `威胁并发、力量关系可读`：决定性接触可以串行，也可以一对多同时发生；同一节拍只保留一个明确结果，例如主角震开合击、敌方合力把主角压退，或主角受压后改角卸力脱困。多人接触写清攻击来源、不同接触位置、主角支撑、合力方向、位移 / 形变、胜负和情绪结果；缺少这些证据时才拆成高速串行接触。轻灵技巧型角色只短暂架力并迅速借力换位，重型力量型角色才适合持续扎根硬抗。相对能力差决定使用多次交换、高速逐个击破、极少动作清场还是地形逃生。

景别按证据尺寸选择：远景 / 大全景交代环境尺度、群体阵形、危险来路和结果范围；全景 / 中远景展示完整身体、步法、兵器轨迹和位移；中景 / 中近景展示攻防关系、重心与上半身表演；近景 / 特写展示接触点、手部、呼吸、眼神和表情；大特写只承载单一关键细节。多人合击可按 `较远景别建立几何 → 较近景别提清接触 / 支撑 / 表情 → 较远景别兑现位移与结果` 组织。切同一主体时，相邻景别若轴线、构图和动作相位近似，优先跨过一个景别或改变约 30 度机位；这只是连续性经验，有明确动作、信息或构图变化时可使用相邻景别。

每个文戏情绪段或武戏动作组只选一至两个承重英雄帧。文戏英雄帧来自关系或表演结果；武戏英雄帧来自蓄势轮廓、决定性接触或结果控场。连接帧允许遮挡、甩镜、方向性运动模糊、失衡和局部出画，不能要求帧帧静态壁纸。正式正文把英雄帧写成事件自然形成的构图与短促清晰点，不写人物停下来摆 Pose。

构图、光影、时间、姿态、场景、色彩、材质、运镜和声音按情绪贡献选择，不机械填满：能加强本镜主情绪的写入正文；无关的省略；会削弱、稀释或制造并列情绪的删除、改写或降权。

时长按 `主体识别 + 动作完成 + 情绪建立 + 效果展开 + 停点 / 切换余量` 倒推。简单动作可以短，渐变情绪、复杂受力、天气变化、奇观展开、焦点迁移和多次切镜需要更长；装不下时加时长、删次要效果、减少镜头或拆成多条素材后期剪辑。普通动作不机械使用逐秒时间码；只有高速连锁、亚秒接触、延迟结果、极短反应窗口或停点保持时间无法靠自然语言稳定控制时，才在对应镜头内部加入少量相对时长约束。

### 速度与时间动力（承重时按需）

先区分 `动作速度 / 摄影机速度 / 切镜速度 / 信息速度 / 声音速度`，只选择真正改变本镜观感的一至三层。内部按 `速度意图 → 主速度承载者与参照物 → 起点状态 → 蓄势 / 启动 / 加速 / 峰值 / 接触 / 余波 / 停点 → 摄影机与切镜响应 → 声音完成点` 设计，再把必要因果压入对应镜头；不把这条链另做一级标题，也不机械填满全部相位。

`高速、迅速、激烈、慢动作、快切` 不能独自承担速度。写清谁相对什么加速或减速、背景和前景怎样位移、接触发生在哪里、摄影机何时跟随或制动、结果怎样保持。人物、摄影机、背景、VFX 和切镜不得默认同时加速；先保住方向、接触和结果，再用 `停 → 动、慢 → 快、密 → 空、高速 → 硬停` 产生速度对比。复杂速度任务读取 `skills/laohu-video-prompt/references/09_速度节奏与时间动力设计.md`。

### 音乐-画面节拍合同（有音乐时必做）

如果提示词主动生成、引用或明确要求音乐，不能只写曲风、BPM 和情绪。先在内部确定音乐段落与本段主视觉事件，再把结果逐镜编译进 `【音乐 / 节拍】`：

```text
音乐段落：前奏 / 进入 / 推进 / 留白或 Break / 高潮 / 尾奏中的实际职责。
拍前蓄势：动作、运镜、遮挡或图形在承重拍之前怎样准备。
同步完成点：动作接触、切镜、转场闭合、VFX 峰值、构图锁定、标题形成或光色反转与哪类强拍 / 乐句边界同落。
拍后余波：完成后怎样停住、衰减、回弹或交给下一视觉短语。
不同步边界：对白、连续动作、表演或故意切分的哪部分不能被机械切碎，以及在哪里重新合拍。
```

强拍承担大变化，弱拍 / 细分拍承担脚步、UI、粒子和连续小运动，长音承担持续变形，休止承担蓄力与停点。卡点看视觉事件何时完成，不是每拍都切镜。固定歌曲和精确节奏优先调用音频参考；纯文生音乐只承诺段落、强弱拍和声画关系。没有音乐时，这一合同不强制；动作音和环境音仍可形成疏密、重复与强弱，但先服从材质、接触、空间和叙事真实。

### 镜内相对时长约束（按需）

时间约束不取代镜头方头，只能嵌入单个镜头的详细内容。优先选择最接近控制目的的一种写法：

```text
顶镡到刀刃离鞘一掌宽控制在0.2秒内。
刀刃接触后0.1秒内，裂缝先沿接触点扩散，随后才爆开，不得提前爆炸。
完整标题形成后稳定保持至少0.8秒，背景运动同时降到最低。
```

一个复杂镜头通常只保留 `1-3` 个会改变结果的相对时长约束。默认不写 `【本镜0.0-0.2秒】`、`【片内14.2-15.0秒】` 等绝对起止区间；这些区间会把事件绑死在固定片长，无法把同一提示词从 15 秒伸缩到 30 秒。只有明确绑定锁定音频、真实时间码或固定播出点时例外。时间数字只锁动作完成速度、触发后延迟、反应窗口与结果保持，动作路径、接触、受力、屏幕结果、运镜和声音仍要写全。这里是生成前约束，不是生成后真实可用时间码；真实剪辑点由生成复盘回填。

运镜必须按 `观看意图 → 摄影机物理路径 → 屏幕变化 → 情绪倾向 → 停点` 展开。推、拉、摇、移、环绕、FPV、横滚、机械臂和希区柯克变焦只是开放术语示例；情绪由当前主体、起终景别、速度、稳定方式、焦点、声音和上下文共同决定，不机械套用固定含义。

## 首尾帧双端锚定模式

首尾帧模式仍使用上面的三段式，不增加第四段。`【基础设定】` 中把普通首帧占位改成：

```text
【首帧参考@图1】固定开场主体、构图、景别、透视、光源和空间锚点。
【尾帧参考@图2】固定结束主体、构图、景别、透视、光源和空间锚点。
```

写正式提示词前内部分析：`必须保持什么、必须改变什么、共同桥梁是什么、最大断裂点在哪里`。这些判断不机械写成第四段，而是转译进 `【画面内容】`：

```text
【画面内容】
从【首帧状态】开始，【触发机制】作用于【主体 / 道具 / 场景】，先发生【解构、离场、遮挡或空间开启】。摄影机沿【物理路径、方向、速度和稳定方式】跟随或穿越，画面中的【主体比例、背景透视、地平线、焦点】发生【可见变化】；【必须保持的不变量】持续可辨。随后【形态 / 服装 / 材质 / 场景 / 时间 / 天气】沿【因果顺序】变化，【共同桥梁】贯穿过程；同期声写清材质、方向、距离和空间变化，不生成 BGM。接近尾帧时，【尾帧中的颜色、轮廓、光源、场景入口、服装局部或主体姿态】提前进入画面，摄影机和主体逐渐减速，减少【碎片 / 烟雾 / 模糊 / 横滚】，校正【主体比例、位置、景别、透视、地平线和焦点】，稳定落入【尾帧参考@图2】。
```

默认把这条变换写成一个连续镜头，只使用一个 `【镜头01｜景别｜机位 / 视角｜连续运镜】` 头部。观看任务确实需要新机位时，按顺序新开 `【镜头02｜新景别｜新机位 / 视角｜硬切 / 遮挡转场 / 甩镜转场 / 匹配剪辑 + 新运镜】`，随后立即写继承的不变量。镜头序号只标顺序，不绑定逐秒时间码，也不能只靠换行让模型猜两个画面如何连接。

示例一，产品拆解重组：图一手机的金属外壳、玻璃面板和摄像头模组沿真实结构接缝依次分离，摄影机缩小后从悬浮零件之间 FPV 穿越；零件受同一旋转涡流牵引，图二的轮廓和主色先在远处成形，摄影机减速退出零件群，所有组件归位并锁入图二构图。

示例二，旅行 Vlog：图一电脑屏幕亮度升高并扩成铺满画面的光门，女生被吸入过渡空间，摄影机从背后稳定跟随；服装、环境声和冷暖光色沿隧道连续变化，图二旅行场景的天空、地面和风声先从出口进入，女生落地，镜头减速并校正到图二人物比例与构图。

示例只说明推导方法，不限制效果类型。首尾差异小，优先用动作、焦点、光色渐变；差异大，再用遮挡、过渡空间、材质桥或运动桥。优先一个主变换机制和一条主摄影机路径，避免特效、运镜和主体同时争夺注意力。

## 配套镜头预演板提示词模板

镜头预演板提示词给图片模型和人工审片，Seedance 2 视频提示词给视频模型。两者同源但服务对象不同。需要预演时，可以放在同一个 `VID` 的一体化执行单里；老胡明确只要视频提示词、镜头已经过构图验证或首测需要提速时，不强制生成预演板。

老胡明确要求视频直接引用故事板时，另输出一条 `【故事板图片提示词】`，把当前 `VID` 的镜头01到镜头N全部写进同一个代码块，并生成在同一张多分镜故事板表格图中。正式视频提示词只使用一次 `【故事板参考@编号 故事板图片】`；不得把每格拆成多张图片或多个外部故事板引用。故事板锁镜头顺序、构图、景别 / 机位、运镜、切镜、动作趋势和空间锚点，稳定资产锁身份与结构，视频正文继续负责格间动作、物理、声音和转场。

## 跨 VID 连续性参考模式

跨 `VID` 连续性不同于同次生成的首尾帧模式。先在正式代码块外填写：

```text
【跨 VID 连续性交接】
连续性类型：直接连续 / 同场重建 / 关系重置
上游 VID：
参考输入：视频尾部 / 终帧 / 无
实际截取范围：A 实际生成后，从最后一次切镜之后选取；不得同时包含两个机位
世界状态：人物相对场景锚点的位置、朝向、距离、持物 / 持握手、伤势、服装、天气、永久破坏
屏幕投影：画面左右、前后景、视线、动作轴、观看侧、运动向量、当前景别与焦点
必须继承：
允许重置：
交接载体视觉指纹：规范名称；轮廓与内部结构；位置与占比；颜色层级；材质与表面纹理；受光与反射；运动方向、速度与相位；VFX 阶段；遮挡边界；同步声音；稳定把手
B 第一可见动作 / 声音：
```

若转场依靠同一交接载体，A 最后一段和 B 第一段都要完整写入同一份视觉指纹。两侧是独立模型请求，`保持上一段、同一个圆盘、继续旋转` 不构成可执行继承；必须让两侧都能单独生成出相同的形状、颜色、材质、纹理、构图占比、运动相位、光效和声音。B 在共同状态之后只写第一项新变化。这个双端重复是连续性约束，不按普通同义重复删除。

直接连续时，A 的最后一个动作组要完成本段结果，同时让下一压力通过视线、影子、画外声、未接触威胁或运动方向进入。A 生成后优先截取最后一次切镜之后约 1-3 秒单一机位；若候选范围混有两个构图、强遮挡、严重失焦、错误人物状态或反向运动，缩短到最后一个有效机位，必要时改用终帧。不要专门添加无剧情职责的站位空镜，也不要把边界放在兵器仍相架、人物悬空落点未知、投射物尚未兑现或爆炸结果尚未显现的位置。

实际上传尾部视频时，B 的 `【基础设定】` 可增加：

```text
【视频参考@VID-A尾部连续性片段】只继承【身份 / 场景状态 / 站位 / 观看侧 / 运动余势中本条真正需要的项目】，不复演参考中已经完成的动作。
```

同场重建改用 `【首帧参考@VID-A终帧】` 或干净构图参考；关系重置不写上一条参考。B 的 `【场景状态与氛围画质】` 仍重建自足开场事实，`【画面内容】` 直接从 B 的新动作或新情绪节拍开始。世界状态默认继承；屏幕左右、景别和观看侧只有在直接连续时整体继承，明确硬切、正面中性镜头、可见越轴或重新建立空间后可以改变。

```text
生成一张用于导演和作者审片的低保真抽象构图骨架镜头预演板。它不是最终电影画面、视频首帧或 Seedance 默认输入，只用于先确认构图、景别、机位、视线方向、空间关系、动线、切换点和留白。

参考资产：按本镜实际需要填写场景资产和道具资产，例如【@S1 老家院子】【@P11 半成品木马车架】。只参考方向、出入口、主要空间锚点、道具数量、位置关系、动线和画面锚点，不复刻真实外观、完整场景布局、家具细节、颜色、材质和最终光影。

跨 VID 参考：直接连续时，预演板第一格依据【视频参考@VID-A尾部连续性片段】最后有效机位和交接卡继续；同场重建时用【首帧参考@VID-A终帧】固定世界状态并重新建立构图；关系重置不复制上一条站位。

整体形式：黑白 / 灰阶抽象构图骨架图；用画幅框、三分线 / 黄金分割线、前景框、视线箭头、动线虚线、引导线、光源箭头、负空间块、少量火柴人 / 简化剪影、必要几何块和中文标签表达画面。允许轻微 2.5D 空间关系，但不要画成完整室内 / 院子 / 街道场景草图。

绘图边界：重点锁定构图、景别、机位、主体比例、站位、道具数量、空间锚点、引导线、动线路径、视觉重心、亮部重点和留白；空间锚点优先用文字标签和极简线条表达。不要画完整家具、完整房间布局、装饰物、床头、枕头、台灯、书桌、窗帘、花盆、墙画等非视觉中心细节。人物外观、真实五官、具体服装、颜色、材质、最终光影和电影质感由视频提示词和资产参考控制。不要画真实角色脸，不复刻资产服装，不做彩色电影剧照。

表情驱动镜头先判断情绪证据主要在脸部微表情、身体距离、完整姿态还是环境关系。脸部微表情承重时可用中近景、近景或特写；疏离、压迫、等待和关系距离承重时，中景、全景或远景可能更准确。人物占比与镜头距离由观众需要读到的证据倒推，不固定为 68%-72% 或 78%-82%。

表情主任务的辅助动作边界：先锁定脸、手、道具、身体或环境中谁是第一视觉落点。手部、脚步、裙摆、系带和道具只有在加强同一主情绪、留在既定构图内且不会诱导模型下摇、转焦或切走时才保留；一旦成为第二主角，就删除、降权或拆成独立证据镜头。手在脸侧、胸前或同一景别内自然支持表情时可以使用，不做题材式禁用。

对镜头情绪表演规则：如果本镜是脑内 VO、画外音、导演提示、观众视角或镜头前方的人在对角色说话，线框构图必须把镜头当作对话对象；人物默认正面对镜头，眼线箭头指向镜头中心，用脸部椭圆、眼线、嘴角、眉心、眼眶、肩线和肩颈回应镜头。不要写“声音方向”“看向海面”“看向天空”作为默认反应；风景只作为留白和反差。只有强撑、躲避、崩溃或遮掩情绪时，才允许短暂低头、偏开、失焦或背过脸，并在构图里说明这是情绪动作。

POV 物理朝向检查：如果本镜是第一人称 POV，先判断视点主体是躺着、坐着、站着还是低头，身体朝向哪里，眼前真实能看见什么；线框构图只能画符合该朝向的可见关系，不能把不可能同时看见的床头、枕头、门口和完整房间都画进同一格。

表格列固定为：镜头 / 关键画面｜线框构图｜构图规则｜景别 / 机位｜空间锚点｜引导线 / 动线路径｜主体比例与位置。

行内容：
1. 镜头 / 关键画面：从镜头01连续编号到实际需要的镜头N，或使用低头前、遮挡转场点等动作节点，不写时间戳。
2. 线框构图：描述该格要画什么构图骨架，例如画幅框、三分线、主体块、视线箭头、动线虚线、前景遮挡线、光源箭头、负空间块和少量空间标签；不要描述完整场景草图。
3. 构图规则：先写这一格让人看哪里、为什么这样看；只有专业构图术语能让关系更清楚时才使用，例如三分、框架、引导线、对角线、纵深透视、留白或遮挡匹配。简单特写可以只写裁切、主体落点和焦点，不为术语完整强造构图结构。
4. 景别 / 机位：
5. 空间锚点：
6. 引导线 / 动线路径：

```

## 使用规则

- 正式视频提示词按模型路由限字：Seedance 2.0 单条不超过 `4000` 字符；Seedance 2.5 在本项目配置为单条不超过 `10000` 字符，该数字是项目生产上限，不冒充平台公开的官方硬限制；模型未明确或跨版本共用时按 `4000` 字符。只统计可直接投喂的单个 `text` 代码块正文，中文、英文、数字、标点、空格和换行均各计一个字符；代码块外的资产、参数、故事板和验收表不计入。完成或改动正文后必须运行 `bash skills/laohu-video-prompt/scripts/count_video_prompt_chars.sh "提示词文件.md" --limit 上限`，并在代码块外记录脚本实测结果；统计后再改正文必须重跑，没有实测时写 `字符数未验证`。不设最低字数，上限不是凑字目标；超限先删重复和作者说明，必要因果仍装不下时减少非承重内容或拆分 `VID`。
- 复杂变化只有逐项写清才能成立时，完整描述启动、传播、接触、结构成形、材质转换、光影、VFX、环境反馈和完成状态；不为缩短文本改成抽象概括。删除的对象只能是重复、矛盾、观众不可感知且不能改变生成结果的解释。
- 超限时先删重复外观、同义风格词、重复否定和作者解释，再合并无新增证据的句子；仍装不下时减少非承重内容或拆分 `VID`。不得保留或交付超限正文，也不得删掉道路边界、人物站位、攻击来源、运动路径、避让方向、接触点、受力结果、镜头承接和情绪表演。
- 内部镜头节点先从主情绪和动作观看方式推导。连续跟拍 / 少量长镜头展示真实时间、空间、完整身法和持续控制；高强度多切展示攻击密度、速度、冲击、失衡和压迫；混合结构可以先建立空间，再快速覆盖爆发动作，最后用结果镜头沉淀。不要预设 15 秒应该有几个镜头。
- 动作组与镜头分层设计。一个动作组可以由一个镜头连续完成，也可以用多个镜头分别看清攻击来路、接触、脚步、受力与结果；每个镜头增加一个新的观看证据，相邻镜头继承同一动作相位和状态，不让动作重新发生。
- 高频动作覆盖不是快闪蒙太奇。前者通过动作匹配、屏幕方向、姿势、武器归属、运动余势和声音连续呈现同一事件；后者用于时间压缩、平行信息、记忆碎片、危机倒计时或卡点并置。
- 只有镜头不增加情绪、动作阶段、空间信息、视觉证据或节奏压力时才合并；只有总时长无法兑现主情绪和动作结果时才删减或拆条，不能为了满足镜头数量区间预先降低复杂度。
- 每条正式视频提示词本体必须单独放进 `text` 代码块，方便老胡直接复制到视频模型。代码块里只放可投喂模型的三段正文；镜头编号、所属场次、镜头任务、表情来源、流程判断、资产判断、时长预演、生成前检查、回传字段和说明文字都放在代码块外。
- 需要预演时，每个 `VID` 可同时输出 `【镜头预演板提示词】` 和 `【Seedance 2 视频生成提示词】`；老胡明确只要视频提示词或镜头已通过构图验证时，不强制增加预演板。
- 跨 `VID` 前先路由为直接连续、同场重建或关系重置。直接连续可调用上一条最后一次切镜后的单一机位尾部视频，同场重建使用终帧 / 构图参考，关系重置不引用上一条尾部；正式正文始终自足，不写 `第0秒` 或 `承接上一段`。
- 镜头预演板和视频提示词使用同一组关键画面节点。预演板格号和内部编号只用于人工对齐；正式视频正文使用 `低头前、遮挡掠过、抬头后、落刀声响起` 等可见 / 可听节点及连续变化，不显示镜头编号。
- 镜头预演板提示词必须单条自足可复制。每个预演板代码块都要包含完整共用绘图要求、参考资产、表格列和当前镜头的行内容。
- 镜头预演板是低保真抽象构图骨架，不是最终电影画面、第一帧或资产图。它默认给人审片，只锁构图、景别、机位、空间关系、主体比例、道具数量、引导线、运动路径和留白，不锁真实外观、颜色、材质、服装和最终光影。
- 镜头预演板可以在开头调用本镜实际需要的场景资产、道具资产和必要群像资产。这些资产只校准空间结构、道具数量、位置关系、动线和画面锚点；预演板仍不复刻人物脸、服装、真实材质、场景色彩和最终光影。
- POV 镜头预演板必须通过物理朝向检查：先判断眼前真实能看见什么，再画构图骨架。
- 连续视频单元可以使用锚点重叠，但不能机械每条都重叠。直接连续时复用世界状态、屏幕投影和运动余势；同场重建只继承世界状态并重新建立画面；关系重置只保留稳定资产。预演板、交接卡和视频提示词必须使用同一连续性类型。
- 单条视频单元先按主体识别、动作完成、情绪变化、对白与听者反应、摄影机路径和停点反推真实所需时长，再检查目标模型与入口是否支持；不能按镜头类型套秒数。支持长时的入口可以按确定上限执行，例如 Seedance 2.5 单条 30 秒测试；长时路线要单独标记模型、做完整时长预演，并验收后半段遗忘与一致性漂移，不能把该能力默认继承给其他模型。总时长作为平台生成参数设置，正式提示词正文不铺从零到结尾的逐秒时间轴，只在局部控制确有必要时写可伸缩的相对时长。
- 正式确定时长前必须做时长预演：根据 `【画面内容】` 拆出动作单元，估算入画、表情、台词、动作、道具响应、环境变化、运镜和停点各自需要的最低可读时间。如果当前秒数装不下这些内容，不要硬塞；改为加时长、删内容或拆镜头。
- 箭、子弹、暗器、飞刀、刀气、车辆、奔马或高速人物穿过画面时，必须按需要写清场景坐标与通行净空、摄影机侧别、主体屏幕方向、来源、轨迹、最近距离、感知时点、避让方向、最终出画 / 撞击位置、环境反馈和结束状态。不要只写“从侧面飞来、擦过、钉入路旁、迅速躲开”。撞击目标不承担剧情时，优先让高速物体出画，再用画外撞击声和画面边缘反馈证明落点。
- 跨镜头对象先建状态账本：进入状态、触发、接触部位、操作路径、中间状态、结果状态和下一镜继承。武器必须区分完整入鞘、顶开护手、部分出鞘、完全出鞘、回鞘与脱手落地；不能从“手碰刀”直接跳到“横刀在手”。
- 人物反应先过知觉因果：客观事件发生后，人物依据当下可听、可见、可触或可从环境推断的线索开始反应，危险再按设计进入观众视野。高速箭矢不默认让人物看清箭头后再躲。
- 写速度时用参照物反向位移、中远景视差、衣料 / 发丝 / 马鬃受风、泥水 / 尘土 / 落叶后抛、步频 / 蹄频、运动模糊方向、摄影机惯性与声音远近变化证明；`高速、疾驰、迅速、突然` 只能作总结，不能独自承担速度。
- 高速群战另建战斗节奏控制层：明确全段实时高速或速度渐变，区分主角、近战敌群、远程投射物、摄影机和环境反馈五层速度；攻击组按空间扇区和武器距离半拍错位、重叠进入，主角上一招余势直接进入下一招，不逐人排队、不恢复默认站姿。
- 接触点需要清楚时，优先写高快门感、跟踪对焦、方向对比和火星 / 水花 / 碎屑反馈；人物与兵器仍保持实时高速。只有主决定性瞬间确实需要延长知觉时间时才使用局部升格，并写明恢复高速节点。
- 高武、玄幻、科幻、超能力或怪兽题材先写能力基线：角色等级、感知、预判、速度、力量、控制精度和普通人差异。顶级高手可以提前读取预动作、声源、气流和环境微变，但仍要有知觉因果。
- 超常效果按来源 / 发力、形成、传播介质、路径、先行征兆、接触点、材质分层响应、人物身体反应、声场 / 摄影机响应、余波和永久结果展开。刀气、剑气、冲击波、念力、激光不能只有发光与爆炸。
- 情绪表演型视频提示词必须按主情绪颗粒度拆分。单条正式视频提示词只承担一个主情绪，最多带一个过渡情绪；提示词外先判断 `主情绪、起始状态、触发语音 / 事件、表情变化、身体反应、结束状态、下一条情绪准备`，再写入 `【画面内容】`。不要把多个关系阶段的大跨度变化塞进同一条提示词。
- 情绪高潮必须有可感知的峰值证据，但不固定等于落泪或崩溃。泪落、呼吸卡断、身体松掉、异常平静、动作停止、声音变空和关系距离拉开都可作为证据；根据人物性格、前期积累和主情绪选择，不能把某一种表演模板套给所有终局。
- 对镜头情绪表演必须做眼线检查：如果 VO 或画外音等同镜头前方的人在对角色说话，`【基础设定】` 或 `【画面内容】` 要写声音从镜头位置 / 镜头前方进入脑海，人物默认正面对镜头、眼线回到镜头，用表情回应镜头。禁止把默认反应写成 `扫向声音方向`、`看向海面`、`看向天空`；这些会让模型把脸转走。低头、偏开、失焦只作为强撑、躲避或崩溃的动作，并要服务情绪。
- 对镜头情绪表演要做关系距离检查。`看镜头看表情` 不等于必须脸部特写，也不等于必须保留肩颈和环境；根据主情绪判断观众应靠近、保持对话距离还是被推远，再选择景别和人物占比。
- 泛化弱词必须过审。`小、轻、低、微微、一点、稍微、淡淡、有点、慢慢、柔和、自然、高级、舒服、压住、收紧` 不是禁用词，但不能单独承担关键画面、声音、动作、光影、情绪和审美判断。写入正式提示词前，先拆清它修饰的对象和维度：动作幅度 / 速度 / 力道，声音音区 / 响度 / 共鸣 / 停顿，光线强度 / 软硬 / 方向，色彩饱和度 / 明度 / 对比，镜头距离 / 景深 / 稳定度。错误写法：`她轻轻笑了一下，声音有点低，光线很柔和。` 正确写法：`她右侧嘴角短促抬起，眼尾没有完全弯开，鼻息带出半声气笑；声音落到中低频，胸腔共鸣更重，句尾下坠；窗外蓝调冷光做主光，旧灯泡只在脸侧留一圈弱暖辅光。`
- 正式提示词只保留 `【基础设定】`、`【场景状态与氛围画质】`、`【画面内容】` 三块。
- 写全分镜视频提示词前，必须在提示词外先做上下镜头连接检查：上一镜停点、本镜起点、视觉锚点、声音桥、视线方向、动作方向、时间跳跃标记和情绪停点。正式代码块里不写“接上一镜”，但要把连接关系转成画面内可见 / 可听的开头或结尾。
- 写有对白、旁白、VO 或字幕的镜头前，必须先回查剧本原文并锁定文本。正式视频提示词只能照搬原文，再补声音状态和表演状态；不能自行改句、删句、加句或换成更像主题总结的话。错误写法：把剧本 `哪个说的。长大了，是要晓得照顾人。以后要当个顶天立地的男子汉，晓得不？` 改成 `长大不是没人管你。长大了，是你晓得照顾人了。`；正确写法：保留剧本原句，只写爷爷声音低、沙、短，中间轻喘停顿。
- 单点反馈必须触发全局同类扫描。老胡点名某一个镜头、某一句台词、某一个动作、某个资产数量、某个年代物件或某个空间逻辑错误时，默认这是同类问题的样本，不是只改这一处。除非老胡明确说“只改这个镜头”，否则必须先修被点名项，再检查当前全分镜文件和相关剧本 / 分镜 / 资产文件里的同类项。台词问题扫所有对白、VO、OS 和画外音；POV 问题扫所有主观镜头；资产数量问题扫所有同类道具；动作模糊问题扫所有动作链；年代物件问题扫所有时代相关场景。当前案例：VID-27 台词被改，不能只改 VID-27，要把剧本对白清单和全分镜视频提示词引号内容全量对照。
- 正式提示词正文里禁止写 `分镜编号`、`所属场次`、`镜头任务`、`作者说明`、`后期备注`、`前后镜头关系`。
- `【基础设定】` 只列本条实际上传或绑定的人物、场景、道具、色卡、动作 / 音色和首帧参考，再写一句同期声策略。资产图容易误导或本镜存在临时状态变化时，才补一句短约束；病弱、哭腔、压低声音、电话失真和距离变化等本镜表演状态写进对应镜头。
- 进入 `【基础设定】` 的角色、场景、道具、生物或固定人群，默认都必须有固定资产支撑。没有固定资产的对象不能写进基础设定，只能作为当前镜头画面元素写进 `【画面内容】`。
- 资产行还必须通过“本镜实际使用”检查。资产引用是模型召回指令，不是作者备注；只要写了 `【@资产名】`、资产名或高权重视觉名词，模型就会倾向于让它出现在当前画面。每条正式提示词只调用本镜实际出镜、出声、VO、被触碰、发声、承载光影、提供空间结构或成为运动中心的资产。前后镜头重要、作者知道、剧情背景存在、下一镜才出现、只是提醒自己的资产，不能写入当前代码块。错误写法：门缝医生画外音镜头引用 `爷爷输液瓶：【@P6】`，导致输液瓶提前出现在门缝里；正确写法：门缝镜头只写门框、小手、白大褂衣角、旧药箱和父亲低声，输液瓶留到进屋病床镜头第一次出现。
- 资产行必须贴近对标稿写法：非人物资产写 `资产名：【@资产名】固定外观、材质、比例、状态、行为规则或使用规则。` 人物资产按本镜实际职责写 `人物名：【素体参考@B01 人物素体形象资产】锁脸、体型和比例；`，只有确实存在并承担本镜复用职责时，再追加 `【服装参考@W01 人物服装资产】` 或 `【妆造 / 最终造型参考@M01 人物妆造设计资产】`；本镜只补当前状态和出镜 / 出声方式。`【@资产名】` 是非人物图片资产或固定资产占位；人物参考与 `【音色参考@xx】` 是独立替换占位。如果平台需要 `<node-asset>` 等格式，导出时再替换。
- 资产名和资产行不能携带错误主视觉锚。模型会把资产名、资产行和参考图里的高权重名词当成最终画面目标；如果把成品白汤圆资产命名成 `硬币汤圆`，又在资产行写硬币信息，即使画面内容补充 `内部不可见`，模型仍可能把硬币贴到成品汤圆表面。正确做法是把当前可见外观和隐藏 / 揭露物分开调用：完整白汤圆资产只写连续白糯米皮、水光和手搓纹理；小面值硬币资产只在包入前、吃出后或递出时短暂可见。本镜如果只看见完整白汤圆，基础设定和画面内容都不能把硬币写成汤圆外观的一部分。
- 人物资产行要区分稳定参考和本镜状态。稳定参考分别用 `【素体参考@xx】`、`【服装参考@xx】`、`【妆造参考@xx】` 调用三类人物图片，用 `【音色参考@xx】` 调用音频参考；本镜状态只写当前衣服是否替换、鞋和场景配件是否出现、睡觉 / 刚醒 / 外出 / 上学 / 戴孝等状态，以及本镜声音是否哭腔、病弱、压低、喊叫、隔门闷声或电话失真。普通生活服装随场景变化，只有品牌服、制服校服、固定戏服、丧服或强连续性服装才跨镜头锁定。睡觉镜头不能机械复制外出棉外套、鞋和书包为穿着，应写睡衣、秋衣、赤脚或被窝遮挡；书包可作为床边场景物出现。
- 人物资产里的场景配件必须按本镜重写。资产图里出现书包、雨伞、帽子、孝布、围裙、工具包、篮子等，不代表每条视频都要继承。正式提示词要写清该配件本镜是否出现、在哪里、由谁拿着或穿戴。错误写法：`姐姐：【@A5 姐姐】11-13 岁女孩，学生外套、书包` 用在元宵饭桌。正确写法：`姐姐：【@A5 姐姐】11-13 岁女孩，普通学生气；本镜在家里吃汤圆，穿普通日常学生外套或素色毛衣，不背书包。`
- 道具资产行必须写清本镜数量、资产身份、同类边界和剧情时间状态。资产是唯一对象，不是类别词；写 `木马车` 容易生成多辆，写 `唯一一辆 P1 旧木马车` 才能锁住对象。本镜只有一个同类道具时，写 `本镜只呈现这一辆 / 一只 / 一件...`；后续才出现的同类资产要写清它的剧情解锁条件，例如 `本镜发生在碰撞冲突之前，剧情里只有 P1；P2 尚未被承诺、尚未制作、尚未出现`，必要时补 `禁止出现第二辆...`；本镜确实有多个同类道具时，逐一写清编号、数量、位置、差异和各自剧情来源。
- 同类道具必须做剧情解锁检查：制作阶段已有资产，不等于当前剧情时间点已经存在。先判断该道具在当前镜头之前是否已经被制造 / 获得，角色是否已经知道或看见，它是当前实物、台词承诺、回忆对象还是未来兑现证据。当前案例：P1 是爷爷前期给小安做好的第一辆木马车；P2 是碰撞冲突后爷爷承诺再做一辆的兑现物，前期镜头不能提前入画。
- 道具状态词必须具体化。`坏了`、`坏掉`、`破了`、`修好了`、`不能用` 不能单独出现；必须补充可见损坏点或功能验证结果。外观损坏写具体部位：右前圆木轮半脱、轮轴松动外露、坐板裂缝、扶手断开、木片翘起；功能损坏写动作结果：推一下卡住不滚、轮子只晃不转、发出闷响、车身歪向一侧。修好也要写补木片、木楔、轮轴重新固定、轮子重新能转。错误写法：`旁边放着坏掉的木车`。正确写法：`旁边只靠着一辆 P1 旧木马车，右前圆木轮半脱离轮轴，轮轴松动外露，车身向右前方歪斜；爷爷轻推一下，右前轮卡住发出闷响，车身只晃了一下没有滚动。`
- POV 写法必须先锚定具体人物资产，再写类别特征。正式提示词里写 `小安第一人称 POV`、`小安视角`、`小安坐在后排的第一人称 POV`，不要只写 `儿童 POV`、`孩子视角`。可以写 `小安第一人称 POV，儿童身高低视线`。这样能避免模型把主观镜头生成成第三人称儿童画面。
- `【画面内容】` 是观众眼前的镜头结果，不是剧情解释区。第三人称、第一人称、过肩、正反打、插入镜头和空镜都要写出当前真正可见 / 可听的结果；前景、中景、背景、视线、动作和声音来源只写本镜存在且承重的部分。不要只写“父亲责备孩子”“两个人争执”“主角震惊”这类剧情摘要。
- `【画面内容】` 不能写角色心理解释、潜台词或未说出口的具体词。错误写法：`像把没事两个字吞回去`、`想替对方找理由`、`像想解释或反驳`、`喉咙吞住话`。这些句子对人像文学描写成立，但模型可能把 `没事`、`理由`、`解释`、`反驳`、`话` 当成台词、字幕或画面文字。正确写法要改成可见 / 可听证据：`嘴唇微微张开又合上，没有发出任何声音，喉咙很浅地动一下，呼吸停半拍，眼眶边缘出现细窄水光，嘴角硬撑，肩线塌下半寸`。
- 正式提示词代码块不能写作者意图、观众理解目标、防误读说明或生成流程解释。`让观众懂`、`表现孩子不冷漠`、`避免误读成马上去世`、`禁止把小安拍成冷漠`、`镜头停顿足够让观众看见忍哭`、`发给模型时模型不知道上下文` 这类句子只能放在提示词外的分镜表、自检、连接检查或复盘里；代码块里要改成屏幕证据或自足设定：短脚步追赶、两个书包压在胸前、呼吸乱、站住发懵、奶奶眼眶红肿、嘴角压住、手指停住、袖口和视线高度变化、角色身份、场景、道具数量、动作起点和声音状态。
- `【画面内容】` 不能泄露作者上帝视角。提示词里只能写观众此刻能看见、听见或通过当前动作感到的信息；隐藏在物体内部、角色心里、后续剧情、尚未揭晓身份或未来承诺里的内容，不能提前生成成可见物。当前案例：硬币被包进汤圆后，下锅转场只能写完整白汤圆、水汽、勺子和碗，不能写可见硬币、露馅、破开的汤圆或 `藏硬币的汤圆混在其中`；如果需要控制，写 `外观完整，内部不可见`。
- 严格 POV 可以先写“画面呈现视点主体眼前所见”的画面来源声明，例如 `小安第一人称 POV，画面呈现小安眼前所见，视线高度约 6-7 岁儿童低视线`，或 `男主第一人称 POV，画面呈现男主趴桌时看见的低位桌面`。这类角色名用于说明画面来自谁的感知结果，不是画面里出现一个被拍摄的角色。禁止用 `镜头等同小安眼睛位置`、`摄影机绑定在小安眼睛位置`、`机位高度等同男主趴桌视点` 替代来源声明，因为这些词描述的是物理摆位，不是最终屏幕结果。来源声明建立后，后续仍然要写眼前结果：肩膀被推导致画面轻微摇晃，试卷靠近画面时油印字逐渐清晰，叹气从画面后方响起。
- 严格 POV 必须证明画面来源，但不套全字段公式。先写 `具体人物第一人称 POV + 画面呈现具体人物眼前所见`，再从手持 / 身体感、前景身体或道具、视线高度、头部运动后的屏幕变化、镜头后方声音、近眼遮挡、互动对象朝镜头动作中选择足够证据。环境光影、焦段、景深、画幅和介质只在改变本镜观看结果时补充。
- POV 前景锚点是候选证据，不是每镜必填。小手、袖口、膝盖、握住的道具、方向盘、被沿或眼镜边框可以证明身体位置；如果前景会遮住主情绪或破坏纯净凝视，可以不用，改由呼吸 / 步伐造成的画面变化、边缘遮挡、镜头后方声音或互动对象直视镜头来证明来源。
- POV 稳定方式从身体状态、运动方式、观看任务和主情绪共同推导。平稳、呼吸微动、短步轻晃、短促颠簸和短暂虚焦都是候选；治愈、紧张、儿童或病弱不自动绑定某一种效果。
- POV 头部 / 视线运动必须写成眼前画面变化：低头看下方蒲团纹理、抬头看遗像桌、缓慢转向门口、向左环顾街边、被人推一下导致画面轻晃、伸手向前触碰物件、缓步向前使地面和前方主体靠近。不要写 `小安转头 / 小安抬头 / 小安停住` 作为外部动作摘要，要写 `镜头从门框甩向窗边并停住`、`画面缓慢抬到父亲下巴和手里的外套`、`两只小手伸向画面前方`。
- POV 光学质感从角色能看见多少、注意什么、身体如何运动和主情绪是否需要失真反推。焦段与景深不负责证明 POV，也不固定为某组人眼等效参数；只有光学结果承重时才写。
- 外部 POV 公式里的“负面词收尾”不能照搬进本项目正式代码块。正式模型正文优先写正向画面；如果需要边界，只写抽象质量边界，不把当前镜头不该出现的具体对象反复写进模型正文。具体跑偏对象、风险和不该出现的剧情物，放到提示词外自检或失败经验里。
- 严格 POV 必须检查互动视线：其他角色只要在和 POV 主体说话、递物、牵手、触碰、安慰或责备，就要写他们 `看向镜头 / 朝镜头低头 / 手伸到镜头前方 / 物件递到镜头前 / 身体压近镜头`。错误写法是 `奶奶蹲低摸袖口`、`爷爷笑着说小安来喽`、`父亲递外套`；正确写法是 `奶奶蹲到镜头高度，眼睛看向镜头，手伸到画面前方摸袖口`、`爷爷视线对准镜头，朝镜头笑着招呼`、`父亲把外套递到镜头前方，外套边缘压近画面`。
- 正式写 `【画面内容】` 前先解决“观众最终看见什么、主要感到什么、这个画面为什么成立”。画面来源、观众站位、镜头关系、空间层次、视线方向、动作方向和剪辑停点是候选判断项；只选择当前镜头真正需要的部分。正反打、过肩、POV 和复杂调度必须锁空间关系，单物特写不必填满整套。
- 主观镜头必须做视点主体语法检查。通用规则：只要镜头被定义为第一人称、主观视角或某人所见，`【画面内容】` 就不能把这个视点主体当成一个被外部摄影机观察的人来写，也不能用“某人眼睛位置”“摄影机在某人眼睛上”替代“某人眼前所见的画面结果”。错误写法是 `视点主体 + 躲 / 看 / 听到 / 停住 / 皱眉 / 转头 / 站起来 / 表情怎样`，例如 `小安躲在被子后面`、`父亲看见门口的人后皱眉`、`主角听到声音后停住`、`你转头看向窗外`。正确写法是让眼前、画面、视线、光、遮挡物、手、袖口、门框、道具、其他人物局部和声音来源成为主语，把动作转译成感官结果，例如 `手擦过画面边缘，画面短暂虚焦`、`前景遮挡物抬高，画面被遮住一部分，声音变闷`、`画面从门框甩向窗边并停住`。当前案例：小安床上 POV 应写 `眼前先是朦胧的天花板和被窝边缘，两只穿浅色睡衣袖口的小手从画面下方伸出，抓住被沿往上拉，棉被遮住画面下半部；门口冷光从被沿上方照进来，一个穿深色夹克的中年男人局部身影进入画面。` 如果镜头需要表现视点主体的脸部表情，应改成旁观低机位、近主观肩后镜头或第三人称近景，并重新写清画面层次。
- 操作型生活场景必须做物料清单和动作链检查。凡是包汤圆、包饺子、做饭、缝衣服、修东西、擦伤口、洗脸、端药、点纸房、收拾行李等镜头，正式提示词不能只写“正在包 / 正在修 / 正在做”，要列出真实操作需要的工具、材料、半成品、成品和工作区，再写哪只手拿、推、拖、扶、按、揉、放。桌面、案板、灶台和工具台不能空。当前案例：E1-S6-C1 包汤圆桌面要出现糯米粉盆、半揉好的糯米团、馅料碗、硬币小碗、已搓好的白汤圆、撒粉区、旧瓷碗和奶奶正在包的手；小安搬小板凳要写两只小手抓住凳面拖到案桌前，脚只负责踩上去，禁止让脚推板凳。
- 歧义动作必须写清工具、接触方式和顺序。凡是 `加一点`、`取一点`、`放进去`、`抹上去`、`处理一下`、`弄好`、`包起来`、`擦一下`、`倒一点`、`递过去`、`推过去` 这类动作，现实里可能由手、勺子、筷子、夹子、布、棉签、碗、刷子、刀具或其他工具完成时，正式提示词必须写明：哪只手拿什么工具，工具从哪里取材料，工具先碰什么、后碰什么，材料如何被放下 / 压平 / 抹开 / 包住 / 擦掉，工具最后放回哪里，手是否还直接接触材料。错误写法：`把硬币放进去，加一点馅，包起来`。正确写法：`右手拿起黑芝麻馅碗边的小木勺，用勺尖舀起一小团馅，勺背轻轻压在硬币上方盖住反光；小木勺放回碗边后，手指只接触白糯米皮，把边缘捏合封口。`
- 材料变形动作必须写过程，不只写结果。包裹、揉捏、缝合、修补、点火、倒水、洗脸、擦伤口等动作，要写动作前形态、哪只手如何接触、材料怎样被压扁 / 抬起 / 合拢 / 粘合 / 变圆 / 变湿 / 起火、内部信息什么时候从可见变成不可见、最终观众看见什么。错误写法：`把硬币放进糯米皮里，加一点馅，收口揉圆`。正确写法：`左手托压扁糯米皮，右手把硬币平放进浅窝，用黑芝麻馅盖住硬币反光，指腹把糯米皮边缘往中间抬起并捏褶封口，两掌轻轻滚圆；封好后硬币和馅料内部不可见，只剩完整白汤圆。`
- 工具劳动动作必须写工作面、工具、材料、受力、结果和收尾位置。劈柴、锯木、刨木、钉钉、锤打、磨刀、铲土、挑水、洗衣、磨粮这类动作，不能只写动作名。错误写法：`父亲在柴堆上劈柴，斧头落下，劈好的柴码整齐`。正确写法：`父亲站在院子边旧木墩前，一截短柴竖在木墩中央，双手握斧顺木纹劈下，斧刃卡在短柴里；他连木带斧抬起半尺，再把柴底往木墩上一磕，裂缝扩大，第二下分成两半，随后把两半柴放到木墩旁边柴垛上。`
- 正反打要先确定轴线和左右关系，例如小安在画面右侧、父亲在画面左侧；反打时两人视线方向相对。过肩镜头要写清谁的肩背在前景、谁在中景、谁看向哪里。内打外 / 外打内要写清摄影机在门内、门外、车内、窗外还是桌子哪一侧。正式提示词里不要只写术语，要写术语对应的可见构图。
- 正式写 `【画面内容】` 前检查景别、机位、运镜和光学质感四类控制杆，但不把它们当四项必填。只把能加强主情绪、理解、生成稳定或剪辑连续的选择写进正文；固定镜头不硬写运镜，简单特写不硬补焦段和前中后景。
- 景别从观看任务倒推：决定观众同时读到多少空间、动作、关系、表情或局部证据，不把远景、全景、中景、近景和特写固定绑定某类情绪。一个镜头承担过多互相争抢的任务时，优先删减、拆镜头或写清景别变化。
- 高张力镜头必须做特写进判断。短视频开场、悬念、审问、背叛、冲突、恐怖、情绪爆点、关系反转和前 3 秒钩子，如果全景会提前暴露人物关系和下一步动作，就不要默认全景开场；用 `局部证据特写 → 反应脸 / 关键动作 → 空间揭示` 先强制聚焦。可用局部证据包括眼睛、嘴角、手指、汗珠、喉结、录音笔红点、门锁、手机震动、合同签名、杯沿裂纹、药瓶标签、刀尖、火苗和泪痕。错误写法：`全景展示审讯室，背叛者坐在椅子上，审讯者站在对面，气氛紧张`。正确写法：`极近特写先拍录音笔红点和攥白的指节，审讯灯只照亮吞咽的喉结；对面椅脚移动声响起时，镜头缓慢后拉，文件袋、椅背和人影才进入画面`。
- 需要压缩时间或心理暗示时，优先考虑特写蒙太奇连接器。相似转场特写用于时间流逝：咖啡满杯到空杯、杯沿渍变深、便利贴增多、键盘碎屑堆积、台灯频闪、烟灰增长、药片减少、纸灰落满桌面。联想蒙太奇特写用于心理暗示：墨水吞掉白纸、玻璃杯水旋成漩涡、海面反光被树影切碎、灰尘在强光里翻涌、灯丝忽明忽暗。正式写法必须有 `现实触发 → 抽象特写意象 → 回到人物反应 / 当前物件结果`，不要把抽象意象写成无来源高级空镜。
- 机位角度必须服务主情绪和视角关系，但没有固定映射。平视、俯拍、仰拍、斜侧和正侧都要结合人物处境、距离和空间结果判断；正反打、过肩、门缝、窗缝和车内机位存在时，写清必要轴线、遮挡和空间内外。
- 运镜必须写路径、方向、速度、停点与屏幕结果。固定镜头写构图中哪些对象保持不变；水平摇镜写左摇 / 右摇、起点、经过物和停点；横移写屏幕方向和前后景视差；推镜写主体从什么景别扩大到哪个表情或物件；拉镜写从哪个局部露出什么环境；升镜 / 降镜写画面高度变化与最终所见；环绕写围绕谁、转动角度、背景横移和主体清晰度；甩镜写触发声音、方向残影和清楚落点。不要只写 `镜头移动`，也不要用机身 / 设备运动代替最终画面。
- 专业运镜术语必须先区分物理机制：Dolly / Track / Tracking Dolly 是机身整体移动；Pan / Tilt 是机身不动、镜头原地转动；Zoom 是焦段变化；Crane 是大幅高低升降；Jib 是小幅近距离升降；Handheld / Bumpy / Breathing Shake / Soft Stabilize 是稳定方式；Orbit / Arc / Match Move 是镜头和主体运动关系；Pass Through / Digital Dolly Through / Time-lapse Dolly / Spiral Dolly / Falling Dolly / Ascend & Dive 是创意或特效运动。希区柯克变焦必须同时写 `机身向前推进 + 光学变焦拉远 + 主体大小基本保持不变 + 背景空间拉伸畸变`。
- 光学质感与作品介质和主情绪一致，但不按题材套套餐。浅景深、深景深、遮挡、微距、DV、胶片、鱼眼或宽幅都要说明观看职责；90 年代家庭回忆使用 DV、暖黄色偏或中等景深只是当前案例候选。
- 镜头语言与情绪没有固定映射。平视、俯拍、仰拍、固定、手持、推拉和景深只是候选，必须根据人物处境、距离变化、稳定感和信息变化判断实际效果；同一种运镜可以服务不同情绪。
- 通用 AI 视频分层只作为开放问题库，不作为正式字段，也不逐层检查齐全。正式提示词仍只保留 `【基础设定】`、`【场景状态与氛围画质】`、`【画面内容】` 三块；从镜头、主体、环境、光影色彩、光学和输出规格中选择本镜承重层。
- 分层职责：镜头语言层写景别、机位角度、运镜方式、镜头速度和确定时长；主体叙事层写人物 / 生物 / 物体、外貌穿搭、动作、神态和细微情绪；环境布景层写地点、空间结构、陈设、道具、前景遮挡、中景动作和远景背景；光影色彩层写光源方向、光线软硬、主色调、冷暖关系、光晕、丁达尔和阴影层次；镜头光学质感写焦段、人眼等效 / 广角 / 定焦、景深、散景、暗角、颗粒、畸变控制、胶片 / DV 介质；输出画质层按需写分辨率、帧率、稳定度和细节清晰度。画幅在内部导演判断与平台参数中处理，正文只写它造成的实际构图结果。
- 落入三段模板时，`【基础设定】` 只列本条实际调用素材、一句声音策略和必要的少量抽象输出限制；`【场景状态与氛围画质】` 先写开拍前场景状态，再保留跨全部镜头成立的主风格、摄影介质和宏观色彩基线；`【画面内容】` 用方括号镜头块承接景别、运镜 / 转场、主体表演、环境布景、本镜光影、HEX 色彩落点、材质、VFX、逐镜声音、台词和停点。
- 四套梯度公式只作为内部问题库，不改变正式三段模板，也不按片长自动套用。先定主情绪、观看任务和生成风险，再从镜头语言、主体叙事、环境布景、光影色彩、光学质感、节奏和特殊效果中选择承重层；未承重层不进入正文。
- 极简不能省掉本镜承重因果，复杂版本也不能堆特殊效果。前中后景、光源、环境包裹和停点只在加强主情绪、动作可读性或连续性时展开。外部通用公式里的“负面规避词结尾”不作为本项目正式正文层级。
- `【场景状态与氛围画质】` 先用一句写开拍前事实，再通常只写 1-3 句全段基线：主风格母体与真实程度、全局摄影介质与颗粒、全段主辅色关系与肤色基线。删除一句后如果只影响某一个镜头，就把它移入该镜头块。
- 如果作品有色彩风格资产，在 `【基础设定】` 引用 `【@C1 色卡名】`，在 `【场景状态与氛围画质】` 写一句主色彩锚定；逐对象 `颜色映射` 跟随对应镜头写清整体光线、主角服装、肤色、发色、场景结构、关键道具和氛围过渡调用的 HEX。
- 正式投喂给视频模型的提示词必须先用目标描述收束生成空间：画面里要出现什么主体、环境、动作、材质、光线、声音和情绪结果，就正向写什么。不能用排除句替代正向描述；模型会注意到被提到的对象。少量硬边界只用于抽象质量问题，例如动作僵硬、逻辑混乱、文字水印、比例畸形，并且不得引入当前镜头不该出现的具体视觉对象。风险判断、常见跑偏和不该出现的剧情物，写在代码块外的自检、回传字段或失败经验里。
- `【画面内容】` 采用连续观看的编号镜头块。内部镜头数量由观看任务决定；每个新块以 `【镜头01｜景别｜机位 / 视角｜运镜 / 转场】` 开始并连续编号，动作、遮挡、视线、焦点、声音、光色峰值或运动方向触发进入，正文立即继承姿势、道具、余势、空间方向和声场。VFX、环境音、动作音、音乐 / 节拍和台词按需逐镜跟随；没有发生的不填。总时长在平台参数中设置，普通镜头不铺逐镜时间戳；复杂镜内时序只按上文规则使用少量可伸缩的相对时长约束。
- 多人物、多物件或交互镜头才建立场景关系图，写清对情绪、动作或连续性承重的位置关系。单人静态特写、纯表情镜头和简单空镜不为填表强加完整空间图。
- 交互必须写清交互方式、接触点、作用力大小轻重、方向和可见结果。人物拍肩、牵拉、推开、递物，物品承重、滚动、碰撞、遮挡、变形，都要写谁 / 什么接触哪里，轻拍、突然一拽、双手用力、缓慢托住还是短促撞上，力从画面哪一侧指向哪一侧，受力后肩膀、手腕、碗、凳子、木轮、布料、液体、影子或镜头发生什么变化。
- 运动必须写清起点、路径、方向、终点和边界参照；运镜必须配合展示人物和物品关系。推镜用于让接触点和表情变清楚，拉镜用于露出人物和物品的空间关系，摇镜用于从一个对象扫到另一个对象，升镜用于从局部关系揭示整体布局。不要只写 `镜头移动 / 镜头拉远 / 镜头跟随`，要写它跟谁、从哪里到哪里、最终让观众看见哪些关系。
- 同镜存在两个以上因果参与者时，先做多主体运动账本：分别锁定世界 / 屏幕起点、朝向、速度与加减速、景深层、路径、外力、相对顺序、终点、出画方向和出画顺序；摄影机另写位置、速度和轴线。共同运动体分离后继承共同惯性，方向或速度变化必须有摩擦、碰撞、制动、转向、推进或地形依据。正文优先写清正向屏幕结果，避免只用 `继续向前` 这种缺少参照的描述。
- 翻身、跳跃、落地、翻滚、摔倒、起身、骑乘上下、复杂武打、舞蹈或身体与道具强交互时，先做人体姿势变换账本：起始姿势 / 朝向、原支撑点、解除约束、新承重点、肩胸骨盆与关节链、重心轨迹、旋转轴、四肢净空路径、离支撑轮廓、首次接触点、缓冲卸力、结束姿势和下一动作入口。正文按生成风险选择关键相位，不用一个动作名称跳过身体变化。
- 爆炸、坍塌、炮击、撞击或能量破坏先做事件传播账本：来源 / 入射方向、命中点、力量传播、首个承力结构、材料失效顺序、碎片分组与飞散方向、二次碰撞、火焰烟尘压力波、遮挡变化、声音到达、摄影机响应和永久终态。按本镜观看任务选择承重阶段，不用一个 `爆炸 / 倒塌 / 飞溅` 结果词替代过程。
- 重大位移、下马、跌落或遮挡切换后，局部攻击前先恢复主体、攻击来源、地面 / 道路边界和摄影机观看侧。连续攻击按来源预动作、人物线索、身体换位 / 格挡、接触角度、改向 / 出画 / 撞击和边缘反馈组织。承重动作按 `危险逼近 → 提前占位 → 短路径处理 → 接触瞬间短暂清晰 → 结果继续高速运动 → 余势停点` 设计帅点；停点来自动作结果，不是摆拍。
- 动作场景先给主要交战者建立开放式角色动作语法：能力等级、距离偏好、起势、攻击几何、防守 / 借位、场景利用、回收节奏和能力边界。群战按明确方位和先后进入，上一招形成的遮挡、失衡、空位、掉落物或反作用力要成为下一招条件，不让每个人共享通用连招或排队上前。
- 当目标是多人围杀的炫酷高速场面时，可以按远程投射组、长兵器外圈、近身刀剑内圈和高位攻击组组织大量敌人。各组攻击在同一时间窗重叠：投射物仍在飞行时长兵器封路，长兵器被改向时近身组贴入，受力身体和碎片尚未落地时高位攻击压下。详细因果不能被写成逐招慢速讲解。
- 攻击组重叠的是时间压力，不是所有兵器同时汇聚同一点。根据地形宽度、人物占位、兵器射程、挥舞净空、友军遮挡、视线和误伤计算交战面容量；当前只有拥有净空攻击线的人进入接触，其余敌人承担封路、换位、回收、补位、瞄准、保护远程组或受伤退出。构图避免主角永远居中、敌人均匀圆环和长枪辐条式齐刺。
- 无明确护体能力的主角被包围后，先通过冲击薄弱侧、贴近敌人形成遮挡、引导长兵器互相干涉或借墙 / 竹林 / 坡面压缩交战面建立生存路径。远程攻击要有友军安全射界，近战越线后射手换角度、延迟或转向出口。
- 兵器、人体和环境接触按材质写声音与结果：金属脆响、木杆弯折与纤维开裂、铁器砸地低频冲击、竹身切口与延迟倾倒、衣料撕裂、肌肉受击闷声和呼吸中断不能混成统一火星爆炸。
- 每段选择一个主决定性瞬间，必要时再选一个次级瞬间。动作段让攻击线、人物轮廓和结果证据同时可读；压迫、关系或情绪段可以用最小反应、关系证据或控制破裂承重。接触时可以让摄影机位移 / 焦点短暂稳定，但画内高速对象与环境余势继续运动；主体可读性优先于拖影、火花、光带和粒子密度。
- 局部光影承担主情绪、动作可读性或空间变化时，说明关键光源、方向、照射对象和可见结果；不要求同时写光型、材质、高光、阴影、反光、轮廓和丁达尔。错误写法：`温馨光影，画面很有氛围。` 正确写法：`女生靠近时挡住右侧窗光，男生脸侧亮面短暂暗下去。`
- 面向观众且承担视觉记忆的镜头设计审美停点 / 情绪停点；功能型镜头、动作连接镜头和证据插入镜头不强制壁纸帧，只在任务完成处形成清楚可剪辑的停点。停点只保留加强主情绪的主体、构图、光色或材质，不要求全部维度齐全。
- 构图、光影、色彩以及后续审美模块都不是封闭词表。老胡给出的词是启发样例，不是固定菜单；正式写提示词时要从剧情情绪、时代背景、空间材质、人物肤色、道具颜色、光源类型、壁纸用途和剪辑连续性反推搭配。未列出的有效方案也可以使用，例如层叠构图、纵深透视、火光主光、雪地反光、黑白灰单色、褪色老照片、煤油灯暖褐、山城雾灰绿等。
- 构图承担主情绪或视线引导时，按需选择三分、中心、框架、引导线、对角线、留白或其他结构，并写成主体落点与空间关系；不要求每镜点名构图术语，也不要求所有停点都稳定、留白和边角洁净，失衡可以是有意情绪手段。
- 留白必须区分空间留白和信息留白。空间留白是天空、海面、墙面、暗部、雾气、窗外虚景和负空间；信息留白是半张侧脸、发丝遮眼、嘴唇下颌、手和首饰、门缝局部、背影回头一点点等局部遮蔽。开场钩子、封面、人物第一眼、暧昧、危险、身份悬念和神秘氛围可以用信息留白；情绪高潮、争吵、落泪、台词反应和关键动作因果必须让表情或动作证据清楚。正式写法要说明遮住哪里、露出哪里、光勾出哪里、观众靠哪个局部补完人物。错误写法：`画面有神秘留白`。正确写法：`人物位于左侧三分线，只露右半张侧脸，前景发丝和树影遮住左眼区域，侧逆光勾出鼻梁、唇峰、耳坠和下颌线，右侧海面负空间保留约 45%`。
- 光影承担情绪、塑形或动作可读性时，从光源、方向、软硬、层级、反光和阴影中选择必要项；自然光足够时只写关键来源与结果，不强制多层布光。
- 色彩承担情绪、身份或连续性时，从主辅色、饱和度、明度、环境反光和分级中选择必要项；单色、近无色和自然综合色可以成立，不强制完整调色体系。
- 色卡使用遵守 `母色卡不变，阶段变体受控变化`。同一作品优先建立全片母色卡，阶段变体只调整明度、暗部冷暖、点缀色面积、肤色气色、环境反光和阴影重量，不要每个分镜随机换色卡，也不要所有分镜完全死用同一色卡。正式提示词里，色卡图是参考，文字规则是执行；两者必须对应。颜色映射只写本镜真实出现的对象，不为填满模板硬写未出镜人物、道具或场景结构。
- 景深和空间只在承担情绪、注意力或空间因果时展开，不强制前中后景齐全。画质先保证关键证据可读，材质只在承担身份、触感或剧情时细写。雾、烟、花瓣、微粒等氛围元素必须有情绪或物理职责，否则删除。镜头稳定、失衡、模糊和停住都由主情绪决定，只防止非意图性的漂移与崩坏。
- 场景、动作和表情必须先通过情节合理性判断。正式写 `【画面内容】` 前，先回答：人物为什么在这个场景，表面正在做什么，内心实际发生什么，动作是否由上一句台词、关系阶段、人物性格和场景姿态自然触发。不要为了显得甜、可爱、伤心或有细节，就机械添加捂嘴、抓衣角、低头、摸头发、转身、看远方等通用动作。错误写法：`独处傻乐，所以捂嘴、抓衣角、下摇到手部。` 正确写法：`她停在海边栏杆处，表面看海，实际回想上一句问候；起初眼神放空，海风吹动发尾后，单侧嘴角先翘起，随后眼睛弯起来，笑意从脸上漏出来。`
- 表情主任务镜头必须保护第一视觉落点。手部、脚步、裙摆、系带或道具只有在加强同一主情绪、留在既定构图内且不会触发镜头下摇或切走时才保留；会抢走脸部注意力的动作删除或拆成独立证据镜头。当前案例中 `下压到手指抠衣角，再回到脸` 会破坏脸部表演，所以改为固定景别内的眼神、嘴角、吞咽、呼吸和肩线变化；这不等于所有表情镜头禁用手部。
- 涉及身体和道具配合的动作，正式提示词必须做空间排练：从哪个方向接近，哪只手或脚先动，身体如何坐下 / 跨过 / 起身 / 转身，道具如何承重和移动，镜头跟随谁，移动后哪些人物仍在画面内。禁止前后动作物理关系冲突，例如“角色已坐在车上”却又把车写成空车滑走，或“第一人称 POV”却看见 POV 主体不可能看见的身后正脸。
- 病弱、受伤、输液和病床镜头必须写状态证据链。不要只写 `虚弱 / 病弱 / 躺床 / 气息略虚`，要同时写脸色、唇色、眼皮、额汗、呼吸、说话音量、断句、停顿、动作幅度、手部力量、床单或被角反应，以及药碗 / 输液管 / 胶布 / 照护者表情等外部证据。错误写法：`爷爷躺床上但保持安慰孩子的笑，气息比平时虚。` 正确写法：`爷爷半靠旧枕头，脸色偏白泛灰，唇色浅，眼皮沉，额角有细汗；看见镜头后只牵动嘴角，声音低、沙、短，中间轻喘停顿；没输液的手从被沿挪出一点又停住。`
- 病床触碰动作必须做床侧、输液侧和可达性排练。躺床、输液、受伤、虚弱或被照护的人要牵手、摸头、拍手、递物、擦泪或安慰孩子时，先判断孩子站在哪一侧、输液针扎在哪只手、输液管从哪里走、哪只手靠近床沿、远侧手是否被身体 / 被子挡住、病人翻身或抬臂是否费力。错误写法：`爷爷躺床上，用另一只手伸过来摸小安的手`。正确写法：`小安站在靠输液手这一侧，指尖碰到胶布又缩回；爷爷不翻身、不抬远侧手，只把床沿附近的输液手小幅度转动，指尖反手轻碰小手，输液管轻轻晃一下。`
- 涉及儿童和成人尺度道具 / 场景交互时，正式提示词必须做身高、视线和可达性排练。先判断儿童是否够得到、看得全、拿得动、能不能独立完成操作；如果不能，就写成人手递下 / 接回、孩子踩矮凳、物件只露局部、玻璃反光、模糊轮廓、垂下来的线、从高处传来的声音。错误写法：`小安趴在柜台边，黑色老式座机、卷曲电话线和硬币占画面中心，听筒被小手放回座机。` 正确写法：`画面低于玻璃柜台上沿，座机主机在柜台上方只是一团模糊黑影；成人手把听筒递到画面前，卷曲电话线从高处垂下来；通话结束成人手接回听筒，高处传来咔哒挂断声。`
- 涉及滑行、奔跑、追逐、推车、摔倒、冲撞、车辆行驶、人物走位和镜头穿越等移动类画面时，必须写清起点、路径、终点、屏幕方向和空间边界。正常路径中哪些区域通畅、障碍物位于哪一侧边界、为什么会撞上，都要符合生活逻辑。错误写法：`木车从小坡滑下，撞到一块石头`。正确写法：`木车从坡顶沿坡面中线滑向坡底缓冲区，旧院墙在画面左侧，水槽 / 木料堆在画面右侧；试玩孩子控制不好，车头偏向左侧旧墙根，撞到坡底左侧贴墙压边石 / 墙脚，路中央保持通畅。`
- 多人群像和围桌场面必须先做座位图 / 站位图。饭桌、会议桌、课堂、灵堂仪式、院子围观、家庭合照、群体争执等多人同框镜头，要写清视点位置、桌子或场地朝向、每个关键人物在画面左 / 右 / 前 / 后 / 近旁 / 远侧的位置，再写台词、视线、递物和冲突。错误写法：`饭桌居中，家人手和碗环绕，大家先后吃到硬币`。正确写法：`小安坐饭桌近侧中间，自己的碗在最前景；爷爷坐小安右手边、画面右前方近旁；姐姐坐画面左侧，奶奶坐对面中间，父亲坐对面偏右靠旧墙。视线依次扫向左侧姐姐、对面偏右父亲、右前方爷爷，再低回自己碗里。`
- 冲突动作必须有前置动机、靠近路径和身体受力。推开、打断、抢夺、摔倒、撞倒、拉扯、抱住、躲开等动作，不能只写冲突结果。要写被推 / 被撞 / 被抢的人为什么靠近、怎么从原位置移动过来、手或道具伸向哪里、主角为什么反应、推力作用到哪个部位、后退或摔倒撞到什么合理边界。错误写法：`爷爷坐在桌旁把硬币伸过来，小安一推，爷爷跌到柴火边`。正确写法：`爷爷撑桌起身，从右侧桌边绕到小安身旁，拿小布巾弯腰想擦眼泪；小安推开贴近脸前的手腕和胳膊，爷爷后退半步，脚跟撞到右侧小木凳后跌坐柴火边。`
- 冲突动作改稿必须把结果句改成可排练动作链。先诊断旧稿是否只有“靠近、推、倒”的结果；再补六项：靠近动机、移动路径、接触点、反应触发、受力方向、承接边界。不要只写 `用力 / 猛地 / 痛苦 / 摔倒` 这类强度词。当前案例的改法是：把 `爷爷坐在桌旁伸硬币` 改成 `爷爷为了安慰孩子，撑桌起身，拿硬币和小布巾绕到小安右前方，弯腰擦眼泪`；把 `小安一推，爷爷跌倒` 改成 `小安推开贴近脸前的手腕和胳膊，爷爷弯腰重心在前，后退半步撞到右侧小木凳，手撑地跌坐到柴火边`。
- 如果来源剧本有 `角色名（语气 / 神态）：`、`角色名 VO（语气 / 神态）：`、`角色名（OS）：`、动作段表情或插入镜头表情，正式视频提示词必须在 `【画面内容】` 中继承这些表演信息，不新增单独字段。不要只复制“忍着哭”“压着火”“故作轻松”这类抽象词，要写成可见 / 可听的表演结果：眼神、眉头、嘴角、嘴唇、下巴、呼吸、肩膀、手指、停顿、声音和身体距离。第一人称 POV、背影、远景或不露脸时，用手部攥紧、呼吸停住、声音发紧、肩背僵住、衣角被攥皱、反射里的眼神、脚步停顿或道具轻抖来替代表情。
- 人物声音要区分“基础音色参考”和“本镜声音状态”。基础音色通过独立 `【音色参考@xx】` 音频资产保持跨镜头一致；本镜声音状态写在画面内容里，例如虚弱、沙哑、哭腔、压低、喊远、隔门闷住、电话电流失真、VO 回响。禁止每个镜头随意换音色，也不要把音色说明塞进人物图片板或每条基础设定里重复长篇声线。
- 关键发声镜头不能只依赖 `【音色参考@xx】`。本镜声线、音区、共鸣、颗粒、近麦 / 距离、咬字、尾音、停顿、气口和回响必须跟随台词写进对应镜头；`【基础设定】` 仍保持短素材清单和一句声音策略。
- 台词、旁白、画外音和脑内 VO 必须按“双层声音表演”写。正式提示词不能只写 `温柔 / 生气 / 压迫 / 破碎 / 甜 / 刺` 这类抽象情绪，也不能只写 `音高压低 / 音量中等 / 语速收紧` 这类机械参数。正确顺序是：先写情绪意图和说话态度，例如示好、试探、亲昵、期待、敷衍、心虚、防御、不耐烦、反推责备、轻蔑、愤怒、暴怒、切断、空洞残响；再写音高 / 音区、响度 / 音量、语速 / 节奏、停顿 / 气口、重音位置、气息状态、咬字 / 吐字、软硬强弱、爆发力、距离感、混响和衰减。错误写法：`男声音高压低，音量中等，语速收紧`。正确写法：`男声带防御和心虚，急于把怀疑压回去；声音收紧发硬，音区偏低，音量不大但压迫感明显，重音压在“她”和“普通朋友”上，“可以吗”短促下压。`
- 如果一个 VO 是人物表情变化的主要触发器，必须按阶段设计声音曲线。初识、热恋、平淡、猜忌、争吵、决裂不能共用同一种普通年轻男声；也不能只逐条改变音量、距离、语速、停顿、重音、气息、咬字和回响衰减。当前案例：《30秒钟带你体验谈恋爱》的男声脑内 VO 应从轻佻试探、亲昵冒进、稳定惦记、热恋期待、敷衍抽离、防御心虚、不耐烦反推责备、烦躁反咬、轻蔑攻击、暴怒切断到空洞残响逐步变化。
- 正式交付给老胡复制的视频提示词默认使用中文专业表达。少量跨全部镜头成立的器材、规格和介质缩写可留在 `【场景状态与氛围画质】`；具体肤色、妆效、光影、景深、质感、环境和运动稳定跟随对应镜头写。
- 情绪人像、恋爱短片、开场钩子和外景美人片仍要在写作前建立风格交集，但正式 `【场景状态与氛围画质】` 只输出收束后的主风格、摄影介质和宏观色彩基线；肤色妆效、场景环境色、具体光影和情绪阶段变化跟随对应镜头写。
- 正式写视频提示词前，把摄影指导层当作开放问题库：光影关系、光影运动、色温、主体细节、空间层次、时间天气空气、焦段景深、画面类型、情绪反差和正向质量边界中，哪些真正改变本镜主情绪、主注意力、物理可读性或连续性？只展开承重项，不做防漏式全量填写。使用动态光时必须有来源和运动原因；使用材质细节时只写与主体状态有关的颜色、纹理、反光或瑕疵；焦段按视野、距离、透视和背景信息选择，不把人像、POV、疏离固定到某个毫米数；情绪反差只有加强主情绪时才使用。
- 情绪人像和开场钩子不能只写抽象表情。先判断哪些脸部、身体或声音证据真正承重，不要求眼神、眉峰、嘴角、鼻翼、下巴、呼吸和停顿全部出现。皮肤或妆效承重时，要正向锁住角色自己的肤色、气色、妆效和纹理，并与地域、年龄、职业、年代、健康和主情绪一致；冷白、清透裸妆和柔雾奶油肌只是林栀案例，不是美女人像通用模板。发丝、首饰、衣料和环境运动只有在指向主表演或身份时进入正文。
- 一条视频提示词内部需要连续动作或镜头切换时，先确定实际需要的镜头节点。摄影机真实连续移动时只写一个 `【镜头01｜景别｜机位 / 视角｜连续运镜】` 头部和完整物理路径；机位不连续时按顺序新开编号镜头头部，并在最后一栏写硬切或软切机制。编号用于明确边界，独立“切镜”二字和逐镜时间戳仍省略。
- 资产写法：实际投喂的图片资产只在 `【基础设定】` 引用，跨全部镜头成立的提示词资产压缩进 `【场景状态与氛围画质】`；`【画面内容】` 不重复长篇描摹资产本体，重点写它在当前镜头中的动作、受光、遮挡、反射、风吹、变形和环境交互。未资产化元素必须在对应镜头写到足够生成。
