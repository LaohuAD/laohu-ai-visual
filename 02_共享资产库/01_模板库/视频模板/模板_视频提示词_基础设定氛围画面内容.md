# 模板：视频提示词_基础设定氛围画面内容

```text
【基础设定】
世界观：
固定角色 / 生物 / 人群规则：
固定场景 / 建筑 / 道具规则：
声音设定：
全局禁止：

【氛围与画质】
风格核心：
视觉基调：
色彩与影调：
画面质感：
镜头节奏：
禁止方向：

【画面内容】
时长：
景别 / 构图：
运镜：
画面内容：
```

## 使用规则

- 单条正式视频提示词正文必须控制在 2000 字以内。
- 正式提示词只保留 `【基础设定】`、`【氛围与画质】`、`【画面内容】` 三块。
- 不要在正式提示词正文里写 `分镜编号`、`所属场次`、`镜头任务`、`作者说明`、`后期备注`、`前后镜头关系`。
- `【基础设定】` 写全片通用的世界观、角色类别、建筑场景、声音总规则和禁止项，不写当前分镜的具体动作。
- `【氛围与画质】` 写全片统一的风格、视觉基调、色彩影调、画质质感和镜头节奏，不写当前分镜的具体事件。
- `【画面内容】` 才写当前分镜发生什么、怎么拍、有什么声音或动作。除非必须精确控制关键节点，不要把每秒都拆死。
