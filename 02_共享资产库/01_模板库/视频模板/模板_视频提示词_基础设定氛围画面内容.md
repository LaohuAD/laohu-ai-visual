## 配套低保真故事板提示词模板

故事板提示词和视频提示词必须分开输出、分开复制、分开保存。故事板提示词复制给生图模型，用来生成一张“分镜故事板表格图”；视频提示词复制给视频模型，用来生成正式视频。两者是同源并行关系，不是互相包含关系。全分镜视频提示词交付时，每个最终视频单元 `VID` 默认同时输出 `【故事板图片提示词】` 和 `【视频生成提示词】` 两个独立代码块。

连续一镜到底拼接时，A 条视频的尾帧就是 B 条视频的首帧。B 条故事板和视频提示词都要调用 `【首帧参考@VID-A尾帧】`，并写清本镜第 0 秒从同一景别、同一构图、同一光源方向、同一人物姿态和同一表情余韵继续。正式视频提示词的 `【画面内容】` 第一句也要写成 `第 0 秒使用【首帧参考@VID-A尾帧】的画面状态继续...`，再进入本条新的动作或情绪。

```text
生成一张用于 AI 视频生成参考的低保真抽象构图骨架分镜故事板表格图。它不是最终电影画面，也不是视频首帧图，只用于给视频模型参考构图、景别、机位、视线方向、空间关系、动线和留白。

参考资产：按本镜实际需要填写场景资产和道具资产，例如【@S1 老家院子】【@P11 半成品木马车架】。只参考方向、出入口、主要空间锚点、道具数量、位置关系、动线和画面锚点，不复刻真实外观、完整场景布局、家具细节、颜色、材质和最终光影。

首帧参考：如果本镜需要与上一条视频拼成一镜到底，写【首帧参考@VID-A尾帧】用于固定第 0 秒构图、景别、人物姿态、表情余韵、光源方向和背景锚点；故事板第 1 行必须从这张尾帧状态继续。

整体形式：黑白 / 灰阶抽象构图骨架图；用画幅框、三分线 / 黄金分割线、前景框、视线箭头、动线虚线、引导线、光源箭头、负空间块、少量火柴人 / 简化剪影、必要几何块和中文标签表达画面。允许轻微 2.5D 空间关系，但不要画成完整室内 / 院子 / 街道场景草图。

绘图边界：重点锁定构图、景别、机位、主体比例、站位、道具数量、空间锚点、引导线、动线路径、视觉重心、亮部重点和留白；空间锚点优先用文字标签和极简线条表达。不要画完整家具、完整房间布局、装饰物、床头、枕头、台灯、书桌、窗帘、花盆、墙画等非视觉中心细节。人物外观、真实五官、具体服装、颜色、材质、最终光影和电影质感由视频提示词和资产参考控制。不要画真实角色脸，不复刻资产服装，不做彩色电影剧照。

表情驱动镜头的近景规则：如果本镜核心是人物情绪、开场钩子、脑内 VO 反应或关系变化，先判断关系距离。正常对话、试探回应、热恋期待、平淡降温、结尾提问默认使用胸部以上中近景 / 舒适近景，人物占画面高度约 68%-72%，脸、眼睛、嘴角清楚，同时保留肩颈、锁骨、耳坠、吊坠和少量环境留白。强冲击、不可置信、被击穿、崩溃、微表情证据和眼泪证据，才允许脸部近景、脸部特写或人物占高 78%-82%。线框构图用脸部椭圆、眼线、嘴角箭头、眉心短线、眼眶水光、肩线、主光方向和负空间表达情绪读点；除非本镜核心任务是完整走位、群像空间或大动作关系，不要默认画成中景、全身走路图或完整场景草图。

表情主任务的低位细节边界：如果本镜要让观众通过脸读情绪，不要在故事板或视频提示词里写手部插入近景、手部小块、抓衣角、抠衣角、抓袖口、握拳、手贴胸口、手背遮嘴、镜头下摇到手，也不要把脚步、鞋尖、裙摆、腰间系带、包带、脚边树叶、路面边界等胸部以下细节写成情绪证据。模型会把这些被点名的手部、腰部、腿部或脚部动作当成镜头目标，导致脸部表情被移出视觉中心。正确写法是把情绪写到眼神、眼睑、眉心、嘴角、嘴唇、下巴、鼻翼、吞咽、呼吸、眼眶水光、肩颈、头部微动作、脸侧发丝、耳坠和项链吊坠。只有手部证据、道具证据、触碰交互、POV 身体锚点、完整走位、服装展示、资产展示和操作动作类镜头，才允许手部小块、低位服装细节、脚步、手部特写或下摇到手。

对镜头情绪表演规则：如果本镜是脑内 VO、画外音、导演提示、观众视角或镜头前方的人在对角色说话，线框构图必须把镜头当作对话对象；人物默认正面对镜头，眼线箭头指向镜头中心，用脸部椭圆、眼线、嘴角、眉心、眼眶、肩线和肩颈回应镜头。不要写“声音方向”“看向海面”“看向天空”作为默认反应；风景只作为留白和反差。只有强撑、躲避、崩溃或遮掩情绪时，才允许短暂低头、偏开、失焦或背过脸，并在构图里说明这是情绪动作。

POV 物理朝向检查：如果本镜是第一人称 POV，先判断视点主体是躺着、坐着、站着还是低头，身体朝向哪里，眼前真实能看见什么；线框构图只能画符合该朝向的可见关系，不能把不可能同时看见的床头、枕头、门口和完整房间都画进同一格。

表格列固定为：时间点 / 关键帧｜线框构图｜构图规则｜景别 / 机位｜空间锚点｜引导线 / 动线路径｜主体比例与位置。

行内容：
1. 时间点 / 关键帧：
2. 线框构图：描述该格要画什么构图骨架，例如画幅框、三分线、主体块、视线箭头、动线虚线、前景遮挡线、光源箭头、负空间块和少量空间标签；不要描述完整场景草图。
3. 构图规则：必须使用专业电影构图术语，写清什么和什么形成什么构图 / 视觉重心 / 视线引导，例如三分构图、框架式构图、前景框构图、引导线构图、对角线构图、三角稳定构图、纵深透视构图、留白构图、圆形匹配构图、遮挡转场构图。
4. 景别 / 机位：
5. 空间锚点：
6. 引导线 / 动线路径：
7. 主体比例与位置：
```

## 使用规则

- 单条正式视频提示词正文必须控制在 2000 字以内。
- 每条正式视频提示词本体必须单独放进 `text` 代码块，方便老胡直接复制到视频模型。代码块里只放可投喂模型的三段正文；镜头编号、所属场次、镜头任务、表情来源、流程判断、资产判断、时长预演、生成前检查、回传字段和说明文字都放在代码块外。
- 每个最终视频单元 `VID` 默认同时输出 `【故事板图片提示词】` 和 `【视频生成提示词】` 两个独立代码块。`【故事板图片提示词】` 存到 `04_分镜/文本/`，生成的故事板图片存到 `04_分镜/图片/`；`【视频生成提示词】` 存到 `05_视频/文本/`。
- 连续一镜到底拼接时，除第一条以外，每条 `VID` 默认在故事板提示词和视频生成提示词里调用 `【首帧参考@上一条VID尾帧】`；正式视频正文不能只写“接上一镜”，必须在 `【画面内容】` 第一句把第 0 秒画面状态写成可见构图、人物比例、光源方向、背景锚点和人物表演。
- 故事板和视频提示词必须使用同一组关键画面节点。内部微分镜编号只用于代码块外的人工作业对齐，不能写进给生图模型的故事板提示词正文；正文要写模型能理解的时间点、关键帧名称和画面内容，例如 `0秒关键帧`、`低头前`、`遮挡转场点`。
- 故事板提示词必须单条自足可复制。每个故事板代码块都要包含完整共用绘图要求、参考资产、表格列和当前镜头的行内容，不能只在文件说明里写共用要求。
- 故事板是低保真抽象构图骨架表格图，不是最终电影画面、不是第一帧图、不是角色 / 场景 / 道具资产图。它只锁构图、景别、机位、空间关系、主体比例、道具数量、引导线、运动路径和留白，不锁完整场景布局、家具细节、真实外观、颜色、材质、服装、表情、最终光影和画面风格。
- 故事板提示词可以在开头调用本镜实际需要的场景资产、道具资产和必要群像资产，写成 `参考资产：【@S1 老家院子】【@P11 半成品木马车架】`。这些资产只用于固定空间结构、道具数量、位置关系、动线和画面锚点；故事板仍不复刻人物脸、服装、真实道具材质、场景色彩和最终光影。需要锁定真实人物、真实材质或最终画面细节时，应回到图片资产、场景资产、道具资产或第一帧参考图流程。
- POV 故事板必须通过物理朝向检查：躺着面向门口就只画被沿 / 床尾方向线、远处门口方向框、视线箭头和小手 / 袖口锚点；不要画完整床头、枕头、窗帘、台灯和书桌。其他 POV 同理，先判断眼前真实能看见什么，再画构图骨架。
- 连续视频单元可以使用锚点重叠，但不能机械每条都重叠。只有连续动作、情绪承接、POV 视线接续、遮挡转场、遗物触摸、门框 / 火光 / 蒲团 / 木轮等强连接需要时，下一条 `VID` 可复用上一条最后一个微分镜作为起点。重叠微分镜在故事板和视频提示词里必须保持同一构图、空间锚点和动作状态。
- 单条正式视频提示词时长默认必须是 4-15 秒内的确定值。4 秒适合极简转场、单一特写和短暂身份锚点；5-7 秒适合普通动作链、空间揭示和轻量奇观；8-12 秒适合人物表情、台词、复杂 POV 和重要奇观；13-15 秒适合同场连续动作、未资产化人物合并和复杂动作因果。时长要服务分镜效果，给模型足够时间展示情绪、动作因果和画面内容。
- 正式确定时长前必须做时长预演：根据 `【画面内容】` 拆出动作单元，估算入画、表情、台词、动作、道具响应、环境变化、运镜和停点各自需要的最低可读时间。如果当前秒数装不下这些内容，不要硬塞；改为加时长、删内容或拆镜头。
- 情绪表演型视频提示词必须按主情绪颗粒度拆分。单条正式视频提示词只承担一个主情绪，最多带一个过渡情绪；提示词外先判断 `主情绪、起始状态、触发语音 / 事件、表情变化、身体反应、结束状态、下一条情绪准备`，再写入 `【画面内容】`。不要把多个关系阶段的大跨度变化塞进同一条提示词。
- 情绪高潮不能过度克制。前期可以写防备、强撑、忍住、失焦或压住眼泪；但辱骂、决裂、背叛、死亡、真相揭开或彻底失去这类终局爆点，必须给可见 / 可听的高潮证据，例如眼泪落下、眼眶迅速泛红、嘴唇颤动、下巴发抖、呼吸卡断、短促哽咽、哭后红眼泪痕、身体松掉或失魂走远。不要把高潮也写成 `僵住、不哭、只是失焦`。
- 对镜头情绪表演必须做眼线检查：如果 VO 或画外音等同镜头前方的人在对角色说话，`【基础设定】` 或 `【画面内容】` 要写声音从镜头位置 / 镜头前方进入脑海，人物默认正面对镜头、眼线回到镜头，用表情回应镜头。禁止把默认反应写成 `扫向声音方向`、`看向海面`、`看向天空`；这些会让模型把脸转走。低头、偏开、失焦只作为强撑、躲避或崩溃的动作，并要服务情绪。
- 对镜头情绪表演还必须做镜头距离检查。`看镜头看表情` 不等于脸部特写；普通对话距离要让脸、肩颈、锁骨、耳坠、吊坠和一点环境留白同时存在。只有情绪爆点、崩溃、不可置信、被击穿、眼泪或微表情证据，才把镜头推进到脸部近景 / 特写。错误写法：`热恋期待，轻微慢推到她眼睛亮起的位置，人物占高约 78%`。正确写法：`胸部以上舒适近景，人物占高约 68%-72%，她可以轻微前倾，但镜头保持正常对话距离，停点仍看见肩颈、吊坠和左侧海天留白`。
- 泛化弱词必须过审。`小、轻、低、微微、一点、稍微、淡淡、有点、慢慢、柔和、自然、高级、舒服、压住、收紧` 不是禁用词，但不能单独承担关键画面、声音、动作、光影、情绪和审美判断。写入正式提示词前，先拆清它修饰的对象和维度：动作幅度 / 速度 / 力道，声音音区 / 响度 / 共鸣 / 停顿，光线强度 / 软硬 / 方向，色彩饱和度 / 明度 / 对比，镜头距离 / 景深 / 稳定度。错误写法：`她轻轻笑了一下，声音有点低，光线很柔和。` 正确写法：`她右侧嘴角短促抬起，眼尾没有完全弯开，鼻息带出半声气笑；声音落到中低频，胸腔共鸣更重，句尾下坠；窗外蓝调冷光做主光，旧灯泡只在脸侧留一圈弱暖辅光。`
- 正式提示词只保留 `【基础设定】`、`【氛围与画质】`、`【画面内容】` 三块。
- 写全分镜视频提示词前，必须在提示词外先做上下镜头连接检查：上一镜停点、本镜起点、视觉锚点、声音桥、视线方向、动作方向、时间跳跃标记和情绪停点。正式代码块里不写“接上一镜”，但要把连接关系转成画面内可见 / 可听的开头或结尾。
- 写有对白、旁白、VO 或字幕的镜头前，必须先回查剧本原文并锁定文本。正式视频提示词只能照搬原文，再补声音状态和表演状态；不能自行改句、删句、加句或换成更像主题总结的话。错误写法：把剧本 `哪个说的。长大了，是要晓得照顾人。以后要当个顶天立地的男子汉，晓得不？` 改成 `长大不是没人管你。长大了，是你晓得照顾人了。`；正确写法：保留剧本原句，只写爷爷声音低、沙、短，中间轻喘停顿。
- 单点反馈必须触发全局同类扫描。老胡点名某一个镜头、某一句台词、某一个动作、某个资产数量、某个年代物件或某个空间逻辑错误时，默认这是同类问题的样本，不是只改这一处。除非老胡明确说“只改这个镜头”，否则必须先修被点名项，再检查当前全分镜文件和相关剧本 / 分镜 / 资产文件里的同类项。台词问题扫所有对白、VO、OS 和画外音；POV 问题扫所有主观镜头；资产数量问题扫所有同类道具；动作模糊问题扫所有动作链；年代物件问题扫所有时代相关场景。当前案例：VID-27 台词被改，不能只改 VID-27，要把剧本对白清单和全分镜视频提示词引号内容全量对照。
- 正式提示词正文里禁止写 `分镜编号`、`所属场次`、`镜头任务`、`作者说明`、`后期备注`、`前后镜头关系`。
- `【基础设定】` 只保留 `世界观`、动态资产行和 `声音设定`。其中 `世界观` 写本条视频所在世界的稳定规则和身份关系；`声音设定` 写全局声音策略；中间的资产行只写本条正式生成实际调用的固定资产。若资产行是人物，优先写成 `角色名：【形象参考@A1 角色人物设计资产】【音色参考@V1 角色音频参考】稳定身份、本镜状态和本镜出镜 / 出声方式。` 形象参考由老胡替换成人物设计资产图片，音色参考由老胡替换成音频参考。当前镜头的病弱、哭腔、压低声音、电话失真、距离变化等临时声音状态写进 `【画面内容】`。
- 进入 `【基础设定】` 的角色、场景、道具、生物或固定人群，默认都必须有固定资产支撑。没有固定资产的对象不能写进基础设定，只能作为当前镜头画面元素写进 `【画面内容】`。
- 资产行还必须通过“本镜实际使用”检查。资产引用是模型召回指令，不是作者备注；只要写了 `【@资产名】`、资产名或高权重视觉名词，模型就会倾向于让它出现在当前画面。每条正式提示词只调用本镜实际出镜、出声、VO、被触碰、发声、承载光影、提供空间结构或成为运动中心的资产。前后镜头重要、作者知道、剧情背景存在、下一镜才出现、只是提醒自己的资产，不能写入当前代码块。错误写法：门缝医生画外音镜头引用 `爷爷输液瓶：【@P6】`，导致输液瓶提前出现在门缝里；正确写法：门缝镜头只写门框、小手、白大褂衣角、旧药箱和父亲低声，输液瓶留到进屋病床镜头第一次出现。
- 资产行必须贴近对标稿写法：非人物资产写 `资产名：【@资产名】固定外观、材质、比例、状态、行为规则或使用规则。` 人物资产写 `人物名：【形象参考@人物设计资产】【音色参考@人物音频参考】稳定身份、本镜状态和本镜出镜 / 出声方式。` `【@资产名】` 是非人物图片资产或固定资产占位；`【形象参考@xx】` 和 `【音色参考@xx】` 是人物形象与音频的替换占位。如果平台需要 `<node-asset>` 等格式，导出时再替换。
- 资产名和资产行不能携带错误主视觉锚。模型会把资产名、资产行和参考图里的高权重名词当成最终画面目标；如果把成品白汤圆资产命名成 `硬币汤圆`，又在资产行写硬币信息，即使画面内容补充 `内部不可见`，模型仍可能把硬币贴到成品汤圆表面。正确做法是把当前可见外观和隐藏 / 揭露物分开调用：完整白汤圆资产只写连续白糯米皮、水光和手搓纹理；小面值硬币资产只在包入前、吃出后或递出时短暂可见。本镜如果只看见完整白汤圆，基础设定和画面内容都不能把硬币写成汤圆外观的一部分。
- 人物资产行要区分稳定参考和本镜状态。稳定参考用 `【形象参考@xx】` 调用人物设计资产图片，用 `【音色参考@xx】` 调用人物音频参考；本镜状态写当前衣服、鞋、书包、睡觉 / 刚醒 / 外出 / 上学 / 戴孝等状态，以及本镜声音是否哭腔、病弱、压低、喊叫、隔门闷声或电话失真。普通生活服装随场景变化，只有品牌服、制服校服、固定戏服、丧服、定装资产或强连续性服装才跨镜头锁定。睡觉镜头不能机械复制外出棉外套、鞋和书包为穿着，应写睡衣、秋衣、赤脚或被窝遮挡；书包可作为床边场景物出现。
- 人物资产里的场景配件必须按本镜重写。资产图里出现书包、雨伞、帽子、孝布、围裙、工具包、篮子等，不代表每条视频都要继承。正式提示词要写清该配件本镜是否出现、在哪里、由谁拿着或穿戴。错误写法：`姐姐：【@A5 姐姐】11-13 岁女孩，学生外套、书包` 用在元宵饭桌。正确写法：`姐姐：【@A5 姐姐】11-13 岁女孩，普通学生气；本镜在家里吃汤圆，穿普通日常学生外套或素色毛衣，不背书包。`
- 道具资产行必须写清本镜数量、资产身份、同类边界和剧情时间状态。资产是唯一对象，不是类别词；写 `木马车` 容易生成多辆，写 `唯一一辆 P1 旧木马车` 才能锁住对象。本镜只有一个同类道具时，写 `本镜只呈现这一辆 / 一只 / 一件...`；后续才出现的同类资产要写清它的剧情解锁条件，例如 `本镜发生在碰撞冲突之前，剧情里只有 P1；P2 尚未被承诺、尚未制作、尚未出现`，必要时补 `禁止出现第二辆...`；本镜确实有多个同类道具时，逐一写清编号、数量、位置、差异和各自剧情来源。
- 同类道具必须做剧情解锁检查：制作阶段已有资产，不等于当前剧情时间点已经存在。先判断该道具在当前镜头之前是否已经被制造 / 获得，角色是否已经知道或看见，它是当前实物、台词承诺、回忆对象还是未来兑现证据。当前案例：P1 是爷爷前期给小安做好的第一辆木马车；P2 是碰撞冲突后爷爷承诺再做一辆的兑现物，前期镜头不能提前入画。
- 道具状态词必须具体化。`坏了`、`坏掉`、`破了`、`修好了`、`不能用` 不能单独出现；必须补充可见损坏点或功能验证结果。外观损坏写具体部位：右前圆木轮半脱、轮轴松动外露、坐板裂缝、扶手断开、木片翘起；功能损坏写动作结果：推一下卡住不滚、轮子只晃不转、发出闷响、车身歪向一侧。修好也要写补木片、木楔、轮轴重新固定、轮子重新能转。错误写法：`旁边放着坏掉的木车`。正确写法：`旁边只靠着一辆 P1 旧木马车，右前圆木轮半脱离轮轴，轮轴松动外露，车身向右前方歪斜；爷爷轻推一下，右前轮卡住发出闷响，车身只晃了一下没有滚动。`
- POV 写法必须先锚定具体人物资产，再写类别特征。正式提示词里写 `小安第一人称 POV`、`小安视角`、`小安坐在后排的第一人称 POV`，不要只写 `儿童 POV`、`孩子视角`。可以写 `小安第一人称 POV，儿童身高低视线`。这样能避免模型把主观镜头生成成第三人称儿童画面。
- `【画面内容】` 是观众眼前的镜头结果，不是剧情解释区。写第三人称旁观结果，模型就会生成第三人称镜头；写第一人称眼前结果，模型才会生成第一人称镜头；写过肩、正反打、插入镜头、空镜，也必须写出该镜头里真正可见的前景、中景、背景、视线方向、动作方向和声音来源。不要只写“父亲责备孩子”“两个人争执”“主角震惊”这类剧情摘要，要改成父亲下颌绷紧、孩子眼前书包带晃动、碗沿反光停住、声音从画外压下来等屏幕结果。
- `【画面内容】` 不能写角色心理解释、潜台词或未说出口的具体词。错误写法：`像把没事两个字吞回去`、`想替对方找理由`、`像想解释或反驳`、`喉咙吞住话`。这些句子对人像文学描写成立，但模型可能把 `没事`、`理由`、`解释`、`反驳`、`话` 当成台词、字幕或画面文字。正确写法要改成可见 / 可听证据：`嘴唇微微张开又合上，没有发出任何声音，喉咙很浅地动一下，呼吸停半拍，眼眶边缘出现细窄水光，嘴角硬撑，肩线塌下半寸`。
- 正式提示词代码块不能写作者意图、观众理解目标、防误读说明或生成流程解释。`让观众懂`、`表现孩子不冷漠`、`避免误读成马上去世`、`禁止把小安拍成冷漠`、`镜头停顿足够让观众看见忍哭`、`发给模型时模型不知道上下文` 这类句子只能放在提示词外的分镜表、自检、连接检查或复盘里；代码块里要改成屏幕证据或自足设定：短脚步追赶、两个书包压在胸前、呼吸乱、站住发懵、奶奶眼眶红肿、嘴角压住、手指停住、袖口和视线高度变化、角色身份、场景、道具数量、动作起点和声音状态。
- `【画面内容】` 不能泄露作者上帝视角。提示词里只能写观众此刻能看见、听见或通过当前动作感到的信息；隐藏在物体内部、角色心里、后续剧情、尚未揭晓身份或未来承诺里的内容，不能提前生成成可见物。当前案例：硬币被包进汤圆后，下锅转场只能写完整白汤圆、水汽、勺子和碗，不能写可见硬币、露馅、破开的汤圆或 `藏硬币的汤圆混在其中`；如果需要控制，写 `外观完整，内部不可见`。
- 严格 POV 可以先写“画面呈现视点主体眼前所见”的画面来源声明，例如 `小安第一人称 POV，画面呈现小安眼前所见，视线高度约 6-7 岁儿童低视线`，或 `男主第一人称 POV，画面呈现男主趴桌时看见的低位桌面`。这类角色名用于说明画面来自谁的感知结果，不是画面里出现一个被拍摄的角色。禁止用 `镜头等同小安眼睛位置`、`摄影机绑定在小安眼睛位置`、`机位高度等同男主趴桌视点` 替代来源声明，因为这些词描述的是物理摆位，不是最终屏幕结果。来源声明建立后，后续仍然要写眼前结果：肩膀被推导致画面轻微摇晃，试卷靠近画面时油印字逐渐清晰，叹气从画面后方响起。
- 严格 POV 必须套用专项公式：`具体人物第一人称 POV + 画面呈现具体人物眼前所见 + 手持质感 / 身体感 + 前景身体或道具锚点 + 视线高度 / 低头 / 抬头关系 + 头部或视线运动 + 眼前主体场景和动作 + 环境光影 + 人眼等效焦段 / 景深 / 画幅 / 画质介质`。这套公式的作用是把 POV 从普通第三人称低机位里区分出来。
- POV 前景锚点必须优先出现。它可以是小手、袖口、手腕、膝盖、鞋尖、胸前衣料、握住的道具、方向盘、门框边缘、柜台上沿、伞柄、书包带、被沿、眼镜边框、手机框或其他贴近视点主体的局部。没有前景身体 / 道具锚点的纯空镜 POV，很容易被模型生成成普通客观空镜；如果本镜确实是视线所见空镜，也要用呼吸、轻微身体晃动、画面边缘遮挡、声音从镜头后方传来等方式证明画面来源。
- POV 手持质感必须按情绪控制：治愈日常写轻微自然手持微抖、呼吸带来极小晃动；电影干净质感写平稳第一视角、无多余抖动；紧张 / 追逐 / 突发写短促颠簸或剧烈手持晃动，但必须写清落点；儿童 POV 写低视线、短步伐轻晃、抬头看成人时画面上扬；病弱 / 疲惫 POV 写呼吸慢、画面轻微浮动、焦点短暂虚一下。不要让模型默认随机剧烈晃动。
- POV 头部 / 视线运动必须写成眼前画面变化：低头看下方蒲团纹理、抬头看遗像桌、缓慢转向门口、向左环顾街边、被人推一下导致画面轻晃、伸手向前触碰物件、缓步向前使地面和前方主体靠近。不要写 `小安转头 / 小安抬头 / 小安停住` 作为外部动作摘要，要写 `镜头从门框甩向窗边并停住`、`画面缓慢抬到父亲下巴和手里的外套`、`两只小手伸向画面前方`。
- POV 光学质感优先贴近人眼。普通叙事可写 `35mm 或 50mm 人眼等效镜头，中等景深`；道具特写和情绪证据可以短暂浅景深；车内、街道、房间空间关系需要更广一点时可以写准广角，但要控制边缘畸变。生活纪实和童年回忆默认避免鱼眼、强变形和无理由超广角。
- 外部 POV 公式里的“负面词收尾”不能照搬进本项目正式代码块。正式模型正文优先写正向画面；如果需要边界，只写抽象质量边界，不把当前镜头不该出现的具体对象反复写进模型正文。具体跑偏对象、风险和不该出现的剧情物，放到提示词外自检或失败经验里。
- 严格 POV 必须检查互动视线：其他角色只要在和 POV 主体说话、递物、牵手、触碰、安慰或责备，就要写他们 `看向镜头 / 朝镜头低头 / 手伸到镜头前方 / 物件递到镜头前 / 身体压近镜头`。错误写法是 `奶奶蹲低摸袖口`、`爷爷笑着说小安来喽`、`父亲递外套`；正确写法是 `奶奶蹲到镜头高度，眼睛看向镜头，手伸到画面前方摸袖口`、`爷爷视线对准镜头，朝镜头笑着招呼`、`父亲把外套递到镜头前方，外套边缘压近画面`。
- 正式写 `【画面内容】` 前必须先判断镜头关系：画面来源、观众站位、镜头和人物的关系、前景 / 中景 / 背景、视线方向、动作方向和剪辑停点。主观镜头、客观旁观镜头、近主观镜头、过肩镜头、正反打、反应镜头、插入镜头、视线所见镜头、内打外、外打内、内反打、正内打和正外打，都必须先解决“观众最终看见什么”和“这个画面为什么成立”。
- 主观镜头必须做视点主体语法检查。通用规则：只要镜头被定义为第一人称、主观视角或某人所见，`【画面内容】` 就不能把这个视点主体当成一个被外部摄影机观察的人来写，也不能用“某人眼睛位置”“摄影机在某人眼睛上”替代“某人眼前所见的画面结果”。错误写法是 `视点主体 + 躲 / 看 / 听到 / 停住 / 皱眉 / 转头 / 站起来 / 表情怎样`，例如 `小安躲在被子后面`、`父亲看见门口的人后皱眉`、`主角听到声音后停住`、`你转头看向窗外`。正确写法是让眼前、画面、视线、光、遮挡物、手、袖口、门框、道具、其他人物局部和声音来源成为主语，把动作转译成感官结果，例如 `手擦过画面边缘，画面短暂虚焦`、`前景遮挡物抬高，画面被遮住一部分，声音变闷`、`画面从门框甩向窗边并停住`。当前案例：小安床上 POV 应写 `眼前先是朦胧的天花板和被窝边缘，两只穿浅色睡衣袖口的小手从画面下方伸出，抓住被沿往上拉，棉被遮住画面下半部；门口冷光从被沿上方照进来，一个穿深色夹克的中年男人局部身影进入画面。` 如果镜头需要表现视点主体的脸部表情，应改成旁观低机位、近主观肩后镜头或第三人称近景，并重新写清画面层次。
- 操作型生活场景必须做物料清单和动作链检查。凡是包汤圆、包饺子、做饭、缝衣服、修东西、擦伤口、洗脸、端药、点纸房、收拾行李等镜头，正式提示词不能只写“正在包 / 正在修 / 正在做”，要列出真实操作需要的工具、材料、半成品、成品和工作区，再写哪只手拿、推、拖、扶、按、揉、放。桌面、案板、灶台和工具台不能空。当前案例：E1-S6-C1 包汤圆桌面要出现糯米粉盆、半揉好的糯米团、馅料碗、硬币小碗、已搓好的白汤圆、撒粉区、旧瓷碗和奶奶正在包的手；小安搬小板凳要写两只小手抓住凳面拖到案桌前，脚只负责踩上去，禁止让脚推板凳。
- 歧义动作必须写清工具、接触方式和顺序。凡是 `加一点`、`取一点`、`放进去`、`抹上去`、`处理一下`、`弄好`、`包起来`、`擦一下`、`倒一点`、`递过去`、`推过去` 这类动作，现实里可能由手、勺子、筷子、夹子、布、棉签、碗、刷子、刀具或其他工具完成时，正式提示词必须写明：哪只手拿什么工具，工具从哪里取材料，工具先碰什么、后碰什么，材料如何被放下 / 压平 / 抹开 / 包住 / 擦掉，工具最后放回哪里，手是否还直接接触材料。错误写法：`把硬币放进去，加一点馅，包起来`。正确写法：`右手拿起黑芝麻馅碗边的小木勺，用勺尖舀起一小团馅，勺背轻轻压在硬币上方盖住反光；小木勺放回碗边后，手指只接触白糯米皮，把边缘捏合封口。`
- 材料变形动作必须写过程，不只写结果。包裹、揉捏、缝合、修补、点火、倒水、洗脸、擦伤口等动作，要写动作前形态、哪只手如何接触、材料怎样被压扁 / 抬起 / 合拢 / 粘合 / 变圆 / 变湿 / 起火、内部信息什么时候从可见变成不可见、最终观众看见什么。错误写法：`把硬币放进糯米皮里，加一点馅，收口揉圆`。正确写法：`左手托压扁糯米皮，右手把硬币平放进浅窝，用黑芝麻馅盖住硬币反光，指腹把糯米皮边缘往中间抬起并捏褶封口，两掌轻轻滚圆；封好后硬币和馅料内部不可见，只剩完整白汤圆。`
- 工具劳动动作必须写工作面、工具、材料、受力、结果和收尾位置。劈柴、锯木、刨木、钉钉、锤打、磨刀、铲土、挑水、洗衣、磨粮这类动作，不能只写动作名。错误写法：`父亲在柴堆上劈柴，斧头落下，劈好的柴码整齐`。正确写法：`父亲站在院子边旧木墩前，一截短柴竖在木墩中央，双手握斧顺木纹劈下，斧刃卡在短柴里；他连木带斧抬起半尺，再把柴底往木墩上一磕，裂缝扩大，第二下分成两半，随后把两半柴放到木墩旁边柴垛上。`
- 正反打要先确定轴线和左右关系，例如小安在画面右侧、父亲在画面左侧；反打时两人视线方向相对。过肩镜头要写清谁的肩背在前景、谁在中景、谁看向哪里。内打外 / 外打内要写清摄影机在门内、门外、车内、窗外还是桌子哪一侧。正式提示词里不要只写术语，要写术语对应的可见构图。
- 正式写 `【画面内容】` 前必须完成镜头语言四件套判断：景别、机位、运镜、光学质感。景别决定画面容纳范围，机位决定观众高度和情绪关系，运镜决定镜头路径和剪辑停点，光学质感决定景深、焦段、前景虚化、光晕、胶片 / DV 介质和真实感。四件套是内部导演判断，不作为单独字段写进正式代码块；正式正文只把结果落到 `景别 / 构图`、`运镜` 和 `画面内容`。
- 景别必须从镜头任务倒推：远景 / 大全景用于建立环境、规模、孤独和空间方向；全景用于展示完整动作和走位；中景用于对话、递物、推拉和生活动作；中近景用于对话表情和肩膀 / 手部反应；近景、特写和微距用于表情证据、手部证据、道具证据和材质纹理。一个镜头如果同时要空间、动作、表情和转场，优先拆镜头或写出清晰景别变化。
- 高张力镜头必须做特写进判断。短视频开场、悬念、审问、背叛、冲突、恐怖、情绪爆点、关系反转和前 3 秒钩子，如果全景会提前暴露人物关系和下一步动作，就不要默认全景开场；用 `局部证据特写 → 反应脸 / 关键动作 → 空间揭示` 先强制聚焦。可用局部证据包括眼睛、嘴角、手指、汗珠、喉结、录音笔红点、门锁、手机震动、合同签名、杯沿裂纹、药瓶标签、刀尖、火苗和泪痕。错误写法：`全景展示审讯室，背叛者坐在椅子上，审讯者站在对面，气氛紧张`。正确写法：`极近特写先拍录音笔红点和攥白的指节，审讯灯只照亮吞咽的喉结；第 3 秒镜头缓慢后拉，文件袋、椅背和对面人影才进入画面`。
- 需要压缩时间或心理暗示时，优先考虑特写蒙太奇连接器。相似转场特写用于时间流逝：咖啡满杯到空杯、杯沿渍变深、便利贴增多、键盘碎屑堆积、台灯频闪、烟灰增长、药片减少、纸灰落满桌面。联想蒙太奇特写用于心理暗示：墨水吞掉白纸、玻璃杯水旋成漩涡、海面反光被树影切碎、灰尘在强光里翻涌、灯丝忽明忽暗。正式写法必须有 `现实触发 → 抽象特写意象 → 回到人物反应 / 当前物件结果`，不要把抽象意象写成无来源高级空镜。
- 机位角度必须服务情绪和视角关系。平视适合日常、真实和温暖家庭生活；轻度俯拍 / 高角度适合脆弱、孤立和被压住；低角度 / 仰拍适合儿童看成人、仪式压迫和遗像桌高度；45 度斜侧适合人物脸部层次和自然对话；正侧适合轮廓、剪影和沉默；正反打、过肩、门缝、窗缝、车内机位必须写清轴线、遮挡和空间内外。
- 运镜必须写路径、方向、速度和停点。固定镜头要写固定在哪个对象或空间；水平摇镜要写左摇 / 右摇、起点、经过物和停点；推镜要写从什么景别推进到哪个表情或物件；拉镜要写从哪个局部拉开到什么环境；升镜 / 降镜要写高度变化和最终看见什么；环绕要写围绕谁、转动角度和主体是否始终清楚；跟拍要写跟谁、屏幕方向和路径边界；甩镜要写触发声音和清楚落点。不要只写 `镜头移动`、`镜头切换`、`氛围感运镜`。
- 专业运镜术语必须先区分物理机制：Dolly / Track / Tracking Dolly 是机身整体移动；Pan / Tilt 是机身不动、镜头原地转动；Zoom 是焦段变化；Crane 是大幅高低升降；Jib 是小幅近距离升降；Handheld / Bumpy / Breathing Shake / Soft Stabilize 是稳定方式；Orbit / Arc / Match Move 是镜头和主体运动关系；Pass Through / Digital Dolly Through / Time-lapse Dolly / Spiral Dolly / Falling Dolly / Ascend & Dive 是创意或特效运动。希区柯克变焦必须同时写 `机身向前推进 + 光学变焦拉远 + 主体大小基本保持不变 + 背景空间拉伸畸变`。
- 光学质感必须和故事介质统一。浅景深用于突出主体和虚化背景，深景深用于空间关系、群像、场景资产和仪式，前景虚化 / 遮挡用于信息差和记忆感，镜头光晕必须有真实逆光或灯光来源，微距用于硬币、糯米皮、蒲团粗布、火苗等物证。90 年代家庭回忆优先老式 DV 质感、暖黄配色、轻微频闪噪点、自然光和中等景深；不要无故切成现代广告级商业大片、鱼眼畸变或宽幅史诗质感。
- 镜头语言与情绪要匹配：温暖治愈用平视、慢推 / 慢拉、自然光和轻遮挡；压抑孤独用高角度、缓慢拉远和空旷构图；紧张冲突用手持轻抖、快速推近、甩镜或正反打特写，但动作受力点必须清楚；严肃庄重用固定机位、平视或轻仰视、深景深和少运镜；宏大震撼用远景、仰拍、升镜和深景深，但仍要有近景锚点。
- 通用 AI 视频公式在本项目中只作为内部分层写作顺序，不作为正式字段。正式提示词仍只保留 `【基础设定】`、`【氛围与画质】`、`【画面内容】` 三块；写作时按 `镜头语言层 → 主体叙事层 → 环境布景层 → 光影色彩层 → 镜头光学质感 → 画幅帧率画质` 检查信息是否齐全。
- 分层职责：镜头语言层写景别、机位角度、运镜方式、镜头速度和确定时长；主体叙事层写人物 / 生物 / 物体、外貌穿搭、动作、神态和细微情绪；环境布景层写地点、空间结构、陈设、道具、前景遮挡、中景动作和远景背景；光影色彩层写光源方向、光线软硬、主色调、冷暖关系、光晕、丁达尔和阴影层次；镜头光学质感写焦段、人眼等效 / 广角 / 定焦、景深、散景、暗角、颗粒、畸变控制、胶片 / DV 介质；画幅帧率画质写横屏 / 竖屏、16:9 / 9:16 / 2.39:1、分辨率、帧率、稳定度和细节清晰度。
- 落入三段模板时，`【基础设定】` 负责世界观、实际调用资产和声音总规则；`【氛围与画质】` 承接风格核心、视觉基调、色彩与影调，主要容纳光影色彩、镜头光学质感、画幅帧率和全片介质；`【画面内容】` 承接镜头语言层、主体叙事层、环境布景层，以及本镜局部光影、动作、声音和转场。不要在正式代码块里新增 `镜头语言层 / 主体叙事层 / 环境布景层` 这些标题。
- 四套梯度公式只作为内部选择，不改变正式三段模板。短视频 / 卡点 / 10 秒内日常镜头用极简快速公式：`景别 + 机位 + 运镜 + 主体画面 + 光影氛围 + 画质规格`。商用短片 / 剧情短片用标准专业公式：`镜头语言层 + 主体叙事层 + 环境布景层 + 光影色彩层 + 镜头光学质感 + 画幅帧率画质`。长剧情 / 微电影 / 高质量封面短片用电影分镜完整版，在标准公式上补 `节奏情绪层` 和 `特殊效果层`，例如慢镜头、升格、纪实、梦幻、水雾、残影、旋转模糊。歌词 MV、氛围空镜和氛围人像用高级氛围感极简公式：`运镜动态 + 景别机位 + 氛围主体 + 前景 / 中景 / 远景环境层次 + 逆光 / 丁达尔光影 + 虚化散景 + 胶片 / DV 电影质感`。
- 所有梯度公式都要服务镜头任务。极简不是省掉动作因果，电影完整版不是堆特殊效果，高级氛围感也不是只写光斑和胶片；它必须写清前景、中景、远景分别是什么，光从哪里来，主体如何被环境包住，镜头最后停在哪里。外部通用公式里的“负面规避词结尾”不作为本项目正式正文层级，具体跑偏对象放在代码块外自检或失败经验里。
- `【氛围与画质】` 只保留 `风格核心`、`视觉基调`、`色彩与影调` 三个字段。三字段不是空标签，而是对标稿里的信息容器。
- `风格核心` 写题材类型、风格母体、真实程度、影像目标、情绪能量和生成边界，例如 `原子朋克、丧尸危机、末日爱情、电影级质感、超写实、极致逼真、Photirealism-真人实景拍摄、禁止动作迟钝僵硬、禁止逻辑混乱`，再补充画面要凸显的危机感、速度感、庄严感或奇观感。
- `视觉基调` 写画幅、摄影系统、镜头系统、机位方式、运动质感和拍摄临场感，例如 `变形宽荧幕电影质感，使用 IMAX 胶片摄影机，搭配 Panavision C 系列镜头，全程手持拍摄，添加动态模糊，轻微手持抖动`。
- `色彩与影调` 写时代 / 美术色彩、主辅色、对比关系、胶片 / 滤镜 / 颗粒、光源类型、高光与暗部处理、明暗过渡和材质光感，例如 `复古暖橙+海盐蓝高对比色调，胶片颗粒质感，自然日光光晕，高光保留纹理，暗部保留完整细节`。
- 如果作品有色彩风格资产，可以在 `【基础设定】` 里写 `色彩风格资产：【@C1 色卡名】固定全片母色卡和阶段变体`，方便老胡上传 / 绑定色卡图；但 `色彩与影调` 仍必须展开文字规则，写清本镜继承哪个母色卡或阶段变体，主色、辅助色、点缀色、肤色、光源色、暗部倾向、环境反光、饱和度、明度、对比度和胶片 / LUT 分级如何落到画面。
- 正式投喂给视频模型的提示词必须先用目标描述收束生成空间：画面里要出现什么主体、环境、动作、材质、光线、声音和情绪结果，就正向写什么。不能用排除句替代正向描述；模型会注意到被提到的对象。少量硬边界只用于抽象质量问题，例如动作僵硬、逻辑混乱、文字水印、比例畸形，并且不得引入当前镜头不该出现的具体视觉对象。风险判断、常见跑偏和不该出现的剧情物，写在代码块外的自检、回传字段或失败经验里。
- `【画面内容】` 才写当前分镜发生什么、怎么拍、有什么声音或动作。它必须写出动作链和因果链：主体动作如何触发道具、环境、光线、声音、表情和空间变化，最后产生什么冲击结果或连锁反应。不要只写“爆炸”“追逐”“打开门”，要写爆炸从哪里亮起、冲击波如何扩散、衣料和尘土如何被掀起、镜头如何抖动 / 失焦、同期声从什么动作产生。光影不要单独列成字段，要嵌入画面内容的自然段或分段描述里，写清它如何产生、照到哪里、影响周围什么环境或材质、形成什么结果，例如逆光、侧逆光、轮廓光、顶光、漫反射、体积光、丁达尔效应、明暗交错、剪影、局部高光、低照度噪点等。除非必须精确控制关键节点，不要把每秒都拆死。
- 正式写 `【画面内容】` 前必须先建立场景关系图：出场人物、出场物品、人物和物品、物品和物品、人物和人物之间的位置关系都要明确，并落到前景 / 中景 / 背景、画面左 / 右、近 / 远、门窗桌墙柜台道路光源等空间锚点里。不能只写事件名。错误写法：`女生拍男生肩膀，男生吓一跳，拉着走。` 正确写法：`镜头中男生站在画面中间偏左，女生从画面右后方绕到他背后，右手从男生右肩后方轻拍肩头；男生右肩向上一缩，身体向画面左前方小幅后撤，嘴型停住，女生站在他右后侧偏近处，随后拉住他的手腕往画面右侧带走。`
- 交互必须写清交互方式、接触点、作用力大小轻重、方向和可见结果。人物拍肩、牵拉、推开、递物，物品承重、滚动、碰撞、遮挡、变形，都要写谁 / 什么接触哪里，轻拍、突然一拽、双手用力、缓慢托住还是短促撞上，力从画面哪一侧指向哪一侧，受力后肩膀、手腕、碗、凳子、木轮、布料、液体、影子或镜头发生什么变化。
- 运动必须写清起点、路径、方向、终点和边界参照；运镜必须配合展示人物和物品关系。推镜用于让接触点和表情变清楚，拉镜用于露出人物和物品的空间关系，摇镜用于从一个对象扫到另一个对象，升镜用于从局部关系揭示整体布局。不要只写 `镜头移动 / 镜头拉远 / 镜头跟随`，要写它跟谁、从哪里到哪里、最终让观众看见哪些关系。
- 局部光影必须说明光源位置、光线方向、光线类型、照射对象、材质影响、形成的高光 / 阴影 / 反光 / 轮廓 / 丁达尔 / 明暗变化，以及这些变化如何影响画面氛围或动作可读性。错误写法：`温馨光影，画面很有氛围。` 正确写法：`右侧窗外暖光从人物侧后方斜照进来，擦过女生发梢和男生右肩，在木桌边缘形成一条软高光；女生靠近男生背后时短暂挡住一部分侧光，男生脸侧亮面暗了一下。`
- 每条视频提示词必须设计壁纸帧 / 审美停点：至少有一个暂停后仍然成立的画面瞬间，具备清楚主体轮廓、前景 / 中景 / 背景层次、视觉中心、留白、主次色彩、方向性光影、材质细节和镜头停稳点。审美停点要从剧情动作里长出来，不靠无关漂亮空镜或滤镜词。正式正文要写成可见结果，例如 `镜头最后停在...`、`画面形成...构图`、`前景...中景...背景...`、`右侧留出...空白`、`暖光勾出...轮廓`。错误写法：`画面温馨好看，有电影感。` 正确写法：`镜头轻轻后拉后停住，男生在画面中间偏左，女生站在他右后侧半步，右侧窗光勾出两人肩线，背景木门和墙面虚化成暖黄块面，画面左上留出一块安静空白，像一张生活喜剧海报。`
- 构图、光影、色彩以及后续审美模块都不是封闭词表。老胡给出的词是启发样例，不是固定菜单；正式写提示词时要从剧情情绪、时代背景、空间材质、人物肤色、道具颜色、光源类型、壁纸用途和剪辑连续性反推搭配。未列出的有效方案也可以使用，例如层叠构图、纵深透视、火光主光、雪地反光、黑白灰单色、褪色老照片、煤油灯暖褐、山城雾灰绿等。
- 壁纸帧必须先有构图逻辑。正式写 `【画面内容】` 前，先为审美停点选择一个明确构图结构：三分构图、黄金分割构图、中心对称构图、框架式构图、引导线构图、对角线构图、留白构图、前景框构图或三角稳定构图。选择后要写清主体落点：主体在左 / 右三分线、黄金分割点、画面中心、门框 / 窗框 / 车窗形成的框内、道路 / 桌沿 / 光束引导线尽头、对角线运动方向或三角支撑关系上。构图还要控制大面积干净留白、上方留白、侧边留白、极简留白或负空间；视觉重心稳定，主体可位于画面 1/3 处，边角干净无杂物。动态推拉摇移可以存在，但关键停点必须回到稳定构图。横屏剧情优先 16:9 标准壁纸；宽银幕情绪用 21:9 宽幅电影画幅；竖版人物和手机壁纸用 3:4 竖幅人像壁纸比例；文艺封面可用方形文艺画幅。
- 留白必须区分空间留白和信息留白。空间留白是天空、海面、墙面、暗部、雾气、窗外虚景和负空间；信息留白是半张侧脸、发丝遮眼、嘴唇下颌、手和首饰、门缝局部、背影回头一点点等局部遮蔽。开场钩子、封面、人物第一眼、暧昧、危险、身份悬念和神秘氛围可以用信息留白；情绪高潮、争吵、落泪、台词反应和关键动作因果必须让表情或动作证据清楚。正式写法要说明遮住哪里、露出哪里、光勾出哪里、观众靠哪个局部补完人物。错误写法：`画面有神秘留白`。正确写法：`人物位于左侧三分线，只露右半张侧脸，前景发丝和树影遮住左眼区域，侧逆光勾出鼻梁、唇峰、耳坠和下颌线，右侧海面负空间保留约 45%`。
- 壁纸帧必须有光影体系。正式写 `【画面内容】` 前，先确定 `时段光线 + 主光方向 + 弱辅光 + 轮廓光 / 反光 + 阴影层次 + 材质反应 + 动态稳定`，不能只写 `自然光`。壁纸优先使用黄金一小时逆光、日出柔光、蓝调时刻冷光、傍晚漫射光、雨后柔和天光；室内生活戏可用柔和窗光、门缝冷光、灶火暖光、旧灯泡暖光或屋檐下漫反射。光型至少写清主光、弱辅光、轮廓光 / 反光中的两层，例如单侧轮廓逆光、侧顺柔光、层次主光 + 弱辅光、包裹柔光、柔和窗光。阴影要写柔和虚化阴影、低对比度阴影、细腻层次阴影、长投影、镜面反光、水面反光或透光纱质柔光，避免生硬死黑阴影。动态镜头要锁定光源方向，例如 `全程保持同一扇窗侧逆光，镜头后拉时光源方向不变`。
- 壁纸帧必须有色彩美学体系。正式写 `【画面内容】` 前，先确定 `主色调 + 辅助色 + 点缀色 + 饱和度策略 + 明度 / 对比 + 环境色反光 + 色彩过渡 + 统一滤镜 / 分级`，不能只写 `高级调色` 或 `复古滤镜`。色彩母体可根据故事扩展选择：莫兰迪低饱和、青橙电影色调、冷调蓝灰、复古胶片棕调、奶油温柔、低饱和马卡龙、暗调黑金、清新森系绿调、黑白灰单色、褪色老照片、山城雾灰绿、煤油灯暖褐、旧木头深棕 + 孝布冷白、纸灰冷灰 + 火盆暖橙等。每个停点优先 `1 个主色 + 1 个辅助色 + 1 个小面积点缀色`，通常不超过 2 种主色；写清统一环境色、柔和色彩渐变、墙面 / 地面 / 水面 / 玻璃 / 木桌环境色反光，以及富士胶片色调、柯达金 200、电影 LUT、轻微暗角或低对比度色彩分级如何统一画面。避免多种高饱和颜色同时堆砌。
- 色卡使用遵守 `母色卡不变，阶段变体受控变化`。同一作品优先建立全片母色卡，阶段变体只调整明度、暗部冷暖、点缀色面积、肤色气色、环境反光和阴影重量，不要每个分镜随机换色卡，也不要所有分镜完全死用同一色卡。正式提示词里，色卡图是参考，文字规则是执行；两者必须对应。
- 壁纸帧必须有景深与空间层次体系。正式写 `【画面内容】` 前，先确定 `前景虚化遮挡 + 中景清晰主体 + 远景朦胧环境 + 焦段选择 + 焦点落点 + 虚实过渡 + 空气透视 / 散景`，不能只写 `浅景深`。焦段按任务选择：85mm 人像定焦用于壁纸人像、表情和背景压缩；50mm 标准人文镜头用于家庭纪实、饭桌、门口对话和自然观看；35mm 人文广角用于 POV、室内空间、放学路和环境关系；135mm 长焦用于压缩距离、远处背影、院门和遗物疏离感。每个停点要写清前景是什么、中景主体是什么、远景如何柔化；景深要匹配信息量，情绪 / 道具 / 遗物可浅景深，群像 / 仪式 / 空间因果用中等或深景深；动态镜头要写焦点从哪里转到哪里，并在停点锁住主体。错误写法：`画面浅景深，很有电影感。` 正确写法：`画面左侧虚化门框形成暗边，中景奶奶端药碗的手清晰锐利，远景堂屋旧墙和灯泡化成暖黄散景，50mm 标准人文镜头，中等偏浅景深，焦点稳定锁在药碗和奶奶手指上。`
- 壁纸帧必须有画质与材质质感体系。正式写 `【画面内容】` 前，先确定 `分辨率清晰度 + 主体边缘锐度 + 材质质感细分 + 微细节锚点 + 运动模糊控制 + 画面洁净度 + 介质颗粒边界`，不能只写 `8K 高清`。要写清本镜值得放大看的材质：旧木纹、糯米皮水光、旧瓷釉面、蒲团粗布经纬、纸灰颗粒、火苗边缘、玻璃反光、硬币旧金属磨损、衣料纤维或旧墙斑驳。材质词要绑定物件：哑光柔和质感、磨砂低反光、丝绒柔和肌理、金属细腻拉丝、水雾朦胧质感、细腻胶片颗粒或受控老式 DV 噪点都要说明落在哪个表面。动作镜头的审美停点要极低运动模糊、主体边缘稳定、关键手部和道具清楚，画面干净通透，避免多余虚影、边缘崩坏、压缩糊块、随机文字和水印。错误写法：`8K 超高清，电影质感。` 正确写法：`镜头停在木轮特写时极低运动模糊，轮辐边缘锐利，粗糙木轴纹理、纸灰颗粒和旧木哑光表面清楚；老式 DV 只有受控轻微颗粒，不破坏木纹和手指边缘。`
- 壁纸帧必须有氛围环境元素体系。正式写 `【画面内容】` 前，先确定 `天气 / 时间基底 + 空气媒介 + 漂浮微粒 + 光学点缀 + 环境运动 + 密度控制 + 题材适配`，不能只写 `氛围感`。可用元素包括清晨薄雾、雨后水汽、黄昏薄雾、冬天冷雾、灶房水汽、火盆烟气、窗边落尘微光、林间水汽、细雨水雾、纸灰飘散、落叶轻动、轻柔烟尘、水面波光、漫射柔光粒子、轻纱透光等；但每个元素必须有来源、方向和密度。家庭纪实优先窗边落尘、灶房水汽、旧灯泡光晕、纸灰和落叶；丧事病床优先冷灰薄雾、低密度浮尘和火盆纸灰；浪漫或 MV 才用明显花瓣和强镜头光斑。错误写法：`画面有雾和光斑，很有氛围。` 正确写法：`雨后水汽贴着院门和旧墙形成很薄的冷灰雾，旧灯泡暖光只在窗边照出细小尘粒，纸灰从火盆边缘轻轻飘起，密度很低，不遮住小安手里的木轮。`
- 壁纸帧必须有镜头运动约束。正式写 `【画面内容】` 前，先确定 `机位稳定策略 + 运镜速度 + 抖动强度 + 变焦 / 旋转控制 + 构图保持 + 可定格停留 + 运动模糊边界`，不能让镜头全程快速推拉、旋转、变焦或晃动。家庭纪实、病床、遗像、饭桌、门口对话、遗物和仪式优先固定机位长镜头、极缓慢微动运镜、轻微呼吸手持、低抖动稳定画面和可定格电影镜头；追逐、冲突和慌乱才短暂使用颠簸手持、甩镜或快速推近。动态镜头必须有停点：关键动作后停住 1-2 秒，让主体、留白、光影、景深和材质稳定下来。错误写法：`镜头快速推进旋转，很有动感。` 正确写法：`镜头以极缓慢推镜靠近药碗，推到奶奶手指和碗沿落在右侧三分线后停住一拍，画面低抖动，碗沿反光、旧瓷釉面和手指纹理清楚，适合截图。`
- 场景、动作和表情必须先通过情节合理性判断。正式写 `【画面内容】` 前，先回答：人物为什么在这个场景，表面正在做什么，内心实际发生什么，动作是否由上一句台词、关系阶段、人物性格和场景姿态自然触发。不要为了显得甜、可爱、伤心或有细节，就机械添加捂嘴、抓衣角、低头、摸头发、转身、看远方等通用动作。错误写法：`独处傻乐，所以捂嘴、抓衣角、下摇到手部。` 正确写法：`她停在海边栏杆处，表面看海，实际回想上一句问候；前 3 秒眼神放空，约第 4 秒单侧嘴角先翘起，随后眼睛弯起来，笑意从脸上漏出来。`
- 表情主任务镜头必须防止低位身体和服装细节抢镜。只要镜头目标是脸部情绪变化，就不要把手部、脚步、鞋尖、裙摆、腰间系带、包带写成情绪证据，也不要写 `下摇 / 下压 / 下移到手 / 下移到裙摆 / 下移到鞋尖`。错误写法：`强撑理解，所以镜头下压到手指抠衣角，再回到脸`；`热恋期待，所以鞋尖在树影边缘顿一下，裙摆和腰间系带轻摆`。正确写法：`胸部以上舒适近景固定锁脸；她低头、抬眼、嘴角硬撑，喉咙吞咽一下，眼眶边缘出现细窄水光，肩线塌下半寸，仍然看回镜头；脸侧发丝、耳坠和吊坠被海风轻轻带动。`
- 涉及身体和道具配合的动作，正式提示词必须做空间排练：从哪个方向接近，哪只手或脚先动，身体如何坐下 / 跨过 / 起身 / 转身，道具如何承重和移动，镜头跟随谁，移动后哪些人物仍在画面内。禁止前后动作物理关系冲突，例如“角色已坐在车上”却又把车写成空车滑走，或“第一人称 POV”却看见 POV 主体不可能看见的身后正脸。
- 病弱、受伤、输液和病床镜头必须写状态证据链。不要只写 `虚弱 / 病弱 / 躺床 / 气息略虚`，要同时写脸色、唇色、眼皮、额汗、呼吸、说话音量、断句、停顿、动作幅度、手部力量、床单或被角反应，以及药碗 / 输液管 / 胶布 / 照护者表情等外部证据。错误写法：`爷爷躺床上但保持安慰孩子的笑，气息比平时虚。` 正确写法：`爷爷半靠旧枕头，脸色偏白泛灰，唇色浅，眼皮沉，额角有细汗；看见镜头后只牵动嘴角，声音低、沙、短，中间轻喘停顿；没输液的手从被沿挪出一点又停住。`
- 病床触碰动作必须做床侧、输液侧和可达性排练。躺床、输液、受伤、虚弱或被照护的人要牵手、摸头、拍手、递物、擦泪或安慰孩子时，先判断孩子站在哪一侧、输液针扎在哪只手、输液管从哪里走、哪只手靠近床沿、远侧手是否被身体 / 被子挡住、病人翻身或抬臂是否费力。错误写法：`爷爷躺床上，用另一只手伸过来摸小安的手`。正确写法：`小安站在靠输液手这一侧，指尖碰到胶布又缩回；爷爷不翻身、不抬远侧手，只把床沿附近的输液手小幅度转动，指尖反手轻碰小手，输液管轻轻晃一下。`
- 涉及儿童和成人尺度道具 / 场景交互时，正式提示词必须做身高、视线和可达性排练。先判断儿童是否够得到、看得全、拿得动、能不能独立完成操作；如果不能，就写成人手递下 / 接回、孩子踩矮凳、物件只露局部、玻璃反光、模糊轮廓、垂下来的线、从高处传来的声音。错误写法：`小安趴在柜台边，黑色老式座机、卷曲电话线和硬币占画面中心，听筒被小手放回座机。` 正确写法：`画面低于玻璃柜台上沿，座机主机在柜台上方只是一团模糊黑影；成人手把听筒递到画面前，卷曲电话线从高处垂下来；通话结束成人手接回听筒，高处传来咔哒挂断声。`
- 涉及滑行、奔跑、追逐、推车、摔倒、冲撞、车辆行驶、人物走位和镜头穿越等移动类画面时，必须写清起点、路径、终点、屏幕方向和空间边界。正常路径中哪些区域通畅、障碍物位于哪一侧边界、为什么会撞上，都要符合生活逻辑。错误写法：`木车从小坡滑下，撞到一块石头`。正确写法：`木车从坡顶沿坡面中线滑向坡底缓冲区，旧院墙在画面左侧，水槽 / 木料堆在画面右侧；试玩孩子控制不好，车头偏向左侧旧墙根，撞到坡底左侧贴墙压边石 / 墙脚，路中央保持通畅。`
- 多人群像和围桌场面必须先做座位图 / 站位图。饭桌、会议桌、课堂、灵堂仪式、院子围观、家庭合照、群体争执等多人同框镜头，要写清视点位置、桌子或场地朝向、每个关键人物在画面左 / 右 / 前 / 后 / 近旁 / 远侧的位置，再写台词、视线、递物和冲突。错误写法：`饭桌居中，家人手和碗环绕，大家先后吃到硬币`。正确写法：`小安坐饭桌近侧中间，自己的碗在最前景；爷爷坐小安右手边、画面右前方近旁；姐姐坐画面左侧，奶奶坐对面中间，父亲坐对面偏右靠旧墙。视线依次扫向左侧姐姐、对面偏右父亲、右前方爷爷，再低回自己碗里。`
- 冲突动作必须有前置动机、靠近路径和身体受力。推开、打断、抢夺、摔倒、撞倒、拉扯、抱住、躲开等动作，不能只写冲突结果。要写被推 / 被撞 / 被抢的人为什么靠近、怎么从原位置移动过来、手或道具伸向哪里、主角为什么反应、推力作用到哪个部位、后退或摔倒撞到什么合理边界。错误写法：`爷爷坐在桌旁把硬币伸过来，小安一推，爷爷跌到柴火边`。正确写法：`爷爷撑桌起身，从右侧桌边绕到小安身旁，拿小布巾弯腰想擦眼泪；小安推开贴近脸前的手腕和胳膊，爷爷后退半步，脚跟撞到右侧小木凳后跌坐柴火边。`
- 冲突动作改稿必须把结果句改成可排练动作链。先诊断旧稿是否只有“靠近、推、倒”的结果；再补六项：靠近动机、移动路径、接触点、反应触发、受力方向、承接边界。不要只写 `用力 / 猛地 / 痛苦 / 摔倒` 这类强度词。当前案例的改法是：把 `爷爷坐在桌旁伸硬币` 改成 `爷爷为了安慰孩子，撑桌起身，拿硬币和小布巾绕到小安右前方，弯腰擦眼泪`；把 `小安一推，爷爷跌倒` 改成 `小安推开贴近脸前的手腕和胳膊，爷爷弯腰重心在前，后退半步撞到右侧小木凳，手撑地跌坐到柴火边`。
- 如果来源剧本有 `角色名（语气 / 神态）：`、`角色名 VO（语气 / 神态）：`、`角色名（OS）：`、动作段表情或插入镜头表情，正式视频提示词必须在 `【画面内容】` 中继承这些表演信息，不新增单独字段。不要只复制“忍着哭”“压着火”“故作轻松”这类抽象词，要写成可见 / 可听的表演结果：眼神、眉头、嘴角、嘴唇、下巴、呼吸、肩膀、手指、停顿、声音和身体距离。第一人称 POV、背影、远景或不露脸时，用手部攥紧、呼吸停住、声音发紧、肩背僵住、衣角被攥皱、反射里的眼神、脚步停顿或道具轻抖来替代表情。
- 人物声音要区分“基础音色参考”和“本镜声音状态”。基础音色写在人物设计资产图片的音色文字说明区，并通过 `【音色参考@xx】` 音频参考保持跨镜头一致；本镜声音状态写在画面内容里，例如虚弱、沙哑、哭腔、压低、喊远、隔门闷住、电话电流失真、VO 回响。禁止每个镜头随意换音色，也不要在每条基础设定里重复长篇基础声线。
- 关键发声镜头必须开音色例外。短视频开场钩子、人物第一次出声、重要 VO 回响、争吵爆点和情绪反转句，不能只写 `【音色参考@xx】`；要在 `【基础设定】` 的 `声音设定` 里用 1-3 句写清本镜声线、音区、共鸣、颗粒、近麦 / 距离、咬字、尾音和语气，再在 `【画面内容】` 写停顿、气口、回响和表演节奏。开场要抓人时，女声可写冷感磁性女中音 / 偏低女声，中低频到中频集中，胸腔共鸣稳定，轻微沙哑颗粒，近麦干声，咬字利落，尾音短收；不甜、不夹、不软，不做主持播音腔。
- 台词、旁白、画外音和脑内 VO 必须按“双层声音表演”写。正式提示词不能只写 `温柔 / 生气 / 压迫 / 破碎 / 甜 / 刺` 这类抽象情绪，也不能只写 `音高压低 / 音量中等 / 语速收紧` 这类机械参数。正确顺序是：先写情绪意图和说话态度，例如示好、试探、亲昵、期待、敷衍、心虚、防御、不耐烦、反推责备、轻蔑、愤怒、暴怒、切断、空洞残响；再写音高 / 音区、响度 / 音量、语速 / 节奏、停顿 / 气口、重音位置、气息状态、咬字 / 吐字、软硬强弱、爆发力、距离感、混响和衰减。错误写法：`男声音高压低，音量中等，语速收紧`。正确写法：`男声带防御和心虚，急于把怀疑压回去；声音收紧发硬，音区偏低，音量不大但压迫感明显，重音压在“她”和“普通朋友”上，“可以吗”短促下压。`
- 如果一个 VO 是人物表情变化的主要触发器，必须按阶段设计声音曲线。初识、热恋、平淡、猜忌、争吵、决裂不能共用同一种普通年轻男声；也不能只逐条改变音量、距离、语速、停顿、重音、气息、咬字和回响衰减。当前案例：《30秒钟带你体验谈恋爱》的男声脑内 VO 应从轻佻试探、亲昵冒进、稳定惦记、热恋期待、敷衍抽离、防御心虚、不耐烦反推责备、烦躁反咬、轻蔑攻击、暴怒切断到空洞残响逐步变化。
- 正式交付给老胡复制和手动调试的视频提示词，`【氛围与画质】` 默认使用中文专业表达。少量器材、规格和通用缩写可以保留，例如 `ARRI Alexa 35`、`IMAX`、`Panavision`、`35mm / 50mm / 85mm`、`LUT`；但肤色、妆效、色彩、光影、景深、质感、环境和运动稳定必须优先中文化，方便老胡后续复盘、替换和微调。不要把整段写成英文关键词清单。
- 情绪人像、恋爱短片、开场钩子和外景美人片的 `【氛围与画质】` 不能只写 `写实电影级 / ARRI / 高级人像`。这些词只锁真实度和设备感，不能锁审美方向。写作前必须建立 `风格交集 = 主风格母体 + 辅助风格 + 胶片 / 滤镜分级 + 明度对比 + 光影方式 + 肤色妆效 + 场景环境色 + 情绪阶段边界`。当前可复用例子：`真人写实海边情绪短片，日系清新治愈青春电影色彩为主，海边低饱和胶片写真为辅，清新透亮，高明度低对比，柔和自然光，空气感散景，富士胶片清透蓝绿倾向，柯达 Portra 式自然人像肤色过渡；前半段清澈明亮，后半段同一美景不变，只通过人物眼神、留白扩大、树影压面和气色变化转成现实虐恋感`。这类句子要拆进 `风格核心 / 视觉基调 / 色彩与影调` 三字段，不新增正式字段。
- 正式写视频提示词前必须完成摄影指导层判断：`光影分离 + 动态光源 / 光影运动 + 光源色温 + 主体细节束 + 空间层次 + 时间天气空气 + 镜头参数 / 景深 + 画面类型自动选型 + 情绪反差点 + 正向质量边界`。这不是新增正式字段，而是写作前防漏项。光影分离要让亮面、暗面、轮廓光、反光和背景有层级；动态光源必须有动机，例如风吹树叶形成移动树影、车灯掠过墙面、火盆 / 烛光轻微跳动、水面反光缓慢变化；主体细节束按 `颜色 + 材质 + 纹理 + 状态 + 反光 + 破损 / 湿度 / 瑕疵 + 边缘细节` 写到具体人物、道具和场景上；镜头参数按画面类型自动选型，85mm / 100mm 用于人像表情，50mm 用于自然关系和跟拍，35mm 用于 POV 和环境关系，135mm 用于疏离和距离压缩；情绪反差点要落实成可见画面，例如清新海边但树影压面、暖光仍在但眼神空掉。
- 情绪人像和开场钩子不能只写抽象表情。`【画面内容】` 要写眼神、眼睑、眉峰、单侧嘴角、鼻翼、下巴、呼吸、停顿和笑意收放路径；皮肤妆效要先用正向状态锁住第一眼观感，不能只写 `高光不过曝 / 不油亮`。推荐顺序是：肤色与气色（冷白 / 暖白 / 中性白、白皙通透、肤色匀净、健康气色）→ 底妆妆效（清透裸妆、轻薄服帖底妆、柔雾奶油肌、柔焦云雾感底妆、贴肤型轻薄粉底、柔雾哑光带内透光肤感、缎光柔雾肤感）→ 五官妆容（柔雾眉、灰棕眼影、细内眼线、自然卷翘睫毛、裸杏腮红、低饱和玫瑰豆沙唇）→ 渲染补精度（细微毛孔、皮肤微纹理、自然漫反射、柔和次表面透光、高光过渡柔和、细腻 35mm 胶片颗粒）。同一人物同一妆造应沉淀为提示词资产，在每条近景 / 中近景 / 特写的 `【氛围与画质】` 展开；`【画面内容】` 再写阳光擦过发丝、肩线、脸侧边缘，耳坠、项链、吊坠、发丝、树影、海风和环境反光参与情绪运动。包带、腰间系带、裙摆、鞋尖等低位造型细节只在服装展示、全身动作、资产展示或明确道具证据镜头里写；表情主任务镜头不让这些细节承担情绪。
- 一条视频提示词内部如果需要连续动作段落，可以在 `【画面内容】` 使用 `动作段1（0-1.5秒）` 这类模型可执行标签；它只用于本条视频内部的动作编排，不等于 `分镜编号`、`所属场次` 或 `镜头任务`。
- 资产写法：提示词资产优先展开到 `【基础设定】` 和 `【氛围与画质】`；图片资产 / 固定资产如果会作为参考图、图生视频首帧或平台资产输入，`【画面内容】` 不要重复长篇描述它的本体外观，重点写它在当前镜头中的动作、受光、遮挡、反射、风吹、变形和环境交互。没有图片资产固定的角色、路人、建筑、道具和场景，必须在 `【画面内容】` 中详细写外观、材质、服装、表情、结构、体量、空间位置和光影影响。
