# 模板：人物表演_情绪时间轴

本模板用于复杂对白、沉默反应、情绪转折、15-30 秒长表演和多人对手戏的内部排演。普通功能台词不强制使用。它不是正式视频提示词的第四层，完成后要压缩进 `【画面内容】` 的自然语言镜头块。

## 一、场景级前提

```text
角色：
既定处境与关系：
本场总目的：角色最终想让对方做什么、相信什么、停止什么，或想掩盖什么
主要阻力：
性格与控制能力：
初始保护策略：反击 / 否认 / 讨好 / 沉默 / 转移 / 装作平静 / 其他
镜头与可读范围：近景 / 中近景 / 中景 / 其他；脸、手、身体、关系距离中哪些能被看清
总时长与模型：
```

## 二、八维节拍表

节拍数量由真实变化决定。这不是固定四段模板，也不按固定秒数机械平均；上一节拍结束状态必须成为下一节拍开始状态。

| 节拍 / 时间范围 | 人物目的 | 情绪变化与保护策略 | 精确触发 | 面部动作与可选 AU | 目光、身体、关系距离 | 声音、呼吸、停顿 | 结束状态与静止反应 |
|---|---|---|---|---|---|---|---|
| 节拍1： |  |  |  |  |  |  |  |
| 节拍2： |  |  |  |  |  |  |  |
| 节拍3： |  |  |  |  |  |  |  |

每个节拍另写一条贯穿约束：

```text
禁止提前反应：在[具体触发 / 具体词 / 峰值]之前，不得出现[落泪 / 崩溃 / 吼叫 / 微笑 / 转身 / 退缩 / 道具动作 / 其他]。
```

## 三、八维填写原则

```text
时间范围：从内容最低可读时间倒推，不套 0-2 / 2-4 / 4-6 秒固定模板。
人物目的：写可执行关系结果，不写“想要尊严、很委屈”。
情绪变化：写保护层怎样维持、松动、破裂或重新建立。
精确触发：优先锁定一句台词中的重词，或一个可见 / 可听事件。
面部动作：先写自然语言；近景且确有歧义时才补 1-3 个 AU。
目光身体：写对象、重心和距离，不写无对象的“看向远方”。
声音呼吸：先写态度，再写重音、音量、语速、气口和停顿。
结束状态：写台词后的余波和下一节拍入口，不写“恢复自然”。
```

## 四、输出编译档位

### A. 功能表演

只输出 `当前态度 + 可见动作 / 声音 + 结束状态`，不展示八维表，不使用 AU。

### B. 单次承重转折

八维内部完整判断，正式正文合并成一个因果句，优先保留：人物目的、保护策略、触发、2-4 个承重通道、禁止提前反应和结束状态。

### C. 复杂长表演 / 多人对手戏

先完成整张节拍表。正式正文中，全局不变项只写一次；每个后续节拍只写 `上一状态 → 新触发 → 本次变化 → 新结束状态`。时间范围是否进入正式正文服从模型规范，项目默认用镜头块、台词重词和动作节点表达顺序。

## 五、压缩成正式提示词

内部完整表：

```text
人物目的：逼对方承认她的劳动也算家庭贡献。
保护策略：用愤怒保护被否定后的受伤。
触发词：“这不算挣钱”。
面部：眉间内收、眼睑收紧；触发后眼眶才出现水光，下巴绷紧。
目光身体：始终直视，触发后仍不后退。
声音呼吸：前半句硬，触发时呼吸停半拍，句尾出现轻微颤音。
禁止提前反应：句尾前不落泪、不移开视线、不转身。
结束状态：说完仍盯着对方，胸口起伏，等回答。
```

正式模型正文压缩为：

```text
她要逼他承认自己的付出，仍用愤怒压住受伤；听见“这不算挣钱”时呼吸停半拍，眉间内收、眼眶才出现水光，声音从硬直降到发颤，但句尾前不落泪、不移开视线；说完仍盯着他，胸口起伏，等他回答。
```

压缩删除的是标签和重复，不是因果。某一维会改变结果却无法由上下文继承时，必须保留；仍超出字符上限时删非承重镜头效果或拆分 VID。
