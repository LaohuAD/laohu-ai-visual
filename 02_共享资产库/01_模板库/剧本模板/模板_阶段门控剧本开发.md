# 模板_阶段门控剧本开发

> 用途：把剧本开发拆成可检查的阶段，避免一次性生成一个看似完整但无法继续制作的剧本。

## 一、体量路由

先判断作品体量，再选择剧本深度。

| 体量 | 适用场景 | 剧本要求 |
|---|---|---|
| 15-60 秒短视频 | 视觉钩子、反转、单个情绪点 | 1 个核心动作，1-3 个镜头 |
| 1-3 分钟概念片 | what-if、形式实验、强概念 | 1 个高概念，1 次情绪或信息翻转 |
| 3-10 分钟短片 | 完整起承转合 | 主角目标、阻力、代价、选择完整 |
| 系列短剧 | 连续冲突、强钩子 | 单集钩子 + 人物长期欲望 + 集间悬念 |
| MV / 视觉诗 | 情绪、节奏、风格 | 音乐结构、视觉母题、情绪推进 |

如果体量不清楚，先问：

```text
这个故事更适合做 15-60 秒短视频、1-3 分钟概念片，还是 3-10 分钟叙事短片？
```

## 二、八步开发流程

### 1. 破题与核心动作

```text
故事题目：
核心动作：
主角想要：
直接阻力：
失败代价：
最有画面感的冲突瞬间：
```

通过标准：

- 不是一句主题口号。
- 能说清“谁想要什么，谁或什么阻止他”。
- 已经出现一个能被拍出来的冲突画面。

### 2. 梗概草稿

```text
一句话故事：
一段话梗概：
开场画面：
中段升级：
结尾选择：
最后一个画面：
```

通过标准：

- 观众能知道自己在等什么。
- 冲突不是随机事件堆叠，而是选择带来后果。
- 结尾不是解释主题，而是人物做出不可逆动作。

### 3. 人物深度与弧光

```text
人物：
外在目标：
内在需求：
错误信念：
前史压力：
性格矛盾：
关系压力：
弧光起点：
弧光终点：
```

通过标准：

- 人物不是工具人。
- Want 和 Need 之间有张力。
- 角色变化能通过动作和选择看见。

### 4. 前史与世界观

```text
故事开始前发生过什么：
主角带着什么旧伤进入第一场戏：
人物关系在故事开始前已经积累了什么：
世界运行规则：
观众需要知道的信息：
观众暂时不能知道的信息：
```

通过标准：

- 世界不是从第一场戏才开始存在。
- 前史不会变成大段解释，而是能散入动作、道具、台词和场景。

### 5. 结构大纲

```text
开场钩子：
诱发事件：
第一次选择：
中点转折：
最低谷：
最终选择：
结尾余味：
```

通过标准：

- 每个节点都是行动，不是心理变化。
- 选择之后有后果。
- 代价逐步升级。

### 6. 场景拆解

| 场次 | 地点 | 时间 | 场景目标 | 阻碍 | 结果 | 预计时长 | 可视化重点 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

通过标准：

- 每场戏至少有一个微型戏剧动作。
- 场景不能只负责交代信息。
- 每场戏都能拆成镜头或视觉资产。

### 7. 场景写作

写作红线：

- 不写“他意识到”“她心里觉得”等心理描写。
- 不用台词解释主题。
- 不写摄影机拍不到的内容。
- 不写括号里的表演暗示。
- 不用煽情独白替代动作。

写作要求：

- 动作即潜台词。
- 台词口语化。
- 场景有声音、停顿、空间关系。
- 关键情绪落到表情、手部动作、视线、呼吸、距离变化。

### 8. 剧本医生

```text
故事核心是否清楚：
主角目标是否明确：
阻力是否足够：
人物弧光是否能被看见：
场景是否都有功能：
台词是否过度解释：
视听表达是否足够：
是否能继续拆成图片和视频提示词：
最大风险：
修改优先级：
```

## 三、输出纪律

- 每次只推进一个阶段。
- 阶段完成后可以进入下一阶段，也可以先做自检。
- 如果是老胡直接要求“一次性出完整项目草案”，也要按阶段标题输出，不混成一段。
- 剧本完成后必须进入 `02_共享资产库/05_工具流程/剧本到AI视觉资产转换规则.md` 的四张表。
