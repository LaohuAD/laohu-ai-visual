# 模板_阶段门控剧本开发

> 用途：把剧本开发拆成可检查的阶段，避免一次性生成一个看似完整但无法继续制作的剧本。

## 一、体量路由

先判断作品体量，再选择剧本深度。

| 体量 | 适用场景 | 剧本要求 |
|---|---|---|
| 15-60 秒短视频 | 视觉钩子、反转、单个情绪点 | 1 个核心动作，1-3 个镜头 |
| 1-3 分钟概念片 | what-if、形式实验、强概念 | 1 个高概念，1 次情绪或信息翻转 |
| 3-10 分钟短片 | 完整起承转合 | 主角目标、阻力、代价、选择完整 |
| 系列短剧 | 连续冲突、强钩子 | 单集钩子 + 人物长期欲望 + 集间悬念 |
| MV / 视觉诗 | 情绪、节奏、风格 | 音乐结构、视觉母题、情绪推进 |

如果体量不清楚，先问：

```text
这个故事更适合做 15-60 秒短视频、1-3 分钟概念片，还是 3-10 分钟叙事短片？
```

## 二、九步开发流程

### 0. 导演总控判断

```text
主导身份：编剧 / 导演 / 文戏导演 / 动作导演 / 摄影指导 / 剪辑指导 / AI 生成导演
价值母题：
观众误判：
传播入口：
体量节奏：15 秒 / 30 秒 / 60 秒 / 1-3 分钟 / 3-10 分钟 / 系列
文戏占比：
武戏 / 动作占比：
核心观看任务：
```

通过标准：

- 已经知道本轮主要解决故事、表演、动作、画面、剪辑还是生成问题。
- 不只写“开头钩子 / 中段升级 / 结尾评论”，而是知道每个段落如何推进注意力。

### 1. 破题与核心动作

```text
故事题目：
核心动作：
主角想要：
直接阻力：
失败代价：
最有画面感的冲突瞬间：
```

通过标准：

- 不是一句主题口号。
- 能说清“谁想要什么，谁或什么阻止他”。
- 已经出现一个能被拍出来的冲突画面。

### 2. 梗概草稿

```text
一句话故事：
一段话梗概：
开场画面：
中段升级：
结尾选择：
最后一个画面：
```

通过标准：

- 观众能知道自己在等什么。
- 冲突不是随机事件堆叠，而是选择带来后果。
- 结尾不是解释主题，而是人物做出不可逆动作。

### 3. 人物深度与弧光

```text
人物：
外在目标：
内在需求：
错误信念：
前史压力：
性格矛盾：
关系压力：
弧光起点：
弧光终点：
```

通过标准：

- 人物不是工具人。
- Want 和 Need 之间有张力。
- 角色变化能通过动作和选择看见。

### 4. 前史与世界观

```text
故事开始前发生过什么：
主角带着什么旧伤进入第一场戏：
人物关系在故事开始前已经积累了什么：
世界运行规则：
观众需要知道的信息：
观众暂时不能知道的信息：
```

通过标准：

- 世界不是从第一场戏才开始存在。
- 前史不会变成大段解释，而是能散入动作、道具、台词和场景。

### 5. 结构大纲

```text
开场钩子：
诱发事件：
第一次选择：
中点转折：
最低谷：
最终选择：
结尾余味：
节奏网格：
```

通过标准：

- 每个节点都是行动，不是心理变化。
- 选择之后有后果。
- 代价逐步升级。

### 6. 场景拆解

| 场次 | 地点 | 时间 | 场景目标 | 阻碍 | 结果 | 预计时长 | 可视化重点 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

通过标准：

- 每场戏有清楚的叙事或情绪功能；冲突场景可用目标、阻碍和结果，文艺、观察、治愈或氛围场景可用等待、发现、关系距离、时间流逝、表演累积或余味推进。
- 场景不能只负责无目的交代信息。
- 每场戏都能拆成镜头或视觉资产。

### 7. 场景写作

写作红线：

- 不写“他意识到”“她心里觉得”等心理描写。
- 不用台词解释主题。
- 不写摄影机拍不到的内容。
- 不写括号里的表演暗示。
- 不用煽情独白替代动作。

写作要求：

- 动作即潜台词。
- 台词口语化。
- 场景有声音、停顿、空间关系。
- 关键情绪落到表情、手部动作、视线、呼吸、距离变化。
- 文戏关键台词先写关系目的和可读后果；潜台词、表情、停顿、关系距离和反应镜头按本场主情绪选择。
- 武戏 / 动作先写清故事任务、主情绪、力量来源、运动路径、接触点和动作结果；起势、发力、受力、反应、爆点和停帧按段落职责选择，不要求每镜齐全。
- 剧本只写可见 / 可听的事件、动作、关系变化和结果，不为每场戏提前填焦段、机位和构图；重要节拍必须具体到能继续产生多个可拍瞬间，不能只写 `人物御敌 / 争吵 / 伤心 / 很紧张`。
- 剧本交接到分镜时，对尚未选择具体观看方案的段落标记 `待导演构思`。分镜先内部生成 3-5 个决定性瞬间、动作调度和摄影机关系不同的候选，再选定执行方案；改变剧情事实的候选回到剧本确认。

### 8. 剧本医生

```text
故事核心是否清楚：
主角目标是否明确：
阻力是否足够：
人物弧光是否能被看见：
节奏密度是否匹配体量：
文戏关键台词是否有关系目的和可读后果；潜台词 / 反应镜头是否承重：
武戏 / 动作是否有可读的力量来源、路径、接触和结果；需要视觉记忆或接剪时是否有爆点停帧：
场景是否都有功能：
台词是否过度解释：
视听表达是否足够：
是否能继续拆成图片和视频提示词：
最大风险：
修改优先级：
```

## 三、输出纪律

- 每次只推进一个阶段。
- 阶段完成后可以进入下一阶段，也可以先做自检。
- 如果是老胡直接要求“一次性出完整项目草案”，也要按阶段标题输出，不混成一段。
- 剧本完成后必须进入 `02_共享资产库/05_工具流程/剧本到AI视觉资产转换规则.md` 的四张表。
