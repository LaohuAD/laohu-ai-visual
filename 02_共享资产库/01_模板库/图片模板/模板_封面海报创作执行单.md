# 封面海报创作执行单

> 本模板用于自媒体视频封面、电影感带字封面、主题海报、系列封面和多平台发布主图。默认只交付文本提示词；图片由老胡自行生成，封面文字默认随图片一次生成。日常调用只交付下面的一条封面生图提示词，后续字段是内部工作区或老胡明确要求解释、A/B、系列体系、平台专版和复盘时才展示的扩展执行单。

## 无字主视觉底图备用提示词（仅在实测失败时）

只有直接带字结果出现无法修正的错字、漏字、乱序、残缺字形或排版失控时才填写；默认删除本节。


## 3:4 / 4:3 / 16:9 比例自适应

本执行单默认只写一条针对当次内容设计的比例自适应提示词。生成时在图片模型中选择 `3:4`、`4:3` 或 `16:9`，让模型按当前画幅自动优化人物占比、标题位置、换行、留白和装饰关系。

```text
跨比例必须保留：人物身份、主标题原文、主标题层级、综合色、标题附近的局部强调、人物引导标题的关系。
允许模型自动变化：人物位于画面哪一侧、标题具体方位、标题换行、留白方向、手势角度、局部装饰位置。
相对约束：标题处于最清楚的可读区域；人物与标题互不遮挡；人物视线和手势自然引导标题；四周保留发布安全边距；构图按当前画幅自动平衡。
```

除非老胡明确要求平台专版，不填写像素坐标、固定左上 / 右上位置，也不分别输出三条提示词。

## 系列封面 / 完整视觉体系（仅在明确需要时）

单次封面默认删除本节。系列、栏目、课程、连续短剧或整套宣传主视觉需要填写：

```text
稳定识别核：Logo 调用 / 标题层级 / 字体气质范围 / 色彩行为 / 主符号语法 / 对齐与边距逻辑 / 期数职责 / 缩略图识别特征
内容变化槽：每期标题 / 主体 / 当期冲突 / 强调色来源 / 期数 / 模型名 / 局部材质
母版提示词位置：
示例续作提示词位置：
最长标题压力测试：
多人或多产品压力测试：
极简空镜或单物压力测试：
3:4 / 4:3 / 16:9 压力测试：
```

稳定识别核写关系，不默认写死具体坐标和暖杏综合色；变化槽必须允许每期画面根据内容重新获得冲突与第一落点。

## 发布前质量门

- [ ] 1 秒内能读出主体与唯一承诺。
- [ ] 缩到 10%-15% 后主轮廓和标题仍可读。
- [ ] 灰度 / 剪影状态下层级仍成立。
- [ ] 标题与画面互补，没有重复陈述。
- [ ] 标题、表情、道具和结果由正片真实内容支撑。
- [ ] 只有一个主符号和主要构图决定。
- [ ] 人物处在事件中，摄影机位置可信。
- [ ] 颜色、光线和光学特征有画内来源。
- [ ] 没有拼贴剧照、大脸发光字或泛电影滤镜替代创意。
- [ ] 文字不遮挡脸、眼睛、手、产品结构和冲突证据。
- [ ] 所有必须出现的文字都在提示词中用中文双引号逐项锁定。
- [ ] 实际文字与双引号原文逐字一致，标点、大小写、顺序和断行正确，字形完整。
- [ ] 同一条提示词能适配 `3:4 / 4:3 / 16:9`，没有把主体和标题写死在固定方位。
- [ ] 标题状态已经确认；锁定标题未被擅改，需要生成时已经完成候选竞争和真人口语审稿。
- [ ] 若为系列视觉体系，稳定识别核与内容变化槽已经分开，并通过最长标题、复杂主体、极简主体和三种默认比例压力测试。
- [ ] 固定 `laohu` Logo 没有被重绘或改造。
- [ ] 不近似复刻第三方片名、版式、姿态、IP 或商业视觉系统。
