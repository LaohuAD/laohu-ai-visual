# 模板_AI图片提示词_资产型通用结构

> 来源：由研究文档《优质 AI 视频稳定优秀的前提，是有一份稳定的 AI 图片输入》沉淀。  
> 用途：用于角色资产、三视图、道具、场景氛围、海报、摄影图、封面和 AI 视频参考图。

## 通用结构

使用本模板输出正式图片提示词时，解释信息和复制正文必须分开。用途、服务场次、必须锁定、允许变化、不能继承、是否可作为视频参考图、生成执行单和回传字段写在代码块外；真正要复制进图片模型的内容，统一放在 `可复制图片提示词：` 后面的 `text` 代码块里。代码块里只放模型投喂正文，必须先正向描述画面里要出现的主体、构图、材质、光影和风格；边界优先写成 `质量边界`，只描述抽象质量要求，例如画面干净、比例自然、身份清楚、材质真实、无文字水印。具体跑偏对象和混用风险写在代码块外。

凡是需要老胡手动上传、替换、绑定、参考或调用的外部内容，都必须用中文全角中括号 `【】` 显性标注。稳定资产写 `【@资产名】`，人物形象写 `【形象参考@A1 角色人物设计资产】`，人物音色写 `【音色参考@V1 角色音频参考】`，临时参考图写 `【参考图1：用途】`、`【参考图2：用途】`。不要裸写 `参考图 1`、`参考图片 2`、`见上图`、`使用图片一`。如果人物资产同时用肖像图和服装图，代码块内推荐写成：`【参考图1：人物肖像】用于固定脸、年龄感、体态和真实自然感；【参考图2：服装穿搭】用于固定服装版型、层次、颜色、材质和配饰方向。`

图片模型代码块里的引号只能用于画面中真实要出现的文字，不用于强调、解释、概念命名或歧义消除。模型会把引号里的内容当成画面文字候选。需要画面出现标签时，优先写 `标签文字为：左手、右手`；需要标题和正文时，写 `标题文字为：音色说明。正文文字为：儿童清亮偏细，重庆口音，语速快，情绪外露`。不要写 `标注“人物自己的左手”`、`标题为“音色说明”`、`所谓“高级感”`。所有强调说明放在代码块外。

```text
主体内容：
画面主体是【人物 / 道具 / 场景 / 海报主视觉】。【主体外貌、状态、动作、材质、故事关系】。

景别：
使用【远景 / 全景 / 中景 / 近景 / 特写】，需要看清【具体信息】。

构图：
主体位于【画面位置】，背景包含【必要元素】，保留【留白 / 动作空间 / 标题空间】。
如需神秘感或高级人物氛围，可使用信息留白：半张侧脸、发丝遮眼、门框 / 窗帘 / 树影前景遮挡、只露嘴唇下颌、手部和首饰、背影回头一点点。必须写清遮住哪里、露出哪里、观众靠哪个局部识别人物；不能遮到主体身份不清。

光影氛围：
光源来自【方向和类型】，整体色调为【冷 / 暖 / 低饱和 / 高对比】，氛围是【具体情绪】。

画质与材质：
画面需要【真实摄影 / 电影剧照 / 海报 / 设定图】质感，重点表现【皮肤、布料、金属、木头、雨水、灰尘等】。

画面风格：
整体风格是【具体风格】，画面目标服务【用途】，主体识别清楚，风格稳定。

画面文字：
如需文字，写清标题文字为：【标题】，位置在【位置】，字体气质为【粗黑体 / 简洁 / 电影片名感】，画面文字保持唯一、清晰、可读。不要用引号做强调。

质量边界：
只写抽象质量要求，例如画面干净、比例自然、身份清楚、材质真实、无文字水印；具体跑偏对象和混用风险写在代码块外。
```

## 使用原则

- 先写用途，再写画面。
- 如果用于 AI 视频，必须考虑角色稳定、光影延续、运动空间和后期拼接。
- 如果用于封面，必须考虑手机端缩略图可读性和标题留白。
- 如果用于角色资产，优先稳定，禁止追求戏剧化。
- 如果用于海报，优先表达冲突，禁止只堆氛围。

## 图片资产子类型

### 资产唯一性原则

一个图片资产只能固定一个确定对象：一个人物、一件道具、一个固定场景或一套服装 / 妆造。资产不是把一个镜头里会出现的所有东西提前画在一起。比如“灶房 + 桌子 + 汤圆 + 硬币 + 奶奶手 + 小孩手”不是资产，而是分镜图、首帧图或视频参考图。

如果一个画面里有多个元素需要稳定，正确做法是拆成多个资产：

```text
S1 灶房局部空间：只固定门窗、墙面、灶台、光源、动线。
P1 旧木案桌：只固定桌子本体和多角度。
P2 完整白汤圆：只固定包好后的连续白糯米皮外观。
P3 小面值硬币：只固定单枚硬币本体。
A1 奶奶：只固定奶奶人物。
```

后续在分镜、视频提示词或第一帧参考图里把这些资产组合起来，写谁站在哪里、谁的手从哪里伸入、道具如何摆放和动作如何发生。

互斥可见状态必须拆资产。凡是一个物件存在“包入前可见 / 包入后不可见”“完整外观 / 剖开内部”“未损坏 / 损坏”“未点燃 / 已燃烧”等状态，不能把两个状态写进同一张资产图。否则模型会把互斥信息融合成错误外观。错误写法：`硬币汤圆资产` 同时写完整白汤圆、黑芝麻馅和硬币贴近汤圆皮。正确写法：完整白汤圆资产只固定连续白糯米皮和水光；小面值硬币资产单独固定硬币，只在包入前、吃出后或递出时和汤圆场景组合调用。

所有图片提示词的可复制正文都遵守“出现什么描述什么”。代码块里不要用排除句去排除另一个资产，因为模型可能先注意到那个无关对象。代码块外可以写 `不能继承` 和验收风险，提醒制作时不能和哪些资产混用；代码块内只写当前目标画面的主体、形状、材质、比例、纹理、光线、背景和清晰度。错误写法：在小硬币资产正文里反复写“汤圆”。正确写法：只写一枚洗净小面值硬币、旧金属磨损、边缘、数字纹理、克制反光、旧瓷小碗边缘或木桌小范围表面。

资产类型按失真来源判断：年代环境、店铺类型、陈列方式、货架 / 柜台 / 桌椅 / 灶台 / 教室 / 小卖部 / 商场的空间语法、灯光和地面墙面跑偏时，做场景资产；物品本体的轮廓、材质、尺寸、结构、磨损、开启方式或特写细节跑偏时，做物品资产。比如“商场拒买玩具”如果要固定的是普通商场玩具货架区的年代感和陈列环境，就做 `商场玩具货架区` 场景资产，而不是把镜头里出现的玩具误做成道具资产。

### 色彩风格资产 / 色卡资产

用于固定全片或某个情绪阶段的色彩系统。它不是人物设计资产里的小配色板；人物小配色板只校对角色服装、肤色和首饰，色彩风格资产负责跨分镜剪辑统一和情绪推进。

```text
用途：
生成色彩风格资产【C1 色卡名】，用于固定【作品名 / 场景段落 / 情绪阶段】的整体色彩与影调，后续视频提示词用【@C1 色卡名】作为色彩参考，并在色彩与影调里展开文字规则。

画面主体：
横向 16:9 色卡设计图，包含主色、辅助色、点缀色、肤色倾向、光源色、暗部倾向、环境反光和胶片 / LUT 分级示意。每个色块旁边标注十六进制 RGB 色值，例如 #DDEAF0，并用简短中文标明用途：主色、辅助色、点缀色、肤色、光源色、暗部、环境反光。

结构：
上方是全片母色卡，按使用比例排列：主色最大，辅助色次之，点缀色最小；下方是阶段变体小色条，例如心动期、热恋期、冷淡期、分手期，每个变体只在母色卡基础上调整明度、暗部冷暖、点缀色面积、肤色气色和阴影重量。

说明文字：
画面内可以出现简短中文标签和十六进制色值；不要写长段解释。长段使用说明放在代码块外。

质量边界：
色块干净，色值清晰，主次比例明确，阶段变体与母色卡保持同源，不做高饱和杂乱撞色，无多余装饰和水印。
```

代码块外必须补 `文字规则`：主色落在哪里，辅助色落在哪里，点缀色只能出现在哪些小面积位置，肤色如何保持，光源色和暗部倾向如何变化，哪些情绪阶段继承母色卡，哪些阶段使用变体。正式视频提示词不能只写“调用色卡”，必须把这段文字规则展开进 `【氛围与画质】` 的 `色彩与影调`。

### 人物形象资产

用于先确定角色第一眼气质、画面风格、环境氛围和光影感觉。它不是三视图，而是一张正面 / 半正面的电影级艺术照。

```text
用途：
生成人物形象资产，用于固定【角色名】的第一眼气质、画面风格、光影氛围和主视觉感觉，后续作为角色主视觉、封面候选和设计资产的气质参考。

主体内容：
画面中央是【角色名】，【年龄感、脸部气质、发型、姿态、眼神、当前服装】。人物处在【具体环境】中，环境必须服务角色气质，而不是抢走主体。

光影氛围：
光源来自【方向】，形成【侧逆光 / 轮廓光 / 丁达尔效应 / 黄金时刻暖光 / 冷暖对比 / 明暗交错】。光线照在【脸、肩颈、服装材质、头发边缘或手部】上，形成明确的情绪和质感。

构图：
正面或半正面艺术照，人物是视觉中心，可使用三分法、低角度、留白、前景遮挡或环境线条引导视线。
如果人物第一眼需要神秘、清冷、危险、暧昧或不可接近感，可使用信息留白构图：只露半张侧脸、发丝遮住一只眼、前景树影或窗帘遮住局部脸、只强调嘴唇下颌线和耳坠、背影只回头一点点。必须保留清楚身份锚点，例如脸型轮廓、鼻梁、唇峰、耳坠、项链、手型、发型或服装材质；不要把脸遮到无法作为后续角色参考。

画质与材质：
真人写实风格，电影画质，影视级真实材质。重点表现皮肤、头发、服装面料、环境材质和空气感。

质量边界：
环境服务人物气质，脸部身份稳定，构图有电影感，画面干净真实，无文字水印。
```

### 群像人物资产

用于固定一类跑龙套人群的年龄层、服装年代、体态差异、站位密度、表情范围和群体气质。群像人物资产不是主角色资产，不锁具体单人脸，不给每个群众做三视图；它更像一张场景合照式参考图，帮助后续视频生成同一类人群。

```text
用途：
生成群像人物资产【群像名】，用于固定【服务场次】里一类跑龙套人群的年龄层、服装年代、站位密度和群体气质。这个资产不固定每个人的姓名和具体脸，只固定这群人整体像什么人。

主体内容：
画面中有【数量】个【年龄层 / 身份】，【男女性别比例、身高错落、体态差异】。他们穿【时代 / 地域 / 生活条件】对应的服装，发型自然，表情范围是【好奇 / 围观 / 起哄 / 惊讶 / 沉默 / 哭丧】。构图像场景合照式参考图，展示站位密度、服装年代、群体情绪和跑龙套气质。

场景：
背景可以是【相关场景】的简洁生活环境，背景只作为人群气质参照，不承担剧情动作。

质量边界：
群体像真实跑龙套人群，服装年代统一，单人脸存在感适中，站姿自然，剧情动作保持低强度，画面干净真实，无文字水印。
```

### 人物素体资产

用于固定人物长相、身材、发型、年龄感和基础体态。适合主角、长期复用角色、后续可能换装的人物。

```text
用途：
生成人物素体资产，用于固定【角色名】的长相、身材、发型、年龄感和基础体态，后续可与不同服装 / 妆造资产组合。

主体内容：
同一个人物，穿简洁白色 / 中性服装，不带强风格配饰。重点固定脸、五官、头发、身材比例、肩颈、体态和气质。

构图：
横屏 16:9 白底或简洁灰白背景。主视觉区包含正面、侧面、背面全身；补充信息区包含面部正立特写；必要时加入基础比例照。背景简洁，重点集中在人物身体比例、五官和基础体态。

质量边界：
同一人物身份稳定，服装简洁，脸和发型稳定，表情克制，比例自然，画面干净真实，无文字水印。
```

### 人物设计资产表情规则

主角色人物设计资产默认只使用中性常见表情。提示词应写清：正脸自然、脸部肌肉放松、嘴唇自然闭合或轻微放松、眼神正常，不做大笑、哭泣、惊讶、咬唇、崩溃等情绪表情。不要把心动、雀跃、怀疑、愤怒、落泪等情绪做成七宫格或九宫格放进人物设计资产，因为粗略表情词会让模型生成浮夸脸，反而破坏后续视频的一致性。情绪表演应在视频提示词里逐镜头写肌肉、眼神、呼吸和身体反应。只有老胡明确要求“表情测试图”时，才额外输出多表情参考图，并标注它不是主人物设计资产。

### 人物资产双提示词规则

正式输出人物图片资产时，默认给两套可复制提示词：

- 人物形象资产：环境内电影级正面 / 半正面艺术照，负责气质、光影、姿态、叙事瞬间和第一眼感觉。
- 人物设计资产：白底 / 简洁背景扩展分区制作参考图，负责正侧背面、面部正立特写、左手特写、右手特写、配色板、局部细节、比例照和音色文字说明区。

两套提示词属于同一个人物资产编号，不拆成两个资产编号。写法应是 `A1 【角色名】人物形象资产提示词` 和 `A1 【角色名】人物设计资产提示词`。后续生成候选图后，最终登记和视频提示词调用仍然只使用 `A1`。禁止写成 `A1-1`、`A1-2`。

禁止用一张“左侧脸部近景 + 右侧三视图”的旧版混合图同时冒充形象资产和设计资产。它既没有形象资产的环境和情绪，也没有设计资产的完整四区拆解。

### 人物设计资产

用于把人物五官、身形比例、服装穿搭、配色和局部细节固定成制作参考图。它承接人物形象资产的气质，但画面目标是清楚、稳定、可复用。

```text
用途：
生成人物设计资产，用于固定【角色名】的五官、身形比例、服装穿搭、配色、左手特写、右手特写、局部细节、音色文字说明和可复用身份识别元素。

主体内容：
同一个人物，同一张脸，同一发型，同一年龄感和气质。服装为【指定服装】，材质、层次、版型、颜色和穿法清楚。

版式：
横屏 16:9 白底或简洁灰白背景，按信息优先级分配画幅。主视觉区为正面 + 侧面 + 背面三视图，身高和身体节点厘米测量线直接合并到三视图旁边，标注脚底、脚踝、膝盖、髋部、腰线、胸线、肩线、颈根、下巴和头顶，不再额外生成一个和三视图重复的全身比例图；脸部区为一张大尺寸纯头部 / 脸部正立特写，只展示头部、五官、发际线、妆容和耳侧小配饰，不做颈肩半身图；右侧或主辅助区为摄影棚真实人像状态区，胸部以上中近景，人物占区域高度约 70%，中性灰或极简灰背景，柔和主光、轻微侧逆轮廓光和明暗层次，用来展示真实摄影光影下的皮肤、妆容、表情、肩颈姿态、首饰受光和上半身服装状态；手部参考区分别展示左手特写和右手特写，但只作为小面积手模级辅助模块，能看清手指长度、指节、指甲、肤色、年龄感和袖口连接；色值卡为紧凑小色块条，只标注十六进制 RGB 色值；局部细节区展示配饰、纹样、袖口、鞋、身份识别元素；音色文字说明区清楚可读但不抢主视觉。

造型账本：
全图共用同一份服装、发饰、耳饰、项链、包、鞋履和腕部状态清单。三视图、手部特写、局部细节区、配色板和比例照必须互相一致。写清【发饰在哪里】、【手腕是否佩戴饰品】、【鞋履具体款式和气质】、【哪些配件只属于头发 / 颈部 / 耳侧 / 脚部 / 手部】。局部细节区每个小模块的标签必须和对应物件一一对齐，不额外发明新饰品，不把同一个配件复制到多个身体部位。

音色文字说明：
在画面中设置清晰中文文字模块，标题文字为：音色说明。正文文字写【音色、音线、年龄感、地域口音、语速、常态情绪】，例如正文文字为：儿童清亮偏细，重庆口音，语速快，情绪外露。文字清楚可读，作为设计资产的一部分。

比例：
人物比例和谐，头身比正确，上下身比例明确，身高和腿长按角色设定执行。比例信息合并在三视图里，不单独重复生成全身比例图。三视图旁优先使用厘米高度线，例如 0cm 脚底、8cm 脚踝、48cm 膝盖、82cm 髋部、105cm 腰线、125cm 胸线、142cm 肩线、148cm 颈根、158cm 下巴、168cm 头顶，具体数值按角色身高调整；不要使用 1、2、3、7.5 这类抽象刻度。

质量边界：
同一人物身份稳定，脸和发型稳定，版式信息优先级正确，三视图、大脸部特写和摄影棚真实人像状态区是主信息，比例厘米线已合并到三视图，手部、色值卡、局部细节和音色说明是辅助信息；摄影棚真实人像状态区必须能看清人物在真实光影下的皮肤、妆容、肩颈、首饰和上半身服装状态；左右手比例正确且手模级好看，服装一致，造型账本一致，局部细节标签和物件准确对应，姿势克制，比例自然，音色说明文字清晰可读，画面干净真实，无无关文字水印。
```

#### 参考图 + 服装图拆分写法

当人物资产需要同时参考“人物图”和“服装图”时，提示词必须明确拆分职责：

```text
人物参考图负责：脸、身形、年龄感、体态、气质、头身比。
服装参考图负责：校服 / 制服 / 日常服的版型、层次、颜色、穿法、身份识别元素。
```

推荐写法：

```text
【参考图1：人物肖像】用于固定人物比例和面部气质；【参考图2：服装穿搭】用于固定服装与层次关系。
服装按内 / 中 / 外 / 腰 / 下 / 足依次写清，或按上衣 / 外搭 / 裤装 / 鞋 / 配饰拆开写清。
```

服装参考图不能只被复制成“穿了什么”。主角和重要角色的定装提示词必须写清身体适配：肩线如何收住肩颈，胸前是否有自然省道 / 弧度 / 支撑，腰侧是否收束，腰带或系带是否压出高腰线，裙摆或裤型从哪里展开，面料贴合、垂坠、挺括或轻薄的位置分别是什么。质量边界要写明：修身但不紧绷，漂亮但不过度暴露，不做松垮无形、直筒麻袋、胸前塌陷、腰线消失、网红紧身性感和夸张丰胸。

服装参考图还要继承穿法逻辑、视觉重心和比例关系，不只是继承单品名称。腰间系带、披肩、外套绑腰、腰封、领巾、围巾、链条、裙摆开衩等细节，要写清它位于正中、偏侧、侧前方还是背后，是斜绕、平行、垂落、交叉还是贴合身体。鞋履要写清鞋头形状、闭口 / 露趾、浅口 / 深口、踝带、跟高、材质、颜色和气质，并说明它如何服务人物身份、腿部线条、场景和整体穿搭。当前案例：林栀 A1 的腰间浅灰条纹层是偏侧斜绕、扁平贴腰、布尾轻薄同侧垂落；鞋履固定为珍珠白冰银尖头浅口踝带低跟单鞋，不再使用露趾凉鞋。

人物设计资产三视图必须写高光体态：脊柱自然拉直，胸腔舒展，肩背打开，肩胛稳定，颈线拉长，下巴微收，腰背挺住，重心稳定，站姿自信；禁止含胸驼背、圆肩、缩脖、头颈前伸、塌腰和松散站姿。左右手特写必须按人物自身左右标注，标准手背参考为：手背朝镜头、指尖向下时，人物自己的左手拇指在画面右侧，人物自己的右手拇指在画面左侧；左右手同年龄、同肤色、同手部比例，但解剖方向相反，不能生成成同一只手。

如果人物设计资产会作为视频参考图、首帧参考或角色一致性参考，必须在资产提示词本体先锁住肤色妆效，不能只等视频提示词后补。美女角色、情绪人像、开场钩子角色和壁纸帧主角推荐写法：冷白偏中性的白皙肤色、白皙通透、肤色匀净、清透裸妆、轻薄服帖底妆、柔雾奶油肌、柔雾哑光带内透光肤感、低饱和裸杏腮红、低饱和玫瑰豆沙唇；真实人类皮肤明暗，细微毛孔，皮肤微纹理，自然漫反射，柔和次表面透光，高光过渡柔和，细腻 35mm 胶片颗粒。参考图如果偏黄、偏油或过曝，只继承脸型、五官、身份和服装结构，不继承偏黄光源、油亮肤感、大片高光、厚粉网红妆或塑料磨皮。

人物设计资产还必须做造型账本一致性检查。先列固定定装清单，再让三视图、手部特写、局部细节和比例照都从这份清单里取内容。发饰不能跑到手腕上，手部参考不能额外生成双腕饰，鞋履不能和整体服装气质断开，局部细节标签不能贴错物件。当前案例：林栀 A1 的深灰发圈只属于发间，左右手腕干净；鞋履固定为珍珠白冰银尖头浅口踝带低跟单鞋，用来完成清冷文艺海边气质。

人物设计资产版式还必须检查画幅占比。三视图、大尺寸纯头部脸部特写和摄影棚真实人像状态区应该占主要面积；左右手、色值卡、局部细节和音色说明只做辅助校对。脸部特写只展示头部和五官妆容，不要变成颈肩上半身特写；左右手保留但缩小为手模级参考，不能比脸部特写更抢眼；色卡只做紧凑色值条，优先写十六进制 RGB 色值；比例信息用厘米高度线并入三视图，不用无意义头身数字，不要让右侧再生成一个和三视图重复的全身比例图。摄影棚真实人像状态区要使用胸部以上中近景、中性灰背景、柔和主光、侧逆轮廓光和明暗层次，专门校准脸部皮肤、妆容、肩颈姿态、首饰受光和上半身服装。当前案例：林栀 A1 把两张面部 / 颈肩图合并为一张大尺寸纯头部特写，把过大的左右手和配色板缩成辅助模块，把厘米比例线并入左侧三视图，并把右侧重复比例图改成摄影棚真实人像状态区。

#### POV 主体人物资产

POV 主体仍然是人物资产，不是局部锚点。第一人称、背影、遮挡、只露手、只露袖口，是视频阶段的镜头策略；图片资产阶段必须先锁定完整身体来源。

适用场景：

- 第一人称主角。
- 儿童 POV、老人 POV、特殊身高 / 身体比例 POV。
- 跨镜头反复出现但正脸展示很少的人物。

提示词必须写清：

- 年龄、身高、头身比、上下身比例。
- 肩宽、左手大小、右手大小、脚步尺度、体态。
- 正面、侧面、背面关系。
- 服装、袖口、鞋、书包或随身物。
- 低视线 / 成人高度对比 / 门框桌椅等比例参考。
- 使用规则：后续视频少正脸，主要调用手部、袖口、肩背、低视线、反射或背影。

推荐写法：

```text
生成人物设计资产，用于固定【角色名】作为 POV 主体的完整身体来源。角色是【年龄】、身高约【身高】、头身比和上下身比例符合【儿童 / 成人 / 老人】真实比例，左手大小、右手大小、肩宽、鞋、书包、背影和侧面都要清楚。画面可以不做主角式正脸海报，但必须包含正面、侧面、背面全身、左手特写、右手特写、袖口 / 鞋 / 书包细节、比例照和音色文字说明区。后续视频主要用第一人称低视线、手部、袖口、背影、反射里的局部身份调用，并在基础设定中使用【形象参考@xx】【音色参考@xx】。
```

#### 人物资产分区版式

当人物资产需要更完整的制作参考时，优先使用四区结构：

```text
主视觉区（上方）：
以正面 + 侧面 + 背面三个核心视角为主体，直观呈现角色的整体身形、服饰搭配和标志性特征。

补充信息区（左侧）：
拆分出面部特写、配色板和音色文字说明区，补充主视角没覆盖的脸部正立、颈部垂直、下颌线水平、头顶到下巴在画面垂直中轴上的标准，以及毛发、服饰色值和基础音色说明。

左右手特写区：
分别生成左手特写和右手特写，小模块只使用标签文字：左手、右手，展示手背 / 手掌或至少一个清楚角度，能看清手指长度、指节、指甲、肤色、年龄感、手部肉感和袖口连接方式。

局部细节区（底部）：
用小模块单独展示关键部件的设计，例如配饰、点缀、关键身份识别元素，把主视角里的模糊细节拆分为精准参考。所有小模块必须来自同一份造型账本，标签和物件一一对应；鞋履模块只展示鞋履，发饰模块只展示发饰，手部模块只展示左手和右手，不能互相错标或新增未设定配件。

比例照（右侧）：
生成人物上半身或全身比例照，必要时使用比例参考物或身高对比。
```

适用场景：

- 校服、制服、固定服装层次需要严格确认的人物。
- 需要头身比正确、上下身比例和腿长感明确的人物。
- 需要配色板、脸部正立标准和局部身份识别点的人物。
- 会跨镜头复用、后续要做一致性网格图的人物。

提示词可额外说明：

- 人物比例和谐。
- 头身比正确。
- 上下身 4:6。
- 长腿。
- 真人写实风格。
- 电影画质。
- 影视级真实材质。
- 发型、服装层次和身份识别元素清楚。

但这些内容仍然服务“固定角色一致性”，不是时尚写真。

### 人物定装资产

人物定装资产不是单张旧版混合图。它指“同一个人物穿上某套服装 / 发饰 / 妆容后的资产状态”，正式交付时仍然拆成两条提示词：定装形象资产 + 定装设计资产。

```text
用途：
生成【角色名】穿【服装 / 妆造名】的人物形象资产，用环境、光影、服装材质、姿态和眼神固定第一眼气质。

主体内容：
同一个人物，同一张脸，同一身服装，同一发饰和妆容，处在【具体环境】中，做出【符合角色和剧情的动作 / 姿态】。

构图：
横屏 16:9 正面 / 半正面电影级艺术照。写清光源方向、照亮部位、阴影结果、服装材质、环境材质、色彩影调和叙事瞬间。
```

```text
用途：
生成【角色名】穿【服装 / 妆造名】的人物设计资产，用四区制作参考图固定下游生成所需细节。

主体内容：
同一个人物，同一张脸，同一身服装，同一发饰和妆容。服装层次、版型、材质、颜色和穿法清楚。

版式：
横屏 16:9 白底或简洁灰白背景。主视觉区为正面 + 侧面 + 背面三视图；补充信息区包含面部正立特写和配色板；局部细节区展示配饰、纹样、袖口、鞋、身份识别元素；右侧放上半身或全身比例照。
```

### 服装 / 妆造资产

用于单独固定服装、发饰、妆容、配饰或盔甲。

```text
用途：
生成服装 / 妆造资产【资产名】，用于后续叠加到人物素体资产上。

主体内容：
只突出服装轮廓、材质、颜色、纹样、配饰、发饰和妆容规则。可以使用无脸模特、平铺展示或多角度服装展示。

简单背景，多角度展示正面、侧面、背面和关键细节。

质量边界：
服装是画面主体，背景简洁，人物脸部信息弱化，服装颜色和材质清晰稳定。
```

### 场景图片资产

用于固定一个会多次进入或多角度拍摄的空间。

```text
用途：
生成固定场景资产【场景名】，用于锁定空间结构、入口、主视角、侧视角、反向视角、光源方向和可运动路径。

主体内容：
同一个场景，不同角度。必须保持建筑结构、入口位置、主光方向、关键道具和空间比例一致。

构图：
三宫格 / 四宫格多角度：主入口、主视角、侧视角、反向视角 / 关键局部。

质量边界：
每格保持同一个场景，光源方向稳定，空间结构互相对应，尺度关系清楚。
```

#### 场景四视图设定图

当一个场景需要多次进入、正反打、左右侧视角、人物走位或结尾拉高镜头时，优先使用四视图设定图。它的目的不是生成四张同风格场景图，而是把同一个空间的布局固定住。

```text
用途：
【参考图1：场景参考】图片，生成固定场景资产【场景名】的四视图设定图，用于锁定同一场景布局、入口 / 窗户 / 墙角 / 家具 / 道具的位置关系、光源方向和人物可运动路径。

主体内容：
同一个场景，同一套空间结构。四个视角必须保持场景布局一致，物体空间逻辑正确，固定结构在不同视角中位置互相对应。场景资产只锁空间、入口、门窗、墙面、固定灶台、固定光源、地面、墙角和可运动路径；可移动道具、人物手部和具体动作另做资产或写入分镜。

构图：
横屏 16:9 四宫格四视图设定图。
格 1 正面视角：定义场景主入口、主构图、主要物件和空间纵深。
格 2 左侧视角：以正面视角向左转动 90 度，展示左侧墙面、左侧物件、侧向动线。
格 3 右侧视角：以正面视角向右转动 90 度，展示右侧墙面、右侧物件、侧向动线。
格 4 正面反打图：从正面视角对面看回去，展示反向空间、入口回看、人物站位和运动路径。

空间一致性：
所有视角必须保持同一场景布局一致，视角逻辑正确，四个视角关系紧密，物体空间逻辑正确，四视图固定结构对应位置互相关联。入口、窗户、固定灶台、墙角、柴火堆、灯位等空间结构位置稳定。场景主体集中在空间结构、固定光源、入口、墙面、地面和可运动路径。

四视图空间原则：
四格必须是同一个位置从不同方位看过来的图。先定义格 1 正面视角，再让格 2、格 3、格 4 围绕格 1 的空间关系旋转或反打，固定结构在四格里能互相对上位置。

局部操作空间拆分：
当核心动作发生在桌面、案板、灶台边、祭祀桌、手工台等局部空间，且后续需要 POV、正反打、手部操作或人物围桌互动时，先拆资产。空间本身做局部场景资产；桌子 / 案板 / 碗 / 汤圆 / 硬币等可移动物做物品资产；人物手部、站位、动作和摆放关系写入分镜、视频提示词或第一帧参考图。场景资产只固定空间，组合关系交给分镜和视频提示词。

质量边界：
四格保持同一空间，固定结构位置一致，左右视角和反打视角关系正确，光源方向稳定，空间尺度真实。
```

### 物品图片资产

用于固定同一件关键道具或物品。

```text
用途：
生成物品资产【物品名】，用于固定同一件物品的轮廓、比例、材质、纹理和特写细节。

主体内容：
同一件物品，多角度展示正面、侧面、背面、顶部和关键细节。

构图：
简单背景，物品占画面主体，光线均匀，材质清楚。

质量边界：
同一物品身份稳定，比例一致，材质清晰，背景简洁，画面干净真实，无文字水印。
```

## 组合资产记录

```text
A1：人物素体资产，固定【角色名】长相和体态。
A2：服装 / 妆造资产，固定【服装 / 妆造名】。
A3：组合形象资产，表示 A1 穿着 A2 后形成的定装形象。
```

正式图片提示词可以写 A3 的具体外观；资产表必须记录 A3 = A1 + A2，方便后续直接调用。
