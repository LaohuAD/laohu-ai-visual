# 模板_AI图片提示词_资产型通用结构

> 来源：由研究文档《优质 AI 视频稳定优秀的前提，是有一份稳定的 AI 图片输入》沉淀。  
> 用途：用于角色资产、三视图、道具、场景氛围、海报、摄影图、封面和 AI 视频参考图。

## 先判断请求类型

本模板同时承载“可复用资产”和“单张图片”，但两者不是同一个交付物。使用模板前先按用户的动词、后续用途和复用范围判断：

```text
生成资产 / 创建资产 / 做人物、场景、道具、服装或风格资产
→ 输出资产包，并在其中包含一张或多张图片提示词。

生成一张图片 / 海报 / 封面 / 氛围图 / 首帧 / 故事板 / 临时参考图
→ 输出单张图片提示词，并明确标注它不是稳定资产，除非用户另有要求。
```

“生成资产”不等于“生成一张好看的图片”。资产图片只是资产的可视化执行载体；资产本身还必须有编号、类型、用途、上游依赖、生成顺序、固定项、允许变化项、引用职责、验收标准和下游调用句。没有这些信息的漂亮人物图、空镜、产品图或海报，只能登记为单张图片或临时参考图，不能进入正式资产表。

## 资产包输出合同

当请求被判定为资产时，正式文件至少保留以下字段；同一资产需要形象图和设计板时使用同一个编号承载，不拆成多个伪资产编号：

```text
资产编号 / 名称：
资产类型：人物素体形象 / 人物服装 / 人物妆造设计 / 群像人物 / 场景 / 道具 / 风格 / 关系组合 / 其他
用途与服务范围：
上游依赖与生成顺序：
必须固定：
允许变化：
禁止继承：
引用职责：
可复制图片提示词：
验收标准：
登记条件：已生成并人工确认后，才登记为可调用图片资产
下游调用句：
```

同一资产的补充视图可以放在同一编号下，但不能把不同职责合并成一张“什么都有、什么都不清楚”的混合图。人物三资产尤其不得共用一个模糊编号。若用户明确只要一张艺术照、人物成品图、海报或首帧，输出单张提示词并标明“非稳定人物资产”。

## 重要人物三资产链

任何需要跨镜头保持一致的重要人物、动物、卡通角色、拟人主体或其他主角级主体，都按以下职责分开；新增第二套造型时复用同一素体，只新增对应服装与妆造设计资产：

- `人物素体形象资产`：摄影棚中性灰背景、均匀校准光、纯白简单衣裤；左侧头部正面特写，右侧依次为人物自己的左45度、正面、背面三张全身图，并附身体属性说明。只锁角色本体，不锁戏服、发型、浓妆和场景。
- `人物服装资产`：服装脱离具体人物脸展示，按头部穿戴、上半身、下半身、足部四区拆解版型、层次、材质、纹样、颜色、接缝、扣合、穿戴顺序、活动余量和局部细节；发型与脸妆不进入此资产。
- `人物妆造设计资产`：同时引用已确认素体与服装，把服装穿回同一角色，再加入发型、妆容、伤妆、临时纹身或身体彩绘；左侧头部正面特写，右侧依次为左45度、正面、背面三张全身图，确认最终上身结果。

参考人物图必须显性写明只继承哪些内容。人物参考图默认只锁脸与身份，不能顺带继承原图的现代发型、服装、妆容、姿势、背景和光线；这些内容只有被明确列为资产职责时才可继承。

## 通用结构

使用本模板输出正式图片提示词时，解释信息和复制正文必须分开。用途、服务场次、必须锁定、允许变化、不能继承、是否可作为视频参考图、生成执行单和回传字段写在代码块外；真正要复制进图片模型的内容，统一放在 `可复制图片提示词：` 后面的 `text` 代码块里。代码块里只放模型投喂正文，必须先正向描述画面里要出现的主体、构图、材质、光影和风格；边界优先写成 `质量边界`，只描述抽象质量要求，例如画面干净、比例自然、身份清楚、材质真实、无文字水印。具体跑偏对象和混用风险写在代码块外。

画幅参数和构图正文必须分离。内部默认按 `16:9` 进行空间预算，实际输出比例由生成平台设置；可复制代码块只写主体位置、相对占比、留白、裁切安全和各分区职责，不写比例数字、横屏、竖屏、横版或竖版。用户指定其他比例时，重新设计画面关系后再写构图结果，不能只换数字。只有用户明确要求正文携带比例或平台没有独立比例设置时例外。

凡是需要老胡手动上传、替换、绑定、参考或调用的外部内容，都必须用中文全角中括号 `【】` 显性标注。稳定资产写 `【@资产名】`，人物分别写 `【素体参考@B01 人物素体形象资产】`、`【服装参考@W01 人物服装资产】`、`【妆造参考@M01 人物妆造设计资产】`，人物音色写 `【音色参考@V1 角色音频参考】`，临时参考图写 `【参考图1：用途】`、`【参考图2：用途】`。不要裸写 `参考图 1`、`参考图片 2`、`见上图`、`使用图片一`。如果人物资产同时用人物图和服装图，代码块内显性写明两者分别负责什么。

图片模型代码块里的引号只能用于画面中真实要出现的文字，不用于强调、解释、概念命名或歧义消除。模型会把引号里的内容当成画面文字候选。需要画面出现标签时，优先写 `标签文字为：左手、右手`；需要标题和正文时，写 `标题文字为：音色说明。正文文字为：儿童清亮偏细，重庆口音，语速快，情绪外露`。不要写 `标注“人物自己的左手”`、`标题为“音色说明”`、`所谓“高级感”`。所有强调说明放在代码块外。

模板中的字段是推理检查点，不是要求最终提示词像登记表。先用 `主体锚点、场景锚点、时间锚点、风格锚点` 建立因果，再把摄影、构图、光影、色彩和材质写成一段自然、可见、可生成的画面。括号里的例子都是开放启发，不是封闭选项；遇到用户未列出的题材、介质、光源、空间或细节，继续按当前画面作用推导。

写正式提示词前，内部先完成 `资产审美定位卡`：`作品类型与媒介 → 目标受众与观看情境 → 资产职责 → 第一眼感受 / 欲望 → 形状、比例、CMF、选角 / 妆造或空间语法 → 视觉记忆点 → 类型俗套否决 → 下游继承`。这张卡用于做决定，不要求逐项复制进最终提示词。没有参考图时内部竞争 3-5 个原创方向；有参考图时先拆硬锚点、开放项和禁止继承项。中性背景、正交视角和均匀光只负责展示，不允许把资产本体设计成没有类型、受众和记忆点的普通平均值。

当人物、道具、场景和风格存在佩戴、持有、摆放、容纳、同框或统一色彩关系时，先建立无环 `资产依赖图`，再写提示词。默认顺序为 `全局风格 / Logo → 独立人物身份、物品结构、空置基础场景 → 人物定装、穿戴状态、已布置场景 → 故事板 / 首尾帧 / 关键帧`。视觉资产总表不是分类目录，资产总览、可复制提示词正文和生成执行单必须按依赖图的拓扑顺序一致排列，使用户可以从上到下逐项生成；任何下游提示词都不能出现在它引用的上游提示词之前。每个下游资产都要在代码块第一句显性写明 `【参考@上游资产】负责锁什么`，并在代码块外列出禁止继承。只有已经生成并验收的图片可以作为硬参考；上游未确认时，下游不能实际执行。

参考职责不能互相吞并：人物身份参考只锁脸、体型、年龄与基础体态；物品参考只锁外形、结构、比例、材质、Logo、文字与穿戴 / 接触方式；场景参考只锁空间、固定构件、光源、动线与尺度；风格参考只锁色彩关系、材质语法与成像基底。若人物与物品、人物与场景彼此需要，先分别固定独立锚点，再建立组合资产或镜头状态，禁止循环硬引用。

引用检查覆盖整张画面，不只覆盖第一主体。凡提示词可能让第二个可识别人物、重复道具、固定文字、Logo、倒影、屏幕图像或固定陈设进入画面，已有确认图片时必须显式引用并保持文字一致；没有图片时必须从同一规范词账本逐项复现身份、服装、颜色、材质、数量、左右、位置和状态；不需要的对象才通过单人构图、空场、画外方向和留白使其不进入可见画面。不得只写人物关系称呼，让模型自由设计配偶、同事或对手的脸和衣服。

多人关系图在各人物独立确认后另建组合资产。组合提示词必须同时引用全部人物身份、固定定装、所属道具、共同场景和风格，并锁定屏幕侧、站坐高差、距离、视线、接触边界和共同受光。单人形象资产可以带一个承担关系证据的次要人物，但有资产就引用、无资产就完整复现规范描述，并降低其画面权重；若不准备描述完整，就让对方完全画外，不能以未定义衣角、手、倒影或模糊身体偷偷进入画面。

```text
用途：
这张图用于【人物素体形象资产 / 人物服装资产 / 人物妆造设计资产 / 场景资产 / 道具资产 / 封面 / 首帧 / 视频参考 / 其他实际用途】，优先解决【身份一致 / 最终上身一致 / 空间锁定 / 动作衔接 / 发布传播 / 其他任务】。

主体锚点：
第一视觉主体是【人物 / 生物 / 物品 / 建筑 / 自然空间 / 关系接触点 / 其他主体】。写清决定其身份和画面任务的外貌、结构、比例、状态、动作、材质、表情、气质或故事痕迹；主体通过【面积 / 亮度 / 清晰度 / 色彩 / 位置 / 反差 / 视线】成为第一落点。

场景锚点：
主体处在【具体地点与空间状态】。写清空间年代与用途、前景入口、中景主体、远景信息、建筑 / 自然结构、天气、关键陈列、可行动路径、引导线、反射面、留白和主体与环境的接触点。场景里的每个重要元素都要说明它如何托住主体，而不是只罗列背景名词。

时间锚点：
画面发生在【年代 / 朝代 / 年份】的【季节 / 气候阶段】【一天中的时刻 / 事件时间】。由这个时间推导太阳高度或环境光基线、自然光方向、色温、阴影长度与软硬、空气湿度 / 雾尘 / 能见度、天空与地表状态；室内灯、烛火、炉火、霓虹、车灯、屏幕等实际光源另写来源和作用。

风格锚点：
以【真人摄影 / 电影剧照 / 纪录摄影 / 二维或三维动画 / 绘画 / 定格 / 其他表现介质】为主，采用【类型语言】与【情绪氛围】，结合【参考作品 / 艺术运动 / 摄影传统】的【构图、色彩、光影、空间、动作气质、材质或成像特征】。参考名只作为风格母体，不替代可见特征。

主情绪命题：
主体正面对【具体处境、关系压力或事件】，以【明确态度】回应；观众第一下感到【唯一主情绪】。由【眼神 / 表情 / 呼吸 / 手势 / 身体重心 / 距离 / 动作 / 景别 / 光影 / 色彩 / 天气 / 物件关系】承担主要证据。辅助余味为【第二眼才出现的复杂感受】，通过降低面积、亮度、饱和度、清晰度或动作强度退到次级；冲突情绪信号【列出需要删除、改写或降权的内容】不与主情绪争抢。

演员临场感：
仅在叙事性人物画面启用。先写【已经进入画面的具体事件压力】，再写人物【眼睑 / 瞳孔 / 呼吸 / 下颌 / 肩线 / 手指 / 重心 / 肌肉张力】中真正可见的生理反应；人物随后选择【靠近 / 退让 / 隐瞒 / 保护 / 反击 / 忍住 / 无视 / 其他符合角色的行动】，并由【对手距离 / 道具受力 / 衣料 / 尘雨 / 影子 / 旁人 / 空间变化】反馈这一选择。静止要写成面对压力后的主动不动。景别必须让承重证据达到观众可读尺寸：微表情承重时靠近，处境与空间承重时拉开，两者都承重时让人物近景与前景压力或环境反馈同框。

摄影与景别：
画面实际裁切到【身体 / 物体的具体边界】，主体约占画面【比例】；摄影机位于【高度、方向、距离】，以【平视 / 俯视 / 仰视 / 侧面 / 越肩 / 背面等具体角度】观看。使用【焦段或透视倾向】，焦点落在【眼睛 / 汗珠 / 手部 / 刀刃 / 材质纹理 / 其他关键细节】，景深和虚化程度服务【需要看清的信息与空间关系】。

构图：
主体位于【画面位置和重心】，由【道路 / 栏杆 / 门框 / 光束 / 视线 / 动作线 / 其他结构】把视线引向【焦点】；前景【遮挡或入口】、中景【主体任务】、远景【空间与情绪信息】形成层次，保留【留白 / 动作空间 / 标题空间】，边角干净。
如需神秘感或高级人物氛围，可使用信息留白：半张侧脸、发丝遮眼、门框 / 窗帘 / 树影前景遮挡、只露嘴唇下颌、手部和首饰、背影回头一点点。必须写清遮住哪里、露出哪里、观众靠哪个局部识别人物；不能遮到主体身份不清。

光影与色彩：
在时间和天气给出的环境光基线上，【主光源】从【方向】以【柔光 / 硬光 / 漫射 / 聚光 / 其他光质】照到【主体具体部位】，形成【亮面、半暗面、轮廓、投影和材质反射】；【辅光 / 反光 / 轮廓光】来自【真实来源】。画面以【主色】为主，【辅助色】承接空间，【点缀色】只落在【小面积位置】，肤色、高光、暗部和环境反光保持同一影调逻辑。

画质与材质：
采用【相机 / 胶片 / 数字电影 / 绘画 / 动画 / 其他成像介质】的画质倾向。重点表现【具体对象】的【颜色 + 材质 + 纹理 + 状态 + 反光 + 湿度 / 磨损 / 瑕疵 + 边缘细节】，清晰度集中在视觉主体，辅助元素服从主次。

情绪可见结果：
画面最终让观众感到【具体情绪】，由【表情肌肉、眼神、呼吸、手势、身体重心、空间距离、天气、颜色、物件关系】共同证明。情绪词只作总结，可见证据必须先成立。

画面文字：
如需文字，写清标题文字为：【标题】，位置在【位置】，字体气质为【粗黑体 / 简洁 / 电影片名感】，画面文字保持唯一、清晰、可读。不要用引号做强调。

质量边界：
只写抽象质量要求，例如画面干净、比例自然、身份清楚、材质真实、无文字水印；具体跑偏对象和混用风险写在代码块外。
```

## 使用原则

- 先写用途，再写画面。
- 先查资产依赖，再写引用。凡当前画面调用上游资产，提示词第一句写清参考对象、职责和不继承项；不得只堆多个 `@` 而不说明每张图控制什么。
- 再查全画面闭合。主角以外的每个可识别对象都必须有来源；同一服装、颜色、材质、左右方向和状态从唯一规范词账本复现，不能让次要人物或背景道具自由漂移。
- 四锚点先定因果：主体明确、场景承托、时间定光、风格定情绪；摄影和光影从四锚点向下推导。
- 先定主情绪命题，再写审美元素；一张图允许复杂余味，但第一情绪只能有一个。视觉焦点和情绪重心必须同时明确，冲突情绪信号要删除、改写或降权。
- 叙事性人物图不能用气质词和漂亮姿势冒充表演；用事件压力、生理反应、行为选择与对手 / 环境反馈建立演员临场感。时尚展示、定装宣传和中性人物资产不强造剧情压力。
- 景别由情绪证据的尺寸和关系范围决定，不按题材套固定中景或特写。观众读不清承重微表情时靠近，读不清临敌、包围或关系距离时拉开或加入前景反馈。
- 专业字段不是必填表：只保留能够增强主情绪的构图、光影、时间、姿态、场景、色彩、焦段和材质；无关字段省略，削弱或转移情绪的字段改写或删除。
- 抽象词必须具象化：景别写裁切边界和焦点落点，构图写主体位置和视线关系，光影写来源与受光结果，情绪写表情、姿态和环境证据。
- 用户输入不完整时做美术指导级自动补全，内部比较 3-5 个在受众承诺、轮廓比例、材质、配色、选角、空间或记忆点上真正不同的方向，选择最能兑现作品类型并抬高成片上限的一套，不随机拼词、不只换滤镜。
- 如果用于 AI 视频，必须考虑角色稳定、光影延续、运动空间和后期拼接。
- 如果用于封面，必须考虑手机端缩略图可读性和标题留白。
- 如果用于角色资产，先完成符合题材、受众与角色功能的选角、身形、妆发、服装和身份记忆点，再用中性展示稳定；设计资产禁止追求无职责的戏剧化，但也禁止用稳定掩盖普通造型。
- 如果用于海报，优先表达冲突，禁止只堆氛围。
- 下方各资产子类型只补充该类型的特殊字段，不替代通用四锚点。正式输出人物形象、场景、道具、封面或首帧提示词时，都要把主体锚点、场景锚点、时间锚点、风格锚点和具象化摄影结果合并进同一个可复制代码块；不能因为子模板没有重复列出某字段就省略关键因果。

## 图片资产子类型

### 资产唯一性原则

一个 `L1 独立锚点资产` 只能固定一个确定对象：一个人物素体、一套人物服装、一套人物妆造设计、一件道具、一个空置基础场景或一套风格规则。资产不是把一个镜头里会出现的所有东西提前画在一起。比如“灶房 + 桌子 + 汤圆 + 硬币 + 奶奶手 + 小孩手”不是独立资产，而是分镜图、首帧图或视频参考图。

`L2 组合资产` 不违反唯一性原则：它固定的是已经确认对象之间可复用的稳定关系，例如某人穿戴某套铠甲、某工牌挂在某人物胸前、某台电脑固定摆在某工作位。组合图必须显式引用各个 L1 上游，不能在组合阶段重新设计其中任何一个对象；它也不能替代原人物、原道具和原场景资产。若关系只在一个动作瞬间成立，就不升级为 L2，而交给 L3 故事板、首帧或视频参考图。

如果一个画面里有多个元素需要稳定，正确做法是拆成多个资产：

```text
S1 灶房局部空间：只固定门窗、墙面、灶台、光源、动线。
P1 旧木案桌：只固定桌子本体和多角度。
P2 完整白汤圆：只固定包好后的连续白糯米皮外观。
P3 小面值硬币：只固定单枚硬币本体。
A1 奶奶：只固定奶奶人物。
```

后续在分镜、视频提示词或第一帧参考图里把这些资产组合起来，写谁站在哪里、谁的手从哪里伸入、道具如何摆放和动作如何发生。

互斥可见状态必须拆资产。凡是一个物件存在“包入前可见 / 包入后不可见”“完整外观 / 剖开内部”“未损坏 / 损坏”“未点燃 / 已燃烧”等状态，不能把两个状态写进同一张资产图。否则模型会把互斥信息融合成错误外观。错误写法：`硬币汤圆资产` 同时写完整白汤圆、黑芝麻馅和硬币贴近汤圆皮。正确写法：完整白汤圆资产只固定连续白糯米皮和水光；小面值硬币资产单独固定硬币，只在包入前、吃出后或递出时和汤圆场景组合调用。

所有带主视图和局部细节区的资产提示词，在正式代码块内先建立 `总览定位 → 局部放大` 关系。局部细节不能第一次发明 Logo、文字、纹样、配饰、接缝、孔位、活动件或场景构件；上方完整视图必须先显示它的载体、位置、朝向、数量与基准状态。推荐在细节段落前增加一句来源映射：`细节 1 来源于正面视图的瓶身标签；细节 2 来源于外侧视图的后跟弧桥；细节 3 来源于鸟瞰和右侧机位共同可见的排水槽。` 底部再补充上方尺度看不清的字形、纹理、材质和装配。完稿检查每个细节能否回指唯一来源，也检查每个承重识别点是否已在总览中定位。

所有图片提示词的可复制正文都遵守“出现什么描述什么”。代码块里不要用排除句去排除另一个资产，因为模型可能先注意到那个无关对象。代码块外可以写 `不能继承` 和验收风险，提醒制作时不能和哪些资产混用；代码块内只写当前目标画面的主体、形状、材质、比例、纹理、光线、背景和清晰度。错误写法：在小硬币资产正文里反复写“汤圆”。正确写法：只写一枚洗净小面值硬币、旧金属磨损、边缘、数字纹理、克制反光、旧瓷小碗边缘或木桌小范围表面。

资产类型按失真来源判断：年代环境、店铺类型、陈列方式、货架 / 柜台 / 桌椅 / 灶台 / 教室 / 小卖部 / 商场的空间语法、灯光和地面墙面跑偏时，做场景资产；物品本体的轮廓、材质、尺寸、结构、磨损、开启方式或特写细节跑偏时，做物品资产。比如“商场拒买玩具”如果要固定的是普通商场玩具货架区的年代感和陈列环境，就做 `商场玩具货架区` 场景资产，而不是把镜头里出现的玩具误做成道具资产。

### 色彩风格资产 / 色卡资产

用于固定全片或某个情绪阶段的色彩系统。它不是人物服装资产或妆造设计资产里的局部色值说明；人物局部配色只校对角色服装、肤色和首饰，色彩风格资产负责跨分镜剪辑统一和情绪推进。

```text
用途：
生成色彩风格资产【C1 色卡名】，用于固定【作品名 / 场景段落 / 情绪阶段】的整体色彩与影调，后续视频提示词用【@C1 色卡名】作为色彩参考，并在色彩与影调里展开文字规则。

画面主体：
分区色卡设计图，必须分成四个清楚分区：人物组、道具组、场景组、氛围与过渡组。人物组包含肤色、发色、妆容、服装不同部位、首饰和可见皮肤高光；道具组包含关键道具名称、材质部位、金属 / 木质 / 纸张 / 布料 / 液体 / 火光等颜色；场景组包含墙面、屋顶、地面、门窗、天空、水面、植被和固定建筑结构；氛围与过渡组包含整体光线、雾气、烟雾、空气透视、远近层次、暗部、阴影、高光、转场铺屏和胶片 / LUT 分级示意。每个色块旁边标注十六进制 RGB / HEX 色值，例如 #DDEAF0，并用简短中文标明用途。

结构：
上方是全片母色卡，按四组分栏和使用比例排列；每组内部主用色最大、辅助色次之、点缀或过渡色最小。下方是阶段变体小色条，例如心动期、热恋期、冷淡期、分手期，每个变体只在母色卡基础上调整明度、暗部冷暖、点缀色面积、肤色气色、环境反光和阴影重量。

说明文字：
画面内可以出现简短中文标签和十六进制色值；不要写长段解释。长段使用说明放在代码块外。

质量边界：
色块干净，色值清晰，主次比例明确，阶段变体与母色卡保持同源，不做高饱和杂乱撞色，无多余装饰和水印。
```

代码块外必须补 `文字规则`：人物组、道具组、场景组、氛围与过渡组分别有哪些 HEX；每个 HEX 落到人物哪个部位、道具哪个部件、场景哪个结构和氛围哪种过渡；点缀色只能出现在哪些小面积位置；肤色和发色如何保持、不能偏成什么色相；光源色、暗部、阴影和空气透视如何变化；哪些情绪阶段继承母色卡，哪些阶段使用变体。

代码块外还必须补 `视频调用句` 和 `颜色映射模板`，方便后续一体化视频执行单直接复制：

```text
视频调用句：请将【@C1 色卡名】作为本段视频的主色彩锚定，所有画面颜色必须严格服从这套色彩系统，不要自动改来换色调，不生成与色卡无关的高饱和颜色。
颜色映射模板：整体光线为【本镜头光线类型】，主要调用【#HEX】和【#HEX】；主角服装的【部位】严格调用【#HEX】，【部位】调用【#HEX】；主角肤色保持【#HEX】附近的【肤色描述】，发色保持【#HEX】附近的【发色描述】，不要偏成【错误色相】；场景结构中【墙面 / 屋顶 / 地面 / 门窗】分别调用【#HEX】；关键道具【道具名】调用【#HEX】；氛围与过渡中的【雾气 / 烟雾 / 空气透视 / 暗部 / 阴影 / 高光】调用【#HEX】。
```

正式视频提示词不能只写“调用色卡”，必须把这段文字规则展开进 `【场景状态与氛围画质】` 的 `色彩与影调`。

### 群像人物资产

用于固定一类跑龙套人群的年龄层、服装年代、体态差异、站位密度、表情范围和群体气质。群像人物资产不是主角色资产，不锁具体单人脸，不给每个群众做三视图；它更像一张场景合照式参考图，帮助后续视频生成同一类人群。

```text
用途：
生成群像人物资产【群像名】，用于固定【服务场次】里一类跑龙套人群的年龄层、服装年代、站位密度和群体气质。这个资产不固定每个人的姓名和具体脸，只固定这群人整体像什么人。

主体内容：
画面中有【数量】个【年龄层 / 身份】，【男女性别比例、身高错落、体态差异】。他们穿【时代 / 地域 / 生活条件】对应的服装，发型自然，表情范围是【好奇 / 围观 / 起哄 / 惊讶 / 沉默 / 哭丧】。构图像场景合照式参考图，展示站位密度、服装年代、群体情绪和跑龙套气质。

场景：
背景可以是【相关场景】的简洁生活环境，背景只作为人群气质参照，不承担剧情动作。

质量边界：
群体像真实跑龙套人群，服装年代统一，单人脸存在感适中，站姿自然，剧情动作保持低强度，画面干净真实，无文字水印。
```

### 人物素体形象资产

用于固定角色本体，不固定具体戏服、饰品、浓妆、剧情表情或场景气氛。它是人物服装资产和人物妆造设计资产的唯一身份上游。

```text
用途：
生成人物素体形象资产【资产编号】【角色名】，用于固定脸型、头型、五官、肤色 / 毛色、身材、身高和永久辨识点，后续供人物服装资产与人物妆造设计资产引用。

参考职责：
【参考图：人物来源】只继承【脸型、五官、肤色、体态等明确项目】；不继承原图的发型、服装、妆容、姿势、背景和光线，除非本资产明确锁定。

主体内容：
同一个角色，穿纯白简单衣裤，不带强风格配饰。重点固定脸 / 头型、五官、肤色或毛色、年龄或形态阶段、身材、身高、身体比例、肩颈、体态、惯用侧和永久辨识特征。

构图：
摄影棚中性灰背景，均匀校准光。左侧为大尺寸头部正面特写；右侧依次为人物自己的左45度全身、正面全身、背面全身。画面另设属性说明区，清楚标注角色编号、年龄或形态阶段、身高、体重设计值、头身比、肩宽、胸围、腰围、臀围、腿身比、臂展、手脚尺寸、惯用侧、肤色 / 毛色、眼色、发色 / 发质、辨识特征和动作限制。不能从参考照片猜测的数字标为“角色设计值 / 待确认”。动物、卡通、机甲和非人主体改写为体长、肩高、四肢、尾耳角翼尺寸、关节范围或变形边界。

质量边界：
同一角色的脸型、五官、肤色 / 毛色、身高和比例在四个视图区一致；白衣白裤简洁，中性灰背景无剧情元素，表情为中性校准状态，属性文字清楚，画面干净真实，无文字水印。
```

### 人物服装资产

用于单独固定穿在、戴在、挂在角色身上，且主要承担穿搭识别的可拆卸物。发型、脸部妆容、伤妆、临时纹身和身体彩绘不属于服装资产；会被摘取、交换、操作、触发剧情或揭示信息的物件升级为道具资产。

```text
用途：
生成人物服装资产【资产编号】【造型名】，用于固定整套可穿戴系统，后续由人物妆造设计资产穿回指定角色。

上游适配：
需要适配特定角色时，引用【素体参考@B01 人物素体形象资产】，只读取头型、肩宽、胸腰臀、腿长、手脚尺寸和活动范围；不继承脸、表情、背景、光线和素体白衣。

四区总览与细节：
头部穿戴区展示【帽冠、簪饰、耳饰、面具等可拆卸穿戴物】的完整结构与局部特写；上半身区展示【内层、中层、外层、领口、肩线、袖型、袖口、胸腰结构】；下半身区展示【腰封、裙 / 裤层次、开衩、褶量、悬挂物和活动余量】；足部区展示【袜、绑腿、鞋靴、鞋底和扣合结构】。每区都写清正背关系、版型、层次、材质、纹样、颜色、接缝、扣合、穿戴顺序、身体接触位置、活动机制和简短中文标签。

造型账本：
列出所有服装与穿戴物的唯一名称、数量、所在部位、左右方向、颜色、材质和穿戴顺序。局部特写只能放大总览已经出现的设计，不能新增随机饰品、换鞋或改变纹样。

质量边界：
服装是唯一主体，四区结构完整，正背关系与局部细节可追溯，材质和颜色稳定，适合后续穿回角色；画面干净，无随机人物脸、无剧情动作、无场景气氛、无无关文字水印。
```

### 人物妆造设计资产

用于把已确认的人物素体与人物服装组合成最终可调用角色，并加入发型、脸部妆容、胡须 / 假发、临时纹身 / 身体彩绘、伤妆、疤痕妆或义体表面。它不重新发明角色本体，也不重新拆解服装。

```text
用途：
生成人物妆造设计资产【资产编号】【角色名·造型名】，作为视频、故事板、封面和后续人物成品图的最终角色参考。

引用职责：
【素体参考@B01 人物素体形象资产】只固定脸 / 头型、五官、肤色、身高、体型、比例、体态和永久辨识点；【服装参考@W01 人物服装资产】只固定服装、穿戴物、材质、颜色、正背结构和穿法。最终资产在二者基础上加入【发型、眉眼唇腮妆容、胡须 / 假发、临时纹身 / 身体彩绘、伤妆、疤痕妆或义体表面】。

上身适配：
写清领口与颈部、肩线与肩宽、胸腰结构、腰封位置、裙 / 裤从哪里展开、袖口与手腕、鞋靴与脚型的贴合关系；说明哪些部位垂坠、挺括、贴合、悬挂或允许随动作摆动。

版式：
中性灰或简洁灰白背景，均匀校准光。左侧为人物头部正面特写，清楚展示同一张脸、最终发型、头部穿戴和妆容；右侧依次为人物自己的左45度全身、正面全身、背面全身，完整展示同一套服装的穿法、正背结构、配饰位置和鞋履比例。可加入简短妆造变化说明，但不重复整套身体属性和服装拆解。

表情与状态：
使用中性校准表情和角色代表性基础体态，不加入当前剧情的哭、怒、惊恐、战损、湿透或持物动作；这些瞬时状态交给视频正文。

质量边界：
素体身份不漂移，服装细节与 W01 一致，发型与妆容清楚，四个视图区的脸、体型、服装、穿戴物和鞋履一致；无随机饰品、无场景气氛、无剧情动作、无无关文字水印。
```

POV、背影、遮挡、低视线、只露手或袖口属于下游镜头策略，不改变三资产链。主角级 POV 仍先完成三类资产；当手、脚、义肢或其他局部承担跨镜头身份识别或关键操作时，可以追加局部补充参考，但不能用局部参考替代完整素体和妆造设计资产。人物声音另用 `【音色参考@V1】`，不写进人物图片板。

### 场景图片资产

用于固定一个会多次进入或多角度拍摄的空间。

场景提示词前先确定世界观与类型对应的空间语法：谁建造、谁使用、怎样进入、怎样生活或战斗、什么材料与尺度合理、主要光源从哪里来。每个重要场景至少设计一个可被复述的空间记忆锚点，例如独特入口、纵深关系、结构节奏、地面反射、主材料连接方式或功能装置；记忆锚点必须服务题材与动作，不用无关奇观装饰空间。

```text
用途：
生成固定场景资产【场景名】，用于锁定空间结构、入口、主视角、侧视角、反向视角、光源方向和可运动路径。

主体内容：
同一个场景，不同角度。必须保持建筑结构、入口位置、主光方向、关键道具和空间比例一致。

构图：
扩展分区场景设计板。上部约三分之二为结构区：左侧约三分之二做 2×2 四机位视图区，主辅助区做高位鸟瞰 / 斜俯视总平面；底部约三分之一做固定构件与材质细节带。

质量边界：
每格保持同一个场景，光源方向稳定，空间结构互相对应，尺度关系清楚。
```

#### 场景扩展分区设计板

当一个场景需要多次进入、正反打、左右侧视角、人物走位、俯拍、拉高镜头或局部特写时，优先使用扩展分区设计板。它的目的不是增加格子数量，而是同时固定机位关系、总平面和空间材质细节。

```text
用途：
【参考图1：场景参考】图片，生成固定场景资产【场景名】的扩展分区场景设计板，用于锁定同一场景布局、入口 / 窗户 / 墙角 / 固定家具 / 建筑构件的位置关系、鸟瞰总平面、光源方向、人物可运动路径和固定细节材质。

主体内容：
同一个场景，同一套空间结构。四机位、鸟瞰和细节带必须保持场景布局一致，物体空间逻辑正确，固定结构在不同区域中位置、材质与颜色互相对应。场景资产只锁空间、入口、门窗、墙面、固定灶台 / 固定家具、固定光源、地面、墙角、建筑节点和可运动路径；可移动道具、人物手部和具体动作另做资产或写入分镜。

构图：
扩展分区设计板。
左上 2×2 四机位视图区：正面视角定义主入口、主构图和纵深；左侧视角由正面向左旋转；右侧视角由正面向右旋转；反向视角从主视角对面看回入口和人物站位。
右上高位鸟瞰 / 斜俯视总平面：占上部结构区约三分之一宽度，完整显示空间边界、入口出口、固定构件、四机位大致位置、人物可运动路径和光源方向；它承担布局证据，不做第五张普通广角。
底部细节带：拆分门窗节点、墙地顶材质、固定灯具、标识载体、连接件、排水 / 通风 / 机械结构、磨损、反射和空间记忆锚点。每个细节均来自上方同一场景，不展示可移动剧情道具。

空间一致性：
所有区域必须保持同一场景布局一致，视角逻辑正确，物体空间逻辑正确。入口、窗户、固定灶台 / 家具、墙角、灯位等空间结构位置稳定；鸟瞰能解释四机位，细节带能回指上方结构。场景主体集中在空间结构、固定光源、入口、墙面、地面、固定节点和可运动路径。

四视图空间原则：
左上四机位必须是同一个位置从不同方位看过来的图。先定义正面视角，再让左侧、右侧和反向视角围绕它旋转或反打；右上鸟瞰负责复核所有固定结构与动线，底部细节负责复核结构材质和识别特征。

底部每项场景细节都必须先在左上四机位或右上鸟瞰中出现并具有唯一空间位置。写细节带前逐项标明来源机位或鸟瞰坐标；门窗、灯具、标识、排水槽、通风口、墙地接缝等不能在底部第一次出现。

局部操作空间拆分：
当核心动作发生在桌面、案板、灶台边、祭祀桌、手工台等局部空间，且后续需要 POV、正反打、手部操作或人物围桌互动时，先拆资产。空间本身做局部场景资产；桌子 / 案板 / 碗 / 汤圆 / 硬币等可移动物做物品资产；人物手部、站位、动作和摆放关系写入分镜、视频提示词或第一帧参考图。场景资产只固定空间，组合关系交给分镜和视频提示词。

质量边界：
四机位、鸟瞰和细节带保持同一空间账本，固定结构位置一致，左右视角和反打关系正确，光源方向稳定，空间尺度真实，材质与颜色在全板一致。
```

### 角色所属物的前置审美判断

当物品归属于具体角色，例如首饰、变身器、武器、设备、法器、包袋、鞋履、铠甲或随身道具，写双提示词前增加以下内部判断，结论写进物品的轮廓、尺度、CMF 和使用方式，不机械输出表格：

```text
角色是谁：身份、年龄、性别表达、体型、气质、世界观位置。
它为何属于角色：剧情功能、情绪职责、造型职责、是否长期佩戴 / 携带。
身体关系：尺寸、重量、握持 / 佩戴位置、接触面积、操作路径、是否妨碍动作与服装。
审美关系：与服装的形状、颜色、材质、纹样和精致度如何统一；角色是否会主动选择它。
风格前置：强风格化装备是否需要先建立色卡 / 风格资产，并由人物、装备、场景、VFX 共同继承。
禁止方向：哪些通用功能造型会破坏角色，例如小巧珠宝需求被画成粗大战术手柄。
```

功能可读只是底线。角色所属物必须同时证明“能用、好用、像这个角色会用、放进整套造型仍然好看”。用户为解释动机提供的类比或举例，不自动成为物品设计或场景中的可见对象。

同一角色有变身前 / 变身后、日常 / 战斗、完好 / 损坏等互斥形态时，在写图片提示词前补充：

```text
身份继承：脸、年龄、身材、肤色、发型、稳定体态。
状态 A 专属：只在状态 A 出现的服装、鞋履、首饰、道具、颜色和材质。
状态 B 专属：只在状态 B 出现的服装、鞋履、首饰、装备、颜色和材质。
切换边界：哪些部位如何替换，完成后不得残留什么。
版面隔离：状态 A 与状态 B 分区展示；禁止同一人物同时穿戴两套互斥状态。
```

引用人物参考图时要写清是 `人物身份参考` 还是 `完整造型参考`。前者不能自动继承参考图服装；色卡也不能用一个综合色彩人物把两种互斥造型混穿。

### 物品资产双提示词

关键商品 / 道具既承担主视觉，又会跨角度、被人物操作、穿戴、拆装、运动或进入特写时，使用同一资产编号交付两套提示词。简单一次性道具若没有主视觉任务，可以只做设计资产。

写两套提示词前必须先确定：目标人群与价格感 / 使用情境、产品或道具在故事中的功能、远看轮廓和比例、真实结构、CMF（颜色 / 材料 / 表面处理）、品牌或世界观识别细节、握持 / 穿戴 / 开启 / 运动方式，以及一个不过度妨碍功能的视觉记忆点。形象资产证明它为何让人想看、想拿、想穿或想买；扩展分区设计资产证明去掉商业灯光后，同一设计从不同角度仍然成立，并把下游会拍到的材质、Logo、文字、纹样、连接和功能结构放大到可检查尺寸。两张图只要有一张不成立，就不算合格资产。

```text
A3 【物品名】物品形象资产提示词

用途：
生成物品形象资产，用单张成品图固定【物品名】的第一眼观感、商业呈现、主视角轮廓、材质气质和品牌识别。

主体内容：
同一件物品以最能体现用途和辨识度的主视角完整出现，写清轮廓、比例、材质、颜色、结构、固定文字和识别细节。

构图：
单张成品图，主体清楚，环境、光影和接地关系服务物品本身，不遮挡关键结构。

质量边界：
身份唯一、结构真实、材质清楚、品牌文字准确，不混入其他型号、无关道具或水印。
```

```text
A3 【物品名】物品设计资产提示词

用途：
生成物品设计资产，用扩展分区设计板固定【物品名】的正反内外、顶部底部、左右关系、比例、材质、Logo / 文字 / 纹样和关键结构。

主体内容：
全板必须是同一件物品、同一型号、同一颜色和同一状态。先按物品风险选择三至五个主结构 / 辅助视图，至少覆盖主外观、相反侧和顶部 / 底部 / 左右关系中的必要项；再列出底部细节带必须放大的材质、表面处理、Logo 载体、固定文字、纹样、接缝、孔位、扣件、边缘、活动件、接口、握持 / 穿戴 / 接触区和功能结构。每个细节必须能在上方主视图找到来源。

构图：
扩展分区物品设计板。上部约三分之二为主结构区，按结构重要性安排三至五个不等宽但基准线统一的视图；主辅助区可增加一个较大的顶部、底部或操作结构视图。底部约三分之一为细节带，细节模块大小按重要性分配。中性浅灰或白色背景，正交或接近正交视角，光线均匀。

质量边界：
主视图、辅助视图和细节带的轮廓、比例、材质、颜色、Logo、文字、纹样、孔位、接缝和左右关系互相对应；细节带不自由发挥，不把不同型号、不同配色或互斥开合 / 损坏状态混在同一张板，也不用透视变化掩盖结构冲突。

写底部细节带前，先把每个细节绑定到一个上方来源视图和具体部位。Logo、文字和纹样必须先在上方正确载体上显示宏观位置与朝向，底部只放大其字形、印刷、表面和连接；活动件、接口与接触区也必须先在完整物品上可定位。禁止上方没有 Logo、底部突然出现 Logo，或上方是一只右鞋、底部细节来自未说明的左鞋。
```

两套提示词仍属于同一个 A3，不拆成 A3-1、A3-2。后续视频需要商品气质与跨角度结构时，两张图都作为 A3 的不同用途参考输入。

## 组合资产记录

```text
B01：人物素体形象资产，固定【角色名】本体的脸、体型和比例。
W01：人物服装资产，固定【服装名】的四区穿戴系统。
M01：人物妆造设计资产，表示 B01 引用 W01 后形成的最终造型，并补充发型与妆容。
```

正式图片提示词可以写 A3 的具体外观；资产表必须记录 A3 = A1 + A2，方便后续直接调用。
