# 模板_角色一致性网格图

> 来源：结合本项目图片资产研究文档与 EvoMap 搜索到的 `Grid Split for image_consistency / storyboard / character_consistency` 方向沉淀。  
> 用途：当多个独立图片生成容易导致角色不一致时，优先尝试“一张网格图里生成多格角色状态”，再拆分为参考图。

## 一、核心判断

多次独立生成角色图，容易出现：

- 脸变。
- 发型变。
- 服装细节变。
- 年龄和气质漂移。
- 镜头之间不像同一个人。

网格图策略是：

```text
一次生成
→ 同一潜在空间中出现同一角色的多个角度 / 表情 / 状态
→ 再拆分成单张参考图
→ 用于后续图片、视频和分镜生成
```

这不是万能方案，但适合做角色定妆、表情组、动作起点和分镜参考。

## 二、适用场景

- 角色三视图。
- 人物素体资产：白衣 / 中性服装，固定长相、身材、发型和基础体态。
- 人物定装资产：同一人物穿固定服装、发饰、妆容后的完整形象。
- 同一角色 4-9 个表情状态。
- 同一角色不同景别参考。
- 同一角色同一服装的多个动作起点。
- 分镜前 4-6 个关键画面。

不适合：

- 每格场景完全不同。
- 每格光影风格完全不同。
- 角色需要大幅换装。遇到长期换装角色，先拆为人物素体资产、服装 / 妆造资产、组合形象资产。
- 海报封面这类需要单张精修的图。

## 三、提示词结构

```text
用途：
生成一张角色一致性网格图，用于后续 AI 视频和分镜参考。所有格子必须是同一个角色、同一张脸、同一发型、同一服装、同一年龄和气质。

网格：
画面为【16:9 横幅 / 2x2 / 3x3】网格，每个格子边界清楚，禁止文字和水印。

角色统一设定：
角色是【身份、年龄、外貌、发型、服装、气质】。所有格子必须保持一致。

每格内容：
格 1：【脸部特写，平静表情】
格 2：【正面全身】
格 3：【侧面全身】
格 4：【背面全身】

风格统一：
真实摄影 / 电影定妆照 / 低饱和色彩 / 柔和侧光 / 背景简洁灰白。人物资产优先稳定，不追求戏剧化场景。

负面约束：
不要不同人物，不要换脸，不要换发型，不要换衣服，不要夸张表情，不要多余文字，不要卡通化，不要水印。
```

## 四、拆分后命名

```text
角色名_grid_原图.png
角色名_ref_01_正面半身.png
角色名_ref_02_侧面半身.png
角色名_ref_03_情绪近景.png
角色名_ref_04_动作起点.png
```

## 六、使用边界

- 网格图通过后，才进入分镜图或视频第一帧。
- 如果网格图都无法稳定，不要急着做视频，应先重写角色设定或换模型。
- 网格图不替代最终镜头图，它是角色一致性中间资产。
- 如果人物会换装，网格图要标注它是人物素体、人物定装还是组合形象。不要把所有服装状态混在一张“同一角色资产”里。
