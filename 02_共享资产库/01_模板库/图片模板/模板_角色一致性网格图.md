# 模板_角色一致性网格图

> 来源：结合本项目图片资产研究文档与 EvoMap 搜索到的 `Grid Split for image_consistency / storyboard / character_consistency` 方向沉淀。  
> 用途：当多个独立图片生成容易导致角色不一致时，优先尝试“一张网格图里生成多格角色状态”，再拆分为参考图。

## 一、核心判断

网格图不是默认资产，也不是人物资产的必经步骤。只有当一个已经判定为“值得复用”的图片资产需要多个角度、局部和整体同时校准时，才使用网格图；如果只需要一张正面肖像、一个场景参考或一次性镜头参考，直接生成单张图片，不为了填模板制作网格图。

多次独立生成角色图，容易出现：

- 脸变。
- 发型变。
- 服装细节变。
- 年龄和气质漂移。
- 镜头之间不像同一个人。

网格图策略是：

```text
一次生成
→ 同一潜在空间中出现同一角色的多个角度 / 表情 / 状态
→ 再拆分成单张参考图
→ 用于后续图片、视频和分镜生成
```

这不是万能方案。它可以作为已选定的 `B` 人物素体资产、可选的 `W` 服装资产或可选的 `M` 最终造型资产的版式生成方法，也可以作为临时表情测试、动作起点和分镜参考；表情测试和动作起点只能登记为临时参考图，不能登记到人物资产表，也不能在正式视频提示词的资产行调用。网格图本身不是新的资产类型，必须在文件中标明它服务哪一个已选择的资产职责；如果该职责只需要单张图，就不要使用网格图。

## 二、适用场景

- 已确认需要跨镜头复用的人物身份三视图。
- 人物素体形象资产：使用白衣 / 中性服装，固定脸型、五官、身材、身高和基础体态。
- 人物妆造 / 最终造型资产：在该套造型跨片段复用或必须锁定最终外观时，固定发型、妆容和最终上身结果；正式M改用三列纵向复合的上头下身专用板，不使用本文件的普通六张独立人物网格。
- 人物服装资产：所有进入正式人物造型链的最终服装都先建立W；W按主件结构使用可拆套装四象限拆解板或连续主件完整展示板，不把服装工程和人物脸、妆容混成同一格。
- 同一角色 4-9 个表演测试状态，仅作临时参考，不登记为人物图片资产，不作为正式视频提示词的状态资产调用。
- 同一角色不同景别参考。
- 同一角色同一服装的多个动作起点。
- 分镜前 4-6 个关键画面。

不适合：

- 每格场景完全不同。
- 每格光影风格完全不同。
- 角色需要大幅换装且每套造型都承担跨片段复用。遇到这种情况，先判断是否只需多个最终造型资产；只有服装本身还要脱离人物复用时，才增加人物服装资产。
- 海报封面这类需要单张精修的图。

## 三、提示词结构

```text
用途：
生成一张角色一致性网格图，用于已确认需要跨镜头复用的【临时表演测试 / 景别测试 / 动作起点测试】。正式F、B、W、M不得直接套用下方普通网格：F使用竖幅完整全身角色写真；B使用固定三列信息板；W引用F与服装设计正文，并使用按主件结构选择的服装专用板；M引用同编号F、已确认B、当前阶段素体、W与妆造补充正文，并使用左前方45度、正面、背面三列纵向组合的上头下身专用板。M上部头部特写覆盖下部原头部位置，下部为从颈根到鞋底的无头穿着身体。

网格：
画面为【16:9 横幅 / 2x2 / 3x3】网格，每个格子边界清楚，画面保持干净，无文字水印。

角色统一设定：
角色是【身份、年龄、脸型、五官、身体比例】；本次网格职责为【已选择的资产职责】。B只写基础衣着和基础外观校准，W只写服装结构，M写最终发型、妆容和本次已确认的服装结果；不在不同格子之间自由变化，也不把一次性表情、动作、场景和道具写成资产固定项。

每格内容：
格 1：【头部正面大特写，脸型、五官和基础表情清楚】
格 2：【左侧45度全身】
格 3：【正面全身】
格 4：【背面全身】

风格统一：
B资产使用真实摄影 / 中性校准光 / 简洁中性背景；M资产使用真实定妆摄影 / 受控主光与补光 / 与妆面形成明度或色相对比的摄影棚背景。M必须让眼神光、睫毛、唇部高光、肤色层次和服装轮廓可读，四个格子共用同一光向、背景层次和色彩基线；不把M做成平光灰底雕像，也不加入复杂叙事场景。

质量边界：
同一人物身份稳定，脸和身体比例一致；当前资产职责内的结构、材质、发型、妆容或服装结果在各格之间一致；不把瞬时表情、哭笑、眼泪、恶心、呼吸、吞咽、姿态和一次性物件固化为状态资产。画面真实清晰，无文字水印。
```

## 六、使用边界

- 网格图通过后，才进入分镜图或视频第一帧；如果任务只需要一次性镜头参考，跳过网格图。
- 如果网格图都无法稳定，不要急着做视频，应先重写角色设定或换模型。
- 网格图不替代最终镜头图，它是角色一致性中间资产。
- 如果人物会换装，网格图必须标注它是B人物素体形象资产、W人物服装资产、M人物妆造设计资产或临时参考。不要把不同服装状态混在一张“同一角色资产”里；W资产按服装主件结构改用可拆套装2×2分件拆解板或连续主件完整正背展示板，不强行套用人物三视图网格。
