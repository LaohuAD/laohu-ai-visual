# 模板_角色一致性网格图

> 来源：结合本项目图片资产研究文档与 EvoMap 搜索到的 `Grid Split for image_consistency / storyboard / character_consistency` 方向沉淀。  
> 用途：当多个独立图片生成容易导致角色不一致时，优先尝试“一张网格图里生成多格角色状态”，再拆分为参考图。

## 一、核心判断

多次独立生成角色图，容易出现：

- 脸变。
- 发型变。
- 服装细节变。
- 年龄和气质漂移。
- 镜头之间不像同一个人。

网格图策略是：

```text
一次生成
→ 同一潜在空间中出现同一角色的多个角度 / 表情 / 状态
→ 再拆分成单张参考图
→ 用于后续图片、视频和分镜生成
```

这不是万能方案。它可以作为三资产中的版式生成方法，也可以作为表情测试、动作起点和分镜参考；网格图本身不是新的资产类型，必须在文件中标明它服务B、W、M中的哪一类，或标明为临时参考。

## 二、适用场景

- 角色三视图。
- 人物素体形象资产：白衣 / 中性服装，固定脸型、五官、身材、身高和基础体态。
- 人物妆造设计资产：引用人物素体形象资产与人物服装资产，固定发型、妆容和最终上身结果。
- 人物服装资产：只有在四区拆解板能够清楚展示穿戴系统时使用；不把它和人物脸、妆容混成同一格。
- 同一角色 4-9 个表情状态。
- 同一角色不同景别参考。
- 同一角色同一服装的多个动作起点。
- 分镜前 4-6 个关键画面。

不适合：

- 每格场景完全不同。
- 每格光影风格完全不同。
- 角色需要大幅换装。遇到长期换装角色，先拆为人物素体形象资产、人物服装资产、人物妆造设计资产。
- 海报封面这类需要单张精修的图。

## 三、提示词结构

```text
用途：
生成一张角色一致性网格图，用于人物素体形象资产或人物妆造设计资产。先在标题中写明资产职责；所有格子必须是同一个角色、同一张脸、同一年龄和同一身体比例。若是B资产，使用基础白衣；若是M资产，必须同时引用已确认的B与W。

网格：
画面为【16:9 横幅 / 2x2 / 3x3】网格，每个格子边界清楚，画面保持干净，无文字水印。

角色统一设定：
角色是【身份、年龄、脸型、五官、身体比例】；本次网格职责为【B人物素体形象资产 / M人物妆造设计资产】。B只写基础白衣和基础发型校准，M写最终发型、妆容和已引用服装，不在不同格子之间自由变化。

每格内容：
格 1：【头部正面大特写，脸型、五官和基础表情清楚】
格 2：【左侧45度全身】
格 3：【正面全身】
格 4：【背面全身】

风格统一：
B资产使用真实摄影 / 中性校准光 / 简洁中性背景；M资产使用真实定妆摄影 / 受控主光与补光 / 与妆面形成明度或色相对比的摄影棚背景。M必须让眼神光、睫毛、唇部高光、肤色层次和服装轮廓可读，四个格子共用同一光向、背景层次和色彩基线；不把M做成平光灰底雕像，也不加入复杂叙事场景。

质量边界：
同一人物身份稳定，脸和身体比例一致；B保持基础衣着与校准状态，M保持已引用服装、发型和妆容一致；表情克制自然，画面真实清晰，无文字水印。
```

## 六、使用边界

- 网格图通过后，才进入分镜图或视频第一帧。
- 如果网格图都无法稳定，不要急着做视频，应先重写角色设定或换模型。
- 网格图不替代最终镜头图，它是角色一致性中间资产。
- 如果人物会换装，网格图必须标注它是B人物素体形象资产、W人物服装资产、M人物妆造设计资产或临时参考。不要把不同服装状态混在一张“同一角色资产”里；W资产应改用四区服装拆解板，不强行套用人物三视图网格。
