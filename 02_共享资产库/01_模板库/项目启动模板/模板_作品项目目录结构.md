# 模板_作品项目目录结构

> 用途：开一个正式 AI 视觉作品时，按创作链路建立目录。目录要少、干净、容易扫描。

## 一、作品目录位置

```text
01_作品项目/进行中/yyyy-mm-dd_作品名/
01_作品项目/已完成/yyyy-mm-dd_作品名/
01_作品项目/已发布/yyyy-mm-dd_作品名/
```

## 三、阶段目录说明

| 目录 | 存什么 | 常见文件 |
|---|---|---|
| `00_原始输入/` | 原始口述、参考图、参考视频、参考音频、外部资料 | `文本/2026-xx-xx_需求_主题.md` |
| `01_世界观故事/` | 故事确认、世界观、人物关系、场景规则 | `文本/00_故事确认.md`、`文本/yyyy-mm-dd_世界观_主题.md` |
| `02_剧本/` | 正式剧本、改稿、台词旁白 | `文本/yyyy-mm-dd_剧本_主题.md` |
| `03_视觉资产/` | 风格规范、角色图、场景图、道具图、图片资产提示词 | `文本/yyyy-mm-dd_风格统一规范_主题.md` |
| `04_分镜/` | 分镜表、镜头任务表、分镜草图、分镜参考视频 | `文本/yyyy-mm-dd_分镜表_主题.md` |
| `05_视频/` | 视频提示词、生成视频、视频参考图、音频参考、剪辑相关文本 | `文本/yyyy-mm-dd_视频提示词_主题.md` |
| `09_归档复盘.md` | 发布复盘、成功失败经验、反哺共享资产记录 | 当前作品复盘入口 |

## 四、媒介子目录规则

每个阶段目录下面固定保留：

```text
文本/
图片/
视频/
音频/
```

- 文本：需求、剧本、设定、提示词、表格、复盘。
- 图片：参考图、资产图、生成图、封面图、分镜草图。
- 视频：参考视频、生成视频、剪辑片段、成片。
- 音频：参考音频、旁白、配乐、音效、同期声、环境声。

不要再为“角色资产、场景资产、道具资产、图片提示词、视频提示词、负面提示词”等预建大量空目录。需要细分时，在对应阶段的 `文本 / 图片 / 视频 / 音频` 下按实际素材量再建。

## 五、最小启动文件

新建作品时至少建立：

- `00_项目总览.md`
- `00_阶段确认记录.md`
- `00_首轮验证看板.md`
- `01_世界观故事/文本/00_故事确认.md`
- `09_归档复盘.md`

如果只是临时想法，还没进入正式作品，不要开作品目录，先放 `00_输入原料/`。
