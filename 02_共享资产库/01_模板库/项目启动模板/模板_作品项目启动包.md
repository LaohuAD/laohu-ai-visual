# 模板_作品项目启动包

本模板同时供创建器读取和人工启动使用。`overview`、作品类型区块和 `record` 是创建器的内容源；只选择一个类型区块填入总览，不复制其他分支。后续专业内容仍由对应 Skill 负责。

```bash
bash skills/laohu-ai-visual/scripts/create_work_project.sh "作品名" [yyyy-mm-dd] [进行中|已完成|已发布] [--kind story|image|mv]
```

旧的三个位置参数继续有效，省略 `--kind` 时采用 `story`。明确的单张图和歌曲型作品分别用 `image`、`mv`。创建只建立入口，不证明已有剧本、设计、媒体或生成证据。

作品名不得为空、含路径分隔符 / 控制字符 / 首尾空白，或仅为 `.` / `..`；UTF-8 编码最多 244 字节，为日期前缀预留文件名空间。日期必须是真实有效的 `yyyy-mm-dd`。非法参数在写入前拒绝；已有同名作品不覆盖。

## 文件与真实进度

当前只维护本总览与 `00_阶段确认记录.md`。有实际产物时才创建阶段目录和对应的文本 / 图片 / 视频 / 音频子目录；需要首轮小样时再采用共享验证看板，需要真实结果复盘时才建立 `09_归档复盘.md`。目录不是预设待办清单，不用空文件证明阶段完成。

创建器已自动生成同名 HTML 与 `00_作品交付中心.html`；后续每次阶段主文件修改后重新运行 `scripts/render_delivery_html.py --project "当前作品路径"`。Markdown 是唯一正文源。

## 叙事作品分支

<!-- story -->
公开叙事作品先由 `laohu-director` 建立观众经历、主胜负手和部门取舍，再交 `laohu-script-writer` 完成完整E-S正式剧本。输入已有锁定导演阐述时直接继承；内部机械返工不重复调用导演。

路由：IDEA → 导演阐述 → 完整E-S正式剧本成立（STORY）→ 必要专业设计与最低可行资产（按事实进入 ASSET）→ `laohu-video-prompt` 将同场 E-S 组成 E-S-P → 基线验收 → 必经 `laohu-vibe-creating-prompt` 实际调用 → 视频 Skill 最终复验与巅峰门 → PROMPT。

普通叙事不另做一份独立文字分镜。只有强媒介知识动画、故事板图像 / 预视化，或老胡明确要求专业分镜资产时才启用 SHOT，并按需建立 `04_分镜/`。实际镜号由剧本确定，批次和时长由内容、目标入口能力与融合质量决定，不预填固定镜号、时长或小样数量。
<!-- /story -->

## 单张图片分支

<!-- image -->
由 `laohu-visual-assets` 的单张成品图分支确定观看目的、决定性瞬间和人物 / 物件—摄影机—环境关系，再交付可复制图片提示词与验收条件。需要原创人物、服装、场景或统一美术设计时，按最上游缺口会商对应专业负责人；公开作品的观众目的或跨部门取舍不清时会商 `laohu-director`。

单张图不强走故事、剧本、独立分镜或视频生产。只有确有跨请求复用需求时才建立稳定资产；提示词、文件夹和占位引用都不能登记为已生成。生产状态按真实成果与适用门槛记录，不为套用视频链补造中间阶段。
<!-- /image -->

## MV 分支

<!-- mv -->
先接收歌曲事实、歌词、创作背景与最终音频；`00_原始输入/音频/` 只是接收入口。最终音频及其时间证据尚未提供，不推测真实时长或逐句时间点。

由 `laohu-mv-director` 核验最终音频、建立歌曲—视觉结构、导演命题、声画关系与表演策略。导演结构成立才可记录 STORY；非叙事 MV 不强写故事，需要连续剧情时才交编剧补足因果，并保护已锁定歌词与音频。已有最终音频不重新生成。

必要设计和资产成立后，由 MV 导演按可靠时间证据组织制作时间线与动态分镜任务；需要独立分镜任务时进入 SHOT 并创建 `04_分镜/`。创作段落和生成单元分开，不被固定小样时长切碎；视频提示词通过基线、必经 VC 实际调用和最终复验后才进入 PROMPT。总导演仅在品牌、系列或跨作品约束未解决时补充裁决，不另建第二份歌曲导演终审。
<!-- /mv -->

## 按需触发的人工定案与外部动作

专业负责人先完成分析、候选和推荐，触发后再交老胡作具体取舍，不把空白问题提前抛回：

- 主要人物首次服装方向、关键身份换装与首次阵营衣橱，按服装 Skill 的人工定案门处理；已确认世界衣橱下的普通配角按对应专业规则处理。
- F 人物写真母图的人工选定，及强风格知识动画的 STY 风格选择与 VMB 视觉母板确认，按相应专业门处理；没有该对象的作品不增设这些关卡。
- 互斥核心事实、改变成本或风险的取舍、用户明确要求共创，或高成本 / 付费生成、公开发布、版权与真实商业声称涉及必要事实时，在对应动作前完成确认。

只有触发时才记录“待某项确认”，并给唯一页面 / 已展示候选与一个明确动作。确认后记录实际选择、证据位置和下游保护项。默认仍为文本交付；未经明确要求，不调用生成工具或发布账号。
<!-- /record -->
