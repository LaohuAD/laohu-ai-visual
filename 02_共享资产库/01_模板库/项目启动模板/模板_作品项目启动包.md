# 模板_作品项目启动包

> 用途：从一个创意开始，快速建立可迭代的影视作品项目，不再从 0 摸索。

## 一、项目基本信息

```text
项目名称：
创建日期：
作品体量：
目标平台：
目标模型：
画幅：
预计镜头数：
是否需要后期拼接：
是否需要旁白 / 台词 / 同期声 / 配乐：
```

## 二、故事启动卡

```text
一句话故事：
观众真正等待的问题：
主角 / POV 身份：
表层目标：
深层需求：
错误信念：
失败代价：
最后必须做出的选择：
不可删核心画面：
```

## 三、视觉启动卡

```text
世界观：
时间与地点：
角色外观统一规则：
服装统一规则：
场景统一规则：
色彩与影调：
画面质感：
镜头语言基准：
声音基准：
禁止方向：
```

## 四、阶段门控

```text
灵感
→ 沟通确定故事内容
→ 剧本结果输出文件
→ 资产图片提示词输出文件
→ 分镜表格输出文件
→ 第一个分镜视频提示词展示文件
→ 所有分镜视频提示词结果输出文件
→ 老胡制作完成后生成封面
→ 归档
```

每个阶段都要产出文件并通过内部质量门；普通创意默认继续进入下一阶段。只有互斥核心事实、高成本生成、真实发布、法律安全风险或老胡明确要求共创时才等待人工确认。

## 六、资产需求清单

| 资产类型 | 是否需要 | 用途 | 输出位置 |
|---|---|---|---|
| 原始口述需求 |  | 保留输入证据 | `00_原始输入/文本/` |
| 参考图 |  | 风格、角色、场景参考 | `00_原始输入/图片/` |
| 参考视频 |  | 运镜、节奏、质感参考 | `00_原始输入/视频/` |
| 参考音频 |  | 音乐、音效、旁白、同期声参考 | `00_原始输入/音频/` |
| 故事确认稿 |  | 确认方向，不混入正式剧本 | `01_世界观故事/文本/` |
| 世界观设定 |  | 固定世界规则 | `01_世界观故事/文本/` |
| 正式剧本 |  | 下游分镜和提示词来源 | `02_剧本/文本/` |
| 角色 / 场景 / 道具图 |  | 固定视觉资产 | `03_视觉资产/图片/` |
| 图片资产提示词 |  | 生成视觉资产 | `03_视觉资产/文本/` |
| 分镜表 |  | 拆镜头、定时长、定表情 | `04_分镜/文本/` |
| 分镜草图 / 参考视频 |  | 辅助镜头设计 | `04_分镜/图片/`、`04_分镜/视频/` |
| 视频提示词 |  | 生成视频 | `05_视频/文本/` |
| 生成视频 |  | 剪辑成片 | `05_视频/视频/` |
| 视频参考图 |  | 图生视频输入 | `05_视频/图片/` |
| 音频素材 |  | 配乐、音效、旁白、环境声、同期声 | `05_视频/音频/` |
| 封面图 |  | 发布传播 | `03_视觉资产/图片/` |
| 发布复盘 |  | 经验沉淀 | `09_归档复盘.md` |

## 七、结束前检查

- 原始输入是否进入 `00_原始输入/`。
- 故事确认是否进入 `01_世界观故事/文本/00_故事确认.md`。
- 正式剧本是否进入 `02_剧本/文本/`。
- 视觉资产是否进入 `03_视觉资产/`。
- 分镜是否进入 `04_分镜/`。
- 视频提示词和生成视频是否进入 `05_视频/`。
- 音频素材或参考音频是否进入对应阶段的 `音频/`。
- 复盘经验是否写入 `09_归档复盘.md`。
- 是否更新 `输入输出索引.md`。
