# 镜头语言词典

| 类型 | 用途 | 中文提示词写法 |
|---|---|---|
| 大远景 | 展示世界观和环境规模 | 展示整条街道和远处城市轮廓，人物只占画面很小一部分 |
| 全景 | 展示人物和环境关系 | 主体完整入画，能看到行动方向和周围环境 |
| 中景 | 展示身体动作 | 拍人物上半身、武器、骑乘动作和身体颠簸 |
| 近景 | 展示表情和局部动作 | 拍面部表情、手部动作、服装和材质细节 |
| 特写 | 展示关键道具或情绪 | 拍眼睛、嘴角、按钮、血迹、碎玻璃 |
| 固定镜头 | 稳定信息 | 固定机位，主体从远处进入画面 |
| 跟拍 | 追逐和行动 | 镜头跟随主体向前移动，主体保持清楚 |
| 推镜 | 强化情绪 | 镜头缓慢推进到人物面部或关键物体 |
| 拉镜 | 揭示环境 | 镜头从人物拉开，露出更大空间 |
| 手持 | 紧张和真实 | 手持跟拍，轻微晃动但主体保持清楚 |
