# 镜头语言词典

本词典服务分镜和视频提示词，不是为了堆专业词。每个术语都要落到四件事：画面来源是什么，和人物是什么关系，画面里看见什么，剪到下一镜时观众是否还能分清空间。

## 一、镜头语言第一判断

写 `【画面内容】` 前先判断：

```text
画面来源：画面来自某个人眼前所见、旁观者、贴近某人肩后、桌面 / 物件视角，还是被某个动作带着走。
观众站位 / 空间侧：画面从门内还是门外成立，从人物左侧还是右侧成立，从桌子哪一边成立，从车内前后排哪个位置成立。
镜头关系：主观镜头 / 客观镜头 / 过肩镜头 / 正反打 / 反应镜头 / 插入镜头 / 内打外 / 外打内。
画面层次：前景有什么，中景有什么，背景有什么；主体占画面多少。
视线与轴线：谁看谁，谁在画面左边或右边，动作从哪边往哪边走。
可见证据：观众凭什么知道这是这个人的视角、这个空间、这个情绪。
```

如果这些没有先定，提示词就会像“描述故事”，不是“导演拍画面”。模型会自己补画面来源和观众站位，结果容易变成第三人称、空间跳轴、角色互相看错方向或同一动作前后矛盾。

## 二、镜头语言四件套

镜头语言不是把专业词堆到提示词里，而是先用四个问题锁定观众最终看见的屏幕结果：

```text
景别：画面需要容纳多少信息，是空间关系、完整动作、人物互动、表情，还是局部证据？
机位：观众站在什么高度和方向看，情绪是日常、压迫、脆弱、庄重还是亲密？
运镜：镜头是否移动，移动从哪里开始、朝哪里去、经过什么、停在哪里？
光学质感：景深、焦段、前景虚化、光晕、胶片 / DV 质感如何服务情绪？
```

写正式视频提示词时，必须先做这四件套选择，再落到 `景别 / 构图`、`运镜` 和 `画面内容`。不要把 `大全景、低角度、环绕、浅景深、镜头光晕` 当成万能高级词；每个术语都要有镜头任务。如果解释不出这个术语解决什么画面问题，就不要写。

### 2.1 景别选择

| 景别 | 适合任务 | 正向写法 |
|---|---|---|
| 大全景 / 远景 | 建立环境、孤独感、规模、空间方向 | 大全景完整展示整片场景，环境占画面大部分，人物只占小比例，观众先看懂位置关系 |
| 全景 | 展示全身动作、走位、跪拜、奔跑、摔倒 | 全景里主体从头到脚完整入镜，能看清动作起点、路径和落点 |
| 中全景 | 展示膝盖以上动作，兼顾少量环境 | 中全景保留人物腿部方向和上身动作，背景给出门框、桌边或路口位置 |
| 中景 | 对话、递物、推拉、家庭生活动作 | 中景聚焦腰部以上和手部动作，能看清人物距离和物件交互 |
| 中近景 | 对话和轻微表情、肩膀和手部反应 | 中近景拍胸口以上，眼神、嘴角、下颌、肩膀和手部局部都清楚 |
| 近景 | 表情证据、手部证据、关键道具 | 近景让脸、手、碗、外套、木轮、硬币等关键细节成为画面中心 |
| 特写 / 极致特写 | 情绪爆点、局部物证、动作触发点 | 特写只保留眼睛、嘴角、指尖、针脚、火苗、硬币、布纹等单一重点 |
| 微距 / 大特写 | 材质纹路、金属划痕、水珠、纤维 | 微距让纹理和反光成为画面信息，背景大幅虚化，只服务强证据或强情绪 |

景别要和时长匹配。远景需要时间让观众看懂空间；特写需要时间让观众看清细节和情绪。一个镜头如果同时要空间、动作、表情和转场，通常要拆镜头或用清晰的景别变化，不要把所有任务塞进一个模糊中景。

### 2.2 机位角度选择

| 机位 | 情绪作用 | 使用规则 |
|---|---|---|
| 平视机位 | 日常、真实、客观、生活化 | 家庭对话、普通行动、温暖回忆优先用平视，避免无故戏剧化 |
| 轻度俯拍 / 高角度 | 脆弱、无助、被压住 | 孩子孤立、病床、空场、失去控制时使用；要写从哪里俯看和画面里谁变小 |
| 高空俯拍 / 鸟瞰 | 空间规模、命运感、结尾拉开 | 只在需要展示整体场景、村庄、院子、标题引出时使用；不要和严格 POV 混用 |
| 低角度 / 仰拍 | 成人压迫、仪式高度、英雄感 | 儿童看成人、孩子看遗像桌、庄重仪式可用；要说明被仰拍对象和压迫来源 |
| 45 度斜侧机位 | 人脸层次、空间立体、对话自然 | 常规人物对话、父亲沉默、奶奶忍哭等可用，写清人物朝向和光线侧向 |
| 正侧机位 | 轮廓、剪影、氛围、沉默 | 黄昏、门口等待、父亲侧影可用；不适合需要正向眼神交流的镜头 |
| 正反打 / 过肩 | 双人对话、冲突、关系变化 | 必须先定轴线、左右关系、谁的肩在前景、谁看向哪里 |
| 门缝 / 窗缝 / 车内机位 | 信息差、偷听、受限视角 | 必须写遮挡物、空间内外、可见范围和声音来源 |

严格 POV 不是机位高度词，而是画面来源。写 `小安第一人称 POV，画面呈现小安眼前所见` 后，机位角度要落到可见结果，例如儿童低视线看见柜台上沿、成人手从上方进入画面；不要写成 `镜头等同眼睛位置`。

### 2.3 运镜运动选择

| 运镜 | 适合任务 | 写法要求 |
|---|---|---|
| 固定镜头 / 静止镜头 | 安静叙事、庄重、让动作自己发生 | 写清画面固定在哪个对象或空间，主体如何在固定画面里变化 |
| 水平摇镜 Pan | 从一个对象转到另一个对象 | 写清左摇还是右摇、起点、经过物、停点 |
| 轨道横移 Dolly Left / Right | 展示空间关系或跟随横向移动 | 写清机身整体沿哪条线移动，和人物 / 桌沿 / 门框保持什么距离 |
| 推镜 Dolly In | 情绪压近、发现重点、压力增强 | 写清从什么景别推进到什么特写，最终停在哪个表情或物件 |
| 拉镜 Dolly Out | 揭示环境、孤独感、结尾开阔 | 写清从哪个局部拉开到什么环境，人物或道具在画面里如何变小 |
| 变焦 Zoom In | 主观注意、突发发现、轻微压缩感 | 少用；要写光学变焦拉近哪个对象，以及空间压缩带来的情绪 |
| 升镜 Crane Up | 结尾、空间揭示、情绪释开 | 写清从哪个前景升起，升到什么高度，最后看见哪些空间关系 |
| 降镜 Crane Down | 从环境落到人物或证据 | 写清从高处降到哪个人物 / 道具 / 地面细节 |
| 环绕 / 半环绕 Orbit | 仪式感、关系变化、梦感 | 写清围绕谁或什么物体，转动角度、速度、主体是否始终清楚 |
| 跟拍 Tracking | 行走、奔跑、追逐、儿童身体感 | 写清跟谁、从哪个方向跟、屏幕方向和路径边界 |
| 肩扛手持 | 纪实、紧张、失控、儿童 POV 颠簸 | 写轻微自然抖动，主体仍保持清楚，不要让画面完全失控 |
| 稳定器跟拍 | 平稳商业质感、顺滑运动 | 写丝滑平稳、无明显抖动，适合城市、人物走位和氛围镜头 |
| 甩镜 / 快速转向 | 突发消息、惊吓、突然回头 | 写触发声音、甩向哪里、落点是什么，落点必须清楚 |
| 旋转 Spin | 眩晕、失控、迷离 | 少用；必须说明旋转速度和情绪目的，避免无意义炫技 |

运镜只写镜头如何动。人物推门、递衣服、点火、劈柴、包汤圆、叩首是画面动作，不是运镜。每个运镜都要写路径、方向、速度和停点；`镜头移动`、`镜头切换`、`镜头转场` 这类空泛词不能单独使用。

### 2.3.1 专业运镜术语扩展

专业运镜术语先按物理机制分类，再决定是否写进正式提示词。术语本身不产生高级感，真正起作用的是路径、方向、速度、停点、主体关系和情绪任务。

```text
机身整体移动：Dolly / Track / Tracking Dolly / Crane / Jib / Steadicam / Gimbal / Orbit / Arc / Match Move。
镜头原地转动：Pan / Tilt / Whip Pan / Snap Pan / Head Pan POV / Down Tilt POV / Up Tilt POV。
光学焦段变化：Zoom In / Zoom Out / Vertigo Shot。
手持稳定方式：Handheld / Bumpy Handheld / Breathing Shake / Soft Stabilize。
创意特效运动：Long Take / Pass Through / Digital Dolly Through / Time-lapse Dolly / Creep Dolly / Spiral Dolly / Falling Dolly / Ascend & Dive。
```

常用术语写法：

| 术语 | 正确用途 | 提示词写法 |
|---|---|---|
| 推镜 Dolly In / Track In | 情绪压近、注意力集中 | 轨道匀速向前推镜，从中景缓慢推进到人物手部或面部，空间缓慢收缩，最终停在核心表情 / 道具上 |
| 拉镜 Dolly Out / Track Out | 揭示环境、孤独、疏离 | 镜头从局部细节向后拉开，人物或道具逐渐变小，周围空间关系逐步完整出现 |
| 横摇 Pan / Slow Pan / Snap Pan | 原地左右转向，模拟看向另一侧 | 机位不动，镜头从左向右缓慢横摇，经过门框和桌边，停在说话人脸上；急摇必须写触发声音和清楚落点 |
| 俯仰摇 Tilt | 原地上下转动，低头 / 抬头看 | 机位不动，镜头向下俯仰摇到手部和地面；或镜头向上抬到成人下巴、遗像、楼梯顶端 |
| 希区柯克变焦 / Vertigo Shot | 窒息、恐慌、崩溃、压迫 | 希区柯克眩晕变焦，机身向前推进，同时光学变焦拉远，主体大小基本保持不变，背景空间拉伸畸变，压迫感增强 |
| 环绕 Orbit Shot | 仪式、浪漫、关系变化 | 镜头以人物或物件为圆心做 180 度半环绕或慢速 360 度环绕，主体始终清楚，背景光影随角度变化 |
| 弧轨 Arc Shot | 柔和曲线移动，比完整环绕克制 | 镜头沿人物前方弧线小幅移动，从正前方滑到 45 度斜侧，停在更有层次的侧脸 / 手部关系上 |
| 一镜到底 Long Take | 连贯行动、空间调度 | 完整一镜到底长镜头，全程无剪辑，镜头跟随人物穿过空间，路径、转向和停点连续清楚 |
| 匹配运镜 Match Move | 镜头速度和物体运动同步 | 镜头移动速度与奔跑人物 / 滑行木车 / 递物动作同步，主体保持清楚，背景产生稳定位移 |
| 穿越镜头 Pass Through | 穿过前景遮挡、进入新空间 | 镜头缓慢穿过门框、纱帘、树叶、花枝或人群缝隙，前景短暂虚化扫过镜头，再落到清楚主体 |
| 穿墙 / 穿镜 Digital Dolly Through | 虚拟空间跳转 | 镜头穿透墙面、镜面或玻璃进入另一空间；只在奇幻、梦境、广告或明确特效段使用 |
| Crane Shot | 大幅高低升降、空间揭示 | 大型电影摇臂缓慢升镜，从近处人物 / 物件升到院子或山谷全貌；降镜则从高处压回人物或证据 |
| Jib Shot | 小幅近距离升降 | 小型摇臂轻微升起或下降，围绕桌边、床边、门口人物做克制高度变化 |
| Tracking Dolly | 轨道直线移动 | 地面轨道平稳前推、后拉或横移，零抖动，适合商业质感和需要空间关系稳定的镜头 |
| Steadicam / Gimbal | 平稳长距离跟拍 | 稳定器跟拍人物行走，画面顺滑，保留少量真实身体感但没有明显颠簸 |
| Handheld Shot | 纪实、生活、临场 | 肩扛手持，轻微自然低频抖动，主体保持清楚，适合家庭纪实和冲突现场 |
| Bumpy Handheld | 追逐、慌乱、失控 | 大幅不规则手持晃动，必须写清镜头落点和主体重新入画方式 |
| Breathing Shake | 安静伤感、身体感 | 极轻微上下起伏，像平稳呼吸，适合 POV、病床、沉默等待 |
| Soft Stabilize | 真实但不晃眼 | 轻微缓震，保留生活感，同时控制画面可读性 |
| Time-lapse Dolly | 时间流动、城市 / 天空变化 | 慢速轨道移动配合延时，云、车流或人群快速流动，镜头缓慢滑行 |
| Creep Dolly | 极慢推拉、压抑或凝视 | 极缓慢蠕动式推镜或拉镜，速度很低，观众几乎感觉不到但情绪逐渐压近 |
| Whip Pan | 快切转场、突然反应 | 急速甩镜，画面出现短暂模糊拖影，必须从触发点甩到明确落点 |
| Spiral Dolly | 迷幻、梦境、广告感 | 镜头一边环绕一边缓慢上升或下降，螺旋轨迹必须服务梦幻 / 失控情绪 |
| Falling Dolly | 坠落、冲击、失重 | 镜头快速垂直下坠，落到地面、火盆、河面或人物脚边，冲击感强 |
| Ascend & Dive | 航拍大场面 | 航拍先升空俯瞰，再快速俯冲贴近地面或主体，只用于空间尺度明确的场景 |
| Head Pan POV | 第一人称左右环顾 | POV 主观镜头模拟人左右转头，画面从门口扫到窗边或路口，停点清楚 |
| Down Tilt POV | 第一人称低头看 | POV 镜头向下低头看手部、地面、蒲团、书包、碗或方向盘 |
| Up Tilt POV | 第一人称抬头看 | POV 镜头缓慢抬头看成人、遗像桌、楼梯、高楼、天空或树冠 |

区分规则：

```text
Dolly / Track 是机身整体移动；Pan / Tilt 是机身不动、镜头原地转动。
Zoom 是焦段变化；Dolly 是空间位置变化。
希区柯克变焦不是普通推拉，必须同时写“机身推进 + 光学变焦拉远”，并写主体大小基本不变、背景拉伸畸变。
Crane 是大幅度高低升降；Jib 是小幅近距离升降。
Orbit 是绕主体成圆或半圆；Arc 是弧形小范围移动。
Handheld 要写抖动强度；Bumpy Handheld 必须写落点；Breathing Shake 是极轻微呼吸起伏。
```

本项目家庭纪实、90 年代老式 DV 质感和亲情故事，默认优先固定镜头、轻微手持、呼吸抖动、慢推、慢拉、低幅度 Tilt / Pan。希区柯克变焦、螺旋、穿墙、下坠、升空俯冲等强特效运镜只能用于明确的恐慌、梦境、广告化、奇幻或强主观崩溃段；使用时必须说明为什么这个镜头需要它。

### 2.4 光学质感选择

| 光学 / 质感 | 作用 | 使用规则 |
|---|---|---|
| 浅景深 | 突出主体、虚化背景、情绪亲密 | 写主体清晰、背景柔和虚化，适合表情、手部、道具特写 |
| 深景深 | 空间关系、群像、风景、仪式 | 前景到背景都清楚，适合院子、饭桌、放学路、场景资产一致性 |
| 前景虚化 / 遮挡 | 增加层次、信息差、记忆感 | 写树枝、门框、肩背、被沿、孝布、火光等遮挡在前景什么位置 |
| 镜头光晕 Lens Flare | 逆光、夕阳、怀旧暖意 | 写光源方向和落到哪里，不能无光源硬加光晕 |
| 胶片 / 16mm / 35mm / 老式 DV | 年代、记忆、材质统一 | 《不想长大》优先 90 年代老式 DV 质感、暖黄配色、轻微频闪噪点、自然光 |
| 电影宽幅 | 史诗、庄重、院线感 | 只有需要电影感和宽幅构图时使用；短剧家用 DV 不要无故写 2.39:1 |
| 鱼眼镜头 | 夸张、变形、特殊主观 | 极少用；会强烈改变现实感，生活纪实镜头默认不用 |
| 微距景深 | 极近物件证据 | 硬币划痕、糯米皮纹理、蒲团粗布纤维、火柴火苗可用 |

光学质感必须和故事介质统一。温馨家庭回忆可以有 DV 噪点、自然光、轻微频闪和暖黄；不要突然切成现代广告级高反差商业质感，除非本镜明确是另一种影像层。

### 2.5 情绪匹配

```text
温暖治愈：平视 / 轻微慢推 / 慢拉，浅景深或中等景深，柔和自然光，前景轻遮挡，动作节奏慢。
宏大震撼：远景 / 大全景 / 仰拍 / 升镜 / 深景深，先给近景锚点再拉开环境。
压抑孤独：高角度 / 缓慢拉远 / 空旷构图 / 冷灰或低饱和，人物在环境中变小。
紧张冲突：手持轻抖 / 快速推近 / 甩镜 / 正反打特写，动作路径和受力点必须清楚。
浪漫氛围：半环绕 / 前景虚化 / 逆光光晕 / 慢动作，但不能遮住主体动作。
严肃庄重：固定机位 / 平视或轻仰视 / 深景深 / 少运镜，声音和动作停顿承担重量。
```

情绪匹配不是硬套公式。先判断镜头任务，再选景别、机位、运镜和光学组合。比如丧事叩首镜头更适合固定、下压、遮挡转场和冷灰白布；不适合 360 度环绕和浪漫散景。父亲点纸房打不燃火，更适合固定或轻微手持、火苗特写、风吹纸飘带和手指颤动，不适合无理由航拍。

## 三、视频提示词分层公式

通用 AI 视频公式可以作为内部写作顺序使用，但不能把这些层级当成正式字段塞进模型正文。正式视频提示词仍只保留 `【基础设定】`、`【氛围与画质】`、`【画面内容】` 三块；分层公式的作用，是保证三块里的内容不缺摄影、主体、空间、光影、光学和输出规格。

内部标准顺序：

```text
镜头语言层 → 主体叙事层 → 环境布景层 → 光影色彩层 → 镜头光学质感 → 画幅帧率画质
```

各层职责：

```text
镜头语言层：景别、机位角度、运镜方式、镜头动态速度、确定时长。
主体叙事层：人物 / 生物 / 物体、外貌穿搭、动作、神态、细微情绪。
环境布景层：地点、空间结构、陈设、道具、前景遮挡、中景动作、远景背景。
光影色彩层：光源方向、光线软硬、主色调、冷暖关系、光晕、丁达尔、阴影层次。
镜头光学质感：焦段、人眼等效 / 广角 / 定焦、景深、散景、暗角、颗粒、畸变控制、胶片 / DV 介质。
画幅帧率画质：横屏 / 竖屏、16:9 / 9:16 / 2.39:1、分辨率、帧率、稳定度、细节清晰度。
```

落入项目三段结构时：

```text
【基础设定】负责世界观、资产和声音总规则。
【氛围与画质】承接风格核心、视觉基调、色彩与影调，主要容纳光影色彩、光学质感、画幅帧率和全片介质。
【画面内容】承接镜头语言层、主体叙事层、环境布景层，以及本镜局部光影、动作、声音和转场。
```

四套梯度公式只作为内部选择，不改变正式三段模板。短视频 / 卡点 / 10 秒内日常镜头用极简快速公式：`景别 + 机位 + 运镜 + 主体画面 + 光影氛围 + 画质规格`。商用短片 / 剧情短片用标准专业公式：`镜头语言层 + 主体叙事层 + 环境布景层 + 光影色彩层 + 镜头光学质感 + 画幅帧率画质`。长剧情 / 微电影 / 高质量封面短片用电影分镜完整版，在标准公式上补 `节奏情绪层` 和 `特殊效果层`，例如慢镜头、升格、纪实、梦幻、水雾、残影、旋转模糊。歌词 MV、氛围空镜和氛围人像用高级氛围感极简公式：`运镜动态 + 景别机位 + 氛围主体 + 前景 / 中景 / 远景环境层次 + 逆光 / 丁达尔光影 + 虚化散景 + 胶片 / DV 电影质感`。

所有梯度公式都要服务镜头任务。极简不是省掉动作因果，电影完整版不是堆特殊效果，高级氛围感也不是只写光斑和胶片；它必须写清前景、中景、远景分别是什么，光从哪里来，主体如何被环境包住，镜头最后停在哪里。

外部通用公式常把“负面规避词”放在结尾。本项目不把它作为正式模型正文的固定层。正式代码块优先正向写清目标画面；必要边界只写抽象质量问题，例如动作逻辑、比例、文字水印、严重畸变。具体不该出现的人物、道具、剧情物和跑偏风险，放在提示词外自检、失败经验或回传字段里。

常见错误：

```text
只写主体漂亮，不写镜头语言，模型会自己补机位。
只写镜头高级，不写主体动作，画面会像空的设定图。
只写环境氛围，不写前景 / 中景 / 远景，空间会散。
只写柔光 / 逆光，不写光源方向和落点，光影会随机。
只写 4K / 60 帧 / 电影质感，不写焦段、景深和介质，画质词会变成空话。
把负面词当正文重点，反而把不该出现的对象召回到画面里。
```

## 四、摄影机关系

| 类型 | 用途 | 提示词写法 |
|---|---|---|
| 客观旁观镜头 | 让观众在旁边看见人物和环境 | 摄影机在床边低处旁观，小安坐在床沿，父亲站在门口，人物完整或半身入画 |
| 主观镜头 / 严格第一人称 | 让观众看见某个角色当下所见 | 小安第一人称 POV，画面呈现小安眼前所见，前景是被窝边、小手、睡衣袖口，中景是父亲腿部和外套下摆，背景是门框和清晨窗光 |
| 近主观镜头 | 贴近角色视线，但仍能看到该角色局部侧影或肩背 | 摄影机贴在小安右肩后，画面左下角有小安肩背和后脑边缘，前方是父亲递来的外套 |
| 过肩镜头 OTS | 对话、压迫、遮挡信息 | 父亲肩膀和后颈虚化占前景左侧，小安在中景右侧抬头说话，镜头保持在父亲肩后 |
| 正反打 | 两人对话和情绪来回 | 先拍小安看父亲，再反打父亲看小安；两人保持同一左右关系和视线方向 |
| 反应镜头 | 让观众确认信息对人物造成了什么影响 | 村民说完后切到姐姐听见的反应：肩膀一僵、书包滑落、转身跑开 |
| 插入镜头 | 强调道具、手部、证据或记忆触发物 | 插入公共座机听筒和卷曲电话线、奶奶针脚、硬币落进汤圆、木轮转动 |
| 视线所见镜头 | 角色看向某物后，切到他看到的东西 | 小安抬头看门口，下一镜切到父亲拿外套站在门框里 |
| 内打外 | 摄影机在屋内 / 车内 / 门内向外看 | 从被窝或屋内看向门口，门外冷光和父亲局部进入画面 |
| 外打内 | 摄影机在门外 / 窗外向室内看 | 从院门外看进堂屋，白布和香火在屋内深处，门框形成遮挡 |
| 内反打 | 在同一空间内部，从对面方向反拍 | 饭桌这边拍奶奶手包汤圆，再从奶奶侧反拍小安趴在桌边看 |
| 正内打 / 正外打 | 正面朝向内侧或外侧拍空间关系 | 正内打是从门口正面拍进屋内；正外打是从屋里正面拍向门外或院外 |

## 五、景别

| 类型 | 用途 | 中文提示词写法 |
|---|---|---|
| 大远景 | 展示世界观和环境规模 | 展示整条街道、院子全貌或远处城市轮廓，人物只占画面很小一部分 |
| 远景 | 建立空间和人物位置 | 人物完整入画，能看清人物和院门、桌子、床、灶台的位置关系 |
| 全景 | 展示人物全身动作 | 主体完整入画，能看到走位、推拉、坐下、跪拜、奔跑方向 |
| 中景 | 展示身体动作和关系 | 拍人物腰部以上、手部动作、递物、阻拦、父子距离 |
| 中近景 | 对话和轻表情 | 拍胸口以上，能看到眼神、嘴角、手部局部和身体距离 |
| 近景 | 展示表情和局部动作 | 拍面部、手部、袖口、碗、外套、木轮、硬币等关键细节 |
| 特写 | 强化道具或情绪证据 | 拍眼睛、嘴角、针脚、硬币、药碗、打火机、木轮 |
| 大特写 | 极强情绪或物件触发 | 只拍眼眶水光、指尖发抖、火苗被风吹灭、硬币被汤圆皮包住 |

## 六、角度

| 角度 | 心理效果 | 用法 |
|---|---|---|
| 平视 | 稳定、日常、真实 | 普通对话、饭桌、家庭生活 |
| 低角度 / 仰拍 | 压迫、权力、高大 | 小安看父亲、孩子看成人、仪式里的遗像桌 |
| 高角度 / 俯拍 | 脆弱、被控制、孤立 | 旁观孩子摔倒、院子空场、结尾拉高 |
| 贴地低机位 | 儿童、奔跑、物件尺度 | 木马车轮、孩子鞋尖、门槛、地面纸灰 |
| 桌面视角 | 手工、食物、仪式细节 | 包汤圆、硬币、碗筷、药碗和手部关系 |
| 门缝 / 窗缝视角 | 信息差、偷听、遮挡 | 医生画外音、孩子隔门听大人说话 |

## 七、构图层次

正式提示词不要只写“近景”“中景”，要写画面三层：

```text
前景：离镜头最近的遮挡、手、袖口、门框、桌边、被窝、肩膀。
中景：本镜核心动作发生处，人物手、脸、道具、对话对象。
背景：空间证据，门、窗、院墙、灶火、遗像桌、车窗外道路。
```

示例：

```text
前景是小安的被窝边缘、浅色睡衣袖口和揉眼的小手；中景是父亲裤腿、外套下摆和递到床边的手；背景是门框、书桌虚影和窗帘缝里的清晨光。
```

这样写的作用是把模型的注意力固定在“画面里应该出现什么”，而不是用一串否定词让模型猜。

## 八、正反打与轴线

正反打的核心是空间连续，不是简单地“拍 A 再拍 B”。

规则：

```text
先确定两人之间的轴线，例如小安在画面右侧、父亲在画面左侧。
同一段对话的镜头保持在轴线同一侧。
反打时两人的视线方向相对：A 看向画面左，B 看向画面右。
如果必须越轴，先用主观镜头、全景重新建立空间、人物移动或遮挡转场过渡。
```

正反打写法：

```text
过肩正打：父亲肩背虚化占画面左前景，小安在右中景抬头说话，视线朝画面左上方。
反打：小安肩膀和头发边缘虚化占画面右前景，父亲在左中景低头看他，视线朝画面右下方。
```

如果提示词只写“两人正反打对话”，模型可能让两个人都看向同一边，观众会感觉他们没有在对话。

## 九、主观镜头写法

所有镜头的 `画面内容` 都要先当成“观众眼前的镜头结果”来写。镜头语言不是术语标签，而是屏幕结果：写第三人称旁观结果，观众就看见第三人称；写第一人称眼前结果，观众才看见第一人称；写正反打、过肩、插入或空镜，也必须写清对应镜头里的前景、中景、背景、视线方向、动作方向和声音来源。

### POV 专项公式

严格 POV 的核心不是“低机位”，而是 `画面 = 视点主体肉眼看到的结果`。正式提示词里可以把 POV 作为开头强标识，但后面必须继续写出前景身体锚点、手持质感、头部 / 视线运动、眼前主体场景、光影和人眼光学质感。

项目标准公式：

```text
具体人物第一人称 POV，画面呈现具体人物眼前所见
+ 手持质感 / 身体感
+ 前景身体或道具锚点
+ 视线高度 / 低头 / 抬头 / 平视关系
+ 头部或视线运动
+ 眼前主体场景和动作
+ 环境氛围与光影
+ 人眼等效焦段 / 景深 / 画幅 / 画质介质
```

这个公式里的 `具体人物` 必须是资产或确定生产命名，例如 `小安第一人称 POV`、`父亲第一人称 POV`、`男主第一人称 POV`，不能只写 `儿童 POV`、`孩子视角`、`人眼视角`。类别词可以补在后面，例如 `小安第一人称 POV，儿童身高低视线`。

POV 前景锚点是区分主观镜头和普通低机位的关键。优先写画面下方的小手、袖口、手腕、膝盖、鞋尖、胸前衣料、握住的道具、方向盘、门框边缘、柜台上沿、伞柄、书包带、被沿、眼镜边框、手机框或其他贴近视点主体的局部。没有前景身体 / 道具锚点的纯空镜 POV，很容易被模型生成成普通客观空镜。

POV 手持质感必须按情绪控制：

```text
治愈日常：轻微自然手持微抖，呼吸带来极小晃动，主体始终清楚。
电影干净质感：平稳第一视角，无多余抖动，只有必要的头部转动。
紧张 / 追逐 / 突发：短促颠簸或剧烈手持晃动，但要写清落点，不能让画面完全失控。
儿童 POV：低视线、短步伐轻晃、抬头看成人时画面上扬，前景小手和袖口帮助证明身体尺度。
病弱 / 疲惫 POV：呼吸慢、画面轻微浮动、焦点短暂虚一下，声音从镜头后方弱弱传来。
```

POV 头部 / 视线运动必须写成眼前画面变化：低头看下方蒲团纹理、抬头看遗像桌、缓慢转向门口、向左环顾街边、被人推一下导致画面轻晃、伸手向前触碰物件、缓步向前使地面和前方主体靠近。不要写 `小安转头 / 小安抬头 / 小安停住` 作为外部动作摘要，要写 `镜头从门框甩向窗边并停住`、`画面缓慢抬到父亲下巴和手里的外套`、`两只小手伸向画面前方`。

POV 光学质感优先贴近人眼，不追求炫技。普通叙事可以写 `35mm 或 50mm 人眼等效镜头，中等景深`；道具特写和情绪证据可以短暂浅景深；车内、街道、房间空间关系需要更广一点时可以写准广角，但要控制边缘畸变。生活纪实和童年回忆默认避免鱼眼、强变形和无理由超广角。

外部公式里常见的“负面词收尾”在本项目不作为正式模型正文模板。正式代码块优先写正向画面；如果确实需要边界，只写抽象质量边界，例如画面比例、动作逻辑、文字水印、夸张畸变。具体跑偏对象、风险和不该出现的剧情物，放到提示词外自检或失败经验里。

通用判断：

```text
画面来源是什么？
观众最终能看见什么？
画面主语应该是人物整体、身体局部、遮挡物、道具、光线、空间，还是声音来源？
这句话是在描述屏幕结果，还是在替作者解释剧情？
```

错误写法是把剧情摘要当画面内容：`父亲责备孩子`、`两人争执`、`主角听到后震惊`、`小安看向门口`。正确写法是把它转成镜头结果：`父亲深色肩背压在左前景，下颌绷紧，声音从画面上方压下来`；`孩子眼前的书包带晃动，手指停在拉链上`；`画面忽然静住，碗沿反光不再晃动`；`视线从被沿上方抬到门口外套下摆和父亲递来的手`。

严格 POV 推荐先建立“画面呈现视点主体眼前所见”的画面来源声明：

```text
小安第一人称 POV，画面呈现小安眼前所见，视线高度约 6-7 岁儿童低视线。
男主第一人称 POV，画面呈现男主趴桌时看见的低位桌面、前排背影和试卷靠近过程。
```

这类角色名是在定义画面来源，不是让角色本人入画。不要写 `镜头等同小安眼睛位置`、`摄影机绑定在小安眼睛位置`、`机位高度等同男主趴桌视点`，因为这些是物理摆位，不是屏幕结果。来源声明建立后，剧情动作要继续翻译成画面结果：肩膀被推则画面轻微摇晃，趴桌呼吸则低位画面微抖，试卷放到桌面则纸张靠近画面、油印字逐渐清晰，叹气从画面后方响起。

POV 互动视线检查：

```text
如果角色正在和 POV 主体说话、递物、牵手、摸头、整理衣服、安慰或责备，
必须写清角色看向镜头、朝镜头低头、手伸向镜头前方、物件递到镜头前或身体压近镜头。
```

错误：`奶奶蹲低摸袖口`、`爷爷笑着说小安来喽`、`父亲递外套`。
正确：`奶奶蹲到镜头高度，眼睛看向镜头，手伸到画面前方摸袖口`、`爷爷视线对准镜头，朝镜头笑着招呼`、`父亲把外套递到镜头前方，外套边缘压近画面`。

主观镜头要写“角色看见什么”，不是写“别拍到什么”。

结构：

```text
某角色第一人称 POV，画面呈现某角色眼前所见。
画面主语优先使用眼前、画面、视线、光、被沿、小手、袖口、门框、外套、成人局部和声音来源。
前景写眼前能看见的身体局部或遮挡物。
中景写正在进入视线的对象、动作或成人局部。
背景写空间证据和声音来源。
镜头运动写成视线抬起、低头、回头、被拉动、跟随呼吸晃动。
```

小安床上 POV 示例：

```text
小安第一人称 POV，画面呈现小安刚醒时眼前所见。眼前先是朦胧的天花板和被窝边缘，两只穿浅色睡衣袖口的小手从画面下方伸出，揉过画面边缘，画面短暂虚焦；被沿被拉高后遮住画面下半部，门口冷光从被沿上方照进来，父亲的裤腿、手、外套下摆和递来的外套进入画面。视线从被窝缝隙慢慢抬到门口父亲局部，再落回床边外套。
```

视点主体语法检查：

通用规则：凡是第一人称、主观视角、某人所见，画面内容都不能把视点主体当成被拍对象，也不能用“某人眼睛位置”替代“某人眼前所见的画面结果”。视点主体可以是任何人或生物，不只是一名儿童。

错误写法：`视点主体 + 躲 / 看 / 听到 / 停住 / 皱眉 / 转头 / 站起来 / 表情怎样`。例如 `小安躲在被子后面`、`父亲看见门口的人后皱眉`、`主角听到声音后停住`、`你转头看向窗外`。

正确写法：把主体动作改成眼前画面变化和感官结果，例如 `被沿被拉高，外界声音变闷`、`画面突然停住，呼吸声断半拍`、`视线停在父亲胸口、下巴和手里的外套上`、`画面从门框甩向窗边并停住`。

当前案例：小安床上 POV 中，错误是写“小安躲在被子后面”；正确是写“眼前被沿被两只小手拉高，棉被遮住画面下半部，门口冷光从被沿上方照进来”。

## 十、运镜

| 运镜 | 用途 | 写法 |
|---|---|---|
| 固定镜头 | 稳定信息和情绪 | 画面保持小安眼前所见，呼吸让被沿和门口局部轻微晃动 |
| 推镜 | 情绪压近、发现重点 | 镜头从桌边缓慢推进到奶奶发红的眼睛和发抖的手 |
| 拉镜 | 揭示更大环境 | 镜头从木轮特写随纸灰拉高，露出整个院子 |
| 摇镜 | 从一个对象转到另一个对象 | 镜头从爷爷药碗慢慢摇到坏木轮 |
| 横移 | 展示空间和人物关系 | 镜头沿饭桌边慢慢横移，依次经过姐姐、爷爷、父亲 |
| 跟拍 | 追随动作主体 | 镜头贴着小安低视线跟随姐姐背影奔跑 |
| 手持 | 紧张、临场、孩子身体感 | 轻微手持晃动，主体保持清楚，跑动时短促颠簸 |
| 环绕 | 关系变化或仪式感 | 围绕纸扎房子和火光慢半圈，保持父亲背影在画面边缘 |
| 甩镜 | 突发转向和惊吓 | 听见叫声后快速甩向门口，落点要清楚 |

运镜只写摄影机怎么动。人物开门、推车、递外套、点火、叩首是画面动作，不是运镜。

## 十一、常见错误

- 把 `儿童 POV` 写成泛称，没有绑定具体人物资产。
- 只写“第一人称”，但画面内容仍在描述第三人称能看见的脸、背影和全身。
- 写“正反打”但没有轴线、左右关系和视线方向。
- 写“过肩”但没有说明谁的肩在前景、谁在中景、谁看向哪里。
- 写“内打外 / 外打内”但没有先定义门、窗、车门、桌子是哪一侧。
- 只写动作结果，不写动作从哪边开始、哪只手先动、道具如何承重和移动。
- 用否定词堆边界，却没有写出前景、中景、背景应该出现什么。
- 把大全景、浅景深、环绕、镜头光晕等专业词当万能高级词，没有说明它们服务的镜头任务。
- 运镜没有路径、方向、速度和停点，只写 `镜头移动`、`镜头切换`、`氛围感运镜`。
- 光学质感和故事介质冲突，例如温馨 90 年代家用 DV 回忆突然写成现代广告级商业稳定器大片。
