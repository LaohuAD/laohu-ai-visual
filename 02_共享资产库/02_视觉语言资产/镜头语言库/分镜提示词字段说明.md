# 分镜提示词字段说明

## 字段结构

```text
分镜编号：
时间段：
景别：
镜头关系：
轴线与视线：
构图：
运镜手法：
画面内容：
声音：
后期备注：
```

## 构图使用原则

需要稳定关系时写构图。

需要动作自然时少写构图。

写构图前先确定镜头关系。镜头关系回答“摄影机站在哪里、观众通过谁看、谁在前景和中景”。常用关系包括主观镜头、客观旁观、近主观、过肩、正反打、反应镜头、插入镜头、视线所见、内打外、外打内和内反打。

正反打和过肩镜头必须写轴线与视线：谁在画面左侧，谁在画面右侧，谁看向画面哪边，谁的肩背或门框形成前景遮挡。只写“正反打”不够，必须让下一步视频提示词能直接转成可见画面。

动作镜头可以写：

```text
主体大致保持在画面中心附近，优先保证动作自然和速度感，不要求严格对称构图。
```

## 运镜使用原则

一个镜头最好只写一种主运镜。

不要为了显得专业堆“推拉摇移跟”。
