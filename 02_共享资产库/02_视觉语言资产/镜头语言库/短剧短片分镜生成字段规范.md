# 短剧短片分镜生成字段规范

> 来源：结合本项目四份研究文档与 EvoMap 搜索到的 `AI Short Drama Shot List Generator`、`Screenwriting & Cinematography Fundamentals`、`seedance-story-orchestrator` 方向沉淀。  
> 用途：把剧本或梗概拆成可生成、可诊断、可剪辑的镜头清单。

## 一、适用范围

适用于：

- 15-60 秒强视觉短视频。
- 1-3 分钟概念短片。
- 3-5 分钟短剧小样。
- 3-10 分钟叙事短片。

不适用于一次性写完整 50-100 集短剧。长项目必须先做单集样片验证。

## 一点五、导演镜头构思

填写分镜字段之前，先把剧本的剧情意图翻译成可拍方案。分镜不是给 `女侠御敌、孩子伤心、两人争吵` 补一个常见景别，而是从同一剧情事实中选择最有表现力的决定性瞬间。

模糊段落先内部生成 3-5 个镜头构思候选，每个候选回答：

```text
剧情任务：这一镜必须完成什么，哪些剧情事实不可改变。
事件节拍：压力、刺激或信息怎样进入画面。
决定性瞬间：拍动作的蓄势、接触、受力、反应、结果，还是关系变化的哪一拍。
动作与调度几何：人物、视线、手、武器、道具和环境形成什么方向、距离与遮挡。
摄影机观看位置：摄影机在谁的哪一侧、什么高度、什么俯仰和倾斜关系，主体如何随透视变化。
画内证据：观众凭什么知道敌人、危险、谎言、失去、保护或关系压力真实存在。
光影落点：哪一个眼神、动作接触点、道具或空间关系需要被照亮。
生成可行性：当前资产、模型时长和动作复杂度能否稳定完成。
```

候选必须在事件瞬间、动作线、调度、机位、证据或光影落点上真正不同。只换地点、天气、滤镜或焦段，不算完成镜头构思。选定方案后才填写分镜表。若所有候选去掉服装、颜色、材质和滤镜后都只是普通站姿或常见正面中景，退回重构。

分镜必须继承剧本已经写明的人物胜负、伤势、关系结果、关键道具状态和不可逆事件；剧本没有写明的动作相位、局部结果、机位、构图、前景证据、声音和光影落点属于创意留白，可由分镜主动决定并写入交接包，供后续继续继承。

## 一点六、观众状态变化与视角编译

分镜先从剧本的 `观众认知状态` 中选择本镜真正要改变的一项或少数几项，再选择景别、机位和切镜。内部至少回答：

```text
进入本镜时观众知道 / 暂信 / 正在问 / 预测什么。
观众第一眼看哪里，靠构图、运动、焦点、光色还是声音建立。
本镜新增、纠正、推翻、加压或兑现了什么。
叙事视角、信息视角和价值视角是否继续稳定。
本镜采用什么光学视点；为什么不是另一个位置。
离开本镜时，哪个动作、视线、声音、遮挡、形状、焦点或运动方向负责切镜后的注意力承接。
```

叙事视角不等于光学视点。主角聚焦的故事可以用客观远景建立空间，也可以用对手过肩表现主角承压；但信息释放、价值站位和情绪对齐必须是有意选择。连续镜头如果没有改变任何相关观众状态，只是换了相近景别或重复同一信息，应合并或删除。

## 二、分镜字段

| 字段 | 说明 |
|---|---|
| 镜头编号 | `E1-S1-C1` 这类集 / 场 / 镜头稳定编号，便于追踪生成结果 |
| 所属场次 | 对应剧本场次或段落 |
| 镜头任务 | 这个镜头在故事里完成什么，不写空泛氛围 |
| 观众状态变化 | 本镜改变已知 / 暂信 / 问题 / 预测 / 第一注意力 / 主情绪中的哪一项；无变化时说明为何仍需保留 |
| 视角分层 | 叙事视角 / 信息视角 / 价值视角的继承或变化，以及本镜实际光学视点 |
| 注意力承接 | 上一镜怎样把眼睛 / 耳朵带进本镜；本镜视线从哪里进入、被什么引导 / 减速、落到哪个决定性信息、从哪里交给下一镜 |
| 时长 | 必须是确定值，例如 `8 秒`，不要写 `6-8 秒` 这类模糊范围 |
| 景别 | 远景 / 全景 / 中景 / 近景 / 特写 / 大特写 |
| 角度 | 平视 / 俯拍 / 仰拍 / 过肩 / 主观视角；特殊位置要说明摄影机在实体空间中为何能站在那里 |
| 镜头关系 | 主观 / 客观旁观 / 近主观 / 过肩 / 正反打 / 反应 / 插入 / 视线所见 / 内打外 / 外打内 / 内反打 |
| 轴线与视线 | 两人或多人关系中的左右位置、视线方向和动作方向 |
| 世界位置与屏幕投影 | 人物相对场景锚点的真实位置 / 朝向 / 距离，与当前机位下的画面左右、前后景、动作轴、观看侧和运动方向分开记录 |
| 构图 | 关系压力、一个主要构图决定、主故事线索、按需一个辅助线索，以及主体、留白、前景 / 背景关系；按需说明受控不工整及其保留的决定性证据 |
| 运镜 | 固定 / 推 / 拉 / 摇 / 移 / 跟拍 / 环绕 |
| 表情细化 | 是否需要在 `laohu-video-prompt` 内进行人物表演细化，以及表情是否占用镜头时长 |
| 表情来源 | 剧本神态标注、OS、VO 回响、动作描述、插入镜头或无 |
| 表情功能 | 核心任务 / 辅助状态 / 不需要 |
| 表演 | 情绪方向、强度、性格边界、时间点、关键部位控制 |
| 光线 | 光源方向、硬软、明暗关系；特殊光线是否改变叙事压力而非只作装饰 |
| 色彩 | 色彩命题、真实色源、冷暖、饱和度、主色和强调色的移动 / 消退 / 反转 |
| 声音 | 台词、同期声、环境声、音乐点 |
| 图片资产 | 需要哪张角色、场景、道具或第一帧图 |
| 视频提示词 | 该镜头的 Seedance / 其他模型提示词 |
| 素材剪辑接口 | 素材主任务、推荐入点、内部可切节点、推荐出点、主要 / 辅助匹配属性、干净把手、不建议裁切点、可连接素材类型、后期依赖 |
| 跨 VID 连续性 | 独立 / 直接连续 / 同场重建 / 关系重置；上游 VID、计划参考类型、必须继承、允许重设、第一可见动作 |
| 失败风险 | 角色变脸、动作乱、表情过度、构图过死、特殊机位无空间理由、信息主次平均、镜头换序后仍无变化等 |

以上字段是开放判断库，不是逐镜必填表。简单事实特写可能只需一个决定性物件、可信机位和清楚出点；复杂关系镜头才展开视线流量、主辅线索、色彩变化和空间压力。每镜最多一个主要构图决定，按需一个辅助机制。成像基底与主要不完美来源通常在全片 / 场次风格资产中统一，本镜只在发生有动机的变化时重写，不能逐镜随机换介质。

镜头组完成后做顺序打乱测试：交换任意两个镜头，如果观众知道什么、暂时相信什么、等待什么、主要感受和人物状态都没有变化，说明镜头只是在重复展示。先增加新证据、关系后果、动作结果或明确等待；仍无职责则合并或删除。正反打可以使用，但不能只按说话人轮流切换；未回应者、空位、群体反应、道具后果和现场继续运转都可能是更准确的下一镜。

## 三、编号与时长硬规则

分镜编号统一采用：

```text
E1-S1-C1
```

- `E` 表示集。
- `S` 表示场。
- `C` 表示镜头。
- 插入镜头使用字母后缀，例如 `E1-S1-C5A`、`E1-S1-C5B`，不重排后续编号。

镜头总时长必须写确定值：

```text
时长：8 秒
时长：12 秒
```

不要写：

```text
时长写成 6 到 8 秒的模糊区间
时间段写成 10 到 12 秒的模糊区间
```

镜头内部动作时间轴可以写起止段，但边界必须确定，并且总和等于镜头总时长。

## 三点五、独立生成与合并规则

分镜表必须按真实生成方式设计：每个视频提示词通常是一次独立生成，平台不会自动继承上一条提示词的人物脸、服装、空间结构和全片设定。

因此，分镜表阶段必须判断：

| 判断项 | 规则 |
|---|---|
| 同一具体人物是否跨多个独立镜头出现 | 如果需要同一张脸和同一身造型，必须有图片资产 |
| 只有文本资产是否足够 | 文本资产只能固定类型和气质，不能保证具体人物一致 |
| 未资产化人物是否被拆开 | 不应跨多个独立提示词重复出现 |
| 同场连续动作是否可合并 | 不超过 15 秒时优先合并成一个分镜 |
| 超过 15 秒还需一致 | 回到视觉资产阶段建立图片资产 |

合并不是把多个镜头任务硬塞成混乱长镜头。合并后要在同一个 `【画面内容】` 里用镜头语言写清动作推进和镜头变化：

```text
平台总时长：9 秒
中景建立空间和人物等待，摄影机缓慢靠近。镜头背后的“大人”开口时，人物抬眼识别声源；摄影机接住这条视线连续推进到胸部以上中近景，眼神和呼吸先变化。她随后整衣、拱手、俯身并说出台词，摄影机沿动作下沉少许，停在礼姿。
```

分镜表仍可用镜头编号管理关键节点；正式视频模型正文必须去掉编号，把节点之间的动作、视线、遮挡、声音、焦点或运动方向写成连续桥梁，避免每个段落都像重新开场。

如果一个镜头的核心任务是细化人物表情，表情需要 4-5 秒，就不要同时塞太多宏大奇观；如果核心任务是展示宏观场景，人物表情可以只作为辅助状态，不强行细化。

### 三点六、跨 VID 连续性设计

同一场戏超过单次生成时长时，分镜表先选择连续性类型，再决定是否为下一条准备参考输入：

| 类型 | 判断 | A 条结束设计 | B 条进入设计 |
|---|---|---|---|
| 直接连续 | 同场景连续时间，动作、视线或情绪余势直接延续 | 当前动作结果完成，下一压力以视线、声音、影子、未接触威胁或运动方向出现；最后有效机位要能读清姿势、道具和空间 | 计划在 A 实际生成后取最后一次切镜后的单一机位尾部视频；从同一世界状态和运动余势进入新动作 |
| 同场重建 | 同场景但时间跳跃、段落重启、机位大改或运动不续 | 留下清楚终态，不强求动态交接 | 使用终帧 / 构图参考或场景资产；保留世界状态，重新建立景别、轴线和构图 |
| 关系重置 | 换场、换时空、空间关系或视觉语法主动变化 | 完成本场情绪 / 叙事停点 | 不引用 A 尾部；只继承人物、道具、色卡等稳定资产，按需设计声音 / 形状 / 动作匹配 |

直接连续也不能为了交接额外增加没有叙事职责的站位空镜。A 的最后一个镜头或动作组必须既完成 A 的局部任务，也形成 B 可用的起点。跨段不要停在未完成兵器接触、人物悬空而落点未知、投射物飞行中或爆炸结果尚未出现；允许动作结果完成后，下一威胁已经提前进入。

分镜规划时只写“计划参考类型”，不能虚构尚未生成的视频时间范围。A 成片出来后，再从最后一次切镜之后选约 1-3 秒单一机位；如果候选范围包含两个构图、强遮挡、严重失焦或错误动作状态，缩短到最后一个有效机位，必要时改用终帧。B 的景别和机位可按新情绪任务改变，但必须先让场景锚点、人物朝向、视线和运动方向重新证明空间。

### 三点七、生成素材剪辑接口

分镜不仅要决定“拍什么”，还要决定生成结果作为素材时“哪里可裁、靠什么接”。每个 `VID` 先规划一个推荐入点、按内容需要规划内部节点、再规划一个推荐出点；节点数量不固定。一镜到底表演不为凑节点破坏情绪累积，动作 / 舞蹈 / MV 按动作相位或节拍增加节点，商业广告优先保留产品细节、手部交互、卖点结果和品牌英雄帧。

每个接口按以下字段记录：

```text
出镜证据：前一段交出的动作向量、屏幕位置、观众视点、视线、焦点、形状、构图、明暗、色彩、遮挡、声音或语义。
可读边界：该属性保持稳定的可选择范围，避免只有偶然一帧。
入镜证据：后一段延续、接收、改向或有意反衬的属性。
干净把手：核心事件前后没有无关新动作、构图突变或声音截断的余量。
```

接口选择先保主情绪、故事信息和节奏，再校准观众注意力、运动空间、图形和声音。相邻两段通常匹配一条主要通道、一条辅助通道即可，不要求动作、构图、颜色和声音全部相似。遮挡、黑 / 白场、闪光、甩镜、抠像、撕纸、绿幕、屏幕替换和手势蒙版只有在题材或后期方案需要时使用；后期依赖型接口必须另记干净轮廓、完整遮挡、可跟踪运动或稳定替换平面要求。

分镜阶段只写计划位置和画面节点，不写尚未存在的时间码。正式视频提示词把接口翻译成观众可见 / 可听的结果；生成后再由复盘填写真实时间码、实际可用范围和失败原因。

## 四、人物表情前置判断

分镜宏观表不是只决定画面大概拍什么，还要决定人物表情是否值得占用镜头时间。

以下情况必须判断是否在 `laohu-video-prompt` 内进行人物表演细化：

- 人物有台词。
- 剧本里出现 `角色名（语气 / 神态）：`、`角色名 VO（语气 / 神态）：`、`角色名（OS）：` 等标注。
- 人物有沉默、反应、眼神变化或微表情。
- 人物情绪从一个状态转到另一个状态。
- 观众需要通过脸、手、呼吸或身体距离理解剧情。
- 镜头任务本身是人物关系、身份、敬畏、压抑、欺骗、犹豫、恭迎、恐惧或觉悟。

判断结果写入分镜表：

```text
表情细化：是 / 否
表情来源：剧本括号 / OS / 动作描述 / VO 回响 / 插入镜头 / 无
表情功能：核心任务 / 辅助状态 / 不需要
表情占用时长：确定值
推荐景别：近景 / 中近景 / 特写 / 大特写 / POV 手部替代表情
表情设计入口：laohu-video-prompt / 画面内容短句 / 无
```

如果表情是核心任务，分镜时长要先给表情留时间。后续画面内容必须继承人物表演交接包，不允许把动作、运镜和奇观塞满后再临时补表情。

剧本神态标注是表情来源的最高优先级。比如 `奶奶（忍着哭）：`、`父亲（压着火）：`、`小安（哭腔）：` 不能在分镜阶段被简化成“人物说话”。分镜要先判断这段神态是镜头核心任务还是辅助状态，再决定是否给近景、特写、大特写，或者在第一人称 POV 中用手部、呼吸、声音、背影、反射和道具反应替代表情。

下游视频提示词必须把抽象神态写成可见表演结果：眼神、眉头、嘴角、嘴唇、下巴、呼吸、肩膀、手指、停顿、声音状态和身体距离。不要只把“忍着哭”“压着火”原样复制到提示词里。

## 五、镜头任务写法

镜头任务必须是动作或信息变化。

可用：

```text
主角第一次发现异常。
主角试图隐藏情绪但失败。
反派掌握主动权。
观众看到关键道具。
两人的关系距离发生变化。
```

不可用：

```text
表现高级感。
营造氛围。
让画面更电影。
展示人物很悲伤。
```

## 六、景别推进原则

景别首先控制观众能同时读到多少证据，不是给情绪贴固定标签：

| 景别 | 优先承载的可见证据 |
|---|---|
| 远景 / 大全景 | 环境尺度、群体阵形、危险来路、出口、位移范围、破坏规模 |
| 全景 / 中远景 | 完整身体力学、步法、武器轨迹、双方距离、受力位移、环境反馈 |
| 中景 / 中近景 | 人物关系、攻防关系、重心变化、上半身动作与较明显表情 |
| 近景 / 特写 | 手部承重、兵器接触、呼吸、眼神、面部控制、关键道具状态 |
| 大特写 / 极端特写 | 一个决定性局部，例如指节失力、剑身弯曲、瞳孔反应或机关启动 |

这些只是证据容量，不是固定情绪映射。远景可以通过人物被空间吞没制造孤独，也可以通过出口打开制造释放；特写可以压迫，也可以平静。先问本镜需要观众看清什么，再由人物处境、观看距离、焦点、运动、声音和主情绪决定具体效果。

多人合击、力量反转和大型破坏通常需要景别协作：先用较远景别建立攻击几何与力量来路，再用较近景别提清接触点、支撑、手部或表情，最后回到较远景别展示压退、震开、脱困、倒塌或冲击范围。不是每段都必须三镜，但如果只用中远景从头拍到尾，常会既看不清接触细节，也感受不到完整结果。

切换景别时追求 `有意义的视觉变化`：

1. 同一主体、相近轴线、相近构图和同一动作相位下，从远景只切中远景、从中景只切中近景，变化太小容易像误切或跳切。
2. 此时可以跨过一个景别，例如远景切近景、中景切特写；也可以让机位相对主体改变约 30 度以上；还可以让动作相位、构图或信息目标发生明显变化。
3. `跨一个景别` 和 `30 度` 都是连续性经验，不是硬规则。相邻景别如果新增了明确证据可以使用；跳得很大但没有空间锚点、方向继承或动作匹配，同样会断裂。
4. 每次切换都回答：上一镜为什么此刻结束，下一镜新增什么，人物姿势、道具状态、屏幕方向和动作余势如何继承。

不要每个镜头都特写。连续特写会让空间断裂，也会让后期拼接困难；近景完成证据任务后，按需要重建人物与环境的空间结果。

## 七、角度与心理倾向

| 角度 | 首先改变的知觉关系；情绪由上下文决定 |
|---|---|
| 平视 | 缩小观看者与主体的高度差，可用于亲近、对峙、冷漠或观察 |
| 仰拍 | 放大主体高度和垂直线，可用于威胁、尊敬、英雄、陌生或滑稽 |
| 俯拍 | 缩小主体并增加周围空间，可用于脆弱、秩序、监视、隔离或路径说明 |
| 过肩 | 具体化两人距离、遮挡和站位，可用于冲突、亲密、试探或普通交流 |
| 主观视角 | 限制为视点主体所见，可用于代入、误判、平静观察或信息差 |

角度必须服务人物关系和主情绪。表中只提供起点，使用时要写清当前角度怎样改变距离、尺度、信息和力量关系。

## 七点五、镜头关系、轴线与正反打

分镜表阶段必须先解决摄影机和人物的关系。视频提示词阶段只能把这种关系写具体，不能重新猜空间。

常用镜头关系：

| 镜头关系 | 用途 | 分镜表应写清 |
|---|---|---|
| 主观镜头 | 代入和信息差 | 谁的 POV、眼睛高度、前景身体局部、中景所见、背景空间 |
| 客观旁观 | 让观众看人物和环境 | 摄影机在空间哪一侧，人物完整或半身关系 |
| 近主观 | 既贴近角色又保留角色局部 | 哪个肩后 / 侧后方，露出什么肩背或侧影 |
| 过肩 | 对话、压迫、遮挡 | 谁的肩背在前景，谁在中景，谁看向哪里 |
| 正反打 | 对话和情绪交换 | 两人左右关系、视线方向、是否保持轴线同侧 |
| 反应镜头 | 信息落到人物身上 | 角色听见 / 看见后身体和表情如何变化 |
| 插入镜头 | 道具证据和触发物 | 物件位置、手部动作、它触发什么信息 |
| 视线所见 | 角色看向某处后切到所见 | 上一镜视线方向和本镜被看的对象 |
| 内打外 / 外打内 | 门、窗、车、屋内外关系 | 摄影机在内还是外，门框 / 窗框如何遮挡 |
| 内反打 | 同一空间内部反拍 | 对面机位与原机位的空间对应关系 |

正反打规则：

```text
先确定人物轴线。
保持同一段对话在轴线同一侧拍摄。
反打时人物视线方向相对。
如果需要越轴，用全景、人物移动、遮挡或主观镜头重新建立空间。
```

画面内容最终要写成可见构图，例如“父亲肩背虚化占左前景，小安在右中景抬头看向画面左上方”，而不是只写“过肩正反打”。

## 八、运镜约束

- 情绪镜头优先固定或缓慢推进。
- 动作镜头可以跟拍，但不要同时写推、拉、摇、移、环绕。
- 如果模型动作容易乱，先改固定镜头。
- Dolly zoom、快速环绕、长镜头等复杂运镜只能用于明确测试，不作为默认写法。
