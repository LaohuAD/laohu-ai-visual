# 人物表情与肢体动作词典

## 基础情绪

| 情绪 | 脸部表现 | 身体配合 |
|---|---|---|
| 喜悦 | 嘴角上扬、脸颊抬起、眼周收紧 | 身体前倾、动作变轻快 |
| 悲伤 | 内眉上抬、嘴角下压、眼神失焦 | 肩膀下沉、低头、动作变慢 |
| 愤怒 | 眉头压低、眼睑绷紧、嘴唇压紧 | 下巴前顶、拳头收紧、身体前压 |
| 恐惧 | 眉毛上抬、眼睛睁大、嘴唇拉开 | 身体后缩、手护胸、呼吸急促 |
| 惊讶 | 眉毛抬起、眼睛睁大、嘴微张 | 身体停住、头微后仰 |
| 厌恶 | 鼻翼皱起、上唇抬起、眉头收紧 | 头后撤、身体侧开 |
| 轻蔑 | 单侧嘴角上扬、眼神斜看 | 轻微偏头、身体不完全转向对方 |

## 常用复合表情

| 复合表情 | 内在逻辑 | 提示词方向 |
|---|---|---|
| 克制的开心 | 高兴，但不能太明显 | 眼睛变亮，嘴角想上扬但被压住 |
| 苦笑 | 接受现实，但心里不甘 | 嘴角上扬但眼睛不笑，眉心轻压 |
| 强装镇定 | 内心慌，外表稳 | 眼神警觉，嘴唇压紧，肩颈僵硬 |
| 压抑愤怒 | 怒气上来，但不能爆 | 眉头压低，嘴唇闭紧，拳头收紧 |
| 礼貌性微笑 | 不认同，但不撕破脸 | 嘴角上扬，眼睛不参与，身体保持距离 |
| 轻蔑的笑 | 觉得对方不配 | 单侧嘴角上扬，眼神冷，头微偏 |
| 忍住眼泪 | 情绪到顶，但不想哭 | 内眉上抬，眼眶发红，吞咽，低头 |
