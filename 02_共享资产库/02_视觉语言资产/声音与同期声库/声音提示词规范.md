# 声音提示词规范

声音不是最后补的东西。对于 AI 视频，声音设定会影响现场感和后期拼接。

## 台词与 VO 表演参数

写人物说话、旁白、画外音、脑内 VO 或回忆回响时，不能只写 `温柔`、`生气`、`压迫`、`深情`、`破碎` 这类情绪标签，也不能只写 `音高压低`、`音量中等`、`语速收紧` 这类机械参数，更不能临时拼接没人会用的“高级听感词”。声音描述要像配音导演给演员和录音师的表演表：先写基础音色，再写这句话的情绪态度，最后写声音参数和声音在画面里如何出现、如何消失。

正式声音描述采用“双层声音表演”：

```text
情绪态度层：这句话是示好、试探、亲昵、期待、敷衍、心虚、防御、不耐烦、反推责备、轻蔑、愤怒、暴怒、切断，还是伤害后的空洞残响。
声音形态层：声音是软还是硬、弱还是强、松还是紧、轻还是重、有没有爆发力；再写音高、音量、语速、停顿、重音、气息、咬字、距离、混响和衰减。
```

正式提示词必须优先使用正常、可执行、可录音复现的声音参数：

```text
音高 / 音区：偏高、偏低、中低音区、音高上扬、句尾下坠。
响度 / 音量：低声、中等音量、突然抬高、压低、贴耳近声、远处小声。
语速 / 节奏：正常偏慢、略快、连读、逐字说、前快后慢。
停顿 / 气口：句前吸气、词前停半拍、句中断开、说完留空白。
重音 / 强调：重音压在哪个词，哪个词轻说，哪个词咬紧。
气息 / 发声状态：带笑气、气息短、气息不稳、喉咙收紧、声音发干。
咬字 / 吐字：清楚利落、齿音偏硬、尾字含住、字头重、尾音短收。
距离 / 空间：近麦干声、贴近耳边、从门外闷住、电话电流失真、脑内轻回响。
混响 / 衰减：轻微记忆回声、半秒内衰减、余音被风吞掉、说完突然空掉。
```

正确写法不是堆术语，而是先说明说话人的情绪和态度，再用参数解释一句话应该怎么被说出来。每句关键台词至少回答六件事：这句话的情绪态度、声音软硬强弱、声音高低、音量大小、快慢停顿、哪个词重、说完怎么收。比如：

```text
男声带轻佻试探和克制示好，声音偏软，攻击性很低；音量中低，语速正常偏慢，句前有一小口带笑吸气；“可不可以”前停半拍，尾音轻轻上扬，听感像在试探边界。
```

错误写法：

```text
男声温柔、深情、压迫、有宿命感。
男声音高压低，音量中等，语速收紧。
```

第一种写法不够，因为它只有情绪标签，没有告诉模型和配音者声音要高还是低、快还是慢、轻还是重、在哪停顿、哪个词该压住、回响多久消失。第二种写法也不够，因为它只有录音参数，没有告诉模型和配音者这句话背后的态度到底是防御、愤怒、轻蔑、敷衍还是心虚。

情绪曲线型短片还要按阶段设计声音变化。比如恋爱关系里的男声不能每一条都同一种年轻男声，也不能只写参数变化：

```text
初识：轻佻试探、克制示好；声音偏软，音量中低，句前带笑吸气，尾音上扬。
亲昵称呼：冒进试探、甜腻笑意；声音更近更软，重音落在亲昵称呼上，尾音上扬后收住。
恋爱初期：稳定惦记、温柔黏人；音量偏轻，语速自然，节奏稳定，尾音明亮或柔软。
热恋邀约：期待、紧张、怕被拒绝；声音更亮但仍柔软，关键请求放慢，句尾上扬后留空白。
平淡期：表面愧疚但敷衍抽离；声音变远变薄，语速解释性变快，句尾下落短收。
猜忌期：心虚、防御、急于压住怀疑；声音收紧发硬，重音压关键词，尾音短促下压。
争吵期：不耐烦、反推责备、烦躁爆发；语速加快，音量抬高，齿音变硬，短句连说。
攻击句：轻蔑、厌烦、刺伤自尊；音区压低，字头更硬，逐字咬清，收尾冷而短。
决裂期：暴怒爆发、厌倦切断；爆发力强，短促重音，最高重音切断关系，说完立刻停声。
余音：伤害后的空洞残响；距离很远，尾音不完整，很快被环境声吞掉。
```

不要把“控制感、压迫感、冷刺感、破碎感、宿命感”这类词当作主描述。它们最多只能作为提示词外的解释，进入模型正文时必须改成可听见的动作：音量提高或降低、音区上移或下压、句子连读或断开、重音压在哪个词、尾音上扬或下落、气息是否发紧、说完是否留空白。

## 动作音效与空间

动作音效不能只写对象名称或 `震撼音效`，统一按以下关系展开：

```text
发声对象 / 事件
+ 材质与动作方式
+ 声源方向和距离
+ 所在空间
+ 先后层次
+ 音量、频段、冲击和节奏
+ 混响与衰减
+ 对画内主体的影响
```

例如机器人脚步不是一句 `巨大脚步声`，而是每次落脚先出现低沉金属撞地，随后叠加关节伺服与液压驱动声，地面产生短促低频震动；机器人向画面外走远时，落脚音量逐步降低、低频变薄，街道两侧高楼留下更长回声。爆炸可以继续分层为玻璃碎裂、金属结构撕裂、混凝土坍塌、碎石落地和烟尘翻涌，不把所有声音压成一个爆炸大响。

## 画外声音与不可见空间

画外声音的价值，是让观众感到画框之外仍有完整世界，并用不可见信息制造期待、压力或想象。写法必须说明声源位于镜头之外、方向、距离、空间反射、接近 / 远离变化，以及画内主体的反应；画外对象可以始终不进入画面。

```text
画面外右后方的远处街区传来两声汽车喇叭，声源始终位于镜头之外，声音经过高楼立面反射后略显空旷；机器人头部向右偏转十度，摄影机和焦点仍停在机器人脸上，画面不揭示汽车。
```

观众会由声音补全远处街区。画外声可以来自门后脚步、楼上拖动物体、远处列车、走廊咳嗽、看不见的追兵、城市警报或风吹招牌；这些都是开放示例，选择标准是它是否扩展空间、触发表演或制造信息差。

## 默认音乐策略

项目默认所有独立生成的视频片段只生成对白、动作声、衣料声、道具声和环境声，不生成 BGM。原因是多段素材需要后期剪辑，模型为每段生成不同音乐会破坏连续性。只有老胡明确要求单镜头自带音乐、原生音乐表演或音乐本身参与画面动作时，才在对应提示词中改变这条策略。

## 常用写法

```text
不需要配乐，不要氛围音乐，仅保留同期声。
```

```text
保留脚步声、衣物摩擦声、金属关节摩擦声、远处风声、环境回声。
```

## 后期拼接提醒

如果视频后期要自己配乐，提示词里要提前写清楚：

```text
不要生成背景音乐，只保留现场环境声和动作声，方便后期统一配乐。
```
