# 画面风格与画质规范

本文件用于指导图片提示词、视频提示词、分镜表和视觉资产中的画面风格设计。

核心规则：本项目统一使用“画面风格”，不要再把该字段写成“影像风格”。“画面风格”不是单个漂亮形容词，而是一整套视觉系统：

```text
画面风格 = 风格母体 + 画质介质 + 色彩影调 + 光影方式 + 构图 / 美术体系 + 题材气质 + 禁止偏移
```

例如 `东方仙侠写实电影风格` 只是风格母体，还不够。它需要继续说明：高清数字电影质感还是 35mm 胶片质感，色彩是金白青玉还是暗黑灰调，光影是柔和体积光还是低光高反差，构图是史诗远景还是礼仪对称构图，最终禁止偏向哪里。

风格设计必须放回图片四锚点理解：主体决定谁被观看，场景决定世界关系，时间决定自然光与环境基线，风格决定这些事实以何种审美秩序被观看。风格不能越过时间直接制造无来源光影，也不能为了套某种电影感而让服装、建筑、天气和动作互相冲突。

参考作品可以作为风格母体，但片名不能替代导演判断。凡是写 `参考某电影 / 剧集 / 摄影师 / 艺术运动`，都要继续拆成当前画面真实调用的可见特征：构图如何组织，色彩如何分级，光影从哪里来，空间怎样展开，动作是什么重量，材质如何反光，采用什么成像介质。参考《卧虎藏龙》时，可以按任务选取克制青绿、东方留白、竹林纵深、自然风、轻盈动作线和写实武侠摄影；不是复制人物、剧情或标志性镜头。作品名负责唤起认知，拆解后的视觉特征负责生成稳定。

风格词表是开放坐标，不是款式菜单。真人写真、电影剧照、纪录摄影、二维 / 三维动画、粘土、定格、毛毡、绘画和混合媒介只是表现介质示例；文艺、幽默、悬疑、武侠、危险、宁静、孤独等也只是类型或情绪方向。AI 必须继续根据主体身份、场景结构、年代时间、目标情绪和发布用途推导新的相容组合，不能从每组随便挑一个词拼成风格。

画面美感必须转成可生成结果，而不是只写漂亮形容词。承担人物第一眼、情绪峰值、段落记忆、封面候选或传播视觉职责的镜头，应设计审美停点；功能型插入、动作连接和信息证据镜头只需形成清楚可剪辑的任务停点。审美停点从主体轮廓、构图、留白、色彩、光影、材质、姿态和运动中选择真正加强主情绪的部分，不要求全部出现。

情绪短片的风格不能停在 `写实电影感`。写实只是一个大范围，它下面可以是油亮商业广告、粗粝纪实、电视剧柔光、短剧风格、韩剧柔光、日系清新、港风霓虹、低光犯罪等完全不同结果。正式提示词要先做风格交集：主风格母体、辅助风格、胶片 / 滤镜分级、明度对比、光影方式、肤色妆效、场景环境色和情绪阶段边界同时成立。比如海边恋爱情绪片适合 `日系清新治愈青春电影色彩 + 海边低饱和胶片写真 + 清新透亮 + 高明度低对比 + 柔和自然光 + 空气感散景 + 富士胶片清透蓝绿倾向 + 自然人像肤色过渡`；它会把模型从硬写实、油亮商业美人片和高反差广告大片里拉出来，转向更白皙、更通透、更低油感的真人人像。

审美停点的判断公式：

```text
审美停点候选控制杆 = 主体轮廓 / 空间层次 / 视觉中心 / 留白 / 色彩 / 光影 / 材质 / 姿态 / 运动停点
```

构图、光影、色彩以及后续所有审美模块都不是封闭词表。老胡给出的三分构图、黄金一小时、莫兰迪、青橙、胶片棕调等，是为了启发底层判断，不是要求以后只能使用这些搭配。正式提示词要先判断剧情情绪、时代背景、空间材质、人物肤色、道具颜色、光源类型、壁纸用途和剪辑连续性，再扩展出适合本镜的方案。有效方案可以来自摄影、绘画、平面设计、电影调色、地方环境和年代记忆，不必局限在用户列举的词里。

构图承担主情绪、主体识别或关系展示时，必须写成可见画面骨架，而不是 `好看 / 高级 / 壁纸感`。以下公式是候选问题库，不是必填清单：

```text
构图候选 = 画幅比例 / 构图结构 / 主体落点 / 留白方向 / 引导线或框架 / 边角状态 / 运动落点
```

常用构图结构包括三分、黄金分割、中心对称、框架、引导线、对角线、留白、前景框和三角关系。选择后写清它如何把注意力带到主情绪证据。留白、平衡和边角清洁只在服务呼吸感、字幕空间、封面用途或主体识别时启用；拥挤、遮挡和失衡也可以有意服务压迫、混乱或失控。

画幅比例会反过来影响构图，但不固定情绪和结构。16:9、21:9、9:16、3:4 和方形先服务平台、主体比例和空间任务，再选择构图。需要读表情、证据或剪辑接口时给清楚停点；纯运动冲击和主观失控不必回到稳定壁纸构图。

光影承担主情绪、主体塑形、动作可读性或连续性时，从以下候选中选择承重项；自然光已经准确时，只写来源和关键受光结果即可：

```text
光影候选 = 时间与天气基线 / 实际光源 / 方向与软硬 / 明暗层级 / 反光 / 阴影 / 材质反应 / 动态稳定
```

光影先从时间和真实光源推导，不先从效果词推导：`年代 / 季节 / 时刻 → 可用光源 → 方向与色温 → 阴影与环境亮度 → 空气与表面反射`。黄金一小时、日出、蓝调时刻、傍晚、雨后天光、窗光、门缝光和旧灯泡都是开放候选，没有固定情绪含义；同一蓝调既可冷静也可恐惧，取决于人物处境、明暗关系和声音。

需要光型分层时，让每一层承担清楚职责；不规定层数。单一硬光、剪影、平光、近无辅光和复杂多层布光都可以成立。丁达尔、散景光斑、光晕、长投影和反光只有在加强主情绪或可读性且有真实来源时才加入。

阴影控制决定画面是否高级。家庭纪实和老式 DV 可以有噪点，但不能让暗部死黑、脸部灰平、主体和背景粘在一起。优先写柔和虚化阴影、低对比度阴影、细腻层次阴影和可读暗部；需要压抑时可以加深阴影，但仍要保留墙面、衣料、木头、纸灰或皮肤纹理。动态视频里要锁定光源稳定性：光源可以轻微跳动，例如火盆火光，但主光方向、阴影方向和反光位置不能一会儿来自窗左、一会儿来自窗右。

光影分离是可用的电影表达之一，不是所有镜头的底层必填。需要把主体从背景中分出、塑造体积或强化材质时，可以选择主光、半暗面、轮廓、背景和反光中的必要层级；剪影、平光、大片暗部或主体故意融入背景也可以成立。凡是写入的光，都要说明从哪里来、照到哪里、怎样加强主情绪或可读性。

使用动态光源时必须有动机。可选来源包括风吹树叶形成移动树影、车辆经过形成扫光、火盆 / 烛光轻跳、霓虹在湿地反射、水面波光形成流动补光；不使用动态光也是合法选择。动态光不等于随机闪烁，主光方向和阴影运动要有来源。当前《30秒钟带你体验谈恋爱》使用树影和海面反光，是由海边环境与情绪变化共同推导出的案例。

色彩承担主情绪、身份识别或连续性时，从以下候选中选择承重关系。黑白、单色、近无色和自然综合色同样可以成立：

```text
色彩候选 = 主色 / 辅助色 / 点缀色 / 饱和度 / 明度与对比 / 环境反光 / 色彩过渡 / 统一分级
```

色彩母体要按故事选择，不是固定套用。可用方向包括莫兰迪低饱和色系、青橙电影色调、冷调蓝灰治愈色系、复古胶片棕调、奶油温柔色系、低饱和马卡龙、暗调黑金、清新森系绿调、黑白灰单色、褪色老照片、山城雾灰绿、煤油灯暖褐、旧木头深棕 + 孝布冷白、纸灰冷灰 + 火盆暖橙、雨后青灰 + 旧墙土黄等。比如家庭回忆可以走复古胶片棕调、旧灯泡暖黄、木桌深棕和糯米白；丧事可以走冷灰白、旧木暗棕和低饱和肤色；放学路可以走土路灰黄、枯草低绿和山城雾灰。

色彩要有权重关系，但不固定为 `1 主色 + 1 辅助色 + 1 点缀色`，也不默认低饱和等于高级。单色、综合色或有意冲突的多色体系都可以使用；真正要避免的是多个高权重颜色无目的地抢主情绪和注意力。

色彩滤镜和分级要服务统一，而不是廉价套滤镜。可以使用富士胶片色调、柯达金 200 暖调、电影 LUT 调色、轻微暗角、胶片低饱和、低对比度色彩分级、暗部偏冷高光偏暖、整体褪色老 DV 统一色偏等，但必须说明它们如何影响暗部、高光、肤色、墙面、衣料和道具。动态视频里同一场景色彩分级要保持一致，避免一会儿高饱和撞色，一会儿冷灰，一会儿现代广告色。

色卡是色彩体系的资产化版本。它不是只给人看的几块漂亮色块，也不是人物设计资产里那种小面积配色板。用于 AI 视频时，色卡应该同时包含图片和文字：图片用横向色块固定主色、辅助色、点缀色、肤色、光源色、暗部色和环境反光，色块标注十六进制 RGB；文字说明每个颜色的使用比例、材质落点、明度对比、饱和度、胶片 / LUT 分级和情绪用途。没有文字解释的色卡，模型可能只学到颜色本身，却不知道哪一块是海面、哪一块是肤色、哪一块只能做小面积点缀。

色卡应按 `母色卡 + 阶段变体` 管理。母色卡负责全片统一，让不同分镜剪在一起仍像同一个世界；阶段变体负责情绪变化。变体不是重新换一套颜色，而是在母色卡里调整明度、暗部冷暖、点缀色面积、肤色气色、环境反光和阴影重量。例如同一条海边恋爱短片，心动期可以让海盐蓝和浅青绿更明亮，肤色清透，点缀色少量珍珠白；失落期仍保留海盐蓝和浅青绿，但整体明度下降，暗部偏冷灰，树影面积变大，珍珠白点缀减少。这样观众会感觉“同一片美景变得不美了”，而不是突然换了一个片场。

景深与空间层次承担主情绪、空间因果或注意力控制时，从以下候选中选择必要项；深景深、平面化和无前景也可以是有意结果：

```text
空间候选 = 前景遮挡 / 中景主体 / 远景环境 / 焦段 / 焦点 / 虚实过渡 / 空气透视或散景
```

前景虚化遮挡负责制造入口和层次，可以来自门框、窗沿、树叶、纱帘、薄雾、雨丝、纸灰、火光、柜台边、桌沿、肩背、手部、车窗边缘或道具边缘。中景通常是清晰主体，承担人物表情、手部动作、关键道具、冲突接触点或遗物停点。远景负责空间和情绪，可以是旧墙、院门、山城雾气、放学路转弯、屋内暗部、远处灯泡光斑、窗外天空或远处背影。写提示词时要把三层说成屏幕结果，而不是只说 `画面有层次`。

焦段从视野范围、相机距离、透视夸张 / 压缩、主体占比和背景信息量反推。35mm、50mm、85mm、135mm、微距、准广角和长焦不与题材或情绪固定绑定；选用时说明它怎样改变脸部比例、空间距离和环境可读性。

景深要匹配观看任务和信息量，但不与题材固定绑定。浅景深、深景深、全平面清晰或有意短暂失焦都可以；关键表情、动作因果和事实证据不能被非意图性虚化。只有焦点承担注意力迁移时才写转移过程，随机漂移和有意失焦要分开诊断。

镜头参数按屏幕结果自动选型：观众需要同时看见多少环境、透视要夸张还是压缩、哪些对象必须清楚。焦段、景深、对焦距离、主体到背景距离和散景只在承重时展开；情绪人像可以深景深，POV 可以长焦，远处背影也不必然用 135mm。

画质与材质围绕主注意力证据和交付用途展开。近景表情、物证和材质展示需要清楚纹理；梦境、主观失焦和高速连接镜头可以有意牺牲部分细节：

```text
画质材质体系 = 分辨率清晰度 + 主体边缘锐度 + 材质质感细分 + 微细节锚点 + 运动模糊控制 + 画面洁净度 + 介质颗粒边界
```

分辨率和清晰度不是只写 `8K 超高清`。要说明哪一部分清楚：人物眼里水光、皮肤纹理、手指边缘、糯米皮水润表面、旧瓷碗釉面、蒲团粗布经纬、木车粗糙木纹、纸灰颗粒、火苗边缘、玻璃反光、硬币旧金属磨损、旧墙斑驳或衣料纤维。主体边缘要锐利稳定，关键道具和手部不能被压缩糊块或动态拖影吃掉。

材质词要细分并绑定物件。哑光柔和质感适合旧墙、棉衣、孝布和纸房子；磨砂低反光适合旧瓷、旧木、玻璃柜台边缘和年代道具；丝绒柔和肌理适合衣料暗部；金属细腻拉丝、旧金属磨损和克制反光适合硬币、旧钥匙、锅沿和工具；水雾朦胧质感适合灶房水汽、雨后空气和火盆烟气；水彩通透质感只适合明确风格化图片，不默认进入真人写实视频。老式 DV 和胶片质感可以有细腻颗粒、轻微频闪和受控噪点，但不能牺牲主体边缘和材质细节。

主体细节不按完整细节束填写。身份、状态、动作因果或主情绪需要时，从颜色、材质、纹理、状态、反光、破损、湿度、瑕疵和边缘细节中选择必要证据，并绑定具体人物、道具或场景；不承重的细节省略。人物肤色和妆效必须来自角色设定，不把某个案例的冷白肤色、清透妆效或柔雾质感升级成美女默认值。

动态模糊要有职责。需要读脸、物证、材质或供截图使用的停点应让关键局部清楚；追逐、甩头、速度冲击和主观眩晕可以保留方向性模糊。问题不是所有帧不够锐，而是关键证据被无意模糊或出现随机扭曲、文字、水印和压缩崩坏。

氛围环境元素只有在加强主情绪、空间真实感或运动层次时才加入；干净空气、静止背景和无微粒环境同样可以成立。被选中的元素按以下候选检查来源和密度：

```text
氛围环境体系 = 天气 / 时间基底 + 空气媒介 + 漂浮微粒 + 光学点缀 + 环境运动 + 密度控制 + 题材适配
```

天气和时间基底先定：清晨薄雾、雨后水汽、黄昏薄雾、冬天冷雾、蓝调时刻湿冷空气、灶房水汽、火盆烟气、林间水汽、细雨水雾、室内旧灯泡暖晕等。它们会影响色彩、光影、景深和材质，不是单独的漂亮词。比如雨后水汽会让远景旧墙更柔，窗边落尘会让光柱可见，火盆烟气会让丧事段更闷。

氛围元素要有来源、位置、方向和密度。薄雾来自山城湿气、雨后地面、清晨低温、火盆或灶房；光斑来自旧灯泡、逆光、窗光、玻璃反射、水面波光；漂浮微粒来自纸灰、糯米粉尘、木屑、火星、落叶、窗边尘埃或雨丝；水面波纹来自雨滴、风、脚步或碗汤晃动。密度要轻，方向要顺着风、光线或人物动作走，不能把主体和关键动作遮住。

不同题材使用不同氛围元素。家庭纪实和老式 DV 用窗边落尘微光、灶房水汽、旧灯泡光晕、轻柔烟尘、纸灰、落叶和土路尘灰；丧事、病床、遗物回收用冷灰薄雾、低密度浮尘、火盆烟气、纸灰慢飘和暗部水汽；放学路用雨后水汽、枯草微动、远处山城薄雾和路面细尘；浪漫 MV 或强风格化镜头才用漂浮花瓣、轻纱透光、明显镜头光斑和大面积柔光粒子。氛围元素必须服务情绪，不做无来源装饰。

镜头运动先服务观看意图和主情绪，再从以下候选中选择控制。持续运动、稳定凝视、故意失衡和短促颠簸都可以成立，不把静态截图当唯一标准：

```text
运动稳定体系 = 机位稳定策略 + 运镜速度 + 抖动强度 + 变焦 / 旋转控制 + 构图保持 + 可定格停留 + 运动模糊边界
```

适合壁纸帧的运动通常是固定机位长镜头、极缓慢微动运镜、轻微呼吸手持、慢推慢拉、低幅度 Pan / Tilt、稳定跟拍和低抖动画面。家庭纪实、饭桌、病床、遗像、门口对话、遗物回收和仪式镜头尤其要稳，让观众能读清人物关系、材质、光影和留白。镜头可以呼吸式轻微浮动，但不能让主体位置每一帧都漂。

强运动要有明确职责。快速推拉、变焦、旋转、甩镜、颠簸、螺旋、鱼眼和航拍可以表达恐慌、追逐、喜悦、游戏感、秩序、梦境或转场冲击，没有固定情绪字典。发生摄影机运动时写清起点、速度、触发和屏幕结果；只有需要观众读清落点或接剪时才要求停稳，不统一回到可截图构图。

需要观众读表情、事实证据、动作结果或剪辑接口时，动态镜头给足可读停留；停留时长由识别、情绪进入和剪辑需要倒推。纯运动冲击、主观眩晕和连续追逐可以持续运动并保留方向性模糊，只要关键因果仍可读。

写作时不要只说 `美感 / 电影感 / 高级感 / 壁纸感`。要写成屏幕结果：谁或什么在画面哪个位置，前景遮挡是什么，中景主体是什么，背景用什么形状或色块托住主体，哪里留白，哪束光勾出轮廓，暗部保留什么纹理，镜头最后停在哪里。家庭纪实镜头可以朴素，但不能没有构图；DV 质感可以有噪点，但不能变成随手乱拍。

## 一、画面风格和画质介质的分工

正式视频提示词的 `【氛围与画质】` 建议使用：

```text
画面风格：
画质介质：
色彩与影调：
质感颗粒：
风格融合边界：
禁止方向：
```

分工：

- `画面风格`：回答“画面看起来属于哪套视觉风格”，例如日系小清新、90年代港风、赛博朋克、中式水墨国风、东方仙侠写实电影风格。
- `画质介质`：回答“像什么设备 / 介质 / 成像质感”，例如 35mm 电影胶片、16mm 复古胶片、8mm 超八、VHS 录像带、高清数字电影、监控摄像头、IMAX 70mm 史诗质感。
- `色彩与影调`：回答主色、辅色、高光、暗部、饱和度和对比度。
- `质感颗粒`：回答颗粒、锐度、柔焦、噪点、暗角、褪色、清晰度、材质真实度。
- `风格融合边界`：回答多个风格如何主次融合，哪些元素可以借，哪些不能借。
- `禁止方向`：回答最容易跑偏成什么，提前堵住。

不要把“画面风格”和“画质介质”混在一句里糊掉。比如“日系胶片”可以作为画面风格母体，但仍要说明它是 35mm 温润胶片、16mm 文艺颗粒，还是 8mm 怀旧录像。

## 二、常用画面风格母体

以下是可组合的风格母体，不是死板词库。使用时根据作品题材、观众感受和模型可生成性做取舍。

### 1. 日系与治愈

常用词：日系小清新、日系胶片、日系治愈、日系冷淡风、日系昭和复古、日系私写真、日系盐系、日系电影感、日系柔光画报、日式烟火风。

## 四、组合方法

使用画面风格时，按这个顺序组合：

```text
题材目标 → 风格母体 → 画质介质 → 色彩影调 → 光影方式 → 构图 / 美术 → 禁止偏移
```

示例：

```text
画面风格：东方仙侠写实电影风格，融合古风电影质感和史诗宏大画面，不使用二次元或网游主城风。
画质介质：高清数字电影质感，接近 IMAX 70mm 史诗清晰度，云雾、白玉、丝绸和远景宫阙都有层次。
色彩与影调：金白天光、暖白玉石、青玉阴影、浅蓝云雾，少量淡朱红点睛，高光不过曝。
质感颗粒：轻微电影颗粒，材质真实，云雾有体积，不要塑料、磨皮、低清贴图。
风格融合边界：仙侠礼仪和东方建筑是主风格，奇观视效只服务神域真实感，不加入赛博、欧式天堂、暗黑魔幻。
```

另一个示例：

```text
画面风格：90年代港风夜景，融合王家卫式霓虹情绪和街头人文扫街质感。
画质介质：35mm胶片模拟，轻微颗粒和柔光，暗部保留细节。
色彩与影调：蓝青阴影、暖黄肤色、红绿色霓虹反光，低对比但不灰脏。
质感颗粒：雨水、玻璃反光、皮肤柔光和旧招牌纹理清楚。
风格融合边界：可以有情绪化霓虹和手持现场感，但不要赛博朋克、不要过度MV化。
```

## 五、使用原则

- 不要只堆风格名词。每个风格名词都要落到画质、色彩、光影、构图或材质。
- 不要把互相冲突的风格硬塞在一起，例如“日系小清新 + 暗黑犯罪低光 + 糖果高饱和”除非有明确主次。
- 可以融合，但必须写主风格和辅风格。主风格决定画面，辅风格只借局部元素。
- 正式视频提示词里不要写一长串风格清单，优先写 1 个主风格 + 1 个辅助风格 + 明确禁止方向。
- 同一作品内的画面风格要稳定，单个分镜可以局部变化，但不能像换了片种。
- 只影响当前镜头的局部光线、动作、情绪和转场，不写进 `【氛围与画质】` 的画面风格里，写进 `【画面内容】`。

一句话：画面风格不是“好看滤镜名”，而是能让模型稳定生成同一种画面世界的组合配方。
