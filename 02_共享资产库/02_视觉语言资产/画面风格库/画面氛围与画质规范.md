# 画面氛围与画质规范

不要只写“电影感、超真实、高清”。

更稳的结构是：

```text
风格核心：
视觉基调：
色彩与影调：
画面质感：
镜头节奏：
禁止方向：
```

## 示例

```text
风格核心：复古未来主义废土动作短片，真实摄影质感，紧张、压迫、粗粝。
视觉基调：画面像一段废土动作电影里的追逐戏，镜头贴近主角，背景残破，远处尸潮逐渐逼近。
色彩与影调：低饱和度冷灰色主调，局部红色 LED 光作为视觉焦点。自然光和环境反射光为主，高光不过曝，暗部保留细节。
画面质感：金属有磨损和划痕，布料有灰尘和褶皱，地面积水有真实反射。不要塑料感，不要过度光滑，不要像游戏渲染。
镜头节奏：动作紧张，镜头可轻微晃动，但主体始终清楚可见。运动模糊适度，不要晃到看不清动作。
```
