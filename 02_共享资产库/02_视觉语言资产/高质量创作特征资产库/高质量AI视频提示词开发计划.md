# 高质量 AI 视频提示词开发计划

本文档的身份是：高质量 AI 视频提示词审美特征资产库。

它的职责集中在高质量 AI 视频提示词审美特征沉淀，只沉淀两类资产：

```text
不变骨架资产：
AI 视频提示词天然需要的固定结构、时长、资产引用、镜头语言、声音、画面内容和故事板关系。

开放审美特征资产：
高质量视频提示词中反复出现、可识别、可组合、可变体、可增益的生成质量因子。
```

本文档里的“特征”是一组能在视频里被看见、听见、生成、剪辑、拼接和复盘的镜头机制。

一个高质量视频提示词不需要命中本文档全部特征。它更像一组导演基因：承重位置命中少数关键特征，生成结果会明显脱离平均视频；多个特征在基础设定、氛围画质、画面内容、人物表演、声音、运镜和转场中互相支撑，作品上限会继续抬高。

本文档必须按“骨架强制、特征择优”的方式理解。

本文档遵守正向导演收束原则：视频提示词优先描述目标视频已经成立后的可见、可听、可剪辑状态。它通过镜头距离、人物表演、声音态度、光影变化、时间密度、故事板构图、资产调用和首尾帧衔接共同收束生成范围。

```text
正向导演收束：
用镜头、表演、声音、光影、时间、空间和剪辑关系描述目标视频。

特征交集：
每个字段负责一个导演维度，多个维度交叠后形成清楚的生成坐标。

承重优先：
一条视频优先服务一个主镜头任务，辅助特征服从主任务。
```

## 0. 特征资产的描述粒度

有效视频提示词特征具备四个条件。

```text
可识别：
看生成视频时，能指出它落在哪个镜头距离、表情变化、运镜路径、光影变化、声音状态、动作因果或停点画面上。

可组合：
它能和其他特征叠加。一个成熟特征通常能同时服务生成稳定、人物表演、剪辑连续、情绪递进和画面美感。

可变体：
同一个通用特征能被不同题材改写。一镜到底尾帧接首帧可以用于恋爱情绪，也可以用于亲情回忆、病床段落、追逐段落和奇观穿越。

可增益：
它是提高生成可控性、情绪命中率、画面质感、剪辑效率和复用价值的质量因子。
```

低密度特征写法是：电影感、真实、高级、自然、情绪饱满、光影好、表情丰富、镜头流畅、画质好。

高密度特征写法是：

```text
开场从上一条尾帧的同一构图、同一光源、同一表情余韵继续。
本案例使用胸部以上舒适近景，眼线回到镜头，肩颈和少量环境留白保留；人物占比由“正常对话距离”倒推，不升级成固定百分比。
男声先写防御和心虚，再写音区偏低、声音发硬、重音落在关键词上。
风吹树叶让侧逆光树影缓慢扫过脸侧，主光方向稳定，暗部保留栏杆纹理。
镜头最后停住一拍，主体位于右侧三分线，左侧海面负空间压掉背景杂质。
```

### 0.1 正向视频提示词密度

高质量视频提示词的核心是让每个短语都有导演职责。

```text
镜头词负责关系：
胸部以上中近景、舒适近景、脸部近景、眼部特写、远景、高机位全景、手持跟拍。

表演词负责变化：
眼神回到镜头、眉心松开、下唇压住、呼吸停半拍、肩颈松掉、眼眶水光慢慢起来。

声音词负责触发：
试探、亲昵、敷衍、防御、心虚、不耐烦、轻蔑、暴怒、切断、哽住。

光影词负责情绪：
侧逆光树影扫过脸侧、窗边漫射光落在眼睛、黄昏暖光压住海面、暗部保留皮肤层次。

顺序词负责节奏：
开场承接尾帧，随后眼神变化，声音落下时表情到达峰值，句尾停住一拍。

剪辑词负责连续：
首尾帧同构图、同光源、同姿态、同表情余韵、同背景锚点，声音桥继续。
```

提示词越能把这些职责拆清，模型越容易生成一条有镜头、有表演、有声音、有剪辑停点的视频。

### 0.2 视频特征交集原则

高质量视频来自多个导演圈层的交集。单个“大词”只能给方向，多个具体特征共同决定结果。

```text
镜头圈层：
景别、机位、焦段、人物占比、主体落点、镜头运动和停点。

表演圈层：
触发、起始状态、脸部证据、身体证据、变化路径和结束余韵。

声音圈层：
说话态度、声线质地、音区、响度、停顿、重音、气息和空间位置。

光影圈层：
主光方向、辅光、轮廓光、动态光源、明暗分离、肤色和材质反光。

剪辑圈层：
首帧、尾帧、声音桥、视觉锚点、动作接力和情绪连续。
```

越重要的视频分镜，越要先写清受众体验目标，再从镜头、表演、声音、光影和剪辑中选择真正承重的部分；不是五项同时写满。

### 0.3 视频画面内容四核与注意力链

正式视频提示词的 `【画面内容】` 统一采用四核推导：

```text
视频画面内容 = 主体与注意力目标 + 动作与表演 + 效果系统 + 节奏与时长
```

四核不是四个词槽，也不是把 `机器人 + 打招呼 + 推镜 + 10 秒` 拼成一句话。它们构成一条观看因果链：先决定观众此刻必须看谁或看什么，再决定主体怎样变化，接着选择镜头、焦点、环境、光色、速度和声音怎样放大这次变化，最后为识别、动作完成、情绪建立和停点分配足够时长。

#### 单镜头主情绪与情绪曲线

注意力目标、观看任务和情绪目标必须分开判断：注意力目标回答观众看哪里，观看任务回答镜头完成什么信息或动作，单镜头主情绪回答观众在这个情绪节拍结束时主要感到什么。只有三者同向，镜头才真正集中。

单镜头主情绪不等于表演只能单调。一个节拍只有一个主情绪，辅助余味降低权重；一个镜头如果承担情绪转折，就按 `起点情绪 → 触发事件 → 表演 / 摄影 / 光色 / 声音变化 → 终点情绪` 展开。情绪变化是有方向的时间过程，不是把警觉、希望、孤独、危险和浪漫同时并列。

多个镜头共同构成视频情绪曲线：前镜可以积压，中镜误导或加深，后镜释放或翻转。切镜的价值之一就是把不同情绪职责分开，让观众按导演安排的顺序感受，而不是在一个镜头里同时解码全部感情。

#### 文戏 / 武戏情绪入场分流

文戏和武戏的共同目标是在第一有效节拍让观众进入人物处境，但有效证据不同。文戏先建立人物的关系目的与阻力：他想从对方那里得到什么，对方为什么不给，哪句台词、沉默、反应、距离变化或未完成动作让观众感到关系正在变化。武戏先建立危险方向、力量差和人物选择：攻击从哪里逼来，谁掌握主动，人物怎样蓄力、进入或退出危险线，结果怎样改变力量关系。第一有效节拍不是固定第一秒，也不是统一快剪；平静长镜头只要从开场就在增加关系压力，同样可以快速带入。

混合场景逐节拍确定主导模式。文戏主导时，动作只加强关系变化；武戏主导时，台词只加强危险、选择或能力差。不能让对白、打斗、运镜和奇观同时争夺主情绪。

摄影、表演、美术、光色、运镜、声音和特效没有独立于主情绪之外的完成分。每个选择都必须回答它如何加强本镜主情绪；无关的省略，削弱或转移情绪的删除、改写或延后到其他镜头。高质量不是所有专业维度都很满，而是最少的必要手段共同把一种感受推到最清楚。

本文出现的推拉摇移、横滚、FPV、机械臂、子弹时间、爆炸、雨声等全部是开放示例，不是封闭镜头库。AI 必须先判断镜头任务和观众注意力，再从摄影、表演、物理、声音和剪辑中继续推导适合当前画面的手段；不得为了使用某个术语而反向制造不需要的动作。

#### 主体与注意力目标：这一刻让观众看哪里

视频主体不只指人物本体，也可以是手、眼睛、刀刃、拳头、倒计时、雨水、爆炸波、门外声音引发的反应、两个人的距离或某个正在发生的现象。每个镜头先确定一个主注意力目标，其他人物、道具、背景、光影和声音按主次服务它。

注意力集中依靠多个通道共同完成：

```text
注意力控制 = 景别与主体占比 + 构图落点 + 焦点 / 景深 + 运动差 + 明暗 / 色彩反差 + 导引线 + 声音指向
```

主体可以在同一段中迁移，但迁移必须有触发。例如先看人物眼睛，再由眼神下移和焦点转移看见握紧的拳头；或先听见画外金属撞击，再切到门外空走廊。不能让脸、背景爆炸、天空闪电、运镜和道具同时争夺最高权重。

#### 动作与表演：主体发生了什么可见变化

动作不是只有肢体运动。人物动作应从以下开放维度选择真正承重的部分：

```text
动作与表演 = 台词 / 发声 + 脸部表情 + 眼神 + 呼吸 + 肢体动作 + 道具交互 + 对方反应 + 环境响应
```

#### 演员表演因果与八维编译

人物表演的起点不是情绪标签，而是 `人物在既定关系和阻力下想得到什么结果`。人物会先用反击、否认、讨好、沉默、转移或装作平静等策略维持控制；具体台词、重词、动作、声音、视线或新信息改变平衡后，脸、目光、身体、声音和距离才按人物控制能力先后泄露。表演的底层链是：

```text
人物目的与阻力 → 保护策略 → 精确触发 → 多通道反应 → 人物行动与关系结果 → 结束状态
```

复杂对白、情绪转折、长镜头和多人对手戏在内部按八维排演：`时间段、人物目的、情绪变化与保护策略、精确触发、面部动作与可选 AU、目光身体与关系距离、声音呼吸与停顿、结束状态与静止反应`。八维分别负责可读时间、行动方向、复合情绪形成、刺激反应因果、近景脸部证据、关系与空间行动、台词声音时间轴、余波和连续接口。`禁止提前反应` 贯穿八维，限定触发前不得落泪、崩溃、吼叫、退缩、转身或完成后续道具动作。

八维是完整内部判断，不是正式正文八个标题。功能表演只需简短态度、动作 / 声音和结束状态；单次承重转折内部八维完整，正文保留目的、保护策略、触发、2-4 个承重通道、禁止提前和结束状态；15-30 秒复杂表演按节拍建立时间轴，全局不变项只写一次，后续只写新触发和变化量。一个自然语言因果句可以同时承载多维，例如：`她要逼他承认自己的付出，仍用愤怒压住受伤；听见“这不算挣钱”时呼吸停半拍，眉间内收、眼眶才出现水光，声音从硬直降到发颤，但句尾前不落泪、不移开视线；说完仍盯着他，胸口起伏，等他回答。`

FACS / AU 只校准可见面部运动。先写自然语言，再在近景、脸部清楚且动作确实承重时附 1-3 个 AU；AU 不是情绪公式，也不替代人物目的、目光、身体、声音和空间。FACS A-E 与 OpenFace 等工具的 0-5 输出不是同一标度。正式压缩先删理论解释、重复外观和重复情绪词，再把字段合并为因果句；AU 最后加入，也最先在不影响自然语言时删除。字符仍不足时删非承重效果或拆 VID，不删目的、触发、禁止提前反应和结束状态。

情绪标签必须翻译成可见 / 可听证据。`攻击性增强` 可以落成眼睛由暗红待机光逐渐变为高亮红光、头部缓慢转正、机械手指依次收紧、肩部液压结构加压下沉、金属关节发出更重的锁止声；`压抑悲伤` 可以落成眼眶湿润却不落泪、嘴角维持平直、呼吸停在胸口、手指压住衣角、身体没有靠近镜头。模型和观众都是通过变化证据感受情绪，不是通过作者给情绪命名。

动作默认按因果链描述：

```text
起始状态 → 触发 → 动作起点 → 路径与速度 → 接触 / 受力 → 可见结果 → 反应 → 结束状态
```

动作简单时可以压缩，例如 `红色机器人面向镜头，右臂抬到肩高，手掌展开左右摆动两次，头部轻轻点一下`。动作复杂时继续拆解发力、路径、受力、衣料 / 材质 / 地面响应和停点，不用 `动作流畅、炫酷打斗` 代替。

多人动作必须区分威胁并发与力量关系可读。决定性接触可以是短促串行，也可以让主角的一件武器同时承受多件兵器；后一种写法必须明确不同攻击来源与接触位置、支撑点、合力方向、位移 / 形变、胜负和情绪结果，并让这一拍只表达主角震开、敌方压退或技术卸力中的一种结果。没有这些证据时，模型才会把所有武器聚成无意义的中央接触团，应拆回无空档串行接触。

景别按证据容量分工，不按情绪贴标签。较远景别建立阵形、危险方向和结果尺度；全景 / 中远景展示完整动作与位移；中景 / 中近景展示攻防关系与重心；近景 / 特写展示接触、手部、呼吸和眼神；大特写只承担单个关键细节。同一主体连续剪辑时，如果轴线、构图与动作相位相近，相邻景别变化容易像误切；优先跨过一个景别、改变约 30 度机位，或让动作相位 / 信息目标明显变化。以上是经验，不是禁止相邻景别的硬规则。

动作方法从角色身份推导。轻灵技巧型使用切角、擦身、卸力、借力、短腕动作和连续换位；重型力量型使用扎根、宽架、硬挡和多向压制；远程控制、范围能力和地形生存继续按题材扩展。判断依据是体格、兵器、训练、能力、性格和目的，不按性别套固定模板。能力差再决定打斗体量：势均力敌交换反转，中度占优高速逐个击破，压倒性碾压极少动作清场，弱势求生依赖地形与代价。

动作镜头承接要让观众先预测再看到兑现。上一镜尾部按需保留 `本镜结果 + 下一威胁线索 + 摄影机方向`，用动作匹配、方向匹配、视线匹配、声音提前进入或运动物遮挡建立趋势；下一镜从同一刀尖、影子、声音、视线或运动物的下一相位开始。遮挡可以藏切点，但不能单独承担因果承接。

高武、机甲、枪战、追逐、超能力和大型破坏使用开放的爆发动作链：

```text
预载 / 蓄力 → 瞬时释放 → 高速位移或力量传播 → 极短接触 → 明确结果 → 余势进入下一动作
```

题材只改变发力介质。人物可以由脚掌、腰胯、脊柱、肩肘和兵器发力；机甲可以由承重脚、关节锁止、伺服蓄压和推进器矢量发力；枪械可以由预瞄、扳机、后坐和弹道发力；爆炸与科幻奇观可以由能量积聚、结构应力和冲击波传播。其他题材继续按同一因果推导。高速必须留下发力点、起终位置、环境反向响应、惯性 / 拖曳、声音时差和动作结果；角色能力通过预动作大小、有效路径长度、接触时长、结果规模和控制精度拉开。

#### 效果系统：怎样让变化被观众准确感受到

本项目里的“效果”不只指爆炸、闪电和粒子特效，而是所有改变观众观看方式的视听手段：

```text
效果系统 = 运镜与稳定方式 + 焦点与光学 + 环境与天气 + 光影与色彩 + 速度与时间 + 声音空间 + 切换与转场
```

效果选择必须回答两个问题：它怎样改变屏幕上的可见 / 可听结果，它为什么能放大当前注意力和情绪。一个没有屏幕结果的术语不能进入正式提示词；一个不能服务镜头任务的炫技效果不占用生成注意力。

#### 运镜具象化：从术语翻译成摄影机和画面的变化

所有运镜统一按以下链路书写：

```text
观看意图 → 摄影机物理路径 → 屏幕变化 → 情绪倾向 → 停点
```

`推、拉、摇、移` 是人类对摄影机运动的概括，正式提示词需要继续展开：

```text
固定镜头：
摄影机位置、角度和焦段保持不变；写清画面固定在哪个构图，主体在固定框内怎样动作，背景哪些元素保持稳定。

推镜：
摄影机沿视轴向主体移动；写清起始景别、前进方向、速度、主体在画面中怎样变大、背景透视怎样变化、最终停在哪个表情或细节。它常有靠近、发现、压迫或聚焦的情绪倾向，但含义由主体状态、速度、稳定度和声音共同决定。

拉镜：
摄影机沿视轴远离主体；写清从哪个局部拉开、周围什么空间逐渐出现、主体怎样变小、最终揭示什么关系。它可以表现释放、孤独、真相揭示或环境压力，不固定等于任何一种情绪。

摇镜 Pan / Tilt：
摄影机位置不变，镜头原地水平或垂直转动；写清从画内哪个对象起，向哪个方向摇，经过什么空间或遮挡，停在画内 / 画外出现的什么新对象上。

移镜 / Track：
摄影机机身沿水平、垂直、弧线或空间轨迹整体移动，角度可以保持或同步变化；写清运动方向、与主体的距离、主体如何在画面中位移或离开、背景怎样横向划过、最终构图是什么。
```

专业运镜也按同一原则继续推导。例如：

```text
横滚 Roll：摄影机围绕镜头中心轴旋转，写清顺 / 逆时针、倾斜角度、速度、地平线怎样转动和何时停正。

机械臂关键帧：写清每个空间节点、机位高低、移动方向、加减速、节点停顿和节点之间怎样转换；`机械臂` 只说明稳定与可重复，不能替代轨迹。

FPV：写清从哪里高速接近、贴近哪个轮廓、沿什么圆形 / S 形 / 穿越路径飞行、是否上升下降、横滚程度、运动模糊和最后停在哪个稳定画面。

希区柯克变焦：机身推进同时光学变焦拉远，主体大小基本不变，背景空间被拉伸；还要写速度、触发和主体反应。

复合运镜：可以同时推进并上仰摇、横移并环绕、下降并拉远，但必须分别说明机身位移和镜头转动，保证模型知道两个变化如何同时发生。
```

运镜情绪不是固定字典。缓慢推近面对哭泣的人可能是亲密靠近，面对持刀者可能是压力逼近，面对未知门缝可能是危险发现；同一个运镜的情绪由起终景别、主体状态、速度、稳定方式、焦点、声音和上下文共同决定。规则提供的是情绪倾向和推导方法，不是 `推 = 紧张、拉 = 孤独` 的死映射。

#### 稳定方式：镜头运动本身也有身体感

稳定度必须写成可见运动，而不是只写 `手持感`：

```text
固定 / 锁定：地平线、机位和构图保持稳定，主体动作承担变化。
机械臂 / 轨道：点到点路径精确，加减速受控，节点短暂停稳，无步伐起伏。
肩扛手持：带摄影师步伐产生的低频上下起伏和轻微左右摆动，主体仍保持可读。
剧烈手持：高频上下震动、左右偏摆和地平线颤动，适合爆炸、奔跑或失控；必须在关键画面重新抓住主体并停稳。
呼吸微晃：极低幅度周期起伏，适合 POV、病弱、等待和安静凝视。
```

例如 `红色机器人保持静止，肩扛手持摄影机以步行速度缓慢靠近，画面随脚步出现低频上下起伏和轻微左右摆动，地平线基本可读；机器人的脸始终在中央焦点，最后在胸部以上近景停稳`。这句话同时说明了主体、摄影机身体感、注意力和停点。

#### 焦点与光学：注意力可以在镜头内部转移

焦点描述至少写：谁清楚、谁模糊、焦点从哪里开始、何时因什么动作转移、最终锁在哪里。`背景虚化，焦点在人脸上` 适合简单镜头；复杂镜头要写可见过程：

```text
侧面平视近景，红色机器人朝画面右侧，头部占画面右半；焦点先锁在雨水沿面甲滑落的轨迹，远处街道化成柔和散景。它的右手在前景握紧，焦点由面甲平滑转移到拳头关节，拳头由模糊变清晰，脸部退入柔焦。
```

焦点转移不是装饰，它相当于导演在画面里说“现在看这里”。焦点、景别、主体运动、亮度和声音要指向同一注意力目标；如果它们互相冲突，观众会分神。

#### 环境、天气、光色：世界也可以参与动作

环境效果必须有前状态、变化来源、变化过程和对主体的影响。`背景爆炸` 要写爆炸从哪个空间发生、火光先照到哪里、玻璃 / 金属 / 混凝土怎样受力、烟尘向哪个方向扩散、冲击波是否影响主体衣料或机位。`晴天变雨天` 要写天空亮度下降、云层压入、第一批雨点出现、地面和主体材质逐渐湿润、色温和反射怎样改变。

光色变化同样属于动作链：

```text
光源出现 / 消失 / 移动
→ 主体受光部位改变
→ 高光、暗部、阴影和反射改变
→ 色调或对比改变
→ 情绪和注意力改变
```

不只写 `变成冷色调、顶光聚光灯`，还要写环境暖光怎样退去，顶部冷白聚光怎样收窄到主体脸和肩部，背景落入低饱和蓝灰暗部，眼睛或道具成为唯一高亮点。

#### 速度与时间：用对比让观众来得及感受

速度至少分为主体速度、摄影机速度和环境速度。三者可以一致，也可以形成对比：主体静止而摄影机高速环绕，主体快速挥刀而镜头在爆点短暂慢化，人物正常移动而背景人群延时加速。

子弹时间、慢动作、速度渐变等概括必须继续写：哪一层变慢或冻结，哪一层仍然运动，变化从什么触发开始，持续到哪个可见结果，何时恢复正常速度。例如爆炸冲击波和玻璃碎片进入慢动作，机器人头部仍以正常速度缓慢转向镜头，摄影机沿半圆轨迹移动；拳头完全握紧时恢复正常速度并发出金属锁止重响。

速度的目的不是让画面一直快或一直慢，而是控制观众的知觉时间。动作爆点太快，观众来不及形成情绪；慢动作没有关键细节，观众只会感到拖沓。速度变化必须把时间让给动作因果、表情证据、材质受力或奇观尺度。

#### 声音空间：让画框之外的世界存在

声音描述按以下开放结构组织：

```text
发声对象 / 事件 + 材质与动作 + 声源方向和距离 + 所在空间 + 先后层次 + 音量 / 频段 / 冲击 + 混响与衰减 + 对画内主体的影响
```

画内声要和动作同步，例如机器人每一步同时出现低沉金属落脚、关节伺服、液压驱动和地面低频震动，随着它走向画外，音量下降、低频变薄、街道混响拉长。爆炸声要写来自远处建筑后方，玻璃大面积碎裂、金属结构撕裂、混凝土坍塌、碎石落地和烟尘翻涌分层出现，余震与碎片声在街谷间持续回荡。

画外声音用于建立不可见空间和想象。例如 `画面外右后方的远处街区传来两声汽车喇叭，声源始终在镜头之外，声音经过高楼反射变得轻微空旷；机器人头部向右偏转十度，但画面不揭示汽车`。观众会感到画框之外仍有完整城市，而不是只看见一块布景。

项目默认声音策略固定为：只生成对白、动作声、衣料声、道具声和环境声，不生成 BGM；多条素材的音乐由后期统一铺设。只有老胡明确要求模型内音乐、单镜头音乐表演或音乐本身参与画面动作时才改变。

#### 节奏与时长：给变化足够被看见和感受到的时间

节奏不等于切镜次数。它由镜头任务变化、动作速度、表演停顿、焦点迁移、环境变化、声音密度、切换频率和快慢反差共同形成：

```text
节奏 = 信息 / 情绪任务变化 + 镜头持续 + 动作速度 + 停顿停帧 + 声音节拍 + 快慢 / 动静 / 远近对比
```

时长按最低可读预算倒推：

```text
所需时长 >= 主体识别时间 + 动作完成时间 + 情绪建立时间 + 效果展开时间 + 停点 / 切换余量
```

多镜头时不能只把各动作所需时间相加，也不能先给每镜分配固定秒数。先判断主情绪需要连续压迫、完整身法、高密度攻击还是爆发后的沉淀，再选择连续跟拍、高强度多切或混合覆盖。一次完整动作可以跨多个短镜头：来路、接触、脚步、受力、反应和空间结果分别成为新的观看证据，只要切后进入下一动作相位并保持状态连续。短镜头既可以是单信息插入或快闪蒙太奇，也可以是激烈动作的连续多机位覆盖，不能仅凭时长判定对错。

简单固定镜头里机器人抬手打招呼，可能只需要一个短镜头；天气变化、眼睛变红、焦点转拳头、远景拉开和雷声落下同时出现，就需要更长时长、删减任务，或拆成多条独立素材后期剪辑。10 秒或 15 秒不是质量标签，关键是观众是否来得及识别每个变化。表情渐变、哭意形成、复杂受力和空间揭示通常比单一手势需要更多时间。

连续视频没有剪切时，按一镜到底写摄影机路径和动作阶段；同一条生成内发生切镜时，显式写 `切镜`、切换触发、新景别和新注意力目标。例如：

```text
镜头缓慢推进到机器人胸部以上近景；它的眼睛亮度升高时切镜，脸部特写，雨水沿面甲流下。右手握紧的金属锁止声触发切镜，手部特写，焦点从模糊面甲转到清晰拳头。雷声落下时切回建立镜头，远景缓慢拉开，机器人在雨幕中逐渐变小。
```

每个切镜都必须增加新的信息、情绪、动作阶段、空间关系或注意力变化。镜头很多且每个切点都要精确时，分别生成素材再剪辑；单条模型内部多切只用于关系清楚、允许模型分配持续时间的段落。正式模型正文用镜头编号、动作先后、触发和停点表达节奏，不写内部逐秒时间码。

#### 图生视频与文生视频的描述预算

图生视频和文生视频共享四核，但文字承担的职责不同：

```text
图生视频：输入图片负责首帧身份、主体外观、基础构图和已有场景；提示词重点写从这张图开始怎样动、哪些内容保持、焦点 / 运镜 / 光色 / 环境 / 声音怎样变化、最终停在哪里。

文生视频：文字同时承担首帧建构和时间变化；必须先写足主体、场景、时间、风格、构图、必要外观和材质，再写动作、效果、节奏与声音。

资产引用视频：已实际投喂的人物 / 场景 / 道具资产承担稳定外观；正文不重复整份资产说明，只重申本镜会变化、受光、受力、被遮挡或必须强调的局部。没有资产固定的元素仍按文生视频粒度写清。
```

一张图片加一段图生视频运动提示词，本质上共同完成了文生视频提示词的两部分：图片提供视觉初始状态，文字提供时间变化。资产越完整，正文越应把字数留给动作和效果；资产越少，正文越要补足模型看不见的首帧信息。

#### 首尾帧双端锚定与变换链

首尾帧模式不是普通图生视频多放一张图，也不是 A 段尾帧接 B 段首帧。它的核心任务是：在首帧和尾帧两个输入硬锚点之间，设计一条连续、可读、可收束的变化因果链。

写提示词前先做端点兼容性分析：

```text
必须保持什么：主体身份、比例基线、关键结构、道具归属、运动方向或品牌识别。
必须改变什么：姿态、服装、材质、产品形态、场景、时间、天气、光色或空间位置。
共同桥梁是什么：相似轮廓、重复颜色、同向运动、共同光源、遮挡物、反射面、碎片、烟雾、隧道或画面边缘入口。
最大断裂点在哪里：景别、机位、透视、主体位置、朝向、尺度、光线方向或场景结构。
```

共同桥梁是开放属性，不是固定转场菜单。选择哪一种桥，取决于两端真正共享什么以及观众要感受到什么。首尾差异越大，越需要明确的遮挡、过渡空间、材质桥或运动桥；两端越接近，越应减少特效，让动作、焦点和光色渐变承担连接。

首尾帧变换链：

```text
首帧状态
→ 触发机制
→ 解构 / 离场
→ 中间状态链
→ 形态、服装、材质或场景变化
→ 尾帧元素提前召回
→ 摄影机减速与构图校正
→ 精确落入尾帧
```

变化过程优先使用一个主变换机制和一条主摄影机路径。FPV 穿越、环绕、机械臂、横滚或模拟子弹时间都可以使用，但必须写清摄影机从哪里出发、穿过或绕过什么、主体和背景在屏幕上怎样变化、焦点落在哪里、最终怎样回到尾帧机位。炫技只能放大变化，不能掩盖变化逻辑。

尾帧收束不能等到最后一瞬间硬切。尾帧中的主色、轮廓、光源、背景锚点、服装局部或主体姿态要提前进入画面；随后减少碎片、模糊、横滚和速度，校正主体比例、位置、景别与透视，稳定落入尾帧。模型仍是概率生成，因此“双端锚定”是输入和验收目标，不是对每次结果的技术保证。

开放示例：手机背壳可以由金属外壳、玻璃面板和摄像头模组沿真实结构接缝解构，摄影机缩小后从悬浮零件之间 FPV 穿越，零件受同一旋转涡流牵引，在尾帧轮廓提前出现后减速归位；旅行 Vlog 可以由电脑屏幕光扩成遮挡入口，人物被光吸入过渡空间，摄影机背后跟随，服装、环境声和光色沿路径变化，出口先露出尾帧场景的天空与地面，人物落地后镜头校正到尾帧构图。示例用于展示推导方法，不限定只能使用拆解重组或时空隧道。

#### 四核镜头高密度执行模板

四核是内部推理骨架，正式代码块仍保持三段式。`【画面内容】` 内每个独立镜头连续编号并压缩为：

```text
【镜头01｜景别｜机位 / 视角｜运镜 / 转场】主体的起始状态、触发、动作 / 表演路径和可见结果。
【VFX】额外视觉效果。（按需）
【环境音】持续声场。（按需）
【动作音】同步动作声。（按需）
【音乐 / 节拍】本镜卡点关系。（按需）
【台词】角色名（表演）：“确认原文”。（按需）
```

精简不是删除因果，而是删除重复、解释性文字和无职责词。只要一个短语已经说明清楚屏幕变化，就不需要再用多组同义形容词包装；只要资产已经提供外观，就不需要在每镜重复整套造型。新的编号镜头头部承担边界信号，硬切或软切机制写进最后一栏；同一镜头只保留一个头部。高信息密度的标准是读完能在脑中连续预演，而不是字数越长越好。

## 1. 不变骨架资产

不变骨架资产是 AI 视频提示词成立的固定容器。

### 1.1 三层结构固定槽位

正式视频提示词的固定结构：

```text
【基础设定】
实际资产：
声音总策略：
输出限制：（按需，只写少量抽象边界）

【场景状态与氛围画质】
开拍前场景状态：
全段风格 / 摄影介质 / 宏观色彩：

【画面内容】
【镜头01｜景别｜机位 / 视角｜运镜 / 转场】画面描述。
【VFX】按需。
【环境音】按需。
【动作音】按需。
【音乐 / 节拍】按需。
【台词】角色名（表演）：“原文”。（按需）
```

三层职责必须区分：

```text
基础设定：
实际输入、声音总策略和少量抽象输出限制，不复述当前剧情。

场景状态与氛围画质：
先固定开拍前已经成立的空间、人物、道具、天气、人群和现有破坏，再固定画面风格、摄影介质、色彩影调和全片审美边界。

画面内容：
用连续编号镜头块写本镜发生的动作、表演、光影变化、逐镜声音、环境交互和转场；编号只标顺序，不绑定逐秒时间码。
```

### 1.2 单条独立生成固定槽位

AI 视频平台默认不读取上一条提示词。每条提示词都要自足。

单条生成前要逐项判断下列信息，只有本镜实际需要的内容才进入正文。`确定时长`、实际调用资产和核心变化通常不可缺；其余为条件项：

```text
确定时长
生成画幅
本镜实际调用资产
本镜人物状态
本镜声音状态
景别
机位
运镜
构图落点
动作起点
动作过程
动作结果
光影来源
声音来源
焦点落点

```

### 1.3 镜头预演板条件槽位

镜头预演板默认给人确认构图、站位、动线和留白，不默认投喂视频模型，也不强制每条视频提示词配套。只有构图、比例、复杂走位、空间方向或高成本生成风险需要先验证时才制作；简单固定镜头或已有可靠首帧时可以省略。

需要预演板时，从下列槽位选择必要信息：

```text
参考资产
首帧参考
时间点 / 关键帧
线框构图
构图规则
景别 / 机位
空间锚点
引导线 / 动线路径
主体比例与位置
```

预演板只锁人工需要确认的构图、站位、动线、比例和视线，不锁真实脸、服装颜色、材质和最终光影；视频提示词控制真实外观、表演、声音和时间变化。只有明确把干净首帧或构图参考图作为模型输入时，才将其转换成无表格、无箭头、无文字的参考图。

### 1.4 视频质量路径

一条高质量 AI 视频通常按以下路径成立：

```text
第一个画面：
主体、景别、构图、光源和情绪起点立刻清楚。

第一个动作：
人物或镜头有明确起点，动作能在真实空间里排练出来。

第一个变化：
表情、声音、光影、道具或环境触发可见变化。

第一个停点：
在识别、动作、情绪或剪辑任务完成处留下可读状态；只有本镜承担视觉记忆职责时，才把它设计成可截图的审美停点。

下一条起点：
只有本条需要连续拼接时，尾帧才留下足够的姿态、方向、光源、声音或动作锚点供下一条承接；独立素材不强制。
```

视频提示词先服务主观看任务和主情绪，再按需服务生成稳定、表演、声音与剪辑。画面美感、时间变化、动作、停点和光影没有独立完成分，只保留真正承重的部分。

### 1.5 情绪识别与观众代入

主情绪清楚只保证观众看懂人物，不保证观众进入人物。高质量叙事视频要根据段落职责，从以下六条路径中选择真正承重的部分：

```text
目标与代价：人物想得到什么，失败会失去什么，观众为什么替他在乎。
信息对齐：观众与人物同时发现、提前知道还是晚一步理解。
空间对齐：危险、出口、距离、遮挡、视线和动作方向是否可感。
身体对齐：呼吸、重心、受力、速度、触感、声场和环境反馈是否形成身体经验。
时间对齐：等待、逼近、触发、冲击和余波是否被观众亲历。
选择对齐：观众是否跟随人物做决定并看到代价。
```

六条不是逐镜必填。一个段落可以先用客观远景建立空间，再用近主观或声音把观众拉近，在关键动作中共享受力，最后用固定镜头或拉远让后果沉淀。全程 POV、特写、手持、快速剪辑和强音效会造成空间丢失与感官疲劳；距离变化和节奏呼吸也是代入设计。

### 1.6 时间密度诊断尺

视频和图片最大的差别是时间。不同长度承载不同的信息量。

3、5、8、12、15 秒只表示不同预算，不对应固定动作数量或情绪结构。先估算主体识别、动作完成、情绪进入、效果展开和剪辑接口需要多少知觉时间；预算不足就删任务、压缩过程或拆素材，预算充足也不为填满时长添加动作。表情停留由变化幅度、景别、台词、角色克制程度和观众识别速度决定，不统一规定 0.5 秒、1 秒或其他固定值。

## 2. 镜头任务审美特征资产

### 2.1 通用基底

高质量视频提示词先判断镜头任务，再选择景别、运镜、表演和声音。镜头的丰富度服从主任务，每一条都要知道自己承担什么。

### 2.2 特征颗粒

```text
信息镜头：
交代人物、地点、关系、时间和道具，优先清晰、稳定、可读。

情绪镜头：
让观众读脸、眼神、嘴角、呼吸、肩颈和声音变化，优先合适近景。

动作镜头：
交代起点、路径、受力、接触点、结果和空间边界，优先动作因果。

奇观镜头：
展示尺度、规则、空间层次和人物反应，宏大感由人物比例、空间深度、光影层次和环境运动共同支撑。

转场镜头：
用遮挡、光、物件、动作、声音或匹配构图连接前后镜头。

封面 / 壁纸镜头：
必须有清楚的主情绪、主体与视觉停点；留白、光影、色彩和空间层次按职责选择，不要求全部出现。
```

### 2.3 特写镜与蒙太奇特征

特写通过放大局部、压缩信息和制造视觉落点，让观众把注意力交给导演。

```text
特写钩子：
眼睛、嘴角、手指、泪光、门缝、火苗、手机屏幕、旧物边缘成为开场视觉落点。

特写连接器：
用相似形状、相似动作、相似光斑或相似材质连接两个时间点。

心理投射特写：
水波、玻璃反光、火光跳动、衣料褶皱、手指停顿承载人物内心波动。

时间压缩特写：
用物件状态变化、光线位置变化、汗水、纸灰、杯中水位、屏幕亮灭表现时间流逝。

节奏切口：
特写进入时画面信息收窄，特写离开时空间重新打开，形成节奏呼吸。
```

特写适合做开场钩子、情绪证据、时间折叠和转场连接。它的价值是控制观众注意力，让细节承担叙事和情绪功能。

### 2.4 质量增益

命中镜头任务特征后，提示词会从“画面描述”升级为“导演调度”。模型更容易知道该优先生成什么。

## 3. 人物表演审美特征资产

### 3.1 通用基底

高质量人物表演要把“开心、伤心、生气、温柔”这类情绪标签展开成触发、起始状态、变化路径、身体证据、声音证据和结束状态。

### 3.2 特征颗粒

```text
主情绪单一：
单条提示词只承担一个主情绪，最多带一个过渡情绪。

触发明确：
表情变化来自一句 VO、一个动作、一个道具、一个眼神或一个空间变化。

脸部证据：
眼神、眼睑、眉心、嘴角、嘴唇、下巴、鼻翼、吞咽、呼吸、眼眶水光。

身体证据：
肩颈松掉、背部僵住、身体后撤、微微前倾、头部偏开、重心不稳。

声音证据：
气口、停顿、音区、响度、咬字、尾音、哭腔、沙哑、电话失真、脑内回响。

结束状态：
本镜最后留下一个可接下一镜的情绪余韵，例如笑意没收住、眼眶红了、身体空掉、视线回到镜头。
```

### 3.3 情绪表演颗粒

人物情绪要写成可见变化路径。

```text
防备：
眼神先停住，眼睑略收，嘴角保持平直，身体微微后撤，肩颈有一点僵。

好奇：
视线重新聚焦，眉心松开，头部轻微前倾，呼吸变浅，眼里出现细小高光。

不屑：
嘴角单侧轻抬，眼神短暂下扫，再回到镜头，表情短促收住。

期待：
眼神变亮，嘴唇轻抿后松开，肩颈微微向前，身体重心靠近镜头。

强撑：
下巴轻抬，嘴角保持礼貌弧度，眼眶有水光，呼吸比表情更先乱。

委屈：
下唇压住，鼻翼轻动，眼眶慢慢发红，短促吸气后低头半秒。

被击穿：
眼神失焦，呼吸断一下，肩颈松掉，泪水从眼眶边缘滑出。

疲惫：
眼皮变沉，嘴角失去支撑，身体重心下坠，视线回到镜头时带着空感。
```

表演颗粒要和镜头距离匹配，但没有固定映射。需要读微表情时可以靠近，也可以用高分辨率中景、镜面反射或遮挡观察；身体崩塌和失魂离开通常需要更多空间，也可以用局部特写表现。选择取决于本镜主情绪与观看关系。

### 3.4 关系距离特征

```text
舒适近景：
当镜头要让观众处在平等、可读但不过度逼近的关系里，可以保留脸、肩颈和少量环境；人物占比由距离感和证据大小倒推。

脸部近景 / 特写：
当局部表情、皮肤、眼泪、嘴唇或信息遮蔽承重时可以使用；亲密、威胁、审讯、喜剧或冷静观察都可能成立。

远景 / 全景：
当空间、距离、群体、路径或人物与环境比例承重时可以使用；它也可以表现自由、秩序、喜悦或事实说明，不固定等于孤独。
```

看清表情不等于怼脸。镜头距离本身就是关系表达。

### 3.5 镜头距离正向资产

```text
胸部以上中近景：
同时需要脸部证据、肩颈动作和少量环境关系时使用。

舒适近景：
需要可读表情且保持不过度逼近的观看关系时使用；不固定人物百分比。

脸部近景：
需要局部表情、身份或质感证据时使用；保留多少脸侧空间由构图与主情绪决定。

眼部 / 唇部特写：
局部本身承担信息、动作或主情绪时使用；时长与停点由可读性和节奏倒推。

半身景：
同时需要身体重心、手部、服装或人物距离时使用；是否保持脸部清晰由主注意力决定。

远景 / 高机位全景：
需要空间结构、路径、群体秩序、尺度或距离关系时使用，不绑定固定情绪。
```

镜头距离要服务观众和人物的关系。对话可以舒适、逼近、疏离或被遮挡；情绪破裂可以贴脸，也可以让环境突然变大；人物离开可以用远景，也可以只留下局部空位。选择由本镜主情绪和证据位置决定。

## 4. 声音与 VO 审美特征资产

### 4.1 通用基底

高质量视频提示词里的声音是表情触发器、时间桥、情绪压力和人物关系的一部分。

### 4.2 特征颗粒

```text
态度先行：
先写示好、试探、亲昵、敷衍、防御、心虚、不耐烦、责备、轻蔑、暴怒、切断等说话态度。

参数承接：
再写音区、响度、语速、停顿、重音、气息、咬字、软硬、距离、混响和衰减。

阶段曲线：
同一个男声 / 女声随关系阶段变化，声音从示好、靠近、敷衍、防御、攻击到切断形成清楚曲线。

声音位置：
脑内 VO、画外音、镜头前方声音、电话声、门外声、远处喊声必须区分。

声音触发表情：
如果声音是主要触发器，画面内容里要写人物听到后脸和身体如何反应。

声音桥：
旧话、火声、电话电流、脚步、门响、海浪、风声可以连接时间和情绪。
```

### 4.3 声音情绪词汇资产

声音先写情绪态度，再写声学参数。态度决定观众听见的人物关系。

```text
试探：
语气放慢，句尾收住，重音轻放，像在观察对方反应。

亲昵：
音色靠近，气息更软，尾音微微拖长，句子之间有自然笑意。

敷衍：
音量平，尾音短，停顿少，重音落得轻，语气像在快速结束话题。

心虚：
重音不稳，句尾变轻，气息有短暂停顿，咬字略松。

防御：
音色变硬，语速略快，重音压在解释性词语上，句子边界清楚。

不耐烦：
咬字变硬，句子切得短，停顿压缩，重音落在否定词或反问词上。

轻蔑：
音量不高，音色冷，尾音下压，重音带一点上挑的嘲讽。

暴怒：
音量冲上来，气息粗，字头有爆破感，句子之间停顿短而重。

切断：
音色变冷，语速放慢，停顿变长，尾音干落，空间感拉远。

哽住：
气息断开，字尾发紧，音量突然变小，下一句开头需要重新吸气。
```

### 4.4 声音空间资产

```text
镜头前方声音：
像说话者站在镜头背后，声音清晰靠前，能直接触发表演对象的眼神变化。

脑内 VO：
更近、更干、更少环境反射，像人物脑内回响，画面人物用表情回应。

电话声：
带窄频压缩和轻微电流感，距离变远，人物反应先于环境变化。

门外声：
带门板阻隔和低频衰减，人物先听见，再转头或停住。

回忆声：
轻微混响，边缘柔化，和现实环境声有层次差。
```

### 4.5 质量增益

命中声音特征后，视频拥有画面之外的情绪压力。观众能通过声音听见人物关系从靠近到抽离、从温柔到攻击、从现实到回忆。

## 5. 动作因果审美特征资产

### 5.1 通用基底

高质量视频提示词里的动作必须能在真实空间里排练出来。动作名不等于动作执行。

### 5.2 特征颗粒

```text
起点：
人物或道具从哪里开始，身体朝向哪里。

路径：
沿哪条线移动，经过哪些空间锚点。

接触：
哪只手、哪个工具、哪个部位先接触什么。

受力：
推、拉、按、扶、擦、递、接、撞、摔的力作用到哪里。

材料变化：
木头裂开、糯米皮合拢、纸灰飘起、火苗扩大、衣料被风带动。

结果：
动作结束后人物、道具、空间、情绪发生什么变化。

边界：
撞到墙脚、桌角、小凳、门槛、栏杆、床沿或空间边缘，动作结果由真实空间接触产生。
```

### 5.3 质量增益

命中动作因果特征后，生成结果会更真实、更可剪辑，观众不会觉得人物和道具在画面里随机漂移。

## 6. 光影画质审美特征资产

### 6.1 通用基底

高质量视频提示词的画质由风格、光影、色彩、景深、材质和运动稳定共同形成影像系统。

### 6.2 特征颗粒

```text
风格交集：
主风格母体 + 辅助风格 + 胶片 / 滤镜分级 + 明度对比 + 光影方式 + 肤色妆效 + 场景环境色。

光影分离：
亮面、半暗面、暗部细节、轮廓光、反光和背景层级分开。

动态光源：
风吹树影、火光跳动、车灯扫过、水面反光、霓虹雨地反射，有来源、有方向、有稳定运动节奏。

色彩主次：
1 个主色 + 1 个辅助色 + 1 个小面积点缀色，肤色被保护。

景深层次：
前景虚化遮挡、中景清晰主体、远景朦胧环境，焦点落点明确。

材质细节：
皮肤、发丝、衣料、木纹、金属、玻璃、纸灰、水汽和旧墙纹理可读。

运动停点：
每个情绪段或动作组只选择一至两个承重英雄帧；文戏从关系变化或表演结果中形成，武戏从蓄势、决定性接触或控场结果中形成。连接帧允许遮挡、甩镜、失衡、局部出画和方向性模糊，不能为了截图让人物一招一停。
```

### 6.3 氛围画质词汇资产

视频的氛围与画质要用中文专业词形成稳定风格交集。

```text
风格母体：
日系治愈短片、电影剧照感、纪实人像短片、青春短剧、低照度情绪片、商业人像影像。

摄影介质：
全画幅人像摄影、35mm 胶片颗粒、阿莱电影质感、手持纪实质感、长焦压缩空间。

光影方式：
窗边自然光、侧逆光、树影动态光、黄昏漫射光、海面反光、低照度局部光。

色彩影调：
清新透亮、低饱和、暖白肤色、冷灰暗部、柔和高光、明暗有层次。

空气状态：
海风水汽、窗边浮尘、雨后湿润、夜晚低照度颗粒、黄昏空气透亮。

人物材质：
白皙清透肤色、半哑光柔雾底妆、真实发丝、衣料垂坠、首饰细碎柔光、唇色纹理。
```

这些词共同决定视频的清透度、耐看度和人物情绪承载力。

### 6.4 动态光源资产

```text
树影动态光：
风吹树叶，侧逆光形成细碎树影，缓慢扫过脸侧、肩线和背景墙。

窗光变化：
窗边自然光稳定进入，薄纱窗帘轻动，亮部柔和移动，暗部保留皮肤层次。

海面反光：
海面细碎反光在脸侧或栏杆上轻轻跳动，画面保持清新透亮。

火光跳动：
火光在脸、手、墙面和道具边缘形成暖色微变化，背景暗部有层次。

车灯扫过：
远处车灯从背景掠过，短暂拉出轮廓光，随后回到低照度环境。
```

动态光源要有来源、方向、速度和作用对象。它的职责是让画面拥有稳定时间感。

### 6.5 原生直出影像链

当参考视频或关键帧未经后期调色却已经具备明确的光影、色调、肤质和镜头质感时，把它视为生成阶段完成的影像系统，不把效果归因于某个 LUT 或一句“电影感”。正式视频提示词先建立以下关系：

```text
场景与时间光源
→ 主光 / 环境光 / 分离光的方向、面积、色温与稳定性
→ 人物相对背景的曝光、对比和高光衰减
→ 皮肤、眼睛、嘴唇、发丝、衣料和首饰的局部反射
→ 背景冷暖、明度、清晰度和散景对主体的托举
→ 摄影机运动、焦点变化和人物运动中的光色连续
```

正式编译默认按 `光源 → 传播路径 / 介质 → 光的变化 → 落点材质 → 镜头可见结果` 的线性因果顺序；视频中的动态光再补充进入、移动、峰值、离开和恢复基线。详细光学机制统一执行 `画面氛围与画质规范.md` 的“光照事件链与传播路径”。只写来源而不写亮面、阴影、反射、透射、散射或色彩变化的屏幕结果，视为不完整；只写结果却无法解释来源、方向和受光对象，视为随机光效。

`【场景状态与氛围画质】` 负责写全段不变的光源基线、肤色基线、背景层次、成像介质和动态范围；`【画面内容】` 只写运动造成的变化，例如人物转头后眼神光怎样移到虹膜、发丝边缘怎样短暂变亮、背景暖色散景怎样产生视差、窗光怎样扫过衣料，以及镜头停点时哪些局部重新稳定。不要在每个镜头重复整套肤色和光影，也不能把变化交给模型自行猜。

视频验收至少检查五项：

```text
光源方向没有无因切换；
人物肤色没有随背景或镜头移动突然漂白、发灰或偏色；
眼神光、高光和阴影随头部 / 摄影机位置产生合理变化；
背景虚化、散景和反射有来源且不抢过眼睛与嘴唇；
需要截图的英雄帧中，主体边缘、眼睛、唇面和关键材质清楚稳定。
```

如果只写 `清透、柔和、治愈、电影感、原生直出`，却没有写光源、曝光、材质反射、背景分离和运动连续性，视为未完成的画质描述。

## 7. 构图与审美停点特征资产

### 7.1 通用基底

承担人物第一眼、情绪峰值、段落记忆、封面候选或传播视觉职责的镜头，需要一个暂停后仍能传达主情绪的审美停点。功能镜头、动作连接、信息证据和纯运动冲击不强制壁纸帧，只需完成自身任务并留下可剪辑状态。

### 7.2 特征颗粒

```text
视觉落点：
观众第一眼知道看脸、眼睛、手、道具、火苗、旧物或空间中的某个点。

引导线：
道路、栏杆、桌沿、窗框、门框、光束、阴影、人物视线或手臂方向带视线。

块面压杂：
天空、海面、墙面、暗部、虚化背景、雾气、树影和门洞阴影压掉杂质。

留白方向：
上方留白、侧边留白、负空间、标题空间或情绪空间明确。

镜头停点：
在本镜职责完成处形成可读状态；承担审美记忆时，可以落在三分线、中心轴、前景框、导引线终点或有意失衡的位置。

边角控制：
边角信息量服从主情绪。需要主体突出时压低干扰；需要拥挤、失控或环境压迫时允许边角充满，但不能是随机生成杂质。
```

### 7.3 故事板构图资产

需要镜头预演板时，它服务人工判断“镜头是否可控”，优先锁定与主情绪和动作因果有关的构图骨架。

```text
胸部以上表演构图：
人物从胸部以上进入画面，脸部清楚，肩颈可见，背景保留少量空间锚点。

面向镜头表演：
镜头前方声音或脑内 VO 触发人物反应时，人物眼线回到镜头，观众直接读脸。

三分线情绪构图：
人物脸部落在左侧或右侧三分线，另一侧保留海面、窗光、墙面或暗部负空间。

中心压迫构图：
人物居中，背景线条向人物收拢，适合被审视、被质问、被关系压住。

边缘呼吸构图：
人物靠近画面边缘，大片环境留白承载孤独、期待、失落或离开。

前景遮挡构图：
门框、窗帘、栏杆、树影或虚化前景切开画面，增强偷窥感、距离感和层次。

特写钩子构图：
眼睛、嘴角、手指、泪光、首饰或道具占据第一视觉落点，背景只保留必要暗示。
```

预演板按任务回答必要问题：人物或主体多大、注意力落在哪里、视线与动作怎样走、需要哪些空间锚点、是否需要留白、是否需要给下一条留下接续。不是每张都必须回答全部问题。

## 8. 连续拼接审美特征资产

### 8.1 通用基底

多条 15 秒以内视频拼成完整短片时，提示词必须服务剪辑连续。A 的尾帧要能成为 B 的首帧。

### 8.2 特征颗粒

```text
首尾帧复用：
B 条开场从 A 条尾帧的同一构图、光源、姿态、表情余韵继续。

情绪余韵：
上一条留下一个眼神、呼吸、嘴角、泪痕或身体状态，作为下一条情绪起点。

声音桥：
VO、环境声、回响、音乐或静默可以跨条延续。

视觉锚点：
栏杆、门框、木轮、火盆、病床、海面、树影等稳定物件承接画面。

动作接力：
上一条动作未完全结束，下一条从同一动作后半段继续。

遮挡转场：
袖口、门框、火光、纸灰、树影、低头、蒲团纹理或强光满屏形成转场点。
```

### 8.3 15 秒一镜到底拼接资产

15 秒以内分镜拼成完整短片时，连续性要同时覆盖画面、声音、情绪和光影。

```text
构图连续：
B 条开场沿用 A 条尾帧的人物位置、景别、画幅比例和背景锚点。

光源连续：
主光方向、动态光源、肤色明度、暗部重量和环境反光保持同一状态。

姿态连续：
头部角度、肩颈状态、身体重心、手部位置和服装褶皱承接上一条尾帧。

表情连续：
笑意、泪痕、眼神失焦、眼眶水光、嘴角收住或呼吸余韵延续到下一条首帧。

声音连续：
VO 尾音、海浪、风声、脚步、门响、电话电流或静默在剪辑点前后保持同一声场。

动作连续：
上一条未完成的转头、低头、抬眼、走远、停步或落泪，在下一条开头自然完成。

情绪连续：
下一条在上一条情绪余温上继续推进。
```

一镜到底感的关键是剪辑点前后状态一致，让观众感到时间连续。

## 9. 模型正文语言审美特征资产

### 9.1 通用基底

视频模型读的是画面和声音结果。正式提示词要写清主体、动作、光影、声音、材质、空间、表演和最终停点。

### 9.2 特征颗粒

```text
正向结果：
写主体、动作、光、声音、材质、空间和最终画面。

可生成术语：
摄影、灯光、美术、表演、声音、美妆、服装、材质要用对应领域能生成的词。

心理可见化：
心理状态转成可见证据，例如委屈写成下唇压住、眼眶发红、短促吸气。

弱词拆解：
小、轻、低、柔和、自然、高级要拆成幅度、速度、音区、响度、光线软硬、饱和度和镜头距离。

代码块纯净：
正式代码块集中呈现模型可生成的画面和声音结果。

引用明确：
引号只服务画面里真实需要出现的文字。
```

### 9.3 资产调用与展开资产

视频提示词中的资产引用要同时服务一致性和当前镜头执行。

```text
人物资产：
【@人物资产】固定脸、身材、发型、服装、妆容和基础气质；当前镜头重点展开表情、姿态、受光、声音触发和尾帧状态。

场景资产：
【@场景资产】固定空间结构、入口、反打、材质和光源方向；当前镜头重点展开人物站位、动线、遮挡、动态光影和环境声。

道具资产：
【@道具资产】固定形状、比例、材质和使用状态；当前镜头重点展开接触方式、受力、反光、声音和动作结果。

色彩资产：
【@色彩风格资产】固定主色、辅助色、点缀色、肤色、光源色和暗部色；正式提示词中展开为具体色彩与影调描述。

音色资产：
【@音色资产】固定基础声线、年龄感、音色质地和说话距离；当前镜头重点展开情绪态度、重音、停顿、气息和尾音。

首帧资产：
【@首帧参考】固定开场构图、人物姿态、光源和背景锚点；当前镜头从这一状态继续推进动作和表情变化。
```

资产固定“它是谁 / 它是什么状态”，画面内容写“这一镜它如何运动、受光、发声、接触、变化和停住”。

## 10. 特征权重与取舍资产

### 10.1 承重特征

```text
生成承重：
独立完整、资产引用准确、时长确定、画面内容可执行。

表演承重：
人物目的、保护策略、触发、承重表演通道、禁止提前反应和结束余韵；复杂节拍内部完成八维判断。

画面承重：
从构图、点线面、光影、色彩、景深和材质中选择真正传递主情绪或信息的关系，不要求全部出现。

剪辑承重：
连续素材按需选择首尾帧复用、转场锚点、声音桥、动作接力或情绪连续；独立素材不强造上下条关系。

复用承重：
提示词的构图、表情、光影、时长、资产、声音和动作因果都能被下一次创作继续调用。
```

### 10.2 正向兼容组合关系

```text
情绪近景：
舒适近景、眼线回到镜头、单一主情绪、脸部证据、声音触发、停住一拍。

崩溃特写：
脸部近景、呼吸断点、眼眶水光、声音哽住、暗部保留肤色层次、尾帧留下泪痕。

失魂远景：
人物缩小、环境变大、高机位或远景、走路无力、风景留白、声音衰减。

热恋期待：
胸部以上中近景、眼神变亮、身体微微前倾、暖白肤色、浅景深、声音亲近。

强撑理解：
舒适近景、礼貌嘴角、眼眶水光、短促吸气、声音放轻、镜头停住读脸。

评论钩子：
人物回到镜头、胸部以上中近景、眼神疲惫但清醒、声音靠前、背景简洁、留白干净。

一镜到底衔接：
首尾同构图、同光源、同姿态、同背景锚点、同声音桥、同情绪余韵。
```

### 10.3 审美组合语法

```text
镜头任务唯一：
一条提示词优先只有一个主任务。看脸、展示动作、交代空间、制造转场按主次排列。

强位互证：
主情绪与被选中的景别、声音、构图、光影或停点互相证明，不要求所有通道同时承担。

声音触发表情：
如果 VO 是核心，声音曲线和脸部变化必须绑定。

画面服务剪辑：
需要进入同一连续段落的素材才和上下条形成明确接续；独立空镜、可替换素材和单条成片按自身用途设计起止状态。

美感服务剧情：
光影、色彩、留白和运镜让人物处境更清楚、情绪更强。
```

## 11. 最终定义

高质量 AI 视频提示词来自稳定骨架和具体镜头特征的组合。

它是在稳定骨架里，让关键开放位置命中足够具体、足够互相支撑的镜头特征：

```text
基础设定自足，资产引用准确。
氛围画质有风格交集、光影分离、色彩主次和材质细节。
画面内容四核形成因果：主体与注意力目标明确，动作与表演可见，效果系统有来源和结果，节奏与时长足够感受。
画面内容有确定时长、景别构图、运镜路径、动作因果和镜头停点。
运镜已经从术语展开为观看意图、摄影机物理路径、屏幕变化、情绪倾向和停点。
焦点、环境、光色、速度和声音共同指向同一注意力目标，画外声音能建立不可见空间。
人物表演有触发、变化路径、脸部证据、身体证据和声音证据。
声音先写情绪态度，再写参数和空间。
图生视频、文生视频和资产输入采用与输入信息相匹配的描述预算。
连续镜头有首尾帧、声音桥、视觉锚点和情绪余韵。
正式模型正文集中书写可见 / 可听结果。
```

这份文档的核心用途是扩大 AI 对高质量视频提示词的可识别特征库。特征越细、越具体、越能组合，生成时能圈住的高质量区域就越小，视频越有机会接近真正可生成、可剪辑、可复盘、可发布的影像作品。
