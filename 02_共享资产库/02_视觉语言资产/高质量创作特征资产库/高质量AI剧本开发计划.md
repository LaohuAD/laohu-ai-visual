# 高质量 AI 剧本开发计划

本文档的身份是：高质量 AI 剧本审美特征资产库。

它的职责集中在高质量 AI 剧本审美特征沉淀，只沉淀两类资产：

```text
不变骨架资产：
影视剧本天然需要的固定容器、结构槽位、人物关系、场景功能、台词字段和下游视觉交接位置。

开放审美特征资产：
高质量剧本中反复出现、可识别、可组合、可变体、可增益的质量因子。
```

本文档里的“特征”是一组能在故事里被看见、听见、表演、拍摄、剪辑和复用的叙事机制。

一个高质量剧本由少数关键承重特征撑起来。它更像一组剧作基因：承重位置命中少数关键特征，故事会明显脱离平均答案；多个特征在选题、人物、冲突、场景、台词、视听和传播窗口中互相支撑，作品上限会继续抬高。

本文档必须按“骨架强制、特征择优”的方式理解。

本文档遵守正向剧本收束原则：剧本开发优先描述目标故事已经成立后的叙事状态，用具体人物、具体处境、具体选择、具体动作、具体台词、具体视听证据和具体结尾画面共同收束故事范围。剧本把道理压进一个人物在某个时刻的选择里。

```text
正向剧本收束：
用人物、处境、选择、动作、台词、视听和结尾画面描述目标故事。

特征交集：
每个剧作特征负责一个叙事维度，多个维度交叠后形成清楚的故事坐标。

承重优先：
一个短片优先服务一个最高叙事主轴，其他信息服从这个主轴。
```

## 0. 特征资产的描述粒度

有效剧本特征具备四个条件。

```text
可识别：
读剧本时，能指出它落在哪个人物选择、动作、台词、场景、道具、冲突节点或结尾画面上。

可组合：
它能和其他特征叠加。一个成熟特征通常能同时服务人物、冲突、场景、台词、镜头和传播。

可变体：
同一个通用特征能被不同题材改写。临界时刻在爱情里可以是告白前一秒，在亲情里可以是离别前一句话，在教育反转里可以是批评即将出口的一瞬间。

可增益：
它是提高故事张力、人物可信度、情绪命中率、可拍性和传播记忆点的质量因子。
```

低密度特征写法是：高级、真实、感人、有电影感、有故事、有反转、人物立体、台词自然、情绪饱满。

高密度特征写法是：

```text
人物在代价面前做选择，选择暴露他的欲望、恐惧、错误信念和真正需求。
冲突由两种价值、欲望、误解或规则互相咬住，人物越行动，代价越靠近。
场景作为压力容器，让人物无法继续隐藏自己的欲望、缺口和关系位置。
台词是人物在关系压力下说出口的动作，完成试探、保护、拒绝、邀请或切断。
结尾让开头的物件、动作、称呼或价值判断带着新含义回来。
```

本文档的表达优先使用以下结构：

```text
通用基底：
多数高质量剧本共同拥有的底层叙事机制。

特征颗粒：
这个机制在剧本里可以被识别成哪些具体表现。

题材变体：
不同题材如何重塑同一机制。

质量增益：
命中后增强的是人物、冲突、情绪、视听、可拍性、剪辑还是传播。
```

### 0.1 正向剧本提示词密度

高质量 AI 剧本提示的核心是让每个短语都有剧作职责。

```text
人物词负责确定故事发动机：
父亲、母亲、孩子、老师、姐姐、弟弟、同学、陌生人、被误解者、旁观者。

处境词负责确定压力：
公开比较、被抢东西、成绩下滑、游乐园恐惧、父母争吵、课堂评价、亲戚饭局。

选择词负责确定价值：
尊重、保护、边界、承认害怕、拒绝羞辱、重新定义勇敢、给孩子安全感。

动作词负责确定可拍性：
停筷、蹲下、递回、挡住、扶肩、关门、收回手、把东西放回孩子面前。

台词词负责确定声音：
前半句压住观众预期，停顿后改写价值方向，最后落到具体支持。

视听词负责确定下游：
脸部停点、手部特写、物件回收、声音桥、封面画面、结尾壁纸帧。
```

提示越能把人物、处境、选择、动作、台词和视听拆清，故事越容易从“道理”变成“可拍短片”。

### 0.2 剧本特征交集原则

高质量剧本来自多个叙事圈层的交集。

```text
人物圈层：
身份、欲望、需求、错误信念、防御动作、声口和最终选择。

冲突圈层：
目标、阻力、规则、信息差、时间压力、代价和不可逆节点。

场景圈层：
地点、进入方式、压力来源、道具动作、声音来源、关系变化和停点画面。

台词圈层：
说话目的、潜台词、关系距离、句子长短、停顿、重音和对方反应。

视听圈层：
特写证据、动作因果、声音桥、物件闭环、封面潜力和结尾画面。

传播圈层：
前 3 秒钩子、观看任务、价值反转、社会认领和评论入口。
```

越重要的短片，越要先写清受众最终感受和故事命题，再从人物、冲突、场景、台词、视听和传播中选择承重结构；不要求每种题材同时填满六项。

## 1. 不变骨架资产

不变骨架资产是剧本成立的固定容器。它的价值不在于直接制造高级感，而在于给开放审美特征提供承载位置。

### 1.1 AI 视觉剧本层级

AI 视觉剧本由以下层级组成：

```text
选题角度层：
故事讲谁、对谁、在什么处境里、为什么现在必须发生。

人物引擎层：
主角想要什么、缺什么、怕什么、误以为什么、最后被迫选择什么。

冲突结构层：
目标、阻力、规则、信息差、时间压力、代价升级和不可逆选择。

场景动作层：
每场戏发生在哪里、谁进入、谁阻挡、动作如何改变关系。

台词声音层：
人物声口、关系距离、潜台词、停顿、方言、旁白、VO 和声音状态。

视听交接层：
可资产化人物、场景、道具、动作、声音、特写、转场和结尾画面。

传播包装层：
前 3 秒钩子、标题解释、评论引导、封面画面、可截图句和可复述点。
```

### 1.2 故事种子固定槽位

故事种子的槽位固定，槽位里的内容开放。

```text
具体人物
具体处境
诱发事件
明确目标
外部阻力
内部阻力
规则限制
时间压力
信息差
具体代价
不可逆选择
情绪出口
结尾回收
传播窗口
```

高质量故事种子是：

```text
一个具体身份的人，因为一个具体触发事件，必须在某个限制内做一个会付出代价的选择，否则会失去某个无法补回的东西。
```

### 1.3 人物固定槽位

每个核心人物至少具备以下槽位：

```text
身份
年龄感
社会位置
表层目标
深层需求
错误信念
恐惧
能力
缺陷
关系压力
习惯动作
说话方式
不愿承认的话
最后必须做出的选择
```

人物质量来自这些槽位互相咬合：说话方式来自身份，缺陷制造冲突，习惯动作能在关键场景里反过来伤人或救人。

### 1.4 场景开放问题库

每场戏先回答场景功能和受众体验变化，再从其余问题中选择实际承重项：

```text
必答：场景功能 / 主情绪 / 观众进入时与离开时的体验差异
候选：地点 / 进入人物 / 目标 / 阻力 / 关系变化 / 可见动作 / 关键道具 / 声音来源 / 情绪起终点 / 场景结果 / 下游视觉资产风险
```

场景要产生与体裁相符的推进。冲突场景可以让关系、秘密、选择或代价变化；观察与氛围场景可以让观众发现细节、重新理解空间、感到时间流逝或积累一种情绪，不要求人物外部状态必然改变。

### 1.5 台词固定槽位

台词是人物在压力下采取的行动。

台词固定槽位包括：

```text
说话人
听话人
说话目的
关系距离
表层意思
潜台词
情绪状态
地域口气
句子长短
停顿位置
重音位置
对方反应
是否推动关系变化
```

同一句台词换一个人物说，会失去人物声口。高质量台词要长到具体人物身上。

### 1.6 下游视觉交接固定槽位

AI 视觉剧本必须能继续拆成图片资产、分镜和视频提示词。剧本阶段至少要识别：

```text
跨镜头人物
跨镜头场景
关键道具
一次性画面元素
人物表情承重点
特写证据
声音证据
动作因果链
可转场物件
结尾画面职责；只有承担视觉记忆或封面候选时才设计壁纸帧
封面候选画面
```

剧本阶段提供足够明确的视觉和声音证据，让下游图片资产、分镜和视频提示词可以稳定继承。

### 1.7 短视频时间密度诊断尺

不同长度提供不同叙事预算，不对应固定任务数量。下面是商业剧情短片的常见容量参考，不适用于所有体裁：

```text
15 秒：
适合一个熟悉预期加一个价值反转。人物少、场景单一、台词短、结尾明确。

30 秒：
适合一个小冲突加一个关系转向。前半段建立压力，后半段用行动和台词改写关系。

60 秒：
适合一个关系阶段变化。观众能看见人物从防御到松动、从误判到理解、从压迫到支持。

90 秒到 2 分钟：
可以容纳一个较完整情绪段落；是否需要开头钩子、中段升级、黑暗时刻、关键选择或结尾回收，由体裁和主情绪决定。

3 到 6 分钟：
适合有铺垫、误解、失去、回收和余味的短片。人物关系和物件闭环承担更大重量。
```

时间越短，越要减少任务并让关键动作或感受尽快可读；时间越长，越要维持观看理由，但观看理由可以来自冲突、关系、悬念、观察、节奏、表演、空间或审美变化。反转、黑暗时刻和物件回收都是候选，不是时长自动触发的必填项。

## 2. 选题角度审美特征资产

### 2.1 通用基底

高质量选题是能自然长出人物、冲突、场景、台词和传播资产的故事发生机制。

它通常包含：

```text
一个具体的人。
一个正在变化的关系。
一个观众熟悉但容易误判的场景。
一个可见的触发动作。
一个有代价的选择。
一个能被结尾回收的物件、称呼或动作。
一个能被观众带走的认知或情绪出口。
```

### 2.2 高质量选题特征颗粒

```text
窄切特征：
从具体侧面进入大题材。亲情落到具体误解和具体物件，教育落到具体话术和具体支持动作。

临界时刻特征：
截取关系即将变化的一秒。话快骂出口、门快关上、孩子快哭出来、父母快发火、老师快定性、主角快误解完成。临界点越具体，剧本越有张力。

观众预期特征：
先让观众根据经验自动补出一个熟悉套路，再用人物选择击穿这个套路。反转利用观众的社会经验、家庭经验和刻板判断完成价值转向。

情绪代价特征：
人物说出或做出关键选择时会失去一点东西。父母选择温柔，失去的是权威姿态；孩子选择承认害怕，失去的是面子；主角选择道歉，失去的是自我保护。

现实疼点特征：
选题能碰到观众生活里真实存在的痛点，例如被比较、被羞辱、被性别偏见限制、被要求懂事、被迫让步、被爱但不被理解。

正向出口特征：
故事制造情绪压力后，给出一种更好的关系处理方式。出口可以是尊重、边界、理解、勇敢说不、承认脆弱、重新命名价值。

可切片特征：
一个 15 秒以内的场景就能独立成立。开头有预期，结尾有反转，观众不用看完整世界观也能理解情绪。
```

### 2.3 题材变体特征

```text
教育反转：
利用传统教育话术的前半句制造预期，后半句改成尊重、鼓励、边界和安全感。

亲情遗憾：
前半段用生活温暖建立爱，后半段用不可逆失去回收物件、动作和误解。

爱情情绪：
用同一张脸在不同 VO 触发下变化，重点是情绪阶段可读。

成长故事：
主角承认一个过去不愿承认的事实，做出更成熟的选择。

社会偏见反击：
先让观众自动按照外貌、性别、贫富、成绩、身高、身份误判，再用回答或行动击穿误判。

奇幻 / 仙侠：
宏大世界服务人物门槛、礼仪、选择和代价，奇观由人物反应和规则代价承重。
```

### 2.4 反差与反转类型资产

反转让观众重新评价自己刚才的判断。

```text
价值反转：
观众以为人物要羞辱、压迫、责备，后半段给出尊重、边界、鼓励和安全感。

身份反转：
观众根据外貌、成绩、身高、贫富或身份做判断，人物用回答或行动展示更大的格局。

视角反转：
观众以为某个大人冷漠、严厉或偏心，后半段发现他的行动在保护关系。

情绪反转：
前半段表情、语气和场面像要爆发，后半段情绪转向温柔、理解或支持。

认知反转：
观众意识到自己刚才也被旧经验、刻板印象或传统话术带着走。

行为反转：
人物跳出传统剧本，做出更高级、更有边界、更尊重人的选择。
```

反转的高级感来自“人物选择可信”。观众意外的是价值方向，信服的是人物动作和关系逻辑。

### 2.5 反转教育结构资产

反转教育短片的核心是：调用旧教育预期，再用更高级的关系处理方式改写它。

```text
前半句预期：
使用观众熟悉的传统教育开头，让观众自动补出责备、比较、羞辱或压迫。

表演误导：
父母、老师或大人先呈现严肃、皱眉、停顿、压低声音，让孩子和观众都进入防御。

价值转向：
后半句把话术转向尊重、保护、鼓励、边界、承认脆弱或重新定义勇敢。

行动落点：
大人用一个具体动作支持孩子，例如蹲下、递回、挡住、扶肩、拿回属于孩子的东西。

孩子反应：
孩子从防备、低头、观察脸色，转向松一口气、抬眼、眼眶发亮或靠近。

观众回响：
观众意识到传统反应可以被替换，并愿意把自己的经历投进评论区。
```

这类剧本要让“教育意义”藏在人物关系、具体动作和表情反应里。

## 3. 人物审美特征资产

### 3.1 通用基底

高质量人物把“善良、勇敢、温柔、坚强”落成稳定欲望、稳定防御、稳定声口和关键时刻暴露的缺口。

### 3.2 特征颗粒

```text
欲望清楚：
人物知道自己想要什么，哪怕他说不出口。想被尊重、想证明自己、想被爱、想逃离、想不被看穿。

需求更深：
人物真正需要的东西往往和表层目标不同。想赢的人可能需要学会承认害怕；想被夸的人可能需要停止讨好。

错误信念：
人物相信一个会限制自己选择的旧信念，例如“懂事就是忍让”“勇敢就是不害怕”“学习不好就没有价值”。

防御动作：
人物遇到压力时有固定反应：嘴硬、沉默、转移话题、逞强、讨好、发火、装不在乎。

选择暴露：
关键场景让人物在代价面前做一个暴露内心的选择。

关系镜像：
配角照出主角缺陷、愿望或可能性。

可表演性：
人物特征能被演员通过眼神、呼吸、停顿、动作和声口表现出来。
```

### 3.3 短视频人物可表演颗粒

人物设定要能直接变成演员动作和镜头表情。

```text
父亲型：
表面话硬，动作保护；先沉默或压低声音，再用一个具体动作替孩子挡住压力。

母亲型：
先紧张和心疼，视线快速扫孩子表情，声音在后半句放软，手上有照顾动作。

孩子型：
先防御、低头、观察大人脸色；被理解后肩膀松掉，眼神重新抬起来。

老师型：
公开场合有权威姿态，语言会影响全班目光；高质量转向是把评价变成支持和榜样。

姐姐 / 哥哥型：
处在被要求懂事的位置，习惯忍让；关键选择是获得尊重或学会表达边界。

被误解者：
先沉默、停顿或被动接受目光，后用一个超出刻板印象的回答或行动改写判断。

旁观者：
代表普通观众的旧反应，表情从习以为常转向意外、羞愧或被触动。
```

人物可表演颗粒让剧本写出“他如何在镜头里爱孩子”。

### 3.4 人物关系动力资产

```text
保护关系：
一方表面严厉，行动把压力挡在自己身上。

尊重关系：
一方承认对方的感受、选择和边界，把价值定义权还给对方。

误判关系：
观众或角色根据旧经验先下判断，随后被人物选择改写。

补偿关系：
人物意识到自己之前忽略了对方，开始用具体行动补上。

传递关系：
大人把一种更好的处理方式教给孩子，孩子在表情里接住这份安全感。
```

关系动力是短视频情绪的发动机。观众真正看的是关系如何在一句话和一个动作后改变。

### 3.5 质量增益

命中人物特征后，剧本会从“事件推动”升级为“人物选择推动”。观众会记住发生了什么，也会记住这个人在那一刻为什么只能这样做。

## 4. 冲突与结构审美特征资产

### 4.1 通用基底

高质量冲突是欲望和阻力互相咬住，人物越行动，代价越靠近。

### 4.2 特征颗粒

```text
对立面清楚：
对立面可以是人、规则、误解、阶层、传统观念、时间、疾病、死亡、社会偏见或人物自己的错误信念。

阻力递增：
每一步行动带来新的压力层级。阻力从轻微不适、关系裂缝、公开压力、不可逆后果逐步升级。

信息差：
观众、主角、配角知道的信息不同。信息差越清楚，误解和反转越自然。

不可逆节点：
故事中至少有一个动作做完就回不去，例如话说出口、东西被扔掉、门被关上、消息被发出、亲人离开。

黑暗时刻：
人物接近失控、被误解、被驱逐或失去支撑，成长和反转在这里获得重量。

回收闭环：
开头的物件、话术、动作、称呼或画面，在结尾带着新含义回来。
```

### 4.3 短视频结构变体

```text
15 秒反转教育：
前 3 秒建立熟悉错误预期，中段压近情绪，后段用一句正向反转改写观众判断。

60 秒情绪切片：
一个人物、一个场景、一条声音线，重点是情绪阶段递进和脸部表演。

3-6 分钟亲情短片：
前半段温暖生活证据，中央误解或伤害，后半段不可逆失去和物件回收。

奇观概念短片：
先给局部证据和人物反应，再揭示宏大空间，最后留下门槛、邀请或更大未知。
```

## 5. 场景审美特征资产

### 5.1 通用基底

高质量场景是压力容器。它让人物的欲望、缺陷和关系显露出来。

### 5.2 特征颗粒

```text
场景功能单一：
每场戏优先完成一个核心变化。既要解释世界观、又要铺情绪、又要反转、又要搞笑，容易变散。

动作来自场景：
人物动作应由场景自然生长。海边可以看海、靠栏杆、被风吹动发丝；饭桌可以递碗、夹菜、停筷；病床可以触碰胶布、压住哭声。

道具参与关系：
道具能被递、收、放、修、藏、丢、摸、点燃、回收，从而改变人物距离。

空间制造压力：
门缝、桌边、车后排、病床一侧、栏杆边、柜台上沿、课堂前排，都能限制人物能看见什么、能做什么。

声音作为动作：
电话电流、门外低声、火盆噼啪、碗沿碰响、鞋底停住、呼吸卡断，都是场景推进的一部分。

停点按场景职责选择：
承担人物第一眼、情绪峰值、段落记忆或封面候选的场景，需要一个准确记忆点；纯功能连接、连续压迫、速度冲击和事实插入场景不强制可截图停点。
```

## 6. 台词与声音审美特征资产

### 6.1 通用基底

高质量台词像人物在做事。它有目的、有遮掩、有关系压力，也有声音形状。

### 6.2 特征颗粒

```text
人物声口：
句子长短、用词、方言、停顿和口气必须属于这个人物。

潜台词：
人物常常不直接说真正想说的话，而是绕开、压住、反问、转移或用生活话包住情绪。

动作性：
一句台词要完成动作：试探、拒绝、安慰、羞辱、保护、圆场、切断、邀请、求证。

短句承重：
短视频里短句更有力。一句普通生活话可以承担刺痛、安慰、反转和记忆点。

反转句：
前半句沿用观众熟悉的话术，后半句改变价值方向。反转句自然落在人物关系和动作里。

声音状态：
台词要考虑气息、音量、音区、哭腔、沙哑、压火、停顿、电话失真、隔门闷声和 VO 回响。
```

### 6.3 短视频台词句型资产

短视频台词要短、准、有转向，最好能被观众复述。

```text
预期转向句：
前半句调用观众熟悉话术，停顿后把价值方向转向尊重、保护、鼓励或边界。

重新命名句：
把传统定义改成更好的定义，例如把勇敢从“不害怕”改成“承认害怕也能表达”。

归还价值句：
把被抢走的尊重、选择、边界或自我价值还给弱势角色。

保护动作句：
台词不单独成立，后面跟一个动作，例如递回、挡住、蹲下、扶肩、把东西放回去。

轻声确认句：
用短句确认对方感受，让防御中的人物松下来。

评论回声句：
结尾留一句观众能代入自己的问题或判断，让评论区自然接话。
```

台词句型是声音结构。高质量台词通常有前半句压力、停顿、后半句转向和具体动作落点。

### 6.4 台词声音形状资产

```text
严肃开头：
句子短，语速放慢，重音压在称呼或问题上，制造观众预期。

停顿转向：
中间留一个短停顿，让孩子和观众以为责备要落下来。

温柔落点：
后半句音量放低，尾音放软，语气从评价变成支持。

边界确认：
咬字清楚，句子干净，声音稳定，让对方知道这条边界被认真对待。

情绪压住：
人物把哭腔、怒火或心疼压在短句下面，表面克制，声音里有重量。
```

台词写作要同时考虑“字面意思”和“演员怎么说”。声音形状越具体，下游视频提示词越容易继承。

### 6.5 质量增益

命中台词特征后，观众会觉得人物真实存在。强台词的标准是“只有这个人此刻会这样说”。

## 7. 视听化审美特征资产

### 7.1 通用基底

AI 视觉剧本必须在文字阶段就预埋可生成的视听证据。剧本要能被镜头、演员、资产和视频提示词继续承接。

### 7.2 特征颗粒

```text
局部证据：
用手、眼、物件、门缝、电话线、火光、泪痕等局部先抓住注意力。

动作因果：
谁为什么靠近，哪只手碰到什么，受力后什么改变，后果落在哪里。

物件闭环:
同一个物件前后功能变化。第一次是玩具，第二次是承诺，最后是遗物。

声音桥：
旧话、铃声、火声、车声、门响可以连接时间和记忆。

视觉反差：
风景很美但人碎了，灯很暖但关系冷了，父亲语气硬但动作在保护。

封面潜力：
剧本里要能长出一张可传播画面：人物、物件、空间和情绪在一帧里集中。
```

### 7.3 AI 视觉交接资产

AI 视觉剧本要提前给图片资产、分镜和视频提示词留下可继承信息。

```text
人物资产信号：
跨镜头出现、承担情绪表演或需要固定长相的人物，在剧本阶段标出形象稳定需求。

场景资产信号：
会反复出现、需要反打或需要运动路径的空间，在剧本阶段标出入口、出口、表演区和光源。

道具资产信号：
会被递、抢、放回、点燃、修复、丢弃或结尾回收的物件，在剧本阶段标出状态变化。

特写信号：
眼神、手、泪痕、嘴角、物件边缘、门缝、灯光、火苗等可成为开场钩子或情绪证据。

声音触发信号：
哪一句台词、VO、门响、电话声、碗沿声或脚步声触发表情变化。

封面信号：
哪一帧能同时看到人物、情绪、道具、空间和价值冲突。

结尾壁纸帧：
最后一个画面要有主体、留白、光影、情绪停点和可截图价值。
```

剧本阶段写清这些信号，下游图片和视频提示词就在剧本视听证据上继续展开。

## 8. 传播与包装审美特征资产

### 8.1 通用基底

短视频剧本同时服务正片沉浸、停留、完播、评论和转发。

### 8.2 特征颗粒

```text
前 3 秒钩子：
用特写、危险句、熟悉话术、反常回答、情绪表情或强局部证据抓住观众。

观看任务：
让观众知道自己接下来要看什么变化，例如“看她怎么从防备到崩溃”“看这句话怎么反转”。

评论钩子：
结尾给观众一个能代入自己的问题，让互动从个人经历自然发生。

社会认领：
故事触碰一类人的共同经验，让观众愿意说“我也是”“我家也是”“原来可以这样”。

正向价值：
反转教育、亲情、成长和偏见反击，最终要让观众带走更好的关系处理方式。
```

### 8.3 观众注意力路径资产

短视频剧本要像导演一样控制观众注意力。

```text
开头锁定：
前 3 秒给出熟悉话术、局部特写、强表情、危险句或反常动作，让观众立刻知道要看什么变化。

判断陷阱：
让观众根据生活经验先做一个自动判断，例如这个大人要责备、这个孩子要被羞辱、这个弱者会自私。

等待反转：
中段压住表情、停顿和动作，让观众等那句话或那个动作落下来。

价值击穿：
关键台词或行动改写观众预期，让观众重新评价刚才的判断。

情绪停点：
给孩子、大人或被误解者一个表情停点，让观众看到价值转向被接住。

评论入口：
结尾把问题交还给观众，让观众带着自己的家庭、学校、关系经验进入评论区。
```

注意力路径的目标是让观众经历一次“我刚才为什么会那样想”的认知回弹。

### 8.4 结尾落点资产

结尾是短视频被记住和被评论的地方。

```text
价值落点：
一句话改写前半段的价值判断，让观众带走新的关系处理方式。

行为落点：
一个动作证明爱、尊重、保护或边界，例如递回、挡住、蹲下、扶肩、把门轻轻关上。

物件回收：
开头出现的鸡腿、娃娃、成绩单、书包、门、碗、玩具或地图，在结尾带着新含义回来。

表情停点：
孩子抬眼、父母松一口气、被误解者沉默后笑一下，让情绪停在观众能读懂的位置。

声音余韵：
台词尾音、门响、海浪、铃声、脚步或短暂停顿，让结尾有回声。

评论钩子：
结尾提出一个和观众经历有关的问题，让观众愿意回答自己的版本。
```

高质量结尾让故事完成，也让开头的判断被重新命名。

## 9. 特征权重与取舍资产

高质量剧本来自承重位置命中准确，少数主特征形成清楚叙事核心。

### 9.1 承重特征

```text
选题承重：
具体人物、临界时刻、观众预期、情绪代价和正向出口。

人物承重：
欲望、需求、错误信念、防御动作和最终选择。

冲突承重：
商业剧情、悬疑和强叙事内容可从对立面、信息差、阻力递增、不可逆节点和黑暗时刻中选择承重机制；文艺、观察、氛围、纪录和教程内容允许由关系距离、时间流逝、发现、节奏或认知变化推进。

场景承重：
压力容器、动作因果、关键道具、声音证据和停点画面。

传播承重：
前 3 秒钩子、反转句、结尾回收、评论入口和封面潜力。
```

### 9.2 正向兼容组合关系

```text
反转教育：
熟悉话术开头、严肃表演误导、价值方向转向、具体支持动作、孩子表情松动、评论入口。

偏见击穿：
外貌或身份误判、观众自动判断、人物超预期回答、旁观者表情变化、价值重新命名。

亲情遗憾：
生活动作铺垫、旧物反复出现、误解加深、不可逆失去、物件回收、声音余韵。

爱情情绪：
同一人物、同一空间、不同 VO 触发、脸部表演递进、结尾情绪停点。

成长选择：
错误信念暴露、外部阻力逼近、人物承认缺口、做出有代价的新选择。

奇观邀请：
局部证据先行、人物反应承重、空间逐步打开、门槛出现、结尾留下更大未知。
```

### 9.3 审美组合语法

```text
主轴唯一：
一个短片优先只有一个最高叙事主轴。亲情遗憾、教育反转、恋爱情绪、偏见击穿、奇观邀请按主次排列。

强位互证：
主角选择、核心物件、结尾画面、台词出口和封面候选最好指向同一个情绪核心。

轻重互补：
剧情越短，人物动作越要具体；情绪越重，台词越要克制；奇观越大，局部证据越要扎实。

包装不破坏正片：
开场钩子和结尾评论服务正片人物选择，人物始终保持剧中真实身份。
```

## 10. 最终定义

高质量 AI 剧本来自稳定骨架和具体叙事特征的组合。

它是在稳定骨架里，让关键开放位置命中足够具体、足够互相支撑的叙事特征：

```text
选题有具体人物、临界时刻、观众预期和情绪代价。
人物有欲望、缺口、错误信念、防御动作和最终选择。
需要冲突的故事，其对立面、信息差、阻力、代价或不可逆变化中至少有一个真正推动人物；不需要冲突的体裁也要有清楚的观看推进。
场景按需承担压力、动作因果、道具、声音、观察或情绪空间；不强制可截图停点。
台词有人物声口、潜台词、动作性和声音状态。
结尾能回收开头的物件、动作、称呼或价值判断。
```

这份文档的核心用途是扩大 AI 对高质量剧本的可识别特征库。特征越细、越具体、越能组合，生成时能圈住的高质量区域就越小，剧本越有机会接近真正可拍、可生成、可剪辑、可传播的影视作品。
