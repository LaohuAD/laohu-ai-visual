# 高质量 AI 图片开发计划

本文档的身份是：高质量 AI 图片审美特征资产库。

它的职责集中在高质量图片审美特征沉淀，只沉淀两类资产：

```text
不变骨架资产：
AI 图片天然需要的画面类型、主体、构图、光影、色彩、材质、风格、参考关系和用途字段。

开放审美特征资产：
高质量图片中反复出现、可识别、可组合、可变体、可增益的视觉质量因子。
```

本文档里的“特征”不是一句抽象评价，而是一组能在画面里被看见、放大、复现、变体化调用的视觉机制。

一个高质量图片不需要命中本文档全部特征。它更像一组视觉基因：承重位置命中少数关键特征，图片会明显脱离平均生图；多个特征在主体、构图、光影、色彩、材质、风格和用途里互相支撑，图片上限会继续抬高。

本文档必须按“骨架强制、特征择优”的方式理解。

本文档遵守正向收束原则：图片开发优先描述目标画面已经成立后的状态，用清晰主体、准确光影、稳定色彩、真实材质、明确构图、专业妆造和具体镜头语言共同收束生成范围。正向特征越具体、越专业、越能互相限定，模型可进入的画面范围越小，输出越稳定。

```text
正向收束：
用主体、光影、色彩、材质、构图、妆造、镜头和用途把目标状态圈准。

特征交集：
每个词负责一个维度，多个维度交叠后形成清楚的审美坐标。

承重优先：
只把最高权重特征放在最重要位置，辅助特征服从主特征。
```

## 0. 特征资产的描述粒度

有效图片特征具备四个条件。

```text
可识别：
看图时，能指出它落在哪个主体、轮廓、构图落点、引导线、块面、光源、色彩、材质或表情上。

可组合：
它能和其他特征叠加。一个成熟特征通常能同时服务主体突出、情绪、风格、资产一致性和后续视频生成。

可变体：
同一个通用特征能被不同用途改写。留白在封面里可以给标题空间，在人物形象资产里可以制造神秘，在场景资产里可以压掉杂质，在道具资产里可以突出轮廓。

可增益：
它不是每张图都必须拥有的硬门，但一旦落在承重位置，就会提高第一眼吸引力、审美稳定度、资产可用性或视频参考价值。
```

低密度特征写法是：好看、高级、有氛围、电影感、真实、精致、大片感、漂亮、清晰、有质感。

高密度特征写法是：

```text
主体通过面积、亮度、清晰度、颜色、反差、位置或运动痕迹成为第一视觉落点。
栏杆、道路、窗框、光束、阴影或人物视线形成导引线，把观众视线带到主体。
大面积天空、海面、墙面、暗部或虚化背景作为块面压掉杂质。
肤色、底妆、发丝、首饰、衣料和环境反光共同证明人物在真实光影里成立。
道具的形状、材质、使用痕迹和边缘清晰度足以支撑后续视频特写。
```

### 0.1 正向提示词密度

高质量 AI 图片提示词的核心不是把词写多，而是让每个词都有画面职责。

```text
名词负责确定对象：
人物、脸部、眼睛、手、衣料、首饰、门框、栏杆、海面、旧木桌、玻璃杯。

形容词负责限定状态：
白皙通透、半哑光、低饱和、柔雾、硬朗、湿润、粗粝、轻薄、垂坠、清透。

动词负责确定关系：
照亮、包裹、压住、切开、引导、反射、勾勒、遮挡、衬托、拉长、聚焦。

专业词负责缩小范围：
侧逆光、轮廓光、漫反射、浅景深、低反光肤感、胶片颗粒、三分构图、明度分组。
```

同一个目标要由多个维度共同圈定。例如人物皮肤写“白”只提供颜色方向，更完整的写法要组合成：

```text
白皙清透肤色，轻薄服帖底妆，半哑光柔雾肤感，脸颊保留自然血色，鼻梁和唇峰有克制细碎柔光，细微毛孔和真实皮肤纹理可见。
```

这个写法同时锁定颜色、妆效、反光、局部高光和真实纹理，模型得到的是一个具体皮肤状态。

### 0.2 特征交集原则

高质量图片来自多个特征圈层的交集。单个大词只能给方向，多个小词共同决定结果。

```text
风格母体：
日系治愈、电影剧照、商业人像、纪实摄影、古风电影、港风霓虹、清冷盐系。

画质介质：
35mm 胶片、全画幅人像摄影、棚拍商业质感、自然光写真、宽幅电影画面。

色彩影调：
清新透亮、低饱和、暖白肤色、冷灰暗部、柔和高光、明暗有层次。

构图关系：
主体突出、三分线落点、前中后景分层、点线面秩序、大面积留白。

材质状态：
半哑光皮肤、真实发丝、垂坠衣料、珍珠柔光、金属冷反射、旧木粗糙纹理。
```

越重要的图片，越要先写清用途和唯一主情绪，再从风格、介质、色彩、构图和材质中选择真正承重的特征。不是五项同时写满，而是避免只靠一个泛化风格词让模型自由漂移。

### 0.3 图片目的与四类开放锚点

先按用途选择最高目标：

```text
叙事 / 审美成品：受众最终感受与唯一主情绪优先。
制作资产：身份、结构、比例、材质和一致性优先，允许中性背景与中性光。
教程 / 演示图片：理解、信任或行动优先，不强造戏剧情绪。
```

主体、场景、时间和风格是四类开放锚点，不是所有图片的统一加法公式。主体决定看什么；场景在需要时决定它与什么世界发生关系；时间在自然光、年代或环境状态承重时决定怎样被照亮；风格决定可见事实以什么审美秩序被观看。叙事图片通常会使用其中多项，白底道具资产、结构设定图和事实特写可能只需要主体与用途边界。构图、光影、色彩、焦段、材质和情绪证据也只按职责进入。

#### 主情绪唯一性：第一下只能让观众先感到一种东西

一张图可以同时有悲伤中的克制、危险中的镇定、孤独中的希望等复杂余味，但必须先确定一个主情绪命题。主情绪不是单个形容词，而是 `人物 / 主体处境 + 对处境的态度`。它回答：主体正在面对什么，以及它以什么姿态回应。

```text
情绪命题：这一刻究竟发生了什么，主体如何回应。
主情绪：观众第一下应该感到什么。
情绪证据：眼神、表情、呼吸、手势、重心、距离、动作、景别、光线、色彩、天气和物件关系怎样共同证明。
情绪退让：哪些辅助余味可以保留，哪些冲突信号必须降低权重或删除。
```

视觉焦点和情绪重心不是一回事。视觉焦点让观众先看到脸、刀、手或道具；情绪重心决定观众看见它以后感到对抗、恐惧、镇定、悲伤、亲密还是释然。焦点明确而情绪发散，仍然是一张没有主心骨的图。

气质标签不能替代情绪命题。`英姿飒爽` 描述人物总体气质，`临敌不退的镇定` 才描述这一刻的主情绪；`治愈` 是效果概括，`经历疲惫后终于允许自己放松` 才是处境和态度。正式提示词先选定主情绪，再让构图、姿态、光影、色彩、天气和场景退到同一个方向。复杂余味可以在第二眼出现，但第一情绪只能有一个。

#### 演员临场感：不是展示情绪，而是在事件里作出选择

人物画面要区分两种结果：`角色气质成立` 只说明人物像女侠、母亲、恋人或领导；`演员临场感成立` 说明观众相信这一刻真的发生了某件事，人物正在承受并回应。叙事性人物图采用开放证据链：

```text
具体事件压力：什么已经逼近、发生、失去、暴露或改变。
可见生理反应：眼睑、瞳孔、呼吸、下颌、肩线、手指、重心、汗水或肌肉张力如何响应。
带态度的行为选择：人物决定靠近、退让、隐瞒、保护、反击、忍住、无视或继续做什么。
对手 / 环境反馈：距离、视线、兵刃、道具、衣料、雨尘、影子、旁人或空间怎样证明压力和选择真实存在。
```

四类证据是推理方向，不是每张图机械填满。关键是至少形成闭合因果：没有外部压力，表情会像摄影师要求的造型；没有生理反应，人物会像假人；没有行为选择，情绪没有人物立场；没有对手或环境反馈，事件容易像独自拍写真。静止可以非常有戏，但它必须是人物面对具体压力后主动选择不动。

景别必须匹配情绪证据的尺寸。眼睑收紧、嘴角轻动、泪膜、呼吸或细小肌肉变化承重时，使用能读清脸部的特写、近景或中近景；包围关系、退路、身体控制或空间压迫承重时，可以使用中景、全景或远景；微表情和处境都要成立时，让近景人物与前景威胁、关系距离、影子或背景反馈同框。不是越近越有情绪，而是最关键的证据必须达到观众能读到的画面尺寸。

专业维度没有独立于情绪目的之外的完成分。构图、光影、时间、姿态、场景、焦段、色彩和材质只在能够加强主情绪时进入提示词；无关信息省略，削弱或转移主情绪的信息删除、改写或降权。信息密度指有效约束密度，不是字段数量和字数。

本文出现的所有分类和示例都是开放启发，不是封闭选项。AI 不得把人物只理解为性别、年龄、职业几个字段，也不得把时间穷举成清晨、黄昏、深夜后停止思考。每次创作都要先问“这个维度在当前画面承担什么作用”，再从开放属性空间中选择真正改变画面的信息；用户示例之外，凡是能改变身份、空间、光线、情绪、可信度或用途的属性，都可以继续推导并使用。

#### 主体锚点：谁承担第一视觉信息

主体不等于“画面里有什么”，而是“观众第一眼必须认出什么、继续看时还要读到什么”。主体可以是人物、生物、物品、建筑、自然奇观、群体关系、动作接触点或抽象视觉符号。先确定主体职责，再决定描述粒度：人物肖像要把脸、姿态和镜头关系写深；道具特写要把形状、材质和使用痕迹写深；环境主视觉则可能让建筑或自然空间本身成为主体。

主体属性使用开放推导，不机械填表：

```text
人物可从以下方向继续推导：
身份背景、性别表达、年龄阶段、地域 / 族群 / 国籍、职业与社会位置、生活条件、脸部、身体、服装、妆发、表情、气质、姿势动作、与镜头关系、与环境接触、当前处境和故事痕迹。

脸部可继续推导：
脸型、骨相、五官比例、发型、发长、发色、眼镜、胡须、肤色、毛孔、雀斑、痘印、皱纹、伤痕、汗水、泪痕、妆效、视线方向和表情肌肉状态。

身体可继续推导：
身高比例、体型、肩颈、重心、手型、腿线、动作幅度、力量状态，以及机械义肢、烧伤、纹身、残缺、旧伤等能改变身份和动作逻辑的特征。

服装可继续推导：
时代、地域、职业、版型、层次、颜色、材质、纹饰、磨损、湿度、褶皱、饰品、鞋履，以及服装如何被重力、风、动作和光线影响。

生物可从物种、品种、体型、年龄、性别、身体结构、翅膀 / 角 / 爪 / 鳞片等特殊结构、毛羽长度与颜色、健康状态、姿势动作和栖息环境继续推导。

物品可从类型、用途、形状、比例、颜色、材质、结构、表面纹理、磨损、水渍、灰尘、裂痕、制造年代、设计风格、使用方式和故事痕迹继续推导。
```

这些例子只说明“如何从身份与物理事实往下拆”，不代表主体只有这些属性。选择标准只有一个：这个属性是否改变观众对主体的识别、情绪、动作理解或画面可信度。没有作用的字段不必填；决定身份的字段必须写深。

#### 场景锚点：主体为什么属于这里

当图片需要环境时，场景不是背景墙，而是主体的尺度参照、动作条件、光源容器、情绪压力和故事证据。按任务回答：这是哪里，主体和环境如何接触，哪些空间关系托住主情绪或生成稳定。前中后景、遮挡、引导线、反射和留白都是候选，不要求同时出现。

场景同样使用开放属性空间：

```text
自然空间可继续推导：
地貌、山地、河流、湖海、森林、草原、荒原、洞穴、地面、天空、植被、土壤、岩石、水体、地平线、能见度、生态状态和尺度关系。

建筑空间可继续推导：
年代 / 朝代、地域、用途、建筑风格、体量、保存状态、外部结构、内部结构、门窗、屋顶、墙面、地面、入口、动线、家具、设施、陈列、生活痕迹、维护程度和光源位置。

天气与环境状态可继续推导：
晴、阴、雨、雪、雾、风、沙尘、湿度、积水、结霜、烟尘、季风、暴雨前气压感，以及天气如何改变可见度、材质、动作和光线。

空间关系按职责继续推导：
主体占比、前景入口、中景主体、远景信息、透视灭点、引导线、框景、留白、遮挡、反射面、可行动路径和接触点都是开放选项；只写真正改变主情绪、动作理解或空间可信度的关系。
```

天气既属于场景状态，也连接时间与光影：同样是傍晚，晴天会出现低角度暖光和清晰长影，阴雨天则可能只有低色温漫射天光、潮湿反射和更短的明暗层级。不能只写“傍晚”就默认所有天气得到同一种光。

#### 时间锚点：先确定世界何时存在，再设计光

时间是自然光和环境状态的重要上游变量。自然光、年代物件、季节或天气承重时，应先确定必要的年代、季节和时刻，让光影从世界条件中生长；白底资产、无时间感产品图和抽象视觉不为完整而强填时间。

```text
时间锚点 = 年代 / 历史时期 + 季节 / 气候阶段 + 一天中的时刻 + 必要时的事件时间

年代 / 历史时期：
古代、具体朝代、近代、现代、未来、具体年份或一段社会技术条件。它会改变建筑、服装、器物、光源和成像介质。

季节 / 气候阶段：
春夏秋冬、旱季雨季、梅雨、初雪、盛夏热浪、深秋落叶等。它会改变太阳路径、植被、空气湿度、服装和地表状态。

一天中的时刻：
凌晨、黎明、清晨、上午、正午、下午、傍晚、黄金时刻、蓝调时刻、夜晚、深夜等。它会改变太阳高度、自然光方向、色温、环境亮度和阴影长度。

事件时间：
雨刚停、停电后的第一个小时、节庆烟火开始前、日食将至、晨雾尚未散去等。它为画面增加更具体的物理状态和叙事压力。
```

时间到光影的默认推导链：

```text
年代 / 季节 / 时刻
→ 可用光源与太阳高度
→ 自然光方向和色温
→ 阴影长度、方向与软硬
→ 环境亮度和动态范围
→ 空气湿度、雾、尘、能见度
→ 天空、地面、墙面、水面和皮肤的反射
→ 人物服装、行为与场景状态
```

时间定光不等于时间包办全部光影。室内窗光、灯泡、烛火、炉火、霓虹、车灯、屏幕光、舞台光等人工或局部光源仍要单独写清来源、方向、光质、颜色、落点和反射。正确关系是：时间提供环境光基线，天气修正自然光，实际光源完成主体塑形。

例如，不只写 `黄昏，丁达尔效应`，而是写：

```text
深秋傍晚太阳贴近院墙上缘，低角度暖金侧逆光从西侧穿过稀疏树叶，人物投下向右前方延伸的细长影子；空气中轻薄尘雾让光路可见，青灰石地接住低亮暖反射，屋檐下仍保留冷灰暗部。
```

这里的丁达尔效果来自低角度太阳、树叶间隙和空气微粒，不是无来源装饰。

#### 风格锚点：决定事实以什么方式被观看

风格不是一个滤镜名，也不只等于氛围。它是表现介质、类型语言、情绪姿态、参考母体、色彩影调、摄影语言和后期介质共同形成的观看方式。

```text
风格锚点 = 表现介质 + 类型语言 + 情绪氛围 + 参考母体 + 色彩影调 + 摄影语言 + 后期介质
```

开放推导方向包括但不限于：

```text
表现介质：
真人摄影、电影剧照、纪录摄影、二维动画、三维动画、手绘、油画、水彩、粘土、定格、毛毡、拼贴、版画或新的混合介质。

类型语言：
文艺、喜剧、悬疑、科幻、恐怖、武侠、爱情、犯罪、纪录片、广告、时尚画报或其他题材传统。

情绪氛围：
温馨、幽默、轻盈、宁静、孤独、克制、危险、紧张、压迫、庄严、荒诞、神秘等。情绪必须继续翻译成表情、姿态、空间、光线、颜色和材质证据。

摄影与后期：
景别、机位、角度、构图、焦段、景深、焦点、透视、相机 / 成像介质、颗粒、锐度、柔焦、高光光晕、暗角、褪色和分级。
```

参考知名影视、摄影、绘画或设计作品可以借用模型已有认知，但不能只写片名。片名只负责唤起风格母体，随后必须拆成当前画面真正需要继承的可见特征：构图秩序、色彩关系、光影方式、空间尺度、动作气质、材质和成像介质。参考《卧虎藏龙》时，不是复制剧情、人物或标志性镜头，而是根据当前任务选择竹林纵深、克制青绿、轻盈动作线、东方留白、自然风和写实武侠摄影中的相关特征。

#### 抽象词具象化：把人类概括翻译成模型可见事实

人类习惯用 `特写、电影感、孤独、治愈、危险、高级` 概括一组视觉事实；模型需要的是这些事实本身。正式提示词允许保留概括词作为方向，但概括词不能独自承重，必须在前后写出可见证据。

```text
景别要翻译：
不只写“人物特写”，还写画面裁切到额头、眼睛、鼻梁、嘴唇、肩部还是手部；主体占画面比例；从正面、侧面、越肩还是低机位观看；焦点落在眼睛、汗珠、泪痕、刀刃还是皮肤纹理。

构图要翻译：
不只写“三分构图”，还写主体在左 / 右三分线哪个位置、占多少面积、哪条线把视线带过去、哪一块留白承担呼吸或标题。

光影要翻译：
不只写“电影光”，还写光从哪里来、以什么角度落到谁的什么部位、形成怎样的亮面 / 半暗面 / 轮廓、在哪种材质上出现何种反射。

情绪要翻译：
不只写“极度悲伤但压抑”，还写眼眶湿而不落泪、下颌收紧、嘴角维持平直、呼吸停在胸口、手指压住衣角、身体没有扑向镜头；并让空椅、未关的门、冷灰远景或低亮环境共同作证。

风格要翻译：
不只写“武侠电影感”，还写写实真人介质、克制东方色彩、衣料和兵器真实重量、留白构图、自然风、动作线条以及对应焦段和快门观感。
```

#### 信息不足时的导演级自动补全

用户只给 `国风女侠美女`、`治愈系美女` 或 `做一个好看的场景` 时，不要把未提供字段机械留空，也不要无逻辑随机拼词。执行内部补全：

```text
1. 提取不可改变的主体和用途。
2. 推断最可能的情绪承诺与观看任务。
3. 为场景、时间、风格各生成 3-5 个方向真正不同的内部候选。
4. 检查被选中的主体、场景、时间与风格锚点是否在时代、物理、色彩、动作和情绪上相容。
5. 选择最协调、最有辨识度、最能突出主体的一组。
6. 再推导构图、光影、摄影、材质和可见情绪证据。
```

所谓方向不同，不是把清晨换成早晨，也不是同一句换近义词，而是改变空间关系、时间光线、情绪姿态或视觉母体。例如 `国风女侠` 可以内部竞争：雨后石庭的冷静收刀、竹林风口的轻盈起势、雪夜廊下的危险静止、晨雾山门的肃穆远望。最终只输出一套因果最完整的方案；没有必要把内部随机过程交给用户。

#### 目的确定后的执行顺序

确定用途、主注意力和主情绪后，从以下顺序中跳过不适用环节，收束正式提示词：

```text
用途与受众体验
→ 主体锚点
→ 需要时补场景、时间和风格锚点
→ 摄影与构图
→ 由时间、天气和真实光源推导光影
→ 色彩、材质与微观细节
→ 情绪的可见结果
→ 一致性与抽象质量边界
```

顺序不是要求每条提示词都写成长表格，而是保证推理不倒置：先决定世界和观看方式，再选摄影控制杆；先写具体画面，再用概括词总结。最终文本可以是分段、短标签或流畅自然语言，只要信息清楚、可复制、可维护。

## 1. 不变骨架资产

不变骨架资产是图片成立的固定容器。它保证画面有稳定结构，开放审美特征负责继续抬高上限。

### 1.1 AI 图片层级

AI 图片由以下层级组成：

```text
用途层：
形象资产、设计资产、场景资产、道具资产、色卡资产、封面、首帧、故事板或临时参考图。

主体层：
人物、道具、场景、群像、建筑、动物、奇观或抽象视觉符号。

构图层：
画幅比例、主体落点、视觉落点、引导线、留白、块面、边角清洁和画面重心。

光影层：
时段、主光方向、辅光、轮廓光、反光、阴影层次和动态光源暗示。

色彩层：
主色、辅助色、点缀色、肤色倾向、光源色、暗部色、环境反光和统一分级。

材质层：
皮肤、头发、衣料、金属、玻璃、木头、纸、石头、水面、雾气和颗粒。

一致性层：
参考图职责、资产编号、服装账本、左右手方向、道具数量、空间结构和可变项。

下游层：
是否会作为视频参考图、首帧、封面、角色一致性锚点或风格资产。
```

### 1.2 图片类型固定槽位

每张图片先判断类型：

```text
人物形象资产
人物设计资产
人物素体资产
人物定装资产
服装 / 妆造资产
组合形象资产
场景四视图资产
道具多角度资产
色彩风格资产
封面海报
视频首帧
低保真故事板
临时参考图
```

图片类型决定信息优先级。人物形象资产优先第一眼气质；人物设计资产优先一致性；封面优先点击和标题空间；故事板优先构图骨架；首帧优先视频可接续。

### 1.3 画面固定槽位

以下是图片问题库，不是每张图都要回答的固定槽位。观众成品图先回答主情绪和第一视觉，再选择承重问题；制作资产先回答身份、结构、一致性和下游调用，再选择必要问题：

```text
主体是谁 / 是什么
主体占画面多少
观众第一眼看哪里
主体落在哪个构图位置
视线如何被引导
哪一块空间负责留白或压杂质
光从哪里来
高光和暗部如何分层
主色和点缀色是什么
最值得放大的材质细节是什么
哪些内容必须一致
哪些内容允许变化
这张图服务下游哪个生成动作
```

### 1.4 图片质量路径

一张高质量图片通常按以下路径成立：

```text
第一眼：
观众成品要让主注意力和主情绪尽快成立；制作资产要让身份、结构或材质首先可读。

第二眼：
被选中的构图、空间、明暗或色彩关系继续组织信息；不强制前中后景、留白和线条同时出现。

第三眼：
只有承担身份、质感或叙事证据的皮肤、发丝、衣料、道具、反光或边缘细节继续支撑可信度。

继续看：
耐看度来自主情绪之下的第二层余味、关系、细节或留白，不来自维度越多越好。

可复用：
资产编号、参考图职责、比例结构、光源方向和可变项让它能进入后续视频生产。
```

图片开发不要求每张图同时承担吸引力、信息稳定、风格统一和下游生成。先按用途确定一个最高职责，再补不会冲突的必要次级职责。

### 1.5 视觉层级资产

高质量图片要有清楚的视觉权重层级。

```text
一级视觉：
观众第一眼看到的主体，例如脸、眼睛、人物剪影、发光道具、门缝光、唯一色块。

二级视觉：
支撑主体的服装、手势、道具、构图线、局部光影、首饰、表情细节。

三级视觉：
环境、背景纹理、远景人物、氛围色、虚化光斑、空间暗部。

四级视觉：
画面边缘、低对比纹理、空气颗粒、墙面细节、远处小物。
```

图片提示词要把一级视觉写得最明确，二级视觉写得有支撑，三级和四级视觉写得服从整体氛围。这样画面会显得有主次，而不是每个元素同样抢眼。

### 1.6 明度组织资产

明度比颜色更早被眼睛捕捉。高质量图片需要把亮、中、暗三类区域组织清楚。

```text
亮部：
落在脸部、眼神、手部、道具核心、窗光、海面反光或标题空间附近。

中间调：
承接肤色、衣料、墙面、天空、地面和主体周边空间。

暗部：
压住背景杂质，形成轮廓、空间深度和情绪重量。

明度分组：
主体所在明度组和背景明度组有清楚差异，主体边缘能从背景里分离。
```

明度组织能让图片在缩小后仍然成立，也能让封面、首帧和人物资产更稳定。

## 2. 主体突出审美特征资产

### 2.1 通用基底

高质量图片首先要给观众眼睛找一个家。画面可以复杂，但第一眼必须知道看哪里。

### 2.2 特征颗粒

```text
视觉落点：
脸、眼睛、泪、手、道具、树、光点、门缝、火苗、旧物或唯一清晰局部成为第一注意力。

主体加满：
当干扰很多时，主体通过面积、亮度、颜色、清晰度、反差、位置、轮廓光或独特动作被强化。

信息降噪：
背景人物、杂物、纹样和环境细节被压低饱和度、降低清晰度、放进暗部或虚化块面。

边角清洁：
画面四角不塞随机文字、路人、半截物体、错位手脚和无关装饰。

远看可认：
缩小到封面尺寸时，仍能认出主体身份、情绪和画面关系。
```

### 2.3 质量增益

命中主体突出特征后，图片会从“元素很多”升级为“第一眼有主角”。这会直接提高封面点击、资产可用性和视频参考稳定性。

## 3. 点线面构图审美特征资产

### 3.1 通用基底

点让观众锁定，线让视线移动，面让空间安静。三者共同决定画面是否有秩序。

### 3.2 特征颗粒

```text
点：
唯一亮点、清晰脸部、眼神、手部动作、发光道具、火苗、泪痕、首饰反光。

线：
栏杆、道路、桌沿、窗框、门框、桥、光束、阴影、海岸线、人物视线、手臂方向、群体朝向。

面：
天空、海面、墙面、暗部、虚化背景、雾气、草坡、石墙、门洞阴影、前景色块。

线条位置：
主体在线条起点、途中或终点会改变观看顺序和空间方向，但不固定对应登场、孤独或动作。只有线性节奏承重时才选择位置，并结合人物处境判断情绪。

留白：
天空、海面、墙面、暗部、门洞、虚化背景或纯色块可以承载安静、压迫、隔绝、字幕或降噪；是否使用取决于主情绪和用途。

遮挡：
门框、窗帘、发丝、手、前景虚化物、半透明玻璃和阴影切割画面，保留局部信息。

神秘局部：
半张脸、唇部、眼睛、手指、侧颈、衣料边缘、首饰微光或背影回头形成想象空间。

视线落差：
人物目光、身体朝向、光束方向和构图线条共同指向画面外或画面内的关键区域。
```

### 3.3 质量增益

点线面让图片不再靠运气好看。它把审美从“元素选择”推进到“视线组织”。

## 4. 人物图片审美特征资产

### 4.1 通用基底

高质量人物图片不是把人画漂亮，而是让观众第一眼知道这个人是谁、为什么值得看、她处在什么光里、她的身体和服装为什么成立。

### 4.2 特征颗粒

```text
高光体态：
脊柱自然拉直，胸腔舒展，肩背打开，颈线拉长，下巴微收，重心稳定。

身衣适配：
衣服不是挂在人身上，而是通过肩线、胸省、腰侧收束、高腰线、面料贴合和垂坠方式衬出身体比例。

妆容气质：
肤色、底妆、眉眼、腮红、唇色和发型共同服务人物气质，不用泛泛的淡妆 / 精致妆。

首饰锚点：
耳坠、项链、发饰、戒指、腕饰和鞋履要和人物身份、场景光影、服装材质统一。

信息留白：
半张侧脸、发丝遮眼、只露嘴唇下颌、背影回头或门框遮挡可以制造神秘，但必须保留身份锚点。

真实光影校准：
人物在摄影棚真实人像状态区或场景光影中，肤色、妆容、首饰和衣料仍然成立。

脸部吸引力：
五官比例清楚，眼神有焦点，眉眼关系干净，鼻梁受光自然，唇形有清晰轮廓，脸部轮廓线柔和但不塌。

肤色妆效：
白皙清透、肤色匀净、轻薄服帖底妆、半哑光柔雾肤感、脸颊自然血色、唇色清透有纹理。

发丝质感：
发根蓬松，发丝分束自然，发尾有轻微层次，侧逆光下发丝边缘有柔和轮廓。

服装曲线：
衣服通过肩线、胸部弧线、腰线、袖口、领口和面料垂坠展示人物身材比例。

姿态气质：
身体重心稳定，胸腔打开，锁骨线自然，肩颈舒展，表情从容，人物处在自己最好状态。

镜头距离：
形象图使用中近景或半身构图突出脸、肩颈和服装；设计图使用全身与局部组合锁定设定；封面图按标题空间和缩略图识别调整主体大小。
```

### 4.3 人物设计资产特征

```text
三视图：
正面、侧面、背面锁定身形、服装、比例和体态。

脸部特写：
真正的头部特写，固定五官、眼神、鼻梁、嘴唇、皮肤质感、妆容和发际线。

手部参考：
左手和右手按人物自身左右校准，拇指方向相反，同年龄、同肤色、同手型。

造型账本：
三视图、局部细节、鞋履、首饰、配色和手部状态共享同一套设定。

音色说明：
如果人物会说话，设计资产图中保留清晰中文短句，说明基础音色和声线。

棚拍状态图：
人物处在简洁摄影棚或干净环境里，胸部以上中近景，真实人像光照展示脸部皮肤、妆容、发丝、首饰和表演状态。

局部细节区：
耳坠、项链、发饰、鞋履、手部、衣料纹理和特殊符号以小比例补充，不抢脸部特写和三视图权重。

比例标注：
身高、头身比、肩宽、胸腰位置、腿长、鞋跟高度和关键服装线条可以和三视图合并标注。
```

### 4.4 人物妆造词汇资产

人物图片的妆容要用美妆和人像摄影语言描述。

```text
底妆：
轻薄服帖、半哑光、柔雾、清透、肤色匀净、保留自然肤质。

肤色：
冷白偏中性、暖白有气色、白皙清透、奶油白、自然粉白、通透象牙色。

眉眼：
自然野生眉、细雾眉、清晰睫毛、眼尾轻微上扬、卧蚕柔和、眼神有湿润高光。

腮红：
低饱和豆沙、自然血色、淡粉雾面、颧面轻扫、提升气色。

唇妆：
水润豆沙、清透玫瑰、柔雾裸粉、唇峰清晰、唇纹真实、边缘自然晕染。

修容：
鼻梁柔和提亮，脸侧自然阴影，下颌线干净，锁骨和颈线有克制明暗。
```

妆造词要服务人物身份和故事气质。清秀人物适合清透轻妆，强势人物适合更清晰的眉眼轮廓，复古人物适合更明确的唇色和发型结构。

### 4.5 人物服装词汇资产

服装不是单独物品，而是人物身体、身份和气质的外化。

```text
版型：
修身、收腰、高腰线、肩线准确、胸部弧线自然、腰侧贴合、袖型利落。

面料：
羊毛、真丝、缎面、针织、薄纱、皮革、亚麻、棉布、呢料、珠片、金属织线。

状态：
平整、垂坠、轻微褶皱、贴合身体、随风轻摆、边缘有厚度、纹理清晰。

搭配：
鞋履、包、耳饰、项链、发饰、腰带和衣服共享同一身份气质。

气质：
清冷、优雅、明媚、疏离、成熟、少女感、精英感、复古、治愈、危险感。
```

服装描述要写出“它如何衬托身体”，而不是只写“她穿了什么”。

## 5. 场景图片审美特征资产

### 5.1 通用基底

高质量场景图片不是漂亮背景，而是可运动、可复用、可生成的空间。

### 5.2 特征颗粒

```text
空间结构：
入口、出口、主视角、反向视角、左右关系、运动路径和遮挡物清楚。

尺度可信：
人物、门、桌、床、栏杆、窗、道路和道具之间的比例符合现实。

光源固定：
窗光、门缝光、路灯、火盆、海面反光、树影和天空光源方向明确。

可表演区：
场景里有角色能站、坐、靠、躲、走、推、追、递物和停住的位置。

情绪块面：
墙面、天空、海面、暗部、旧门框、草坡或雾气能承担留白和压杂质。

可反打：
场景不是一张单向美图，反向视角也能成立，适合多镜头剪辑。

前中后景：
前景负责遮挡和纵深，中景承载表演区，背景交代空间和情绪。

动线清楚：
人物从哪里来、往哪里走、在哪里停、如何转身、被什么遮挡，都能从图片空间里推出来。

空气状态：
清晨薄雾、雨后水汽、黄昏尘埃、窗边浮尘、海风湿度、夜晚低照度颗粒让空间有时间感。

环境材质：
墙面、地面、窗框、栏杆、海面、木门、石阶、布帘和金属把手各自拥有明确触感。

光影路径：
窗光、门缝光、树影、海面反光、路灯、烛光或车灯在空间里形成可见方向。
```

### 5.3 质量增益

命中场景特征后，图片会从“漂亮背景图”升级为“可拍摄空间”。这能减少视频里空间错乱、人物漂浮、光源乱跳和道具位置不连续。

## 6. 道具图片审美特征资产

### 6.1 通用基底

高质量道具图片要让物件具备形状、材质、使用痕迹、比例和剧情功能。

### 6.2 特征颗粒

```text
轮廓清楚：
远看能认出物件，不被纹样、背景和角度吞掉。

材质可信：
金属、旧木、瓷、纸、布、玻璃、糯米、火灰和水面各有不同反光与纹理。

使用痕迹：
磨损、缺口、灰尘、手印、裂缝、折痕、水汽、烧痕或修补痕迹要服务剧情。

比例稳定：
物件和手、桌面、人物身体、空间尺度关系合理。

状态清晰：
完整状态、破损状态、内部揭露状态、燃烧状态、使用后状态各自形成清楚资产版本。

可特写：
放大后边缘、纹理、反光和关键识别点仍然清楚。
```

## 7. 光影与肤色审美特征资产

### 7.1 通用基底

光影决定观众怎样看见主体、空间和材质；人物肤色与皮肤介质首先要符合地域、年龄、职业、年代、健康和主情绪，而不是统一追求“白皙舒服”。只有光影或皮肤承担主情绪、身份识别、主体塑形或生成稳定性时，才从方向、软硬、反光、色温、妆效和纹理中选择必要控制项。

### 7.2 特征颗粒

```text
光影关系：
单一硬光、平光、剪影、近无辅光或多层布光都可以成立；关键是需要看清的情绪与事实证据不被破坏。

主光方向：
光从画面哪侧、哪个高度、什么时段进入，照到脸、手、衣料或道具哪里。

暗部可读性：
只在暗部包含必要表情、动作或身份信息时补自然反光；需要剪影、隐藏或压迫时允许暗部失去细节。

分离方式：
主体可以通过轮廓光、明度、色差、清晰度、面积、运动或空间位置与背景分离，不默认补轮廓光。

肤色正向：
明确角色自己的冷暖、明度、气色、纹理与妆效。冷白、健康暖肤、深肤、晒痕、雀斑、皱纹、粗粝皮肤、无妆、年代妆、柔雾或油润都可以成为正确身份状态。

高光控制：
高光范围、硬度与反射强度服从光源、皮肤状态和主情绪；可以克制，也可以因汗水、油脂、舞台妆或湿润环境而明显，但不能无来源糊掉关键五官。
```

## 8. 色彩风格审美特征资产

### 8.1 通用基底

高质量图片的色彩不是几个漂亮色号。主色、辅助色、点缀色、肤色、光源色、暗部色和环境反光是开放控制杆；按主情绪、身份、场景真实性和连续性选择，不要求每张图片都建立完整色卡系统。

### 8.2 特征颗粒

```text
色彩权重：
单色、黑白、自然综合色、一个主色或有意冲突的多色体系都可以；高权重颜色要有清楚职责。

空间与主体关系：
需要分层时，用明度、饱和度、冷暖或综合色差区分主体和环境；不需要时允许同色吞并、平面化或近无色差。

点缀色：
只有承担注意力、身份、危险、证据或节奏时才设置；面积可小也可大，取决于画面任务。

肤色与调色：
整体调色保护角色既定肤色、气色与皮肤介质，不把所有人物拉向白皙、提亮、去纹理或统一干净妆效。

阶段变体：
同一作品的不同情绪阶段在母色卡里调明度、暗部重量、点缀色面积和肤色气色。
```

### 8.3 视觉风格坐标资产

图片风格要落到坐标系里，而不是只落到单个风格词里。

```text
真实程度：
真人实景摄影、商业人像摄影、电影剧照、写实插画、轻风格化绘本。

明度关系：
高明度清透、中明度柔和、低明度厚重、明暗强对比、柔和低对比。

色彩性格：
清新透亮、低饱和莫兰迪、秋日焦糖、冷灰盐系、暖白治愈、霓虹高反差。

光影方式：
自然窗光、侧逆光、柔和棚拍光、黄昏暖光、阴天漫射光、低照度实景光。

画质介质：
35mm 胶片颗粒、全画幅数码人像、阿莱电影质感、复古胶片、商业精修质感。

情绪方向：
温暖但克制、清透但有距离、明媚但带一点孤独、精致但有生活痕迹。
```

稳定风格来自多个坐标共同定位。例如“清新透亮，日系治愈系风格色彩”能改善油腻感，是因为它同时把画面推向高明度、低油光、柔和肤色、浅色环境、低攻击性对比和干净空气感。

### 8.4 色卡资产组成

色卡资产不是单纯几个色块，而是一套画面色彩控制系统。

```text
主色：
决定画面大面积情绪，例如海盐蓝、暖白、冷灰绿、旧木棕、雾粉、黄昏金。

辅助色：
分配给环境、服装、远景、墙面、天空、地面和虚化区域。

点缀色：
少量用于首饰、唇色、发饰、道具、灯光或画面钩子。

肤色倾向：
固定人物皮肤的明度、冷暖、红润度、通透感和妆效。

光源色：
固定自然光、灯光、夕阳、霓虹、火光或窗光的色温。

暗部色：
固定阴影是冷灰、蓝灰、暖褐、墨绿、深蓝还是柔黑。

环境反光：
定义墙面、海面、衣料、地面和天空如何把颜色反到人物脸上。

分级风格：
胶片颗粒、对比度、饱和度、黑位、白位、高光柔化和暗部保留。

阶段变体：
同一作品根据情绪阶段调整明度、饱和度、暗部重量和点缀色面积。
```

色卡可以做成图片资产，也要配套文本资产。正式图片或视频提示词里调用色卡时，应把色彩规则展开成可生成描述。

## 9. 图片用途权重与取舍资产

不同用途的承重特征不同。

```text
人物形象资产：
第一眼气质、脸、体态、服装、光影、情绪和信息留白承重。

人物设计资产：
一致性、三视图、脸部特写、手部、造型账本、配色和音色说明承重。

场景资产：
空间结构、光源、入口、反打、可表演区和尺度承重。

道具资产：
轮廓、材质、比例、状态、使用痕迹和可特写承重。

封面：
主体突出、视觉钩子、标题留白、对比、情绪和缩略图识别承重。

首帧：
视频连续性、人物姿态、光源方向、焦点、动作起点和尾帧可接续承重。

故事板：
构图、景别、机位、主体比例、站位、动线、留白和空间锚点承重。
```

### 9.1 用途优先级资产

图片用途决定特征权重。

```text
人物形象资产：
脸部吸引力、人物气质、身衣适配、妆容肤色和第一眼记忆点优先。

人物设计资产：
同一人物一致性、三视图可读性、局部细节准确、服装账本统一优先。

人物棚拍状态图：
真实人像光影、肤色妆效、表演状态、肩颈胸部以上构图和镜头亲近感优先。

场景资产：
空间结构、光源方向、可表演区、反打视角和动线优先。

道具资产：
轮廓识别、材质触感、比例关系、使用状态和可特写边缘优先。

封面海报：
主体视觉冲击、缩略图可认、情绪钩子、标题空间和颜色对比优先。

视频首帧：
动作起点、主体姿态、光源一致、焦点稳定、尾帧可接续优先。

故事板：
景别、构图、人物站位、镜头方向、空间关系和情绪表演优先。
```

### 9.2 信息密度资产

高质量图片的信息不是越多越好，而是围绕用途集中。

```text
高信息区：
脸、手、道具核心、服装关键结构、标题钩子、空间入口、动作起点。

中信息区：
衣料整体、背景主体结构、环境材质、光影层次、辅助道具。

低信息区：
天空、墙面、暗部、虚化背景、海面、雾气、远景和边角。
```

高信息区承载细节，中信息区承载关系，低信息区承载呼吸。三者分开后，画面既丰富又稳定。

## 10. 参考图职责资产

参考图的价值在于分工清楚。每张参考图都要有明确职责。

```text
人物参考：
控制脸型、五官、年龄感、肤色、发型、体态和基础气质。

服装参考：
控制版型、面料、颜色、穿着方式、收腰位置、肩线、袖型和鞋履搭配。

妆造参考：
控制底妆、眉眼、腮红、唇色、发型、首饰和整体精修程度。

场景参考：
控制本次需要继承的空间结构、入口、光源方向、材质或表演区；只有纵深承重时才控制前中后景关系。

风格参考：
控制色彩、影调、光影方式、画质介质、空气状态和镜头质感。

构图参考：
控制主体位置、景别、留白、视觉落点、线条方向和画面重心。

动作参考：
控制姿态、手势、身体重心、表情节点和动态轨迹。
```

多张参考图同时使用时，要先确定主参考。人物资产通常以人物参考为主，服装和风格为辅；封面通常以构图和主体冲击为主，风格和色彩为辅；场景资产通常以空间结构为主，光影和材质为辅。

## 11. 模型可读视觉词汇资产

正式图片提示词要把审美目标转成模型能直接生成的视觉语言。

### 11.1 摄影语言

```text
镜头：
35mm 环境人像、50mm 标准人像、85mm 人像特写、长焦压缩空间、广角建立空间。

景深：
浅景深、柔和背景虚化、真实镜头散景、主体清晰背景轻虚化、前景轻微虚化。

机位：
平视、略低机位、略高机位、肩部高度、眼平视角、贴近人物的中近景。

光线：
窗边自然光、侧逆光、柔和主光、弱辅光、轮廓光、阴天漫射光、黄昏暖光。

画质：
全画幅人像摄影、阿莱电影质感、35mm 胶片颗粒、真实镜头景深、自然光影层次。
```

### 11.2 材质语言

```text
皮肤：
按人物身份选择冷白、健康暖肤、深肤、晒痕、雀斑、皱纹、粗粝、半哑光、柔雾、油润、无妆或年代妆；再按镜头职责决定毛孔、纹理、反光和底妆细节。

头发：
自然发丝分束、发根蓬松、发尾层次、侧逆光发丝边缘、真实发丝反光。

衣料：
垂坠、挺括、细腻织纹、轻微褶皱、贴合身体、边缘有厚度、随风轻摆。

金属：
冷反射、边缘高光、细小划痕、重量感、局部镜面反光。

玻璃：
透明厚度、边缘折射、柔和反光、微弱指纹、水汽凝结。

木头：
木纹清晰、旧木磨损、边角包浆、粗糙触感、温润低反光。

纸张：
纤维纹理、折痕、边缘毛糙、轻微泛黄、墨迹渗透。
```

### 11.3 构图语言

```text
主体突出：
主体面积更大、亮度更高、边缘更清晰、颜色更纯、背景信息更低。

视线引导：
栏杆、道路、窗框、光束、阴影、人物目光和手臂方向把视线带向主体。

空间层次：
前景遮挡、中景表演、背景交代环境，三层之间有明度和清晰度差异。

留白块面：
天空、海面、墙面、暗部、虚化背景或雾气给主体留下呼吸空间。

画面重心：
主体落在三分线、黄金分割、画面中心、边缘呼吸位或线条终点。
```

## 12. 多图资产组

正式作品里的图片资产常常是一组图，而不是单张图。

### 12.1 人物资产组

```text
人物形象图：
负责第一眼气质、吸引力、脸部记忆点和人物整体魅力。

人物设计图：
负责三视图、比例、服装、发型、局部细节、手部和标注。

脸部特写图：
负责五官、眼神、肤色、妆容、发际线和脸部光影。

棚拍状态图：
负责真实光影下的皮肤、肩颈、首饰、表情和表演质感。

视频首帧图：
负责具体镜头的姿态、光源、构图、动作起点和视频连续性。
```

### 12.2 场景资产组

```text
主视角：
负责观众最常看到的空间印象。

反向视角：
负责剪辑中的反打和空间连续。

侧向视角：
负责人物移动、进入、离开和站位关系。

路径视角：
负责追逐、行走、靠近、转身和镜头运动。

氛围视角：
负责光影、天气、空气状态和情绪基调。
```

### 12.3 道具资产组

```text
干净资产图：
负责形状、比例、材质和识别点。

手持状态图：
负责和人物手部、身体、镜头距离的比例关系。

使用状态图：
负责打开、点亮、破损、浸湿、燃烧、摆放或被递出的剧情状态。

特写图：
负责边缘、纹理、铭文、裂缝、反光和关键符号。
```

### 12.4 色彩风格资产组

```text
色卡图：
负责主色、辅助色、点缀色、肤色、光源色和暗部色。

风格样张：
负责综合色彩、光影、空气、颗粒和镜头质感。

阶段变体：
负责同一作品不同情绪阶段的明度、饱和度、暗部和点缀色变化。

文本规则：
负责把色卡转成正式提示词里可复制的中文描述。
```

## 13. 正向兼容组合关系

高质量图片需要主特征和辅助特征形成兼容关系。

```text
清新透亮人物：
高明度或干净综合色环境，保留角色自己的肤色与气色；柔和自然光、服装明度和景深只选择真正让主情绪更轻盈的部分。

电影剧照人物：
先确定这一刻的主情绪与观看距离，再选择光源、空间层次、皮肤介质、影调和焦点；电影感不固定等于侧逆光、低饱和和前中后景齐全。

商业人像人物：
以品牌或人物身份的识别目标为中心，按需选择背景、棚拍光、服装版型、首饰反光、肤色状态和精修程度，不把统一磨皮当高质量。

情绪封面：
主体大面积占比、强视觉落点、标题留白、明暗对比、颜色钩子、表情或动作瞬间。

可拍场景：
只锁本段拍摄真正需要的入口、表演区、光源、材质、动线或反打关系；单方向镜头不为资产完整强造反打和三层空间。

道具特写：
轮廓干净、材质明确、手持比例稳定、边缘清晰、局部纹理丰富、背景信息柔化。
```

组合关系的重点是主次清楚。一个主风格负责画面方向，一到两个辅助特征负责质感和情绪，所有局部细节都服务这个主方向。

## 14. 最终定义

高质量 AI 图片不是被关键词堆出来的，也不是被高清参数堆出来的。

它是在稳定骨架里，让关键开放位置命中足够具体、足够互相支撑的视觉特征：

```text
用途先决定最高目标：叙事成品传递主情绪，制作资产锁身份与一致性，教程演示保证理解与行动。
主体或主关系有清楚的第一注意力。
构图、光影、时间、场景、色彩、材质和风格按贡献选择，不要求全部出现。
被选中的人物、场景、道具、时间与风格信息形成因果，不互相削弱目标。
图片用途决定信息优先级，而不是所有信息平均铺开。
参考图职责清楚，图片资产组分工明确。
人类抽象词已经翻译成裁切、位置、光源、焦点、姿态和材质等可见事实。
所有分类和示例都作为开放推导入口，不限制 AI 发现新的有效属性。
提示词使用正向、高密度、模型可读的视觉语言。
```

这份文档的核心用途不是告诉 AI “按步骤生图”，而是扩大 AI 对高质量图片的可识别特征库。特征越细、越具体、越能组合，生成时能圈住的高质量区域就越小，图片越有机会成为可复用、可剪辑、可发布的视觉资产。

## 15. 外部资料校准

本次结构参考并校准了以下官方资料，只吸收跨模型成立的原则，不把单个平台参数写成普遍规则：

- [Google Cloud Imagen 提示和图片属性指南](https://cloud.google.com/vertex-ai/generative-ai/docs/image/img-gen-prompt-guide)：官方基础骨架强调主体、背景 / 环境和风格，并通过摄影位置、光线、材质与迭代增加控制。本项目在此基础上把“时间”升格为光影上游锚点。
- [Midjourney Prompt Basics](https://docs.midjourney.com/hc/en-us/articles/32023408776205-Prompt-Basics)：官方强调主体、介质、环境、光线、颜色、情绪和构图，同时指出重要细节越少，模型自由度越高。本项目把这些维度组织为开放属性空间，而不是固定清单。
- [OpenAI GPT Image Generation Models Prompting Guide](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide)：官方建议保持一致结构，明确场景、主体、关键细节、用途、构图、视角、人物尺度、视线和物体交互；相机规格主要用于高层观感与构图，不假设模型精确模拟物理镜头。

外部资料负责确认共同规律，老胡的实际生成反馈负责决定本项目怎样落地。后续仍要用首测结果校准四锚点的描述密度、模型差异和参考图权重。
