# 老胡 AI 视觉核心规则手册

> 当前共享规则唯一主入口。后续新对话先读 `AGENTS.md`，再读本文件；旧的碎片规则只作为历史证据，不作为优先执行入口。

## 一、根本目的判断

处理任何需求先分三层：

```text
表层需求：老胡直接说了什么。
真实目标：老胡真正想让作品、流程或体验变成什么。
根本目的：本次处理如何提升最终作品质量、创作体验、可生成性、可剪辑性和后续迭代效率。
```

如果老胡指出的是可复用执行问题，不能只写在作品里，必须更新本手册、相关 skill 和检查脚本。

图片提示词和视频提示词有一个共同硬门：不能靠泛词交付。老胡要的不是“看起来有氛围的短句”，也不是字段齐全的长清单，而是能直接生成、复盘和迭代的执行稿。凡是结果主要靠 `好看、高级、治愈、唯美、电影感、真实、清新、自然、氛围好、光影好、情绪饱满` 支撑，却没有把主情绪及其关键可见 / 可听证据写清，就必须退回重写。证据从主体、构图、表演、光影、色彩、材质、声音、空间和停点中按需选择，不要求全部出现。

先定目的，再选手段。输出先分三类：叙事 / 审美成品以受众体验目标和主情绪为最高目标；制作资产以身份、结构、比例、材质和一致性为功能目标，保持中性基准；教程、产品演示和流程说明以理解、信任或行动为主要受众体验，不强造戏剧情绪。所有专业信息分为 `情绪承重项、生成必需项、专业展示项`：前两类保留，专业展示项删除。

高质量特征资产库是执行门槛，不是参考资料：

```text
写图片、封面、首帧、人物资产、场景资产、道具资产、色彩风格资产 → 必须吸收 高质量AI图片开发计划。
写视频提示词、故事板、分镜、氛围画质、画面内容、音乐卡点转场镜头 → 必须吸收 高质量AI视频提示词开发计划。
如果视频里需要首帧、图片参考、壁纸帧或视觉美学镜头 → 同时吸收高质量图片和视频两份开发计划。
```

导演级影视创作必须先过 `02_共享资产库/05_工具流程/导演级影视创作总控流程.md`。后续创作默认以顶级影视导演、编剧、摄影指导、动作导演、美术指导、剪辑指导和 AI 生成导演的复合身份工作。正式进入剧本、资产、分镜、视频提示词或复盘前，先判断本轮主要由哪个身份主导，再过八个总控门：身份门、价值门、故事门、节奏门、文戏门、武戏门、画面门和剪辑门。这个流程不是新增字段，而是内部导演判断，用来决定各个 skill 往哪里发力。

节奏不是只写 `开头钩子 / 中段升级 / 结尾评论`。15 秒的钩子与爆点、30 秒的任务变化、60 秒的冲突转折和 1-3 分钟的段落节奏都只作为商业内容诊断尺，不是必须填满的节拍表。实际节奏由主情绪、观看任务和体裁决定：文艺片可以靠静止、等待和关系距离推进，动作片可以快但要看清因果，教程则以理解和行动节奏为准。

文戏和武戏必须分开判断，但两者都服从主情绪和镜头任务。文戏从台词目的、潜台词、表情、停顿、关系距离和反应中选择承重项，重点是话外之意与关系变化。武戏的功能硬条件是力量来源、运动路径、接触点和动作结果可读；起势、发力、受力、反应、爆点和停帧是跨动作段落分配的候选节拍，不要求每镜齐全。不要用“情绪饱满、运镜炫酷”糊过去，也不要用完整公式冒充导演判断。

镜头切换和长镜头都要有任务。短切、长镜头、特写进、跟踪、甩镜、遮挡转场和固定镜头都是候选；它们可以产生不同情绪倾向，但不与冲突、沉浸、危险、庄重等情绪固定绑定。每次选择都要回答：为什么现在这样拍或这样切，观众得到或失去什么信息，主情绪被加速、压住、误导还是释放。

自我校准与查证机制是硬规则。当不知道怎么写、判断不稳、规则冲突、题材陌生或外部影视规律不清时，先查项目现有规则，再查已有成功 / 失败案例；仍不确定时查外部资料或行业参考，然后把查到的原则翻译成本项目可执行规则。禁止靠猜写影视规律，禁止用泛词糊过去，禁止把一个案例经验硬套所有题材，禁止遇到冲突不说明范围。

低密度输出的本质问题不是“字数少”，而是没有给模型足够的约束交集。正确做法是用多个专业维度缩小范围：主体落点、点线面构图、主光方向、明暗分离、动态光源、主辅点缀色、肤色妆效、材质状态、镜头焦段、景深、前中后景、声音态度、表情肌肉路径、动作起点和停点共同确定目标。一个词只能给方向，多个维度的交集才会让结果稳定。

生图的上游统一采用图片四锚点：`图片成立 = 主体明确 + 场景承托 + 时间定光 + 风格定情绪`。主体决定第一视觉信息，场景决定尺度、空间关系和故事证据，时间决定自然光与环境状态的基线，风格决定事实以何种介质、类型和情绪秩序被观看。四锚点确定后再推导构图、摄影、光影、色彩、材质和情绪证据，不能先堆专业词再反向拼一个世界。

时间必须形成因果链：`年代 / 季节 / 时刻 → 可用光源与太阳高度 → 光线方向和色温 → 阴影长度与软硬 → 环境亮度与动态范围 → 雾、尘、湿度和能见度 → 表面反射与人物行为`。时间是自然光基线，不包办所有照明；天气会修正自然光，室内窗光、灯泡、火光、霓虹、车灯和屏幕光仍要写来源、方向、光质、颜色、落点和反射。

所有属性分类都按开放属性空间使用。人物的年龄、职业、脸部和服装，场景的自然、建筑和天气，时间的朝代、季节和时刻，风格的介质、类型和情绪，以及焦段、构图、材质等，只是帮助 AI 继续提问的示例，不是穷举答案。选择一个属性的依据是它是否改变身份、空间、物理、情绪、可信度或用途；用户未列出的有效属性要主动推导，用户没有指定场景 / 时间 / 风格时要做导演级候选竞争后自动补全。

人类概括词必须经过抽象词具象化检验。`特写` 要落到画面裁切边界、主体面积、相机角度和焦点落点；`三分构图` 要落到主体位置、导引线和留白职责；`电影光` 要落到光源、方向、受光部位、明暗层级和材质反射；`极度悲伤但压抑` 要落到眼神、嘴角、下颌、呼吸、手指、姿态和环境证据。概括词可以保留作总结，但具体可见画面必须先成立。

画面美学的根本不是“元素漂亮”，而是关系有秩序。正式写任何图片、首帧、封面、故事板或视频提示词前，先确定受众体验、主情绪、主注意力和主观看任务，再从视觉落点、视线导引、主体与环境接触、姿态线条、光影体积、色彩关系、空间层次、材质触感、取舍与留白中选择真正承重的关系。它们是开放问题库，不是每张图都要答完的十项清单；平光、平面化、无前景、满构图、黑白或有意粗粝都可能是准确答案。好看的画面不是所有东西都精致，而是被选择的关系共同指向同一个感受；不好看的画面则常见于主次平均、背景抢戏、手段互相抵消或信息很多但没有第一视觉落点。

这个判断要落成正向提示词，不写成抽象口号。不要只说 `美学到位、构图高级、氛围很好、人物好看`。例如一张以“终于愿意靠近”为主情绪的海边人像，可以只选择这些承重证据：`脸和眼睛是第一视觉落点；栏杆线条把视线引到肩颈；人物手指轻触栏杆；侧逆光只勾出发丝、耳饰和下颌线；低饱和海盐蓝退到背景，暖肤色成为唯一温度；海面留白给她回望镜头的停顿让路`。这不是海边人像固定套餐，而是在说明每个被选中的关系都要能回答“它怎样加强主情绪”。

图片还要先确定一个主情绪命题。视觉焦点清楚不代表情绪重心清楚：脸可以是第一落点，但直视镜头、拔刀、雨雾、日出、暖光和时尚展示如果同时承担不同情绪，观众仍然不知道该感到对抗、孤独、希望、危险还是欣赏。正确顺序是 `人物处境 → 人物对此的态度 → 主情绪命题 → 可见情绪证据 → 辅助余味退让`。`英姿飒爽、清冷、治愈、高级、漂亮` 是气质标签或审美评价，不是完整主情绪；主情绪必须能说清“她面对什么、她如何回应”，例如 `强敌逼近，她明知危险仍一步不退`，其主情绪是临敌不退的镇定。复杂余味可以保留，但所有视觉证据必须先指向同一个情绪方向，冲突信号要删除、改写或降低面积、亮度与对比权重。

人物有明确主情绪，不等于已经像演员。叙事性人物画面必须建立 `具体事件压力 → 可见生理反应 → 带态度的行为选择 → 对手 / 环境反馈` 的证据链：先让危险、关系或事件真实进入画面，再让眼睑、瞳孔、呼吸、下颌、肩线、手指、重心或肌肉张力出现符合人物控制程度的反应；人物随后做出一个能暴露态度的选择，最后由对手距离、道具受力、衣料、尘雨、影子、旁人反应或空间变化证明这个选择发生在真实处境中。静止也必须是面对具体压力后的主动不动，不是无事件的站桩。只写 `英姿飒爽、眼神凌厉、手持长刀、身体侧立`，得到的是角色写真语法；写清敌刃已经逼近、她的呼吸和肩线仍稳、只用拇指把刀推出少许、对方兵刃却在前景轻颤，才形成演员临场感。景别由承重证据决定：微表情承担判断时靠近；整体处境承担判断时拉开；两者都重要时用近景或中近景，并让前景威胁、关系距离和背景反馈补足事件压力。

剧本不需要替导演写完机位，但项目不能把概括剧本直接送进提示词。剧本、分镜和提示词之间必须经过“导演镜头构思”：`剧情意图 → 可拍事件节拍 → 决定性瞬间 → 人物 / 道具动作几何 → 摄影机观看位置 → 画内证据 → 光影落点 → 分镜执行参数`。剧本负责谁面对什么、为何行动、发生何种可见变化以及结果是什么；导演镜头构思负责选择拍哪一瞬、人物和武器形成什么线条、从哪里看最有力量、画面内什么证据让观众不靠解释也能读懂；分镜再落实景别、角度、构图、轴线、时长和运动；图片 / 视频提示词负责把已选镜头翻译成模型可执行正文。不能用提示词阶段的长篇光影、材质和风格细节挽救一个没有决定性瞬间与摄影机关系的普通镜头。

当用户、剧本或梗概只给 `女侠御敌、两人争吵、孩子伤心、母亲保护孩子` 等模糊画面方向时，先在内部生成 3-5 个真正不同的镜头构思候选。差异至少来自事件压力、动作相位、人物调度、摄影机几何、画内证据或光影落点之一，不能只是替换场景和滤镜。用四项筛选：是否准确完成剧情任务，是否让主情绪一眼可读，是否形成有辨识度的画面骨架，是否在当前模型和资产条件下可生成。剧本已经写明的胜负、伤势、动机、关系结论和关键道具状态必须继承；剧本没有写明的创意空间由当前模块主动选择，并把新增决定写入分镜和交接包供后续继承，不为普通创意补全停下来询问。

情绪传递与观众代入是两层结果。情绪传递让观众从表情、动作、光色和声音认出人物正在害怕、悲伤、快乐、坚定或羞耻；情绪代入要求观众在观看过程中与人物共享一部分目标、风险、信息、空间压力、身体感觉、时间等待和选择后果。关键段落先回答人物想得到什么、最怕失去什么，再决定观众何时知道危险、危险从哪个方向逼近、呼吸与受力怎样被看见和听见、等待与冲击持续多久、人物在哪一刻作出不可逆选择。观众不必认同人物价值观，也可以通过共享其感知和后果进入角色处境。

代入不等于把所有镜头改成 POV、特写、手持和快速剪辑。客观远景可以先建立无法逃离的空间，反应镜头可以完成信息对齐，主观或近主观镜头可以共享感官压力，固定镜头可以逼观众陪人物等待，拉远和静默可以让后果沉淀。一个段落按实际需要组织 `进入处境 → 对齐目标与信息 → 共同经历身体和时间压力 → 跟随选择 → 拉开承受余波`；任何环节都可以省略，但不能只展示最终表情就声称观众已经代入。

每个核心模块都执行独立升级循环：`继承硬约束 → 识别缺口 → 在本专业职责内创意补全 → 自审是否更能代入 / 生成 / 剪辑 → 记录新增创意 → 交给下一模块`。编剧补故事和人物选择，视觉资产补身份与世界痕迹，分镜补决定性瞬间与观看位置，视频提示词补时间、感官、声音和物理过程，VC 优化补体验连续性，复盘模块提出并落实优先修正。任何模块都不能用“上游没写”作为输出普通结果的理由，也不能悄悄覆盖上游已经明确的事实。

视频提示词要在图片美学上再加一层时间秩序。图片的美是关系有秩序；视频的美是关系在时间里有秩序地变化。正式写视频、故事板、音乐卡点、转场素材或短片执行稿前，从起点、触发、动作、表演、镜头、光影、环境、声音、峰值、结束和接续中选择本段实际发生且承担主情绪的节点。简单静止镜头可以只有起点、一次微变化和结束；连续长镜头、动作转折或首尾帧过渡再展开完整因果。独立素材不强制接下一镜，功能镜头不强制形成可截图停点。只写单帧美会让视频像会动的海报，只写动作会像事件记录；真正要求的是被选中的变化彼此有因果，不是时间字段全部齐全。

正式视频 `【画面内容】` 采用四核：`主体与注意力目标 + 动作与表演 + 效果系统 + 节奏与时长`。主体决定观众此刻看哪里；动作把台词、表情、呼吸、肢体、交互和反应写成变化；效果从运镜、稳定、焦点、环境、光色、速度、声音和转场中选择真正承重的手段；节奏保证主体被识别、动作能完成、情绪能建立、效果能展开、停点能成立。四核不是四个词槽，而是一条观看因果链。

影视创作必须建立情绪目标层级：`全片情绪命题 → 场次情绪功能 → 镜头主情绪 → 情绪节拍的可见 / 可听证据`。全片回答作品最终让观众带走什么感受；场次回答这一段是在积压、诱导、加深、误导、释放还是翻转；镜头回答这一刻让观众主要感到什么。主注意力目标、主观看任务、主情绪目标是三种不同判断：前者决定看哪里，中者决定这一镜完成什么，后者决定观众看完主要感到什么。三者必须同向，不能用“一个主体、一个动作”冒充情绪已经集中。

一个镜头一个主情绪目标，更准确地说是一个情绪节拍一个主情绪。复杂情绪可以存在为第二层余味；长镜头也可以发生情绪变化，但要按 `起点情绪 → 触发 → 表演 / 镜头 / 声音变化 → 终点情绪` 形成清楚转折。禁止在同一节拍内把希望、孤独、危险、浪漫、展示感和悲伤以同等权重平铺，再期待观众自行归纳。多个情绪应当通过多个镜头或多个有触发的节拍组织成曲线，而不是堆在一个镜头里互相稀释。

情绪拥有否决权，专业完整度没有。构图、光影、时间、姿态、场景、焦段、色彩、材质、运镜、声音和特效都是实现情绪目的的控制杆，不是必须全部展示的评分项。逐项只问一个问题：它是否让观众更准确、更强烈地感到本镜主情绪？加强主情绪就保留；不产生作用就省略；削弱、稀释或把注意力引向另一种情绪就删除或改写。提示词字数多、术语多、字段满，不等于导演目的清楚。

每镜必须只有一个主注意力目标。景别、构图、焦点、运动差、明暗色彩、导引线和声音共同把注意力收拢到脸、手、道具、动作接触点、环境变化或画外声音引起的反应。注意力可以迁移，但必须有眼神、动作、焦点、声音或切镜触发；不能让人物表演、背景奇观、道具和炫技运镜同时抢最高权重。

运镜统一按 `观看意图 → 摄影机物理路径 → 屏幕变化 → 情绪倾向 → 停点` 展开。推、拉、摇、移、环绕、横滚、FPV、机械臂和希区柯克变焦只是概括术语；正式提示词还要写机身是否位移、镜头是否原地转动、方向轨迹、速度稳定度、主体大小与位置、背景透视 / 横向位移 / 地平线变化、焦点和最终构图。运镜情绪倾向不是固定含义：缓慢推镜可以是亲密、发现、压迫或危险靠近，必须结合主体状态、起终景别、速度、稳定方式、焦点、声音和上下文判断。

被选中的效果必须写来源、变化过程和可见 / 可听结果。焦点、环境、光色、速度、声音和画外空间只是候选控制杆；只有承担主情绪、动作可读性或连续性时才进入正文，不为证明专业而全部填写。

时长按 `主体识别时间 + 动作完成时间 + 情绪建立时间 + 效果展开时间 + 停点 / 切换余量` 倒推。简单手势可以短，渐变表情、复杂受力、焦点迁移、天气变化、奇观展开和多次切镜需要更长；装不下时加长、删次要效果、减镜头或拆素材后期剪辑。正式模型正文不用逐秒时间码或镜头编号，以 `开场状态 → 动作发展 → 可见 / 可听桥梁触发切换 → 新画面继承 → 停点` 表达节奏。

图生视频、文生视频和资产引用必须使用不同描述预算。图生视频由输入图片承担首帧身份、外观、基础构图和已有场景，文字重点写从这张图开始怎样动；文生视频的文字同时承担首帧建构和时间变化，未资产化主体、场景、时间、风格、外观和材质要写足；实际投喂的资产负责稳定本体，正文只重申本镜临时状态、受力受光、遮挡交互和承重细节。项目默认只生成对白、动作声、衣料声、道具声和环境声，不生成 BGM。

首尾帧生成模式必须与连续拼接模式分开判断。连续拼接是把 A 条尾帧交给 B 条做首帧；首尾帧生成模式是在同一次请求里同时投喂首帧和尾帧，让模型生成两端之间的连续过程。进入首尾帧模式后，先比较两张图的主体身份、比例、位置、朝向、姿态、景别、透视、光线、色彩、场景结构和道具，再写四项内部判断：`不变量` 是人物身份、品牌结构、关键道具或运动方向等必须保持的内容；`变化量` 是服装、材质、场景、时间、天气、姿态或产品形态等必须完成的改变；`共同桥梁` 是轮廓、颜色、光源、遮挡、材质碎片、运动方向或空间入口等可连接两端的画面因素；`最大断裂点` 是最容易造成跳变的尺度、透视、位置、朝向、光线或空间差异。示例只是开放推导入口，不是固定效果清单。

首尾帧变换链统一按 `首帧状态 → 触发机制 → 解构 / 离场 → 中间过渡空间 → 形态 / 服装 / 材质 / 场景变化 → 尾帧元素提前召回 → 减速收束 → 精确落入尾帧` 设计。中间状态必须能看见因果，不能只写“炫酷变化到图二”；摄影机路径要服务变化，可以跟随、环绕、FPV 穿越、机械臂运动或模拟子弹时间，但不能和主体变换同时争夺最高注意力。尾帧的颜色、轮廓、光源、场景锚点或主体姿态必须在结束前逐步出现，最后减速并锁回尾帧景别、构图、透视和主体位置。正式正文仍保持 `【基础设定】【氛围与画质】【画面内容】` 三段，不新增第四段；基础设定引用 `【首帧参考@图1】` 和 `【尾帧参考@图2】`，画面内容写完整中间过程。两端是输入硬锚点和验收目标，但生成仍有随机性，必须通过结果复盘验证落帧精度。

这条规则要落到 `【画面内容】`，不能变成场外解释。错误写法是 `她回头看镜头，镜头推进，画面很美，氛围治愈`。正确写法是 `胸部以上中近景开场，她侧身靠在栏杆边看海，眼神先落在远处海面；男声从镜头位置响起，她睫毛停半拍，头部向镜头回转约 30 度。摄影机接住转头动作，以85mm人像镜头极慢推到舒适近景；海风带动发尾和耳坠，柔金侧逆光在转头时勾出下颌线。她眼神对上镜头，嘴角松开，画面停成可截图尾帧。`

执行时必须区分“给老胡看的解释”和“给模型看的提示词”。解释可以讲原因；正式提示词必须写目标结果。比如不要写 `很治愈、很干净、减少油腻感` 后就结束，而要把当前角色与作品真正选定的色彩、肤色、妆效、光源和受光结果写清。林栀案例可以使用海盐蓝、浅青绿、冷白偏中性肤色、清透裸妆和柔金侧逆光，但这些不是治愈人像的通用答案。

## 反模型众数倾向与审美否决门

AI 的默认输出天然会靠近训练语料里更高频、更安全、更顺口、更容易即时理解的表达。它可能清楚、完整、没有明显错误，但经常只是公共情绪模板、通用镜头模板或普通正确话。人类创作的质量不在于第一反应像不像，而在于能不能从多个可行说法里否决平均值，留下“意料之外，情理之中”的那一个。

这条规则适用于剧本、台词、标题、封面文案、口播、评论钩子、歌词式文案、风格提示词核心句、主物象、结尾余味句、视频提示词里的风格核心和任何高价值表达位置。

高价值位置不能接受第一反应：

```text
片名 / 标题 / 歌名
开场第一句 / 前 3 秒钩子
副歌核心句 / hook / 口播金句
主物象 / 主视觉概念 / 风格提示词核心句
桥段翻面句 / 关系转折句 / 人物选择句
结尾余味句 / 评论引导句 / 发布标题
```

第一版只能当候选，不能直接当成品。关键位置必须至少生成 3-5 个方向不同的候选；方向不同指人物视角、情绪姿态、关系命名、修辞路线、声音结构或画面策略不同，不是同一句话换近义词。内部可以先写候选、淘汰和胜出理由；正式交付时只输出审美否决后的结果，除非老胡明确要看候选过程。

审美否决固定做五道检查：

1. 平均值淘汰：找出最像 AI 默认答案、短视频鸡汤、普通分手歌、说明文结论、泛电影感提示词、同题材万能句的表达。它们可以作为草稿，不能直接进最终稿。
2. 同题材可替换性：一句台词、歌词、标题、钩子、风格句或主物象，如果换到任何同题材作品里仍然成立，说明它还没有长出这支作品自己的身份。
3. 关系准确性：不要只写 `遗憾、释怀、亏欠、放下、成全、救赎、治愈、破碎、孤独` 这类熟词。必须判断它真正命名的是退让、亏欠、羞耻、逃避、责任转移、亲密消耗、欲望落空、体面伪装、自我欺骗、权力不对等还是安全感崩塌。
4. 体裁成品性：歌词要能唱、能停、能复唱、尾音能落、韵脚能记；剧本台词要像人物在关系里说出来；标题要能传播；桥段要能翻面；结尾要留下动作、物象、声音或余味；视觉提示词要能生成画面，不是作者解释。
5. 留白检验：不要把所有情绪解释成道理。把 `我终于懂了 / 我放下了 / 我释怀了` 改成看见什么、听见什么、躲开什么、停在哪个动作里、哪句话没说完。留白不是含混，必须有场景、动作、物象、关系或声音结构托住。

反众数不是故意怪异。不要为了避开高频而使用生僻词、复杂隐喻、拗口句、难懂梗或故作高级的抽象概念。真正好的表达是：第一下新鲜，第二下能明白它为什么只能这样写。它偏离平均值，但仍被人物关系、场景动作、声音节奏和作品主题托住。

老胡发来的任何内容都先作为“意图材料”处理，而不是只作为字面命令处理。包括口述灵感、参考图、失败反馈、修改意见、流程吐槽、示例提示词和临时想法。

处理顺序：

```text
从老胡给出的内容里提炼原意
→ 判断他真正想达成的作品效果、创作体验或系统能力
→ 基于原意扩展可执行的规则、边界、样例和检查项
→ 判断是否属于当前作品产物、通用经验、Skill 规则、模板或检查脚本
→ 再进入具体创作、修改或沉淀
```

扩展和发散必须贴着老胡给出的材料走。不要把老胡的碎片反馈当成单点修补，也不要脱离他的原意自由加戏。能反复复用的经验要沉淀进对应执行文件；只服务当前作品的内容写入当前作品。

剧本前必须先判断是否需要“故事设计稿”。故事设计稿不是小说，而是介于灵感和正式剧本之间的导演级确认层。它先锁定受众最终感受、观众持续等待的东西、首尾画面、情绪路径、场景链、视听母题、生成难点和资产需求；商业叙事再补主角目标、阻力、代价和关键转折，文艺、氛围或纪录内容则可用关系压力、认知变化、观察对象和余味作为发动机。结构字段由体裁选择，不为填表强造冲突。

是否写小说式文章，要按用途判断。小说适合寻找人物内心、叙述语气和文学质感，但不适合作为 AI 视频生产的默认前置文件。影视短片和 AI 短剧默认先做故事设计 / 确认；正式进入剧本前，至少要有一句话核心、一段话梗概、首尾画面、主要场景链和观众情绪路径。系列作品还要先定单集样片结构和可重复的叙事 / 情绪引擎；商业短剧可以使用冲突引擎，但显性冲突不是所有系列的唯一发动方式。

故事设计稿之前可进入“灵感解构与价值脑洞层”。根据题材从表层事件、隐藏矛盾、公共议题、正向价值、观众误判、反转、隐喻物、片名、开场观看任务和结尾回响中选择有效问题；不是每个作品都要影射、反转、教育或特写钩子。它的目的，是先弄清作品为什么值得被感受和传播，而不是给所有灵感套同一套正能量短剧结构。

正能量不是把道理喊出来，也不是把人物写成完美好人。正能量短片要先找到现实里常见的错误预期，再用一个具体场景把它反过来：羞辱式激励转成尊重式引导，恐吓式教育转成能力感建立，性别规训转成身份松绑，长幼压迫转成边界教育，冷漠围观转成具体援手，民族记忆转成当下选择，传统礼仪转成现代尊重。影射和寓意必须指向普遍社会现象、价值冲突或历史记忆，避免攻击现实中可识别的个人、群体或未经确认的具体事件。含蓄可以，恶意扣帽子不行；锋芒要落在价值判断上，不落在人身攻击上。

灵感解构默认输出方向可以包含：

```text
可延伸的价值母题：爱国、民族记忆、历史尊严、家庭教育、尊老爱幼、尊师重道、儿童尊严、女性成长、反霸凌、反羞辱教育、边界感、善意援手、普通人的担当、传统文化新表达、爱情里的尊重与清醒。
可用的反差机制：观众以为要责骂，结果是保护；观众以为要羞辱，结果是尊重；观众以为是自私，结果是大义；观众以为是软弱，结果是勇敢说不；观众以为是失败者，结果是隐藏的付出者。
可视化隐喻物：门槛、饭碗、书包、奖状、旧照片、地图边界、断电倒计时、快要关上的门、被抢走又递回来的食物、没有说出口的称呼、光线照到的座位。
命名方向：用短片的反转核心、价值判断、关键物件、未说出口的话或观众误判来起名，不用空泛大词。
开场策略：优先用局部证据特写或危机型未闭合动作，让观众先产生问题，再揭示全局。
```

当老胡只给一个灵感时，助手至少先给 3-5 个不同价值方向的脑洞候选，而不是只沿第一个方向扩写。候选之间必须在价值母题、反差机制、隐喻物、开场钩子或结尾回响上拉开，不是同一个教育意义换几句说法。选定方向后，再进入故事设计稿和正式剧本。

老胡指出错误、给出反例、补充正确写法或要求沉淀经验时，必须采用“通用规则 + 错误写法 + 正确写法 + 当前案例”的结构写回规则。

```text
通用规则：这条经验适用于什么场景、触发条件是什么、底层判断方法是什么。
错误写法：典型错误句式、错误流程或错误判断，并说明为什么会导致问题。
正确写法：可直接复用的改法、执行步骤、判断顺序或提示词句式。
当前案例：用本次作品、本次镜头或本次文件举一个具体样本，说明错误如何改成正确。
```

这条方法论用于防止治标不治本。老胡指出的是当前案例，但要先判断它背后的可复用能力缺口，再决定沉淀层级。不能只记录角色名、镜头号、某个词或某个作品的特殊现象；要抽象成下一次换人物、换题材、换镜头语言也能使用的判断。比如“小安 POV 写成第三人称”不能只沉淀成“不要写小安怎样”，而要沉淀成“任何主观镜头都要检查视点主体是否被写成外部摄影机观察对象”，再把小安床上 POV 作为当前案例。

执行时至少检查三层：

```text
顶层 / 核心手册：是否需要新增通用判断。
对应 skill / 模板 / 词典：是否需要新增错误写法、正确写法、案例和自检项。
当前作品文件：是否需要把当前结果改成规则落地样本。
```

只改当前作品、不写通用规则，是治标；只写通用规则、不修当前作品，是空转；只写抽象原则、不写错误 / 正确 / 案例，下次仍然容易复发。

已确认设定默认必须保留。老胡没有明确拒绝、删除、改掉或否定的内容，不能在改稿、压缩、重排、优化对白、优化节奏时顺手删掉。尤其是人物关系、家庭缺口、死亡因果、核心道具来源、地域口气、POV 限制、时间线和结尾回收这类会影响故事情绪重量的设定，改写前必须先检查故事确认文件、阶段确认记录和当前剧本自检。若确实需要删改，必须说明删改原因并向老胡确认。

视频提示词阶段不得擅自改剧本台词。正式剧本一旦确认，台词原文、旁白原文、VO 原文和字幕原文就是下游硬约束。视频提示词只能把台词放进镜头调度里，并补充声音状态、停顿、气息、距离、混响、遮挡、电话失真等表演方式；不能改句子、换意思、删关键词、顺手加新台词或把台词改成更像主题总结的话。若原台词过长导致时长装不下，只能拆镜头、调整时长、压缩画面动作或向老胡确认改词，不能自行改写。

通用规则：视频提示词写对白前必须回查剧本原文，并把当前镜头台词锁定为“原文照搬 + 表演状态”。错误写法是把剧本 `爷爷：哪个说的。长大了，是要晓得照顾人。以后要当个顶天立地的男子汉，晓得不？` 改成 `长大不是没人管你。长大了，是你晓得照顾人了。`，这会丢掉人物口气和原剧本节奏。正确写法是保留原句，只写 `爷爷声音低、沙、短，中间轻喘停顿`。当前案例：VID-27 必须使用剧本原台词 `长大了就没人管我了`、`哪个说的...顶天立地的男子汉`、`那你还给我修车不？`、`修。爷爷说话算话。`

单点反馈必须触发全局同类扫描。老胡点名某个镜头、某句台词、某个资产、某个动作或某张生成图时，默认它是同类问题的样本，不是只改这一处。除非老胡明确说“只改这个镜头”，否则必须在当前作品同一文件、同一阶段产物和相关上下游文件里搜索同类风险：台词问题扫所有对白 / VO / OS；POV 问题扫所有主观镜头；资产数量问题扫所有同类道具；动作模糊问题扫所有动作链；年代物件问题扫所有时代相关场景。错误做法是只把 VID-27 改回原台词，却不检查其他 38 条视频提示词是否也改了剧本台词。正确做法是把剧本对白清单和视频提示词引号内容全量对照，逐条修正，再把这次反馈沉淀成规则和检查项。

场景、分镜和视频提示词必须先过“情节合理性判断”，再选择动作、构图和表演。不能为了让画面显得可爱、甜、伤心、暧昧或有细节，就随手添加捂嘴、抓衣角、低头、转身、摸头发、看远方等常见动作。先问：这个人此刻为什么会在这个地方；她表面在做什么，内心实际在发生什么；这个动作是从上一条台词、关系阶段、场景位置和人物性格里自然长出来的，还是作者为了补画面而硬塞进去的。动作越小、越生活化，越要有情节来源。

通用规则：镜头任务决定场景，场景决定身体状态，心理状态决定表情和动作。错误写法是 `独处傻乐，所以捂嘴、抓衣角、低头看手`，这类动作看起来像恋爱小动作，但未必符合当前场景；如果人物此刻靠在海边栏杆看海，真实情节更可能是表面看海、实际回想男生问候，发呆后突然笑出来。正确写法是先把场景和心理连起来：`林栀停在栏杆边，侧身看海，起初眼神放空，像在认真看海；海风吹动发尾后，单侧嘴角先翘起，随后眼睛弯起来，笑意自己从脸上漏出来`。当前案例：《30秒钟带你体验谈恋爱》VID-05 不应把重点放在抓衣角和手部插入近景，而应改成栏杆边看海、发呆、突然傻笑，用表情承担独处傻乐。

表情驱动镜头必须先判断“关系距离”，不能把“看清表情”机械理解成“脸越大越好”，也不能把某种情绪固定绑定某种景别。先问观众此刻是平等对话、被逼近、远处观察、窥视、审判、回忆还是主动靠近，再判断表情证据需要占多大面积、环境与身体关系要保留多少。中近景、舒适近景、脸部特写、远景都可能承载同一句对话；决定因素是距离本身如何加强主情绪和关系。当前《30秒钟带你体验谈恋爱》VID-06 使用胸部以上舒适近景，是因为该镜需要“期待但仍保持正常对话距离”；VID-12 与 VID-14 可更紧，是因为微表情证据承重。这些是当前案例，不形成固定比例或情绪景别字典。

表情主任务镜头必须保护第一视觉落点，但不禁止手部、身体或服装参与表演。先判断脸、手、道具、身体重心和环境中谁承担主情绪；辅助动作只有在加强同一情绪、留在既定构图内且不会诱导模型下摇或切走时才保留。`抓衣角`、`握拳`、`手贴胸口`、鞋尖或裙摆如果会成为新的镜头目标，就删除或拆成独立证据镜头；如果手在脸侧、胸前或同一景别内自然支持表情，可以使用。当前《30秒钟带你体验谈恋爱》VID-09 / VID-11 / VID-13 删除抓衣角、抓袖口和握拳，是因为这些动作把镜头从脸上带走，而不是因为所有表情镜头都不能用手。

冲突驱动、商业剧情、人物逆袭、品牌起源和创业故事可以使用“强故事三要素”：

```text
对立面：冲突驱动故事需要明确阻力，对立面可以是人物、制度、环境、时间、缺陷或错误信念。
独特个性：主角、品牌、产品或世界观不能面面俱到，必须有会吸引一部分人也排斥另一部分人的明确个性。
黑暗时刻：需要命运升级时，接近失败、失控、被围攻、被驱逐或被迫重生可以逼出不可逆选择。
```

这三项不是所有体裁的必填。文艺、观察、纪录、治愈、氛围和教程内容可以由关系距离、时间流逝、发现、认知变化、表演累积、空间观察或余味推进；但仍必须有清楚的观看理由和受众体验变化。只有赞美和空喊道理、没有任何压力、变化、发现或观察价值的内容，才需要退稿。具体执行以 `laohu_script_writer` 为准。

亲情遗憾、童年成长、怀旧家庭故事不能只写温馨场面，必须建立情感因果链：

```text
误解 / 嫌弃
→ 愿望 / 缺口
→ 亲人记住
→ 具体回应
→ 温馨使用
→ 缺点引爆
→ 后果压近
→ 遗物回收
```

这类故事的对立面通常不是坏人，而是“孩子的不懂事、自我中心、误解”和“亲人的沉默之爱、死亡不可逆”之间的冲突。前半段越生活、越暖，越要埋后半段能反打的证据，例如咳嗽、药碗、递药、旧物损坏、父亲背过身、老人用笑遮痛。核心物件不能凭空出现，必须回答：它回应了主角哪个愿望，谁记住了这个愿望，对方付出了什么行动，结尾它如何反过来刺痛观众。

伏笔不能像标签一样插入镜头，必须从人物正在做的生活动作里长出来。先建立日常状态和空间位置，再让伏笔打断或改变这件日常事，最后用人物反应把剧情带回主线。比如老人病弱伏笔，不要只写“药碗插入、老人咳嗽”，而要写孩子坐在堂屋门口屋檐下的小板凳、老人蹲在门槛外半步逗他、咳意上来时先偏头避开孩子并抬袖遮嘴、奶奶从身后堂屋里端药出来、老人故作轻松牵孩子去看木马。这样观众看到的是生活里自然露出的病，不是作者把信息塞给观众。

病弱、受伤、输液、病床和临终前状态不能只写成状态标签。凡是人物已经躺床、输液、被照护、刚受伤或明显虚弱，必须把病弱转成一组可见 / 可听证据链：脸色、唇色、眼皮、额汗、呼吸、说话音量、句子长度、停顿、动作幅度、手部力量、床单或被角反应、药碗 / 输液管 / 胶布 / 照护者表情。错误写法是 `爷爷躺床上但保持安慰孩子的笑，气息略虚`，模型可能生成脸色红润、声音中气十足的正常老人。正确写法是 `爷爷半靠旧枕头，脸色偏白泛灰，唇色浅，眼皮沉，额角有细汗；说话低、沙、短，中间轻喘停顿；没输液的手只从被沿挪出一点又停住`。当前案例：E1-S8-C2 病床自责疑问必须让爷爷的病弱体现在脸色、唇色、声音断句、手部无力、输液管和奶奶压住哭的反应里。

病床触碰动作必须做床侧、输液侧和可达性排练。凡是人物躺床、输液、虚弱或被照护时与孩子 / 亲人发生牵手、摸头、拍手、递物、擦泪等亲密动作，先判断床头床尾、孩子站在哪一侧、输液针扎在哪只手、输液管从哪里走、哪只手靠近床沿、远侧手是否被身体和被子挡住、老人翻身或抬臂是否费力。不能为了表达安慰，就让病人突然翻身、抬远侧手、跨过身体摸孩子。正确做法是让触碰发生在已经可达的位置，动作幅度小，输液管和床单有轻微反应。当前案例：E1-S8-C3 小安站在旧木床靠输液手这一侧，想碰爷爷手背胶布又缩回；爷爷不翻身、不抬另一只远侧手，只把搭在床沿附近的输液手在床单上小幅度转动，指尖反手轻轻碰住孩子的手，输液管轻轻晃一下。

生活动作必须符合真实身体反应、人物关系和社交本能。不能把“咳嗽、打喷嚏、摔倒、端药、递物、牵手、抱孩子、擦伤口、点火、推车”等动作只写成事件标签。写入剧本、分镜和视频提示词前，要先排练人在真实场景里会怎么做：咳嗽会偏头、抬手或袖口遮嘴，尤其不会正对孩子咳；端热碗会双手稳住、碗里液体会晃；牵孩子会先把手伸到孩子视线前；点火被风吹灭时会用掌心挡风、手指发紧。动作越生活化，越要写细节，因为模型不会自动补出符合人情的礼貌和身体反应。

通用规则：凡是一个动作会影响他人身体、安全、卫生、亲密距离或情绪关系，就必须写清动作方向、遮挡、避让、受力、手部位置、身体转向和声音来源。错误写法是 `爷爷对着镜头剧烈咳嗽`、`奶奶端药出来`、`父亲点火` 这类只有事件名、没有身体过程的句子；正确写法是 `爷爷咳意上来，立刻把脸偏向画面左侧避开孩子，抬起袖口挡住嘴，咳嗽声闷在袖口里`、`奶奶从身后偏暗的堂屋端着旧瓷药碗出来，药汁在碗里轻轻晃`、`父亲把纸角拢到掌心里挡风，打火机火苗照亮发紧的手指又被风吹灭`。当前案例：E1-S3-C2 必须让爷爷在堂屋门口和小安说话时偏头遮嘴咳嗽，而不是正面对着小安 POV 咳。

歧义动作必须写清工具、接触方式和顺序。凡是“加一点、取一点、放进去、抹上去、处理一下、弄好、包起来、擦一下、倒一点、递过去、推过去”等动词，现实里可能由手、勺子、筷子、夹子、布、棉签、碗、刷子、刀具或其他工具完成时，不能让模型自己猜。必须写明使用什么工具，哪只手拿工具，工具先接触什么材料，再移动到哪里，材料怎样被放下 / 压平 / 抹开 / 包住 / 擦掉，工具最后放回哪里，手是否还能直接接触该材料。尤其涉及食物、药物、伤口、胶水、颜料、火、尖锐工具、儿童和老人时，要符合卫生、礼貌、安全和身体常识。

通用规则：动作名不等于动作执行。错误写法是 `加一点馅进去`、`取一点药抹上`、`擦一下伤口`、`倒点水` 这类省略工具和接触方式的句子；模型可能生成手抓馅、手抹药、乱擦伤口或液体凭空出现。正确写法要拆成 `工具 + 手 + 材料 + 接触面 + 顺序 + 结果`。当前案例：E1-S6-C2 不能只写 `用黑芝麻馅盖住硬币`，要写 `右手拿起黑芝麻馅碗边的小木勺，用勺尖舀起一小团馅，勺背轻轻压在硬币上方盖住反光；小木勺放回碗边后，手指只接触白糯米皮，把边缘捏合封口`。这样才能避免生成奶奶用手抓黑芝麻馅，也能让包汤圆动作真实、干净、可排练。

人物资产必须区分稳定身份、固定定装、场景配件和动作道具。人物稳定身份包括脸、年龄、身高、体态、发型、基础气质、左右手参考和基础音色；固定定装是某段剧情里持续穿着的服装；场景配件是只在特定场景出现的书包、雨伞、帽子、孝布、围裙、工具包、篮子等；动作道具是当前动作临时使用的打火机、勺子、毛巾、药碗、锄头等。不能把只出现一两个场景的配件写进人物设计资产的全身三视图当成常驻外观，否则模型会在所有调用该人物资产的镜头里自动召回这个配件。

通用规则：人物设计资产的主视觉三视图只锁长期稳定形象。临时配件可以放在局部细节区、状态说明或单独道具 / 服装资产里，并标清适用场景；视频提示词每一镜必须写清本镜状态：穿什么、是否背书包、是否戴孝布、是否围围裙、是否拿工具。错误写法是 `A5 姐姐人物设计资产：三视图展示学生外套、书包、普通鞋`，随后元宵饭桌仍调用 A5，模型就可能让姐姐背着书包吃汤圆。正确写法是 `A5 姐姐三视图固定脸、身高、体态、基础学生外套和普通鞋；书包只作为放学路 / 报丧状态配件在局部细节区出现。E1-S6 包汤圆和 E1-S7 饭桌提示词写明姐姐在家里，不背书包；E1-S9 放学路才写背书包，报丧后奔跑中扯下肩带并甩落书包。`

人物定装不能只解决“穿什么”，还要解决“观众为什么会被这个人吸引、心疼或记住”。设计主角和重要角色穿搭时，先判断作品需要观众产生的第一眼反应，再反推服装版型、材质、首饰、发型、妆容和场景色彩关系。错误写法是只写 `好看的衣服、精致首饰、漂亮穿搭`，这会让模型生成普通写真、网红感或与场景脱节的衣服。正确写法要把定装和人物气质、场景光影、动作需求、观众情绪绑在一起：比如海边高级情绪片可以用月白丝缎长裙、雾蓝灰轻薄外搭、珍珠 / 银色细首饰和清透妆发，接住海风、海面冷色和黄金时刻侧逆光，同时让角色显得清冷温柔、好看到让人心疼。当前案例：林栀的穿搭目标不是单纯华丽，而是让观众产生“这么好看的女孩也会被这样对待”的疼惜和不平；因此固定清冷温柔的海边高级定装，禁止朴素 T 恤牛仔裤、红毯礼服、甜宠公主风和高饱和网红穿搭。

人物定装还必须写清“衣服如何适配身体”。参考服装图只提供版型方向，不能让模型机械复制成一件挂在人身上的衣服。主角和重要角色的定装提示词要同时写身材基础和版型机制：肩颈、锁骨、胸腰比例、腰线、体态；衣服的肩线、胸省 / 弧度、腰侧收束、高腰位置、裙摆或裤型展开点、面料贴合度和垂坠方式。错误写法是只列 `上衣、裙子、腰带、包、首饰`，模型容易生成松垮无形、胸前塌陷、遮住腰线或直筒麻袋。正确写法是 `上衣按人物身形修身合体，肩线利落，胸前有自然省道和柔和弧度，腰侧收住；腰间系带压出高腰线和细腰比例；高腰长裙从细腰处自然展开`。同时要写清边界：修身但不紧绷，漂亮但不过度暴露，不做网红紧身性感、夸张丰胸或低俗化。当前案例：林栀定装必须让【参考图2：冷灰水墨定装穿搭】衬出她的肩颈、胸腰比例和高腰长裙比例，而不是变成松垮罩衫。

服装参考不能只继承单品名称，还要继承穿法逻辑、视觉重心和比例关系。腰间系带、披肩、外套绑腰、腰封、领巾、围巾、链条、裙摆开衩这类细节，如果参考图里是偏侧、斜绕、松弛、轻薄或作为比例修饰，就不能机械居中成正面大结、毛巾、围裙或厚重遮挡布。鞋履也不是脚下随便补一个款式，必须和人物身份、场景、服装、首饰、脚背露肤、腿部线条和动作需求统一：写清鞋头形状、闭口 / 露趾、浅口 / 深口、踝带、跟高、材质、颜色和气质。当前案例：林栀腰间浅灰条纹层必须偏侧斜绕、扁平贴腰、布尾轻薄同侧垂落；鞋履从露趾凉鞋改为珍珠白冰银尖头浅口踝带低跟单鞋，闭口细尖头、浅口露脚背、纤细踝带和低细跟服务清冷文艺气质。

人物设计资产的三视图必须展示角色自己的代表性基准体态，而不是统一套“挺拔高光体态”。姿态要与年龄、职业、健康、性格、身体特征和剧情身份一致：女侠可以肩背打开、重心稳定，疲惫老人可以有真实含胸，受伤角色可以保留代偿姿态。制作资产锁的是身份，不是把所有人物美化成同一种站姿。当前林栀 A1 可以展示她 24 岁的自信挺拔状态，但该案例不适用于所有角色。

人物设计资产必须有同一份造型账本。主视觉三视图、面部特写、手部特写、局部细节区、配色板和比例照，必须共享同一套服装、发饰、耳饰、项链、包、鞋履和腕部状态。不能一个分区有一个发圈，另一个分区把它变成两个手环；不能三视图穿一种鞋，局部细节又生成另一种鞋；不能标签写鞋子，图像却对应别的物件。写提示词时要先列清：发饰在哪里、手腕是否有饰品、鞋履是什么风格、哪些配件只属于头发 / 颈部 / 耳侧 / 脚部 / 手部。当前案例：林栀 A1 的深灰发圈只属于发间，左右手腕保持干净；鞋履固定为珍珠白冰银尖头浅口踝带低跟单鞋，服务清冷文艺海边定装。

人物设计资产版式必须按信息优先级分配画幅。主角和重要角色的设计资产中，三视图、大尺寸纯头部脸部特写、摄影棚真实人像状态区是主信息；左右手、色值卡、局部细节和音色说明是辅助校对信息。身高和身体节点比例不要再单独占一个和三视图重复的全身比例图，而应合并到三视图里：用厘米测量线标注脚底、脚踝、膝盖、髋部、腰线、胸线、肩线、颈根、下巴和头顶，不能用 1、2、3、7.5 这类模型难以理解的抽象刻度。右侧或主辅助区域优先做“摄影棚真实人像状态区”：胸部以上中近景，简洁中性灰背景，使用中性、可比较、不过度美化的宽柔光，曝光准确保留角色自己的肤色、皮肤纹理、妆容、肩颈姿态、首饰和服装状态；轮廓光只在需要检查发丝或服装边界时轻量加入，不作为固定美女光型。它的目的不是新增剧情表情或统一美化，而是提前校准后续视频最容易出问题的皮肤、光影、妆容和真实人像气质。脸部特写必须是真正的头部 / 脸部特写，用来放大五官、眼神、鼻梁、嘴唇、皮肤质感、妆容和发际线，不要拆成两张半身 / 颈肩特写来浪费面积。手部参考要有，但应是小面积手模级模块，展示手指、指节、甲床、肤色和左右解剖方向，不要抢走脸和三视图的主画幅。配色只做紧凑色值卡，优先使用十六进制 RGB 色值，不写大块颜色名称。当前案例：林栀 A1 把原本右侧重复的 168cm 全身比例图改为摄影棚真实人像状态区，厘米身高和身体节点标注并入左侧三视图。

人物设计资产本身会反向影响后续视频肤色，因此必须先锁住角色自己的肤色、气色、妆效和皮肤介质基准，并让它与地域、年龄、职业、年代、健康状态、服装和作品主情绪一致。冷白偏中性、清透裸妆和柔雾奶油肌只是林栀案例；暖肤、深肤、晒痕、雀斑、皱纹、粗粝皮肤、无妆或年代妆都可以是更正确的身份锚点。参考图只继承任务需要的身份特征，不继承与目标冲突的光源或妆效；摄影棚状态区用于验证所选基准在真实光线下是否成立。

人物设计资产的左右手必须按人物自身左右校准。左手和右手不是画面左边和画面右边，而是人物自己的左手和右手。手部参考区要分别标注“左手”“右手”，并写清拇指方向。标准手背参考可以写：手背朝镜头、指尖向下时，人物自己的左手拇指在画面右侧，人物自己的右手拇指在画面左侧；手掌朝镜头时左右关系相反。左右手应同年龄、同肤色、同手部比例，但解剖方向相反，不能生成成两张同一只手。

儿童 POV 和儿童交互镜头必须做身高 / 可达性排练。只要出现柜台、灶台、饭桌、电话、货架、车门、门锁、窗台、水缸、床沿、药碗、工具等成人尺度物件，先判断儿童的身高、视线高度、手臂长度、抓握力量和真实操作能力。孩子够不到、看不全或不能独立操作的物件，不能按成人视角写完整操作；要让成人手递下或接回，让孩子踩矮凳，让画面只看见物件下沿、侧面、玻璃反光、模糊轮廓、垂下来的线或递到眼前的局部。

通用规则：儿童镜头里，物件是否能被看见和是否能被操作，是两个不同判断。看不见完整主机，就写柜台上沿挡住视线、玻璃后方一团模糊黑影；能接住听筒，不代表能拨号或挂电话；能坐在小板凳上看灶台，不代表能俯视整口锅。错误写法是 `小安趴在柜台边，黑色老式座机、卷曲电话线和硬币占画面中心，听筒被小手放回座机`。正确写法是 `画面低于玻璃柜台上沿，座机主机在柜台上方只是一团模糊黑影；成人手把听筒从高处递到小手前，卷曲电话线从上方垂下来；通话结束成人手接回听筒，高处传来咔哒挂断声`。当前案例：E1-S3-C4 小安只能抱着从柜台上方递下来的听筒告状，不能比柜台还高、不能平视完整座机主机、不能自己挂电话。

道具状态变化必须具体到可见部位或功能结果。凡是写“坏了、坏掉、破了、旧了、修好了、不能用、滚不动”这类状态词，都必须继续回答：坏在哪里，观众从画面里怎么看出来；如果外观可见，就写轮子半脱、轮轴松动、裂缝、断口、翘起木片、补木片；如果内部或功能损坏，就写人物尝试操作后的结果，例如推一下卡住不滚、轮子只晃不转、发出闷响、车身歪向一侧。正确做法不是把“坏”解释给观众听，而是让观众看见或听见“坏”的证据。当前案例：E1-S5-C1 不能只写“坏木车靠在旁边”，而要写 `右前圆木轮半脱、轮轴松动外露、车身向右前方歪斜；爷爷轻推后右前轮卡住发出闷响，车身只晃一下没有滚动`。

场景位置不能只写一个会造成歧义的模糊名词。`门口`、`院子`、`屋里`、`车上`、`路边` 等在 POV、正反打、人物走位或动作因果中承担空间职责时，用最少的必要锚点消歧；不要求每次同时补齐摄影机侧、主体侧、前中后景、门窗桌墙和光源。比如 `老家堂屋门口屋檐下、门槛内侧的小板凳` 已能区分堂屋门口与院门外，后续锚点只在动作或主情绪需要时增加。

多人群像和围桌场面必须先做座位图 / 站位图。凡是饭桌、会议桌、课堂、灵堂仪式、院子围观、家庭合照、群体争执等多人同框镜头，不能只写“大家围坐”“众人站着”“家人围在桌边”。必须先确定视点位置、桌子或场地朝向、每个关键人物在画面左 / 右 / 前 / 后 / 近旁 / 远侧的位置，再让台词、视线、递物、起身、推搡和冲突沿这个固定空间发生。错误写法是 `饭桌居中，家人手和碗环绕，姐姐、父亲、爷爷先后吃到硬币`；正确写法是 `小安坐饭桌近侧中间，自己的碗在最前景；爷爷坐小安右手边、画面右前方近旁；姐姐坐画面左侧，奶奶坐对面中间，父亲坐对面偏右靠旧墙。视线依次扫向左侧姐姐、对面偏右父亲、右前方爷爷，再低回自己碗里`。当前案例：E1-S7-C1 把爷爷放在镜头右前方近旁，是为了让 E1-S7-C3 爷爷从右侧伸手安慰、小安向右前方推开、爷爷向右后方柴火边失衡有空间因果。

冲突动作必须有前置动机、靠近路径和身体位置。推开、打断、抢夺、摔倒、撞倒、拉扯、抱住、躲开这类动作，不能只写冲突结果。必须先回答：被推的人为什么靠近，怎么从原位置移动到主角身边，身体重心在哪里，手伸向哪里，主角为什么在这一刻产生反应，推力作用到哪个部位，后退或摔倒撞到什么合理边界。没有这些前置条件，动作会显得像凭空伤人，观众也会觉得因果不成立。

通用规则：冲突不是两个身体突然碰撞，而是“安慰 / 阻拦 / 抢夺 / 靠近 / 触碰”引发的反应。错误写法是 `爷爷坐在桌旁把硬币伸过来，小安一推，爷爷连人带凳跌到柴火边`；正确写法是 `爷爷先撑桌起身，从右侧桌边绕到小安身旁，拿小布巾弯腰想擦眼泪；小安执念爆发，两只小手推开贴近脸前的手腕和胳膊；爷爷弯腰重心在前，被推后退半步，脚跟撞到右侧小木凳，失衡跌坐到柴火边`。当前案例：E1-S7-C3 必须让爷爷从饭桌旁走过来给小安擦眼泪，推倒才有生活逻辑。

冲突动作改稿时，要把“结果型描述”重构成“可排练动作链”。第一步先找原稿里只写结果的地方，例如“伸过来、推开、摔倒”；第二步补人物动机，让靠近动作有情绪理由，例如安慰、擦眼泪、阻拦或抢回物件；第三步补空间路径，说明人物从哪个固定位置移动到哪一侧；第四步补接触点和视线焦点，说明手、道具、脸、肩膀、胳膊怎样压近画面；第五步补受力链和边界，说明被推后退几步、撞到什么、怎样跌坐或撑地；第六步补后果控制，说明这是弱因果、意外、惊吓或冲突升级，不把动作写成直接致命或夸张暴力。

这类改稿的重点不是让动作更复杂，而是让观众相信这个动作能在真实空间里发生。当前案例里，老胡把原本“爷爷在桌边伸硬币，小安推，爷爷跌倒”的结果句，改成“爷爷因安慰孩子而离开座位，拿硬币和小布巾绕到小安身旁，弯腰擦眼泪，小安推开贴近脸前的手腕和胳膊，爷爷因弯腰重心在前而后退撞凳失衡”。这套方法以后适用于所有冲突调度，不只适用于爷爷这一场。

亲情遗憾故事里的关键对白不能像完成任务一样突然出现。奶奶叮嘱、父亲压怒、老人忍哭、临别交代等情绪台词，必须先有生活动作、环境阻力、身体泄露或物件回忆铺垫，再让台词出来。比如量衣服、改袖口、整理孝布、端药、擦脸、打火机几次打不燃、纸房飘带被风吹乱、门被风推响、手指发抖、肩背绷紧、袖口针脚和旧物回响，都可以替人物说出说不出口的情绪。

如果一段对白显得快、莫名其妙、像在交代任务，不要优先加解释性台词。先检查它前面有没有可见生活证据，人物有没有说不出口的动作阻力，环境有没有替情绪施压。沉默寡言的父亲尤其要用动作和环境刻画：手抖、背影、握孩子太紧、火点不着、风吹纸房飘带等，比直接说“我很难过”更有力量。

回忆 VO 要和当前触发物件对位。旧话不是哪里情绪重就往哪里放，而是由画面中的物件、动作或声音触发：袖口针脚触发“添衣裳”，P1 旧车修补痕迹和 P2 新车触发“一人一个”和“说话算话”，P11 半成品木马车架的悬空后轮触发“爷爷还在继续做、却没来得及完成”的未完成感，药碗触发疾病伏笔，纸房火光触发离别和叮嘱。VO 出现时，画面必须给出对应证据，让观众知道这句话为什么在这一刻响起。

连续结尾分镜必须先做空间和动作链排练。凡是 2 条以上分镜共同完成一个结尾动作、遗物发现、回忆触发或片名出现，不能把每条镜头当成孤立画面各自写漂亮。先锁定上一镜停点、本镜起点、下一镜触发点、道具数量、道具状态、位置方向、人物手是否还牵着、谁停住、谁往前走、镜头最后停在哪里；然后再写每条正式提示词。错误写法是第一镜写“离开时看到木轮”、第二镜突然变成“墙角两辆车”、第三镜才说“旧车翻倒”，空间和道具状态前后不一致。正确写法是第一镜父亲牵小安往大门走，院中两辆完整木马车和一架 P11 半成品木马车架提前进入视线；第二镜小安松开父亲走到 P11 面前，摸悬空后轮、粗糙木轴和未完成坐板并触发爷爷回忆；第三镜从同一只悬空后轮继续拨动，枯叶和纸灰飞起后升镜拉高出片名。

结尾片名不要硬贴在静态画面后。短片最后如果要出现片名，优先让片名从最后的物件动作、环境运动或镜头运动里自然长出来：例如拨动木轮带起枯叶 / 纸灰，镜头跟随轻物拉高，完整院子显露后再出现《不想长大》。这样片名不是额外说明，而是观众刚刚看见的情绪结果。结尾镜头可以从近处遗物出发，慢慢扩展到整个空间，把个人动作、亲人遗物和故事主题合成一个最后记忆点。

片名镜头必须规划文字的屏幕结果。正式提示词里如果要生成片名、字幕、片头字或结束文字，不能只写“出现片名”。要写清文字内容、出现时机、位置、大小、字体气质、颜色、边缘质感、停留时间，以及它避开哪些人物、道具和视觉中心。文字属于画面元素，写得模糊就会变成随机贴字、遮挡主体或和画面情绪脱节。当前案例：《不想长大》应在院子全景稳定后出现，位于画面上方留白处，暖白色、轻微手写笔触、老式 DV 毛边，横排居中，大小约占画面宽度三分之一，不遮挡下方人物、两辆完整木车和 P11 半成品车架。

第一桶金、创业起源、个人逆袭类故事，默认使用三幕英雄之旅：

```text
离开之幕：为什么离开旧世界。
启动之幕：进入未知世界后遇到什么怪兽。
归来之幕：第一桶金如何到来，它是新起点还是新深渊。
```

如果只写“努力后成功赚到钱”，没有旧世界、怪兽、黑暗时刻和归来后的代价，默认不是有感染力的第一桶金故事。

短视频流量类内容要检查喜剧表达和传播反差：

```text
狠词怂态度：用强烈措辞表达弱势处境，制造反差。
言不由衷：说观众一听就知道夸张或不可能的话，让荒谬感成立。
经典借用：借用经典作品、流行梗或熟悉桥段，但必须服务当前观点。
九浅一深：浅内容抓流量，深内容留铁粉。
```

流量低时不要只怪平台限流。先检查表达是否太顺、太安全、没有争议钩子、没有反差、没有可转述的包袱。具体执行以 `laohu_script_writer` 和 `laohu_generation_review` 为准。

短视频剧情片要区分正片层和包装层。正片层负责故事沉浸、人物表演、声音关系和情绪闭环；包装层负责前 3 秒开场钩子、标题解释、观看任务、结尾评论引导和账号发布语境。包装层可以让角色或表演者短暂对镜头说话，但不能反过来破坏正片规则。错误做法是因为需要开场口播，就让正片人物全程解释剧情，或因为正片人物无对白，就完全放弃短视频开头和结尾互动。正确做法是单独设计包装层：谁说、说什么、几秒、声音状态、如何进入正片、如何从正片情绪退回评论钩子。当前案例：林栀正片中无对白，只用表情承受男声脑内回响；包装层开场说“30秒，带你谈一场恋爱”，结尾说“30秒台词我演了2分钟，你的30秒呢？花了多久？”用于解释“30秒”指台词时长，不是成片时长，并引导观众评论自己的时间成本。

苦难、低谷、困难可以写，但不能卖惨：

```text
人可以惨，但不能卖惨。
苦难只能作为真实处境或短暂钩子，必须转向和解、励志、行动或成长。
如果内容只索取同情，没有出口，默认需要回到剧本阶段重写。
```

平台和观众会识别过度表演的惨。卖惨不是长期人设，和解和励志才是可持续刚需。

故事和短视频内容要主动设计杠杆：

```text
大脑墙：观众已有的防线、信仰、偏见、身份、恐惧和价值观。
痛点杠杆：人对痛苦、损失、风险、错失、不甘和难受的敏感度高于喜悦，真实痛点能让观众从旁观变成参与。
金句钉：精炼、扎心、可复述、可截图的句子，用来穿透大脑墙。
共鸣网：让个人经验接入一类人、一种关系、一个社区或共同处境。
利他金：让观众带走方法、情绪释放、认知升级、勇气、判断标准或行动路径。
```

内容讲得正确但传播弱时，先检查是否缺少故事杠杆。没有金句、没有共鸣关系、没有观众收益的内容，很难撬动情感、认知和转发。

痛点杠杆必须有边界：可以唤起真实难受和损失厌恶，不能制造虚假焦虑、夸大恐惧或恶意操控。让用户难受的目的，是让他看见问题和行动出口，不是让他停在自责或恐慌里。

广告语、口播金句和品牌表达要尽量写成“个体宣言”：

```text
不是普通正确话，而是一个人、品牌、产品或群体站出来表态。
不是只复述共识，而是从共识里找到未被说透的真实偏好、隐秘不满、反常识角度或判断倾向。
偏见不是歧视或恶意标签，而是主流共识尚未承认、但观众心里已经存在的立场缝隙。
```

金句弱时，先检查它是否缺少明确立场、个体宣言感和替某类人发声的力量。

表达不要只追求理性正确，要借用感性、缺点和共同敌人：

```text
理性让内容站得住，感性让内容被记住。
优点容易变成普通赞美，缺点更容易形成真实边界、亲密感、个性和共同敌人。
能够被接受的缺点，往往比完美优点更能成为人物、品牌、产品或观点被认可的理由。
```

借用缺点不是羞辱、恶意攻击或廉价自黑，而是把边界说清楚：它不讨好谁，反对什么，和谁站在一起，最后如何转化成个性、选择、反击、成长或关系。

内容和视觉都要警惕选择性忽视：

```text
想讨好所有人，就会失去风格。
人会忽视熟悉、平滑、顺从、平均的刺激。
短视频、广告语、歌词、剧本台词、封面和视觉风格，都需要一个服务主张的轻微跑调点。
```

轻微跑调点可以是一个不顺滑的词、反常识判断、可接受缺点、出人意料的构图、冲突色、奇怪但准确的比喻或带刺的节奏。它不是无意义猎奇，而是为了让目标观众停止滑走，并让非目标观众自然离开。

短视频开头和强转场必须优先判断是否需要“未闭合动作”。未闭合动作不是普通炫技转场，而是在 0-3 秒内先给观众一个尚未解决的问题，让观众大脑自动预测结果：手机电量倒计时会不会归零，充电头能不能插上，迎面卡车会不会撞上，棒球会不会砸到镜头，铁水火花会不会铺满画面。观众已经开始等待答案时，剪辑在答案发生前一瞬切入正文，正文就借到了上一秒的注意力。

通用规则：短视频开头不能只展示美、帅、氛围、人物登场或普通标题。只要目标是提升滑动停留、开场抓人、进入歌曲 / 舞蹈 / 剧情 / 口播主题，就先设计一个可见的未闭合动作。未闭合动作可以来自倒计时、即将断电、即将碰撞、即将插入、即将爆开、即将击中镜头、即将揭晓、即将坠落、即将关门、即将熄灭。它必须有清楚的起始状态、时间压力、逼近路径、不可回避边界、峰值遮挡 / 冲击和正文揭示。

错误写法：`开头一个炫酷转场，突然切到女主唱歌。` 这只是装饰转场，观众没有等待的问题。正确写法：`手机屏幕显示电量 1%，系统关机倒计时从 5 跳到 1，画面下方充电头沿桌面快速滑近接口；插头金属头距离接口只剩一指宽时，屏幕骤暗，下一帧从同一块黑屏里亮出女主舞台眼神。` 当前案例：手机倒计时、卡车逼近、打铁花火花铺满、棒球撞镜头都属于“先让结果逼近，再在结果兑现前切走”的危机型开头转场。

## 二、核心流程

```text
灵感
→ 沟通确定故事内容
→ 剧本结果输出文件
→ 资产图片提示词输出文件
→ 分镜表格输出文件
→ 按需生成镜头预演板提示词
→ 第一个分镜视频提示词展示文件
→ 所有分镜视频提示词结果输出文件
→ 老胡制作完成后生成封面
→ 归档
```

每一个阶段都必须形成正式产物并通过内部质量门，但不要求老胡逐阶段批准普通创意。可以跳过不需要的固定图片资产，但不能跳过剧本来源、导演镜头构思、分镜编号、确定时长和文件承载。真实高成本生成、发布操作、法律安全风险或老胡明确要求共同创作时，才启用人工确认门。

当老胡给的是口述故事、脑中大概故事、碎片剧情或边讲边补的长段输入时，先保留核心事件、整理主线并识别因果、动机、时间线和情绪落点缺口。属于创意留白的缺口由编剧主动补全并记录；只有互相排斥的核心方向、价值立场冲突或老胡明确要求共创时，才进入逐项追问。

需要追问时一次只问一个最关键问题，不让老胡填表。其他缺口继续由编剧按体裁补全：冲突驱动故事补目标、阻力、转折、高潮和关键选择；文艺、观察、纪录、治愈或氛围内容补观看对象、关系 / 时间变化、情绪累积和余味。

口述故事进入剧本前必须满足：

```text
故事设计稿里没有彼此冲突、无法由专业判断选择的核心问题。
作品的推进机制能说清：冲突、关系、时间、发现、观察、表演、空间或认知变化至少有一种真正承重。
观众体验变化能预演：如何进入、注意什么、主要感到什么、哪里发生变化、最后带走什么。
已明确事实与创意补全分开记录，后续知道哪些必须继承、哪些仍可继续发挥。
```

如果老胡明确要求“直接全部输出”“一口气跑完”“从最开始到最后结果”“只要一个结果”，只能理解为跳过阶段之间的人工确认停顿，不能理解为降低每个阶段的创作深度、信息密度或执行颗粒度。

正确做法：

```text
仍然完整执行故事、剧本、视觉资产、分镜、第一条视频提示词校准、全部视频提示词、VC 优化、自检。
可以把最终交付集中到一个主结果文件里。
但主结果文件里的每个阶段必须是完整产物，不是压缩摘要。
正式视频提示词仍按每条独立生成请求写到接近可用上限，不能因为一次性输出很多条就把画面内容写薄。
```

禁止做法：

```text
把“只要一个结果”误解成“只给总览”。
把剧本压成故事梗概，把资产压成几行判断，把分镜压成简表，把视频提示词压成低密度短句。
为了节省输出长度牺牲画面内容、人物表演、运镜路径、声音细节和生成可执行性。
```

视频提示词生成结果在输出呈现前，必须增加一次 Vibe Creating 优化。优化使用外部原文 skill：

```text
02_共享资产库/05_工具流程/外部优化Skill/vibe-creating-prompt/SKILL.md
```

项目新增 `laohu_vibe_creating_prompt` 作为第 6 个核心 skill，负责把该外部原文 skill 接入本项目。外部原文不改名、不改内容；项目 skill 只做调用、边界和三段模板回填。执行时先由 `laohu_video_prompt` 生成符合本项目三段模板的正式提示词初稿，再由 `laohu_vibe_creating_prompt` 优化画面表达、情绪体验、关键意象和视觉统一性，最后交回 `laohu_video_prompt` 把优化结果重新落回 `【基础设定】`、`【氛围与画质】`、`【画面内容】` 三块后写入文件。

VC 优化不能破坏本项目硬约束：确定时长、三段模板、台词 / 旁白 / 音乐 / 音效原文、资产一致性、空间动作因果完整、禁止作者说明和后期备注。若 VC 优化结果改动了剧本台词、旁白、VO、字幕或用户明确指定句子，回填到正式三段提示词时必须改回原文。

## 二点五、文件承载与阶段确认

项目里的正式产物默认不直接塞在聊天里，必须写成文件。老胡说“输出文件”“结果输出文件”“生成输出文件”“给我看文件”“生成一个文本”等类似描述时，一律创建或更新 `.md` 文本文件，并在回复里给具体结果文件链接、简短说明和已继续完成的下一步或真实执行动作。

不管什么时候，只要本轮产出了结果文件，回复时必须直接给结果文件链接，不能只给目录链接让老胡自己找。可以说明文件属于哪个阶段，但不能用阶段目录链接替代结果文件链接。只有老胡明确说“给我目录”“我要看目录”“目录结构给我”时，才回复目录链接。

当视觉资产和视频提示词都已经产出时，默认对话只给两个主结果链接：`视觉资产总表` 和 `一体化视频执行单`。不要同时抛出一堆分镜表、故事板过程文件、旧展示文件和目录链接让老胡自己判断哪个该复制。过程文件可以在说明里提一句已保留为记录，但执行入口必须清楚、少而准。

对话里不要输出很长的剧本、分镜表、提示词全集或复盘全文。对话只负责三件事：

```text
1. 告诉老胡当前阶段做了什么。
2. 给出具体产物文件链接。
3. 说明下一步已经继续完成什么，或哪一步需要老胡执行真实生成 / 发布操作。
```

除非老胡明确要求“直接贴在聊天里”，否则正式内容都放文件。

标准阶段门：

| 阶段 | 产物文件位置 | 内部质量门通过后的下一步 |
|---|---|---|
| 灵感沟通 | `00_原始输入/文本/` 或 `00_项目总览.md` | 确定故事内容 |
| 故事内容确认 | `01_世界观故事/文本/00_故事确认.md` | 写剧本结果输出文件 |
| 剧本结果输出文件 | `02_剧本/文本/` | 资产图片提示词 |
| 资产图片提示词输出文件 | `03_视觉资产/文本/`、`03_视觉资产/图片/` | 分镜表格 |
| 分镜表格输出文件 | `04_分镜/文本/` | 按需生成镜头预演板 / 第一个分镜视频提示词 |
| 镜头预演板提示词输出文件（可选） | `04_分镜/文本/` | 人工确认构图 / 生成干净首帧或构图参考图 |
| 第一个分镜视频提示词展示文件 | `05_视频/文本/` | 所有分镜视频提示词 |
| 所有分镜视频提示词结果输出文件 | `05_视频/文本/` | 老胡制作视频 |

每个作品必须维护阶段确认记录，建议位置：

```text
01_作品项目/<状态>/<作品名>/00_阶段确认记录.md
```

每次交付阶段文件后，要在确认记录里写清楚：阶段、文件、内部质量门状态、是否触发人工确认、下一步。`00_阶段确认记录.md` 是沿用的历史文件名，不代表普通创意必须等待老胡批准。

目录边界：

- `00_原始输入/`、`01_世界观故事/`、`02_剧本/`、`03_视觉资产/`、`04_分镜/`、`05_视频/` 是作品的 6 个创作阶段目录。
- 每个阶段目录下面固定保留 `文本 / 图片 / 视频 / 音频` 四类媒介子目录。
- `01_世界观故事/文本/00_故事确认.md` 是故事内容确认稿，不放入剧本目录。
- `02_剧本/文本/` 只放正式剧本结果和确认后的剧本改稿。
- `03_视觉资产/` 放世界观可视化、风格、角色、场景、道具、图片资产提示词和封面视觉方案。
- `04_分镜/` 放分镜表、镜头任务表、镜头预演板提示词、预演图和分镜参考片段。
- `05_视频/` 放视频提示词、生成视频、视频参考图、音频参考和剪辑相关文本。
- 不再额外预建许多空分支目录。若某阶段素材量变大，可以在该阶段的 `文本 / 图片 / 视频 / 音频` 下再按需细分。

资产定义：

```text
资产 = 需要复用和一致性锁定的角色 / 场景 / 道具 / 风格 / 画面参考。
画面元素 = 只在单个镜头或单个场次出现、服务当下画面的临时内容。
```

低保真故事板统一定位为 `镜头预演板 / 分镜预演图`。它不是资产、最终画面参考图或视频首帧图，而是给导演、作者和生成操作者审查构图、景别、机位、人物比例、空间关系、视线、动线、切换点和停点的低成本人审工具。它可以在视频提示词之前或并行生成，但不默认作为 Seedance 输入。

低保真故事板必须遵守：

- 可以在提示词开头列出本镜参考的场景资产、道具资产和必要群像资产，但只用于校准方向、出入口、主要空间锚点、道具数量、位置关系和动线；不复刻资产外观、颜色、材质、家具细节、真实光影和人物长相。
- 不画真实五官、具体服装、具体材质、真实光影和最终特效。
- 不承担 `【基础设定】` 和 `【氛围与画质】` 的世界观解释职责。
- 只锁构图、景别、机位、主体比例、站位、道具数量、空间锚点、引导线、动线路径、视觉重心、亮部重点和留白区。
- 图像形式优先为黑白 / 灰阶抽象构图骨架图：画幅框、三分线 / 黄金分割线、视线箭头、动线虚线、前景框、引导线、光源箭头、负空间块、少量火柴人 / 简化剪影、必要几何块和中文标签。可以有轻微 2.5D 空间关系，但不能画成完整室内 / 院子 / 街道场景草图。
- 空间锚点优先用文字标签和极简线条表达，例如 `门口方向`、`床尾 / 被沿`、`旧墙`、`院门`、`柴堆`、`光源方向`。除非该物件是当前镜头的视觉中心或动线边界，否则不要画完整家具、完整房间布局、装饰物、床头、枕头、台灯、书桌、窗帘、花盆、画框等细节。
- POV 故事板必须先做物理朝向检查：视点主体是躺着、坐着、站着还是低头；身体朝向哪里；眼前真实能看见床头、床尾、门口、地面、手部还是道具；不能把不可能同时看见的床头、枕头、门口和完整房间都塞进同一张构图。当前案例：小安躺在床上面向门口方向，故事板只能用被沿 / 床尾方向线、小手或袖口、远处门口方向框和视线箭头建立关系，不能画出完整床头、枕头、窗帘、台灯和书桌。
- 色彩、材质、人物长相、服装细节、最终光影、声音、动作过程、台词、VO 和情绪变化继续由资产、视频提示词和剧本约束。

镜头预演板提示词和视频提示词必须同源，但服务对象不同。`【镜头预演板提示词】` 给图片模型和人工审片，`【Seedance 2 视频生成提示词】` 给视频模型。需要预演时，两者可放在同一 `VID` 的一体化视频执行单里，减少文件切换；老胡明确只要视频提示词或镜头已经通过构图验证时，不强制生成预演板。

视频生成提示词的 `【基础设定】` 只调用本镜真正上传或绑定的人物、场景、道具、色卡、首帧、动作和音色参考。镜头预演板不属于默认调用项；需要模型参考构图时，优先从预演结果生成或挑选一张无表格、无箭头、无文字标注、无多格拼图的干净首帧 / 构图参考图。只有实际测试证明某张预演图能提高稳定性时，才显式调用它。

如果老胡采用 15 秒以内多段视频拼接成一镜到底效果，A 条视频的尾帧可以作为 B 条视频的首帧参考。生成 B 时在 `【基础设定】` 引用 `【首帧参考@VID-A尾帧】`；`【画面内容】` 用自然语言写“镜头从该尾帧保持的景别、构图、光源方向、人物姿态、表情余韵和背景锚点继续”，再写新动作。不要写 `第0秒` 或逐秒时间码。

镜头预演板提示词必须单条自足可复制，但只画当前镜头需要人工验证的关系。黑白 / 灰阶骨架、画幅框、构图线、视线、动线、前景框、光源方向、负空间、简化剪影、空间标签和表格列都是候选；多人调度可多画站位与动线，单物特写可能只需画幅、主体占比和焦点，不能为了“完整板式”把无关标记全部塞入。

连续一镜到底拼接时，镜头预演板第一格可以从 `【首帧参考@VID-A尾帧】` 的构图和人物状态继续，随后才画本条的新变化；它服务人工检查，不因此自动成为视频模型参考。

表情驱动、情绪人像、开场钩子、脑内 VO 反应和关系变化类视频，故事板先判断情绪证据主要在脸部微表情、身体距离、完整姿态还是环境关系。脸部微表情承重时优先中近景、近景或特写；疏离、压迫、等待或关系距离承重时，中景、全景和远景也可能更准确。故事板只突出主情绪证据，不让无关手部、鞋尖、裙摆、包带或完整场景抢镜；当前恋爱情绪短片案例可使用胸部以上构图，但不升级成所有情绪镜头的固定景别。

镜头预演板可以写 `参考资产：...`，但只校准方向、出入口、空间锚点、道具数量、位置关系和动线，不复刻资产外观。人物只用简化剪影表示站位与比例。

镜头预演板提示词正文不要写项目内部代号；代码块内从 `镜头01` 连续编号到实际需要的 `镜头N`，或使用 `低头前`、`遮挡转场点`、`抬头后` 等可见画面节点，不使用内部时间码。

推荐故事板表格列：

```text
镜头 / 关键画面
线框构图
构图规则
景别 / 机位
空间锚点
引导线 / 动线路径
主体比例与位置
```

第 2 列 `线框构图` 必须描述该格真正需要验证的构图骨架。画幅框与主体块是基础；三分线 / 黄金分割线、视线箭头、动线虚线、前景遮挡线、光源箭头、负空间块和空间标签只在承重时加入。火柴人或简化剪影用于人物比例和站位；几何块用于当前视觉中心或关键道具；真实空间路径、引导线和运动箭头也只画实际存在的关系。单物特写不应为了板式完整补满所有标记。

错误写法：`线框构图` 把床头、枕头、窗帘、台灯、书桌、墙画、门口全部画成完整卧室，结果视频模型把故事板当成首帧参考并继承错误空间。正确写法：只画画幅框、下沿被沿弧线 / 床尾方向线、远处门口方向框、视线箭头、小手或袖口小标记、右侧三分线和留白区；床头、枕头、窗帘、台灯等不作为本镜视觉中心时只放到文字判断里，不画进构图图。

构图规则列必须写清主体落点和本镜真正使用的视觉关系，但不强制套专业构图名称。三分、黄金分割、对称、框架、引导线、对角线、三角、层叠、纵深、留白、负空间和遮挡转场都是候选；中心特写、满构图和有意失衡也可以成立。错误写法是泛泛写 `构图好看 / 画面有重点`；正确写法可以是 `门框两侧竖线和被沿弧线框住父亲剪影，左侧空窗压低亮度，让眼睛先落到父亲手里的外套`。

故事板必须明确主注意力目标，但视线不一定需要复杂流向。主体落点、裁切、面积、构图线、前景框、引导线、负空间、光源方向、明暗重心和运动差都是候选；静止中心特写可以只证明“先看哪里”。黑白线稿只标注本镜实际承重的视觉重心、光或运动关系，不统一补 `主光方向`、`亮部重点` 和完整观看顺序。

镜头预演板提示词保存到作品 `04_分镜/文本/`，生成图片保存到 `04_分镜/图片/`；视频提示词保存到 `05_视频/文本/`。预演图默认只用于人审。如果要上传视频平台，先转换成干净单帧构图参考，并通过首轮测试确认它确实提高构图稳定性。

只有跨镜头、跨场次、跨集、跨作品反复出现，或需要锁定外观、空间、材质、比例、色彩和风格连续性的内容，才进入资产表。一次性路人、一次性奇观、单镜头场景、单次时空裂隙和只服务当前镜头的画面，不默认叫资产。

短片或首轮测试里，如果某个角色或场景只出现一次，应优先写入分镜画面内容、单镜头参考图或临时生成提示词，不要强行做角色资产、场景资产或道具资产。

资产不是只能在前期一次性定完。前期视觉资产负责搭建第一轮框架；正式视频提示词负责更高精度的导演调度。写到视频提示词阶段时，如果发现某个场景、道具、动线、空间尺度或关键物件虽然前期没有做资产，但已经被多个镜头调用，或仅靠文字仍然模糊、容易生成错位，就必须反向补充资产。补充资产后要同步更新视觉资产文件、分镜表和视频提示词引用，并在回复里告诉老胡：新增资产编号、资产名称、文件位置、服务镜头和它解决什么生成风险。

判断顺序：

```text
视频提示词写细后发现空间 / 道具 / 动线仍模糊
→ 判断它是否影响连续性、可生成性或剪辑拼接
→ 是：回到视觉资产文件补充图片资产提示词
→ 同步分镜表和视频提示词资产引用
→ 告诉老胡资产名、位置、生成效果和使用场次
```

这条规则的意思是：视频提示词精度可以反向推动资产补充。前期资产不是死清单，后期补资产属于正常流程。当前案例：《不想长大》前期把 `S4 放学路 / 村口` 暂定为单镜头参考；写到 E1-S9-C1 到 E1-S9-C3 后，发现放学路需要连续承载肩带滑落、村民报丧、姐姐跑远、小安抱书包追不上，因此应升级为正式四视图场景资产。

确定性命名规则：

```text
剧本显示称呼 ≠ 生产命名 ≠ 资产编号，但三者必须能映射。
```

每个具体人物、具体道具、具体场景和具体生物，只要承担剧情交互、跨镜头出现、可能进入资产表或会在视频提示词里反复被调用，都必须有确定生产命名。不要只写“大人”“他”“仙人”“女仙”“群仙”“神兽”“宫殿”“法器”这类抽象泛称。

当老胡要求“再做一个 / 补一个 / 重新做一个”资产时，不能只按字面名词覆盖已有资产。必须先判断这是新增资产、修正已有资产，还是补同类但不同位置 / 不同剧情阶段的资产；再用作品上下文、服务场次和生产命名消歧。尤其是“卧室 / 房间 / 院子 / 桌子 / 车 / 电话”这类泛称，同一作品里可能对应多个确定对象。正确做法是把资产名写成可定位对象，例如 `S3 小安城市卧室`、`S9 老家爷爷卧房`；禁止因为用户说“卧室资产”就擅自覆盖已有城市卧室，或把乡下爷爷卧房和小安城市卧室混成同一个场景。

如果观众听到的称呼必须保留，例如台词里喊“大人”，剧本和资产表要补一层生产命名：

```text
剧本显示称呼：大人
生产命名：主角
资产命名：A1 主角袖口与玉扳指
提示词写法：主角不露脸，只通过白金袖口、玉扳指、手势和仙纹体现身份；其他角色可称他为“大人”。
```

`群仙` 是群体类别，不是单一固定人物资产；可以做成 `群仙礼仪规则` 这类提示词资产。`神兽` 是生物类别，不是固定资产；如果需要固定，必须写成具体对象，例如 `白鹿`、`云龙`、`青鸾`，再判断它是否复用、是否需要图片资产。`女仙`、`守门者`、`迎客仙人` 如果只是一次性功能角色，不做图片资产，但仍要在当前镜头写清外观、礼仪动作和画面职责。

这条规则的目的不是给所有东西起花名，而是让剧本、资产、分镜、图片提示词和视频提示词指向同一个对象。AI 视频平台按单条提示词独立生成，模型不会从上下文猜出“大人”“群仙”“神兽”分别是谁；命名不确定会导致角色混乱、资产误用和跨镜头一致性失控。

视觉资产分为两类：

```text
图片资产：用图片固定具体形象和一致性。
文本资产 / 提示词资产：用文字固定氛围、妆造、环境、风格和世界观视觉规则。
```

图片资产适合：固定角色脸、服装、妆容、关键道具、固定空间、视频第一帧。文本资产 / 提示词资产适合：仙界整体氛围、某类人物妆造、服饰体系、环境大类、色彩材质、世界观视觉规则。短片里即使某个画面元素不值得做图片资产，也可能值得沉淀为文本资产。

提示词资产可以在多个镜头之间复用。世界观视觉规则、服饰体系、妆造规则、环境材质、色彩光影、神兽礼仪和仙界秩序等都可以成为提示词资产。正式视频提示词仍须自足，但调用时先筛选本条真正相关的内容：实际引用素材进【基础设定】，跨全部镜头成立的内容压缩进【氛围与画质】，局部规则写进对应镜头；不能只写“使用 A1”，也不能整包复制造成冗长。

所有需要老胡手动上传、替换、绑定、参考或调用的外部内容，都必须使用中文全角中括号 `【】` 显性包起来。这条规则覆盖视频提示词、图片提示词、故事板提示词、封面提示词、首帧提示词、资产设计提示词和生成执行单。中括号不是强调符号，而是生产占位符，负责提醒“这里要上传 / 替换 / 绑定某个外部参考”。稳定资产写 `【@资产名】`；人物形象写 `【形象参考@A1 角色人物设计资产】`；人物音色写 `【音色参考@V1 角色音频参考】`；临时参考图写 `【参考图1：用途】`、`【参考图2：用途】`，例如 `【参考图1：女主肖像】用于固定脸、年龄感、体态和气质`，`【参考图2：服装穿搭】用于固定服装版型、层次和配饰方向`。不要裸写 `参考图 1`、`参考图片 2`、`见上图`、`用图片一`，因为这些写法不方便老胡复制前快速核对，也容易让模型把参考关系当普通正文弱化。

提示词资产和图片资产进入正式视频提示词时，分工不同：

```text
提示词资产：内部稳定世界观、类型、妆造、环境、风格、色彩和材质；正式正文只把实际参考列入【基础设定】，把全局部分压缩进【氛围与画质】，把局部部分写进对应镜头。
图片资产 / 固定资产：主要解决具体形象一致性，正式生成时如果会作为参考图或平台资产输入，就不需要在【画面内容】里反复描摹资产本体。
色彩风格资产：同时属于图片参考和提示词资产，用来固定全片或阶段的色彩系统；正式提示词在【基础设定】引用色卡，在【氛围与画质】压缩成全局色彩原则，在【画面内容】按镜头展开真实对象的 HEX 映射。
```

视频提示词中的资产图片引用统一使用中性占位符：

```text
【@资产名】
```

写法示例：

```text
角色 / 道具 / 场景名：【@资产名】固定外观、材质、服饰、比例、表情规则、动作限制或使用规则。
色彩风格资产：【@C1 海边清新虐恋色卡】固定主色、辅助色、点缀色、肤色倾向、光源色、暗部倾向、环境反光、饱和度、明度、对比度和情绪阶段变体。
```

如果某个平台要求 `<node-asset>...</node-asset>` 等格式，可以在导出时替换；项目规则中默认用 `【@资产名】`。这个占位符只代表此处应插入或引用已经设计好的资产图片，不代表模型自动知道资产内容。若本次生成没有把资产图片一起投喂，仍要保留必要外观描述。

图片资产已作为生成输入时，`【画面内容】` 的文字重点不是“它长什么样”，而是“它在这一镜怎么参与画面”：

- 人物图片资产：重点写动作、表情变化、眼神、呼吸、衣袖被风吹动、身体和镜头距离、和其他角色 / 道具 / 环境的交互。
- 服装 / 妆造图片资产：重点写衣料如何随动作摆动、如何被光照亮、如何与场景色彩形成反差或融合。
- 场景图片资产：重点写镜头从哪里进入、经过哪些前中后景、光线如何扫过空间、人物或道具如何在空间里运动。
- 物品图片资产：重点写它被谁拿起、如何反光、发声、发光、遮挡画面、触发机关或影响环境。

未资产化画面元素没有图片兜底，必须在 `【画面内容】` 中详细描述：人物写相貌、服装、发饰、首饰、表情、姿态和服装花纹；建筑写风格、材质、体量、画面占比、空间位置和光影影响；道具写形状、材质、比例和使用方式；群像、路人和一次性场景也要写到足以生成。

注意：如果某个图片资产只登记在项目文件里，但本次正式生成没有把图片作为输入投喂给模型，不能把它当作模型已知内容，仍要在提示词正文里保留必要外观描述。

图片资产继续细分：

资产之所以能成为资产，核心是唯一性。一个图片资产只能固定一个确定对象：要么是一个人物，要么是一件道具，要么是一个固定场景，要么是一套服装 / 妆造。不要把一个镜头里会同时出现的多种元素塞进同一个资产里，例如“场景 + 桌子 + 汤圆 + 硬币 + 人物手部”不能叫一个资产，这已经是分镜图或视频第一帧。多个元素需要同时稳定时，就拆成多个单一资产，后续在分镜、视频提示词或第一帧参考图里组合调用。

同一物件的互斥可见状态不能硬塞进同一个资产。尤其是“包入前可见 / 包入后不可见”“完整外观 / 剖开内部”“未损坏 / 损坏”“未点燃 / 已燃烧”“未穿戴 / 已穿戴”等状态，如果同时写进一个图片资产，模型会把这些互斥状态混成同一画面。正确做法是按生成风险拆分：稳定外观做一个资产，短暂可见物或内部信息另做一个资产，揭露镜头再组合调用。当前案例：《不想长大》P4 只能固定“元宵完整白汤圆”的连续白糯米皮外观，P10 单独固定“小面值硬币”；不能把“硬币贴近汤圆皮 / 嵌在汤圆馅旁边”写进 P4，否则视频会把硬币生成在成品汤圆表面。

所有模型正文都只写当前目标结果。这个规则不只适用于单物品资产，也适用于人物资产、场景资产、封面、首帧、生图、分镜参考和正式视频提示词。不要为了防止跑偏而在代码块里反复提无关对象；模型不会理解“这里是排除项”，它会先注意到被提到的视觉名词。风险对象、剧情上下文、不能和谁混用，可以写在代码块外的 `不能继承`、`使用说明`、`验收标准` 里；真正投喂给模型的代码块只描述当前要生成的主体、形状、材质、比例、构图、光线、动作、声音、背景和清晰度。当前案例：P10 硬币资产正文只写“一枚洗干净的小面值硬币、边缘圆润、旧金属磨损、数字纹理、旧瓷小碗边缘或木桌小范围表面”；P4 白汤圆资产正文只写“完整白糯米皮、连续光滑、水光、轻微手搓纹理”。硬币和汤圆的混用风险写在代码块外。

场景资产固定的是空间本身：墙、门、窗、灶台、地面、入口、光源、尺度、动线和固定建筑结构。可移动桌子、碗、汤圆、药碗、纸扎房子、人物手部等，不应默认塞进场景资产；如果它们需要保持一致，应单独做道具或人物资产。场景资产可以保留“某处有摆放桌子的空位”“右侧墙角可放遗像桌”这类空间位置，但不要把具体道具细节当成场景资产的一部分。

资产类型要按“失真来源”判断，不按镜头里最显眼的名词机械判断。如果生成容易跑偏的是年代环境、场所类型、陈列方式、货架 / 柜台 / 灶台 / 教室 / 小卖部 / 商场的空间语法、光源和地面墙面，就做场景资产；如果跑偏的是一个物品本体的轮廓、材质、尺寸、结构、磨损、开启方式或特写细节，才做道具 / 物品资产。例如“商场拒买玩具”不等于一定做玩具道具资产；如果真正要稳定的是 90 年代末到 2000 年代初普通商场玩具货架区、荧光灯、浅色地砖、货架和包装陈列，就应做 `商场玩具货架区` 场景资产。人物手部、父亲牵走、孩子撒赖和剧情动作仍写入分镜或视频提示词。

色卡不是简单几块颜色。人物设计资产里的紧凑色值卡只服务该人物的服装、肤色、首饰和局部细节校对；全片色卡 / 色彩风格资产服务整支视频的调色连续性。正式色卡资产必须分成四组：

```text
人物组：肤色、发色、眉眼唇腮妆容、服装不同部位、首饰、手部和可见皮肤高光。
道具组：关键道具名称、金属、木质、纸张、布料、液体、火光、屏幕或其他可复用物品色。
场景组：墙面、屋顶、地面、门窗、天空、水面、植被、固定建筑结构和环境反光色。
氛围与过渡组：整体光线、雾气、烟雾、空气透视、远近层次、暗部、阴影、高光、转场铺屏色和胶片 / LUT 分级。
```

每组都要标注十六进制 RGB / HEX 色值，例如 `#DDEAF0`，并写清颜色职责、使用比例和禁止偏移方向。色号只是锚点，还必须写清颜色落在哪里：服装哪一层、皮肤哪种明度、头发哪种冷暖、墙面 / 屋顶 / 地面哪一块、道具哪个部件、雾气和暗部如何过渡。不要只写主色、辅助色、点缀色，也不要把色卡做成一排无法执行的漂亮色块。

色彩风格资产默认有一个全片母色卡，再按剧情需要派生阶段变体。全片母色卡锁统一世界和剪辑连续性；阶段变体负责情绪变化，例如恋爱前半段可以更清新透亮，失落后半段仍保留同一海天蓝绿，但降低明度、扩大冷灰暗部、让树影压到脸侧。不要每个分镜都随机换一套色卡；也不要所有分镜死用完全一样的颜色，导致情绪没有推进。正确做法是 `母色卡不变，阶段变体受控变化`。

人物资产不要一上来只做三视图。三视图属于设计资产，解决“怎么稳定复用”；形象资产要先解决“这个人是什么气质、在什么光影和环境里成立”。人物形象资产可以参考艺术照写法：具体环境、光源方向、丁达尔效应或侧逆光、冷暖对比、服装材质、姿态、眼神、构图留白和叙事瞬间都要写出来，让角色先有真实的气场和第一眼记忆点。

人物写真类图片必须补“镜头互动层”。凡是人物形象资产、美女治愈系图片、封面、首帧、时尚写真、国风女侠、数字人宣传图，只写脸、衣服、肤色和光影还不够；人物要像摄影现场里的被拍摄者，而不是静止站桩模型。提示词必须写清：景别机位是胸部以上、膝上、七分身还是中近景；身体朝向是正面、3/4 侧身、背身回眸、侧脸还是肩背朝镜头；头颈如何转、下巴是否微收、肩线和颈线如何形成气质；眼神是直视镜头、越肩看镜头、看向镜头外还是低垂；手部放在哪里并接触什么，例如拨发、触脸、扶栏杆、搭车身、握剑柄、扶门框、拈花或自然落在裙侧；重心落在哪条腿，前腿、膝盖、髋肩反向扭转、S 型曲线或拉腿延伸感如何成立；服装、发丝、首饰如何随姿态受力和受光。这样做的原因是，模型默认会生成“漂亮人站着”的平均图，而写真感来自人物与镜头、环境和道具之间的关系。

镜头互动层必须服务角色气质，不服务低俗凝视。可以正向写肩颈线条、背部轮廓、腰线、腿部线条、姿态张力、衣料贴合、裙摆展开、手指自然舒展和眼神方向；不要把画面焦点放到私密身体部位或过度暴露。比如国风女侠的英气应落到挺拔脊柱、肩背打开、剑柄接触、眼神压住镜头、袖口和发丝被侧逆光勾亮；治愈系美女的松弛应落到栏杆、海风、微微侧身、手指拨发、眼神柔和和浅色留白。错误写法是 `美女站在背景前，穿黑裙，写真感，光影柔和`；正确写法是 `膝上中近景，人物位于右侧三分线，身体 3/4 侧向镜头，头部向镜头轻微回转，下巴微收，眼神直视镜头；左手指尖从脸侧轻轻拨开发丝，右手自然搭在裙侧，重心落在后腿，前腿向镜头方向轻轻伸出，肩线和腰线形成柔和 S 型曲线；裙摆随前腿方向展开，柔光从左前方照出脸部立体感`。

人物形象资产和人物设计资产必须分开输出，不能用一张“左侧脸部近景 + 右侧三视图”的旧版混合图代替。形象资产要像电影人物艺术照，负责环境、光影、姿态、服装材质、情绪和第一眼气质；设计资产要像制作参考图，负责白底 / 简洁背景制作拆解，包含正侧背面、面部正立特写、配色板、左右手特写、局部细节、比例照和音色文字说明区。旧版混合图的问题是：既没有形象资产需要的叙事氛围，也没有设计资产需要的完整制作拆解。

主角色人物设计资产默认只固定中性常见表情，不默认做七宫格、九宫格或多格情绪表情资产。正确的人物设计资产表情是：正脸自然、脸部肌肉放松、嘴唇自然闭合或轻微放松、眼神正常，方便后续视频在同一张脸上调度情绪。不要在资产图里用“心动、雀跃、怀疑、愤怒、崩溃、落泪”这类粗略词做一排表情，因为模型会把这些词生成成夸张符号，导致脸部肌肉不真实，也会让后续视频被错误表情锁死。恋爱、悲伤、愤怒、怀疑、崩溃等复杂表演，要留给分镜和视频提示词逐镜头写清眼神焦点、眼睑、眉心、嘴角、下颌、呼吸、吞咽、手部和身体停顿。只有老胡明确要求做表情测试时，才单独输出表情测试参考图，并标明它不是主人物设计资产。

形象资产提示词和设计资产提示词不等于两个资产编号。它们是同一个人物资产编号下的两个生成入口，用来帮助老胡生成候选图。比如小安是 `A1`，可以有 `A1 小安人物形象资产提示词` 和 `A1 小安人物设计资产提示词`，但最终进入视频提示词的参考资产仍然只叫 `A1`。不要写 `A1-1`、`A1-2`，否则下游会误以为视频提示词需要分别调用两个资产。

群像人物资产用于“稳定一群人的类型”，不是“给每个群众建角色档案”。邻家孩子、同学、亲戚、村民、围观群众这类跑龙套人群，如果只是单个镜头路过，可以继续做画面元素；如果会连续参与围观、起哄、轻冲突、仪式或集体反应，并且容易生成成现代人群、偶像化人群或时代服装错误，可以做 `G` 系列群像资产。群像资产推荐场景合照式参考图：一群人在相关环境里展示年龄层、数量、服装年代、体态差异、站位密度和表情范围。它不固定具体单人脸，不做每个人的三视图；谁伸手、谁跑动、谁说话、谁和主角互动，仍由分镜和视频提示词当镜调度。

POV 主体也必须按正常人物资产设计。第一人称、背影、遮挡、低视线、只露手或只露袖口，是镜头表达方式，不是资产阶段的豁免。如果 POV 主体是主角或跨镜头反复出现，必须先建立完整人物资产，锁定年龄、身高、头身比、上下身比例、肩宽、左手大小、右手大小、鞋、服装、书包、背面 / 侧面 / 正面关系和视线高度。后续视频可以不频繁展示正脸，但资产阶段不能只做“手、袖口、书包”局部锚点；否则模型不知道这是儿童、成人、老人还是别的身体，成人与儿童比例、左右手大小、步态和镜头高度都会漂移。

人物设计资产必须增加左右手制作参考。左手特写和右手特写分别独立成模块，不能只写“手部特写”。手部模块要展示手背 / 手掌或至少一个清楚角度，说明手指长度、指节、指甲、肤色、年龄感、手部肉感、常见袖口连接方式和可作为 POV 前景锚点的识别点。这样做的原因是：第一人称、递物、牵手、触摸道具、拨动木轮、擦眼泪等镜头经常只出现手；如果左右手没有固定，模型会把儿童手生成成人手、把左手右手混乱，甚至让手部比例和人物年龄脱节。

人物设计资产还必须增加音色文字说明区。只要角色会跨镜头说话、喊叫、VO 回响或画外音出现，设计资产图片上要有清晰中文文字模块，写出基础音色、音线、年龄感、地域口音、语速和常态情绪。例如：`音色说明：儿童清亮偏细，重庆口音，语速快，情绪外露`；`音色说明：低沉克制，短句重庆话，压着火，尾音重`。这段文字是设计资产的一部分，方便后续把同一张人物设计图作为形象参考时，同时让人和模型看到基础声音设定。若另有音频参考，应在资产表中记录对应 `音色参考` 编号。

视频提示词阶段不再把长篇基础声线反复写进人物资产行。凡是本镜出镜、出声、VO 或画外音出现的人物，`【基础设定】` 中优先使用双参考占位格式：`角色名：【形象参考@A1 角色人物设计资产】【音色参考@V1 角色音频参考】稳定身份、本镜状态和本镜出镜方式。` 其中 `【形象参考@xx】` 由老胡替换成人物设计资产图片，`【音色参考@xx】` 由老胡替换成音频参考。若暂时没有音频参考，可以短句补充基础音色并标记待补音色参考；一旦有音频参考，就不要在每条提示词里重复长篇基础声线。当前镜头的病弱、哭腔、压低声音、电话失真、隔门闷声、喊叫、VO 回响等仍写在 `【画面内容】`，因为这些是本镜表演状态，不是基础音色。

场景资产也不要只做一张漂亮场景图。漂亮图只能证明气氛成立，不能证明空间可拍。固定场景如果会多次进入、需要正反打、左右侧视角、人物走位或结尾拉高镜头，优先做场景四视图设定图：正面视角、左侧视角（以正面视角向左转动 90 度）、右侧视角（以正面视角向右转动 90 度）、正面反打图。四个视角必须保持同一场景布局一致，视角逻辑正确，物体空间逻辑正确，四视图场景物件对应位置互相关联。判断标准是：入口、窗户、桌椅、墙角、灶台、柴火堆等关键物件在四张图里能互相对上，而不是四个相似风格的空间。

四视图不能写成“功能拼图”。错误写法是：格 1 饭桌、格 2 灶台、格 3 遗像桌、格 4 另一个反打空间；这会让模型生成四个相似房间，而不是同一个房间的不同方位。正确写法必须先定义一个正面视角，再说明左侧视角、右侧视角和反打图都从这个正面视角旋转而来，关键物件在四格里能对上位置。

当核心动作发生在桌面、案板、操作台、灶台边、祭祀桌、手工台等局部空间时，先判断它到底是“场景局部”还是“道具 / 家具”。如果要固定的是一张可移动桌子、案板或操作台本体，它应作为单一道具 / 家具资产做多角度；如果要固定的是灶房一角、祭祀桌所在墙面、门窗和光源关系，才作为局部场景资产。局部场景资产也只能固定空间和固定结构，不能把人物手部、汤圆、硬币碗、馅料、药碗等可移动元素一起塞进去。物品特写只负责材质和细节；多个资产如何摆放、谁的手从哪里进入、动作如何发生，交给分镜图、视频提示词或视频第一帧参考图处理。

如果人物后续可能穿不同衣服，必须拆成生产链：`人物形象资产 → 人物素体资产（白色素衣 / 中性服装）→ 服装 / 妆造资产 → 组合设计资产`。素体资产固定脸和身材；服装资产固定衣服版型、层次、材质和颜色；组合设计资产把人物穿上指定衣服后再做白底四区参考图，用于后续图生视频和角色一致性。

人物资产图如果需要更完整的制作参考，优先采用扩展分区结构：主视觉区放正面、侧面、背面三视图；补充信息区放面部正立特写、配色板和音色文字说明；手部参考区分别放左手特写和右手特写；局部细节区拆配饰、袖口、鞋、书包、点缀和身份识别元素；比例照用上半身或全身比例图锁定身高、头身比和上下身比例。

扩展分区图的局部细节区必须用于校验一致性，不是自由发挥的装饰拼盘。局部细节区里每个模块都要来自主视觉三视图或固定定装清单，并且文字标签与物件一一对应。鞋履、发饰、耳饰、项链、包、袖口、手部等模块不能互相错标；如果模型容易混淆，要在图片提示词里明确 `局部细节标签和物件准确对应`。

当老胡同时提供人物参考图和服装参考图时，必须拆开理解：人物图负责脸、身形、年龄感、体态、气质和头身比；服装图负责校服 / 制服 / 日常服的版型、层次、颜色、穿法和身份识别元素。正式图片提示词要写清 `【参考图1：人物肖像】用于固定人物比例和面部气质；【参考图2：服装穿搭】用于固定服装版型、层次和配饰方向`。服装建议按 `内 / 中 / 外 / 腰 / 下 / 足` 或 `上衣 / 外搭 / 裤装 / 鞋 / 配饰` 的顺序展开，避免模型只记住“穿校服”“穿 T 恤”这类笼统词。

人物资产固定的是身份稳定特征，不等于所有镜头都锁死同一套衣服。人物资产的核心职责是固定脸、年龄感、身高、头身比、体态、发型、手脚尺度、基础气质和声音锚点；服装只有在品牌方要求、制服 / 校服、特殊戏服、丧服、固定定装或连续性强依赖时，才作为跨镜头不可变资产锁定。普通生活衣服要服从场景逻辑：睡觉时应是睡衣、秋衣或被窝遮挡下的居家状态；起床时是从睡衣 / 秋衣过渡到外出衣服；车内和老家白天可以是外出棉外套、裤鞋和书包；放学路是学生外套和书包；丧事段是素色衣服、孝布或仪式状态。视频提示词写资产行时，要区分 `固定身份特征` 和 `本镜当前穿着 / 身体状态`，不能把资产表里的默认外出服机械复制到床上、睡觉、洗漱、病床、丧事等不成立场景。

POV 主体必须用确定人物命名锚定，不能只写类别。正式视频提示词里如果视角来自某个已资产化人物，要写 `小安第一人称 POV`、`小安视角`、`小安坐在后排的第一人称 POV`，而不是只写 `儿童 POV`、`孩子视角`、`儿童低机位`。`儿童`、`老人`、`父亲`、`学生` 是类型词或关系词，不能替代资产名。可以在具体人物之后补充类型特征，例如 `小安第一人称 POV，儿童身高低视线`。这样模型才知道镜头不是泛化儿童镜头，而是 A1 小安这个具体主体在看。

资产组合编号规则：

```text
A1 = 人物素体资产
A2 = 服装 / 妆造资产
A3 = A1 穿着 A2 后形成的人物定装 / 组合形象资产
```

助手不需要执行图片合成，但必须在资产表里记录组合关系、编号、用途和后续调用方式。后续视频提示词如果需要调用 `A3`，应在正式提示词中展开为具体外观描述，同时在提示词外的资产使用表里记录 `A3`。

独立生成一致性规则：

```text
每条正式视频提示词 = 一次独立投喂。
模型不会读取上一个分镜、全片设定、项目说明或前文解释。
```

因此正式视频提示词里不能写“沿用全片”“参考上文”“承接前一条基础设定”来替代实际内容。每一条正式提示词的 `【基础设定】`、`【氛围与画质】`、`【画面内容】` 都必须独立完整，复制其中任意一条给视频平台，也能知道要生成什么、怎么拍、什么不能跑偏。

独立完整是助手的自检要求，不是写给视频模型看的字段。正式提示词正文里不要出现“本条是否独立完整”“复制本条”“上一镜头”“下一镜头”“接 E1-S1-C2”“后期备注”等场外说明。这些判断可以写在文件说明、分镜表、自检表或阶段记录里，但不能放进投喂给模型的提示词代码块。

跨分镜一致性只能通过两类方式保证：

```text
图片资产：固定具体人物脸、服装、道具、空间、第一帧。
文本资产 / 提示词资产：固定风格、妆造、场景大类、礼仪规则和氛围。
```

如果同一个具体人物跨多个独立生成分镜出现，并且需要保持同一张脸、同一套具体服装和同一身份，必须先建立图片资产。未建立图片资产时，不要把这个人物拆到多个独立提示词里反复出现，否则生成平台会把每一条当成不同人物。

未资产化人物或同一空间的连续动作，处理顺序：

1. 不需要一致：降级为单镜头画面元素。
2. 需要一致且总时长不超过 15 秒：合并为一条视频提示词。
3. 需要一致且必须跨多条提示词：回到视觉资产阶段，先建立图片资产。

15 秒内同场合并规则：同一场景、同一未资产化人物、连续动作，如果拆开会造成变脸或空间断裂，且总时长不超过 15 秒，优先合并成一个视频单元。总时长在平台参数中设置，正式正文按动作触发关系写成连续镜头叙事；需要切镜时明确前一画面的遮挡、视线、声音、焦点或运动方向怎样把摄影机带入下一画面，不写内部时间戳或镜头编号。

转场规则：

```text
转场不是“后期备注”，而是画面内容里可生成的视觉行为。
```

需要分镜衔接时，写片内可见的动作或画面变化：

- 危机型开头转场：倒计时、断电、车辆逼近、坠落、火花爆开、球体撞镜、门缝关闭、插头接近接口等未闭合动作，把观众等待的问题留到正文揭示。
- 遮挡转场：袖口、云雾、仙旗、人物身体、巨门、飞檐掠过镜头并短暂遮满画面。
- 明暗转场：金白强光铺满画面、云影压暗、门内白光吞没画面、画面从暗处重新亮起。
- 运镜转场：镜头被裂隙吸入、穿过云层、越过门槛、绕过法器后落到新空间。
- 匹配转场：圆形裂隙接圆形仙印，龙眼倒影接玉扳指光点，浮灯光点接远处宫阙灯火。
- 动作转场：拂袖横扫、仙旗掠过、巨门开启、法器展开等大动作覆盖画面边缘。
- 硬切准备：镜头结束在清晰停点、稳定构图、动作完成或声音收束上，方便直接剪接。

不要每个镜头都用黑场或白场。转场要和镜头内容绑定，避免整片像同一种模板套出来。

危机型转场必须写清“观众等什么”。倒计时要写数字如何变化、剩余电量或时间如何压近、可救物体在哪里、最后一秒切在哪里；碰撞要写移动物体从哪个方向来、速度如何变快、左右边界为什么逃不开、撞上前一瞬用车灯、强风、尘土或暗影遮满画面；火花 / 水花 / 烟雾 / 球体撞镜要写材料如何扩散到满屏，以及满屏瞬间如何接到下一画面。不要只写 `突然转场`、`用火花转场`、`球砸向镜头`，要写起点、路径、峰值、满屏材料和揭示帧。

## 二点六、单文件迭代与版本控制

每个阶段默认只维护一个当前输出文件。老胡提出修改意见时，直接在同一个输出文件上迭代修改，不要自动新建 `v1`、`v2`、`v3` 或多个重复文件。

只有老胡明确说以下类似表述时，才新建版本文件：

```text
新增一个版本
另存一版
保留旧版
做 A/B 两版
这版不要覆盖
```

否则默认行为是：

```text
读取当前阶段输出文件
→ 按修改意见更新同一个文件
→ 更新阶段确认记录
→ 回复同一个文件链接和变更摘要
```

文件命名默认不带版本号。推荐：

```text
yyyy-mm-dd_剧本_<主题>.md
yyyy-mm-dd_图片提示词_<主题>.md
yyyy-mm-dd_分镜表_<主题>.md
yyyy-mm-dd_视频提示词_E1-S1-C1_展示.md
yyyy-mm-dd_视频提示词_全分镜_<主题>.md
```

不推荐：

```text
yyyy-mm-dd_剧本_<主题>_v1.md
yyyy-mm-dd_剧本_<主题>_v2.md
```

## 三、短剧格式

短剧 / 短片剧本必须保留固定符号格式。即使老胡要求“一口气跑完”“只要一个结果”，只要最终文件里包含剧本结果，也不能把剧本改写成普通叙事段落。剧本符号是下游分镜、声音、表演和视频提示词判断的信息结构，不能省略。

```text
第1集 1-1
外  地点  日 / 夜 / 雨 / 晨 / 傍晚
人物：角色A、角色B、群众若干

△ 动作描述，只写能被看见或听见的内容。
角色A：台词。
角色A（压低声音）：带语气 / 神态的台词。
角色A（OS）：内心独白或画外心理声。
角色B VO：画外旁白。
【字幕：内容】
【空镜：场景描述】
闪回
△ 回忆画面动作。
闪回结束
```

符号含义：

```text
△ = 动作描述，只写能被看见或听见的内容。
角色名：= 角色出声台词。
角色名（语气 / 神态）：= 角色出声台词，但括号标注压低声音、哽住、忍着火、发抖、笑着、急了等可表演状态。
角色名（OS）：= 角色内心独白、心理声或画外心理声。
角色名 VO：= 未出场角色、旁白或画外声音。
角色名 VO（语气 / 神态）：= 画外声音带有明确说话状态时使用。
【字幕：】= 屏幕文字、时间提示、地点提示或需要显示的文字。
【空镜：】= 没有主要人物台词的环境、物件、气氛、时间流逝或转场画面。
闪回 / 闪回结束 = 明确标注回忆段落开始和结束。
插入镜头 = 短暂切入的物件、动作、记忆碎片或表情细节，不需要独立成场。
```

禁止把正式剧本写成普通叙事段落，例如“镜头从云层中破出，群仙让路……”这种只能用于故事梗概或分镜说明；正式剧本必须写成 `△` 或 `【空镜】` 等明确符号。

剧本格式的目的不是让文本好看，而是让下游知道信息类型。`角色名：` 只能说明角色出声说话，不能说明这句话是压低声音、哄孩子、忍着火、哭腔、敷衍，还是故作轻松。只要语气和神态会影响表演、声音、剪辑或观众理解，就必须写在括号里。

剧本中的语气 / 神态标注必须向下游继承。`角色名（语气 / 神态）：`、`角色名 VO（语气 / 神态）：`、`角色名（OS）：`、动作描述里的表情神态和 `插入镜头` 里的表情碎片，都不是给作者看的装饰，而是分镜和视频提示词的人物表演源头。

执行链路：

```text
剧本语气 / 神态标注
→ 分镜表记录表情来源
→ 判断表情功能和表情占用时长
→ 选择近景 / 特写 / 大特写 / POV 替代表达
→ 视频提示词在【画面内容】里写成可见表演结果
```

分镜表至少要能回答：

```text
表情细化：是 / 否
表情来源：剧本括号 / OS / 动作描述 / VO 回响 / 插入镜头 / 无
表情功能：核心任务 / 辅助状态 / 不需要
表情占用时长：确定值
推荐景别：近景 / 中近景 / 特写 / 大特写 / POV 手部替代表情
```

视频提示词不能只把 `忍着哭`、`压着火`、`故作轻松` 原样搬进去。必须调用人物表演库，把抽象神态转成模型能生成的眼神、眉头、嘴角、嘴唇、下巴、呼吸、肩膀、手指、停顿、声音状态和身体距离。参考入口：

```text
02_共享资产库/02_视觉语言资产/人物表演库/人物表演提示词规范.md
02_共享资产库/02_视觉语言资产/人物表演库/人物表情与肢体动作词典.md
02_共享资产库/01_模板库/视频模板/模板_人物表演_情绪时间轴.md
```

例如 `奶奶（忍着哭）` 在视频提示词里应呈现为眼眶发红、内眉上抬、嘴角压住、喉咙吞咽、手指轻抖、说话短暂停顿；`父亲（压着火）` 应呈现为眉头压低、下颌绷紧、嘴唇压紧、声音低、拳头收紧、呼吸压住。

如果镜头是第一人称 POV、背影、远景、遮挡或人物不露脸，也不能丢掉神态标注。要把表情转成 POV 可见 / 可听的替代表现：手部攥紧、指节发白、呼吸突然停住、声音发紧或压低、肩背僵住、衣角被攥皱、门缝侧影、玻璃 / 水面 / 金属反射里的眼神、脚步停顿、道具被握紧或碗沿轻轻发抖。

正式剧本要主动使用这些结构：

```text
角色名（压低声音）：用于台词音量、语气、情绪状态明显影响含义。
角色名（OS）：用于没有真正说出口的内心声或心理活动。
角色名 VO：用于画外声音、回忆旧话重放、未出场角色声音或旁白。
【字幕：内容】：用于屏幕显示的时间、地点、手机信息、纸条文字等。
【空镜：内容】：用于环境、物件、气氛、时间流逝和转场画面。
闪回 / 闪回结束：用于当前场景触发的回忆段。
插入镜头：用于短暂切入的物件、动作、表情或记忆碎片。
```

场次标注与特殊标注规则：

```text
首行写“第X集 X-X”，场次编号连续清晰。
第二行写“内 / 外  具体地点  日 / 夜 / 晨 / 傍晚 / 雨”等时间与环境。
人物列表使用全名或稳定称呼，全文统一；群众可写“亲戚若干”“村民若干”。
换场、时间跳跃、长闪回或新空间开始时，必须空行并重新标注场次。
短闪回可在当前场次内用“闪回 / 闪回结束”；长回忆建议独立场次。
空镜和字幕必须与场景内容紧密相关，不写脱离剧情的漂亮废话。
```

### 台词口气与方言

正式剧本台词必须匹配人物的地域、年龄、文化程度、亲属关系和当下情绪。台词不是书面信息说明，而是人物真实说话的声音。

如果老胡指定重庆话、川渝口语、老一辈农村口气或其他方言口气，剧本必须执行：

```text
先判断谁该有方言：老人、父母、村民、孩子、外来人不能一个腔。
再判断说话场景：训人、哄人、忍悲、随口抱怨、临别叮嘱的口气不同。
方言要可听懂，不能为了方言堆满每一句。
生活口语优先，书面普通话后置。
```

重庆话 / 川渝口语常用方式：

```text
可用“啷个”“莫”“嘛”“噻”“撒子”“晓得”“要得”“没得”“娃儿”等口气词。
老人和村民多用短句、碎句、生活词，不写主持腔和教育腔。
孩子说话要直接、任性、反应慢，不说成人总结。
```

反例：

```text
奶奶：你以后要照顾好自己，注意身体，保持良好的生活习惯。
```

正确：

```text
奶奶：饭莫挑，天冷了晓得添衣裳。你爸忙，没人天天盯到你，听到没得？
```

这条规则的目的不是做方言表演，而是让人物的声音和生活经验一致。尤其是怀旧、农村、隔代亲情、老一辈文化程度不高的故事，书面腔会直接削弱真实感和情绪可信度。

### 情绪型时间省略

影视叙事里的转场时间，不等于故事现实时间。尤其是亲人离世、丧葬、童年回忆、遗物揭示、火光、遗像、空屋和旧话回响这类段落，画面可以一下切到结果，但剧本必须判断这是“马上发生”，还是“一段时间后的记忆压缩”。

处理规则：

```text
先拆故事现实时间：事情真实经历了多久。
再拆影像表达时间：画面打算如何压缩呈现。
如果用户用遗像、火光、旧话回响、叩首抬头、遗物等跳切，不要先判定为时间线错误。
先判断它是否在表达人物记忆、心死、离别预感、长时间衰败或迟来的理解。
如果会被观众误解成“立刻发生”，剧本里要补时间提示或环境变化。
```

可用方式：

```text
【字幕：一段时间后】
【空镜：院里的树叶由绿转黄，灶台冷了，墙上的日历被风吹起。】
△ 儿童 POV 的主观镜头高度比前一段略微变高，仍是孩子视角，但暗示他已经长高了一点。
△ 奶奶的床边药瓶越来越多，屋里说话声越来越少。
△ 火光里重新响起爷爷曾经说过的话。
奶奶 VO：你要好好吃饭，好好穿衣，照顾好自己。
```

无对白仪式段不是空白。它可以用叩首、绕棺、纸扎燃烧、火光、遗像、孝布、遗物、旧台词回声、主观镜头高度变化和环境声承载情绪。不要为了“讲清楚”临时塞解释性台词；如果前文已经埋下遗言、承诺或叮嘱，后文火光和遗物画面可以重放这些声音，让观众自己补上情绪。

旧话回响可以从声音升级成“曝光记忆层”。当 VO 是亲人遗言、承诺、叮嘱、后悔或旧话回响，并且当前画面有火光、纸灰、玻璃反光、水面、墙面、旧物、窗帘、烟雾等可承载影像的媒介时，可以使用二次曝光或三重曝光，让讲话人的半透明形象像从现实物里浮出来。写法必须先固定现实层，再写记忆层叠在哪里、透明度如何、嘴形或动作是否跟 VO 对位、哪些现实物仍然清楚。不要只写“出现回忆画面”，也不要把曝光人物写成恐怖鬼影。

通用规则：

```text
现实层：当前镜头真实可见的物件、人物、空间和动作，永远是主层。
二次曝光层：过去说话的人、旧场景或旧动作低透明叠在火光、纸灰、玻璃、旧物等媒介上。
三重曝光层：第一层现实物，第二层情绪媒介或前一仪式画面，第三层讲话人影像或关键动作。
```

错误写法：`火光里响起爷爷奶奶 VO。`

正确写法：`现实层是纸房燃烧和父亲背影；爷爷 VO 出现时，火焰右侧叠出爷爷低透明半身影像，嘴形轻轻跟着台词动；奶奶 VO 出现时，火焰左侧叠出奶奶侧脸，边缘被热浪撕开，现实火焰和父亲背影仍然清楚。`

当前案例：《不想长大》E1-S10-C4 用火盆纸钱承载奶奶二次曝光；E1-S10-C6 用纸房火光承载爷爷奶奶二次曝光；E1-S11-C2 用院中 P1/P2 两辆完整木车 + P11 半成品木马车架现实层，叠加爷爷半透明记忆层，让小安摸 P11 悬空后轮的动作和爷爷承诺 VO 对位。

有些时间省略可以保留短暂懵感。尤其是奶奶叮嘱后切到遗像、孩子叩首后抬头看到新状态、旧物突然出现在丧葬现场这类转场，不一定要先用字幕或连续空镜讲清时间。可以用一个镜头切换先让观众愣一下，再通过主观镜头高度、仪式状态、环境变化和前文声音回响，让观众自己反应过来“中间已经跨过一段时间”。只要画面证据足够，短暂懵感不是问题，而是情绪落点的一部分。

### 回忆、POV 与突发消息

回忆不是普通插叙素材，而是当下情绪的显影。童年、亲情、遗物和怀旧故事里的回忆，优先由现实场景中的台词、物件、触碰、声音、气味或动作触发，再切入记忆画面。

正确做法：

```text
现实中有人说出一句话，或主角摸到一个物件。
→ 画面边缘发白、声音变远、光线变软或现实声继续压在画面上。
→ 进入记忆场景。
→ 记忆画面和现实 VO / 声音交叉，让观众知道这段回忆为什么此刻出现。
→ 回到现实物件或当前人物反应。
```

不要把回忆单独放在前面，当成没有触发点的普通场景。这样观众会先接收一个孤立信息，却不知道它为什么重要。回忆真正的作用，是让现实里的一个物件、一句话或一个动作突然长出过去。

第一人称 / 儿童 POV 叙事必须做视角可行性检查：

```text
这个细节是不是主角能看见的。
这个声音是不是主角能听见的。
这个动作是不是主角能感到的。
如果主角不能直接看到，能否通过门缝、影子、反射、画外音、脚步声、身体感觉或他人反应转译。
```

例如写“小安书包肩带滑下来”，不能像第三人称一样直接交代；要写“小安右肩一沉，低头往右边看见肩带正从肩膀上滑落，书包角蹭到胳膊”。这类写法不是啰嗦，而是保证后续分镜和视频提示词不会把第一人称 POV 做成普通旁观镜头。

POV 叙事还必须做“主体命名检查”。如果全片已经确认是小安 POV，正式提示词不能退回到 `儿童 POV` 这种泛称；每条涉及主观镜头的代码块都要写清 `小安第一人称 POV` 或 `小安视角`。如果只写儿童、孩子、小孩，模型可能把它理解成第三人称拍一个孩子，或者把 POV 变成任何儿童视角。正确写法是先锚定人物，再描述眼前画面结果：`小安第一人称 POV，画面呈现小安眼前所见，视线高度约 6-7 岁儿童低视线；前景是被沿、两只小手和睡衣袖口，中景是父亲递来的外套和成人局部身体`。

`【画面内容】` 首先是观众眼前的镜头结果，不是剧情解释区、作者解说区或场外调度区。写进去的不是“故事里理论上发生了什么”，而是屏幕最终让观众看见、听见、感到什么。只要 `【画面内容】` 用第三人称旁观结果来描述，模型就会生成第三人称旁观镜头；只要用第一人称眼前结果来描述，模型才会稳定生成第一人称画面。这个原则适用于所有镜头，不只适用于 POV。

正式视频提示词不能把心理解释、潜台词和未说出口的具体词写进模型正文。小说和剧本可以写 `像把没事两个字吞回去`、`想替对方找理由`、`想反驳但说不出来`，因为读者能理解这是心理和潜台词；但视频模型会把 `没事`、`理由`、`反驳`、`话` 这类具体词当成可发声内容、字幕内容或动作目标，导致角色突然念出台词、生成文字或把表演变成解释。正确做法是把心理转译成屏幕证据：嘴唇微张又合上、喉咙吞咽、呼吸停半拍、眼眶细窄水光、嘴角硬撑、下巴绷住、肩线塌下半寸、没有发出任何声音。当前案例：《30秒钟带你体验谈恋爱》VID-09 不写 `像把没事两个字吞回去`，改成 `嘴唇微微张开又合上，没有发出任何声音，脸上显出十分委屈却还在强撑的状态`。

正式视频提示词要优先使用“镜头主语”的导演语言。`【画面内容】` 不是小说旁白，尽量用 `镜头中出现...`、`镜头固定在...`、`镜头推进到...`、`镜头摇移到...`、`镜头下压到...`、`镜头抬起后...`、`镜头被...遮满`、`镜头从...掠过`、`镜头停在...`、`镜头后方传来...` 这类可执行摄影句式。尤其是 POV、遮挡转场、动作转场、推拉摇移、插入特写和复杂调度镜头，必须让“镜头”成为动作承载者，而不是只写“视线看到 / 画面呈现 / 主角感到”。这样模型更容易理解这是拍摄结果，不会把文学叙事补成第三人称人物。

通用规则：能写成镜头动作的地方，优先写成镜头动作。错误写法是 `视线停在爷爷遗像上，视线慢慢低下，蒲团纹理越来越清楚`；正确写法是 `镜头固定在爷爷黑白遗像照片上；亲戚提醒后，镜头缓慢下压，蒲团粗布纹理从画面下方推近并逐渐占满整个镜头`。错误写法是 `转场后回到同一张遗像桌方向的画面`；正确写法是 `转场后镜头仍是满屏蒲团纹理；随后镜头缓慢抬起，遗像桌、旧墙、白布和蒲团前沿重新进入同一位置`。当前案例：E1-S10-C2 必须用镜头下压、镜头被蒲团纹理遮满、镜头抬起、镜头中出现奶奶黑白遗像照片来写。

正式视频提示词正文不能写作者意图、观众理解目标、防误读说明或生成流程解释。`让观众懂`、`表现孩子不冷漠`、`避免误读成马上去世`、`禁止把小安拍成冷漠`、`镜头停顿足够让观众看见忍哭`、`发给模型时模型不知道上下文` 这类句子，是给作者和审稿人的判断，不是模型可生成的画面。它们必须放在分镜表、连接检查表、自检或复盘里；进入正式代码块时，要改成可见 / 可听证据，或直接展开本条提示词所需信息：书包压在胸前、短脚步追几步、呼吸乱、站住发懵、奶奶眼眶红肿、嘴角压住、手指停住、袖口和视线高度变化。当前案例：E1-S9-C3 不写 `画面让观众懂孩子不懂，禁止把小安拍成冷漠`，应写 `两个书包压在胸前，短脚步追几步后停住，镜头后方只有急促呼吸和短短喊声，视线茫然停在姐姐跑远的转弯处`。如果担心单条提示词缺上下文，不写解释句，而是把角色身份、场景、道具数量、动作起点和声音状态补完整。

画面内容必须区分“作者知道的信息”和“观众此刻能看见的信息”。隐藏在物体内部、角色心里、后续剧情里、尚未揭晓身份里、未来才兑现的承诺里、观众暂时不能知道的伏笔里，不能直接写成当前画面可见物。否则模型会把隐藏信息提前生成出来，造成剧透、物理不合理或画面损坏。正确做法是只写当前可见外观和当前动作结果，把隐藏信息留到它被揭露的镜头。当前案例：E1-S6-C4 汤圆下锅转场中，作者知道部分汤圆里包着硬币，但观众此刻只能看见完整白汤圆在锅里翻滚和落入碗中；不能写“藏硬币的汤圆混在其中”，否则模型可能生成露出的硬币、破开的汤圆或外漏馅料。应写 `完整白汤圆，内部不可见，硬币和馅料都被包在里面不露出`。

通用规则：写 `【画面内容】` 前先确定画面来源和观众站位，再选择画面主语。第三人称客观镜头可以写“人物站在床边、父亲走进门”；第一人称主观镜头要写“眼前的被沿、两只小手、门口冷光、父亲局部进入画面”；过肩镜头要写“前景是谁的肩背，中景是谁的脸和手”；正反打要写“谁在画面左侧 / 右侧、视线朝向哪里”；插入镜头要写“道具占画面什么位置，手如何进入画面”。画面主语必须服务当前镜头关系，不能把剧情主角、视点主体、作者想法和观众最终看见的镜头结果混在一起。

严格 POV 必须先写清“画面呈现视点主体眼前所见的画面结果”，用来防止模型把 POV 主体生成成画面里的第三人称人物。不要写 `镜头等同小安眼睛位置`、`摄影机绑定在小安眼睛位置`、`机位高度等同男主趴桌视点`。这些句子是在描述物理摆位，模型可能生成眼睛附近的怪异机位、露出视点主体脸部边缘，或把第一人称误解成“低机位拍这个人”。正确写法是：`小安第一人称 POV，画面呈现小安眼前所见，视线高度约 6-7 岁儿童低视线`；`男主第一人称 POV，画面呈现男主趴桌时看见的桌面、前排背影和试卷靠近过程`。这类写法允许出现视点主体名字，因为它是在说明画面来自谁的感知结果，不是在描述画面里有一个被拍到的“小安 / 男主”。写完来源后，后续画面内容仍要回到“眼前出现什么、什么进入画面、声音从哪里来、身体感如何影响画面”。

严格 POV 只有一个不可省略的功能条件：必须证明“画面来自谁的感知，以及观众此刻看见的是这个人眼前所见”，不能只贴一个 `POV` 标签。项目使用开放证据链：

```text
具体人物第一人称 POV，画面呈现具体人物眼前所见
+ 从身体局部、近眼遮挡、呼吸或步伐引起的画面运动、视线高度、头部转动后的屏幕变化、镜头后方声音、互动对象朝镜头发生动作中选择足以证明来源的证据
+ 写清当前眼前真正承重的主体、动作和结果
+ 焦段、景深、画幅、介质和环境光影只在改变观看结果时补充
```

这里的 `具体人物` 必须是资产或确定生产命名，例如 `小安第一人称 POV`、`父亲第一人称 POV`、`男主第一人称 POV`，不能只写 `儿童 POV`、`孩子视角`、`人眼视角`。类别词只能作为补充，例如 `小安第一人称 POV，儿童身高低视线`。

POV 前景锚点是高效证据之一，不是每镜必填。小手、袖口、膝盖、握住的道具、方向盘、被沿、眼镜边框或其他近眼局部都可以证明身体位置；如果它会遮住主情绪证据、破坏纯净凝视或当前人物本来就看不见自己的身体，可以不用。此时应改用呼吸或步伐引起的画面变化、近眼边缘遮挡、镜头后方声音、互动对象直视并朝镜头动作等证据，使 POV 仍然成立。

POV 稳定方式从身体状态、运动方式、观看任务和主情绪共同推导。平稳、呼吸微动、短步轻晃、短促颠簸、焦点短暂虚化都只是候选；治愈、紧张、儿童或病弱不自动绑定某一种效果。被选中的晃动必须有身体原因并保留关键落点。

POV 头部 / 视线运动必须写成眼前画面变化：低头看下方蒲团纹理、抬头看遗像桌、缓慢转向门口、向左环顾街边、被人推一下导致画面轻晃、伸手向前触碰物件、缓步向前使地面和前方主体靠近。不要写 `小安转头 / 小安抬头 / 小安停住` 作为外部动作摘要，要写 `镜头从门框甩向窗边并停住`、`画面缓慢抬到父亲下巴和手里的外套`、`两只小手伸向画面前方`。

POV 光学质感从角色此刻能看见多少、注意什么、身体如何运动以及主情绪是否需要主观失真反推。焦段与景深不负责证明 POV，也不固定为 `35mm / 50mm + 中等景深`；广角、长焦、深景深、浅景深、短暂失焦甚至鱼眼都可以使用，但必须产生角色感知所需的空间、注意力或失真结果。没有这个职责时，不写具体光学参数比套“人眼等效”更准确。

外部 POV 公式里的“负面词收尾”不能照搬进本项目正式代码块。正式模型正文优先写正向画面；如果需要边界，只写抽象质量边界，不把当前镜头不该出现的具体对象反复写进模型正文。具体跑偏对象、风险和不该出现的剧情物，放到提示词外自检或失败经验里。

严格 POV 不能把 `正面 / 背面 / 侧面 / 正面构图` 这类资产视角词松散接在 POV 主体后面。资产设计阶段可以写人物正面、侧面、背面，因为那是在做外部制作参考；正式视频提示词里的第一人称画面不是拍摄 POV 主体这个人，而是呈现 POV 主体眼前所见。如果写 `小安第一人称 POV 低视线正面`，模型可能把“正面”理解成小安的正面，于是生成小安的脸或身体，第一人称就失败。正确做法是把方向绑定到画面对象或空间锚点：`小安第一人称 POV，面向遗像桌方向的低视线构图`、`视线停在爷爷遗像上`、`画面朝向车前排和挡风玻璃方向`、`视线沿放学路家方向追向姐姐背影`。一句话：POV 里不写“视点主体的正面”，只写“视线朝向哪个物件 / 哪个空间方向”。

正确的 POV 剧情语言不是完全避开剧情，而是让剧情动作通过画面来源主体的身体感表现出来。例如 `第3秒肩膀感受到外力推动，画面跟随轻微摇晃`、`男主短叹气从画面后方响起`、`试卷靠近画面时油印字逐渐清晰`。这些句子虽然提到男主或身体感，但它们没有把男主拍出来，而是在说明画面为什么抖、声音从哪里来、物件为什么靠近画面。

严格 POV 还必须做“互动视线检查”。当画面中的其他角色在和 POV 主体说话、递东西、牵手、摸头、整理衣服、搀扶、追问或安慰时，他们不是看向画面里的另一个人，而是看向镜头、朝镜头低头、把手伸到镜头前方或把物件递到镜头前。否则模型会自动生成一个第三人称小孩在画面里，让对方看向那个小孩。

错误写法：`奶奶蹲低，摸着袖口说`、`爷爷笑着说小安来喽`、`父亲把外套递给小安`。这些句子没有说明对方的目光和动作是朝镜头发生的，容易生成旁观镜头。

正确写法：`奶奶蹲到镜头高度，眼睛看向镜头，手伸到画面前方摸袖口`；`爷爷从院里迎出来，视线对准镜头，笑着朝镜头说“小安来喽”`；`父亲的手把外套递到镜头前方，外套边缘压近画面`。一句话：POV 互动对象的眼神、手和身体方向要和镜头建立关系。

严格 POV 不能用群体外部关系词来替代眼前画面。`姐弟俩`、`小安和姐姐`、`村民看到姐弟俩`、`小安抱书包追姐姐` 这类句子是外部摄影机 / 旁白视角；视点主体自己的眼睛不能看见自己和别人组成的关系，只能看见前方姐姐背影、迎面村民的局部、自己的袖口 / 小手 / 书包带、地上物件和画面晃动。当前案例：E1-S9-C2 不写 `村民看到姐弟俩`，应写 `村民从左前方走近，视线朝镜头和前方姐姐扫过来`；E1-S9-C3 不写 `小安弯腰把姐姐书包抱起来`，应写 `视线压到地上书包，画面下方两只小手伸出去，书包被抱起后挡住半个画面`。

错误写法：在严格主观镜头里写 `小安坐在床边`、`小安看向门口`、`小安听到后停住`；在过肩镜头里只写 `两个人对话` 而不写肩背前景和视线方向；在正反打里只写 `父亲责备孩子` 而不写镜头拍谁、谁在画面哪一侧、视线如何对接。这些写法看似在讲剧情，实际没有告诉模型观众看见的镜头结果。

正确写法：把剧情动作翻译成屏幕结果。严格主观镜头写 `床沿和被子占住画面下半部，两只小手把被沿拉高，父亲外套从门口方向压进画面`；过肩镜头写 `父亲深色肩背虚化在左前景，孩子半张脸在右中景抬起，视线越过父亲肩线`；正反打写 `父亲在画面左侧低头看向右下方，反打时孩子在画面右侧仰头看向左上方`。一句话：画面内容写什么机位，观众就会看见什么机位。

严格第一人称 POV 和低机位旁观镜头必须区分。所有主观镜头都要做“视点主体语法检查”。

通用规则：视点主体可以是小安、父亲、爷爷、主角、观众、第二人称里的“你”，也可以是任意角色或生物。只要镜头被定义为第一人称、主观视角或某人所见，`【画面内容】` 就不能把这个视点主体当成一个被外部摄影机观察的人来写，也不能用“某人眼睛位置”“摄影机在某人眼睛上”替代“某人眼前所见的画面结果”。画面主语优先是眼前、画面、视线、光、遮挡物、手、袖口、脚尖、胸前衣料、门框、窗框、道具、其他人物局部和声音来源。

错误写法：`视点主体 + 躲 / 看 / 听到 / 停住 / 皱眉 / 转头 / 站起来 / 表情怎样`。例如 `小安躲在被子后面`、`父亲看见门口的人后皱眉`、`主角听到声音后停住`、`你转头看向窗外`。这些句子会让模型去拍视点主体本身，或者生成一个旁观者看着视点主体动作的镜头。

正确写法：把视点主体动作转译成感官结果和画面变化。`揉眼` 写成“手擦过画面边缘，画面短暂虚焦”；`往后缩` 写成“前景遮挡物抬高，画面被遮住一部分，声音变闷”；`盯住对方` 写成“视线停在对方胸口、下巴、手或道具上”；`突然停住` 写成“画面静住，呼吸声断半拍，手指僵在前景”；`转头` 写成“画面从门框甩向窗边并停住”。

当前案例：小安床上 POV 不写 `小安躲在被子后面，小安听到后停住`。正确写成：`眼前先是一片朦胧，被窝占下半画面，浅色睡衣袖口和两只小手从画面下方伸出，门口冷光从被沿上方照进来，父亲的腿、外套下摆和递来的手进入画面。` 如果画面需要展示视点主体的脸部表情，应主动改成“贴近视点主体的旁观低机位”“近主观肩后镜头”或“第三人称近景”，再重新写清前景、中景、背景和人物视线。

所有镜头都要先解决观众最终看见什么、主要感到什么、这个画面为什么成立。画面来源、观众站位、镜头关系、空间层次、视线方向、动作方向和剪辑停点是候选判断项；只选择本镜真正需要的部分。主观、过肩、正反打和复杂调度必须锁必要空间关系，单物特写和简单空镜不填完整关系表。

正反打要先确定轴线和左右关系。例如小安在画面右侧、父亲在画面左侧，反打时两人的视线方向要相对，不能让两个人都看向同一边。过肩镜头要写清谁的肩背在前景、谁在中景、谁看向哪里。内打外 / 外打内要写清摄影机在门内、门外、车内、窗外还是桌子哪一侧。这样做的目的，是让每一条独立生成的视频提示词都能保持空间连续、视线成立和剪辑可接，而不是让模型凭空补机位。

正式写 `【画面内容】` 前要检查四类镜头控制杆，但它们不是四项必填：

```text
景别：画面需要容纳多少信息，是空间关系、完整动作、人物互动、表情，还是局部证据。
机位：观众站在什么高度和方向看，这怎样改变尺度、距离、遮挡、力量与信息范围。
运镜：镜头是否移动，移动从哪里开始、朝哪里去、经过什么、停在哪里。
光学质感：景深、焦段、前景虚化、光晕、胶片 / DV 质感如何服务情绪。
```

四类控制杆用于内部选择，固定镜头不必硬写运镜，自然景深已经准确时不必硬写焦段，简单特写不必补完整空间。正式正文只写被选中的结果；如果解释不出某个术语解决什么观看问题、怎样加强主情绪，就不要写。

景别从观看任务倒推：它决定观众能同时读到多少空间、动作、关系、表情或局部证据，不与孤独、亲密、庄重等情绪固定绑定。一个镜头如果同时承担过多互相争抢的任务，优先删减、拆镜头或写清景别变化。

特写进是短视频开场、悬念、审问、背叛、冲突、恐怖、情绪爆点和关系反转的注意力开关。它不是简单把主体拍大，而是先用局部证据强制观众聚焦，让观众在全局揭示前产生问题：这是谁、发生了什么、为什么这个局部危险或刺痛。全景开场能交代空间，但也会过早暴露人物关系和下一步动作，让期待感提前结束；因此高张力场面不能默认从全景开始。写分镜和视频提示词前要先判断：本场是否需要 1-3 秒抓住注意力；全景是否会提前泄底；是否有局部证据能代表危险、欲望、秘密、压力或情绪；特写之后是否有明确揭示路径。常用结构是 `局部证据特写 → 反应脸 / 关键动作 → 空间揭示`。错误写法是 `全景展示审讯室，背叛者坐在椅子上，审讯者站在对面，气氛紧张`；正确写法是 `极近特写先拍录音笔红点、攥白的指节、吞咽的喉结和审讯灯半亮下巴；对面椅脚移动声响起时，镜头缓慢后拉，让文件袋、椅背和人影进入画面`。

特写还可以作为蒙太奇连接器，用局部状态变化压缩时间或做心理暗示。相似转场特写蒙太奇适合表现时间流逝和人物崩溃，例如同一桌面上的咖啡从满到空、杯沿渍变深、便利贴增多、键盘碎屑堆积、台灯从暖亮变成冷白频闪；不需要字幕说过了多久，物件状态反差会让观众自己感到时间被折叠。联想蒙太奇特写适合表现心理暗示，例如墨水扩散吞掉白纸、玻璃杯水旋成漩涡、海面反光被树影切碎、灰尘在强光里剧烈翻涌；但意象必须和人物处境有共同结构，按 `现实触发 → 抽象特写意象 → 回到人物反应 / 当前物件结果` 写，不要把抽象意象当无来源高级空镜。

机位角度必须服务主情绪和视角关系，但没有固定映射。平视、俯拍、仰拍、斜侧和正侧要结合人物处境、距离、尺度与空间结果判断；同一俯拍既可能表现脆弱，也可能表现秩序或观察。正反打、过肩、门缝和车内机位存在时，写清必要轴线与遮挡。严格 POV 不能用机位高度替代画面来源，必须写成 `画面呈现某人眼前所见`。

运镜必须写路径、方向、速度和停点。固定镜头要写固定在哪个对象或空间；水平摇镜要写左摇 / 右摇、起点、经过物和停点；横移要写机身沿哪条线移动；推镜要写从什么景别推进到哪个表情或物件；拉镜要写从哪个局部拉开到什么环境；升镜 / 降镜要写高度变化和最终看见什么；环绕要写围绕谁、转动角度和主体是否始终清楚；跟拍要写跟谁、从哪个方向跟、屏幕方向和路径边界；甩镜要写触发声音和清楚落点。不要只写 `镜头移动`、`镜头切换`、`氛围感运镜`。

专业运镜术语必须先区分物理机制：Dolly / Track / Tracking Dolly 是机身整体移动；Pan / Tilt 是机身不动、镜头原地转动；Zoom 是焦段变化；Crane 是大幅高低升降；Jib 是小幅近距离升降；Handheld / Bumpy / Breathing Shake / Soft Stabilize 是稳定方式；Orbit / Arc / Match Move 是镜头和主体运动关系；Pass Through / Digital Dolly Through / Time-lapse Dolly / Spiral Dolly / Falling Dolly / Ascend & Dive 是创意或特效运动。正式提示词不能只写术语名，必须写路径、方向、速度、停点、主体关系和情绪任务。

希区柯克变焦 / Vertigo Shot 不是普通推拉。使用时必须同时写 `机身向前推进 + 光学变焦拉远`，并写清 `主体大小基本保持不变，背景空间拉伸畸变`，用于窒息、恐慌、崩溃、对峙或绝望。缺少其中任何一项，模型容易只生成普通推镜、普通变焦或背景随机变形。

光学质感与作品介质和主情绪一致，但没有题材固定套餐。浅景深、深景深、遮挡、光晕、微距、DV、胶片、鱼眼或宽幅都要说明其物理变化与观看职责；90 年代家庭回忆采用 DV 或暖黄色偏只是当前案例候选，不自动覆盖同题材作品。

镜头语言与情绪没有固定映射。平视、俯拍、仰拍、固定、手持、推拉、环绕和景深只是候选；必须根据人物处境、距离变化、稳定感、信息变化和主情绪判断实际效果。同一固定镜头可以温暖也可以压迫，同一手持镜头可以恐慌也可以亲密。当前案例：E1-S10-C2 选择固定低视线、镜头下压、蒲团遮挡和冷灰白布，是因为它们加强仪式压迫与失去，不是因为“庄重”必然对应固定机位。

通用 AI 视频分层在本项目中只作为开放问题库，不作为正式字段，也不逐层检查齐全。正式视频提示词仍只保留 `【基础设定】`、`【氛围与画质】`、`【画面内容】` 三块；从以下层级选择本镜承重项：

```text
镜头语言层 → 主体叙事层 → 环境布景层 → 光影色彩层 → 镜头光学质感 → 画幅帧率画质
```

分层职责：

```text
镜头语言层：景别、机位角度、运镜方式、镜头动态速度、确定时长。
主体叙事层：人物 / 生物 / 物体、外貌穿搭、动作、神态、细微情绪。
环境布景层：地点、空间结构、陈设、道具、前景遮挡、中景动作、远景背景。
光影色彩层：光源方向、光线软硬、主色调、冷暖关系、光晕、丁达尔、阴影层次。
镜头光学质感：焦段、人眼等效 / 广角 / 定焦、景深、散景、暗角、颗粒、畸变控制、胶片 / DV 介质。
画幅帧率画质：横屏 / 竖屏、16:9 / 9:16 / 2.39:1、分辨率、帧率、稳定度、细节清晰度。
```

落入项目三段结构时，`【基础设定】` 只列本条实际使用的参考素材和一句声音策略；`【氛围与画质】` 只保留跨全部镜头成立的主风格、摄影介质和宏观色彩基线；`【画面内容】` 承担主要信息，按镜头写景别、机位、运镜、主体表演、环境布景、本镜光影、HEX 色彩落点、材质、声音、切换和停点。不要在正式代码块里新增 `镜头语言层 / 主体叙事层 / 环境布景层` 这些标题。

所谓极简、标准、复杂或氛围公式只是一组开放问题库，不按片长、题材或商业等级自动套用。详细度由主情绪、观看任务、输入资产和生成风险决定：简单镜头可以只写主体、变化、观看位置和结束状态；复杂交互再补空间、受力、光色、声音或连续摄影机路径。外部通用公式里的“负面规避词结尾”不作为本项目正式正文层级，具体跑偏对象放在代码块外自检或失败经验里。

报丧、噩耗和突发事故要保护突发性。如果剧情需要孩子突然知道某个消息，消息出现前不要提前展示白布、灵堂、棺木、哭丧队伍等已经布置完成的结果画面。否则观众会提前知道，人物也会显得逻辑不通：既然现场都已经布置好了，为什么孩子才刚刚听说？

正确做法是先保持日常状态：放学路、书包、田坎、普通村民、随口一句直白消息。等主角被消息砸中并进入现场后，再揭示白布、遗像、哭声和仪式布置。

台词的委婉程度必须匹配人物身份、文化程度和戏剧功能。村民、老人、父母、孩子不一定会说文学化委婉话。需要冲击时，台词可以直白甚至粗粝，例如“你们爷爷死喽”。`走了`、`离开了` 这类委婉说法只在说话人身份、亲疏关系和场景情绪确实需要克制时使用。

叩首抬头、遗像更换和物件匹配转场可以压缩时间，但不能把正式画面写成“遗像切换”“变成另一个遗像”这类剪辑说明。模型需要的是同一空间、同一构图、同一遮挡动作和核心对象变化。匹配遮挡转场的关键不是把场景全换掉，而是让场景尽量不变，只让观众突然发现关键对象已经变了。

```text
前状态：小孩跪在爷爷遗像前，白色孝布遮住画面上沿一点，遗像桌、旧墙、白布和蒲团位置稳定。
动作遮挡：低头看下方蒲团，蒲团布纹逐渐占满画面，声音被布料闷住。
转场点：蒲团纹理满屏处形成遮挡转场。
后状态：转场后仍从相似的蒲团纹理近景接起，再抬头；同一张遗像桌、旧墙、白布、蒲团位置保持不变，只有桌中央黑白遗像从爷爷换成奶奶。
声音连接：前文奶奶叮嘱在画面里回响。
```

这种写法的重点不是解释“过了多久”，而是让观众先愣一下，再通过同构图里的唯一变化自己懂。当前案例：E1-S10-C2 不写 `抬头后场景都变了`，也不写 `桌中央变成奶奶遗像`；应写 `低头前同一遗像桌前是爷爷遗像，白色孝布遮住画面上沿一点；视线低下看蒲团纹理，蒲团纹理满屏形成遮挡转场；抬头后旧墙、白布、桌面、蒲团位置不变，只有桌中央黑白遗像从爷爷换成奶奶`。

## 四、编号与时长

分镜编号统一使用：

```text
E1-S1-C1
```

- `E` = Episode，集。
- `S` = Scene，场。
- `C` = Cut，镜头。
- 插入镜头使用 `E1-S1-C5A`、`E1-S1-C5B`，不重排后续编号。

镜头总时长必须是确定值：

```text
时长：12 秒
```

正式视频提示词单条时长默认必须在 `4 秒` 到 `15 秒` 之间。这个区间的作用是让模型有足够时间展示分镜效果，同时避免单条镜头拖得过长导致动作被延长、节奏被稀释。

判断方式：

```text
4 秒：极简转场、单一特写、单一动作结果、短暂身份锚点。
5-7 秒：普通动作链、空间揭示、群体反应、轻量奇观。
8-12 秒：人物表情 / 台词 / 礼仪动作、复杂 POV、重要身份确认、较完整奇观展示。
13-15 秒：同一场景连续动作、未资产化人物合并、复杂动作因果或大型场面调度。
```

低于 4 秒会让情绪、脸部、动作因果和奇观一闪而过，观众难以代入；高于 15 秒容易把一个镜头拖成长段落，让模型稀释剧情节奏。选择时长时先判断镜头任务需要多少时间让观众看懂、感受到、记住，再给一个确定秒数。

时长必须从 `【画面内容】` 倒推，而不是先固定一个常用秒数再硬塞内容。正式输出前要做一次时长预演：拆出动作单元，例如入画、观察、表情变化、台词、手势、道具响应、环境变化、运镜和转场停点；给每个动作单元估算最低可读时间，再相加得到预估时长。如果 5 秒装不下 8 秒内容，就增加到 8 秒、删减画面内容或拆成两个镜头。若预估超过 15 秒，说明单条提示词承载过多，应优先拆镜头。

短闪回、插入记忆和单信息补充镜头必须按信息点倒推时长，不要为了显得完整而拉长。若镜头只承担“看见愿望物 / 被拒绝 / 被带离”这类 2-3 个信息点，通常 5-7 秒足够；只有包含完整情绪停顿、复杂动作链或多句关键对白时才上到 8-12 秒。短闪回的价值是像记忆刺点一样击中观众，过长会让主线停滞、情绪变散，也会增加生成成本。时长不足会干，时长过长同样会浪费画面和费用。

不要写“8 到 10 秒”这类模糊区间。总时长在平台参数或执行单元标题中给确定值；正式模型正文不再给动作分配内部时间戳，也不使用镜头编号切块，而是用动作先后、切换触发、摄影机连续变化和停止画面表达节奏。

## 五、视频提示词三层结构

每条正式视频提示词必须包含且只能包含：

```text
【基础设定】
【氛围与画质】
【画面内容】
```

三段结构继续保留，但权重改为：基础设定最短，氛围与画质简短，画面内容最重。前两段只负责参考输入和跨镜头统一，不承担当前镜头的详细调度。

`【基础设定】` 只列本条实际上传或绑定的人物、场景、道具、色卡、首帧、动作与音色参考，再用一句话写声音策略。参考图容易误导或本镜存在临时状态变化时，才补一句短约束。当前分镜的一次性动作、具体事件和局部美术不进入基础设定。

进入 `【基础设定】` 的角色、场景、道具、生物或固定人群，默认都必须有固定资产支撑。没有固定资产的对象只能作为当前镜头画面元素写进 `【画面内容】`，不能被写进基础设定假装已经锁定一致性。

实际不进入本镜画面结果的资产，不能写进 `【基础设定】`，也不能在 `【氛围与画质】` 和 `【画面内容】` 里提名。资产引用不是备注，而是模型召回指令；只要写入 `【@资产名】`、资产名称或高权重视觉名词，模型就会倾向于把它生成进画面。每条正式提示词都要先做“本镜实际调用资产清单”：人物是否出镜 / 出声 / VO，场景是否提供可见空间，物件是否被看见 / 触碰 / 发声 / 作为运动或光影中心。没有承担这些职责的资产，即使它在前后镜头重要，也只能留到真正出现的镜头再调用。

通用规则：资产调用必须服务当前可见 / 可听结果，不能服务作者心里的剧情背景。错误写法是 `门缝医生画外音` 镜头里引用 `爷爷输液瓶：【@P6】`，并写玻璃输液瓶高光、输液管晃动；这样模型会把输液瓶提前塞进门缝画面，破坏小安只听见对话的信息差。正确写法是门缝镜头只调用小安、父亲和门缝里实际看见的白大褂衣角 / 旧药箱 / 父亲裤腿；输液瓶留到下一镜小安进屋后第一次看见。当前案例：E1-S8-C1 已移除 P6 输液瓶，只保留门缝、医生衣角、旧药箱和父亲低声；E1-S8-C2 才调用 P6。

```text
资产名：【@资产名】固定外观、材质、比例、状态、行为规则或使用规则。
```

人物资产行不是服装复制器，也不是重复声线说明的地方。人物资产行应先用 `【形象参考@xx】` 和 `【音色参考@xx】` 调用稳定参考，再按本镜需要补当前状态。模板可以写成：`小安：【形象参考@A1 小安人物设计资产】【音色参考@V1 小安音频参考】6-7 岁重庆小男孩；本镜穿浅色儿童睡衣 / 薄棉秋衣，身体在被窝里，用小手、袖口、揉眼和呼吸表现刚醒。` 如果当前镜头是睡觉，就不能仍写外出棉外套、儿童鞋和书包像穿在身上；书包可以作为床边场景物出现，但不能变成睡觉穿着的一部分。当前镜头的哭腔、病弱、压低、喊叫、电话失真和 VO 回响写进 `【画面内容】`，不要把它们写成新的基础音色。

道具资产不是一类物件的泛称，而是一个需要保持唯一性的具体对象。凡是道具资产进入 `【基础设定】` 或 `【画面内容】`，必须写清本镜数量、资产身份、同类边界和剧情时间状态：一辆 / 一只 / 一件 / 两辆分别是什么，它在当前剧情时间点是否已经存在、是否已经被人物看见、是否只是台词里的承诺或未来结果。如果只写 `木马车`、`药碗`、`纸房子` 这种类名，模型会倾向于复制同类物件，导致一辆生成两辆、旧车提前生成新车、一个道具变成一组道具。正确写法：`旧木马车：【@P1 旧木马车】唯一一辆旧木马车...本镜发生在碰撞冲突之前，剧情里只有爷爷已经送给小安的这一辆 P1，P2 新木马车尚未被承诺、尚未制作、尚未出现，禁止出现第二辆木马车。` 如果本镜确实需要两辆，则必须说明两辆的剧情来源、编号、数量、位置和差异，例如：`两辆木马车：P1 旧木马车在左侧，深木色有修补痕迹；P2 新木马车在右侧，浅木色有新刨痕。P2 是爷爷在碰撞冲突后承诺再做一辆的兑现证据，只在结尾遗物回收段出现。`

同类道具要做剧情解锁检查。制作阶段可以提前设计 P2 资产，但正式视频提示词不能因为资产表里已有 P2，就让 P2 在剧情尚未发生之前入画。先问三个问题：当前镜头之前这个道具是否已经被制造 / 获得；角色是否已经知道或看见它；它是当前实物、台词承诺、回忆对象还是未来兑现证据。当前案例：《不想长大》前半段只有 P1 旧木马车；P2 新木马车只有在 E1-S5-C1 爷爷说出“再做一个 / 一人一个”之后才成为承诺对象，在结尾 E1-S11-C2 / C3 才作为兑现证据入画。E1-S3-C2、E1-S3-C5、E1-S4、E1-S5 前半都不能出现 P2。

`【氛围与画质】` 只保留 1-3 句跨本条全部镜头成立的宏观基线：主风格母体与真实程度、全局摄影介质 / 画幅 / 颗粒、统一色彩关系与肤色基线。它不是“把三个字段写满”，更不承载局部物体、光源、焦段、雾气和 HEX 映射。

局部规则归属判断：删除一句后如果只影响某一个镜头，这句话就应放进该镜头的 `【画面内容】`。例如 85mm 人像焦段、月光从右后方擦过剑脊、墙面调用 #4B5458、雾从院门向里流动，都必须贴着对应镜头写。

三个字段内部仍要按组合系统理解，不要死背风格词：

```text
画面风格 = 风格母体 + 画质介质 + 色彩影调 + 光影方式 + 构图 / 美术体系 + 题材气质 + 正向边界
```

风格母体可以来自日系、胶片复古、港风 / 东方复古、欧美经典电影、科幻未来、暗黑犯罪、Ins 日常高级、童话梦幻、黑白单色、纪实原生、小众失真、动画手绘、季节人像等体系。使用时不要把词当咒语，而要拆成可生成元素：色彩是低饱和还是高饱和，光是自然柔光还是低光硬反差，介质是 35mm 胶片还是高清数字电影，构图是对称、留白、手持纪实还是史诗远景，美术是中式水墨、白玉仙宫、赛博霓虹还是市井烟火。

正式提示词里优先写 `1 个主风格核心 + 1 个摄影 / 介质锚点 + 1 套色彩影调`。多个风格并用时必须写主次，例如“古风电影质感为主，借 IMAX 70mm 史诗清晰度和高动态光影；画面保持东方古典礼制、白玉青玉材质、真实宽幅电影和清贵神域气质”。不要堆一串互相冲突的风格名词让模型自己猜。

情绪人像和短视频开场不能只写 `写实电影级 / ARRI / 高级人像`。这些词只说明真实度和摄影设备感，不能决定画面会偏日系清透、韩剧柔光、商业广告、短剧、电视剧、纪实街拍还是油亮时尚大片。正式写 `【氛围与画质】` 前，必须先建立风格交集：

```text
风格交集 = 主风格母体 + 辅助风格 + 胶片 / 滤镜分级 + 明度对比 + 光影方式 + 肤色妆效 + 场景环境色 + 情绪阶段边界
```

主风格母体回答“这条片子像哪一类影像”，辅助风格回答“借哪一类质感”，胶片 / 滤镜分级回答“色彩如何统一”，明度对比回答“亮、暗、硬、软”，肤色妆效回答“人物第一眼是否好看”，场景环境色回答“天空、海面、树影、墙面、水面怎样影响人物”，情绪阶段边界回答“前后情绪如何在同一风格内变化”。当前案例：《30秒钟带你体验谈恋爱》不能只写真人写实电影人像，应写成 `真人写实海边情绪短片，日系清新治愈青春电影色彩为主，海边低饱和胶片写真为辅，清新透亮、高明度低对比、柔和自然光、空气感散景、富士胶片清透蓝绿倾向、柯达 Portra 式自然人像肤色过渡；前半段清澈明亮，后半段同一美景不变，只通过人物眼神、留白扩大、树影压面和气色变化转成现实虐恋感`。这样写不是堆词，而是把模型的可选风格空间收窄到一个稳定交集里。

视频提示词仍要经过摄影指导判断，但摄影指导不是补齐字段，而是从开放控制杆中选择能改变本镜结果的手段。正式写 `【氛围与画质】` 和 `【画面内容】` 前，先问主情绪、主注意力、动作可读性和连续性分别需要什么，再选择：

```text
摄影指导候选 = 光影关系 / 光影运动 / 色温 / 主体细节 / 空间层次 / 时间天气空气 / 焦段景深 / 画面类型 / 情绪反差 / 正向质量边界
```

只有光影承担体积、分离、身份或主情绪时，才展开必要的亮暗、轮廓、背景和反光关系；剪影、平光、大片暗部或主体融入背景也可能是准确选择。使用动态光源时必须有可见动机，并写清来源、运动原因、阴影如何移动、哪些主体被影响，以及主光方向是否稳定。

光源色温先由时间、真实光源、场景材质和人物肤色建立物理基线，再判断暖、冷或冷暖并置怎样加强主情绪。暖光可以危险、虚假或窒息，冷光也可以清醒、宁静或治愈。当前《30秒钟带你体验谈恋爱》采用海边柔金侧逆光和蓝绿反光，是该时间、场景与“美景仍在而关系变冷”的情绪结构共同推导出的案例，不是恋爱题材固定答案。

主体细节只在承担身份、状态、动作因果或主情绪时展开，并绑定具体主体：

```text
主体细节候选 = 颜色 / 材质 / 纹理 / 状态 / 反光 / 破损 / 湿度 / 瑕疵 / 边缘细节
```

人物、道具和场景只选择当前镜头真正可见且承重的细节。人物可选肤色、妆效、发丝、衣料、首饰、泪痕或眼里高光；道具可选磨损、湿度、反光、缺口或使用状态；场景可选墙面、地面、水汽、灰尘、树影或远景空气。不是把每组都写完，判断标准是删除该细节后是否损失身份、因果或主情绪。

镜头参数按屏幕结果自动选型：需要多少环境、相机离主体多远、透视要夸张还是压缩、哪些信息必须同时清楚。焦段、景深、对焦距离、主体到背景距离和散景只在承重时展开；不把情绪人像固定为 85mm 浅景深，也不把 POV 固定为 35mm。

如果情绪反差承担观看理由，就必须变成可见证据。`温暖但是孤独`、`清新但是疼`、`奢华但是破败`、`干净但是危险` 不能只作口号，可分别落实为环境仍美但眼神空掉、暖光仍在但树影压面、精致材质边缘破损、洁净空间出现异常静止。没有反差职责的镜头不必人为制造第二情绪。

正式投喂给视频模型、图片模型、资产生成模型、封面模型或首帧模型的提示词，都必须先写“画面里要出现什么”。模型正文的主任务是正向描述目标结果：主体、环境、构图、动作、材质、光线、声音、情绪和最终可见 / 可听结果。不能用排除句替代正向描述；否则模型会先注意到被提到的对象，把它当成候选画面元素。少量硬边界只用于抽象质量问题，例如文字水印、动作僵硬、逻辑混乱、比例畸形，并且不得引入当前画面不该出现的具体视觉对象。图片提示词、视频提示词、资产提示词、封面提示词和分镜首帧提示词都遵守这条规则：出现什么就描述什么，不出现什么就尽量不写；风险说明放在代码块外的人类说明、验收标准或复盘里。

所有给模型用的图片提示词和视频提示词，都必须把“可复制投喂正文”单独放进 `text` 代码块。代码块的职责只有一个：方便老胡直接复制到图片模型或视频模型。代码块外可以写用途、服务场次、资产编号、必须锁定、允许变化、不能继承、是否可作为视频参考图、生成执行单、回传字段和确认说明；代码块内只能写模型需要看到的提示词正文。图片提示词代码块优先使用 `质量边界` 写抽象质量要求，例如画面干净、比例自然、身份清楚、材质真实、无文字水印；视频提示词代码块只能包含 `【基础设定】`、`【氛围与画质】`、`【画面内容】` 三块。

图片模型的可复制代码块里，引号只能服务画面中真实需要出现的文字，不用来强调概念、标注解释或制造重点。生图模型会把引号里的词当成画面文字候选，导致资产图上出现本不该出现的长标签。正确写法是 `标签文字为：左手、右手`、`标题文字为：音色说明`、`正文文字为：儿童清亮偏细，重庆口音，语速快，情绪外露`；不要在代码块里写 `标注“林栀自己的左手”`、`标题为“音色说明”`、`所谓“高级感”`。如果只是给老胡看的解释或强调，放在代码块外，不进入模型正文。

镜头节奏通常属于分镜表或当前 `【画面内容】` 的运镜与动作节奏；只有它是全片统一风格的一部分时，才可以简短写入 `视觉基调`。只影响当前镜头的局部光线、情绪、声音和动作，写进 `【画面内容】`。

正式投喂时，前两部分不能写成“沿用全片”。即使内容来自同一个作品，也要在当前这一条提示词里重新完整写出。过程判断可以在文件说明里记录，但正式提示词正文必须让模型不依赖任何前文。

`【画面内容】` 才写当前分镜发生什么、怎么拍、有什么声音、动作和光影。景别、构图和运镜要用专业但自然的拍摄语言，不要把画面动作误写成运镜。比如“拂袖横扫”属于画面动作；运镜应写“低角度前推”“跟随袖口轻微横移”“微距推近”“破云俯冲后抬升”“固定机位轻推”等。

全分镜视频提示词不能只保证单条内部完整，还必须保证上下镜头之间能剪起来。生成全片提示词前，必须先为每个镜头判断四件事：上一镜停在什么视觉锚点或声音锚点；本镜从什么可见物、动作、视线或声音开始；两镜之间是连续时间、压缩时间、回忆、跳切还是仪式性省略；观众靠什么判断空间、人物和情绪没有断。常用连接方式包括动作接动作、视线接所见、声音先行 / 延后、物件匹配、光线匹配、遮挡转场、同方向运动、情绪停点硬切。若相邻镜头没有连接锚点，要在前一镜结尾或后一镜开头补一个画面内可见 / 可听的停点。

多人、多物、复杂空间或存在交互的镜头，正式写 `【画面内容】` 前必须先建立场景关系图；单主体静态表情、单物特写和简单空镜只需锁定主体、观看位置与必要空间锚点。关系图不作为正式字段投喂模型，而是用于解决本镜真正存在的位置、遮挡、视线、接触和运动关系。不要为了流程完整，把前景 / 中景 / 背景、画面左 / 右、门窗桌墙等全部塞进没有这些关系的镜头。

关系图按发生的内容展开：有触碰、承重、碰撞或变形时，写接触点、力度、受力方向和可见结果；有方向性运动时，写起点、路径、终点和边界参照；运镜承担关系揭示时，写它怎样让接触点或空间布局变清楚；有会影响主情绪、动作可读性或连续性的光影变化时，写光源、受光对象和可见变化。没有交互就不造受力链，没有光影变化就不造动态光效。

错误写法是 `女生拍男生肩膀，男生吓一跳，拉着走`、`温馨光影`、`镜头拉远` 这类只有事件名或效果名的句子。正确写法要像可见镜头结果：`镜头中男生站在画面中间偏左，女生从画面右后方绕到他背后，右手从男生右肩后方轻拍肩头；男生右肩向上一缩，身体向画面左前方小幅后撤，嘴型停住。右侧窗外暖光从人物侧后方斜照进来，女生靠近时短暂挡住男生脸侧亮面；镜头随后轻轻后拉，露出女生站在他右后侧并拉住他手腕往画面右侧走。`

承担人物第一眼、情绪峰值、段落记忆、封面候选或传播视觉职责的镜头，应设计“审美停点 / 情绪停点”：暂停后仍能把本镜主情绪传清。停点只选择真正承重的主体轮廓、构图、留白、光影、色彩、材质或姿态，不要求全部出现。功能型插入镜头、动作连接镜头和信息证据镜头不强制壁纸帧，只需在任务完成处形成清楚、可剪辑的停点。

需要审美停点时，把它写成可见镜头结果，例如 `镜头最后停在...`、`画面形成...关系`、`右侧留出...空白`、`暖光勾出...轮廓`。判断标准不是每镜都能做封面，而是镜头的停点与职责一致：情绪镜头能留下感受，信息镜头能留下证据，动作镜头能留下因果，连接镜头能留下剪辑接口。不能为了截图价值破坏主情绪或动作节奏。

构图、光影、色彩以及后续所有审美模块，都不能被当成封闭词表。老胡给出的三分构图、黄金一小时、莫兰迪、青橙、胶片棕调等都是启发样例，不是固定菜单。正式写提示词时要先判断本镜的剧情情绪、时代背景、空间材质、人物肤色、道具颜色、光源类型、壁纸用途和剪辑连续性，再选择或组合合适的审美方案。正确做法是从底层目的扩展同类可能，例如构图可以继续扩展到层叠构图、纵深透视、色块构图、剪影构图；光影可以扩展到火光主光、雪地反光、霓虹湿地反射；色彩可以扩展到黑白灰单色、褪色老照片、煤油灯暖褐、山城雾灰绿等。不要机械照抄用户列举词，也不要把未列出的有效搭配排除掉。

构图承担主情绪、主体识别或关系展示时，先选择能完成该职责的画面骨架，并把主体落点、视线方向或空间关系写清。三分、黄金分割、中心对称、框架、引导线、对角线、留白、前景框和三角关系只是候选，不要求每镜点名术语；简单特写只要裁切、焦点和注意力成立即可。

构图逻辑的第一步是给观众眼睛找一个家。正式写镜头前必须先判断本镜的视觉落点是什么，也就是观众第一眼应该锁定的点：一张脸、一双眼睛、一滴泪、一只手、一个道具、一棵树、一束光或一个唯一发亮的局部。点越少，画面越安静；干扰越多，主体就越要通过面积、亮度、颜色、清晰度、反差、位置或运动被加满。错误写法是 `草地上有很多人物和远处山景，主体在画面里`；正确写法是 `人群和山景全部压低清晰度与饱和度，唯一清晰高亮的是画面右侧三分线处回头的女孩脸，脸部比周围人更亮半档，眼神直接锁向镜头`。如果提示词没有说明第一眼看哪里，模型会平均铺开元素，画面看起来有内容但没有主角。

视觉导引线在视线路径承重时使用。主体在线条起点、途中或终点会改变观看顺序，但不固定对应存在感、孤独或动作；斜线、水平线、曲线和汇聚线首先改变方向与节奏，实际情绪由人物处境和画面密度决定。选用时写清起点、路径和终点，不选用时不为“高级构图”强造线条。

空间块面负责压掉杂质。大面积天空、海面、墙面、暗部、虚化背景、雾气、草坡、石墙、门洞阴影和前景色块，都可以作为面来切割空间、制造留白、压住杂乱信息。面不是背景填充，而是让主角从杂乱中被分离出来的工具：明亮块面托出暗主体，深色块面托出亮主体，虚化块面压掉细节，石墙 / 门洞 / 窗框块面制造稳定和压迫。正式提示词要写清哪一块面占据画面的哪一侧、压掉哪些杂质、给主体留下哪一小块灵魂空间。错误写法是 `背景虚化，有高级感`；正确写法是 `画面左侧三分之二被深绿色虚化树影压成干净暗面，只在右侧三分线留出一块柔金亮面承接人物侧脸`。

点、线、面要按顺序服务主体突出：先确定视觉落点，再选择导引线，最后用块面和留白压掉无关信息。不要为了显得丰富把点、线、面都塞满；本镜如果是情绪人像，点可以是眼睛和泪痕，线可以是栏杆或树影方向，面可以是海面留白或暗部背景；本镜如果是场景空镜，点可以是一棵树或一个人影，线可以是道路或山脊，面可以是天空、草坡和阴影。只要观众第一眼不知道看哪里，这条提示词就要先重写构图。

画面情绪不能只归因于光影和构图两个大词。正式写图片、视频、首帧、封面和故事板前，要把透视、灭点、线性节奏、影调、色彩透视、动态范围、材质、空气介质和柔化质感视为开放控制杆；只选择能加强主情绪、主体识别或生成稳定性的部分。被选中的控制杆必须写成可生成结果，未承担职责的不要为了显得专业而出现。

留白、平衡和边角清洁只在它们加强主情绪、主体识别、字幕空间或封面用途时写入。稳定不是唯一正确状态：恐慌、眩晕和失控可以有意破坏平衡，但必须是清楚的情绪选择，不是生成事故；不需要留白的事实特写和动作接触点，不强行腾出空白。

留白分为空间留白和信息留白。空间留白是画面里真实空出来的区域，例如天空、海面、墙面、暗部、雾气、窗外虚景和负空间，用来让画面有呼吸、标题区、视线方向和情绪重量。信息留白是关键内容没有一次性给满，例如只露半张侧脸、只露嘴唇和下颌、发丝遮住一只眼、门缝里只露手、前景树影遮住脸部一部分、只拍项链吊坠和锁骨、背影只回头一点点。信息留白的底层作用是让观众补完：完整展示让观众确认美，局部遮蔽让观众参与想象。

信息留白和局部遮蔽必须服务镜头任务。适合使用的场景包括人物第一眼气质、短视频前 3 秒钩子、封面海报、暧昧、危险、身份悬念、心理暗示、欲望感、不可接近感和高级氛围；不适合用于必须看清事实、看清表情高潮、看清台词反应、看清道具操作和看清动作因果的镜头。错误写法是 `美女很神秘，画面留白很多`。正确写法是 `人物位于左侧三分线，只露右半张侧脸，左半张脸被前景发丝和树影遮住；金色侧逆光勾出鼻梁、唇峰、耳坠和下颌线，眼睛不完全露出，右侧保留大面积海面负空间，观众只能通过嘴角、呼吸和耳坠晃动判断情绪`。如果本镜任务是被击穿、落泪或争吵反应，就不能把眼睛和嘴角长期遮住；最多用发丝、树影或泪痕做短暂遮挡，关键停点必须让眼神、眼眶、嘴角和下巴清楚。

画幅比例先服务发布平台和镜头任务，再影响构图。16:9、21:9、3:4、9:16 和方形都只是候选；宽画幅不必然要求横向留白，竖画幅也不必然要求全身姿态。要根据主情绪、主体比例、空间关系和后续裁切选择，不把“壁纸用途”误当所有视频的默认目的。

光影承担主情绪、主体塑形、动作可读性或连续性时，按需从时段基线、实际光源、方向、软硬、明暗层级、反光、材质反应和动态稳定中选择承重项。自然光已经足够准确时，可以只写来源和关键受光结果；不强制主光、辅光、轮廓光和光学效果同时出现。

当时间和光线承担情绪或空间职责时，要具体到真实来源与关键结果，例如 `傍晚漫射光从院门方向斜进来，旧墙反弹一层弱暖光`。黄金一小时、日出、蓝调时刻、雨后天光、窗光、门缝光和旧灯泡只是开放候选，不把任何时段固定绑定某种情绪。

需要光型分层时，先确定哪一层真正塑造主体或主情绪，再补足必要的暗部可读性与分离关系。单一硬光、剪影、近无辅光或平光也可以成立，只要它是有意选择并且不会损害本镜需要看清的证据；不能为了凑层数添加无来源高亮和装饰反光。

动态视频里的光影必须稳定。AI 常会为了“有变化”让光源乱闪、主光位置跳变、阴影方向前后矛盾。正式提示词要写清关键镜头内光源不跳变，例如 `全程保持同一扇窗的侧逆光`、`镜头后拉时光源方向不变，人物移动只短暂遮住脸侧亮面`、`火光可以轻微跳动，但主光仍来自火盆下方，背景暗部保持低对比层次`。如果一条镜头抽帧后光影破碎，通常不是模型单独问题，而是提示词没有锁定光源、阴影和反光关系。

色彩承担主情绪、身份识别或连续性时，按需选择主色、辅助色、点缀色、饱和度、明度、环境反光或分级，并写到真实对象上。不是每镜都需要完整色彩体系；黑白、近无色、单色或自然综合色同样可以成立，只要情绪方向和连续性清楚。

色彩母体按人物处境、真实光源、场景材质和主情绪选择，不按丧事、病床、饭桌或放学路套固定色谱。冷灰、暖黄、黑白、高饱和、多色冲突和自然综合色都可以成立；要说明颜色落在什么对象上、怎样分配注意力，以及为何不会把主情绪带偏。

色彩规则要有清楚权重和过渡，但不固定为 `1 个主色 + 1 个辅助色 + 1 个点缀色`，也不默认低饱和等于高级。单色、综合色或有意冲突的多色体系都可以使用；真正要避免的是多个高权重颜色无目的地争抢主情绪和注意力。环境反光和色彩渐变只在真实存在并承担统一职责时写入。

色彩滤镜和分级要服务统一，而不是廉价套滤镜。可以写富士胶片色调、柯达金 200 暖调、电影 LUT 调色、轻微暗角、胶片低饱和、低对比度色彩分级、暗部偏冷高光偏暖、整体褪色老 DV 统一色偏等；但必须绑定画面结果：暗部是什么颜色，高光是什么颜色，肤色是否自然，墙面和衣料是否被同一环境色包住。动态镜头中同一场景色彩分级要保持一致，不能一会儿高饱和、一会儿冷灰、一会儿现代广告色。

如果作品已经建立色彩风格资产，正式视频提示词在 `【基础设定】` 写 `色彩风格资产：【@C1 色卡名】`；`【氛围与画质】` 用一句色卡锚定句说明全段主辅色、肤色基线、暗部倾向和高饱和点缀边界；逐对象 `颜色映射` 写进对应镜头。整体光线、主角服装部位、肤色、发色、墙面 / 屋顶 / 地面 / 门窗、关键道具、雾气 / 烟雾 / 空气透视 / 暗部 / 阴影 / 高光分别调用哪些 HEX，都要跟随它真实出现的镜头描述。色卡图负责色块关系，镜头文字负责颜色职责和落点。

颜色映射只写本镜头真实出现的对象。没有出现的道具、服装部位或场景结构不要为了填满表格硬写；但只要出现并且影响画面观感，就必须从四组色卡中调用对应色值，不能让模型自由改色。

景深与空间层次承担主情绪、空间因果或注意力控制时，按需选择前景遮挡、中景主体、远景环境、焦段、焦点或空气透视。深景深、平面化、无前景和背景同样清晰也可以是有意选择；不强制前中后景齐全，更不能为了层次遮住关键表情、动作或事实证据。

焦段从视野范围、摄影机距离、透视夸张 / 压缩、主体占比、背景信息量和主情绪反推，不与人像、POV、亲密或疏离固定绑定。35mm、50mm、85mm、135mm、微距、准广角和长焦都只是物理选择；写入时说明它怎样改变脸部比例、空间距离和环境可读性。

景深控制要和剧情信息匹配。人物情绪、手部道具、遗物、硬币、蒲团纹理、木轮、火苗等可以用极致浅景深、主体清晰锐利、背景柔和散景；群像、仪式、饭桌座位、推搡因果、滑坡路线、场景资产和空间关系需要中等景深或深景深，不能为了好看把关键信息虚掉。前景虚化要服务层次和信息差，例如 `画面左侧门框虚化成暗边，中景爷爷手里的布巾清晰，远景饭桌旧灯泡柔成暖黄光斑`；不能遮住关键动作，也不能让焦点在运动中随机漂移。

动态镜头只有在焦点承担注意力迁移、证据可读或连续性时才写对焦过程。稳定锁定、主动转焦、深景深和有意短暂失焦都可以成立；被选中时写清触发、变化与落点，不承重时不为“电影感”强加焦点动画。

画质与材质只围绕本镜主注意力目标和交付用途展开。近景表情、产品细节、遗物证据和材质展示需要写清锐度、纹理、反光和运动模糊；快速连接镜头、梦境或主观失焦可以有意降低细节。不能只写 `8K / 高清 / 电影级`，也不能把所有表面纹理都写进同一镜头抢夺注意力。

材质质感必须绑定具体物件。哑光柔和质感可用于旧墙、棉衣、孝布和纸房子；磨砂低反光可用于旧瓷、旧木、玻璃柜台边缘和年代道具；丝绒柔和肌理只在衣料或暗部需要柔软质地时使用；金属细腻拉丝、旧金属磨损和克制反光用于硬币、旧钥匙、锅沿、斧头和工具；水雾朦胧质感用于灶房水汽、雨后空气、火盆烟气和蓝调时刻；水彩通透质感只适合明确风格化图片，不默认进入真人写实视频。材质词不能空堆，必须写清照到哪个表面、反光强弱、边缘是否清楚、纹理是否可见。

截图放大不糊还要控制运动模糊和画面洁净度。动作镜头可以有少量方向性模糊，但审美停点必须主体边缘稳定、关键手部和道具清楚、微细节可读。老式 DV、胶片或年代回忆可以有细腻胶片颗粒、轻微频闪和受控噪点，但不能变成脏噪点、压缩糊块、AI 多余虚影、边缘崩坏、肢体扭曲、随机文字或水印。正式提示词要写 `木轮转动后逐渐慢下来，镜头停点极低运动模糊，轮辐边缘和粗糙木轴纹理清晰`，而不是只写 `8K 高清，电影质感`。

氛围环境元素只有在加强主情绪、空间真实感或运动层次时才进入正文。天气、空气媒介、微粒、光学点缀和环境运动都是候选，不是必填层；干净空气、静止背景和无特效环境同样可以更有力量。被选中的元素要有来源、位置、方向和密度。

氛围元素必须有来源和方向。薄雾来自清晨、雨后、山城湿气、火盆烟气或灶房水汽；细碎光斑来自窗光、旧灯泡、逆光、玻璃反射或水面波光；漂浮微粒来自纸灰、糯米粉尘、木屑、火星、落叶、窗边灰尘或雨丝；水面波纹来自雨滴、风、脚步、碗汤晃动或河面微风。写提示词时要说明这些元素在哪里可见、如何运动、密度多轻、是否只在光柱 / 背景 / 前景边缘里出现。

氛围环境要服务题材，不是装饰特效。家庭纪实和老式 DV 优先窗边落尘、灶房水汽、旧灯泡光晕、轻柔烟尘、纸灰和落叶；丧事和病床适合冷灰薄雾、压低烟气、火盆纸灰和低密度浮尘；放学路适合雨后水汽、枯草微动、土路尘灰和远处山城薄雾；浪漫、MV 或强风格化镜头才适合漂浮花瓣、轻纱透光和明显镜头光斑。氛围元素不能遮住关键动作、台词、表情、道具数量和 POV 视线，也不能把写实生活戏变成超现实舞台感。

镜头运动先服务观看意图和主情绪，再决定稳定方式、速度、抖动、变焦 / 旋转、构图保持和运动模糊。稳定画面、持续运动、故意失衡或短促颠簸都可以成立；没有观看职责时优先少动，需要恐慌、追逐或身体临场感时允许不稳定，但要让观众仍能读懂关键动作或情绪证据。

需要观众读表情、事实证据、动作结果或剪辑接口时，运动必须给出可读停点；停多久由内容所需时间倒推，不统一规定 1-2 秒。纯运动冲击、主观眩晕或连续追逐可以不回到壁纸构图，但不能让关键因果不可读。若抽帧全糊或主体漂移，先判断这是有意情绪结果还是失控生成，再决定是否补稳定约束。

`【画面内容】` 的详细度由镜头职责决定。动作、交互、破坏、变形和环境响应承担观看任务时，必须写出必要的动作链和因果链；静止表情、等待、空镜和单物证据镜头只需写清状态变化与停点，不强造连锁反应。不要只写“发生爆炸”“众人惊慌”，但也不要让一滴眼泪同时触发道具、光线、天气和摄影机变化。

舞蹈、武术、身法、仪式动作和水袖表演必须比普通动作写得更具体。它们的可生成性来自身体链，而不是动作名。正式提示词要写脚位、重心、膝胯、胸腔、肩肘腕、手指、衣袖 / 水袖、头眼方向、呼吸、停点和同期声；尤其水袖舞要写清力从脚底和腰背发起，肘带腕、腕带袖，袖面滞后、追身、甩出、回收、遮挡或落成圆弧的过程。不能只写“优雅旋转、衣袖飘动、舞姿好看”，否则模型会自由生成成随机摆拍或普通转圈。

数字人舞蹈宣传片先确定观众要记住人物身份、脸部气质、动作线条、足下技巧、服装材质还是空间奇观。人物识别承重时可以提高主体占比并使用中近景、半身或七分身；完整跳跃、足下点水、群体队形和空间尺度承重时，全身、全景或远景可能更准确。景别、推拉、横移、环绕、遮挡、转焦和停点都按主任务选择，不形成固定镜头套餐。当前《泠月·云袖照影》以记住数字人本人为目标，所以中近景占比更高；这不是所有舞蹈宣传片的默认答案。除非老胡明确要求歌曲、配乐或 BGM，舞蹈宣传片只生成同期声和环境声。

当需求明确指向 `15 秒卡点舞蹈`、`短视频风格` 或高冲击音乐切片时，先确定这段要让观众感到的主能量，再按音乐节拍、动作阶段和可读时间设计视觉节点。前 1 秒特写钩子、中段每 2-3 秒爆点、结尾稳定近景只是诊断参考，不是固定结构；一镜到底、持续旋转或远景空间调度如果更能传达主情绪也可以使用。每个被选中的动作和运镜都要有路径、触发、主姿态和剪辑职责。除非老胡明确要求生成音乐，否则只写同期声，不主动写 BGM。

关键发声镜头不能只依赖 `【音色参考@xx】`。人物设计资产和音频参考负责跨镜头基础一致性，但短视频开场钩子、人物第一次出声、重要 VO 回响、争吵爆点和情绪反转句，需要在本条 `【基础设定】` 的 `声音设定` 里重新写本镜声线、音区、共鸣、颗粒、近麦 / 距离、咬字、尾音和语气，再在 `【画面内容】` 写停顿、气口、回响和表演节奏。开场要抓人时，女声可以设计为冷感磁性女中音 / 偏低女声，中低频到中频集中，胸腔共鸣稳定，轻微沙哑颗粒，近麦干声，咬字清楚利落，尾音短收；不甜、不夹、不软，不做主持播音腔。这个方向只适用于需要记忆点、冷笑挑衅和短视频钩子的镜头，不自动覆盖所有情绪段。

台词、旁白、画外音和脑内 VO 必须按“双层声音表演”写。不要只写 `温柔`、`生气`、`压迫`、`破碎`、`深情`、`甜`、`刺` 这类抽象标签，也不要只写 `音高压低、音量中等、语速收紧` 这类机械参数。正确顺序是先写情绪意图和说话态度，例如示好、试探、亲昵、期待、敷衍、心虚、防御、不耐烦、反推责备、轻蔑、愤怒、暴怒、切断、空洞残响；再写声音形态，例如音高 / 音区、响度 / 音量、语速 / 节奏、停顿 / 气口、重音位置、气息状态、咬字 / 吐字、软硬强弱、爆发力、近麦或远处距离、混响和衰减。错误写法：`男声音高压低，音量中等，语速收紧。` 正确写法：`男声带防御和心虚，急于把怀疑压回去；声音收紧发硬，音区偏低，音量不大但压迫感明显，重音压在“她”和“普通朋友”上，“可以吗”短促下压。`

如果一个 VO 是推动人物表情变化的主要触发器，必须按情绪阶段设计声音曲线。初识、热恋、平淡、猜忌、争吵、决裂不能共用同一种普通年轻男声；也不能只逐条改变音量、距离、语速、停顿、重音、气息、咬字和回响衰减。每个阶段都要先写情绪态度：初识是轻佻试探和克制示好；亲昵称呼是冒进试探和甜腻笑意；热恋邀约是期待、紧张和怕被拒绝；平淡期是表面愧疚但敷衍抽离；猜忌期是心虚、防御和急于压住对方；争吵期是不耐烦、反推责备、烦躁爆发和推卸责任；攻击句是轻蔑、厌烦和刺伤自尊；决裂句是暴怒爆发、厌倦切断和彻底拒绝。当前案例：《30秒钟带你体验谈恋爱》的男声脑内 VO 是林栀表情变化的核心触发器，不能只写普通、温柔、疲惫或压迫，也不能只写音量语速参数；要写成可执行的声音表演。

人物情绪开场必须把表情写成可生成的肌肉路径。不要只写 `笑一下 / 清冷微笑 / 伤心 / 生气 / 不屑`，要写眼神先怎样扫过镜头，眼睑、眉峰、单侧嘴角、鼻翼、下巴、呼吸和停顿怎样变化，笑意是出现、压住、扩大、冷掉还是断掉；肢体上肩颈、手指、包带、裙摆、腰间系带和头发如何跟着情绪轻动。短视频开场可以写不屑轻笑、单侧嘴角上扬、眼神停半拍、气口短促、说完后笑意收住，不能只写普通清冷微笑。

正式交付给老胡复制和手动调试的视频提示词，`【氛围与画质】` 默认使用中文专业表达。可以保留 `ARRI Alexa 35`、`35mm`、`LUT` 等行业专名，但肤色、妆效、色彩、光影、景深、质感、环境和稳定方式优先写成可读、可改的中文。正确标准不是固定一套冷白裸妆词，而是能看出哪一句控制角色自己的肤色与气色、哪一句控制妆效与纹理、哪一句控制光源和高光；林栀的冷白柔雾只作为当前案例。

当皮肤、妆效、曝光、服装首饰或环境运动承担情绪人像的主注意力时，要定义其正向目标状态，并与人物身份和主情绪一致；不要求每条人像把这些项目全部展开。肤色可以是冷、暖、中性、深肤、晒痕或带年龄纹理，妆效也可以是裸妆、年代妆、舞台妆或无妆。当前林栀可固定为冷白偏中性、清透裸妆和柔雾奶油肌，但该提示词资产只服务林栀，不是美女人像通用皮肤模板。

动作链必须先通过“身体 / 物件 / 镜头空间排练”检查。凡是涉及骑乘、上车、推车、抱起、摔倒、追逐、转身、穿门、端碗、打火、递物、拉扯等具体动作，正式提示词要写清主体从哪个方向接近、哪只手或脚先动、身体重量如何转移、道具如何承重或移动、镜头跟随谁、移动后谁还能不能被看见。不能出现前一句让角色坐在道具上，后一句又把道具写得像空物体独自滑走；不能让镜头是第一人称 POV，却同时看见该 POV 不可能看见的正脸、全身或身后动作。若一个动作在真实空间里无法排练出来，要么改动作，要么改机位，要么拆镜头。

移动类画面必须先做方向和边界排练。凡是滑行、奔跑、追逐、推车、摔倒、冲撞、车辆行驶、人物走位和镜头穿越，都要写清：从哪个具体起点出发，沿哪条路径移动，往哪个具体终点去，屏幕左 / 右 / 前 / 后有哪些稳定参照物，正常路径中哪些区域保持通畅，碰撞或摔倒发生在什么合理边界。障碍物不能为了制造冲突随机放在路中央；除非剧情明确是路中央障碍，否则生活场景里的碰撞应发生在墙脚、路边石、门槛、桌角、坡底边缘、水槽边、木料堆旁等空间边界。当前案例：E1-S4-C1 是小安从坡顶沿坡面中线滑向坡底缓冲区；E1-S4-C3 是试玩孩子控制不好，车头偏向画面左侧旧墙根，撞到坡底左侧贴墙压边石 / 墙脚，路中央保持通畅。

身体 / 物件 / 镜头空间排练还要检查“人会不会这样做”。涉及咳嗽、打喷嚏、呕吐、擦伤口、喂药、端热碗、点火、抱孩子、推老人、牵小孩、安慰、责备等生活动作时，不能只写动作名称，必须补出符合身体本能和人物关系的动作细节：避开谁、遮住哪里、哪只手支撑、哪只手拿物、声音被什么闷住、液体如何晃、风如何干扰、对方如何反应。当前案例：爷爷咳嗽不是“对着镜头咳”，而是咳意上来后偏头避开孩子，抬袖遮嘴，身体微微转开，咳声闷在袖口里。

操作型生活场景必须同时做“动作链排练”和“物料清单检查”。凡是写包汤圆、包饺子、做饭、缝衣服、修木车、点纸房、擦伤口、洗脸、端药、收拾行李等真实生活操作，不能只写一个动作名和一个道具名。必须先列出这个操作现实中需要哪些物料、工具、半成品、成品和工作区，再写人用哪只手拿、推、拖、扶、按、放、揉、包、擦，最后写这些动作产生的声音和画面结果。错误写法：`小板凳被拖到桌边，小安踩上去，看见糯米团和小碗`。正确写法：`两只小手扣住小板凳凳面两侧，把板凳拖到案桌前，凳腿擦地发出吱呀声；一只手先扶住桌沿，鞋尖踩上凳面，画面升高后看见桌面上的糯米粉盆、半揉好的糯米团、黑芝麻馅碗、硬币小碗、已搓好的白汤圆、撒粉区、旧瓷碗和奶奶正在包的手`。当前案例：E1-S6-C1 不能让小安用脚推板凳，也不能让包汤圆桌面空到只剩几粒东西；板凳要用手拖，桌面要像真实家庭元宵操作现场。

包裹、揉捏、缝合、修补、倒入、搅拌、点燃、清洗这类“材料会变形或状态会改变”的动作，还必须写出材料变形链。不能只写 `放进去`、`加一点馅`、`收口揉圆`、`包好`、`修好`、`点燃` 这类结果词。要写清动作前的形状、手如何接触、材料如何被压扁 / 抬起 / 折叠 / 粘合 / 变圆、哪些内部信息在什么时候由可见变成不可见，以及最终观众能看见什么。错误写法：`奶奶把硬币放进糯米皮里，加一点馅，慢慢收口揉圆`。正确写法：`奶奶左手托住压扁的糯米皮，右手把硬币平放进中间浅窝，再挑一小团黑芝麻馅盖住硬币反光；指腹把糯米皮近侧和远侧边缘往中间抬起，捏出几道小褶并压紧封口，封好后硬币和馅料都在内部不可见；两掌轻轻滚动三四下，褶皱变平，变成一颗完整光滑的白汤圆`。当前案例：E1-S6-C2 的重点不是“有硬币汤圆”这个概念，而是观众看见硬币怎样被包进去、怎样消失在汤圆内部、怎样变成无法分辨的一颗白汤圆。

工具劳动动作必须写清“工作面 + 工具 + 材料 + 受力 + 结果 + 收尾位置”。劈柴、锯木、刨木、钉钉、锤打、磨刀、铲土、挑水、洗衣、磨粮这类动作，不是一个动作名就能成立。必须先判断真实场景里人会站在哪里，材料放在哪个稳定工作面上，工具怎样握，力从哪个方向作用，材料会怎样卡住、裂开、掉屑、弯折、溅水或变形，失败时怎样重复，完成后成品和废料放到哪里。错误写法是 `父亲在柴堆上劈柴，斧头落下，劈好的柴码整齐`；正确写法是 `父亲站在院子边旧木墩前，一截短柴竖在木墩中央，双手握斧顺木纹劈下，斧刃卡在短柴里；他连木带斧抬起半尺，再把柴底往木墩上一磕，裂缝扩大，第二下分成两半，随后把两半柴放到木墩旁边柴垛上`。当前案例：E1-S6-C3 的父亲沉默不是靠“沉默”两个字表现，而是靠重复、费力、卡住又磕开的劈柴动作和不参与屋内笑闹的背影表现。

空间排练必须用具体场景锚点替代泛称。凡是写 `门口`，要明确是院门口、堂屋门口、卧房门口、车门口还是小卖部门口；凡是写 `屋里 / 院子 / 桌边 / 车内`，要说明摄影机所在位置、主体所在位置、可见锚点和光源方向。当前案例：E1-S3-C2 不能写成 `坐在门口小板凳`，应写成 `坐在老家堂屋门口屋檐下、门槛内侧的小板凳；画面两侧是旧木门框，下方是磨旧门槛，身后堂屋偏暗，前方院子有暖光`。

年代戏、回忆戏和家庭生活戏必须做“时代物件 / 通信条件检查”。道具不是只有外形功能，还会暴露时代、家庭条件、城乡差异和人物生活方式。凡是出现手机、电话手表、智能设备、电脑、汽车、厨房、电器、支付方式、照明、交通工具、医疗器械、校服和玩具等时代敏感物件，正式写入前必须判断三件事：故事年代是否已经存在这个物件；这个家庭阶层和地域是否合理拥有；人物在当下场景是否能合理接触到。若自家没有条件拥有，就寻找当时真实可达的公共场所或替代方式，例如 90 年代普通孩子给农村爷爷打电话，更适合写成小卖部 / 传达室 / 公用电话亭的老式座机、投币电话或柜台电话，而不是电话手表。

错误写法：在 90 年代童年回忆里写 `电话手表屏幕亮起`、`孩子用智能设备给爷爷打电话`。这会把画面直接拉到现代，破坏年代质感，也让家庭通信关系变轻。正确写法：`小卖部玻璃柜台边放着黑色老式座机，卷曲电话线垂在柜台上，旁边搪瓷小碟里有几枚硬币；两只小手抱住沉重听筒，电话里传来带电流失真的爷爷声音`。这样既符合年代，也让“孩子特意去告状”和“爷爷认真记住”更有情绪重量。

如果一条视频提示词内部包含多个镜头或连续动作，镜头节点数量仍由观看任务决定：长镜头服务连续时间、空间和情绪累积；少量切镜服务反应、揭示和景别递进；快闪蒙太奇服务时间压缩、并置信息、记忆碎片、危机倒计时和动作卡点。每增加一个镜头必须增加新的信息、情绪、空间关系、动作阶段、视觉证据或节奏压力；精确多切优先拆素材后期剪辑。正式模型正文不写内部时间戳，也不使用 `镜头01 / 镜头02` 标签；换行只用于提升可读性，后一段必须由前一段的动作、遮挡、视线、焦点、声音、光色峰值或运动方向自然触发。

当前镜头的局部光影只有在承担主情绪、主体塑形、动作可读性或连续性时才展开，并嵌入 `【画面内容】`，不单独列成必填字段。写入时要落到真实来源、方向、受光对象和可见结果；不承担职责时，用全段光线基线即可，不重复堆术语。

画面内容不写内部时间戳。总时长由平台参数控制；节奏通过镜头数量、动作数量、动作先后、切换触发、声音桥和停点表达。声音细节跟随产生它的动作或物体写，例如“冲击波撞入天穹时发出低沉轰鸣”“玉简展开时有清脆玉石声”。

正式提示词里的画面内容建议包含：

```text
开场以【景别 + 机位 + 运镜路径】建立主体状态、空间和注意力目标，动作与表演形成可见结果。
当【动作 / 遮挡 / 视线 / 焦点 / 声音 / 光色峰值 / 运动方向】出现时，摄影机沿【连续路径】进入新的景别和机位；新画面继承【人物姿势 / 道具状态 / 动作余势 / 声音】，继续动作因果，最终停在【结果画面】。
```

正式提示词正文禁止出现给作者看的字段，包括但不限于：

```text
分镜编号
所属场次
镜头任务
作者说明
本条是否独立完整
前一个镜头 / 下一个镜头
后期备注
生成前检查
回传字段
```

这些信息可以放在文件说明、分镜表、自检表和阶段记录里，但不能放进投喂给视频模型的代码块。

正式视频提示词必须严格使用 `02_共享资产库/01_模板库/视频模板/模板_视频提示词_基础设定氛围画面内容.md` 的字段结构。剧本、分镜表、流程判断、生成前检查和回传字段可以作为提示词外的评审材料，但不能混进正式视频提示词正文里。

也就是说，“视频提示词”这一段只能出现：

```text
【基础设定】
【氛围与画质】
【画面内容】
```

每条视频提示词本体必须独立放进一个 `text` 代码块，方便直接复制。镜头编号、所属场次、镜头任务、表情来源、时长预演、资产使用说明、生成前检查、回传字段和解释文字都放在代码块外；代码块内不要出现这些给作者或助手看的内容。

除非模板文件已经增加新字段，否则不要临时发明【前置判断】【负面约束】【生成前检查】【回传字段】【后期备注】等额外块放进正式提示词正文。需要表达生成边界时，优先写成 `风格核心`、`视觉基调`、`色彩与影调` 或 `画面内容` 里的正向结果和抽象质量边界；不把当前镜头不该出现的具体对象写进正式正文。需要衔接时，写进 `【画面内容】` 的片内转场动作，不写给剪辑师看的后期说明。

`【画面内容】` 要比全局设定更直接地承载本镜任务，但不按字段数量判断详细度。正式执行稿先写主体、变化和主情绪证据，再从环境运动、镜头路径、构图、光影、材质、表演、声音和转场中选择生成必需项与承重项；没有发生的内容不必补齐。真正的问题是镜头不可执行或情绪证据不足，不是字数短于前两部分。

情绪人像和开场钩子还要额外检查四件事：第一，关键发声是否在 `声音设定` 中写出本镜音色，不只依赖 `【音色参考@xx】`；第二，表情是否有眼神、眉峰、单侧嘴角、呼吸、停顿和笑意收放路径；第三，是否先用美妆 / 美容术语正向定义肤色、气色、底妆妆效、腮红、唇妆、眼妆和整体肤感，再用毛孔、微纹理、漫反射、次表面散射、胶片颗粒等渲染词补精度；第四，是否按镜头任务选择细节，表情主任务用脸侧发丝、耳坠、项链、吊坠、肩线、树影、海风和环境反光参与情绪，服装展示或全身动作镜头才用包带、腰间系带、裙摆、鞋尖和脚步，不让低位细节抢走脸部表演。

正式创作必须增加泛化弱词审稿。`小、轻、低、微微、一点、稍微、淡淡、有点、慢慢、柔和、自然、高级、舒服、压住、收紧` 这类词不是禁用词，但不能单独承担关键画面、声音、情绪、动作、审美或生成判断。AI 容易用这些词做语义适配：只要意思大概接近，就用一个安全宽词覆盖多个维度，结果是画面没有力量，情绪没有边界，声音没有态度，镜头没有具体可执行结果。写正式剧本、资产提示词、故事板、视频提示词、封面提示词和复盘结论时，凡是这些词影响读者感受或模型生成，都必须先问：它修饰的对象是什么；维度是大小、幅度、速度、音量、音区、亮度、饱和度、对比度、距离、力度、压力、权力关系还是情绪程度；观众能看见或听见什么结果；是否有更专业、更准确、更有立场的词可以替代或补足。

泛化弱词的正确处理不是简单删除，而是拆维度、补证据、换专业词。错误写法：`她轻轻笑了一下，声音有点低，光线很柔和。` 正确写法：`她右侧嘴角短促抬起，眼尾没有完全弯开，鼻息带出半声气笑；声音落到中低频，胸腔共鸣更重，句尾下坠；窗外蓝调冷光做主光，旧灯泡只在脸侧留一圈弱暖辅光。` 如果必须保留 `轻 / 低 / 小`，后面也要跟上可执行证据，例如 `轻微自然手持微抖` 要补成低频呼吸式晃动、主体边缘稳定、停点不漂移；`低饱和` 要补主色、辅助色、明度对比和环境反光；`小动作` 要补哪根手指碰哪里、几次、造成什么可见变化。

正式视频提示词没有项目统一字数目标和硬上限。默认不精简、不主动压缩，不以“平台可能限长”为理由预先删减；先以最高质量和最高有效信息密度写完整主体、空间、动作、表演、镜头、声音和前后因果。只有老胡明确反馈某个平台实际超限并要求精简某一条时，才另做该平台导出适配，并保留原始完整版。即使执行导出精简，也不得删掉道路边界、人物站位、攻击来源、运动路径、避让方向、接触点、受力结果、镜头承接和情绪表演。

高速物体和复杂调度必须通过空间闭环检查。凡是箭、子弹、暗器、飞刀、刀气、车辆、奔马或高速人物穿过画面，按当前镜头需要明确：场景坐标与通行净空、摄影机在主体哪一侧、主体屏幕运动方向、攻击来源、运动轨迹、与主体最近距离、主体感知时点、避让方向、物体最终出画 / 撞击位置、环境受力反馈、结束后主体与镜头状态。错误写法：`箭从侧面飞来，擦脸而过，钉进路旁竹身。` 正确写法：`道路中央保持连续净空，竹子只在边沟外生长；摄影机在马匹左侧平行跟拍，马由左向右；箭从右上背景射向左下前景，她的头和右肩向左下避开箭路，箭穿过她原来头部位置后从左下出画，画外左后方传来撞木声。` 撞击目标不承担剧情时，不强求它与人物同框。

空间闭环还要升级成 `多主体运动账本`。只要两个以上因果参与者同时运动、分离、追逐、承重、碰撞或改变相对位置，就分别记录：世界坐标起点、屏幕坐标起点、朝向、速度向量、加减速、景深层、触发、路径、外力、碰撞 / 避让、相对顺序、终点、出画方向、出画顺序，以及摄影机的位置、速度、轴线和是否越轴。共同运动体分离时先继承共同惯性；改变方向或速度必须有摩擦、碰撞、制动、转向、推进或地形依据。错误写法：`她翻身下马，马继续向前，她落地滑行。` 这没有说明两者分离后的相对顺序，跟拍时容易生成马倒退或人物超车。正确写法：`分离前人马共同由左向右疾驰；分离后马头始终朝右、马尾朝左，保持原步态继续到画面右缘；她从马鞍近摄影机一侧翻下，保留向右惯性，但脚与湿地摩擦使她迅速减速，始终落在马肩线后方；两者屏幕横向间距持续扩大，马先从右侧出画，摄影机以低于马速的速度跟随她且不越轴。`

对象路径正确还不等于人物动作成立。复杂人体动作使用 `人体姿势变换账本`：`起始姿势 / 朝向 → 原支撑点 → 解除约束 → 新承重点 → 肩胸骨盆与关节发力顺序 → 重心轨迹 → 旋转轴 / 方向 → 四肢与道具的净空路径 → 离支撑轮廓 → 首次接地点 → 缓冲卸力顺序 → 结束姿势 → 下一动作入口`。错误写法：`她双手一按，翻身下马，落地滑行。` 这仍可能生成普通跳下。正确写法：`双脚先退出马镫；左掌压前鞍桥、右掌压后鞍座，肘部短促屈曲承重，骨盆被双臂推离鞍座；右腿从马臀上方划弧越到左侧，双膝收拢避开鞍桥，胸口保持朝前，身体绕双手之间的支撑轴向左侧翻；右手先离鞍、左手最后推开，左脚外缘先触湿地，左膝屈曲后左髋、左前臂和左肩依次承接惯性，转入沿道路向右的低位滑行。` 不是所有动作都要逐关节拆解，只对姿势变化大、容易穿模、承担情绪爆点或生成风险高的动作使用完整账本。

镜头逻辑还必须同时通过三张账本。第一张是 `状态账本`：武器、道具、服装、门窗、车辆、伤口、光源等跨动作出现时，记录进入状态、触发、接触部位、操作路径、中间状态、结果状态和下一镜继承；关键状态 A 到 B 不能靠名词跳过。第二张是 `知觉账本`：客观事件先发生，人物只能依据当下可获得的声音、视野、余光、阴影、反射、气流、震动、触感或环境反馈作反应；人物不能先看见高速投射物的完整轨迹再躲。第三张是 `观众信息账本`：明确观众领先、同步还是落后于人物，并说明它制造焦虑、惊吓、误判还是反转；客观大全景用于校准空间，不能让全片退回上帝视角。

重大位移或遮挡切换后先恢复空间，再进入局部动作。至少重新证明主体在哪、攻击从哪一侧来、道路 / 地面边界怎样延伸、摄影机站在哪一侧；不能让一只手腕、一个暗器或一个接触点脱离场景突然出现。动作帅点按 `危险逼近 → 提前占位 → 短路径处理 → 接触瞬间清晰 → 结果高速离开 → 余势停成有力量的轮廓` 设计。所谓停帧不是让人物停下来摆拍，而是让拔刀完成、刀身改向、落地回收、衣摆与水花余势共同形成可被摄影机捕捉的决定性瞬间。

动作不是可以随意互换的通用连招。主要交战者先建立 `角色动作语法`：常用距离、起势线索、进入路线、主要攻防路径、借位方式、场景利用、回收节奏和能力边界。它用于生成符合身份的新动作，不是把角色锁死在几招里。例如高段实战刀客可以依靠错步、刀背浅角度改向、肩肘近身、借敌遮挡和借竹换高；压倒性宗师则以极小预动作、极短位移和巨大但精确的结果建立差距。群战按方位和层级连续接力，上一击造成的遮挡、失衡、空位或反作用力必须进入下一击，不让角色回到默认站姿重新开打。

动作观赏性和动作完整性要分别检查。完整性回答攻击从哪里来、身体怎样做、物体去了哪里；观赏性回答哪一瞬最能显示处境、能力与情绪，摄影机如何在不破坏连续速度的前提下让它可读。每段选一个主要决定性瞬间，必要时再选一个次级瞬间；其他动作负责把力量送进去或把余势带出去。特效、拖影、火花、水花、碎片和色彩只能证明速度、材质、接触与情绪，不能把主体轮廓和攻击线淹没。`主体与动作因果清楚` 的优先级高于 `光效数量多`。

错误写法：`她握住刀柄落地，下一镜已经横刀在手；她看见箭头后迅速躲开。` 这同时跳过刀从入鞘到出鞘的动作，也让人物使用了不可信的高速视觉信息。正确写法：`翻身落地时右掌压住刀鞘中段，护手与刀柄保持原位，刀刃完整入鞘；第一枚暗器发射机关声响起，左手固定鞘口，右手握柄，拇指顶开护手，横刀沿右腿外侧连续出鞘，拔刀弧线直接磕开暗器。右侧高坡先传来弓弦脆响，马耳先转，她随声源方向本能压低头肩；箭在她已经开始避让后才闯入画面。`

速度证据不能由 `高速、疾驰、迅速、突然` 独自承担。根据镜头目的选择近景反向掠过、中远景视差、衣料 / 马鬃 / 发丝受风、水花 / 尘土 / 落叶后抛、步频 / 蹄频、运动模糊方向、摄影机惯性与低频震动、声源远近变化等可见 / 可听证据。主体脸和关键动作仍要可读；高速投射物只在近身极短瞬间保留方向性轮廓，升格和子弹时间只在情绪或关键信息需要时使用。

超常题材还要建立两层真实。第一层是 `能力基线真实`：先定义普通人、训练者、顶级高手和超常存在分别能感知、预判、移动、发力和控制到什么程度。写实不能把顶级高手写成普通人的反应速度；高手可以更早读取预动作、声源、坐骑反应、气流和环境微变，但每次提前行动仍要有可感知来源。第二层是 `超常物理真实`：刀气、剑气、冲击波、念力、激光或能量场按来源、形成、传播、先行征兆、接触、材质分层响应、声场 / 摄影机响应和永久结果形成闭环。

复杂破坏另用 `事件传播账本`，不要把结果词当过程：`来源 / 发射方向 → 命中点 / 入射角 → 力量传播方向 → 首个承力结构 → 材料失效顺序 → 碎片分组、速度锥和落点 → 二次碰撞 / 连锁破坏 → 火焰、烟尘、压力波与遮挡变化 → 声音到达 / 回响 → 摄影机响应 → 永久终态`。炮弹命中高楼时，玻璃外抛、外墙剥落、混凝土崩裂、钢筋拉扯、楼板失稳、主体倾斜和坍塌方向不能混成一团；星际战斗中的装甲、舱体、推进器、碎片和失压物质也按同一因果方法处理。只细写会参与因果、连续性或观众理解的对象，不为“周全”平均描写所有装饰物。

能力基线还必须区分角色等级。高段实战者的优势是更早获得线索、更短的有效路径、更稳的重心和更少的无效动作，但仍要通过移动、格挡、借力、换位和承受风险解决攻击；压倒性宗师才有极少动作、巨大结果和近乎绝对的控制精度。不能因为角色“眼观六路、耳听八方”就让她不移动、不受压或凭空弹飞所有暗器。

错误写法：`白衣高手发出巨大金色刀气，女侠震惊，地面爆炸。` 这只有光效和结果，没有真实世界承接。正确写法：`拇指把刀推出一寸，刀口附近空气先出现窄幅折射，竹叶背向刃线压弯，雨珠被推出弧形空带；低频压力先压到女侠脸侧，她依据风压向左后收肩，淡金刃线随后从右脸外一寸掠过；刃线落在三米外湿土，表层积水先被推开，泥层沿接触线剥离，碎石迟半拍崩出，埋在土中的竹根出现平整切面，裂缝向两端扩展，最后才传回低沉轰响和碎石回落声。` 超常能力保持巨大，但每一层都能被看见、听见和感到。

正式视频提示词初稿完成后，必须走一次 `laohu_vibe_creating_prompt`。它调用 `vibe-creating-prompt` 外部原文 skill 的能力，把机械执行语言、低价值技术噪声和松散描述提纯成更利于模型抓住画面中心、情绪方向和体验连续性的表达；优化后的最终正文仍只能是 `【基础设定】`、`【氛围与画质】`、`【画面内容】` 三块。

## 六、人物表情前置判断

分镜宏观表阶段必须判断：

```text
表情细化：是 / 否
表情功能：核心任务 / 辅助状态 / 不需要
表情占用时长：
表演来源：laohu_video_prompt / 画面内容短句 / 无
```

只要有人物台词、沉默、反应、眼神、微表情、情绪转折或关系变化，就必须判断是否需要表情细化。

表情是核心任务时，先设计人物表演，再写画面内容。不要把动作、运镜和奇观写满后临时塞表情。

情绪表演型视频必须按主情绪颗粒度拆分。单条正式视频提示词只承担一个主情绪，最多带一个过渡情绪；不要把心动、沉浸、失落、怀疑、争吵、崩溃等多个阶段塞进同一条提示词。每条提示词在提示词外先判断：

```text
主情绪：
起始状态：
触发语音 / 事件：
表情变化：
身体反应：
结束状态：
下一条情绪准备：
```

主情绪可以在本条里形成过程，例如从强撑理解滑向伤心、从不可置信滑向委屈愤怒；但过渡情绪只负责把人物推向下一条，不抢走本条中心。当前案例：《30秒钟带你体验谈恋爱》不能把“心动、热恋、怀疑、争吵、决裂”写进同一条视频提示词；应按心动、雀跃、沉浸、失落、自我安慰、怀疑、委屈愤怒、被抽空等情绪单元拆分。

情绪高潮必须有可感知的峰值证据，但不固定等于落泪、崩溃或动作放大。辱骂、决裂、背叛、死亡和真相揭开可以表现为泪落、呼吸卡断、身体松掉，也可以表现为异常平静、动作突然停止、声音变空或关系距离不可逆地拉开；关键是证据与人物性格、前期积累和主情绪一致。当前《30秒钟带你体验谈恋爱》案例可选择落泪，但不能升级成所有终局高潮的固定表演模板。

对镜头情绪表演必须先判断镜头是否是关系里的对话对象。凡是脑内 VO、画外音、导演提示、观众视角、镜头前方的人对角色说话，或作品核心是让观众通过演员脸部感受内心，镜头就不只是旁观摄影机，而是对手戏位置。

执行规则：

- 人物默认正面对镜头、眼线指向镜头、用脸回应镜头。
- 男声 / 女声 VO 可以写成从镜头位置、镜头前方或镜头中心进入脑海。
- 故事板线框构图要画 `视线箭头指向镜头`、`眼线锁镜头`、`视线从下方回到镜头`。
- 风景、海面、天空、城市灯光只做留白、反差、光影和情绪衬托，不能成为主要表演对象。
- 低头、短暂偏开、失焦、背过脸可以出现，但必须是强撑、躲避、崩溃或遮掩情绪的明确动作；如果不是最终躲开镜头，动作后要让视线回到镜头。

错误写法：`她扫向声音方向`、`她抬头看海`、`她看向天空和树冠想象未来`、`眼神抬向声音来的方向`。这些写法会让模型把画外音当成空间里的发声点，让人物把脸转走，观众看不到表情。

正确写法：`男声从镜头前方贴进她脑海，她慢慢把脸转回镜头，盯住镜头前方做安全评估`；`她在镜头上短暂失焦，又马上重新盯住镜头`；`她正对镜头笑到眼里发亮，天空留白只在身后承托未来想象`。当前案例：《30秒钟带你体验谈恋爱》正片里男声像从镜头位置进入林栀脑海，林栀应对着镜头完成防备、心动、失落、怀疑和争吵反应。

初识搭话和陌生直球表白不能直接写成震惊心动。真实关系里的第一反应通常先经过安全评估和边界判断：眼神快速扫对方、眉心轻皱、嘴唇闭紧、身体微微后撤、手指收住、肩线有防备；确认对方没有明显威胁后，才出现困惑、好奇、觉得荒唐、忍笑和一点点松动。只有经过连续稳定关注、日常问候、尊重边界或可靠回应之后，表情才逐步进入真正的心动、雀跃和投入。当前案例：林栀第一次听见 `你好可爱呀，可不可以跟我在一起？`，不应瞳孔放大像被击中，而应先警觉、防备、判断，结尾只留下很小的好奇。

## 七、首轮测试交付

首轮测试只保留当前阶段文件。必须完整可复制，不让老胡自己拼前两部分。

首轮创作不能把所有过程内容倾倒进聊天，但正式进入视频提示词前仍要按阶段形成产物并完成内部质量门：

```text
第一步：写整个内容剧本输出文件，锁定硬约束与观众体验目标。
第二步：写完整分镜表格输出文件，完成导演镜头构思、情绪和代入检查。
第三步：写第一个分镜视频提示词展示文件，作为内部写法与可生成性校准。
第四步：校准通过后写所有分镜提示词结果输出文件，给具体文件链接。
```

阶段门默认是内部质量检查，不是要求老胡逐步批准创意。只要老胡已经给出最终目标，助手应在不违背硬约束的前提下自主完成故事、剧本、资产规划、导演镜头构思、分镜和提示词；每阶段仍要形成正式产物和自检记录，但不为普通创意选择停下来询问。只有老胡明确要求逐阶段共同创作、下一步涉及真实高成本生成 / 发布，或出现外部成本、法律安全和互斥核心定位风险时，才设置人工确认门。

老胡明确要求直接全部输出时，质量标准不下降。直接全部输出 = 一次性完成所有阶段的正式产物；不是把所有阶段压成概要。尤其是全分镜视频提示词，必须保持单独生成时应有的详细度和信息密度。若总文件过长，也应优先保留完整正式提示词，压缩提示词外说明，而不是压缩投喂给模型的画面内容。

最终首轮直用文件应包含：

```text
流程判断
单场次剧本
分镜概览表
完整视频提示词
生成后回传字段
```

其中“完整视频提示词”必须是严格模板格式，不要把剧本、分镜说明、流程判断和提示词揉成一段不伦不类的混合稿。
