# 多模型 AI 视频提示词通用规范

> 用途：在 Seedance 2、即梦、可灵、Runway、Sora、Veo 等模型之间迁移提示词时，保留共同有效的制作逻辑。

## 一、通用结构

```text
作品目标
→ 输入素材
→ 基础设定
→ 氛围与画质
→ 镜头内容
→ 声音与节奏
→ 禁止项
→ 生成后诊断
```

## 二、不同模型都需要写清的字段

| 字段 | 作用 |
|---|---|
| 作品用途 | 决定是封面、短剧、MV、广告、电影片段还是测试镜头 |
| 时长 | 决定动作密度；必须是确定值，不写 `8-10 秒` 这类范围 |
| 画幅 | 决定构图和留白 |
| 主体 | 决定模型优先生成对象 |
| 场景 | 决定空间和光影 |
| 动作 | 决定时间轴 |
| 景别 | 决定观看距离 |
| 运镜 | 决定镜头运动 |
| 风格 | 决定画面审美 |
| 声音 | 决定音画关系 |
| 禁止项 | 降低跑偏概率 |

## 三、迁移规则

### 从文字生成视频转到图生视频

文字生成视频重点写：

```text
角色是谁、在哪里、做什么、镜头怎么拍。
```

图生视频还要补：

```text
参考图负责锁定：人物 / 服装 / 场景 / 构图 / 风格。
不要改变：参考图中必须保持的部分。
允许变化：动作、表情、镜头运动、环境细节。
```

### 从单镜头转到多镜头

单镜头重点写：

```text
一个动作从开始到结束。
```

多镜头必须增加：

```text
全局连续性设定。
每个镜头的独立任务。
镜头之间的入点、出点和后期衔接。
使用 E1-S1-C1 编号追踪集 / 场 / 镜头。
每个镜头总时长写确定值。
```

### 从无声画面转到音画同步

无声画面重点写：

```text
视觉动作和节奏。
```

音画同步必须增加：

```text
声音来源。
声音出现时间。
声音和动作的对应关系。
是否需要保留同期声或配乐。
```

## 四、提示词压缩原则

当模型提示词长度有限时，优先保留：

1. 主体。
2. 主要动作。
3. 场景。
4. 景别。
5. 运镜。
6. 关键风格。
7. 禁止项。

优先删掉：

- 空泛形容词。
- 重复风格词。
- 不参与画面的背景设定。
- 不能被看见或听见的心理描写。

## 五、模型适配记录格式

每次跨模型测试后，新增记录：

```text
模型：
任务类型：T2V / I2V / 多参考图 / 音频参考
原提示词：
改写提示词：
生成结果：
模型优势：
模型限制：
下次写法调整：
是否更新模板：
```
