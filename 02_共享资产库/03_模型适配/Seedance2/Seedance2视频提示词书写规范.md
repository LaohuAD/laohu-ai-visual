# Seedance 2 视频提示词书写规范

本文件定义老胡 AI 视觉项目在 Seedance 2 上的默认生产剖面。它不是模型能力上限，也不把单次经验写成官方硬限制；它负责在同等条件下减少提示词噪声，把有限注意力留给主体、表演、镜头和画面结果。

## 1. 官方能力与项目默认

已确认的官方能力：Seedance 2 支持文字、图片、音频和视频多模态输入，能够参考表演、光影和运镜；接口把 `duration`、`resolution`、`ratio`、`generate_audio` 作为结构化生成参数。官方示例既有短提示词，也有长提示词、镜头编号、自然语言长镜头和少量时间段写法。

项目默认生产方式：

```text
生成 / 首测分辨率：720p。
成片清晰度：镜头确认后再做后期放大和统一锐化。
声音：生成对白、动作声、衣料声、道具声和环境声；默认不生成 BGM。
时长：在平台参数中设置总时长；提示词正文不再逐秒分配。
镜头组织：内部先确定镜头节点，正式正文改写为连续镜头叙事；不显示镜头编号，每次切换由动作、遮挡、视线、焦点、声音、光色峰值或运动方向触发。
参考输入：只上传本条真正有用的主体、场景、首帧、动作或音色参考。
```

720p 和无 BGM 是项目生产默认，不是 Seedance 2 的能力限制。用户明确需要模型内音乐、原生音乐表演或更高分辨率直出时，可以切换，但要先说明它对多片段剪辑、生成稳定性和成本的影响。

## 2. 三段式结构

三段式继续保留，因为它分别解决三个不同问题：模型要参考什么、全段总体像什么、摄影机具体拍什么。新的权重分配是“基础设定最短、氛围画质简短、画面内容最重”。

```text
【基础设定】
【@A1 人物】
【@S1 场景】
【@C1 色卡】
【@V1 动作 / 音色 / 首帧参考】（只在本条实际使用时填写）
声音：只生成对白、同期动作音效和环境声，不生成 BGM。

【氛围与画质】
720p 生成；【一句主风格母体】；【一句全局摄影 / 介质规则】；【一句跨全部镜头成立的色彩原则】。

【画面内容】
以【景别 + 机位 + 主注意力目标】建立开场主体、空间和状态。主体动作与表演形成可见结果；摄影机按【物理路径、方向、速度、稳定方式】运动，写清主体、背景、地平线和构图怎样变化；焦点、环境、光色、速度与同期声共同放大该变化。

当【动作 / 遮挡 / 视线 / 焦点 / 声音 / 光色峰值 / 运动方向】出现时，它直接触发画面切换；摄影机沿【连续路径】进入【新景别、机位和注意力目标】，新画面继承【姿势、道具状态、动作余势、空间方向和声场】。继续动作因果、摄影机物理路径和屏幕变化、局部光影色彩、材质、环境、速度与声音，结尾停在【可剪辑 / 可截图画面】。
```

## 3. 各段职责

### 基础设定

只列本条实际投喂或调用的素材，不复述完整资产说明书。人物、场景、道具、色卡、首帧、动作视频和音色参考都属于这一段；没有实际上传或绑定的资产，不假装模型已经知道。

引用资产后，只在两种情况下补一句短约束：

1. 参考图存在容易被误继承的状态，例如人物资产是半身图，而本镜需要全身动作。
2. 本镜需要改变资产的临时状态，例如衣服被雨打湿、剑出鞘、人物刚哭过。

### 氛围与画质

只写跨本条全部镜头都成立的宏观规则，通常 1-3 句：

- 主风格母体与真实程度。
- 全局摄影介质、画幅、颗粒或稳定度。
- 全段统一的色彩关系和肤色基线。

局部对象、具体光源、墙面颜色、某件衣服的 HEX、雾从哪里来、树影如何移动、某个镜头用 85mm 还是 35mm，都不在这里展开；它们跟随对应镜头写进 `【画面内容】`。如果删除一句话后仍不影响所有镜头，它就不属于这一段。

### 画面内容

这是正式提示词的主体。每个镜头按以下顺序写：

```text
镜头编号
+ 景别
+ 机位角度
+ 运镜起点、路径、速度和落点
+ 主体动作 / 表情 / 台词
+ 动作造成的可见物理结果
+ 本镜光源方向、软硬、色温和阴影变化
+ 本镜色卡 HEX 对象映射
+ 材质、前中后景和环境运动
+ 同期声
+ 切换触发
+ 结尾停帧
```

不要把它写成字段堆栈。要用导演能预演、演员能表演、摄影能执行的自然语言，把镜头运动和画面事件写在同一条因果链里。

### 画面内容四核

每个镜头内部先完成 `主体与注意力目标 + 动作与表演 + 效果系统 + 节奏与时长`。主体决定观众看哪里；动作写台词、表情、呼吸、肢体、交互和反应；效果按需要选择运镜、稳定、焦点、环境、光色、速度、声音和转场；节奏为识别、动作完成、情绪建立、效果展开和停点分配时间。

运镜术语必须具象化为 `观看意图 → 摄影机物理路径 → 屏幕变化 → 情绪倾向 → 停点`。推、拉、摇、移、横滚、FPV、机械臂和希区柯克变焦只提供方向；正文还要写机身是否位移、镜头是否原地转动、方向轨迹、速度稳定度、主体大小与位置、背景透视或地平线变化，以及最终构图。运镜的情绪由当前主体、起终景别、速度、焦点、声音和上下文决定，不按固定字典套用。

### 图生视频、文生视频与资产输入

Seedance 2 的描述预算跟随实际输入变化：

```text
图生视频：输入图片负责首帧身份、外观、基础构图和已有场景；提示词重点写从这张图开始怎样动，焦点、运镜、环境、光色、速度、声音和停点怎样变化。

文生视频：文字同时负责首帧建构和时间变化；没有资产支撑的主体、场景、时间、风格、构图、必要外观和材质先写足，再写动作、效果与节奏。

资产输入：基础设定引用本条实际上传的人物 / 场景 / 道具 / 首帧；画面内容不重复整份资产外观，只重申本镜的临时状态、受光、受力、遮挡、交互和承重细节。没有实际输入的元素仍按文生视频粒度写清。
```

图片加图生视频提示词共同完成“初始画面 + 时间变化”。资产越完整，文字越应把注意力留给动作和效果；资产越少，文字越要补足模型看不见的首帧信息。

### 首尾帧生成模式

当平台当前版本支持双端参考时，在同一次请求中上传 `【首帧参考@图1】` 和 `【尾帧参考@图2】`。这不同于 A 条视频尾帧作为 B 条视频首帧的跨片段拼接：首尾帧模式要求模型在两个端点之间生成中间过程。

先做端点兼容性分析：比较主体身份、比例、位置、朝向、景别、透视、光线、色彩、场景结构和关键道具；提炼 `不变量、变化量、共同桥梁、最大断裂点`。基础设定只列双端参考和实际资产，画面内容用自然语言写 `首帧状态 → 触发 → 中间状态链 → 尾帧召回 → 减速收束 → 落入尾帧`，不新增第四段，不使用逐秒时间码。

首尾差异越大，越需要遮挡、过渡空间、材质或运动桥；首尾差异越小，越应减少特效，优先让动作、焦点、光色和摄影机路径自然连接。尾帧元素必须提前召回，不能在最后一瞬硬跳。双端图片是硬目标和验收基准，但实际生成仍需检查端点漂移与落帧精度。

多参考输入的数量、格式、分辨率和可用类型属于模型能力和版本参数，不写成跨版本永久数字。执行前以当前平台界面或官方文档为准；只上传本条真正承重的参考，避免参考之间互相争夺权重。

## 4. 镜头语言替代时间戳

正式 Seedance 2 提示词默认不写 `[0-3秒]`、`第0秒`、`动作段1（0-1.5秒）`。总时长在平台参数设置；正文通过镜头数量、动作数量、动作先后、转场触发和停点控制节奏。

推荐写法：

```text
脸部特写开场，平视略低机位，85mm 人像镜头缓慢绕到人物右前侧。她屏住呼吸直视镜头，额角汗珠沿颧骨滑下；冷白侧光擦亮汗珠和眼神高光，背景压成低饱和深灰，摄影机在她瞳孔收紧时停稳。

汗珠落出下巴并掠过画面下缘，这个动作直接触发硬切；低机位膝上中景从同一方向的剑鞘横移到人物正面，她继承刚才绷紧的呼吸后撤半步、拇指顶开剑格，右手顺势抽剑。剑身带出一道受控冷光，衣摆被动作气流向画面左侧掀起，金属摩擦声与落脚声同时出现；剑尖指向镜头外侧后停成海报帧。
```

只有平台功能、外部音频同步或明确测试证明必须依赖时间位置时，才在平台参数或后期表中记录时间，不把内部时间码重新塞回模型正文。

### 4.1 镜头数量由观看任务决定

镜头节点数量由这段视频需要观众看见、理解和感受到的视觉步骤决定，不设两镜头上限。编号只保留在分镜表和预演板里；正式 Seedance 正文把节点改写成连续观看过程，切换不能只写“切到”，必须说明前一画面用什么桥梁触发、摄影机怎样变化以及新画面继承什么。

```text
连续长镜头：需要保持真实时间、空间连续、动作完整、压迫感或情绪累积时，使用 1 个镜头。
少量切镜：需要建立主体、补充反应、揭示证据、完成正反关系或景别递进时，使用若干镜头。
快闪蒙太奇：需要压缩时间、并置信息、制造记忆碎片、危机倒计时、动作爆点或卡点冲击时，可以使用更多短镜头。
```

镜头数量不能机械追求多或少。每增加一个镜头，都必须带来新的信息、情绪、空间关系、动作阶段、视觉证据或节奏压力；只换角度却没有新增观看价值的镜头应合并。

还要区分两种生产方式：

1. `单条 Seedance 内部多镜头`：适合镜头之间关系简单、允许模型自行分配持续时间、少量偏差仍可接受的段落。
2. `多条素材后期蒙太奇`：适合镜头很多、切点必须精确、每个画面都重要、人物 / 道具 / 构图需要逐镜控制的段落。分别生成再剪辑，通常比把大量镜头塞进一条 15 秒请求更稳定。

判断原则：如果少一个镜头，观众会漏掉必要信息或情绪台阶，就保留；如果某个镜头必须精确到构图和切点，就优先独立生成；如果镜头只是重复前一个意思，就删除。

## 5. 色卡落点

色卡引用写进 `【基础设定】`，宏观色彩原则留在 `【氛围与画质】`，逐对象 HEX 映射写进对应镜头。颜色必须落在视频里真实出现的对象上。

```text
【基础设定】
【@C1 月下庭院色卡】

【氛围与画质】
低饱和冷月古风写实电影色彩，人物肤色保持中性通透，暗部保留青灰层次，全段高饱和色只作为极小面积金属反光。

【画面内容】
月光主光调用 #CAD5DE 擦过脸侧和剑脊；黑衣外层保持 #171A1D，内衬压在 #343A40；肤色稳定在 #E8C8B5 附近，发色为 #171310；湿石板用 #4B5458 承接冷反光，远处薄雾用 #A7B4BC 降低饱和度，暗部落在 #101417。当人物视线带动摄影机进入新空间时，再跟随新出现对象写对应 HEX。
```

这样做不是减少色彩控制，而是让每个颜色和当前镜头里的具体物体、光线和空间职责绑定。

## 6. 镜头预演板

项目里的低成本故事板改称 `镜头预演板` 或 `分镜预演图`。它主要给导演、作者和生成操作者看，用图片先确认：

- 构图和视觉重心。
- 景别、机位和人物比例。
- 视线、动作方向和空间关系。
- 镜头切换、遮挡点和首尾停点。

镜头预演板默认使用黑白 / 灰阶低保真构图骨架，不锁真实人物脸、服装颜色、最终材质、最终光影和完整电影美术。它不默认上传给 Seedance 2，也不默认写入 `【基础设定】`。

需要模型参考构图时，优先从预演结果生成或挑选一张干净的首帧 / 构图参考图：无表格、无箭头、无文字标注、无多格拼图。只有实际测试证明某张预演图能提高当前镜头稳定性时，才把它作为参考输入，并降低它对最终美术的约束权重。

一体化视频执行单仍可以把 `【镜头预演板提示词】` 和 `【Seedance 2 视频生成提示词】` 放在同一个 `VID` 下，减少文件切换；但前者给图片模型和人工审片，后者才给视频模型。老胡明确只要视频提示词时，不强制生成预演板。

## 7. 声音与剪辑

默认声音策略：

```text
保留：对白、呼吸、脚步、衣料、兵器、道具、环境和空间混响。
音乐：由整片剪辑阶段统一加入。
```

多条 4-15 秒素材要剪成几分钟作品时，模型分别生成 BGM 会造成调性、节拍、响度和段落结构无法连续。无 BGM 不是审美禁令，而是把整片音乐控制权留给剪辑阶段。

## 8. 信息完整与按需导出

正式提示词先追求生成所需信息完整和最高有效信息密度。项目不设置统一字数目标和硬上限，默认不精简、不主动压缩；只有老胡明确反馈 Seedance 当前入口实际超限并要求精简某一条时，才另做导出适配，原始完整版继续保留。

只有老胡已经明确反馈当前入口实际超限并要求精简这一条时，导出适配才按以下优先级保护信息：

```text
镜头动作与表演
> 景别、机位、运镜和切换
> 动作因果与空间关系
> 本镜光影、色彩和声音
> 实际引用资产
> 全局风格修饰词和器材名
```

删除重复资产外观、同义风格词、作者解释、观众意图、逐秒时间码和不参与本镜的对象。不得删除道路边界、人物站位、攻击来源、运动路径、避让方向、接触点、受力结果、镜头承接和情绪表演。提示词短不是目标；空间、动作与因果可执行，每句话都能改变生成结果，才是目标。

投射物与高速运动额外检查：先锁定道路 / 坡面 / 边沟等空间边界和通行净空，再写摄影机侧别、主体屏幕方向、攻击来源、运动轨迹、最近距离、人物感知与避让方向、出画 / 撞击结果和环境反馈。撞击目标不承担剧情时，不强求与人物同框；让物体出画后用画外声或边缘反馈完成空间延伸，避免模型把竹子、树、墙等落点搬到人物面前。

多主体运动不能只分别写 `向前`。在投喂正文前，先锁每个因果参与者的世界 / 屏幕起点、朝向、速度与加减速、景深层、外力、相对前后顺序、终点和出画顺序，再单列摄影机速度与轴线。正文优先给 Seedance 可见的正向屏幕约束：对象哪一端朝向哪边、从画面哪里移到哪里、谁始终领先、间距扩大还是缩小、谁先出画。跟随镜头中对象相对后移不代表世界坐标反向；没有可见外力时，不生成倒退、超越、急停或瞬移。

Seedance 对动作名称的理解通常会回归常见姿势，因此大幅变姿要写可见相位。`翻身下马`至少展开为脱镫、手掌承重、骨盆离鞍、跨鞍腿越过马背、肩胸骨盆绕支撑轴转向、双手先后离鞍、首次落地与连续卸力；`凌空转身`要写起跳脚、摆臂 / 摆腿、旋转轴、收腿与展开、落地朝向；`摔倒`要写失衡来源、先接触部位、关节折叠与最终受力面。只保留对轮廓、物理和情绪承重的相位，不把提示词写成无差别人体解剖表。

复杂动作还要先锁状态与知觉。跨镜头道具按 `进入状态 → 触发 → 接触与操作 → 中间状态 → 结果状态` 展开，特别区分武器完整入鞘、部分出鞘、完全出鞘、回鞘和脱手。人物只能使用当前可获得的声音、余光、反射、气流、震动和触感作判断；高速投射物默认先由发射声、环境异动或攻击者预动作触发人物反射，再进入观众视野。

Seedance 中的速度要落到相对运动和材料反馈。奔马写近景掠过与远景视差、马鬃衣摆风压、水花后抛、蹄频、摄影机惯性；箭矢写短促发射声、方向性模糊、近身极短轮廓和画外撞击。只有关键信息确实需要时才使用升格或速度渐变。

写实高武、玄幻和科幻镜头要同时保持能力等级与现实反馈。先定义角色能比普通人提前读取哪些预动作、声音、气流和环境变化，再写超常能力如何从发力形成、沿什么介质传播、如何提前影响雨珠 / 雾气 / 竹叶 / 衣料、在哪里接触、怎样分层破坏湿土 / 石块 / 竹根 / 建筑，以及声场和摄影机如何承受冲击。Seedance 正文用这些可见 / 可听结果建立真实感，不用泛化的 `炫酷能量、巨大金光、震撼爆炸` 代替。

动作角色不能只靠服装和武器区分，还要建立角色动作语法：能力等级、距离偏好、起势线索、惯用攻击几何、防守 / 借位、场景利用和回收节奏。连续群战中，每名攻击者从已建立方位完成预动作并进入攻击线，上一招造成的遮挡、失衡、空位、掉落物或反作用力直接成为下一招条件。Seedance 对平均连招和模糊多人围攻容易回归排队攻击，因此必须把攻击者的进入顺序和空间关系写成可见事件。

动作完整后再设计观赏性：每段选择一个主决定性瞬间，让摄影机在攻击线、人物轮廓和结果证据同时成立时短暂停止位移或稳定焦点，画内投射物、受力身体、水花、衣摆和碎片继续高速运动。不要把动作观赏性统一写成慢动作、长定格、Pose 或满屏光效；主体可读性和因果优先于特效密度。压迫、关系和情绪段的决定性瞬间可以是最小动作或控制破裂，不强制武打停帧。

爆炸、楼体坍塌、炮击、飞船受击等复杂事件按传播链写：命中点与入射角先确定，力量沿结构和介质传播；玻璃、金属、混凝土、钢筋、土石、舱体或液体按各自材料方式失效；碎片按大小与速度形成有方向的飞散锥并可能二次撞击；随后才写烟尘、火焰、压力波、声场、摄影机和永久残局。Seedance 不会替作者自动补齐这些因果，结果词越大，越需要把决定画面真实性的中间过程写清。

## 9. 生成前检查

```text
1. 基础设定是否只调用本条真正使用的素材？
2. 氛围与画质是否只剩跨全部镜头成立的宏观规则？
3. 内部镜头节点数量是否由观看任务决定；正式画面内容是否去掉镜头编号，并用动作、遮挡、视线、焦点、声音、光色峰值或运动方向连接每次切换，而不是按内部时间戳、固定数量或互不承接的分段组织？
4. 每增加一个镜头，是否带来了新的信息、情绪、空间、动作阶段、视觉证据或节奏压力？
5. 快闪蒙太奇是否判断过应在单条 Seedance 内完成，还是拆成多条素材后期剪辑？
6. 每镜是否先写清主情绪、主体状态 / 动作和可见结果，再选择承重项？不要求每镜同时填满景别、机位、运镜、光影、色彩、声音和停帧；但被选中的项必须具体可执行。
7. 色卡是否从抽象色号落到了人物、服装、场景、道具、雾气、暗部和高光？
8. 镜头预演板是否仅供人审，未被默认当作 Seedance 输入？
9. 是否只生成同期声和环境声，把 BGM 留给整片剪辑？
10. 是否使用 720p 做首测，并把总时长放在平台参数中？
11. 结尾是否停在能剪辑、能接续、能截图的一帧？
```

核心判断：Seedance 2 提示词不是文学小作文，也不是摄影参数清单。它是一份可执行的导演调度：参考素材负责一致性，宏观基线负责统一，镜头语言负责让故事和情绪真正发生。
