# Seedance 2 视频提示词书写规范

本文件定义老胡 AI 视觉项目在 Seedance 2 上的默认生产剖面。它不是模型能力上限，也不把单次经验写成官方硬限制；它负责在同等条件下减少提示词噪声，把有限注意力留给主体、表演、镜头和画面结果。

## 1. 官方能力与项目默认

已确认的官方能力：Seedance 2 支持文字、图片、音频和视频多模态输入，能够参考表演、光影和运镜；接口把 `duration`、`resolution`、`ratio`、`generate_audio` 作为结构化生成参数。官方示例既有短提示词，也有长提示词、镜头编号、自然语言长镜头和少量时间段写法。

项目默认生产方式：

```text
生成 / 首测分辨率：720p。
成片清晰度：镜头确认后再做后期放大和统一锐化。
声音：声音轨仅由对白、动作声、衣料声、道具声和环境声组成；整片 BGM 留给剪辑阶段统一加入。
时长：在平台参数中设置总时长；提示词正文不再逐秒分配。
镜头组织：内部先确定镜头节点，正式正文用 `【镜头01｜景别｜机位 / 视角｜运镜 / 转场】` 连续编号并显示边界。摄影机真实连续移动时只保留一个头部并写完整路径；独立机位跳变时新开下一编号，把硬切、遮挡转场、甩镜转场或匹配剪辑写进最后一栏，随后重新锚定继承状态。编号不等于逐秒时间码。
参考输入：只上传本条真正有用的主体、场景、首帧、动作或音色参考。
```

720p 和无 BGM 是项目生产默认，不是 Seedance 2 的能力限制。用户明确需要模型内音乐、原生音乐表演或更高分辨率直出时，可以切换，但要先说明它对多片段剪辑、生成稳定性和成本的影响。

## 2. 三段式结构

三段式继续保留，因为它分别解决三个不同问题：模型要参考什么、开拍前场景和全段质感是什么、摄影机具体拍什么。新的权重分配是“基础设定最短、场景状态与氛围画质简短、画面内容最重”。

```text
【基础设定】
【@A1 人物】
【@S1 场景】
【@C1 色卡】
【@V1 动作 / 音色 / 首帧参考】（只在本条实际使用时填写）
声音：声音轨仅由对白、同期动作音效和环境声组成。
输出限制：【无字幕、无水印、保持输入身份与基本物理逻辑等少量抽象边界；按需填写】。

【场景状态与氛围画质】
开场时【固定空间边界、人物与道具初始位置、天气、人群活动和现有破坏已经处于什么状态】。720p 生成；【一句主风格母体】；【一句全局摄影 / 介质规则】；【一句跨全部镜头成立的色彩原则】。

【画面内容】
【镜头01｜景别｜机位 / 视角｜运镜 / 转场】
【主体、空间、动作、表演和可见结果】。
【VFX】【本镜额外视觉效果与结果】。（按需）
【环境音】【本镜持续声场】。（按需）
【动作音】【本镜同步动作声】。（按需）
【音乐 / 节拍】【本镜卡点关系】。（按需）
【台词】角色名（【按情绪职责控制表演密度】）：“【确认原文】”。（按需）
```

## 3. 各段职责

### 基础设定

只列本条实际投喂或调用的素材，不复述完整资产说明书。人物、场景、道具、色卡、首帧、动作视频和音色参考都属于这一段；没有实际上传或绑定的资产，不假装模型已经知道。

引用资产后，只在两种情况下补一句短约束：

1. 参考图存在容易被误继承的状态，例如人物资产是半身图，而本镜需要全身动作。
2. 本镜需要改变资产的临时状态，例如衣服被雨打湿、剑出鞘、人物刚哭过。

### 场景状态与氛围画质

先用一句写视频开始前已经成立的固定空间边界、人物与道具初始位置、天气、人群活动和现有破坏；再写跨本条全部镜头都成立的宏观规则，通常 1-3 句：

- 主风格母体与真实程度。
- 全局摄影介质、画幅、颗粒或稳定度。
- 全段统一的色彩关系和肤色基线。

开场以后才发生的角色入场、玻璃破碎、天气突变、环境破坏和局部光色变化不属于初始状态。局部对象、具体光源、墙面颜色、某件衣服的 HEX、雾从哪里来、树影如何移动、某个镜头用 85mm 还是 35mm，都不在这里展开；它们跟随对应镜头写进 `【画面内容】`。如果删除一句话后仍不影响所有镜头，它就不属于宏观基线。

### 画面内容

Seedance 正式正文按 `观众屏幕视点` 写，像对已经生成的视频逐帧复述。允许写画面内可见的对象与变化、成片可听的声音，以及观众能直接感到的景别、构图、屏幕方向、焦点、透视、地平线、遮挡和镜头运动结果；不直接写角色内心判断、作者因果解释、胜负总结或情绪结论。`她借对方拉力脱困` 要改成对手膝盖、链条张力、她的抬脚和穿出路径；`镜头传达镇定` 要改成眼神、呼吸、腕部幅度和焦点停点。

摄影设备路径只用于内部推导。正式正文使用 `镜头保持在交战轴线右侧`、`镜头沿右前方弧线靠近，人物由全身扩大到胸部以上，背景逐渐虚化` 等屏幕结果，不写 `机身沿轨道移动`。画外事件只有通过声音、光影、影子、反射、飞入物、遮挡变化或画内人物反应进入时才可描述。

这是正式提示词的主体。每个镜头按以下顺序写：

```text
【镜头01｜景别｜机位 / 视角｜运镜 / 转场】
+ 主体、空间、动作、表演和可见结果
+ 【VFX】额外视觉效果（按需）
+ 【环境音】持续声场关键词（按需）
+ 【动作音】同步动作声关键词（按需）
+ 【音乐 / 节拍】卡点关系（按需）
+ 【台词】角色名（表演）：“确认原文”（按需）
```

不要把画面描述写成无关系的字段堆栈。中文方头负责给模型明确镜头边界和局部通道，自然语言负责把镜头运动和事件写在同一因果链里。每个新的编号镜头头部代表新镜头，不再另写独立的 `切镜` 二字；同一镜头只保留一个头部并写完整连续路径。

VFX 放在画面描述后，只写额外视觉效果和可见结果，不重复主体动作。环境音写本镜持续空间，动作音写本镜同步接触或运动，两者逐镜落位。没有内容时省略，不写匿名 `[无]`。

台词使用 `[台词：角色名（表演）：“确认原文”]`。功能台词用简短准确的状态词；情绪承重台词展开眼神、面部、呼吸、视线、姿态、距离和发声变化中的必要证据。运镜同样按逐镜情绪职责选择：每个镜头头部只服务一个主要情绪功能，先回答摄影机站在谁的感知位置，再选距离、速度、方向、稳定性和焦点；不建立固定运镜情绪词典。

### 画面内容四核

每个镜头内部先完成 `主体与注意力目标 + 动作与表演 + 效果系统 + 节奏与时长`。主体决定观众看哪里；动作写台词、表情、呼吸、肢体、交互和反应；效果按需要选择运镜、稳定、焦点、环境、光色、速度、声音和转场；节奏为识别、动作完成、情绪建立、效果展开和停点分配时间。

运镜术语必须在内部具象化为 `观看意图 → 摄影机物理路径 → 屏幕变化 → 情绪倾向 → 停点`。推、拉、摇、移、横滚、FPV、机械臂和希区柯克变焦只提供方向；正式正文写镜头方向轨迹、速度稳定度、主体大小与位置、背景透视或地平线变化、焦点和最终构图。运镜的情绪由当前主体、起终景别、速度、焦点、声音和上下文决定，不按固定字典套用，也不用设备名替代屏幕结果。

### Seedance 2.5 控制语句预检

官方Seedance 2.5材料把参考职责具体到摄影、构图、空间关系、部件位置、结构和运动路径，同时仍提示物理合理性与多主体稳定存在边界。项目因此不把“多传几张参考图”当成控制完成；每张参考先分配职责，每条承重句再补齐 `对象 → 本次实际基准 / 起点 → 可变维度 → 方向、幅度或路径 → 可见 / 可听终态`。官方来源：`https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5`。

比较级、最高级和`继续 / 进一步`必须指向本次真正上传的参考或本镜已经写明的起点，同时给出当前请求独立可执行的绝对终态。人物身份参考只锁不允许漂移的眼鼻口耳拓扑、身高和骨架，脸颊软组织、表情、伤妆或本镜动作另列为可变项；场景参考只锁固定拓扑，临时站位、破坏、烟尘和光色另写当前状态。具体排除改成正向唯一结果，真实时间状态的`尚未 / 仍未`保留。

正式投喂前逐句问：删掉这句话会改变哪个像素、声音、动作相位或剪辑接口；句中弱词是否已经落到屏幕参照；参考图若失效，当前终态是否仍能仅靠文字执行。任何一问没有答案，先修正文再付费生成。

### 图生视频、文生视频与资产输入

Seedance 2 的描述预算跟随实际输入变化：

```text
图生视频：输入图片负责首帧身份、外观、基础构图和已有场景；提示词重点写从这张图开始怎样动，焦点、运镜、环境、光色、速度、声音和停点怎样变化。

文生视频：文字同时负责首帧建构和时间变化；没有资产支撑的主体、场景、时间、风格、构图、必要外观和材质先写足，再写动作、效果与节奏。

资产输入：基础设定引用本条实际上传的人物 / 场景 / 道具 / 首帧；画面内容不重复整份资产外观，只重申本镜的临时状态、受光、受力、遮挡、交互和承重细节。没有实际输入的元素仍按文生视频粒度写清。
```

图片加图生视频提示词共同完成“初始画面 + 时间变化”。资产越完整，文字越应把注意力留给动作和效果；资产越少，文字越要补足模型看不见的首帧信息。

### 首尾帧生成模式

当平台当前版本支持双端参考时，在同一次请求中上传 `【首帧参考@图1】` 和 `【尾帧参考@图2】`。这不同于 A 条视频尾帧作为 B 条视频首帧的跨片段拼接：首尾帧模式要求模型在两个端点之间生成中间过程。

先做端点兼容性分析：比较主体身份、比例、位置、朝向、景别、透视、光线、色彩、场景结构和关键道具；提炼 `不变量、变化量、共同桥梁、最大断裂点`。基础设定只列双端参考和实际资产，画面内容用自然语言写 `首帧状态 → 触发 → 中间状态链 → 尾帧召回 → 减速收束 → 落入尾帧`，不新增第四段，不使用逐秒时间码。

首尾差异越大，越需要遮挡、过渡空间、材质或运动桥；首尾差异越小，越应减少特效，优先让动作、焦点、光色和摄影机路径自然连接。尾帧元素必须提前召回，不能在最后一瞬硬跳。双端图片是硬目标和验收基准，但实际生成仍需检查端点漂移与落帧精度。

### 跨 VID 连续性参考

跨 `VID` 连续性与同次生成的首尾帧模式分开处理。平台当前版本若支持视频参考，直接连续的 B 条可以上传 `【视频参考@VID-A尾部连续性片段】`；若仅支持图片参考，或尾部动态本身不稳定，则使用 `【首帧参考@VID-A终帧】`。具体可上传数量、时长、文件规格和参考权重以当前平台界面为准，不在项目规则中写死。

直接连续只选择 A 最后一次切镜之后的单一机位，通常约 1-3 秒足以传递姿势、站位、屏幕方向、风雨 / 烟尘运动和摄影机惯性。若最后两秒同时包含硬切前后的两个镜头，不能整段引用；缩短到最后一个有效机位，必要时退化为终帧。同场景但时间、节拍或机位重启时只用终帧 / 构图参考；换场或空间关系重置时不引用 A 尾部。

B 的基础设定说明视频参考只负责继承本条需要的身份、场景状态、站位、观看侧和运动余势，不复演 A 已完成动作；场景状态重新写清人物、道具、天气和破坏；画面内容直接从 B 的第一项新变化开始。世界位置、持物、伤势与永久破坏默认硬继承；画面左右、景别、焦点和观看侧可在明确重新建立空间后改变。

多参考输入的数量、格式、分辨率和可用类型属于模型能力和版本参数，不写成跨版本永久数字。执行前以当前平台界面或官方文档为准；只上传本条真正承重的参考，避免参考之间互相争夺权重。

## 4. 镜头语言替代时间戳

正式 Seedance 2 提示词默认不写 `[0-3秒]`、`第0秒`、`动作段1（0-1.5秒）`。总时长在平台参数设置；正文通过镜头数量、动作数量、动作先后、转场触发和停点控制节奏。

推荐写法：

```text
脸部特写开场，平视略低机位，85mm 人像镜头缓慢绕到人物右前侧。她屏住呼吸直视镜头，额角汗珠沿颧骨滑下；冷白侧光擦亮汗珠和眼神高光，背景压成低饱和深灰，摄影机在她瞳孔收紧时停稳。

汗珠落出下巴并掠过画面下缘，这个动作直接触发硬切；低机位膝上中景从同一方向的剑鞘横移到人物正面，她继承刚才绷紧的呼吸后撤半步、拇指顶开剑格，右手顺势抽剑。剑身带出一道受控冷光，衣摆被动作气流向画面左侧掀起，金属摩擦声与落脚声同时出现；剑尖指向镜头外侧后停成海报帧。
```

只有平台功能、外部音频同步或明确测试证明必须依赖时间位置时，才在平台参数或后期表中记录时间，不把内部时间码重新塞回模型正文。

### 4.1 镜头数量由目标体验与动作覆盖共同决定

不要先用平均镜长推算镜头数。先判断本段要让观众经历的是不中断的身法与控制、高密度攻击与失衡，还是从空间建立到爆发再到结果沉淀的混合节奏，再选择连续长镜头、少量切镜或高强度多切。15 秒使用少量镜头或约 10 个镜头都可能成立，Seedance 的生成方案应服务画面结果，不服务数字区间。

```text
连续长镜头：保持真实时间、空间连续、完整身法、压迫感或情绪累积。
高强度多切：把同一连续动作拆为来路、接触、脚步、受力、反应和空间结果等不同观看相位，以切换速度传递激烈程度。
混合结构：先建立空间，中段快速覆盖爆发动作，结尾放长结果与情绪。
快闪蒙太奇：压缩时间、并置信息、制造记忆碎片、危机倒计时或卡点冲击；它不等于连续动作的多机位覆盖。
```

镜头数量不能机械追求多或少。动作因果在动作单元层闭合，不要求每个短镜头独自完成整条因果；每个镜头只需提供一个新的清楚证据。一个动作跨镜时，切后进入下一相位，并保持姿势、动作手、武器归属、屏幕方向、运动余势和声场连续。只有重复角度才合并，只有总时长无法完成核心结果才删减或拆条。编号只保留在分镜表和预演板里，正式正文用转场桥梁和状态继承连接。

还要区分两种生产方式：

1. `单条 Seedance 内部多镜头`：适合镜头之间关系简单、允许模型自行分配持续时间、少量偏差仍可接受的段落。
2. `多条素材后期蒙太奇`：适合镜头很多、切点必须精确、每个画面都重要、人物 / 道具 / 构图需要逐镜控制的段落。分别生成再剪辑，通常比把大量镜头塞进一条 15 秒请求更稳定。

判断原则：如果少一个镜头，观众会漏掉必要信息或情绪台阶，就保留；如果某个镜头必须精确到构图和切点，就优先独立生成；如果镜头只是重复前一个意思，就删除。

## 5. 色卡落点

色卡引用写进 `【基础设定】`，宏观色彩原则留在 `【场景状态与氛围画质】`，逐对象 HEX 映射写进对应镜头。颜色必须落在视频里真实出现的对象上。

```text
【基础设定】
【@C1 月下庭院色卡】

【场景状态与氛围画质】
低饱和冷月古风写实电影色彩，人物肤色保持中性通透，暗部保留青灰层次，全段高饱和色只作为极小面积金属反光。

【画面内容】
月光主光调用 #CAD5DE 擦过脸侧和剑脊；黑衣外层保持 #171A1D，内衬压在 #343A40；肤色稳定在 #E8C8B5 附近，发色为 #171310；湿石板用 #4B5458 承接冷反光，远处薄雾用 #A7B4BC 降低饱和度，暗部落在 #101417。当人物视线带动摄影机进入新空间时，再跟随新出现对象写对应 HEX。
```

这样做不是减少色彩控制，而是让每个颜色和当前镜头里的具体物体、光线和空间职责绑定。

## 6. 镜头预演板

项目里的低成本故事板改称 `镜头预演板` 或 `分镜预演图`。它主要给导演、作者和生成操作者看，用图片先确认：

- 构图和视觉重心。
- 景别、机位和人物比例。
- 视线、动作方向和空间关系。
- 镜头切换、遮挡点和首尾停点。

镜头预演板默认使用黑白 / 灰阶低保真构图骨架，不锁真实人物脸、服装颜色、最终材质、最终光影和完整电影美术。它不默认上传给 Seedance 2，也不默认写入 `【基础设定】`。

需要模型参考构图时，优先从预演结果生成或挑选一张干净的首帧 / 构图参考图：无表格、无箭头、无文字标注、无多格拼图。只有实际测试证明某张预演图能提高当前镜头稳定性时，才把它作为参考输入，并降低它对最终美术的约束权重。

一体化视频执行单仍可以把 `【镜头预演板提示词】` 和 `【Seedance 2 视频生成提示词】` 放在同一个 `VID` 下，减少文件切换；但前者给图片模型和人工审片，后者才给视频模型。老胡明确只要视频提示词时，不强制生成预演板。

## 7. 声音与剪辑

默认声音策略：

```text
保留：对白、呼吸、脚步、衣料、兵器、道具、环境和空间混响。
音乐：由整片剪辑阶段统一加入。
```

基础设定只声明全段声音边界；具体声音必须逐镜落位。`[环境音：]` 写该镜持续存在的空间声场、方向和距离关键词，`[动作音：]` 写接触、运动、破坏或能力释放的同步声音，`[台词：]` 写原文及必要表演。声音承担镜头转场时，上一镜的声源或声音峰值必须成为下一镜头头部的进入依据，不能只在全段末尾列一张总清单。

默认的 4-15 秒素材路线继续用于常规 Seedance 2.0 生成。老胡明确选择 Seedance 2.5 的 30 秒入口时，允许建立单条 30 秒专用路线，但必须与 2.0 路线分开记录，并验收长程人物 / 服装 / 场景一致性、动作与音频节拍持续同步、后半段指令遗忘和长提示词截断；不能把 2.5 的 30 秒能力写成所有 Seedance 版本的默认能力。

多条短素材要剪成几分钟作品时，模型分别生成 BGM 会造成调性、节拍、响度和段落结构无法连续。无 BGM 不是审美禁令，而是把整片音乐控制权留给剪辑阶段；固定音乐 MV 测试则应把用户提供的完整音频作为不可改动的主时间轴。

## 8. 信息完整与按需导出

正式提示词按版本与项目路由限字：Seedance 2.0 单条不超过 `4000` 字符；Seedance 2.5 在老胡AI视觉项目中配置为单条不超过 `10000` 字符，这是一项项目生产上限，不宣称为平台公开的官方硬限制；模型未明确或同一正文跨版本共用时按 `4000` 字符。只统计可直接投喂模型的单个 `text` 代码块正文，从 `【基础设定】` 到 `【画面内容】` 结束，中文、英文、数字、标点、空格和换行均各计一个 Unicode 字符；文件中的测试题、资产、参数、故事板和验收表不计入。不设最低字数，上限不是扩写目标；仍应在限额内保持最高有效信息密度。超限先删重复、作者解释和无画面作用的说明；必要动作因果仍装不下时减少非承重内容或拆分视频单元，不提交超限正文。

只有老胡已经明确反馈当前入口实际超限并要求精简这一条时，导出适配才按以下优先级保护信息：

```text
镜头动作与表演
> 景别、机位、运镜和切换
> 动作因果与空间关系
> 本镜光影、色彩和声音
> 实际引用资产
> 全局风格修饰词和器材名
```

删除重复资产外观、同义风格词、作者解释、观众意图、逐秒时间码和不参与本镜的对象。不得删除道路边界、人物站位、攻击来源、运动路径、避让方向、接触点、受力结果、镜头承接和情绪表演。提示词短不是目标；空间、动作与因果可执行，每句话都能改变生成结果，才是目标。

投射物与高速运动额外检查：先锁定道路 / 坡面 / 边沟等空间边界和通行净空，再写摄影机侧别、主体屏幕方向、攻击来源、运动轨迹、最近距离、人物感知与避让方向、出画 / 撞击结果和环境反馈。撞击目标不承担剧情时，不强求与人物同框；让物体出画后用画外声或边缘反馈完成空间延伸，避免模型把竹子、树、墙等落点搬到人物面前。

多主体运动不能只分别写 `向前`。在投喂正文前，先锁每个因果参与者的世界 / 屏幕起点、朝向、速度与加减速、景深层、外力、相对前后顺序、终点和出画顺序，再单列摄影机速度与轴线。正文优先给 Seedance 可见的正向屏幕约束：对象哪一端朝向哪边、从画面哪里移到哪里、谁始终领先、间距扩大还是缩小、谁先出画。跟随镜头中对象相对后移不代表世界坐标反向；没有可见外力时，不生成倒退、超越、急停或瞬移。

Seedance 对动作名称的理解通常会回归常见姿势，因此大幅变姿要写可见相位。`翻身下马`至少展开为脱镫、手掌承重、骨盆离鞍、跨鞍腿越过马背、肩胸骨盆绕支撑轴转向、双手先后离鞍、首次落地与连续卸力；`凌空转身`要写起跳脚、摆臂 / 摆腿、旋转轴、收腿与展开、落地朝向；`摔倒`要写失衡来源、先接触部位、关节折叠与最终受力面。只保留对轮廓、物理和情绪承重的相位，不把提示词写成无差别人体解剖表。

复杂动作还要先锁状态与知觉。跨镜头道具按 `进入状态 → 触发 → 接触与操作 → 中间状态 → 结果状态` 展开，特别区分武器完整入鞘、部分出鞘、完全出鞘、回鞘和脱手。人物只能使用当前可获得的声音、余光、反射、气流、震动和触感作判断；高速投射物默认先由发射声、环境异动或攻击者预动作触发人物反射，再进入观众视野。

Seedance 中的速度要落到相对运动和材料反馈。奔马写近景掠过与远景视差、马鬃衣摆风压、水花后抛、蹄频、摄影机惯性；箭矢写短促发射声、方向性模糊、近身极短轮廓和画外撞击。只有关键信息确实需要时才使用升格或速度渐变。

写实高武、玄幻和科幻镜头要同时保持能力等级与现实反馈。先定义角色能比普通人提前读取哪些预动作、声音、气流和环境变化，再写超常能力如何从发力形成、沿什么介质传播、如何提前影响雨珠 / 雾气 / 竹叶 / 衣料、在哪里接触、怎样分层破坏湿土 / 石块 / 竹根 / 建筑，以及声场和摄影机如何承受冲击。Seedance 正文用这些可见 / 可听结果建立真实感，不用泛化的 `炫酷能量、巨大金光、震撼爆炸` 代替。

动作角色不能只靠服装和武器区分，还要建立角色动作语法：能力等级、距离偏好、起势线索、惯用攻击几何、防守 / 借位、场景利用和回收节奏。连续群战中，每名攻击者从已建立方位完成预动作并进入攻击线，上一招造成的遮挡、失衡、空位、掉落物或反作用力直接成为下一招条件。Seedance 对平均连招和模糊多人围攻容易回归排队攻击，因此必须把攻击者的进入顺序和空间关系写成可见事件。

Seedance 容易把同一自然段中的多件武器聚合成中央接触团，因此多人武戏必须写成 `威胁并发、力量关系可读`。决定性接触可以串行，也可以让多件武器同时作用于主角；一对多时必须明确各攻击来源、不同接触位置、主角支撑点、合力方向、位移 / 形变、胜负和情绪结果，并只表达主角震开、敌方压退或主角改角卸力中的一个结果。缺少这些证据时拆回无空档串行接触。轻灵技巧型角色可以短暂受压或爆发弹开，但应迅速借力换位，不写成长时间静态比力。

Seedance 的切镜还要给出足够大的视觉差异。较远景别用于阵形、攻击来路和结果尺度，全景 / 中远景用于完整动作与位移，中景 / 中近景用于攻防关系，近景 / 特写用于接触、手部和表情。连续剪同一主体时，如果轴线、构图和动作相位近似，优先跨过一个景别或改变约 30 度机位；动作相位、构图或信息目标已经明显变化时，相邻景别也可以使用。不要把经验写成固定镜头套餐。

动作完整后再设计观赏性与战斗节奏。目标为高速群战时，按远程投射、长兵器封路、近身补位和高位压制组织重叠攻击波，主角上一招余势直接进入下一招。主角、敌群、投射物、摄影机和环境反馈分别写速度。决定性接触优先用高快门感、跟踪焦点和材料飞散提清，人物与兵器保持实时高速；不默认让摄影机停止、人物减速、长定格或 Pose。只有关键信息确实需要延长知觉时间时才局部升格，并立即恢复高速。

Seedance 正式镜头先分流文戏与武戏的情绪入口。文戏在第一有效节拍写清关系目的、阻力或关系变化，并让台词、停顿、表情、距离、反应和声场围绕同一压力；武戏在第一有效节拍写清危险方向、力量差或主角选择，并让动作、速度、空间、受力和摄影机共同承载。第一有效节拍不等于固定第一秒，也不等于统一快剪；它指删除无职责铺垫后，观众第一次获得足以进入人物处境的证据。

高武、机甲、枪战、追逐、超能力和大型破坏统一按 `预载 / 蓄力 → 瞬时释放 → 高速位移或力量传播 → 极短接触 → 明确结果 → 余势继续` 编译，但必须把题材对应介质写出来。Seedance 容易把抽象“瞬移、高速、威力巨大”生成成跳帧或慢速摆招，因此正文至少写清发力点、起终位置、环境反向响应、惯性 / 拖曳、声音时差和结果；角色等级通过预动作大小、路径长度、接触时长、结果规模和控制精度区分。

每个文戏情绪段或武戏动作组只提清一至两个承重英雄帧。其余连接帧允许方向性模糊、遮挡、甩镜、失衡、局部出画和短暂丢焦，随后在决定性接触或结果处重新捕获。不要让 Seedance 为了“每一帧都能截图”把角色变成一招一停；也不要让大面积拖影持续覆盖主体和攻击线。

Seedance 镜头切换要在上一镜结尾提前种下下一镜。优先使用动作匹配、方向匹配、视线匹配、声音提前进入或运动物遮挡：本镜结果尚在运动时，下一敌人的刀尖、影子、脚步、链响、机关声或人物视线先进入；新镜头从同一线索的下一相位继续。只有遮挡词、没有威胁预告和方向继承，模型会把两个镜头当成互不相干的任务。

Seedance 多人群战还要限制真实可交战人数。总敌人数可以多，但当前接触者由场地正面宽度、身体占位、武器长度、挥舞净空、友军遮挡和远程射界决定。其他人必须处于封路、补位、回收、换角、瞄准、保护或退出状态。主角无护体屏障时先冲出圆心，把包围改成扇面或纵深追击；不使用对称俯拍圆阵和所有长兵器同时刺中中心。兵器、人身和环境接触分别写材质声音、阻力和受力结果，减少模型回归统一火星碰撞。

爆炸、楼体坍塌、炮击、飞船受击等复杂事件按传播链写：命中点与入射角先确定，力量沿结构和介质传播；玻璃、金属、混凝土、钢筋、土石、舱体或液体按各自材料方式失效；碎片按大小与速度形成有方向的飞散锥并可能二次撞击；随后才写烟尘、火焰、压力波、声场、摄影机和永久残局。Seedance 不会替作者自动补齐这些因果，结果词越大，越需要把决定画面真实性的中间过程写清。

## 9. 生成前检查

```text
1. 基础设定是否只调用本条真正使用的素材？
2. 场景状态与氛围画质是否先写开拍前已经成立的场景事实，再只保留跨全部镜头成立的宏观规则？
3. 内部镜头节点数量是否由观看任务决定；正式画面内容是否以 `【镜头01｜景别｜机位 / 视角｜运镜 / 转场】` 连续编号，硬切 / 软切机制是否写进最后一栏，连续运镜是否只保留一个头部并写真实摄影机路径？
4. 每增加一个镜头，是否带来了新的信息、情绪、空间、动作阶段、视觉证据或节奏压力？
5. 快闪蒙太奇是否判断过应在单条 Seedance 内完成，还是拆成多条素材后期剪辑？
6. 每镜是否先写清主情绪、主体状态 / 动作和可见结果，再选择承重项？不要求每镜同时填满景别、机位、运镜、光影、色彩、声音和停帧；但被选中的项必须具体可执行。
7. 正式画面内容每个实义句是否都能在成片中被看见、听见或直接感到；小说因果、角色判断、导演评价和设备叙事是否已翻译为屏幕证据；画外信息是否有声音、光影、反射、飞入物或人物反应入口？
8. 色卡是否从抽象色号落到了人物、服装、场景、道具、雾气、暗部和高光？
9. 镜头预演板是否仅供人审，未被默认当作 Seedance 输入？
10. 是否只生成同期声和环境声，把 BGM 留给整片剪辑；每镜环境音、动作音和台词是否分别落位？
11. 是否使用 720p 做首测，并把总时长放在平台参数中？
12. 结尾是否停在能剪辑、能接续、能截图的一帧？
```

核心判断：Seedance 2 提示词不是文学小作文，也不是摄影参数清单。它是一份可执行的导演调度：参考素材负责一致性，宏观基线负责统一，镜头语言负责让故事和情绪真正发生。
