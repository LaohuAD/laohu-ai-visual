# 真实生产验证回传包

> 用途：当老胡手动生成图片、视频，完成剪辑或拿到发布数据后，按本文件把真实结果带回项目，让 `laohu_` skills 能继续诊断、返修、沉淀资产。  
> 原则：不要求一次性填满。缺失项标“缺”，不要编数据。

## 一、总入口

真实验证分四类：

| 回传类型 | 触发 skill | 主要目标 |
|---|---|---|
| 图片候选 | `laohu_visual_assets` / `laohu_generation_review` | 判断图片能否进入视频参考 |
| 视频片段 | `laohu_generation_review` | 判断镜头是否可用、是否返修 |
| 剪辑版本 | `laohu_generation_review` | 判断成片是否可发布 |
| 发布数据 | `laohu_generation_review` | 判断封面、标题、内容和发布策略 |

所有真实回传都先判断是否属于具体作品。属于作品的，优先归档到作品目录，不直接放共享资产库。

## 六、最小回传也可以

如果时间很紧，至少给：

```text
作品名：
阶段：图片 / 视频 / 剪辑 / 发布
原提示词或版本位置：
结果文件位置或结果描述：
你觉得最大的问题：
你想继续：重写 / 复盘 / 进入下一步
```

有这 5 项，就可以先调用对应 skill 做初步判断。

## 七、回流规则

每次真实回传后，至少判断：

- 是否更新作品目录。
- 是否更新 `输入输出索引.md`。
- 是否进入成功案例或失败案例。
- 是否更新提示词模板、视觉语言资产或模型适配规则。
- 是否能回流到 `老胡文稿` 变成文章、口播或课程案例。

不要只保存结果。真实结果必须反向改善下一次创作。
