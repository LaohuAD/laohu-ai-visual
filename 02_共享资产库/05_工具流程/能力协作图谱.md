# 老胡 AI 视觉能力协作图谱

本文件规定十七个 Skill 怎样互相借力。它不替代生产状态，不复制专业方法，也不把所有节点变成同一种能力。

## 一、网络原则

### 顺序生产，网状会商，按根因返工

作品必须按真实状态向前生产；能力不必排成只能向下说话的一条队。当前负责人可以向相邻专业咨询、接受总导演复验、读取共享事实，也可以把问题返回最早根因。

### 各有主业，彼此听得懂

每个节点是 T 型能力：纵向对自己的专业结果负责，横向理解导演意图、观众经历和相邻专业接口。理解不等于接管，参考不等于复制。

## 二、五类协作边

| 类型 | 何时使用 | 主责是否转移 | 必须返回 | 禁止行为 |
|---|---|---:|---|---|
| `HANDOFF` | 阶段完成，成果与状态正式交给下一负责人 | 是 | 锁定事实、自由区、完成条件、失败边界 | 只转发摘要，不交可执行状态 |
| `CONSULT` | 当前负责人缺少相邻专业判断，但仍能整合结果 | 否 | 对一个明确问题的判断与适用边界 | 把咨询变成共同负责或覆盖对方权威 |
| `REVIEW` | 总导演在关键节点检查整片方向，或专业节点执行独立复验 | 否 | 继续 / RETURN / 请求者取舍及证据 | 审阅者直接在下游偷改上游决定 |
| `RETURN` | 当前问题的根因不在本节点 | 是 | 首断点证据、保护项、最小返工目标 | 在末端增加文字掩盖上游缺口 |
| `SHARED_SOURCE` | 多节点需要同一人物、世界、资产、平台或模型事实 | 否 | 权威路径、版本/状态、当前有效事实 | 复制第二份事实或无权修改共享真源 |

`CONSULT ≠ HANDOFF`。调用不转移主责，也不授予调用者修改被调用节点权威文件的权限。

`laohu-language-mode`只通过`CONSULT`为当前文本块返回语言合同，不接管专业内容，也不改变生产状态。各节点可以用`SHARED_SOURCE`读取它的模式 Reference；若发现内容不足，必须用`RETURN`回到原负责人，不能让语言节点补写领域答案。

## 三、调用合同与回执

调用前写清：

```text
当前主负责人：
协作边类型：HANDOFF / CONSULT / REVIEW / RETURN / SHARED_SOURCE。
触发条件：为什么当前节点不能只靠本职完成。
目标节点与必要 Reference：
只需要回答的问题：
当前保护项：
允许挑战的假设：
禁止覆盖项：
结果进入当前哪个决定：
```

调用后留下`调用回执`：

```text
实际读取或交接：
取得的判断、事实或状态：
改变或确认的决定：
未采用内容及原因：
当前主负责人：
下一步与失败返回：
```

没有改变或确认任何决定的读取不算能力激活。不默认读取所有文件；“项目复杂”不是全量加载的理由。

## 四、节点登记

| 节点 | 唯一主责 | 主要可咨询节点 | 典型触发 | 禁止覆盖项 |
|---|---|---|---|---|
| `laohu-ai-visual` | 真实目的、状态和主责路由 | 总导演、各阶段负责人 | 入口不清、混合请求、状态冲突 | 专业成品与作品事实 |
| `laohu-language-mode` | 模式判定、文本块分权与跨体裁表达合同 | 所有专业节点 | 沟通 / 剧本 / 资产 / 模型文本的接收者或身份改变 | 任何领域内容、生产状态、锁定事实与专业规则 |
| `laohu-director` | 观众经历、全片取舍、跨部门统筹与复验 | 编剧、美术、人物、声音、视频、复盘 | 公开作品、跨专业冲突、整片方向不清 | 正式剧本、专业设计与生成执行 |
| `laohu-story-material` | 原话、素材原子、检索与使用回流 | 编剧 | 编剧提出生活证据缺口 | 剧情选择与导演命题 |
| `laohu-script-writer` | 人物因果、场面、台词和镜头化内容母版 | 总导演、人物、场景、声音、视频 | 表演、空间或可生成性影响剧本事实 | 导演主胜负手、专业资产定案 |
| `laohu-mv-director` | 歌曲事实、时间轴、声画结构和 MV 表演 | 总导演、声音、美术、视频 | 歌曲与品牌/系列冲突或制作约束 | 最终音频事实、一般作品总导演职责 |
| `laohu-art-direction` | 跨部门视觉语言 | 总导演、编剧、人物、服装、场景、资产 | 题材边界、主辅类型、视觉漂移 | 故事因果和具体专业设计 |
| `laohu-character-design` | 人物身体化与跨媒介身份母版 | 总导演、编剧、服装、场景、声音 | 第一印象、表演能力或媒介身份不清 | 剧情与已锁定真人身份 |
| `laohu-costume-design` | 世界衣橱与人物服装定案 | 总导演、人物、美术、场景、资产 | 身份、阶段、行动与服装冲突 | 人物核心身份和剧本事件 |
| `laohu-set-design` | 空间叙事、布景与调度条件 | 总导演、编剧、美术、资产、视频 | 空间不能承载动作或摄影关系 | 人物动机和镜头事件顺序 |
| `laohu-audio-design` | 声音身份、当场演法、声源与生成任务 | 总导演、编剧、人物、MV、视频 | 声音改变表演、信息或节奏 | 锁定台词、最终音频和剧情事实 |
| `laohu-visual-assets` | 稳定视觉形态、图片提示词与依赖 | 总导演、美术、人物、服装、场景、视频 | 对象跨请求复用或高代价漂移 | 剧情、调度和专业设计定案 |
| `laohu-video-prompt` | E-S-B 组织与模型可执行的时间编译 | 总导演、编剧、资产、声音、模型 Reference | 镜头执行、时长、入口或连续性不清 | 人物动机、故事事实和未确认资产 |
| `laohu-vibe-creating-prompt` | 已合格视频提示词的 VC 提纯 | 视频提示词 | 每条正式提示词首稿通过基线 | 上游事实、资产、台词和三段式接口 |
| `laohu-cover-design` | 发布主视觉与点击承诺 | 总导演、成片、发布事实 | 正片完成，需要入口压缩 | 超出正片的承诺 |
| `laohu-generation-review` | 真实结果首断点与返工路径 | 总导演及最早可能负责人 | 已有真实图片、视频、剪辑或数据 | 用计划意图替真实结果补答案 |
| `laohu-capability-evolution` | 长期能力断点、规则写回与回归 | 所有业务节点 | 重复失败、研究、反思、平台变化 | 一次性偏好直接升级硬规则 |

## 五、导演参与范围

总导演默认介入四个节点：创作前定向、剧本后复验、生成前总检、成片后验收。单一内部资产、确定性转换、编号检查、渲染归档和已锁定导演阐述下的局部机械返工不强制调用。

MV 中若 `laohu-mv-director` 已完整承担歌曲导演职责，总导演只处理歌曲之外的品牌、系列、观众和跨作品约束，不产生第二份导演终审。

## 六、返工原则

可见问题先判断发生在哪里，而不是最后在哪里被看见：

```text
目的或观众路线互相冲突 → laohu-director
内容已成立但文本块身份或接收者混写 → 当前负责人 CONSULT laohu-language-mode
人物为什么做、台词为什么说、镜头事实不成立 → laohu-script-writer
视觉世界互相打架 → laohu-art-direction 或对应专业设计
已确认对象在生成中走样 → laohu-visual-assets
既有镜头没有被正确编译 → laohu-video-prompt
真实结果与所有计划都不一致 → laohu-generation-review 先定位首断点
```

RETURN 必须携带证据和保护项。没有首断点证据时只标观察，不把所有节点同时叫来重做。
