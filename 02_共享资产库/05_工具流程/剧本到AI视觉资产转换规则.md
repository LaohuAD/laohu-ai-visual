# 剧本到 AI 视觉资产转换规则

> 用途：把剧本继续拆成可复用视觉资产、一次性画面元素、镜头参考图和镜头提示词，服务 AI 图片、AI 视频和后期剪辑。

## 一、转换原则

剧本不是终点。

在老胡 AI 视觉项目里，剧本必须继续向下拆：

```text
剧本
→ 资产判定
→ 可复用角色 / 场景 / 道具资产
→ 一次性画面元素
→ 镜头提示词
→ 低保真故事板提示词
→ 图片提示词
→ 视频提示词
→ 生成素材
→ 剪辑成片
```

资产不是画面里出现过的所有东西。资产必须满足至少一个条件：

- 会跨镜头、跨场次、跨集或跨作品反复出现。
- 需要锁定外观、空间结构、材质、比例、色彩或风格连续性。
- 会作为后续图生视频、剪辑拼接、封面或系列创作的稳定参考。

只出现一次的路人角色、单次奇观、单镜头场景、一次性入口裂隙，默认是画面元素或临时参考图，不进入资产表。

镜头预演板也不进入资产表。它是在分镜表之后按需生成的构图 / 景别 / 空间 / 动线人审图，保存到作品 `04_分镜/文本/` 和 `04_分镜/图片/`。它使用黑白 / 灰阶低保真构图骨架，默认不作为 Seedance 输入。

镜头预演板只解决文字最弱的空间与构图关系：主体大小、相对位置、景别、机位、道具数量、空间锚点、引导线、动线路径和留白。它不固定真实五官、具体服装、颜色、材质、最终光影和电影美术。需要模型参考构图时，另行生成或挑选无表格、无箭头、无文字、无多格拼图的干净首帧 / 构图参考图。

所有需要老胡手动上传、替换、绑定、参考或调用的外部内容，都必须使用中文全角中括号 `【】` 显性标注。稳定资产写 `【@资产名】`；人物按三资产职责分别写 `【素体参考@B01 人物素体形象资产】`、`【服装参考@W01 人物服装资产】`、`【妆造参考@M01 人物妆造设计资产】`；人物音色写 `【音色参考@V1 角色音频参考】`；临时参考图写 `【参考图1：用途】`、`【参考图2：用途】`。图片资产提示词、故事板提示词、首帧提示词、封面提示词和生成执行单都遵守这条规则。不要裸写 `参考图 1`、`参考图片 2`、`见上图`、`使用图片一`；正确写法是 `【参考图1：人物素体肖像】用于固定脸与身体；【参考图2：服装穿搭】用于固定版型、层次、颜色、材质和配饰方向`。

镜头预演板和视频提示词必须同源。分镜表和预演板可以用 `镜头01 / 镜头02` 或格号管理关键画面，正式视频模型正文使用同一组节点，但去掉编号并改写成连续镜头叙事；连续动作、情绪承接、POV 接续和遮挡转场可以使用锚点重叠，硬切、换场、时间跳切和闪回不强制重叠。每次切换仍要写清可见 / 可听触发、摄影机变化和新画面继承。

镜头预演板表格列为：

```text
镜头 / 关键画面
线框构图
构图规则
景别 / 机位
空间锚点
引导线 / 动线路径
主体比例与位置
人审重点
```

资产判定前必须先做确定性命名：

```text
剧本显示称呼：观众或角色在剧本里看到 / 听到的叫法。
生产命名：本项目内部用于分镜、资产和提示词交接的稳定名称。
资产命名：当对象确实需要固定时，对应的资产编号和名称。
```

示例：

```text
剧本显示称呼：大人
生产命名：主角
资产命名：A1 主角袖口与玉扳指
```

禁止把抽象泛称直接当成固定资产。`群仙` 是群体类别，可以是群体画面元素或“群仙礼仪规则”提示词资产；`神兽` 是生物类别，必须具体到 `白鹿`、`云龙`、`青鸾` 等确定对象后，才继续判断是否需要资产；`宫殿`、`法器`、`女仙` 也要先具体化为对象、功能和出现范围，再决定是否资产化。

视觉资产内部分两类：

- 图片资产：用图片固定具体形象和一致性，例如角色长相、固定服装、固定道具、固定场景、第一帧。
- 文本资产 / 提示词资产：用文字固定氛围、妆造、环境、风格和世界观视觉规则，例如仙界人物妆造、白玉宫阙环境规则、金白云光材质规则。
- 色彩风格资产：用色卡图片 + 文本规则固定全片或阶段的色彩系统，例如主色、辅助色、点缀色、肤色倾向、光源色、暗部倾向、环境反光、饱和度、明度、对比度和统一分级。

提示词资产可以在多个镜头、场次或作品中复用。它通常会进入后续正式视频提示词的基础设定、氛围与画质或画面内容，但正式提示词里必须展开具体内容，不能只写“调用某提示词资产”。

色彩风格资产的判定条件：如果一个作品需要跨多个分镜保持统一调色，或者同一场景在不同情绪阶段需要受控变色，就应建立 `C` 系列色彩风格资产。它默认包含一个全片母色卡和必要的阶段变体。母色卡保证剪辑连续性，阶段变体保证情绪推进；不要每个分镜随意换色卡，也不要所有分镜完全死用同一组颜色。人物服装资产与妆造设计资产里的局部色值只用于服装、妆面和配饰校对，不等于全片色彩风格资产。

图片资产子类型：

- 人物素体形象资产：固定脸型、五官、身材、身高、年龄 / 形态阶段、基础体态和永久辨识特征；使用白衣 / 中性衣裤、简洁灰色摄影棚和校准光，版式为左侧头部正面特写，右侧左45度 / 正面 / 背面全身三视图，附属性说明区。
- 人物服装资产：只固定穿在、戴在或挂在角色身上的可拆卸穿戴系统，按头部穿戴、上半身、下半身、足部四区拆解，写清版型、层次、材质、颜色、纹样、接缝、扣合、穿戴方式和活动余量。
- 人物妆造设计资产：同时引用人物素体形象资产与人物服装资产，固定发型、面部妆容、胡须 / 假发、临时纹身 / 身体彩绘、伤妆以及服装穿回同一主体后的最终可见结果；版式为左侧头部正面特写，右侧左45度 / 正面 / 背面全身三视图。M是受控定妆摄影资产，不是灰底平光合成图：必须设计主光、补光、眼神光、背景明度 / 色相对比、景深和妆面高光，让眉眼、睫毛、腮红、唇形与唇面光泽在头部特写中可读，并让四个视图共享同一摄影关系。
- 群像人物资产：用场景合照式参考图固定跑龙套人群的年龄层、服装年代、体态差异、站位密度、表情范围和群体气质，不锁具体单人脸。
- 场景图片资产：同一固定空间的扩展分区场景设计板，左上四机位锁定多角度空间，右上鸟瞰锁定总平面和动线，底部细节带锁定固定构件、材质、颜色和空间记忆锚点。
- 物品图片资产：同一件物品的扩展分区物品设计板，上部主结构 / 辅助视图锁定轮廓比例和方向关系，底部细节带锁定材质、表面处理、Logo、文字、纹样、连接和功能结构。
- 色彩风格资产：横向色卡图 + 文本规则，色块标十六进制 RGB，说明使用比例、材质落点、情绪阶段变体和统一分级。

资产编号必须稳定。例如：

```text
B01 = 人物素体形象资产
W01 = 人物服装资产
M01 = B01 引用 W01 后形成的人物妆造设计资产
```

助手只负责规划、提示词和记录组合关系，不负责实际图片合成。

### 二点一、资产依赖与生成层级

资产判定完成后，不得把人物、场景、道具和风格分别写成互不引用的提示词清单。先建立有向无环的依赖图，再决定实际生成顺序：

```text
L0：色彩风格、固定 Logo、世界观材质与主成像基底
L1：人物素体形象、人物服装、关键道具、空置基础场景
L2：人物妆造设计、已布置场景、群像入景等稳定组合
L3：故事板、首帧、尾帧、关键帧中的具体动作与瞬时状态
```

每条依赖必须登记：

| 下游资产 | 上游参考 | 引用强度 | 上游只负责 | 禁止继承 | 生成前置门 | 上游变化后的重验范围 |
|---|---|---|---|---|---|---|
|  |  | 硬参考 / 风格参考 / 情境或尺度参考 |  |  | 已生成并由老胡确认 / 阻塞 |  |

提示词开头显性声明 `【素体参考@B01】负责脸和身体；【服装参考@W01】负责穿戴系统；【妆造参考@M01】负责最终发型、妆容和上身结果；【物品参考@...】负责道具；【场景参考@...】负责空间；【色彩参考@...】负责色彩`。只有真实生成并验收的上游图能成为下游硬参考；预写占位符不代表资产已经存在。禁止循环硬引用：先固定B、W、道具、场景和色卡，再建立M与场景布置组合。上游换图、换色、改结构、改尺寸、改 Logo 或改空间后，所有受影响下游必须重验。

资产转换结果必须按依赖图的拓扑顺序写入最终文件。资产总览、图片提示词正文和图片生成执行单使用同一队列；任何带上游引用的提示词都排在对应上游完整提示词之后，使老胡可以从文件第一条资产开始逐项生成和确认。不能按人物 / 场景 / 道具分类排完正文，再另外写一句“实际按依赖表执行”；那会把查找、跳页和误生成成本留给执行者。同层无依赖资产可以按编号排列，发现相互引用则退回拆环。

每张图片提示词增加内部对象盘点，不只检查主资产：

| 目标图片 | 画面对象 | 是否可识别 | 来源资产 / 规范账本 | 必须继承 | 允许变化 | 处理 |
|---|---|---|---|---|---|---|
|  |  | 是 / 否 |  |  |  | 引用闭合 / 文本闭合 / 画面排除 |

重复人物、关键道具、Logo、固定文字、倒影和屏幕对象不能处于无来源状态。已有确认图片时显式引用并保持文字一致；当前没有图片时，从规范词账本完整写出身份、定装、颜色、材质、数量、左右、位置和状态；不需要出现时才保持画外。双人或多人需要长期同框时，等所有单人锚点确认后建立 L2 关系组合资产，调用每个人、所属物、场景和风格，固定屏幕侧、服装、高差、距离与视线。不得让两张单人资产互相循环引用，也不得用“丈夫 / 妻子 / 同事”这类关系称呼替代可生成的身份与定装。

## 三、人物图片资产表

| 资产编号 | 角色 | 资产子类型 | 固定内容 | 服装 / 妆造 | 推荐图片形态 | 背景 | 组合关系 | 需要图片资产 |
|---|---|---|---|---|---|---|---|---|
| B01 |  | 人物素体形象资产 | 脸型 / 五官 / 身材 / 身高 / 年龄或形态阶段 / 基础体态 / 本体辨识特征 / 必要属性 | 白色或中性简单衣裤 | 左侧头部正面特写；右侧左45度、正面、背面全身三视图；属性说明区 | 中性灰摄影棚 | 被W、M引用 | 是 / 否 |
| W01 |  | 人物服装资产 | 头部穿戴 / 上半身 / 下半身 / 足部的版型、层次、材质、颜色、纹样、穿戴和活动余量 | 不绑定具体人物脸 | 四区服装拆解板 + 局部结构特写 | 简洁中性背景 | 被M引用 | 是 / 否 |
| M01 |  | 人物妆造设计资产 | 发型 / 妆容 / 身体彩绘或伤妆 / 服装穿回后的最终可见结果 / 定妆摄影关系 | 同时引用B01与W01 | 左侧头部正面特写；右侧左45度、正面、背面全身三视图 | 受控定妆摄影棚：背景明度与妆面形成对比，主光方向稳定，补光保留脸部细节 | B01 + W01 | 是 / 否 |

只在一个镜头出现的迎宾、路人、群众、守门者，不默认进入角色资产表。

主角色三资产中的B和M默认只固定中性常见表情：正脸自然、脸部肌肉放松、眼神正常。复杂情绪表演如果只靠图片提示词里的几个情绪词，模型容易生成浮夸、不真实的表情符号；因此恋爱、悲伤、怀疑、愤怒、崩溃等表演应留到分镜和视频提示词里，按镜头细化眼神、眉心、嘴角、呼吸、手部和身体停顿。只有在老胡明确要求表情测试时，才单独输出表情测试参考图，且不得替代B或M。

如果群众不是一个具体角色，但会连续参与围观、起哄、轻冲突、仪式或集体反应，并且需要稳定年代感、服装气质和群体真实感，可以进入群像人物资产表。群像人物资产使用 `G` 系列编号，例如 `G1 邻家孩子群像`。它只固定“这群人是什么类型的人”，不固定每个群众的具体脸、姓名和单人三视图。具体动作、台词、谁从哪里进入、谁伸手触碰道具，应留给分镜和视频提示词。

人物资产不要把“好看的成品人像”误当成身份资产。主角、封面主体、重要人物、长期系列角色或需要跨镜头一致性的主体，先做B人物素体形象资产锁脸、身体、身高和基础体态；需要固定穿搭时再做W人物服装资产；最后由M人物妆造设计资产把发型、妆容和服装穿回同一主体。单张艺术照可以作为成品图或临时气质参考，但不替代B、W、M。

人物三资产必须分别输出：B01用中性灰摄影棚校准板锁定脸、身体和属性；W01用四区服装拆解板锁定穿戴系统；M01引用B01与W01，用左侧头部正面特写和右侧左45度 / 正面 / 背面全身三视图锁定最终妆造，并用受控定妆摄影把妆面、眼神光、唇部高光、肤色层次、背景对比和服装轮廓拍出来。不得用艺术照、定装照或旧版混合图代替B、W、M的职责，但M本身必须是“最终妆造在摄影条件下的可见结果”，不能退化成灰底雕像。

三类提示词对应三个正式资产编号：`B01 人物素体形象资产提示词`、`W01 人物服装资产提示词`、`M01 人物妆造设计资产提示词`。M01只有在B01与W01都已生成并确认后才能生成；视频提示词按本镜需要调用B、W、M，不使用含义模糊的单一“人物资产”替代。

POV主体也必须进入正常三资产判断。第一人称POV只决定后续怎么拍，不代表角色没有身体。只要POV主体是主角、跨镜头出现或承担观众代入，B必须锁年龄、身高、头身比、上下身比例、肩宽、手脚尺度、正面 / 侧面 / 背面和视线高度；W锁袖口、鞋、书包等穿戴物；M锁最终发型与妆面。视频阶段用 `【素体参考@Bxx】【服装参考@Wxx】【妆造参考@Mxx】` 转成手部、袖口、肩背、低视线和反射里的身份锚点。

人物三资产必须拆清稳定身份、服装穿戴、场景配件和动作道具。B锁脸、年龄、身高和体态；W只锁持续作为穿搭识别的穿戴物；M锁发型、妆容和最终上身结果。书包、雨伞、帽子、孝布、围裙、工具包、篮子等如果只在特定场景出现，不得塞进B或M的常驻三视图；如果会被摘下、拿取、交换或推动剧情，则转为独立道具资产。当前案例中的书包只属于放学路 / 报丧状态，应写入状态账本和对应镜头，不污染B、W、M。

音色不是视觉三资产的必备模块。会说话、VO或画外音的角色，单独记录 `音色参考` 编号或在视频提示词里写声音设定；人物行使用 `角色名：【素体参考@B01】【服装参考@W01】【妆造参考@M01】【音色参考@V1】稳定身份、本镜状态和本镜出镜 / 出声方式。` 本镜哭腔、病弱、喊叫、压低、隔门闷声、电话失真和VO回响由视频提示词写进 `【画面内容】`。

如果角色长期复用且会换装，唯一正式链路是：

```text
人物素体形象资产 B
→ 人物服装资产 W（锁版型、层次、材质、颜色、纹样和穿戴物）
→ 人物妆造设计资产 M（引用B与W，锁发型、妆容和最终上身结果）
```

如果角色只在一个场景出现且不换装，也不能用一张漂亮定装图同时承担身份、服装和妆造三种职责；按实际一致性风险选择B、W、M的最小链路，并在资产表中明确省略的职责。

当输入里同时出现人物参考图和服装参考图时，不要只输出一条笼统的人物定装提示词。必须先拆清楚：

```text
人物参考图：进入B，固定脸、身形、年龄感、体态和头身比。
服装参考图：进入W，固定校服 / 制服 / 日常服的版型、层次、颜色、穿法和身份识别元素。
最终结果：M同时引用B和W，把服装穿回同一主体，并补发型与妆容，用于后续视频调用。
```

人物资产图需要严格制作参考时，B和M统一采用左侧头部正面大特写、右侧左45度 / 正面 / 背面全身三视图；B的属性区用厘米和设计值锁身高、身体节点与比例，M不重复完整体型表。B使用中性校准背景与光线，M使用受控定妆摄影背景与光线：M的背景必须与肤色和妆面形成明度或色相对比，主光照出眼睑、睫毛、鼻梁、唇面和衣料，补光保留暗侧结构，必要时用弱轮廓光分离发丝；四个视图共享同一光向和色彩关系。W按头部穿戴、上半身、下半身、足部四区展开总览和局部结构；配色、接缝、纹样与材质都必须回指总览中的具体部位。左右手只有在承担POV、操作或特写一致性时才作为B的辅助模块，不把音色塞进视觉资产图。

当人物参考图和服装参考图合成定装时，还要写清身体适配。服装参考图只提供款式方向，不能机械复制成一件挂在人身上的衣服。提示词必须检查：肩线是否利落，胸口是否有自然立体省道或柔和弧度，腰侧是否收住，腰带 / 系带是否压出高腰线，裙摆 / 裤型从哪里展开，面料是贴合还是垂坠，是否避免松垮无形、胸前塌陷、腰线消失、过度暴露和网红紧身性感。服装细节还要继承穿法逻辑和视觉重心：参考图里偏侧斜绕的腰部层次，不能被机械居中成正面毛巾、围裙或大结；鞋履要写清鞋头形状、闭口 / 露趾、浅口 / 深口、踝带、跟高、材质、颜色和气质。当前案例：林栀的深灰无袖上衣要按她身形修身合体，浅灰系带要偏侧斜绕并强调细腰和高腰比例，蓝灰水墨长裙从细腰处自然展开，鞋履固定为珍珠白冰银尖头浅口踝带低跟单鞋。

人物素体形象资产和人物妆造设计资产要锁符合角色身份的基准体态，不统一美化成“高光站姿”。女侠可以肩背打开、重心稳定，疲惫老人可以保留真实含胸，受伤角色可以保留代偿姿态。若补左右手参考，必须按人物自身左右校准，保持同年龄、同肤色、同手部比例且解剖方向相反。

人物服装资产和人物妆造设计资产必须共用同一份造型账本。W先列清上衣、下装、腰部结构、头部穿戴、耳饰、项链、鞋履和腕部状态；M只从这份账本穿回服装并补发型、妆容，不新增或改造服装。局部细节区不是自由装饰拼图，必须一物一标并回指总览，避免发饰变手环、鞋履换款或标签错位。

三类人物资产的可复制图片提示词都遵守引号纪律：代码块里只有画面真实要出现的文字才写成文字指令，不用引号做强调或解释。手部模块只标注左手、右手，解剖方向写成视觉规则；属性说明、服装标签和妆造说明只写必要短文，不让长段解释占据资产画面。

资产唯一性先于资产数量控制。一个 L1 独立锚点只能固定一个确定对象：一个人物身份、一件道具、一个空置基础场景或一套服装 / 妆造。不要为了省资产，把场景、桌子、汤圆、硬币、人物手部和动作合成一个“资产”。这类一次性合成图应归为分镜图、首帧图或视频参考图。多个元素都需要稳定时，先拆成多个 L1 资产；只有穿戴、摆放或组合关系会跨镜复用时，才建立显式引用上游的 L2 组合资产，且组合图不能重设计或替代各独立资产。

资产类型必须按失真来源判断。剧本里出现“玩具”“电话”“汤圆”“课桌”“药碗”等名词时，先问本轮生成最容易失控的是物品本体，还是物品所在的年代空间 / 陈列环境 / 使用场所。如果失控点是商场货架、小卖部公共电话角落、教室桌椅布局、灶房光源、柜台陈列、地砖墙面等空间组织方式，应建场景资产；如果失控点是玩具车本体、座机本体、完整白汤圆外观、单枚硬币、药碗等具体物的形状材质和特写，才建道具 / 物品资产。注意互斥可见状态要拆开：完整白汤圆和包入前 / 吃出后的硬币不能合成一个“硬币汤圆”资产。当前案例：商场拒买玩具闪回要固定的是普通商场玩具货架区的年代环境，因此做 `S7 商场玩具货架区`，不是 `P10 玩具车`。

只出现一次、不会再次进入或多角度复用的场景，不默认进入场景资产表。

固定场景资产优先做扩展分区场景设计板，而不是单张漂亮图或平均四宫格。至少同时处理主入口、正面 / 左侧 / 右侧 / 反向四机位、高位鸟瞰总平面、人物可运动路径、关键固定构件、材质细节和光源方向。

当一个固定场景会被反复进入、需要正反打、左右侧视角、人物走位或镜头拉高展示全局时，扩展分区设计板左上 2×2 四机位使用：

```text
正面视角：定义场景主入口、主构图、主要物件和纵深。
左侧视角：以正面视角向左转动 90 度。
右侧视角：以正面视角向右转动 90 度。
正面反打图：从正面视角对面看回去。
```

四机位的核心不是“多几张图”，而是“同一个空间能被不同机位反复使用”。所有视角必须保持同一场景布局一致，视角逻辑正确，物体空间逻辑正确。右上鸟瞰必须解释入口、出口、固定构件、四机位和人物动线；底部细节带必须回指上方结构的材质、颜色、连接、磨损与记忆锚点。入口、窗户、固定家具、墙角、灶台、柴火堆等关键结构不能在不同区域里换位置或换材质。

左上四机位不能写成“功能拼图”。比如把格 1 写饭桌、格 2 写灶台、格 3 写遗像桌、格 4 写另一个反打空间，本质是四个功能区，不是同一个位置从不同方位看过来的图。正确写法必须先定义正面视角，再让左侧、右侧和反向视角围绕它旋转或反打，由右上鸟瞰复核布局。底部细节带只展示空间本体的固定节点；可移动剧情道具单独做物品资产。

所有人物、服装、物品和场景设计资产在进入提示词前都要建立 `细节来源映射`：每个局部模块对应哪个总览视图、位于哪个部位 / 空间坐标、朝向和数量是什么、局部只新增哪一层观察精度。转换顺序必须是 `先把细节的载体和位置写回总览 → 再写局部放大`。底部出现而上方没有出现的 Logo、文字、纹样、配饰、接口或固定构件一律判为新增设计，先退回资产规划；不能依靠“保持一致”让模型自行猜位置。

桌面、案板、灶台边、手工台、祭祀桌等局部空间，如果承载关键动作、儿童 POV、正反打、手部操作、人物围桌互动或动作连续，必须先拆清楚：灶房一角、墙面、入口、窗户、固定光源和动线属于场景资产；桌子、案板、碗、汤圆、硬币、药碗、针线篮属于道具 / 家具资产；人物手部和站位属于分镜或视频提示词。局部场景资产不能把可移动道具和动作混在一起。
