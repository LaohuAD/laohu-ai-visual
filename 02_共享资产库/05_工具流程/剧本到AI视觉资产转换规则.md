# 剧本到 AI 视觉资产转换规则

> 用途：把剧本继续拆成可复用视觉资产、一次性画面元素、镜头参考图和镜头提示词，服务 AI 图片、AI 视频和后期剪辑。

## 一、转换原则

剧本不是终点。

在老胡 AI 视觉项目里，剧本必须继续向下拆：

```text
剧本
→ 资产判定
→ 可复用角色 / 场景 / 道具资产
→ 一次性画面元素
→ 镜头提示词
→ 图片提示词
→ 视频提示词
→ 生成素材
→ 剪辑成片
```

资产不是画面里出现过的所有东西。资产必须满足至少一个条件：

- 会跨镜头、跨场次、跨集或跨作品反复出现。
- 需要锁定外观、空间结构、材质、比例、色彩或风格连续性。
- 会作为后续图生视频、剪辑拼接、封面或系列创作的稳定参考。

只出现一次的路人角色、单次奇观、单镜头场景、一次性入口裂隙，默认是画面元素或临时参考图，不进入资产表。

视觉资产内部分两类：

- 图片资产：用图片固定具体形象和一致性，例如角色长相、固定服装、固定道具、固定场景、第一帧。
- 文本资产 / 提示词资产：用文字固定氛围、妆造、环境、风格和世界观视觉规则，例如仙界人物妆造、白玉宫阙环境规则、金白云光材质规则。

提示词资产可以在多个镜头、场次或作品中复用。它通常会进入后续正式视频提示词的基础设定、氛围与画质或画面内容，但正式提示词里必须展开具体内容，不能只写“调用某提示词资产”。

图片资产子类型：

- 人物素体资产：固定长相、身材、发型、年龄感和基础体态，常用白衣 / 中性服装、简洁灰白背景。
- 人物定装资产：固定同一人物穿某套服装、发饰、妆容后的完整形象。
- 服装 / 妆造资产：单独固定服装、发饰、妆容、配饰或盔甲。
- 组合形象资产：人物素体 + 服装 / 妆造组合后的新形象资产。
- 场景图片资产：同一固定空间的三宫格 / 四宫格 / 多角度资产，锁定空间结构、光源、入口、主视角和可运动路径。
- 物品图片资产：同一件物品的多角度资产，背景简洁，锁定轮廓、比例、材质和细节。

资产编号必须稳定。例如：

```text
A1 = 人物素体资产
A2 = 服装 / 妆造资产
A3 = A1 穿着 A2 后形成的人物定装 / 组合形象资产
```

助手只负责规划、提示词和记录组合关系，不负责实际图片合成。

## 七、镜头提示词表

| 镜头编号 | 所属场次 | 剧本片段 | 确定时长 | 景别 | 构图 | 运镜 | 表情动作 | 图片参考 | 视频提示词 |
|---|---|---|---|---|---|---|---|---|---|
| E1-S1-C1 | 第1集 1-1 |  | 8 秒 |  |  |  |  |  |  |

编号规则：

- 使用 `E1-S1-C1` 表示第一集第一场第一个镜头。
- 插入镜头用字母后缀，例如 `E1-S1-C5A`、`E1-S1-C5B`，不重排后续编号。
- 镜头总时长必须是确定值，不写 `8-10 秒`、`10-12 秒` 这类范围。
- 单场次剧本是视频提示词的来源；可以跳过资产固定，但不能跳过资产判定、剧本场次和镜头任务。

## 八、执行提示词

```text
请基于下面这版剧本，拆成 AI 视觉制作表。

必须先输出资产判定表，再输出需要的制作表：
1. 资产判定表。
2. 人物图片资产表。
3. 服装 / 妆造资产表。
4. 文本资产 / 提示词资产表。
5. 场景资产表。
6. 道具资产表。
7. 一次性画面元素表。
8. 镜头提示词表。

要求：
每个视觉资产都要说明它为什么需要复用或一致性锁定。
图片资产必须标明子类型、资产编号和组合关系。
人物长期复用且会换装时，拆成人物素体资产、服装 / 妆造资产、组合形象资产。
场景图片资产优先做三宫格 / 四宫格 / 多角度，不要只做单张漂亮图。
物品图片资产要做多角度和材质细节，背景简洁。
提示词资产可以跨镜头复用，但进入正式视频提示词时必须展开具体内容。
只出现一次的内容不要强行列为资产，放入一次性画面元素表。
不要只列漂亮画面，要列能推动故事的画面。
镜头编号使用 E1-S1-C1。
镜头总时长写确定值，不要写范围。
镜头提示词先写中文说明，不要写英文。
```
