# 剧本到 AI 视觉资产转换规则

> 用途：把剧本继续拆成可复用视觉资产、一次性画面元素、镜头参考图和镜头提示词，服务 AI 图片、AI 视频和后期剪辑。

## 一、转换原则

剧本不是终点。

在老胡 AI 视觉项目里，剧本必须继续向下拆：

```text
剧本
→ 资产判定
→ 可复用角色 / 场景 / 道具资产
→ 一次性画面元素
→ 镜头提示词
→ 低保真故事板提示词
→ 图片提示词
→ 视频提示词
→ 生成素材
→ 剪辑成片
```

资产不是画面里出现过的所有东西。资产必须满足至少一个条件：

- 会跨镜头、跨场次、跨集或跨作品反复出现。
- 需要锁定外观、空间结构、材质、比例、色彩或风格连续性。
- 会作为后续图生视频、剪辑拼接、封面或系列创作的稳定参考。

只出现一次的路人角色、单次奇观、单镜头场景、一次性入口裂隙，默认是画面元素或临时参考图，不进入资产表。

镜头预演板也不进入资产表。它是在分镜表之后按需生成的构图 / 景别 / 空间 / 动线人审图，保存到作品 `04_分镜/文本/` 和 `04_分镜/图片/`。它使用黑白 / 灰阶低保真构图骨架，默认不作为 Seedance 输入。

镜头预演板只解决文字最弱的空间与构图关系：主体大小、相对位置、景别、机位、道具数量、空间锚点、引导线、动线路径和留白。它不固定真实五官、具体服装、颜色、材质、最终光影和电影美术。需要模型参考构图时，另行生成或挑选无表格、无箭头、无文字、无多格拼图的干净首帧 / 构图参考图。

所有需要老胡手动上传、替换、绑定、参考或调用的外部内容，都必须使用中文全角中括号 `【】` 显性标注。稳定资产写 `【@资产名】`，人物形象写 `【形象参考@A1 角色人物设计资产】`，人物音色写 `【音色参考@V1 角色音频参考】`，临时参考图写 `【参考图1：用途】`、`【参考图2：用途】`。图片资产提示词、故事板提示词、首帧提示词、封面提示词和生成执行单都遵守这条规则。不要裸写 `参考图 1`、`参考图片 2`、`见上图`、`使用图片一`；正确写法是 `【参考图1：女主肖像】用于固定脸、年龄感、体态和真实自然感；【参考图2：服装穿搭】用于固定版型、层次、颜色、材质和配饰方向`。

镜头预演板和视频提示词必须同源。分镜表和预演板可以用 `镜头01 / 镜头02` 或格号管理关键画面，正式视频模型正文使用同一组节点，但去掉编号并改写成连续镜头叙事；连续动作、情绪承接、POV 接续和遮挡转场可以使用锚点重叠，硬切、换场、时间跳切和闪回不强制重叠。每次切换仍要写清可见 / 可听触发、摄影机变化和新画面继承。

镜头预演板表格列为：

```text
镜头 / 关键画面
线框构图
构图规则
景别 / 机位
空间锚点
引导线 / 动线路径
主体比例与位置
人审重点
```

资产判定前必须先做确定性命名：

```text
剧本显示称呼：观众或角色在剧本里看到 / 听到的叫法。
生产命名：本项目内部用于分镜、资产和提示词交接的稳定名称。
资产命名：当对象确实需要固定时，对应的资产编号和名称。
```

示例：

```text
剧本显示称呼：大人
生产命名：主角
资产命名：A1 主角袖口与玉扳指
```

禁止把抽象泛称直接当成固定资产。`群仙` 是群体类别，可以是群体画面元素或“群仙礼仪规则”提示词资产；`神兽` 是生物类别，必须具体到 `白鹿`、`云龙`、`青鸾` 等确定对象后，才继续判断是否需要资产；`宫殿`、`法器`、`女仙` 也要先具体化为对象、功能和出现范围，再决定是否资产化。

视觉资产内部分两类：

- 图片资产：用图片固定具体形象和一致性，例如角色长相、固定服装、固定道具、固定场景、第一帧。
- 文本资产 / 提示词资产：用文字固定氛围、妆造、环境、风格和世界观视觉规则，例如仙界人物妆造、白玉宫阙环境规则、金白云光材质规则。
- 色彩风格资产：用色卡图片 + 文本规则固定全片或阶段的色彩系统，例如主色、辅助色、点缀色、肤色倾向、光源色、暗部倾向、环境反光、饱和度、明度、对比度和统一分级。

提示词资产可以在多个镜头、场次或作品中复用。它通常会进入后续正式视频提示词的基础设定、氛围与画质或画面内容，但正式提示词里必须展开具体内容，不能只写“调用某提示词资产”。

色彩风格资产的判定条件：如果一个作品需要跨多个分镜保持统一调色，或者同一场景在不同情绪阶段需要受控变色，就应建立 `C` 系列色彩风格资产。它默认包含一个全片母色卡和必要的阶段变体。母色卡保证剪辑连续性，阶段变体保证情绪推进；不要每个分镜随意换色卡，也不要所有分镜完全死用同一组颜色。人物设计资产里的紧凑色值卡只用于人物服装和肤色校对，不等于全片色彩风格资产。

图片资产子类型：

- 人物形象资产：用单张正面 / 半正面艺术照固定角色第一眼气质、环境氛围、光影方向、姿态和主视觉感觉。
- 人物素体资产：固定长相、身材、发型、年龄感和基础体态，常用白衣 / 中性服装、简洁灰白背景。
- 人物设计资产：用白底 / 简洁背景扩展分区版式固定三视图、面部特写、左手特写、右手特写、配色板、局部细节、比例照和音色文字说明区。
- 群像人物资产：用场景合照式参考图固定跑龙套人群的年龄层、服装年代、体态差异、站位密度、表情范围和群体气质，不锁具体单人脸。
- 人物定装资产：固定同一人物穿某套服装、发饰、妆容后的状态；正式交付仍拆成定装形象资产和定装设计资产两条提示词。
- 服装 / 妆造资产：单独固定服装、发饰、妆容、配饰或盔甲。
- 组合形象资产：人物素体 + 服装 / 妆造组合后的新形象资产。
- 场景图片资产：同一固定空间的扩展分区场景设计板，左上四机位锁定多角度空间，右上鸟瞰锁定总平面和动线，底部细节带锁定固定构件、材质、颜色和空间记忆锚点。
- 物品图片资产：同一件物品的扩展分区物品设计板，上部主结构 / 辅助视图锁定轮廓比例和方向关系，底部细节带锁定材质、表面处理、Logo、文字、纹样、连接和功能结构。
- 色彩风格资产：横向色卡图 + 文本规则，色块标十六进制 RGB，说明使用比例、材质落点、情绪阶段变体和统一分级。

资产编号必须稳定。例如：

```text
A1 = 人物素体资产
A2 = 服装 / 妆造资产
A3 = A1 穿着 A2 后形成的人物定装 / 组合形象资产
```

助手只负责规划、提示词和记录组合关系，不负责实际图片合成。

## 三、人物图片资产表

| 资产编号 | 角色 | 资产子类型 | 固定内容 | 服装 / 妆造 | 推荐图片形态 | 背景 | 组合关系 | 需要图片资产 |
|---|---|---|---|---|---|---|---|---|
| A1 |  | 人物形象 / 人物设计 / 人物素体 / 服装妆造 / 组合形象 | 长相 / 身材 / 发型 / 年龄感 / 表情 / 气质 / 左手 / 右手 / 音色文字说明 | 白衣 / 固定服装 / 待组合 | 形象资产：环境内电影艺术照；设计资产：白底扩展分区制作参考图 | 环境内 / 简洁灰白 | A3 = A1 + A2 | 是 / 否 |

只在一个镜头出现的迎宾、路人、群众、守门者，不默认进入角色资产表。

主角色人物设计资产不要默认做多格情绪表情。人物设计资产的默认脸应是中性常见表情：正脸自然、脸部肌肉放松、嘴唇自然闭合或轻微放松、眼神正常。复杂情绪表演如果只靠图片提示词里的几个情绪词，模型容易生成浮夸、不真实的表情符号；因此恋爱、悲伤、怀疑、愤怒、崩溃等表演应留到分镜和视频提示词里，按镜头细化眼神、眉心、嘴角、呼吸、手部和身体停顿。只有在老胡明确要求表情测试时，才单独做表情测试参考图，且不得替代人物设计资产。

如果群众不是一个具体角色，但会连续参与围观、起哄、轻冲突、仪式或集体反应，并且需要稳定年代感、服装气质和群体真实感，可以进入群像人物资产表。群像人物资产使用 `G` 系列编号，例如 `G1 邻家孩子群像`。它只固定“这群人是什么类型的人”，不固定每个群众的具体脸、姓名和单人三视图。具体动作、台词、谁从哪里进入、谁伸手触碰道具，应留给分镜和视频提示词。

人物资产不要一上来只做三视图。先判断是否需要人物形象资产来立住气质：如果角色是主角、封面主体、重要女性 / 男性角色、长期系列角色或需要明确“美感、气场、光影氛围”的人物，应先做人物形象资产。形象资产使用环境、光影、服装材质、姿态和眼神确定第一眼感觉；设计资产再用白底四区图锁定五官、比例、服装和细节。

人物形象资产和人物设计资产必须作为两套提示词输出。形象资产写环境内电影级正面 / 半正面艺术照，包含具体场景、光源方向、照亮部位、阴影结果、人物姿态、服装材质、眼神、构图和叙事瞬间；设计资产写白底 / 简洁背景扩展分区制作参考图，包含正面、侧面、背面、面部正立特写、左手特写、右手特写、配色板、局部细节、比例照和音色文字说明区。禁止用“左侧脸部近景 + 右侧三视图”的旧版混合图同时冒充两者。

两套提示词不拆成两个资产编号。它们只是在同一个资产编号下提供两种生成入口：`A1 人物形象资产提示词`、`A1 人物设计资产提示词`。生成候选图后，老胡选择其中一张或一组作为最终参考，视频提示词只调用 `A1`。禁止把同一人物写成 `A1-1`、`A1-2` 这种子资产编号。

POV 主体也必须进入正常人物资产判断。第一人称 POV 只决定后续怎么拍，不代表角色没有身体。只要 POV 主体是主角、跨镜头出现或承担观众代入，人物资产表里必须为他建立完整人物资产，写清年龄、身高、头身比、上下身比例、肩宽、左手大小、右手大小、脚步尺度、服装、鞋、书包、正面 / 侧面 / 背面、视线高度和音色文字说明。可以在处理方式里注明“视频阶段少正脸、主要用手部 / 袖口 / 背影 / 低视线调用，并用【形象参考@xx】【音色参考@xx】进入基础设定”，但不能把他降级为局部身份锚点。

人物资产必须拆清稳定身份、固定定装、场景配件和动作道具。稳定身份锁脸、年龄、身高、体态、发型、基础气质、左手、右手和基础音色；固定定装锁持续穿着的服装；场景配件只在指定场景出现，例如书包、雨伞、帽子、孝布、围裙、工具包、篮子；动作道具只服务当前动作，例如打火机、勺子、毛巾、药碗、锄头。人物设计资产的主视觉三视图不应把场景配件做成常驻外观。需要展示配件时，放在局部细节区或状态模块，并写明适用场景。当前案例：A5 姐姐的书包只属于放学路 / 报丧状态；包汤圆、吃汤圆、丧事和结尾镜头调用 A5 时必须写明本镜不背书包。

人物设计资产必须把基础音色做成图片上的文字说明区。会说话、VO 或画外音的角色，设计资产提示词里要写清 `音色说明：...` 模块，包含音色、音线、年龄感、地域口音、语速和常态情绪；若已有音频参考，还要记录 `音色参考` 编号。交给视频提示词时，人物行推荐使用 `角色名：【形象参考@A1 角色人物设计资产】【音色参考@V1 角色音频参考】稳定身份、本镜状态和本镜出镜 / 出声方式。` 本镜哭腔、病弱、喊叫、压低、隔门闷声、电话失真和 VO 回响由视频提示词写进 `【画面内容】`。

如果角色长期复用且会换装，推荐链路是：

```text
人物形象资产
→ 人物素体资产（白色素衣 / 中性服装，锁脸和身材）
→ 服装 / 妆造资产（锁版型、层次、材质、颜色、纹样和配饰）
→ 组合设计资产（素体穿上指定服装后的白底四区参考图）
```

如果角色只在一个场景出现且不换装，可以直接做人物形象资产 + 人物设计资产；若称为人物定装资产，也必须拆成定装形象资产和定装设计资产。仍要区分“气质展示”和“制作参考”，不要用一张图同时承担所有职责。

当输入里同时出现人物参考图和服装参考图时，不要只输出一条笼统的人物定装提示词。必须先拆清楚：

```text
人物参考图：固定脸、身形、年龄感、体态、基础气质、头身比。
服装参考图：固定校服 / 制服 / 日常服的版型、层次、颜色、穿法和身份识别元素。
组合形象：把人物参考和服装参考合成为同一个定装资产，用于后续视频调用。
```

人物资产图需要严格制作参考时，优先采用信息优先级版式：正面 / 侧面 / 背面三视图、大尺寸纯头部脸部正立特写、厘米标注全身比例图是主信息；左右手、紧凑色值卡、局部细节模块和音色说明是辅助信息。脸部特写只展示头部和五官妆容，不做颈肩半身图；左右手必须有，但要小面积手模级，不抢脸和三视图画幅；配色只做紧凑十六进制 RGB 色值卡；全身比例图要用厘米测量线标注脚底、脚踝、膝盖、髋部、腰线、胸线、肩线、颈根、下巴和头顶，不用 1、2、3、7.5 这类抽象刻度。服装描述建议按 `内 / 中 / 外 / 腰 / 下 / 足` 或 `上衣 / 外搭 / 裤装 / 鞋 / 配饰` 展开，避免只写“穿校服”“穿 T 恤”导致模型丢失层次。

当人物参考图和服装参考图合成定装时，还要写清身体适配。服装参考图只提供款式方向，不能机械复制成一件挂在人身上的衣服。提示词必须检查：肩线是否利落，胸口是否有自然立体省道或柔和弧度，腰侧是否收住，腰带 / 系带是否压出高腰线，裙摆 / 裤型从哪里展开，面料是贴合还是垂坠，是否避免松垮无形、胸前塌陷、腰线消失、过度暴露和网红紧身性感。服装细节还要继承穿法逻辑和视觉重心：参考图里偏侧斜绕的腰部层次，不能被机械居中成正面毛巾、围裙或大结；鞋履要写清鞋头形状、闭口 / 露趾、浅口 / 深口、踝带、跟高、材质、颜色和气质。当前案例：林栀的深灰无袖上衣要按她身形修身合体，浅灰系带要偏侧斜绕并强调细腰和高腰比例，蓝灰水墨长裙从细腰处自然展开，鞋履固定为珍珠白冰银尖头浅口踝带低跟单鞋。

人物设计资产还要锁高光体态和左右手正确性。三视图要展示角色当前年龄段最好的状态：脊柱拉直、胸腔舒展、肩背打开、颈线拉长、腰背挺住、重心稳定，避免含胸驼背、圆肩、缩脖、头颈前伸和塌腰。左右手参考要按人物自身左右写，不按图片左右误标；手背朝镜头、指尖向下时，人物自己的左手拇指在画面右侧，人物自己的右手拇指在画面左侧。左右手要同年龄、同肤色、同手部比例，但拇指方向相反，不能像同一只手复制两遍。

人物设计资产必须增加造型账本一致性检查。先列清固定定装清单：上衣、下装、腰部结构、包、发饰、耳饰、项链、鞋履、手腕是否佩戴饰品；再让三视图、手部特写、局部细节、配色板和比例照都从同一份清单继承。局部细节区不是自由装饰拼图，必须一物一标，标签和物件对应。错误风险包括：发圈在三视图里属于头发，却在手部区复制成两个手环；鞋履和整体气质不搭；鞋子模块标签错位。当前案例：林栀 A1 发圈只属于发间，左右手腕干净，鞋履固定为珍珠白冰银尖头浅口踝带低跟单鞋。

人物设计资产的可复制图片提示词还要遵守引号纪律：代码块里只有画面真实要出现的文字才写成文字指令，不用引号做强调或解释。手部模块只让画面标注左手、右手；如果要说明它们是人物自己的左右手，把解释写成解剖方向规则，不写成长标签。音色模块写成标题文字为：音色说明；正文文字为：具体音色描述。不要写标注“人物自己的左手”、标题为“音色说明”这类引号式表达。

## 四、场景资产表

| 资产编号 | 场景 | 时间 | 地点 | 空间结构 | 光影 | 可运动路径 | 推荐图片形态 | 需要图片资产 |

| S1 |  |  |  |  |  |  | 扩展分区场景设计板：左上四机位 + 右上鸟瞰 + 底部固定构件细节带 / 视频第一帧 | 是 / 否 |

资产唯一性先于资产数量控制。一个图片资产只能固定一个确定对象：一个人物、一件道具、一个场景或一套服装 / 妆造。不要为了省资产，把场景、桌子、汤圆、硬币、人物手部和动作合成一个“资产”。这类合成图应归为分镜图、首帧图或视频参考图。多个元素都需要稳定时，就拆成多个资产，再在分镜和视频提示词里组合。

资产类型必须按失真来源判断。剧本里出现“玩具”“电话”“汤圆”“课桌”“药碗”等名词时，先问本轮生成最容易失控的是物品本体，还是物品所在的年代空间 / 陈列环境 / 使用场所。如果失控点是商场货架、小卖部公共电话角落、教室桌椅布局、灶房光源、柜台陈列、地砖墙面等空间组织方式，应建场景资产；如果失控点是玩具车本体、座机本体、完整白汤圆外观、单枚硬币、药碗等具体物的形状材质和特写，才建道具 / 物品资产。注意互斥可见状态要拆开：完整白汤圆和包入前 / 吃出后的硬币不能合成一个“硬币汤圆”资产。当前案例：商场拒买玩具闪回要固定的是普通商场玩具货架区的年代环境，因此做 `S7 商场玩具货架区`，不是 `P10 玩具车`。

只出现一次、不会再次进入或多角度复用的场景，不默认进入场景资产表。

固定场景资产优先做扩展分区场景设计板，而不是单张漂亮图或平均四宫格。至少同时处理主入口、正面 / 左侧 / 右侧 / 反向四机位、高位鸟瞰总平面、人物可运动路径、关键固定构件、材质细节和光源方向。

当一个固定场景会被反复进入、需要正反打、左右侧视角、人物走位或镜头拉高展示全局时，扩展分区设计板左上 2×2 四机位使用：

```text
正面视角：定义场景主入口、主构图、主要物件和纵深。
左侧视角：以正面视角向左转动 90 度。
右侧视角：以正面视角向右转动 90 度。
正面反打图：从正面视角对面看回去。
```

四机位的核心不是“多几张图”，而是“同一个空间能被不同机位反复使用”。所有视角必须保持同一场景布局一致，视角逻辑正确，物体空间逻辑正确。右上鸟瞰必须解释入口、出口、固定构件、四机位和人物动线；底部细节带必须回指上方结构的材质、颜色、连接、磨损与记忆锚点。入口、窗户、固定家具、墙角、灶台、柴火堆等关键结构不能在不同区域里换位置或换材质。

左上四机位不能写成“功能拼图”。比如把格 1 写饭桌、格 2 写灶台、格 3 写遗像桌、格 4 写另一个反打空间，本质是四个功能区，不是同一个位置从不同方位看过来的图。正确写法必须先定义正面视角，再让左侧、右侧和反向视角围绕它旋转或反打，由右上鸟瞰复核布局。底部细节带只展示空间本体的固定节点；可移动剧情道具单独做物品资产。

所有人物、服装、物品和场景设计资产在进入提示词前都要建立 `细节来源映射`：每个局部模块对应哪个总览视图、位于哪个部位 / 空间坐标、朝向和数量是什么、局部只新增哪一层观察精度。转换顺序必须是 `先把细节的载体和位置写回总览 → 再写局部放大`。底部出现而上方没有出现的 Logo、文字、纹样、配饰、接口或固定构件一律判为新增设计，先退回资产规划；不能依靠“保持一致”让模型自行猜位置。

桌面、案板、灶台边、手工台、祭祀桌等局部空间，如果承载关键动作、儿童 POV、正反打、手部操作、人物围桌互动或动作连续，必须先拆清楚：灶房一角、墙面、入口、窗户、固定光源和动线属于场景资产；桌子、案板、碗、汤圆、硬币、药碗、针线篮属于道具 / 家具资产；人物手部和站位属于分镜或视频提示词。局部场景资产不能把可移动道具和动作混在一起。
