# 视觉生成模型注意力与提示词编译参考

## 作用与边界

这份 Reference 不教模型架构，也不把所有平台假定成同一种实现。它只提炼对老胡 AI 视觉生产稳定有用的共同机制：图片和视频模型怎样从文字与参考图中分配有限注意，哪些信息容易被遗漏、串绑或平均，专业设计怎样编译成高有效密度的模型输入。

它由 `laohu-visual-assets` 在图片提示词编译、F人物主视觉、多来源制作资产和复杂构图中调用；由 `laohu-video-prompt` 在多主体、多参考、复杂动作、图生视频和长序列中调用。人物、服装、美术、场景与剧本仍由各自 Skill 决定内容，本 Reference 只负责把已经成立的决定转成模型更容易执行的表达。人物结果图与人物视频还必须消费共享`人物表演提示词规范`；美术风格则消费`画面风格与画质规范`形成的作品结果图成像合同，不能让已有专业材料停在未调用的共享文件里。

以下三类内容必须分开：

```text
事实：官方文档或论文能够支持的模型现象与平台行为。
推论：从共同现象推导出的跨模型生产规则。
适配：特定模型的字符、权重、负面词、参考图数量和参数，只进入模型适配，不冒充通用机制。
```

## 一、先理解注意力，不把模型当成人类读者

### 1. 模型主要接收概念、属性、关系和位置，不替作者理解人生因果

文本条件通常通过词元与图像 / 视频特征发生关联。研究反复观察到：模型会遗漏主体、把属性给错对象、让不同实体互相泄漏，或在复杂组合中降低对提示词的遵从。`人物很强却从不证明自己`、`把感情压进旧物`这类小说式解释，对人类有意义，却没有直接规定脸、身体、衣物、空间或动作怎样出现。

因此进入模型正文前必须做一次视觉编译：

```text
人物或世界判断
→ 观众首先感到什么
→ 这种感受由哪些可见 / 可听证据造成
→ 哪一项是主证据
→ 其余信息怎样支持或退让
```

模型正文描述结果，不解释作者为什么这样设计。原因、候选比较和人物小传留在专业设计包；代码块只保留会改变像素、运动、声音、构图、身份或连续性的内容。

### 2. 信息越多，不等于有效控制越多

不同平台对长提示词的处理方式不同，但共同风险相似：承重概念被长清单稀释，后部细节被忽略，多主体属性串绑，互相冲突的风格与动作被平均。有效信息密度不是单位字数包含多少名词，而是每句话是否推动同一个主结果，并且模型能够判断它属于谁、位于哪里、何时发生。

提示词进入正文前建立内部注意力合同：

```text
唯一生成任务：这张图 / 这段视频最终必须成立什么。
主注意力：观众第一眼或当前时刻主要看什么。
主证据：哪一个轮廓、表情、动作、接触、色块或空间关系证明任务成立。
支撑证据：哪些信息只用于托住主证据。
主动退让：哪些环境、装饰、特效、次要人物、摄影参数或风格机制不能争抢。
不可丢锚点：通常3—6项，可少不可机械凑数。
```

这张合同是任何视觉生成的基础完成条件，不按任务简单或复杂、草稿或成品决定是否执行。图片、视频、封面、单张成品图和B / W / M / S / A / G制作资产，只要提示词将被交给模型产生结果，就必须完整判断唯一任务、主注意力、主证据、支撑证据、主动退让和不可丢锚点。任务复杂度与交付阶段只改变锚点数量、描述长度、通道选择和调用回执篇幅，不改变合同是否执行；快速试验可以得到很短的正文，但不能跳过任何判断。

注意力合同是内部筋骨，不机械进入最终提示词。三段式、资产板式和视频镜头块只是表皮；没有完整注意力合同，分段再整齐也仍是同权清单。

#### 从“规则存在”升级为“控制强度成立”

验收不能停在关键词出现。每个承重维度按四级判断：

```text
0级｜缺失：没有这项控制。
1级｜点名：写了焦点、构图、光影、情绪、声音或动作，但模型仍需猜对象、关系与结果。
2级｜可执行：对象、位置、变化和结果清楚，但主次偏弱，竞争信息仍可能分流。
3级｜主导：它通过至少两种相互独立的可见 / 可听机制获得优先级，其他元素明确退让，并与唯一主结果同向。
```

承重维度必须达到3级；支撑维度达到2级即可；主动退让项不得被写成新的1级焦点。总分、平均分和“多数项合格”都不能补偿主结果不成立。人物图写了“焦点在脸上”只算点名；脸同时拥有最高局部清晰度、稳定眼神光、冷暖或明暗反差，而前景与背景降低对比和锐度，才形成主导。视频写了“情绪变化”只算点名；精确触发、异步身体变化、对手反馈、声音结果与停点共同闭合，才形成主导。

机械脚本只能拦截0级与部分1级错误，不能宣布画面已经达到3级。正式交付必须由业务 Skill 对承重维度逐项作强度判断，并用可见 / 可听证据说明为什么不是“有就算过”。

完整判断不等于完整投喂。注意力合同完成后，把候选信息再做一次`必须锁定 / 方向引导 / 模型补全`分类：

- `必须锁定`：缺失会改变主体身份、题材归属、唯一主结果、关系、主轮廓或下游必要复现。
- `方向引导`：规定气质、色域、材料行为、动作能量、构图或光线的范围，允许模型在范围内选择局部答案。
- `模型补全`：不承担当前身份、关系和结构复现的纹样排列、次级配件、自然衣褶、背景填充与非承重摄影细节；默认不进入正文。

三类是内部编译决定，不机械变成最终提示词的三个栏目。

### 选择性编译门

上游专业结果是设计库不是投喂清单。每项信息只有在以下至少一项成立时进入正文：缺失会改变主结果；会造成身份、题材或关系误读；在当前主体尺寸真实可见并承担非默认人物记忆点；或为主证据提供必要摄影托举。其余信息留在设计包、人工验收或下游制作资产。

`生成开放空间`不是模糊指令，而是有意不控制已经被人物母型、色彩和材料方向覆盖的次级局部。每增加一项精确控制，都要能回答它替代了哪部分开放空间、为什么值得；无法回答就降为方向引导或删除。

交付前做过度控制冲突审稿：如果同一帧同时精确规定眼睑、虹膜、眉峰、嘴唇、牙齿、双手、双脚、发丝层次、衣摆、纹样位置、前景遮挡、背景奇观和多项摄影焦点，先判断它们是否都承担唯一主结果。不能证明者退出正文。`局部遵从但整体僵硬`属于选择性编译失败，不以增加更多细节修复。

### 3. 属性必须靠近所属对象，关系必须可定位

多个对象出现时，不把所有形容词集中写在段尾。按`对象 → 本对象属性 → 本对象动作 / 位置 → 与其他对象关系`组织，使颜色、材料、衣物、动作和表情就近绑定。

```text
弱：一男一女站在院中，黑衣、白衣、冷静、惊讶、持剑。
强：画面左侧黑衣男子垂手握住未出鞘长剑，表情冷静；画面右侧白衣女子后退半步，眼睛骤然睁大。
```

空间关系使用左 / 右、前景 / 后景、靠近 / 远离、朝向、遮挡、接触点和承托物；时间关系使用起点、触发、变化、结果和停点。只列名词，不提供绑定和顺序，会让模型自己分配。

### 4. 模型正文统一使用镜头可执行语言

本项目把最终交给生图或视频模型、能够通过成像或录音结果验收的表达称为`镜头可执行语言`；当它以连续自然语言组织静态或动态画面时，也称`镜头可执行的画面叙述`。它不是新的提示词版式，也不是要求所有图片都变成影视剧照；它是结果写真、B / W / M / S / A / G制作板、封面和视频镜头块共同遵守的编译标准：先在内部完成导演判断与专业设计，再把需要模型执行的部分翻译成对象、关系、动作、光色、声音和终态。

正式文本分为三类，不能混写：

```text
先验召回：题材、媒介、身份、成熟风格或摄影母型；负责缩小模型选择范围，但不能代替当前画面证据。
镜头控制：谁 / 什么位于哪里，正处于什么状态，怎样动作或变化，与谁发生关系，最后看见或听见什么；这是正文主体。
作者解释：为什么这样设计、人物心里明白什么、观众应该感到什么、这一镜象征什么；只留在内部工作卡，翻译后才能进入正文。
```

每条承重句按需包含：

```text
控制对象
+ 本次可见 / 可听起点
+ 空间位置或关系对象
+ 动作、变化方向、幅度或路径
+ 摄影机、光线、环境或声音响应
+ 可见 / 可听终态
```

不是每句话都要机械填满六项；但一句话如果既不提供模型熟悉的先验，也不能改变像素、构图、运动、声音、身份、物理关系、注意力或连续状态，就不进入模型正文。审稿时执行`镜头—麦克风测试`：演员或物体能否执行，摄影机能否拍到，麦克风能否录到，结果能否从生成画面或声音中判断。只能回答“为什么”的句子仍是导演阐述。

```text
解释性：她带着一个忍不住要问的问题朝熟人走来，让观众感到她很亲近。
可执行：她从石柱后快步转出，目光越过镜头落向右前景的熟人；右脚刚踩上石板，左脚仍在身后蹬地，嘴唇已经张开，右手抬到胸前，肩后长发和外层衣摆沿原方向迟半拍扬起。

解释性：她把所有答案逐一排除后，终于心虚起来。
可执行：她指间转动的草茎停住；视线先落向膝上书册，再落到鞋尖，嘴唇两次轻动却没有出声，下一口呼吸变浅，随后才重新抬眼。
```

#### 4.1 静态图片：用单帧承载前后状态

静态图没有真实时间轴，但可以截取`事件临界帧`：前一瞬仍留有物理痕迹，当前关系与行为正在发生，下一动作已经具有明确方向。结果写真、人物主视觉、封面主体和叙事首帧优先从下列通道选择2—4项承重，不让所有通道同权表演：

这条内部关系称为`单帧因果`：`过去痕迹 / 当前关系响应 / 下一趋势`。它不依赖`刚、仍、正在、即将、晚半拍`等固定时间词；时间词只是可选连接。即使删掉这些词，重心、眼线、接触、受力、惯性、环境余波和摄影机位置也必须让三种关系仍可见、可推断。

```text
关系对象与眼线
面部正在形成或尚未完成的变化
呼吸、颈肩、躯干重心、手指与步幅
发丝、衣料、饰品和道具留下的惯性或受力
前景遮挡、人物距离和摄影机信息权限
风、水、尘、植物、蒸汽、光斑或人群留下的环境回声
```

脸不是唯一情绪器官，环境也不是自动增加的氛围层。所有通道必须共同证明一个主要人物状态、关系动作或视觉结果；服装、光线和场景只能支持、延迟响应或证明余波。若人物、衣发、道具、背景和摄影机都处于最稳定、最完整、最正面的展示状态，画面通常只剩站桩或目录照。人物生命感、前后帧和人物—摄影机—环境闭环的详细方法继续读取`skills/laohu-visual-assets/references/06_人物生命感与现场摄影关系.md`。

#### 4.2 视频：把情绪写成异步传播的时间因果

视频使用`时序镜头可执行语言`：

```text
起点与人物保护状态
→ 精确台词、动作、声音、接触或信息触发
→ 2—4个承重通道按先后异步变化
→ 主要结果到达峰值
→ 对手、道具、空间或声音留下即时影响
→ 静止余波与下一状态
```

眼神、眼睑与眉、口唇与下颌、呼吸、声线、颈肩、手指、躯干重心、步幅、关系距离、衣料、道具和环境都可以承重，但不能从第一帧同时达到最大强度。先写触发，再写反应；能被人物控制的通道与意外泄露的通道允许不同步。环境只响应真实动作、受力、风、水、声音或光源，不替人物随机制造落叶、粒子和飘带。人物表演的八维节拍、禁止提前反应和台词—听者同步关系继续读取`skills/laohu-video-prompt/references/01_文戏对白与人物表演.md`。

#### 4.3 编译完成门

模型正文交付前逐句检查：

1. 这句话属于先验召回、镜头控制还是作者解释？
2. 如果是先验召回，它是否明确只负责当前需要的题材、身份、成像或单一风格机制？
3. 如果是镜头控制，主体、位置 / 时间、变化和结果是否能够验收？
4. 如果是作者解释，是否已经翻译为关系对象、眼线、身体、衣发、道具、环境、摄影机、光线或声音证据？
5. 全部承重通道是否共同指向一个结果，而不是各自展示不同情绪与美术效果？

机械脚本可以拦截`让观众、为了表现、这一镜证明、不是……而是……`等明显泄漏，但不能靠禁词表完成语义判断。最终反向审稿必须人工回答镜头—麦克风测试。

## 二、用四层完成一次提示词编译

四层是内部因果，不要求最后出现四个栏目。

### 灵魂：只保留一个承重结果

先回答这次生成到底在造什么。人物主视觉不是同时展示人物全部人生、世界全貌和服装技术结构，而是截取一个值得被观众看见的瞬间：人物此刻的目的、关系对象和未完成状态是主证据，脸、身体、服装色彩、妆发、空间、光线和摄影机共同把它变成完整人物答案。它可在人工选定后成为B / W / M的拆解源图，但不为拆解强行切回正面全身展示。

场景写真、道具写真、制作资产和视频分别改写承重结果：

- 人物主视觉：一个具体瞬间中的角色吸引力、活人关系与穿搭后的整体人物气质。
- 场景写真：空间被使用时的身份、尺度和第一记忆。
- 道具 / 产品写真：形态、材料、功能或价值感的主证据。
- 制作资产：身份、结构、侧背面、材料或拓扑能够被下游复现。
- 视频：一个可观察变化从起点经过触发到达结果。

一张图或一个镜头只有一个主结果。其他专业信息可以存在，但必须能回答“它怎样帮助主结果”，否则外移、降级或另建资产。

### 筋骨：建立已知母型与证据层级

先给模型训练中高频、稳定的母型，再做原创变化：

```text
已知对象 / 服装 / 场景 / 摄影母型
→ 身份与题材限定
→ 轮廓和结构的2—4项原创变化
→ 色彩、材料、妆造和使用痕迹
→ 摄影机、光线和背景怎样突出主证据
```

例如先写清汉服体系中的交领襦裙、圆领袍、道袍、褙子、侠客短打或其他可识别品类，再说明裙摆、肩片、分片、穿法和材料怎样改造。只写项目自造的`燕尾行旅衣`或`灵蚕丝`，是在要求模型从无稳定母型处猜测。

证据按三层组织：

```text
主证据：缺失就整张图失败。
身份支撑：帮助读懂人物、世界和功能，但不抢第一落点。
质感证据：近看增加可信度，远景看不到时不承担主任务。
```

### 血肉：用高频词召回，用具体描述完成原创

模型熟悉词负责召回成熟分布，特性描述负责把结果变成当前作品：

```text
高频类别词＋形状＋结构位置＋材料表面＋受光反应＋动作或使用状态
```

世界观专有词可以保留名称，但必须紧跟视觉翻译：

```text
冷玉扣：半透明青白玉石扣，边缘在侧光下呈窄亮线，中心保持乳白矿物浑浊。
山径线：一条从右肩斜向左腰收拢的细银色刺绣结构线，宽度均匀，在腰侧停止。
雾绫：轻薄半透明灰白纱层，柔软垂坠，边缘细密，无硬塑料反光。
```

视觉翻译至少回答真正影响当前画面的维度，不机械填满：形状、尺度、所在部位、颜色、表面、软硬、透光 / 反光、垂坠 / 张力、运动状态、与相邻材料的差异。

抽象感受也必须翻译成观众能直接读到的底色：

```text
生人勿近 → 眼神稳定不游移，嘴唇闭合，肩颈展开，身体与他人保持距离，冷硬侧光切出面部平面。
灵动亲近 → 眼神先于身体转向，眉眼开放，重心轻微前倾，暖色面部主光，衣料有小幅轻快响应。
```

这里描述的是感受怎样显现，不解释人物为何形成这种性格。

### 表皮：把决定编译成当前资产真正需要的格式

结果图写真内部必须完成`基础设定 → 氛围与画质 → 画面内容与构图`三段职责，标题可以显式，也可以融合为连续画面叙述；B / W / M / S / A / G继续使用各自规格板；视频继续使用三段式和逐镜块。表皮只负责让模型与下游正确接收，不能取代前三层的选择。

正文优先使用正向、具体、直接的结果语言。需要排除的具体对象放在模型独立负面通道、代码块外的人工验收或模型适配层；没有独立负面通道时，也优先把否定改写成当前唯一正面状态，例如`锁定机位`、`天空清澈`、`衣袍从腰到鞋面连续闭合`。

## 三、图片提示词的注意力编译

### 1. 先分配单帧证据尺寸

静态图只有一个瞬间和有限像素。全身、脸部微表情、服装微纹理和宏大环境不能同时达到最高可读级别。先按图片用途分配：

| 图片任务 | 主证据 | 支撑证据 | 应主动退让 |
|---|---|---|---|
| F人物主视觉图 | 当下目的、关系反应、未完成动作与整体角色吸引力 | 可见脸身、穿搭轮廓、妆发、主配色和1—3个记忆点 | 不可见的侧背面、鞋履、内里技术结构和无关宏大背景 |
| 头肩肖像 | 五官、妆面、发型和表情 | 肩颈服装与背景色 | 鞋履、全身比例、场景拓扑 |
| 服装效果图 | 穿着轮廓、层次、色彩和材料行为 | 人物姿态、发妆协调 | 脸部微纹理、复杂环境事件 |
| 制作规格板 | 结构、视角、材料、参数、对应关系 | 中性光与简洁标签 | 叙事氛围、电影景深、复杂姿态 |
| 场景写真 | 空间身份、尺度、路径和光源 | 一处人物 / 物件尺度参照 | 人物精细妆面与多项服装细节 |

如果一个要求在当前主体尺寸下不可见，就不能作为不可丢锚点。需要同时锁脸、全身、侧背面和内里时，应让消费模型将F的可见事实与人物 / 服装 / 妆造正文结合，分别派生头肩、B / W / M制作板。不靠同一张主视觉图兼任所有分辨率和结构证据。

### 1.1 建立视觉主导合同

结果图与承担观看任务的制作板在正文前建立：

```text
第一眼：唯一主焦点，观众先读到哪一个脸、动作、接触点、产品结构或空间关系。
第二眼：哪项身份、身体、服装、道具或结果证据解释第一眼。
第三眼：哪项世界、场景或质感信息补全语境。
主导机制：焦点 / 锐度、局部明暗、冷暖 / 饱和、面积尺度、眼线、引导线 / 框景、运动方向中至少两项怎样共同抬高第一眼。
主动退让：前景、背景、服装高光、装饰、奇观、次要人物和特效分别怎样降低对比、锐度、饱和、面积或完整度。
```

第一眼必须拥有至少两种独立机制；第二眼可以共享其中一种，但不能在两种以上机制上与第一眼同强；第三眼只负责语境。不同机制不能互相抵消：若脸最清楚，天空却更亮、前景却更大更黑、服装却拥有最强饱和，实际第一眼仍可能漂移。构图术语只有在写出线条从哪里进入、经过什么、最终落到哪里时才算执行。

人物结果图按任务分流：

- `静态关系帧`：用关系对象、未完成动作、眼线、重心、手势、衣发惯性和环境回声，证明人物正在回应什么。
- `动态动作帧`：除单帧因果外，必须闭合`意图 → 支撑 / 起势 → 力量来源 → 单一力量或运动路径 → 接触 / 临界接触 → 受影响对象 → 结果与余势`。选择一个准确动作相位，不把挥剑、衣摆、受伤者、天空奇观和粒子同时设为高潮。

动态人物图还要锁定摄影机所在轴侧、可读人体轮廓、承重脚或支点、接触点以及结果方向。高速、风压、碎片和VFX只能证明同一力量线，不能替代力量来源与接触结果。

### 2. 风格名称必须分权，不同权堆叠

名称锚点有召回价值，但每个名称必须只负责明确机制：

```text
主锚点：决定第一眼审美世界，只保留一个。
机制锚点：最多补一项构图、色彩、光影、材料或运动机制。
文化根系：提供形态、色域或材料来源，不再争夺摄影风格。
```

正式提示词必须写出具体职责，例如`徐克《蜀山传》只负责云海纵深与浮峰尺度；张艺谋《英雄》只负责克制色块和人物剪影`。如果两个名字同时决定全部构图、色彩、光影和材料，就是让模型平均。名称越多，越要删掉不改变当前主证据的锚点。

`古偶唯美、港风、日系清新`等风格标签先由`laohu-art-direction`解压成作品级`结果图成像合同`，再进入本环节选择性编译。平台风格预设是外部实现手段，可能包含未公开的隐藏配方；未公开时不伪造其内部参数，也不让它替代作品合同。同一作品的正式图片和视频默认继承同一合同，只补当前任务真正改变的对象、关系、构图、光色和材料结果。

### 3. 摄影语言必须服务主证据

摄影参数不是高级感装饰。只写会改变画面结果的部分：

- 景别与主体占比决定哪些信息能被看见。
- 机位高度和方向决定身体比例、权力和观看距离。
- 焦段影响透视与空间压缩：中长焦适合突出人物和服装轮廓，广角更能证明环境纵深，但会改变近大远小。
- 光圈 / 景深决定背景退让程度；背景仍承担题材证据时，不能虚化到不可读。
- 主光写来源、方向、软硬和落点；补光 / 环境反光只托住暗部或轮廓。
- 调色写主辅色关系与明度层级，不用`高级、电影感`代替。

参数和画面结果冲突时，以主证据为准。例如完整角色写真若需要脸和服装共同清楚，可使用中长焦、适度浅景深和足以覆盖全身的焦平面；不为追求`f/1.2`把衣摆、鞋履或面部其中一项推入失焦。

### 4. 结果写真三段式的真正职责

```text
【基础设定】灵魂：图片类型、唯一用途、主体身份、已知母型与本图唯一承重结果。
【氛围与画质】统一先验：一个主锚点、一个按需机制锚点、各自明确职责；主辅色、光源、成像介质和材料总体质感。
【画面内容与构图】可执行证据：对象从整体到局部的层级描述；姿态、摄影位置、景别 / 焦段 / 景深、主光、第一落点、背景支撑和主动退让。
```

三段内部必须指向同一人物或对象。基础设定说清透灵动，氛围不能转为阴冷压迫，服装不能用厚重封闭轮廓，构图也不能让人物缩在宏大背景里。

三段职责必须成立，标题可以显式或融合。合并成自然语言时仍要保留三个职责的先后关系，但不得输出`灵魂、筋骨、血肉、表皮、注意力合同、主证据`等内部元语言。

## 四、视频提示词的注意力编译

### 0. 图片把因果压成一帧，视频把同一因果展开

图片阶段已经验证有效的内核可以进入视频，但不能原样复制静态细节。两者共同回答：唯一任务是什么、观众先看哪里、什么证据证明它、作品怎样成像、哪些信息主动退让。图片把`过去痕迹 / 当前关系响应 / 下一趋势`压进一个事件临界帧；视频把它展开为`可读起点 / 精确触发 / 变化传播 / 决定性结果 / 即时影响 / 余韵停点`。

跨图片与视频的共性按职责迁移：

| 图片中已经成立的能力 | 视频中的等效能力 | 不能误迁移成什么 |
|---|---|---|
| 作品结果图成像合同 | 全段稳定成像基线及合法阶段变体 | 每镜重新选风格、滤镜、导演或调色 |
| 单一第一落点 | 第一落点到决定性落点的注意力迁移 | 人物、摄影机、环境、特效和声音同权运动 |
| 单帧关系与未完成动作 | 人物目的、关系对象、触发后的行动策略 | 让人物只负责跑、转头、微笑或摆姿势 |
| 2—4个承重生命通道 | 触发后异步传播的表演、衣发、道具、环境与声音 | 全身全部部位同时变化 |
| 主构图、主光与景深托举 | 构图重组、焦点迁移、光线变化共同跟随注意力 | 每帧都做壁纸构图或无因动态光 |
| 必须锁定 / 方向引导 / 模型补全 | 稳定锚点、主变化、开放的次级运动分别控制 | 把图片设计全文重新投喂给图生视频 |

视频增加的不是更多字段，而是状态变化和不可换序。先保证时间零点作为画面能够成立，再只改变本段必须改变的部分；决定性时刻可以获得最高构图、表演、光色和声音预算，连接相位允许不完整、遮挡、模糊和普通。所谓“输入决定输出”只在高权重起点、身份、构图和成像方向上成立；输入图不能替视频正文决定人物为什么动、变化何时发生、结果怎样留下。

### 1. 视频比图片多一个时间竞争

视频同时处理每帧的空间身份与跨帧运动。文本不只要回答`是什么`，还要回答`谁在何时为什么变化，变化最后兑现什么`。每个生成单元先只设一个主要兑现，按需最多一个明确从属的次要兑现。动作、摄影机、环境、特效和声音若同时成为主变化源，模型容易丢失身份、运动路径或后半段指令；它们应分别承担铺垫、触发后兑现或结果余韵。

每个镜头先选一个主变化承载者：人物、物体、摄影机、环境、VFX、图形或声音。其余层稳定、延迟响应或只证明结果。多项变化必须形成因果或时间顺序，不能并排要求。

```text
动机 / 起点状态 → 铺垫与早期证据 → 精确触发 → 主变化与阻力 → 主要兑现 → 即时结果 → 余韵 / 稳定停点
```

这条链是时序因果，不是强制逐秒切段。一个镜头可以连续完成相邻两个相位，多个镜头也可以共同铺垫一次兑现；但换序后如果力量不变，就说明时间链没有完成。

### 2. 文生视频与图生视频分开

- 文生视频：提示词同时负责主体、场景、风格、构图和运动，因此先建立简洁空间基线，再写主动作与摄影机。
- 图生视频：输入图已经强力提供主体、构图、色彩、光线和风格；正文主要描述主体动作、环境运动、摄影机运动、速度、方向、时序与结束状态。重复大段静态外观会与动作争夺注意，甚至诱发模型重新解释人物。
- 首尾帧 / 多参考：分别写清每张输入控制身份、结构、状态、构图还是结束目标；同一属性只允许一个主参考。参考图之间冲突时，文字声明未必能完全抵消视觉输入，先修参考组合。

### 3. 多主体按位置和动作分别绑定

不要连续堆叠多人的服装、情绪和动作后统一写“他们”。用屏幕位置、外观短识别词或关系角色逐一绑定：

```text
左侧小师妹先转头看向右后方的大师兄；她说完后仍保持前倾。右后方大师兄只抬眼，擦剑的手在听见最后一个词时停一拍。
```

主体数量越多，单镜头动作越要减少。每增加一个承重人物，都必须有世界位置、屏幕位置、注意对象、动作触发和结束状态；不能满足时拆镜头或使用调度参考。

### 4. 抽象情绪只作为方向，动作承担执行

`悲伤、紧张、强大、轻盈、魅惑`可以概括方向，但必须由可见 / 可听变化执行：眼线、呼吸、嘴角、肩颈、手部、重心、距离、语速、音量和环境响应。视频模型尤其需要物理动词、方向、速度、幅度、参照物和停点；`衣摆迟半拍`必须说明相对身体哪次转身、沿什么方向扫过、何时回落。

## 五、高有效信息密度审稿

正式首稿先产出`高密度母稿`：把当前唯一结果所需的身份、主次、关系、动作 / 表演、摄影、光色、材质、环境、声音、VFX和终态全部闭合，再进入压缩。这里的“高密度”不是字数越长越好，也不是把所有专业字段写满；它要求所有高价值控制先有位置，任何承重空缺都不能被“简洁”掩盖。只有母稿通过强度门后，才删除作者解释、同义重复、当前尺寸不可见细节和模型可靠补全项。不得从短概要开始，在没有显式报错时就提前停止。

每句话内部标记但不输出：`锁定`（缺失会改结果）、`引导`（限定方向并留模型发挥）、`开放`（模型补全）。锁定句必须能改变像素、声音、动作、身份、物理或连续状态；引导句必须限定一个可观察范围；开放项不进入正文。有效信息密度看高价值控制占比，不看专业名词数量。

逐句执行四问：

1. 这句话控制谁或什么，属性是否贴近所属对象？
2. 它改变哪一项像素、构图、运动、声音、身份、物理或连续性？
3. 它是在提供可见结果，还是解释作者原因？
4. 删除后主结果、不可丢锚点或下游复用是否真的改变？

优先删除：作者解释、人物小传、同义评价词、同权风格堆叠、当前尺寸不可见的微细节、参考图已经锁定的静态外观、没有画面结果的摄影参数、具体负面对象、无来源粒子和不承担主任务的环境装饰。

必须保留：唯一任务、主体身份、主注意力、主证据、已知母型、原创差异、属性绑定、空间 / 时间关系、必要摄影结果、参考职责和结束状态。

出现下列任一情况，不能把提示词交给模型：

- 列出了许多信息，但不能指出唯一主结果。
- 同一层级有两个以上互相竞争的风格、情绪、动作或摄影目标。
- 专有名词没有高频类别或视觉翻译。
- 抽象人物判断没有变成观众能直接感到的脸身姿动或声画结果。
- 全身图要求毛孔级妆面，同时要求复杂服装内里和宏大背景全部清楚。
- 图生视频仍重复整段人物、服装、场景和风格，主动作只剩一句。
- 正文大量使用`不要、避免、不是、非某种风格`来定义结果。
- 摄影参数与想看清的证据不一致。

## 六、Reference调用回执

正式交付内部至少留下：

```text
唯一生成任务：
主注意力与主证据：
不可丢锚点：
主动退让：
模型已知母型：
需要视觉翻译的专有词：
风格锚点分权：
摄影 / 时间怎样服务主证据：
删除的竞争信息：
```

## 七、资料依据与证据边界

- [OpenAI Academy：Creating images with ChatGPT](https://openai.com/academy/image-generation/)：建议从用途、主体、动作、地点和风格等少量清楚信息开始；具体光线优于抽象评价；多参考图要说明各自职责，较小参考集合更容易管理。
- [Adobe Firefly：Write effective text prompts](https://helpx.adobe.com/id_en/firefly/web/work-with-images/generate-images/writing-effective-text-prompts.html)：强调简单直接的主体、描述词、感觉、风格和光线，并通过逐次修改逼近结果。
- [Google Veo Prompt Guide](https://ai.google.dev/gemini-api/docs/video)：把主体、动作、风格、摄影机、构图、焦点、镜头效果与氛围分开，并要求清楚描述动作与相机。
- [Runway Image-to-Video Prompting Guide](https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide)：输入图负责主体、构图、光线和风格，图生视频文字主要负责运动、摄影机和时间进程；建议从最关键运动开始再迭代。
- [Runway Gen-4 Video Prompting Guide](https://help.runwayml.com/hc/en-us/articles/39789879462419-Gen-4-Video-Prompting-Guide)：建议简单、正向、直接，抽象概念要翻译为物理动作，多主体使用位置或简单身份词绑定。
- [CLIP](https://arxiv.org/abs/2103.00020)：支持自然语言与视觉概念之间可以形成可迁移对应，但不等于模型具有人类式因果理解。
- [Prompt-to-Prompt](https://arxiv.org/abs/2208.01626)：表明文本词语与交叉注意可影响生成图像的空间布局。
- [Attend-and-Excite](https://arxiv.org/abs/2301.13826)：指出文本到图像模型会出现主体遗漏，并通过加强相关主体词的注意改善覆盖。
- [Training-Free Structured Diffusion Guidance](https://arxiv.org/abs/2212.05032)与[Compositional Text-to-Image Synthesis with Attention Map Control](https://arxiv.org/abs/2305.13921)：讨论属性绑定、实体泄漏、缺失实体和复杂构图对齐问题。
- [Time-Aligned Captions for Multi-Scene Text-to-Video Generation](https://research.google/pubs/talc-time-aligned-captions-for-multi-scene-text-to-video-generation/)：显示时间对齐的描述有助于多场景视频的文本遵从与视觉一致性。
- [Still-Moving](https://research.google/pubs/still-moving-customized-video-generation-without-customized-video-data/)：区分静态空间先验与视频运动先验，为“参考图负责外观、视频提示负责运动”的生产分权提供研究旁证。

这些资料能支持共同风险和编译方向，不能证明所有模型的词序权重、长度阈值和负面词机制完全相同。平台特定事实仍应通过当前官方文档与真实生成回传校准。
