# 短剧剧本到视频提示词编号与时长规则

> 用途：把已包含文字分镜的正式剧本稳定转换为资产设计和 AI 视频提示词，避免重复分镜、编号混乱、时长模糊和首轮测试文件不可直接使用。

## 一、根本目的

老胡要的不是“看起来像提示词的一段描述”，而是能从剧本场次一路落到真实视频生成测试的制作说明。

因此视频提示词任务必须先判断：

```text
表层需求：老胡是否只是说了一个画面、镜头、台词或题材。
真实目标：老胡是否要做一个可测试、可剪辑、可迭代的作品片段。
根本目的：本次输出是否能让下一轮生成、反馈、修改更稳定。
```

即使老胡没有直接说“先写剧本”，只要目标是生成视频提示词，也不能丢掉剧本来源。可以不做完整人物 / 场景资产，但必须至少先形成含集数、场号、镜号、画面关系、表演与结束状态的单场次剧本。

## 二、标准流程

视频提示词生成按以下顺序执行：

```text
镜头化单场次剧本（E-S-C）
→ 资产判断：是否需要角色 / 场景 / 道具 / 第一帧参考图
→ 取消独立分镜宏观表；逐镜读取剧本画面关系、语气 / 神态、参考时长和结束状态
→ 逐场建立 E-S-B 批次候选；每个新场次的 B 从 01 重新开始
→ 先过硬边界门，再过融合质量门，记录合并 / 拆批理由
→ 在批次内部把来源镜头编译为镜头01、镜头02……，每批重新起算
→ 如涉及人物情绪 / 台词 / 反应：在 laohu-video-prompt 内深化表演执行，不重写剧情
→ 生成三段式正式正文
→ 生成前检查、必经 VC 与最终复验
```

资产判断不是必须生成资产，而是必须判断是否需要资产：

- 文生视频足够：说明为什么可以跳过资产。
- 角色、服装、场景或第一帧需要稳定：先回到图片资产。
- 首轮概念测试：可以直接文生视频，但仍要在生产记录保留场次、源剧本镜头和批次编号；正式模型正文使用完整三段式。

普通叙事作品不再单独制作普通文字分镜。仅当作品是 MV、强媒介知识动画、需要故事板图像 / 预视化，或老胡明确要求专业分镜资产时，才保留独立 SHOT 交付。

## 二点一、源剧本镜头与批次映射

批次（Batch）是一次实际提交给目标视频模型的完整生成请求。正式编号使用 `E01-S02-B01`：E 是集数，S 是场次，B 是该场内的批次；每个新场次的 `B` 从 `01` 重新开始。历史 `VID` 只作兼容识别，新任务不再以它作为当前权威编号。

每个批次在代码块外的生产记录中必须列出它继承的 E-S-C 源剧本镜头：

- 一个 E-S-C 源镜头拆成多个执行镜头时，记录明确的一对多映射，不丢原镜号。
- 多个 E-S-C 源镜头并入同一批次时，只能选择同一场次内连续的镜头，并保留全部来源编号和原顺序。
- 视频负责人可以调整初稿景别、基础运镜和构图，但必须保留主要可见事实、人物关系、情绪触发、道具控制权和结束状态。
- 若需改变实际出画人物、事件顺序、冻结台词、关键道具由谁操控、关系结果或结束状态，停止编译并返回编剧。

## 二点二、场内批次边界

一个批次只能属于一个场次，不能跨场。批次候选按两道门判断：

```text
硬边界门：
同一场次 + 连续 E-S-C 来源
+ 参考时长、字符、输入参考、生成模式均在当次目标入口能力合同内

融合质量门：
前一镜的结果自然成为后一镜的条件
+ 人物、资产、空间、光态与动作相位可稳定继承
+ 对白、动作、反应和内部切镜共同完成一个不可换序的小结果
```

时长上限不是必须填满的配额。即使候选总时长没有超限，只要合并会造成后半段遗忘、人物或空间漂移、台词漏失、承重动作被吞、结束停点不稳，就必须拆批。反过来，也不能沿用旧模型的 5 秒、10 秒或 15 秒惯性，把一次可以稳定完成的连续事件机械拆碎。

目标入口能力合同必须记录模型、入口、模式、可用时长、字符、参考输入限制和证据来源。只有官方说明、真实入口显示 / 报错或可复现实测才能建立硬边界；未核验时标记未知，不把某一模型的历史参数写成全项目常量。用户指定“Seedance 2.5 最长 30 秒”时，也要在实际生产前核验本次入口；核验成立后 30 秒只是该入口当次上限，不是每批目标时长。

每个候选批次建立组合卡：

```text
批次ID：E01-S02-B01
所属场次：E01-S02
源剧本镜头（E-S-C）：
目标入口能力合同：
参考时长合计 / 确定生成时长：
硬边界门：
融合质量门：
合并理由：
开场状态：
结束状态：
与上批 / 下批的关系：
交接载体：
```

## 二点三、批次正式正文

每一批正式视频提示词使用：

```text
【基础设定】
【场景状态与氛围画质】
【画面内容】
```

生成平台不会知道上一批、全片设定或项目文件，因此三段正文必须自足，不能用“沿用全片”“参考上文”“同上一镜头”替代实际描述。批次ID、源 E-S-C 映射、组合判断、资产判断、剪辑说明、回传字段和相邻关系留在代码块外；代码块内只放模型需要的内容。

`【画面内容】` 先写一至三句本批时间因果主线，再写 `【镜头01｜景别｜机位 / 视角｜运镜 / 转场】`、`【镜头02｜……】` 等连续方头。每个新批次都从镜头01重新起算；这些编号是批内执行顺序，不取代源 E-S-C 编号。台词直接嵌入人物所在镜头的自然语言正文，与开口前动作、说话对象、重音 / 气口 / 口型、身体变化、听者反应和句后停点连续书写，不另列 `【台词】` 或 `【对白】`。

总时长由空间识别、动作完成、表演变化、完整台词、摄影机路径、结果停点和剪辑把手反推，在平台参数或代码块外写确定值。正文不默认逐秒拆死；只有局部动作速度、触发延迟、反应窗口或停点保持确需强控制时，才写少量相对时长。

字符限制也来自当次目标入口能力合同。未获得可靠证据时标记 `入口长度兼容性未验证`，只做字符实测，不用跨版本默认值冒充官方硬限制。超限先删重复、作者解释和不改变生成结果的说明；必要因果仍装不下时，减少非承重内容或拆批，不能删人物目的、精确触发、动作路径、接触受力、听者反应和结束状态。

## 二点四、批次之间与跨场转场

同场相邻批次先选择主接续类型：直接连续、同场重建、艺术转场、因果 / 声音桥或关系重置。上批已经完成的动作不在下批重演；下批从第一项新变化开始。

- 直接连续：上批真实生成后，从最后一次切镜之后选约 1—3 秒单一有效机位作为尾部连续性片段；混镜、强遮挡、失焦、变形或状态错误时缩短，必要时改用合格终帧与稳定资产。
- 同场重建：继承人物、道具、伤势、天气、破坏和世界位置，以终帧、干净构图参考或场景资产重新建立景别、轴线和屏幕投影。
- 艺术转场：以动作相位、遮挡、形状、颜色、光线、材质或声音作为共同交接载体，上批种下，下批接住下一相位并新增意义。
- 因果 / 声音桥：上批给出决定性声源、台词尾音、物体结果或因果问题，下批先接住后果再揭示新信息。
- 关系重置：明确断开临时站位、摄影方向和旧 GEO，只继承长期身份、剧情事实与必要音频结构。

跨场双端转场不把两场写进同一批。上一场最后一批只负责种下转场载体；下一场 `B01` 从该载体的下一相位接住，然后立即建立新时间、新地点和新场景状态。前批不预演下一场，后批不把旧场 GEO 当成当前空间。

相邻批次代码块外记录：

```text
上游批次：
A 已完成结果 / A 真实结束状态：
B 开场状态 / B 第一项新变化：
接续类型：
必须不变 / 允许变化：
交接载体：
真实参考：有效尾部片段 / 终帧 / 稳定资产 / 无
预计裁剪区：
```

直接连续必须满足 `A 真实结束状态 = B 开场状态`。计划尾帧不能冒充真实尾帧；上批生成后由 `laohu-generation-review` 二次验收，才能把真实尾部片段或终帧绑定给下批。

## 二点五、人物表情前置判断

逐镜编译时必须完成人物表情判断。只要镜头里有人物出镜、台词、沉默、反应、情绪转折、眼神交流、微表情或关系变化，就先判断是否需要在 `laohu-video-prompt` 内进行人物表演细化。

剧本里的语气 / 神态标注必须被优先继承。`角色名（语气 / 神态）：`、`角色名（V.O.，语气 / 神态）：`、`角色名（O.S.）：`、动作描述里的表情神态和独立镜号里的表情细节，都是表演来源。它们不能只停留在剧本里，也不能在视频编译时被改成“正常说话”。

判断标准：

- 表情是镜头核心任务：先以人物表演设计为主，再生成画面内容。
- 表情只是辅助状态：在画面内容中写短表演，不抢镜头时间。
- 表情不重要或无人出镜：不调用人物表演细化。

视频编译记录必须写清：

```text
是否需要表情细化：是 / 否
表情来源：剧本括号 / OS / 动作描述 / VO 回响 / 插入镜头 / 无
表情功能：核心任务 / 辅助状态 / 不需要
表情占用时长：确定值，例如 4 秒
推荐景别：近景 / 中近景 / 特写 / 大特写 / POV 手部替代表情
表情设计入口：laohu-video-prompt / 画面内容短句 / 无
```

如果需要人物表情细化，先输出人物表演设计，再嵌入 `laohu-video-prompt` 的画面内容。不要先把画面动作写满，再临时塞表情。

转译示例：

```text
剧本：奶奶（忍着哭）：饭莫挑，天冷了晓得添衣裳。
分镜：表情来源=剧本括号；表情功能=核心任务；表情占用时长=3-4 秒；推荐景别=近景 / 特写。
视频提示词：奶奶强忍眼泪，眼眶发红，内眉上抬，嘴角向下压住，喉咙吞咽一下才继续说话，拿碗的手指轻微发抖。

剧本：父亲（压着火）：你啷个这么不懂事？
分镜：表情来源=剧本括号；表情功能=辅助状态或核心任务，按剧情判断；表情占用时长=2-3 秒。
视频提示词：父亲眉头压低，下颌绷紧，嘴唇压紧后才开口，声音压得很低，垂在身侧的拳头收紧，呼吸被硬生生压住。

剧本：小安（哭腔）：我就是想要嘛。
如果是第一人称 POV：表情来源=剧本括号；推荐景别=POV 手部替代表情。
视频提示词：画面看不到小安的脸，只看见镜头下方两只小手攥紧衣角，呼吸突然停住半拍，哭腔从镜头后方挤出来，碗沿反光轻轻晃动。
```

核心原则：正式视频提示词不是复制神态词，而是呈现神态结果。抽象词要落到眼神、眉头、嘴角、嘴唇、下巴、呼吸、肩膀、手指、停顿、声音和身体距离上；POV 或不露脸镜头要落到手部、呼吸、声音、背影、反射和道具反应上。

## 三、短剧剧本格式

参考格式：

```text
第1集 1-1
内 / 外  地点  日 / 夜 / 雨 / 雪 / 晨 / 傍晚
人物：角色A、角色B、群众若干

【镜1｜E01-S01-C01｜景别｜基础运镜｜参考时长】
△ 当前镜号内的画面关系、动作、声音与必要的可表演心理解释。
角色A：台词。
角色B（压低声音）：台词。
角色A（O.S.）：同场但本镜画外台词。
角色B（V.O.）：旁白、回忆声或内心声。

【字幕：字幕内容】

闪回
△ 闪回动作。
闪回结束

【空镜：场景描述】
```

执行规则：

- 集数、场号和镜号必须分层清楚，例如`第1集`、`1-1`、`E01-S01-C01`。
- 时间地点必须写内 / 外和日 / 夜等简写。
- 人物名称全文统一，群众可写“若干”。
- 动作描述用 `△` 开头，不写小说式心理描写。
- 台词格式为 `角色名：台词`。
- 心理活动或画外音用 `OS`，画外旁白用 `VO`。
- 字幕用 `【字幕：内容】`。
- 空镜用 `【空镜：场景描述】`，并且要和场景内容紧密关联。
- 闪回必须另起一行标注 `闪回` 和 `闪回结束`。

## 四、E/S/C 编号规则

分镜编号采用：

```text
E1-S1-C1
```

含义：

- `E` = Episode，集。
- `S` = Scene，场。
- `C` = Cut，镜头。

插入规则：

```text
主场：E1-S1-C1、E1-S1-C2、E1-S1-C3、E1-S1-C4、E1-S1-C5
插场：E1-S1-C5A、E1-S1-C5B
```

字母后缀只表示插入，不占新数字，不强行重排后续镜头。后续反馈修改时，优先用插入编号保持版本可追踪。

## 五、时长规则

镜头总时长必须是确定值，不写模糊范围；具体值由主体识别、动作完成、情绪变化、对白与听者反应、摄影机路径和停点反推，不按镜头类型套秒数。总时长写在基础设定并作为平台参数；正式画面内容不从零开始铺绝对时间轴。只有局部动作完成、触发延迟、反应窗口和结果保持确实需要时，才写 `两秒内、约0.4秒后、至少0.8秒` 这类相对时长。老胡明确指定支持更长时长的模型与入口时，可以按该入口的确定上限建立独立路线，例如 Seedance 2.5 单条 30 秒；模型特定例外不能反向改变其他模型的默认范围。

这个区间不是随便限制秒数，而是为了让模型和观众都有足够展示空间：

- 低于 4 秒，人物表情、脸部特写、关键动作、台词反应和奇观展开容易一闪而过，画面会干，观众来不及代入。
- 未做长时设计时，高于 15 秒容易把一个镜头拖成长段落，模型可能延长动作、稀释故事节奏，剪辑也更难控制；明确的 30 秒路线必须增加连续动作阶段、音乐段落、场景变化和结束收束，并验收后半段遗忘与一致性漂移。
- 4-15 秒内要尽量让分镜效果发挥完整：该展示情绪就给情绪停留，该展示动作因果就给动作过程，该展示奇观就给奇观展开和停点。

时长选择参考：

```text
4 秒：极简转场、单一特写、单一动作结果、短暂身份锚点。
5-7 秒：普通动作链、空间揭示、群体反应、轻量奇观。
8-12 秒：人物表情 / 台词 / 礼仪动作、复杂 POV、重要身份确认、较完整奇观展示。
13-15 秒：同一场景连续动作、未资产化人物需要合并、复杂动作因果或大型场面调度。
```

不要为了凑短而压缩镜头，也不要为了显得丰富把内容拖长。时长不能先拍脑袋固定成 4 秒、5 秒、6 秒，再把丰富画面硬塞进去；必须先对 `【画面内容】` 做一次时长预演，再决定镜头总时长。

时长预演流程：

```text
1. 先读画面内容，拆出动作单元：入画、观察、表情变化、台词、手势、道具响应、环境变化、运镜、转场停点。
2. 给每个动作单元估算最低可读时间：观众能否看清，模型能否生成完整，声音和动作是否有落点。
3. 把动作单元时间相加，得到预估时长。
4. 如果预估时长在目标模型入口支持范围内，选择最接近预演结果的确定秒数；默认路线通常为 4-15 秒。
5. 如果 5 秒装不下 8 秒内容，不要硬塞：要么增加到 8 秒，要么删减画面内容，要么拆成两个镜头。
6. 如果预估超过目标模型入口的明确上限，说明一个提示词承载内容过多，优先删减次要内容或拆镜头；若入口明确支持 30 秒，先判断长程连续生成是否正是测试目标，再决定保留 30 秒。
```

多镜头视频先建立 `动作单元预算`，再选择镜头覆盖方式，不能从固定平均镜长或固定镜头数出发。连续跟拍 / 少量长镜头用于完整身法、空间控制和真实时间；高强度多切可用多个短镜头分别覆盖同一动作单元的来路、接触、脚步、受力、反应和结果，以切换速度传递激烈程度；混合结构负责在空间建立、爆发和沉淀之间调节。15 秒使用约 10 个镜头并不天然过多，使用 4-6 个也不天然更稳，最终由主情绪、动作可读性、状态连续和成片效果决定。

动作单元必须形成完整因果，单个镜头不必独自完成整条链。每增加一个镜头都要增加新的观看证据，切后必须进入同一动作的下一相位并继承姿势、动作手、武器归属、屏幕方向、运动余势和声音。只有无新观看价值的角度才合并；只有总时长无法兑现核心结果时才删减或拆条。

常用动作单元只比较相对预算，不给固定秒数：

```text
低预算：单一物体响应、单一手势、已经建立主体后的短插入证据。
中预算：可读的眼神变化、一句短台词连同反应、一次焦点迁移或简单揭示。
高预算：完整礼仪、复杂受力、群体依次反应、空间穿越、奇观展开或多阶段情绪转折。
额外接口预算：只有遮挡、强光、压暗、声音收束或尾帧接续需要被观众读到时才增加。
```

同一动作在大特写、远景、快节奏喜剧、克制文戏和慢动作里需要的时间不同。最终必须用目标节奏实际预演，不把上面类别换算成固定秒数表。

检查问题：

```text
画面内容从第一句话到最后一个停点，真实播放一遍大概要几秒？
当前时长是否足够让动作、表情、声音和光影因果被看见？
如果观众只看一次，能否看懂这个镜头的重点？
如果模型按这个时长生成，会不会把多个动作挤成快闪？
如果装不下，是加时长、删内容，还是拆镜头？
```

禁止：

```text
时间段写成 10 到 12 秒的模糊区间
时长写成 8 到 10 秒的模糊区间
核心镜头时长写成 8 到 12 秒的模糊区间
```

正确：

```text
时长：12 秒
时长：10 秒
时长：8 秒
```

镜头内部动作不再用时间轴分配，改用导演镜头语言：

```text
平台总时长：12 秒
中近景建立年轻迎客仙人，他整衣拱手并说出台词，摄影机停在礼姿。
他的袖口横向拂过并遮满画面，以同一运动方向自然切入裂隙开始扩张的低机位中景；袖口离开后，摄影机沿裂隙边缘继续环绕并后拉，裂隙完全打开后停成宽幅构图。
```

判断标准：

- 镜头总时长不能让用户再猜到底生成几秒。
- 镜头总时长必须在 4-15 秒内，除非老胡明确要求按某个模型特殊限制处理。
- 不要把所有镜头都默认写成 4 秒；4 秒只适合单一任务，人物情绪、台词、复杂动作和恢宏奇观通常需要更长展示空间。
- 镜头数量和动作数量必须能装进总时长。
- 如果模型只支持固定视频时长，优先按模型支持值改写为确定时长。
- 首轮测试文件必须使用确定时长。

## 六、全局概览与执行稿的区别

如果只是给老胡看全局剧情，用简要表格：

| 编号 | 所属场次 | 时长 | 镜头任务 | 表情细化 | 简要内容 |
|---|---|---:|---|---|---|
| E1-S1-C1 | 第1集 1-1 | 12 秒 | 建立身份和入口 | 是，年轻仙人恭迎表情占 2 秒 | 年轻仙人恭迎，大人拂袖打开时空裂隙 |

如果是给老胡真实生成测试，不能只给示例。必须给完整可复制内容：

```text
【基础设定】
【场景状态与氛围画质】
【画面内容】
```

首轮测试只保留一个清楚入口文件。历史稿可以保留，但必须标明“不作为当前测试入口”。

## 七、自检

输出视频提示词前检查：

- 是否先形成了单场次剧本或引用了已有剧本。
- 是否判断了资产是否需要，不需要时是否说明原因。
- 是否已从剧本镜号读取人物表演，并在视频编译阶段判断是否需要细化。
- 涉及人物情绪 / 台词 / 反应时，是否已在 `laohu-video-prompt` 内完成人物表演细化或明确说明不需要。
- 人物表情占用时长是否和镜头总时长一致。
- 是否使用 `E01-S01-C01` 这类剧本镜号，并保留到 E-S-B 批次来源映射。
- 是否存在“10 到 12 秒”“8 到 10 秒”这类模糊总时长。
- 是否只给全局概览，却误装成可执行提示词。
- 是否只给示例，导致老胡还要自己拼。
- 是否完整输出基础设定、场景状态与氛围画质、画面内容和生成前检查。
- 正式提示词是否独立完整，没有用“沿用全片”“参考上文”替代内容。
- 正式提示词代码块是否只保留三段，没有混入前置判断、后期备注、作者说明、上一镜头 / 下一镜头关系。
- 同一未资产化人物是否被拆到多个独立批次里反复出现；如果是，是否已按当次目标入口能力合同与融合质量判断合并，或回到资产阶段。
- `【画面内容】` 是否足够详细，包含时间轴、运镜、主体动作、环境运动、材质光影、人物表演和声音，而不是只有简单概括。
- 镜头衔接是否写成画面内转场，而不是场外说明。
