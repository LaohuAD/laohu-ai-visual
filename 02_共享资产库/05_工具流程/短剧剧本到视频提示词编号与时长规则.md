# 短剧剧本到视频提示词编号与时长规则

> 用途：把短剧 / 短片剧本稳定转换为分镜、资产设计和 AI 视频提示词，避免跳过剧本、编号混乱、时长模糊和首轮测试文件不可直接使用。

## 一、根本目的

老胡要的不是“看起来像提示词的一段描述”，而是能从剧本场次一路落到真实视频生成测试的制作说明。

因此视频提示词任务必须先判断：

```text
表层需求：老胡是否只是说了一个画面、镜头、台词或题材。
真实目标：老胡是否要做一个可测试、可剪辑、可迭代的作品片段。
根本目的：本次输出是否能让下一轮生成、反馈、修改更稳定。
```

即使老胡没有直接说“先写剧本”，只要目标是生成视频提示词，也不能丢掉剧本到分镜的流程。可以不做完整人物 / 场景资产，但必须至少先形成单场次剧本，再从剧本生成分镜提示词。

## 二、标准流程

视频提示词生成按以下顺序执行：

```text
单场次剧本
→ 资产判断：是否需要角色 / 场景 / 道具 / 第一帧参考图
→ 分镜宏观表：判断人物表情是否需要细化、是否占用镜头时长
→ 如涉及人物情绪 / 台词 / 反应：先在 laohu_video_prompt 内设计表演
→ 基础设定
→ 氛围与画质
→ 画面内容
→ 生成前检查
```

资产判断不是必须生成资产，而是必须判断是否需要资产：

- 文生视频足够：说明为什么可以跳过资产。
- 角色、服装、场景或第一帧需要稳定：先回到图片资产。
- 首轮概念测试：可以直接文生视频，但仍要保留剧本场次、镜头编号和完整三层提示词。

每一条正式视频提示词必须包含：

```text
【基础设定】
【氛围与画质】
【画面内容】
```

基础设定和氛围画质在同一作品内通常可以复用。它们是全片统一层：基础设定写世界观、角色类别、建筑场景、道具、声音总规则；氛围与画质写全片统一风格、视觉基调、色彩影调、质感和镜头语言。当前分镜才有的动作、局部声音、局部光线、转场和具体事件，必须写进画面内容。

正式生成平台按单条提示词独立执行。生成平台不会知道上一条分镜、全片设定或项目文件，因此每条正式视频提示词都必须在本条内完整写出基础设定、氛围与画质和画面内容。不能用“沿用全片”“参考上文”“同上一镜头”来替代实际描述。

但“独立完整”是执行检查，不是正式提示词字段。正式投喂给模型的代码块只保留：

```text
【基础设定】
【氛围与画质】
【画面内容】
```

不要把前置判断、资产判断、作者说明、剪辑说明、后期备注、上一镜头 / 下一镜头关系写进正式提示词。需要镜头衔接时，必须写成画面内可见的转场动作。

正式视频提示词单条正文必须控制在 2000 字以内。正式代码块里不要写给作者看的字段：`分镜编号`、`所属场次`、`镜头任务`、`作者说明`、`生成前检查`、`回传字段`。分镜编号和镜头任务要保留在分镜表、文件说明或标题里，不能投喂给视频模型。

画面内容不默认逐秒拆死。可以用自然语言描述当前镜头整体画面效果；只有关键节点需要强控制时才写确定时间点，例如“约第2秒裂隙亮起”“第6秒台词出口”。声音细节要嵌入画面内容，说明由什么画面动作产生，不要单独写一组泛泛声音字段。

跨分镜一致性判断必须在分镜阶段完成：

```text
同一个具体人物 / 道具 / 固定空间跨多条独立提示词出现
→ 是否需要保持同一外观？
→ 需要：是否有图片资产？
→ 没有图片资产：不要拆分，优先合并或回到资产阶段。
```

人物外观一致性优先依靠图片资产。文本资产可以固定“仙界迎宾人物妆造”这类类型规则，但不能保证同一个年轻迎客仙人在 C1、C2、C3 里长成同一张脸。

15 秒合并规则：

- 同一场景、同一未资产化人物、连续动作，拆开会造成变脸或动作断裂时，若总时长不超过 15 秒，优先合并为一个分镜 / 一条视频提示词。
- 合并后的镜头可以在内部写确定起止段，例如 `第0秒-第2秒`、`第2秒-第5秒`。
- 镜头总时长仍必须是确定值，例如 `时长：9 秒`，不能写 `8-10 秒`。
- 如果合并后超过 15 秒，且人物仍需重复出现，就应升级为图片资产，而不是继续靠文字硬撑。

转场写法：

- 遮挡转场：袖口、云雾、仙旗、人物身体、巨门、飞檐掠过镜头并遮满画面。
- 明暗转场：金白强光吞没、云影压暗、门内白光铺满、暗处重新亮起。
- 运镜转场：镜头被裂隙吸入、穿过云层、越过门槛、绕过法器后落到新主体。
- 匹配转场：圆形裂隙接圆形仙印，龙眼倒影接玉扳指光点，浮灯接宫阙灯火。
- 动作转场：拂袖横扫、仙旗掠过、巨门开启、法器展开等动作覆盖画面边缘。
- 硬切停点：人物礼姿停住、光效收束、声音落点明确，方便直接剪接。

不要把“接下一镜”“后期剪辑时如何衔接”写进正式提示词；直接写画面最后发生了什么。

## 二点五、人物表情前置判断

分镜宏观表阶段必须增加人物表情判断。只要镜头里有人物出镜、台词、沉默、反应、情绪转折、眼神交流、微表情或关系变化，就先判断是否需要在 `laohu_video_prompt` 内进行人物表演细化。

判断标准：

- 表情是镜头核心任务：先以人物表演设计为主，再生成画面内容。
- 表情只是辅助状态：在画面内容中写短表演，不抢镜头时间。
- 表情不重要或无人出镜：不调用人物表演细化。

宏观表必须写清：

```text
是否需要表情细化：是 / 否
表情功能：核心任务 / 辅助状态 / 不需要
表情占用时长：确定值，例如 4 秒
表情设计入口：laohu_video_prompt / 画面内容短句 / 无
```

如果需要人物表情细化，先输出人物表演设计，再嵌入 `laohu_video_prompt` 的画面内容。不要先把画面动作写满，再临时塞表情。

## 三、短剧剧本格式

参考格式：

```text
第1集 1-1
内 / 外  地点  日 / 夜 / 雨 / 雪 / 晨 / 傍晚
人物：角色A、角色B、群众若干

△ 动作描述，只写能被看见或听见的内容。
角色A：台词。
角色B（压低声音）：台词。
角色A（OS）：内心独白或画外心理声。
角色B VO：未出场画外声。

【字幕：字幕内容】

闪回
△ 闪回动作。
闪回结束

【空镜：场景描述】
```

执行规则：

- 场次标注必须清楚，例如 `第1集 1-1`。
- 时间地点必须写内 / 外和日 / 夜等简写。
- 人物名称全文统一，群众可写“若干”。
- 动作描述用 `△` 开头，不写小说式心理描写。
- 台词格式为 `角色名：台词`。
- 心理活动或画外音用 `OS`，画外旁白用 `VO`。
- 字幕用 `【字幕：内容】`。
- 空镜用 `【空镜：场景描述】`，并且要和场景内容紧密关联。
- 闪回必须另起一行标注 `闪回` 和 `闪回结束`。

## 四、E/S/C 编号规则

分镜编号采用：

```text
E1-S1-C1
```

含义：

- `E` = Episode，集。
- `S` = Scene，场。
- `C` = Cut，镜头。

插入规则：

```text
主场：E1-S1-C1、E1-S1-C2、E1-S1-C3、E1-S1-C4、E1-S1-C5
插场：E1-S1-C5A、E1-S1-C5B
```

字母后缀只表示插入，不占新数字，不强行重排后续镜头。后续反馈修改时，优先用插入编号保持版本可追踪。

## 五、时长规则

镜头总时长必须是确定值，不写模糊范围。

禁止：

```text
时间段写成 10 到 12 秒的模糊区间
时长写成 8 到 10 秒的模糊区间
核心镜头时长写成 8 到 12 秒的模糊区间
```

正确：

```text
时长：12 秒
时长：10 秒
时长：8 秒
```

镜头内部动作时间轴可以写起止段，但必须边界确定，并且总和等于镜头总时长：

```text
总时长：12 秒
第0秒：年轻迎客仙人拱手。
第3秒：他说出台词。
第5秒：第一人称袖口入画并拂袖。
第8秒：时空裂隙开始扩张。
第12秒：时空裂隙完全打开。
```

判断标准：

- 镜头总时长不能让用户再猜到底生成几秒。
- 分段时间轴不能超过总时长。
- 如果模型只支持固定视频时长，优先按模型支持值改写为确定时长。
- 首轮测试文件必须使用确定时长。

## 六、全局概览与执行稿的区别

如果只是给老胡看全局剧情，用简要表格：

| 编号 | 所属场次 | 时长 | 镜头任务 | 表情细化 | 简要内容 |
|---|---|---:|---|---|---|
| E1-S1-C1 | 第1集 1-1 | 12 秒 | 建立身份和入口 | 是，年轻仙人恭迎表情占 2 秒 | 年轻仙人恭迎，大人拂袖打开时空裂隙 |

如果是给老胡真实生成测试，不能只给示例。必须给完整可复制内容：

```text
【基础设定】
【氛围与画质】
【画面内容】
【负面约束】
【生成前检查】
```

首轮测试只保留一个清楚入口文件。历史稿可以保留，但必须标明“不作为当前测试入口”。

## 七、自检

输出视频提示词前检查：

- 是否先形成了单场次剧本或引用了已有剧本。
- 是否判断了资产是否需要，不需要时是否说明原因。
- 是否在分镜宏观表阶段判断人物表情是否需要细化。
- 涉及人物情绪 / 台词 / 反应时，是否已在 `laohu_video_prompt` 内完成人物表演细化或明确说明不需要。
- 人物表情占用时长是否和镜头总时长一致。
- 是否使用 `E1-S1-C1` 这类编号。
- 是否存在“10 到 12 秒”“8 到 10 秒”这类模糊总时长。
- 是否只给全局概览，却误装成可执行提示词。
- 是否只给示例，导致老胡还要自己拼。
- 是否完整输出基础设定、氛围与画质、画面内容和生成前检查。
- 正式提示词是否独立完整，没有用“沿用全片”“参考上文”替代内容。
- 正式提示词代码块是否只保留三段，没有混入前置判断、后期备注、作者说明、上一镜头 / 下一镜头关系。
- 同一未资产化人物是否被拆到多个独立提示词里反复出现；如果是，是否已经合并到 15 秒以内或回到资产阶段。
- `【画面内容】` 是否足够详细，包含时间轴、运镜、主体动作、环境运动、材质光影、人物表演和声音，而不是只有简单概括。
- 镜头衔接是否写成画面内转场，而不是场外说明。
