# 真实作品首轮验证计划

> 用途：用最小真实样片验证当前 5 个核心 skill 是否能跑通剧本、视觉资产、视频提示词、人工生成和复盘回流。

## 一、验证原则

- 只验证一个确定时长小样，不追求完整大片。
- 每一步保留原提示词、结果位置、用户判断和下一步动作。
- 图片先小批量，视频只测 1 个确定时长镜头。
- 视频生成由用户手动执行；skill 负责提示词、交接包、诊断、返修和沉淀。
- 真实结果不管成功失败都保留，失败结果优先进入经验沉淀。
- 缺失信息写“缺”，不要补猜模型参数或生成结果。

## 二、最小验证链路

```text
1. laohu-ai-visual：建立作品目录，判断本轮小样目标
2. laohu-script-writer：锁定确定时长单场次剧本
3. laohu-visual-assets：拆角色、场景、道具、风格、图片资产和封面方向
4. 用户手动生成或补充图片候选
5. laohu-visual-assets：验收图片候选，决定哪些进入视频参考
6. laohu-video-prompt：输出分镜概览、人物表演、完整三层视频提示词
7. 用户手动测试视频生成
8. laohu-generation-review：诊断真实结果，决定返修、剪辑、发布或入库
```

首轮不建议直接进入发布。只有视频小样达到 B 级以上，才继续在 `laohu-generation-review` 内做剪辑验收和发布复盘。

## 三、建议首测作品

```text
作品名：雨夜外卖员最后一单
目标形态：60 秒 AI 短片中的 12 秒核心镜头小样
核心镜头：外卖员在雨夜楼道门口，看见收件人门缝里的旧照片，意识到和失踪女儿有关。
首轮目标：验证角色定妆图、雨夜楼道场景图、第一帧图和单镜头视频提示词是否能形成闭环。
```

也可以换成老胡正在做的真实作品，但必须先建作品目录，并把本计划里的字段复制过去。

## 四、阶段产物和验收标准

### 1. 剧本小样

调用：`laohu-script-writer`

必须产出：

- 确定时长单场次剧本。
- 一个主要动作。
- 一个信息变化。
- 开始状态和结束状态。
- 剧本交接包。

通过标准：

- 观众能看见角色发现了什么。
- 画面不依赖长解释。
- 不把过多信息塞进一个镜头。

### 2. 视觉资产

调用：`laohu-visual-assets`

必须产出：

- 角色资产。
- 场景资产。
- 关键道具。
- 镜头任务表。
- 主风格建议。
- 图片资产提示词。
- 小批量图片生成执行单。
- 图片候选 A/B/C/D 验收标准。
- 视觉资产交接包。

通过标准：

- 每个资产都服务镜头任务。
- 标出必须先生成的图片资产。
- 标出角色一致性、场景光影和第一帧可运动风险。

### 3. 视频提示词

调用：`laohu-video-prompt`

必须产出：

- 单场次剧本来源。
- 分镜概览表。
- 人物表演判断和表情占用时长。
- 【基础设定】。
- 【氛围与画质】。
- 【画面内容】。
- 质量边界。
- 生成前检查。
- 回传字段。

通过标准：

- 每个镜头只有一个主要任务。
- 使用 `E1-S1-C1` 编号。
- 总时长是确定值。
- 参考图负责锁定什么写清楚。
- 人物表演不是一个情绪词，而是时间轴和关键部位控制。
- 能直接复制到目标视频模型测试。

### 4. 真实视频回传

用户手动生成后，至少带回：

```text
作品名：
镜头编号：
模型：
原视频提示词位置：
参考图位置：
视频文件位置或结果描述：
用户初判：
最大问题：
下一步意图：进入剪辑 / 重生成 / 重写提示词 / 做失败复盘
```

调用：`laohu-generation-review`

通过标准：

- 判断成功 / 半成功 / 失败。
- 定位主要失败类型。
- 给出下一版修正提示词。
- 指明回到哪个核心 skill。
- 判断是否进入成功或失败经验。

## 五、首轮结果分级

| 等级 | 判断 | 下一步 |
|---|---|---|
| A | 角色稳定、镜头任务完成、动作自然、可剪辑 | 进入剪辑小样 |
| B | 核心任务完成，但有局部问题 | 修正后再生成 1 轮 |
| C | 画面可看，但角色、动作或信息不稳 | 回到视觉资产或视频提示词 |
| D | 不服务作品或严重跑偏 | 进入失败案例，重写上游 |

首轮只要达到 B 级，就算验证有效。A 级不是第一目标。

## 六、归档位置

建议在作品目录中建立或使用：

```text
01_作品项目/进行中/<作品名>/
├── 00_原始输入/
├── 01_世界观故事/
├── 02_剧本/
├── 03_视觉资产/
├── 04_分镜/
├── 05_视频/
└── 09_归档复盘.md
```

每次有实质经验回流，都要更新 `输入输出索引.md`。
