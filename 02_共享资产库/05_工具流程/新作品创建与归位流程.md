# 新作品创建与归位流程

## 一、创建原则

正式作品必须按创作链路建立目录，不按“提示词大杂烩”或“素材大杂烩”建目录。

根目录只保留管理文件：

- `00_项目总览.md`
- `00_阶段确认记录.md`
- `00_首轮验证看板.md`
- `09_归档复盘.md`

创作内容按 6 个编号阶段目录归位：

```text
00_原始输入
01_世界观故事
02_剧本
03_视觉资产
04_分镜
05_视频
```

每个阶段目录下面固定保留：

```text
文本/
图片/
视频/
音频/
```

## 三、归位规则

| 阶段 | 文本 | 图片 | 视频 | 音频 |
|---|---|---|---|---|
| `00_原始输入/` | 原始需求、口述、链接摘录 | 参考图、截图 | 参考视频 | 参考音频 |
| `01_世界观故事/` | 故事确认、世界观、角色关系、场景规则 | 世界观参考图、关系图 | 世界观参考片段 | 世界观声音参考 |
| `02_剧本/` | 剧本、改稿、台词旁白 | 剧本辅助图 | 剧本参考片段 | 台词试读、旁白参考 |
| `03_视觉资产/` | 风格规范、图片资产提示词、封面提示词 | 角色图、场景图、道具图、封面图 | 视觉风格参考视频 | 风格音乐、环境声参考 |
| `04_分镜/` | 分镜表、镜头任务表、生成任务清单 | 分镜草图、镜头参考图 | 运镜参考片段 | 分镜音效、节奏参考 |
| `05_视频/` | 视频提示词、剪辑说明、视频复盘草稿 | 视频参考图、第一帧 | 生成视频、剪辑片段、成片 | 配乐、音效、旁白、同期声 |

## 四、阶段确认

阶段推进顺序：

```text
灵感
→ 沟通确定故事内容
→ 剧本结果输出文件
→ 资产图片提示词输出文件
→ 分镜表格输出文件
→ 第一个分镜视频提示词展示文件
→ 所有分镜视频提示词结果输出文件
→ 老胡制作完成后生成封面
→ 归档
```

每个阶段完成后更新：

```text
00_阶段确认记录.md
```

正式内容只放文件，对话只给文件链接、阶段摘要和下一阶段确认问题。

## 五、脚本

新作品优先使用：

```bash
bash skills/laohu_ai_visual/scripts/create_work_project.sh "作品名" yyyy-mm-dd 进行中
```

脚本会创建当前标准结构。
