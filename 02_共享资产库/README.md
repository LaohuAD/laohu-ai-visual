# 本地创作积累

这里保存可选的本地创作积累，不承担五个技能包正常执行所需的专业规则。那些方法已经迁入相应包的SKILL或Reference。

- `故事素材库/`：完整来源、逐字原话、故事原子、使用证据与可重建检索数据。它是素材权威，私人内容不进入Git。
- `02_视觉语言资产/画面风格库/`：已有题材样例，按当前作品适配使用，不自动变成通用硬规则。

故事包的 `references/故事原子/` 是面向应用的实体内容：由完整库同步结论、机制、证据、边界、置信度和来源编号，不附source原话。用户可直接上传故事包；只有本地追溯时才读这里的来源。缺少共享库不影响故事包使用已随包携带的原子或执行通用编剧方法。

后续每次新增灵感都在这里保存完整来源和故事原子，同时由故事素材工具自动同步到技能包；新增、修订、暂停和恢复均需两处一致，不能等到上传前才临时补副本。应用原子不单独手改，修订回到权威库。同步不替代实际云端上传，也不向云端自动推送。
