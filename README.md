# 老胡 AI 视觉作品生产系统

一个面向 AI Agent 的对话式视觉作品创作工作流项目。

它不是提示词收藏夹，也不是单纯的 AI 视频提示词模板。它的作用是把一句灵感，逐步推进成一个可生成、可修改、可复盘、可长期进化的 AI 视觉作品。

整个系统通过 Markdown 文件、作品目录、阶段确认记录和项目专属 skill 工作，不需要前端、后端、登录系统或表单页面。

## 适合谁

- 想用 AI 做短片、短剧、概念片、封面或视觉视频，但不想每次从零写提示词的人。
- 想把灵感、故事、剧本、视觉资产、分镜、视频提示词、生成结果和复盘分阶段打磨的人。
- 想让 AI Agent 在本地项目里按固定规则协作创作，而不是在聊天窗口里丢失上下文的人。
- 想长期沉淀自己的视觉风格、提示词方法、失败案例和发布经验的人。
- 想独立发作品、做课程或做内容展示，而不是批量套模板的人。

## 为什么它不是一个傻瓜式成品

这个项目故意保留了一定的“粗糙度”。

这里的粗糙，不是指不重视质量，也不是说系统不会继续打磨。它更像一个给创作者使用的初始工作台：规则、流程、目录和质量门已经搭好，但最终审美、题材偏好、镜头语言、画面资产和判断标准，需要使用者在真实作品里继续训练。

如果我把所有东西都按老胡自己的审美打包成一个开箱即用的傻瓜式项目，结果会有两个问题：

1. 后面的人做出来的视觉作品，很容易都像“老胡模板”刻出来的。
2. 很多只想批量发布、快速摘桃子的人，可以直接拿去量产，而不是形成自己的创作判断。

所以这个项目更适合：

- 想长期独立发作品的人。
- 想做高质量 AI 视觉，而不是批量生产素材的人。
- 想形成个人镜头语言、个人审美和个人题材系统的创作者。
- 愿意把自己的生成失败、发布反馈和修改经验不断喂回系统的人。

它不是“拿来就自动生成大片”的机器，而是一个可以慢慢长成你个人 AI 视觉创作系统的骨架。

## 这个项目能做什么

### 1. 从灵感确定故事内容

输入一句灵感、一段口述、一个画面或一个题材，系统会先判断：

- 表层需求：你直接说了什么。
- 真实目标：你真正想让作品表达什么。
- 根本目的：这次创作要服务作品质量、生成稳定性、剪辑可用性还是发布传播。
- 作品体量：15-60 秒短视频、1-3 分钟概念片、3-10 分钟短片或系列短剧。
- 观众等待的问题：观众为什么要继续看。
- 主角、对立面、黑暗时刻和结尾记忆点。

### 2. 写剧本和单场次剧本

系统不会默认从灵感直接跳到视频提示词。即使最终目标是文生视频，也会先形成剧本来源：

- 故事确认。
- 世界观和人物关系。
- 正式剧本。
- 单场次剧本。
- 需要继续拆成分镜的镜头任务。

短剧 / 短片编号使用 `E1-S1-C1` 规则，插入镜头用 `E1-S1-C5A` 这类字母后缀，不重排后续编号。

### 3. 判断视觉资产

项目会区分“资产”和“画面元素”。

资产不是画面里出现过的一切。只有跨镜头、跨场次、跨集或跨作品复用，或者需要锁定外观、空间、材质、比例、色彩和风格连续性的内容，才进入资产表。

视觉资产分两类：

- 图片资产：固定角色脸、服装、场景空间、关键道具、第一帧等具体形象。
- 文本资产 / 提示词资产：固定氛围、妆造、服饰体系、建筑语法、色彩材质、声音气质和世界观视觉规则。

一次性角色、一次性奇观和单镜头场景，默认先降级为画面元素或临时参考图，避免为了显得系统而把目录搞乱。

### 4. 生成分镜表和视频提示词

系统会从剧本继续拆成分镜表，再进入视频提示词。

正式视频提示词必须使用三段结构：

```text
【基础设定】
【氛围与画质】
【画面内容】
```

每条正式视频提示词都按“单条独立生成请求”处理，不能写“沿用上文”“参考前一个镜头”“后期备注”这类场外说明。每条提示词都必须自足完整。

视频镜头总时长必须是确定值，例如 `9 秒`、`12 秒`、`15 秒`，不写 `10-12 秒` 这种模糊范围。

如果同一个未资产化人物连续出现在同一场景里，且总时长不超过 15 秒，优先合并成一条视频提示词，避免独立生成时人物变脸。

### 5. 复盘生成结果和发布反馈

系统会把真实结果回流成长期经验：

- 角色是否变脸。
- 动作是否乱。
- 表情是否失控。
- 风格是否跑偏。
- 镜头是否能剪。
- 提示词是否独立完整。
- 封面、标题、开头、完播和评论反馈是否达标。
- 成功或失败是否需要沉淀到共享资产或 skill。

失败样本不是垃圾。对这个系统来说，失败提示词和失败结果是训练下一轮判断的证据。

## 核心流程

默认采用分阶段确认制：

```text
灵感输入
→ 沟通确定故事内容
→ 剧本结果输出文件
→ 资产图片提示词输出文件
→ 分镜表格输出文件
→ 第一个分镜视频提示词展示文件
→ 所有分镜视频提示词结果输出文件
→ 制作完成后生成封面
→ 归档复盘
→ 经验沉淀
```

除非你明确说“一步到位”“直接做完”“不要中途确认”，否则系统不会默认跳过确认门。

这个设计是为了避免一个常见问题：故事没确认，资产没判断，分镜没定，AI 就急着写一堆视频提示词，最后生成出来的内容看似华丽，但人物、时长、镜头任务和剪辑逻辑全都接不上。

## 如何让系统升级

这个项目最重要的能力，不是第一次生成，而是持续吸收经验。

你可以把这些材料丢进项目：

- 自己认可的剧本、分镜、提示词和视频结果。
- 你喜欢的电影、短剧、广告、MV 或账号案例。
- 优秀 AI 视频提示词拆解。
- 某次 AI 图片或视频生成失败的截图、视频和原因。
- 发布标题、封面、评论、收藏、转发和完播反馈。
- 你对某个镜头、某条提示词、某个资产判断的肯定或否定。
- 你自己的口头创作经验。

然后让 AI Agent 按这个流程吸收：

```text
原始材料归档
→ 判断材料类型
→ 提炼它对剧本、视觉资产、分镜、视频提示词、生成复盘哪一环有用
→ 判断是当前作品经验还是跨作品规则
→ 更新作品复盘或共享资产
→ 必要时更新对应 laohu_ skill
→ 在输入输出索引记录
```

你可以这样对 Agent 说：

```text
这是一段我认可的视频提示词写法。
请不要直接照抄原文，先判断它对基础设定、氛围画质、画面内容、人物表演还是镜头转场有用。
如果是长期有效规则，请更新到对应共享资产或 skill。
```

也可以这样说：

```text
这是一次视频生成失败样本。
请分析失败原因：是剧本任务、资产一致性、分镜拆法、提示词独立性、画面内容详细度还是模型限制的问题。
如果这个问题以后还会出现，请沉淀成规则。
```

## 快速开始

### 1. 获取项目

这个仓库有两种用法：一种是安装 Agent skills，另一种是获取完整项目模板。

方式 A：只安装 skills。

```bash
npx skills add LaohuAD/laohu-ai-visual
```

只想安装某一个 skill：

```bash
npx skills add LaohuAD/laohu-ai-visual --skill laohu_ai_visual
```

这会把 `skills/*/SKILL.md` 安装到当前 Agent 的 skills 目录。适合你已经有自己的项目，只想复用老胡 AI 视觉创作能力。

注意：`npx skills add` 主要安装 skill 本体。完整的作品目录、共享资产库、模板库和检查脚本仍在这个仓库里。如果你想使用完整 AI 视觉作品生产系统，建议用下面的克隆或 `degit` 方式获取整个项目。

方式 B：克隆完整项目。

```bash
git clone https://github.com/LaohuAD/laohu-ai-visual.git
cd laohu-ai-visual
```

方式 C：用 `npx degit` 拉一份干净模板。

```bash
npx degit LaohuAD/laohu-ai-visual my-ai-visual-system
cd my-ai-visual-system
```

如果你想保留 `00_输入原料/`、`01_作品项目/`、`02_共享资产库/`、`skills/` 这整套目录结构，推荐用方式 B 或 C。

### 2. 检查项目结构

```bash
bash skills/laohu_ai_visual/scripts/check_laohu_skills.sh
```

如果输出：

```text
Contract check passed.
```

说明核心目录、规则文件和脚本都在。

### 3. 创建一个新作品

```bash
bash skills/laohu_ai_visual/scripts/create_work_project.sh "我的视觉作品"
```

也可以指定日期：

```bash
bash skills/laohu_ai_visual/scripts/create_work_project.sh "我的视觉作品" "2026-06-13"
```

脚本会在 `01_作品项目/进行中/` 下创建一套完整作品目录。

### 4. 和 AI Agent 对话创作

在支持项目上下文和本地文件读写的 AI Agent 里打开本项目，然后直接输入你的灵感。

示例：

```text
我想制作一个横屏仙界视频，开头是一个仙风道骨的年轻人，对着镜头喊：“大人，请登仙界！”
后面全程 POV 镜头，展示恢宏仙界、奇观、美女、神兽和新奇玩意。需要宏大场景，也要有特写和炫酷运镜。
```

系统应该先判断当前应该进入故事确认、剧本、视觉资产、分镜还是视频提示词阶段，而不是直接丢出一堆不可生成的提示词。

## 推荐使用方式

### 新作品创作

```text
我想做一个 AI 视觉短片，灵感是：……
```

系统应该先进入故事确认或剧本阶段。

### 已有剧本转视频

```text
这是我的剧本，请先拆资产，再生成分镜表。
每个阶段都输出文件，等我确认后再进入下一阶段。
```

### 生成结果复盘

```text
这是我生成出来的视频结果，我不满意的点是：……
请判断问题在剧本、资产、分镜、提示词还是模型限制，并把可复用经验沉淀回项目。
```

### 吸收创作经验

```text
接下来我发给你的内容，都是从这些内容里扩展或发散思维。
请真正明白我想表达什么，并把可复用经验吸收到这个项目里。
```
