## 二、判定法：四层归属（来自项目自身）

判断一句留不留，标准不是「是不是总结」，而是「**它服务哪一层**」：

| 层 | 承载 | 判据（`02_四层能力重编译.md` 原文） |
|---|---|---|
| **灵魂 SOUL** | 价值、方向、取舍 | 「什么值得追求、舍弃或保护发生变化了吗」 |
| **筋骨 STRUCTURE** | 负责人、关系、顺序、状态、调用链 | 「章法不是步骤表，而是整个能力怎样接力」 |
| **血肉 CRAFT** | 材料选择、专业方法、条件、效果因果 | 完整技法六步（见第三节） |
| **表皮 FORM** | 格式、字段、路径、参数、工具、硬边界 | 「不把审美偏好写成机械强制」 |

**四层是判断方式，不是四个固定标题，也不是每次都要填满的表格。**

三类句子的处置：

```text
方向句   「临界点越具体，张力越大」        → 灵魂层（定向）→ 留
表现句   「临界时刻 = 话快骂出口、门快关上」 → 血肉层（可见证据）→ 留
复述句   「信息差就是各方知道的不一样」     → 四层都不服务     → 删
```

v1 的错误：拿「复述句」的判据去砍了「方向句」，因为没做归属判断。

**伪箴言信号**（灵魂层的反向检查，原文）：换到任何项目仍然成立；删掉后不影响选择；需要长篇说明才知道它在说什么；只是禁令换行；只有气势，没有因果。

## 三、模块形态：内容按层归位，结构自然形成

**不用四段固定模板。** 每一段写成什么，由它承载的层决定：

```text
灵魂  → 取舍句、方向句、缺一即松的判定
筋骨  → 本专业独占什么判断、分流给谁、调用链、状态
血肉  → 触发条件、可见/可听表现、候选比较、反例、什么时候换别的
表皮  → 字段名、命名、路径、参数、字符、平台硬边界
```

**血肉层的完整技法六步（项目原文，逐项都要有）**：

```text
触发条件
→ 材料承担的关系、情绪、信息或功能
→ 候选材料或方法的比较
→ 为什么选择这一种
→ 它如何改变可见、可听或可执行结果
→ 什么情况下保留原稿或换用其他方法
```

**材料选择四判据（项目原文）**：因果承重、典型性、媒介可见性、实现与维护代价。

## 四、文件怎么归类（三条规则）

```text
规则 1  会被两个以上专业读  → 独立成 references 文件
        例：景别与取景范围（图片、视频、剪辑、分镜都要读）
规则 2  只被一个专业读      → 并进那个专业已有的 reference 文件
        例：人物图片审美特征 → 并进 laohu-portrait 已有的 reference
规则 3  并进去后主题变混    → 在该专业 references/ 下新建一个主题文件
```

判断口诀：先看谁会读 → 只有一个专业读就并进去；并进去会串味才单开一个。

## 五、语言怎么表达（完整改前 / 改后，带层标注）

### 样本 A：剧本《选题角度审美特征资产》（原文 1631 字）

**所在文件**：`laohu-script-writer/references/高质量AI剧本开发计划.md` 第 2 节（就是你要删的那份）
**改后去向**：并进 `laohu-script-writer/skills/laohu-premise-theme/references/创意开发与主题检验.md`

**改前：**

```text
## 2. 选题角度审美特征资产

### 2.1 通用基底

高质量选题是能自然长出人物、冲突、场景、台词和传播资产的故事发生机制。

它通常包含：

一个具体的人。
一个正在变化的关系。
一个观众熟悉但容易误判的场景。
一个可见的触发动作。
一个有代价的选择。
一个能被结尾回收的物件、称呼或动作。
一个能被观众带走的认知或情绪出口。

### 2.2 高质量选题特征颗粒

窄切特征：
从具体侧面进入大题材。亲情落到具体误解和具体物件，教育落到具体话术和具体支持动作。

临界时刻特征：
截取关系即将变化的一秒。话快骂出口、门快关上、孩子快哭出来、父母快发火、老师快定性、主角快误解完成。临界点越具体，剧本越有张力。

观众预期特征：
先让观众根据经验自动补出一个熟悉套路，再用人物选择击穿这个套路。反转利用观众的社会经验、家庭经验和刻板判断完成价值转向。
```

**改后（并进目标文件，逐段标层）：**

```markdown
## 选题角度                                    ← 筋骨：本专业独占的判断范围

> 触发：说「不知道拍什么」「这个题材太大」「没角度」   ← 血肉：触发条件

选题成立 = 七个要件齐：具体的人 / 正在变化的关系 / 观众熟悉但易误判的场景 /
可见触发动作 / 有代价的选择 / 结尾可回收的物件或称呼 / 能被带走的认知出口。
缺一即选题不成立。                              ← 灵魂：取舍判定（缺一即不成立）

| 特征 | 可见表现（血肉） | 方向（灵魂） | 失控表现（血肉） | 分流（筋骨） |
|---|---|---|---|---|
| 窄切 | 大题材落到具体误解、具体物件、具体话术 | 切得越窄，人物越立得住 | 题材写在标题里，故事里找不到 | 人物动机不足 → character-conflict |
| 临界时刻 | 话快骂出口、门快关上、孩子快哭出来、父母快发火、老师快定性、主角快误解完成 | 临界点越具体，张力越大 | 从关系稳定处起笔，张力靠台词堆 | |
| 观众预期 | 先让观众按经验补出熟悉套路，再用人物选择击穿 | 反转靠价值转向，不靠信息隐瞒 | 靠隐瞒信息制造惊讶，观众不参与 | 结构松散 → story-structure |

回问：用户只给题材不给人物时，先问「谁在这件事里最怕失去什么」，不替他定角度。
```

**信息一条没少**：七个要件、三个特征、临界时刻的全部例子、观众预期的完整机制都在。
**「临界点越具体，张力越大」保留了**——它归灵魂层，是择优梯度。

### 样本 B：图片《人物图片审美特征资产》的「特征颗粒」（原文 1918 字）

**所在文件**：`laohu-image-creation/skills/laohu-portrait/references/人物图片审美特征资产.md`（我上一轮新建的）

**改后：**

```markdown
## 人物成图特征                                 ← 筋骨

> 触发：写人像 / 人物资产成图提示词时            ← 血肉

| 组 | 可直接使用的词（血肉） | 方向（灵魂） | 失控表现（血肉） | 分流（筋骨） |
|---|---|---|---|---|
| 高光体态 | 脊柱拉直 / 胸腔舒展 / 肩背打开 / 颈线拉长 / 下巴微收 / 重心稳定 | 舒展优先于挺直 | 全身僵硬如摆拍 | 体态本体 → body-design |
| 身衣适配 | 肩线、胸省、腰侧收束、高腰线、面料贴合、垂坠方式 | 衣服衬比例，不是挂在人身上 | 衣服挂在人身上，不衬比例 | 服装结构 → costume-design |

| 首饰锚点 | 耳坠、项链、发饰、戒指、腕饰、鞋履与身份／光影／材质统一 | 宁少勿乱 | 首饰自成一套，不服人物 | 配饰设计 → accessory-design |
| 信息留白 | 半张侧脸 / 发丝遮眼 / 只露唇下颌 / 背影回头 | 留白不能偷掉身份锚点 | 遮到认不出人 | |
| 发丝质感 | 发根蓬松 / 分束自然 / 发尾层次 / 侧逆光下柔和轮廓 | 分束优先于顺滑 | 塑料发片 | 发型本体 → hair-design |
| 镜头距离 | 成品像：中近景或半身；B 与 M：左侧头特写＋右侧三视图；W：四区总览＋局部 | 按用途定构图，不套用一种 | 用同一种构图打所有资产 | 资产取景资格 → visual-assets |
```

**改法**：原来的解释句压成「方向」或「失控表现」两列——
「衣服不是挂在人身上，而是通过……衬出身体比例」→ 方向列写「衣服衬比例，不是挂在人身上」，失控列写「衣服挂在人身上，不衬比例」。**同一句话，从说明变成可检查的标准。**

## 七、树状图怎么展示

树里每个节点标它**回答什么**（触发条件），不标它「是什么」：

```text
laohu-photography/                    老胡摄影
├── SKILL.md                          路由：透视/景深/曝光/成像逻辑不成立时进入
└── references/
    ├── 专业判断与编译.md              综合判断与同素材比较
    ├── 对焦景深与焦外.md              触发「谁必须清楚」「糊到什么程度」
    ├── 景别与取景范围.md              触发「看不清」「太远」「装不下」
    ├── 机位与俯仰角度.md              触发「从哪边看」「高一点低一点」
    ├── 镜头关系与画面来源.md          触发「谁的视角」「过肩还是主观」
    ├── 镜头语言.md                    触发「这镜怎么拍」
    └── 镜头语言词典.md                导航页，指向以上各模块
```

扫一眼就知道该进哪个文件——这就是「从目录上感受到清晰划分」。
