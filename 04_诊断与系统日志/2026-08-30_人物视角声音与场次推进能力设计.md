# 人物视角声音与场次推进能力设计

## 一、真正要改变的结果

当前编剧能力已经能检查人物目标、场次压力、观众等待、可见证据和台词口气，但人物声音仍可能退化为方言词、口头禅、文学金句或类型片腔调。本轮要建立的不是一种固定文风，而是一条判断：

> 人物声音首先是他怎样看见、解释和应对世界，然后才是他怎样说话。

优化后，人物的职业经验、生活习惯、价值判断、回避方式和未说出的愿望应先改变他注意的证据与得出的结论，再进入台词、OS或VO。漂亮表达只有在推动人物选择、观众判断或场次状态时才能承重。

## 二、三种方案与选择

### 方案A：所有方法直接写入主 Skill

优点是每次都能看见；缺点是编剧主入口已同时承担因果、素材、构件、场次和交接，继续增写细则会提高默认上下文成本。

### 方案B：主 Skill 保判断，既有台词 Reference 保方法，反审 Reference 拦失败

主 Skill 新增简短的“人物声音合同”与验收项；`references/04_口述台词与方言.md`承接职业化感知、同组词语换义、普通愿望与当下身份反差、旁白的声画分工；`references/05_剧本语言诊断与反向审稿.md`拦截视角漂移、随机比喻、全员金句、类型腔替代人物和无状态变化的漂亮独白。

这是胜出方案：它使新能力在正式编剧时可达，同时不新建平行 Skill 或 Reference。

### 方案C：新建“人物文风” Reference

短期分类清楚，但与现有口述、台词、方言、金句和反审职责重叠，容易让人物声音被误解为额外文风装饰，不采用。

## 三、四层影响

### 灵魂

保留“先找关系，再炼句子”的旧原则，不新造箚言。新核心判断是：人物声音不是句子的装饰，而是人物对证据的选择、解释和应对。

### 筋骨

在台词成稿前先建立人物声音合同，再选择是否使用台词、OS或VO。一段强表达完成后，必须回到场次的`感知证据 → 人物解释 → 当场行动 → 可见后果`，不能停在人物感慨。

### 血肉

1. 职业化感知：人物因经验优先注意普通人不会注意的证据。
2. 人物化解释：同一证据经人物的欲望、恐惧和价值观得出不同结论。
3. 同组词语换义：一场只选一组关系相近的词语或比喻，让它们随处境改变指向，不随机更换漂亮意象。
4. 身份与愿望反差：普通愿望只有在它提高当下选择代价或可被后续回收时才承重。
5. 结果残留：用温度、气味、损坏、声音、位置和他人反应证明刚才发生过的事，不让旁白重述画面。

### 表皮

正式剧本继续只写可见可听内容。文学样章可以使用内心语言；正式剧本中保留的OS / VO必须标明声音身份，并与画面形成补充、对位或反差，不同义复述。

## 四、边界与反例

- 不把黑色幽默、杀手、黑帮、金句或类型片腔定为项目默认。
- 不要求每句同时承担多个功能；高信息句与普通行动、沉默、犹豫必须有节奏对比。
- 不用“人物独特”为不可信的职业判断免责；超出常识的感知能力需要前史、训练或当场证据。
- 不把文学旁白当作场次推进；删掉旁白后人物选择和状态不变，说明它只是风格层。
- 不让所有人物共用同一套比喻、句长、节奏和作者价值判断。

## 五、验证设计

- 当前场景：经验丰富的灰色职业人物面对日常刺激，语言必须来自其感知和普通愿望，且最后导向行动。
- 相邻场景：农民、护士、程序员、孩子与古代底层人物也能得到不同感知与解释，而不是共用黑色电影腔。
- 保真场景：方言、危险中短句、低烈度沉默、正式剧本与文学样章分权继续成立。
- 失败场景：只有氛围形容词、作者解释、随机比喻或漂亮独白，却没有可见证据、当场行动与状态变化时必须被拦下。
