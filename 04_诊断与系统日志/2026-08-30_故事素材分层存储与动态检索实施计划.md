# 故事素材分层存储与动态检索 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 把单 JSONL 素材库升级为原话、原子、usage 分层权威文件，用可重建 SQLite 索引和动态分页会话保证大库仍只向 AI 返回当前缺口所需内容。

**Architecture:** `sources/atoms/usage` 文件是长期真源，`story_material.sqlite3` 只是本地可重建索引。检索以 story / sequence / scene / beat / texture 范围建立会话，每页按返回字符预算装载卡片，用 cursor 继续，不设总候选数的创作上限。

**Tech Stack:** Python 3 标准库、SQLite3、JSON / JSONL、`unittest`。

**执行结果（2026-08-30）：** Tasks 1—8 已执行。29项素材专项与架构测试通过，真实库迁移为2条 source / 9条 atom / 0条 usage，逐记录等价且旧快照哈希不变；绑架短片真实 scene 会话返回1张卡、仍可续页、未含 source 原话并已正常关闭。能力架构验证通过。项目总检查只剩本轮前已存在的公共目录 `.DS_Store` 卫生项，本轮未擅自删除用户文件。结论 KEEP；真实大规模性能和长片成片收益继续 OBSERVE。

```python
class StoryMaterialStore:
    def __init__(self, root: Path):
        self.root = root
        self.index_path = root / "index" / "story_material.sqlite3"

    def source_path(self, source_id: str) -> Path:
        date = source_id.split("-")[1]
        return self.root / "sources" / date[:4] / date[4:6] / f"{source_id}.json"

    def atom_path(self, atom_id: str) -> Path:
        date = atom_id.split("-")[1]
        return self.root / "atoms" / date[:4] / date[4:6] / f"{atom_id}.json"
```

- [x] **Step 2: 实现 SQLite schema 与 rebuild**

```sql
CREATE TABLE sources(id TEXT PRIMARY KEY, source_type TEXT, fact_status TEXT,
  curation_priority TEXT, status TEXT, detail_path TEXT);
CREATE TABLE atoms(id TEXT PRIMARY KEY, source_id TEXT, atom TEXT,
  fact_confidence TEXT, analysis_confidence TEXT, status TEXT, detail_path TEXT);
CREATE TABLE atom_terms(atom_id TEXT, field TEXT, value TEXT,
  PRIMARY KEY(atom_id, field, value));
CREATE TABLE usage_summary(atom_id TEXT PRIMARY KEY, shortlisted INTEGER,
  used INTEGER, validated INTEGER, rejected INTEGER, latest_result TEXT);
```

```python
def pack_cards(cards: list[dict], budget: int, offset: int) -> tuple[list[dict], int, bool]:
    selected, used, cursor = [], 0, offset
    while cursor < len(cards):
        size = len(json.dumps(cards[cursor], ensure_ascii=False))
        if selected and used + size > budget:
            break
        selected.append(cards[cursor])
        used += size
        cursor += 1
    return selected, cursor, cursor < len(cards)
```
