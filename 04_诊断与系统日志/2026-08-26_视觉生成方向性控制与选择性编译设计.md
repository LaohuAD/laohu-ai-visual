# 视觉生成方向性控制与选择性编译设计

**状态：** 待老胡书面确认后进入实施计划。  
**适用范围：** 老胡 AI 视觉中所有会交给图片或视频模型生成结果的提示词；本轮先落地并验证图片结果图、F人物主视觉和《师妹问师兄》F01。  
**证据状态：** 用户反馈与同模型对照图是真实体验证据；模型注意力、属性绑定和多候选选择来自论文与官方资料；跨模型的最佳提示长度、词序权重和内部重写机制仍属于平台变量。

## 一、要解决的根本问题

当前项目已经能够完成完整注意力分析、四层编译、题材视觉合同、人物与服装设计、摄影关系和F→B/W/M资产接力，但真实生成暴露了一个新的断点：

```text
内部分析越完整
→ 越容易把每项分析都翻译成模型指令
→ 提示词从方向引导变成逐像素调度
→ 多个正确细节同时争夺注意力
→ 模型用于整体审美补全的空间被压缩
→ 结果更遵从局部，却更僵硬、更模板化或更缺少生命感
```

问题不在于“提示词太长”或“可执行语言错误”，也不在于模型拥有无限自主审美。真正缺失的是：项目尚未把`完整判断`与`完整投喂`分开，缺少从专业设计库中选择少数承重决定、明确方向范围并主动留下生成空间的编译机制。

本次设计要建立的新行为是：

> 人负责选择审美世界、角色母型、主结果与少数不可错锚点；模型在这些方向边界内完成非承重纹样、自然衣褶、次级配件、背景填充和局部摄影细节。内部判断必须完整，最终输入必须经过选择性压缩。

## 二、事实、推论与偏好

### 已确认事实

- 同模型对照中，旧故事化描述生成的小师妹在眼神、关系、动作统一和画面呼吸上优于新F01长提示词；新提示词局部遵从更强，但惊讶表情、奔跑动作、前景遮挡和背景奇观互相竞争。
- 用户给出的冷艳古风男性短提示词只锁身份母型、脸部方向、服装色彩、姿态、光线和气质，模型自行完成发冠、刺绣、金属链和背景辉光，得到完成度较高的角色海报。
- 文生图研究已经记录主体遗漏、属性错绑、概念渗漏和图文符合度与审美质量并非同一指标；部分现代系统会先用语言模型扩写短提示词，但各平台实现不同。

### 当前推论

- 高质量短提示词的优势不是字数少，而是`语义压缩率高、方向一致、非承重细节开放`。
- 过密提示词失败的原因不是细节本身有罪，而是没有区分`必须锁定、方向引导、模型补全`，导致所有细节被提升为同权约束。
- 模型开放空间并不自动产生原创；它通常优先返回训练分布中成熟但高频的答案。因此必须用一至两个非默认人物锚点抵抗平均化，并用人工候选竞争决定胜出。

### 项目价值取舍

- 不追求模型逐条服从而牺牲整体人物魅力。
- 不以“交给模型发挥”为理由放弃身份、题材、主轮廓、主色、关系和角色记忆点。
- 不把短提示词、固定字数或少关键词写成新的形式教条。
- 结果图追求观众体验；制作资产继续追求结构、角度、材料和拓扑可复现。两类结果不互相借壳。

## 三、方案比较

### 方案A：继续增强全量可执行控制

把人物、表情、肢体、服装、纹样、摄影和环境全部转换成可观察指令，并靠更严格绑定解决冲突。

- 收益：追溯清楚，局部规格容易验收。
- 风险：结果图继续像镜头执行表；模型把算力用于满足局部而非形成完整审美；跨模型适配成本高。
- 结论：只适用于B/W/M/S/A等制作规格板和确实承重的复杂关系，不作为结果图默认。

### 方案B：退回极简关键词召回

只写身份母型、少量外貌、色彩和风格词，让模型自由完成。

- 收益：容易调用训练分布中的成熟审美，输入成本低。
- 风险：角色趋向古偶模板、网红脸和高频服装；题材世界与人物独特性不稳定；无法证明为什么胜出。
- 结论：适合早期探索，不足以承担系列主角与长期资产上游。

### 方案C：方向性控制＋选择性锁定＋主动留白

内部仍执行完整注意力合同和专业设计；最终提示词只编译少量不可错锚点与方向性约束，明确哪些次级内容不需要控制，由模型从当前成熟分布中补全；再以多候选和人工选择抵消随机性与平均化。

- 收益：兼顾审美完成度、角色独特性、题材归属和可追溯性。
- 风险：需要新增编译判断，不能靠字符数机械验收；结果仍需真实候选比较。
- 结论：胜出方案。

## 四、四层能力怎样改变

### 灵魂：从“完整控制”改为“完整取舍”

完整注意力不是把所有注意事项写进提示词，而是完整决定：什么必须由人确定，什么只规定方向，什么应该交给模型，什么不应进入当前图片。

### 筋骨：增加三类决定与一次压缩门

每条正式生成提示词在内部注意力合同之后，增加：

```text
必须锁定：缺失会变成人物、题材或主结果错误的决定。
方向引导：规定审美范围与变化方向，但不规定唯一局部答案。
模型补全：当前不承担身份、关系或下游复现，允许模型自行组织的细节。
```

随后执行`选择性编译门`：上游人物、服装、美术、场景和摄影设计是可调用的设计库，不是必须全文进入最终提示词的清单。每项只有满足以下任一条件才进入正文：

1. 缺失会改变唯一主结果；
2. 缺失会造成身份、题材、关系或主轮廓误读；
3. 当前画幅和主体尺寸能够看见，并且它是本角色的非默认记忆点；
4. 它负责摄影机、光线或环境对主证据的必要托举。

其余内容留在专业设计包、人工验收或下游制作资产中。

### 血肉：母型召回与非默认锚点配合

结果图默认使用：

```text
一个高识别身份 / 题材 / 摄影母型
+ 一个唯一人物或对象承重结果
+ 3—6项不可丢锚点
+ 1—2项非默认人物记忆点
+ 一个主构图与主光关系
+ 少量方向性材料 / 色彩 /动作描述
```

数量只是内部审稿参考，不作为机械字数或关键词门槛。复杂场面可以增加必要关系，但每增加一项精确控制，都要说明它替代了哪部分模型自由度以及为什么值得。

### 表皮：格式不统一，编译逻辑统一

- F人物主视觉、场景写真、道具写真、封面和叙事成品图可以保留适合自身的外部结构；三段式不是强制所有图片使用。
- B/W/M/S/A/G继续使用专业规格板，不因本次优化删除结构证据。
- 视频继续保留时间因果与多主体绑定，但同样增加`必须锁定 / 方向引导 / 模型补全`判断，避免静态外观和非承重动作挤占主变化。
- 不建立固定提示词长度；脚本只检查职责、引用和硬结构，不根据字数判断审美。

## 五、F人物主视觉的专用编译

F的唯一任务是让人类确认一个完整角色是否真正成立。它可以成为B/W/M的共同源图，但不能为拆解牺牲人物与关系。

F最终正文只承接五项：

1. 角色母型与第一眼气质；
2. 一个正在发生的关系瞬间或人物状态；
3. 脸身、服装、妆发中的少数稳定锚点；
4. 一个支持人物的摄影观看方式；
5. 一个统一题材和质感的主风格先验。

服装在F中只锁`可识别品类母型、整体轮廓、主色关系、主要材料行为、一个人物化结构记忆点`。刺绣准确位置、连续纹样、次级配件、不可见背面、内里和鞋履结构交给模型补全或W结合专业正文处理。脸部只锁稳定关系和本次表情方向，不把眼睑、虹膜、眉峰、牙齿、手指和每缕头发同时写成精确调度，除非真实生成暴露了某一项明确失败。

当前F01应从“逐部位动作执行表”压缩成：小师妹人物母型、奔向大师兄的亲近目的、眼线与前倾重心这一组主证据、青瓷月白轻盈行旅裙装、半扎双环髻与山径线两个记忆点、古偶唯美人物成像和仙门云海空间支撑。具体脚步相位、两手五指、眼睑组合、三层发丝弧线、全部服装结构和精确焦点分配不再同时进入正文。

## 六、人机协作与候选竞争

一次提示词不再承担内部候选平均。主要人物与重要结果图执行：

```text
固定同一组必须锁定项
→ 形成3个只改变一个承重方向的候选提示词
→ 每个方向生成2—4张
→ 人工先按整体人物魅力和主结果盲选
→ 再检查身份、题材、记忆点、服装妆造和下游可用性
→ 胜出图进入B/W/M或视频链
```

候选方向可以改变关系瞬间、景别或主光中的一项，不能同时换脸、换衣、换动作、换场景和换风格。审美选择与提示词遵从分开评分：一张图可以很遵从但不好看，也可以很好看却变成另一个人物，两者都不能自动胜出。

## 八、失败处理与回退

- 如果短化后人物漂亮但变成高频模板：增加一项非默认人物锚点，不恢复全量细节。
- 如果题材归属丢失：补一个真正承重的题材证据或风格机制，不堆同义风格词。
- 如果服装结构漂移：判断它是否必须在F成立；必须则补主轮廓或主结构，不可见工程信息留给W。
- 如果关系和生命感下降：先检查唯一人物目的、眼线、重心和摄影机关系，不优先增加微表情部位清单。
- 如果模型连续遗漏关键锚点：减少同权概念、增强主体绑定或使用参考图；仍失败时记录模型适配，不把通用规则改成该平台特例。
- 如果制作资产因压缩而缺失结构：回退错误范围，仅恢复B/W/M/S/A/G的专业证据，不把F重新变成规格板。

## 九、代表性回归

实施后至少使用五类场景验证：

1. 年轻女性仙侠主角：F01同模型新旧对照，检查生命感、关系、古偶完成度和角色记忆。
2. 冷艳男性古风角色：短母型容易漂亮，检查是否能用一项非默认锚点避免模板化。
3. 年长男性师父：检查方向性留白不会自动美化年龄、变成仙翁或农人。
4. 非仙侠现代人物：证明规则依赖任务母型而非固定古偶词库。
5. W或S制作资产：证明选择性压缩不破坏结构板、材料证据与多视图一致性。

每类至少比较：整体审美、唯一主结果、身份准确、题材归属、不可替换性、提示遵从、下游可用性。没有真实生成时只标记规则行为通过，不能宣称审美已经提升。

## 十、完成标准

- 项目能够明确区分完整分析与最终投喂。
- 每条正式生成输入都能指出必须锁定、方向引导和模型补全，但最终正文不机械显示三个栏目。
- 结果图不再全文拼接人物、服装、场景和摄影设计。
- F01减少互相竞争的精确控制，同时保住身份、题材、关系、主服装轮廓与人物记忆点。
- B/W/M/S/A/G专业规格不因结果图压缩而退化。
- 候选竞争把审美与遵从分开评估，人类选择成为正式生产环节。
- 真实跨模型对照决定KEEP / OBSERVE / REVERT，不以规则写完替代成图证据。
