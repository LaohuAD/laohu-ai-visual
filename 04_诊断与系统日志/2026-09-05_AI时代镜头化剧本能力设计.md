# AI时代镜头化剧本能力设计

## 零、本轮范围校准：恢复完整作品，不再用局部样例代替

本轮正式交付不是“一场灯光对话”的扩写，而是把老胡文稿项目已经存在的《泠月 Luna 灯光武打教学短片制作脚本》重编为一集七场、约三分钟的镜头化完整剧本。原稿中的八种灯光、武打升级、实验馆空间路线、Luna 武装递进、老胡损伤递进和结尾回环都是必须保护的内容事实；后续可以重写表达、调整场次与镜头边界，但不能因验证新格式而把完整故事缩成单场样例。

先前生成的《开灯：电影感到底从哪来》只保留为暴露格式与主体错误的历史验证材料，不再代表当前作品，也不得成为新完整剧本的内容母稿。

### 0.1 品牌人物与视觉主体合同

Luna 是老胡内容体系的虚拟形象代言人、默认视觉主角和颜值担当。这不等于 Luna 只能单人出镜，也不等于每一个结果镜头都只能看见她；它规定的是整部作品的注意力归属：

- 双人、群像和武打场面允许老胡、对手、群演与环境完整出镜。
- Luna 是本片八种灯光的主要受光演示对象；讲人物为什么好看、光线怎样改变脸部与气质时，证据必须直接落在 Luna 身上。
- 关键动作由 Luna 发起，力量路线从她出发，决定性英雄帧、变身帧和高潮兑现优先留给她。
- 老胡可以拥有完整反应、逃跑、接招、受力和喜剧停点；单独拍他时，镜头必须承接 Luna 已经造成的动作结果、空间变化或关系后果，不能把他重新塑造成作品的颜值中心或灯光示范主体。
- “主要拍摄主体”不机械等于固定出镜时长占比。验收看开场承诺、灯光证据、动作发起、高潮兑现、结尾记忆点和封面承诺是否共同指向 Luna。

### 0.2 完整作品的故事母线

片名暂定《学个打光，差点把楼打没了》。老胡请 Luna 演示影视人物打光，前三题答得太顺后开始膨胀，第四题故意把伦勃朗光说成“三角油光”；Luna 借“实践教学”名义逐级加码，灯光从面部塑形变成走廊追击、穿墙断柱、顶光塌楼、底光变身、万剑与月轮炮。老胡在逃命和挨打途中喊出每种光的可见规律，最后两人随回收轨回到课堂，在漂亮的鳄鱼光中完成知识与笑点回环。

知识不能停下来单独讲，打斗也不能只是与知识无关的热闹。每一种光必须同时承担三件事：先在 Luna 身上形成可辨认的受光证据，再成为她下一次动作或力量几何的依据，最后通过老胡的反应与空间结果让观众记住它。

### 0.3 集、场、镜的作品结构

本稿采用一集七场。`VID` 是后续生成单元，不再充当剧本场次；正式剧本先按时间、空间和行动连续性划场，再在每场内按观看对象、动作阶段和反应结果划镜。

1. `1-1 中央测试台`：开课，完成正面柔光、蝴蝶光、鳄鱼光和伦勃朗光误答，第一脚把老胡送入侧门。
2. `1-2 明暗分区走廊`：正侧光追击，老胡被踢进测试墙。
3. `1-3 逆光长廊与结构测试区`：侧逆光闪击，连续穿墙、断柱并被抛向天台。
4. `1-4 高塔天台`：硬顶光形成垂直压迫，楼板逐层坍塌。
5. `1-5 地下光井`：底光翻转 Luna 的面部结构，完成月神武装与法相显形。
6. `1-6 弧形回收轨`：万剑封路、月轮炮和泡沫陨星把老胡送回课堂。
7. `1-7 中央测试台`：鳄鱼光恢复 Luna 的漂亮状态，知识收束，并用“下一期学运镜”留下结尾钩子。

每一场应有场头、人物、开场状态、连续镜号正文和场次结果。全片镜号从 `E01-S01-C01` 起，换场后场号递增；面向读者显示的“镜1、镜2……”全片连续，不在新场重新从镜1开始。

### 0.4 本轮不做的事情

- 不把完整短片机械拆成八集或八条互不相干的知识视频。
- 不另起炉灶重写一个纯灯光对话故事。
- 不把 Luna 的视觉主位误写成单人独角戏。
- 不以监视器、测试摄影机或解释性设备关系代替直接受光证据。
- 不在本轮直接进入资产、图片或视频提示词；先完成并审定镜头化正式剧本。

## 一、设计结论

老胡 AI 视觉的正式剧本不再只交付分场叙事，也不再把第一次镜头切分留给下游重新猜。凡是准备继续进入人物、服装、场景、视觉资产或视频提示词的作品，正式剧本在同一正文中完成文字分镜：先让人和下游 AI 读懂故事、人物关系、情绪压力与现场变化，再用集号、场号和镜号把每一段画面归入明确镜头。

剧本中的镜头设计是导演初稿，不是模型执行稿。剧本负责给出景别、基本镜头变化、参考时长和可想象的画面关系；视频提示词继续负责依据模型、资产和真实生成条件深化摄影机路径、构图变化、动作时间、声音与结束状态。下游可以优化手段，不能无记录改掉剧本的故事事实、人物关系、主画面、情绪方向和镜头编号来源。

## 二、第一个能力断点

旧系统已经定义 `E1-S1-C1`，视频提示词也要求逐镜方头，但正式剧本明确不写景别、机位和镜号。数据流因此是：

```text
分场剧本中的一大段动作与对白
→ 下游第一次判断在哪里切镜
→ 视频提示词再次组织画面关系
→ 人物出镜、朝向、控制权、反应和景别可能被重新猜测
```

问题不在于下游缺少更复杂的提示词，而在于剧本没有给下游一个稳定、可读、可追溯的镜头基础。单独增加一张分镜表仍会重复解释剧本；因此应把文字分镜并入正式剧本，并取消普通叙事作品从正式剧本到视频提示词之间的独立“分镜宏观表”。

## 三、剧本第一目标

剧本首先服务理解。人和下游 AI 读完后，应能准确复述：

- 整部作品和当前一集讲什么，主要关系怎样变化。
- 每场发生在哪里、何时发生、谁在场、从什么状态开始。
- 每个镜头实际看见谁、谁在画外、人物怎样朝向彼此、视线落在哪里。
- 谁先做什么，什么触发台词、打断、沉默和情绪变化。
- 关键道具由谁控制，灯光、声音、屏幕与环境变化由谁触发。
- 当前镜头停在哪里，下一镜从哪个新画面或新反应开始。

“可生成”不是剧本语言的第一目标。模型可执行语言由视频提示词负责；剧本不能因此退化成抽象梗概，也不能因为追求简短省掉人物心理因果、关系压力、空间位置和表演过程。

## 四、统一正文结构

### 4.1 文档头

正式剧本开头使用三个紧凑区块：

```text
【剧本说明】
作品形态 / 本稿用途 / 下游怎样继承 / 哪些内容可深化而不可改写 / 编号读法。

【作品信息】
片名 / 题材 / 画幅 / 体量或集数 / 参考时长 / 稿件状态 / 核心人物与关系。

【故事说明】
一句话故事 / 核心处境 / 主要矛盾 / 情绪运动 / 关键转折 / 结尾落点或集末卡点。
```

文档头负责整体讲戏。镜头正文不再出现“本镜为了表现”“建立某种关系”“证明某件事”等作者解释；人物动作、画面关系和台词本身必须让读者理解这一镜的作用。

### 4.2 集、场、镜

```text
第1集

1-1　日　内　具体地点
人物：……

【镜1｜E01-S01-C01｜全景｜固定镜头｜约4秒】
△ 开镜画面关系。
△ 动作、环境与构图变化。
人物（必要的情绪、声音与表演状态）：台词。
△ 对方反应与镜尾状态。
```

- `E` 是集号。
- `S` 是场号；连续时间或空间发生实质改变时新开场。
- `C` 是镜号；发生切镜、观看主体改变、视点跳转或摄影机无法连续抵达时新开镜。
- 景别是镜头属性，不是编号。
- 同一连续镜头可以由全景推进到近景，但正文必须写出人物和画面怎样连续变化。
- 一个镜头只保留一个主要观看焦点或主要状态变化；可以包含共同服务该结果的连续动作。

所有观众会看到或听到的正文必须归入一个镜号。场次标题和人物表之后不得出现游离在镜号之外的 `△` 动作、台词、声音或空镜。

## 五、画面关系替代设备坐标

剧本不机械书写“摄影机位于某物右前方45度”。这类设备坐标依赖参照系，仍可能让读者不知道人物露出哪一面、彼此看谁、谁被挡住。

镜头正文先写观众实际看见的结果：

```text
人物是否出镜
→ 位于画面左、右、中央、前景或后景
→ 露出正面、侧面、三分之二侧面或背面
→ 身体朝向和视线对象
→ 人物之间的距离、障碍、遮挡和高低差
→ 动作发生后这些关系怎样改变
```

当这些事实成立，读者自然能反推出摄影机的位置。只有 POV、过肩、俯视、低视角、门缝观察、反射观察等会改变观众信息权限的特殊视角，才在镜头方头中直接标明。

“前景 / 后景”不能单独证明构图。多人物镜头至少在正文中写清画面位置、身体朝向、眼线与关系对象；否则 AI 可能把所有人都安排成面向镜头。

## 六、情绪、心理与表演

普通自然说话可以不标情绪。只要情绪会改变台词含义、关系判断或后续动作，就在台词前的动作和人物括号中共同交代：

```text
触发证据
→ 人物怎样理解
→ 情绪怎样进入眼神、呼吸、手、身体距离或声音
→ 台词怎样说
→ 对方怎样反应
→ 说完停在哪里
```

允许少量、准确、可表演的心理解释，用于消除同一动作的多义性；心理不能代替画面，必须在同一镜头或相邻镜头出现可见、可听的表演证据与行动后果。

括号不只写“生气、笑、哭”。必要时写清强度、压制方式、语速、气口、重音或表面情绪，例如：

```text
Luna（压着刚冒出来的火，语速仍然平稳，句尾明显收紧）：……
```

## 七、声音术语

- `（O.S.）`：角色属于当前现场，但此刻没有出现在画面中，声音从画外传来。
- `（V.O.）`：旁白、内心声、回忆声或覆盖在另一组画面上的声音。
- 需要明确是内心独白时写 `（内心V.O.）`，不再用 `OS` 同时表示画外对白和内心声。

中文团队采用其他习惯时可以在文档头声明，但同一作品不得混用。

## 八、与下游的接力

新流程：

```text
故事与镜头化正式剧本
→ 美术、人物、服装、场景设计
→ 视觉资产编译与必要参考图
→ 视频提示词依据剧本镜号与资产深化执行
→ VC提纯与最终复验
```

普通叙事作品取消独立“分镜宏观表”和再次从分场剧本拆镜的步骤。知识动画、MV、预演板和用户明确要求故事板图片时，仍可保留其专业分镜资产或预演产物，但不得重新发明已经由正式剧本锁定的故事事件。

视频提示词必须保留剧本来源映射：

- 原样继承的镜头：记录对应 `E-S-C`。
- 一个剧本镜头因模型限制拆成多个执行镜头：使用子编号或明确一对多映射。
- 多个剧本镜头合并进一个 `VID`：保留全部来源编号与原顺序。
- 调整景别、运镜或构图：允许，但要保护剧本的主要画面、关系、情绪和镜尾状态。
- 需要改变人物出镜、事件顺序、台词、控制权或关系结果：返回编剧修改，不在视频提示词中暗改。

## 九、题材与体量边界

集、场、镜格式可以跨短视频、微短剧、影视短片和系列剧复用；具体节奏不能共用一套固定数字。“一集不超过三场”“一集约一千字”等只作为特定平台、时长和制作方式的候选经验，不进入全项目硬规则。

场次数量由地点、时间、行动连续性和当前作品体量决定。短内容可以主动减少无收益换场，长内容不能为满足短剧经验把不同时间和空间硬塞进同一场。

## 十、验收

### 当前场景

《学个打光，差点把楼打没了》的镜头化完整剧本必须做到：原制作脚本的八种灯光、七段空间推进、Luna 武装递进、老胡损伤递进和课堂回环全部保留；Luna 是主要受光对象、动作发起者、高潮兑现者和品牌视觉中心；老胡可以完整出镜并承担受力、反应与喜剧关系，但不得成为颜值展示和灯光教学的主要模特。每段动作与台词都属于具体镜号；多人同框时人物画面位置、身体朝向、眼线、动作来源、接触点和受力结果明确；情绪变化有触发、表演、说法和后果。

### 相邻场景

手机通话或家庭对话场景也能沿用同一集—场—镜结构；不因没有专业灯光或控制台就机械增加设备说明。

### 保真场景

故事设计、人物目标、观众等待、场次压力、道具状态、声音职责和生产证据账本继续保留；文艺、观察和低烈度作品不被强迫增加争吵、反转或高速切镜。

### 失败场景

拒绝以下正文：镜号之前出现游离动作；把 `1-1` 当镜号；把景别当编号；只写前景后景而不写人物朝向与眼线；一个镜头内无过渡切到多个不可连续视点；用“本镜建立关系”代替正文；用 `OS` 同时表示内心声和现场画外对白。
