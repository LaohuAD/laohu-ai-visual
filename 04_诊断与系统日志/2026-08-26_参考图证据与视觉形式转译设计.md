# 参考图证据与视觉形式转译能力设计

> 设计状态：待老胡审阅。本文只确定能力边界、职责、数据流、写回位置和验证方式，不直接修改业务 Skill。

## 一、设计结论

保持老胡 AI 视觉现有十二个 Skill、生产状态和权威层级不变，不新建海报 Skill，不建立按纸感、点阵、双色、撕纸等表面样式命名的风格库。

本轮采用“加厚现有负责人”的方式：在 `laohu-art-direction` 下新增一个按需读取的条件性 Reference，补足从参考照片、参考图集合、文章主题或抽象命题到视觉形式之间的专业转译；`laohu-visual-assets`只消费已经确认的形式判断并编译成模型可执行提示词；`laohu-cover-design`只在发布目标下重新组织文字与图像；`laohu-generation-review`用真实结果定位转译、编译或生成漂移的第一个断点。

本轮真正要改变的长期结果是：

```text
面对不同来源、题材、媒介和作品目的时，
系统不再依赖固定风格词或偶然审美直觉，
而能从可追溯证据中选择最合适的形状、空白、节奏、色彩、文字与再生产方式，
产生真正不同的高质量候选，并说明胜出、淘汰和停止的原因。
```

- 固定数字只在特定风格、平台或确定性接口中生效，不升级为全项目审美规则。
- 对受限许可项目只吸收可以独立重新推导的一般问题和一般机制，不复制其独特表达、固定组合、脚本和文档结构。

## 三、第一个能力断点

当前生产链已有：

```text
故事与题材事实
→ 美术风格合同、形态 / 色彩 / 材料 / 光影 / 文化 / 世界物理
→ 人物、服装、场景专业设计
→ 注意力合同与提示词编译
→ 图片生成与真实复盘
```

缺失的中间链是：

```text
参考照片、参考图集合、文章或抽象命题
→ 输入角色与保真责任
→ 可观察证据及其置信度
→ 语义最小集与关系不变量
→ 保留 / 合并 / 删除 / 转化 / 留空
→ 形状、质量、线、负形、节奏、裁切、重叠、比例、色彩、文字与再生产语法
→ 机制不同的候选
→ 现有注意力合同
```

因此第一个能力断点是 `laohu-art-direction` 的条件性血肉层缺口，不是顶层灵魂错误，也不是 `laohu-visual-assets`提示词写得不够长。

## 四、设计边界

### 4.1 本轮负责

- 分清不同输入图像在当前任务中的职责和允许变化范围。
- 从真实可见事实中提取承重关系，不把情绪推论伪装成观察事实。
- 判断最少保留什么仍能识别当前作品或当前图像。
- 把关系编译成可比较的形式候选。
- 区分风格家族的稳定内核、允许变化和样本残留。
- 让色彩、文字、空白和再生产工艺承担明确职责。
- 建立太写实、太抽象、太泛化、只剩装饰和参考泄漏的失败门。

### 4.2 本轮不负责

- 不新建独立海报、抽象艺术、Zine、点阵或双色 Skill。
- 不把外部项目登记为运行时依赖，也不安装或调用它们完成本项目作品。
- 不规定全项目必须使用纸张、版画、点阵、留白、双色或英文微字。
- 不替编剧决定故事，不替人物 / 服装 / 场景完成对象本体设计。
- 不替封面决定点击承诺，不替视觉资产选择固定资产版式。
- 不在没有真实生成结果时宣称视觉效果已经提升。
- 不在本设计阶段修改现有业务文件。

## 五、运行架构

### 5.1 触发条件

只有出现以下任一信号时读取新的条件性 Reference：

- 用户提供一张或多张图片，希望分析、转化、抽象、重组或形成新视觉系统。
- 用户提供参考图集合，希望提取可复用风格，但不复制原图内容。
- 任务是概念海报、编辑主视觉、艺术化封面、系列视觉或图像蒸馏。
- 文章、主题或情绪需要转成一个可见关系，而不是直接画成完整场景。
- 真实生成结果只有表面风格，没有源图、故事或作品特有的关系。
- 候选只在色彩、位置、滤镜和纹理上变化，没有改变视觉语法。

普通制作资产、已经锁定的专业设计、纯结构校准板和无需参考分析的日常图片不读取，避免默认上下文膨胀。

### 5.2 数据流

```text
当前权威输入
→ 输入图像角色与保真级别
→ 观察证据 / 推论 / 设计选择分离
→ 固定系统 / 可变系统 / 样本残留
→ 语义最小集与关系不变量
→ 形式转译卡
→ 3—5套机制不同的候选
→ 美术方向胜出与淘汰
→ 部门分发
→ 视觉资产注意力合同和提示词编译
→ 封面按传播任务重组
→ 真实生成复盘
```

## 六、核心能力模型

### 6.1 输入角色与保真级别

每张输入图只承担一个主要职责，必要时有一个明确次要职责：

| 输入角色 | 需要保留 | 允许改变 | 禁止行为 |
|---|---|---|---|
| 编辑目标 | 用户要求保留的主体与事实 | 明确授权的环境、构图、表面或局部 | 静默丢弃主体、冒充原图未变 |
| 身份参考 | 人物、产品、角色的识别特征 | 动作、场景、摄影和非身份表面 | 继承原构图和无关背景 |
| 结构参考 | 拓扑、比例、姿势、运动路径或版式关系 | 内容对象、材质和风格 | 把占位颜色和示意文字带进成品 |
| 风格参考 | 构图、色彩、材料、光线、再生产或文字机制 | 当前对象和具体布局 | 复制原主体、文字、品牌和精确组合 |
| 版式参考 | 信息层级、图文关系、阅读路径和空间预算 | 坐标、字体、文案和对象组合 | 换图不换设计 |
| 辅助插入 | 一个指定人物、物体、纹理或片段 | 它在新构图中的尺度与位置 | 让辅助对象接管整张图 |

保真级别不使用抽象的“高 / 中 / 低”单独作结论，而要列出具体不变量：像素、身份、数量、比例、轮廓、颜色、空间关系、文字、Logo、可变区和不可变区。要求像素级不变时，优先走确定性合成；不能验证时不得承诺已经完全保真。

### 6.2 参考集合分析

对参考集合形成三类结果：

- `固定系统`：在多数有效样本中重复，移除后家族身份明显丢失。
- `可变系统`：样本之间变化，但家族身份仍然成立，可以成为候选轴。
- `样本残留`：只属于个别作品的文字、品牌、人物、日期、地点、对象或精确版式，不复用。

只有一张参考图时，只能记录观察特征和当前推论，不能声称集合频率。尺寸和比例使用元数据；视觉占比可以估计，但必须标记为估计。

### 6.3 视觉证据卡

根据实际输入选择必要字段，不机械填满：

```text
主要对象与完整关系：
辨识度最高的1—3项事实：
主质量与次质量：
主轴、边界和方向：
数量、分组、间隔与节奏：
重叠、遮挡和深度关系：
色彩角色及面积 / 明度 / 饱和度层级：
有意义的空白：
情绪推论及其可见依据：
不确定和不可推断内容：
```

每项证据按四问排序：删掉后是否失去辨识；是否组织其他元素；是否因面积、明暗、饱和、孤立或重复形成对比；是否属于当前图像而非通用题材。

### 6.4 语义最小集与关系不变量

先问：删到什么程度，仍然是这张图、这个故事或这个作品，而不是一个通用图标或同题材模板。

优先保留：主次、相对尺度、方向、数量组、间隔、左右 / 上下、重叠、包围、路径、视线、尺度参照和有意义的空白。优先删除：表面噪声、重复微细节、无功能装饰、背景杂物、泛化气氛和只为显得“设计过”的符号。

语义最小集不是越少越好。删到需要标题解释才能认出当前对象，说明抽象过度；保留到可以从形式近似还原完整原图，说明抽象不足。

### 6.5 形式转译卡

每个承重形式必须能回指一条来源事实：

```text
来源事实
→ 保留、合并、删除、转化还是留空
→ 质量 / 色域 / 轮廓 / 线 / 负形 / 节奏 / 裁切 / 重叠 / 比例 / 字体 / 再生产方式
→ 相对位置、尺度和主次
→ 它改变的观看结果
→ 失效和反转条件
```

形式候选库只提供动作，不提供固定象征：

- 质量与色域：平面、块面、岛状、带状、包围、断裂、压缩。
- 线与边界：轴线、路径、地平线、轮廓残段、方向序列。
- 负形：缺口、通道、孔洞、间隔、被省略的位置。
- 节奏：不等距重复、聚散、密度变化、大小层级、停顿。
- 空间：裁切、偏心、重叠、遮挡、尺度反差、前后关系。
- 文字：标题、标签、反声、路径、质量、节奏、主视觉或不使用。
- 再生产：摄影、点阵、网点、复印、版画、纸张、扫描、平面数字图形等；它必须改变边缘、密度、色层或缺陷，不只是风格名称。

### 6.6 复杂度压缩

输入越复杂，形式通常越需要主动合并，而不是逐项描写。树叶、人群、窗格、浪花、碎石、织物、城市细节和重复物体优先压缩成质量、方向、分组、间隔和少量代表性节奏。

复杂度的目标不是简洁本身，而是让主关系在正常尺寸和缩略图都能成立。若简化后只剩通用圆、方、点、曲线，应恢复一条最有辨识度的来源关系，而不是恢复完整对象。

### 6.7 色彩职责

色彩候选必须明确一种主要职责：身份、主次、入口、桥接、平衡、方向、空间分层、情绪事件或世界规则。

执行色彩移除测试：在内部假设移除该颜色。如果视线路径、视觉平衡、图地关系、连续性和含义基本不变，它只是装饰，应重新设计或删除。若原图本身是窄色域或单色，不为“丰富”强行增加颜色。

### 6.8 文字与图像关系

先判断文字是否必要，再决定它承担什么：补充事实、制造点击、形成反声、建立尺度、连接空间、打断秩序或成为主视觉。文字不得自动退化为底部小标签，也不得因为“设计感”制造伪日期、伪坐标、伪档案号和无意义英文。

标题与图像的关系由场景事实决定：对齐或反向作用于地平线、道路、建筑、人物视线、动作方向、轮廓和安静区域。允许少量有意义的前后遮挡，但必须保护眼睛、嘴、关键动作、产品结构、Logo和辨识性轮廓。缩略图和灰度下仍要保住层级。

### 6.9 候选竞争与失败门

完整调用仍形成3—5套候选，但新增以下要求：

- 相邻候选至少改变一个承重关系和一种形式语法。
- 换颜色、换位置、换纸纹或镜像不构成新候选。
- 每案说明保留了什么、删掉了什么、观众先看什么、形式为什么适合当前内容。
- 固定系统保持家族身份，可变系统承担候选差异，样本残留不得进入。

失败门：

| 失败 | 表现 | 返回动作 |
|---|---|---|
| 太写实 | 可以近似重建原图，细节和场景深度占主导 | 合并质量、删除表面、保留关系 |
| 太抽象 | 离开标题无法识别当前对象或关系 | 恢复一条高辨识来源证据 |
| 太泛化 | 形式可无损替换到大量同题材作品 | 恢复当前作品独有的尺度、间隔、动作或关系 |
| 只剩装饰 | 色块、点、线、纸纹和英文无法回指事实 | 删除装饰，重做证据映射 |
| 参考泄漏 | 复制原图文字、品牌、主体或精确构图 | 隔离样本残留，重做当前原创对象 |
| 保真冒充 | 声称原图、身份或产品完全未变但没有验证 | 降级声明或改走确定性合成 |

## 七、四层重编译

### 7.1 灵魂 `SOUL`

现有顶层目的和美术箴言保持不变。新证据没有证明项目价值方向错误，不新增全项目口号。

新的条件性 Reference 内使用一条可执行判断：参考图提供证据，不替作品作决定；先保住承重关系，再选择表面语言。它只裁决参考使用，不升级为顶层箴言。

### 7.2 筋骨 `STRUCTURE`

- 不新增 Skill、状态和公共负责人。
- `laohu-art-direction`新增条件性 Reference 路由和形式转译卡。
- `laohu-visual-assets`必须继承形式转译卡，但不得重做候选和艺术命题。
- `laohu-cover-design`可以按点击任务重新组织文字和画面，但不能越过事实与保真边界。
- `laohu-generation-review`区分上游转译错误、专业设计未兑现、提示词编译错误和模型生成漂移。

### 7.3 血肉 `CRAFT`

新增输入角色、固定 / 可变 / 残留、视觉证据卡、语义最小集、关系不变量、形式映射、复杂度压缩、色彩职责、文字—图像关系和双向失败门。

### 7.4 表皮 `FORM`

- 在美术方向交接包中增加形式转译卡和参考职责，不固定比例与风格参数。
- 在视觉资产代码块中显式写参考职责、必须保留、允许改变和不得继承。
- 可机械验证的精确文字、Logo、像素、几何和文件完整性继续交给确定性工具；审美选择不写成关键词搜索脚本。
- 增加行为场景，不用“文件中出现某个词”证明能力成立。

## 八、唯一负责人和拟写回文件

## 九、行为验证

### 9.1 当前场景

输入一张具有建筑、人物尺度、路径和明显色彩关系的照片，要求做原创编辑主视觉。

预期行为：

- 先判定照片角色和具体保真不变量。
- 分开观察事实、情绪推论和设计选择。
- 提取语义最小集和关系不变量。
- 产生至少三套关系与形式语法真正不同的候选。
- 每个形式都能回指来源事实，胜出有淘汰理由。
- 结果不默认成为上图下抽象、纸感或双色。

### 9.2 相邻场景

输入一篇没有图片的文章，主题是“一个人反复准备，却始终没有出发”。

预期行为：

- 不虚构已观察的照片事实。
- 从内容因果提取一个可见关系，例如反复排列而缺失一个出口，而不是随机选择旅行箱、道路或时钟。
- 候选可以使用摄影、图形、字体或混合媒介，不被外部样片锁成纸感海报。

### 9.3 保真场景

输入已经确认的F人物写真、B素体、W服装、M妆造和S场景制作资产。

预期行为：

- 不强制读取新 Reference。
- 不把制作资产改成极简Zine、上下分栏、双色、点阵或抽象面板。
- 保留现有资产依赖、固定版式、注意力合同和下游接口。

### 9.4 失败场景

- 只有一张风格参考图时，拒绝宣称已经发现集合固定规律。
- 用户要求原图像素完全不变但运行环境只能生成式编辑时，停止冒充并返回确定性合成需求。
- 参考图包含第三方品牌、人物、文字或受限许可固定组合时，只提取允许使用的机制，不复制样本残留。
- 候选只换颜色、位置或纹理时，拒绝把它们算作三个方向。
- 形式无法回指来源事实时，删除装饰并返回证据卡。

### 9.5 巅峰行为

- 同一输入下出现真正不同的高质量候选。
- 胜出方案强化作品主胜负手，不是最像外部样片的一案。
- 能说明保留、删除、转化和留空分别改变了什么观看结果。
- 能否决一份没有硬伤但过于通用的漂亮结果。
- 缩略图、正常尺寸、去文字和相邻题材测试均有明确结论。

## 十、进化记录与结论门

本轮实施后新建一条与 `EVO-20260825-007`、`EVO-20260825-008`互相链接的记录，不并入旧记录，因为可见症状相邻，但候选机制不同：旧记录解决题材视觉负责人和提示词注意力，本记录解决来源证据到形式选择的中间转译。

初始状态只能是 `OBSERVE`：

- 文本和行为场景通过，只能证明新机制进入了运行链。
- 至少一次当前场景和一次相邻场景完成真实图片候选后，才判断是否 `KEEP`。
- 若新方法让不同题材都收敛成纸感、留白、单色、抽象图形或伪编辑文字，立即缩小触发范围或 `REVERT`。

重新唤醒条件：

- 真实生成仍只有表面风格，没有源图或作品特有关系。
- 参考图分析再次把单一样本当成固定规律。
- 候选仍只换色、位置和滤镜。
- 制作资产被错误抽象化或丢失结构证据。
- 用户要求完全保真但系统继续使用不可验证的生成式编辑。
- 新方法稳定提升候选差异、作品专属性和缩略图识别，可考虑由 `OBSERVE` 升级为 `KEEP`。

## 十二、设计验收

- 没有新增 Skill、作品状态和顶层职责。
- 第一个能力断点明确落在美术指导的条件性血肉层。
- 每个新增判断都有触发、动作、效果、失败和返回条件。
- 深度来自因果和边界，广度来自选择轴，不来自更多风格词。
- 固定比例、色板、纸张、文字和版式没有升级为通用规则。
- 受限许可项目没有被复制成项目文件、脚本和固定流程。
- 视觉资产和封面只消费属于自己的接口，没有接管美术候选判断。
- 制作资产、现有注意力合同和十二Skill基础框架通过保真回归。
- 没有真实成图时只记录 `OBSERVE`，不宣称审美提升已经成立。
- 实施文件范围清楚，能够分阶段回退，不混入无关改动。
