# 参考图证据与视觉形式转译能力实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. If 老胡 later explicitly authorizes subagents, superpowers:subagent-driven-development may be used instead. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变现有十二个 Skill、生产状态和权威层级的前提下，把“参考照片、参考图集合、文章或抽象命题”稳定编译为可追溯、可竞争、可复盘的视觉形式判断，并保护制作资产和既有注意力合同不被风格化误伤。

**Architecture:** `laohu-art-direction`继续拥有作品级视觉方向，在按需 Reference 中新增“输入职责 → 观察证据 → 语义最小集 → 关系不变量 → 形式转译卡 → 机制候选”；`laohu-visual-assets`只消费胜出卡并进入现有图片提示词编译；`laohu-cover-design`只为点击任务重组图文关系；`laohu-generation-review`从真实结果定位第一个断点。新增能力先以行为场景 RED 固定边界，文本与架构验证通过后登记为 `OBSERVE`，不把规则成立冒充成视觉效果已被真实成图证明。

**Tech Stack:** Markdown Skill / Reference、JSON 行为场景、Python 架构验证器、Bash 总检查脚本、Git 本地检查点。

### Task 2: 新建参考图证据与视觉形式转译方法

**Files:**

- Create: `skills/laohu-art-direction/references/03_参考图证据与视觉形式转译.md`
- Test: `tests/capability_scenarios.json`

- [ ] **Step 1: 创建 Reference 头部、原则和使用边界**

文件必须以以下能力判断开场：

```markdown
# 参考图证据与视觉形式转译

参考图提供证据，不替作品作决定。先保住承重关系，再选择表面语言。

本 Reference 只在参考分析、艺术转译、编辑主视觉、概念海报、系列视觉、图像蒸馏或“只有表面风格、没有作品关系”的诊断中读取。普通制作资产、已经锁定的专业设计、纯结构校准板和不需要参考分析的日常图片不强制读取。
```

必须明确：它不新建海报 Skill，不把纸感、点阵、双色、撕纸、Zine、英文微字或上下分栏设为默认答案，不接管人物 / 服装 / 场景本体设计。

- [ ] **Step 2: 写“输入图像角色与保真级别”**

覆盖：

- 编辑目标
- 身份参考
- 结构参考
- 风格参考
- 版式参考
- 辅助插入

每种角色都要写清`必须保留 / 允许改变 / 不得继承 / 失效表现`。要求像素级不变时，明确优先确定性合成；生成式编辑无法验证时必须降级声明，不能承诺完全保真。

- [ ] **Step 3: 写“观察事实 / 推论 / 设计选择”与集合边界**

必须包含：

```text
一张参考：只能记录可观察特征和当前推论，不能声称样本频率。
多张参考：分成固定系统 / 可变系统 / 样本残留。
固定系统：移除后家族身份明显丢失。
可变系统：变化后家族身份仍成立，可成为候选轴。
样本残留：人物、文字、品牌、日期、地点、具体对象或精确组合，不复用。
```

尺寸和比例读取元数据；视觉占比若只能目测，必须标记估计，不伪造精确测量。

- [ ] **Step 4: 写视觉证据卡**

至少覆盖：主要对象与完整关系、1—3项高辨识事实、主 / 次质量、轴线和边界、数量 / 分组 / 间隔 / 节奏、重叠 / 遮挡 / 深度、色彩角色、有意义空白、情绪推论及依据、不确定内容。

证据排序使用四问：删除是否失去辨识、是否组织其他元素、是否形成视觉对比、是否属于当前作品而不是题材通用物。

- [ ] **Step 5: 写“语义最小集与关系不变量”**

明确优先保护主次、相对尺度、方向、数量组、间隔、左右 / 上下、重叠、包围、路径、视线、尺度参照和有意义空白；优先删除表面噪声、重复微细节、无功能装饰、背景杂物、泛化气氛和伪设计符号。

双向停止门：

- 离开标题就无法识别当前对象或关系：抽象过度。
- 能从形式近似还原完整原图：抽象不足。

- [ ] **Step 6: 写“形式转译卡”**

固定接口：

```text
来源事实
→ 保留 / 合并 / 删除 / 转化 / 留空
→ 质量 / 色域 / 轮廓 / 线 / 负形 / 节奏 / 裁切 / 重叠 / 比例 / 字体 / 再生产方式
→ 相对位置、尺度和主次
→ 改变的观看结果
→ 失效与反转条件
```

形式轴是候选动作，不是固定象征。覆盖质量与色域、线与边界、负形、节奏、空间、文字、再生产方式。再生产方式必须改变边缘、密度、色层或有来源的缺陷，不能只写一个风格名。

- [ ] **Step 7: 写复杂度、色彩和文字关系**

必须包含：

- 复杂输入优先压缩成质量、方向、分组、间隔和少量代表性节奏。
- 简化后只剩通用圆方点线时，恢复一条当前作品独有关系，而不是恢复全部对象。
- 色彩必须承担身份、主次、入口、桥接、平衡、方向、空间分层、情绪事件或世界规则中的一个主要职责。
- 执行色彩移除测试；移除后观看关系不变的颜色属于装饰。
- 文字先判断是否必要，再决定补充事实、制造点击、形成反声、建立尺度、连接空间、打断秩序或成为主视觉。
- 禁止伪日期、伪坐标、伪档案号和无意义英文。

- [ ] **Step 8: 写候选竞争和失败门**

完整调用产生3—5套候选；相邻候选至少改变一个承重关系和一种形式语法。换色、换位置、换纸纹、镜像不算新候选。

失败分类必须明确：

- `太写实`
- `太抽象`
- `太泛化`
- `只剩装饰`
- `参考泄漏`
- `保真冒充`

每类都写`可观察表现 → 最早返回动作 → 重新进入条件`。

- [ ] **Step 9: 写交付模板和双门验收**

交付模板必须包含：任务触发、输入角色、保真不变量、观察 / 推论 / 选择、固定 / 可变 / 残留、视觉证据卡、语义最小集、形式转译卡、候选、胜出、淘汰、下游必须继承、验证状态。

底线门拦住事实混写、参考泄漏、保真冒充、无来源装饰和伪候选；巅峰门要求候选机制真不同、胜出服务主胜负手、缩略图和去文字仍成立，并能否决“漂亮但通用”。
