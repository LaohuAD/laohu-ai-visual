# AI时代镜头化剧本能力实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让正式剧本在同一正文中完成易读叙事与初步文字分镜，再将同场相邻的 `E-S-C` 剧本镜头按目标模型硬边界与融合质量组合为 `E-S-B` 视频生成批次，消除镜号归属、下游重复拆镜、生成单元命名和跨批连续性的猜测。

**Architecture:** `laohu-script-writer` 继续作为唯一编剧负责人，正式剧本以集—场—镜锁定可见事件；`laohu-video-prompt` 作为批次唯一负责人，只在同一场内将相邻源镜头组合为 `E-S-B`，批次内再用连续“镜头N”编译摄影、表演、动作、声音与停点。跨场转场由前场末批和后场 `B01` 通过同一交接载体双端完成，但一个批次不跨场。

**Tech Stack:** Markdown 规则与样例、Python `unittest`、JSON 行为场景、项目现有 HTML 渲染器。

DOMAIN_HEADING = re.compile(
    r"^(?P<id>E\d{2}-S\d{2}-B\d{2}|(?:VID|LZ|[BCFGPWMSA])\d+)"
    r"(?:\s*[｜|]\s*(?P<title>.*))?$"

def domain_type(domain_id: str) -> str:
    if re.fullmatch(r"E\d{2}-S\d{2}-B\d{2}", domain_id):
