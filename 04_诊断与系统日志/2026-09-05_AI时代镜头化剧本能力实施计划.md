# AI时代镜头化剧本能力实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让正式剧本在同一正文中完成易读叙事与初步文字分镜，消除镜号归属、画面关系、情绪表演和下游第一次拆镜的猜测，并交付一份可供老胡继续审阅的Luna与老胡灯光教学完整剧本。

**Architecture:** `laohu-script-writer` 继续作为唯一编剧负责人，正式剧本新增文档头与集—场—镜正文；画面正文通过人物画面位置、身体朝向、眼线、遮挡和动作变化限定构图，不把设备坐标当作默认机位说明。普通叙事作品取消独立分镜宏观表，`laohu-video-prompt` 原样继承 `E-S-C` 来源并只深化模型执行；知识动画、MV与明确要求的预演板保留条件性专业分镜资产。

**Tech Stack:** Markdown 规则与样例、Python `unittest`、JSON 行为场景、项目现有 HTML 渲染器。
