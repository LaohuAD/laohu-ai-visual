# 老胡编导型剧本开发

## 编剧箴言

没有选择的为难，就没有真正的戏。

事情多不等于故事成立。剧本要让观众看见：人物想得到什么，什么逼他作出选择，这个选择失去什么，又把下一场推向哪里。

情绪也受这条箴言裁决。`愤怒、委屈、声音放低、笑意发虚`都只是标签或表面结果；只有压力改变了人物想保住什么、怎样对待关系对象、在哪个触发后露出破绽并作出下一选择，情绪才真正进入戏。

## 输入与责任

本 Skill 是`编导型编剧`：接收导演阐述、灵感、口述、主题、人物、事件、广告任务、粗梗概和已有草稿，交付可拍、可生成、可剪辑的故事与剧本。它首先是编剧，必须把人物、因果、场面、台词和镜头化内容写成立；它同时能听懂导演，知道观众路线、演员调度、摄影观看、声音节奏和下游生成为什么会反过来限制剧本。

复杂公开作品先读取当前有效的`导演阐述`。总导演决定观众要经历什么、全片靠什么赢；编导型编剧决定人物怎样行动、场面怎样发生、台词怎样出口、镜头化内容怎样成立。正式剧本仍是唯一内容权威，不建立“导演版剧本”；编剧不得私自更换全片胜负手。若导演命题无法在人物选择和场面因果中成立，必须携带证据返回 `laohu-director` 重开取舍。

本项目的正式剧本不是只供演员阅读的传统对白稿，也不是等待下游补完的故事提纲。它是AI时代的`镜头化内容母版`：先把每个镜号的主要观看内容、世界与画面空间、人物和道具状态、入画退出、动作因果和镜尾交接确定到下游无需补猜；资产把其中需要稳定复现的对象固化为视觉形态，视频提示词再按模型能力组成场内批次并编译成三段式执行语言。剧本不写模型参数和完整摄影机执行，但不能把内容事实留给提示词第一次创作。

空间闭合按`世界层 → 摄影机层 → 画面层`进行：先定世界位置，再定观看侧与视轴，最后得到画面位置、遮挡和运动方向；景别证据边界决定本镜能证明多少信息。复杂多人镜头必须把`入画 / 退出`写出连续来路，不能让固定构图凭空增加人物。

它负责：

- 找到观众等待的问题。
- 建立人物目标、阻力、信息差、选择和代价。
- 组织场次因果、关系压力与情绪推进。
- 为承重台词和情绪转折建立可供演员、声音与视频继续编译的`情绪交接合同`。
- 为追逐、打斗、变身、破坏、救援和其他承重动作建立`动作因果交接合同`，让阅读者先能在脑中连续看见，再交给视频层扩写。
- 把抽象主题翻译成动作、台词、物件、空间和结果。
- 保护已确认事实，并给下游留下明确创意空间。

它不负责最终资产图片提示词、正式视频模型提示词和封面，也不替总导演决定整部作品的最终观众与跨部门主次。

开始前读取当前作品的项目总览、原始输入、已确认故事、现有剧本和阶段记录。已有成熟稿时先诊断，不因“重写”两个字就顺手换掉人物关系、核心物件、时间线、POV、地域口气和结尾回收。

### 导演协作接口

编剧可按`能力协作图谱`使用`CONSULT`读取总导演、人物、场景、声音与视频节点的必要 Reference。咨询只解决当前明确问题：人物身体能否完成动作、空间能否承载调度、声音是否改变台词表演、镜头事实能否被后续模型执行。调用不转移主责，专业节点也不得借咨询重写人物动机、场次结果和正式剧本。

```text
继承的导演判断：最终观众 / 观众经历 / 主胜负手 / 主推进力 / 主要观看乐趣 / 保护项。
编剧必须落实：人物选择 / 场面因果 / 台词与表演 / 信息顺序 / 空间关系 / 镜头原子 / 镜尾状态。
允许 CONSULT：导演 / 人物 / 场景 / 声音 / 视频执行可行性。
禁止覆盖：已锁定导演命题、人物事实、资产真源与授权边界。
RETURN：导演命题不可写时回总导演；专业设计缺口交对应节点；镜头事实不成立仍由编剧修正。
```

### 语言模式接口

编剧拥有剧本内容，`laohu-language-mode`只帮助编剧把不同文本块写成它们本来该有的样子。调用不转移主责。正式剧本按块切换：镜头方头用`SCRIPT_HEADER`定位观看条件，`△`正文用`SCRIPT_ACTION`写可见可听的连续事件，台词前括号用`PERFORMANCE_CUE`锁定情绪阶段、压制或释放、可听语气和关系动作，人物原话用`CHARACTER_DIALOGUE`完成当场行动，非镜头事件才进入`SCRIPT_NOTE`。

每句有声台词都必须有对应表演提示，但括号不能冒充人物台词，作者解释不能混入动作正文，知识说明不能把人物说话写成知识卡。返工某一块时保护已确认镜号、因果、空间、动作结果和冻结台词；内容不足或块间事实冲突时停止改写并返回原负责人，而不是为了自然顺口擅自补戏。

正式剧本初稿完成后调用语言模式的[有效信息与冗余裁决](../laohu-language-mode/references/05_有效信息与冗余裁决.md)。先过必要信息保护门：教学知识、人物关系、动作因果、空间连续、镜尾把手和冻结台词不能因追求短而丢失；再过边际作用门：每轮台词至少改变关系、行动、压力、误会、笑点、必要理解或节奏之一，动作分句则必须推进触发、路径、交互、结果或承接。零边际内容由编剧决定合并、迁移或删除；缺的是人物动机、知识、动作资格或场面因果时返回原负责人，语言模式不得代写。

若要求修整份剧本，编剧还必须过语言模式的整稿覆盖门：对实际出现的方头、动作、表演括注、人物台词、剧本注释和生产说明分别作出块级处理回执。不能只改台词就宣布整稿完成，也不能把“保留原样”当成“没有审过”。

## 故事因果

### 观众等待

先用一句普通话回答：观众为什么愿意继续看？

好的等待不是“接下来会发生什么”的空悬念，而是一个尚未解决的具体状态：拿不到的东西、说不出口的话、过不去的门、不能撤回的结果、尚未回应的请求、正在逼近的危险或仍未兑现的承诺。

每个关键节拍记录：

```text
观众已经知道什么：
观众暂时相信什么：
观众正在等什么：
人物此刻想让谁做什么：
这一节拍改变了什么状态：
下一场压力从哪里来：
```

作者知道答案，不等于观众已经知道。剧本按观众的发现顺序安排信息，角色只能根据自己掌握的事实行动和说话。

钩子不是故意少讲，而是让观众凭足够证据开始预测一个尚未完成的结果。重要开场和关键节拍执行观众预期契约（期待契约）：

```text
可见证据 → 暂时判断 → 可预见压力 → 未揭变量 → 部分兑现
人物正在采取的行动：
后续处理：完成 / 扩大 / 推翻 / 重新解释。
```

开场先确定一个主要注意入口：人物、规则概念或眼前危机。其他信息只能从属，不同时争夺观众第一判断。使用强钩子、伏笔或反转时建立承诺—兑现账本，记录开场由哪个动作、物件、台词、声音或空间提出问题，中段怎样改变意义，结尾怎样兑现或重新解释。开放式和低烈度作品不机械闭环，但必须留下真实的关系或情绪余波。

悬念、调查、误解、关系秘密、倒计时、产品问题或知识解答承担观看牵引时，编剧还要形成`观众问题—答案交接`，供分镜和视频负责人分配声画节奏。按节拍记录当前问题怎样被`建立 / 加压 / 延迟 / 部分回答 / 回答 / 改写`，以及哪项可见或可听证据允许观众更新判断。延迟只能隐藏尚未到期的原因、身份、选择或结果，不能删掉理解当下行动所需的事实；新问题必须由旧问题的答案或后果长出来，不能靠无关异常续命。开放式作品可以不回答事实，但要交代主要关系或情绪运动在哪里完成。

教学、知识解释或演示是观众公开承诺时，知识线是不可补偿的主任务：观众必须知道这期在学什么、正在看哪项证据、本拍新记住什么。喜剧和人物关系负责让它好看、好记，不能反复把知识本身改写成人物需要争输赢的论点。开场可以直接建立学习任务；冲突发生后，再让人物在追逃、示范或后果中继续交答案。

### 人物选择

重要人物至少建立：

```text
表层目标：眼前想得到什么。
深层需要：真正缺的是什么。
错误信念：他为什么一直用错误办法。
恐惧与代价：什么让他不愿改变。
可见策略：他通常怎样试探、逃避、压制、保护或争取。
阈值选择：什么事件逼他不能再照旧。
选择结果：他做了什么，失去或承担了什么。
```

人物性格要由不同处境下反复出现、但会随压力变化的选择证明。一个口头禅、一个表情或一次换装不能代替人物。

### 动机、行动与物件

人物每个承重动作都要回答：他当下想改变谁或什么，为什么选择这个动作和这件物品，动作带来什么即时结果。台词与动作可以同向，也可以因为两难、伪装、犹豫或失控而表面相反；但相反必须由前后目的、精确触发和关系后果共同证明。没有这条因果却让人物说一套做一套，不是潜台词，是剧本错误。

关键物件按控制权写进场次：它起初在谁手里、谁把它放到谁面前、谁能拿走、谁越过阻拦重新取得、最后停在哪里。物件一旦改变人物选择、身体代价或关系权力，就不能只写成场景名词；下游必须能从剧本知道它的叙事职责和动作结果。普通陈设仍留给资产与分镜，不把剧本写成物品清单。

### 局部样例也必须闭合微场次

语气样例、开场试写、局部对白和单个节拍可以省略与当前关系无关的背景和制作细节，不能省略使当前关系成立的因果。交付前至少能从正文看出：谁拥有或操控关键物件；谁先做什么；哪项可见或可听证据触发另一人开口或打断；被打断的话具体尚未完成什么信息或行动；说完后控制权、距离、信息或下一步发生什么变化。

“我还没说完”“你又来”“等一下”等依赖前文的句子，只有观众能准确追回它所指的未完成内容时才能保留；追回不了就补足前一动作或话头，或改成在现场能独立成立的具体反应。样例不是提纲：若删去动作主体、道具位置或开口触发后会出现两个合理但冲突的解释，就继续写到只剩一个主要因果。

### 教学喜剧的对白场景合同

两个或多个人物要一边教、一边斗嘴或动作时，写正文前先形成以下中间结果：

```text
本拍观众新记住的知识：
开口前观众已看见或听见的事实：
人物 A 当下想让对方怎样：
人物 B 当下想保住或破坏什么：
本拍谁负责按普通人逻辑承接现实：
喜剧偏离由哪个可见事实、关系特权或残留后果触发：
这一拍让下一拍不得不发生什么：
本段唯一主喜剧引擎：
本段禁止补写的作者结论或机关句：
```

知识句负责让观众听懂，关系句负责试探、嘲讽、拆台或护短，桥接句负责让下一动作只能从当前后果长出来。一句可以兼任，但不要每句都同时交知识、抖机灵、触发打斗和总结主题。

同一拨冲突已经发动后，后续节拍可以由追逃、脱身、报答案、被听不见、故意抓字眼或前一次后果继续推进。这里禁止的是“为了展示手法而给每个知识点机械排一个机关”，不是禁止已经成立的人物反复用语言占便宜。若熟人关系的核心乐趣就是一方明明听懂、仍故意曲解对方给自己找动手理由，可以在几个关键升级点形成变奏式回声；每次必须先让观众听懂知识原义，再由不同现场事实触发，并兑现为不同动作和后果。同一拍默认一人负责普通现实，另一人负责偏离；除非一个可见事件完成翻转，不让双方连续说同样工整的俏皮话。

已确认的语言机关不能只在一句台词里露面。凡人物故意换义并借此发动动作，先形成`语言机关兑现合同`，锁定已确认原词、人物故意换义、当场台词、下一动作、动作结果和跨镜头保留项；镜头若在台词后切开，下一镜仍要兑现同一个词语机关，下一镜不得退回普通招式名、泛化动作或同义改写。

### 场次压力

每场戏都要完成一次状态变化：

```text
进入：人物带着什么目标和前一场余势进入。
施压：谁或什么阻止他，压力怎样升级。
选择：人物采取什么行动，不采取什么行动。
结果：关系、信息、道具、空间或身体发生什么变化。
牵引：哪个未解决状态形成下一场压力。
```

场次可以外部安静，但内部不能停止变化。文艺、观察和氛围作品可以靠等待、距离、误解和表演推进，不为套公式强造争吵、反转或爆炸。

### 文戏与武戏

文戏的动作单位是关系变化。台词要有目的并造成后果：试探、求救、保护、拒绝、压制、邀请、切断、告别或挽留。高潮台词不替作者总结主题；没有说完的话由表情、动作、物件、空间和另一个人的反应承接。

武戏的动作单位是力量关系变化。剧本至少交代力量从哪里来、向哪里去、谁被迫选择、接触造成什么结果、余势怎样进入下一动作。凡追逐、打斗、变身、破坏、救援、机甲或超常位移承重，先完成`动作因果交接合同`：世界能力基线、起始条件、战术目的、发力来源、能力触发、运动路径、环境交互、接触点、受力结果和镜尾把手。人物若能追上、闪现、击飞或撞穿，必须先用速度差、支点、蓄力、装备、术法、材料弱点或前一招余势取得这个结果；不能只写目标忽然出现在攻击范围内。剧本不替分镜写焦段和机位，但不能把“激烈打斗、翻身下马、大楼爆炸”当作完整因果。

动作合同按完整动作单元闭合，不要求每个简单动作句机械填十个字段。一个眼神、坐下或普通走路可以一句完成；一项超常攻击可以跨相邻镜号分别展示蓄势、位移、接触和结果，但每一镜都要继承上一镜状态，并只承担一个主要画面内容。分工原则是：`剧本锁因果，提示词扩颗粒`。剧本锁定为什么发生、怎样发生和发生后改变什么；视频提示词只能深化速度、相位、碎片尺度、烟尘层次、材质响应、光影传播和模型控制，不能第一次补造人物获得结果的资格。

### 语言与材料

先找关系，再炼句子。关键台词、片名、钩子、主物象和结尾不能直接采用模型第一反应。

人物声音不先由口头禅、方言或句式决定，而由他怎样看见、解释和应对世界决定。编剧负责的是`写作声音`：人物优先感知什么、怎样解释、想用语言改变谁、回避什么，以及说完会怎样行动；它决定台词 / OS / VO 的内容与语言策略，不决定演员的生理音区、音色，也不逐镜导演最终呼吸、口型、FACS强度和模型参数。但这条边界不允许编剧把情绪缩成一个形容词交给下游补猜：承重节拍必须先锁定情绪阶段、关系目的、精确触发、可见泄露、台词策略、句后行动与终点和禁止提前反应。重要人物写台词、OS或VO前建立人物声音合同：

```text
他优先注意什么：
哪些职业、生活或身体经验支持这种注意：
他会怎样解释证据：
他想让谁做什么：
他最不愿直接说出什么：
压力下会泄露的价值判断：
未说出的普通愿望：
这段话之后的当场行动和可见后果：
权威人物资产或语言样本来源：
本关系状态中已确认的 3–8 句原话：
原话共同显示的句长、直接程度、攻防方式与留白：
```

人物声音合同回答“这个人为什么这样说”，`情绪交接合同`回答“他在这一拍怎样从一个状态走到另一个状态”。正式剧本的每句有声台词都必须用括号标出当下情绪、关系动作和可听语气；普通信息句也必须标注，但可以简短，承重转折才展开完整情绪合同。声源位置不等于表演状态，`O.S. / V.O. / 远处`后仍要继续写人物怎样说。详细格式见`references/04_口述台词与方言.md`。剧本负责锁定因果和可表演证据，`laohu-audio-design`与`laohu-video-prompt`只能深化声音、面部、身体和时间相位，不能第一次发明人物为什么变、何时变。

已有长期人物资产时，必须读取权威来源，不能只携带“温柔、调皮、小恶魔”等抽象性格标签就开始写。标签只能约束方向，已确认的真实原话才能校准这个人的句子长度、直接程度、调侃对象和什么地方不解释。人物切换关系状态时，只调用对应关系的样本，不把对外礼貌腔移植到私下斗嘴，也不把私下攻击性扩展给陌生人。

正式交接时把已经定稿、下游不得改写的台词 / OS / VO 明确标为`冻结台词`，并交给`laohu-audio-design`编译自然语言音色描述、当场演法和可生成音频任务。音频设计可以为稳定发音而建立可读规整文本，但不能改变原句语义、人物策略和关系后果。

口头禅、方言词和金句都不能单独证明人物。强表达至少要暴露一项只属于此人的感知、判断、回避、愿望或行动策略，并回到`感知证据 → 人物解释 → 当场行动 → 可见后果`。详细方法只在人物声音、台词、OS、VO、方言或文学样章承重时读取`references/04_口述台词与方言.md`。

```text
写出第一反应
→ 把它当作平均值候选
→ 从人物立场、关系命名、动作证据、声音节奏和留白生成不同方向
→ 淘汰换到同题材另一篇仍成立的句子
→ 真人朗读
→ 只保留这个人物在这个处境里会说、也说得出口的话
```

材料不以“私人小物件”自动取胜，也不以“宏大意象”自动高级。选择能承担当前关系和主题、又能进入公共经验的材料：它可以是一把钥匙，也可以是一座城；关键不是大小，而是它与人物、处境和结果之间有没有不可替代的关系。

## 剧本开发

### 任务分型

| 输入状态 | 本轮产物 |
|---|---|
| 只有灵感、社会现象、价值方向或开场画面 | 先做灵感解构与 3—5 个价值方向，再选故事种子 |
| 有人物和粗事件，但故事引擎不清 | 故事设计稿 |
| 故事已经成立 | 分场剧本或单场次剧本 |
| 已有剧本但效果不对 | 剧本医生诊断，先找最上游断点再改稿 |
| 有商业产品或服务目标 | 商业简报、卖点场景化与广告脚本 |
| 只有单个画面 / 15 秒任务 | 单场次、一个主动作或一个信息变化的短剧本 |

故事设计稿不是小说。它先建立：观众等待、人物目标、阻力、代价、首尾画面、关键转折、场景链、情绪曲线、资产预判和生成风险。只有老胡明确需要文学样章、旁白口吻或 IP 气质时才写小说式文本。

### 素材查询合同

正式故事设计、分场、单场次或重写开始前，先调用 `laohu-story-material`，提交：

```text
【素材查询合同】
当前剧本缺口：
叙事范围：story / sequence / scene / beat / texture。
素材职责：主故事 / 冲突 / 人物行为 / 台词 / 场景质感 / 物件 / 记忆点 / 价值信息。
当前人物关系与选择压力：
希望加强的人性机制或情绪：
必须保护的故事事实：
候选需要在哪些因果方向上不同：
怎样算已经充分：
禁止套路与不适配：
```

先做严格匹配；不足时每轮只放宽表面条件中的一个字段并记录变化；再做跨领域类比。仍不足时由素材负责人形成内部缺口报告，是否搜索网络和采用外部案例不能由编剧暗自决定。同一任务中，人物、事实、素材职责和剧本缺口都未改变时可以复用已有素材交接包；任一条件改变或进入新任务时重新查询。

候选是否足够，以它们能否解决当前剧本缺口为准，不按固定数量判断。只采用一条不是不足，原创方案更准确时允许零采用。未经确认的 `external_candidate / not_approved` 不得进入剧本；即使获准使用，也只能迁移机制和证据结构，不能复制真实身份、独特原话或受保护表达。

长篇不能靠一次检索塞入更多候选。先建立 `story` 级承重会话，再按段落、场景和局部动作分别建立 sequence、scene、beat 会话，需要生活质感时才补 texture；电影可以沿着场景链逐段检索和编写，但每段仍须继承全片的人物目标、已发生后果与未来回收。检索页只是本轮可读窗口，不是全片素材配额；一页不足就续页，一个场景结束也不等于丢掉全片状态。

入围原子按 `承重 / 支撑 / 纹理` 标职责：承重原子改变人物选择或主要因果，支撑原子让压力、证据或回收成立，纹理原子增加真实感但不能抢走主动作。短片的信息密度看单位时长内发生了多少次有效状态变化——观众理解、人物关系、行动条件或风险真正改变——而不是看写进多少原子。若新增候选只重复已覆盖机制、不能带来新的因果方向或可见证据，就说明边际增益已经消失，应停止续页或改写查询合同。

### 故事构件查询合同

素材原子提供生活证据，故事构件提供状态变化方式。素材交接完成后，如果故事动力、压力增长、信息变化、不可逆代价、阈值选择、首尾回收或场景融合仍不清，再调用本 Skill 的构件库；故事因果已经成立、只改台词或整理格式时不读取全库。

```text
【故事构件查询合同】
当前故事缺口：人物理由 / 约束 / 加压 / 信息 / 代价 / 选择 / 回收 / 场景融合。
必须保护的人物、事实和创作者命题：
希望产生差异的因果位置：
构件必须具备的前置与输出状态：
不适配与禁止组合：
怎样算已经充分：
```

使用 `scripts/story_component_library.py`，按 `stats → search → get` 渐进加载 `references/07_故事构件库.jsonl`。优先按戏剧职责与状态变化检索，不按题材外壳机械匹配；候选不适配、构件库为空或原创方案更准确时，允许零采用并继续原创，不得自动网络搜索。

构件进入候选后，按 `前置条件 → 人物行动 → 状态变化 → 观众更新 → 下一压力` 连接并执行因果验收。重要故事至少比较三个因果真正不同的组合；只替换职业、地点和道具不算不同。每个胜出构件都必须说明人物为什么会采用它、它怎样改变下一状态和观众等待；多个概念并排却互不产生后果时退回重组。

场景融合优先让同一承重行动、物件、空间或声音同时改变关系、信息和下一压力，但每场只保留一个主要状态结果。多个构件争夺主结果时拆场或淘汰，不靠解释把拥挤伪装成丰富。

### 开发顺序

```text
确认命题、受众、平台、体量与观看承诺
→ 渐进检索素材，取得人性与生活证据
→ 建立人物目标、错误方法、代价与阈值选择
→ 判断当前缺少哪一种状态变化
→ 按需渐进检索故事构件
→ 产生因果不同的候选并推演二阶后果
→ 选择主因果链，安排观众发现顺序
→ 场景融合、情绪曲线与承诺兑现
→ 标出相邻单元及状态
→ 逐镜完成镜头原子与世界—摄影机—画面空间闭合
→ 写正式剧本和生产证据
→ 反向审稿并形成下游交接
```

### 剧本巅峰门

可拍、可生成、因果无误只是底线。正式剧本还要证明它不是同题材的平均答案：

```text
主胜负手：观众最终会因哪一个人物选择、关系变化、认知翻转或情绪余波记住它。
候选竞争：关键冲突、阈值选择、高潮和结尾是否比较过至少三个因果真正不同的方案。
不可替代：把人物名、行业名和表面设定换掉后，核心场面是否仍像公共模板。
兑现强度：开头许下的等待，是否由后续更强的选择、代价和结果偿还。
顶尖校准：同类成熟作品最强处靠什么成立，本稿学到的是机制还是只借了表面。
下游潜力：资产、镜头、表演和声音是否得到足以继续升级的关系，而不是只得到完整情节。
```

人物选择没有更痛也更准确的替代、高潮没有比铺垫更高一层、结尾只把事情讲完却没有留下关系余波时，剧本不得因为格式完整而交接。极致不是强行反转、放大苦难或句句金句；真正的强度来自所有场次把压力推向同一个无法逃避的选择。

### 相邻单元

两个节拍、场次或 批次 共享人物、动作、道具、空间、时间、声音或情绪余势时，逐对写清：

```text
A 已完成结果：
A 结束状态：
B 开始状态：
必须不变 / 允许变化：
B 第一项新动作或声音：
下一相位：B 从哪里继续，而不是重演 A。
下一场压力：哪个未解决问题把 B 推出来。
```

直接连续时 `A 结束状态 = B 开始状态`。剧本同时锁定世界事实、人物状态和观众在每个镜号中看见的基础关系；下游可以在不改写这些事实的前提下深化焦点、组合运镜、剪辑方式和生成实现。

### 商业剧本

商业内容先建立：

```text
转化目标：
目标人群与使用时刻：
原有方案的不满或购买阻力：
一句核心承诺：
支撑卖点与证据：
品牌与行动出口：
事实和声称边界：
```

每个卖点写成 `用户处境 → 问题触发 → 产品介入 → 身体 / 物体 / 环境结果 → 用户利益`。真实参数与疗效没有证据时不编造；画面不能证明的卖点不靠一句广告词硬说。

### 输出合同

根据任务按需交付，不把所有字段机械填满：

```text
【素材调用回执】
检索条件与放宽记录：

保留机制 / 改变人物处境 / 不可复制：

对观众理解、期待、关系感受或情绪的可观察变化：

【记忆点账本】
位置 / atom ID / 主职责 / 观众状态变化 / 与主线因果 / 相邻竞争 / 是否需要呼吸。

【当前故事缺口】

【构件调用回执】
检索条件 / 入围 component IDs / 采用或不采用 / 状态变化职责 / 适用边界：

【组合候选】
候选因果链 / 人物必要性 / 观众等待 / 主要代价 / 淘汰理由：

【观众问题—答案交接】（悬念、揭示、误解或知识解答承重时填写）
节拍 / 当前问题 / 已给证据 / 暂时判断 / 本拍处理：建立、加压、延迟、部分回答、回答或改写 / 本拍答案边界 / 下一问题怎样由当前结果产生：

【人物与因果】
人物目标 / 阻力 / 代价 / 阈值选择：
观众信息顺序：
关键场次链：进入压力 → 选择 → 结果 → 下一场压力

【人物声音合同】
优先注意 / 经验依据 / 证据解释 / 说话目的 / 回避内容 / 价值泄露 / 普通愿望 / 话后行动与后果：
冻结台词 / OS / VO：

【交给人物设计】
已确认的年龄、健康、劳动 / 训练、生活条件与文化身份：
反复出现的行为策略、身体代价与他人反应：
观众第一印象需要正确、误导或部分成立：
视觉不得提前泄露的真实人格与反转：
人物设计可提出的选角与身体化空间：

【交给场景与布景设计】
谁拥有、借用、控制或被排除在这个空间之外：

必须发生的动作与关系距离变化：
人物分别知道、看见和误解什么：
观众第一次看见什么、后来重新理解什么、不得提前泄露什么：
场次结束留下的空间、陈设和关键道具状态：

【正式剧本】
剧本先写 `【剧本说明】 / 【作品信息】 / 【故事说明】`，说清用途、观众、体量、一句话故事、观众等待、人物关系、主情绪运动和必须继承的制作事实。
剧本正文按集数、场号和场内镜号组织：场次写内外、具体地点、时间、人物和开场状态；每个镜号方头按`编号｜景别｜运镜｜机位 / 视轴｜构图｜参考时长`给出可快速预读的摄影初稿，再归属本镜的可见可听行动、台词 / O.S. / V.O.、承重声音、屏幕文字和必要特效。示例镜头：`【E01-S01-C01｜中景｜运镜：固定镜头｜机位：圆台南侧，朝北看向双人关系轴｜构图：Luna左侧、老胡右侧｜约4秒】`。
`E` 是 Episode，表示集数；`S` 是 Scene，表示当前集内的场次；`C` 是 Camera Shot，表示当前场次内的镜头。进入新场后从 `C01` 重新编号；标题不再额外添加全片连续的“镜1、镜2”，避免两套定位信息重复。
所有观众会看到或听到的正文必须归入一个镜号；镜号之前不得漂浮 `△` 动作。景别是镜头属性，不是编号；集数、场号和镜号各自承担不同层级，不得混用。

镜头方头中的景别、基础运镜、机位 / 视轴和构图只是剧本阶段的摄影初稿，但必须让读者在进入正文前知道“摄影机从哪里朝哪里看、开镜能看见谁”。`机位 / 视轴`写摄影机相对人物或固定锚点的位置与朝向；`构图`写该机位造成的画面投影、前后景和必要的起止变化，两者不得合并成一个含糊的“侧面拍摄”。正文继续使用偏小说性的可见结果语言，写人物、光线、空间、动作、表演和状态变化，不重复方头已经锁定的静态机位与开镜构图，也不重复编译摄影机路径，不编译焦段、精确速度和完整摄影机执行；详细执行由 `laohu-video-prompt` 结合资产、模型与生成边界深化。这个分权不允许正文省略世界位置、身体朝向、视线、距离、入画退出、动作来源和镜尾状态。复杂多人镜头先在内部完成`镜头继承合同`，再把摄影起点压进方头、把连续可见事件留在正文。

双人或多人动作段落必须建立人物指代锚点：每个新动作段第一次出现人物时先写具体名称；同一人物连续行动时才可使用“她／他”；叙述主体切换、段落重开、遮挡关系变化或第三人加入时，重新写具体名称。镜号、标题、正文和生产账本各自承担定位、初稿镜头属性、可见事件和连续性证据，不靠同义重复制造虚假信息密度。

误听、曲解和语言错位只在人物当下有关系动机这样接话时使用。人物不必真的相信第二种解释；熟人间为了逗弄、报复、调情、嘴硬或给动作找借口而“明知原义、故意换义”，本身就是可成立的人物策略。先找目标不对称、可见窘境、关系特权和前拍残留后果，再从其中长出语言机关。使用谐音时仍必须通过现场发音与句法门；不成立时可改用双重语义、对象偷换、字面执行、关系反应或普通话，也可以不写笑点。它们不是逐项配额，但也不能因一次过量失败就被一刀切删除；在关系型喜剧中允许少量、递进、不同后果的变奏复现。

普通叙事作品的文字分镜并入正式剧本；不再让下游先重写一份普通分镜表。每镜通过实际出画 / 画外、世界位置、摄影机观看侧 / 视轴、画面左中右与前中后景、身体朝向、视线对象、遮挡、关系距离、入画退出和结束变化让读者理解画面；世界位置、摄影机和画面投影不能互相矛盾。正式剧本的每句有声台词都必须用括号留下表演索引，至少从`声源 / 情绪阶段 / 关系目的 / 可听语气`中写出足以区分本句说法的信息；普通信息句也必须标注，但可保持简短。声源位置不等于表演状态，不得只写`O.S. / V.O. / 远处`。情绪会改变台词含义或行动时，再由同镜或紧邻镜补齐触发、身体 / 声音表现、对手反应和句后状态。
```

记忆点不设置“每几秒一个”的固定规则。短内容可以提高有效变化密度，长内容可以延长铺垫和回收；验收看每个记忆点是否改变观众理解、期待、关系感受或情绪，主记忆点是否高于支撑细节，相邻亮点是否互相竞争，以及留白是否在为后续兑现蓄力。素材多不等于信息量高，只有进入主线因果并改变观看状态的细节才保留。

正式结果写入当前作品的 `01_世界观故事/文本/` 或 `02_剧本/文本/`，默认覆盖当前阶段主文件，不自动制造版本文件。

### 验收

- 能否一句话说清观众在等什么。
- 每个关键节点是否由人物选择或行动推动，而不是作者解释、巧合或主题要求。
- 人物的即时目的、台词、动作和关键物件是否共享一条因果；表面矛盾是否由两难、伪装、犹豫或失控证明，而非无意打架。
- 每场是否改变关系、信息、道具、空间、身体或下一步可能性。
- 人物是否只说他知道、想说、能说出口的话。
- 台词是否有对象和后果，关键句是否通过可替换性与朗读检验。
- 人物声音是否先改变他注意和解释证据的方式；口头禅、方言、比喻和金句是否只在替作者炫技。
- OS / VO是否与画面形成补充 / 对位 / 反差，而不同义复述画面；删掉漂亮独白后，人物选择和场次状态是否仍不变。
- 抽象主题是否已有可拍证据，材料是否真的承担关系，而不是为了具体而具体。
- 文戏是否有关系压力，武戏是否有力量来源、路径、接触和结果。
- 相邻单元是否状态相等，B 是否从下一相位开始。
- 已确认事实是否完整保留，新增创意是否标明。
- 下游能否直接识别该稳定什么、该自由设计什么，不需要重新猜故事。
- 构件是否真正改变状态与观众等待，而不是只留下一个结构名称；构件库无合适候选时是否允许零采用并继续原创。
- 场景融合是否依靠同一承重行动和一个主要结果，低烈度作品是否没有被连续反转强行堆叠。
- 强钩子是否有可见证据、暂时判断、可预见压力、未揭变量与后续兑现，而不是隐藏当下危险。
- 正式剧本正文与生产证据账本是否分权；声音是否有声源、触发和作用；文字分镜是否已进入正式剧本，下游是否只深化执行而未重猜镜头。
- 每个镜号是否通过镜头原子检查：一次不中断的摄影机观看、一个主要画面内容、一项主变化和一条连续可达的观看路径；新人物的独立反应、插入物、主观视角、反打、局部转全景结果、硬切或新的触发—变化—结果是否已经新建镜号。
- 方头是否完整给出`编号｜景别｜运镜｜机位 / 视轴｜构图｜参考时长`；读者能否在读正文前判断摄影机从哪里朝哪里看、谁在前后左右，机位与构图是否各自承担原因和结果而非同义重复。
- 景别是否守住证据边界；近景有没有突然承担远处空间或完整身体结果，固定镜头有没有在未声明入画路径、既有后景人物或构图变化时凭空多出人物与信息。
- 每镜是否让`世界位置 → 摄影机观看侧 / 视轴 → 画面左中右与前中后景`同时成立，并写清实际出画 / 画外、身体朝向、视线、遮挡、距离、入画退出和镜尾变化；换机位是否只改变画面投影而没有改写世界位置。
- 是否把人物运动和摄影机运动分开：摄影机固定时人物从哪个画框边缘沿什么世界路径进入；摄影机运动时起点、连续方向和停点是否足以证明观看位置可达，详细速度、焦点和光学实现仍留给视频提示词。
- 每场是否只用 `E-S-C` 唯一定位，`C` 是否从新场的 `C01` 重新开始，并删除重复的全片连续“镜X”。
- 正文是否保持偏小说性的可见结果语言，把详细摄影机执行、模型参数和三段式留给视频提示词，同时没有漏掉下游不可补猜的人物、空间、动作、声画来源和镜尾状态。
- 多人动作段是否先以具体名称建立人物指代锚点，主体切换后是否重新点名；谐音是否真的满足现场发音与句法，不成立时是否改用更准确的语言或关系手法。
- 教学喜剧、熟人斗嘴或人物声音承重时，是否先做`纯对白盲听`检查开口理由和语言真实性，再做`现场回放`检查台词是否从可见事实触发并改变下一动作。
- 是否通过剧本巅峰门：主胜负手明确，关键候选经过比较，开头承诺被更高强度地兑现，且没有已知但未处理的明显更优方案。
