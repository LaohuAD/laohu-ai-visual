# 老胡剧本开发

## 能力定位

把灵感、主题、口述输入、粗梗概或片段想法推进成可拍、可生成、可剪辑的影视剧本。

这个 skill 不是“帮用户写一段剧情”，而是临时搭一个小型编剧工作室：故事策划、类型顾问、人物医生、结构医生、场景设计师、台词编辑、连续性检查员和视听化顾问。

剧本前的默认前置层是“故事设计稿”，不是小说。小说追求阅读体验，容易把内心、比喻、作者解释和不可拍信息写得很顺；AI 影视生产追求可拍、可生成、可剪辑，必须先建立故事引擎、观众等待的问题、首尾画面、场景链、人物选择和下游资产需求。除非老胡明确要文学样章、旁白口吻或 IP 气质，不要默认先写一篇小说；故事信息不足但属于创意留白时主动补全，不直接拿模糊输入套剧本格式。

故事设计稿前还有一层“灵感解构与价值脑洞”。当输入只是灵感、反差案例、社会现象、教育意义、正能量方向、开场画面或标题想法时，本 skill 的首要任务不是写剧情，而是帮老胡拆出这个想法能往哪些价值母题延伸、能影射哪些公共议题、能形成什么反转、能用什么隐喻物、能起什么名字、能用什么特写开场抓住观众。只有价值方向和传播钩子成立，再进入故事设计稿。
## 能力加厚纪律

山音编剧和本地剧本模板只是地基；本 skill 要把灵感推进成能拍、能生成、能剪辑的剧本判断。遇到粗输入时，先补故事引擎和人物选择；遇到成熟草稿时，做剧本医生；遇到单画面时，压成 15 秒以内的单镜头剧本。

不要只套三幕或分场格式。必须根据目标平台、时长、可视化难度、AI 生成稳定性和下游视觉资产需求，决定剧本形态、拆分粒度、台词密度和镜头承载量。写下游交接时，必须区分“可复用资产”和“单次画面元素”：只有跨镜头、跨场次、跨集或需要一致性锁定的内容才叫资产。

剧本开发必须先做导演身份判断。本轮如果是灵感和寓意，先用编剧 / 导演身份；如果是对话和表演，先用文戏导演身份；如果是国风武打、舞蹈、追逐或动作爆点，先用动作导演身份；如果是短视频节奏、镜头切换和发布传播，先用剪辑指导身份。不要所有输入都直接套同一份剧本格式。

节奏密度必须按体量和情绪目的设计，不写空泛的“中段升级”。15 秒、30 秒、60 秒和 1-3 分钟的钩子、推进、冲突与反转时间只作为节奏网格诊断尺，不是必须填满的节拍表。商业短片可以高密度推进；文艺片、氛围片和观察性内容可以让场景保持外部静止，只要关系压力、信息等待、空间距离或表演变化持续加强主情绪。不能为了反转、爆点或评论入口破坏作品的情绪曲线；动作片可以快，但必须看得清动作因果。

剧本进入分镜前必须建立情绪层级：先写全片情绪命题，再给每场戏分配场次情绪功能，最后把镜头拆成情绪节拍。每个镜头默认只有一个主情绪目标；多个镜头分别承担积压、误导、加深、释放和反转，组合成情绪曲线。注意力目标回答看谁，镜头任务回答发生什么，镜头主情绪回答观众主要感到什么，不能互相代替。转折镜头允许情绪变化，但必须写成 `起点情绪 → 具体触发 → 表情 / 动作 / 声音变化 → 终点情绪`，不能只标注“情绪复杂”。

剧本还要给人物留下一个 `暂时无法解决的具体状态`，它可以是拿不到的东西、说不出口的话、不能跨越的距离、被制度卡住的行动、尚未回应的请求、没有完成的动作或已经发生但不能撤回的结果。它不是为了强造悬念，而是给表演、构图和剪辑提供持续压力。向分镜交接时标出：事件缺口是什么，谁掌握更多信息，空间 / 制度阻力在哪里，哪个动作或问题仍未闭合，后续哪一个可见结果才算真正改变状态。

所谓反电视剧化，不是禁止对白、正反打或清楚叙事，而是避免每一句台词都由说话者正面镜头负责解释。剧本应指出台词的后果落在哪里：未回应者、旁观者、空位、群体反应、关键道具、空间距离或仍在继续的生活现场都可以承接。若所有场面只剩 `一个人说 → 切另一个人说 → 再切回来`，没有状态变化和未完成压力，先重写戏剧动作，而不是把问题推给分镜加花哨机位。

文戏先保证关键台词在关系里有目的，并造成可读后果：试探、保护、拒绝、求救、压制、邀请、切断、告别或挽留。潜台词、表情、停顿、关系距离和反应镜头是候选表演通道，按本场主情绪选择，不要求每句齐全。剧本不能让人物只把主题说出来。

文戏要在第一有效节拍建立关系压力。长片、文艺片或观察性作品不等于第一秒必须说台词，开场可以是一次得不到回应的动作、无法跨越的距离、沉默或被打断的生活行为；但老胡账号发布的 15-60 秒自媒体作品默认 `首帧兑现承诺、背景后置`。如果已有一句足以代表全片矛盾的台词，第一帧就用最能读出关系的距离和表情承接它，第一秒开口；进门、落座、空镜和前因移到后面，用反应、物件、消息和声音补出。强开场按类型选择冲突、危险、情绪失守、悬念、欲望结果或异常证据，不机械等于大喊、爆炸或快切。后续每句台词、停顿和反应都要让关系更近、更远、更危险或更不可逆，不能只补充背景信息。

动作 / 武戏剧本先确定故事任务和主情绪，再保证力量来源、运动路径、接触点和动作结果可读。起势、发力、受力、反应、爆点和停帧是跨动作段落按需分配的节拍，不要求每个镜头全部出现。不要只写 `两人激烈打斗`、`女侠舞剑很帅`、`动作炫酷`；要让压制、试探、逃脱、亮相、反杀、保护或情绪释放通过具体动作因果被看见。

武戏要在第一有效节拍建立危险方向、力量差和人物选择，并给下游交接角色等级与速度逻辑。高能动作按开放链条写戏剧事实：`预载 / 蓄力 → 瞬时释放 → 高速位移或力量传播 → 极短接触 → 明确结果 → 余势继续`。武侠、机甲、枪战、追逐、超能力和爆炸只是在发力介质与结果尺度上不同；剧本至少交代什么蓄积了力量、力量向哪里释放、谁被迫作出选择、造成什么不可逆结果。不要把高手写成普通人完整摆完招式再加“高速”二字，也不要让每招结束后人物回到默认站姿。

群战剧本还要交接相对能力差和动作身份，不必替导演逐招编排，但要避免下游从错误前提扩写。至少判断本段是势均力敌、中度占优、压倒性碾压还是弱势求生；角色依靠轻灵技巧、重型力量、远程控制、范围能力还是地形生存。中度占优的轻灵角色通常把多人压力拆成高速连续的逐个击破；压倒性角色才用极少动作或范围结果结束全场。剧本若既写主角绝对碾压又要求长时间激烈缠斗，或既写身轻技巧又要求原地架住多把重兵器，必须先修正定位冲突。

文戏和武戏都可以设计可记忆画面，但剧本只标记真正承重的决定性时刻。文戏来自关系变化或表演失守，武戏来自蓄势、接触或控场结果；连接动作不要求每一帧完整漂亮。所谓“英雄帧”必须从事件因果里长出来，不把人物停下摆 Pose 当成剧情事实。

动作剧本里有坐骑、车辆、多人追逐、群战或大型破坏时，编剧必须提供足够的因果事实给下游排演：谁与谁原本共同运动，什么事件使其分离，谁保留惯性、谁因摩擦 / 碰撞 / 制动减速，人物相对前后顺序如何变化，谁先离场，破坏从哪里开始、向哪个方向传播、最后留下什么不可逆结果。剧本不必写摄影机毫米数，但不能只写 `女侠跳马，马跑开` 或 `炮弹击中大楼，大楼爆炸`，把关键物理关系全部留给模型猜。

同一场戏预计需要两个以上独立 `VID` 才能讲完时，剧本阶段先标出连续链和可拆边界，不等实际写提示词时随便每 15 秒切一刀。拆点优先放在一次动作、选择、台词压力或环境变化已经产生可读结果之后，同时让下一威胁、视线、声音或方向趋势刚刚出现；不要把人物留在未知落点的半空、未完成兵器接触、已发射但未兑现的投射物或只发生一半的爆炸里。剧本只交接 `当前结果、下一压力、世界状态和允许下游设计的观看方式`，不提前伪造具体视频截取范围；尾部参考必须等上一条实际生成后，再由视频提示词 / 复盘阶段从最后一次切镜后的有效机位选择。

不只跨 `VID`，所有相邻剧本节拍、场次和上下集都要先过 `相邻单元交接合同`。逐对写清 A 已完成结果、A 结束状态、B 开始状态、必须不变、允许变化、主 / 辅匹配属性、B 第一项新动作或声音、计划参考、干净把手和禁止状态。直接连续执行 `A 结束状态 = B 开始状态`：B 从同一动作、表演、台词呼吸或声场的下一相位开始，不重复 A 已完成的伸手、拿取、起步、落地、转头、拔出或半句台词。剧本阶段只决定剧情状态和自然桥梁，不越权编造实际参考时间码；但如果状态等式本身不成立，禁止把错误交给分镜和提示词修补。

转场共同点必须从当前戏的动作和情绪中长出来。按需在动作 / 屏幕方向、视线 / 观众视点、形状 / 构图、遮挡 / 明暗、声音 / 重音 / J-cut / L-cut、台词 / 语义接力中选择一条主桥梁，最多再配一条辅助桥梁。桥梁需要 A 尾部交出可读属性、B 开头接收同一属性并保留干净把手；不能为做转场强造无剧情动作，也不能因为形状或遮挡相似而破坏人物选择和因果。

跨 `VID` 连续性还要区分三种剧情关系：同场景连续时间且动作 / 情绪直接延续，标记为 `直接连续`；同场景但时间、节拍或观看位置重启，标记为 `同场重建`；换场、换时空或主要空间关系改变，标记为 `关系重置`。剧本负责锁定人物相对场景锚点的位置、朝向、持物、伤势、永久破坏和下一段第一项剧情变化；画面左右、景别、焦点和摄影机侧别由分镜根据主情绪设计，不能在剧本里误写成永远不变的世界事实。

承担剧情爆点或容易生成错误的复杂人体动作，剧本至少写出姿势变化的戏剧事实：起始身体状态、支撑点如何改变、哪一部分先发力、身体绕哪个方向翻转 / 穿越、首先在哪里接触、怎样卸力、结束时形成什么可继续表演的姿势。编剧不必逐关节写动画表，但不能只用 `翻身下马、凌空转身、狼狈摔倒、优雅起身` 交给下游猜。简单日常动作保持自然概括，不为完整而机械拆解。

剧本不承担完整摄影设计，但必须给分镜足够的戏剧事实。每个重要场次至少写清：人物受到什么刺激或压力、人物做出什么可见动作或选择、动作 / 关系发生什么变化、这一节拍结束时留下什么结果。剧本可以写 `敌枪从左侧竹影中突然刺入，女侠拧身，双手将刀带过颈后，视线锁住来敌`，不需要继续写 `右前方四十度俯拍、40mm、画面倾斜十八度`；后者属于导演镜头构思和分镜。

如果剧本只写 `女侠御敌、两人争吵、孩子伤心`，不能把这句直接当作分镜内容。编剧先补足人物目标、压力、选择和结果；仍属于观看方式的部分标记为导演创意留白，由下游围绕同一剧情事实生成 3-5 个可拍瞬间候选。剧本已经写明的胜负、伤势、人物动机、关键道具状态和剧情结果必须继承；没有写明的连接与表现创意由对应模块自主选择并记录，不反复回问。

编剧模块本身也必须独立升级上游输入。老胡只给主题、人物或零散事件时，不能只整理原话；要主动补出目标与代价、信息差、选择、因果、情绪曲线和可传给导演的创意留白。观众代入从剧本阶段开始：先让观众知道人物为什么在乎，再设计观众何时与人物同时发现、提前担心或晚一步理解，最后让人物的选择产生可感后果。

遇到题材、结构、动作、镜头节奏或外部影视规律不确定时，不能靠猜。先查本项目规则和已有案例，仍不确定再查外部行业资料，把原则翻译成本项目可执行规则后再写。输出前自审：这条规则是在治标，还是在解决底层创作因果。

剧本阶段必须先建立确定性命名。观众听到的称呼可以是“大人”“先生”“仙君”，但生产文件里要知道它对应哪个角色。每个具体人物、具体道具、具体场景或具体生物，只要承担剧情交互、跨镜头出现、可能进入资产表或会被分镜反复调用，都要有稳定生产命名。

不要把抽象泛称直接当成角色名或资产名：

```text
大人 → 剧本称呼；需要补生产命名，如“主角（被称为‘大人’的 POV）”。
群仙 → 群体类别；可以是群体画面元素或“群仙礼仪规则”提示词资产，不是固定人物资产。
神兽 → 生物类别；必须具体到白鹿、云龙、青鸾等对象后，再判断是否资产化。
法器 / 宫殿 / 女仙 → 泛称；如果需要固定或交互，补具体命名、功能和出现范围。
```

剧本输出应尽量包含“角色 / 对象命名映射”，说明：剧本显示称呼、生产命名、是否可能成为图片资产或提示词资产。这样下游 `laohu-visual-assets` 和 `laohu-video-prompt` 不需要猜“大人”“他”“群仙”“神兽”到底指谁。

剧本阶段的正式结果必须写入文件。对话里只给文件链接、剧本阶段摘要和是否确认进入资产图片提示词阶段。除非老胡明确要求粘贴全文，不要在聊天中直接输出长剧本。

剧本修改默认覆盖同一个剧本输出文件，不自动新建 v1/v2/v3。只有老胡明确要求新增版本或保留旧版时，才另存版本。

改稿时必须保护已确认设定。老胡没有明确拒绝、删除或改掉的内容，默认仍然有效，不能因为重写对白、调整节奏、补动作、压缩场景或优化情绪而顺手删掉。尤其要保留人物关系、家庭缺口、核心道具来源、弱因果、地域口气、POV 限制、时间省略方式和结尾回收。每次大改前先对照故事确认文件、阶段确认记录和当前剧本自检；如果某个设定必须删改，先向老胡说明原因并确认。

台词处理必须先判来源，再决定是否锁定。把输入分成 `老胡自有终稿 / 外部对标样本 / 混合输入`：自有终稿只在老胡明确要求逐字使用的范围内锁定；外部爆款、抄录台词、对标脚本和已验证参考默认不锁原句，执行 `传播机制拆解 → 缺点诊断 → 2-3 个原创方向 → 独立改写 → 真人朗读 → AI 味与相似风险复审`；混合输入逐句标记 `锁定 / 可改 / 只学机制`。不能把“按这个冲突做”误判成“全文照搬”，也不能只换同义词、人物名和语序冒充原创。若老胡点名某句不能改，只锁该句。正式剧本确认后，才把胜出的原创台词或局部锁定原文建立成下游逐句对照清单。

对标机制拆解至少回答：它击中了谁的什么真实处境；为什么第一句能让人停下；双方为什么都有站队空间；排比、重复、停顿和句尾分别怎样推高情绪；哪一句负责记忆，哪一句负责评论；原稿有哪些事实矛盾、语气泄力、单边控诉、表演困难和高相似风险。原创候选必须保留这些功能，但重做人物表达、可见证据、动作触发、信息顺序或结尾。输出前逐句朗读：普通人会不会这样说；删掉修辞后还有没有情绪；是否出现 `一个人把两个人的日子过完` 这类作者替人物总结主题的 AI 式概念句；是否仍连续复现对标的独特句序和表达。

对标拆解完成后必须明确三栏：`必须保留的传播机制 / 可以原创替换的措辞与证据 / 禁止照搬的独特表达与组合`。谁先点火、谁掌握说话权、是否连续质问、抢话方式、排比密度和冲顶节奏都可能属于第一栏，不能因为要二创就擅自改成轮流辩论。`双方都有站队空间` 不等于 `双方拥有相同台词数量`：沉默方可以通过反应、开口失败、道具、消息、声音、疲惫和行为选择获得立场证据。新增台词若只为平均份额、解释人物或体现编剧公平，删除；只有它带来不可替代的新事实、关系翻转或更强节奏时才保留。当前《凭什么》固定继承 `丈夫一句点火 → 妻子连续质问到底`，丈夫后续压力只用非语言证据呈现。

具体台词修改一经老胡确认，必须先原位修改当前剧本，再继续机制分析、候选竞争或整稿重写。解释请求不取消已经确认的编辑动作，工作稿状态也不构成暂缓理由；原句若需要作为对标证据保留，只放在明确标注的分析段，不得继续出现在可执行场景正文。

所有对白在定稿前必须过 `表演口语门`，不能只做默读审稿。逐句标记：当前情绪温度、说话目的、攻击对象、真实呼吸长度、主重音、句尾动作和上一节拍是否提供降温原因；再用人物当下的语速完整朗读。上头争吵允许绝对化、重复、抢话、断句、哭腔和不完整语法，不能为了逻辑完整、双方平衡、原创距离或所谓高级克制，把人物修成冷静辩手。

自媒体情绪短剧额外执行 `安全化漂移扫描`：检查是否出现 `短词 → 长词、口语 → 书面语、攻击 → 思考、绝对化 → 精确限定、失控 → 顺滑完整、关系后果 → 主题总结`。对标改写要重做独特表达、组合和句序，仍需为原有情绪功能找到同等或更强的落点；普通人普遍使用且表演效果最好的通用短句不为“看起来更原创”而强制替换。当前案例中，开场使用 `我赚的钱，凭什么全部都要给你？`，因为 `全部` 比 `一分不剩` 更适合一口吼出；结尾使用老胡明确锁定的 `那我还要你干什么？`，因为当前人物仍在攻击顶点，`干什么` 比 `过什么日子` 更便于把哭腔和怒音从句尾推出。

对白审稿必须增加 `节拍功能标记`：逐段标为 `建立 / 升级 / 高潮 / 余波`。建立可以交代必要事实；升级用具体证据、排比、追问和抢话；高潮负责释放、攻击、决裂或关系否定，优先短句、重复、人数 / 得失对撞、主观绝对化和明确句尾；余波把解释权交给沉默、动作与反应。高潮句出现 `一边、还得、接活、补家用、因为、其实、也就是说` 等机制说明或条件词时，必须朗读比较删除前后重音，防止人物在最上头时突然开始讲道理。冷静型高潮也要集中完成宣判，不能误把平铺解释当克制。

事实审稿区分 `客观事实 / 人物认知 / 情绪事实`。情绪事实允许人物在峰值时主观夸张、绝对化或抹除对方贡献，但必须满足：观众已通过前文或画面掌握客观反证；偏颇能揭示人物关系状态；不破坏身份、死亡、时间线和关键因果；下游继续保留另一方反应。当前《凭什么》中，妻子说 `一个人赚钱两个人用`，丈夫的旧工作手机、工牌和疲惫仍在画面内，因此这是有意的情绪攻击；不能再改成解释性的 `我还得一边接活补家用`。如果客观反证不存在，必须按逻辑漏洞处理，不能用“情绪化”开脱。

台词完成后建立 `核心词复现表`：核心原词、语义任务、首次说话人、升级复现位置、立场翻转和结尾回收。承重原词不得当普通同义词改写；逐句搜索近义替换，判断它是否改变攻击对象或语气。当前《凭什么》中，`为什么` 只是询问原因，`凭什么` 才是在质疑丈夫凭经济贡献获得何种资格，因此姓氏、吃饭、穿衣、过年和双重反问都必须复现 `凭什么`。

剧本自审增加 `道具状态链`：凡关键道具发生拿取、甩出、滑动、递交、损坏或跨场出现，逐拍记录 `持有者 → 位置 → 接触者 → 动作路径 → 结果落点 → 下一动作入口`。写下一动作前先核对上一结果。禁止同一道具在没有移动过程时同时出现在两人手边，或让角色接触尚未到达的位置。当前银行卡链固定为 `丈夫甩出 → 停在妻子电脑旁 → 妻子拿起甩回 → 滑到丈夫一侧 → 撞停在旧工作手机旁`。

剧本交付前执行连续性扫描：逐个比较相邻节拍的上一结果与下一起点，再比较计划拆分出的相邻 `VID`。发现道具跳位、人物无因换手 / 换向、伤势或破坏复原、情绪无触发降温、B 重演 A、未完成结果被拆开，先回到最早错误节拍修正。这个门服务真实生成成本：文本阶段可发现的错误不得下放给一次几十元的视频生成试错。

情绪曲线必须经过 `空间压力排练`，不能只标注音量和表情。每个承重节拍回答：谁掌握主动，双方距离 / 高差 / 朝向如何变化，谁前进或后退，退路与障碍在哪里，峰值造成什么身体或空间结果，外部声音怎样改变下一行动。不是每句都安排走位，但连续压迫台词必须选择几个真正承重的动作节点。当前结尾让妻子按短句逐步逼近、丈夫逐步后退至背抵墙面，孩子哭声在最后一问后切断对峙，妻子去儿童房、丈夫转向手机；这才形成完整的 `第一峰值 → 控制蓄势 → 二次上升 → 贴墙最高峰 → 分流余波`。

关键台词在真人朗读之外，再做 `句尾声音测试`：单独朗读最后两三个音节，记录口腔开合、舌位阻力、气流是否外推、主重音、可否拖长、哭腔是否断掉和音量峰值是否落在正确词上。爆发不等于机械选开口音；需要冷断、咬住或压抑时，窄口与短促尾音可以承担功能。必须根据当前句尾是在爆破、质问、哀求、威胁、冷断还是思考来选择。

剧本和文案必须做泛化弱词审稿。`小、轻、低、微微、一点、稍微、淡淡、有点、慢慢` 这类词不是禁用词，但不能用来糊住人物立场、情绪力度、动作状态和关系压力。AI 常把这些词当成语义适配器：只要意思相近，就用一个安全宽词覆盖很多情况；人类写作要反过来，先判断人物身份、关系、处境和态度，再选词。需要刺痛就刺痛，需要粗粝就粗粝，需要冷淡就冷淡，需要克制就克制，不要用温吞安全词替代人物真实口气。错误写法：`她有点难过，轻轻说话。` 正确写法：`她眼眶下缘发红，嘴角上撑失败，嗓子先卡了一下，后半句几乎贴着气息落下去。`

剧本、口播、标题、评论钩子和歌词式文案必须执行“反模型众数倾向”审稿。语言模型的第一反应通常是同题材里最高频、最安全、最容易立刻读懂的表达；这类表达看似顺，但很容易变成公共情绪模板。关键位置不能直接接受第一版，包括片名、开场第一句、前 3 秒钩子、主冲突句、主物象、核心台词、桥段翻面句、结尾余味句、评论引导句、封面标题和口播金句。

高价值位置的内部写作流程固定为：

```text
先写出第一反应
→ 把第一反应标记为“平均值候选”
→ 生成 3-5 个方向不同的候选
→ 淘汰同题材可替换、说明文结论、短视频鸡汤和普通正确话
→ 做关系准确性检验
→ 做体裁成品性检验
→ 做留白检验
→ 只把胜出的版本写入正式稿
```

候选必须是不同方向，不是同义词替换。可从人物视角、情绪姿态、关系命名、修辞路线、声音结构、动作物象和反转角度上拉开。例如教育反转短片不能只写 `鼓励孩子 / 温柔教育 / 好好沟通`，要先命名旧教育预期和新教育反转之间的关系：羞辱式激励变成尊重式引导，恐吓式成长变成能力感建立，性别规训变成身份松绑，长幼压迫变成边界教育。

同题材可替换性检验：如果一句话换到任何失恋歌、亲情短片、教育短片、成长口播或治愈视频里都成立，它就只是题材平均值。正式剧本要让这句话被本作品的人物关系、场景动作、物件证据和声音节奏绑住。错误写法：`我终于学会放下你了。` 这句话能放进无数分手作品。更好的方向是把关系落到动作和物件里：`你的杯子还在第二层，我没再往里倒热水。` 它不直接讲释怀，而是让观众从未完成的生活动作里读到关系已经停住。

关系准确性检验：不要只写 `遗憾、释怀、亏欠、放下、成全、救赎、心疼、温柔、治愈`。先问这段关系到底在发生什么：退让、亏欠、羞耻、逃避、责任转移、亲密消耗、欲望落空、体面伪装、自我欺骗、权力不对等、安全感崩塌，还是被迫长大。关系命名准了，台词才会有方向；关系命名不准，语言再漂亮也只是情绪雾。

留白检验：剧本不是把主题讲明白，而是让观众在画面、动作、物件和未说完的话里自己补上。不要把 `我理解了什么` 写成结论，优先写 `我看见什么、听见什么、躲开什么、停在哪个动作里、哪句话没说完`。留白不能空，必须有可拍证据托住。比如亲情遗憾里，少写 `他终于懂了爷爷的爱`，多写 `他蹲在半成品木车前，拨了一下悬空的后轮，轮子只转了半圈就停住`。

反众数不是故意怪。不要为了逃离高频去写生僻词、硬隐喻、拗口长句或陌生概念。真正的文学感是“偏离平均但仍然准确”：观众第一下觉得新鲜，第二下知道这句话只能由这个人、在这个关系、这个场景里说出来。

### 商业广告脚本与卖点场景化

当作品要卖产品、卖服务、建立品牌记忆或促成咨询 / 下单 / 试用时，编剧的对象不是“产品有哪些参数”，而是“某类人在某个真实处境中为什么会需要它”。先写最小商业简报：

```text
转化目标：
目标人群与使用时刻：
已有方案的不满 / 购买阻力：
一句核心承诺：
支撑卖点（2-4 个）：
每个卖点的生活场景与可见证据：
钩子句 / 卖点句 / 品牌与行动句：
声称证据和禁止越界：
```

每个支撑卖点都要编成 `用户处境 → 问题触发 → 产品介入 → 身体 / 物体 / 环境结果 → 用户利益`。一条 15 秒广告默认只建一个核心承诺，用 2-4 个证据支撑；不为显得全面把所有参数、工艺和优点念完。卖点之间必须共同支撑一个购买结论，不是四个并排知识点。

老胡没给台词或文案时，先判断文案是否对转化承重。承重时默认主动产出：钩子句用于让目标人群认出自己的处境；卖点句只命名画面已经证明的好处；结尾句说清产品 / 品牌并给一个自然行动出口。文案不念屏幕上看得见的东西，不用虚假焦虑、绝对化词、无证据数字或伪竞品贬低制造需求。

## 自检

输出前检查：

- 本作品的推进机制是否能一句话说清：冲突、关系、时间、发现、观察、表演、空间或认知变化由什么承重。
- 冲突驱动故事的对立面是否足够具体，且不只是纸片反派；非冲突体裁标记 N/A。
- 主角、品牌、产品或世界观是否有会吸引一部分人也排斥另一部分人的独特个性。
- 黑暗时刻是否确实承担命运升级并逼出选择；不需要该机制的体裁标记 N/A。
- 如果是第一桶金 / 创业起源故事，是否有离开之幕、启动之幕、归来之幕。
- 第一桶金是否既有结果，也有代价、转折或新危险。
- 使用阻力时是否具体，而不是抽象困难。
- 使用冲突升级时是否有清楚因果；观察、文艺和氛围体裁不为升级而升级。
- 每场戏是否完成了它的叙事或情绪功能，而不是无目的展示信息或奇观。
- 主角是否同时具备外在目标、深层需求、错误信念和最后选择。
- 已确认设定是否都在正式剧本正文中得到保留或转译；是否存在只留在索引 / 故事确认里、正文改稿时被删掉的背景刀口。
- 开头是否快速给出类型承诺、看点和观众等待的问题。
- 当前任务是否已经判断需不需要故事设计稿；若故事引擎、首尾画面、场景链、人物选择或资产预判不清，是否已经先补故事种子 / 故事确认，而不是直接写剧本。
- 如果输入只是灵感、正能量方向或反差案例，是否先做了 3-5 个价值脑洞候选；是否拆出影射议题、正向价值、观众误判、反转机制、隐喻物、命名方向和开场特写钩子。
- 是否已经按导演总控流程判断本轮主身份：编剧、导演、文戏导演、动作导演、摄影指导、剪辑指导或 AI 生成导演。
- 文戏是否写清台词目的、潜台词、表情路径、停顿、关系距离和反应镜头；复杂承重节拍是否交接人物目的、保护策略、精确触发、禁止提前反应和结束状态；是否避免台词变成主题总结。
- 武戏 / 动作是否先写清故事任务、主情绪、力量来源、路径、接触与结果；起势、发力、受力、反应、爆点和停帧是否只分配给真正承重的节拍。
- 坐骑、车辆、追逐或群战是否交代共同运动、分离触发、惯性、减速原因、相对顺序和离场顺序，没有把关键物理关系全部留给分镜猜。
- 承担爆点或高生成风险的复杂人体动作是否给出起始姿势、支撑变化、主要发力、翻转 / 穿越方向、首次接触、卸力和结束姿势，没有只留动作名称。
- 爆炸、炮击、坍塌、撞击或能量破坏是否交代来源、命中点、传播方向、主要材料失效和不可逆结果，没有用一个结果词跳过因果。
- 节奏密度是否匹配体量；15 秒、30 秒、60 秒和 1-3 分钟内容是否有对应的信息推进、冲突推进或情绪推进。
- 短视频、舞蹈、歌曲、口播、转场素材或包装层开头是否已经判断未闭合动作；如果需要，是否写清前状态、时间压力、不可回避边界、峰值切点和正文入口。
- 45 秒视觉短片是否有钩子、宏大揭示、近景锚点和结尾记忆点。
- POV 内容是否体现第一人称沉浸和身份关系，而不是普通第三人称游览。
- 第一人称 / 儿童 POV 的每个细节是否都能被主角看见、听见、摸到或感到；不可见信息是否已经通过门缝、影子、画外音、反射、身体感觉或他人反应转译。
- 回忆是否由当前台词、物件、触碰、声音或气味触发，而不是悬空插入；回忆画面是否有朦胧质感、声音穿插或 VO 标识。
- 报丧、噩耗和突发事故是否保留突发性；是否避免在消息前提前露出白布、灵堂、棺木等结果画面。
- 死亡消息和方言台词是否匹配人物身份、文化程度和戏剧冲击，不是否被过度写成书面委婉话。
- 情绪型时间压缩是否通过叩首抬头、遗像切换、物件匹配、视角高度、服装变化、环境状态或声音回忆给出足够证据。
- 每个关键节点是否是行动或选择。
- 是否有摄影机拍不到的心理描写。
- 单镜头剧本是否不超过 15 秒，且只有一个主要动作或信息变化。
- 台词是否在解释主题。
- 剧本格式是否充分使用语气 / 神态括号、OS、VO、字幕、空镜、闪回、闪回结束、插入镜头等结构；是否有该标没标的信息。
- 台词是否匹配人物地域、年龄、文化程度和关系口气；用户指定重庆话等方言时，是否写出可听懂的方言口语气质，而不是书面普通话。
- 亲情遗憾、童年成长、怀旧家庭故事是否有完整情感因果链：主角误解、具体愿望、亲人记住、具体回应、缺点引爆、后果压近、遗物回收。
- 核心物件是否已经成为情感证据，而不是突然出现的象征物。
- 如果是短视频或口播内容，是否有至少一个反差表达、错位表达或可转述的金句 / 包袱。
- 高价值表达位置是否没有直接采用第一反应；是否至少做过 3-5 个方向不同的候选竞争。
- 片名、钩子、核心台词、主物象、金句和结尾句是否通过同题材可替换性检验；如果换到同题材其他作品里仍然成立，是否已经重写。
- 关键句是否命名了具体关系结构，而不是只使用遗憾、释怀、亏欠、放下、成全、治愈、破碎等公共情绪词。
- 情绪是否通过动作、物件、声音、停顿和未说完的话形成留白，而不是写成说明文结论。
- 喜剧表达是否来自人物处境和观点冲突，而不是外加段子。
- 如果写到惨、低谷或困难，是否已经转向和解、励志、行动或成长。
- 是否找到观众的大脑墙和真实痛点，并设计金句钉、共鸣网或利他金。
- 是否利用了损失厌恶，但没有滑向虚假焦虑、恐吓或恶意操控。
- 广告语、口播金句或品牌表达是否像个体宣言，而不是普通正确话。
- 金句是否从共识里找到了未被说透的偏见、真实偏好或反常识角度。
- 表达是否借用了感性、可接受的缺点和共同敌人，而不是只停在理性正确和优点赞美。
- 人物、品牌或产品的缺点是否被转化成边界、个性、关系或成长动力，而不是恶意标签。
- 内容是否有明确风格边界，是否知道吸引谁、放弃谁。
- 是否设计了一个服务主张的轻微跑调点，避免语言、观点或角色被选择性忽视。
- 是否有一句可记住、可转述、可截图的表达。
- 观众看完是否获得方法、情绪释放、认知升级、勇气或行动路径。
- 是否能拆成可复用资产、一次性画面元素、角色 / 场景 / 道具需求和镜头任务。
- 是否输出剧本交接包，方便下游判断哪些需要做视觉资产，哪些只写进单镜头画面内容。
- 是否需要进入作品目录并更新版本。
