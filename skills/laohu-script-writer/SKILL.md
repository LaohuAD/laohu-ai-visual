# 老胡剧本开发

## 编剧箴言

没有选择的为难，就没有真正的戏。

事情多不等于故事成立。剧本要让观众看见：人物想得到什么，什么逼他作出选择，这个选择失去什么，又把下一场推向哪里。

## 输入与责任

本 Skill 接收灵感、口述、主题、人物、事件、广告任务、粗梗概和已有草稿，交付可拍、可生成、可剪辑的故事与剧本。

它负责：

- 找到观众等待的问题。
- 建立人物目标、阻力、信息差、选择和代价。
- 组织场次因果、关系压力与情绪推进。
- 把抽象主题翻译成动作、台词、物件、空间和结果。
- 保护已确认事实，并给下游留下明确创意空间。

它不负责最终资产图片提示词、正式视频模型提示词和封面。

开始前读取当前作品的项目总览、原始输入、已确认故事、现有剧本和阶段记录。已有成熟稿时先诊断，不因“重写”两个字就顺手换掉人物关系、核心物件、时间线、POV、地域口气和结尾回收。

## 故事因果

### 观众等待

先用一句普通话回答：观众为什么愿意继续看？

好的等待不是“接下来会发生什么”的空悬念，而是一个尚未解决的具体状态：拿不到的东西、说不出口的话、过不去的门、不能撤回的结果、尚未回应的请求、正在逼近的危险或仍未兑现的承诺。

每个关键节拍记录：

```text
观众已经知道什么：
观众暂时相信什么：
观众正在等什么：
人物此刻想让谁做什么：
这一节拍改变了什么状态：
下一场压力从哪里来：
```

作者知道答案，不等于观众已经知道。剧本按观众的发现顺序安排信息，角色只能根据自己掌握的事实行动和说话。

钩子不是故意少讲，而是让观众凭足够证据开始预测一个尚未完成的结果。重要开场和关键节拍执行观众预期契约（期待契约）：

```text
可见证据 → 暂时判断 → 可预见压力 → 未揭变量 → 部分兑现
人物正在采取的行动：
后续处理：完成 / 扩大 / 推翻 / 重新解释。
```

开场先确定一个主要注意入口：人物、规则概念或眼前危机。其他信息只能从属，不同时争夺观众第一判断。使用强钩子、伏笔或反转时建立承诺—兑现账本，记录开场由哪个动作、物件、台词、声音或空间提出问题，中段怎样改变意义，结尾怎样兑现或重新解释。开放式和低烈度作品不机械闭环，但必须留下真实的关系或情绪余波。

悬念、调查、误解、关系秘密、倒计时、产品问题或知识解答承担观看牵引时，编剧还要形成`观众问题—答案交接`，供分镜和视频负责人分配声画节奏。按节拍记录当前问题怎样被`建立 / 加压 / 延迟 / 部分回答 / 回答 / 改写`，以及哪项可见或可听证据允许观众更新判断。延迟只能隐藏尚未到期的原因、身份、选择或结果，不能删掉理解当下行动所需的事实；新问题必须由旧问题的答案或后果长出来，不能靠无关异常续命。开放式作品可以不回答事实，但要交代主要关系或情绪运动在哪里完成。

### 人物选择

重要人物至少建立：

```text
表层目标：眼前想得到什么。
深层需要：真正缺的是什么。
错误信念：他为什么一直用错误办法。
恐惧与代价：什么让他不愿改变。
可见策略：他通常怎样试探、逃避、压制、保护或争取。
阈值选择：什么事件逼他不能再照旧。
选择结果：他做了什么，失去或承担了什么。
```

人物性格要由不同处境下反复出现、但会随压力变化的选择证明。一个口头禅、一个表情或一次换装不能代替人物。

### 动机、行动与物件

人物每个承重动作都要回答：他当下想改变谁或什么，为什么选择这个动作和这件物品，动作带来什么即时结果。台词与动作可以同向，也可以因为两难、伪装、犹豫或失控而表面相反；但相反必须由前后目的、精确触发和关系后果共同证明。没有这条因果却让人物说一套做一套，不是潜台词，是剧本错误。

关键物件按控制权写进场次：它起初在谁手里、谁把它放到谁面前、谁能拿走、谁越过阻拦重新取得、最后停在哪里。物件一旦改变人物选择、身体代价或关系权力，就不能只写成场景名词；下游必须能从剧本知道它的叙事职责和动作结果。普通陈设仍留给资产与分镜，不把剧本写成物品清单。

### 场次压力

每场戏都要完成一次状态变化：

```text
进入：人物带着什么目标和前一场余势进入。
施压：谁或什么阻止他，压力怎样升级。
选择：人物采取什么行动，不采取什么行动。
结果：关系、信息、道具、空间或身体发生什么变化。
牵引：哪个未解决状态形成下一场压力。
```

场次可以外部安静，但内部不能停止变化。文艺、观察和氛围作品可以靠等待、距离、误解和表演推进，不为套公式强造争吵、反转或爆炸。

### 文戏与武戏

文戏的动作单位是关系变化。台词要有目的并造成后果：试探、求救、保护、拒绝、压制、邀请、切断、告别或挽留。高潮台词不替作者总结主题；没有说完的话由表情、动作、物件、空间和另一个人的反应承接。

武戏的动作单位是力量关系变化。剧本至少交代力量从哪里来、向哪里去、谁被迫选择、接触造成什么结果、余势怎样进入下一动作。剧本不替分镜写焦段和机位，但不能把“激烈打斗、翻身下马、大楼爆炸”当作完整因果。

### 语言与材料

先找关系，再炼句子。关键台词、片名、钩子、主物象和结尾不能直接采用模型第一反应。

人物声音不先由口头禅、方言或句式决定，而由他怎样看见、解释和应对世界决定。编剧负责的是`写作声音`：人物优先感知什么、怎样解释、想用语言改变谁、回避什么，以及说完会怎样行动；它决定台词 / OS / VO 的内容与语言策略，不决定演员的生理音区、音色，也不逐镜导演呼吸和口型。重要人物写台词、OS或VO前建立人物声音合同：

```text
他优先注意什么：
哪些职业、生活或身体经验支持这种注意：
他会怎样解释证据：
他想让谁做什么：
他最不愿直接说出什么：
压力下会泄露的价值判断：
未说出的普通愿望：
这段话之后的当场行动和可见后果：
```

正式交接时把已经定稿、下游不得改写的台词 / OS / VO 明确标为`冻结台词`，并交给`laohu-audio-design`编译自然语言音色描述、当场演法和可生成音频任务。音频设计可以为稳定发音而建立可读规整文本，但不能改变原句语义、人物策略和关系后果。

口头禅、方言词和金句都不能单独证明人物。强表达至少要暴露一项只属于此人的感知、判断、回避、愿望或行动策略，并回到`感知证据 → 人物解释 → 当场行动 → 可见后果`。详细方法只在人物声音、台词、OS、VO、方言或文学样章承重时读取`references/04_口述台词与方言.md`。

```text
写出第一反应
→ 把它当作平均值候选
→ 从人物立场、关系命名、动作证据、声音节奏和留白生成不同方向
→ 淘汰换到同题材另一篇仍成立的句子
→ 真人朗读
→ 只保留这个人物在这个处境里会说、也说得出口的话
```

材料不以“私人小物件”自动取胜，也不以“宏大意象”自动高级。选择能承担当前关系和主题、又能进入公共经验的材料：它可以是一把钥匙，也可以是一座城；关键不是大小，而是它与人物、处境和结果之间有没有不可替代的关系。

## 剧本开发

### 任务分型

| 输入状态 | 本轮产物 |
|---|---|
| 只有灵感、社会现象、价值方向或开场画面 | 先做灵感解构与 3—5 个价值方向，再选故事种子 |
| 有人物和粗事件，但故事引擎不清 | 故事设计稿 |
| 故事已经成立 | 分场剧本或单场次剧本 |
| 已有剧本但效果不对 | 剧本医生诊断，先找最上游断点再改稿 |
| 有商业产品或服务目标 | 商业简报、卖点场景化与广告脚本 |
| 只有单个画面 / 15 秒任务 | 单场次、一个主动作或一个信息变化的短剧本 |

故事设计稿不是小说。它先建立：观众等待、人物目标、阻力、代价、首尾画面、关键转折、场景链、情绪曲线、资产预判和生成风险。只有老胡明确需要文学样章、旁白口吻或 IP 气质时才写小说式文本。

### 素材查询合同

正式故事设计、分场、单场次或重写开始前，先调用 `laohu-story-material`，提交：

```text
【素材查询合同】
当前剧本缺口：
叙事范围：story / sequence / scene / beat / texture。
素材职责：主故事 / 冲突 / 人物行为 / 台词 / 场景质感 / 物件 / 记忆点 / 价值信息。
当前人物关系与选择压力：
希望加强的人性机制或情绪：
必须保护的故事事实：
候选需要在哪些因果方向上不同：
怎样算已经充分：
禁止套路与不适配：
```

先做严格匹配；不足时每轮只放宽表面条件中的一个字段并记录变化；再做跨领域类比。仍不足时由素材负责人形成内部缺口报告，是否搜索网络和采用外部案例不能由编剧暗自决定。同一任务中，人物、事实、素材职责和剧本缺口都未改变时可以复用已有素材交接包；任一条件改变或进入新任务时重新查询。

候选是否足够，以它们能否解决当前剧本缺口为准，不按固定数量判断。只采用一条不是不足，原创方案更准确时允许零采用。未经确认的 `external_candidate / not_approved` 不得进入剧本；即使获准使用，也只能迁移机制和证据结构，不能复制真实身份、独特原话或受保护表达。

长篇不能靠一次检索塞入更多候选。先建立 `story` 级承重会话，再按段落、场景和局部动作分别建立 sequence、scene、beat 会话，需要生活质感时才补 texture；电影可以沿着场景链逐段检索和编写，但每段仍须继承全片的人物目标、已发生后果与未来回收。检索页只是本轮可读窗口，不是全片素材配额；一页不足就续页，一个场景结束也不等于丢掉全片状态。

入围原子按 `承重 / 支撑 / 纹理` 标职责：承重原子改变人物选择或主要因果，支撑原子让压力、证据或回收成立，纹理原子增加真实感但不能抢走主动作。短片的信息密度看单位时长内发生了多少次有效状态变化——观众理解、人物关系、行动条件或风险真正改变——而不是看写进多少原子。若新增候选只重复已覆盖机制、不能带来新的因果方向或可见证据，就说明边际增益已经消失，应停止续页或改写查询合同。

### 故事构件查询合同

素材原子提供生活证据，故事构件提供状态变化方式。素材交接完成后，如果故事动力、压力增长、信息变化、不可逆代价、阈值选择、首尾回收或场景融合仍不清，再调用本 Skill 的构件库；故事因果已经成立、只改台词或整理格式时不读取全库。

```text
【故事构件查询合同】
当前故事缺口：人物理由 / 约束 / 加压 / 信息 / 代价 / 选择 / 回收 / 场景融合。
必须保护的人物、事实和创作者命题：
希望产生差异的因果位置：
构件必须具备的前置与输出状态：
不适配与禁止组合：
怎样算已经充分：
```

使用 `scripts/story_component_library.py`，按 `stats → search → get` 渐进加载 `references/07_故事构件库.jsonl`。优先按戏剧职责与状态变化检索，不按题材外壳机械匹配；候选不适配、构件库为空或原创方案更准确时，允许零采用并继续原创，不得自动网络搜索。

构件进入候选后，按 `前置条件 → 人物行动 → 状态变化 → 观众更新 → 下一压力` 连接并执行因果验收。重要故事至少比较三个因果真正不同的组合；只替换职业、地点和道具不算不同。每个胜出构件都必须说明人物为什么会采用它、它怎样改变下一状态和观众等待；多个概念并排却互不产生后果时退回重组。

场景融合优先让同一承重行动、物件、空间或声音同时改变关系、信息和下一压力，但每场只保留一个主要状态结果。多个构件争夺主结果时拆场或淘汰，不靠解释把拥挤伪装成丰富。

### 开发顺序

```text
确认命题、受众、平台、体量与观看承诺
→ 渐进检索素材，取得人性与生活证据
→ 建立人物目标、错误方法、代价与阈值选择
→ 判断当前缺少哪一种状态变化
→ 按需渐进检索故事构件
→ 产生因果不同的候选并推演二阶后果
→ 选择主因果链，安排观众发现顺序
→ 场景融合、情绪曲线与承诺兑现
→ 标出相邻单元及状态
→ 写正式剧本和生产证据
→ 反向审稿并形成下游交接
```

### 剧本巅峰门

可拍、可生成、因果无误只是底线。正式剧本还要证明它不是同题材的平均答案：

```text
主胜负手：观众最终会因哪一个人物选择、关系变化、认知翻转或情绪余波记住它。
候选竞争：关键冲突、阈值选择、高潮和结尾是否比较过至少三个因果真正不同的方案。
不可替代：把人物名、行业名和表面设定换掉后，核心场面是否仍像公共模板。
兑现强度：开头许下的等待，是否由后续更强的选择、代价和结果偿还。
顶尖校准：同类成熟作品最强处靠什么成立，本稿学到的是机制还是只借了表面。
下游潜力：资产、镜头、表演和声音是否得到足以继续升级的关系，而不是只得到完整情节。
```

人物选择没有更痛也更准确的替代、高潮没有比铺垫更高一层、结尾只把事情讲完却没有留下关系余波时，剧本不得因为格式完整而交接。极致不是强行反转、放大苦难或句句金句；真正的强度来自所有场次把压力推向同一个无法逃避的选择。

### 相邻单元

两个节拍、场次或 VID 共享人物、动作、道具、空间、时间、声音或情绪余势时，逐对写清：

```text
A 已完成结果：
A 结束状态：
B 开始状态：
必须不变 / 允许变化：
B 第一项新动作或声音：
下一相位：B 从哪里继续，而不是重演 A。
下一场压力：哪个未解决问题把 B 推出来。
```

直接连续时 `A 结束状态 = B 开始状态`。剧本只锁世界事实和人物状态；景别、焦点、机位与剪辑方式留给下游。

### 商业剧本

商业内容先建立：

```text
转化目标：
目标人群与使用时刻：
原有方案的不满或购买阻力：
一句核心承诺：
支撑卖点与证据：
品牌与行动出口：
事实和声称边界：
```

每个卖点写成 `用户处境 → 问题触发 → 产品介入 → 身体 / 物体 / 环境结果 → 用户利益`。真实参数与疗效没有证据时不编造；画面不能证明的卖点不靠一句广告词硬说。

## 剧本交接与验收

### 输出合同

根据任务按需交付，不把所有字段机械填满：

记忆点不设置“每几秒一个”的固定规则。短内容可以提高有效变化密度，长内容可以延长铺垫和回收；验收看每个记忆点是否改变观众理解、期待、关系感受或情绪，主记忆点是否高于支撑细节，相邻亮点是否互相竞争，以及留白是否在为后续兑现蓄力。素材多不等于信息量高，只有进入主线因果并改变观看状态的细节才保留。

正式结果写入当前作品的 `01_世界观故事/文本/` 或 `02_剧本/文本/`，默认覆盖当前阶段主文件，不自动制造版本文件。

### 验收

- 能否一句话说清观众在等什么。
- 每个关键节点是否由人物选择或行动推动，而不是作者解释、巧合或主题要求。
- 人物的即时目的、台词、动作和关键物件是否共享一条因果；表面矛盾是否由两难、伪装、犹豫或失控证明，而非无意打架。
- 每场是否改变关系、信息、道具、空间、身体或下一步可能性。
- 人物是否只说他知道、想说、能说出口的话。
- 台词是否有对象和后果，关键句是否通过可替换性与朗读检验。
- 人物声音是否先改变他注意和解释证据的方式；口头禅、方言、比喻和金句是否只在替作者炫技。
- OS / VO是否与画面形成补充 / 对位 / 反差，而不同义复述画面；删掉漂亮独白后，人物选择和场次状态是否仍不变。
- 抽象主题是否已有可拍证据，材料是否真的承担关系，而不是为了具体而具体。
- 文戏是否有关系压力，武戏是否有力量来源、路径、接触和结果。
- 相邻单元是否状态相等，B 是否从下一相位开始。
- 已确认事实是否完整保留，新增创意是否标明。
- 下游能否直接识别该稳定什么、该自由设计什么，不需要重新猜故事。
- 构件是否真正改变状态与观众等待，而不是只留下一个结构名称；构件库无合适候选时是否允许零采用并继续原创。
- 场景融合是否依靠同一承重行动和一个主要结果，低烈度作品是否没有被连续反转强行堆叠。
- 强钩子是否有可见证据、暂时判断、可预见压力、未揭变量与后续兑现，而不是隐藏当下危险。
- 正式剧本正文与生产证据账本是否分权，声音是否有声源、触发和作用，镜头决定是否留给分镜与视频负责人。
- 是否通过剧本巅峰门：主胜负手明确，关键候选经过比较，开头承诺被更高强度地兑现，且没有已知但未处理的明显更优方案。
