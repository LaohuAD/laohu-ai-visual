# 体量、形态、编号与连续性



当任务需要决定作品体量、剧本形态、短剧编号、单镜头边界或跨单元连续性时读取。



## 体量路由

先判断作品体量：

- 15-60 秒短视频：1 个核心动作，1-3 个镜头。
- 1-3 分钟概念片：1 个高概念，1 次翻转。
- 3-10 分钟短片：主角目标、阻力、代价、选择完整。
- 系列短剧：先做单集样片，不一次性写完整季。
- MV / 视觉诗：按音乐结构和情绪推进。

如果用户没有说明体量，先根据输入推荐一个体量，并说明为什么。只有体量选择会明显改变后续结构时才追问。

45 秒横屏视觉短片的剧本节拍：

```text
0-3 秒：钩子和身份关系。观众必须知道自己为什么要继续看。
3-10 秒：第一视觉承诺。给出题材、世界和最强入口动作。
10-25 秒：宏大揭示。展示空间尺度、秩序、奇观和 POV 运动。
25-35 秒：近景锚点。给人物反应、手部动作、材质、道具或局部奇观特写。
35-45 秒：升级和记忆点。留下更大门槛、反转、邀请、冲击波、开门或最后一帧。
```

如果用户要求“恢宏但有特写”，剧本阶段必须先把远景 / 中景 / 近景 / 特写的功能分开。不要等到视频提示词阶段再临时补特写。

常见体量节奏网格只作诊断尺，不是死规定：

```text
15 秒：强钩子 → 建立冲突 → 动作 / 信息升级 → 爆点或封面停帧。
30 秒：约每 3-5 秒改变一次镜头任务，10-15 秒出现一次小反转或关系翻面。
60 秒：约每 5-8 秒推进一次信息，20-30 秒出现大冲突，45 秒后进入不可逆转折或情绪爆点。
1-3 分钟：用段落推进，文戏允许长镜头压情绪，武戏用短切和运动爆点提速。
```

如果节奏明显慢于这个网格，必须解释慢的理由：情绪压迫、长镜头沉浸、空间调度、悬念等待或文艺留白。解释不出来，就说明节奏不是高级，而是松散。

短视频开头钩子必须优先寻找“观众等待的问题”。开头不是先把所有信息讲清，而是先让一个结果逼近：倒计时是否归零、插头是否插上、车辆是否撞到、火花是否铺满、球是否砸到镜头、门是否关上、秘密是否揭开。这个问题越具体，观众越难立刻滑走，因为大脑已经开始预测结局。

剧本层写法要先建立未闭合动作，再进入正片层或包装层。标准结构：

```text
前状态：观众一眼看懂当前危险 / 缺口 / 倒计时。
时间压力：数字减少、距离缩短、速度加快、光线变暗、声音逼近。
不可回避边界：左右逃不开、时间不够、接口只差一点、球已经进入镜头轴线。
峰值切点：结果发生前一瞬或刚要发生的一瞬。
正文入口：用同一块黑屏、强光、火花、撞镜、烟雾、袖面或声音把观众带入正片。
```

错误写法：`开头炫酷转场进入舞蹈。` 这没有观看任务，只是装饰。正确写法：`手机电量只剩 1%，屏幕弹出 5 秒关机倒计时，充电头从画面下方滑向接口；数字跳到 1 时，插头金属头刚要插入，屏幕突然暗下，黑屏中响起第一下袖风，切入泠月的脸部近景和水袖起势。` 这类写法的根本目的不是吓人，而是用未完成结果把观众的注意力借给正文。

POV 剧本要写出第一人称沉浸，但不要描写不可见的“主角本人长相”。可写：

```text
镜头被谁引导。
前景出现袖口、手势、门槛、云雾、法器或光压。
观众视角被邀请、推动、吸入、俯瞰、穿越或停住。
场景如何回应“大人物”的身份。
```

## 剧本形态路由

参考山音编剧能力的“多格式覆盖”思路，但按老胡 AI 视觉生产重写为四种形态：

| 剧本形态 | 用途 | 输出深度 |
|---|---|---|
| 完整作品剧本 | 3-10 分钟短片、系列样片、概念短片 | 故事种子、人物、结构、分场、重点场景、剧本医生 |
| 分场剧本 | 已有梗概，需要拆制作段落 | 场次目标、阻碍、结果、可视化重点、声音重点 |
| 单镜头剧本 | 拿去生成一个最长 15 秒的视频镜头 | 一个镜头任务、动作、台词/同期声、情绪变化、结尾画面 |
| 修改版剧本 | 用户已有草稿，需要提升质量 | 问题诊断、修改原则、改写版本、下游拆解提醒 |

如果用户说“一个画面”“一个场次”“一个镜头”，优先判断是否应输出“单镜头剧本”。单镜头剧本不是分镜表，它是一个可被 `laohu-video-prompt` 继续翻译成视频提示词的短剧本单元。

如果用户最终目标是视频提示词，即使没有直接说“写剧本”，也必须先给出或引用单场次剧本。可以判断不需要固定人物 / 场景资产，但不能跳过剧本场次到分镜提示词的来源链路。

如果用户给的是选题、世界观、人物关系、教育反转、恋爱情绪、国风角色宣传片或系列短剧方向，不要直接输出完整剧本。先按体量判断：

```text
灵感 / 反差案例 / 正能量方向：灵感解构与价值脑洞 → 故事设计稿。
单镜头 / 15 秒内视觉动作：极简故事种子 → 单镜头剧本 → 视频提示词。
1-3 分钟短片 / 概念片：故事设计稿 → 分场剧本 → 分镜 → 视觉资产和视频提示词。
系列短剧：系列冲突引擎 → 单集样片故事设计稿 → 样片剧本 → 再决定是否扩展系列。
需要文学气质 / 旁白声音：故事设计稿 → 可选小说式样章 / 旁白样章 → 正式剧本。
```

直接写剧本只适用于故事引擎、首尾画面、主要场景链、人物选择和下游资产需求已经清楚的情况。否则先由本 skill 自动补故事设计稿，再继续剧本。

剧本输出文件建议位置：

```text
故事内容确认文件：
01_作品项目/<状态>/<作品名>/01_世界观故事/文本/00_故事确认.md

剧本结果输出文件：
01_作品项目/<状态>/<作品名>/02_剧本/文本/yyyy-mm-dd_剧本_<主题>.md
```

剧本交付后必须更新：

```text
01_作品项目/<状态>/<作品名>/00_阶段确认记录.md
```

STOP/CHECKPOINT：

```text
故事设计完成 → 内部检查事实、因果、情绪和观众代入路径后继续正式剧本；老胡明确要求共创讨论时才停。
正式剧本完成 → 锁定已写明事实，列出导演创意留白，继续进入视觉资产 / 分镜。
如果老胡要求直接做视频提示词 → 仍先内部形成单场次剧本，再自动交给导演构思与视频提示词，不用为普通创意再次确认。
```

## 短剧格式与编号

正式剧本首先服务人类和下游 AI 对故事、情绪、空间和镜头边界的共同理解。它不是文学小说，也不是直接投喂模型的执行提示词；它要让读者不靠作者口头解释就能想象出正在发生什么。

剧本最前面必须有三组导读信息：

```text
【剧本说明】
剧本用途 / 阅读对象 / 下游怎样继承 / 哪些事实不可擅改。

【作品信息】
标题 / 类型 / 媒介 / 画幅 / 预计时长 / 集数 / 主要人物 / 受众。

【故事说明】
一句话故事 / 观众等待 / 人物关系 / 主情绪运动 / 场次结果 / 必须继承的道具和空间事实。
```

导读信息只在正文前统一讲戏，不在每个镜头里反复写“镜头作用：建立教学关系”或“证明灯光变化”。镜头的职责应该由正文中发生的动作、台词、反应和结果自己显现。

短剧 / 短片分场剧本使用以下基础格式；长片、剧集、广告和教程可改体量，不改集—场—镜的层级：

```text
第1集

1-1  外  云海白玉祭坛  日 / 雨
人物：年轻迎客仙人、主角（被称为“大人”的 POV）
开场状态：年轻迎客仙人站在祭坛右侧，主角尚未出画。

【E01-S01-C01｜全景｜运镜：固定镜头｜机位：祭坛南侧，朝北看向人物｜构图：人物居中，主角画外｜约4秒】
△ 动作描述。
角色名：台词。
角色名（压低声音）：带语气 / 神态的台词。
角色名（O.S.）：同场存在但当前没有出现在画面内的角色台词。
角色名（V.O.）：旁白、回忆声、跨时空声音或不作为现场对话的内心声。
角色名（内心V.O.）：需要明确区分时使用的未说出心声。
【字幕：内容】
【空镜：场景描述】
闪回
△ 回忆画面动作。
闪回结束
```

剧本符号是固定格式，不是装饰。只要输出内容被标为“剧本结果”“单场次剧本”“分场剧本”，无论它是单独文件还是整合进最终总结果文件，都必须保留这些符号。不要为了压缩或整合，把剧本改写成普通叙事段落。

所有观众会看到或听到的正文必须归入一个镜号。镜号先出现，再写本镜的 `△` 动作、台词、声音和屏幕文字；禁止在场次头与第一个镜号之间放置漂浮动作。

镜号以`一次不中断的摄影机观看`为边界，不以一段剧情、一组对白或一条因果链为边界。一镜一事：每镜只有一个主要画面内容、一项主变化和一条连续可达的观看路径。触发—动作—反应只有在它们仍属于同一主要画面内容、没有新增独立信息任务、且当前构图能够连续看清时才可留在同一镜号；新人物的独立反应、插入物、主观视角、正反打、局部动作转全景结果、硬切，或前一结果完成后又启动新的触发—变化—结果，都必须新建镜号。信息密度来自相邻镜头不断交出新证据，不来自单镜堆入更多内容。

镜头方头先给读者一张可快速预读的摄影合同：

```text
【唯一 E-S-C 编号｜景别｜运镜：基础运镜｜机位：相对位置与视轴方向｜构图：开镜投影或必要的起止变化｜参考时长】
```

景别是证据尺度；运镜回答摄影机是否以及怎样变化；机位 / 视轴回答摄影机相对谁或哪个固定锚点、从哪里朝哪里看；构图回答这个观看位置最终让谁处于画面左中右、前中后景，以及复杂长镜头是否发生必要的起止重构。四者不是同义字段：机位是原因，构图是画面结果。时长是剧本节奏参考，不是生成平台的最终参数。

运镜只写“固定镜头”“缓慢推近”“跟拍”“横移”“后拉”等基础方向；机位只写足以消除观看方向歧义的相对关系，不写无叙事价值的设备坐标；构图只写承重对象和必要层级，不把所有布景塞进方头。复杂组合路径、焦点、焦段和速度曲线由视频负责人深化。方头不加“镜头作用”“建立关系”“证明变化”等作者解释。

`E` 是 Episode，表示集数；`S` 是 Scene，表示当前集内的场次；`C` 是 Camera Shot，表示当前场次内的镜头。进入新场后从 `C01` 重新编号，`S` 同时递增；同一作品不再额外添加全片连续的“镜1、镜2”等第二套显示编号。

剧本正文保持偏小说性的可见结果语言。它写人物、光线、空间、动作、表演和状态变化，不再把方头已经给出的静态机位、视轴与开镜构图埋进正文，也不重复编译完整摄影机路径；详细速度、焦点、光学和模型执行交给 `laohu-video-prompt`。正文仍须写清世界中的人物和道具位置、身体朝向、视线、遮挡、距离、入画退出、动作来源与结束状态；当人物运动或运镜使构图发生变化时，正文要写可见过程，不能只在方头写一个箭头让模型补猜。

## 画面关系与观看位置

正式剧本先建立空间，再描述画面。它不默认写精确设备坐标，却必须让三层关系同时成立：

```text
世界层：人物、道具和固定锚点在场景中的真实方位、距离、朝向、进入路径与接触关系。
摄影机层：摄影机位于人物关系轴线的哪一侧，视轴朝向哪里，景别允许看见多大范围；固定还是沿哪一条连续方向变化。
画面层：在这个观看位置下，谁落在画面左中右、前中后景，谁遮挡谁，眼线和运动方向如何投影。
```

“老胡站在圆台右侧”是世界位置，不自动等于“老胡位于画面右后方”；只有摄影机观看侧与视轴确定后，世界位置才能投影成画面位置。换机位可以改变左右与前后景投影，不能无过程地改写人物在世界中的真实站位。

空间验收顺序固定为：`世界位置 → 摄影机观看侧 / 视轴 → 画面左中右与前中后景`。任一箭头无法解释，镜头仍未闭合。

这套三层空间用于真人、实拍与三维空间。二维动画、MG、UI和字幕动效没有真实世界站位时，用`信息拓扑 → 视窗 / 版式观看范围 → 屏幕层级与焦点`完成同一职责：一个单点细节画面不能同时证明完整系统关系，视窗缩放、遮罩展开、图层前后移或版式重排若承担新的独立信息任务，同样需要新建镜号。不能为了统一术语，给二维内容强造摄影机和地面轴线。

每个复杂多人镜头写正文前先形成`镜头继承合同`：

```text
本镜唯一主观看任务：观众只等待哪一项变化。
开镜状态：开拍时已经成立的人物、道具、光线、声音与动作预备态。
世界位置：每个承重对象相对门、圆台、桌、墙、道路等固定锚点在哪里。
摄影机观看侧与视轴：从人物关系轴线哪一侧、朝哪个方向看；是否固定。
开镜画面投影：实际入画者、画面左中右、前中后景、身体朝向、视线与遮挡。
允许的连续变化：人物怎样走、转、靠近、离开或进入画框；摄影机若移动，沿什么连续方向改变观看关系。
镜尾状态：谁仍在画内、停在哪里、持有什么、朝向哪里，空间 / 身体 / 道具 / 声音发生了什么不可逆变化。
下镜第一项新变化：下一镜从哪个新证据或下一动作相位开始。
```

合同用于编剧排演和下游继承，不要求把字段表机械贴进每个简单镜头。正文仍以自然、可见的动作语言承接；只有会影响读者理解、资产设计、批次组合或视频执行的事实才显式写出。

每镜根据需要写清：

- `实际出画 / 画外`：谁在画面里，谁只有声音。
- `世界位置`：人物或道具相对固定场景锚点在哪里，不因换机位自动变化。
- `摄影机观看侧 / 视轴`：从关系轴线哪一侧、朝什么方向观看；只写足以消除投影歧义的粗粒度关系。
- `画面位置`：在当前观看侧下，人物或道具处于左、中、右和前、中、后景的哪一层。
- `身体朝向`：正面、侧身、背对、转向某人或某物。
- `视线对象`：看向谁、监视器、遥控器、灯或画外的哪个方向。
- `遮挡`：谁挡住谁，门框、肩膀、监视器或其他物件限制了什么信息。
- `关系距离`：人物之间隔着什么，能否直接触碰，谁向谁靠近或退开。
- `入画 / 退出`：新出现的人物原本在哪里，从哪个画框边缘沿哪条世界路径进入；退出时去向哪里。
- `关系变化`：本镜结束时出画、持物、距离、朝向、视线或空间状态与开始相比发生了什么变化。

双人或多人动作段落建立人物指代锚点：每个新动作段第一次出现人物时先写具体名称；同一人物连续行动时才用“她／他”；叙述主体切换、段落重开、遮挡改变或第三人加入时，重新写具体名称。正文不能让一个没有明确先行词的“他／她”承担递交、攻击、受力、看向或退让等承重动作。

不必写“摄影机高1.4米、离圆台2.7米”这类无叙事价值的设备数值；但不能只靠“左前景 / 右后景”假定机位已经成立。方头至少写清摄影机在人物关系轴线哪一侧、朝哪里看，再用构图栏检查画面投影是否与世界站位一致。例如：`【E01-S01-C01｜双人中景｜运镜：固定镜头｜机位：圆台南侧，朝北看向双人横轴｜构图：Luna左前景、老胡右后景，监视器居中｜约5秒】`。POV、过肩、俯拍、仰拍、门口限制视角或反射视角写在机位栏；身体朝向、视线、进入路径和动作后的新状态留在正文。

方头既不能少到让读者进入正文后才发现观看方向，也不能长成完整视频提示词。简单镜头每栏用一个短语；复杂长镜头的机位栏只写起点观看侧，运镜栏写连续方向，构图栏用`起始 → 决定性 → 结束`概括主重构。若观察位置无法从起点连续到达终点，必须新建镜号。

### 固定镜头、人物入画与景别证据边界

`固定镜头`只表示摄影机位置、视轴和构图边界不变，不表示演员不能移动。固定镜头中人物可以进入、退出、转身或靠近，但正文必须选择一种成立方式：

- 人物从开镜起已经可见：在开镜构图中先写明他处于哪个画面层级。
- 人物由画外进入：写明他原本在什么世界位置，从画框哪一侧沿什么路径进入，进入后停在哪里。
- 人物始终不入画：使用 O.S.，只让声音和画内人物反应承担关系。

固定近景先说“主持人的脸占据画面中心”，随后直接说“助手位于画面右后方”，却没有声明助手开镜已在后景、从右侧入画或构图怎样变化，这不是省略，而是空间合同断裂。最小修复通常是保持助手 O.S.，把他的露面放到新双人镜头；只有开镜就设计成可读的双人纵深构图时，才可同镜保留。

景别是证据边界，不是装饰名称：

- 特写 / 近景主要证明单一局部、脸部和有限上半身关系，不能同时证明远处完整空间与全身结果。
- 中景主要证明身体动作、人物距离和局部环境锚点。
- 中远景 / 全景主要证明完整位移、多人拓扑、破坏范围和人物与环境的关系。

同一镜头需要跨尺度时，必须由基础运镜和正文共同证明是一次连续可达的推近、后拉、横移、环绕或焦点迁移；如果新尺度承担独立信息任务，直接新建镜号，不用“近景转全景”把两个观看任务装回一个编号。

### 剧本先定什么，留给下游什么

视频提示词中有一部分能力必须在剧本阶段先形成雏形，因为它们一旦缺失，下游只能改戏或补猜：

| 必须由剧本先定 | 剧本写到什么程度 | 下游怎样补充 |
|---|---|---|
| 镜头原子与观看任务 | 一个主要内容、一项主变化、真实切镜边界 | 按模型能力拆镜 / 并镜，但保留来源映射与剧情事实 |
| 世界—摄影机—画面空间 | 世界站位、观看侧 / 视轴、画面投影、入画退出 | 资产固化锚点；视频补完整摄影机路线、焦点与屏幕变化 |
| 动作与道具因果 | 起点、操作者、接触 / 触发、路径、结果、控制权和镜尾状态 | 资产固化外观结构；视频补动作相位、速度、受力和材质反馈 |
| 人物表演 | 当下目的、准确触发、可见反应、对手反馈和句后状态 | 视频补可执行表演通道、气口、细微时间关系 |
| 声音与必要特效 | 剧情声源 / 触发、特效来源、必须发生的可见可听结果 | 音频与视频补声场、材质、传播、同步和衰减 |
| 光线变化 | 叙事需要的起始光态、触发、人物 / 空间受光变化和结束光态 | 美术与视频补灯光技术、动态传播、材质和成像控制 |
| 相邻镜头交接 | A镜结束状态、B镜第一项新变化、需要继承的动作 / 视线 / 声音 / 光色 / 道具 | 视频选择转场、批次边界、连续性把手和生成实现 |

以下内容不迁入剧本正文：目标模型和入口参数、E-S-B 批次组合、正式三段式、字符预算、实际参考图绑定、GEO运行时切片、完整摄影机路径与速度曲线、焦段 / FOV 数值、VFX与声音工程参数、正向提示词语法以及 VC 提纯。它们属于资产、音频或视频执行层。剧本提供可继承事实，不提前伪装成生成提示词。

符号含义：

```text
△：归属当前镜号的动作、画面关系、反应、声音与必要的可表演心理解释；心理解释不能替代画面证据。
角色名（声源 / 情绪阶段 / 关系目的 / 可听语气）：角色出声台词；每句都写，但普通信息句可以很短。
角色名（O.S.，情绪阶段 / 关系目的 / 可听语气）：角色处于当前场景但不在当前画面内；`O.S.`不能代替表演状态。
角色名（V.O.，情绪阶段 / 关系目的 / 可听语气）：旁白、回忆声、跨时空声音或不作为现场对话的内心声；`V.O.`不能单独成括号。
角色名（内心V.O.）：内心声需要与其他 V.O. 明确区分时使用。
【字幕：内容】：屏幕文字、时间提示、地点提示或需要显示的文字。
【空镜：场景描述】：环境、物件、气氛、时间流逝、转场画面。
闪回 / 闪回结束：明确标注回忆段落的开始和结束。长回忆建议独立场次，短回忆可在当前场次内用闪回。
插入画面：短暂切入的物件、动作、记忆碎片或表情细节；不需要独立成场，但必须建立自己的镜号。
```

语气和神态标注不是给台词加装饰，而是把表演方式写清楚。凡是台词需要靠声音状态理解，例如压低声音、忍着哭、哄孩子、敷衍、急了、吼住、哽住、故作轻松，都应该写进括号。不要每句都硬加括号；只在它会改变表演、情绪或观众理解时使用。

复杂对白、沉默反应、长镜头和情绪转折还要向下游交接关键 `演员节拍`，但不把剧本写成肌肉说明书。编剧先确定：人物此刻想让对方做什么、相信什么、停止什么或想掩盖什么；人物开始时靠什么保护策略维持控制；哪句台词、哪个词、动作、声音、视线或信息真正触发变化；触发前哪些反应不得出现；台词后停在什么状态。剧本正文只写剧情和表演真正需要的动作、语气、停顿与反应，FACS / AU 默认留给 `laohu-video-prompt` 做可选辅助校准，不把编码塞进角色台词或每条动作描述。

错误写法：`她很愤怒，也很悲伤，哭着把整段台词说完。` 这没有目的、触发和先后。正确写法：`她要逼对方承认自己的付出，先用愤怒压住受伤；听到“这不算挣钱”时呼吸停住半拍，后半句眼眶才湿，但说完前不落泪；句尾仍盯着对方等回答。` 下游可以据此继续拆脸部、声音和身体，不需要重新猜情绪曲线。

O.S.、V.O.、字幕、空镜、闪回的分工：

```text
O.S.：同场角色的声音，说话人暂时在画外；它仍是现场对话。
V.O.：旁白、回忆中的旧话重放、跨时空声音或内心声；需区分内心时写`内心V.O.`。
字幕：屏幕上需要显示的时间、地点、章节、手机信息、纸条文字等。
空镜：没有主要人物台词的环境、物件、气氛、时间流逝或转场画面，必须和场景内容紧密相关。
闪回：当前场景触发的回忆；开始写“闪回”，结束写“闪回结束”。
插入镜头：很短的镜头补充，例如手指攥紧、硬币落入碗底、药瓶晃动、旧照片一闪。
```

本节中的“插入镜头”旧称统一按“插入画面”理解：不独立成场，但发生硬切时必须新建镜号。

场次标注规则：

```text
集标题写“第X集”，每场另写 `X-X`；集数、场号和镜号不是同一级。
第二行写“内 / 外  具体地点  日 / 夜 / 晨 / 傍晚 / 雨”等时间与环境。
人物列表使用全名或稳定称呼，全文统一；群众可写“亲戚若干”“村民若干”。
换场、时间跳跃、长闪回或新空间开始时，必须空行并重新标注场次。
短闪回可以在当前场次内用“闪回 / 闪回结束”，长回忆建议独立场次。
```

反例：

```text
镜头从云层中破出，俯瞰九重天宫。群仙让路。
```

正确：

```text
△ 镜头从云层中破出，俯瞰九重天宫。
△ 群仙像潮水一样向两侧分开，向镜头背后的“大人”俯首。
【空镜：银河飞瀑贯穿天地，远处最高仙庭被金白天光笼罩。】
```

镜号使用 `E01-S01-C01`：

- `E` 表示 Episode / 集数。
- `S` 表示 Scene / 当前集内场次。
- `C` 表示 Camera Shot / 当前场次内镜头；进入新场后从 `C01` 重新编号。
- 插入镜头使用 `E01-S01-C05A`、`E01-S01-C05B`，不重排后续编号。
- 同一镜号在剧本内唯一，场内顺序连续；删改镜头后检查下游映射。

进入视频生产单元后，总时长必须依据当次目标模型能力合同写确定值，例如 `12 秒`，不要写 `10-12 秒`。故事设计和普通正式剧本不继承历史模型的固定十五秒上限，也不让旧参数反过来切碎一个完整场景；剧本内部只有在节奏确需锁定时才写明确动作边界。

## 生产型正式剧本

正式交付分成剧本正文与生产证据账本。剧本正文服务阅读、表演和故事事实，证据账本只把会改变下游设计与连续性的承重事实抽出来。

```text
【剧本说明】
用途 / 阅读与继承方式 / 不可擅改事实

【作品信息】
标题 / 类型 / 画幅 / 预计时长 / 集数 / 受众

【故事说明】
一句话故事 / 观众等待 / 人物关系 / 主情绪运动 / 必须继承事实

第1集

1-1
内 / 外  具体地点  日 / 夜 / 晨 / 连续
人物：……
开场状态：人物位置、正在进行的行动和上一场余势

【E01-S01-C01｜全景｜运镜：固定镜头｜机位：祭坛南侧，朝北看向人物｜构图：人物居中，主角画外｜约4秒】
△ 本镜的主观看内容、出画 / 画外人物、世界位置、摄影机观看侧 / 视轴、画面投影、身体朝向、视线对象、关系距离、入画退出和可见可听行动。
角色名（每句必写：声源 / 情绪阶段 / 关系目的 / 可听语气）：台词。
角色名（O.S.，情绪阶段 / 关系目的 / 可听语气）：同场画外台词。
角色名（内心V.O.，情绪阶段 / 关系目的 / 可听语气）：未说出的内心声。
【声音：声源、发生方式和对行动的影响】
【屏幕文字：观众实际看见的内容】
【特效：剧情必须发生的可见结果，不写实现方法】

【场次结果】
人物 / 关系 / 信息 / 道具 / 空间 / 身体状态变化：
留下的未解决状态：
```

正式剧本默认是AI时代的镜头化内容母版：它用镜号、初稿景别、基础运镜、机位 / 视轴、构图、参考时长、镜头原子和空间投影完成文字分镜，但不写焦段数值、摄影器材、无叙事价值的设备坐标，也不把正文重复写成摄影机执行提示词。`laohu-video-prompt` 逐项继承剧本方头，可以按模型能力组成 E-S-B 批次、拆镜、并镜或深化组合运镜，但不是第一次发明谁在画内、谁从哪里入画、摄影机在哪一侧、谁持物、谁朝向谁、动作如何发生和镜头在什么结果上结束。

情绪承重镜同时继承`情绪交接合同`。剧本先确定情绪阶段、关系目的、精确触发、可见泄露、台词策略、句后行动和禁止提前反应；声音与视频只把这些事实深化成呼吸、重音、面部、手部、身体距离和时间相位，不第一次猜人物为何变化。括号只保留短的状态索引，证据写在同镜或紧邻镜的`△`动作与声音中。

动作承重镜同时继承`动作因果交接合同`：

```text
世界能力基线：现实、科幻、玄幻或喜剧物理允许什么；能力来自身体、装备、术法、载具还是环境。
起始条件：双方位置、距离、速度、朝向、承重点、道具与上一镜余势。
战术目的：追上、绕到侧面、封路、逼停、击飞、救人还是改变空间。
发力来源：哪只脚、哪个关节、哪件装甲、哪个支点或哪股能量提供力量。
能力触发：蓄力、点火、结印、踩墙、关节锁止、光线接入或其他可见启动信号。
运动路径：人物、攻击或物体从哪里沿什么方向到哪里；如何取得速度差和攻击角度。
环境交互：墙、地面、碎石、尘雾、衣料、光、空气或结构先后怎样响应。
接触点：谁的什么部位或物体在何处接触谁。
受力结果：受力方向、身体 / 物体变化、材料失效和可见残局。
镜尾把手：结束位置、姿态、装备 / 环境新状态，以及下一镜从什么余势继续。
```

这份合同写进可读的`△`画面，不作为十栏表格贴在每个镜头下。简单动作按需压缩；超常追击、闪现、撞墙、穿楼、机甲变形和大规模特效不能省略取得结果的中间因果。剧本只写读者必须看懂的层级，视频提示词再扩写速度曲线、坑的尺寸、裂纹形态、碎片分组、烟尘传播、光影相位和模型控制；不得倒过来让视频层第一次决定为什么追得上、为什么能命中、为什么会飞出去。

生产证据账本使用：

```text
证据编号：
首次出现和使用位置：
承重对象：人物 / 服装 / 场景 / 道具 / 声音 / 特效 / 屏幕文字。
叙事职责：
出现前状态：
触发动作：
出现后状态：
后续必须保持：
允许下游发挥：
连续性风险：
下游负责人：
```

只记录影响故事理解、人物表演、资产稳定或相邻状态的证据，不把普通陈设和每句台词全部资产化。

声音按职责区分：同期声真实发生并参与行动因果；画外声的声源暂不入画但改变人物或观众信息；主观声属于人物认知、记忆或身体状态；剧情内音乐写声源与影响，非剧情内音乐只写结构职责。`悲伤 BGM`、`紧张音效`没有声源、触发或作用时，不算生产证据。

## 单镜号边界

单镜号的参考时长由表演节拍和完整动作决定；历史十五秒只作旧任务参考，不是通用上限。它必须满足：

- 只有一个主要画面内容和一项主变化；剧情上属于同一段，不等于视觉上属于同一镜。
- 至少有一个可被拍到的开始状态和结束状态。
- 台词、旁白、同期声不能和画面互相抢。
- 情绪变化要能被脸、手、呼吸、视线或身体距离看见。
- 世界位置、摄影机观看侧 / 视轴和画面投影必须同时成立。
- 固定镜头中新人物入画必须有起始位置、画框入口和连续路径；开镜已在画内则先声明。
- 如果出现第二个主要观看重心、新主体的独立反应、插入画面、主客观切换、正反打、硬切或无法连续到达的观看位置，主动新建镜号。

单镜头剧本常见类型：

| 类型 | 适用 |
|---|---|
| 动作起点镜头 | 人物开始移动、伸手、转身、发现异常 |
| 情绪反应镜头 | 角色听到信息后的表情和身体变化 |
| 道具信息镜头 | 关键道具被看见、触碰或揭示 |
| 关系变化镜头 | 两个人靠近、远离、对峙、沉默 |
| 结尾钩子镜头 | 留下悬念、反转或最后一帧记忆点 |
