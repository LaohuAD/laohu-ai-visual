# 剧本语言诊断与反向审稿

当初稿已经形成、需要改稿、诊断、反模型平均化或终稿验收时读取；先修上游结构，再处理局部句子。

## 从现稿反推问题，按根因改稿

已有稿不先按外部模板重写。先从正文提取：谁作了哪项选择、对手实际做了什么、观众何时取得证据、场次如何改变、结尾兑现什么。每项标为已有证据、缺少必要证据或本体裁不需要；作者解释有而镜头没有，不能记作证据齐全；没有反派、成长或中点反转，也不能直接记作缺陷。

输入已经锁定先后或动作触发时，反审先对照输入中的事件次序，再看语言是否流畅：谁先做什么，谁因此回应，物件何时移交，观众何时知道。事件都出现、结尾也相同，仍不代表保真；把“先接受帮助，才说出原因”改成“先说原因，再接受帮助”，会改变人物为什么开口。只调整未锁定的实现，不能用更顺的叙述交换既定因果；确有矛盾才返回内容负责人裁决。

按以下顺序，只修本轮存在的断点：

1. **命题与全片因果**：导演主结果是否被具体选择托住；中段是否只换困难而没改变办法；副线是否改变主线条件或观众对主命题的理解。命题缺口读[前提与主题](../skills/laohu-premise-theme/SKILL.md)，事件因果缺口读[故事结构](../skills/laohu-story-structure/SKILL.md)，导演命题与锁定事实互斥时 RETURN 总导演。
2. **人物与场次**：给对手按自己的目的重新走一遍关键场次。突然答应究竟是被说服、顺势执行原计划还是观众刚知道原因？停滞修条件，跳跃补触发，已经成立的安静预示保留。低烈度作品读 [场面推进与苦难叙事](../skills/laohu-scene-craft/references/场面推进与苦难叙事.md)，不替它制造吵架、死别或和解。
3. **对白与表演**：调用 [对白创作](../skills/laohu-dialogue/SKILL.md)，按完整方法和案例检查策略、对手反应和未说内容；再执行纯对白盲听、现场回放与语言模式整稿覆盖。人物能直说的真实话、知识前提、冻结台词和必要重复优先保护，不为去解释腔一律改成暗示。
4. **生产与接续**：复验E-S场次、正文归属、表演信息、动作资格、道具控制权、世界位置和场尾；按 [镜头化剧本与连续性](../skills/laohu-format-adaptation/references/镜头化剧本与连续性.md) 裁决完整场次与下游边界。内容改动若影响已存在下游，沿原有源依赖与审核关系标记待复验，不自动替下游宣布仍通过。

每个实际问题在既有审稿记录留一行：镜号或段落、原证据、根因、保护项、最小修法、修后变化、需重验的接收者。不新增平行剧本或给老胡增加一套理论表。只改局部就不声称整稿已审；整稿任务逐块作出处理判断，但允许无问题的块原样保留。

反向攻击改稿：如果删掉新增技法名，新稿具体哪一个选择仍更准确？有没有为了演示方法，凭空增加人物、秘密、故障或道具？有没有把挽留改成单纯控制，把对手合理答应改成突然刁难，把开放结尾改成拥抱？出现这些情况，回到同一材料比较；不以“更有戏”覆盖原目标。

流派冲突按当前导演命题和生产合同裁决。固定三幕、页码、卡数、问号数量、人人成长、每场正负翻转、每句潜台词和大事全部画外都不能成为通用验收。方法完整不等于每次全用；实际触发的 Reference 必须能指出改变或确认了哪个决定，未产生增益允许零改动。

## 剧本写作规则

- 每场戏必须有清楚的叙事或情绪功能；目标、阻碍和结果只用于冲突场景，等待、发现、关系距离、时间流逝、观察和余味也可以推进作品。
- 冲突驱动、逆袭、品牌起源和创业故事从对立面、独特个性、代价、黑暗时刻与不可逆选择中选择承重机制；文艺、观察、纪录、治愈和氛围内容不强制这些节点，但必须有观看理由和体验变化。
- 第一桶金 / 创业起源故事必须写清：为什么离开旧世界、在未知世界打败了什么怪兽、第一桶金是新起点还是新深渊。
- 允许必要而简短的可表演的心理解释，用来消除关系、行动或台词含义的歧义；它不能代替画面，同镜或紧邻镜必须给出可见或可听证据和行动后果。
- 台词不能解释主题，台词要像真人说话。
- 每句有声台词必须能追溯到可执行表演信息：可逐句括注，也可在本场开头显式声明角色表演基线、适用镜号或台词范围，以及“未另标者继承本场基线”。情绪、关系目的、可听语气或声源变化处单独标注；跨场不自动继承。声源位置不等于表演状态，O.S. / V.O. 只说明声源，不能代替表演。承重台词再建立完整`情绪交接合同`。只写“生气”“笑”“哭”，或只写“声音放低、句子很短”“笑意开始发虚”，也不足以指导表演。
- 追逐、打斗、变身、破坏、救援、机甲和超常位移必须审查`动作因果交接合同`：世界能力基线、起始条件、战术目的、发力来源、能力触发、运动路径、环境交互、接触点、受力结果和镜尾把手。若人物突然追上、闪现、击飞、撞穿或令建筑坍塌，却没有先取得速度差、支点、蓄力、装备、术法、材料弱点或前一动作余势，这不是“留给提示词发挥”，而是结果没有资格，应退回剧本补因果。
- 心理文字只做诠释，不做证据。例如可以写“她把这次插话理解成又一次不被当回事”，但必须立即让读者看见她停下原本要说的话、收紧遥控器、改变声音或采取新的行动；否则就是作者代替画面下结论。
- 台词必须匹配人物地域、年龄、文化程度和关系口气。用户指定方言时，要写成对应方言气质的可听懂口语；重庆老家、老一辈农村人物优先使用重庆话 / 川渝口语短句，避免书面普通话和主持腔。
- 亲情故事按 [人物行动与连续性](../skills/laohu-character-conflict/references/人物行动与连续性.md)的情感因果链检查人物的愿望、回应和关系后果；已确认离世与遗物时才使用对应链条。温馨段应为后续结果留证据，但不因题材是亲情就添疾病、死亡或规定晚辈有错。
- 已确认的背景刀口必须进入正式剧本，不要只留在索引或故事确认里。例如“主角从小没了妈”会改变奶奶叮嘱的重量，若老胡没有明确删除，就要在合适场景以克制台词或物件反应保留，不展开支线也不能从正文消失。
- 关键道具不能凭空承担关系。若主结果是“有人记住了我的愿望”，审查前置愿望、拒绝 / 缺口、记住和具体回应；若来自共用、争夺、维护或移交，审查相应使用史和控制权变化，不强加礼物或遗物身份。
- 遇到遗像、火光、旧话回响、叩首抬头、季节变化、空屋、遗物等非线性跳切时，先判断它是不是情绪型时间省略，不要直接当成时间线错误修正。正确做法是区分故事现实时间和影像表达时间：故事现实时间可以经过数天、数月或数年，影像表达可以用一个转场压缩。若这种压缩会让观众误会为“马上发生”，剧本要优先用可见变化提示时间：儿童 POV 的主观镜头高度略微变高、衣物尺寸变化、季节 / 房间变化、院落冷清、药瓶或遗物位置变化、声音回忆。必要时再用 `【字幕：一段时间后】`，不要优先靠成年旁白解释。
- 时间省略不一定要完全消灭观众的短暂懵感。若用户想要“先懵一下，再自己懂”，可以用一个镜头切换直接进入遗像、仪式或遗物新状态，再让观众通过视角高度、仪式状态、环境变化和前文声音回响自行拼出时间跨度。只要画面证据足够，短暂懵感是情绪落点，不是必须修掉的逻辑漏洞。
- 亲情遗憾、童年创伤和死亡相关故事，不要轻易把因果写成司法判决。若用户想表达的是“可能是诱因、无人归罪、长大后无法考证的自我怀疑”，应采用弱因果：事实层留下身体原本有病、意外摔倒、无人责怪等可见证据；心理层让疑问埋在角色心里；观众层让成熟观众自己读懂可能性。弱因果不能空口补设定，前半段温馨场景里要轻轻埋证据，例如短促咳嗽、药碗、递药、角色用笑遮过去。不要让角色直接说“都是你害的”，除非用户明确要惩罚叙事。
- 亲人离世、丧葬、遗物、童年回忆类段落可以使用无对白仪式段。无对白不是没内容，而是用叩首、绕行、火光、纸扎燃烧、遗像、遗物和前文台词回声承载情绪。此类段落不要临时补解释性台词；前文已经出现过的遗言、承诺或叮嘱可以作为 VO / 声音回忆在火光或遗物画面中重放。
- 回忆不能悬空插入。童年、亲情和遗物类故事里的回忆，优先由现实中的一句台词、一个物件、一次触碰、一个声音或一个味道触发，再进入朦胧记忆画面。回忆段可以用当前人物 VO、现实声音穿插、画面边缘发白、声音隔水感、光线变软等方式标明它是记忆。不要把回忆单独放在前面当普通场景，否则观众会觉得莫名其妙。
- 片名字幕最好由最后的画面运动引出。尤其亲情遗憾、童年成长、怀旧短片，不要把标题简单贴在最后一帧；优先用物件动作、轻物飘起、镜头拉高、空间揭示或声音回响把片名托出来，让观众感觉片名是这个结尾自然长出的名字。
- 正式短剧剧本必须充分使用格式承载信息。允许已被显式本场基线覆盖的普通`角色名：`台词；覆盖不到或表演变化时使用`角色名（情绪 / 关系目的 / 可听语气）：`。画外或旁白标明`O.S. / V.O.`并继承或补齐表演状态。根据剧情主动使用`【字幕：】`、`【空镜：】`、`闪回 / 闪回结束`。这些标记把表演、声音来源、时间层次和剪辑关系提前写清楚；任何插入画面也必须建立自己的镜号。

动作反向审稿时，先临时删去招式名、发光、烟雾和爆炸，再复述一次：人物凭什么取得速度差，在哪个支点发力，沿什么路线接近，在何处接触，力量把谁推向哪里，环境为何出现这个结果。删去特效后因果就断，说明特效正在遮住动作跳跃。恢复特效时，让它证明蓄力、速度、能量传播、材料响应或结果，不只负责“看起来厉害”。`脚发光 → 人闪一下 → 对手撞墙`不自动构成完整动作；发光要对应能力触发，闪烁要有起点、越距与落点，撞墙要来自可见接触、受力方向和墙体响应。
- 第一人称 / 儿童 POV 剧本必须做视角可行性检查。每个画面细节都要问：这个孩子现在能不能看见、听见、摸到或感到？如果写书包肩带滑下来，要写他低头看见肩带从肩上滑落，或肩膀一沉、书包角蹭到胳膊。不能写儿童 POV 无法直接看到的大人表情、远处事件、房间外完整对话或俯视全景，除非通过门缝、影子、画外音、反射、脚步声、别人反应等方式转译。
- 报丧、噩耗、突发事故类场景必须保护突发性。若剧情需要孩子或观众突然被消息砸中，不要在消息前提前展示白布、灵堂、棺木、哭丧队伍等已经布置完成的结果画面。可以先用日常放学路、普通村民、突然停顿和直白粗糙的台词制造落差，等主角进入现场后再揭示丧葬布置。
- 台词的委婉程度必须匹配说话人身份和戏剧功能。村民、老人、父母、孩子不一定会说文学化委婉话；需要直白冲击时，可以用更糙、更生活的说法，例如“你们爷爷死喽”。不要把所有死亡消息都写成“走了”“离开了”这类书面委婉表达，除非说话人身份和场景确实需要克制。
- 叩首抬头、遗像切换、物件匹配这类转场可以压缩时间和情绪。写法要先给观众一个清晰的前状态，例如爷爷遗像；再用低头、黑暗、遮挡或动作完成转场；抬头后进入新状态，例如奶奶遗像。为了避免误会成同一秒发生，要用主观视角高度、衣服变化、环境状态、仪式细节或声音回忆给出时间已经过去的证据，不靠新台词解释。
- 短视频台词如果太平、太正、太安全，要检查是否能加入狠词怂态度、言不由衷或经典借用。
- 高价值表达位置不能接受第一反应。片名、开场钩子、核心台词、主物象、桥段翻面句、结尾余味句、评论引导和口播金句尚未定案时通常经过 3-5 个可行方向竞争；已锁定表达只比较剩余自由区，并检验实际收益与代价、同题材可替换性、关系准确性、体裁成品性和留白检验。
- 喜剧表达必须来自人物处境和观点反差，不要硬塞段子。
- 谐音误听必须让两种听法都通过现场发音与句法；不近音时可改用其他手法，也可以不写笑点。双重语义、断句换义、对象偷换和字面执行不是配额；同一关系引擎可以跨几个关键节拍递进复现，但必须先说清知识原义，并让每次曲解从不同现场证据长出、改变不同动作后果。禁止机械排班，也禁止因旧稿过量就把人物已经成立的顽皮曲解全部删平。
- 双人或多人动作段落先做人物指代锚点检查：第一次出现人物时先写具体名称；叙述主体切换、段落重开或第三人加入后重新点名。无法唯一回指的“他／她”不能承担递物、攻击、受力、眼线和离场。
- 完整场次先验收情节、行动回应、台词与表演，不以摄影方头或标注时长放行；基础资产后由laohu-video-segmentation划P，摄影与切镜由视频建立C。
- 短视频剧情片要区分正片层和包装层。开场钩子、结尾评论引导、标题解释和账号口播可以存在于包装层；正片人物是否说话、是否解释、是否保持沉浸，仍按正片规则执行。不要把包装层口播混进正片人物关系里。
- 困难与低谷是否消费人物，按 [场面推进与苦难叙事](../skills/laohu-scene-craft/references/场面推进与苦难叙事.md) 的苦难边界裁决；和解、励志只服务对应命题，悲剧与不和解可以成立。
- 短视频、品牌、人物和产品故事必须设计至少一个故事杠杆：大脑墙、痛点杠杆、金句钉、共鸣网或利他金。
- 广告语、口播金句和品牌表达要尽量写成个体宣言，而不是普通正确话。
- 故事、口播、品牌表达不要只证明自己理性正确；要借用感性、可接受的缺点和共同敌人，让观众产生关系感。
- 写人物、品牌或产品时不要只夸优点；优点用于建立价值，缺点用于建立边界、个性和真实感。
- 内容必须有风格边界：明确吸引谁、放弃谁，并设计一个服务主张的轻微跑调点，避免被选择性忽视。
- 关键情绪落到动作、视线、呼吸、手部、距离变化。
- 完整场次先验收情节、行动回应、台词与表演，不以摄影方头或标注时长放行；基础资产后由laohu-video-segmentation划P，摄影与切镜由视频建立C。
- 剧本不是终点，必须能继续拆成可复用资产、画面元素、场景 / 道具需求和镜头任务。

## 对白传播与表演四线校验

当初稿使用外部对标、连续质问、争吵、强情绪口播或高潮台词时，不能只做“是否原创”和“是否讲清”的文字检查；同时检查传播机制、表演口语、台词节拍与连续性三线。

### 构件、期待与场景反审

- 构件只有“倒计时、身份反转、循环、误会”等名称，没有前置条件、人物行动理由和输出状态时，删掉名称，回到人物为何行动。
- 多个高概念轮番出现但互不改变下一状态，属于并排堆叠；不能把信息多、反转多解释为剧情丰富。
- 每个构件各占一场、人物像在演示功能时，寻找同一承重行动能否同时改变关系、信息、物件与下一压力；多个结果争夺主位时拆场或淘汰。
- 钩子只有作者藏信息，观众看不见当下危险、无法形成暂时判断和可预见压力时，不叫悬念。
- 结尾真相若要求否认前文可见事实，或依赖此前不存在的新证据，不能用“意料之外”自辩。
- 每段都反转但没有代价、信息或关系残留时，剧情实际上在反复归零。
- 低烈度作品可以由等待、距离、误解、表演、沉默和物件位置推进，不为连续反转强行堆叠。
- 声音只写`悲伤 BGM / 紧张音效`而没有声源、触发和作用时，无法进入生产交接。
- 正式剧本字段齐全但观众等待、人物选择和状态变化不成立时，格式不能代替因果通过巅峰门。

### 人物声音与漂亮表达反审

- 长期人物已有权威人物资产或老胡亲自确认过的原话时，没有读取同一关系状态的语言样本就写新台词，判为人物声音证据缺失。“温柔、调皮、毒舌”等性格标签不能代替已确认原话。
- 人物只是口头禅、方言词、高频比喻或金句不同，但优先注意的证据、对证据的解释和压力下的行动都一样时，还没有形成人物声音。
- 职业判断超出常识、又没有前史、训练或当场证据时，删除“他很专业”的免责解释，把判断降到可信的概率或补足证据。
- 一段连续使用多个彼此无关的漂亮比喻时，找出人物当下唯一矛盾和他最熟悉的词语领域；保留一组能换义和回收的词，其余句子恢复普通语言。
- 所有人物都使用同样的句长、比喻密度、价值判断和完整人生总结时，判定为全员作者腔；回到每个人能看见什么、想改变谁和不愿承认什么。
- 删掉漂亮独白后，人物选择和场次状态不变，这段只是风格层；可以作为文学样章或包装文案，不能冒充剧情推进。
- 第一人称内心语言中途变成第三人称作者说明，或人物得出只有作者知道的结论时，分别按视角漂移和上帝视角操纵处理。
- OS / VO只把画面事实再说一遍，没有补充、对位或反差时，优先删去声音，不用“文学性”保留重复信息。
- 一句单看像俏皮话，但它反击的迟疑、心虚、失误或动作在正文中没有发生，判为悬空机灵。不用作者解释补这个前提；补可见事实，或把反应改成人物真的接到的东西。
- 两人连续用同样工整的对偶、类比、概念翻转和总结句对攻，判为作者腹语。重新分配“谁负责承接现实、谁负责偏离”，用改口、半句、沉默、动作和空间后果代替一部分俏皮话。
- 教学喜剧中，如果观众需要先理解作者设计的语言机关，才能听懂本拍的知识或人物为何动手，判为喜剧侵入教学。先恢复可直接识别的知识证据，再检查喜剧是否仍能从关系和后果中成立。
- 情绪承重句的括号若只有音量、语速、句长、笑意或抽象情绪名，先问人物正在压住什么、想让对方做什么、被哪个精确事实击中；答不出来就返回人物与场面因果，不让视频提示词猜心理。
- 拿掉括号后，紧邻镜头若看不见呼吸、目光、脸、手、重心、距离、声线或动作选择中的任何证据，说明情绪只存在于作者说明。反过来，动作已经证明情绪时，括号只负责消除“为何这样做”的关键歧义，不重复描述表面动作。
- 已确认的词语曲解若在下一动作或切镜后变成普通招式名，使用`语言机关兑现合同`追回已确认原词、人物故意换义、下一动作、动作结果和跨镜头保留项；笑点不能只活在上一句台词里。

### 纯对白盲听与现场回放

对白初稿完成后做两遍反审：第一遍删掉动作、括号情绪和作者说明，只按说话顺序朗读；第二遍恢复现场事实、人物目标和动作后果回放。

```text
纯对白盲听：每句能否从前一句自然接上；哪句需要作者在旁边解释才好笑；哪句只是金句不是反应。
现场回放：每句开口前的可见事实是什么；它想改变谁；说完后人、关系、动作或观众理解有没有变。
```

机械检查只能证明镜号、字段、台词归属和必要锨点存在，不得把结构测试通过写成“台词像人”或“笑点通过”。这两项至少需要独立朗读、未参与写作者的判断或真实观众反应，当前执行者只能记为 `OBSERVE`。

### 传播机制保护

先拆对标真正承重的关系动力：一方连续压制、双方抢话、一问一答、沉默对抗，还是轮流陈述。观众能理解双方，不等于双方必须平均分配台词。沉默方的处境可以由开口失败、表情、疲惫、手机通知、工牌、孩子哭声、空间退路和最后选择提供证据。

新增一句对白前问：原场面谁掌握说话权，这种不对称怎样制造压力，新句是否带来不可替代的新事实、关系翻转或节奏升级。只为“更平衡、更完整、证明作者没偏袒”而增加的自辩，若切断原有攻击链，删除。

### 表演口语优先与安全化漂移

台词先放回人物当下的呼吸、语速、重音和攻击 / 防御目标，再检查书面准确。爆发中的绝对化可以是人物主观真实，只要作品保留客观反证；关键事实、法律责任、产品声称和时间线仍须准确。

改写后扫描：是否把短词换成长词、口语换成书面语、攻击换成思考、失控换成完整顺滑、关系后果换成主题总结。变化削弱情绪且没有剧情触发时，退回人物状态，不以“更克制、更原创”自辩。情绪承重句还要朗读句尾，检查最后一口气能否完成爆发、冷断、压抑或威胁收紧。

### 台词节拍与高潮压缩

逐段标记 `建立 / 升级 / 高潮 / 余波`：建立交事实，升级用生活证据和关系动作加压，高潮把前文压成最短的一击，余波交给沉默、动作、声场和对方反应。高潮位置突然补背景、限定条件或解释劳动机制，通常会泄力；但不能为了短而删掉真正决定关系后果的词。

### 核心词、道具状态与空间压力

三条线一起验收：

```text
核心词复现：片名词、质问、誓言或动作词怎样首次出现、升级、翻转和回收；不按普通同义词随意替换。
道具状态链：持有者、位置、朝向、接触者、运动路径、落点、损坏和下一动作入口是否连续。
空间压力链：距离、朝向、退路、障碍、站坐高差和声音来源怎样服务同一关系压力。
```

一句对白可以独立成立，却因替换核心词破坏全片回声；一个动作可以很有力，却因道具仍在错误的人手里变成穿帮；一组正反打可以都好看，却因人物距离和退路失真失去关系压力。三线任一断裂，不能只润色句子放行。

若核心词本身已经成为动作指令，再加一条逐镜检查：上一镜建立的词义是否在下一镜的台词、发力方向和动作结果里继续成立。下一镜不得退回普通招式名；切镜不是忘词许可。

## 反例黑名单

- 不要只写世界观介绍而没有任何观看任务、关系、压力、发现、变化或观察价值；冲突故事再检查目标、阻力和代价。
- 不要用只有赞美和道理的内容冒充正能量；田园、治愈和温柔内容可以成立，但要有具体人物行动、关系变化、观察发现或情绪余味。
- 不要让主角、品牌或产品面面俱到；面面俱到会变成摇摆人，故事个性会消失。
- 当作品选择黑暗时刻作为承重机制时，不要把它写成轻微麻烦；它应逼出重生、逆袭、黑化、牺牲或不可逆选择。未选择该机制的体裁不强制黑暗时刻。
- 不要把第一桶金写成成功流水账；没有离开旧世界、没有怪兽、没有归来后的代价，就不是有感染力的起源故事。
- 不要把“恢宏”“震撼”“仙气”当成剧情动作。
- 不要在剧本里写摄影机拍不到的心理解释。
- 不要让台词替作者解释主题。
- 不要把类型腔当人物声音；一个黑帮人物、一个杀手或一个侦探说得像经典电影，不能证明这句话只属于当前这个人。
- 不要让一段氛围、危机解释或人生感慨占据整场，却没有人物根据刚才感知到的证据采取行动。
- 不要把已确认设定改丢。没有被老胡明确拒绝的内容，不能因为改稿更顺、对白更短、节奏更快就从正式剧本里消失。
- 不要把农村老人、父母、孩子写成书面普通话朗读腔；不要用“你以后要照顾好自己、保持良好习惯”这类正确但不像真人说的话替代生活口语。
- 不要把所有台词都写成 `角色名：台词`。该标注语气、神态、OS、VO、字幕、空镜、闪回、插入镜头时必须标注；否则下游不知道这句话是压低声音、忍着哭、内心声、画外声，还是回忆里的旧话。
- 不要把亲情故事写成与关系无关的温馨合集；用当前命题下的共同生活、误解、回应、选择或距离变化组织，不拿遗物回收当所有亲情的完成条件。
- 不要让亲情道具凭空承担情绪；它如何进入生活、被谁使用与关照、后来怎样改变意义必须可见，具体链条由当前关系决定。
- 不要把回忆写成没有触发点的独立场景。回忆要服务当下情绪揭示，最好由现实台词、物件、触碰、声音或气味触发，并通过画面质感和 VO 让观众知道这是记忆。
- 不要把片名当作最后一行文字硬贴到静态画面后。能用最后一个动作、环境运动、镜头拉高或空间揭示引出片名时，必须让片名从画面里长出来。
- 不要让第一人称 POV 偷偷变成第三人称旁观镜头。儿童 POV 看不到的完整对话、远处布置、大人背后的表情和全景信息，要改成门缝、影子、画外音、反射、身体感觉或他人的反应。
- 不要在突发报丧前提前露出白布、灵堂、棺木等结果画面；这会削弱消息的突然性，并制造“既然已经布置好了，为什么孩子才知道”的逻辑问题。
- 不要把农村村民、老人和低文化人物的关键消息统一写成书面委婉话。需要冲击时，台词该直就直、该糙就糙。
- 不要把喜剧写成纯耍嘴皮；没有处境、反差和观点，笑点会变成噪声。
- 不要把两个不近音的词硬说成谐音，也不要让同一角色连续靠“没听清”发动动作；观众听不出第二种可能时，那不是误会，只是作者强行改词。
- 不要在多人动作段一上来就写“他递给他”“她看着她”，也不要让代词跨过主体切换继续指人；先用具体人物名建立唯一指向。
- 不要把方头里的基础运镜、机位 / 视轴和开镜构图逐句重复到正文；正文写观众看见的连续事件和人物状态，视频提示词再负责编译摄影机精确路径。
- 不要为了流量制造无底线冒犯；争议必须服务观点、人物或故事。
- 不要全做浅内容；长期账号必须有能留下铁粉的深内容。
- 不要只堆苦难索取同情；检查人物处境与后果是否可信，不把没有和解或成长本身当成人物失真。
- 不要把低谷写成堆伤口；黑暗时刻要逼出选择，不是逼观众同情。
- 不要只讲正确观点，没有金句、没有共鸣关系、没有观众收益。
- 不要制造虚假焦虑。痛点必须基于真实损失、真实风险或真实难受，并且给出行动出口。
- 不要把利他写成讨好；利他必须提供真实价值，不是无原则迎合。
- 不要只复述共识。金句要从共识里挖偏见、立场、反常识和个体宣言。
- 不要把“借用偏见”写成歧视、污名或恶意标签；它只能指真实偏好、隐秘不满和未被说透的立场。
- 不要把“借用缺点”写成羞辱、恶意攻击或廉价自黑；缺点必须能转化成个性、关系、共同敌人或成长动力。
- 不要只突出优点、只做赞美、只讲正确逻辑；这种内容容易变成正确废话，缺少亲密感和传播钩子。
- 不要为了讨好所有人而磨平风格；平滑顺和、无选择、无摩擦的词和观点容易被观众选择性忽视。
- 不要把跑调点写成无意义猎奇；它必须服务主张、人物、故事或品牌边界。
- 不要把 45 秒短片写成需要多集才能讲清的复杂设定。
- 不要让 POV 视角变成普通旁观镜头；必须有被引导、被邀请或穿越的身体感。
- 不要把一次性路人和一次性奇观写成必须长期复用的资产。

### 语言模式接口

编剧拥有剧本内容，`laohu-language-mode`只帮助编剧把不同文本块写成它们本来该有的样子。调用不转移主责。正式剧本按块切换：镜头方头用`SCRIPT_HEADER`定位观看条件，`△`正文用`SCRIPT_ACTION`写可见可听的连续事件，台词前括号用`PERFORMANCE_CUE`锁定情绪阶段、压制或释放、可听语气和关系动作，人物原话用`CHARACTER_DIALOGUE`完成当场行动，非镜头事件才进入`SCRIPT_NOTE`。

每句有声台词必须能追溯到可执行表演信息：可逐句括注，也可在本场开头显式声明角色表演基线、适用镜号或台词范围，以及“未另标者继承本场基线”。情绪、关系目的、可听语气或声源变化处单独标注；跨场不自动继承。声源位置不等于表演状态，O.S. / V.O. 只说明声源，不能代替表演。括号不能冒充人物台词，作者解释不能混入动作正文，知识说明不能把人物说话写成知识卡。返工某一块时保护已确认镜号、因果、空间、动作结果和冻结台词；内容不足或块间事实冲突时停止改写并返回原负责人，而不是为了自然顺口擅自补戏。

正式剧本初稿完成后调用语言模式的[有效信息与冗余裁决](../../laohu-language-mode/references/05_有效信息与冗余裁决.md)。先过必要信息保护门：教学知识、人物关系、动作因果、空间连续、镜尾把手和冻结台词不能因追求短而丢失；再过边际作用门：每轮台词至少改变关系、行动、压力、误会、笑点、必要理解或节奏之一，动作分句则必须推进触发、路径、交互、结果或承接。零边际内容由编剧决定合并、迁移或删除；缺的是人物动机、知识、动作资格或场面因果时返回原负责人，语言模式不得代写。

若要求修整份剧本，编剧还必须过语言模式的整稿覆盖门：对实际出现的方头、动作、表演括注、人物台词、剧本注释和生产说明分别作出块级处理回执。不能只改台词就宣布整稿完成，也不能把“保留原样”当成“没有审过”。

### 剧本巅峰门

可拍、可生成、因果无误只是底线。正式剧本还要证明它不是同题材的平均答案：

```text
主胜负手：观众最终会因哪一个人物选择、关系变化、认知翻转或情绪余波记住它。
候选竞争：尚未锁定的关键冲突、阈值选择、高潮或结尾是否比较过有效对手（开放方向通常三案）；已经锁定的只比较剩余实现，不能改事实凑数。
不可替代：把人物名、行业名和表面设定换掉后，核心场面是否仍像公共模板。
兑现强度：开头许下的等待，是否由后续更强的选择、代价和结果偿还。
顶尖校准：同类成熟作品最强处靠什么成立，本稿学到的是机制还是只借了表面。
下游潜力：资产、镜头、表演和声音是否得到足以继续升级的关系，而不是只得到完整情节。
```

人物选择没有更痛也更准确的替代、高潮没有比铺垫更高一层、结尾只把事情讲完却没有留下关系余波时，剧本不得因为格式完整而交接。极致不是强行反转、放大苦难或句句金句；真正的强度来自所有场次把压力推向同一个无法逃避的选择。

## 整稿交接复验

- 能否一句话说清观众在等什么。
- 每个关键节点是否由人物选择或行动推动，而不是作者解释、巧合或主题要求。
- 人物的即时目的、台词、动作和关键物件是否共享一条因果；表面矛盾是否由两难、伪装、犹豫或失控证明，而非无意打架。
- 每场是否改变关系、信息、道具、空间、身体或下一步可能性。
- 人物是否只说他知道、想说、能说出口的话。
- 台词是否有对象和后果，关键句是否通过可替换性与朗读检验。
- 人物声音是否先改变他注意和解释证据的方式；口头禅、方言、比喻和金句是否只在替作者炫技。
- OS / VO是否与画面形成补充 / 对位 / 反差，而不同义复述画面；删掉漂亮独白后，人物选择和场次状态是否仍不变。
- 抽象主题是否已有可拍证据，材料是否真的承担关系，而不是为了具体而具体。
- 文戏是否有关系压力，武戏是否有力量来源、路径、接触和结果。
- 相邻单元是否状态相等，B 是否从下一相位开始。
- 已确认事实是否完整保留，新增创意是否标明。
