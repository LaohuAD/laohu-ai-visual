# 场面推进与苦难叙事

### 6. 场景写作

每场戏写成可拍内容：

```text
场次：
地点 / 时间：
场景目标：
阻碍：
结果：
可视化重点：
声音重点：
进入点：
离开点：
```

场景不能只做无目的信息搬运。每场戏必须有清楚的叙事或情绪功能：冲突场景可以用目标、阻碍和结果；文艺、观察、治愈或氛围场景可以用等待、发现、关系距离、时间流逝、表演累积、空间变化或余味推进，不强制微型冲突。

#### 场景选择与低烈度推进

先在内部试演当前场景：谁以为这次行动会得到什么；对方怎样回应；实际结果与预期哪里不同；哪一刻使原来的策略无法照用。找不到转折时，区分“确实无作用”和“转折发生在观众理解里”。价值可以由信任变成怀疑，也可以仍在关照却越来越不能靠近，不要求每场从正面翻成负面，更不把每句台词或每个镜号当一场独立戏。

进入与退出按作用裁剪：进入前的寒暄、行路和家务若没有建立关系或行动条件，可以晚进；主要结果已经兑现，剩余台词只解释意义，可以早出。但开口触发、取物路径、知识前提、最后一次反应和镜尾接续不能被“掐头去尾”删掉。交接仍用现有场次结果与相邻单元，不增加一套场景卡。

场面有内容却平淡时，先在已确认地点和对象内比较：人物只是坐着讲，还是同一件必须完成的劳动使他不能随便走开、不能同时说完、不得不把东西交给对方？把关系放进动作的收益应可见。新地点能改变公共目光、隐私、进出资格或对方的优势时可以提为候选，但既有场景已锁定就不能为“场景更戏剧化”搬家；空间设计缺口再 CONSULT 场景负责人。

低烈度与群像按实际缺口选一种主机制，其余从属：

| 触发 | 具体做法与作用 | 失效与边界 |
|---|---|---|
| 重复吃饭、收工、取物显得相同 | 先建立一次日常程序，再在已有重复里改变发起者、回应、空位、距离或物件去向；观众用熟悉的旧状态察觉关系变化 | 不为套法新增三次重复；没有既往状态就不能声称缺席很有意义 |
| 两个人都关心对方，谈话仍停在轮流表态 | 让一人的邀请恰好遇上另一人的回避、劳动或错误理解；同一句普通话分别承担不同目的，回复改变一项小行动 | 不能靠双方无理由听不懂拖戏；至少一处反应证明谁接住了什么、错过什么 |
| 群像像轮流接受采访 | 给各人独立且同时发生的当下追求，选择一个相遇点使其互相打断、借用或错失；主场面仍有唯一承重结果 | 不平均分配台词，不为了“多线”新增角色；共同主题不等于人人同一句态度 |
| 大事全拍显得煽情或成本不符 | 比较事件本身与事后反应哪个承重；若选择省略，先建立它将发生或可能发生的依据，再给出足以识别新状态的结果与延续行动 | 作者必须知道发生过什么、谁知情、时间跨了多少；歧义只留在允许的意义层。空间和因果缺失不能包装成留白 |
| 空镜和声响只是悲伤装饰 | 先确定可听来源及日常意义，再让声响继续、停止、错位或无人回应，使人的变化相对稳定环境被听见 | 不搬用名作的标志性声音组合，不用“忧伤BGM”代替剧情声源；音频负责人深化声场，不补编剧事实 |
| 结尾事情结束，情绪也立即消失 | 让前面建立的日常动作继续，但执行的人、接受者或物件去向已改变；观众看见结果将怎样进入后面的生活 | 不强迫最后一镜上升、独白或象征物；原结尾锁定时只在其内部实现 |

原创例：已确认两位合租者曾一起吃饭，现在一人搬走。先前收碗时，一人伸手，另一人会把自己的碗递过来；后来仍在同一张桌前，留下的人顺手伸向对面的空位，随后收回手，把自己的碗端走。变化落在曾经有人接续、现在无人接续的动作上，不需宣布孤独。若剧本从未建立递碗习惯，就先给依据，或换已有证据支持的动作；不要凭“空椅子很有意境”强塞一个空镜。

上述方法由外部日、韩、法编剧访谈及契诃夫、小津案例整理启发，已转成项目自己的条件方法；出处与逐项差异见 `00_资料来源与专业校准.md`。它们不规定四幕、固定“嗯”的次数、所有大事画外或取消对手，也不改变 E-S-C 镜头化母版。无叙事任务的 MV 仍由 MV 导演依音乐组织，不能为使用此表补一条人物故事。

### 8. 苦难叙事边界

人物、创业、品牌、成长类故事可以写困难、低谷、被误解和黑暗时刻。先检查作品是在呈现人的处境与选择，还是反复堆伤口索要同情；悲伤、失败和不和解的结尾本身不是卖惨。

导演命题已经确定为修复关系或成长时，可选择以下出口：

```text
和解：主角理解过去、放下怨气、修复关系、接受现实或重新定义自己。
励志：主角把困难转成行动、能力、选择、反击、成长或新秩序。
```

写作判断：

```text
人可以惨，但不能卖惨。
困难必须与处境、关系、行动或可见后果发生联系，不能只增加同情强度。
苦难细节要真实克制，不要堆眼泪、堆伤口、堆可怜。
是否伤害信任应由真实阅读和发布反馈校准，不把猜测的平台分发机制当事实。
```

如果故事只有“我很惨，所以你应该同情我”，返回补人物的具体处境、选择和后果。悲剧、观察或开放命题可以没有胜利与和解，但观众必须看见关系为何到了这里、什么仍未解决、什么已经无法恢复；不能为了正向出口篡改真实事实或已确认结尾。

### 动机、行动与物件

人物每个承重动作都要回答：他当下想改变谁或什么，为什么选择这个动作和这件物品，动作带来什么即时结果。台词与动作可以同向，也可以因为两难、伪装、犹豫或失控而表面相反；但相反必须由前后目的、精确触发和关系后果共同证明。没有这条因果却让人物说一套做一套，不是潜台词，是剧本错误。

关键物件按控制权写进场次：它起初在谁手里、谁把它放到谁面前、谁能拿走、谁越过阻拦重新取得、最后停在哪里。物件一旦改变人物选择、身体代价或关系权力，就不能只写成场景名词；下游必须能从剧本知道它的叙事职责和动作结果。普通陈设仍留给资产与分镜，不把剧本写成物品清单。

### 局部样例也必须闭合微场次

语气样例、开场试写、局部对白和单个节拍可以省略与当前关系无关的背景和制作细节，不能省略使当前关系成立的因果。交付前至少能从正文看出：谁拥有或操控关键物件；谁先做什么；哪项可见或可听证据触发另一人开口或打断；被打断的话具体尚未完成什么信息或行动；说完后控制权、距离、信息或下一步发生什么变化。

“我还没说完”“你又来”“等一下”等依赖前文的句子，只有观众能准确追回它所指的未完成内容时才能保留；追回不了就补足前一动作或话头，或改成在现场能独立成立的具体反应。样例不是提纲：若删去动作主体、道具位置或开口触发后会出现两个合理但冲突的解释，就继续写到只剩一个主要因果。

### 场次压力

每场戏都要完成一次状态变化：

```text
进入：人物带着什么目标和前一场余势进入。
施压：谁或什么阻止他，压力怎样升级。
选择：人物采取什么行动，不采取什么行动。
结果：关系、信息、道具、空间或身体发生什么变化。
牵引：哪个未解决状态形成下一场压力。
```

场次可以外部安静，但内部不能停止变化。文艺、观察和氛围作品可以靠等待、距离、误解和表演推进，不为套公式强造争吵、反转或爆炸。

### 文戏与武戏

文戏的动作单位是关系变化。台词要有目的并造成后果：试探、求救、保护、拒绝、压制、邀请、切断、告别或挽留。高潮台词不替作者总结主题；没有说完的话由表情、动作、物件、空间和另一个人的反应承接。

武戏的动作单位是力量关系变化。剧本至少交代力量从哪里来、向哪里去、谁被迫选择、接触造成什么结果、余势怎样进入下一动作。凡追逐、打斗、变身、破坏、救援、机甲或超常位移承重，先完成`动作因果交接合同`：世界能力基线、起始条件、战术目的、发力来源、能力触发、运动路径、环境交互、接触点、受力结果和镜尾把手。人物若能追上、闪现、击飞或撞穿，必须先用速度差、支点、蓄力、装备、术法、材料弱点或前一招余势取得这个结果；不能只写目标忽然出现在攻击范围内。剧本须确认基本观看侧、机位与视轴；焦段、器材和摄影机精确执行参数由后续专业深化，但不能把“激烈打斗、翻身下马、大楼爆炸”当作完整因果。

动作合同按完整动作单元闭合，不要求每个简单动作句机械填十个字段。一个眼神、坐下或普通走路可以一句完成；一项超常攻击可以跨相邻镜号分别展示蓄势、位移、接触和结果，但每一镜都要继承上一镜状态，并只承担一个主要画面内容。分工原则是：`剧本锁因果，提示词扩颗粒`。剧本锁定为什么发生、怎样发生和发生后改变什么；视频提示词只能深化速度、相位、碎片尺度、烟尘层次、材质响应、光影传播和模型控制，不能第一次补造人物获得结果的资格。
