# 老胡封面与海报设计

## 能力定位

把已经成立的作品、视频、短剧、广告或账号选题，转译成观众一眼能认出、愿意点击、点击后不觉得被骗的发布主视觉。

本 Skill 负责：

- 自媒体视频封面与缩略图。
- 电影感自媒体带字封面。
- 短剧、短片、概念片主题海报。
- 系列化封面系统和多平台比例适配。
- 标题与画面的层级、位置、颜色、字重、遮挡和安全区。
- 日常默认只交付一条直接带字、可复制的完整封面生图提示词；概念竞争、标题判断、排版推导和质量门在内部完成，不默认展示成设计报告。
- 封面发布前质量门与生成后复盘交接。

本项目默认只生产文本。这里的“生成封面”是编写一条可直接投喂图片模型的封面生图提示词；除非老胡明确要求调用图片工具，否则不直接创建图片文件。

## 能力边界

- `laohu_script_writer` 提供故事冲突、观众承诺、作品正式片名和剧情承重文案。没有最终封面标题时，本 Skill 必须先根据已确认内容生成并筛选封面展示标题候选；只有标题问题暴露出故事定位、事实或立场本身尚未成立时，才退回编剧重写。
- `laohu_visual_assets` 提供人物、场景、道具、Logo、色卡和经过验收的干净参考图；它不再负责最终封面策略和排版。
- `laohu_cover_design` 决定封面承诺、主符号、画面关系、标题层级和平台适配。
- `laohu_generation_review` 检查实际缩略图、封面成品、点击表现和承诺兑现，并把问题送回对应模块。
- 封面不是分镜拼贴，也不是从成片随便截一帧加大字。只有真实成片截图恰好通过封面质量门时才可采用。

## 默认触发时机

日常封面属于后置发布流程。满足以下任一条件时默认触发：作品和视频提示词已经完成，老胡说准备发布、项目完结、已经发布并要求补封面，或者直接要求为某个已完成作品创作封面。只有老胡明确提出概念海报、前期提案主视觉或先用封面反推创意时，才在剧本或视频完成前提前执行。

不能为了尽早填满作品目录，在故事、角色和最终画面尚未成立时机械生成正式发布封面。后置执行的价值是：封面可以从成片真实兑现的冲突、人物状态和视觉资产中选最强传播承诺，避免封面比正片多承诺或与成片长相冲突。

## 开始前读取

按以下优先级读取可用结果，越靠前越接近最终观众实际会看到的内容：

1. `AGENTS.md`
2. `02_共享资产库/00_核心规则手册.md`
3. 当前作品最终版一体化视频执行单、全部最终视频提示词与发布定位
4. 最终成片、老胡回传的成片截图或明确选定的封面候选帧
5. 已确认的人物、产品、场景、道具、色卡与固定 Logo 资产
6. 正式剧本、故事确认、分镜与故事板，用于校验事实、关系和结局
7. `02_共享资产库/01_模板库/图片模板/模板_封面海报创作执行单.md`
8. `02_共享资产库/02_视觉语言资产/高质量创作特征资产库/高质量AI图片开发计划.md`

参考内容用于封面时的事实与身份优先级通常是：`最终成片截图 > 已确认人物 / 产品资产 > 场景 / 道具 / 色卡 > 分镜 / 故事板`。这不是要求每次都引用成片截图，而是发生冲突时服从更接近最终结果的证据；某张成片截图构图普通时，可以只用它锁人物、服装和状态，再重新设计更有点击力的封面镜头。

不要为了做封面重新发明与成片冲突的人物、服装、道具、时代、地点、Logo 或结局。上游缺少封面所需的干净人物 / 场景 / 道具参考时，回到 `laohu_visual_assets` 补资产。缺少封面展示标题时，本 Skill 根据已完成作品自主生成并筛选；只有标题问题暴露出故事定位、事实或立场本身尚未成立时，才回到 `laohu_script_writer`。不能用模糊文字掩盖上游缺口。

## 能力加厚纪律

封面规则固定的是判断顺序和质量门，不固定综合色、字体、服装、构图和装饰。先从当次内容的真实冲突、受众欲望、点击承诺和可用资产推导视觉方案，再选择能让观众停住的一帧；历史模板只在它仍适合本题时作为案例资产调用。不得为了填满执行单而加入不服务标题、主体或情绪的元素。

## 四、输入判断

先建立最小封面简报：

```text
作品与发布平台：
封面类型：自媒体缩略图 / 电影感带字封面 / 主题海报 / 系列封面 / 宣传主图
发布目的：点击 / 识别 / 追更 / 转化 / 收藏 / 发行感
目标观众：
点击后真正能看到的内容：
观众此刻最关心的一个问题、欲望或冲突：
不能误导的事实：
已有标题、人物、场景、道具、Logo、色卡与成片截图：
标题状态：逐字锁定 / 允许优化 / 需要生成
目标比例与扩展比例：
```

信息可以从作品文件可靠推断时直接补全；只有互斥方向会改变发布定位、标题立场或真实成本时才询问老胡。

老胡提供主标题或副标题时，默认视为 `逐字锁定`：不润色、不缩写、不换同义词、不补写新的副标题。只有老胡明确说“可以优化”“给我候选”或“标题还没定”时，才进入标题竞争。内部简报用于决策，不进入日常交付正文。

### 4.1 两种工作模式

先判断是 `内容原生设计` 还是 `系列模板续作`：

```text
内容原生设计：默认路线。根据当次内容承诺、标题、受众、参考资产和情绪重新设计画面，不预设暖杏色、黄白字、描边、复古服装、手绘刷痕或固定版式。
系列模板续作：只有老胡明确说沿用某套模板、只换标题，或该系列已经形成需要保持的稳定识别时使用。继承已经验证的图文机制，只替换明确开放的槽位。
```

系列模板续作不能为了“每次都创新”破坏已经稳定的识别系统；内容原生设计也不能为了显得高级而忽略老胡已有成功经验。用户给出的暖杏手绘模板是一个经过使用的案例资产，不是跨作品标准；只有它的情绪、受众和标题任务与当次内容相符时才调用。

### 4.2 参考图调用

带参考图是封面的常见输入。正式提示词开头使用显性占位符并限定职责：

```text
【封面主体参考@用户上传图片01】用于固定人物身份、脸、体态和主体内容。
【成片截图参考@VID01 最终封面候选帧】用于固定正片已经兑现的人物造型、剧情状态和环境事实；允许重新设计封面构图。
【构图参考@用户上传图片02】只用于参考图文层级和视线组织，不复制人物、标题和具体版式。
【风格参考@用户上传图片03】只用于参考暖杏哑光底色、手绘刷痕材质或综合色关系。
【Logo参考@老胡Logo】用于调用固定 Logo 图片。
```

只写实际上传或已存在的参考。所有被调用的 `【……参考@……】` 必须直接写在最终模型提示词代码块中，并在同一句限定职责，不能只在代码块外列资产表。没有使用参考资产时，不强行添加空占位符。不能裸写 `使用这个图片`、`参考上图` 或只放一个 `@` 不说明用途；也不能让一张人物图同时无意锁死服装、背景、构图和标题。

## 五、封面承诺

封面先回答“观众为什么停下并点击”，再回答“它有多电影感”。建立四项：

```text
内容事实：点击后作品真正提供什么。
点击钩子：哪一个冲突、欲望、异常、身份或结果最值得先看。
主视觉符号：什么单一画面关系能把钩子变成视觉记忆。
标题任务：文字补充画面无法独自说明的哪一层信息。
```

封面允许悬念和立场压缩，不允许虚构成片没有的怪物、明星、关系、结果、金额、性能或冲突。标题与画面不能重复说同一句话：画面已经清楚展示“妻子把丈夫逼到墙角”，标题应命名争议或观看问题，而不是再写“妻子把丈夫逼到墙角”。

## 六、概念竞争

进入内容原生设计时，高价值封面不能接受第一反应，内部先生成 3-5 个机制真正不同的方案。系列模板续作只检查标题、主体、引导动作和当前内容是否仍匹配，不为形式完整强制改版。内容原生设计的每案至少改变以下两项：

- 观众站在事件内部、对手位置、旁观位置、监视位置还是结果之后。
- 人物与空间的压力关系。
- 主视觉符号。
- 画面进入点、阻断点、落点和余韵出口。
- 标题与人物、道具、空间之间的关系。
- 主色来源与唯一强调色。

不是把同一张“大脸 + 背景 + 发光标题”换颜色，也不是远景、中景、近景轮流交差。每个方案用一句话说明：`观众先看到什么 → 被什么挡住或加速 → 落到什么决定性信息 → 为什么会想点开`。

按以下顺序筛选：

1. 是否兑现作品最强观看承诺。
2. 1 秒内是否能读出主体和冲突。
3. 缩小到手机缩略图后，轮廓和标题是否仍成立。
4. 是否具有本作品专属符号，而不是同题材可替换模板。
5. 是否能由现有资产或原创提示词稳定生成。
6. 是否有足够文字安全区和多比例裁切空间。

## 七、画面设计

### 7.0 把封面当成传播型视觉资产

封面沿用视觉资产的设计思维：先明确它服务什么作品、面向谁、调用哪些人物 / 产品 / 场景 / Logo / 截图参考、哪些身份必须锁定、哪些画面关系允许重新创作，再形成一条完整图片提示词。但封面不只是稳定身份的制作参考，它是观众最终看到的传播画面，必须在缩略图尺寸内主动组织注意力和情绪。

每次按以下因果链推导，不从固定版式或题材词库开始：

```text
内容最强承诺与观众欲望
→ 标题承担的点击任务与准确原文
→ 标题是第一落点还是与人物 / 产品共同第一落点
→ 什么人物姿势、表情、视线、手势、产品状态或环境事件最能把注意力送到标题
→ 什么构图对比、尺度冲突、明暗分离、色彩反差、形状方向或留白能放大情绪
→ 引用资产分别锁什么、允许改变什么
→ 用一条比例自适应提示词编译成最终可见画面
```

它像设计一个作品里最值得停住的镜头：人物可以摆 Pose，但姿势必须有传播任务；环境可以简化，但不能只是空底；特效和装饰可以出现，但必须加强标题或核心情绪。一般自媒体封面让标题承担最强视觉焦点，人物、环境和装饰为标题引流；人物 IP、产品识别或强情节封面可以让主体与标题形成共同第一落点，但不能出现三个以上互相争抢的中心。

### 7.1 从关系压力决定构图

先判断谁在看谁、谁掌握信息、谁被空间压住、谁要离开、谁等待、什么物件比人物更有权力，再决定机位和景别。门框、玻璃、桌面、走廊、屏幕、巨大墙面、前景人群、空位和反射只有在它们真实改变关系时才使用。

每张封面只保留一个主要构图决定，最多一个辅助机制。主体、标题、背景、光斑、道具和装饰不能同时争夺第一落点。

### 7.2 决定观众与摄影机的位置

摄影机必须有可信的物理位置和观看理由。先回答观众站在谁的感知位置，再选择焦段、距离、高度和角度。不要为了仰拍、鱼眼、长焦压缩或俯视效果，把摄影机放到现实中不存在的位置；特殊光学只在它改变叙事压力时使用。

允许 `受控不工整`：人物贴近边缘、头顶空间偏多、低地平线、现实前景切过身体、动作停在一半或主体落在边角，都可以表达被监视、疏离、失衡、局促或无法接近，但必须来自关系压力并保住标题、主表情、产品结构或冲突证据。随机裁头、遮掉决定性表情、破坏产品识别和让动作因果不可读，不属于审美选择。受控不工整是标准平衡构图无法准确表达处境时的候选，不是新的怪构图模板。

### 7.3 建立视觉通行路线

写清：

```text
进入点：第一眼从脸、手、标题、道具、亮区还是运动方向进入。
阻断 / 加速：什么前景、线条、明暗边界或人物朝向改变视线速度。
决定性落点：观众最终必须看见的冲突证据。
余韵出口：哪个空位、反射、边缘人物、未闭合动作或文字关系留下问题。
```

无法写清这条路线，说明画面仍是名词堆叠。封面可以直接猛烈，也可以克制，但不能没有明确落点。

### 7.4 让人物处在事件里

人物不是模特站桩。叙事封面至少包含：`事件压力 + 可见反应 + 带态度的动作 / 不动作 + 环境或对手反馈`。静止也要像某件事刚发生或即将发生，而不是人物摆好姿势等待拍照。

普通瞬间、犹豫、半转身、迟到、等待、离开、隔玻璃看见、伸手后停住等，可以比夸张表情更像真实电影；但自媒体缩略图仍要保证缩小后冲突证据可读。

### 7.5 色彩与光线必须有来源

颜色从服装、墙面、天空、天气、实景灯、屏幕、水面、玻璃、植物、金属和时代材料中产生。先写颜色来源和职责，再决定调色；不要用默认蓝灰、青橙、紫蓝霓虹或“高级低饱和”替代故事判断。

颗粒、色散、柔焦、污渍、旧纸、CRT、反射和镜头耀斑必须有介质或物理来源。它们可以增加被拍摄感，但不是每张封面的电影感装饰。

封面按当次内容选择一个主成像基底，按需选择一个主要不完美来源，不把胶片、VHS、监控、柔焦、纸张和数字锐度全部堆在一起。决定性标题、主表情或主产品结构要清楚，辅助区域可以普通、暗、软、遮挡、失焦或留空；不能让标题、脸、产品、背景纹理和装饰都以同等精致度争抢注意力。这仍是内容原生判断，不是新的固定风格模板。

### 7.6 提炼一个主视觉符号

主题海报从故事冲突中提炼一个可复述的符号，例如被推回的银行卡、没有坐人的椅子、裂开的门缝、只亮一格的手机、隔开两人的桌面。符号必须参与人物关系或事件结果，不是随便找一个漂亮物件放大。

一个强符号优先于多个剧情截图。海报不得把三至五张分镜、人脸、场景和特效平均拼贴；系列群像确实需要多人时，也要有唯一主关系和清楚层级。

## 八、标题与排版

### 8.1 标题不是剧本摘要

自媒体标题优先触发利益、损失、争议、异常、身份或未闭合问题；电影海报标题优先形成作品身份和余味。标题必须与作品真实内容一致，不能靠夸大承诺换点击。

标题处于 `允许优化 / 需要生成` 时，内部竞争 5-8 个候选，检查：口语是否自然、缩略图是否一眼读懂、是否和画面重复、是否像同题材通用标题、是否有 AI 式总结腔。标题已经逐字锁定时不生成候选。主标题尽量短；副标题、期数、模型名和账号名只在确有发布职责时出现。

标题先做来源与权限判断：

```text
逐字锁定：老胡明确确认的片名、栏目名、产品名或标题，封面阶段不得润色、缩写、换同义词。
允许优化：老胡给的是工作标题或方向，本 Skill 竞争 5-8 个适合缩略图发声的候选，并说明保留了什么承诺、改掉了什么问题。
需要生成：没有标题时，从内容事实、核心冲突、观众利益 / 损失、异常状态、身份或未闭合问题中生成候选；不能从“AI电影、东方史诗、治愈人生”等泛题材词命名。
```

封面展示标题与作品正式片名可以不同，但职责必须写清：片名建立作品身份，展示标题负责本次发布点击。封面模块可以独立完成展示标题；若需要改变正式片名、人物立场或作品主题，回到 `laohu_script_writer`。不能因为上游没给标题就停止封面创作，也不能悄悄改掉已锁定标题。

### 8.2 建立文字层级

每个文字元素只能承担一种职责：

```text
一级：主标题或最强点击句。
二级：补足对象、对比、结果、期数或类型。
三级：老胡用AI赚钱、laohu、日期、演员、模型或发行信息。
```

层级通过字号、字重、位置、明暗、间距和面积建立，不依赖描边、发光、阴影和多个颜色同时抢眼。文字可以压住人物、藏入空间、沿透视线进入或与道具形成前后景，但不能遮住决定性表情、手势、产品结构和冲突证据。

### 8.3 字体按内容与发声方式选择

字体选择回答“这句话由谁、以什么力度说出来”：坚硬、克制、亲密、手写、制度化、新闻感、实验性或史诗性。不要只按“悬疑用某字体、爱情用某字体”的题材查表，也不要用难读的艺术字代替设计。

字距保持正常，不使用负字距挤压。长标题优先断成有语义的 2-3 行，控制每行节奏；不能让最长词、英文模型名或账号名溢出安全区。

### 8.4 直接带字工作流与引号锁定

当前图片模型已经能够直接完成封面文字，默认把画面、文字和排版写进同一条完整图片提示词，不再先生成无字底图。凡要求真实出现在封面上的文字，都必须使用中文双引号逐项锁定原文：

```text
主标题“我为什么不再相信一键成片”
副标题“Seedance 2.5 实测”
账号署名“老胡用AI赚钱”
```

双引号内就是最终可见文字，不能写同义词、概述、占位符或让模型自由改写。每一项写清语言、标点、大小写、行数、语义断行、文字方向、字号层级、字重、颜色、对齐逻辑以及与人物 / 道具的前后关系。默认只描述文字承担的相对视觉职责和断行原则，不锁死左上、右上、百分比坐标或绝对范围；只有平台专版、固定系列版式或老胡明确要求时，才写具体方位。需要分行时分别锁定每行，例如 `主标题分两行，上行“老胡”，下行“用AI赚钱”`，不能只写“标题分两行”让模型猜。

不需要出现在画面上的内部说明、风格词、构图词和策略分析不得加引号，避免被模型误当成可见文字。固定 `laohu` Logo 仍使用 `【Logo参考@老胡Logo】`，不把键入的“laohu”替代 Logo 图片，不重绘、改字、改比例、重着色或材质化；只有文字本身就是标题或署名而非 Logo 时，才把“laohu”作为可见文字写入双引号。

生成后逐字核对错字、漏字、多字、顺序、标点、大小写、换行和字形完整性。只有实测结果仍无法达到发布标准时，才退回 `无字主视觉底图 + 后期精确排版`；这是失败备用路线，不再是默认交付，也不为每张封面机械附带。

## 九、单条比例自适应提示词

日常默认只适配 `3:4 / 4:3 / 16:9`，并且只输出一条针对当次内容设计的比例自适应提示词。老胡在生成界面选择画幅后，模型根据当前画布自动优化主体占比、标题位置、换行、留白和局部装饰；不为三个比例分别写死左上、右上、具体百分比或三套提示词。

这条提示词使用相对约束：`标题是第一文字层级并位于最清楚的可读区域`、`人物以视线和手势把注意力导向标题`、`人物与标题互不遮挡`、`局部强调只服务标题或主符号`、`四周保留发布安全边距`、`按当前画幅自动形成平衡而有张力的构图`。相对约束并不等于空泛；主体、标题、综合色、强调材质、表情和互动文案仍要按当次内容具体设计。只有老胡明确要求某个平台专版时，才增加固定方位、像素或逐比例变化。

`9:16 / 1:1 / 21:9` 等其他比例不是日常默认交付；老胡明确点名时再按同一母版逻辑扩展，不预先维护六套版本。

### 9.1 系列封面与完整视觉体系

单张比例自适应解决“同一封面怎样换画幅”，系列视觉体系解决“多期内容怎样一眼看出属于同一栏目，同时每期仍能表达自己的内容”。只有老胡明确要求系列、栏目、课程、连续短剧、整套宣传主视觉或已经存在稳定识别时，才输出本节，不把一次性封面升级成庞大品牌手册。

先建立两张账本：

```text
稳定识别核：固定 Logo 的调用规则、标题层级关系、字体气质范围、综合色行为、主符号语法、边距 / 对齐逻辑、期数位置职责和缩略图识别特征。
内容变化槽：每期标题原文、人物 / 产品 / 场景主体、当期冲突动作、强调色来源、期数、模型名和按内容变化的局部材质。
```

稳定识别核不是固定坐标和固定暖杏色。它可以是一种关系，例如 `主体总以视线把注意力交给标题`、`标题始终是唯一高对比文字层`、`laohu Logo 只作为低层级署名`；内容变化槽必须允许每一期根据题材改变人物方向、背景、综合色和构图压力。系列母版建立后，用至少三种极端内容做压力测试：最长标题、多人 / 多产品主体、最简空镜或单物封面；再分别检查 `3:4 / 4:3 / 16:9`。任一测试需要遮脸、压产品、缩小到不可读或破坏第一落点，说明视觉系统没有真正成立。

完整视觉体系按需要交付：正式片名 / 展示标题关系、主视觉符号、稳定识别核、内容变化槽、色彩行为、字体气质、文字层级、参考资产职责、比例变化原则、一个母版提示词和一条示例续作提示词。它不要求为所有未来内容预生成图片，也不把系列识别误写成所有元素永远不变。

### 9.2 暖杏手绘封面案例资产，不是默认模板

用户提供的现有模板是一种适合轻松教程、AI 工具分享和亲和型人物封面的案例资产。吸收它的结构判断，不把具体综合色、服装、描边和刷痕写成全项目默认。该案例拆成八层：

```text
1. 参考主体：哪张上传图片成为封面主体，具体锁什么。
2. 点击任务：一秒读到标题、人物和一个情绪反差；“高点击率”必须翻译成可见机制。
3. 背景减法：简单哑光底色，不让背景与标题争抢。
4. 人物引导：人物表情、视线和手势共同指向标题，不是普通站姿。
5. 标题锚定：双引号锁原文，黄白主色、黑边、高对比、主层级。
6. 局部强调：橙黄色斜向手绘刷痕只出现在标题附近，不铺满全图。
7. 装饰信息：情绪符号和互动短文案只能少量出现；短文案必须提前写定并用双引号锁定。
8. 风格收束：暖杏哑光、美式潮流手绘质感、简约艺术性、舒服但有注意力反差。
```

原模板中的 `人物随机穿着`、`一些反差点`、`一些情绪符号`、`增加一些互动短文案` 都是风险槽位。调用本案例时默认继承参考图人物和服装；确实要换装时，从 `复古英伦工装风 / 美式复古学院马甲风` 中明确选择一套，不写随机。反差、符号和短文案也必须指定一种可见机制与准确原文，不能让模型自由加字。

仅在当次内容适合暖杏手绘方向时，才使用下面的案例骨架：

```text
【封面主体参考@用户上传图片01】用于固定人物身份、脸、体态和主体内容。使用该主体制作一张适配3:4、4:3或16:9画幅的自媒体封面，根据生成时选择的实际画幅自动优化构图、人物占比、标题换行和留白。背景保持简洁的暖杏色哑光底色，整体具有治愈感与克制的吸引力，人物穿着【明确选择一种服装方向】，以有注意力张力但不过度夸张的表情、视线和引导性手势自然指向标题。主标题“___”是画面最明显的文字层级，文字以黄白色为主并带清楚黑边，保证缩略图高对比和字形完整；人物轮廓带干净白边，使主体从背景中清楚分离。只在标题附近加入橙黄色斜向手绘刷痕作为局部强调，不铺满背景。加入少量与主题有关的视觉情绪符号；如需互动短文案，只出现“___”，文字原文准确、层级低于主标题。整体为简约艺术性的美式潮流手绘质感，人物、标题、刷痕和装饰按当前画幅自动形成舒服而有吸引力的视觉关系，四周保留发布安全边距。
```

使用时删除未启用的槽位和说明括号。代码块中的 `___` 必须换成最终文字后才交付，不能把占位符直接投喂模型。

## 十、参考与原创隔离

真实电影、海报和封面只抽象分析方法，不复刻成品。一次优先只借一个主要维度：构图关系、配色逻辑、字体层级、材质介质或题材气质；其余维度重新设计。生成前检查人物数量与位置、姿态、道具组合、空间骨架、主综合色、字体轮廓和标题关系是否仍能一眼认出参考。

不得使用导演、摄影师、电影、商业海报或设计师名字作为最终提示词的风格捷径。把参考翻译成可见关系、材质、光源、焦段、排版和叙事压力。

## 十二、质量门

### 12.1 一秒与缩略图测试

- 1 秒内能否认出主体、冲突或核心欲望。
- 缩到原尺寸约 10%-15% 后，主轮廓、脸部方向、道具和主标题是否仍可读。
- 转成灰度或剪影后，视觉层级是否仍成立。
- 模糊观察时，第一落点是否仍是预定标题、主符号或二者共同关系。

### 12.2 承诺与原创测试

- 标题、表情、道具和场景是否由成片真实内容支撑。
- 是否只有一个主承诺、一个主符号、一个第一落点。
- 是否像本作品，而不是任何同题材内容都能替换。
- 是否只是大脸、发光字、拼贴剧照、蓝灰滤镜或无事件氛围图。
- 是否存在第三方品牌、IP、片名、人物姿态、版式或字体轮廓近似风险。

### 12.3 文字与平台测试

- 主标题是否口语自然、没有 AI 式总结腔。
- 所有必须出现的文字是否逐项使用中文双引号锁定，双引号内是否只有最终可见原文。
- 实际生成文字是否逐字匹配原文、标点、大小写和断行，没有错字、漏字、多字、乱序或字形残缺。
- 标题换行是否按语义，最长词是否完整。
- 字体、字重和颜色是否服务发声方式，不靠效果堆叠。
- 文字是否避开脸、眼睛、手、产品结构和决定性证据。
- `3:4 / 4:3 / 16:9` 是否共用一条当次内容的比例自适应提示词，并由生成时选择的画幅触发自动重排。
- `laohu` Logo 是否只调用固定参考，没有被重画或改造。

### 12.4 摄影与成像测试

- 摄影机位置是否现实可信，人物是否处在事件中。
- 色彩、光线、反射和光学缺陷是否有画内来源。
- 是否像真实捕捉到的事件，而不是提示词把名词摆出来展示。
- 是否出现无动机颗粒、色散、雾、轮廓光、霓虹或全画面过锐。

任一主门失败，先改概念或画面关系，不在错误底图上继续堆字体和特效。

## 自检

- 是否先定义内容事实和点击承诺，再设计电影感。
- 内容原生设计是否生成 3-5 个真正不同的概念并淘汰模板答案；系列模板续作是否避免无意义改版。
- 是否只有一个主要构图决定、主符号和第一落点。
- 是否先决定关系压力、观众位置和视觉通行，再决定焦段和风格。
- 人物是否处在事件中，光色和光学痕迹是否有来源。
- 是否默认交付画面与文字一体生成的带字提示词；所有可见文字是否使用中文双引号逐项锁定。
- 标题是否先判断逐字锁定、允许优化或需要生成；缺标题时是否主动生成展示标题，已锁定时是否避免擅改。
- 是否只在带字生成实测失败时提供无字底图备用方案，而不是继续机械执行两阶段流程。
- 是否覆盖日常默认的 `3:4 / 4:3 / 16:9`，且没有无需求维护其他比例或写死三个版本的位置。
- 明确要求系列或完整视觉体系时，是否区分稳定识别核与内容变化槽，并通过最长标题、复杂主体、极简主体和三种默认比例压力测试。
- 是否保持老胡品牌、固定 Logo 和原创边界。
- 日常交付是否只保留一条 `【封面生图提示词】`，没有把内部简报、候选比较和质量门变成默认设计报告。
- 所有实际引用是否直接写在提示词代码块内；若没有引用，是否删除了空占位符。
- 是否输出具体结果文件；只有明确要求扩展时才输出封面设计交接包。
- 是否把实际成品和发布数据交给复盘，而不是把设计意图当成已成功。
