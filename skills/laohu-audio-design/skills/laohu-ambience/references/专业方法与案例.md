# 环境声设计：专业方法与案例

## 当前专业决策

底床是跨事件持续的空间声音；早期反射帮助形成近处边界感；混响尾部是声能在空间衰减的感知。切镜切掉底床可能让同一房间变得断裂，而画面朝向变了也不代表环境声源消失。

实际声源层→听点与距离→墙/门/材质遮挡→前中背景→可循环片段与跨镜延续→有意静音例外。适用于房间、街道、自然、机械空间；反例是为了安静全部降为数字零、主观耳鸣却被当现实声场错误返修。

### 同一材料候选比较

候选A：同一关门走廊：切近景时全静音，开门后突然换成海浪。

候选B：通风底声持续；门外雨声先被门遮住高频，开门后变清楚，声源身份不变。

取舍：后者用传播变化说明门状态，前者无因换空间。

适用与反例：有意主观静音可以成立但须有授权触发；不从混响单词伪推建筑精确尺寸。

### 编译或返修结果示例

“封闭走廊内低而稳定的通风底声延续；门外雨声经关闭的门传入，细碎高频受到遮挡。门打开后雨声变清楚，通风声不随切镜消失。”

### 返回合同

返回环境层、听点距离、传播/反射、循环和跨镜声场接口；指出本次改变哪个决定、原有哪项事实不能动、从哪个状态开始以及下一负责人如何验收。输入缺口影响因果时停止专业深化，带证据返回；不把下游修词当作上游事实已存在。

## 完整专业方法

### 从持续声源建立可连续的地点

不要先写“神秘、空旷、压抑”，先列地点持续运作的声源：通风、道路、昆虫、水体、机械或远处人群，再区分本场人物能否听见及观众是否处于同一听点。背景不等于所有声音都小；一个远警报在意义改变时可以成为前景线索，音量未必突增。

直达声、早期反射和长尾混响分开考虑。直接路径被门墙遮住时，高频可读性与直达比例改变；转到另一机位不会自动改变建筑材质。空间尺寸与吸收共同影响衰减，不能“房间大=尾巴必然长”。户外也可以有反射，软装房间也不必完全干声。没有足够证据就描述听感方向，不伪报精确建筑声学参数。

循环底床应避开特别醒目的独次事件作为接缝；否则重复的鸣叫、喇叭或脚步暴露循环。可识别事件单独成SFX，底床承担连续世界。场景变化允许新底床，但需交代声音桥保留什么、何时旧空间退出；主观失聪、耳鸣或静音需要已锁叙事触发，不能被默认“修复”为持续环境。


## 一、声音线索的因果链

每条声音都用一条可核验关系闭合：

```text
物理声源
→ 发声动作与材质
→ 方向、距离与传播路径
→ 遮挡、反射、吸收与空间混响
→ 事件相位：起声 / 接近 / 接触 / 余震 / 衰减
→ 观众或人物听到的结果
→ 知识、关系、空间或行动怎样被改变
```

“恐怖环境音”没有指定声源和传播，只是目标感受。“隧道深处一次金属擦刮，经弯道和站台硬墙反射，先到达右后方的短促高频，低频余震再缓慢衰减”才是模型、剪辑和混音可共同使用的证据。
