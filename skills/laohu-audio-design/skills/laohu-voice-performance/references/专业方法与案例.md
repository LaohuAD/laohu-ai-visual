# 配音：专业方法与案例

## 当前专业决策

语义重音决定听者把哪一处当重点；意群是一次呼吸/思想组织的语言单位；话后余势是说完之后仍可听出的决定或压力。相同文本重音不同可以从解释转成命令，因此冻结字词仍允许有界演绎。

说给谁/想改变什么→起声策略→触发词→重音/语速/呼吸改变→话后结果；先比较承重策略，再交audio-prompt做平台映射。适用对白旁白；反例是从第一字崩溃，或靠加“啊、嗯”使文本自然却破坏冻结文本。

### 同一材料候选比较

候选A：同一句“你现在走吗？”：只加“悲伤、有感情”。

候选B：保持原文；“现在”承重，走字前收气，句末不拉成长哭腔；是否采用服从既定关系目的。

取舍：强候选把策略变成可听差异且不补词，弱候选无法辨别演法。

适用与反例：不擅加嗯啊或改问句；只有目标缺口会改变当前演法或已锁事实时才返编剧/实际调用者，不靠标签补人物动机。

### 编译或返修结果示例

锁定原文“你现在走吗？”保持逐字；候选A重音落在“现在”，在“走”前收住气息；候选B在“你”上轻加重，句尾平收。选择取决于已定关系目的，不能任意互换。

### 返回合同

返回说话对象/策略、冻结句、重音气口、触发和话后余势；指出本次改变哪个决定、原有哪项事实不能动、从哪个状态开始以及下一负责人如何验收。输入缺口影响因果时停止专业深化，带证据返回；不把下游修词当作上游事实已存在。

## 完整专业方法

### 冻结句子的意群排演

先将已锁文本按意思和呼吸组织成意群，不按标点机械等长停顿。给每个意群一个语言行动：争取回答、延缓离开、掩饰失控、确认事实等；这些行动来自已确定处境，不能由配音另编人物理由。重音只挑当前会改变听者判断的词，避免每词都强调；气口先服务身体状态，再服务节奏。

若情绪发生转折，先保护未被触发前的策略。触发后可选择音高范围缩窄、句尾失去支撑、停顿延长、子音收紧等一项主要变化，允许另一项随后出现；不把气声、哭腔、降速和颤音叠满。沉默仍是行动的一部分，但没有可听文件时只能描述意图，不能写已实测的停顿长度。

配音与画内表演协商说话权：谁先开口、何处允许打断、听者何时才能反应。表演主导的停顿不可由audio-editing自动清除；后期需要缩短时先返回父级确认是否仍保人物选择。若当前引擎缺少词级控制，交audio-prompt说明不支持范围，不改台词来冒充控制成功。


## 4. 比较候选，再编译模型任务

角色尚未选定声线时比较3—5个声音方向；声线已锁定而本句表演承重时，比较至少两个真正不同的演绎候选。候选差异必须落在信息意图、重音、句群速度、停顿位置、音高运动、呼吸压力、对听者的距离或话后余势中的承重项，不能只换“充满感情 / 更有电影感”。


## 三、当场表演编译

先写人物的语言行动，再写可听证据：

```text
想让听者做什么
→ 起声时采取什么策略
→ 哪个词、信息或对方反应触发变化
→ 重音、音高运动、句群速度、气息、停顿或咬字怎样改变
→ 话说完后还留下什么可听余势
```

情绪词只是人类阅读索引。“先克制后崩溃”要翻译为哪一句之前呼吸变窄、哪一个重词先被压低、什么时候韵尾失去支撑、哪里停住但没有立刻哭出来。不许从第一字就把高潮演满。


## 五、候选与听试

同一文本的候选至少改变一项承重策略：

- 保护关系：不把重话说满，用停顿和音量收束把解释权留给听者。
- 逼迫行动：缩短句群和运动范围，重音落在需要对方执行的动词。
- 隐藏真意：表面节奏保持礼貌稳定，只让换气、韵尾或某个词的发力暴露压力。

先做盲听再看提示词和参数。每次只比较主要差异：人物辨识、语义准确、表演目的、发音、音频异常和编辑可用性。非确定性模型即使参数相同也可能变化，所以参数是可追溯条件，不是完全复现保证。

RADA目标/行动/障碍支持表演按语言行动组织；ElevenLabs文档指出标记与提示方式因模型变化。[RADA](https://www.rada.ac.uk/short-courses/stanislavski-workshop/)、[TTS best practices](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/best-practices)。以下是平台无关演法，不保证标签精确执行。

本页的项目编译链与原创例子是本地方法设计；专业资料不证明生成模型一定遵从，也不证明观众效果已经发生。平台控制每次实际执行前重新核验。
