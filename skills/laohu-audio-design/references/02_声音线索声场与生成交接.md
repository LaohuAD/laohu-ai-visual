# 声音线索、声场与生成交接

只在环境声、Foley、动作声、画外线索、音乐生成、多轨编辑或跨镜声音连续承重时读取。它负责让声音有物理来路和叙事职责，不用音效新增剧本中没有的事件。

## 一、声音线索的因果链

每条声音都用一条可核验关系闭合：

```text
物理声源
→ 发声动作与材质
→ 方向、距离与传播路径
→ 遮挡、反射、吸收与空间混响
→ 事件相位：起声 / 接近 / 接触 / 余震 / 衰减
→ 观众或人物听到的结果
→ 知识、关系、空间或行动怎样被改变
```

“恐怖环境音”没有指定声源和传播，只是目标感受。“隧道深处一次金属擦刮，经弯道和站台硬墙反射，先到达右后方的短促高频，低频余震再缓慢衰减”才是模型、剪辑和混音可共同使用的证据。

## 二、声音线索表

```text
线索 ID：AMB / SFX / MUS。
所属场次、镜头或 VID：
叙事职责：建立 / 加压 / 延迟 / 揭示 / 连接 / 留白 / 节奏组织。
声源与发声动作：
材质、尺度与力量：
方向、距离、运动和遮挡：
空间尺度、反射、吸收、混响和衰减：
事件相位与时间证据：
前景 / 中景 / 背景，变化条件：
与对白、画面、音乐和其他声音的主从关系：
生成方式：单独资产 / 合并自然事件 / 循环底床 / 现场或版权音频。
入点 / 变化点 / 出点 / 头尾把手：
观众听感结果与验收方法：
```

前景声优先被识别，中景声连接行动与地点，背景声建立空间底色，但三者会随观众问题和人物位置变化。远处警报可以是背景，当人物意识到它是在追自己时，它转成前景线索；不只是音量变大。

## 三、何时拆成单独资产

任一条件成立就倾向拆分：

- 需要独立修改时点、音量、定位、均衡、混响或衰减。
- 需要跨镜保留、做声音桥、循环或替换版本。
- 这条声音承担关键信息，不能随机淹没。
- 提供商对复杂序列遵从不稳定，分层生成可以降低重试成本。

只有同一声源的起因和结果本就不可分，并且无需独立控制时才合并。例如一次相机快门的机械动作可以作为一个 SFX；脚步、门轴、室内底床和远处人声不应在需要剪辑时被锁死在一条文件。

## 四、声音连续性与剪辑把手

相邻单元继承：

```text
A结束声场：持续声源 / 当前方向距离 / 遮挡 / 空间余响 / 人声余势 / 音乐相位。
B起点声场：哪些必须相等 / 哪些因切换视点而等效改变 / B的第一个新声音事件。
声音桥：A在画面切换前种下还是B在画面出现前先到；它改变了什么理解。
头尾把手：干净入点、自然衰减、可循环区或用于交叉淡化的空间底床。
```

镜头切换不代表声场必须切断。同一空间的底床、远处机械和人物上一句的气息余势通常继续；视点转向墙后时，声源身份不变，只是频谱、直达声和反射关系变化。

## 五、音乐任务

已有最终歌曲时，它是时间权威，不重新生成相似替代品。需要新作音乐时建立：

```text
使用场景与不可抢占的信息
总时长或段落时间窗
速度、律动与节拍密度
调性 / 和声色彩 / 旋律轮廓，只写确实承重项
乐器、演奏方式、音色材质和制作空间
段落功能、动态轨迹、转折与收束
人声 / 纯器乐 / 歌词权威
参考音频的权利与只允许继承的抽象关系
需要单曲还是可编辑的分段 / stem
```

音乐不以艺术家高仿、受保护歌曲复制或未授权音频参考作为成功标准。一条长音乐默认独立于单个 VID，以便镜头替换和剪辑不造成硬断。

## 六、生成与验收

先建立平台无关合同，再选当次提供商。需求是“文本生音效”时，接口至少要核实提示词、时长、循环、输出格式和异步任务方式；需求是音乐时，还要核实段落结构、时长、器乐 / 人声、参考音频、版权、输出及局部重生成能力。

听试不只问“好不好听”：

- 声源和画面动作是否同因。
- 方向、距离、遮挡和空间尺度是否一致。
- 关键信息是否在可读窗口到达，没有被对白、音乐或其他声音遮蔽。
- 起声、峰值、余震和衰减是否符合事件相位。
- 循环点、入出点、动态余量和文件规格是否能进入真实剪辑。

响度目标由最终发布平台和混音交付规格决定。EBU R 128 是广播响度归一化的可用标准，不是所有网络平台的唯一硬编码值：<https://tech.ebu.ch/publications/r128>

## 官方证据与时效边界

以下资料于 2026-09-03 核验：

- ElevenLabs Sound Effects 官方文档说明文本可生成单次音效、复杂序列、环境底床和循环，并提供时长与提示词影响等控制：<https://elevenlabs.io/docs/overview/capabilities/sound-effects>
- ElevenLabs Music API 官方文档区分简单提示词和结构化 composition plan，支持段落、时长、歌词、风格、种子和器乐选择等当前能力：<https://elevenlabs.io/docs/api-reference/music/compose/>
- EBU R 128 定义了广播音频响度归一化和允许最大电平的推荐：<https://tech.ebu.ch/publications/r128>

接口、字段、时长、价格和商用范围都可能变化。每次生成前核验当次官方文档和账户资格；不把这些当前值写成项目永久规则。
