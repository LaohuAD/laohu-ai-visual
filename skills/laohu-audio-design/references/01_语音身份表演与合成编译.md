# 语音身份、表演与合成编译

只在设计人物声线、旁白、对白、多人会话、语音合成或真人音色授权时读取。它解决“怎样说才还是这个人”，不改写他说什么。

## 一、三层分开才能稳定

| 层 | 回答 | 稳定性 |
|---|---|---|
| 声音身份 | 这是谁 | 跨句、跨场、跨媒介保持 |
| 当场表演 | 他此刻想用话改变谁 | 随目的、关系、压力和触发改变 |
| 合成实现 | 这个模型怎样尽量做到 | 随提供商、模型和版本变化 |

常见错误是把某次生成的滑杆值存成人物身份，或把“沉稳”当成每句话的固定演法。正确做法是先保留可听关系，再为每个模型适配。

## 二、稳定声音身份

只写有证据或已选定的关系：

- 音区与音高活动范围：常态落点、上下行幅度，不是一个孤立“低音”。
- 音色质地与共鸣：明暗、厚薄、颗粒、气声比例、胸 / 口 / 鼻腔共鸣的感知结果。
- 咬字与句法：子音边缘、韵尾、连读、断句和重读的常态倾向。
- 语速与呼吸：句群长度、换气位置、气息支撑和语速变化范围。
- 辨识锚点：去掉台词内容仍能被听出的1—3个关系，不是刻板口音或招牌小动作。

当参考音频带有房间混响、配乐、压缩伪影或特殊表演时，这些不能被误当成声线本身。参考样本越差，相似度越高越可能放大噪声和异常；需要先换干净样本，而不是一味追求相似。

## 三、当场表演编译

先写人物的语言行动，再写可听证据：

```text
想让听者做什么
→ 起声时采取什么策略
→ 哪个词、信息或对方反应触发变化
→ 重音、音高运动、句群速度、气息、停顿或咬字怎样改变
→ 话说完后还留下什么可听余势
```

情绪词只是人类阅读索引。“先克制后崩溃”要翻译为哪一句之前呼吸变窄、哪一个重词先被压低、什么时候韵尾失去支撑、哪里停住但没有立刻哭出来。不许从第一字就把高潮演满。

## 四、语音文本规整与发音字典

保留三份内容：

1. `锁定原文`：与剧本或歌词权威一致。
2. `可读规整文本`：数字、缩写、符号、单位和异形词改为当次模型能稳定读对的形式，但不改语义。
3. `发音字典`：人名、地名、品牌、方言词、多音字和术语的目标读法、人可读备用形式与适用语言。

抽象控制优先使用“在这个词前留出辨认窗口”、“本句只在尾部加速”等相对关系。只有对齐、时长或口型确实承重时才加数字窗口。SSML 可表达停顿、重音、韵律、发音和文本解释，但不同引擎实现子集不同；先保留抽象意图，再生成当次平台的标记。

## 五、候选与听试

同一文本的候选至少改变一项承重策略：

- 保护关系：不把重话说满，用停顿和音量收束把解释权留给听者。
- 逼迫行动：缩短句群和运动范围，重音落在需要对方执行的动词。
- 隐藏真意：表面节奏保持礼貌稳定，只让换气、韵尾或某个词的发力暴露压力。

先做盲听再看提示词和参数。每次只比较主要差异：人物辨识、语义准确、表演目的、发音、音频异常和编辑可用性。非确定性模型即使参数相同也可能变化，所以参数是可追溯条件，不是完全复现保证。

## 六、权利与平台边界

- 内置音色：记录当次许可与使用范围。
- 原创合成声线：保留设计来源，避免以在世真人的高相似度作为成功标准。
- 真人克隆：必须由有权人明确授权，并完成当次提供商的同意或身份验证。不代用户声明权利，不绕过验证。
- 参考表演：可提取速度、停顿、距离和呼吸等抽象关系；未获授权时不得把声纹身份作为生成目标。

## 官方证据与时效边界

以下资料于 2026-09-03 核验，用于证明能力与边界，不把某家平台的当前字段写成永久规则：

- W3C `SSML 1.1`：定义 break、emphasis、phoneme、prosody、say-as 等标记的通用语义：<https://www.w3.org/TR/speech-synthesis/>
- Google Cloud Text-to-Speech SSML：说明实际服务可用 SSML 控制停顿和数字、日期、缩写等读法：<https://cloud.google.com/text-to-speech/docs/ssml>
- Microsoft Azure Speech：说明发音、语速、音高、音量和多声线等控制取决于实际 SSML 支持：<https://learn.microsoft.com/en-us/azure/ai-services/speech-service/text-to-speech>
- OpenAI Audio API：语音合成使用模型、声线、文本和可选表演指令；自定义声线需音频样本与同意记录，且受资格限制：<https://platform.openai.com/docs/api-reference/audio>
- ElevenLabs TTS 与 Voice Cloning：平台参数会影响随机性、相似与表现，样本噪声会限制克隆质量，克隆需要权利确认或验证：<https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech> 、<https://elevenlabs.io/docs/eleven-api/concepts/voice-cloning>

提供商文档、模型、字段、价格和限制会变。每次真实调用前重新查官方文档；无法核验时只交付平台无关合同。
