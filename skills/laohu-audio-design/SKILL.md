# 老胡音频与音色设计

## 声音箴言

闭上眼，人物、空间和行动仍要成立。

## 职责与调用边界

本 Skill 是音频设计与生成任务编译的唯一负责人。它把已确认的写作声音、可听声音身份、场次目的、画面事件和时间证据，编译为可候选、可生成、可剪辑、可复用、可验收的语音、环境声、动作声、声音线索和音乐任务。

它独占四项判断：

1. 怎样把人物的`稳定声音身份`与本句的`当场语音表演`分开。
2. 怎样把抽象听感翻译成发音、重音、停顿、呼吸、距离、声场和事件相位。
3. 哪些声音应该成为可单独调整的资产，哪些可以在同一自然事件内生成。
4. 怎样先建立`平台无关能力合同`，再由`提供商适配层`映射当次模型的真实参数和限制。

它不改写剧本、锁定台词、歌词、人物立场或 MV 结构；不从外貌和性格词伪造生理音色；不替`laohu-video-prompt`决定本镜头的最终声画时点；不替`laohu-mv-director`改写已存在的最终音频。没有可用接口或没有外部执行授权时，只交付文本合同并标记`待生成`，不宣称已经产生音频。

## 音频设计工作流

### 1. 建立声音任务合同

```text
声音任务合同：作品 / 任务类型 / 用途 / 语言与口音 / 受众与播放终端 / 锁定文本 / 时间证据 / 上游声音身份 / 当场目的 / 现有音频与参考 / 可设计范围 / 不可改事实 / 目标接口 / 输出格式 / 复用范围 / 成本与权利边界。
```

先分类任务：`声音身份 / 旁白 / 对白 / 角色多人会话 / 环境声 / Foley与动作声 / 声音线索 / 音乐 / 混合任务`。语音设计读取`references/01_语音身份表演与合成编译.md`；环境、音效、音乐和跨镜连续读取`references/02_声音线索声场与生成交接.md`。

### 2. 过声音权利门

使用内置音色或确认可商用的原创合成声线时，记录来源和使用范围。创建、复制或高相似度还原真人声音时，必须有`用户明确授权`、可追溯的`同意证据`和当次提供商要求的验证。公开可下载、用户说“像他”或模型技术上能做，都不等于获得克隆权。证据不足时停止真人克隆，转为内置音色、原创合成声线或由权利人完成同意流程。

### 3. 分开身份、表演和实现

```text
稳定声音身份：音区 / 音色质地 / 共鸣 / 咬字 / 常态语速 / 呼吸支撑 / 辨识锚点 / 证据与假设。
当场语音表演：说给谁 / 想改变什么 / 起声状态 / 精确触发 / 重音与停顿 / 呼吸与声线变化 / 话后余势。
声音实现参数：提供商 / 模型 / voice ID或已授权样本 / 指令或SSML / 语速、稳定性等平台参数 / 格式 / 采样率 / 声道 / 随机性与版本。
```

三者相容但不互相冒充。声音身份不决定每句用同一情绪；当场表演不能改掉稳定辨识；某平台的滑杆值不是人物设定。

面向老胡和生成模型的默认表面是一段`自然语言音色描述`，不要求用户先懂参数表。按“人物身份与年龄感 → 音区与音色 → 咬字、语速、停顿与呼吸 → 说话时给人的关系感”写成连贯的人话。例如：“一位中年教师的男声，音区偏低，音色温厚而有轻微颗粒感，共鸣稳定，咬字清楚但不刻意端着；语速中等，句子之间留有思考的短停，说话像在把一件复杂的事情讲给面前的人听。”

用户已提供情绪或场次目的时，把它翻译成这段话里的可听变化，不只追加“带着悲伤”。`未提供情绪`时，使用人物的`中性常态`：只描述稳定声线和正常说话方式，不自行加入压抑、激动、哭腔、悬疑或广播腔。“中年教师”只能限定设计范围，不能自动证明低沉、磁性或权威感；这些仍是需要选择和验证的音色假设。

### 4. 比较候选，再编译模型任务

角色尚未选定声线时比较3—5个声音方向；声线已锁定而本句表演承重时，比较至少两个真正不同的演绎候选。候选差异必须落在信息意图、重音、句群速度、停顿位置、音高运动、呼吸压力、对听者的距离或话后余势中的承重项，不能只换“充满感情 / 更有电影感”。

语音在生成前完成`语音文本规整`、`发音字典`、多音字 / 名字 / 数字 / 缩写校正、重音与停顿标记。先保留人可读的原文与抽象控制，再根据当次接口映射为指令、SSML、音频参考或原生参数；平台不支持的字段要明确降级，不伪装成已精确控制。

### 5. 建立音频线索表与资产关系

每条声音用`声源—传播—听感结果`闭合：谁或什么发声，通过什么材质和空间传来，被什么遮挡或改变，在什么事件相位进入、变化和衰减，让观众知道什么或误判什么。前景 / 中景 / 背景是注意力与距离关系，不是把音量从大到小排队。

台词、环境底床、需精确对齐的动作声、画外线索和长音乐，默认作为可单独调整的`单独资产`。只有声音本就是同一不可分的物理事件，且不需要独立版本、音量、定位或时点控制时，才合并生成。

### 6. 交付生成任务并保持连续

统一资产 ID：`VOICE01`稳定声音身份，`DUB01`旁白 / 对白，`AMB01`环境底床，`SFX01`动作声 / 特效声，`MUS01`音乐。每项记录输入版本、引用资产、提供商与模型版本、参数、随机性、输出格式、生成结果和选中理由。

多句、多镜和多版本共用人物时维护`声音连续性`：稳定辨识项不变，表演可随目的和压力变化，模型更换或重生成不得偷换人物。下游只继承已真实存在且验收过的文件；文本合同不冒充音频资产。

## 音频设计交接包

```text
【任务与权威】任务类型 / 上游文本与时间证据 / 用途 / 语言 / 平台 / 播放终端 / 不可改事实。
【权利状态】内置 / 原创 / 克隆 / 参考；来源 / 使用范围 / 用户明确授权 / 同意证据 / 提供商验证 / 失效条件。
【声音身份】VOICE ID / 稳定音区、音色、共鸣、咬字、语速、呼吸 / 辨识锚点 / 事实、推论与设计假设。
【自然语言音色描述】一段可直接阅读和投喂的连贯描述；有情绪时写当场变化，未提供情绪时使用中性常态。
【表演候选】候选A—E / 承重差异 / 观众听感 / 风险 / 胜出与淘汰理由。
【语音生成】DUB ID / 锁定文本 / 规整文本 / 发音字典 / 重音、停顿、呼吸与话后余势 / 目标时长或时间窗。
【音频线索表】AMB / SFX / MUS ID / 声源 / 传播和声场 / 事件相位 / 前中背景 / 观众结果 / 单独资产或合并依据。
【平台无关能力合同】必须实现 / 方向引导 / 可由模型变化 / 不可接受结果 / 需要的输入与输出。
【提供商适配】当次已核验接口 / 模型 / 参数映射 / 不支持项与降级 / 费用与时延 / 版本日期。
【连续与剪辑】入点 / 变化点 / 出点 / 可循环区 / 头尾把手 / 跨镜保留 / 可替换范围。
【生成记录】待生成 / 已生成 / 已听试 / 已选定；文本与参数版本 / 输出文件 / 可重现信息 / 异常。
【交给视频】可听结果 / 事件触发 / 精确时间或相对窗口 / 声画对齐 / 不可重生成项。
【交给MV】最终音频或待生成状态 / 段落、节拍、音色、动态和停顿证据 / 不可伪造的时间码。
【交给复盘】选中候选 / 真实文件 / 目标听感 / 首个失配时点 / 必须保护项。
```

## 双门验收

### 底线门

- 锁定文本、人物事实、最终音频和时间证据没有被改写或冒充。
- 身份、表演和平台参数已分开；每条声音有声源、时点、距离、声场或听感结果中的必要证据。
- 真人克隆已经过权利门；提供商能力来自当次已核验文档，未支持控制没有伪精确。
- 文本合同、已生成文件和已听试结果的状态分开，下游可以追溯。

### 巅峰门

- 胜出候选是否用可听差异托住人物目的、空间关系和观众等待，而不是形容词更多。
- 声音身份去掉文本后仍可辨识；同一身份换句子和压力后仍是同一人，又不是同一演法。
- 闭眼测试时，观众能否从前中背景、遮挡、反射、近远变化和声音余势重建行动与空间。
- 独立资产是否保留了剪辑、版本比较和后期混音的自由，同时没有把自然事件拆到失去因果。
- 是否还有一个具体、可实施且预计明显更强的候选未比较；若有，不以“能生成”为完成。

真实音频尚未生成或尚未听试时，只能标记文本设计通过或`待生成`；真实结果失败时交给`laohu-generation-review`定位第一个断点，再返回剧本、人物、音频、视频、MV或提供商适配层。
