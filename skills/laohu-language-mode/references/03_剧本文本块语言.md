# 剧本文本块语言

正式剧本是一份混合体裁文件。镜头方头、动作正文、表演括号、人物台词和剧本说明相邻出现，却承担不同任务。编剧继续拥有内容权；本文件只防止五类文字互相冒名。

## 一、SCRIPT_HEADER：快速定位，不提前讲戏

镜头方头只负责定位：编号、景别、运镜、机位或视轴、构图和参考时长。它可以写特殊观察权限，如 POV、过肩、俯视或门缝观察；不能塞入完整动作、人物心理、主题解释和“本镜为了表现什么”。

```text
【E01-S02-C04｜中景｜运镜：下坠跟拍｜机位：老胡身后偏左，镜头与他一同下落并向上看洞口｜构图：老胡近景背侧、Luna留在高处洞口｜约4秒】
```

机位写摄影机从哪里朝哪里看，构图写这个观看关系投到画面后谁在哪里。两者不能互相代替。

## 二、SCRIPT_ACTION：让人看见事情怎样发生

动作正文只写可见可听事件，以及为了消除动作多义性而确有必要、并在同镜或相邻镜得到表演证据的少量人物理解。它可以使用偏小说性的画面语言，但每句话都要推动人物、信息、空间、动作、关系或镜尾状态。

承重动作至少让读者看懂：

```text
起始条件
→ 发力来源或能力触发
→ 运动路径
→ 与人物、道具和环境的交互
→ 接触点与受力方向
→ 结果停点和下一镜把手
```

剧本锁因果，视频提示词扩颗粒。剧本可以写“墙面被踏出鞋印凹坑，碎屑向后炸开，Luna借反作用力越过四米”；视频提示词再深化凹坑大小、光影、烟尘速度和摄影机时序。剧本不能只写“Luna 瞬移过去，一脚踢飞老胡”，让下游猜速度从哪里来。

禁止用“她意识到”“为了表现”“象征着”“气氛变得紧张”代替可见证据。必须保留人物理解时，先写触发它的事实，再写眼神、呼吸、手部、身体距离、说话方式或后续选择如何泄露。

## 三、PERFORMANCE_CUE：把情绪变成能演的说法

每句有声台词必须能追溯到可执行表演信息：可逐句括注，也可在本场开头显式声明角色表演基线、适用镜号或台词范围，以及“未另标者继承本场基线”。情绪、关系目的、可听语气或声源变化处单独标注；跨场不自动继承。声源位置不等于表演状态，O.S. / V.O. 只说明声源，不能代替表演。

最小结构是：

```text
声源 / 情绪阶段 / 压制或释放方式 / 可听语气 / 关系态度
```

只写“声音放低、句子很短”不够，因为它没有说明人物为什么这样说、情绪走到哪一步，以及这句话在对对方做什么。更可执行的写法是：

```text
Luna（怒意压到爆发前，声音低冷而短，给老胡最后一次改口机会）：老胡。
```

提示不是心理小传。眼神、呼吸、手势、站位和身体距离属于 `SCRIPT_ACTION`；括号只保留会改变这句表演的情绪阶段、收放方式、气口、语速、重音和关系态度。不同台词的提示应随前一刻发生的事变化，不能批量复制“冷冷地、认真地、微笑着”。

## 四、CHARACTER_DIALOGUE：人物说话是在做事

人物说话是在试探、遮掩、挑衅、求饶、拖延、靠近、推开、纠错、保住面子或逼对方行动。台词先服从人物当下要办的事，再承担观众信息；不能让角色轮流替作者念主题、知识卡或制作说明。

写台词前确认：

```text
他此刻在哪里，身体正在做什么
他知道什么、误会什么、不知道什么
他为什么现在开口，而不是沉默或说别的
这句话要让眼前的人做什么
按当前呼吸和压力，他说得完多少
```

教学视频仍要把知识说清，但可以拆给可见受光证据、短促台词、对手复述和动作结果共同完成。正在逃跑的人可以喊“正侧光！一边亮一边暗，脸的结构出来了！”；他不必在一次喘息里念完“适合硬朗、冲突、材质感等多种应用场景”的知识卡。剩余用途可以由前后镜头、字幕或较安全的停顿承接。

人物声音来自身份、关系、地域、知识边界和当下压力，不靠固定口癖。Luna 在外人面前可以落落大方，在老胡面前可以释放调皮、霸道的小恶魔本性；两种状态都必须从她眼前的目的和前后行动长出来，不能靠每句都加狠话证明人设。

已确认台词是保护项。修改动作、空间、情绪提示和提示词时，不得顺手换掉“正侧着踹”“你说谁脸黑”等已经承担关系与动作结果的原话。台词确实造成新的内容矛盾时，返回编剧或用户决定。

每轮台词完成后再按[有效信息与冗余裁决](05_有效信息与冗余裁决.md)检查开口资格、语言动作、新增作用、话后结果、呼吸容量和尾部检查。短不等于有效，长不等于啰嗦；必要重复如果改变关系、误会、笑点或下一动作可以保留。教学知识超过人物当下气口时，优先迁移到可见演示、屏幕文字或安全停顿，不能为了“像人”把观众必须知道的内容一起删掉。沉默若承担关系或节奏作用，同样视为剧本动作而不是空白。

## 五、SCRIPT_NOTE：给制作看，不冒充观众看见

剧本说明不冒充镜头事件。它只承接不会直接出现在画面、却会影响连续性、权限或下游执行的信息，例如资产状态、受伤延续、画外声来源、待人工核实项和不可改写边界。

如果一项信息必须让观众知道，就把它变成动作、声音、台词或可见结果；不要藏在说明里再假定观众已经理解。若一项说明只是在替作者解释“本镜很有压迫感、人物已经生气”，删除或返回动作正文建立证据。

## 六、逐块反向审稿

整稿返工先过“整稿覆盖门”：把当前剧本已出现的每种文本块各审一遍，留下块级处理回执。这不是要求每类必须改动，而是要求每类必须经过裁决。不能只改台词，然后让动作、表演括注、场次结果和下游交接继续沿用同一种说明腔。

- 方头删除后，正文是否仍能讲清事件；正文删除后，方头是否只剩定位信息。
- 动作是否能让人画出人物、路径、接触与结果，而不是只看懂作者结论。
- 每句台词前是否既有声源又有可演状态；情绪是否来自精确触发。
- 只听台词时，是否像这两个人在当前处境里说话；删掉人物名后，声音是否仍有区别。
- 剧本说明是否只交接生产信息，没有替观众看戏。
- 每个保留分句删掉后具体会损失什么；若说不出损失，是合并、迁移、删除，还是内容缺失需要返回原负责人。
