# 有效信息与冗余裁决

有效不等于短，也不等于信息名词多。一个分句只有在当前接收者、当前时刻和当前载体里造成了必要变化，才有留下的理由；一个长句若连续完成不可互换的作用，可以有效，一个短句若什么都没改变，也可以是废话。

本文件是十一种语言模式共享的唯一裁决方法。专业负责人先保证内容成立，本文件只判断信息应不应该留在当前块、是否应与相邻内容合并、是否该迁移载体，以及何时必须退回专业负责人。

## 一、逐分句状态变化模型

正式写作完成后，把每个分句、字段或控制项放进下面这条内部链；它是审稿动作，不要求写进成品：

```text
receiver_before：接收者在读到它之前知道什么、相信什么、感到什么、正在做什么
target_delta：读完以后必须新增或改变什么
contribution：这个分句凭什么造成该变化
evidence_of_change：变化会从哪个决定、反应、动作、画面、声音或执行结果中被看见
removal_cost：删掉它，具体损失什么；若说不出损失，默认不保留
best_carrier：这个作用最适合由台词、动作、字幕、说明、资产规格、图片、视频还是声音承担
decision：KEEP / MERGE / MOVE / DELETE / RETURN
```

判断单位是“作用”，不是标点。一个句号里可以有三个不同作用，也可以有三句话只重复同一个作用。

## 二、先过双门，再谈压缩

### 必要信息保护门

先问删减会不会破坏内容成立。以下信息即使不短，也必须保护：

- 观众理解当前事件所需的知识、因果、关系和信息顺序。
- 动作的起点、触发、发力来源、路径、接触、受力、结果与镜尾把手。
- 人物—摄影机—环境的空间锚点、观看侧、入画退出和连续状态。
- 人物身份、资产锚点、锁定台词、声音身份与模型硬约束。
- 会改变下游设计、生成、剪辑、验收或返工去向的决定。

缺了这些内容，不得以“更简洁”“节奏更快”为理由硬删。信息本身尚未成立时执行 `RETURN`，由原负责人补齐。

### 边际作用门

必要内容齐全后，再问新增的这个分句有没有独立作用。以下任一项成立，才有保留资格：

- 新增一个之前没有的事实、区别、因果、限制或可执行控制。
- 改变人物关系、行动方向、压力、误会、笑点、节奏或观众预期。
- 排除一个现实可发生的错误理解或错误生成结果。
- 为下一块留下明确的触发、状态、承接或回收。
- 用更合适的载体替代了原本不可执行或会污染当前块的表达。

只把前文换一组词、继续列同级用途、重复同一审美形容词、解释观众已经看见的结果，边际作用通常为零。

## 三、五种裁决

- `KEEP`：删掉会损失必要内容或独立作用，留在当前位置。
- `MERGE`：作用成立，但与相邻内容共用同一变化；合成一个更清楚的单位。
- `MOVE`：信息有用，但当前接收者、时机或载体不对；迁移到字幕、动作、说明、资产、图片、视频或声音的真正负责人。
- `DELETE`：没有独立作用，且删除不损害内容、关系、节奏和执行。
- `RETURN`：不能靠表达裁决解决，缺的是知识、剧情、动作因果、资产设计、模型事实或用户决定；返回原负责人。

`MOVE` 不是删掉以后假设别人会补。必须写明迁入位置和承接内容。`RETURN` 也不是把问题踢走，必须指出缺口属于谁、缺什么、补齐后从哪个文本块继续。

## 四、十一种模式各自怎样算有效

| 模式 | 有效变化 | 常见无效信息 |
|---|---|---|
| `USER_COMMUNICATION` | 让老胡多看清一个事实、因果、取舍、风险、边界或下一步决定 | 同一判断换术语重说；不改变决定的系统自述 |
| `PRODUCTION_NOTE` | 改变制作状态、负责人、保护项、输入输出、验收或返工路径 | 不影响执行的过程倾倒；没有对象的“加强、优化、注意” |
| `SCRIPT_HEADER` | 唯一确定镜号、景别、运镜、机位、视轴、构图或时长权限 | 抢先写完整动作、心理和主题解释 |
| `SCRIPT_ACTION` | 让读者连续看见人物、空间、触发、路径、交互、结果或镜尾状态怎样改变 | 重复方头；用形容词替代动作；解释已经可见的心理 |
| `PERFORMANCE_CUE` | 改变演员这一句的情绪阶段、压制释放、气口、重音、语速或关系动作 | 重复动作正文；只写泛情绪词；把心理小传塞进括号 |
| `CHARACTER_DIALOGUE` | 让人物通过说话改变关系、行动、压力、笑点、误会、必要理解或节奏 | 人物替作者念知识卡；无对象、无意图、无后果的填空句 |
| `SCRIPT_NOTE` | 锁定不直接上画面但确实影响连续、权限、资产或下游执行的事实 | 替观众看戏；解释主题和氛围；复述正文 |
| `ASSET_SPEC` | 排除错误身份、形态、材质、依赖、变体或跨请求漂移 | 不能排除任何错误结果的高级、绝美、惊艳等空泛形容 |
| `IMAGE_PROMPT` | 改变同一个静态时刻的像素、主体绑定、姿态、构图、空间、材质或光影 | 需要时间才成立的完整过程；作者意图；互相同义的审美词 |
| `VIDEO_PROMPT` | 改变时间中的像素、动作、表演、声音、摄影机、空间、物理结果或镜间承接 | 不改变声画结果的解释；重复静态形容词；无先后的动作堆放 |
| `AUDIO_PROMPT` | 改变声音身份、发音、呼吸、力度、节奏、距离、声场、同步或可听结果 | 不影响听觉的服装颜色和纯视觉姿态；擅自改写锁定台词 |

同一事实跨模式出现不等于重复。例如“金色虹膜”在资产规格里锁身份，在图片提示词里控制受光后的像素，在视频提示词里控制受光变化中的连续性；只要接收对象和作用不同，三处都可以有效。

## 五、人物台词的六步合同

### 开口资格

人物为什么必须在此刻说，而不是沉默、看一眼、转身或让动作回答？没有回应对象、信息缺口、关系动作、节奏任务或现实压力的台词，先删除试读。

### 语言动作

这句话不是“表达了什么内容”，而是在对谁做什么：纠错、求饶、挑衅、试探、遮掩、拖延、逼问、保住面子、拉近距离或推开对方。

### 新增作用

它至少改变一项：关系、行动、压力、误会、笑点、必要理解、节奏。教学台词可以同时交知识，但知识必须是观众此刻理解下一步所需，而不是把完整资料卡交给人物朗读。

### 话后结果

说完以后，对方的反应、下一动作、观众判断或场面压力必须能留下证据。没有任何后果的句子，除非它承担必要停顿、气氛落差或关系留白，否则删除或合并。

### 呼吸容量

人物能说多少由身体和场面决定。安静演示、坐谈和正式讲解可以容纳完整长句；奔跑、挨打、憋气、哭泣、爆发和偷听只能容纳相应气口。不要用统一短句替代身体判断。

### 尾部检查

一句话完成核心语言动作后，单独审查破折号、逗号或补充句后的尾巴。若它只继续列用途、解释笑点、复述屏幕文字或替作者总结，而关系、行动和理解已不再变化，执行 `MOVE / MERGE / DELETE`。

必要重复可以 `KEEP`。人物再次说“我说正侧光”，字面虽然重复，第二次却可能是在自证、求饶，并触发“正——侧着踹”的误听与动作；爱情故事里同一句“你吃了吗”，也可能从客套变成承认关心。重复的内容相同，关系动作不同，作用就不同。

沉默也要过同一合同。沉默若改变关系距离、制造等待、暴露回避或把决定留给动作，它是有效表演；若只是作者没有写台词，则不是自动高级。

## 六、跨载体迁移

- 人物说不完但观众必须知道：把知识用途迁到屏幕文字、演示结果或安全停顿，台词保留当下识别与关系动作。
- 动作正文里的稳定外观清单：迁到资产规格，正文只保留会在本镜改变的状态。
- 图片提示词里的完整过程：选定一个决定性静态时刻，其余迁到视频提示词。
- 视频提示词里的作者解释：转译成可见可听控制；不能转译又不影响执行则删除。
- 声音提示词里的纯视觉信息：只有它改变呼吸、力度、距离或声场时才转译，否则删除。

迁移之后再做保真检查：知识没有丢、关系笑点没有断、动作因果没有断、空间没有漂、锁定原话没有被改、下游能找到新承载位置。

## 七、禁止机械简洁

- 禁止：统一字数上限。
- 禁止：统一句长阈值。
- 禁止：形容词数量阈值。

这些指标最多用于发现可疑位置，不能裁决自然、有效或可执行。真正的裁决证据是：它改变了什么，删掉损失什么，是否放在最佳载体，以及变化能否被人或模型看见、听见、执行。

## 八、完成回执

若返工对象是整份成品，先过整稿覆盖门：列出已出现的每种文本块，对每类至少完成一次`KEEP / MERGE / MOVE / DELETE / RETURN`判定。不能只改台词或只删一处尾巴，就宣布整稿问题已经解决。

重要文本块审完后，内部至少留下：

```text
保护了哪项必要信息：
删除或合并了哪项零边际内容：
迁移了什么，迁到哪里：
哪项缺口返回了谁：
审稿前后，接收者或执行结果发生了什么可观察变化：
块级处理回执（整稿任务）：已出现的每种文本块分别改了什么，或为什么保留
```

若只能报告“更精简、更顺、更自然”，而说不出一个具体变化，本轮有效信息合同尚未完成。
