# 资产、图片、视频与声音提示词桥接

本文件只区分四种接收对象和语言任务。专业内容、模型事实、格式、字段与验收继续由原 Skill 持有；此处不得复制视频三段式、图片注意力编译、资产编号体系和声音生成合同。

四类正文完成后统一读取[有效信息与冗余裁决](05_有效信息与冗余裁决.md)：先保护会改变身份、像素、动作、声音、空间、物理和连续状态的必要控制，再删除零边际同义词或迁移错误载体。调用仍不转移专业主责。

```text
ASSET_SPEC / IMAGE_PROMPT → laohu-visual-assets
VIDEO_PROMPT → laohu-video-prompt
AUDIO_PROMPT → laohu-audio-design
```

## 一、ASSET_SPEC：固定可复用身份

资产规格写给设计者、生成负责人和下游 Skill。它说明对象在多次生成中必须稳定什么、允许改变什么、服务哪些镜头、依赖哪些已确认设计，以及怎样判断走样。

它优先写身份锚点、形态、比例、结构、材质、色彩、依赖和变体边界。临场情绪、一次性动作与剧情散文不能代替稳定特征；只有当前镜头才需要的偶发状态应留在镜头或提示词，不污染母资产。

进入此模式后读取 `laohu-visual-assets` 的当前 Skill 和命中的人物、服装、场景或道具 Reference。

## 二、IMAGE_PROMPT：编译一个静态时刻

图片模型需要一个同时成立的静态时刻。提示词说明主体身份、当前姿态、人物—摄影机—环境关系、构图、光色、材质和决定性画面结果。它可以保留动作将起未起或刚刚发生后的单帧因果，但不能写一条需要时间才能完成的完整动作链。

“为了表现她很强大”“象征神秘”属于创作者说明；应转成低机位、占画比例、受光位置、姿态、遮挡或环境反应等可见关系。

进入此模式后读取 `laohu-visual-assets`，并按需读取共享的`视觉生成模型注意力与提示词编译参考.md`。本模式不另建第二套图片提示词规则。

## 三、VIDEO_PROMPT：编译时间因果

视频模型需要知道谁从什么状态开始，什么触发了变化，动作与摄影机怎样经过时间展开，环境发生什么可见反应，以及最终停在哪里。视频语言必须保留起点、触发、过程、主要兑现、结果和接续把手。

只有静态形容词不构成视频；把多个动作并列也不等于时间因果。动作速度、人物路径、摄影机路径、表演变化、声画事件与结束状态必须能在同一时序里成立。

进入此模式后读取 `laohu-video-prompt`，由它选择目标模型、同场批次、三段式正文、题材 Reference、VC 与复验。本模式不得复制这些规则，也不得绕过视频负责人直接交付正式提示词。

## 四、AUDIO_PROMPT：编译可听结果

声音模型与配音执行者只接收可听信息：声音身份、当场演法、发音、语速气口、情绪进程、声源位置、声场传播、时间位置和与画面的关系。视觉姿态只有确实改变呼吸、力度、距离或声场时才转译进声音任务。

已确认的人物台词必须锁定台词。音频负责人可以补读音、重音、气口和表演说明，不能为“更自然”擅自续写、删改或重排人物原话。需要改词时返回编剧。

进入此模式后读取 `laohu-audio-design` 的语音身份、表演与声场 Reference。

## 五、同一事实的四次编译

内容事实：Luna 的金色眼睛是稳定身份；她在本镜压着怒意抬眼看老胡，随后向前一步。

```text
ASSET_SPEC：金色虹膜与清晰瞳孔结构为稳定身份锚点；不得因受光变化改成全眼发光或无瞳孔。

IMAGE_PROMPT：Luna抬眼看向画面右侧的老胡，金色虹膜在侧光下仍保留瞳孔细节，右脚刚越过地面标记线，画面停在她迈步前压住怒意的一瞬。

VIDEO_PROMPT：Luna先垂眼停住半拍，指节收紧；她抬眼锁定右侧的老胡，金色虹膜接到侧光，随后右脚越过标记线向前一步，镜头停在两人距离缩短后的新位置。

AUDIO_PROMPT：锁定台词“老胡。”；怒意压到爆发前，吸气后停半拍，音量低，两个字短而冷，句尾收住，不拖长。
```

四段共享事实，但不能互相复制。

## 六、失败返回

- 稳定身份与变体边界不清：返回 `laohu-visual-assets` 或更上游设计负责人。
- 静态时刻不存在、画面关系冲突：返回图片负责人或剧本。
- 起点、动作因果、镜尾或场内连续性缺失：返回 `laohu-video-prompt`；根因属于剧本时继续返回编剧。
- 台词未锁定、声音身份矛盾：返回 `laohu-audio-design` 或编剧。

语言模式只指出哪种信息没有进入正确接收合同，不能借修辞补齐专业事实。
