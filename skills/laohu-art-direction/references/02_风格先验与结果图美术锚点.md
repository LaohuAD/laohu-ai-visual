# 风格先验与结果图美术锚点

## 作用

这份 Reference 解决的不是“怎样发明一种从未存在过的画风”，而是怎样借助人类已经形成共同认知的优秀作品、导演、艺术家和视觉传统，把生成模型召回到一个成熟审美区域，再用当前项目自己的题材合同、人物、服装、场景和叙事完成原创转译。

适用于人物写真、场景写真、道具 / 产品写真、概念成品像、英雄帧和其他“设计完成后，被摄影机拍成一张结果照片”的图片。B / W / M / S / A等生产规格板不机械套用本 Reference 的三段式标题，只继承会改变其构图、色彩、材料、光影和观看重点的共同内核。

## 名称为什么有用

著名导演、作品、艺术家、摄影传统、艺术流派或时代影像风格名称，是高密度的审美检索词。一个名称可能同时召回构图习惯、色彩组织、光线方向、材料质感、空间尺度和媒介颗粒。它能缩小模型候选空间，但不能替代当前对象的具体设计。

正确组合是：

```text
名称锚点
＋这个名称具体召回什么视觉机制
＋机制怎样落在当前原创对象上
```

错误组合是：

```text
某某风格、高级、电影感、震撼、精修
```

前者给模型方向和证据，后者只给评价词。

## 风格标签解压

风格名称存在三种不同身份，不能混用：

```text
人类风格标签：古偶唯美、港风、日系清新等；负责检索、沟通与选择方向。
平台风格预设：平台在界面中提供的外部实现；可能同时改变多个隐藏通道，未公开时不猜其配方。
作品结果图成像合同：本项目把胜出方向写成可继承、可检查、可迁移的正式视觉合同。
```

标签只是压缩后的名字。解压时不是追求把所有摄影术语写满，而是确定哪些通道共同证明同一审美承诺，再让视觉资产按当前图片任务选择性编译。

### 结果图成像合同

```text
审美承诺：观众第一眼进入怎样的世界，对象被怎样观看。
表现媒介：真人摄影、2D、3D、绘画、定格或混合媒介。
风格母体：一个主类型与一个主成像传统。
名称锚点：一个主锚点；按需一个只负责单一机制的机制锚点；文化根系另行限定。
单一主成像基底：现代数字、35mm、16mm、早期数字、MiniDV、VHS等只选一个。
色彩与肤色：主辅色、明度、饱和度、肤色和环境色来源。
光影与影调：光源、方向、软硬、对比度、暗部、高光过渡与轮廓分离。
构图与空间：主体落点、观看距离、引导关系、留白、前中后景与纵深。
表面与光学：皮肤和材料反射、边缘响应、微反差、锐度，按需柔光 / 辉光 / 颗粒。
选择性不完美：按需一个有来源的不完美家族。
相邻类型边界：最容易滑向什么，以及用哪条正面关系保持区分。
连续继承：同一作品、系列或连续阶段默认继承；变体必须写触发与返回条件。
```

选择槽位不是投喂清单。合同完整，单张结果提示词仍只保留会改变当前主体、关系、构图与成像结果的内容。连续作品继承同一合同；只有剧情阶段、记录媒介、观看者或世界规则改变时才写局部变体和返回条件。

例如，`古风偶像剧唯美人物成像`若是当前胜出方向，可以解压为：真人古装偶像剧正片人物视觉；高明度、柔和中低对比；暖净肤色与青瓷月白的低饱和主色；大面积柔和天光配轻微逆光，暗部通透，高光缓慢滚降；现代数字成像为主，受控柔光与极细颗粒只负责消除数码硬感；中长焦、适度浅景深，环境仍保留题材证据。这个例子只说明解压方法，不是仙侠或古装人物的固定套餐。

## 锚点的选择层级

### 第一层：主锚点

决定观众第一眼属于什么审美世界。一个结果只设一个主锚点，优先选择与媒介接近的著名导演、影片、动画作品、摄影传统、画派或时代影像。主锚点必须写明它负责的首要机制，不能用一个名称同时替代人物、服装、场景、光色与摄影的全部设计。

### 第二层：机制锚点

按需补主锚点不够明确的单一通道；同一结果通常最多一个机制锚点，并显式限定它只负责什么，例如：

- 构图与留白；
- 色块与冷暖秩序；
- 自然光、舞台光或夜景光；
- 衣料运动、空气透视与空间尺度；
- 皮肤、木石、金属、丝麻或玻璃的质感；
- 平面造型、线条节奏或动画运动。

### 第三层：文化根系

为题材提供长期形态与色彩来源，例如敦煌壁画、宋代山水、汉画像石、浮世绘、包豪斯、表现主义、黑色电影、纪实摄影等。文化根系不能被拆成无语境图案，要转成曲直、疏密、色域、材料、光源和运动规则。

三个层级不是三个同权风格包。主锚点负责审美世界，机制锚点补单一控制通道，文化根系提供历史形态与材料来源；它们必须共同服务同一个原创对象。若多个名称都在争夺色彩、光影、构图和材质，返回重新分权，不能让模型自行平均。

## 结果写真交接格式

```text
主锚点：名称；召回目的。
机制锚点：按需填写名称；只负责哪一条构图 / 色彩 / 光影 / 材料 / 运动机制。
文化根系：名称；转译成哪些形态、色域、材料或节奏。
结果图成像合同：表现媒介；主风格母体；主成像基底；色彩与肤色；光影与影调；构图空间；表面与光学；选择性不完美；相邻类型边界；连续继承条件。
当前原创转译：落在谁、什么服装、什么场景、什么道具和什么观看结果上。
显式证据：图片中能直接检查的3—6项结果。
主动退让：哪些锚点机制、背景、装饰或质感不能争抢本图主注意力。
失效表现：名称消失后画面仍是泛化模板，或名称盖过当前人物和故事。
```

## 当前仙侠项目的推荐锚点组合

`师妹问师兄仙侠短剧`的结果写真可使用：

```text
主锚点：徐克《蜀山传》，召回东方仙侠的超常空间尺度、云海纵深和灵机进入现实世界的方式。
机制锚点：张艺谋《英雄》，召回克制而清楚的色块秩序、留白、人物剪影和衣料运动。
文化根系：敦煌飞天壁画与宋代山水，转译飘带 / 山径曲线、矿物色、云气层次与人与天地的尺度关系。
当前原创转译：只用于本项目原创宗门、原创角色、原创山径线服装系统、冷玉与星砂材料、云海和生活化仙门空间。
```

验收时去掉“仙侠、宗门、境界”等文字：人物服装、材料、背景空间、云气层次和光源仍应指向东方超常世界，而不是乡野古装、写实武侠或影楼古装。

## 资料依据

- [Midjourney Prompt Basics](https://docs.midjourney.com/hc/en-us/articles/32023408776205-Prompt-Basics)把主体、媒介、环境、光线、颜色、情绪与构图列为核心信息，并强调简洁、直接。
- [Midjourney Style Reference](https://docs.midjourney.com/hc/en-us/articles/32180011136653-Style-Reference)将色彩、媒介、纹理与光线作为风格引用的主要承载内容。
- [Adobe Firefly：Writing effective text prompts for video generation](https://helpx.adobe.com/firefly/web/work-with-audio-and-video/work-with-video/writing-effective-text-prompts-for-video-generation.html)把景别、人物、动作、地点和审美放进同一清楚结构，并明确光线、摄影、调色与氛围会改变结果。
- [Adobe Firefly：Writing effective text prompts](https://helpx.adobe.com/ae_en/firefly/web/generate-images-with-text-to-image/generate-images-using-text-prompts/writing-effective-text-prompts.html)建议使用具体、直接的描述，并明确感觉、风格和光线。
- [Fujifilm 专业影像资料](https://ir.fujifilm.com/en/investors/ir-materials/business-overview/main/0/teaserItems1/0/linkList/0/link/ff_presentation_202507_002e.pdf)把胶片模拟放在色彩饱和度与影调软硬的坐标中，支持把胶片名称继续翻译成可见的色彩和高光暗部响应，而不是只报型号。
- [Google：Ultimate prompting guide for image generation](https://cloud.google.com/blog/products/ai-machine-learning/ultimate-prompting-guide-for-nano-banana)建议像创意总监一样指定光线、镜头、焦点、调色、胶片与材料。
- [CLIP](https://arxiv.org/abs/2103.00020)说明自然语言可以调用模型已学习的视觉概念；[Prompt-to-Prompt](https://arxiv.org/abs/2208.01626)说明文本词语会影响空间布局和视觉关系。

名称锚点负责召回，具体机制负责可控，当前原创对象负责作品归属。三者缺一，结果要么平均，要么空泛，要么变成别人的内容。
