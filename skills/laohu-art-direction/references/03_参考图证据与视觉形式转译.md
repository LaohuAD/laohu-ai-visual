# 参考图证据与视觉形式转译

参考图提供证据，不替作品作决定。先保住承重关系，再选择表面语言。

本 Reference 只在参考分析、艺术转译、编辑主视觉、概念海报、系列视觉、图像蒸馏，或“结果只有表面风格、没有作品关系”的诊断中读取。普通制作资产、已经锁定的专业设计、纯结构校准板和不需要参考分析的日常图片不强制读取。

它补的是`来源事实怎样变成形式选择`，不新建海报、抽象艺术、Zine、点阵或双色负责人，不接管人物、服装、场景本体设计，也不把纸感、网点、撕纸、英文微字、上下分栏、双色或大留白设成默认答案。

## 一、先判断任务是否真的需要转译

### 进入条件

出现以下任一信号时进入：

- 用户给出一张或多张图片，要求分析、抽象、重组、转化或建立原创视觉系统。
- 用户给出参考集合，希望提取可复用机制，但不复制原图内容。
- 任务是编辑主视觉、概念海报、艺术化封面、系列视觉或图像蒸馏。
- 文章、主题、关系或情绪需要转成一个可见关系，而不是直接画成完整场景。
- 真实结果已经有明显风格表面，却没有源图、故事或当前作品独有的关系。
- 多个候选只换颜色、位置、滤镜、纹理或镜像，没有形成机制不同的方向。

### 不进入条件

- F、B、W、M、S、A 等制作资产只需继承已确认专业设计和固定版式。
- 用户已经锁定设计并要求零设计改动，只需要资产编译。
- 纯结构校准板、中性规格板或技术拆解板不承担编辑主视觉职责。
- 普通图片任务没有参考分析、艺术转译或关系蒸馏需要。

不进入不是降低标准，而是保护不同图片职责。制作资产要证明结构、身份和可生产性；编辑主视觉要组织观看关系。用同一套抽象语言处理两者，会同时损害两种结果。

## 二、输入图像角色与保真级别

先为每张输入图指定一个主要职责；只有确有必要时，才增加一个不冲突的次要职责。职责不清时，不能直接把图片交给模型“参考整体感觉”。

| 输入角色 | 必须保留 | 允许改变 | 不得继承 | 失效表现 |
|---|---|---|---|---|
| 编辑目标 | 用户明确要求保护的主体、事实与关系 | 已授权的环境、构图、表面、局部或媒介 | 未授权的身份变化和事实增删 | 输出换了主体、事件或产品，却声称只是视觉升级 |
| 身份参考 | 人物、产品、角色的稳定识别特征 | 动作、场景、摄影、光线和非身份表面 | 原构图、无关背景、瞬时表情和临时服装 | 人还在但不像本人，或新图被原背景和姿势绑死 |
| 结构参考 | 拓扑、比例、姿势、空间、运动路径或版式关系 | 当前对象、材质、色彩和风格 | 占位色、示意文字、编号和无关内容 | 结构失真，或把草图中的占位信息做成成品 |
| 风格参考 | 被点名的构图、色彩、材料、光线、边缘、再生产或文字机制 | 当前对象、内容与具体布局 | 原主体、原文字、品牌、故事和精确组合 | 变成换图不换作品，或直接复刻参考内容 |
| 版式参考 | 信息层级、图文关系、阅读路径和空间预算 | 坐标、字体、文案、对象比例和裁切 | 原文案、原字体组合、精确位置和品牌结构 | 只把参考中的图片替换掉，设计关系基本未变 |
| 辅助插入 | 一个指定人物、物体、纹理或局部片段 | 它在新构图中的尺度、位置和必要色光适配 | 辅助图的整体构图和无关环境 | 辅助对象反过来接管整张图的世界与版式 |

保真级别不能只写`高 / 中 / 低`。必须列出具体不变量：像素、身份、数量、比例、轮廓、颜色、空间关系、文字、Logo、可变区、不可变区和验证方式。

若用户要求原图像素、Logo、精确文字、产品结构或几何完全不变，优先选择蒙版、分层、排版、矢量、脚本合成等确定性方法。运行环境只能进行生成式编辑而无法验证时，必须明确降级声明或停止承诺“完全不变”；不能用肉眼相似冒充像素级保真。

## 三、先分开观察事实、推论与设计选择

### 观察事实

能够从输入中直接指出或测得的内容，例如对象数量、相对位置、轮廓方向、遮挡、色域、明度关系、文字、材料表面和空间路径。

### 推论

基于可见事实做出的含义或情绪判断，例如压迫、停滞、纪念、危险、疏离。推论必须带可见依据，不能把“我觉得孤独”伪装成图像事实。

### 设计选择

为了当前作品目的主动决定保留、合并、删除、转化或留空什么。选择不等于来源事实；它需要说明观看收益、代价和反转条件。

没有图片时，明确记录`没有照片观察事实`。可以从故事、文章、人物选择或关系因果中提取可见关系，但不能虚构镜头、人物外貌、地点材质或照片色彩，再把它们写成已观察证据。

## 四、参考集合：固定系统 / 可变系统 / 样本残留

只有一张参考图时，只能记录观察特征和当前推论，不能声称某特征在一个风格家族中高频出现。

多张参考形成集合后，才分三类：

- `固定系统`：在多数有效样本中重复，移除后家族身份明显丢失。
- `可变系统`：样本之间会变化，但家族身份仍成立，可以成为候选轴。
- `样本残留`：只属于个别作品的人物、文字、品牌、日期、地点、对象、颜色或精确版式，不复用。

固定系统不是“出现次数最多就自动保留”。要继续判断它是否服务当前作品目的、是否与权利边界冲突、是否只是采样偏差。可变系统也不是随意变化；必须标出变化后仍需保护的关系。

图片宽高、分辨率和色彩元数据应读取文件信息。主体占比、留白占比、视觉中心等无法精确测量时可以估计，但必须标记为估计，不能把目测写成精确统计。

## 五、视觉证据卡

根据任务选择必要字段，不机械填满：

```text
主要对象与完整关系：
辨识度最高的1—3项事实：
主质量与次质量：
主轴、边界和方向：
数量、分组、间隔与节奏：
重叠、遮挡和深度关系：
色彩角色及面积 / 明度 / 饱和度层级：
有意义的空白：
情绪推论及其可见依据：
不确定和不可推断内容：
```

`质量`在这里指视觉块面的重量和面积关系，不是画质。证据按四问排序：

1. 删除它后，当前对象、作品或关系是否失去辨识？
2. 它是否组织其他元素，而不只是独立细节？
3. 它是否因面积、明暗、饱和、孤立、重复或方向形成强对比？
4. 它是否属于当前图像和当前作品，而不是同题材通用符号？

优先保护同时满足多问的证据。不能因为一个细节很漂亮，就让它越过承重关系成为主视觉。

## 六、语义最小集与关系不变量

`语义最小集`回答：删到什么程度，仍然是这张图、这个故事或这个作品，而不是通用图标或同题材模板。

优先保留：

- 主次和相对尺度。
- 方向、路径、视线和运动趋势。
- 数量组、间隔、聚散和不等距节奏。
- 左右 / 上下、内外、包围、穿越、支撑和压住关系。
- 重叠、遮挡、前后顺序和尺度参照。
- 有意义的空白、缺口、出口和不可到达区域。

优先删除：

- 表面噪声与重复微细节。
- 无功能装饰和背景杂物。
- 不改变关系的纹理、粒子、光斑和伪旧痕迹。
- 泛化气氛和只为显得“设计过”的符号。
- 需要靠伪日期、伪坐标、伪档案号解释的装饰文字。

`关系不变量`不是把原图锁死。它只保护当前结果必须继承的主次、尺度、方向、数量、间隔、路径、重叠、包围或空白关系；对象形状、媒介、材质和具体位置可以在授权范围内变化。

双向停止门：

- 删到离开标题就无法识别当前对象或关系，说明`太抽象`。
- 保留到可以从形式近似还原完整原图，说明`太写实`或抽象不足。

语义最小集不是越少越高级。正确的最少，是刚好保住作品专属性和观看任务。

## 七、形式转译卡

每个承重形式必须能回指一条来源事实：

```text
来源事实
→ 保留 / 合并 / 删除 / 转化 / 留空
→ 质量 / 色域 / 轮廓 / 线 / 负形 / 节奏 / 裁切 / 重叠 / 比例 / 字体 / 再生产方式
→ 相对位置、尺度和主次
→ 它改变的观看结果
→ 失效与反转条件
```

### 可选择的形式动作

- `质量与色域`：平面、块面、岛状、带状、包围、断裂、压缩。它回答重量和边界，不自动象征某种情绪。
- `线与边界`：轴线、路径、地平线、轮廓残段、方向序列。它回答视线和运动怎样通过画面。
- `负形`：缺口、通道、孔洞、间隔、被省略的位置。空白必须保护关系或制造阅读，不是“高级感”的固定配方。
- `节奏`：不等距重复、聚散、密度变化、大小层级和停顿。它来自数量和间隔证据，不是随机散点。
- `空间`：裁切、偏心、重叠、遮挡、尺度反差和前后关系。它必须保住决定性证据。
- `文字`：标题、标签、反声、路径、质量、节奏、主视觉或不用。文字有职责才出现。
- `再生产方式`：摄影、点阵、网点、复印、版画、纸张、扫描、平面数字图形等。它必须具体改变边缘、密度、色层或有来源的缺陷，不是尾部风格标签。

形式库提供动作，不提供固定象征。同一条道路可以转成方向线、负形通道、色带或裁切边界，取决于它在当前作品中承担出口、阻断、距离还是时间；不能把“曲线等于柔和、红色等于危险”当作普遍答案。

## 八、复杂度压缩

输入越复杂，越不能逐项描写。树叶、人群、窗格、浪花、碎石、织物和城市细节优先压缩成质量、方向、分组、间隔与少量代表性节奏。

压缩顺序：

```text
先保护主关系
→ 合并同职责细节
→ 删除不改变关系的表面
→ 保留少量能证明来源的特征
→ 在正常尺寸和缩略图复验
```

复杂度压缩的目标不是简洁本身，而是让主关系在有限注意力中成立。简化后只剩通用圆、方、点、曲线时，应恢复一条当前作品最有辨识度的尺度、间隔、动作、路径或空白关系，而不是恢复完整场景。

## 九、色彩职责

每套候选中的颜色必须承担一种主要职责：身份、主次、入口、桥接、平衡、方向、空间分层、情绪事件或世界规则。

执行`色彩移除测试`：在内部假设移除该颜色。如果视线路径、视觉平衡、图地关系、连续性和含义基本不变，它只是装饰，应重新设计或删除。

窄色域、单色、综合色和高饱和都可以成立，前提是符合当前来源关系和观看目的。原图是窄色域或单色时，不为“丰富”强行补色；原图依靠颜色区分方向或身份时，也不能为追求极简把它无因删除。

## 十、文字与图像关系

先判断文字是否必要，再决定职责：补充事实、制造点击、形成反声、建立尺度、连接空间、打断秩序或成为主视觉。

文字不得自动退化为底部小标签，也不得因为“编辑感”制造伪日期、伪坐标、伪档案号、无意义英文和不可核验数字。

标题可以和地平线、道路、建筑、人物视线、动作方向、轮廓或安静区域建立同向、反向、穿越、夹持或留空关系。允许少量有意义的前后遮挡，但必须保护眼睛、嘴、关键动作、产品结构、Logo、决定性道路 / 出口和辨识性轮廓。

这里负责提供可重组关系和保护边界；真正用于发布的标题承诺、字数、点击任务和平台缩略图由`laohu-cover-design`决定。

## 十一、候选竞争

完整调用仍形成3—5套候选。艺术转译任务的相邻候选至少同时改变：

1. 一个承重关系，例如从包围变为穿越、从尺度压迫变为缺口出口。
2. 一种形式语法，例如从质量与负形组织变为轴线与节奏组织。

只换颜色、位置、纸纹、滤镜、字体或镜像，不算`机制不同`。

每案必须写：

```text
保护的来源事实：
保留 / 合并 / 删除 / 转化 / 留空：
观众第一落点与阅读路径：
当前形式为什么适合当前内容：
作品专属关系：
主要风险与淘汰条件：
重新开启候选条件：
```

固定系统保护家族身份，可变系统承担候选差异，样本残留不得进入。自动选出当前最佳，说明胜出如何强化主胜负手；没有硬伤但过于通用的漂亮方案不能因为“稳”而胜出。

## 十二、失败门与返回动作

| 失败 | 可观察表现 | 最早返回动作 | 重新进入条件 |
|---|---|---|---|
| 太写实 | 可以近似重建原图，细节和场景深度压过重新组织 | 回语义最小集，合并质量、删除表面、保留关系 | 主要形式不再依赖完整对象描摹 |
| 太抽象 | 离开标题无法识别当前对象或关系 | 恢复一条高辨识来源证据 | 去文字仍能读出当前关系 |
| 太泛化 | 形式可无损替换到大量同题材作品 | 恢复当前作品独有的尺度、间隔、动作、路径或空白 | 相邻替换会破坏含义 |
| 只剩装饰 | 色块、点线、纸纹和英文无法回指事实 | 删除装饰，重做视觉证据卡与形式转译卡 | 每个承重形式都有来源和观看作用 |
| 参考泄漏 | 复制原主体、文字、品牌、精确版式或受限固定组合 | 隔离样本残留，重设参考职责；必要时停止使用该参考 | 当前对象和关系已重新原创，泄漏内容消失 |
| 保真冒充 | 声称原图、身份、产品或文字完全未变但没有验证 | 降级声明或改走确定性合成 | 有可核验的保真证据 |

这些失败先回到最早断点。若形式转译卡已经正确保护来源关系，而视觉资产编译漏掉，回`laohu-visual-assets`；若卡、提示词和绑定都正确而实际结果偏离，才记录模型生成漂移。

## 十三、交付模板

```text
【任务触发】为何读取本Reference；若未触发，不伪造分析。
【输入图像角色与保真级别】每张图的主职责、具体不变量、允许改变、不得继承、验证方式。
【证据状态】观察事实 / 推论 / 设计选择；没有图片时明确写无照片观察事实。
【参考集合】固定系统 / 可变系统 / 样本残留；单张参考不冒充集合规律。
【视觉证据卡】对象关系、高辨识事实、质量、轴线、数量节奏、遮挡、色彩、空白、不确定内容。
【语义最小集与关系不变量】必须留下什么；为什么；太写实与太抽象停止门。
【形式转译卡】来源事实 → 形式动作 → 位置尺度主次 → 观看结果 → 失效与反转条件。
【候选竞争】3—5套机制不同方向；胜出、淘汰理由、重新开启条件。
【下游继承】人物 / 服装 / 场景 / 视觉资产 / 封面各自必须继承、允许变化、禁止越权。
【验证状态】文字压力测试 / 候选图测试 / 真实生成通过；未验证项不得冒充成立。
```

## 十四、双门验收

### 底线门

- 输入角色和具体保真不变量明确，不使用“参考整体感觉”代替职责。
- 观察事实、推论和设计选择分开；单张参考不冒充集合规律。
- 每个承重形式能回指来源事实，没有参考泄漏、保真冒充和无来源装饰。
- 相邻候选不是只换色、位置、纹理、纸张、字体或镜像。
- 制作资产没有被误改成海报、Zine或抽象面板。

### 巅峰门

- 候选在承重关系与形式语法上真正不同。
- 胜出方案强化当前作品主胜负手，不是最像参考样片的一案。
- 能说明保留、合并、删除、转化和留空分别改变什么观看结果。
- 正常尺寸、缩略图和去文字后仍保住必要关系。
- 能否决没有硬伤但过于通用的漂亮结果。

文字方案和行为场景通过，只能说明方法进入运行链。至少完成一次有参考照片、一次无图片命题的真实候选生成，并完成缩略图、去文字和制作资产保真回归后，才能判断视觉效果是否值得从`OBSERVE`升级为`KEEP`。
