# 叙事灯光与光源因果

当灯光承担人物登场、关系判断、信息隐藏、线索发现、空间揭示、危险逼近、阶段转折或跨镜连续性时读取。普通中性资产、结构校准板和灯光不承重的画面不强制读取。

## 1. 光先决定观众怎样理解，再决定画面怎样好看

灯光不是给情绪贴颜色，也不是把人物照亮。它通过分配`信息权限`改变观众此刻能看见什么、看不见什么、相信什么、怀疑什么以及等待什么。

先建立`叙事灯光合同`：

```text
观众解释任务：这一束光要让观众怎样理解人物、关系、空间或事件。
当前事实与人物行动：谁在什么位置做什么；什么不能被灯光改写。
信息权限：必须显露 / 可以暗示 / 必须隐藏；第一眼、第二眼和延后发现分别是什么。
光源动机：日光、窗、顶灯、台灯、舞台灯、火、车灯、屏幕、设备、法术或剧情异常从哪里来，谁能开启、遮挡或改变它。
空间条件：开口、距离、高差、遮挡、墙地顶材料、反射 / 吸光、烟尘雨雾和可见路径。
光的选择：方向、高度、相对面积与距离、软硬、亮度关系、色温 / 色偏、衰减、补光或负补光条件。
受光证据链：光源 → 人脸 / 身体 / 道具 → 材料反应 → 背景与空间 → 观众可见结论。
静态光态：当前一帧中主光、暗部、轮廓、背景和空气分别处于什么状态。
灯光变化事件：起始光态 → 触发 → 传播过程 → 结束光态；静态图记 N/A。
保护项：身份、结构、空间锚点、肤色 / 产品色、关键动作和必须可读证据。
反转条件：什么变化会让同一光型讲出另一种故事；什么情况下宁可不用这套光。
```

合同不要求把所有摄影术语写进模型正文。它先帮助内部做选择，再把真正改变像素的少数关系交给图片或视频提示词。

## 2. 光型不是情绪预设

方向名称只说明光与主体的大致几何关系，不自动携带情绪。同一种光型的结果会被光源面积、距离、角度、软硬、明暗比、曝光、环境反射、人物动作、脸型、肤色、衣料、空间和故事上下文共同改写。

| 候选关系 | 常见可见作用 | 成立条件与可能反转 |
|---|---|---|
| 顶光 | 加深眼窝与下方阴影，或把人物从周围划出独立光区 | 小而硬、近乎无补光时可形成审视与压力；大而柔、环境退隐时也可形成孤独、仪式或安静。不能把“顶光＝压迫”写成固定映射 |
| 侧光 | 建立清楚明暗交界，强化面部、衣料、食物、尘气和墙面纹理 | 日常窗光可以增加生活触感；暗侧吞掉表情时可以制造犹豫或秘密；若关系任务需要双方表情同时可读，强侧光反而会伤戏 |
| 逆光 / 侧逆光 | 分离轮廓、打开纵深、隐藏正面信息 | 柔和低反差可让人物像回忆或离别；强烈高反差可形成登场、危险或转折；补光过足会失去隐藏，曝光过低会丢身份与动作 |
| 伦勃朗式面部光 | 前侧上方照明在暗侧面颊留下三角亮区，保留脸部体积并限制情绪信息 | 它首先是面部受光图案，不是一个故事类型；人物朝向、鼻影长度、补光和眼神光改变后，沉稳也可能变成普通棚拍或不自然脏影 |
| 体积光 | 借烟、尘、雾、雨或微粒显出光的路径，建立尺度、方向和纵深 | 体积光不是独立光源；必须先有来源和传播介质。光束指向人物或物件时可形成登场、发现或启示，遍地无来源光柱只会成为装饰 |
| 底光 | 让阴影方向违背日常面部经验，突出下颌、鼻底和眼部异常 | 冷色手电 / 应急灯可产生陌生与不安，低位暖火可形成亲密、秘密与共同体；不能把“底光＝恐怖”固定化 |

还要允许更普通但更正确的答案：正面柔光、阴天环境光、室内实景灯、墙面反弹、地面反光、屏幕光、负补光和近乎无补光。克制的平光若能准确保存事实、表演和肤色，可以比强戏剧光更高级；“多层布光”不是质量等级。

## 3. 从故事任务反推灯光，而不是从灯光词反推故事

按以下顺序选择：

```text
故事事实与人物行动
→ 观众解释任务和信息权限
→ 场景内可以成立的光源动机
→ 2—3套光源—受光候选
→ 比较谁能让关键证据最清楚、竞争信息最退让
→ 检查反转条件、连续性和实现代价
→ 形成叙事灯光合同
```

每套候选至少写清：它让观众先看到什么、暗处保留什么、光从哪里来、人物和空间分别出现什么受光结果、为什么比另一套更适合、在哪种动作或机位下失效。

例如同样是人物上方来光：

- 深夜加班者的压力来自硬而集中的顶灯、眼窝与桌面阴影、周围办公区坠暗以及人物无法离开光区的关系。
- 舞者的仪式感来自较大较柔的顶光、身体和地面形成完整光区、环境缓慢退隐以及动作在光区内完成。

两者共享“上方来光”，但`观众解释任务、信息权限、光源面积、暗部组织、空间反馈和动作关系`不同。只写“顶光、压迫感”或“顶光、仪式感”都没有完成因果编译。

## 4. 参考帧用于观察结果，不用于伪造片场真相

逐帧拉片能提高观察效率，但`单帧不能还原灯位图`。画面已经混合了场景结构、遮挡、反弹、负补光、烟雾、镜头曝光、动态范围、镜头滤镜、调色和后期局部处理；同一种像素结果也可能由多种布光方案得到。

分析时分三层：

```text
可观察事实 / 布光推论 / 迁移选择
```

### 可观察事实

只记录画面真的提供的证据：明暗交界位置、阴影方向与边缘软硬、眼神光形状、发丝与身体轮廓、脸部可读范围、背景相对亮度、材质高光、颜色分离、衰减趋势、光束路径和空气介质。

### 布光推论

可以推测主光大致来自哪一侧和高度、光源相对大小、是否可能有补光 / 负补光、背景是否单独受光，但必须标记`高 / 中 / 低置信度`。不得从单帧声称知道灯具型号、精确灯位、功率、距离、色温数值、现场是否真实使用某种附件，除非另有幕后资料。

### 迁移选择

先分开：

```text
迁移不变量：观众解释、信息显隐、主暗关系、轮廓分离、空间纵深或材质强调等需要保留的观看结果。
迁移变量：新人物脸型肤色、服装材料、空间尺寸与表面、动作位置、摄影机角度、曝光和目标模型能力。
```

迁移的是机制，不是反推文本。换了人、空间、材料或机位后，应重新求解方向、面积、软硬、亮度关系和补光；不得把电影帧反推提示词整段复制到另一画面。

若参考来自连续片段，再观察光随人物、摄影机和事件如何变化。单张截帧适合研究当前光态，不能独自证明登场、离别、危险显露等时间性效果。

## 5. 把合同编译成可见语言

静态图片只写当前帧能看见的关系：

```text
有来源的主光及方向
+ 光源相对大小 / 软硬和衰减
+ 人脸、身体、关键道具的静态受光证据
+ 背景与空间的明暗关系
+ 材料和空气怎样响应
+ 必须保持可读或允许隐藏的信息
```

动态视频把灯光写成事件：

```text
起始光态
→ 谁或什么触发光源、遮挡或曝光关系变化
→ 光怎样扫过、熄灭、亮起、被遮住、穿过介质或沿空间传播
→ 人物、材料和背景按什么顺序响应
→ 结束光态留下什么新的信息、关系或危险
```

“灯光变暗、气氛更紧张”不可执行；“列车进入隧道后窗外日光被连续截断，冷白应急灯逐盏接管车厢，人物脸上的阴影由侧向快速切成自下而上，隧道深处仍保持黑暗”才形成可观察变化。

## 6. 边界与失败返回

- 场景设计负责光源在空间中的位置、开口、遮挡、反射材料和可变状态，不替逐镜决定表演光态。
- 视觉资产负责把已确认合同编译成静态受光证据；身份、服装、妆造和空间校准板优先中性可读，不强加叙事光态。
- 视频提示词负责把变化编译成起点、触发、传播和结束状态，不重新发明作品级光影方向。
- 调色和曝光可以加强关系，不能替代不存在的光源与受光证据。
- 真实结果若光源无因、脸和关键证据被照坏、轮廓与背景粘连、材料反应错误或跨镜方向跳变，交复盘按第一个断点返回对应负责人。

候选没有光源动机但故事明确需要梦境、记忆、法术或主观异常时，不强行伪装现实灯具；把异常来源、触发条件、世界规则和恢复条件写清即可。现实动机与主观表达不是二选一，关键是观众能判断异常是有意发生，而不是模型随机打光。
