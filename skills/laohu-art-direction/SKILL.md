# 老胡美术风格设计

## 美术箴言

题材名称不是视觉证据，观众一眼认出的关系才是。

风格不是滤镜，也不是形容词堆叠。它是同一组世界判断在人物、服装、妆造、空间、道具、色彩、材料、光影和运动中的重复兑现。

## 职责与调用边界

本 Skill 是作品级`美术风格设计`的唯一负责人。它把已经成立的故事、受众、题材承诺、世界规则与媒介目标，转成各专业能共同继承的视觉方向：`题材视觉合同`、形态系统、色彩系统、材料系统、光影系统、文化来源、运动与世界物理、跨部门证据分配、相邻类型风险、候选竞争、胜出与淘汰理由。

它解决的是“这个作品为什么看起来属于这一类、又为什么不是相邻那一类”。它不替编剧改故事，不替人物设计选脸身，不替服装设计发明具体衣服，不替场景设计画空间，不替视觉资产写F / B / W / M / S固定画框，也不替视频提示词决定逐镜运镜。

- `laohu-script-writer`拥有故事题材承诺、世界事实、人物选择与观众体验。
- 本 Skill拥有这些事实怎样形成统一视觉语言、哪些部门必须提供什么可见证据。
- `laohu-character-design`、`laohu-costume-design`、`laohu-set-design`在该方向内完成各自原创设计与候选竞争；如果专业设计证明方向不可执行，携证据返回本 Skill重开视觉候选。
- `laohu-visual-assets`只把已经确认的美术方向和专业设计编译成资产提示词并验收生成偏差，不重新决定题材风格。
- `laohu-generation-review`在真实图片或视频中判断：是美术方向本身错误、专业设计没有兑现，还是资产生成发生漂移。

### 调用强度

| 方式 | 触发 | 本轮结果 |
|---|---|---|
| 完整调用 | 新作品、题材混合、系列首集、世界首批人物与地点、用户明确追求独特视觉、真实结果落入相邻题材 | 3—5套真正不同的视觉方向竞争，形成完整美术风格设计交接包 |
| 轻量调用 | 已有稳定风格下的新人物 / 地点 / 阶段；单个部门与总风格冲突；实际生成轻微漂移 | 继承主合同，只补当前证据、风险与部门边界 |
| 诊断调用 | 已有真实图片 / 视频，但遮住题名后题材归属错误或只剩通用漂亮 | 做相邻类型诊断，定位第一个断点，给最小回流动作 |
| 无需调用 | 已有人工确认且跨部门可执行的美术风格设计交接包；只做纯结构校准板且不承担作品风格 | 直接继承，不重复设计 |

先判定`美术风格设计授权状态`：`开放设计`允许建立新方向；`建议方向`保护用户给出的题材、气质、媒介或参考意图；`锁定风格`只在用户有权使用且明确要求零改动复现、同时现有证据足以覆盖跨部门语言时成立。只有一句“像某作品”或一张单角度图片不能锁定完整风格。

### 知识讲解的默认推荐与用户覆盖

当任务是`直译型说明 / 概念拆解 / 知识讲解 / 数据解释`，用户没有给出明确风格时，优先把`VOX式编辑视觉叙事＋纸质拼贴`列为推荐候选：它擅长让旁白中的对象、关系、比较、流程和证据逐步进入画面，并用纸片、档案图、图表、路径和文字层级形成可追踪解释。这只是`默认推荐先验`，不是所有知识视频必须采用的固定模板，也不等于复制 Vox 的品牌、字体、配色或版式。

用户明确描述或提供自己的风格时，进入`用户风格覆盖`：先保护其媒介、空间、色彩、材质、构图与运动意图，再围绕该方向产生可视化选项，不再为了统一流程强行加入 VOX / 纸艺。无论最终选择纸艺、手绘、写实、3D、像素、档案影像或其他风格，下游接力保持相同：`风格选项 → 用户人工定案 → 视觉母板 → 逐段关键帧 / 分镜图 → 动画编排 → 视频提示词`；变化的是母板内容，不是生产骨架。

### 参考证据与艺术转译调用门

出现参考分析、艺术转译、编辑主视觉、概念海报、系列视觉、图像蒸馏、来源关系丢失或候选只换色纹理等信号时，读取`references/03_参考图证据与视觉形式转译.md`。先判定`输入图像角色与保真级别`，再分开`观察事实 / 推论 / 设计选择`；没有图片时必须明确没有照片观察事实，只能从剧本、文章或关系因果建立可见关系，不得虚构图片证据。

普通制作资产、已经锁定的专业设计、纯结构校准板和不需要参考分析的日常图片不强制读取该 Reference。新方法只决定来源证据怎样进入视觉形式，不把 B / W / M / S / A 改造成海报或抽象面板，也不接管人物、服装、场景的对象本体设计。

### 叙事灯光调用门

当灯光承担人物登场、关系判断、信息隐藏、线索发现、空间揭示、危险逼近、阶段转折或跨镜连续性，或任务要求从电影片段、逐帧拉片和参考图提取灯光机制时，读取`references/04_叙事灯光与光源因果.md`。先建立`叙事灯光合同`，用`观众解释任务 → 信息权限 → 光源动机 → 受光证据链 → 静态光态 / 灯光变化事件 → 反转条件`完成作品级选择，再交场景、图片和视频分别落地。

普通中性资产、结构校准板和灯光不承重的画面不强制读取。`光型不是情绪预设`：顶光、侧光、逆光、伦勃朗式面部光、体积光和底光只是几何或可见结果的候选，不能固定兑换成压迫、神秘、浪漫或恐怖。逐帧参考只能形成`可观察事实 / 布光推论 / 迁移选择`；`单帧不能还原灯位图`、灯具功率和后期链路。先分开`迁移不变量`与`迁移变量`：前者保护观众解释、信息显隐和主暗关系，后者按新人物、空间、材料和摄影条件重新求解。

## 题材视觉设计工作流

### 1. 建立题材视觉合同

```text
题材视觉合同：作品 / 目标观众 / 媒介与发布场景 / 主类型 / 辅类型 / 两者关系 / 世界现实度与超常度 / 观众第一眼承诺 / 核心情绪 / 文化与时代来源 / 已确认事实 / 可设计范围 / 禁止误读 / 相邻类型 / 输出用途 / 权利边界。
```

`主类型`决定观众首先相信自己在看什么；`辅类型`只改变选定的通道，不能抹掉主类型。混合题材不使用机械百分比冒充判断，要写清：哪些视觉证据必须由主类型占主导，哪些通道允许辅类型改写，冲突时谁退让。

把信息分成`事实 / 推论 / 设计选择`。题材标签、市场分类和用户情绪词不能直接兑换成“蓝色、长袍、雾、电影感”；先问观众期待什么世界规则、人物能力、社会秩序和情绪经验，再寻找可见证据。

### 2. 把类型承诺转成视觉证据矩阵

建立`视觉证据矩阵`，按作品实际需要分配，不要求每格都装满：

```text
人物与身体：体量、姿态、行动方式、人与世界的关系。
服装与妆造：轮廓、层级、穿法、材料、工艺、照料与身份制度。
场景与建筑：尺度、空间权力、建造逻辑、自然与异常世界关系。
道具与图形：功能、技术 / 法术原理、符号系统、文字与纹样边界。
色彩与光影：主辅点睛色、明度结构、光源逻辑、情绪变化规则。
材料与表面：触感、重量、旧新、透光 / 反光、自然或超常来源。
运动与世界物理：重力、速度、风、布料、能量、身体与环境反馈。
摄影与媒介：构图密度、镜头距离、质感、2D / 3D / 真人的等效关系。
```

高辨识度不是把所有通道同时做满。先选本作品最承重的2—4个证据通道，再指定其他部门怎样托住。主要人物可以有意朴素、隐匿或近似凡人，但必须登记由群像、空间、道具、运动或世界异常怎样补偿题材归属，不能把例外误写成全世界默认值。

### 3. 建立六套共同视觉系统

视觉证据要汇成可以跨部门复用的系统，而不是零散关键词：

- `形态系统`：主导几何、轮廓节奏、比例关系、疏密、高低、曲直、开合和重复规则。
- `色彩系统`：基础色域、人物 / 阵营 / 地点关系、明度层级、饱和度范围、点睛色触发条件和阶段变化。
- `材料系统`：世界能获得什么、怎样加工、谁能使用、如何老化、哪些材料属于超常世界且仍有内在逻辑。
- `光影系统`：光源从哪里来、怎样塑造空间和身份、何时现实、何时异常、如何避免统一滤镜。
- 灯光承担叙事时，`光影系统`还要交付叙事灯光合同：观众解释任务、信息权限、光源动机、受光证据链、静态光态 / 灯光变化事件、保护项与反转条件；不承担时保持原有轻量系统。
- `文化来源系统`：历史、地域、宗教、民俗和艺术来源分别支持什么，不把来源符号拆成无语境装饰。
- `运动与世界物理`：人物、衣料、头发、武器、能量、自然环境怎样运动，哪些异常是世界规则，哪些只是特效。

每套系统同时写`保持项 / 允许变化 / 禁止默认 / 失败表现`。色卡是色彩系统的生产证据之一，不是风格本身；重要作品必须给出主色、辅色、点睛色、禁用关系与色彩触发条件，不能只写“高级、低饱和、仙气”。

### 4. 建立风格先验与美术锚点

作品级方向不能只靠`电影感、东方、仙侠、高级、精修真人`这类弱描述。对任何承担题材风格的结果图写真，必须建立`风格先验与美术锚点`，至少明确写入一组人类已有共同认知、在训练语料中具有高识别度的著名导演、作品、艺术家、摄影传统、艺术流派或时代影像风格名称。名称负责把模型召回到成熟审美分布，可迁移的视觉机制负责把召回结果落到当前原创内容。

一个结果只设一个主锚点，用来决定观众第一眼进入哪一种审美世界。按需增加的机制锚点通常最多一个，并必须写清它只负责哪一条可见通道，例如只负责大色块关系、逆光层次或空间纵深；文化根系负责纹样、衣制、器物和空间语法，不与主锚点争夺整体画风。若多个名称不能排出主次和职责，先退回方向比较，不把同权重名称打包交给下游模型猜测。

每组锚点必须同时写清：

```text
名称锚点：著名导演、作品、艺术家、摄影传统、艺术流派或时代影像风格。
召回目的：希望它优先召回的空间尺度、构图、色彩、光线、材料、镜头或运动经验。
可迁移的视觉机制：能直接进入本项目的构图关系、色块秩序、光源逻辑、材质触感、空气感或形态节奏。
原创转译：上述机制怎样服务当前人物、世界、场景和故事，不复制原作角色、剧情、标志性服装或场景内容。
失效表现：只剩名称、只剩滤镜，或画面换一个题材也成立。
```

名称不能替代可见描述，但也不能因为已经写了可见描述就删掉名称。正式结果写真采用`名称锚点＋可迁移机制＋当前原创对象`三者同时出现；制作规格板、校准板和技术拆解板不机械重复三段式与全部名称，只继承其中会改变版式、色彩、材料、光影和观看重点的共同内核。

不同媒介可以选择不同名称锚点，但必须服务同一题材视觉合同。真人结果图优先使用导演、影片、摄影传统与时代影像；2D可以使用动画导演、动画作品、画派与版画传统；3D可以使用成熟影视、游戏、雕塑或概念设计传统。需要建立、校准或迁移锚点时读取`references/02_风格先验与结果图美术锚点.md`，并消费共享风格库`02_共享资产库/02_视觉语言资产/画面风格库/画面氛围与画质规范.md`，不得让已经沉淀的成像基底、色彩影调、光影、构图、材料与选择性不完美停留在未调用资料里。

#### 风格标签解压

风格标签先解压，不能直接冒充正式提示词。把人类选择的短标签、平台提供的`平台风格预设`和作品自身的`结果图成像合同`分开：短标签用于检索，平台预设是外部实现手段，成像合同才是同一片子持续继承的作品权威。平台未公开的隐藏配方不得猜测；应先从共享`画面风格与画质规范`的`可复用的作品成像母版`选择最接近的成熟方向，再按当前题材调整表现媒介、主风格母体、名称锚点职责、单一主成像基底、色彩与肤色、光影与影调、构图空间、表面光学、按需一个选择性不完美以及相邻类型边界。它们是内部选择槽，不是要求全部进入每张模型正文。

连续作品继承同一结果图成像合同；只有剧情阶段、记录媒介、观看者或世界规则发生变化时，才建立局部变体和返回条件。

### 4A. 触发时建立来源证据到形式的中间结果

命中参考证据与艺术转译调用门时，在方向竞争前形成四项可检查结果；普通任务不机械增加这些栏目：

1. `输入图像角色与保真级别`：每张图只设一个主要职责，写具体必须保留、允许改变、不得继承和验证方式；像素、Logo、精确文字或几何完全不变时优先确定性合成。
2. `观察事实 / 推论 / 设计选择`：可见事实不与情绪解释混写；单张参考不冒充集合规律，多张参考才分固定系统 / 可变系统 / 样本残留。
3. `语义最小集与关系不变量`：确定主次、尺度、方向、数量、间隔、路径、重叠、包围或有意义空白中哪些必须留下；同时执行太写实与太抽象双向停止门。
4. `形式转译卡`：把每条来源事实编译成保留 / 合并 / 删除 / 转化 / 留空，再选择质量、色域、轮廓、线、负形、节奏、裁切、重叠、比例、文字或再生产方式，说明观看结果、失效与反转条件。

形式转译卡只承接来源关系，不替当前作品决定点击承诺，也不把纸感、点阵、双色、撕纸、留白或英文微字设成默认风格。每个承重形式必须能回指来源事实；无法回指的装饰先删除，不交给下游模型碰运气。

### 5. 让3—5套方向竞争

完整调用形成3—5套真正不同的候选。至少改变两个承重系统，且至少一个改变作品怎样被观众识别，而不是只换色卡、滤镜、纹样、天气或材质。

每个候选写清：题材解释、主视觉关系、承重证据通道、形态 / 色彩 / 材料 / 光影 / 运动系统、文化来源、对人物服装场景的影响、相邻类型风险、媒介风险、主要收益、淘汰风险。一般任务由AI自动选出当前最佳，记录`淘汰理由`和`重新开启候选条件`；当风格定案将控制整批关键帧、系列内容或用户明确要求自己选择时，AI只给推荐与理由，保留`用户人工定案`节点，不得把推荐冒充确认。

候选必须主动调用行业成熟机制和人类已有视觉传统。著名导演、作品、艺术家或流派名称是审美召回锚点，不是当前内容来源；当前人物、剧情、场景和服装仍由本项目原创设计。不得把原作的标志性角色、剧情、服装、场景或品牌识别直接搬入当前内容，也不得只写一个名称后让模型猜测全部设计。

艺术转译任务还要满足：相邻候选至少改变一个承重关系和一种形式语法，形成`机制不同`的方向。换颜色、位置、纹理、纸张、字体、滤镜或镜像不构成新候选。每案写清保留、合并、删除、转化、留空以及观众先看什么；固定系统保护家族身份，可变系统承担差异，样本残留不得进入。没有硬伤但过于通用的漂亮方案不能因为稳妥自动胜出。

### 6. 做相邻类型边界测试

涉及明显题材归属、混合类型或已经发生风格漂移时，读取`references/01_题材视觉证据与相邻类型边界.md`，至少执行：

1. `去标签测试`：去掉作品名、宗门、职业、境界和说明文字，单看画面是否仍能读出主类型。
2. `去背景测试`：去掉云雾、山峰、霓虹、废墟等最常见背景捷径，人物、服装、道具是否仍提供类型证据。
3. `相邻替换测试`：画面不改能否直接放进最近的相邻类型；如果能，主类型证据不足。
4. `跨部门一致性`：同一形态、色彩、材料、光影或世界物理关系是否在至少两个承重部门被不同方式兑现；如果只有一句提示词或一个装饰，尚未形成风格。
5. `例外补偿测试`：某人物或地点有意隐藏题材特征时，其他可见通道是否明确补偿；没有补偿就是漂移，不是克制。

测试不要求“每个仙侠人物都发光”“科幻一定有霓虹”“恐怖一定低照度”。它判断的是类型承诺有没有通过适合本故事的视觉关系成立。

### 7. 分发到专业设计与资产编译

胜出方向要转成部门可执行接口：

```text
交给人物：第一眼归属、身体与动作方向、群像差异、不可越过的刻板印象边界。
交给服装：世界服饰制度、轮廓 / 材料 / 色彩 / 工艺证据、身份层级、相邻类型风险。
交给妆造：年龄与身份呈现、发型轮廓、妆面质地、装饰文化来源、镜头距离证据。
交给场景：世界地点语法、空间尺度、材料经济、光源与异常规则、布景密度。
交给道具：技术 / 法术原理、形态与材料系统、使用反馈和图形边界。
交给视觉资产：已确认风格合同、色卡、风格先验与美术锚点、可迁移的视觉机制、参考边界、生成提示词必须显化的证据和验收反例。
触发艺术转译时交给视觉资产：参考职责、具体保真不变量、胜出形式转译卡、不得继承的样本残留和验证等级；视觉资产只编译，不得重做候选。
触发发布主视觉时交给封面：可重组的图文关系、语义保护区与事实边界；点击承诺、标题和平台缩略图仍由封面负责人决定。
交给视频：世界物理、运动、光影变化、声音与特效边界；不替逐镜编译。
灯光承重时交给场景 / 视觉资产 / 视频：同一份叙事灯光合同；场景落实光源位置与反射条件，视觉资产编译静态受光证据，视频只编译起始光态、触发、传播过程和结束光态。
```

下游可以在自己的专业范围内原创和比较，但不能默默改写主类型、色彩逻辑、材料经济和文化来源。若下游发现合同不可执行，返回证据和受影响通道，由本 Skill重开最小范围，不让视觉资产层临时补风格词。

## 美术风格设计交接包

```text
【任务判断】完整 / 轻量 / 诊断 / 无需；美术风格设计授权状态；保护项与权利边界。
【题材视觉合同】主类型、辅类型及关系；观众第一眼承诺；现实度 / 超常度；核心情绪；相邻类型；禁止误读。
【事实与来源】事实 / 推论 / 设计选择；文化与行业来源；支持范围；不得推出；高风险缺口。
【候选竞争】候选A—E的主视觉关系、承重通道、系统差异、收益、风险；自动胜出、淘汰理由和重新开启条件。
【胜出视觉方向】一句可被各部门共同执行的视觉判断；主胜负手；选择性克制。
【风格先验与美术锚点】著名导演、作品、艺术家、摄影传统、艺术流派或时代影像风格；召回目的；可迁移的视觉机制；当前原创转译；失效表现。
【结果图成像合同】风格标签的正式解压；表现媒介；主风格母体；名称锚点及职责；单一主成像基底；色彩与肤色；光影与影调；构图空间；表面与光学；按需一个选择性不完美；相邻类型边界；连续继承与阶段变体条件。
【视觉证据矩阵】人物、服装妆造、场景、道具、色彩光影、材料表面、运动物理、摄影媒介的必须证据 / 支撑证据 / 可省略项。
【形态系统】主导几何、轮廓节奏、比例、疏密、曲直、开合；保持 / 可变 / 禁止 / 失败表现。
【色彩系统】主色、辅色、点睛色、明度与饱和度关系、触发条件、阶段变化、禁用关系；可执行色卡。
【材料系统】来源、加工、阶层与阵营使用、表面与老化、超常材料逻辑；禁止默认材质。
【光影系统】光源、明暗结构、现实与异常切换、人物与空间关系；禁止统一滤镜。
【叙事灯光合同（触发时）】观众解释任务；信息权限；光源动机；受光证据链；静态光态 / 灯光变化事件；保护项；反转条件；参考帧的可观察事实、布光推论置信度与迁移边界。
【文化来源】历史 / 地域 / 宗教 / 民俗 / 艺术来源及其支持范围；不可挪用的标志性外形。
【运动与世界物理】重力、速度、风、衣料、能量、身体与环境反馈；特效边界。
【相邻类型测试】去标签、去背景、相邻替换、跨部门一致性、例外补偿的结果与首个失败点。
【参考证据与形式转译】触发时填写：输入图像角色与保真级别；观察事实 / 推论 / 设计选择；固定系统 / 可变系统 / 样本残留；语义最小集与关系不变量；形式转译卡；验证状态。未触发时写“不适用”，不得伪造参考分析。
【部门分发】交给人物 / 服装 / 妆造 / 场景 / 道具 / 视觉资产 / 视频的必须继承、允许变化和返回条件。
【验证状态】文字压力测试 / 候选图测试 / 真实生成通过；未验证项不得冒充已成立。
```

## 双门验收

### 底线门

- 主类型、辅类型、观众承诺和相邻类型明确，不用题材名替代视觉判断。
- 至少一个承重视觉系统跨两个专业部门有可执行证据。
- 色彩、材料、光影和文化来源不是悬空形容词。
- 承担题材风格的结果写真含有明确名称锚点、可迁移机制与当前原创对象；不能只剩名称或只剩泛化风格词。
- 已完成去标签、去背景和相邻替换测试；有意例外有补偿。
- 下游职责清楚，视觉资产不会被迫重新设计风格。
- 艺术转译任务没有参考泄漏、保真冒充、无来源装饰和只换表皮的伪候选；普通制作资产没有被强制改造成编辑主视觉。

### 巅峰门

- 3—5套方向在作品如何被识别上真正不同，不是同一方案换滤镜。
- 胜出方向强化本作品的主胜负手，而不是“最像这一类”的平均答案。
- 主类型一眼成立，同时保留人物与故事独有的关系，不靠堆满典型符号。
- 文化来源被转化为世界规则和视觉关系，不是符号拼贴。
- 真人、2D、3D或AI生成保留同一视觉关系，而非机械复制表面。
- 艺术转译候选在承重关系与形式语法上真正不同，胜出方向保留当前作品专属关系，并能否决漂亮但通用的结果。

只有文字方案时标记`美术风格设计稿通过`；只有实际候选图通过相邻类型测试后，才标记`候选图验证通过`；真实图片或视频通过后才标记`真实生成通过`。

## Reference 路由

- 新题材、混合题材、题材归属漂移、需要高质量作品机制校准或需要区分相邻类型时，读取`references/01_题材视觉证据与相邻类型边界.md`。
- 需要为结果写真选择著名导演、作品、艺术家、摄影传统、艺术流派或时代影像锚点，把风格标签或平台预设转成作品可继承的结果图成像合同，或校准同一作品的色彩、光影、构图、介质和表面一致性时，同时读取`references/02_风格先验与结果图美术锚点.md`与`02_共享资产库/02_视觉语言资产/画面风格库/画面氛围与画质规范.md`。
- 灯光承担叙事、需要比较光型候选、从电影逐帧 / 参考图提取灯光关系，或同一种光在不同故事任务中需要重新求解时，读取`references/04_叙事灯光与光源因果.md`；形成合同并分发后停止，不把灯光名词表装入每个下游任务。
- 用户提供一张或多张图片要求分析、抽象、重组或原创转译；任务是编辑主视觉、概念海报、系列视觉、图像蒸馏；无图命题需要形成可见关系；或真实结果只有表面风格而丢失来源关系时，读取`references/03_参考图证据与视觉形式转译.md`。
- 普通轻量继承已有完整交接包时不必读取Reference；只核对受影响通道和返回条件。
