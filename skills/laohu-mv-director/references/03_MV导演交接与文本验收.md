# MV 导演交接与文本验收

## 一、文本产物层级

根据任务停在用户要求的阶段，不机械交付全部栏目：

1. 歌曲任务合同。
2. 歌曲事实卡与证据置信度。
3. 导演命题、候选竞争与胜出路线。
4. 歌曲—视觉结构图。
5. 生产时间线与分镜导演卡。
6. 视觉资产图片任务交接。
7. 视频提示词交接。

这些全部是 Markdown 文本。图片任务中的`【@资产】`、首帧、尾帧和音频名称只是待绑定职责；没有真实文件时不能写成已经生成、上传、识别或验收。

## 二、歌曲—视觉结构图

```text
| C段 | 时间 / 相对位置 | 声音与歌词事实 | 段落功能 | 主要引擎 | 主要声画关系 | 视觉变化 | 交接 |
```

时间证据不足时写歌词范围和相对位置，并明确`待音频校准`。结构图记录歌曲真实创作段落，不服从任何模型的单次时长。

## 三、生产时间线

```text
| VID | 所属C段 | 全局范围 | 本地范围 | 时长与置信度 | 歌词 / 声音依据 | 表演方式 | 唯一主要兑现 | 分镜资产模式 | 下一接口 |
```

规则：

- 全局范围属于 Master Audio；本地范围从当前生成单元零点开始。
- 确定时长来自真实输入和目标模型能力合同，不从歌词字数猜测。
- 待校准单元可以给相对范围和候选边界，不伪装成可直接提交的时间参数。
- 生产单元覆盖目标版本全部声音，不重叠、不漏段、不静默删除尾音。
- 同一条时间线中不得把创作段落编号、生成单元编号和内部镜头编号混用。

## 四、分镜导演卡

```text
### VID{编号}｜{全局或相对范围}｜{单元短名}

所属歌曲段落：
声音依据与歌词范围：
本段观众任务：
主要 / 辅助声画关系：
人物与表演：精确跟唱 / 情绪表演 / 舞蹈动作 / 纯视觉。
唯一主要兑现：
起点状态：
精确触发：
变化与阻力：
决定性完成点：
结束状态与余韵：
分镜资产模式：单帧 / 首尾帧 / 多关键状态。
图片状态任务：每张图为什么存在、决定性瞬间、必须继承与不得提前出现。
连续性：人物、服装、场景、道具、构图、母题、声音和情绪余势。
下一单元第一项新变化：
目标模型能力合同 / 待确认缺口：
```

导演卡不写最终图片提示词，也不写正式三段式视频提示词。

## 五、交给视觉资产

```text
MV分镜资产任务：
对应 VID 与图片编号建议：
资产用途：稳定身份 / 单元首帧 / 单元尾帧 / 多关键状态 / 状态参考。
主观看任务与第一视觉落点：
人物、关系对象和决定性瞬间：
构图与屏幕方向：
作品级成像合同与阶段变体：
实际可引用的稳定资产：
必须继承 / 允许设计 / 禁止提前：
上下游状态：
图片提示词状态：待 `laohu-visual-assets` 编译。
```

同一单元有多张图时，每张图必须承担不同的时间状态或生成职责。只换景别、滤镜或姿势而没有状态差异，不建立多关键状态。

## 六、交给视频提示词

```text
VID、全局范围、本地范围与确定时长：
目标模型能力合同：
生成方式与实际绑定资产：
歌曲段落、歌词、声音事件和声画关系：
跟唱 / 非跟唱与表演依据：
起点、触发、屏幕变化、主要兑现、结束状态：
内部镜头候选与剪辑接口：
相邻单元必须继承：
未解决缺口与返回负责人：
```

如果分镜图尚未实际生成，只能写待绑定任务，不能假设图中已经有什么；如果时间仍待音频校准，不能进入正式视频提示词时长参数。

## 七、完成门

### 结构底线

- 三层结构完整且权威没有混淆。
- 每个创作段落有声音依据和主要声画关系。
- 每个生产单元有唯一任务、完整状态变化和相邻接口。
- 跟唱段写清人声、唱词、对象与可见嘴部；非跟唱段没有被强迫开口。
- 图片任务明确采用单帧、首尾帧或多关键状态，并说明原因。
- 全部结果保持文本状态，不出现伪媒体结果。

### 作品巅峰

- 胜出方向经过真正不同的候选竞争。
- 主视觉引擎和母题能够从开头发展到结尾，而不是段段换概念。
- 重复段落的意义改变可见，高潮完成全片最重要的声画相遇。
- 最强画面来自这首歌的关系、声音和结构，换一首同曲风歌曲不能直接套用。
- 图片和视频下游可以在不依赖创建聊天的情况下继续工作。

## 八、研究来源与本地边界

本能力吸收了外部 `mvmaker-h3-skills` 中“歌曲创作结构与生产分段分层、四类视觉引擎、五种声画关系、分段表演与口型、不可变阶段交接”等机制。来源：<https://github.com/penposs/mvmaker-h3-skills>，审计提交 `796797030275fe57afaba736771e8510c848799d`，Apache-2.0。

本项目没有复制其平台执行链、固定时长、固定宫格、音频切片、任务队列、下载或合成流程；它是研究来源，不是运行时外部 Skill。当前本地权威是 `laohu-mv-director`，以后来源更新也必须重新经过能力进化与行为回归。
