# 视频提示词 Vibe Creating 优化

## 能力定位

把已经生成好的正式视频提示词初稿，进行一次 Vibe Creating 提纯，再交还给 `laohu_video_prompt` 输出给老胡。

本 skill 不是替代 `laohu_video_prompt` 写提示词，也不是新增一套视频提示词格式。它只负责在正式视频提示词结果出来之后，检查这条提示词是否适合 VC 优化，并在适合时优化画面表达、情绪体验、关键意象、视觉统一性和低价值技术噪声。

最终交付给视频模型的正文仍只能是：

```text
【基础设定】
【氛围与画质】
【画面内容】
```

## 知识地基

执行前优先读取：

- `AGENTS.md`
- `02_共享资产库/00_核心规则手册.md`
- `skills/laohu_video_prompt/SKILL.md`
- `02_共享资产库/05_工具流程/外部优化Skill/vibe-creating-prompt/SKILL.md`

其中 `外部优化Skill/vibe-creating-prompt/SKILL.md` 是飞书文档提取的原始 skill 内容，不要改写原文。当前 skill 只负责把它接入老胡 AI 视觉项目的三段视频提示词流程。

## 能力加厚纪律

执行顺序固定：

```text
laohu_video_prompt 生成三段正式视频提示词初稿
→ laohu_vibe_creating_prompt 读取初稿
→ 按 vibe-creating-prompt 判断是否适合 VC 优化
→ 优化画面表达、情绪体验、关键意象和体验连续性
→ 把优化结果重新落回三段模板
→ 交还 laohu_video_prompt 写入展示文件或全分镜结果文件
```

VC 优化必须遵守本项目硬约束：

```text
不能改变三段模板。
不能改变确定总时长。
不能删除或改写用户明确指定的台词、旁白、音乐、音效。
不能破坏已确认的分镜编号、镜头任务和资产一致性。
不能把摄影机物理路径、屏幕变化、焦点转移、动作受力、声音空间、切换触发和停点误判成低价值技术噪声。
不能压缩或改乱多主体运动账本中的世界 / 屏幕方向、朝向、共同惯性、速度变化原因、相对顺序、出画顺序和摄影机速度 / 轴线；也不能删除事件传播账本中的命中点、传播方向、材料失效、碎片落点、声场和永久终态。
不能把人体姿势变换账本里的约束解除、支撑点转换、肩胸骨盆与关节链、重心 / 旋转轴、四肢净空、首次接触和卸力顺序压缩回 `翻身、跳下、旋转、摔倒` 等概括动词。
不能删改角色动作语法中的能力等级、距离偏好、起势、攻击几何、防守 / 借位、场景利用和回收节奏；不能把不同人物磨成同一套通用连招。连续动作中，上一招形成的遮挡、失衡、空位、掉落物、反作用力和下一招入口必须保留。
不能把攻击来路、逼近速度、提前占位、接触瞬间短暂清晰、结果高速余势和决定性瞬间误判为重复动作描述。VC 可以减少无贡献的特效形容词，但必须保证主体轮廓、攻击线、接触点和人物能力证据比光效更清楚。
不能在正式模型正文中重新加入 `镜头01 / 镜头02 / 镜头N` 标签，也不能把连续镜头叙事切成互不承接的独立段落。动作、遮挡、视线、焦点、声音、光色峰值和运动方向承担切换桥梁时必须保留；新画面的姿势、道具状态、动作余势、空间方向和声场继承不能被优化掉。
首尾帧双端锚定模式中，不能删除或弱化首帧 / 尾帧引用、不变量、变化量、共同桥梁、中间状态链、尾帧召回、减速收束和落帧校正；默认保持完整描述，只有老胡明确要求超限适配时才允许重写重复措辞。
不能违背上游已经明确的人物关系、剧情反转、场景设定、动作结果和资产状态。上游未写明且属于体验连续性、感官连接、动作过渡、声音空间、光影呼应和情绪节奏的创意留白，可以主动增强，并在优化记录中标明新增决定。
默认不能为了缩短文字做任何精简，不能删掉空间坐标、人物站位、运动路径、避让方向、接触点、受力结果、镜头承接和情绪表演；只有老胡明确反馈某个平台实际超限并要求精简某一条时，才另做导出适配，原始完整版继续保留。
不能把判断、执行动作、补充说明写进正式投喂代码块。
不能把“前一个镜头”“下一个镜头”“后期备注”等场外说明写进提示词正文。
```

如果外部 `vibe-creating-prompt` 原文要求输出“判断 / 执行动作 / 输出结果 / 补充说明”，这些只用于内部优化记录或提示词外说明。正式投喂给视频模型的内容，只保留“输出结果”里优化后的三段提示词。

VC 优化不能把有身份的表达磨成平均值。遇到主视觉概念、风格核心、开场钩子、转场机制、结尾封面帧、人物情绪主句和声音状态主句时，先做反众数审美否决：检查它是否只是泛电影感、泛写实、泛治愈、泛国风、泛高级或普通情绪标签。如果原文已经有准确的关系压力、具体光影、可见留白、动作停点和作品身份，优化只能增强这些锚点，不能为了顺口把它改回 `高级电影感、情绪饱满、氛围浓厚` 这类公共模板。

VC 提纯的正确方向是“更具体、更可见、更有作品归属”，不是“更顺、更泛、更像漂亮说明文”。例如 `黑衣女侠在庭院舞剑，国风高级` 需要被提纯成月洞门、冷月侧逆光、墨黑衣料、剑脊高光、湿石板暗面、竹影留白和动作停点；不能只改成 `古风氛围更加浓烈，画面更有电影质感`。

VC 优化也必须独立提升观众代入，不能只压缩文字。检查观众是否知道人物为什么在乎、何时和人物获得信息、危险或快乐从哪里进入、身体和声场怎样响应、镜头是否给足等待与余波；在不破坏硬约束和总时长的前提下，可以重排感官证据、强化声音桥、动作触发、焦点迁移和尾帧余韵。全程贴脸、手持和刺激不是代入，体验连续性与呼吸同样重要。

遇到动作段，VC 先找本段唯一的主决定性瞬间，再检查前面的危险与速度是否把力量送到这里、后面的受力与环境余势是否把结果带出去。所谓提纯，是让观众更快看见这一瞬为什么厉害，不是把整段改成慢动作、命中定格、炫光堆叠或人物站桩。压迫、关系和崩溃段同样要有决定性瞬间，但它可以是最小动作、关系证据或控制破裂，不强制动作 Pose。

## 能力边界

可以优化：

- 过于机械、执行单味太重的画面描述。
- 低价值技术参数和不会提升生成效果的拍摄术语。
- 情绪方向不够清楚的画面内容。
- 视觉中心不够明确的描述。
- 多镜头之间共同体验不够统一的表达。
- 画面内容太散、太像说明书、不像可生成画面的句子。

不能优化：

- 剧本结构、分镜编号和镜头总时长。
- 已确认资产外观。
- 用户明确指定的台词、旁白、音乐和音效措辞。
- 严格功能演示、UI 教程、参数保留型执行稿。
- 需要精确对白同步的长篇剧情片段。
- 决定模型执行的运镜物理路径、主体 / 背景可见变化、焦点迁移、速度层、画外声源和时长预算；默认完整保留，不能删除因果。
- 老胡明确要求“不要做 VC 优化”的提示词。

## 输入判断

收到视频提示词初稿后，先判断：

```text
是否已有三段模板：
是否有明确视觉锚点：
是否有明确主体动作或状态：
是否有局部调性：
是否有视频主题和画面风格：
是否包含用户硬约束：
是否包含低价值技术噪声：
是否适合 VC 优化：
执行动作：直接放行 / 轻度提纯 / 直接改写 / 原样保留 / 先补问
```

注意：老胡项目里的视频提示词通常已经经过剧本、分镜和资产阶段，因此优先选择“直接放行 / 轻度提纯 / 直接改写”，不要为了 VC 分类反复追问。只有视觉锚点、主体动作、风格方向严重缺失，且会影响生成落地时，才回退给 `laohu_video_prompt` 补问或重写初稿。

## 优化方式

### 1. 直接放行

适用：

```text
三段模板完整。
主体、动作、情绪、风格都清楚。
没有明显低价值技术噪声。
语言已经适合生成。
```

处理：不改正文，只在提示词外记录“已通过 VC 检查”。

### 2. 轻度提纯

适用：

```text
原提示词基本可用，但有重复、松散、过度说明或轻微机械感。
```

处理：压掉解释性语言，强化视觉中心、情绪方向和体验连续性。不得新增剧情。

### 3. 直接改写

适用：

```text
原提示词结构正确，但画面表达像执行单、参数单或说明书。
底层是情绪、故事或体验场景，适合转成更自然的生成语言。
```

处理：保留三段模板和硬约束，重写画面表达。低价值技术术语转成观看感受和可见画面结果。

### 4. 原样保留

适用：

```text
功能演示、UI 教程、参数必须保留、对白同步严格、老胡明确不希望 VC 化。
```

处理：不做 VC 改写，只可做错别字或格式级检查。

### 5. 先补齐

适用：

```text
缺视觉锚点。
缺主体动作或状态。
缺风格方向。
缺视频主题。
```

处理：优先在 VC 职责内补足体验连续性、感官连接和表达缺口；超出职责的故事或镜头缺口返回 `laohu_video_prompt` 主动补齐，不向老胡输出长问题。只有外部成本、法律安全或互斥核心定位才进入人工确认。

## 自检

- 是否已经读取外部原文 skill：`02_共享资产库/05_工具流程/外部优化Skill/vibe-creating-prompt/SKILL.md`。
- 是否没有改写外部原文 skill 内容。
- 是否只在 `laohu_video_prompt` 初稿之后执行。
- 是否保留了三段模板。
- 是否保留了确定总时长。
- 是否保留了台词、旁白、音乐、音效原文。
- 是否保留了资产一致性和已确认分镜编号。
- 是否没有违背上游明确剧情、人物关系或结果；新增体验、感官、连接与节奏创意是否已记录并继续交接。
- 是否真正提升观众代入，而不只是把句子压短或改顺；目标代价、信息、空间、身体、时间和选择中本段承重项是否更清楚。
- 是否没有把 VC 判断标签写进正式投喂代码块。
- 是否没有把具体、有作品身份的表达磨成泛电影感、泛写实、泛治愈、泛国风或漂亮说明文。
- 首尾帧双端锚定提示词是否保留不变量和变化量、主变换机制、摄影机路径、尾帧召回与收束，没有为了流畅删掉落帧因果。
- 高价值视觉表达是否已经通过反众数审美否决，保留了具体场景、光影、构图、动作、声音、留白和作品关系。
- 是否保留了空间、动作、表演、声音和前后因果的生成必要信息，没有为了文字更短破坏可执行性。
- 是否保留多主体世界运动与屏幕相对运动的区别、共同惯性、相对顺序和摄影机轴线；复杂破坏的事件传播链是否仍完整可执行。
- 复杂人体动作的关键姿势相位是否完整保留，支撑点、重心、旋转轴、四肢路径和落地卸力是否仍能被模型看见。
- 是否交还给 `laohu_video_prompt` 写入第一个分镜展示文件或全部分镜提示词结果文件。
