# 日本版面与文字空间机制

当文字本身承担第一落点，画面包含两级以上信息、展览 / 编辑 / 系列身份，或用户提出日本海报、纵横混排、网格、密度、留白、错位与不工整版面时读取。只有一个短标题、图像关系已经成立且没有排版判断缺口的普通人物 / 产品封面，可以不加载。

本 Reference 吸收的是日本文字文化与平面设计中的可迁移机制，不提供一套“日式海报模板”。它必须和 `laohu-cover-design` 的点击承诺、第一落点、标题—场景轴线、语义保护区与缩略图验收一起使用；不能用版面实验覆盖平台任务和内容事实。

## 一、研究结论：日本设计不是一种版式

日本设计内部同时存在秩序、空白和破格，彼此并不统一：

1. **文字先有组法，再有风格。** 日本语组版的可靠资料从组方向、文字揃え、字间、行间、版面、段和文字组块开始。它们建立阅读的基础秩序，不等于视觉一定克制。
2. **空白不是少放东西。** 原研哉所说的“空っぽ / emptiness”来自特定品牌哲学：保留受众参与和解释的空间。它不能被简化为白底、小字或“高级感”。
3. **破格不是无规则。** 日本平面设计也有仲條正義式的分散、浮游、不稳定构成，以及故意改变既有阅读秩序的实验。破格成立的前提是观众仍能识别信息、体验到改变，而且这种改变与作品身份相关。
4. **没有普遍正确的间距。** 专业资料反复强调字形、字号、行长、字间、行间和版面空间需要针对当前内容作视觉调整。固定栏数、固定倍数和固定坐标只能是某一成品的结果，不能冒充理论。
5. **“日本感”极易变成刻板包装。** 竖排、红黑米白、毛笔字、细小英文、印章、留白、裁切巨字和纸张纹理都不是日本设计的共同本质；没有内容机制时，只是在复刻传播市场中的日本想象。

因此，本项目不建立“日本风格开关”。每次只吸收能改变当前阅读、关系、节奏和识别的机制。

## 二、版面是空间中的阅读程序

先把文字和图像视为一组有先后的动作，而不是一堆待摆放元素：

```text
观众从哪里进入
→ 哪些信息被看成同一组
→ 视线沿什么方向移动
→ 在哪里停顿、转向或被打断
→ 哪条决定性信息完成承诺
→ 哪个空位或次级信息负责余韵与出口
```

完整的`版面骨架`至少写清六项：

```text
基本阅读方向：横向、纵向、环绕、向心或从主视觉向外展开。
信息组块：主标题、补充说明、事实证据、日期地点、署名分别属于哪一组。
对齐骨架：文字和图像共同依附的真实边界、基线、中心、轮廓或重复间隔。
密度地图：高密、中密、低密分别在哪里，为什么需要这项对比。
间距层次：组内怎样聚合，组间怎样分开，版面场怎样留出呼吸或悬念。
结构例外：哪一个元素故意越界、错位、放大、旋转或改变方向，它打断什么。
```

只写“8栏网格、留白很多、错落排版”不算骨架；这些词没有说明关系和作用。

## 三、网格从承重边界长出来

网格的职责是让多个元素共享关系，并在改标题、换比例和增加信息时仍能重排。选择网格前先找：

- 语义保护区的边缘：脸、眼睛、产品结构、关键动作、主符号不能被侵占的范围。
- 图像中的承重线：地平线、墙缝、道路、桌沿、人物视线、产品轴线、强明暗边界。
- 必须复用的文字边：主标题起边、二级信息起边、日期地点信息栏、系列 Logo 边。
- 裁切与比例变化后仍能保留的关系：哪些边能从 `3:4` 重排到 `16:9`，哪些只能服务单一画幅。

然后使用能表达这些关系的**最少轨道**。两块内容只需要一条分界和一条共同起边时，不要为了专业感虚构十二栏；日期、地点、主办方等多组信息需要反复对齐时，才增加模块和内部栏。

网格成立的可观察证据：

```text
删除它后，至少一个文字组失去共同起边、图文关系、比例重排依据或系列复用逻辑。
```

如果删除所谓网格后画面完全不变，它只是解释性标签。

## 四、间距不是空值，是分组语言

间距同时存在于四个尺度：

| 尺度 | 主要任务 | 失败表现 |
|---|---|---|
| 字形之间 | 修正不同字形造成的视觉松紧，保住词语整体 | 数学等距但视觉忽松忽紧 |
| 行与行之间 | 让标题按语义成句，并控制阅读速度 | 每行像独立标题，或粘成难读色块 |
| 信息组之间 | 告诉观众哪些内容属于同一层、哪一层已经结束 | 主副标题、日期地点和署名看起来同权 |
| 组块与画布 / 图像之间 | 建立焦点、停顿、压力、边界和余韵 | 文字只是悬空贴在“剩余空白”里 |

不用固定倍数替代视觉判断，但必须形成清楚级差：**同组关系最强，相关组次强，不同阅读阶段明显分开**。多数时候靠距离建立强弱；刻意疏排的标题也可以靠共同基线、起边、字重、包围或重复节奏维持一组。组间没有比组内更强的分界时，观众会把不同职责误读成同一段；为了“疏朗”把同一标题拆散，又没有补上其他组块信号，也会破坏语义。

中文、日文、数字与拉丁字母混排时，按可见字面而不是字符方框做光学校正。数字和欧文的基线、宽度与视觉重心可能不同，不能只靠软件默认等距。图片模型无法可靠执行精细字距时，提示词仍要锁定组块、对齐和层级；真实生成失败后按主 Skill 的既有边界进入精确后期排版，不伪称模型已经完成专业组版。

## 五、密度决定速度，留白决定停顿

密度不是“字多”或“元素多”，而是一个区域内同时要求观众辨认多少关系。先画内部密度地图：

```text
高密区：第一落点或必须连续读完的信息组。
中密区：为主信息提供对象、原因、时间或身份。
低密区：分隔阶段、保护轮廓、制造停顿或让观众补完。
```

自媒体缩略图通常把高密度集中成一个短而强的簇，其他信息主动退让；展览海报、出版封面和系列视觉可以让密度在多个区域间迁移，但仍要有明确入口和结束。

每块留白必须说明一种职责：

- `聚焦`：隔离一个小而重要的标题、脸、器物或结果证据。
- `分组`：切开两个阅读阶段，使二级和三级信息不与主标题同权。
- `延迟`：让答案、人物或器物晚于标题出现，形成悬念。
- `压力`：把主体挤向边缘、出口或标题，表达不平衡关系。
- `补完`：只给必要线索，让观众参与解释。
- `裁切余量`：为多画幅和发布界面保住承重内容。

“高级、日系、呼吸感”不是职责。删除这块空白后阅读和关系没有变化，它就是未使用面积。

## 六、纵排、横排与混排

日本语资料证明纵排与横排都是完整的组版系统，同一版面也可以按职责混用；这不等于任何中文海报使用纵排都会更日本。

先选基础方向，再决定是否混排：

| 条件 | 优先判断 |
|---|---|
| 手机信息流、问句、数字、英文、价格和知识标题承重 | 横排通常更快，先保完整语义与一秒识别 |
| 竖向人物、建筑、裂缝、帘幕或下坠路径承重，短标题可沿结构读完 | 可以测试纵排，让阅读方向成为画面动作 |
| 主标题与日期 / 地点 / 数据承担不同阅读职责 | 可以纵横混排，但每个方向只承担一类清楚任务 |
| 只是想要东方、日本、展览或高级感 | 不使用纵排作为装饰答案 |

纵横混排每增加一次方向切换，就增加一次认知成本。只有切换能制造必要的转向、交叉、阻断或身份区分时才保留。中文项目不能直接照搬日文假名节奏、禁则和标点位置；真实纵排必须用中文字体、标点、数字和目标平台重新验收。

## 七、秩序与破格

破格先要有可被观众感知的秩序。先建立至少一项稳定关系：共同起边、重复间隔、同一阅读方向、模块序列或明确中心；再允许一个承重元素改变规则。

合法破格包括：

- 标题越过图像边界，让文字成为空间压力。
- 一个字或一个信息组偏离基线，证明停顿、裂缝、失衡或人物处境。
- 一个次级组改为另一方向，把观众转交给日期、地点或出口。
- 分散构成让多个元素形成浮游场，但整张画布而非单一大图成为主视觉。

破格必须回答：`它打断了什么、观众因此先后看见什么、为什么比守规矩更准确`。只为显得先锋而随机错位、旋转、拉伸和散排，属于噪声。

分散构成尤其需要节制。仲條正義的案例说明它可以把“一点集中”改成全场浮游的视觉体验；同一机制放进手机缩略图却可能直接摧毁第一落点。日常点击封面只有在缩小后仍能压缩成一个主簇时才使用；展览、系列身份和艺术海报可以承担更长阅读时间。

## 八、四类候选骨架

候选用任务区分，不用文化标签区分：

| 骨架 | 适合 | 主胜负手 | 主要风险 |
|---|---|---|---|
| `焦点压缩` | 自媒体标题、人物 / 产品点击封面 | 标题、主体与证据压成一个强簇 | 退化成通用大脸大字 |
| `轴线通行` | 有道路、墙缝、视线、动作或产品轴线的画面 | 图像结构直接负责阅读路径 | 轴线只是构图解释，缩小后消失 |
| `模块编辑` | 展览、课程、档案、系列、日期地点较多 | 信息组块清楚，跨比例可重排 | 小字和标签表演设计感，内容变冷 |
| `分散张力` | 艺术海报、实验排版、身份型系列 | 全画布节奏与不稳定感成为作品记忆 | 第一落点丢失，随机错位难以生成 |

3—5 个候选不必覆盖四类，但不能只在同一骨架内换颜色、字体和左右位置。候选比较时同时写明：哪个骨架服务当前任务、哪个已知风险使它被淘汰。

## 九、编译成提示词

内部完成专业判断后，模型正文只保留可见关系，不投喂研究术语和来源解释：

以下只演示怎样把判断翻译成可见关系。示范前提已经确认：这是一张 `16:9` 知识视频封面；主标题“先别急着做”与副标题“判断错了，努力越多越浪费”逐字锁定；正片截图确实包含人物用红笔划掉待办清单的动作，桌沿在画面中形成清楚水平线。若真实输入没有这些事实，不得借用。

```text
主标题“先别急着做”保持为一个紧密的横排文字组，与人物划掉清单的红笔动作共同形成第一落点；
副标题“判断错了，努力越多越浪费”沿桌沿的水平关系进入下一阅读阶段，字号和显著性退后一级；
人物、红笔和被划掉的清单集中成高密度事实区，标题外侧保留低密度隔离区，副标题附近只保留必要的裁切余量；
标题共同起边与人物手臂方向建立斜向压力，红笔可以越过清单边缘一次，但不遮挡脸、主标题和被划掉的结果；
不增加装饰性日文、伪英文、随机编号、无事实数据图或只为设计感出现的纵排。
```

这段示例说明的是组块、对齐、密度与留白职责，不是要求其他封面使用同一标题、红笔、清单、桌沿、斜向压力和横排。执行者必须先列出本次已确认的图像事实，再选择自己的骨架；示例中的对象和轴线不能反向注入当前任务。

## 十、底线门与巅峰门

### 底线门

- 基本阅读方向清楚，文字不会因混排变成无序跳读。
- 主、副、三级信息已经形成可辨认组块，组内与组间间距有级差。
- 对齐骨架来自画面事实、信息关系或系列系统，不是任意坐标。
- 留白有职责，网格有可观察作用，结构例外能说明打断对象。
- 纵排与日本元素没有被当作风格捷径。
- 缩略图、真实尺寸、灰度、模糊和多比例下仍保住目标信息。

### 巅峰门

- 同一真实承诺下，是否比较了至少两种骨架，而不是只换装饰。
- 胜出案的文字组块是否与人物、产品、道具或空间共同制造作品专属关系。
- 有没有一个规则正确但更像模板的候选应被淘汰。
- 破格是否只发生一次并击中作品关系，还是到处都在证明“会排版”。
- 留白、密度和间距是否共同控制观看速度，而非分别满足术语。
- 换掉作品标题和主体后，这套版面是否仍能无损套用；如果能，专属性仍不足。

## 十一、来源与证据边界

检索日期：2026-08-27。以下资料用于校准机制，不构成必须模仿的样式：

| 来源 | 可支持的事实 / 机制 | 不能推出 |
|---|---|---|
| [W3C《日本語組版処理の要件》](https://www.w3.org/International/jlreq/) | 日本语纵排、横排、段与部分混排有完整方向和配置规则 | 中文封面必须纵排，或纵排天然更东方 |
| [Morisawa「組むためのアルゴリズム」](https://www.morisawa.co.jp/culture/japanese-typesetting/01/) | 组方向、文字揃え、字间、行间、版面与文字组块是组版的基础变量；视觉间距不等于方框等距 | 固定字距、固定栏数适用于所有封面 |
| [Morisawa「組み方を考える」](https://www.morisawa.co.jp/culture/japanese-typesetting/10/) | 不同文字种、数字、欧文和符号的组合需要精细间距与基线调整 | 图片模型能自动完成专业混排 |
| [JAGDA / 山本太郎《今あらためて問う。タイポグラフィとは何か》](https://gdr.jagda.or.jp/articles/94/) | 字号、行长、行间、语间、字间和版面都是 spacing；没有普遍唯一答案，秩序也可被有意打破 | 所有实验破格都优于清楚阅读 |
| [JAGDA / 葛西薫「文字の先と端」](https://archive.jagda.or.jp/archive/event/2007/mojinosakitohashi/mojinosakitohashi3.pdf) | 文字间隔需要按字形周围的可见空白做光学校正 | 可以脱离字体和实际字样规定统一参数 |
| [MUJI / 原研哉「Visualize the philosophy of MUJI」](https://www.muji.com/jp/flagship/huaihai755/archive/hara.html) | “空っぽ”服务受众自由参与和解释，是特定传播哲学 | 白底、小字、极简和少信息等于日本设计 |
| [JAGDA《仲條正義という方法》](https://gdr.jagda.or.jp/articles/37/) | 分散构成、字间、罫线与留白可以共同产生浮游和不稳定体验 | 把元素散开就会高级或先锋 |
| [JAGDA《ステレオタイプ・タイプフェイス》](https://gdr.jagda.or.jp/articles/31/) | “Japanese style”字体和视觉符号可能再生产对亚洲的刻板想象 | 用毛笔、竹节、印章或伪汉字能证明文化真实性 |
| [日本设计中心「富山県立近代美術館ポスター」](https://www.ndc.co.jp/projects/tad-poster/) | 系列海报的长期价值来自可持续识别和打破同类模板 | 固定一套坐标和颜色就能建立系列身份 |

外部资料中的具体作品、版式、字体、色板、文案和品牌身份不进入本项目模板。研究只在它改变当前候选、选择和否决时算生效。
