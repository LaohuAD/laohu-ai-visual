# 老胡封面与海报

## 封面箴言

封面可以留悬念，不能多承诺。

封面不是正片摘要，也不是随便截一帧加大字。它要把正片真实价值压缩成一个观众一眼读得懂、愿意点击、点开后不觉得被骗的视觉承诺。

## 输入与责任

日常封面在作品和最终视频提示词完成后执行。只有老胡明确要求概念海报、前期提案主视觉或以封面反推创意时才提前介入。

按接近观众实际结果的程度读取：

1. 最终成片与老胡确认的截图。
2. 最终视频提示词和发布定位。
3. 已确认人物、产品、场景、道具、色卡与固定 Logo。
4. 正式剧本、故事确认、分镜与故事板，用于核对事实。

成片截图可以只锁人物、服装和剧情状态，封面构图仍可重新设计。上游缺少干净身份或产品参考时回到 `laohu-visual-assets`；故事定位、事实和立场没有成立时回到 `laohu-script-writer`。

本项目默认只交付可复制的封面生图提示词，不直接生成图片。

## 点击承诺与视觉关系

### 最小封面简报

```text
作品与平台：
目标观众：
发布目的：点击 / 识别 / 追更 / 转化 / 收藏。
点击后真正能看到的内容：
观众此刻最关心的一个问题、欲望、异常或冲突：
不能误导的事实：
标题权限：逐字锁定 / 允许优化 / 需要生成。
可用人物、产品、场景、Logo、色卡和成片截图：
目标画幅：
```

能从作品可靠推断的直接补全；互斥方向会改变发布立场、标题事实或成本时再确认。

## 画面文字执行

### 参考图职责

所有实际引用直接写入最终提示词代码块：

```text
【成片截图参考@…】只锁人物造型、剧情状态和环境事实，允许重做封面构图。
【封面主体参考@…】只锁身份、脸、体态或产品结构。
【构图参考@…】只借图文层级和视线组织。
【风格参考@…】只借明确的材质、综合色或成像关系。
【Logo参考@老胡Logo】只调用固定 Logo。
```

没有实际参考就删除空占位。一个参考不能在没有说明的情况下同时锁死身份、服装、背景、构图和标题。

## Reference 路由

只有一个短标题、图像关系已经成立且没有排版判断缺口的普通人物、产品与剧情封面，不加载额外 Reference。

文字本身承担第一落点，画面有两级以上信息、展览 / 编辑 / 系列身份，或出现日本海报、纵横混排、网格、密度、留白、错位与不工整版面诉求时，读取 [references / 02_日本版面与文字空间机制](../laohu-art-direction/skills/laohu-layout-design/references/02_日本版面与文字空间机制.md)。该 Reference 只提供版面机制，不提供“日式风格开关”；必须写出哪条机制改变了当前候选或淘汰，不能只记录已阅读。

涉及传统图像、建筑、器物、纹样、非遗、文化品牌 KV、展览海报或文化版式时，读取 [references / 01_文化素材事实与视觉基因转译](skills/laohu-cover-concept/references/01_文化素材事实与视觉基因转译.md)。先区分原始 / 历史资料、当代二创、商业案例、版式参考和来源不确定材料；商业案例只学方法，不证明文化事实。未知经文、宗教图像、核心符号、法器、仪式和不明文字先隔离或标为待核验。

文化要转译成构图、尺度、材料、颜色、字体、留白和空间关系，不靠堆景点、图腾、服饰和纹样证明“东方”。

## 输出

日常结果写入当前作品：

```text
07_封面发布/文本/yyyy-mm-dd_封面提示词_<作品名>.md
```

默认只交付：

````markdown
【封面生图提示词】

```text
实际使用的参考及职责。
按当前画幅组织的主体、事件、第一落点、标题、光色、材质和安全边距。
主标题“……”
副标题“……”
```
````

内部简报、候选比较和淘汰理由不默认展示。只有老胡明确要求设计说明、A/B、系列体系、平台专版或复盘时，在同一文件追加，不另建空报告。

直接带字是默认路线。生成实测仍无法保证文字准确时，才退回“无字主视觉 + 后期精确排版”，不提前维护两套。

## 缩略图验收

- 一秒内能否认出主体、冲突或核心欲望。
- 日常自媒体默认版式下，标题是否在上方约三分之一形成完整居中文字组，主体视觉中心是否围绕画布中轴稳定，承重内容是否退出外圈安全边带；若偏离，是否有内容证据和胜过基线案的缩略图结果。
- 摄影机是否从可信的视角基线出发；强透视、偏心、斜切与贴边是否真正服务内容，而不是把“炫酷”误写成畸变和失衡。
- 缩小到约 10%—15% 后，第一落点、主轮廓和标题是否仍可读。
- 灰度、剪影和模糊观察时，层级是否仍然成立。
- 去色后第一落点、标题层级、图地关系和决定性轮廓是否仍成立；若失败，先回查是否把本应由结构承担的主次全部交给颜色，不机械加黑白描边。
- 标题、表情、道具和环境是否由正片真实内容支撑。
- 是否只有一个主承诺、一个主符号和一个第一落点。
- 是否像本作品，而不是可替换到任意同题材内容的模板。
- 标题权限是否正确，生成结果是否逐字核对错字、漏字、多字、乱序、标点、大小写和断行。
- 参考是否只继承声明的职责，没有带入第三方识别和无关构图。
- 标题—场景轴线是否来自当前画面事实，语义保护区是否完整；有限遮挡若存在，是否真的服务空间和阅读，而不是表面潮流。
- 基本阅读方向、信息组块、对齐骨架、密度地图和间距层次是否共同成立；结构例外是否只在有理由时打断秩序。
- 网格、纵排、混排、留白和分散构成是否改变了阅读与作品关系，而不是在表演日本、东方、展览或先锋感。
- `3:4 / 4:3 / 16:9` 是否在同一母版下都保住脸、标题、产品和安全边距。
- 固定 Logo 是否只调用原资产。
- 点击后真正能看到的内容是否兑现封面承诺。
- 是否只过了安全可用门，还是已经在同一真实承诺下选出最强点击关系；是否仍存在一个已知且明显更强的候选没有处理。

实际封面生成后交给 `laohu-generation-review`，以真实缩略图和发布数据判断，而不是用设计意图宣布成功。
