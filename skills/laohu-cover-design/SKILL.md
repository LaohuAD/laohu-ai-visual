# 老胡封面与海报

## 封面箴言

封面可以留悬念，不能多承诺。

封面不是正片摘要，也不是随便截一帧加大字。它要把正片真实价值压缩成一个观众一眼读得懂、愿意点击、点开后不觉得被骗的视觉承诺。

## 输入与责任

日常封面在作品和最终视频提示词完成后执行。只有老胡明确要求概念海报、前期提案主视觉或以封面反推创意时才提前介入。

按接近观众实际结果的程度读取：

1. 最终成片与老胡确认的截图。
2. 最终视频提示词和发布定位。
3. 已确认人物、产品、场景、道具、色卡与固定 Logo。
4. 正式剧本、故事确认、分镜与故事板，用于核对事实。

成片截图可以只锁人物、服装和剧情状态，封面构图仍可重新设计。上游缺少干净身份或产品参考时回到 `laohu-visual-assets`；故事定位、事实和立场没有成立时回到 `laohu-script-writer`。

本项目默认只交付可复制的封面生图提示词，不直接生成图片。

## 点击承诺与视觉关系

### 最小封面简报

```text
作品与平台：
目标观众：
发布目的：点击 / 识别 / 追更 / 转化 / 收藏。
点击后真正能看到的内容：
观众此刻最关心的一个问题、欲望、异常或冲突：
不能误导的事实：
标题权限：逐字锁定 / 允许优化 / 需要生成。
可用人物、产品、场景、Logo、色卡和成片截图：
目标画幅：
```

能从作品可靠推断的直接补全；互斥方向会改变发布立场、标题事实或成本时再确认。

### 四项承诺

```text
内容事实：作品真正给了观众什么。
点击钩子：哪个冲突、欲望、异常、身份或结果最值得先看。
主视觉符号：什么单一画面关系能让钩子被记住。
标题任务：文字补足画面不能独自说明的哪一层。
```

画面已经说清的内容，标题不重复念一遍。封面允许隐藏答案，不允许虚构成片没有的人物、怪物、关系、金额、结果、产品性能和冲突。

### 概念竞争

内容原生设计先在内部竞争 3—5 个机制不同的方向。每案至少改变两项：观众位置、人物与空间的压力、主符号、视觉进入路线、标题与主体关系、综合色来源。

文字承重时，候选还要改变`版面骨架`，不能在同一网格中只换字体、颜色和左右位置。焦点压缩、轴线通行、模块编辑与分散张力是可比较的骨架，不是四种必须轮流套用的样式；胜负仍由平台观看时间、内容关系和作品专属性决定。

不是同一张“大脸 + 背景 + 发光字”换颜色，也不是远中近景轮流交差。每案用一句话说明：

```text
先看到什么
→ 被什么阻断或加速
→ 落到哪一个决定性信息
→ 为什么想点开
```

筛选顺序：真实承诺、一秒识别、手机缩略图、作品专属性、可生成性、文字安全区和多比例裁切。

筛选通过只是底线，不能从“没有误导、文字可读、比例安全”直接进入交付。胜出封面还要在同一真实承诺下，把点击欲望、第一落点和作品专属性推到当前候选最高：如果另一个构图、主符号或标题关系能明显更快抓住目标观众，就继续竞争。极致不等于字更大、颜色更炸、表情更夸张；最强封面可以靠更准的异常、更狠的取舍和更大的留白获胜。

日常自媒体封面进入候选竞争时，至少保留一个遵守下节默认版式的基线案。偏心、压底、贴边、斜切、强透视或大面积遮挡案必须和它直接比较；不能因为破格案更像海报、更有概念或更“炫”就跳过基线。只有缩略图结果与内容关系都更强时，破格案才允许胜出。

系列模板只有在老胡明确要求续作、或栏目已经形成稳定识别时使用。继承的是关系与职责，不是固定颜色、坐标和装饰；内容变化仍要服务当期承诺。

### 第一落点

封面只保留一个第一落点，最多一个辅助中心。一般自媒体封面让标题成为第一文字层级，人物、产品、道具、视线和手势把注意力送过去；人物 IP 或产品识别承重时，主体与标题可以共同第一落点。

内部写清视觉通行：

```text
进入点：第一眼从脸、标题、手、产品、道具还是亮区进入。
加速 / 阻断：什么线条、前景、方向或明暗边界改变视线速度。
决定性落点：观众必须看到的冲突或利益证据。
余韵出口：什么空位、动作、反射或文字关系留下问题。
```

无法写清通行路线，说明画面还是名词拼贴。

### 日常自媒体默认版式

当任务是日常自媒体缩略图，且没有已确认系列模板、平台固定母版或内容事实要求特殊构图时，先使用以下默认版式，再决定是否破格：

```text
标题：作为一个完整横排文字组，水平居中放在画面上方约三分之一；标题组不压底，不塞进人物之外的剩余空隙。
主体：人物或产品的主体视觉中心回到画布纵向中轴附近；近景优先让脸、眼神和辨识性轮廓在中央稳定成立，再安排肩部、手势和背景动势。
边界：标题、脸、眼睛、产品结构与决定性轮廓退出外圈安全边带。日常生成可把画布四周约 6%—10% 视为只供背景出血和非承重装饰使用的缓冲区，实际平台遮挡更大时继续内收。
视角基线：人物近景默认从可信的平视或轻微仰视开始，使用正常透视建立压迫感；不把超广角畸变、斜切半张脸、任意偏心和贴边裁切当成“PV感”或“炫酷”的默认答案。
```

`上方约三分之一`、`中轴附近`和`外圈约 6%—10%`是老胡日常自媒体封面的项目默认关系，不是所有海报的固定坐标。居中指视觉重量围绕中轴平衡，不要求人物姿态、头发和装饰左右镜像。文化海报、剧情压迫、双人对峙、系列母版或平台界面可以改变标题位置与主体重心，但必须写清：内容里的什么关系要求偏离；偏离后标题位置、主体视觉中心、边界距离和缩略图为什么仍比默认基线更强。

### 版面骨架与文字空间

排版不是画面完成后把标题贴进剩余空白，而是把阅读顺序编进空间。内部先形成：

```text
基本阅读方向：观众横向、纵向、向心还是从主视觉向外阅读。
信息组块：哪些文字必须被看成同一组，哪些属于下一阅读阶段。
对齐骨架：文字和图像共同依附哪条真实边界、基线、中心或重复间隔。
密度地图：高密、中密、低密区域分别承担抓取、补充还是停顿。
间距层次：同组关系最强，相关组次强，不同阶段明显分开；关系可以由距离、共同起边、基线、字重或重复节奏建立。
结构例外：哪一个元素有理由越界、错位、放大或改变方向。
```

网格从语义保护区、图像承重线、文字共同起边和多比例重排关系长出来；栏数是结果，不是专业感。删除网格后如果对齐、裁切和重排决定都不变，就不必命名网格。

留白必须承担聚焦、分组、延迟、压力、补完或裁切余量中的至少一项；“高级、日系、呼吸感”不是职责。自媒体缩略图仍只允许一个第一落点；分散、多中心和长阅读版面只在展览、系列身份或艺术海报中有明确增益，并且缩小后没有摧毁主承诺时使用。

纵排、横排和混排先服从语言、语义、图像轴线与阅读成本。只是为了显得东方、日本、展览或先锋时不使用纵排；每增加一种阅读方向，都要说明它造成的必要转向、交叉、阻断或身份区分。

### 标题—场景轴线与语义保护区

标题不是在空白处随便找位置。先从当前画面事实中选择一条`标题—场景轴线`：地平线、道路、建筑边界、人物视线、动作方向、主体轮廓或安静区域；再决定标题与它同向、反向、穿越、夹持还是留空。轴线决定图文怎样共同制造进入、阻断、加速或余韵，不是固定坐标、固定左右布局或每张封面都必须斜排。

日常自媒体默认版式先以画布中轴和上方标题区建立稳定关系，再寻找内容轴线。内容轴线可以加强、轻微偏转或有证据地打破基线，不能反过来把标题推到边界、把主体切出中心，最后再用“轴线通行”解释已经失衡的结果。

排字、裁切和装饰之前，标出`语义保护区`：眼睛、嘴、关键动作、产品结构、Logo、辨识性轮廓，以及当前封面承重的道路、出口、包围、空位或关系证据。保护区来自内容责任，不是统一安全框；某项不承重时不机械保护，真正承重时不能为字更大或版式更潮而牺牲。

允许标题与主体形成少量`有限遮挡`，但同时满足：不破坏语义保护区；缩略图仍能辨认主体和标题；遮挡确实改变空间、关系或阅读节奏；没有夸大正文价值。纯装饰性压脸、压产品、压关键动作，或只为了模仿某张参考版式的遮挡，直接淘汰。无文字封面或没有必要前后关系时，遮挡可以不使用。

### 人物、空间与主符号

人物要处在事件里：有压力、有反应、有带态度的动作或不动作，并留下对手、道具或环境反馈。静止可以成立，但不能像模特等拍照。

摄影机位置要可信，构图从关系压力生长。门框、玻璃、桌面、走廊、空位和反射只有在改变人物关系时使用。受控不工整可以表达疏离、失衡和被监视，但不能遮掉决定性表情、标题和产品结构。

主视觉符号从故事因果里提炼，例如一次被推回的物件、一个不再有人坐的位置、一扇无法关上的门。符号必须参与人物关系或结果，不是找一件漂亮东西放大。

颜色、光线、颗粒、色散、旧纸和耀斑都要有画内来源与传播职责。默认蓝灰、青橙、霓虹、低饱和和胶片颗粒不能替代内容判断。

## 画面文字执行

### 标题权限

- 老胡提供并确认的主标题、副标题、片名和栏目名：逐字锁定，不润色、不缩写、不换同义词。
- 工作标题或明确允许优化：内部竞争 5—8 个口语自然、缩略图可读、与画面分工清楚的候选。
- 没有标题：从内容事实、观众利益 / 损失、异常状态、身份和未闭合问题生成；不从“AI 电影、东方史诗、治愈人生”等泛题材词命名。

正式片名建立作品身份，封面展示标题负责本次点击，两者可以不同，但职责要清楚。改变作品主题、事实或人物立场时必须回编剧。

### 文字层级

每个文字元素只承担一种职责：

```text
一级：主标题或最强点击句。
二级：对象、对比、结果、期数或类型补充。
三级：账号、日期、模型、演员或发行信息。
```

层级主要靠字号、字重、面积、位置、明暗和间距；描边、发光和多颜色不能同时抢眼。换行按语义，不遮挡眼睛、手势、产品结构和冲突证据。

先用组块和间距建立层级，再用字号和字重放大差异。通常让组内关系比组间更紧；刻意疏排的标题可以靠共同基线、起边或包围关系维持一组，但它与相邻元数据之间仍要有更强分界。数学等距不能替代对字形、数字、中文与欧文混排的光学校正。图片模型不能稳定执行精细字距时，先保证组块、对齐和层级，真实生成失败后再按既有边界进入精确后期排版。

所有真实出现在画面里的文字用中文双引号逐项锁定，并写清语言、标点、大小写、语义断行、层级、字重、颜色和相对关系。内部说明和风格词不用引号，避免被模型画出来。

固定 Logo 使用 `【Logo参考@老胡Logo】`，不靠键入 `laohu` 代替，不重画、改字、改比例、重着色或材质化。

### 参考图职责

所有实际引用直接写入最终提示词代码块：

```text
【成片截图参考@…】只锁人物造型、剧情状态和环境事实，允许重做封面构图。
【封面主体参考@…】只锁身份、脸、体态或产品结构。
【构图参考@…】只借图文层级和视线组织。
【风格参考@…】只借明确的材质、综合色或成像关系。
【Logo参考@老胡Logo】只调用固定 Logo。
```

没有实际参考就删除空占位。一个参考不能在没有说明的情况下同时锁死身份、服装、背景、构图和标题。

### 比例自适应

日常默认用一条提示词适配 `3:4 / 4:3 / 16:9`。写主体占比、标题层级、留白方向、相互遮挡、安全边距和裁切优先级，让模型按实际画布重排；不为三个比例分别复制三条提示词或写死坐标。

`9:16 / 1:1 / 21:9` 只有老胡点名时再扩展。系列模板需要用最长标题、多人主体、极简主体和不同画幅做压力测试。

## Reference 路由

只有一个短标题、图像关系已经成立且没有排版判断缺口的普通人物、产品与剧情封面，不加载额外 Reference。

文字本身承担第一落点，画面有两级以上信息、展览 / 编辑 / 系列身份，或出现日本海报、纵横混排、网格、密度、留白、错位与不工整版面诉求时，读取 `references/02_日本版面与文字空间机制.md`。该 Reference 只提供版面机制，不提供“日式风格开关”；必须写出哪条机制改变了当前候选或淘汰，不能只记录已阅读。

涉及传统图像、建筑、器物、纹样、非遗、文化品牌 KV、展览海报或文化版式时，读取 `references/01_文化素材事实与视觉基因转译.md`。先区分原始 / 历史资料、当代二创、商业案例、版式参考和来源不确定材料；商业案例只学方法，不证明文化事实。未知经文、宗教图像、核心符号、法器、仪式和不明文字先隔离或标为待核验。

文化要转译成构图、尺度、材料、颜色、字体、留白和空间关系，不靠堆景点、图腾、服饰和纹样证明“东方”。

## 缩略图验收

- 一秒内能否认出主体、冲突或核心欲望。
- 日常自媒体默认版式下，标题是否在上方约三分之一形成完整居中文字组，主体视觉中心是否围绕画布中轴稳定，承重内容是否退出外圈安全边带；若偏离，是否有内容证据和胜过基线案的缩略图结果。
- 摄影机是否从可信的视角基线出发；强透视、偏心、斜切与贴边是否真正服务内容，而不是把“炫酷”误写成畸变和失衡。
- 缩小到约 10%—15% 后，第一落点、主轮廓和标题是否仍可读。
- 灰度、剪影和模糊观察时，层级是否仍然成立。
- 去色后第一落点、标题层级、图地关系和决定性轮廓是否仍成立；若失败，先回查是否把本应由结构承担的主次全部交给颜色，不机械加黑白描边。
- 标题、表情、道具和环境是否由正片真实内容支撑。
- 是否只有一个主承诺、一个主符号和一个第一落点。
- 是否像本作品，而不是可替换到任意同题材内容的模板。
- 标题权限是否正确，生成结果是否逐字核对错字、漏字、多字、乱序、标点、大小写和断行。
- 参考是否只继承声明的职责，没有带入第三方识别和无关构图。
- 标题—场景轴线是否来自当前画面事实，语义保护区是否完整；有限遮挡若存在，是否真的服务空间和阅读，而不是表面潮流。
- 基本阅读方向、信息组块、对齐骨架、密度地图和间距层次是否共同成立；结构例外是否只在有理由时打断秩序。
- 网格、纵排、混排、留白和分散构成是否改变了阅读与作品关系，而不是在表演日本、东方、展览或先锋感。
- `3:4 / 4:3 / 16:9` 是否在同一母版下都保住脸、标题、产品和安全边距。
- 固定 Logo 是否只调用原资产。
- 点击后真正能看到的内容是否兑现封面承诺。
