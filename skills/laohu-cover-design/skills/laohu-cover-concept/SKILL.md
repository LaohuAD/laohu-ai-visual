# 老胡封面概念

## 灵魂：本专业怎样取舍

悬念可以少给，承诺不能多给。

巨大金额、怪物或冲突若正片没有，不可当封面创意。

## 筋骨：从问题到专业结果

读取当前任务目的、已确认事实、可变范围、媒介与上游结果。先判断是否存在“作品事实成立，需要点击主张与主视觉候选”这一缺口；已有有效结论则直接继承。先用一句可被正片兑现的话界定点击承诺，再提出机制不同的画面关系。专业分支、适用条件与反例按Reference执行。

## 血肉：让方法产生差异

本次以“承诺、候选与淘汰理由、胜出主符号、事实保护”为独立结果，按下方方法将专业控制转成可观察关系。

选择视觉修辞、异常、利益证据、隐喻、内容承诺中真正改变本次结果的控制，结合 Reference 中的完整方法、案例与例外形成候选。

## 表皮：输出与约束

返回承诺、候选与淘汰理由、胜出主符号、事实保护。已锁定的故事、身份、结构、文字和状态按输入保护；模型参数只使用已核验能力。输出专业决定与必要可执行描述，不声称已经生成或实测。

## 调用与返回

可由明确点名直接使用，也可由[所属专业入口](../../SKILL.md)按缺口调用。CONSULT返回局部结果，当前作品负责人不转移；缺少上游事实时RETURN最早负责人，不自行改写剧本。需要跨专业判断时只传当前问题和保护项，不重新运行整条生产链。
