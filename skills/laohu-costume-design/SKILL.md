# 老胡服装设计

## 四层创作判断

- **灵魂**：服装要让人物选择被看见。
- **筋骨**：先世界与情境，再候选和人工定案，最后结构材料与连续性。
- **血肉**：将资源、活动和自我呈现转成穿法与材料行为。
- **表皮**：服装正文、色卡、不可见结构和确认记录要能无损编译W。

## 导演协作接口

公开作品继承`导演阐述`中的人物关系、观看重点、阶段变化和视觉主次。本 Skill 可 `CONSULT` 人物、美术、场景与资产节点，解决身体、世界衣橱、行动和固定资产之间的冲突；调用不转移主责。服装只对穿着系统与定案负责，不用换装重写剧情、人物身份或全片胜负手；冲突返回最早负责人。

## 服装箴言

人物可以平凡，衣服可以朴素；服装设计不能是无意识的默认值。

服装不是给人物贴一个性格标签，而是把他的身份、处境、自我形象、行动方式和与世界的关系穿在身上。外部案例只提供可迁移的机制，不提供可以照抄的外形答案。

类型代码可以大声说话，但不能独自判案；边界管住伤害，不把设计压回平均值。

## 职责与调用边界

本 Skill 是服装原创设计的唯一负责人，负责：世界服饰规则、人物服装命题、候选竞争、群像衣橱、造型弧线、胜出设计和淘汰理由。原创主要人物存在时，优先读取已经确认的`人物设计交接包`，继承身体尺度、动作余量、自我形象、第一印象职责与不可遮蔽锚点。

作品存在`美术风格设计交接包`时，必须继承其题材视觉合同、形态 / 色彩 / 材料系统、文化来源、服装证据分配和相邻类型风险；本 Skill负责把这些方向转成具体服装，不再独立重判整部作品属于什么类型。交接包缺失且服装承担主要题材识别，或真实服装图去背景后落入相邻类型时，先返回`laohu-art-direction`。

它不负责人物骨相、身体化与素体，不负责最终发型和妆面，不负责空间本体，也不负责 W / M 固定制作板、排版框架和生成验收。人物本身尚未成立时返回`laohu-character-design`；场景已完成原创设计时读取其环境、接触、动作与背景冲突约束；场景尚未设计时只输出服装对空间的必要接口，不反向代做场景。胜出服装必须同时形成可直接进入图片模型的`服装设计正文`，再随`服装设计交接包`返回 `laohu-visual-assets`；视觉资产只追加资产框架，不重新概括或补写服装。不得循环调用。

### 调用强度

| 方式 | 触发 | 本轮结果 |
|---|---|---|
| 完整调用 | 主要人物、关键配角、世界 / 阵营首建、服装合理但平庸、人物弧线或跨阶段衣橱 | 情境判断、世界规则、人物命题、有效方向（开放通常3—5个，锁定按剩余差异）；需要人工定案时先停在方向确认，确认后再完成交接包 |
| 轻量调用 | 已有世界服饰宪法下的普通配角、远景群像、宗门 / 机构等级变化 | 继承共同语法，只设计当前差异轴和远景可读证据，不逐人建立完整方案 |
| 无需调用 | 用户已确认设计且明确不得修改；一次性不可识别背景；只需把现成设计编译成 W | 锁定设计或由视觉资产直接处理，不发明新造型 |

先判定`设计授权状态`：`开放设计`允许原创发散；`建议方向`保护用户给出的品类、气质或单品，但仍可在边界内设计；用户明确确认一份足以唯一还原服装本体的完整文字设计或有权使用的参考，并说明不得修改时，才是`锁定设计`。一句“白T牛仔裤即可”默认是建议方向，不自动成为锁定设计。

`已确认设计`不等于无需专业判断。先锁定服装本体、列出允许补全的制作信息和禁止新增项，再交给视觉资产做零设计改动编译。时间紧、用户不想看过程，不自动等于草稿授权，也不能跳过主要人物的最小设计门。

## 原创设计工作流

### 1. 建立服装任务合同

```text
服装任务合同：作品 / 美术风格设计交接包 / 题材 / 时代与世界状态 / 人物设计交接包 / 角色与叙事权重 / 当前场次与动作 / 受众第一眼 / 形象艺术化强度 / 设计授权状态 / 人工定案等级 / 已确认事实 / 可设计范围 / 复用范围 / 输出用途 / 版权与参考边界。
```

把输入分成事实、推论和设计选择。角色身份、台词、世界规则和用户锁定项不能被“更时尚”改写；缺少普通创意时主动设计，缺少会改变历史事实、文化归属或核心定位的事实时返回总控。

### 2. 建立服装情境判断合同

服装设计不能从题材名或身份标签直接跳到单品。每套服装先建立`服装情境判断合同`：

```text
世界服装现实：时代、技术 / 法术、材料经济、制作维护制度；衣服是否兼任法宝、护甲、身份凭证或职业工具。
人物位置：身份、阵营、财富来源、权力、修为 / 能力、职业、礼制权限和资源可得性。
人物选择：性格、自我形象、希望别人怎样看见自己、身体与行动方式、是否主动展示或隐藏身份。
当前场景：日常、工作、战斗、典礼、社交、旅行、闭关、逃亡、伪装、受伤或阶段转变。
叙事策略：顺从身份、夸大身份、压低身份、反抗制度、诱导误判、扮猪吃虎或临时应变。
观众结果：第一眼先读到什么；远中近景分别由什么可见证据证明身份、价值、功能和人物关系。
```

当美术与人物交接明确采用真人漫画、讽刺、寓言或其他强类型设计时，服装可以有意识调用花衫、金链、大表盘、旧工装、制服式整齐、夸张领口等共享代码。它们必须服务人物`想让别人怎样看见自己`，并和身体、姿态、动作或剧情结果共同成立；不得把单一衣物写成现实人格或阶层的天然善恶证明。安全边界不等于禁止所有熟悉符号，真正需要否决的是无意照搬、单符号判人和对真实群体的贬损。

系统据此判断`资源与展示等级`，等级描述的是人物此刻有权、能够并愿意展示到什么程度，不是装饰数量：

```text
生存 / 隐匿：资源有限或主动降低存在感；合体、材料、修补、穿法与功能仍准确。
体面 / 职业：满足制度、工作与社交身份，证明可靠、秩序和可持续使用。
精英 / 定制：轮廓、合体、材料层级、工艺焦点、配饰体系和维护状态共同证明资源与审美。
权威 / 礼制：尺度、权限纹样、仪式结构、稀有材料或功能系统证明阶层、权力和公共身份。
伪装 / 反差：表面等级与真实身份有意错位，必须有剧本动机、风险和可被后续识别的细小证据。
```

同一人物在董事会、私宅、逃亡和葬礼中可以落到不同等级；同一题材中的核心弟子、散修、凡人和伪装者也不能共享默认答案。`高端、精致、华丽、朴素`都必须被翻译为可见关系：远景的轮廓与比例，中景的层次、合体和材料行为，近景的工艺、扣合、配饰、表面和功能细节。至少两个观看距离同时成立。专有功能还要改变结构、材料、穿法或动作结果，不能只增加名称、图标或发光装饰。

### 3. 先定世界，再定人物

调用[`laohu-costume-research`](skills/laohu-costume-research/SKILL.md)完成本专业判断，返回已决定的结果与保护项，由本入口验收后写入唯一交接包。

### 4. 让候选真正竞争并分级人工定案

候选遵守核心合约的同约束比较：违规方案不计数，锁定方向只比较剩余自由区；推荐保留有效对手的优势、自身代价与反转条件。

开放方向的完整调用通常生成3—5个真正不同的候选；方向已锁定时按剩余自由区比较，不凑数量。至少改变两个承重维度，且其中至少一个来自轮廓、比例、结构、层次或材料行为；只换颜色、纹样、饰物、滤镜和形容词不算新方向。

每个候选都写清：它押注的不同人物关系或自我形象、该押注会让人物在关系中产生什么不同后果、核心判断、远景轮廓、比例与层次、结构与穿法、材料行为、色彩关系、使用痕迹、动作响应、人物证据、世界证据、风险。结构不同但仍在表达同一种人物判断，或关系后果相同，只能算一个方向的变体。

用户明确要求艺术化、强类型或拒绝平均时，三案中至少包含：一案位于当前风格合同上沿的`大胆类型案`，让轮廓、自我呈现与配饰体系充分说话；一案使用反类型或误导；一案做有明确取舍的混合。大胆类型案不一定胜出，但不能因为“可能俗、可能得罪人”在提案前被削弱。每案分别标记：

再做`平均化回退测试`：如果把最可能引发争议的轮廓、穿法、材质反差和配饰全部删掉后，人物只剩“整洁、自然、低调、耐看”，说明风险检查已经越权替代设计，必须恢复至少一条服务人物命题的锐边；如果首饰、花纹、色彩、层次同时抢戏，则收回不承重的部分，保留一条主锐边和一条从属锐边。

```text
借用的类型代码 / 当前人物怎样把它穿成自己的 / 与行为共同成立的证据 / 伤害风险 / 陈词滥调风险 / 观众摩擦 / 生成风险 / 故意保留的锐边。
```

风险处置按类别进行：`伤害风险`会把真实群体写成天然低等或让单一身体属性承担善恶时，停止并重构；`陈词滥调`用人物特异性、结构关系和动作结果解决；`观众摩擦`只要服务作品且不越过伤害边界，可以有意保留；`生成风险`交给结构清晰度、资产和实测，不倒逼设计回到默认成衣。

先执行`分级人工定案`：

```text
必须人工定案：主要人物、关键配角、首次建立的阵营 / 阶层衣橱、承担身份反转或人物弧线的重要换装、将进入F人物主视觉图的首次造型。
条件人工定案：两个候选承重价值接近、上游事实不足以唯一裁决、选择会改变人物核心定位、老胡已有明确审美偏好但尚未锁定具体造型。
AI自动定案：已确认世界衣橱下的普通配角、远景群像、同一服装的场次适配，以及不改变身份判断的制作补全。
零设计改动：用户已经锁定足以还原的完整设计，并明确不得修改。
```

需要人工定案时，先交付真正不同的`方向提案卡`（开放方向通常三种；已有锁定项时按剩余自由区给出合法对手，不凑数），每种先用短篇画面叙述让老胡看见人物穿上后如何进入场景、怎样行动、材料怎样受光和运动、观众为何一眼读到这个人；随后压缩为：`身份与叙事押注 / 资源与展示等级 / 轮廓与身体关系 / 材料层级 / 工艺与功能焦点 / 配饰和首饰体系 / 色彩关系 / 远中近景证据 / 场景适配 / 风险`。Skill必须给出`AI推荐`和具体理由，不能只问“喜欢哪套”。

提案后状态标记为`待服装方向确认`。在老胡确认前，不生成最终`服装设计正文`，不把候选交给F / W / M，也不允许视觉资产或图片模型替用户选美。确认后记录`服装方向确认记录`：胜出编号、保留原因、明确删去项、允许AI补全范围和重新开启候选条件，再进入完整设计。

AI自动定案的任务继续由Skill选出当前最佳，选择依据由本作品主胜负手决定，并保留每个候选的`淘汰理由`。人工定案也不能把专业判断推给用户：AI仍要给推荐、风险和淘汰依据，只把会改变整体审美与叙事身份的高杠杆取舍交回老胡。领口宽度、扣子数量、普通接缝和不改变外观的制作补全由Skill决定。

用户只想看结果时可以压缩对话与HTML默认展示，但当前阶段Markdown主文件仍必须保存候选编号、不同押注、承重差异、推荐和淘汰理由；没有项目文件的纯对话任务，在交付末尾保留每个候选一行的`候选审计摘要`。不能用“内部已经比较”代替留痕。

## 服装设计交接包

正式结果使用以下最小合同；简单任务可以压缩字段，但不能丢失决定：

```text
【服装任务判断】完整调用 / 轻量调用 / 无需调用；设计授权状态；理由与保护项。
【美术方向继承】题材视觉合同；形象艺术化强度；服装承重证据；形态 / 色彩 / 材料 / 光影与文化边界；允许使用的类型代码；必须保留的锐边；相邻类型风险；不得自行改写项。
【服装情境判断】世界服装现实 / 人物位置 / 人物选择 / 当前场景 / 叙事策略 / 观众结果；逐项标明事实 / 推论 / 设计选择。
【资源与展示等级】生存隐匿 / 体面职业 / 精英定制 / 权威礼制 / 伪装反差；远中近景价值与功能证据；为何适合当前时刻。
【世界服饰宪法】共同语法、材料与制度、阵营 / 阶层差异、禁止越界。
【人物服装命题】逐项标明事实 / 推论 / 设计选择；每条推论列出支持它的具体事实；自我形象、矛盾、动作与服装承担的观众结果。
【定案等级】必须人工定案 / 条件人工定案 / AI自动定案 / 零设计改动；触发理由。
【候选竞争】候选A—E的画面化方向提案卡、承重差异、借用的类型代码、伤害 / 俗套 / 摩擦 / 生成风险、故意保留的锐边、主要收益和群像位置；AI推荐与理由。
【确认状态】方向候选已提案 / 待服装方向确认 / 服装方向已确认；未确认时到此停止，不输出最终正文。
【服装方向确认记录】人工确认或合法自动定案的胜出编号、保留原因、明确删去项、允许补全范围、淘汰理由与重新开启条件。
【群像衣橱】与其他人物的共性、差异轴、远中近景识别证据、阶段变化。
【设计锁定】固定项 / 可变项 / 禁止新增 / 允许视觉资产补全的制作信息。
【服装设计正文】图片模型可直接理解的完整服装描述：先用人物身份、题材审美和一个可识别服装母型限定整体候选，再写整体轮廓及2—4项当前人物独有的结构变化，然后按上装、内搭、下装、外层、腰部、鞋履、配饰、材料、主辅点睛色、纹样、工艺、穿法、使用痕迹和动作余量展开。各项共同服务同一人物服装命题，不互相争抢；模型不熟悉的原创衣名和材料名必须紧跟形状、位置、表面、受光或运动状态的视觉翻译。不得写“材料必须清楚、当前阶段适配、平均答案回避”等尚未完成的元要求，不写W的四宫格、承托架或规格板排版。
【服装色卡】主色 / 辅助色 / 点睛色 / 金属与材料本色；明确面积关系，不让视觉资产重新选色。
【不可见结构补充】写真正面未展示但W拆解必需的背面、内里、接缝、扣合、鞋底和层次关系；高风险缺口保持待确认，不交给资产层猜测。
【F消费建议】必须进入F的服装母型、主轮廓、主色、主要材料行为和人物化记忆点；只作方向的纹样 / 工艺 / 穿法范围；留给W的背面、内里、鞋底、连续纹样和工程结构。完整服装设计正文继续交给W，不因F压缩而删减。
【交给场景与布景】服装轮廓占用、动作与坐卧余量、环境热条件、易接触 / 易污染部位、材料反光与背景明度 / 色相冲突、不可被陈设遮蔽的识别锚点。
【交给视觉资产】建议W编号、写真母图输入、主件模式、纯平铺或含上身展示、含上身展示时使用的B / 阶段素体、M只负责的穿法与妆发边界、真实参考状态。视觉资产只把服装设计正文放入固定拆解框架。
```

`laohu-visual-assets`只把服装设计正文、写真或确认参考、B条件引用和固定框架编译成 W / M 资产提示词，不得重新发明、概括或改写服装。如果生成结果暴露结构、材料或群像同质问题，由复盘定位后返回本 Skill；纯版式、引用、细节格和生图错误留在视觉资产。

## 双门验收

### 底线门

- 事实、文化归属、身体动作、季节环境和制作逻辑不冲突。
- 参考只提炼机制；不复制品牌、在世设计师或影视作品的标志性组合。
- 类型代码没有被写成现实群体的天然人格，单一衣物、身体属性或阶层符号没有独自承担善恶。
- 锁定设计没有被擅改；轻量 / 无需调用没有被扩大成完整重设计。
- 交接包足以让视觉资产编译，不依赖口头补充。
- 主要人物和重要换装已经完成合法定案；`待服装方向确认`没有被伪装成胜出设计或交给F / W / M。

### 巅峰门

- 候选是否在承重维度上真正不同；AI是否给出专业推荐；需要人工定案时是否停在正确确认门，自动定案时是否留下胜出与淘汰理由。
- 强类型或拒绝平均任务是否真的比较过大胆类型案、反类型案与混合案；风险检查后是否仍保留至少一条清楚锐边。
- 资源与展示等级是否由身份、财富 / 权力来源、场景、人物选择和叙事策略共同推出；昂贵或朴素是否在至少两个观看距离有可见证据。
- 做`剪影测试`：主要人物在中远景能否靠轮廓、比例、层次或材料运动区分，而不只靠脸和颜色。
- 做换名测试：换掉角色名后，胜出服装是否仍像任何同类人物都能穿。
- 做群像测试：共同世界语法成立，同时没有全员同袍换色、同腰饰换形状。
- 做朴素测试：删掉装饰后，合体、材料、穿法、磨损和自我形象是否仍能证明是这个人。
- 有真实生成图时，以成片距离、动作、材质和连续性复验；没有真实图时只能标记设计稿通过，不能声称视觉结果已验证。
