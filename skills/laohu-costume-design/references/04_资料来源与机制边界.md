# 资料来源与机制边界

本 Reference 只在需要外部专业校准、文化资料或案例机制时读取。来源支持“怎样判断”，不替具体人物决定“穿什么”。

## 一、影视服装的任务

- [Costume Designers Guild：What Is Costume Design?](https://costumedesignersguild.com/what-is-costume-design/)把服装视为在人物开口前传达身份的叙事语言，并要求设计考虑时代、经济状态、情绪以及人物希望怎样被看见。项目吸收`身份 + 自我形象 + 当下剧情状态`，不复制页面展示的任何成衣。
- [Academy：How To Create a Great Costume Design](https://www.oscars.org/news/how-create-great-costume-design)强调服装是人物内在经验和自我形象的外在表达。项目吸收`人物服装命题`，不把“时尚”当服装设计的唯一目标。
- [Academy Costume Design Teachers Guide](https://www.oscars.org/sites/oscars/files/teachersguide-costumedesign-2015.pdf)要求从年龄、社会地位、态度、地域、时代和人物转折推导服装。项目吸收`事实清单 + 转折衣橱`。

## 二、历史与材料资料

- [故宫博物院织绣藏品](https://www.dpm.org.cn/collection/embroiders.html)提供成衣、冠帽、鞋袜、佩饰以及锦、缎、绫、罗、绸、纱、绢、绒、缂丝、棉布等实物线索。使用时记录年代、制度和工艺，不把清宫服饰泛化成全部东方古装。
- [数字敦煌服饰画专题](https://ip.e-dunhuang.com/special.html?color=all&currentpage=5&data_order=all&search=all&value=%E6%9C%8D%E9%A5%B0%E7%94%BB)覆盖供养人、世俗人物、佛国人物等跨千年的图像资料。使用时区分宗教图像、世俗生活、时代与人物身份，不把飞天、披帛和纹样随意贴到所有仙侠角色。
- [Kyoto Costume Institute Digital Archives](https://www.kci.or.jp/en/archives/)以年代组织服装与配饰资料。项目用它比较轮廓、结构、材料和社会变化，不把任何设计师作品当可直接复刻模板。

## 三、可迁移的设计机制

外部品牌、秀场、博物馆和优秀影视案例可以帮助观察：

```text
轮廓怎样改变身体与空间关系。
材料怎样在静止和运动中表现重量、弹性、光泽与磨损。
共同语法怎样让一个系列属于同一世界。
少量稳定代码怎样形成辨识度，而不依赖Logo。
传统资料怎样保留文化语法并进入新技术和新叙事。
```

每次吸收写成：`来源事实 → 可迁移机制 → 本案条件 → 改变的设计决定 → 可观察结果`。不能只写“参考巴黎时装周、某品牌、某设计师风格”。

## 四、禁止借用

- 品牌Logo、专属纹样、标志性轮廓与配色组合。
- 在世设计师或具体系列的近似复刻。
- 影视角色可识别的全套服装、配饰与妆造组合。
- 宗教、民族、军职和等级符号脱离语境的装饰化使用。
- 只因来源“高级、获奖、时尚”就越过人物、世界和动作条件。

若用户明确要求精确复现，并提供有权使用的确认参考，进入`已确认设计`零改动编译，不把该案例升级为通用原创规则。
