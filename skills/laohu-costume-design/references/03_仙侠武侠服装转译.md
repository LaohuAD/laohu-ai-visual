# 仙侠武侠服装转译

本 Reference 用于已经由`laohu-art-direction`确定主辅类型和题材视觉合同之后，把仙侠、武侠、东方玄幻、东方神话及其2D、3D、写实或动画方向落实到服装。它不再把四类题材视为同一种“东方古装”。目标不是“古装加飘带”，而是让世界规则、门派劳动、身体动作、物质来源和东方文化共同产生衣服。

若作品尚未说明自己首先是仙侠、武侠、东方玄幻还是中国神话，或真实结果去掉题名后落入相邻类型，先读取`skills/laohu-art-direction/references/01_题材视觉证据与相邻类型边界.md`并返回美术风格设计，不由服装单独替整部作品裁决类型。

## 一、五层转译

```text
世界基底：时代混合范围、气候地形、纺织与炼制能力、材料稀缺性。
门派制度：共同领口 / 开合 / 肩颈 / 腰线 / 标识 / 配发与奖赏规则。
修炼功能：武器路径、发力方式、打坐、炼丹、画符、御兽、疗伤怎样改变结构。
个人偏离：人物怎样遵守、改造、忽略或反抗门派规则。
剧情阶段：晋升、受伤、流亡、入魔、继承、丧失、重返宗门留下什么变化。
```

这五层共同工作，才能避免全员交领袍、低饱和颜色和腰间饰物的平均答案。

## 二、从文化资料提取语法

历史服饰、壁画、织物和器物只作为资料，不直接拼贴复刻。每次提取四类机制：

- 结构：交叠、系结、袍裙关系、甲片、披帛、冠帽、鞋履怎样组织身体。
- 比例：肩、腰、袖、衣长、下摆和头部体量形成什么秩序。
- 材料与工艺：锦、缎、绫、罗、绸、纱、绢、棉、皮、金属和刺绣在真实条件下怎样表现。
- 制度与语境：礼仪、阶层、职业、地域、宗教图像和时代功能是什么。

再问：保留哪条文化语法，改变哪条世界规则，为什么变化。禁止把不同朝代、宗教、民族和现代秀场的标志性外形无来源混成“东方感”。

## 三、修炼功能如何进入结构

不要用职业图标区分修炼路线。先从身体和工具推导：

- 剑修：拔剑路径、肩背活动、袖量、腰侧净空、剑鞘接触区与长距离行走。
- 体修：关节活动、受击区、包覆与散热、易损部位、修补频率和材料回弹。
- 丹修 / 医修：火热、药尘、袖口收束、工具收纳、可洗性、污染与防护。
- 符修 / 阵修：手腕精度、纸笔收纳、跪坐与展开平面、快速取用路径。
- 魅惑或礼仪体系：观看关系、控制与自我呈现可以通过覆盖、开合、材料光泽、步态和礼仪结构表达，不依赖露骨露肤。

同一修炼路线内部仍要由人物自我形象和社会位置产生差异，不能把功能服变成新制服模板。

### 法衣不是古装上的发光贴纸

仙侠世界先回答衣服在修炼文明中承担什么：普通遮蔽、门派配发、护体法衣、战斗甲衣、礼制冠服、传承法宝，或多项复合。每项功能都必须落到至少一种可见后果：

```text
护体：受力区的层次、织物张力、局部强化、护边或材料回弹怎样不同。
净尘 / 防水 / 调温：表面怎样保持、如何排湿、透层与密层怎样组合，动作后是否留下尘水痕迹。
灵力传导：结构线、扣合、腰背或腕部路径怎样与功法和动作对应，不把全身铺满无因纹样。
收纳 / 变形：开合、折叠、悬挂、袖袋、腰部组件怎样在使用前后出现可核对状态。
身份验证：只有谁能使用的材料、颜色面积、结扣、令牌接口或宗门工艺怎样进入制度。
传承 / 奖赏：旧制、新制、修补、主人习惯和继承痕迹怎样同时存在。
```

高资源仙门的核心弟子若没有伪装、受罚、流亡或自我压低身份等剧情理由，常服也应达到本世界的`精英 / 定制`等级；日常轻便只降低仪式尺度，不把材料、合体、功能和制作精度降成凡人棉麻。相反，散修、凡人和隐藏身份的大能可以朴素，但仍要根据真实资源、维护方式和超常功能决定是否保留微弱非凡证据。仙侠的精美来自修炼文明对衣服的重组，不等于全员礼服或全身金玉。

## 四、主角关系设计

若作品以“大师兄—小师妹”反复对话为固定结构，两人的服装先承担关系：

- 大师兄的强不必靠最华丽。可以让门派制度在他身上被穿得最少、最旧或最不经意，却在结构、材料等级、修补方式或旁人对其服装的反应里证明资格。
- 小师妹的灵动不等于短裙、双马尾和粉色。优先从活动半径、观察习惯、携物方式、袖口与下摆的运动响应、对门规的小幅改造建立活力。
- 其他师兄师姐先作为群像关系中的对照：力量、魅惑、悲情、守序、游离等必须落到不同的轮廓、比例、结构和材料行为，不只落到配色。

每名角色仍要经过人物服装命题与候选竞争，以上只是推导方向，不是固定外形。

## 五、面向生成模型的可见性

- 远景依靠轮廓、比例、层次、头肩结构和材料运动，不依赖小刺绣。
- 中景依靠开合、腰线、袖口、武器净空、主次材料和穿法。
- 近景再使用接缝、织纹、扣合、磨损、修补和有因果的纹样。
- 2D动画优先减少互相打架的小装饰，强化清楚的形状关系。
- 写实或3D仍要尊重重量、重力、支撑、摩擦、透气与动作余量，不能用“仙气”取消物理。

## 六、仙侠与相邻类型的服装边界

汉服语法、交领、长发、佩剑、山水背景和低饱和都不是仙侠专属证据。服装若承担仙侠归属，至少要形成一组可见的三级证据：修行制度、身体能力、门派资源或超常材料怎样共同改变轮廓、层级、穿法、表面和运动；不能只增加一个法器、纹样或发光装饰。

```text
武侠服装：以人的训练、兵器、旅途、江湖身份和现实重力为中心。
仙侠服装：在中国衣冠语法上，被修行寿命、门派制度、资源等级、功法身体和超常材料进一步重组。
中国神话服装：更强调神格、族群、祭祀、象征和宇宙谱系。
东方玄幻服装：更强调架空文明、族群、原创力量体系和跨文化世界规则。
```

执行三项测试：

1. `去背景测试`：没有山峰云雾时，服装是否仍提供主类型证据。
2. `相邻替换测试`：不改服装能否直接进入现实江湖、历史朝堂或神话祭祀；若能且角色并非有意隐藏，继续设计。
3. `群像制度测试`：人物差异是否来自修行路线、门派制度、资源和自我形象，还是只来自颜色、武器和腰饰。

仙侠允许朴素、旧衣、短打、深色和现实材料，也允许高手有意像凡人；但这种例外必须由服装结构中的微弱制度证据、其他人物、场景、道具或运动物理补偿。避免廉价网游感不等于删掉全部非凡证据。

## 七、拒绝门

- 六个角色都是交领长袍，只换颜色和腰饰。
- 高阶人物只增加金边、刺绣、玉石和发冠数量。
- 女性魅力只靠露肤，力量只靠盔甲，仙气只靠飘带。
- 为了避免俗套把所有非凡材料、修行制度和世界物理全部删掉，最终退化成低饱和武侠。
- 服装会遮挡拔剑、抬臂、盘坐、奔跑或法器操作，却没有世界解释。
- 引用某品牌、秀场或影视角色名称来代替结构描述。
- 历史资料被当成可自由复制的“元素库”，没有制度和语境来源。
