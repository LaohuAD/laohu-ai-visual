# 服装造型专业方法

## 决定结果的关系

先写人物为何选择而非相邻答案，再比较肩腰关系、纵横重心、长短比例、体积覆盖、层次与负空间。轮廓和结构至少一项承担候选差异；用黑白剪影、坐下和行走比较，不靠色彩饰物凑三案。方向人工定案由父入口负责。

## 专业术语如何进入决定

silhouette（外轮廓）；proportion（比例）；visual balance（视觉平衡）；negative space（负空间）。

这些术语用于指出哪项关系要被核验。例如“范围”要有对象和限制，“结构”要有相邻与连接，“状态”要有起因和结束。交付给图片或视频模型时把术语编译为具体可见关系；交给专业制作时保留术语及其条件，不能声称已执行软件、施工、测量或真人试验。

## 代表场景与反例修正

有钱人仅多金边不能证明高级；可选择精准合体与低装饰或公开权威的大尺度轮廓，按自我呈现比较。普通白T也要具体决定肩缝、衣长、松量与穿法。

先复现失败所在的条件，再执行本节修正。如果修正会改写父入口锁定的身份、整体造型、入口或剧情状态，停止局部补丁，携带冲突事实和两个可行返回选项交回负责人。不要因一个反例就把所有同类手法永久禁止。

## 独立结果清单

轮廓候选、身体强调或保护策略、层次结构、远中近证据、胜出造型正文。

每项都写实际决定，不写“需要清楚、保持高级、加强真实”等未完成要求。可见正文与内部理由分开：正文写对象已经怎样成立，理由写为何胜出及何时重开。只有文本推演时，验收明确记为文字设计检查，真实效果仍待对应生产证据。


# 原创服装设计与候选竞争

候选遵守核心合约的同约束比较：违规方案不计数，锁定方向只比较剩余自由区；推荐保留有效对手的优势、自身代价与反转条件。

本 Reference 用于完整调用、主要人物、服装平庸、普通人物容易落入默认值，以及候选看似很多但只换表面元素的情况。



## 一、人物服装命题

设计前先回答六个问题：

1. 他在社会、组织和关系中处于什么位置。
2. 他想让别人怎样看见自己，是否有意隐藏另一面。
3. 当前最稳定的行为习惯是什么，而不是性格形容词是什么。
4. 身体、职业、武器、劳动、礼仪和环境对衣服提出什么真实要求。
5. 哪些衣物来自制度，哪些来自购买能力、继承、奖赏、修补或个人选择。
6. 这一阶段相对前后阶段发生了什么可见变化。

把答案压成一句人物服装命题。命题必须包含关系和选择，例如：

```text
她不愿通过外表争取注意，却长期站立、反复抬臂收银；衣服要让人先读到自我收束和可靠，再从洗软的肘部、稳定的腰线和便于动作的袖口读到她的耐力。
```

“坚韧所以红色”“清冷所以白衣”“名门所以金纹”不是命题，只是符号替换。



## 衣服不替人物贴标签，它记录人物怎样选择

服装的因果链不是“人物特点 → 对应单品”，而是：

```text
世界制度、资源和身体动作划出可选范围
→ 人物想被怎样看见，又愿意为此付出什么
→ 他在相邻可行答案之间作出取舍
→ 取舍进入轮廓、比例、结构、材料、穿法和维护
→ 服装在远中近景及动作中产生人物结果
```

“同样预算紧张”不会天然导向同一套旧衣服。一个必须在窗口岗位维持体面的人，可能把有限精力放在合体、平整和不外露的修补上；一个长期重体力劳动的人，可能优先保住活动余量、受力部位和可反复修复的结构；一个主动降低存在感的人，也可能有意选择不制造轮廓和声音的穿法。这些都只是待比较的设计方向，必须由人物事实、自我形象、工作环境和剧情动作决定，不能反写成阶层模板。

因此，服装的不可替代性不靠独属饰物，而靠`同样条件下他会这样选，另一个人不会`。候选竞争优先改变这种人物取舍，再改变承载它的外形；如果人物判断没变，只换衣服外观，仍是同一方向。



## 二、承重设计变量

| 变量 | 要解决的问题 |
|---|---|
| 轮廓 | 远看是收、撑、垂、包、开、贴、叠、拖还是提 |
| 比例 | 肩、腰、衣长、袖长、上下装面积和露肤怎样组织 |
| 结构 | 领、门襟、开衩、接缝、口袋、扣合和受力点为何这样存在 |
| 层次 | 内外层怎样露出、开合和形成身份或环境证据 |
| 材料行为 | 挺 / 垂、轻 / 重、透 / 密、干 / 润、伸展 / 回弹怎样随动作被看见 |
| 色彩关系 | 明度、冷暖、面积、重复点和制度色怎样形成秩序，不只列色名 |
| 图案与工艺 | 出处、制作成本、等级、仪式或个人历史是什么 |
| 穿法与维护 | 扣到哪里、卷不卷、怎样修补、多久洗一次、怎样反复穿 |
| 运动响应 | 走、坐、打斗、抬臂、跪拜、奔跑、御风时服装怎样工作 |
| 身体关系 | 服装怎样顺应、修饰、强调或有意隐藏肩颈、腰线、胸背、腿长、重心与动作能力 |
| 配饰体系 | 首饰、腰带、冠帽、鞋履、包袋和工具怎样形成同一等级、礼制与人物选择，而不是随机点缀 |

记忆点优先落在前六项。腰牌、玉佩、徽章、补丁和特殊纹样只有在有因果且近景承重时才使用。



## 三、3—5个真正不同的候选

完整调用先定本轮最值得竞争的2—4条差异轴，再生成候选。每个候选至少改变两个承重变量，且至少有一个来自轮廓、比例、结构、层次或材料行为。

以下不构成不同候选：

- 同一长袍换青、灰、白。
- 同一结构更换玉佩、腰牌、剑穗。
- 同一方案分别写简约、高级、仙气。
- 从多个知名品牌或影视角色各抄一套外形。

### 强类型任务不要只在安全区里换答案

真人漫画、讽刺、寓言、无字幕短剧和用户明确要求“拒绝平均”时，候选结构需要同时看见三种立场：

1. `大胆类型案`：把人物主动经营的形象推到当前题材允许的上沿，让轮廓、材料、穿法和配饰体系在第一眼就说话。
2. `反类型案`：外表与行为预期有意错位，依靠后续剧情重新解释。
3. `混合案`：保留一条熟悉代码，同时用当前人物独有的身体、动作或维护逻辑把它从通用模板里救出来。

金链、花衫、大表盘、白衬衣、旧工装、围裙都不是自动禁用项，也不是自动有效项。先问人物为什么选择它、怎样展示它、它在远中近景和动作里改变了什么、剧情结果怎样击中它。`花衫＋金链＝坏人`是单符号判案；“他故意敞开花衫领口露出粗链，抬腕拍喇叭时把大表盘送到镜头前，随后泥水把这套自我炫耀全部覆盖”才是服装—动作—结果的完整叙事链。

风险栏要拆成伤害、陈词滥调、观众摩擦和生成失控。只有伤害风险直接否决；俗套先通过人物特异性重写，摩擦可以有意保留，生成失控由结构和资产测试处理。不得把四类风险统一翻译为“删掉最有辨识度的东西”。

候选竞争卡：

```text
候选名与核心判断：
本候选独有的人物押注：它认为人物最想被怎样看见、最需要隐藏什么或与谁形成什么关系；如果采用它，人物在关系中会产生什么不同后果。
改变的承重变量：
远景轮廓与比例：
结构、材料与运动：
人物证据 / 世界证据：
在群像中的位置：
最大收益：
最大风险：
借用的类型代码 / 当前人物的变体：
伤害 / 陈词滥调 / 观众摩擦 / 生成风险：
故意保留的锐边：
```



## 四、方向提案与定案

需要人工定案时，候选竞争先交付`方向提案卡`，而不是直接写技术说明。每案先用一段可想象的画面叙述：人物在代表性场景里出现，衣服怎样组织身体，材料怎样受光和动作，配饰怎样与手势、兵器或关系对象发生作用，观众第一眼和第二眼分别读到什么。画面叙述只负责让人看见差异，不能用“高级、精致、强大、灵动”代替可见证据。

随后补充：

```text
身份与叙事押注：
资源与展示等级：
轮廓与身体关系：
材料层级与受光 / 运动：
工艺、功能与配饰体系：
色彩面积关系：
远景 / 中景 / 近景证据：
场景动作适配：
最大收益 / 最大风险：
```

AI必须给出`AI推荐`：推荐哪案、它更准确地解决了什么、需要放弃什么。人工确认管理整体审美与叙事取舍，不管理普通接缝和扣子数量；确认结果写入`服装方向确认记录`后才继续展开完整设计。

不触发人工定案的轻量任务，由Skill自动选出当前最佳。评分不固定为通用权重；先根据作品主胜负手决定本轮权重，再比较：叙事准确、人物不可替换性、世界一致性、群像区分、动作功能、阶段弧线、生成与连续性风险。

每个未选方案必须留下具体淘汰理由，例如“人物证据强，但与师姐同为上宽下垂，群像剪影冲突”，不能只写“不够好”。若两个方案会改变核心人物承诺或成本，才返回总控请用户取舍。

候选完成后再做一次`同押注合并`：如果两个方案虽然结构不同，却都只是在表达同一种“清冷、强势、灵动”，或最终都让他人以同样方式靠近、服从、误判或疏远人物，把它们合并成一个方向并继续寻找另一种人物关系判断。候选数量不能代替认知差异。



## 五、价值与精致必须被看见

精美、高端、昂贵和华丽不是同义词，也不是装饰密度。先判断人物为什么拥有、被允许或愿意展示这些资源，再从多个系统共同证明：

- 轮廓与合体：定制关系是否准确组织人物身体和行动，而不是通用尺码外壳。
- 材料层级：主料、里料、透层、挺层和局部强化是否有清楚主次，受光和运动是否彼此不同。
- 工艺焦点：把高成本集中在一两个承重区域，形成秩序，不让全身同权繁复。
- 配饰与首饰：金属、玉石、法器、鞋履和腰部系统是否来自同一制度、财富来源与使用习惯。
- 维护状态：洁净、熨烫、修补、收纳和重复穿着怎样证明人物资源与生活方式。
- 功能价值：防护、调温、净尘、收纳、身份验证或职业操作怎样真实改变结构、材料或动作。

远景至少让轮廓、比例或材料运动中的一项证明等级；中景至少让合体、层次、开合或配饰体系中的一项继续证明；近景才让织纹、刺绣、珠宝、扣合和表面完成确认。高等级不要求三个距离都繁复，但至少两个距离必须有相互独立、方向一致的证据。

服装与身体不是两份清单。人物拥有曲线、力量、年龄、伤病或特殊体态时，先判断角色愿意强调、平衡、隐藏还是保护哪部分，再决定肩腰比例、覆盖、松量、纵横线和材料支撑。身体修饰必须服务人物自我形象和场景行动；不能把女性一律收腰显瘦、男性一律扩肩，也不能用宽袍把人物身体设计全部抹掉。



## 六、有意识的朴素

普通人物可以没有独特饰物，但不能没有决定。检查：

- 合体：松紧和长度来自身体、自我形象与活动，而非模型默认。
- 材料：克重、垂坠、洗旧、起球、褪色与购买能力一致。
- 重复：人物为何反复穿，它如何被保养、折叠和修补。
- 穿法：规整、随意、保护性、节省时间或避免注意，哪一种有行为证据。
- 选择：同样预算下为什么选这一件，而不是相邻答案。

每个细节标注来源：`事实`来自剧本或确认材料，`推论`列出支持它的具体事实，`设计选择`是专业补全。磨损、洗护、购买习惯、家庭来源和修补历史如果没有事实，只能作为设计选择，不得写成角色既有经历。

有意识的朴素往往靠多个微小决定同向，而不是靠一个抢眼记忆点。为了证明“有设计”强加补丁、徽章、红线和象征物，仍是类型捷径。



## 七、六项测试

1. `换名测试`：角色名替换后是否仍完全成立。
2. `剪影测试`：去掉脸、颜色和纹样后能否区分主要人物。
3. `动作测试`：关键动作发生时，结构和材料是否帮助叙事。
4. `历史测试`：磨损、修补、继承和阶段变化是否有来处。
5. `删饰测试`：去掉所有非必要饰物后，设计本体是否仍成立。
6. `价值证据测试`：遮住品牌、角色名和“高端 / 朴素”等形容词后，远中近景中是否仍有至少两个距离能证明当前资源与展示等级。
7. `平均化回退测试`：把风险栏要求删除的元素全部拿掉后，是否只剩任何同类人物都能穿的正常成衣；若是，回到候选竞争而不是把安全平均稿交付。


## 四、主角关系设计

若作品以“大师兄—小师妹”反复对话为固定结构，两人的服装先承担关系：

- 大师兄的强不必靠最华丽。可以让门派制度在他身上被穿得最少、最旧或最不经意，却在结构、材料等级、修补方式或旁人对其服装的反应里证明资格。
- 小师妹的灵动不等于短裙、双马尾和粉色。优先从活动半径、观察习惯、携物方式、袖口与下摆的运动响应、对门规的小幅改造建立活力。
- 其他师兄师姐先作为群像关系中的对照：力量、魅惑、悲情、守序、游离等必须落到不同的轮廓、比例、结构和材料行为，不只落到配色。

每名角色仍要经过人物服装命题与候选竞争，以上只是推导方向，不是固定外形。



## 五、面向生成模型的可见性

- 远景依靠轮廓、比例、层次、头肩结构和材料运动，不依赖小刺绣。
- 中景依靠开合、腰线、袖口、武器净空、主次材料和穿法。
- 近景再使用接缝、织纹、扣合、磨损、修补和有因果的纹样。
- 2D动画优先减少互相打架的小装饰，强化清楚的形状关系。
- 写实或3D仍要尊重重量、重力、支撑、摩擦、透气与动作余量，不能用“仙气”取消物理。



### 5. 区分有意识的朴素与无意识的默认值

`有意识的朴素`仍有准确的合体关系、材料等级、重复穿着、保养方式、动作习惯、购买能力和人物自我形象；它可以没有抢眼装饰。`无意识的默认值`只剩职业单品和安全色，把角色名换掉仍完全成立。

主角穿白T和牛仔裤可以是设计结论，但必须通过`换名测试`：换成同年龄同职业的另一个人后，比例、面料、穿法、磨损和选择理由是否仍毫无变化。若是，继续设计；不要用补丁、徽章、特殊纹样强行证明人物化。



## 实际填写示范与判定

以下为虚构练习条件，不冒充当前作品事实。

方案对照：同为窗口工作人员，A用略收束肩线、适中腰长和袖口整理表达随时接待；B用宽松外层与集中腰部收纳表达优先操作。按同一抬臂与转身动作比较，若故事要建立专业可靠而不是忙乱，应减少外层悬摆但保留活动余量；不以黑白色自动判定可靠。

交付前把示范中的对象换成当前已确认对象，再重新推理；不得直接照抄示范形态。成功标准是同一套事实能够解释选择、结构和下一状态，失败时能指出最早需要变化的决定。
