# 服饰考据专业方法

## 决定结果的关系

分别查成衣实物、穿着图像、工艺和制度文本；记年代地域、藏品号和用途，辨别礼服与日常、理想图像与实际穿法。建立共同轮廓、材料经济、工艺水平、获得维护循环，再标幻想改造的位置与因果；证据不能覆盖的部分明确设计选择。

## 专业术语如何进入决定

dress history（服饰史）；provenance（来历记录）；sumptuary regulation（服饰等级限制）；typology（类型比较）。

这些术语用于指出哪项关系要被核验。例如“范围”要有对象和限制，“结构”要有相邻与连接，“状态”要有起因和结束。交付给图片或视频模型时把术语编译为具体可见关系；交给专业制作时保留术语及其条件，不能声称已执行软件、施工、测量或真人试验。

## 代表场景与反例修正

将宫廷礼服当所有百姓日常会误读资源制度。保留有证据的开合语法，按职业与气候另定面料和层数；不能将跨朝代装饰拼合后标历史还原。

先复现失败所在的条件，再执行本节修正。如果修正会改写父入口锁定的身份、整体造型、入口或剧情状态，停止局部补丁，携带冲突事实和两个可行返回选项交回负责人。不要因一个反例就把所有同类手法永久禁止。

## 独立结果清单

证据卡、世界服饰宪法、母型范围、禁混项、历史与幻想转译边界。

每项都写实际决定，不写“需要清楚、保持高级、加强真实”等未完成要求。可见正文与内部理由分开：正文写对象已经怎样成立，理由写为何胜出及何时重开。只有文本推演时，验收明确记为文字设计检查，真实效果仍待对应生产证据。


# 世界服饰系统与群像衣橱

本 Reference 用于同一作品有多名人物、阵营、阶层、职业、门派、群像或跨阶段衣橱。它解决“每个人单看合理，合在一起却像同一套模板换色”的问题。



## 一、世界服饰宪法

先建立七条共同约束：

```text
身体与环境：气候、地形、劳动、战斗、礼仪、交通怎样影响覆盖与活动。
材料经济：纤维、皮革、金属、染料、灵性材料从哪里来，谁能负担。
工艺技术：织造、裁剪、甲片、刺绣、炼制、修补达到什么水平。
社会制度：阶层、职业、组织、性别与年龄如何被允许或被迫穿着。
礼仪禁忌：什么场合必须覆盖、显露、佩戴、脱下或更换。
使用循环：衣服怎样领取、购买、继承、奖赏、回收、修补和废弃。
共同语法：全世界共享哪些轮廓、开合、接缝、材料和穿着逻辑。
```

世界服饰宪法是生成差异的边界，不是全员制服。它规定哪些变化有来处，哪些只是现代审美随意贴入。

### 世界资源怎样进入服装等级

每个世界还要说明四种资源怎样被穿出来：

```text
财富资源：谁负担得起稀有原料、定制工时、维护、替换和完整配饰体系。
权力资源：谁有权使用某种尺度、颜色面积、纹样、冠服、徽记、法器或公开仪式结构。
技术 / 超常资源：哪些织造、合成、附魔、防护、调温、净尘、变形或身份验证能力真实存在；由谁制作和修复。
文化资本：谁知道怎样搭配、克制、偏离制度，怎样让昂贵不依赖堆饰，怎样有意把普通穿得准确。
```

同一财富水平不会自动导向同一外观。公开权威场景可能提高展示等级，私人工作场景可能压低装饰但保留材料与合体，逃亡和卧底会主动制造`伪装 / 反差`。表面等级与真实身份错位时，必须记录：错位动机、观众何时察觉、人物承担什么风险、哪一项细小证据不会被完全抹掉。没有剧情依据，不得为了“反差”随机让豪门穿地摊、让凡人穿帝王礼服。



## 二、群像关系矩阵

主要人物并排比较：

| 角色 | 共同语法 | 主轮廓 | 比例 / 层次 | 材料行为 | 色彩面积关系 | 制度项 | 个人偏离 | 阶段变化 |
|---|---|---|---|---|---|---|---|---|

每个人至少有一个与关系或功能相连的主差异轴，但不是每个维度都不同。过度差异会破坏同一世界；过度统一会让人物只靠脸区分。

以下组合优先判为同质：

- 全员交领长袍，只换颜色。
- 全员相同腰线和袖量，只换兵器。
- 全员低饱和，仅用一个腰间饰物区分。
- 权力只用更多金边、更多刺绣表示。



## 三、阵营与阶层

阵营先规定共同结构，再允许角色偏离。阶层不只靠昂贵材料和徽章；中远景更有效的变量包括：覆盖面积、层数、肩颈结构、衣长、袖量、光泽、材料挺度、活动余量、维护状态和队列中的重复率。

等级服装应能回答：

```text
谁有权使用某种轮廓、颜色面积或材料。
谁必须遵守制服，谁有权偏离。
等级变化在远景、中景、近景分别由什么证据承担。
制度怎样留下领取、奖赏、旧制沿用或违规改造的痕迹。
```

建立群像时，同时记录`资源与展示等级`，但不能把它当成一条由低到高的珠宝数量刻度。同一等级必须允许不同人物策略：有人把资源押在面料和合体，有人押在礼制轮廓，有人押在功能法器，有人主动隐藏。阶层差异决定可选范围，人物选择决定最终穿法。



## 四、一次性远景群像

不值得逐人建资产的群众使用轻量调用。先记录目标画幅与分辨率、群众在画面中的可见尺度、镜头持续时间、运动模糊与遮挡，再按画面证据而不是固定百分比判断：观众能读出群体等级 / 阵营、但不能稳定识别独立个人时使用轻量调用；镜头能识别某个个人、该人跨镜复现或承担动作时升级为完整人物 / 服装判断；连群体等级都不可读且不影响剧情时无需调用。

轻量调用只设计群体语法和2—4档远景层级：

- 轮廓：肩颈、袖量、衣长、头部轮廓。
- 覆盖与层数：谁更封闭、谁更利于劳动或战斗。
- 明度与材料反光：远景可读，避免依赖小纹样。
- 重复与偏离：多数人遵守什么，少数关键位置如何被允许不同。
- 运动：行列、作业或战斗时布料响应怎样体现身份。

不建个人B / W / M，不等于写“一群不同等级弟子”后让模型自由补完。群像语法进入群像资产或镜头正文，由视觉资产和视频负责人按复用风险决定。



## 六、群像验收

1. 黑白剪影并排：不用脸和颜色能否读出主要角色与等级。
2. 去掉饰物：世界与人物差异是否仍成立。
3. 随机换装：把两名角色服装互换，人物关系是否明显变弱。
4. 远中近景：等级证据是否匹配实际镜头距离。
5. 阶段排序：打乱衣橱后，观众能否凭造型变化恢复人物阶段。


# 仙侠武侠服装转译

本 Reference 用于已经由`laohu-art-direction`确定主辅类型和题材视觉合同之后，把仙侠、武侠、东方玄幻、东方神话及其2D、3D、写实或动画方向落实到服装。它不再把四类题材视为同一种“东方古装”。目标不是“古装加飘带”，而是让世界规则、门派劳动、身体动作、物质来源和东方文化共同产生衣服。

若作品尚未说明自己首先是仙侠、武侠、东方玄幻还是中国神话，或真实结果去掉题名后落入相邻类型，先读取`skills/laohu-art-direction/references/01_题材视觉证据与相邻类型边界.md`并返回美术风格设计，不由服装单独替整部作品裁决类型。



## 一、五层转译

```text
世界基底：时代混合范围、气候地形、纺织与炼制能力、材料稀缺性。
门派制度：共同领口 / 开合 / 肩颈 / 腰线 / 标识 / 配发与奖赏规则。
修炼功能：武器路径、发力方式、打坐、炼丹、画符、御兽、疗伤怎样改变结构。
个人偏离：人物怎样遵守、改造、忽略或反抗门派规则。
剧情阶段：晋升、受伤、流亡、入魔、继承、丧失、重返宗门留下什么变化。
```

这五层共同工作，才能避免全员交领袍、低饱和颜色和腰间饰物的平均答案。



## 二、从文化资料提取语法

历史服饰、壁画、织物和器物只作为资料，不直接拼贴复刻。每次提取四类机制：

- 结构：交叠、系结、袍裙关系、甲片、披帛、冠帽、鞋履怎样组织身体。
- 比例：肩、腰、袖、衣长、下摆和头部体量形成什么秩序。
- 材料与工艺：锦、缎、绫、罗、绸、纱、绢、棉、皮、金属和刺绣在真实条件下怎样表现。
- 制度与语境：礼仪、阶层、职业、地域、宗教图像和时代功能是什么。

再问：保留哪条文化语法，改变哪条世界规则，为什么变化。禁止把不同朝代、宗教、民族和现代秀场的标志性外形无来源混成“东方感”。



## 六、仙侠与相邻类型的服装边界

汉服语法、交领、长发、佩剑、山水背景和低饱和都不是仙侠专属证据。服装若承担仙侠归属，至少要形成一组可见的三级证据：修行制度、身体能力、门派资源或超常材料怎样共同改变轮廓、层级、穿法、表面和运动；不能只增加一个法器、纹样或发光装饰。

```text
武侠服装：以人的训练、兵器、旅途、江湖身份和现实重力为中心。
仙侠服装：在中国衣冠语法上，被修行寿命、门派制度、资源等级、功法身体和超常材料进一步重组。
中国神话服装：更强调神格、族群、祭祀、象征和宇宙谱系。
东方玄幻服装：更强调架空文明、族群、原创力量体系和跨文化世界规则。
```

执行三项测试：

1. `去背景测试`：没有山峰云雾时，服装是否仍提供主类型证据。
2. `相邻替换测试`：不改服装能否直接进入现实江湖、历史朝堂或神话祭祀；若能且角色并非有意隐藏，继续设计。
3. `群像制度测试`：人物差异是否来自修行路线、门派制度、资源和自我形象，还是只来自颜色、武器和腰饰。

仙侠允许朴素、旧衣、短打、深色和现实材料，也允许高手有意像凡人；但这种例外必须由服装结构中的微弱制度证据、其他人物、场景、道具或运动物理补偿。避免廉价网游感不等于删掉全部非凡证据。



## 七、拒绝门

- 六个角色都是交领长袍，只换颜色和腰饰。
- 高阶人物只增加金边、刺绣、玉石和发冠数量。
- 女性魅力只靠露肤，力量只靠盔甲，仙气只靠飘带。
- 为了避免俗套把所有非凡材料、修行制度和世界物理全部删掉，最终退化成低饱和武侠。
- 服装会遮挡拔剑、抬臂、盘坐、奔跑或法器操作，却没有世界解释。
- 引用某品牌、秀场或影视角色名称来代替结构描述。
- 历史资料被当成可自由复制的“元素库”，没有制度和语境来源。


# 资料来源与机制边界

本 Reference 只在需要外部专业校准、文化资料或案例机制时读取。来源支持“怎样判断”，不替具体人物决定“穿什么”。



## 一、影视服装的任务

- [Costume Designers Guild：What Is Costume Design?](https://costumedesignersguild.com/what-is-costume-design/)把服装视为在人物开口前传达身份的叙事语言，并要求设计考虑时代、经济状态、情绪以及人物希望怎样被看见。项目吸收`身份 + 自我形象 + 当下剧情状态`，不复制页面展示的任何成衣。
- [Academy：How To Create a Great Costume Design](https://www.oscars.org/news/how-create-great-costume-design)强调服装是人物内在经验和自我形象的外在表达。项目吸收`人物服装命题`，不把“时尚”当服装设计的唯一目标。
- [Academy Costume Design Teachers Guide](https://www.oscars.org/sites/oscars/files/teachersguide-costumedesign-2015.pdf)要求从年龄、社会地位、态度、地域、时代和人物转折推导服装。项目吸收`事实清单 + 转折衣橱`。



## 二、历史与材料资料

- [故宫博物院织绣藏品](https://www.dpm.org.cn/collection/embroiders.html)提供成衣、冠帽、鞋袜、佩饰以及锦、缎、绫、罗、绸、纱、绢、绒、缂丝、棉布等实物线索。使用时记录年代、制度和工艺，不把清宫服饰泛化成全部东方古装。
- [数字敦煌服饰画专题](https://ip.e-dunhuang.com/special.html?color=all&currentpage=5&data_order=all&search=all&value=%E6%9C%8D%E9%A5%B0%E7%94%BB)覆盖供养人、世俗人物、佛国人物等跨千年的图像资料。使用时区分宗教图像、世俗生活、时代与人物身份，不把飞天、披帛和纹样随意贴到所有仙侠角色。
- [Kyoto Costume Institute Digital Archives](https://www.kci.or.jp/en/archives/)以年代组织服装与配饰资料。项目用它比较轮廓、结构、材料和社会变化，不把任何设计师作品当可直接复刻模板。



## 三、可迁移的设计机制

外部品牌、秀场、博物馆和优秀影视案例可以帮助观察：

```text
轮廓怎样改变身体与空间关系。
材料怎样在静止和运动中表现重量、弹性、光泽与磨损。
共同语法怎样让一个系列属于同一世界。
少量稳定代码怎样形成辨识度，而不依赖Logo。
传统资料怎样保留文化语法并进入新技术和新叙事。
```

每次吸收写成：`来源事实 → 可迁移机制 → 本案条件 → 改变的设计决定 → 可观察结果`。不能只写“参考巴黎时装周、某品牌、某设计师风格”。



## 四、禁止借用

- 品牌Logo、专属纹样、标志性轮廓与配色组合。
- 在世设计师或具体系列的近似复刻。
- 影视角色可识别的全套服装、配饰与妆造组合。
- 宗教、民族、军职和等级符号脱离语境的装饰化使用。
- 只因来源“高级、获奖、时尚”就越过人物、世界和动作条件。

若用户明确要求精确复现，并提供有权使用的确认参考，进入`已确认设计`零改动编译，不把该案例升级为通用原创规则。


### 3. 先定世界，再定人物

主要人物属于同一世界时，先建立`世界服饰宪法`：身体与环境、材料经济、工艺与技术、社会制度、礼仪禁忌、共同轮廓语法、阵营差异、使用与修补逻辑。单人设计不能越过这一步自由拼贴。

再为每个人写一句`人物服装命题`：

```text
这个人处在什么位置，想让别人怎样看见自己；他真正的需要或矛盾是什么；哪种穿衣选择能在不解释的情况下让观众看见这层关系。
```

人物事实不能直接兑换成衣服元素。服装设计真正拥有的是：一个人在世界允许的范围内，为什么选择这一种穿法，而没有选择相邻答案。

```text
世界与身体约束 → 人物可选范围 → 人物的取舍 → 轮廓、结构、材料与穿法 → 观众读到的身份和关系。
```

如果只能从“贫穷、清冷、强大、活泼”直接跳到补丁、白衣、重甲和亮色，说明人物服装命题尚未成立。

胜出方向进入图片模型正文前，必须再做一次`母型—变体编译`：先确定模型和观众都能识别的服装品类或历史 / 行业母型，再说明它为当前人物改变了哪些轮廓、结构、层次与穿法，最后落到颜色、材料、工艺和使用痕迹。原创名称可以保留，但不能单独承担造型；专有材料必须写出形状、表面、软硬、透光 / 反光、垂坠 / 张力和动作状态中真正相关的视觉证据。

详细方法读取 [references / 专业方法](../../laohu-costume-silhouette/references/专业方法.md)。多人物、阵营、阶层、群像或跨阶段衣橱读取 [laohu-costume-research / SKILL](../SKILL.md) / [laohu-costume-continuity / SKILL](../../laohu-costume-continuity/SKILL.md)。仙侠、武侠、东方玄幻读取 [laohu-costume-research / SKILL](../SKILL.md) / [laohu-garment-structure / SKILL](../../laohu-garment-structure/SKILL.md) / [laohu-costume-silhouette / SKILL](../../laohu-costume-silhouette/SKILL.md)。需要外部证据或案例机制时才读取 [references / 专业方法](专业方法.md)。



## 实际填写示范与判定

以下为虚构练习条件，不冒充当前作品事实。

证据卡按“物件/年代地域/使用场合/材料工艺/可见结构/不确定/本案转译”填写。图像中的宽袖能支持轮廓观察，不能独自证明内里缝制；现代复原展示可提供穿法假设，不能越过考古证据标唯一历史正确。幻想改造保留何种开合语法必须说清。

交付前把示范中的对象换成当前已确认对象，再重新推理；不得直接照抄示范形态。成功标准是同一套事实能够解释选择、结构和下一状态，失败时能指出最早需要变化的决定。
