# 导演判断与协作网络

本 Reference 只解决两个问题：怎样从用户语言中找到真正的导演命题，怎样让多个专业节点围绕它协作而不互相越权。

## 一、导演面对的不是需求清单，是一段将被观众经历的时间

用户可能说“做一个灯光教学”“拍一段爱情故事”“让人物更高级”“把打斗做炸”。这些是入口，不是导演答案。

先分开五层：

```text
表面要求：用户直接点名的内容或操作。
现实目的：作品最终要替用户完成什么。
观众处境：谁会在什么环境、带着什么已知进入。
观看变化：观众的理解、情绪、关系判断或行动意愿怎样移动。
专业手段：剧本、表演、镜头、美术、声音和生成怎样共同造成变化。
```

从表面要求直接跳到专业手段，作品容易“每项都做了，但不知道为什么看”。导演先补中间三层。

## 二、先建导演问题单

用户的叙述中同时有事实、偏好、推论和尚未决定的选择。不分开它们，导演会把自己的补猜写成用户意图。

```text
已确认证据：用户原话、已定作品、已有人物与资产、平台和成本事实。
暂用假设：为继续推导而做的可逆判断，必须写明依据和置信度。
待确认：不同答案会改变用途、成本、风险、品牌或主要审美方向。
导演问题：不是“用什么镜头”，而是“观众为什么要看，他将在何处改变”。
保护项：已锁定的人物关系、作品事实、商业诚信、媒介限制和用户授权。
```

先用可观察证据缩小可能性，再用假设继续工作。只有待确认项会造成重大分叉时才停下询问；可逆且不扩大范围的假设可以先进入候选竞争。

## 三、从用户目的推导观众经历

### 1. 找真实成功信号

不要只问用户想放什么，要判断用户最终拿什么结果验收：

- 教学：观众是否在不觉得被上课的过程中记住并会辨认。
- 故事：观众是否跟随人物做出一次有代价的选择。
- 治愈：观众是否从紧绷、孤独或自责移动到被理解、允许或重新行动。
- 爱情：观众是否看见两个人如何确认、错过、靠近或承担，而不只是看见浪漫物件。
- 广告：观众是否从“这与我无关”移动到“它能解决我的具体处境”。

这些不是题材模板，只示范如何把结果写成观众变化。同一灯光题材可以是严肃摄影课、人物喜剧、悬疑实验或产品演示；题材相同不代表导演命题相同。

### 2. 找继续观看的动力

逐段回答：观众此刻知道什么、在等什么、担心什么、误解什么、下一秒为什么不能划走。

推进力可以来自：

- 人物选择与后果；
- 问题、猜测与答案；
- 关系靠近、躲避与重新解释；
- 技能展示与难度升级；
- 危险、时间、空间或资源收紧；
- 证据逐步出现；
- 节奏、音乐和视觉母题的期待与释放。

导演只选一个主推进力。其他动力可以辅助，但不能并列争抢全片结构。

### 3. 找主要观看乐趣

观众愿意留下，不等于只因“信息有用”。知识、故事和商业内容都需要当下回报：人物魅力、幽默关系、发现感、奇观、共鸣、审美、掌控感或实用收益。

主推进力回答“为什么继续”，主要观看乐趣回答“继续的过程为什么不苦”。两者必须互相托住。

## 四、让导演方向真正竞争

候选不是把一个方案改三种外观。候选遵守核心合约的同约束比较：违规方案不计数，锁定方向只比较剩余自由区；推荐保留有效对手的优势、自身代价与反转条件。重要新作品先找出最能改变结果的`差异轴`，开放方向通常让三个可行方向分别在其中一条轴上做出不同取舍；锁定方向按剩余自由区选择有效对手：

- 观众与作品的关系：学习者、窥视者、陪伴者、证人、挑战者还是消费决策者。
- 主推进力：选择与后果、问题与答案、关系靠近、证据更新、难度升级或时间收紧。
- 主要观看乐趣：人物关系、发现感、幽默、奇观、共鸣、审美或解决问题的掌控感。
- 信息权力：谁先知道，谁被矒住，观众何时比人物多知道或少知道。
- 表演与视听承重：靠身体、台词、空间、声音、光影、剪辑还是奇观主要完成。
- 现实代价：时长、资产量、模型稳定性、表演难度、制作费和品牌风险。

每个候选用同一张`候选方向卡`表达：

```text
候选名称：
它对用户目的的解法：
观众以什么身份进入，离开时改变什么：
全片只让观众等待什么：
主推进力 / 主要观看乐趣：
关键阈值和最终兑现：
谁承重，其他部门怎样退让：
最大现实代价与最可能失败：
反转条件：什么新证据出现时，这一案不再是最优。
```

两道测试先排除伪候选：

- `受众等价测试`：把三案的人名、地名和类型词去掉，如果观众的进入、等待、更新和离开仍然相同，就是一案三写。
- `机制差异测试`：把外观、台词和特效互换，如果因果骨架不受影响，差异只停在表面。

然后进入两轮比较：

1. `硬门`：事实、授权、用户目的、媒介、成本和不可补偿失败任一不成立，直接淘汰。
2. `巅峰比较`：比较谁更能让观众走完、谁的观看乐趣与主结果更统一、谁更难被同类作品替换、谁能让各专业的优秀朝同一个结果用力。

必须让一份`普通但正确的候选`作为有效对手真实参赛；它若更准确服务目的，可以胜出。落选必须有实际比较证据，不能预先把它写弱。记录胜负依据、双方收益和代价，防止推荐案靠违规或故意平庸的陪衬获胜。

胜出后仍要写下剩余代价、当前可执行增益和反转条件。没有这三项，“最优”只是没被挑战过的自信。

## 五、形成可裁决的导演命题

先用普通话写出真实冲突：

```text
两个都说得过去的方向是什么：
本作优先保住什么：
愿意舍弃什么：
为什么这个取舍更接近观众结果：
什么条件出现时需要反转：
```

只有能够改变候选胜负时，才压成箴言。以下写法不合格：

- 把多个正确名词排在一起；
- 只说“先做 A，再做 B”；
- 换成任何题材都成立；
- 无法从短句还原具体取舍；
- 听起来有气势，但没有一个方案会因此被淘汰。

现代汉语诗性来自准确关系、熟悉词语、停顿和可感动作，不来自生造术语。灵魂层可以凝练；流程、字段、路径和权限必须展开说明。

## 六、把导演命题拆成部门任务

每个部门只领取与自己有关的“观众结果 + 专业问题”，不领取一串形容词。

```text
编剧：哪个人物行动、场面或知识兑现让观众更新。
美术：哪些可见关系让观众一眼进入正确世界与情绪。
人物：身体、第一印象和稳定动作怎样承载角色关系。
服装：身份、阶段、行动与世界制度怎样穿在身上。
场景：空间怎样允许、阻止、暴露或重新解释人物行动。
声音：声源、说法、沉默和节奏怎样改变观众注意与预期。
资产：哪些对象一旦漂移会破坏身份、空间和连续性。
视频提示词：已经成立的镜头怎样成为模型能执行的时间因果。
生成审核：真实结果最早在哪个环节偏离导演意图。
```

部门任务必须同时写`必须解决 / 不得解决 / 可自由设计 / 返回条件`。只写“高级、电影感、统一、符合人设”，仍然没有给专业节点可执行的问题。

## 七、网状调用不是所有人读所有文件

### HANDOFF

当前负责人完成阶段结果并把状态、锁定项、自由区和失败边界交给下一负责人。HANDOFF 后，下游对本阶段成品负责，但不得改写上游权威事实。

### CONSULT

当前负责人遇到相邻专业问题，读取对应 Skill 的必要 Reference，取得局部判断。CONSULT ≠ HANDOFF；调用不转移主责，也不授予覆盖对方权威文件的权限。

### REVIEW

总导演在关键节点检查“这份专业结果是否仍让观众沿同一路线经历作品”。REVIEW 只裁决跨部门取舍，不替专业负责人现场重做成品。

### RETURN

发现问题时返回第一个能改变根因的负责人。台词没有人物动机回编剧；人物脸稳定但气质与世界冲突回人物或美术；提示词无法执行已确认动作才回视频；导演命题本身互相打架才回总导演。

### SHARED_SOURCE

所有节点读取同一份已确认人物、世界、资产、平台和模型事实。共享只解决单真源，不意味着任何节点都能修改它。

## 八、调用合同

每次 CONSULT 使用最小合同：

```text
当前主负责人：
为什么本专业无法独立判断：
需要咨询的节点与 Reference：
只需要它回答的问题：
当前必须保护：
允许它挑战的假设：
禁止覆盖项：
返回判断将进入哪个决定：
```

调用回执：

```text
实际读取：
取得的专业判断：
改变或确认的当前决定：
未采用的建议及原因：
主责是否仍在当前节点：是 / 否；若否，必须改用 HANDOFF。
```

没有改变或确认任何决定的读取，不算能力已经激活。

## 九、跨题材校准

### 同题异目的

同样是“Luna 演示灯光”：

- 摄影教学课的主推进力可能是问题—演示—辨认；
- 人物喜剧的主推进力可能是老胡误判—Luna 曲解—惩罚升级；
- 悬疑短片的主推进力可能是光线逐步暴露隐藏事实。

若三个方案只换台词和场景，说明导演判断没有生效。

### 异题同机制

灯光教学、爱情告白和产品演示都可能使用“观众先误判，随后因新证据重新解释前面画面”的机制。可以共享的是观众更新机制，不是人物、台词、镜头或题材外壳。

### 反模板任务

低冲突治愈故事不需要为了“有戏”强塞争吵和反转。它仍要有变化：一个人从不敢接受照顾到允许另一个人留下；推进力可以是微小动作与关系确认。总导演寻找必要变化，不把高烈度当作唯一强度。

## 十、三次复验

```text
剧本后：导演命题是否已经成为人物行动、信息顺序、表演和场面结果。
生成前：资产、声音和提示词是否托住同一主结果，有没有部门抢戏或互相矛盾。
成片后：不看内部说明，观众实际是否沿预定路径完成变化。
```

复验结论只允许三种：`继续`、`带证据 RETURN`、`请求者重新取舍`。不得用导演身份在下游文件中无记录改写。

## 十一、从局部素材进入完整成片

生成前就在既有导演阐述或交接包中，把预计素材按实际观看顺序串一次：开头承诺何时可辨、哪些段落需要理解停留、峰值前怎样留出对比、哪一处可剪、结尾需要保留什么余韵。使用现有图片、文字卡与朗读即可暴露容量问题，不新增剪辑软件权限；估计时长明确标估计，有最终音频才按真实时间复验。

给人工剪辑的交接要可执行：本段进入与退出依据、必须保留的动作结果与听者反应、声音桥或有意断声、字幕原文与出现时机、保护主体或知识证据的字幕区域、跨镜曝光与色彩连续目标、允许的局部变化及返回负责人。字幕不能解释本来应开放的关系答案，调色不能改变已锁定身份或知识色码。总导演统一整片节奏与观看结果，声音负责人提供声场与同步合同，MV导演保护歌曲结构，视频负责人提供可剪把手；不建立第二份剧本。

成片复验先离开内部说明完整观看，再定位单镜问题：局部各自好看但连起来重复、疲劳、声场跳变或承诺没有兑现时，先检查整片节奏与交接，不直接要求所有镜头变得更强。尚无媒体只能确认交接文本成立，不能宣称完整成片效果已通过。
