# 人体与体态设计专业方法

## 决定结果的关系

先定位头颈胸廓骨盆和关节链，再标重心与支撑面、躯干四肢比例、软组织分布；对拿取、承重、转身分别检查动作路径。生活事实先经过长期适应机制才落成身体特征；同职业允许不同适应。真实受限能力缺证据时写待验证，不虚构医学事实。

## 专业术语如何进入决定

center of mass（质心）；base of support（支撑面）；range of motion（关节活动范围）；kinetic chain（动力链）。

这些术语用于指出哪项关系要被核验。例如“范围”要有对象和限制，“结构”要有相邻与连接，“状态”要有起因和结束。交付给图片或视频模型时把术语编译为具体可见关系；交给专业制作时保留术语及其条件，不能声称已执行软件、施工、测量或真人试验。

## 代表场景与反例修正

搬运者提箱时仅前臂弯曲、躯干重心不响应，重量没有进入身体。比较靠近重心抱持与单侧拖移方案，根据剧本目的选定；不把所有劳动者都加肌肉和污渍。

先复现失败所在的条件，再执行本节修正。如果修正会改写父入口锁定的身份、整体造型、入口或剧情状态，停止局部补丁，携带冲突事实和两个可行返回选项交回负责人。不要因一个反例就把所有同类手法永久禁止。

## 独立结果清单

身体比例关系、静态重心、活动范围假设、熟练动作签名、服装和道具接触接口。

每项都写实际决定，不写“需要清楚、保持高级、加强真实”等未完成要求。可见正文与内部理由分开：正文写对象已经怎样成立，理由写为何胜出及何时重开。只有文本推演时，验收明确记为文字设计检查，真实效果仍待对应生产证据。


# 人物核心事实、选角与身体化

候选遵守核心合约的同约束比较：违规方案不计数，锁定方向只比较剩余自由区；推荐保留有效对手的优势、自身代价与反转条件。



## 先问人生怎样使用这具身体

人物设计不是从“圆脸还是长脸”开始，而是从一组能改变形象决定的核心事实开始：

```text
他长期做什么，身体哪里熟练、哪里受限。
他拥有多少资源、照料、睡眠、营养和安全感。
他在关系里通常靠近、退让、占据还是隐身。
他怎样理解自己，又想让别人怎样看见自己。
他的年龄、健康、劳动、训练和生活环境留下什么可见结果。
本剧最重要的选择，需要这具身体怎样完成或承受。
```

职业、阶层和性格词只提供调查方向，不直接推出身材、脸型和姿态。两名同龄刀修可以分别依靠体量、精度或耐久形成危险感；两名普通收银员也可能因工作年限、照料程度、空间习惯和身体节奏完全不同。



## 人生不必写满身体，反复发生的事才会留下形状

人物身体化的主链是：

```text
已确认事实
→ 它怎样长期作用于身体、注意力和空间使用
→ 人物为适应这种生活反复怎样站、动、停、看、握持或避让
→ 哪些适应形成稳定的脸身姿动关系
→ 观众因此产生什么第一印象
```

中间的`长期作用机制`不能省略。它负责阻止“辛苦所以黑眼圈、善良所以眉眼柔和、强大所以宽肩肌肉”这类符号替换。人物经历只有满足以下条件，才进入稳定母版：

- 它反复发生，而不是一次剧情动作。
- 它确实改变身体使用、照料状态或空间习惯，而不是只改变作者评价。
- 它在目标媒介和实际景别里能够被看见。
- 它能与同类人物拉开关系差异，而不是给所有同职业者复制同一痕迹。

例如，同样在食堂后厨工作多年，主灶、切配和搬运不会共享一套“劳动者粗糙感”。主灶长期在热源与多任务之间切换，可能形成短距离转身、提前让开热锅路径和高频停看；切配的识别力可能落在稳定站距、重复落点与手臂节奏；搬运更依赖抓握、承重路径和通过狭窄空间时的身体侧转。具体选择仍要由剧本动作、工作分工和人物关系决定，不能把这个例子反写成职业模板。

如果一种经历能推出多种合理身体结果，就把它们变成候选，而不是假装只有唯一答案。人物设计的专业性，不在给事实配一个特征，而在比较哪一种身体适应最能承住这个人物的关系与行动。



## 身体化候选卡

```text
候选编号与选角假设：
观众关系押注：
剧本与生活证据：
面部关系和年龄感：
身体比例、体量与功能：
自然发貌与照料习惯：
基础姿态和空间占用：
稳定动作语言：
去掉服装、武器和饰物后仍成立的证据：
群像中的差异位置：
媒介与生产风险：
刻板印象风险：
假设置信度 / 待验证条件 / 重新开启候选条件：
胜出收益 / 淘汰理由：
```

稳定动作语言介于中性素体和具体表演之间。它不规定本镜必须抬手、皱眉或哭，而是规定同一人物在不同动作中仍反复可见的组织方式，例如：先移视线再动重心；动作幅度小但停止极准；靠近别人时肩膀不退；使用长刀时髋先于肩转动。



## 从生活与社会材料找到身体选择

皱纹、破衣、疲惫和暖光只能提供表面线索，不能独自证明经历。优先从剧本已确认的职业流程、公共空间、代际关系与资源限制中找人物怎样行动：谁有资格先开口，谁需要等交接，工具放在哪里，哪些劳动不能停，谁替谁保留座位，收入或照护限制怎样改变时间安排。每条材料按“来源事实 → 现实限制 → 人物选择 → 可见使用方式 → 可能的另一种选择”展开；观察不足记假设，不把职业或贫富推成固定性格、脸型与道德。

例如，同为夜班照护者，一人习惯把常用物按取用顺序放在伸手范围内，另一人反复复核后才动手；这能成为手部节奏、重心与空间行为的候选，不能擅自写成剧情已经发生。人物事实仍由编剧确认，设计只负责身体化。删掉“沧桑、善良、辛苦”等装饰词后，若选择与使用关系仍可辨认，材料才真正进入人物，而不是只给皮肤加纹理。


## 与服装设计的接口

人物设计交给服装的不是一张裸模，而是一组设计约束：

```text
身体尺度与活动范围：
人物怎样理解和管理自己的身体：
稳定姿态、动作节奏与工具关系：
观众第一印象可由服装加强、修正或必须退让的部分：
不可遮蔽的脸、颈肩、手、身体或动作锚点：
阶段变化与场景限制：
文化、身份和权利边界：
```

服装可以改变轮廓和自我呈现，不能擅自改写身体事实、人格真相或永久身份锚点。



## 与道具和装备资产的接口

刀、枪、乐器、工具、轮椅、义体、坐骑控制件或长期装备会改变人物身体组织时，人物设计先交付：

```text
人体尺度、手脚尺度与活动范围：
握持、穿戴、承托和接触接口：
重量、重心、长度或阻力的设计假设：
稳定动作语言必须保留的起势、路径与停点：
不可改的人物—物件关系：
需要道具资产以结构图或真实操作验证的高风险点：
```

人物设计不画道具结构，也不凭人物气质发明装备造型；`laohu-prop-design`负责道具 / 装备的功能结构、材质与人体操作条件；视觉资产的道具分支继承已确认设计，负责制作视图、图片提示词和稳定复现验证。真实物件暴露人体工学冲突时，携带握持、受力、活动或遮挡证据返回人物设计与道具资产共同裁决最早断点。



## 人体、面部与运动资料

- [CDC NHANES Anthropometry Procedures](https://wwwn.cdc.gov/nchs/data/nhanes/public/2021/manuals/2021-Anthropometry-Procedures-Manual-508.pdf)、[NLM Visible Human](https://www.nlm.nih.gov/research/visible/visible_human.html)：用于人体结构与测量方法校准，不把统计平均当成角色默认身体。
- [SMPL](https://smpl.is.tue.mpg.de/)、[AMASS](https://amass.is.tue.mpg.de/)、[FLAME](https://is.mpg.de/ps/code/flame-learning-a-model-of-facial-shape-and-expression-from-4d-scans)：用于理解身体、动作、脸形与表情的参数化关系；不能由模型参数反推人格。
- [Oosterhof 与 Todorov 面孔社会判断研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2516255/)与[Princeton 第一印象说明](https://www.princeton.edu/news/2017/10/16/todorov-explores-irresistible-influence-first-impressions)：面孔会触发快速评价，但不保证准确。
- [Hu 等：First Impressions of Personality Traits From Body Shapes](https://pubmed.ncbi.nlm.nih.gov/30346244/)：观察者会对三维身体形状形成具有共识的效价与能动性判断；支持把体量作为观众第一印象通道，不支持把这种共识当作真实性格测量。
- [身份与表情知觉研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4358059/)、[步态与情绪识别](https://pubmed.ncbi.nlm.nih.gov/19761306/)、[姿态与情绪研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5432628/)：支持把表情、姿态和运动纳入人物设计，同时要求稳定身份与当前状态分离。



### 2. 把人物核心事实转成身体化命题

先写`人物核心事实`：生活条件、劳动与训练、健康和年龄、资源与照料、关系位置、自我形象、长期压力、行动能力、别人如何对待他。再写一句`人物身体化命题`：

```text
这个人怎样使用自己的身体进入世界；观众第一眼应先读到什么；哪组脸、身体、姿态和动作关系能让这种处境可见，而不是给人格贴标签。
```

身体化至少同时处理：面部结构与年龄感、身体比例与软组织、手脚和颈肩、自然发质与整理习惯、生活或训练痕迹、静止时的重心与空间占用、动作起势与收势、与人和物的距离习惯。详细方法读取[laohu-body-design / SKILL](../SKILL.md) / [laohu-casting / SKILL](../../laohu-casting/SKILL.md) / [laohu-ensemble-design / SKILL](../../laohu-ensemble-design/SKILL.md)。

人物进入可听表演时，再建立稳定而非逐镜的`可听声音身份`：生理与年龄允许的音区、音色质地、常态音量、共鸣位置、咬字清晰度、语速范围、呼吸支撑、地域 / 职业 / 身体经验留下的发声痕迹，以及跨媒介必须保持的听觉辨识。它不能从外貌刻板推断，也不等于“低沉、磁性、温柔”三个形容词；没有可靠依据时登记为设计假设。编剧仍负责他说什么和语言策略，声音制作负责真实选角 / 音色资产，视频负责本场怎样说。

稳定动作语言进一步写成`条件化行为签名`：明确在何种压力、关系和目标下，这个人通常先怎样判断，再选择怎样的身体与发声策略；具体动作必须随空间、道具、伤病和对手变化。例如“公开受压时先压低音量、缩短句子并保持眼线，直到对方触碰他保护的人才前进一步”是签名；“每次紧张都摸耳环”只是机械招牌动作。条件不触发时，不得为了人物一致性硬塞同一动作。

人物事实不能直接兑换成外貌特征。先确认它长期改变了什么身体使用方式，再决定这种改变应落在比例、痕迹、姿态、动作还是空间习惯上：

```text
人物事实 → 长期作用机制 → 反复形成的身体适应 → 可见的脸身姿动关系 → 观众第一印象。
```

只把反复发生、因果足够强、能被目标媒介看见并能提高人物辨认度的结果写进母版；没有这条中间因果的伤疤、疲惫、粗糙、瘦弱和强壮，都是类型装饰。



## 实际填写示范与判定

以下为虚构练习条件，不冒充当前作品事实。

承重卡：物体先靠近腹前，双脚形成稳定支撑，重心变化先于抬起后的步移；转弯时箱角与门框留出明确距离。此卡只证明动作组织，不指定不存在的身高和重量测量。若动作能力与剧本伤病冲突，保留伤病事实返回编剧，而非设计出更强身体。

交付前把示范中的对象换成当前已确认对象，再重新推理；不得直接照抄示范形态。成功标准是同一套事实能够解释选择、结构和下一状态，失败时能指出最早需要变化的决定。
