# 选角专业方法

## 决定结果的关系

把剧本中反复选择与行动分为必须能力、观众第一预期和自由区；比较同样满足事实的亲近型、低估型、压迫型选角关系。先设计两项以上脸身姿动差异，再以同一场压力动作比较，不拿静态精修胜负替代表演潜力。锁定真人只覆盖可见证据，缺少侧背面不能推为真实测量。

## 专业术语如何进入决定

casting breakdown（角色选角拆解）；chemistry read（关系试演）；range（可表演范围）。

这些术语用于指出哪项关系要被核验。例如“范围”要有对象和限制，“结构”要有相邻与连接，“状态”要有起因和结束。交付给图片或视频模型时把术语编译为具体可见关系；交给专业制作时保留术语及其条件，不能声称已执行软件、施工、测量或真人试验。

## 代表场景与反例修正

沉默的维修员不必都宽肩粗脸；可比较动作幅度小而落点准、体量大却主动让路、精力充沛但手部谨慎三种身体关系。若三案只是换发色，退回候选轴。

先复现失败所在的条件，再执行本节修正。如果修正会改写父入口锁定的身份、整体造型、入口或剧情状态，停止局部补丁，携带冲突事实和两个可行返回选项交回负责人。不要因一个反例就把所有同类手法永久禁止。

## 独立结果清单

选角范围、三至五个合法关系候选、同场试演题、推荐与淘汰理由、身份锁定边界。

每项都写实际决定，不写“需要清楚、保持高级、加强真实”等未完成要求。可见正文与内部理由分开：正文写对象已经怎样成立，理由写为何胜出及何时重开。只有文本推演时，验收明确记为文字设计检查，真实效果仍待对应生产证据。


## 人物证据阶梯

按可靠度使用材料：

1. 剧本中反复发生的选择、动作、代价和他人反应。
2. 已确认的年龄、健康、训练、劳动、生活条件与世界规则。
3. 用户有权使用的真人、原创设定、历史图像与可信观察资料。
4. 基于前述事实提出、可以被淘汰的选角与身体化假设。
5. 类型惯例和模型默认值，只能作为需要警惕的平均答案。

一句“他很强”不能直接变成宽肩肌肉；先问力量类型、训练方式、动作经济性、耐力、爆发、武器与代价。一句“她很聪明”也不能直接变成细眼镜或高额头；智力由选择证明，外形只能建立特定第一印象或生活结果。



## 选角假设不是找一张漂亮脸

每个候选押注一种不同的观众关系：观众会先亲近、警惕、低估、依赖、误读还是无法忽视这个人。候选至少改变两个承重维度：

- 面部：长宽与体块、五官相互位置、年龄感、软组织、自然非对称。
- 身体：身高、头身、颈肩、躯干与四肢、骨架和软组织分布、手脚尺度。
- 姿态：重心、脊柱与肩胯关系、占用空间、静止时是否保留余力。
- 运动：起势、停止、节奏、动作幅度、手脚先后、与他人或工具的距离。
- 痕迹：只使用能由生活、劳动、训练、健康或剧情支持的后天结果。

不要为了差异机械分配“一个圆脸、一个方脸、一个长脸”。每项差异都要回答：它怎样改变观众对人物关系的预期，怎样支持或阻碍人物在本剧中的行动。



## 有意识的平凡

平凡不是“无特征”。一个有意识的普通人设计，至少能回答：

- 身体如何适应日常劳动与休息。
- 自我照料是仔细、将就、间歇还是由别人代劳。
- 面部和姿态的年龄感来自什么生活节奏。
- 在熟悉空间里怎样移动，在权威面前怎样缩放自己。
- 去掉特殊装饰后，哪一组比例、节奏和痕迹仍属于他。

若答案只能是“正常、自然、普通、耐看”，说明仍是模型默认人。不要用一个痣、一缕白发或一道伤疤替代完整判断。



## 选优顺序

1. 先看是否准确承接剧本人物和主胜负手。
2. 再看不靠服装道具是否仍可识别、可表演。
3. 再看与群像是否形成必要差异，而非为了不同而不同。
4. 再看目标媒介是否能稳定生产和运动。
5. 最后才比较局部美感与流行程度。

最漂亮、最凶、最仙或最奇特不自动胜出；最能让人物关系在身体上成立的候选胜出。



# 媒介适配、表演测试与交接



## 先有同一个人，再有不同媒介

跨真人写实、2D、3D和AI生成的共同核心是`媒介无关身份母版`：

```text
脸部相互关系：不是单个五官清单，而是长宽、间距、体块和年龄感。
身体相互关系：头身、颈肩、躯干四肢、骨架与软组织、手脚尺度。
外轮廓与主锚点：去色、换装、转角度后仍可辨。
基础姿态与稳定动作语言：静止与运动都属于同一个人。
自然发貌与永久痕迹：可随造型整理，但身份来源不漂移。
第一印象职责：媒介变化后仍让观众产生同一层级的预期。
```

跨媒介追求的是感知等效，不是机械复制数值。2D可以强化比例，3D需要闭合体积，真人需要真实软组织；只要它们保留同一人物关系与识别逻辑，就可以是同一个人。



## 四种媒介适配

### 真人与写实

- 写`选角范围`而非凭空指定某位演员：年龄感、体量、脸部关系、动作能力、声音与表演要求。
- 保留自然非对称、皮肤和软组织，不把概念图的几何纯度强加真人。
- 区分演员固有身份、可通过妆发服装改变的部分、不可安全改变的身体事实。
- 已锁定真人时，零改动只覆盖参考真实可见范围；不可见角度和身体数据不得虚构成测量值。

### 2D动画

- 选择清楚的形状语言和比例强化，但强化服务人物关系，不服务统一萌化或美型模板。
- 测试正面、45度、侧面、背面、五个基本表情和三种承重姿态。
- 去掉发色和服装后，头部关系、身体轮廓和动作节奏仍能识别。
- 线条、色块和局部变形可以简化表面，不得重画身份。

### 3D角色

- 设计必须在旋转后体积闭合，不能只有正面概念成立。
- 在建模前标出骨点、软组织、自然非对称、表情活动区和关键轮廓转折。
- 用极端但合理的表情、抬臂、蹲起、扭转、握持和服装接触做压力测试，暴露拓扑、绑定和穿插风险。
- 技术修正可以改变拓扑和内部结构，不能借机改变脸身关系和动作身份。

### AI生成

- 先冻结少量稳定锚点和相互关系，再由视觉资产编译提示词、视图、参考职责和依赖。
- 同一人物的正面、45度、侧背、全身和动作图必须使用同一规范词账本；发色、饰物和服装不能成为唯一身份来源。
- 用去装、换装、转角度、换光线和基础动作做回归；只在一张精修正脸成立不算身份稳定。
- 文字母版、待绑定占位和真实已验收图片严格分开。



## 三轮表演压力测试

### 中性身份测试

正面、45度、侧面、背面、放松站姿。确认脸身比例、主锚点、年龄感与同组差异。

### 表情与姿态测试

至少覆盖亲近、戒备、受压、决断和失控边缘，不要求五张夸张表情。检查情绪变化后是否仍是同一个人，第一印象能否被表演修正而不是靠换脸。

### 动作与关系测试

选择最能暴露人物身体组织的三个动作：日常熟练动作、承重或工具动作、与他人的距离动作。检查重心、起势、节奏、空间占用和停点是否保持稳定动作语言。

只有文字推演时标记`待试演 / 待建模 / 待生成验证`；不得声称已经通过视觉压力测试。



## 与视觉资产的接口

视觉资产把胜出设计编译为生产资产：

- B记录稳定身份与身体工程信息，不重新选择脸和身体。
- 阶段素体只改变已授权的年龄、体重、伤病、康复或形态区。
- M编译当前稳定发貌意图、妆发、饰物和穿衣结果，不重画人物母版。
- G校准有限关系组身份或开放群众范围，不替代上游群像差异设计。
- 图片提示词、板式、真实绑定、依赖、生成和验收由视觉资产负责。

若用户只提供一张锁定正脸，视觉资产不得把推定的背面、身高和围度标为真人事实。可以建立`推定制作信息`，但高风险缺口必须显式隔离并等待更多证据。



## 媒介回归表

```text
母版锚点 / 真人写实实现 / 2D等效实现 / 3D等效实现 / AI稳定词与参考职责 / 允许变化 / 失败表现 / 返回负责人。
```

验收优先级：人物关系与身份等效 > 表演和运动成立 > 群像差异 > 媒介风格纯度 > 局部装饰一致。


# 资料来源、文化真实性与证据边界



## 资料只回答机制，不替人物作决定

研究来源按四类使用：

1. `创作机制`：成熟角色团队如何从核心事实、观察、草图、候选和测试形成设计。
2. `人体与动作`：解剖、人体测量、形态和运动数据帮助避免结构错误，不直接规定审美与人格。
3. `知觉与表演`：第一印象、身份、表情、姿态和步态研究帮助管理观众预期，不证明面相能准确判断善恶。
4. `文化与权利`：历史图像、社群资料、代表性标准和授权范围帮助避免泛化、挪用和无证复刻。

每次引用都标明：`来源支持的事实 / 可迁移机制 / 本项目推论 / 仍需验证 / 不得推出的结论`。

- [ArtCenter Entertainment Design 课程说明](https://www.artcenter.edu/academics/undergraduate-degrees/entertainment-design/course-of-study/course-descriptions.html)：分析、参考、构思、色材与生产图需要接力。
- [Pixar：Stylization at Pixar](https://renderman.pixar.com/stories/stylization-at-pixar)：风格化轮廓和形状服务故事，不把风格当滤镜。

## 文化与代表性

- [BFI Diversity Standards](https://www.bfi.org.uk/inclusion-film-industry/diversity-standards-resources)及[银幕呈现标准](https://posi.www.bfi.org.uk/inclusion-film-industry/bfi-diversity-standards/bfi-diversity-standards-film/standard-screen-representation-themes-narratives)：人物应多维、具体、非刻板；“出现差异”不等于完成真实呈现。
- [Costume Designers Guild：What Is Costume Design?](https://costumedesignersguild.com/what-is-costume-design/)：短片可能只用几分钟甚至几个瞬间建立人物，服装能在角色开口前传达身份、经济状态、情绪和他希望如何被看见；支持把自我呈现作为人物代码，不支持让单一服饰直接判定人格。
- [WIPO Traditional Cultural Expressions](https://www.wipo.int/en/web/traditional-knowledge/traditional-cultural-expressions/index)：传统文化表达涉及归属、保护和许可，不能因公开可见就任意复制。
- [Smithsonian Native Knowledge 360](https://americanindian.si.edu/nk360/informational/native-american-literature-in-your-classroom)：族群与历史描述要具体到社群和语境，不使用泛化集合名。
- [故宫博物院绘画藏品](https://www.dpm.org.cn/collection/paints.html)、[数字敦煌开放素材库](https://ip.e-dunhuang.com/)、[中国美术馆雕塑](https://www.namoc.cn/namoc/diaos/dc_list_23.shtml)：可用于中国历史人物、姿态、比例和身份的题材校准；先确认时代、地区、阶层与宗教语境，不把“东方”当成可混搭风格包。
- [美国电影艺术与科学学院服装及妆造教学资料](https://www.oscars.org/sites/oscars/files/costumes_and_makeup_activites_guide.pdf)：妆发可呈现时期、生活方式、地位和心理变化，但仍需连续性与部门分权。



## 真人与参考权利

- “根据真人真事”不自动授权复制真人相貌。
- 新闻照片、社交媒体图片、搜索结果和演员姓名不自动成为可用角色参考。
- 用户锁定真人时记录来源、权利状态、允许用途、可见角度、可确认身体范围和禁止推定项。
- 一张正脸只证明正脸中真实可见的信息；背面、身高、围度、伤痕和身体能力缺证据时写`缺`或`推定制作信息`，不能写成事实。
- 历史人物与公共人物仍需按项目用途、平台、诽谤、人格与版权风险判断，不能因知名而默认自由复刻。



## 文化真实性检查

```text
具体时代、地区、社群与身份：
谁提供了材料，谁有解释权：
可确认事实：
为本项目提出的设计推论：
哪些符号只属于特定仪式、信仰、创伤或权力关系：
哪些差异可能被误读成善恶、原始、异域或笑料：
需要顾问、授权或更多证据的部分：
```

没有足够资料时，缩小声称范围、保留未知或改为明确虚构；不要用“考据感、民族风、东方脸、异域骨相”掩盖来源空缺。


### 3. 先选择艺术化强度，再决定把哪里推离平均线

人物设计不能把`真人写实`误解成`统计平均`。现实可信度和艺术夸张度是两条独立轴：人物可以有真实皮肤、重量和生活逻辑，同时拥有被有意识推大的体量差、轮廓、姿态、动作幅度或自我呈现。按作品条件选择强度，不设全项目统一中间值：

| 强度 | 适用条件 | 设计动作 |
|---|---|---|
| `R0 观察写实` | 纪录、真人还原、严肃现实题材 | 只放大观察精度，不改变主要比例 |
| `R1 选择性写实` | 常规剧情、关系戏、自然主义广告 | 保持现实比例，强化少量后天痕迹与稳定姿态 |
| `R2 真人漫画` | 无字幕短剧、动作喜剧、寓言、强类型角色 | 保持真人材质与受力，有选择地推大2—4组脸身姿动关系 |
| `R3 图形化变形` | 动画、荒诞、讽刺、儿童或明确超现实世界 | 允许比例和轮廓明显变形，但身份与运动逻辑仍须闭合 |

选择依据是`观众有多少时间 / 是否依赖对白字幕 / 景别多远 / 类型是否允许 / 人物第一眼承担多少信息 / 生成与表演能否保持`。短、远、无字、强喜剧通常需要更高强度；近、长、写实、真实人物通常需要更低强度。高强度不是每个维度一起变大，而是先找角色相对同组平均值最有信息量的偏离，再保护其他部分退让。

每个开放设计的主要人物写一张`选择性夸张卡`：

```text
艺术化强度：R0 / R1 / R2 / R3。
当前同类的平均答案：
借用的类型预期：
有意推大的2—4组关系：
保持写实的部分：
故意不被风险检查削弱的锐边：
行为怎样确认、修正或推翻第一印象：
若减弱到安全中间值，会损失什么观众结果：
```

类型编码可以使用体量、年龄感、姿态、发貌、自我呈现、服装、道具和空间占用，但`单一身体属性不得独自承担道德判决`。例如肥胖可以参与“占满座椅”的轮廓，金链可以参与“主动炫耀”的自我呈现；坏仍由占路、伤人、拒绝提醒等行为证明。反过来，不能因为某个代码可能成为俗套，就把体量、首饰、姿态和穿法全部删除，只留下一个没有信息的正常人。

先把三层分权写明：`现实判断`需要事实证据，不能把银幕惯例说成现实统计；`艺术编码`可以有意识调用、推大或反转观众熟悉的类型预期；`人物真相`必须由这个具体人物在压力下的行为独立证明。三层同时成立，才既不会以“客观”为名制造偏见，也不会以“谨慎”为名把人物磨成平均值。



### 5. 让候选在人物关系与艺术锋利度上竞争

开放方向的完整调用通常生成3—5个真正不同的候选；方向已锁定时按剩余自由区比较，不凑数量。候选遵守核心合约的同约束比较：违规方案不计数，锁定方向只比较剩余自由区；推荐保留有效对手的优势、自身代价与反转条件。单名未锁定的主要人物或关键配角，按该人物通常竞争3—5个候选；事实与自由区不足时如实记录可行替代，不放宽锁定事实凑数。四名以上彼此承重的主要群像，可以竞争3—5套`完整群像选角系统`来控制成本，但每套都必须为每名尚未锁定的主要人物提供不同的脸身姿动方案，使每个人都经过其自由区内的真实替代比较；只调整成员站位或让个别人物变化，不算新的整组系统。普通配角、锁定身份和远景群众按调用强度降级，不机械乘算候选。

候选至少改变两个承重维度，且至少一个来自身体比例、面部关系、体量、基础姿态、运动节奏或空间行为；只换发型、发色、瞳色、痣、伤疤、饰物和风格词不算新方向。

题材允许艺术化、人物第一印象承重或用户明确要求强辨识度时，候选不能全是风险递减后的同一中间值。至少包含：一案把类型代码与选择性夸张推到当前合同允许的上沿；一案使用反类型或误导；其余方案可以在两者之间形成有明确理由的混合。最强推进案可以淘汰，但不能在发散前就被删掉。

每个候选必须写清：

```text
选角假设 / 人物关系押注 / 第一印象 / 艺术化强度 / 借用的类型预期 / 有意推大的关系 / 故意保留的锐边 / 核心脸部关系 / 身体与比例 / 基础姿态 / 稳定动作语言 / 可听声音身份 / 条件化行为签名 / 生活与训练证据 / 群像位置 / 媒介风险 / 刻板印象风险 / 主要收益 / 淘汰风险。
```

自动选出当前最佳，不把普通专业取舍重新问给老胡。保留候选编号、胜出理由和每个候选的`淘汰理由`。候选外形不同但表达同一种人物关系，仍算同一方向的变体。

风险栏负责指出`伤害、陈词滥调、观众争议、生成失控`分别是什么，不自动执行删减。只有会把现实群体当作劣等或把单一身体属性当作道德事实的伤害风险需要硬停止；陈词滥调需要增加人物特异性，观众争议可以成为作品有意保留的摩擦，生成风险交给媒介适配处理。



### 6. 区分有意识的平凡与模型默认人

`有意识的平凡`可以没有夺目骨相、稀有发色和夸张比例，但仍有准确的年龄感、身体使用方式、照料程度、劳动痕迹、空间习惯和生活节奏。`模型默认人`只是同龄、同性别、同题材角色的平均脸与平均身体。

执行`换人测试`：把姓名和职业换成同年龄同处境的另一个角色，脸部关系、身体比例、姿态、动作节奏和生活痕迹是否仍可原样复用。若是，继续设计；不要靠添痣、异色瞳、伤疤和古怪发型强行制造人物化。

再执行`平均化回退测试`：列出候选被谨慎措辞删掉的所有特征。如果删去体量偏差、姿态、动作幅度、自我呈现与类型代码后只剩“自然、正常、耐看”，该候选无论多安全都不能胜出。反过来，如果每个维度都夸张、没有主次，也不能胜出。



## 实际填写示范与判定

以下为虚构练习条件，不冒充当前作品事实。

任务：修理工被顾客公开指责仍坚持完成检修。A以体量和主动让路形成反差；B以窄幅动作和稳定注视形成专业控制；C以快速动作遇压力突然停住形成紧绷感。若主结果是观众先低估再信任，选B；A的体量先压过低估，C容易预告失控。保留手部节奏作主锚点，不以工具油污证明人格。

交付前把示范中的对象换成当前已确认对象，再重新推理；不得直接照抄示范形态。成功标准是同一套事实能够解释选择、结构和下一状态，失败时能指出最早需要变化的决定。
