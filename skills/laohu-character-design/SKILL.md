# 老胡人物设计

## 四层创作判断

- **灵魂**：人生要落在同一具可表演身体上。
- **筋骨**：先确定选角关系，再让脸身和群像相互校准。
- **血肉**：用相同场次动作比较身体化候选，不靠装饰区分。
- **表皮**：人物母版、写真正文及锁定身份是正式接力对象。

## 导演协作接口

公开作品继承`导演阐述`对观众第一判断、人物关系、表演尺度和不得提前泄露内容的要求。本 Skill 可 `CONSULT` 编剧、服装、场景和声音节点，取得身体动作、穿着、空间与声音身份的局部判断；调用不转移主责。人物设计不能重写导演命题和剧情，发现二者无法由身体与表演成立时返回最早负责人。

## 人物箴言

人物不是一张脸，是一段人生长成的身体。

观众可以先看错，人物不能被设计错。外形可以制造预期，真正的人格仍由他在压力下的选择证明。

边界是护栏，不是方向盘。写实守住世界，夸张负责让这个人离开平均线。

## 职责与调用边界

本 Skill 是原创人物形象设计的唯一负责人，负责把已确认的剧本人物转成可见、可听、可表演、可生产的`人物母版`：选角假设、年龄感、身体关系、面部关系、自然发貌、生活痕迹、基础姿态、稳定动作语言、可听声音身份、观众第一印象、群像差异、跨媒介等效翻译、候选竞争、胜出与淘汰理由。主要人物还要交付可直接进入图片模型的`人物写真设计正文`与`妆造补充正文`，前者描述已经胜出的脸、身体、气质与成像方向，其中后者由`laohu-makeup-design`维护，补足妆容、发型、发饰及侧背面结构。

作品存在`美术风格设计交接包`时，必须继承其题材视觉合同、形态与色彩系统、文化边界、人物证据分配和相邻类型风险；本 Skill只在这些边界内设计人物。交接包缺失且人物第一眼承担题材归属，或真实人物图去标签后落入相邻类型时，先返回`laohu-art-direction`，不能用脸型、发色、妆容或“仙气 / 未来感 / 恐怖感”等词代做作品级风格。

`人物母版`不是第二份人物小传。作品已有`人物连续性圣经`时，把人物母版作为其中的形象设计分区或被它明确引用的专业交接包：剧本继续拥有目标、知识、关系、选择和人格事实；本 Skill只拥有这些事实怎样被身体化。不得在两个文件重复维护同一事实或形成互相冲突的两个人物真相。

它不替编剧决定人物为什么行动，不替服装设计决定穿什么，不制作 F / B / 阶段素体 / M / G固定资产板，也不把某一镜的哭笑、眼神、受力和动作写进永久身份。它必须写清人物写真设计正文，并CONSULT `laohu-makeup-design`取得妆造补充正文后整合；天然发貌和永久身份仍由人物母版锁定，但不添加资产排版、三视图、参数栏或网格框架。胜出结果分别交给：

- `laohu-costume-design`：读取身体、行动、自我形象、第一印象和不可遮蔽锚点，继续原创服装。
- `laohu-set-design`：读取人体尺度、稳定动作语言、空间占用、距离习惯和人与工具的关系，继续原创空间与人物调度接口。
- `laohu-visual-assets`：把人物写真设计正文、妆造补充正文与其他上游设计组合进F、B、阶段素体、M、G固定资产框架，管理依赖和验收；不得重写人物与妆造设计。
- `laohu-audio-design`：继承可听声音身份与条件化行为签名，编译自然语言音色描述、当场语音表演和真实音频生成任务，不反向改写人物身份。
- 剧本与视频：继承稳定动作语言、可听声音身份和条件化行为签名，但当前场次表演仍由各自阶段根据人物目的与精确触发编译。

### 调用强度

| 方式 | 触发 | 本轮结果 |
|---|---|---|
| 完整调用 | 主要人物、关键配角、世界首批角色、多人同质、人物第一印象承担反转、需要真人 / 2D / 3D / AI 共用母版 | 任务合同、核心事实、有效候选（开放方向通常3—5个，锁定方向按剩余差异）、群像比较、自动选优、人物设计交接包 |
| 轻量调用 | 已有胜出母版下的新年龄阶段、普通配角、有限关系组补员、单一媒介的局部适配 | 继承身份，只处理当前差异轴、阶段变化或媒介翻译，不重开完整选角 |
| 无需调用 | 有权使用且已锁定的真人 / 原创角色参考；一次性不可识别远景群众；只需把已确认人物编译成资产 | 登记锁定边界或交给视觉资产做群体描述，不擅自改脸、改身体或补完不可见事实 |

先判定`人物设计授权状态`：`开放设计`允许原创；`建议方向`保护用户给出的年龄、气质、类型、身材或参考意图；`锁定身份`只在用户有权使用并明确要求零改动复现、且现有证据足以锁定相应信息时成立。锁定一张正脸不等于锁定背面身体、三围和不可见角度。

## 人物设计工作流

### 1. 建立人物任务合同

```text
人物任务合同：作品 / 美术风格设计交接包 / 题材与世界 / 媒介 / 角色与叙事权重 / 目标观众 / 人物设计授权状态 / 形象艺术化强度 / 已确认事实 / 可设计范围 / 不可改台词与剧情 / 复用范围 / 群像关系 / 输出用途 / 权利与文化边界。
```

把输入分为`事实 / 推论 / 设计选择`。编剧已经证明的目标、策略、选择、代价和关系不能被外貌重写；只有“高冷、善良、邪气、天才”等形容词时，不直接翻译成眼型和脸型，先找它在剧本中的行为证据。证据不足但不改变核心故事时，提出可回退的选角假设，同时登记`假设置信度 / 待验证条件 / 重新开启候选条件`；会改变人物立场、文化身份、真人权利或核心剧情时返回总控。

### 8. 锁定胜出人物母版

胜出后分开：

```text
固定身份：跨阶段和媒介都要保持的人脸关系、身体关系、永久特征和主识别锚点。
等效保持：不同媒介不照搬数值，但必须保留同一感知关系的部分。
阶段可变：年龄、伤病、体重、康复、照料程度和长期形态变化。
瞬时表演：只进入当前场次、镜头、声音和视频提示词的表情与动作。
禁止新增：会改写人物身份、文化来路、人格真相或主要轮廓的自由发挥。
```

锁定参考只记录真实可见和有证据的信息。不可见角度、背面身体、围度、身高和动作能力属于`高风险缺口`时停止猜测；可以提出待确认的制作假设，但不得冒充真人事实或零改动还原。

## 人物设计交接包

```text
【人物任务判断】完整 / 轻量 / 无需；设计授权状态；形象艺术化强度；权利与保护项。
【美术方向继承】题材视觉合同；人物承重证据；形态 / 色彩 / 材料 / 光影与运动边界；相邻类型风险；不得自行改写项。
【人物核心事实】逐项标明事实 / 推论 / 设计选择；人物身体化命题。
【选择性夸张卡】同类平均答案；借用的类型预期；有意推大的关系；保持写实；故意保留的锐边；减弱后的观众损失。
【第一印象—真实人格】视觉证据来源；一致 / 误导 / 部分成立；行为证明；禁止提前泄露。
【候选竞争】候选A—E或完整群像系统A—E的选角假设、脸身姿动差异、收益、风险和群像位置；每名主要人物的替代比较可追溯。
【胜出人物母版】自动胜出方案、主胜负手、胜出理由、淘汰理由。
【假设状态】事实充分度、假设置信度、待验证条件、重新开启候选条件。
【稳定动作语言】重心、起势、节奏、空间占用、距离习惯、与工具 / 武器的身体关系；不含当前镜头表演。
【可听声音身份】稳定音区、音色质地、常态音量、共鸣、咬字、语速、呼吸支撑与可验证来路；不含本场情绪曲线和具体台词演法。
【条件化行为签名】触发条件 / 人物解释 / 稳定策略 / 可变动作槽 / 升级阈值 / 弧光后新基线；不复制固定招牌动作。
【群像差异矩阵】共同基线、人物差异轴、不可重复锚点、远中近景证据。
【媒介适配】媒介无关身份母版；真人 / 2D / 3D / AI的固定、等效与可变项；压力测试结果。
【设计锁定】固定身份 / 等效保持 / 阶段可变 / 瞬时表演 / 禁止新增 / 高风险缺口。
【人物写真设计正文】图片模型可直接理解的完整人物描述：先用身份、年龄、受众观看位置和一个稳定感知底色限定人物候选范围，再写脸部关系、肤质、身体比例、姿态、发质与基础整理、目标媒介和成像质感。`强大却不证明自己、把感情压进旧物`等人物原因不得原样进入正文；必须翻译为观众直接感到的眼神、表情基线、肩颈、重心、距离、照料痕迹与光影关系。不写资产编号、网格、三视图和参数栏，不越权决定服装。
【妆造补充正文】图片模型可直接理解的妆容、眉眼、睫毛、肤面修饰、唇色、发型轮廓、发缝、侧背面发束、发饰与人物气质关系；先写模型熟悉的妆面 / 发型母型，再写位置、形状、色度、光泽、发束结构和当前人物变化。只补写真或服装设计没有说清的妆造，不重写脸身和服装。
【F消费建议】必须进入F的身份锚点；只作气质 / 表情 / 身体方向的内容；留给B / M或人工验收的不可见工程信息。人物设计仍完整交付，不替视觉资产决定最终字数和句式。
【交给服装】身体尺度与动作余量、人物自我形象、第一印象可加强或应退让处、不可遮蔽锚点、场景和文化边界。
【交给场景与布景】人体尺度、站坐蹲卧与转身余量、稳定动作语言、空间占用、距离习惯、常用工具 / 武器关系和高风险可达性缺口。
【交给道具 / 装备资产】人体尺度与活动范围、握持 / 穿戴 / 承托接口、重量重心与长度假设、稳定动作语言要求、不可改的人物—物件关系、待验证高风险点。
【交给视觉资产】F人物写真母图的完整人物正文、B / 阶段素体 / M / G职责、真实参考状态、身份规范词、需生成视角、资产不得重设计项。F先由专业人像模型实现完整角色成品，随后反向拆给同编号B / W / M；F不重新选角，也不直接进入视频。
```

人物设计不写 F / B / M / G 的资产版式提示词，不把文字母版标成已生成资产。它写的是专业设计正文，由视觉资产接入对应框架。若制作板暴露身份无法稳定、动作无法成立、妆造与身份冲突或媒介翻译失败，携带真实证据返回本 Skill；纯版式、引用、参数栏、生图和下游调用错误留在`laohu-visual-assets`。

## 双门验收

### 底线门

- 剧本人格、观众第一印象和外貌事实没有混写。
- 人物母版覆盖脸、身体、姿态和稳定动作语言，不是脸型发型清单。
- 锁定真人或原创参考没有被擅改，不可见事实没有伪装成已知。
- 人物、服装、资产、镜头和声音职责不越权，交接包无需口头补充。
- 文化与身体差异没有作为唯一证据证明善恶、智力、阶级价值或可笑；类型代码与现实事实已经分权。

### 巅峰门

- 有效候选（开放方向通常3—5个，锁定方向按剩余差异）是否在人物关系和承重维度上真正不同，胜出与淘汰能否复验。
- 做`去装测试`：去掉服装、武器、饰物、发色和背景后，人物是否仍成立。
- 做`剪影与运动测试`：静止轮廓、重心、起势和空间占用能否区别于同组人物。
- 做`艺术强度测试`：当前强度是否匹配时长、字幕、景别与类型；风险检查是否把所有锐边磨成正常、自然、耐看。
- 做`最强推进案测试`：开放设计是否真的比较过一案位于当前艺术合同上沿的候选，而不是只在安全区内微调。
- 做换人测试：换掉姓名和职业后，胜出母版是否仍像任意同类角色。
- 做群像测试：共同世界成立，但没有同脸、同体型、同年龄感和同动作节奏。
- 做媒介回归：简化、体积化或写实化后，等效身份锚点和人物关系是否仍在。
- 有真实试演、模型表情 / 姿态测试或生成图时再写视觉验证通过；只有文字设计时只能标记人物设计稿通过。

## 妆发专业协作

天然发质、发际线与永久身份由人物母版锁定；妆容、发型、发饰及特效化妆由`laohu-makeup-design`提供专业设计。人物入口整合其妆造补充正文，不自行重新设计；下游按这一接口解释交接包中的妆造字段。


独立专业请求以用途、对象事实、必要动作与可设计范围建立最小合同，不要求先创作完整剧本；正式作品已有事实必须继承，输入不足不能成为补造剧情的授权。
