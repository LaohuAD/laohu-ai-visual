# 媒介适配、表演测试与交接

## 先有同一个人，再有不同媒介

跨真人写实、2D、3D和AI生成的共同核心是`媒介无关身份母版`：

```text
脸部相互关系：不是单个五官清单，而是长宽、间距、体块和年龄感。
身体相互关系：头身、颈肩、躯干四肢、骨架与软组织、手脚尺度。
外轮廓与主锚点：去色、换装、转角度后仍可辨。
基础姿态与稳定动作语言：静止与运动都属于同一个人。
自然发貌与永久痕迹：可随造型整理，但身份来源不漂移。
第一印象职责：媒介变化后仍让观众产生同一层级的预期。
```

跨媒介追求的是感知等效，不是机械复制数值。2D可以强化比例，3D需要闭合体积，真人需要真实软组织；只要它们保留同一人物关系与识别逻辑，就可以是同一个人。

## 四种媒介适配

### 真人与写实

- 写`选角范围`而非凭空指定某位演员：年龄感、体量、脸部关系、动作能力、声音与表演要求。
- 保留自然非对称、皮肤和软组织，不把概念图的几何纯度强加真人。
- 区分演员固有身份、可通过妆发服装改变的部分、不可安全改变的身体事实。
- 已锁定真人时，零改动只覆盖参考真实可见范围；不可见角度和身体数据不得虚构成测量值。

### 2D动画

- 选择清楚的形状语言和比例强化，但强化服务人物关系，不服务统一萌化或美型模板。
- 测试正面、45度、侧面、背面、五个基本表情和三种承重姿态。
- 去掉发色和服装后，头部关系、身体轮廓和动作节奏仍能识别。
- 线条、色块和局部变形可以简化表面，不得重画身份。

### 3D角色

- 设计必须在旋转后体积闭合，不能只有正面概念成立。
- 在建模前标出骨点、软组织、自然非对称、表情活动区和关键轮廓转折。
- 用极端但合理的表情、抬臂、蹲起、扭转、握持和服装接触做压力测试，暴露拓扑、绑定和穿插风险。
- 技术修正可以改变拓扑和内部结构，不能借机改变脸身关系和动作身份。

### AI生成

- 先冻结少量稳定锚点和相互关系，再由视觉资产编译提示词、视图、参考职责和依赖。
- 同一人物的正面、45度、侧背、全身和动作图必须使用同一规范词账本；发色、饰物和服装不能成为唯一身份来源。
- 用去装、换装、转角度、换光线和基础动作做回归；只在一张精修正脸成立不算身份稳定。
- 文字母版、待绑定占位和真实已验收图片严格分开。

## 三轮表演压力测试

### 中性身份测试

正面、45度、侧面、背面、放松站姿。确认脸身比例、主锚点、年龄感与同组差异。

### 表情与姿态测试

至少覆盖亲近、戒备、受压、决断和失控边缘，不要求五张夸张表情。检查情绪变化后是否仍是同一个人，第一印象能否被表演修正而不是靠换脸。

### 动作与关系测试

选择最能暴露人物身体组织的三个动作：日常熟练动作、承重或工具动作、与他人的距离动作。检查重心、起势、节奏、空间占用和停点是否保持稳定动作语言。

只有文字推演时标记`待试演 / 待建模 / 待生成验证`；不得声称已经通过视觉压力测试。

## 与服装设计的接口

人物设计交给服装的不是一张裸模，而是一组设计约束：

```text
身体尺度与活动范围：
人物怎样理解和管理自己的身体：
稳定姿态、动作节奏与工具关系：
观众第一印象可由服装加强、修正或必须退让的部分：
不可遮蔽的脸、颈肩、手、身体或动作锚点：
阶段变化与场景限制：
文化、身份和权利边界：
```

服装可以改变轮廓和自我呈现，不能擅自改写身体事实、人格真相或永久身份锚点。

## 与道具和装备资产的接口

刀、枪、乐器、工具、轮椅、义体、坐骑控制件或长期装备会改变人物身体组织时，人物设计先交付：

```text
人体尺度、手脚尺度与活动范围：
握持、穿戴、承托和接触接口：
重量、重心、长度或阻力的设计假设：
稳定动作语言必须保留的起势、路径与停点：
不可改的人物—物件关系：
需要道具资产以结构图或真实操作验证的高风险点：
```

人物设计不画道具结构，也不凭人物气质发明装备造型；视觉资产的道具 / 装备分支负责功能结构、材质、制作图、图片提示词和操作验证。真实物件暴露人体工学冲突时，携带握持、受力、活动或遮挡证据返回人物设计与道具资产共同裁决最早断点。

## 与视觉资产的接口

视觉资产把胜出设计编译为生产资产：

- B记录稳定身份与身体工程信息，不重新选择脸和身体。
- 阶段素体只改变已授权的年龄、体重、伤病、康复或形态区。
- M编译当前稳定发貌意图、妆发、饰物和穿衣结果，不重画人物母版。
- G校准有限关系组身份或开放群众范围，不替代上游群像差异设计。
- 图片提示词、板式、真实绑定、依赖、生成和验收由视觉资产负责。

若用户只提供一张锁定正脸，视觉资产不得把推定的背面、身高和围度标为真人事实。可以建立`推定制作信息`，但高风险缺口必须显式隔离并等待更多证据。

## 媒介回归表

```text
母版锚点 / 真人写实实现 / 2D等效实现 / 3D等效实现 / AI稳定词与参考职责 / 允许变化 / 失败表现 / 返回负责人。
```

验收优先级：人物关系与身份等效 > 表演和运动成立 > 群像差异 > 媒介风格纯度 > 局部装饰一致。
