# 资料来源、文化真实性与证据边界

## 资料只回答机制，不替人物作决定

研究来源按四类使用：

1. `创作机制`：成熟角色团队如何从核心事实、观察、草图、候选和测试形成设计。
2. `人体与动作`：解剖、人体测量、形态和运动数据帮助避免结构错误，不直接规定审美与人格。
3. `知觉与表演`：第一印象、身份、表情、姿态和步态研究帮助管理观众预期，不证明面相能准确判断善恶。
4. `文化与权利`：历史图像、社群资料、代表性标准和授权范围帮助避免泛化、挪用和无证复刻。

每次引用都标明：`来源支持的事实 / 可迁移机制 / 本项目推论 / 仍需验证 / 不得推出的结论`。

## 核心创作与制作来源

- [Riot Games：/dev: Illaoi in Project L](https://www.riotgames.com/en/news/dev-illaoi-in-project-l)：从角色核心事实进入视觉方向、运动研究、原型和跨团队角色DNA。只吸收工作机制，不复制角色外形。
- [CalArts Character Animation 课程](https://catalog.calarts.edu/programs/UvzOg8mt3npdQQJrTCkI/general-aoYks)与[申请作品要求](https://calarts.edu/apply/bfa-character-animation)：生活观察、人体、动作、设计、故事和表演共同构成人物能力，不支持只练精修脸。
- [ArtCenter Entertainment Design 课程说明](https://www.artcenter.edu/academics/undergraduate-degrees/entertainment-design/course-of-study/course-descriptions.html)：分析、参考、构思、色材与生产图需要接力。
- [Pixar：Stylization at Pixar](https://renderman.pixar.com/stories/stylization-at-pixar)：风格化轮廓和形状服务故事，不把风格当滤镜。
- [Walt Disney Family Museum 角色工作表](https://www.waltdisney.org/sites/default/files/SW.worksheets.final.pdf)与[模型和缩微制作](https://www.waltdisney.org/blog/movie-models-and-miniatures)：人物需要身体、表情、姿态、多角度和相对尺度的一致依据。
- [Blender Studio：Stylized Character Workflow](https://studio.blender.org/training/stylized-character-workflow/chapter/intro-stylized-character-workflow/)、[Animation Testing](https://studio.blender.org/tools/pipeline-overview/asset-creation/animation-testing)、[Expression Tests](https://studio.blender.org/training/stylized-character-workflow/5d4a99d97b4f5e512c939903/)：头身迭代、表情姿态和动画压力测试用于验证可生产性。
- [Casting Society](https://www.castingsociety.com/page/aboutuscsa)、[BAFTA：Nina Gold](https://www.bafta.org/stories/note-to-self-nina-gold/)：选角是把角色变成有血肉生命的创作决定，不只是按标签匹配外貌。

## 人体、面部与运动资料

- [CDC NHANES Anthropometry Procedures](https://wwwn.cdc.gov/nchs/data/nhanes/public/2021/manuals/2021-Anthropometry-Procedures-Manual-508.pdf)、[NLM Visible Human](https://www.nlm.nih.gov/research/visible/visible_human.html)：用于人体结构与测量方法校准，不把统计平均当成角色默认身体。
- [SMPL](https://smpl.is.tue.mpg.de/)、[AMASS](https://amass.is.tue.mpg.de/)、[FLAME](https://is.mpg.de/ps/code/flame-learning-a-model-of-facial-shape-and-expression-from-4d-scans)：用于理解身体、动作、脸形与表情的参数化关系；不能由模型参数反推人格。
- [Oosterhof 与 Todorov 面孔社会判断研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2516255/)与[Princeton 第一印象说明](https://www.princeton.edu/news/2017/10/16/todorov-explores-irresistible-influence-first-impressions)：面孔会触发快速评价，但不保证准确。
- [身份与表情知觉研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4358059/)、[步态与情绪识别](https://pubmed.ncbi.nlm.nih.gov/19761306/)、[姿态与情绪研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5432628/)：支持把表情、姿态和运动纳入人物设计，同时要求稳定身份与当前状态分离。

## 文化与代表性

- [BFI Diversity Standards](https://www.bfi.org.uk/inclusion-film-industry/diversity-standards-resources)及[银幕呈现标准](https://posi.www.bfi.org.uk/inclusion-film-industry/bfi-diversity-standards/bfi-diversity-standards-film/standard-screen-representation-themes-narratives)：人物应多维、具体、非刻板；“出现差异”不等于完成真实呈现。
- [WIPO Traditional Cultural Expressions](https://www.wipo.int/en/web/traditional-knowledge/traditional-cultural-expressions/index)：传统文化表达涉及归属、保护和许可，不能因公开可见就任意复制。
- [Smithsonian Native Knowledge 360](https://americanindian.si.edu/nk360/informational/native-american-literature-in-your-classroom)：族群与历史描述要具体到社群和语境，不使用泛化集合名。
- [故宫博物院绘画藏品](https://www.dpm.org.cn/collection/paints.html)、[数字敦煌开放素材库](https://ip.e-dunhuang.com/)、[中国美术馆雕塑](https://www.namoc.cn/namoc/diaos/dc_list_23.shtml)：可用于中国历史人物、姿态、比例和身份的题材校准；先确认时代、地区、阶层与宗教语境，不把“东方”当成可混搭风格包。
- [美国电影艺术与科学学院服装及妆造教学资料](https://www.oscars.org/sites/oscars/files/costumes_and_makeup_activites_guide.pdf)：妆发可呈现时期、生活方式、地位和心理变化，但仍需连续性与部门分权。

## 真人与参考权利

- “根据真人真事”不自动授权复制真人相貌。
- 新闻照片、社交媒体图片、搜索结果和演员姓名不自动成为可用角色参考。
- 用户锁定真人时记录来源、权利状态、允许用途、可见角度、可确认身体范围和禁止推定项。
- 一张正脸只证明正脸中真实可见的信息；背面、身高、围度、伤痕和身体能力缺证据时写`缺`或`推定制作信息`，不能写成事实。
- 历史人物与公共人物仍需按项目用途、平台、诽谤、人格与版权风险判断，不能因知名而默认自由复刻。

## 文化真实性检查

```text
具体时代、地区、社群与身份：
谁提供了材料，谁有解释权：
可确认事实：
为本项目提出的设计推论：
哪些符号只属于特定仪式、信仰、创伤或权力关系：
哪些差异可能被误读成善恶、原始、异域或笑料：
需要顾问、授权或更多证据的部分：
```

没有足够资料时，缩小声称范围、保留未知或改为明确虚构；不要用“考据感、民族风、东方脸、异域骨相”掩盖来源空缺。
