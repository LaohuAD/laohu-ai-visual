# 人物核心事实、选角与身体化

## 先问人生怎样使用这具身体

人物设计不是从“圆脸还是长脸”开始，而是从一组能改变形象决定的核心事实开始：

```text
他长期做什么，身体哪里熟练、哪里受限。
他拥有多少资源、照料、睡眠、营养和安全感。
他在关系里通常靠近、退让、占据还是隐身。
他怎样理解自己，又想让别人怎样看见自己。
他的年龄、健康、劳动、训练和生活环境留下什么可见结果。
本剧最重要的选择，需要这具身体怎样完成或承受。
```

职业、阶层和性格词只提供调查方向，不直接推出身材、脸型和姿态。两名同龄刀修可以分别依靠体量、精度或耐久形成危险感；两名普通收银员也可能因工作年限、照料程度、空间习惯和身体节奏完全不同。

## 人生不必写满身体，反复发生的事才会留下形状

人物身体化的主链是：

```text
已确认事实
→ 它怎样长期作用于身体、注意力和空间使用
→ 人物为适应这种生活反复怎样站、动、停、看、握持或避让
→ 哪些适应形成稳定的脸身姿动关系
→ 观众因此产生什么第一印象
```

中间的`长期作用机制`不能省略。它负责阻止“辛苦所以黑眼圈、善良所以眉眼柔和、强大所以宽肩肌肉”这类符号替换。人物经历只有满足以下条件，才进入稳定母版：

- 它反复发生，而不是一次剧情动作。
- 它确实改变身体使用、照料状态或空间习惯，而不是只改变作者评价。
- 它在目标媒介和实际景别里能够被看见。
- 它能与同类人物拉开关系差异，而不是给所有同职业者复制同一痕迹。

例如，同样在食堂后厨工作多年，主灶、切配和搬运不会共享一套“劳动者粗糙感”。主灶长期在热源与多任务之间切换，可能形成短距离转身、提前让开热锅路径和高频停看；切配的识别力可能落在稳定站距、重复落点与手臂节奏；搬运更依赖抓握、承重路径和通过狭窄空间时的身体侧转。具体选择仍要由剧本动作、工作分工和人物关系决定，不能把这个例子反写成职业模板。

如果一种经历能推出多种合理身体结果，就把它们变成候选，而不是假装只有唯一答案。人物设计的专业性，不在给事实配一个特征，而在比较哪一种身体适应最能承住这个人物的关系与行动。

## 人物证据阶梯

按可靠度使用材料：

1. 剧本中反复发生的选择、动作、代价和他人反应。
2. 已确认的年龄、健康、训练、劳动、生活条件与世界规则。
3. 用户有权使用的真人、原创设定、历史图像与可信观察资料。
4. 基于前述事实提出、可以被淘汰的选角与身体化假设。
5. 类型惯例和模型默认值，只能作为需要警惕的平均答案。

一句“他很强”不能直接变成宽肩肌肉；先问力量类型、训练方式、动作经济性、耐力、爆发、武器与代价。一句“她很聪明”也不能直接变成细眼镜或高额头；智力由选择证明，外形只能建立特定第一印象或生活结果。

## 选角假设不是找一张漂亮脸

每个候选押注一种不同的观众关系：观众会先亲近、警惕、低估、依赖、误读还是无法忽视这个人。候选至少改变两个承重维度：

- 面部：长宽与体块、五官相互位置、年龄感、软组织、自然非对称。
- 身体：身高、头身、颈肩、躯干与四肢、骨架和软组织分布、手脚尺度。
- 姿态：重心、脊柱与肩胯关系、占用空间、静止时是否保留余力。
- 运动：起势、停止、节奏、动作幅度、手脚先后、与他人或工具的距离。
- 痕迹：只使用能由生活、劳动、训练、健康或剧情支持的后天结果。

不要为了差异机械分配“一个圆脸、一个方脸、一个长脸”。每项差异都要回答：它怎样改变观众对人物关系的预期，怎样支持或阻碍人物在本剧中的行动。

## 身体化候选卡

```text
候选编号与选角假设：
观众关系押注：
剧本与生活证据：
面部关系和年龄感：
身体比例、体量与功能：
自然发貌与照料习惯：
基础姿态和空间占用：
稳定动作语言：
去掉服装、武器和饰物后仍成立的证据：
群像中的差异位置：
媒介与生产风险：
刻板印象风险：
假设置信度 / 待验证条件 / 重新开启候选条件：
胜出收益 / 淘汰理由：
```

稳定动作语言介于中性素体和具体表演之间。它不规定本镜必须抬手、皱眉或哭，而是规定同一人物在不同动作中仍反复可见的组织方式，例如：先移视线再动重心；动作幅度小但停止极准；靠近别人时肩膀不退；使用长刀时髋先于肩转动。

## 群像先比较关系，再分别做资产

主要角色超过三人时，先在同一矩阵比较：

```text
角色 / 故事功能 / 观众第一印象 / 年龄感 / 身高体量 / 头身颈肩 / 脸部关系 / 重心 / 动作能量 / 空间占用 / 主锚点 / 不得与谁重复。
```

共同世界语法可以统一健康基线、审美习惯或训练体系，但不能把所有人收敛成相同脸部模板、模特身材、站姿和动作节奏。有限关系组校准图只能验收差异，不能替代这一步的设计因果。

群像候选有两种合法计数方式：逐人各做3—5个候选，或为四名以上彼此承重的主角做3—5套完整群像选角系统。使用整组方式时，每一套都要让每名未锁定主角获得一个真正不同的脸身姿动方案；同一人物在全部系统里原样不动，说明他没有经过候选竞争。

## 有意识的平凡

平凡不是“无特征”。一个有意识的普通人设计，至少能回答：

- 身体如何适应日常劳动与休息。
- 自我照料是仔细、将就、间歇还是由别人代劳。
- 面部和姿态的年龄感来自什么生活节奏。
- 在熟悉空间里怎样移动，在权威面前怎样缩放自己。
- 去掉特殊装饰后，哪一组比例、节奏和痕迹仍属于他。

若答案只能是“正常、自然、普通、耐看”，说明仍是模型默认人。不要用一个痣、一缕白发或一道伤疤替代完整判断。

## 选优顺序

1. 先看是否准确承接剧本人物和主胜负手。
2. 再看不靠服装道具是否仍可识别、可表演。
3. 再看与群像是否形成必要差异，而非为了不同而不同。
4. 再看目标媒介是否能稳定生产和运动。
5. 最后才比较局部美感与流行程度。

最漂亮、最凶、最仙或最奇特不自动胜出；最能让人物关系在身体上成立的候选胜出。
