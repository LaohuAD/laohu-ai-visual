# 复盘验收核心

## 能力定位

把真实结果和真实反馈转成下一轮可执行动作。

这个 skill 合并生成结果诊断、剪辑成片验收和发布复盘。它不只回答“哪里不好”，而是判断问题处在作品链路哪一层：剧本、视觉资产、视频提示词、生成结果、剪辑成片、封面标题、发布漏斗或课程化回流。

## 能力加厚纪律

复盘不是评价好看不好看，而是把结果变成可执行返修和可复用经验。

必须区分：

- 生成问题：角色变脸、动作乱、表情失控、风格跑偏、声音冲突、模型限制。
- 剪辑问题：主线不清、入点出点断裂、动作/视线/色调/声音接不上、字幕遮挡。
- 发布问题：曝光、点击、前 3 秒、中段、完播、互动、评论和课程化反馈。

复盘必须沿导演链路回查，不只问“哪里不好”。每次生成、剪辑或发布失败，先判断：

```text
是灵感价值不够？
是故事引擎弱？
是节奏密度不够？
是文戏表演没写透？
是武戏动作没受力？
是镜头切换没任务？
是画面美学没停点？
是资产没锁住？
是视频提示词不够可执行？
是剪辑没有节奏变化？
是标题封面没有承接反转？
```

动作或奇观镜头还要单独回查两类系统性失真。`多主体运动失真` 检查人物、坐骑、车辆、群像、投射物与摄影机的世界方向、屏幕方向、朝向、速度变化、相对顺序和出画顺序，识别无因倒退、超车、瞬移、换层和越轴。`事件传播失真` 检查爆炸、炮击、坍塌、撞击或能量攻击的命中点、传播方向、承力结构、材料失效、碎片飞散锥、二次碰撞、烟火压力、声音、摄影机响应和永久终态。先判断是上游没写清，还是模型在清楚约束下仍失控。

人物动作看似完成但像直接跳变时，单独回查 `人体姿势变换失真`：动作名称是否被真正展开，约束是否先解除，手脚支撑点是否可接触，肩胸骨盆和主要关节是否按顺序变化，重心与旋转轴是否连续，四肢是否越过道具 / 对手而不穿模，首次落地与卸力是否符合受力，结束姿势是否能接下一动作。姿势链完整但生成仍简化，才归为模型动作遵循问题。

输出返修时最多给 3 个优先动作。不要把所有问题堆给下一轮；每个优先动作都要指向明确上游层：价值脑洞、剧本、分镜、视觉资产、视频提示词、剪辑、封面标题或发布策略。

首尾帧模式必须单独诊断，不能只归类为普通图生视频或转场失败。按 `端点输入 → 不变量 / 变化量 → 中间变换链 → 摄影机路径 → 尾帧召回 → 尾帧收束` 回查：首帧漂移，先检查首帧参考和开场是否重复改变构图；人物、产品或关键道具中途变形，检查不变量是否明确、参考是否冲突；过程突然跳变，检查触发、共同桥梁和中间状态是否缺失；画面很炫但看不懂，检查运镜是否压过主变换；尾帧未落准，检查尾帧元素是否出现太晚、结尾是否缺减速和构图校正。双端锚点是输入硬目标，不把概率模型一次偏差说成绝对规则失效；至少结合原提示词、首尾图和生成结果再定因。

跨 `VID` 连续失败也要单独定因，不能只归类为人物不一致或转场不流畅。按 `连续性路由 → A 交接点 → 实际参考截取 → 世界状态 / 屏幕投影 → B 开场提示 → 模型执行` 六层回查：直接连续却没有使用尾部动态参考，先查输入策略；同场重建仍上传带强运动的尾部视频，先查参考类型；参考片段同时包含硬切前后两个机位，先查截取；A 停在未完成接触、半空未知落点或未兑现破坏，先回到分镜边界；B 复演 A，检查基础设定是否没有限定参考职责、画面内容是否从旧动作而非新动作开始；人物画面左右改变但世界位置正确，检查是否属于有意重新建立机位，不能误判为世界状态错误。

复盘时至少对照 A 最后有效机位、实际上传的参考片段、B 正式三段提示词和 B 成片首个有效画面。分别记录：人物 / 道具 / 伤势 / 破坏是否继承，场景锚点和世界位置是否正确，屏幕方向、观看侧和运动余势是否连续，B 是否出现动作重播，参考是否把上一条错误状态放大。只有这些输入与提示都清楚而模型仍漂移，才归为模型执行偏差；否则先回到对应的剧本边界、分镜、截取或视频提示词层修正。

复盘不只在 B 失败后追责，还承担 A 生成后的 `二次绑定门`。先读取上游的相邻单元交接合同，逐帧确认 A 真正完成了什么、最后有效机位停在什么人物姿势、道具位置、动作相位、空间方向和声场；再把计划中的 `A 结束状态` 改成真实状态，检查它是否仍能与 B 开始状态相等。只有 `A 结束状态 = B 开始状态`、主匹配属性可读、参考片段只有一个机位、B 第一动作确为下一相位时，才标记 `允许生成 B`。否则给出最小修复：改截取范围、退化为终帧 / 构图参考、改 B 开场，或返修 A；不能因为 A 已经花钱生成，就继续花钱放大错误。

该门适用于任何作品，不只跨 `VID` 打斗或当前案例。相邻剧本节拍、分镜、场次和上下集若在成片中发生状态冲突，也要回到同一合同定位第一个断点：是上游结果没成立、交接记录错了、下游重演 / 跳相位、参考绑定错了，还是模型在清楚约束下仍漂移。剪辑接口兑现得漂亮也不能掩盖状态错误；连续性先通过，接口才有使用价值。

成功结果也要提炼可复用规则；失败结果默认有训练价值，要保存原提示词、结果描述、原因判断、修正提示词和下次避免规则。证据不足时输出暂定诊断，不编造平台数据或不存在的素材。

归档、复盘、生成结果诊断和发布复盘必须写入文件。对话里只给复盘文件链接、关键结论摘要和下一步阶段建议。

复盘和归档文件默认在同一个当前文件上更新，不自动新建 v1/v2/v3。只有老胡明确要求新增版本或保留旧版时，才另存版本。

### 商业转化链诊断

对电商、TVC、品牌或获客作品，视听质量与转化质量必须分开评估。画面漂亮、人物一致、动作完成，不代表观众已经理解为什么要买。额外评分以下五项，不适用的非商业作品记 `N/A`：

```text
需求命中：目标人群能否在开场处境中认出自己的问题或欲望。
核心承诺：看完后能否只用一句话说出这个产品带来的主要好处。
卖点证明：每个承重卖点是否有场景、产品机制、接触 / 受力和可见 / 可听结果，而不只是口播宣称。
文案同步：钩子、卖点句和行动句是否与当时画面证据同向，是否准确可信。
品牌与行动：观众是否知道这是什么产品、属于谁、下一步应该做什么。
```

` 卖点证明 ` 为 0 分时，不先改配乐、转场、滤镜和特效。先回查编剧是否选错卖点，资产是否没有承载证据的结构与场景，视频提示词是否只拍了结果没拍产品如何产生结果。真实产品出现无证据数字、疗效、认证、绝对化词或竞品对比时，同时判定为声称越界，不因文案有冲击力而放行。

## 内置质量校准视角

以下视角只用于提高诊断质量，不改变复盘输出结构，不在正式交付里新增专家分析栏目。

| 视角 | 内部校准方式 |
|---|---|
| Robert McKee / John Truby | 如果观众“不知道在看什么”，优先检查剧本目标、阻力、代价和人物选择，而不是只修提示词词藻。 |
| Blake Snyder / Dan Harmon | 如果开头弱或中段散，检查前 3 秒类型承诺、钩子、节拍推进和最小故事循环。 |
| Akira Kurosawa / Saul Bass | 如果镜头不成立，检查视觉任务、主体运动、构图概念和剪辑停点是否清楚。 |
| Roger Deakins / Emmanuel Lubezki / Vittorio Storaro | 如果画面廉价或不统一，检查光源方向、镜头身体感、色彩层级和画质描述是否冲突。 |
| Ralph McQuarrie / Syd Mead / Doug Chiang | 如果角色、场景或道具不稳定，检查资产是否真的锁住轮廓、材质、结构、比例和世界观语法。 |
| 胡金铨 / 徐克 / 程小东 / 袁和平 | 如果仙侠动作假、飘、乱，检查身法逻辑、空间纵深、礼仪节奏、动作起止点和可见受力。 |
| Runway Academy / OpenAI 提示工程 | 如果生成偏离，检查提示词是否独立完整、具体、无场外说明、无上下文依赖、无互相矛盾指令。 |

复盘时不要把所有问题都归为“模型不行”。先判断上游是否给了模型可执行的信息；只有剧本、资产、分镜和提示词都清楚后，才把剩余问题归为模型能力限制或随机性。

如果老胡反馈“像 AI、太普通、太安全、太顺、像鸡汤、像模板、像说明文、没有文学感、没有记忆点”，默认先进入反模型众数倾向诊断。不要只看某一句是否通顺，要回查高价值位置是否直接采用了第一反应：标题、开场钩子、主物象、核心台词、评论引导、风格核心、转场机制、结尾余味句、封面帧。复盘要判断它是不是同题材可替换、关系命名不准、体裁成品性不足或留白没有可见证据。

证据不足时先停在初判，不要硬写完整复盘：

```text
缺原提示词 → 只能判断表面症状，先让老胡补原提示词或当前提示词文件。
缺生成结果 → 只能基于口述做初步诊断，不写确定结论。
缺分镜 / 剧本 → 先判断是否是上游任务不清，不直接改视频提示词。
缺发布数据 → 只做内容和制作复盘，不编造曝光、点击、完播或互动原因。
```

## 能力边界

可以产出：

- 图片 / 视频生成结果诊断。
- 多镜头剪辑可行性和成片验收。
- 发布漏斗与评论反馈复盘。
- 成功 / 半成功 / 失败判断。
- A/B/C/D 等级。
- 失败类型、原因定位和上游返修路线。
- 下一版修正提示词。
- 首尾帧模式的端点兼容性、中间变换链和尾帧落准诊断。
- 最多 3 个优先返修动作。
- 案例入库草稿和共享资产反哺建议。

不负责：

- 自动调用高成本视频生成接口。
- 自动操作剪辑软件或平台后台。
- 伪造缺失数据。
- 替代最终审美选择。

## 输入判断

先判断当前反馈类型：

```text
反馈类型：图片生成 / 视频生成 / 封面生成 / 剪辑成片 / 发布数据 / 用户主观反馈 / 成功案例 / 失败案例
所属作品：
当前阶段：
原提示词或版本位置：
模型路由：Seedance 2.0 / Seedance 2.5 / 其他 / 未明确
正式提示词字符数 / 路由上限：
结果位置或结果描述：
用户最不满意的地方：
下一步意图：
证据完整度：完整 / 部分 / 口述初判
```

缺失信息写“缺”。如果证据不足，先给“基于现有描述的初步诊断”。

### 首次观看重放

评分和归因前，先把成片当成第一次看，不要从作者意图倒推“这里本来想表达什么”。按实际播放顺序逐节拍记录：

```text
我此刻实际知道什么，而不是剧本希望我知道什么。
我暂时相信什么；这是不是作品有意建立的判断。
我正在问什么；作品是否给了继续等待的理由。
我预测下一步是什么；后续是兑现、升级还是有依据地推翻。
我的眼睛 / 耳朵第一时间落在哪里；是否被错误背景、特效或声音抢走。
我与谁情绪对齐；目标、代价、空间和身体感是否足够。
切镜后我是否知道人物、道具、方向和事件仍处于什么状态。
```

定位 `第一个断点`，而不是先列所有缺点。断点优先分为：预测断裂、注意力误导、情绪对齐丢失、信息过早 / 过晚、事件边界模糊、动作或连续性断裂。后面的困惑可能只是第一个断点的连锁后果；返修应先回到最早失效的剧本节拍、资产证据、分镜选择、提示词编译或模型执行层。

如果作者看得懂、陌生观众看不懂，不能用“剧情里已经写了”判成功；如果陌生观众产生了不同但有证据支持、且更有吸引力的理解，先判断它是可保留的新价值还是破坏核心事实的误读。

视频结果先按四核诊断，不先用“模型不行”概括：

```text
主注意力目标：观众是否明确知道这一刻该看脸、手、道具、接触点、环境变化还是画外声音引起的反应；焦点、运动、光色和声音是否共同指向它。
动作与表演：主体是否从起始状态经过触发、路径、接触 / 受力、可见结果和反应到达结束状态；情绪是否由表情、呼吸、肢体、距离和声音证明。
效果系统：摄影机物理路径是否正确，焦点、环境、光色、速度、声音和转场是否有来源、变化过程与屏幕 / 声音结果。
节奏与时长：主体是否来得及被识别，动作是否完成，情绪是否建立，效果是否展开，切镜和停点是否有余量。
```

图片资产与使用了图片参考的视频还要单独评三项；纯文本生成且没有稳定资产职责时可记 `N/A`。

`资产审美适配` 判断设计是否兑现作品类型、受众、资产职责和作品承诺。0 分：类型错位，直接使用默认模板，主要靠滤镜、粒子、黑金、粉色圆角或其他俗套冒充设计；1 分：方向基本成立，但受众、设计语法或第一眼欲望不够准确；2 分：选角 / 造型、轮廓比例、CMF、空间语法和情绪承诺同向，观众一眼相信它属于这类作品。此项为 0 时先回 `laohu_visual_assets` 重做美术定位，不先修视频运镜或特效。

`资产视觉记忆 / 传播潜力` 判断关键资产是否拥有可被观众复述、截图辨认或用于封面传播的识别关系。0 分：同题材任意资产都可替换，只有通用漂亮；1 分：已有识别细节，但远看轮廓、近看细节或作品归属仍弱；2 分：至少有一个服务功能与世界观的轮廓、比例、材质、配色、造型或空间记忆点，并能在主视觉和后续视频中被继承。记忆点不等于堆奇观或故意怪异。

`资产制作可用性` 判断美术设计能否被稳定生产。0 分：单张形象图漂亮但换角度崩坏，结构 / 比例 / 材质矛盾；道具只用平均四宫格，缺少下游会拍到的材质、Logo、文字、纹样、接缝和功能细节；场景只有几张相似广角，没有鸟瞰总平面与固定构件细节；或底部局部出现了上方总览从未定位的 Logo、文字、配饰、接口和固定构件。1 分：主要身份和结构可用，但局部角度、细节来源、操作关系、空间总平面或世界统一性不稳，部分细节只能猜测来源。2 分：形象资产证明吸引力；道具设计板以主结构 / 辅助视图和细节带证明同一物件，场景设计板以四机位、鸟瞰和固定构件细节带证明同一空间；每个局部都能回指上方唯一来源视图、位置、朝向和数量，上方承重识别点也有对应放大证据，动作、接触、材质和下游调用边界清楚。

`主注意力目标` 0 分：脸、背景奇观、道具、运镜和声音同时争抢，观众不知道看哪里；1 分：主体大致明确，但焦点、构图或声音偶尔把注意力拉走；2 分：每镜一个主目标，景别、焦点、运动、光色、导引线和声音共同指向它，迁移触发清楚。

`镜头构思强度` 用来区分“镜头骨架普通”和“提示词执行不够精细”。0 分：只有概括剧情、普通站姿或常见正面中景，冲击力主要靠服装、滤镜、雨雾、颗粒和电影感词支撑；1 分：事件瞬间或机位已有方向，但动作几何、画内证据、主情绪可读性或生成可行性仍有明显缺口；2 分：剧情任务、决定性瞬间、人物 / 道具调度、摄影机观看位置、画内证据和光影落点形成同一画面因果，去掉颜色与材质仍能从黑白剪影读出镜头力量。若此项为 0，优先退回分镜构思，不先修提示词措辞。

`观众代入强度` 与主情绪可读性分开评分。0 分：观众能看见人物在害怕、悲伤或快乐，却不知道人物为什么在乎，也没有共享信息、空间压力、身体感受、时间过程或选择后果，只在外部观察表演；1 分：目标风险和部分感官 / 信息关系成立，但观众进入角色的过程断裂或过快；2 分：段落从目标与代价出发，通过本段承重的信息、空间、身体、时间和选择路径让观众与人物共同经历，并在需要时拉开留下余波。不要求六项齐全，也不要求全程 POV、特写或手持。

`情绪入场` 先按文戏 / 武戏分流再评分。0 分：开场只有背景说明、漂亮摆拍、普通走位或无差别动作，观众迟迟不知道人物在关系中想得到什么，或危险与力量从哪里逼来；1 分：主情绪和处境可以识别，但第一有效节拍出现偏晚，前段存在无职责铺垫；2 分：文戏第一有效节拍即建立关系目的与阻力，或武戏第一有效节拍即建立危险方向、力量差与人物选择，后续镜头沿同一体验持续加压。这里的“快”不等于统一快剪，长镜头只要从开场就在增加关系或力量压力同样得满分。

`动作与表演` 0 分：承担本镜任务的动作跳变，情绪只有标签；1 分：动作基本完成，但关键触发、路径、受力、反应或情绪证据不足；2 分：与本镜任务有关的动作因果和表演证据清楚。简单抬眼、静止等待和单一手势不因缺少完整受力链扣分。

`演员临场感` 只对叙事性人物图片、首帧、封面或人物镜头评分；中性人物资产、定装展示和纯时尚摆姿任务记 `N/A`。0 分：人物只有气质词、持械动作或摄影姿势，像在配合摄影师摆拍；1 分：主情绪和事件大致存在，但事件压力、生理反应、行为选择、对手 / 环境反馈或景别可读性缺一处关键证据；2 分：观众能看见具体压力如何进入、人物身体如何响应、人物选择如何暴露态度，以及对手或环境如何为此作证。静止可以得满分，但必须是面对压力后的主动不动。

`效果系统` 0 分：只出现推镜、爆炸、冷色调、慢动作等名词，屏幕变化混乱；1 分：部分效果成立，但摄影机路径、焦点、环境、光色、速度或声音有一层失控；2 分：观看意图、摄影机物理路径、屏幕变化、情绪倾向和停点一致，各效果都有来源与结果。

`节奏与时长` 0 分：动作或情绪没建立就切走，或长时间没有变化；1 分：主体和动作可读，但效果、情绪或停点偏赶 / 偏拖；2 分：时长覆盖主体识别、动作完成、情绪建立、效果展开和停点 / 切换余量，快慢反差服务观看。

`音乐-画面融合` 只在成片存在音乐时评分；没有音乐记 `N/A`。0 分：只有个别动作偶然撞上鼓点，主要镜头、转场和图形变化与音乐段落各自运行，或所有镜头机械每拍一切；1 分：主要重拍和部分转场同步，但中段视觉短语缺少音乐驱动、拍前蓄势或拍后余波；2 分：音乐段落与宏观视觉阶段对应，每个主要视觉短语至少有一个决定性完成态与强拍、乐句边界、长音或休止建立关系，弱拍承载连续小运动，留白与故意切分有明确作用并能重新合拍。复盘时记录真实声音瞬态与视觉完成帧的偏差，不能只看提示词意图判满分。

`情绪目标混乱` 要与注意力和任务分开诊断。注意力集中、任务完成，情绪仍然可能杂乱：镜头只拍一个人、只完成拔刀，但雨雾、暖光、表演、音乐和运镜可能分别传达孤独、希望、危险、浪漫和展示感。0 分：观众说不出唯一主感受；1 分：镜头主情绪大致存在，但部分证据冲突；2 分：一个情绪节拍一个主情绪，所有主要证据同向，辅助余味退后；转折镜头有起点、触发、变化和终点。复盘时先分别问“看哪里、完成什么、感到什么”，不要只修构图或删动作。

`壁纸帧 / 审美停点` 只对承担人物第一眼、情绪峰值、段落记忆、封面候选或传播视觉职责的镜头评分；功能镜头、动作连接和证据插入镜头记 `N/A`。0 分：应该形成记忆点却没有清楚主情绪和视觉落点；1 分：情绪方向成立，但停点不稳或承重关系不够清楚；2 分：暂停后仍能准确传达本镜主情绪，所需的主体、姿态、构图、光色或材质中至少一种关系有记忆性。前中后景、留白、色卡和复杂光影都不是满分必需项。

动作场面的审美停点还要检查是否使用 `承重英雄帧 + 连续连接帧`。每个动作组有一至两个由蓄势、接触或结果自然形成的英雄帧即可；连接帧允许遮挡、甩镜、失衡、局部出画和方向性模糊。若人物为了截图每招停稳、回正、摆 Pose，`动作速度与能力` 和 `壁纸帧 / 审美停点` 都不能得满分。

`节奏密度` 用来判断内容是否持续给观众新的观看理由。0 分：只有开头和结尾，中段空转，镜头切换没有任务；1 分：有推进但信息点、冲突点或情绪点间隔不稳；2 分：15 秒、30 秒、60 秒或 1-3 分钟体量都有匹配的信息推进、冲突推进、情绪推进或动作爆点。复盘时如果老胡说“拖、散、看不下去”，不要只改运镜，要回查节奏网格。

`文戏表演` 只对文戏与关系反应镜头评分。0 分：台词像主题总结，表演只有抽象情绪词，人物不知道这一刻想从对方那里得到什么；1 分：人物目的和台词大致成立，但潜台词、触发、停顿、距离或反应证据不足；2 分：人物目的可执行，观众能从被选中的台词、潜台词、表情、停顿、距离或反应中准确读出关系变化，不要求所有通道同时出现。

`表演控制` 只对存在复杂情绪转折、长镜头、多人对手戏或明确反应时序的镜头评分，普通功能台词记 `N/A`。0 分：第一帧就同时端出愤怒、悲伤、眼泪和崩溃，或触发前提前完成反应，台词结束后瞬间复位；1 分：起点、触发和终点大致可读，但保护策略、强度过程、禁止提前反应、跨通道时序或静止余波缺一项承重控制；2 分：表演从人物目的和保护策略出发，被具体台词 / 重词 / 动作 / 声音 / 视线 / 信息触发，脸、目光、呼吸、声音、身体或距离按需要异步经历出现、增强、峰值和减弱，未承重通道没有抢先泄露后续情绪，禁止反应没有提前，结尾状态能被下一节拍继承。

复盘复杂表演时，内部必须反查八维：`时间段、人物目的、情绪变化与保护策略、精确触发、面部动作与可选 AU、目光身体与关系距离、声音呼吸与停顿、结束状态与静止反应`。这不是按八个标题或 AU 数量评分，而是检查每个会影响结果的维度是否已有可见 / 可听证据、是否在正确时刻变化、是否被下一节拍继承。某维不适用或本节拍不变化可省略；若承重维度在内部设计中缺失，不能因正式提示词短而判为合理压缩。

若提示词使用 FACS / AU，复盘只检查它是否辅助自然语言动作，不按编码数量评分。只写 AU 串、把 AU 当情绪公式、混用 FACS A-E 与工具 0-5、在多人远景或遮挡画面强行精细控制，都判为提示词设计问题；自然语言已经清楚而模型仍未执行，才记录为模型遵循偏差。

`武戏受力` 只对武戏、碰撞和复杂动作镜头评分。0 分：只有炫酷词，关键动作飘、乱或因果不清；1 分：动作路径可读，但本镜承重的起势、发力、受力、反应或爆点仍有缺口；2 分：观众能看清力量从哪里来、经过什么路径、造成什么结果。不是每个动作都必须同时展示起势、发力、受力、反应、爆点和停帧。

`时间动力与速度曲线` 在速度、停顿、反应窗口、快切、慢动作、转场运动、动态图形或声画节奏承重时评分；普通静态展示记 `N/A`。0 分：只感到全程同速或随机忽快忽慢，人物、摄影机、切镜、VFX 和声音互相争抢，关键动作与信息不可读；1 分：已有局部快慢对比或完成点，但主速度承载者、参照物、加减速、相位、停点或跨镜连续性有缺口；2 分：动作速度、摄影机速度、切镜速度、信息速度和声音速度主次明确，蓄势、启动、加速、峰值、接触、余波与停点按任务成立，快段仍看清方向与结果，慢段仍推进等待或情绪，跨镜保持方向、速度级别和相位。评分不按切镜数量、BPM、慢动作时长或速度形容词多少。

`动作速度与能力` 只对武戏、追逐、机甲、枪战、超能力和大型破坏评分。0 分：只写高速、瞬移、激烈或巨大，人物仍按普通速度排招，或位移像跳帧；1 分：已有部分位移、环境或摄影机速度证据，但预载、瞬时释放、落点、接触结果、余势或角色等级差仍不完整；2 分：爆发动作链形成 `预载 / 蓄力 → 瞬时释放 → 高速位移或力量传播 → 极短接触 → 明确结果 → 余势继续`，并通过位移、发力、环境、摄影 / 声音中的必要证据让观众身体上感到速度；高手的预动作更小、路径更短、结果更大、控制更精确。

`接触与力量可读性` 只对武戏、碰撞和强交互评分。0 分：多把武器聚成一团，没有清楚支撑、合力方向、位移、胜负或情绪结果；1 分：主要接触可辨，但力量关系、脱离或结果仍含糊；2 分：威胁可以并发，串行接触的双方、角度、脱离与结果清楚；一对多接触则明确攻击来源、不同接触位置、主角支撑、合力方向、位移 / 形变以及主角震开、被压退或改角脱困的唯一结果。不能因武器数量机械扣分。

`景别证据与切换` 评分所有多镜头叙事。0 分：景别不匹配证据尺寸，或同一主体在相近轴线、构图和动作相位下只做微小景别变化，形成误切 / 跳切；1 分：单镜信息大致可读，但切换没有明显新增证据，或近景后没有重建空间结果；2 分：远景 / 全景、全景 / 中远景、中景 / 中近景、近景 / 特写分别承担空间几何、完整动作、关系重心、接触 / 表情等适合自身容量的证据；切换通过跨景别、约 30 度机位变化、动作相位、构图或信息目标中的至少一项形成有意义差异，并继承方向和状态。跨一级景别与 30 度只作经验，不机械评分。

`镜头策略与动作覆盖` 评分多镜头视频。0 分：镜头数量来自固定模板，长镜头内部空洞，或快速切镜只是重复同一动作、重置姿势和制造混乱，没有把目标情绪传给观众；1 分：大体选择了连续跟拍、高强度多切或混合结构，但部分切换没有新增观看证据，动作相位或状态继承不清；2 分：镜头策略与主情绪一致，少量镜头能持续展示完整身法与空间控制，或多个短镜头能连续覆盖同一动作的来路、接触、脚步、受力、反应和结果。评分不按镜头多少扣分，15 秒约 10 镜与少量长镜头都按实际激烈程度、动作可读性、连续性和可用素材判断。

`屏幕可观察性` 评分正式模型正文。0 分：主要依赖小说因果、角色内心、导演评价或设备运动，模型必须猜最后画面；1 分：主体动作可见，但部分力量原因、镜头结果或画外信息仍未转译；2 分：每个实义句都能在成片中找到可见、可听或可直接感知的对应证据，内部因果已编译为动作、受力、位移、材质、焦点、透视和声音变化。重点排查 `她判断 / 她确认 / 借力 / 失去支撑 / 夺回主动 / 传达镇定` 等解释句，以及 `机身、摄影设备、轨道到达某点` 等幕后设备叙事；画外事件必须有声音、光影、反射、飞入物或画内反应作为入口。

`镜头预示性承接` 用来判断切换是否在观众脑中自然连续。0 分：遮挡或换景后新敌人、新武器和新方向凭空出现；1 分：姿势和方向继承，但下一威胁没有提前线索，切换仍像换任务；2 分：上一镜尾部完成结果的同时，以刀尖、影子、视线、声音或运动物提前引入下一威胁和摄影机方向，下一镜从同一线索的下一相位开始。静态独立镜头或明确断裂性硬切可记 `N/A`。

`多主体运动连续性` 只在两个以上因果参与者同时运动、分离、追逐、承重或碰撞时评分。0 分：出现无因倒退、超车、瞬移、换层、出画颠倒或摄影机越轴；1 分：各自路径大致成立，但共同惯性、相对顺序、速度变化原因或摄影机关系不稳；2 分：世界 / 屏幕方向、朝向、速度、外力、相对顺序、终点和出画顺序连续可信。单主体静态镜头记 `N/A`。

`人体姿势变换连续性` 只对骑乘上下、跳跃落地、翻滚摔倒、复杂武打、舞蹈或身体与道具强交互评分。0 分：动作名直接跳到结果，肢体穿模或姿势突然替换；1 分：主要轮廓可读，但支撑转换、关节链、重心 / 旋转轴、四肢净空或落地卸力缺关键相位；2 分：关键姿势相位形成连续不同轮廓，身体几何、受力与下一动作入口可信。简单抬手、走路和静态表演记 `N/A`。

`事件传播连续性` 只在爆炸、坍塌、炮击、撞击或大型能量破坏时评分。0 分：只有爆炸 / 飞溅 / 倒塌结果，材料和方向随机；1 分：命中与主要破坏成立，但材料失效、碎片落点、二次碰撞、烟火压力、声音或永久终态有明显断点；2 分：力量从来源到命中、结构、材料、碎片、声场、摄影机和残局形成可追踪传播。无复杂破坏镜头记 `N/A`。

`构图逻辑` 用来判断画面骨架是否把注意力和主情绪组织清楚。0 分：主体位置与画面关系随机，观众不知道看哪里或关键动作被遮挡；1 分：视觉落点大致成立，但稳定性、关系距离、运动方向或画幅适配仍有干扰；2 分：所选择的中心、偏置、对称、不对称、引导、框景、留白、拥挤、平面化或失衡结构准确服务本镜目的。三分法、黄金分割、引导线和留白只是候选，故意压迫、失衡、满构图或事实特写也可以得满分。

构图复盘要区分 `受控不工整` 与生成错误。人物贴边、头顶空间偏多、低地平线、窗框裁切、半完成动作和局部遮挡，如果有可信机位、明确关系压力并保住决定性证据，可以得满分；随机裁头、眼神被挡、产品结构缺失、动作接触不可读或画幅适配失败仍然是错误。不能因为画面不符合标准平衡就自动判差，也不能用“实验感”替模型事故开脱。

`视线流量` 判断观众的眼睛是否被有意接送。0 分：入口、决定性信息和出口互相冲突，视线在无关高亮、装饰或背景间乱跳；1 分：第一落点明确，但中间引导、余韵或下一镜交接偏弱；2 分：视线从明确入口进入，经眼神、动作、线条、明暗、遮挡、焦点或声音到达决定性信息，再由边缘、空位、反射、失焦区或动作趋势自然交给下一镜。单一事实特写可以很短，不因没有复杂路线扣分。

`摄影机位置动机` 判断镜头是否像真实空间中有人在正确位置观看。0 分：鱼眼、俯拍、隔窗、镜面、贴地或异常角度没有空间依据，只为炫技；1 分：位置物理上可行，但与信息关系和主情绪联系较弱；2 分：机位既能在场景中成立，又准确决定观众与人物的距离、信息权限和关系压力。纯动画 / 超现实作品也要有世界内部的观看逻辑。

`信息主次与选择性不完整` 判断画面是否知道什么该清楚、什么该退让。0 分：人物、道具、背景、特效和细节同等抢眼，或每帧都被做成完整海报；1 分：主线索可读，但辅助线索与背景仍过满；2 分：每镜一个主故事线索、按需一个辅助线索，其余内容可以普通、暗、软、遮挡、失焦或留空，决定性镜头与连接镜头拥有不同视觉预算。资产设计板因结构校准职责不按此项要求故意遮挡。

`特殊光学 / 光线动机` 判断鱼眼、镜面、反射、百叶影、水波光、车灯扫动、异常曝光等手段是否改变叙事。0 分：效果只作装饰或抢走主体；1 分：气氛成立但与信息、关系或身体感联系不够；2 分：特殊手段有明确物理来源，并改变危险、距离、认知、力量或情绪压力。没有特殊效果的普通镜头可记 `N/A`，不因克制扣分。

`成像基底与不完美一致性` 判断作品是否只有一个清楚的主介质，以及不完美是否有来源。0 分：35mm、VHS、监控、柔焦和现代数字锐度无因混用，或把生成事故当风格；1 分：主基底成立，但局部颗粒、色散、噪声、拖影或清晰度漂移；2 分：主成像基底稳定，阶段切换有剧情 / 设备动机，每段主要不完美来源单一且服务画面。中性资产设计板以结构校准为准。

`镜头顺序不可交换性` 只评多镜头叙事。0 分：任意调换镜头仍不改变信息、等待、情绪或人物状态，只是一组漂亮截图；1 分：部分镜头有推进，仍有重复展示；2 分：每次切换都增加证据、改变关系、兑现动作结果、建立等待或承接余波，顺序被打乱会明确破坏观看逻辑。独立单镜头记 `N/A`。

`情绪重心` 用来判断图片是否只有视觉焦点，没有情绪主心骨。0 分：视觉焦点清楚，但直视、拔刀、雨雾、暖光、日出、浪漫或时尚展示等信号各说各话，观众不知道该感到什么；1 分：有主情绪词，但人物处境、态度或部分视觉证据仍互相冲突；2 分：主情绪命题清楚写出主体面对什么、如何回应，观众第一情绪唯一，眼神、姿态、动作、景别、光影、色彩和环境都指向它，辅助余味只在第二眼出现。复盘时如果老胡说“什么都想传达但没有重心”，先区分视觉焦点和情绪重心，不要只通过放大人物或提高对比度修构图。

`透视与视觉重心` 只在空间尺度、纵深、运动路径或环境压力承重时评分。0 分：透视关系妨碍主体识别或动作理解；1 分：空间方向大致成立，但灭点、尺度或运动关系不稳；2 分：线性透视、空气透视、平面化、压缩空间或有意畸变中的任一种都准确服务镜头目的。近实远虚、近暖远冷和明确灭点是候选，不是统一满分标准。

`光影体系` 判断光是否完成本镜职责，而不是是否层数够多。0 分：光源无因、方向跳变，或关键情绪与动作证据被照坏；1 分：光线基线成立，但主体塑形、证据可读性或连续性有偏差；2 分：单一自然光、平光、剪影、硬光、近无辅光或多层布光中的任一种都能准确服务主情绪、主体识别和连续性。只有问题确实来自光线时，才回查时段、来源、方向、软硬、暗部和材质反应。

`色彩体系` 判断颜色是否服从主情绪、身份与连续性。0 分：颜色无目的争抢注意力或跨镜漂移；1 分：方向大致成立，但关键对象、明度、饱和度或连续性有干扰；2 分：单色、黑白、综合色、低饱和或有意高饱和冲突中的任一种都层级清楚，并准确加强本镜目的。主辅点缀色、低饱和和不超过两种主色都不是固定满分答案。

`影调透视与色彩透视` 判断明暗、冷暖、饱和度和动态范围是否把主体与空间关系组织清楚。0 分：这些关系无意混杂，主情绪或主体被吞掉；1 分：总体方向成立但局部层级不稳；2 分：高调、低调、硬调、软调、近暖远冷、近冷远暖、纯黑剪影或整体平光中的选择有明确作用。暗部可以无细节，画面也可以有意灰、褪色或油润，只要这是目标而不是失控。

`景深与空间层次` 判断焦点和空间信息是否与观看任务匹配。0 分：关键主体失焦、空间因果不明或随机漂焦；1 分：焦点大致正确，但虚实、遮挡或空间可读性仍不稳；2 分：浅景深、深景深、全平面清晰、无前景或完整前中后景中的任一种都让观众准确读到所需信息。只有纵深承担任务时才要求空间层次，不以三层齐全作为满分条件。

`画质与材质质感` 按交付用途和主注意力评分。0 分：需要看清的脸、证据、产品或接触点崩坏，或介质效果变成生成事故；1 分：关键内容可读，但锐度、纹理、模糊或颗粒仍影响目的；2 分：需要看清的细节准确可读，需要模糊、粗粝、低清、DV 噪点、梦境失焦或运动拖影的部分也符合意图。不要求每镜都洁净锐利、微细节丰富或可放大做壁纸。

`氛围环境元素` 只在天气、空气、微粒、光学点缀或背景运动承担主情绪和空间真实感时评分；干净静止环境可记 `N/A` 或得满分。0 分：元素无来源、遮挡主体或把情绪带偏；1 分：来源大致成立但方向、密度或节奏不稳；2 分：被选中的环境元素有真实来源，并准确加强主情绪，不以元素数量判断质量。

`镜头运动职责` 用来判断运动是否服务主情绪和观看任务。0 分：运动没有目的，关键表情、动作因果或证据被漂移与模糊破坏。1 分：运动方向成立，但速度、稳定度、焦点或停留时间与内容不匹配。2 分：稳定、持续运动、失衡或模糊都是有意选择；需要读表情、证据或剪辑接口时给足可读停留，纯运动冲击则保留连续性。复盘先判断问题是意图错误还是生成失控，不以“每帧可截图”作为所有镜头的统一标准。

声音适配不能只判断有没有配乐、同期声是否抢戏，还要判断人物声线一致性。凡是跨镜头说话、喊叫、VO 回响或画外音出现的人物，都要检查他是否继承了资产表 / 基础设定里的基础声线；病弱、哭腔、压低声音、隔门闷声、电话失真、VO 回响等只能作为当前镜头声音状态变化，不能让同一人物换成另一种音色。

诊断顺序：

```text
灵感价值和传播入口是否清楚
→ 故事引擎是否清楚
→ 节奏密度是否匹配体量
→ 文戏 / 武戏主任务是否写透
→ 镜头切换是否有任务
→ 剧本任务是否清楚
→ 资产设计是否抬高而不是压低视频审美上限
→ 资产一致性是否足够
→ 分镜机位和运动是否可执行
→ 正式提示词是否独立完整且没有场外说明
→ 生成结果是否偏离提示词
→ 偏离是否属于模型限制、随机性或素材不足
```

常见失败路由：

| 问题 | 回到 |
|---|---|
| 剧情目标、人物动机、开头钩子不清 | `laohu_script_writer` |
| 结构稳定但资产普通、丑、没有购买 / 观看欲望或不属于题材 | `laohu_visual_assets`，先重做类型、受众、审美命题、设计语法与记忆点，不先修视频运镜 |
| 角色、场景、道具、风格、封面或图片参考不稳 | `laohu_visual_assets` |
| 基础设定、氛围画质、表情、分镜内容或完整视频提示词问题 | `laohu_video_prompt` |
| 单段生成结果需要修正 | `laohu_generation_review` |

## 剪辑验收

当已有多个视频、图片、音频、字幕或成片版本时，先判断能不能剪成作品：

```text
开头钩子：
信息递进：
情绪递进：
结尾记忆点：
观众看完要知道什么：
```

逐镜头检查：

```text
计划接口：提示词阶段原定的入点 / 内部节点 / 出点与匹配属性。
实际可用入点：真实时间码、稳定状态、可接收属性、前置干净把手。
实际可用内部节点：真实时间码、节点类型、可读帧范围、两侧状态。
实际可用出点：真实时间码、交出属性、尾部干净把手。
不建议裁切区间：未完成动作 / 台词 / 情绪 / 声音 / 变形或构图漂移的真实时间码。
可匹配素材标签：动作方向 / 屏幕位置 / 观众视点 / 视线 / 形状 / 构图 / 景别 / 角度 / 明暗 / 色彩 / 遮挡 / 声音 / 台词 / 语义。
计划与实际偏差：成功 / 部分成功 / 失败；失败发生在提示词设计、模型执行还是素材本身不适合。
相邻单元合同：A 已完成结果、A 真实结束状态、B 计划开始状态、必须不变、允许变化、主 / 辅匹配属性、B 第一项新动作 / 声音。
状态等式：`A 真实结束状态 = B 计划开始状态` 是否成立；B 是否从下一相位开始而非重演。
二次绑定结论：允许生成 B / 改截取 / 改用终帧或构图参考 / 修改 B 开场 / 返修 A。
动作连续：
视线连续：
角色外观：
光影色调：
声音：是否继承人物基础声线；当前镜头声音状态是否服务剧情；是否出现跨镜头换音色、声音抢戏或声音与空间不匹配。
字幕：
转场是否必要：
```

验收时逐帧或按最小可用时间精度查看实际成片，不能沿用提示词里的计划位置虚构时间码。一个可用接口必须同时满足：交接属性清楚、附近没有身份 / 道具 / 空间错误、切点前后留有选择余量、裁掉前后内容后剩余段落仍成立。只有单帧碰巧相似但前后漂移、动作未完成或声音被截断，不能判为可用接口。

对 J-cut / L-cut 不只看有没有声音跨画面，还要看声音是否有明确声源、是否在正确声场中进入 / 延续、是否提前泄露不该知道的信息、是否抢走关键表演。对抠像、撕纸、绿幕、屏幕替换和手势蒙版，检查轮廓是否干净、遮挡是否完整、运动是否可跟踪、替换平面是否稳定；这些条件不成立时标记为后期高成本，不把它算成可直接使用。

STOP/CHECKPOINT：

```text

生成诊断完成 → 证据足够时直接选择最多 3 个高收益动作并写下一版修正提示词；不为普通创意返修等待确认。
剪辑验收完成 → 按作品目标直接给出保留 / 删除 / 返修优先级；真实删除源素材或发布前再由老胡验收。
发布复盘完成 → 可复用经验直接反哺共享资产、封面、标题或课程化规则，并记录改动。
```

## 封面验收

封面按传播画面单独验收，不能只沿用普通图片的“好看、清晰、人物一致”。先以实际发布尺寸观看，再回到大图检查文字和参考继承：

```text
一秒识别：第一次看到时，能否立刻认出主体、主标题和唯一观看承诺。
缩略图可读：缩到原图 10%-15% 后，主轮廓、标题字形和情绪关系是否仍成立。
第一视觉落点：眼睛实际先落在标题、预定主符号或二者共同关系上，还是被背景、装饰、人物服装或次级文字抢走。
文字准确：所有中文双引号锁定文字是否逐字一致，标点、大小写、顺序、断行和字形是否完整。
标题引流：人物视线、表情、姿势、手势、道具、环境线条、明暗和色彩是否把注意力送向标题，而不是各自争抢。
画面承诺：封面制造的问题、欲望、冲突或结果是否能在正片中兑现，避免只赢点击却伤害观看信任。
比例自适应：同一条提示词在 `3:4 / 4:3 / 16:9` 中是否保持身份、标题原文、主层级和主关系，同时允许人物侧别、标题方位、断行和留白自动变化。
坐标僵化：是否因固定左上 / 右上、百分比坐标或绝对范围，导致某一画幅拥挤、遮脸、失衡或标题溢出。
参考职责：主体参考是否只锁主体，构图参考是否只提供图文关系，风格参考是否只提供综合色与材质；是否错误继承了参考图的背景、服装、版式、第三方文字或品牌。
原创与品牌：是否保持老胡品牌锚点、正确调用 `【Logo参考@老胡Logo】`，同时没有近似复刻第三方版式、片名系统或商业识别。
```

问题按首个断点回流：标题本身不成立或承诺与正片不一致，回 `laohu_script_writer`；人物、产品、场景或 Logo 参考不干净，回 `laohu_visual_assets`；主符号、视觉流量、图文关系、文字层级或比例适配失败，回 `laohu_cover_design`。如果提示词、资产和职责都清楚而模型仍持续错字或排版失控，才启用无字底图加后期排版的失败备用路线。

## 发布复盘

发布后按漏斗定位：

| 卡点 | 典型信号 | 优先回流 |
|---|---|---|
| 曝光低 | 平台给量少、初始互动弱 | 选题、发布时间、账号定位 |
| 点击低 | 有曝光但播放少 | 封面、标题、第一眼钩子 |
| 前 3 秒流失 | 快速划走 | 开头画面、第一句、冲突呈现 |
| 中段流失 | 平均观看低、看不懂 | 剧本结构、分镜节奏、信息密度 |
| 完播低 | 后半段掉完 | 悬念递进、结尾反转、镜头删减 |
| 互动低 | 看完但不评论点赞 | 情绪峰值、观点表达、评论引导 |
| 制作吐槽集中 | 画面、声音、字幕、变脸被反复提 | 对应回到资产、提示词或剪辑 |

短视频流量表达复盘：

```text
表达是否太顺：观点是否只是正确、平稳、无反差。
表达是否太安全：是否没有任何可评论、可争论、可转述的偏离点。
表达是否太理性：是否只在证明逻辑正确，缺少感性反应、关系感和让观众卷入的情绪入口。
是否只突出优点：人物、品牌、产品或观点是否只被赞美，缺少可被接受的缺点、边界和共同敌人。
是否被选择性忽视：表达是否太熟悉、太平滑、太像正确套话，缺少能打断惯性注意的轻微跑调点。
风格是否被讨好磨平：是否想让所有人都喜欢，导致立场、语气、角色缺点和视觉记忆点都不锋利。
是否直接采用第一反应：标题、钩子、金句、主物象、风格核心、结尾余味句是否没有经过 3-5 个方向候选竞争。
是否同题材可替换：这句话、这个标题、这个风格句或这个视觉概念是否能换到任何同类作品里仍然成立。
是否关系命名过泛：是否只写遗憾、释怀、温柔、治愈、破碎、成长、热血、英姿飒爽，没有说清具体关系压力或人物处境。
是否留白空心：是否只写神秘、余味、含蓄、意境，而没有动作、物象、空间块面、遮蔽比例、声音停顿或尾帧停点托住。
喜剧是否缺席：是否能加入狠词怂态度、言不由衷、经典借用、自嘲或错位表达。
浅深比例是否失衡：是否全是浅内容抓眼球，缺少能留下铁粉的深内容；或全是深内容，缺少轻快入口。
争议是否服务主题：争议必须让观点更鲜明，不能只是制造噪声。
是否疑似卖惨：困难是否只在索取同情，缺少和解、励志、行动或成长出口。
故事杠杆是否缺失：是否没有大脑墙、痛点杠杆、金句钉、共鸣网或利他金，导致内容正确但无法穿透、记住、扩散或转化。
痛点是否太弱：是否没有唤起真实损失、风险、错失、不甘或难受，导致观众只是在旁观而不是参与。
金句是否像个体宣言：广告语、口播金句或品牌表达是否只是正确话，缺少明确立场、反常识角度和替某类人发声的力量。
```

如果曝光和互动都弱，但选题本身不差，优先回到 `laohu_script_writer` 检查表达方式，而不是只改封面标题。

## 自检

- 是否先判断反馈类型，而不是直接改词。
- 是否保留或引用原提示词、素材或发布数据。
- 是否没有虚构缺失证据。
- 是否明确生成、剪辑、发布分别哪里出问题。
- 如果验收封面，是否先按实际发布尺寸做一秒识别与 10%-15% 缩略图检查；是否核对实际第一落点、双引号文字、标题引流、内容承诺和 `3:4 / 4:3 / 16:9` 自适应，而不是只评价大图好不好看。
- 封面是否因固定坐标在某一画幅失衡；参考图是否越权锁死背景、服装、版式或第三方识别；问题是否正确路由到 `laohu_script_writer`、`laohu_visual_assets` 或 `laohu_cover_design`。
- 是否先排查剧本、资产、分镜和提示词，再判断是否是模型限制。
- 是否只统计单个正式 `text` 代码块，并按 Seedance 2.0 `≤4000`、Seedance 2.5 `≤5000`、模型未明确或跨版本共用 `≤4000` 验收；超限时是否先回到提示词层压缩或拆分，而不是把不可提交归因于模型生成失败。
- 图片或视频用了资产时，是否分别检查 `资产审美适配、资产视觉记忆 / 传播潜力、资产制作可用性`；是否避免因多视图稳定就忽略设计普通，也避免因单张形象图漂亮就忽略换角度崩坏。道具是否有主结构 / 辅助视图与底部细节带，场景是否有左上四机位、右上鸟瞰和底部固定构件细节带；所有局部是否能回指同一结构与材质账本。
- 是否检查总览与局部的父子证据链：底部每项 Logo、文字、纹样、配饰、孔位、接口或固定构件，是否已经在上方完整视图中明确载体、宏观位置、朝向和数量；局部是否只提高观察精度；能否完成 `局部向上找唯一来源 + 总览识别点向下找放大证据`。
- 使用故事板作为视频输入时，是否遵守“一条提示词、一张图片、内部多分镜”；镜头01到镜头N是否都在同一张故事板表格图中，视频提示词是否只引用整张板一次；是否误把每格拆成独立故事板资产；正式提示词是否仍完整描述格间动作、运镜、物理、声音和切镜，最终成片是否避免显示故事板表格、格线、编号和说明文字。
- 如果结果看起来不想看、不想买、不像该题材或各资产不像同一世界，是否先回到 `laohu_visual_assets` 重做类型、受众、审美命题、设计语法和记忆点，而不是用运镜、VFX、滤镜或更复杂提示词补救。
- 如果流量低，是否检查表达反差、喜剧手法、争议钩子和浅深内容比例。
- 如果内容正确但传播弱，是否检查大脑墙、痛点杠杆、金句钉、共鸣网和利他金是否缺失。
- 如果转化弱，是否检查痛点是否真实、具体、可感知，并且是否给出行动出口。
- 如果金句弱，是否检查它是否像个体宣言，是否只是复述安全共识。
- 如果表达像 AI 默认答案、鸡汤、模板或说明文，是否检查高价值位置有没有直接采用第一反应；是否做过候选竞争、平均值淘汰、同题材可替换性、关系准确性、体裁成品性和留白检验。
- 如果表达像正确废话，是否检查它是否太理性、太赞美、太突出优点，缺少感性入口、可接受缺点和共同敌人。
- 如果内容没人注意，是否检查它是否太熟悉、太平滑、太讨好所有人，缺少风格边界和轻微跑调点。
- 如果内容涉及苦难、低谷或困难，是否检查它是走向和解 / 励志，还是停在卖惨。
- 是否先复述这张图 / 这条视频本来要让观众感到什么，再判断失败是目的不清、证据冲突，还是具体生成失控。
- 是否只检查与本镜目的有关的控制杆：注意力、构图、光线、色彩、焦点、空间、材质、表演、运动、声音、资产或连续性；不把整张专业清单强加给每个结果。
- “没有美感 / 没有壁纸帧”是否只用于本来承担视觉记忆的镜头，并回查它的主情绪、视觉落点和停点，而不是默认补前中后景、留白、色卡和复杂布光。
- “构图不好 / 画面乱”是否回查关键主体、关系距离、动作方向和干扰信息；是否允许中心、偏置、拥挤、失衡、满构图或平面化在有意时成立。
- 是否检查视线从哪里进入、落到哪个决定性信息、从哪里离开；摄影机是否有可信实体位置；每镜是否只有一个主要构图决定、一个主故事线索和按需一个辅助线索。
- 是否把每帧都做得同样锐利、昂贵、完整和高信息量；连接镜头是否允许普通、遮挡、失焦、未完成表演、未回应者、空位或现场继续运转。
- 特殊机位、鱼眼、镜面、反射、百叶影、水波光、车灯扫动和异常曝光是否有物理来源并改变叙事压力；没有动机时是否删除而非保留为装饰。
- 全片 / 阶段是否只选择一个主成像基底，每段是否只有一个主要不完美来源；色彩是否有物理色源和变化动机，而不是滤镜随机漂移。
- 多镜头是否做过顺序打乱测试；若换序后观众信息、等待、情绪和人物状态不变，是否已重构、合并或删除重复镜头。
- “光影潦草 / 平灰”是否先判断平光或灰调是不是目标；不是目标时，再检查真实光源、方向、可读性、材质反应和连续性，不默认补主辅轮廓光。
- “颜色乱 / 廉价”是否检查高权重颜色是否争抢主情绪和身份；不默认低饱和、两种主色或主辅点缀结构才高级。
- “景深失效 / 空间扁平 / 焦点乱”是否区分有意平面化与失控；只在空间承重时检查必要的焦点、遮挡、尺度、透视和空气关系。
- “糊 / 质感假 / 画面脏”是否按交付用途判断必须看清什么、允许模糊什么，而不是统一追求锐利、洁净和可放大壁纸。
- “人物皮肤油 / 脸像塑料 / 高光糊脸”是否先检查人物身份和目标肤质，再检查光源面积、曝光、反光、底妆、纹理与介质；不把冷白、裸妆和柔雾奶油肌套给所有角色。
- “画面死板 / 没氛围”是否先判断静止与干净是否正是主情绪；确需环境变化时，再检查天气、空气、微粒、光学点缀或背景运动的来源和贡献。
- “镜头一直晃 / 主体一直漂 / 运镜破坏美感”是否检查运动的观看职责、身体原因、关键可读点和剪辑接口；不强制每帧稳定或可截图。
- “动作不帅 / 没有高手感 / 不刺激”是否先区分动作物理是否完整、角色动作语法是否有身份、攻击来路是否可读、速度是否有逼近与结果反差、摄影机是否抓住决定性瞬间；不能只补慢动作、火花、拖影、摇晃或人物 Pose。
- 群战是否检查每名攻击者的方位、起势和进入顺序，以及上一招造成的遮挡、失衡、空位、掉落物或反作用力是否成为下一招条件；不能把依次排队攻击误判成模型随机性。
- 决定性瞬间是否符合段落主任务：动作段检查控制与接触，压迫段检查空间与最小反应，关系 / 情绪段检查证据被认出或人物控制破裂；不要求所有段落都用武打停帧。
- “镜头切换生硬 / 三个镜头像三条视频 / 人物每段重新起势”是否回查每个独立机位有没有新的 `[景别][运镜 / 转场]` 头部，第二括号是否写清硬切或软切机制；每次切换是否有前一画面的触发桥梁，摄影机和焦点是否沿桥梁变化，新画面是否继承姿势、道具、余势、空间方向和声场。只删除编号或只增加括号但不补承接关系仍然不合格。
- “声音出现时机乱 / 音效和动作对不上 / 台词表演太平”是否回查环境音、动作音和台词是否逐镜归属；情绪承重台词是否有与镜头可读范围相匹配的眼神、面部、呼吸、视线、姿态、距离和声线证据。
- “演员会哭会怒但不像在演戏”是否回查人物目的、保护策略、精确触发、可见 / 可听变化、禁止提前反应和结束状态；是否把整段情绪从第一帧一次性端出。
- 复杂表演是否内部反查八维，并检查脸、目光、呼吸、声音、身体和关系距离的异步变化；是否出现台词尚未触发，眼泪、退缩、笑意、音量或身体姿势已经提前泄露后续情绪。
- 上一节拍结束状态是否成为下一节拍开始状态；是否出现说完一句就表情复位、泪痕消失、呼吸恢复、身体距离重置或对手漏接反应。
- 使用 FACS / AU 时是否先有人话动作、少量承重编码和动态强度过程；是否避免情绪公式、编码堆叠、远景滥用及 A-E / 0-5 混写。
- 是否把“仙侠不对味”拆成礼仪、身法、空间纵深、奇观节奏和东方视觉语法问题。
- 是否给出最多 3 个优先动作。
- 是否说明回到 `laohu_script_writer`、`laohu_visual_assets`、`laohu_video_prompt`、`laohu_cover_design` 或本 skill。
- 是否输出下一版修正提示词或明确为什么暂时不能写。
- 是否给出入库和反哺位置。

## 反例黑名单

- 不要在缺原提示词、缺结果、缺分镜或缺数据时写确定结论。
- 不要把所有问题都归为模型限制。
- 不要只说“画面不好看”，必须拆成光、色、构图、动作、材质、表演、资产或剪辑问题。
- 不要一次给超过 3 个优先返修动作。
- 不要未保留原提示词就覆盖式复盘。
- 不要把单次作品问题自动升级成全局规则；必须判断是否可复用。
- 不要伪造发布数据、评论反馈、平台原因或用户反应。
- 不要把流量差只归因于平台限流；先检查选题、开头、表达反差、评论钩子和作品承诺。
- 不要为了争议牺牲底层价值；无意义冒犯只会制造噪声。
- 不要把惨当成人设长期售卖；苦难内容必须转向和解、励志、行动或成长。
- 不要只输出正确观点；缺少痛点、金句、共鸣关系和观众收益的内容很难形成传播杠杆。
- 不要用虚假焦虑制造转化；痛点必须来自真实风险或真实难受，并且给观众解决路径。
- 不要把广告语和口播金句写成普通正确话；缺少个体宣言感的金句很难穿透。
- 不要把借用偏见写成歧视或恶意标签；它只能指真实偏好、隐秘不满和未被说透的立场。
- 不要把借用缺点写成羞辱或廉价自黑；缺点必须服务个性、关系、共同敌人或成长动力。
- 不要把所有词句、观点和视觉都磨得平滑顺和；过于熟悉和平均的内容会被选择性忽视。
