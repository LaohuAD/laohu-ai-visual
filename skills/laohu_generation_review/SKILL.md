# 复盘验收核心

## 能力定位

把真实结果和真实反馈转成下一轮可执行动作。

这个 skill 合并生成结果诊断、剪辑成片验收和发布复盘。它不只回答“哪里不好”，而是判断问题处在作品链路哪一层：剧本、视觉资产、视频提示词、生成结果、剪辑成片、封面标题、发布漏斗或课程化回流。

## 能力加厚纪律

复盘不是评价好看不好看，而是把结果变成可执行返修和可复用经验。

必须区分：

- 生成问题：角色变脸、动作乱、表情失控、风格跑偏、声音冲突、模型限制。
- 剪辑问题：主线不清、入点出点断裂、动作/视线/色调/声音接不上、字幕遮挡。
- 发布问题：曝光、点击、前 3 秒、中段、完播、互动、评论和课程化反馈。

成功结果也要提炼可复用规则；失败结果默认有训练价值，要保存原提示词、结果描述、原因判断、修正提示词和下次避免规则。证据不足时输出暂定诊断，不编造平台数据或不存在的素材。

归档、复盘、生成结果诊断和发布复盘必须写入文件。对话里只给复盘文件链接、关键结论摘要和下一步阶段建议。

复盘和归档文件默认在同一个当前文件上更新，不自动新建 v1/v2/v3。只有老胡明确要求新增版本或保留旧版时，才另存版本。

## 内置质量校准视角

以下视角只用于提高诊断质量，不改变复盘输出结构，不在正式交付里新增专家分析栏目。

| 视角 | 内部校准方式 |
|---|---|
| Robert McKee / John Truby | 如果观众“不知道在看什么”，优先检查剧本目标、阻力、代价和人物选择，而不是只修提示词词藻。 |
| Blake Snyder / Dan Harmon | 如果开头弱或中段散，检查前 3 秒类型承诺、钩子、节拍推进和最小故事循环。 |
| Akira Kurosawa / Saul Bass | 如果镜头不成立，检查视觉任务、主体运动、构图概念和剪辑停点是否清楚。 |
| Roger Deakins / Emmanuel Lubezki / Vittorio Storaro | 如果画面廉价或不统一，检查光源方向、镜头身体感、色彩层级和画质描述是否冲突。 |
| Ralph McQuarrie / Syd Mead / Doug Chiang | 如果角色、场景或道具不稳定，检查资产是否真的锁住轮廓、材质、结构、比例和世界观语法。 |
| 胡金铨 / 徐克 / 程小东 / 袁和平 | 如果仙侠动作假、飘、乱，检查身法逻辑、空间纵深、礼仪节奏、动作起止点和可见受力。 |
| Runway Academy / OpenAI 提示工程 | 如果生成偏离，检查提示词是否独立完整、具体、无场外说明、无上下文依赖、无互相矛盾指令。 |

复盘时不要把所有问题都归为“模型不行”。先判断上游是否给了模型可执行的信息；只有剧本、资产、分镜和提示词都清楚后，才把剩余问题归为模型能力限制或随机性。

证据不足时先停在初判，不要硬写完整复盘：

```text
缺原提示词 → 只能判断表面症状，先让老胡补原提示词或当前提示词文件。
缺生成结果 → 只能基于口述做初步诊断，不写确定结论。
缺分镜 / 剧本 → 先判断是否是上游任务不清，不直接改视频提示词。
缺发布数据 → 只做内容和制作复盘，不编造曝光、点击、完播或互动原因。
```

## 能力边界

可以产出：

- 图片 / 视频生成结果诊断。
- 多镜头剪辑可行性和成片验收。
- 发布漏斗与评论反馈复盘。
- 成功 / 半成功 / 失败判断。
- A/B/C/D 等级。
- 失败类型、原因定位和上游返修路线。
- 下一版修正提示词。
- 最多 3 个优先返修动作。
- 案例入库草稿和共享资产反哺建议。

不负责：

- 自动调用高成本视频生成接口。
- 自动操作剪辑软件或平台后台。
- 伪造缺失数据。
- 替代最终审美选择。

## 输入判断

先判断当前反馈类型：

```text
反馈类型：图片生成 / 视频生成 / 剪辑成片 / 发布数据 / 用户主观反馈 / 成功案例 / 失败案例
所属作品：
当前阶段：
原提示词或版本位置：
结果位置或结果描述：
用户最不满意的地方：
下一步意图：
证据完整度：完整 / 部分 / 口述初判
```

缺失信息写“缺”。如果证据不足，先给“基于现有描述的初步诊断”。

## 生成诊断

评分项每项 0-2 分：

```text
角色一致性：
镜头任务：
动作自然度：
表演控制：
构图可用性：
壁纸帧 / 审美停点：
光影风格：
景深与空间层次：
画质与材质质感：
氛围环境元素：
镜头运动约束：
声音适配：
拼接可用性：
```

`壁纸帧 / 审美停点` 用来判断这条视频有没有值得截图的画面瞬间，不等于封面一定要从视频里截。0 分：全片只是交代事件，抽帧后没有主体轮廓、层次、留白和光影记忆点；1 分：有少数构图还行的帧，但主体、光影或背景层次不够稳定；2 分：至少一个暂停后仍然成立的画面瞬间，具备清楚主体、前中后景层次、视觉中心、留白、主次色彩、方向性光影、材质细节和情绪张力。复盘时如果老胡说“几乎找不到一个可以作为壁纸的画面”，不能只归因于模型，要回查分镜和视频提示词是否在生成前设计了审美停点。

`构图逻辑` 用来判断壁纸帧有没有画面骨架。0 分：提示词只堆人物、道具、场景和动作，没有视觉落点、三分构图、黄金分割、中心对称、框架式、引导线、对角线、留白、前景框或三角稳定这类结构；主体位置随机漂移，边角堆满杂物，观众第一眼不知道看哪里。1 分：有构图词，但主体落点、留白方向、视觉重心、导引线终点、块面压杂或镜头停点不稳定。2 分：构图结构明确，主体位于画面 1/3 处、黄金分割点、中心轴、前景框、引导线尽头或三角支撑关系上；视觉落点清楚，主体通过面积、亮度、颜色、清晰度、反差、位置或运动成为第一注意力；有道路、栏杆、桌沿、门框、光束、阴影或人物视线等导引线；有天空、海面、墙面、暗部、虚化背景、雾气、草坡、石墙或门洞阴影等块面压掉杂质；有大面积干净留白、上方留白、侧边留白、极简留白或负空间，边角干净，动态镜头最后能停成稳定壁纸帧。画幅比例也要一起判断：16:9 标准壁纸、21:9 宽幅电影画幅、3:4 竖幅人像壁纸比例或方形文艺画幅是否服务当前用途。

`光影体系` 用来判断画面有没有高级质感、立体感和稳定光源。0 分：只写 `自然光 / 温馨光影 / 电影感光线`，生成结果平、灰、无层次，或者光源乱闪、阴影方向跳变。1 分：有光线时段或光型，但主光方向、弱辅光、轮廓光 / 反光、阴影层次或材质反应不完整。2 分：能清楚看出时段定向光线、主光、弱辅光、轮廓光 / 反光、柔和阴影或长投影，暗部有细节，镜面 / 水面 / 玻璃 / 木桌 / 旧瓷碗等反光服务画面，动态镜头中光源方向稳定。复盘时如果老胡说“画面平、灰、没有层次”，不能只归因于模型，要回查提示词是否锁定了黄金一小时逆光、日出柔光、蓝调时刻冷光、傍晚漫射光、雨后柔和天光、柔和窗光、门缝冷光、灶火暖光或旧灯泡暖光等具体光线。

`色彩体系` 用来判断画面是否有统一调性，而不是廉价撞色。0 分：多种高饱和颜色同时堆砌，人物衣服、墙面、道具、灯光各自为政，没有主色和辅助色，抽帧后廉价杂乱。1 分：有色调方向，例如复古、冷灰或暖黄，但主色、辅助色、点缀色、环境色反光、色彩过渡或统一分级不稳定。2 分：主色调、辅助色、小面积点缀色、饱和度策略、明度 / 对比、环境色反光、柔和色彩过渡和统一滤镜 / 分级都清楚；整体通常中低饱和或低饱和，不超过 2 种主色。复盘时如果老胡说“颜色乱 / 廉价 / 高饱和撞色”，要回查提示词是否只写了 `复古滤镜 / 高级调色`，却没有锁定莫兰迪低饱和、青橙电影色调、冷调蓝灰、复古胶片棕调、奶油温柔、暗调黑金、黑白灰单色、褪色老照片、山城雾灰绿等适合本镜的色彩母体和主次关系。

`景深与空间层次` 用来判断画面是否有空间纵深和稳定视觉焦点。0 分：画面扁平，前景 / 中景 / 远景没有分层，所有物体从前到后一样清楚或焦点随机漂移，抽帧后没有空间入口。1 分：有前景、背景或浅景深词，但焦段选择、焦点落点、虚实过渡或动态对焦不稳定，前景可能遮住关键动作。2 分：前景虚化遮挡、中景清晰主体、远景朦胧环境、焦段选择、焦点落点、虚实过渡和空气透视 / 散景都清楚；85mm、50mm、35mm、135mm 或其他焦段服务本镜任务，动态镜头焦点稳定锁住主体。复盘时如果老胡说“空间扁平 / 没有纵深 / 景深失效 / 焦点乱”，要回查提示词是否只写了 `浅景深 / 电影感`，却没有写清前景是什么、中景主体是什么、远景如何柔化、焦点从哪里转到哪里。

`画质与材质质感` 用来判断截图放大后是否清楚、干净、有真实材质。0 分：截图发糊、主体边缘崩坏、动态拖影过重、材质像塑料或糊成一片，出现多余虚影、AI 扭曲瑕疵、脏杂点、随机文字或水印。1 分：有 `8K / 高清 / 材质` 等词，但微细节锚点、材质绑定、运动模糊控制、介质颗粒边界不稳定，老式 DV 噪点变成脏噪声。2 分：分辨率清晰度、主体边缘锐度、材质质感细分、微细节锚点、运动模糊控制、画面洁净度和介质颗粒边界都清楚；木纹、布纹、糯米皮、旧瓷、纸灰、火苗、玻璃反光、硬币磨损等关键纹理可读，审美停点极低运动模糊。复盘时如果老胡说“糊 / 放大不能看 / 质感假 / 画面脏”，要回查提示词是否只写了 `8K 高清`，没有写具体材质、边缘、微细节和模糊控制。

`氛围环境元素` 用来判断画面是否有环境情绪，而不是只有人物、道具和硬场景。0 分：画面死板空白，或雾、花瓣、光斑、碎屑无来源乱飘，遮住主体，像舞台特效。1 分：有薄雾、水汽、烟尘、光斑、纸灰、落叶等元素，但天气 / 时间基底、来源、方向、密度或题材适配不稳定。2 分：天气 / 时间基底、空气媒介、漂浮微粒、光学点缀、环境运动、密度控制和题材适配都清楚；氛围元素来自真实天气、光源、火盆、灶房、窗边尘埃、雨后水汽、纸灰、落叶或水面波光，并且不遮挡关键动作。复盘时如果老胡说“画面死板 / 没氛围 / 氛围元素乱 / 雾太假”，要回查提示词是否只写了 `氛围感`，没有写清环境基底、元素来源、运动方向和密度控制。

`镜头运动约束` 用来判断视频运动是否破坏静态美感。0 分：全程快速推拉、旋转、变焦、甩镜或大幅抖动，主体位置一直漂移，抽帧几乎都糊或构图变形。1 分：有局部稳定帧，但运镜速度、抖动强度、变焦 / 旋转控制、可定格停留或运动模糊边界不稳。2 分：机位稳定策略、运镜速度、抖动强度、变焦 / 旋转控制、构图保持、可定格停留和运动模糊边界都清楚；固定机位长镜头、极缓慢微动、轻微呼吸手持、慢推慢拉、低幅度摇移或稳定跟拍服务镜头任务，关键动作后停住 1-2 秒，形成可截图构图。复盘时如果老胡说“没有一帧能当壁纸 / 抽帧全糊 / 镜头一直晃 / 主体一直漂 / 运镜破坏美感”，要回查提示词是否缺少运动稳定体系。

声音适配不能只判断有没有配乐、同期声是否抢戏，还要判断人物声线一致性。凡是跨镜头说话、喊叫、VO 回响或画外音出现的人物，都要检查他是否继承了资产表 / 基础设定里的基础声线；病弱、哭腔、压低声音、隔门闷声、电话失真、VO 回响等只能作为当前镜头声音状态变化，不能让同一人物换成另一种音色。

诊断顺序：

```text
剧本任务是否清楚
→ 资产一致性是否足够
→ 分镜机位和运动是否可执行
→ 正式提示词是否独立完整且没有场外说明
→ 生成结果是否偏离提示词
→ 偏离是否属于模型限制、随机性或素材不足
```

常见失败路由：

| 问题 | 回到 |
|---|---|
| 剧情目标、人物动机、开头钩子不清 | `laohu_script_writer` |
| 角色、场景、道具、风格、封面或图片参考不稳 | `laohu_visual_assets` |
| 基础设定、氛围画质、表情、分镜内容或完整视频提示词问题 | `laohu_video_prompt` |
| 单段生成结果需要修正 | `laohu_generation_review` |

修正提示词必须说明：

```text
保留：
删除：
强化：
放松：
新增质量边界：
下一版修正提示词：
```

高频返修 playbook：

| 失败类型 | 保留 | 删除 | 强化 | 回到哪个 Skill |
|---|---|---|---|---|
| C1/C2 人物变脸或接不上 | 可用动作、可用构图、可用光影 | 跨提示词复用同一未资产化人物 | 图片资产、一条 15 秒内合并提示词、明确入点出点 | `laohu_visual_assets` 或 `laohu_video_prompt` |
| 画面美但不像本题材 | 可用画质、主体位置、镜头节奏 | 泛化仙气、无来源光、素材库拼贴感 | 世界观视觉语法、建筑材质、服饰礼仪、色彩层级、文本资产 | `laohu_visual_assets` |
| 仙侠动作假、飘、乱 | 可用动作意图、可用转场点 | 无受力飞行、乱飘衣袖、无起止点动作 | 身法逻辑、起势/发力/收势、空间纵深、遮挡转场、同期声 | `laohu_video_prompt` |
| 宏大但无沉浸感 | 可用大景、空间尺度 | 连续远景航拍、无前景主体 | POV 身体感、近景锚点、手部/袖口/法器/门槛、镜头停点 | `laohu_video_prompt` |
| 诊断准但改法泛 | 已识别的问题类别 | 一次列太多返修方向 | 最多 3 个优先动作，每个动作对应一个上游文件或 Skill | `laohu_generation_review` |

## 剪辑验收

当已有多个视频、图片、音频、字幕或成片版本时，先判断能不能剪成作品：

```text
开头钩子：
信息递进：
情绪递进：
结尾记忆点：
观众看完要知道什么：
```

逐镜头检查：

```text
入点：
出点：
动作连续：
视线连续：
角色外观：
光影色调：
声音：是否继承人物基础声线；当前镜头声音状态是否服务剧情；是否出现跨镜头换音色、声音抢戏或声音与空间不匹配。
字幕：
转场是否必要：
```

成片等级：

```text
A：可发布。
B：小修后可发布。
C：可做内部样片，不建议发布。
D：需要返修核心镜头。
```

返修动作最多 3 个，避免把所有问题混成一团。

STOP/CHECKPOINT：

```text
证据不足 → 停，先补原提示词、生成结果、分镜、剧本或发布数据。
生成诊断完成 → 停，等老胡确认返修方向后再写下一版修正提示词。
```

## 发布复盘

发布后按漏斗定位：

| 卡点 | 典型信号 | 优先回流 |
|---|---|---|
| 曝光低 | 平台给量少、初始互动弱 | 选题、发布时间、账号定位 |
| 点击低 | 有曝光但播放少 | 封面、标题、第一眼钩子 |
| 前 3 秒流失 | 快速划走 | 开头画面、第一句、冲突呈现 |
| 中段流失 | 平均观看低、看不懂 | 剧本结构、分镜节奏、信息密度 |
| 完播低 | 后半段掉完 | 悬念递进、结尾反转、镜头删减 |
| 互动低 | 看完但不评论点赞 | 情绪峰值、观点表达、评论引导 |
| 制作吐槽集中 | 画面、声音、字幕、变脸被反复提 | 对应回到资产、提示词或剪辑 |

短视频流量表达复盘：

```text
表达是否太顺：观点是否只是正确、平稳、无反差。
表达是否太安全：是否没有任何可评论、可争论、可转述的偏离点。
表达是否太理性：是否只在证明逻辑正确，缺少感性反应、关系感和让观众卷入的情绪入口。
是否只突出优点：人物、品牌、产品或观点是否只被赞美，缺少可被接受的缺点、边界和共同敌人。
是否被选择性忽视：表达是否太熟悉、太平滑、太像正确套话，缺少能打断惯性注意的轻微跑调点。
风格是否被讨好磨平：是否想让所有人都喜欢，导致立场、语气、角色缺点和视觉记忆点都不锋利。
喜剧是否缺席：是否能加入狠词怂态度、言不由衷、经典借用、自嘲或错位表达。
浅深比例是否失衡：是否全是浅内容抓眼球，缺少能留下铁粉的深内容；或全是深内容，缺少轻快入口。
争议是否服务主题：争议必须让观点更鲜明，不能只是制造噪声。
是否疑似卖惨：困难是否只在索取同情，缺少和解、励志、行动或成长出口。
故事杠杆是否缺失：是否没有大脑墙、痛点杠杆、金句钉、共鸣网或利他金，导致内容正确但无法穿透、记住、扩散或转化。

```

如果曝光和互动都弱，但选题本身不差，优先回到 `laohu_script_writer` 检查表达方式，而不是只改封面标题。

## 自检

- 是否先判断反馈类型，而不是直接改词。
- 是否保留或引用原提示词、素材或发布数据。
- 是否没有虚构缺失证据。
- 是否明确生成、剪辑、发布分别哪里出问题。
- 是否先排查剧本、资产、分镜和提示词，再判断是否是模型限制。
- 如果流量低，是否检查表达反差、喜剧手法、争议钩子和浅深内容比例。
- 如果内容正确但传播弱，是否检查大脑墙、痛点杠杆、金句钉、共鸣网和利他金是否缺失。
- 如果转化弱，是否检查痛点是否真实、具体、可感知，并且是否给出行动出口。
- 如果金句弱，是否检查它是否像个体宣言，是否只是复述安全共识。
- 如果表达像正确废话，是否检查它是否太理性、太赞美、太突出优点，缺少感性入口、可接受缺点和共同敌人。
- 如果内容没人注意，是否检查它是否太熟悉、太平滑、太讨好所有人，缺少风格边界和轻微跑调点。
- 如果内容涉及苦难、低谷或困难，是否检查它是走向和解 / 励志，还是停在卖惨。
- 是否把“画面不好看”拆成光源、色彩、构图、主体运动、材质、表演或资产一致性问题。
- 是否把“没有美感 / 没有壁纸帧”拆成主体轮廓、前中后景层次、视觉中心、留白、主次色彩、方向性光影、材质细节、情绪张力和镜头停稳点问题。
- 是否把“构图不好 / 画面乱 / 不像壁纸”继续拆成构图结构、主体落点、留白方向、视觉重心、边角清洁、画幅比例和动态镜头停稳点问题。
- 是否把“光影潦草 / 画面平灰 / 没有高级质感”拆成时段光线、主光方向、弱辅光、轮廓光 / 反光、阴影层次、材质反应和动态光源稳定问题。
- 是否把“色彩杂乱 / 廉价撞色 / 没有统一调性”拆成主色调、辅助色、点缀色、饱和度策略、明度 / 对比、环境色反光、色彩过渡和统一滤镜 / 分级问题。
- 是否把“景深失效 / 空间扁平 / 没有纵深 / 焦点乱”拆成前景虚化遮挡、中景清晰主体、远景朦胧环境、焦段选择、焦点落点、虚实过渡、空气透视 / 散景和动态焦点稳定问题。

## 反例黑名单

- 不要在缺原提示词、缺结果、缺分镜或缺数据时写确定结论。
- 不要把所有问题都归为模型限制。
- 不要只说“画面不好看”，必须拆成光、色、构图、动作、材质、表演、资产或剪辑问题。
- 不要一次给超过 3 个优先返修动作。
- 不要未保留原提示词就覆盖式复盘。
- 不要把单次作品问题自动升级成全局规则；必须判断是否可复用。
- 不要伪造发布数据、评论反馈、平台原因或用户反应。
- 不要把流量差只归因于平台限流；先检查选题、开头、表达反差、评论钩子和作品承诺。
- 不要为了争议牺牲底层价值；无意义冒犯只会制造噪声。
- 不要把惨当成人设长期售卖；苦难内容必须转向和解、励志、行动或成长。
- 不要只输出正确观点；缺少痛点、金句、共鸣关系和观众收益的内容很难形成传播杠杆。
- 不要用虚假焦虑制造转化；痛点必须来自真实风险或真实难受，并且给观众解决路径。
- 不要把广告语和口播金句写成普通正确话；缺少个体宣言感的金句很难穿透。
- 不要把借用偏见写成歧视或恶意标签；它只能指真实偏好、隐秘不满和未被说透的立场。
- 不要把借用缺点写成羞辱或廉价自黑；缺点必须服务个性、关系、共同敌人或成长动力。
- 不要把所有词句、观点和视觉都磨得平滑顺和；过于熟悉和平均的内容会被选择性忽视。
