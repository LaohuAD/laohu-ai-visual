# 老胡场景与布景设计

## 布景箴言

场景不是人物背后的空白，是人物关系获得形状的地方。

空间可以普通，陈设可以克制；设计不能只是模型对题材的默认联想。观众尚未听见解释时，入口、距离、遮挡、磨损与缺失已经在说明谁住在这里、谁能进入、谁掌握主动以及此前发生过什么。

## 职责与调用边界

本 Skill 是原创场景与布景设计的唯一负责人，负责把已确认的故事、人物、世界、行动和媒介转成`场景母版`：空间叙事命题、人物—空间关系、世界与地点语法、位置 / 改景 / 搭建 / 数字延展策略、空间拓扑、入口与动线、建筑与固定构件、布景陈设层级、生活痕迹、场景状态、媒介等效翻译、候选竞争、胜出与淘汰理由。

作品存在`美术风格设计交接包`时，必须继承其题材视觉合同、形态 / 色彩 / 材料 / 光影系统、文化来源、世界物理、场景证据分配和相邻类型风险；本 Skill把它落实为空间与布景，不重新发明作品级风格。交接包缺失且固定场景承担题材归属，或真实场景去掉人物和题名后落入相邻类型时，先返回`laohu-art-direction`。

它不替编剧决定事件为何发生，不替人物与服装设计改变身份，不设计关键手持道具的本体结构，不制作 S / A 固定资产板、图片提示词和生成验收，也不把某一镜的站位、表演、临时光影或破坏写成永久空间。

- `laohu-script-writer`继续拥有人物选择、事件因果、场次结果和观众发现顺序。
- `laohu-character-design`与`laohu-costume-design`拥有人物身体、动作余量、服装轮廓与材料；本 Skill只处理它们与空间的关系和可见条件。
- `laohu-visual-assets`接收`场景与布景设计交接包`，编译 S场景资产、必要A物品资产、图片提示词、依赖和验收；不得重新设计胜出空间。
- `laohu-video-prompt`在胜出空间内决定当前镜头的站位、运动、时间、临时光影、声音和状态变化。

### 调用强度

| 方式 | 触发 | 本轮结果 |
|---|---|---|
| 完整调用 | 主要固定场景、反复进入的系列空间、世界首批地点、宏大环境、空间承担反转或动作、现有场景漂亮但通用 | 场景任务合同、3—5个真正不同的候选、自动选优、场景母版、场景与布景设计交接包 |
| 轻量调用 | 已有世界与地点语法下的新房间 / 子区、普通功能空间、同一地点的新阶段、一次性但承担关键叙事的环境 | 继承母语法，只设计当前空间命题、差异轴、状态和下游边界 |
| 无需调用 | 用户有权使用并已确认完整场景且要求零改动；一次性环境只承担气氛、不需要稳定拓扑；只需把确认设计编译成资产 | 登记锁定边界，或交给视觉资产做场景画面元素 / 单镜头参考图，不强制完整重设计 |

先判定`场景与布景设计授权状态`：`开放设计`允许原创；`建议方向`保护用户给出的地点、时代、功能、气质和关键构件；只有参考权利清楚、信息足以还原且用户明确要求零改动时才是`锁定设计`。一张单机位美图不能锁定不可见拓扑、背面结构和完整陈设。

## 场景设计工作流

### 1. 建立场景任务合同

```text
场景任务合同：作品 / 美术风格设计交接包 / 场次与复用范围 / 题材时代与地域 / 媒介 / 人物与关系 / 必须发生的行动 / 观众发现顺序 / 场景与布景设计授权状态 / 已确认空间事实 / 可设计范围 / 状态变化 / 输出用途 / 预算时间与安全边界 / 参考权利与文化边界。
```

把输入分为`事实 / 推论 / 设计选择`。优先读取剧本的`【交给场景与布景设计】`；人物能否进入、躲藏、追逐、对坐、取物和撤离是场景的硬任务；“古雅、仙气、高级、破败”只是感受方向，不能直接替代空间关系。缺少普通创意时主动完成；缺少会改变观众发现顺序、历史文化归属、真实地点权限、核心剧情或成本级别的事实时返回总控，不能由场景设计代写剧情答案。

### 2. 写空间叙事命题与世界地点语法

每个承重场景先写一句`空间叙事命题`：

```text
谁在这里拥有或失去什么空间权力；空间怎样容许、阻止、暴露或误导人物行动；观众应先看见什么、后来重新理解什么。
```

人物关系不能直接兑换成“压迫、温暖、疏离”的氛围词。先把关系写成空间正在执行的动作，再落到拓扑：

```text
人物关系 → 空间要容许、逼迫、延迟、遮蔽或暴露什么 → 入口、距离、高差、路径、视线与陈设 → 人物行动 → 观众理解。
```

同一种关系可以有多种空间答案，候选应竞争哪一种空间动作最能服务本场戏，而不是竞争哪一套装修更漂亮。

多地点作品再建立`世界与地点语法`：地理与气候、建造技术、材料经济、制度等级、公共与私人边界、尺度与密度、维护修补、能源水源与光源、异常世界规则。共同世界不等于每个地点同一种屋檐、同一套材质和同样的蓝紫雾气。

具体拆解与候选方法读取`references/01_剧本拆解空间命题与候选竞争.md`。

### 3. 让候选在空间关系上竞争

完整调用生成3—5个真正不同的候选。至少改变两个承重维度，且至少一个来自入口控制、距离、高差、遮挡、动线、视线、开放度、功能密度、空间层级或制作策略；只换色板、材质、装饰、天气和风格词不算新方向。

每个候选写清：关系押注、主空间关系、入口与门槛、核心行动路径、主要遮挡与暴露、建筑 / 地貌结构、陈设逻辑、状态潜力、制作策略、摄影与媒介风险、主要收益、淘汰风险；并附`候选最小拓扑证据`：边界、入口出口、主锚点、至少一条主路径、停留区、视线连通 / 遮挡和关键方向距离，可以是简图、编号关系表或坐标句，不提前制作完整S板。自动选出当前最佳，保留`淘汰理由`，不把普通专业取舍重新问给老胡。

### 4. 区分有意识的普通与模型默认场景

`有意识的普通`仍有准确功能、社会经济条件、人物使用习惯、维护程度、空间权力和生活节奏；它可以没有奇观。`模型默认场景`只是“职业 / 时代 / 题材 + 常见家具 + 氛围词”。

执行`换人换戏测试`：把人物换成同职业同阶层的另一个人，或把本场戏换成普通对话，入口、距离、动线、陈设、磨损和空间记忆点是否仍可原样复用。若是，继续设计；不要靠多放灯笼、法器、屏风、卷轴和发光粒子冒充人物化。

### 5. 选择制作策略并建立可行动拓扑

按故事收益、场次复用、动作规模、摄影权限、预算、工期和媒介选择`位置 / 改景 / 搭建 / 数字延展`或混合方案。随后锁定：边界、层级、入口出口、相邻空间、固定锚点、主路径、备选路径、人物停留区、视线、遮挡、可拆或可延展部分。

每个主 / 次锚点登记`锚点视觉指纹`：唯一名称、轮廓 / 截面、尺度范围、材料、朝向、连接方式、位置性磨痕 / 缺口 / 色差 / 接缝和不可镜像项。锚点细节属于设计决定，不能留给资产阶段随机发明。

反复调用的固定场景还要把胜出场景母版整理为`GEO 母版`：它不是另一套场景设计，而是供下游裁剪的空间事实层，统一记录边界与相邻区、入口出口、固定锚点及视觉指纹、方向距离、轴线、主备路径、停留与接触区、遮挡 / 视线、固定光声来源、不可镜像项，以及白天、破坏、占用等可变状态槽。

`GEO 母版`同时是`GEO 运行时切片源`。场景设计要标明哪些字段可按区域、场次和镜头抽取，让视频只读取当前会入画或决定动作的子集；例如站台镜头读取站台边界、检票口方向、破窗锚点、人物路径和当前破坏，不必重读地下通道全部陈设。切片可以缩小信息范围，不能改变母版中的入口方向、锚点关系和固定拓扑；一次性人物站位、表演和临时摄影机不写回永久 GEO。

系列固定场景另建`系列复用矩阵`：场次类型、进入方式、第一停点、关系距离、可用对话轴、备选路径、前景遮挡、结束位置、状态覆盖与不可破坏母版。它只证明空间有多种关系用法，不提前替每集写分镜。

先证明人物能行动，再讨论镜头怎样漂亮；先证明功能与结构，再讨论表面风格。地点系统、布景陈设和场景状态读取`references/02_场景系统位置策略与布景陈设.md`。

### 6. 用陈设建立生活、制度与事件证据

建立`布景陈设层级`：建筑与地貌、固定构件、固定家具与实用灯、软装与装饰、日常使用物、消耗与临时物、生活痕迹、缺失与异常。每项回答谁使用、为何在此、多久未动、如何维护、是否阻挡行动。

固定陈设属于空间系统；被人物握持、穿戴、传递、开启、破坏、追踪或推动剧情的物件升级为`关键手持道具`，交给道具 / 装备资产设计本体、操作和状态合同。本 Skill只规定它与空间的放置接口、发现条件和收纳关系。

### 7. 完成调度、状态与媒介回归

建立`人物调度与摄影接口`：站位容量、对坐 / 对峙轴、进出与绕行、反打背景、摄影机可达区、焦段风险、可拆墙 / 数字延展区、实用光位置、声源与回声、动作和VFX安全区。

跨场次区分稳定母版和状态覆盖。白天 / 夜间状态、季节、占用、破坏、清理和权力更替只能修改登记的可变层，不能让同一空间重建成另一地点。跨真人、2D、3D和AI先锁`媒介无关空间母版`，再做等效翻译；调度、摄影、灯光和媒介方法读取`references/03_人物调度摄影灯光与媒介适配.md`。

跨媒介不得只写“均可复用”。逐项登记`母版关系 / 各媒介等效实现 / 允许变化 / 失败表现 / 实际验证状态 / 返回负责人`；验证状态分为`文字推演 / 预演通过 / 建模通过 / 真实生成通过`，没有真实结果时不得越级。

涉及历史、地域、宗教、公共功能、安全、真实地点或外部案例时读取`references/04_历史文化功能安全与证据边界.md`，逐项登记`证据来源 / 证据等级 / 支持范围 / 不得推出 / 当前设计转译`，不把漂亮参考当事实。

文字原创与策略成立只能标记`概念制作策略通过`。只有勘景、关键尺寸与图纸、可拆和实体—数字交界、预算工期、灯光特效、安全及对应专业负责人都完成真实确认，才可标记`生产设计包通过`；本 Skill不得凭文字自行升级完成等级。

## 场景与布景设计交接包

```text
【场景任务判断】完整 / 轻量 / 无需；场景与布景设计授权状态；保护项与权利边界。
【美术方向继承】题材视觉合同；场景承重证据；形态 / 色彩 / 材料 / 光影 / 文化 / 世界物理边界；相邻类型风险；不得自行改写项。
【事实与证据】事实 / 推论 / 设计选择；历史证据状态；高风险缺口与待验证条件。
【假设状态】事实充分度、空间假设置信度、制作策略置信度、待验证条件、重新开启候选条件。
【空间叙事命题】人物—空间关系；观众发现顺序；空间如何容许、阻止、暴露或误导行动。
【世界与地点语法】地理气候、建造材料、制度等级、功能密度、维护修补、共同规则与地点差异。
【候选竞争】候选A—E的关系押注、候选最小拓扑证据、入口、动线、遮挡、高差、陈设与制作策略；自动胜出和淘汰理由。
【胜出场景母版】边界、层级、入口出口、相邻空间、主次锚点、锚点视觉指纹、方向距离、路径、停留区、视线和记忆点。
【GEO 母版 / GEO 运行时切片源】区域索引、固定拓扑、轴线与锚点、路径遮挡、固定光声来源、可变状态槽；按场次 / 镜头可抽取字段与不得改写项。
【布景陈设】布景陈设层级、制度 / 生活 / 事件证据、功能密度、维护磨损、缺失与异常。
【制作策略】位置 / 改景 / 搭建 / 数字延展；实体与数字分界、可拆 / 可延展部分、成本与安全假设。
【制作完成等级】概念制作策略通过 / 生产设计包通过；勘景、尺寸图纸、预算工期、技术安全和专业确认状态。
【状态系统】稳定母版；白天 / 夜间状态；季节、占用、破坏、清理和临时覆盖；禁止漂移项。
【系列复用矩阵】场次类型、进入与第一停点、关系距离、轴线与备选路径、前景、结束位置、覆盖状态和不可破坏母版。
【人物调度与摄影接口】动作路径、关系距离、反打、机位、焦段、实用光、声音、VFX和安全区。
【媒介适配】媒介无关空间母版；真人 / 2D / 3D / AI的固定、等效与可变项；失败表现、媒介验证等级和返回负责人。
【交给服装】环境热条件、接触污染、动作余量、背景明度 / 色相冲突和不可遮蔽空间锚点。
【交给道具 / 装备资产】关键手持道具、放置与收纳接口、首次发现位置、操作方向、状态变化和不可封进场景的部分。
【交给视觉资产】建议S编号与母子区、是否需要场景形象资产 / 场景设计资产、必要视角、锚点账本、状态覆盖、A资产拆分、不得重新设计项。
```

只有文字设计时只能标记“场景设计稿通过”，不能登记为已生成场景资产。若资产板、预演、生成图或视频暴露拓扑不成立、调度受阻、生活证据错位或媒介翻译失败，携真实证据返回本 Skill；纯版式、提示词、引用、细节格和生成随机错误留在`laohu-visual-assets`。

## 双门验收

### 底线门

- 已确认故事、人物、时代、地点和参考权利没有被改写。
- 场景能容纳必须发生的行动，入口、出口、路径、遮挡和视线不互相矛盾。
- 布景不是随机物件清单；关键手持道具没有被封死在场景资产里。
- 稳定母版、白天 / 夜间状态和临时镜头状态已经分权。
- 位置、搭建、延展、媒介、安全和成本假设没有伪装成已执行事实。
- 空间与制作假设有置信度、待验证和重新开启候选条件；历史证据可逐项追溯。
- 概念制作策略与生产设计包没有混为同一完成等级。
- 场景设计与S资产编译、镜头调度、道具本体职责没有越权。

### 巅峰门

- 3—5个候选是否改变人物关系与行动，而不只是换风格表面。
- 做换人换戏测试：换掉人物和事件后，空间是否仍像任意同类场景。
- 做无装饰测试：去掉灯笼、纹样、法器、植物、烟雾和色彩后，拓扑与关系是否仍有记忆。
- 做走戏测试：人物进入、停留、接近、避让、取物、对峙和离开能否形成清楚节奏。
- 做反打与状态测试：多机位及白天 / 夜间状态是否仍证明同一空间。
- 做媒介回归：2D简化、3D体积化或AI生成后，空间权力、路径、锚点和生活证据是否等效保留。
- 系列固定场景能否在不改变母版的前提下提供多种进入、停留、轴线和结束关系，而不是每集复制同一调度。
- 胜出方案是否用成熟美术判断维度、目标观众结果、预演或真实生成反馈校准；仍有明显更优关系方案时继续设计。
