# 场景系统、位置策略与布景陈设

当作品有多个地点、需要实景 / 改景 / 搭建 / 数字延展判断、固定拓扑、布景陈设、生活痕迹、道具分界或跨场次状态时读取。

## 1. 从世界到地点系统

先建立世界共同语法，再设计地点差异：

```text
自然条件：地貌、气候、水源、风、植被、灾害。
建造能力：结构体系、跨度、连接、运输、维护。
材料经济：什么常见、什么昂贵、什么只能修补。
制度空间：等级、礼法、公共 / 私人、谁能进入。
功能密度：真实流程需要多少设备、家具、储藏和服务空间。
生活节奏：何时拥挤、何时空置、如何清洁、取暖、照明和排废。
世界异常：规则怎样改变承重、路线、边界、能源或尺度。
```

地点差异不能只靠色彩。宗门大殿、外门宿舍、药庐、剑峰小院和禁地必须在进入方式、尺度、维护、材料等级、声音、光源和使用人群上分化。

## 2. 位置 / 改景 / 搭建 / 数字延展

| 策略 | 适用 | 主要风险 |
|---|---|---|
| 位置实景 | 真实尺度、材料与历史层最有价值，动作与权限可满足 | 摄影权限、噪声、天气、调度和不可拆结构 |
| 实景改造 | 基础结构合适，只需改变年代、制度、身份或局部路径 | 参考污染、恢复成本、改动权限 |
| 完整搭建 | 关系距离、调度、可拆墙、动作与光线需要精确控制 | 预算、工期、尺度缩水、表面假 |
| 局部搭建＋数字延展 | 近景接触需要实体，远景尺度或奇观需要延展 | 实体与数字透视、光色、材质和状态不一致 |
| 完全数字环境 | 2D / 3D / AI、异常世界、危险或不可抵达地点 | 漂浮、无功能、无尺度、镜头间重建 |

“AI生成不用考虑搭建”是错误判断。实体预算会转化为生成稳定性、资产数量、参考容量、镜头自由度和返修成本。

## 3. 可行动拓扑

胜出方案至少锁定：

- 空间边界、层级、朝向与相邻关系；
- 主入口、次入口、出口和不能通行处；
- 主锚点与次锚点；
- 主路径、备选路径、停留区、危险区和隐藏区；
- 视线相通与被遮挡关系；
- 固定构件、固定家具和实用光；
- 摄影、动作、声音和VFX需要的净空；
- 母场景与子区关系。

拓扑不是S资产设计板。本 Skill确定设计关系；`laohu-visual-assets`再用鸟瞰、四机位、细节带和锚点指纹证明这些关系能够稳定生成。

候选阶段不必画完整制作板，但必须留下`候选最小拓扑证据`：边界、入口出口、主锚点、主路径、停留区、视线连通 / 遮挡和关键方向距离。没有这份证据，几段空间形容词不能证明候选真的不同。

胜出后为每个主 / 次锚点登记`锚点视觉指纹`：唯一名称、轮廓 / 截面、尺度范围、材料、朝向、连接方式、位置性痕迹和不可镜像项。视觉资产只把它编译成可生成规格，不重新发明这些身份特征。

## 4. 布景陈设层级

按层设计，避免把所有物件平铺成清单：

1. 建筑 / 地貌：墙、地、顶、台地、水体、道路、结构骨架。
2. 固定构件：门窗、楼梯、壁龛、柜体、灶台、管线、固定法器接口。
3. 固定家具与实用灯：桌椅、床榻、货架、工作台、灯具、火源。
4. 软装与制度陈设：帘幕、地毯、挂画、标识、礼仪、荣誉与禁忌物。
5. 日常使用物：餐具、文具、清洁、工具、储藏、儿童或宠物痕迹。
6. 消耗与临时物：食物、燃料、药材、垃圾、来客物、工作中间状态。
7. 生活痕迹：磨损、修补、灰尘、压痕、日晒、潮痕、搬动空位。
8. 缺失与异常：不该空却空、不该新却新、用途错位、被刻意清除。

每项至少回答：谁使用、频率、放置原因、维护者、是否固定、会不会阻挡动作。漂亮但无因果的物件先删除。

## 5. 环境物与关键道具分界

判断不按大小，而按剧情职责：

- 只证明时代、功能、身份、密度和生活方式：留在布景系统。
- 需要人物握持、穿戴、开启、读写、传递、偷取、追踪、破坏或造成状态变化：升级为关键手持道具 / A资产。
- 同一物件可以先是陈设，后成为道具；首次进入操作链时拆出独立本体与状态合同。
- 场景只锁收纳位置、承托面、朝向、发现条件和环境接口，不锁人物手部动作。

## 6. 生活、制度与事件证据

三类证据共同形成可信空间：

| 类型 | 说明 | 例子 |
|---|---|---|
| 制度证据 | 权限、等级、礼法、工作流程 | 门槛宽度、座次、服务入口、封存位置 |
| 生活证据 | 长期使用、经济、照料与习惯 | 修补方式、反复触碰磨损、临时收纳 |
| 事件证据 | 过去或当前事件留下的结果 | 搬动空位、被擦过的灰、临时遮盖、破坏传播 |

陈设不要替剧本泄底。秘密可以有可回看证据，但第一次观看时要与人物认知和观众发现顺序一致。

## 7. 场景状态系统

把场景拆成：

```text
稳定母版：拓扑、固定构件、永久材料、主锚点。
阶段状态：季节、长期占用、权力更替、修缮、废弃、长期破坏。
场次覆盖：白天 / 夜间状态、天气、营业 / 休息、来客、清理、临时陈设。
镜头瞬时：人物站位、移动物、烟尘、水迹、刚发生的破坏与临时光影。
```

白天 / 夜间状态不能只换色温。还要判断使用者、门窗、实用灯、开放区域、声音、可见深度、工作状态和安全路径。镜头瞬时状态交给视频；跨多个镜头持续存在的真实结果再由复盘判断是否升级为状态资产。

反复出现的系列场景再登记`系列复用矩阵`，比较不同场次可用的入口、第一停点、关系距离、轴线、备选路径、前景和结束位置。目的是防止“连续性”退化成每集同一机位、同一站位，不替视频阶段预写镜头。

## 8. 宏大环境

宏大不等于构件无限增加。先固定：世界边界、主地标、进入路径、人尺度证据、区域层级、地貌与建筑语法、普通区域、负空间和异常规则。异常必须改变路线、受力、资源或制度；只增加奇观表面时留在可变风格层。
