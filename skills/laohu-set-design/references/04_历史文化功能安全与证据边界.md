# 历史文化、功能安全与证据边界

当场景涉及历史时期、地域、宗教、族群、真实地点、公共机构、建筑功能、安全规范、外部影视案例或参考权利时读取。

## 1. 证据分级

按任务需要使用，不为“资料多”而全收：

1. 一手与官方资料：博物馆原状陈列、考古报告、建筑测绘、档案、法规、机构标准、真实地点资料。
2. 专业二手研究：经过编辑或同行评议的建筑史、社会史、物质文化与影视美术研究。
3. 成熟制作机制：影视学院课程、行业岗位标准、公开美术流程、制作访谈和技术案例。
4. 视觉参考：照片、画作、电影、游戏与概念设计，只证明可见机制，不自动证明历史事实。
5. 搜索聚合与模型常识：只作检索入口，不直接写成定论。

逐项登记`历史证据状态`：`已证实 / 有争议 / 类比推定 / 纯虚构设计`，并附`证据来源 / 证据等级 / 支持范围 / 不得推出 / 当前设计转译`。一个总的“参考过历史资料”不能替代逐项证据。缺失的关键年代、地域、制度和建筑事实进入`高风险缺口`，不靠“古风通用元素”填平。

## 2. 历史与幻想的转译

历史资料先拆机制：

- 建筑为何采用这种结构、跨度、院落和门槛；
- 材料来自哪里，谁负担得起，如何运输维护；
- 陈设由礼法、工作、季节还是审美决定；
- 谁能进入、坐在哪里、从哪条服务路径行动；
- 光、火、水、通风、储藏和排废如何运作。

幻想设计可以改变其中一到数条底层规则，但要重算结果。例如漂浮建筑改变承重后，还要回答进出、补给、防风、排水和坠落风险；不能只把宫殿放到云上。

外部作品只吸收“如何用门槛表现权力、如何用缺失物制造调查痕迹”等机制，不复制其标志性建筑轮廓、道具组合、色板、镜头和场景故事。

## 3. 功能与社会经济校准

现实空间按真实流程判断面积、设备、共享设施、储藏、服务区、人员密度和维护状态。医院、学校、交通、工厂、餐饮、司法和住宅涉及当前标准时，优先查现行主管部门或机构资料。

- 清洁不等于空房；需要运作的物品仍要存在。
- 贫困不等于破烂堆积；资源稀缺体现于维修、替代、多用和更新周期。
- 富裕不等于黑金玻璃与超大面积；服务系统、材料稀缺、维护与空间权限更能证明。
- 古代不等于所有木头发黑；新旧、日晒、烟熏、触摸和潮湿按来源分布。

## 4. 安全、权限与成本

本 Skill可以提出制作策略，但不能把假设写成真实许可或已执行结果。

- 真实地点：拍摄、改造、烟火、吊挂、文物和人流权限需真实确认。
- 搭建：结构、消防、逃生、用电、承重、材料毒性和拆除由合格专业人员确认。
- 动作：坠落、火、水、兵器、车辆、动物和人群由对应专业部门制定安全方案。
- 公共空间：无障碍、卫生、消防和运营事实需要核验现行标准。
- AI / 数字制作：预算仍包括资产数量、复杂度、参考容量、算力、返修和连续性维护。

文字设计阶段写“待专业核验”，不能写“安全通过、已获许可、符合规范”。

区分两种完成等级：`概念制作策略通过`只说明位置 / 改景 / 搭建 / 数字延展的分工合理；`生产设计包通过`还需要真实勘景、关键尺寸和平立剖图、可拆构件与实体—数字交界、预算工期、灯光特效、安全以及对应专业负责人的确认。没有后者，不得声称已经可施工。

## 5. 参考权利与文化边界

- 用户有权使用且明确锁定的场景参考，只在证据范围内复现；不可见部分保持未知或登记制作假设。
- 公开影视、游戏、建筑摄影和概念图用于研究机制，不复制完整组合和标志性外形。
- 宗教、丧葬、族群、地域和神圣空间不作为随意奇观素材；需要理解真实使用者、禁忌和语境。
- 活着的文化不被压缩成“异域纹样包”；地域差异至少落实到气候、材料、工艺、生活与制度。

## 6. 推荐的一手入口

- [AFI Production Design Curriculum](https://conservatory.afi.com/production-design-curriculum/)：剧本分析、视觉叙事、实景记录、平立面、模型、调度、摄影与VFX接口。
- [AFI Production Design Learning Outcomes](https://conservatory.afi.com/learning-outcomes/)：研究、预演、位置改造、搭建、图纸、预算与跨部门交付。
- [ScreenSkills Production Designer](https://www.screenskills.com/job-profiles/browse/film-and-tv-drama/craft/production-designer-film-and-tv-drama/)：行业职责、研究、位置、摄影、服装、灯光与特效协作。
- [ScreenSkills Set Decorator](https://www.screenskills.com/job-profiles/browse/film-and-tv-drama/craft/set-decorator/)：布景陈设、家具、墙地面、角色背景和道具边界。
- [Academy Production Design Activities Guide](https://www.oscars.org/sites/oscars/files/complete_art_direction_activities_guide.pdf)：建筑、色调、材质和陈设怎样传递人物与故事信息。
- [Unreal Engine Virtual Production](https://www.unrealengine.com/explainers/virtual-production/what-is-virtual-production?lang=en-US)：预演、技术预演、虚拟勘景、实体与数字延展分界。
- [Disney Animation Visual Development](https://www.disneyanimation.com/process/visual-development/)：从剧本主题建立角色与世界，再进入资产生产。
- [Disney Animation Modeling](https://www.disneyanimation.com/process/modeling/)：视觉开发、环境模型、Layout与Look Development的接力。
- [故宫原状陈列](https://www.dpm.org.cn/shows/original.html)、[数字故宫](https://www.dpm.org.cn/bottom/friend.html)、[故宫数字文物库](https://digicol.dpm.org.cn/)：中国古建筑、原状室内、器物类别、材质与历史陈设证据。

来源提供事实、机制和校准维度，不替本 Skill完成当前作品的原创选择。
