# 剧本拆解、空间命题与候选竞争

当场景需要从剧本原创、人物关系由空间承重、现有设计漂亮但通用，或需要比较多套真正不同的空间方案时读取。

## 1. 从场次事实提取空间任务

先提取，不先装修：

| 剧本事实 | 要转换的空间问题 |
|---|---|
| 谁先到、谁后来 | 谁控制入口，后来者是否被看见、等待或突入 |
| 谁知道什么 | 信息能否被遮挡、偷听、误认、提前暴露 |
| 谁想接近或逃离 | 距离、路径、门槛和障碍怎样制造代价 |
| 谁拥有这里 | 哪些区域能自然占据，哪些需要获得许可 |
| 必须发生的动作 | 人体、工具、家具、地面和净空是否支持 |
| 场次反转 | 同一空间的哪项旧证据会被重新理解 |
| 下一场压力 | 出口、残留物、破坏或目击关系留下什么 |

输入只写“庭院、书房、宗门大殿”时仍不足。至少补出：本场空间任务、人物关系、必须行动、观众发现顺序、复用范围和不可改事实。

## 2. 人物—空间关系

空间关系不是“角色喜欢什么风格”，而是身体和权力如何被安排。

- 领地：谁能随意移动、触碰、坐下和改变陈设。
- 门槛：谁进入前需要被允许，谁可以越过礼法。
- 距离：亲近、对峙、回避和等级由什么维持。
- 暴露：人物一进门会先被谁看见，秘密在哪里失守。
- 遮挡：屏风、柱、帘、转角、地形和高差隐藏什么。
- 路径：直达代表公开和权力；绕行可能代表礼法、危险或犹豫。
- 高差：不自动等于强弱，要结合谁能上去、谁被迫仰视、谁可退场。
- 占用：哪些痕迹证明长期生活，哪些是临时闯入。

建立最小关系表：

```text
人物A如何进入 / 停留 / 使用 / 离开：
人物B如何进入 / 停留 / 使用 / 离开：
两人最近与最远关系距离：
谁控制视线、出口和关键物：
空间迫使他们做出的选择：
反转后被重新理解的旧证据：
```

## 关系先变成空间动作，再变成装修与陈设

不要把“亲密、压迫、控制、疏离、照顾”直接翻译成色彩和氛围。先选择空间在这段关系里承担的动词：

```text
容许：谁可以不经许可进入、靠近、触碰或改变这里。
逼迫：空间让谁必须靠近、等待、绕行、低头或暴露。
延迟：门槛、距离、路径和操作顺序怎样推迟一次行动。
遮蔽：谁看不见什么，谁能单向观察，秘密怎样暂时成立。
暴露：人物、物件或行动在哪个节点无法继续隐藏。
庇护：空间替谁吸收风险，又把代价转移给谁。
```

再把动词落实到入口、距离、高差、路径、视线、遮挡、承托面和陈设位置。这样设计出来的不是关系的插图，而是会参与剧情的空间。

例如“母亲一边照顾孩子，一边限制他继续吃某种食物”，不能只靠温暖餐厅和丰盛饭菜说明。需要判断：那盘食物最初在谁的可达范围内，母亲从哪里夹取、为什么会先递出又收回，青菜与肉食怎样摆放，移走餐盘需要经过什么承托面和路径，孩子是否能继续触及。食物本体归道具资产，夹取和移走的具体镜头归视频；本 Skill负责让餐桌、座位、距离、放置与收纳接口支持这段关系和完整动作。若空间安排迫使人物做出与台词相反的动作，装修再漂亮也不成立。

同一关系至少允许两个合理空间候选。例如控制可以来自物理封闭，也可以来自表面开放但所有路径都经过主人；亲密可以来自距离近，也可以来自人物始终替对方保留一条不被打扰的路径。候选比较的是哪一种空间动作最准确，不把某个空间比喻固化成关系公式。

## 3. 空间叙事命题

合格命题包含四项：人物关系、空间动作、观众认知、结果。

```text
例：大师兄用一座没有正门、人人都能闯入的小院维持散漫假象；真正重要的区域不是被锁住，而是藏在所有人都看得见却不会停留的位置。小师妹每次沿同一路径冲入，观众逐集发现普通陈设都服从精确的修行与防守距离。
```

不合格命题：`清幽仙气、古朴雅致、破败中见高级`。这些只描述结果表面，没有人物和行动。

## 4. 候选差异轴

完整调用先选择本场真正承重的2—4条差异轴，再生成3—5个方向：

- 权力：主人控制 / 访客控制 / 表面开放实际筛选。
- 开放：无门开放 / 多重门槛 / 单入口封闭 / 多路径渗透。
- 距离：强迫靠近 / 保持礼法距离 / 可快速拉开。
- 层级：水平平等 / 垂直压迫 / 高低可反转。
- 视线：全可见 / 逐层揭示 / 单向观察 / 互相误判。
- 动线：直线 / 回环 / 分叉 / 必须经过承重节点。
- 密度：功能紧凑 / 空旷权力 / 生活挤压 / 刻意清空。
- 时间：稳定日常 / 可迅速变成战场 / 状态层逐步暴露。
- 制作：实景借势 / 局部改造 / 完整搭建 / 数字延展改变尺度。

候选卡：

```text
候选编号与关系押注：
主空间关系：
入口、路径、距离、高差、遮挡与视线：
建筑 / 地貌与陈设怎样共同证明：
必须动作如何发生：
观众先看见与后来重读：
位置 / 改景 / 搭建 / 数字延展策略：
主要收益 / 失败风险：
```

## 5. 选择与淘汰

先确定本作品主胜负手，再给候选排序：

1. 是否最强支持人物选择和场次反转。
2. 是否让必须动作自然发生，而不是为镜头临时搬家具。
3. 是否形成不用装饰也成立的空间记忆。
4. 是否能跨场次、状态和媒介稳定复用。
5. 是否在成本、工期、安全和生成稳定性内实现。

淘汰理由必须指向关系与代价。例如：`候选C的封闭单入口强化秘密，但小师妹反复闯入需要每集重做开门节拍，损害系列日常速度，淘汰。`不要只写“不够高级”。

## 6. 平凡与反差

普通人物和普通地点不需要强行奇观，但要有选择。

- 清贫不等于空：物少但每件有多次使用、修补和收纳关系。
- 富贵不等于满：稀缺材质、维护成本、服务空间与留白共同证明权力。
- 散漫不等于乱：混乱可以集中在人物真正不在意的区域，其他区域显出隐性秩序。
- 深不可测不等于发光法阵：距离、磨损、异常净空、错误用途和旁人反应都能证明。

做换人换戏测试和无装饰测试。若只剩题材物件清单，返回空间命题重做。
