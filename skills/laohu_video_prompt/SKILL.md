# 视频提示词核心

## 能力定位

把剧本场次、分镜或视频创意推进成可生成、可诊断、可剪辑的完整视频提示词。

这个 skill 合并原先的视频基础设定、氛围画质、人物表演、画面内容和提示词组装。它不是拼接器，而是视频导演说明书：先判断剧本来源和镜头任务，再设计表演与时长，最后输出完整三层提示词。

用于模型测评、教程和公开发布的提示词默认使用原创虚构内容。画面出现品牌、包装、Logo、车标、店招、服装标识、界面或商业文字时，只能继承 `老胡 / laohu / 老胡用AI赚钱` 及其行业品类变体，不得使用或近似复刻现实品牌和 IP，也不得发明未经授权的第四品牌名称或图腾。需要 Logo 时必须调用 `【Logo参考@老胡Logo】` 固定图片资产，不设计或生成 Logo，不描摹、重画、重着色、材质化、改字形或改比例；只写 Logo 载体、位置、尺寸、真实透视、缩放、遮挡、受光与跨镜头保持。

综合模型测评和公开商业样片中，只要真人模特承担可识别表演或关键商品交互，正式提示词就必须在 `【基础设定】` 同时引用其人物形象资产与人物设计资产，不能只靠年龄、性别、发型和服装文字临时选角。单人且性别不是测试变量时优先成年女性；多人让女性承担主要视觉、关键动作或主要台词，再穿插成年男性。明确测试特定性别或人口结构时按题目执行。

声音内容不自动等于音频参考资产。普通 BGM、环境音、动作音和随机声场直接写进 `【基础设定】` 或对应镜头块，由模型按统一文本生成。只有固定歌曲 / MV、指定音色或声纹、现成对白口型同步、必须准确复现的节奏结构，才调用 `【音乐参考@...】` 或 `【音色参考@...】`。如果音频不是测试的固定控制变量，不得为了形式完整机械创建 AU 资产。

## 能力加厚纪律

本 skill 生成任何分镜、故事板、视频提示词、氛围画质、画面内容、音乐卡点镜头、转场镜头或短片执行稿前，必须先读取并吸收 `高质量AI视频提示词开发计划.md`；如果本轮还涉及首帧、封面、图片参考或画面美学镜头，还必须同时吸收 `高质量AI图片开发计划.md`。这两个文档不是可选参考，而是高质量输出的执行门槛。没有经过这两份高质量特征资产库校准的结果，不能交付。

视频提示词必须做无效信息退稿。只要正式结果主要由 `治愈、唯美、电影感、高级、真实、清新、自然、氛围好、光影好、镜头流畅、情绪饱满` 这类泛词支撑，而没有把本镜主情绪和关键可见 / 可听证据写清，就必须退回重写。证据从镜头、表演、声音、光影、色彩、空间、材质、时间和停点中按需选择；高质量不是把话写长，而是每个短语都有导演职责。

视频提示词同样必须反模型众数倾向。模型最容易把 `电影级、超写实、高级感、治愈系、国风、赛博、写实短片` 这类高频风格词补成平均画面：看似正确，但没有作品身份。凡是 `风格核心`、主视觉概念、前 3 秒钩子、转场机制、结尾封面帧、人物情绪主句和声音状态主句，都不能接受第一版。内部先生成 3-5 个方向不同的候选：不同风格母体、不同光影方案、不同色彩影调、不同构图策略、不同转场物理机制或不同情绪反差点；再淘汰同题材可替换、泛电影感、泛广告感、泛短剧感和只靠漂亮词承重的方案。

视频提示词不能承担第一次发明镜头的职责。读取剧本和分镜后，先检查是否已经存在成立的导演镜头构思：具体事件节拍、决定性瞬间、动作 / 调度几何、摄影机观看位置、画内证据和光影落点。如果只有 `女侠御敌、人物悲伤、两人争吵` 加一个普通中景，必须退回分镜层生成 3-5 个镜头构思候选；不能靠增加运镜、颗粒、雨雾、材质和电影感把弱镜头扩写成长提示词。

如果老胡直接要求单条视频提示词且没有分镜文件，本 skill 必须在内部补做导演镜头构思，先选镜头、后写三段正文。剧本已写明的人物胜负、受伤、动机、关系结论和关键道具状态必须继承；未写明的动作相位、摄影机位置、构图、画内证据、声音、光影、局部连接和情绪实现由本 skill 主动设计，并记录为本模块新增创意。

视频提示词阶段要把“观众看懂情绪”升级为“观众经历情绪”。除表演证据外，按段落需要补足目标与代价、观众和角色的信息关系、危险方向与空间距离、呼吸 / 重心 / 受力 / 速度 / 触感 / 声场、等待与冲击的时长、人物选择及余波。不是每镜都用 POV、特写或手持；建立空间、贴近感官、共同经历和拉开沉淀要形成节奏。上游没有写这些时，本 skill 不能只说缺失，必须在不违背硬约束的前提下补出可生成方案。

本 skill 的第一道总控不是字段完整，而是情绪代入。正式写作前必须完成一轮 `情绪—感知—动作—摄影机` 判断：先命名本镜让观众和主角共同经历的唯一主情绪；再确定观众与主角共享哪些信息、空间距离和身体感；动作导演把情绪落实成危险来路、人物选择、力量变化和结果；摄影机通过自己的观看位置、距离、速度、方向、焦点、遮挡和惯性把这种身体感传给观众；最后才补光影、声音、环境、道具、空间和生成稳定性细节。技术细节不能抢走主角的行动和摄影机的观看立场。若补充控制后画面变得更合理却更没有代入感，必须退回前面的情绪和动作设计重做。

视频提示词的反众数检验：

```text
同题材可替换性：这句风格核心是否能直接换到任何古风 / 恋爱 / 治愈 / 武打视频里？如果能，说明还没绑定本作品。
画面成品性：它是否能直接生成光、色、构图、材质和运动，还是只是在讲作者想要高级？
关系准确性：人物情绪和声音状态是否命名了具体关系压力，而不是只写伤感、期待、温柔、克制、破碎。
留白可见性：留白是否落成空间块面、遮蔽比例、未完成动作、声音停顿或尾帧停点，而不是只写神秘感。
```

正确做法不是把风格词堆得更怪，而是把风格交集写准。错误写法：`古风电影级写实，英姿飒爽，镜头炫酷，高级国风。` 正确方向：`写实古风武侠庭院短片，黑衣女侠独自夜练；胡金铨式东方礼仪身法为主，低饱和墨黑、冷月银、竹影灰构成主色，湿石板暗面压住杂质，月洞门和廊柱做框架构图，冷月侧逆光勾出剑脊、肩线和发丝；动作爆点停成可截图的剑舞海报帧。`

每条高质量视频提示词写作前先确定主情绪、主观看任务和主注意力，再用九类问题检索可能的承重项。不是九项必填，只有当前镜头真正需要的结果才落进正式三段模板：

```text
镜头任务：本条视频只承担一个主任务，信息、情绪、动作、奇观、转场或壁纸停点不能混乱抢权重。
镜头关系：景别、机位、运镜、焦段、人物占比、主体落点和停点决定观众和主体的距离。
表演变化：触发、起始状态、脸部证据、身体证据、变化路径、结束余韵。
声音表演：先写说话态度和情绪意图，再写音区、响度、语速、停顿、重音、气息、咬字、距离和混响。
光影系统：光影承重时，从真实光源、方向、软硬、明暗、肤色和材质反光中选择必要关系。
色彩系统：色彩承重时，从色相、饱和度、明度、肤色、光源色、暗部与分级中选择必要关系。
空间层次：空间承重时，从前景、中景、背景、导引线、负空间、场景锚点和空气状态中选择必要关系。
材质细节：人物皮肤、发丝、衣料、首饰、道具磨损、环境湿度、颗粒、反光和边缘细节。
剪辑连续：首帧、尾帧、声音桥、视觉锚点、动作接力、光线匹配和可截图停点。
```

视频美学的根本不是单帧漂亮，而是“关系在时间里有秩序地变化”。图片只保留这一瞬间真正承重的关系；视频则把实际发生的变化写出先后、触发与结果。动作、摄影机、光影、声音、表情和尾帧都是候选通道，不发生或不承重的通道不必补齐。

正式写视频提示词前，从时间关系链中选择本镜实际发生的节点：起点状态、触发事件、动作路径、表演变化、镜头路径、光影变化、声音进入和退出、峰值停点、尾帧接续。简单静止镜头可能只有起点、微变化和结束；复杂转折再展开更多节点。被选中节点必须转译进 `【画面内容】`，未发生的不要补齐。

正式输出仍只保留 `【基础设定】`、`【场景状态与氛围画质】`、`【画面内容】`。第二段虽然升级了名称，三段总数没有变化：基础设定承接实际输入和抽象输出边界，场景状态与氛围画质承接开拍前事实及全段视觉基线，画面内容承接逐镜执行。上述九项是内部导演判断，不能作为新字段塞进代码块；但如果任一项对当前镜头承重，就必须转译成三段正文里的可见 / 可听结果。

### 观众认知状态的视听编译

从剧本和分镜继承的 `观众认知状态` 只作为内部分析，不能原样进入正式模型正文。视频提示词只编译成观众和模型可见、可听、可执行的证据：

```text
“观众暂时相信她在撒谎” → 写她避开视线、把沾血袖口藏到桌下，同时让画外警笛逼近；不能把判断句直接交给模型。
“观众正在问门后是谁” → 写门缝下方影子停住、门把手极轻下压、角色屏住呼吸；不写作者提问。
“观众预测刀会落下” → 写刀锋停在最高点、肩背完成蓄力、被攻击者退路被封；不写观众心理说明。
“本镜推翻身份判断” → 写旧徽章从衣领滑出、焦点从枪口移到徽章、持枪者眼神与枪口同时失稳。
```

正式 `【基础设定】`、`【场景状态与氛围画质】`、`【画面内容】` 不得出现“观众暂时相信、观众正在问、观众预测、导演想表达、为了让观众明白”等内部标签。必须继续追问：屏幕上究竟出现什么，声场里究竟传来什么，人物和环境发生什么可观察变化。

视角同样要编译：叙事视角和信息视角决定本段允许展示什么，光学视点决定镜头实际站位。提示词写 `谁的肩背占左前景、谁在右中景、摄影机保持轴线哪一侧、焦点何时迁移`，不只写“主角视角”或“代入感”。

`【画面内容】` 必须先过视频画面内容四核：

```text
主体与注意力目标：这一镜观众必须看谁 / 看什么，注意力是否会迁移。
动作与表演：台词、脸部、眼神、呼吸、肢体、道具交互、反应和环境响应怎样变化。
效果系统：运镜、稳定、焦点、环境、光色、速度、声音和转场怎样放大变化。
节奏与时长：观众识别、动作完成、情绪建立、效果展开和停点需要多少时间。
```

四核是开放推导骨架，不是四个词槽。每个镜头优先建立一个主注意力目标；景别、焦点、运动差、明暗色彩、导引线和声音共同把观众注意力收拢到该目标。注意力可以从脸迁移到手、从道具迁移到画外声音引起的反应，但必须由眼神、动作、焦点转移、声音或切镜触发，不能让背景奇观、人物表演和炫技运镜同时抢最高权重。

每个镜头还必须有一个主情绪目标。主注意力目标、主观看任务和主情绪目标不能混为一谈：分别回答 `看哪里、发生什么、主要感到什么`。一个镜头一个主情绪目标，是指一个情绪节拍只允许一种感受承最高权重；辅助余味可以存在，但不能与主情绪并列抢夺。多个镜头分别承担积压、加深、误导、释放或反转，组合成整段视频的情绪曲线。

情绪转折镜头不是例外逃生口。需要从一种感受转向另一种时，必须写清 `起点情绪 → 可见 / 可听触发 → 表情、动作、镜头、光色和声音怎样变化 → 终点情绪`。例如“警觉转为释然”要由对方放下武器、人物肩颈松开、呼吸恢复、刀尖下落、焦点由刀转回眼睛等证据推动，不能在同一段里同时堆警觉、释然、希望、孤独和浪漫氛围。

构图、光影、时间、姿态、场景、色彩、材质、运镜、速度和声音都只服务本镜主情绪，不是必须填满的专业栏目。逐项执行情绪贡献检查：加强主情绪的保留，无关的删减，削弱、稀释或制造另一种并列情绪的删除或改写。不能因为某种运镜炫、某束光漂亮、某个场景高级，就允许它抢走本镜情绪目的。

动作按 `起始状态 → 触发 → 起点 → 路径与速度 → 接触 / 受力 → 可见结果 → 反应 → 结束状态` 写。情绪必须进入动作与表演证据：台词态度、眉眼嘴角、呼吸、肩颈、手指、重心、与道具 / 对方的距离和声音变化。`悲伤、攻击性、紧张、治愈` 可以作总结，不能代替模型要生成的变化。

运镜统一执行具象化链路：

```text
观看意图 → 摄影机物理路径 → 屏幕变化 → 情绪倾向 → 停点
```

正式提示词不能只写 `镜头移动、推镜、环绕、FPV、手持、横滚`。内部先推导摄影机是否位移、镜头是否 Pan / Tilt、方向轨迹、速度与稳定方式；正式正文只保留观众可直接感到的镜头结果：镜头沿哪个屏幕方向变化，主体大小和位置怎样改变，背景怎样划过或拉伸，地平线怎样倾斜，焦点怎样转移，最后停在哪里。复合运镜示例：`镜头缓慢向前推进并向上仰摇，机器人从全身中景逐渐扩大到胸部以上近景，低机位仰角增强，最后停在面甲和眼睛。`

运镜的情绪倾向不是固定含义。推镜可能是亲密、发现、压迫或危险靠近；拉镜可能是释放、孤独、环境揭示或真相扩大。必须结合起终景别、主体状态、速度、稳定方式、焦点、声音和上下文判断，不把 `推 = 紧张、拉 = 孤独` 写成死规则。专业术语也按同一方法展开：机械臂写空间关键帧和节点停顿，FPV 写飞行轨迹和横滚，希区柯克变焦写机身推进、光学变焦拉远、主体大小基本不变和背景拉伸。

效果系统按实际需要从以下开放维度选择，不机械全部填满：

```text
焦点：谁清楚、谁模糊、焦点何时因何事从哪里转到哪里。
环境：天气、建筑、地面、烟尘、雨水、爆炸或人群怎样从前状态发生变化并作用于主体。
光色：光源如何出现、移动或消失，受光部位、阴影、反射、色温和画面主次怎样变化。
速度：主体、摄影机和环境各自多快，哪一层慢化 / 冻结 / 加速，何时恢复正常。
声音：发声对象、材质动作、方向距离、空间、先后、冲击、混响衰减和画外想象。
切换：由动作、遮挡、声音、视线、焦点或光色峰值触发切镜，切入新的注意力目标。
```

画外声音必须当作空间叙事。写清声源始终位于镜头之外、来自哪个方向和距离、经过什么空间反射、是否逐渐接近或远离，以及画内主体如何反应。声音可以让观众感到画框外仍有街区、房间、追兵、车辆或人群，不必为了说明声源把对象强行拍进画面。项目默认每条正式提示词写 `只生成对白、动作声、衣料声、道具声和环境声，不生成 BGM`；只有老胡明确要求模型内音乐时改变。

节奏不等于镜头越多越好。按以下预算选时长：

```text
所需时长 >= 主体识别时间 + 动作完成时间 + 情绪建立时间 + 效果展开时间 + 停点 / 切换余量
```

简单手势可以短，渐哭、复杂受力、天气转变、奇观展开、焦点迁移和多次镜头切换需要更长。平台允许范围内优先给情绪和动作足够时间；内容装不下时按顺序选择加长总时长、删减次要效果、减少镜头或拆成多条素材后期剪辑。正式正文不写逐秒时间码或镜头编号。每个独立机位以新的 `[景别][运镜 / 转场]` 镜头头部开始，硬切、遮挡转场、甩镜转场或匹配剪辑写入第二个括号；同一镜头只保留一个头部并写摄影机从起点到停点的连续物理路径。

图生视频与文生视频共享四核，但描述预算不同：

```text
图生视频：图片负责首帧身份、外观、基础构图和已有场景；文字重点写从该状态怎样动，焦点、运镜、光色、环境和声音怎样变化。
文生视频：文字同时负责建立首帧和时间变化；没有资产的主体、场景、时间、风格、构图、外观和材质必须先写足，再写动作与效果。
实际引用资产：资产负责稳定本体，正文只重申本镜临时状态、受力受光、遮挡、交互和承重细节；未投喂资产的元素仍按文生视频粒度写。
```

首尾帧双端锚定模式另做一层端点推理。它不同于把上一条视频尾帧作为下一条首帧的连续拼接：本模式在同一次生成中同时引用 `【首帧参考@图1】` 与 `【尾帧参考@图2】`，提示词负责两端之间的可见变化。

用户提供两张图片时，必须实际读取并逐项比较两张图，不能只根据文件名、用户概述或预设效果猜测。图片暂时不可读取时，先说明缺少哪些端点信息，再补图或补充描述；不能假装已经完成兼容性分析。

写作前必须回答：

```text
必须保持什么：身份、比例、关键结构、道具、运动方向或其他连续性锚点。
必须改变什么：场景、服装、材质、姿态、产品形态、时间、天气或光色。
共同桥梁是什么：轮廓、颜色、光源、反射、遮挡、碎片、烟雾、运动方向或空间入口。
最大断裂点是什么：景别、机位、透视、主体位置、朝向、尺度、光线或场景结构。
```

再按首尾帧变换链组织 `【画面内容】`：`首帧状态 → 触发机制 → 解构 / 离场 → 中间状态链 → 形态 / 服装 / 材质 / 场景变化 → 尾帧元素提前召回 → 减速收束 → 精确落入尾帧`。每一段要有可见因果，不能只写“变成图二”。摄影机可以跟随、环绕、FPV 穿越、机械臂移动、横滚或模拟子弹时间，但优先保持 `一个主变换机制 + 一条主摄影机路径`，写清路径和屏幕变化，避免主体变化与炫技运镜互相抢权重。

尾帧召回要发生在结束前：先让尾帧中的主色、轮廓、光源、场景入口、服装局部或主体姿态进入画面，再降低速度、减少粒子和运动模糊，校正主体比例、位置、景别、透视与地平线，最后稳定落入尾帧。首尾图是输入硬锚点和验收目标，但不能承诺概率模型每次完全不漂；生成后必须检查首帧、身份连续、中间跳变和尾帧落准。

首尾帧模式仍使用三段式：`【基础设定】` 只引用双端图片和本条实际资产，`【场景状态与氛围画质】` 写首帧已经成立的场景状态与全程基线，`【画面内容】` 写完整变换链、摄影机路径、逐镜声音和收束。不要新增“首尾帧说明”作为第四段，也不要使用逐秒时间码。

跨 `VID` 连续性参考是另一种模式：它不是同一次生成的首尾帧变换，而是用已生成 A 条的尾部状态帮助独立生成 B 条。写连续多段前先路由：

```text
直接连续：同场景、连续时间，动作 / 视线 / 情绪余势直接延续；使用 A 最后一次切镜后的单一机位尾部视频。
同场重建：同场景但时间、段落、机位或运动重启；使用 A 终帧 / 干净构图参考和世界状态，不强锁动态。
关系重置：换场、换时空、主要空间关系改变；不引用 A 尾部，只复用本条实际需要的稳定资产。
```

规划 A 时，把最后一个动作组设计成 `当前结果已完成 + 下一压力已出现`：人物完成落地或收势，武器完成改向 / 脱手 / 入鞘，爆炸与破坏结果已经可见，同时让下一威胁通过视线、影子、画外声、未接触刀尖或运动方向进入。不要把拆点留在兵器仍相架、人物悬空且落点未知、投射物已发射但结果未出现、爆炸材料尚未响应的中间相位；也不要专门添加没有剧情职责的静止站位镜头。

A 实际生成后再选参考，不在剧本或分镜阶段虚构时间码。优先取最后一次切镜后约 1-3 秒的单一机位，确认只有一个构图和一套空间关系，且人物姿势、持物、场景锚点、屏幕方向、观看侧、速度与摄影机余势可辨。若这一范围混入硬切前后的两个镜头、强遮挡、严重失焦、错误角色状态或反向运动，缩短到最后一个有效机位；仍不稳定时改用终帧。动态视频负责动作相位、运动方向、风雨 / 烟尘和摄影机惯性，终帧负责构图、位置、光源和道具状态，不能用错参考类型。

每个连续链在正式提示词外建立交接卡：

```text
上游 VID：
连续性类型：直接连续 / 同场重建 / 关系重置
参考输入：尾部视频 / 终帧 / 无
实际截取：最后一次切镜后的范围；不得包含两个机位
世界状态：场景锚点、人物位置 / 朝向 / 距离、持物 / 持握手、伤势、服装、天气、永久破坏
屏幕投影：画面左右、前后景、视线方向、动作轴、观看侧、运动向量、当前景别 / 焦点
必须继承：
允许重置：
B 第一可见动作 / 声音：
```

世界状态默认硬继承；屏幕投影只在直接连续时整体继承。同场重建或明确硬切可以改变景别、焦点、主体画面左右和摄影机侧别，但必须先用场景锚点、人物朝向、视线、正面中性镜头或可见越轴重新证明空间。人物在画面左边不是永久世界坐标，人物距门三步、右手持剑、断柱位于其身后才是世界事实。

B 仍是单条自足提示词。实际上传尾部视频时，`【基础设定】` 写 `【视频参考@VID-A尾部连续性片段】`，随后用一句话说明本条只继承哪些身份、场景状态、站位、观看侧与运动余势，不复演参考里已完成的动作；`【场景状态与氛围画质】` 重新描述 B 开拍前已经成立的空间与状态；`【画面内容】` 直接从 B 第一项新动作 / 新声音开始，不写 `承接上一段` 或 `继续上一镜`。若没有实际上传参考，不能在基础设定假装引用。

每个内部镜头节点最终都要融入连续导演语言：先写开场主情绪、注意力目标、主体状态 / 变化和可见结果；需要切换时，前一画面的动作、遮挡、视线、焦点、声音、光色峰值或运动方向必须成为桥梁，再写摄影机怎样进入新景别和机位、人物与道具继承什么状态。正式正文可以分段，但不写 `镜头01 / 镜头02` 标签。精简不是删除动作因果，而是删除无职责字段、重复资产外观、同义风格词和作者解释。

视频提示词还必须做导演总控判断。每条镜头先判断它是文戏、武戏、转场、空镜、表演、动作、信息揭示还是审美停点，再选择节奏与摄影方式。短切、长镜头、特写进、跟踪、甩镜、遮挡转场和固定镜头都是候选，没有固定题材或情绪映射。每次选择都要回答：为什么现在这样拍或这样切，观众得到或失去什么信息，主情绪被加速、压住、误导还是释放。

文戏视频先写清关键台词在关系里做什么，并让它造成可见 / 可听后果。潜台词、眼神、嘴角、下颌、呼吸、肩颈、停顿、关系距离和反应镜头是候选通道，按主情绪选择，不要求每句齐全。不要只写 `她很伤心地说` 或 `他温柔地回答`，也不要为证明文戏完整把所有表演信号同时堆上去。

武戏 / 动作视频先确定动作任务、主注意力和主情绪。凡是发生发力、碰撞、格挡、闪避或落地，必须让力量来源、运动路径、接触点和动作结果可读；起势、发力、受力、反应、爆点和停帧则按动作节拍分配，不要求每镜齐全。衣料、发丝、地面、竹影、火花、水面和镜头响应只选择能证明力量或加强主情绪的部分；只有承担视觉记忆或接剪职责的爆点才停成可截图帧。

动作导演判断优先于技术补丁。先问“这一镜要让观众和主角一起感到什么”，再设计人物怎样在压力中选择、发力、受力、反击和承受后果；摄影机要站到能共同经历这股力量的位置，而不是站在外面把动作说明一遍。站位、兵器状态、射界、材质、穿模和切镜检查必须服务已经成立的情绪与观看路径；如果一项技术修正让主角变被动、镜头变旁观或运镜只剩炫技，不能保留它的结构，只能把它降为校准约束后重新设计动作组。

音乐卡点、治愈系画面、氛围空镜和转场素材也不能降级成漂亮词集合。先确定主情绪、主注意力和可见变化，再从景别、机位、运镜、空间、光色、材质、环境运动、卡点、停点和接续中选择真正承重的部分。它们可以靠静止、声音、单一动作、空间观察或色彩变化取胜，不强制点线面、光影分离、动态光源、空气媒介和壁纸帧齐全。

短视频开头和转场素材必须先判断是否需要“危机型未闭合动作”。这类镜头的任务不是单纯好看，而是让观众在前 1-3 秒产生一个必须等待的结果：手机会不会关机，插头能不能插上，车会不会撞到，人能不能逃开，火花会不会铺满屏幕，球会不会砸到镜头。正式提示词要把这个等待问题写成可见画面机制，而不是写成作者说明。

危机型开头转场的可执行公式：

```text
前状态：一眼看懂危险、缺口或倒计时。
压力推进：数字变化、距离缩短、速度加快、声音逼近、光线变暗或边界压近。
路径和边界：主体从哪里来、往哪里去、左右 / 前后为什么不能轻易避开。
峰值遮挡 / 冲击：黑屏、强光、火花、水花、烟雾、球体、车灯、袖面、门板或手机屏幕铺满画面。
揭示帧：满屏材料退去后，第一眼露出正文主体、脸、动作、标题或舞蹈起势。
```

错误写法：`开头用手机电量倒计时转场，随后进入舞蹈。` 正确写法：`竖屏手机屏幕占满 16:9 画面中央，电量图标只剩红色细线，系统倒计时数字从 5 跳到 4、3、2；画面下方一枚白色充电头沿桌面向接口滑近，塑料外壳轻微擦过桌面发出细响。数字跳到 1 时，充电头金属端距离接口只剩一指宽，屏幕瞬间暗下形成满屏黑场；黑场里先响起一声水袖破风，下一帧从黑屏中央亮出泠月的眼睛和抬腕起势。`

每条正式视频提示词必须按独立生成请求处理，包含完整的【基础设定】【场景状态与氛围画质】【画面内容】三部分。AI 视频平台不会读取上一条分镜、全片设定或项目上下文，所以正式投喂正文不能写“沿用全片”“参考上文”来替代实际内容。

前两部分可以从同一作品复用，但输出时必须重新压缩：基础设定只列实际引用素材，氛围与画质只写跨全部镜头成立的宏观基线；当前动作、事件、局部声音、光色和一次性视觉变化写进对应镜头。

视频提示词不能跳过剧本来源。即使老胡没有直接说“写剧本”，也要先形成或引用单场次剧本。

视频提示词必须做泛化弱词审稿。`小、轻、低、微微、一点、稍微、淡淡、有点、慢慢、柔和、自然、高级、舒服、压住、收紧` 可以作为辅助修饰，但不能单独承担生成控制。正式写 `【基础设定】`、`【场景状态与氛围画质】` 和 `【画面内容】` 时，先把这些词拆成可生成维度：动作幅度、速度、力道、声音音区、响度、共鸣、停顿、光线强度、软硬、色彩饱和度、明度对比、镜头距离、景深和空间压力。错误写法：`轻微手持、声音低、低饱和、柔和光影、小动作`。正确写法：`低频呼吸式手持微抖，主体脸部边缘保持稳定；男声落在中低频，胸腔共鸣更重，句尾下压；海天主色低饱和蓝绿，肤色保持白皙通透，暗部偏冷但保留栏杆纹理；拇指指腹在杯沿同一处摩擦两次，指节短暂绷白。`

人物表情不是最后补词。分镜宏观表阶段必须判断表情是否需要细化、是否占用时长；需要时先设计表演，再写画面内容。

场景和动作必须先通过情节合理性判断。正式写视频提示词前，先问四个问题：这个人此刻为什么在这个场景；她表面正在做什么；内心真实发生了什么；接下来的动作和表情是否由上一句台词、关系阶段、人物性格和场景姿态自然触发。不能为了显得甜、可爱、伤心或细节丰富，就机械添加捂嘴、抓衣角、低头、摸头发、转身、看远方等常见动作。动作要从情节里长出来，不从“视频提示词常用动作库”里随手抽。

当前案例：《30秒钟带你体验谈恋爱》VID-05 的主情绪是独处傻乐。错误处理是把独处傻乐写成捂嘴、抓衣角、下摇到手部小动作；这会把镜头变成通用甜宠动作，反而弱化“一个人发呆回想时突然笑出来”的真实感。正确处理是让林栀站在海边栏杆处，表面看海，实际回想前一条男声问候；前几秒眼神放空，某一秒单侧嘴角先翘起，然后眼睛弯起来，笑意从脸上漏出来。这个镜头应优先锁脸、锁眼神和嘴角，不下摇到手部。

表情驱动镜头先判断关系距离和情绪证据位置。脸部微表情承重时可用中近景、近景或特写；身体距离、完整姿态、环境压迫或疏离承重时，中景、全景和远景可能更准确。人物占比由观众需要读到的证据倒推，不固定为 68%-72% 或 78%-82%。当前恋爱短片的胸部以上舒适近景只是案例，不是通用模板。

特写进必须作为高张力短视频的开场判断。特写进不是“脸越大越好”，而是用局部证据先抢回观众注意力：眼睛、嘴角、手指、汗珠、喉结、录音笔红点、门锁转动、手机震动、合同签名、杯沿裂纹、药瓶标签、刀尖、火苗、泪痕等，都可以先于全景出现。悬念、审问、背叛、冲突、恐怖、情绪爆点、关系反转和前 3 秒钩子，不要默认全景交代谁在哪干什么；先判断全景是否会提前泄底。如果会，就使用 `局部证据特写 → 反应脸 / 关键动作 → 空间揭示`。错误写法：`全景展示审讯室，背叛者坐在椅子上，审讯者站在对面，气氛紧张`。正确写法：`极近特写先拍录音笔红点和攥白的指节，审讯灯只照亮吞咽的喉结；对面椅脚移动声响起时，镜头缓慢后拉，文件袋、椅背和人影才进入画面`。

人物美感镜头必须区分空间留白和信息留白。空间留白是天空、海面、墙面、暗部、雾气、窗外虚景和负空间；信息留白是只露半张侧脸、嘴唇、手、锁骨、耳坠、发丝遮眼、门缝局部、背影回头一点点。空间留白让画面呼吸，信息留白让观众补完。人物第一眼、开场钩子、封面、暧昧、危险、身份悬念和神秘氛围，可以用局部遮蔽制造期待；但情绪高潮、争吵、落泪、台词反应和关键表情证据，必须让眼睛、嘴角、眼眶、下巴和呼吸清楚。正确写法：`胸部以上近景，人物位于左侧三分线，只露右半张侧脸，左半张脸被前景发丝和树影遮住；侧逆光勾出鼻梁、唇峰、耳坠和下颌线，右侧海面留白占画面约 45%，观众通过嘴角和耳坠轻晃读到情绪。`

特写可以作为蒙太奇连接器。时间压缩不要只写字幕或日夜交替，可以用相似构图的局部状态变化：咖啡满杯到空杯、杯沿渍变深、便利贴变多、键盘碎屑堆积、台灯频闪、烟灰增长、药片减少、花瓣枯萎、纸灰落满桌面。心理暗示不要只写角色痛苦，可以用联想特写表现同构的内心过程：墨水吞掉白纸、玻璃杯水旋成漩涡、海面反光被树影切碎、灰尘在强光里翻涌、灯丝忽明忽暗。正式写法必须有 `现实触发 → 抽象特写意象 → 回到人物反应 / 当前物件结果`，不要把抽象意象当无来源高级空镜。

表情主任务镜头必须保护第一视觉落点，但不禁止手部、身体或服装参与表演。先判断脸、手、道具、身体重心和环境中谁承担主情绪；辅助动作只有在加强同一情绪、留在既定构图内且不会诱导模型下摇或切走时才保留。抓衣角、握拳、手贴胸口、鞋尖或裙摆如果会成为新的镜头目标，就删除或拆成独立证据镜头；手在脸侧、胸前或同一景别内自然支持表情时可以使用。当前恋爱短片删除低位动作，是因为它们抢走脸部注意力，不升级成所有表情镜头禁用手部的规则。

情绪表演型视频必须按“主情绪颗粒度”拆分。单条正式视频提示词只承担一个主情绪，最多带一个过渡情绪；不要把心动、沉浸、失落、怀疑、争吵、崩溃等多个阶段塞进同一条提示词。每条提示词在提示词外先判断 `主情绪、起始状态、触发语音 / 事件、表情变化、身体反应、结束状态、下一条情绪准备`，再把结果写进 `【画面内容】`。主情绪可以在本条里形成过程，例如从强撑理解滑向伤心、从不可置信滑向委屈愤怒；但过渡情绪只能为下一条做准备，不能抢走本条中心。

情绪高潮必须有可感知的峰值证据，但不固定等于落泪、崩溃或动作放大。泪落、呼吸卡断、身体松掉、异常平静、动作突然停止、声音变空和关系距离拉开都可能成立；根据人物性格、前期积累和本镜主情绪选择。当前恋爱短片可用落泪作为案例，不把它升级成终局高潮通用模板。

对镜头情绪表演必须先确定“镜头是不是对话对象”。如果作品设定是脑内 VO、画外音、导演提示、观众视角或镜头前方的人在对角色说话，镜头就不是旁观摄影机，而是关系里的对手戏位置。此时人物默认要正面对镜头、眼线指向镜头、用脸回应镜头；故事板也要画 `视线箭头指向镜头`、`眼线锁镜头` 或 `视线从下方回到镜头`。不要把男声写成 `声音方向`、`步道前方`、`海面方向` 或一个空间里的发声点，模型会让人物转头去找那个方向，导致观众看不到表情。低头、短暂偏开、失焦或背过脸只能作为后期崩溃、躲避、强撑和遮掩情绪的明确动作；写完后要让视线回到镜头或说明它是故意躲开镜头。当前案例：《30秒钟带你体验谈恋爱》正片里男声像从镜头位置进入林栀脑海，林栀应对着镜头完成防备、心动、失落、怀疑和争吵反应；风景只做留白和反差，不能成为她的主要表演对象。

初识搭话和陌生直球表白不能直接写成震惊心动。真实关系里的第一反应通常先经过安全评估和边界判断：眼神快速扫对方、眉心轻皱、嘴唇闭紧、身体微微后撤、肩线有防备、呼吸短暂停住；确认对方没有明显威胁后，才出现困惑、好奇、觉得荒唐、忍笑和一点点松动。只有经过连续稳定关注、日常问候、尊重边界或可靠回应之后，表情才逐步进入真正的心动、雀跃和投入。当前案例：林栀第一次听见 `你好可爱呀，可不可以跟我在一起？`，不应瞳孔放大像被击中，而应先警觉、防备、判断，结尾只留下很小的好奇。

剧本里的 `角色名（语气 / 神态）：`、`角色名 VO（语气 / 神态）：`、`角色名（OS）：` 和动作段里的表情神态，是下游视频提示词的人物表演源头，不是剧本文字装饰。只要剧本写了压着火、忍着哭、哭腔、故作轻松、哽住、笑着、发抖、低声、急了、愣住等标注，分镜表必须继承为 `表情来源`，并判断 `表情功能`、`表情占用时长` 和推荐景别；视频提示词必须在 `【画面内容】` 里把它转成可见 / 可听的表演结果。

视频提示词不得擅自改剧本台词。正式剧本确认后，台词原文、旁白原文、VO 原文和字幕原文都属于硬约束。视频提示词可以加声音状态和表演方式，例如低声、哽住、气息短、隔门闷住、电话失真、停顿、轻喘、看向镜头后再说；但不能改句子、换词、删关键词、加新句或把台词改成主题总结。写任何有对白的镜头前，必须回查当前剧本原文；若上下文被压缩或不确定，就先检索剧本文件，不能凭记忆补写。当前案例：VID-27 必须保留剧本原台词 `哪个说的。长大了，是要晓得照顾人。以后要当个顶天立地的男子汉，晓得不？`，不能改成 `长大不是没人管你`。

视频提示词收到单点反馈时，必须全局扫描同类问题。老胡指出某一个镜头的台词、POV、动作、资产数量、年代物件、道具状态或空间逻辑错误，默认是在指出一种通用失败模式。除非老胡明确说只改这一条，否则处理顺序是：先修当前镜头，再搜索当前全分镜文件和相关剧本 / 分镜 / 资产文件的同类项，最后把同类问题一起修掉。当前案例：老胡指出 VID-27 台词被改，不应只改 VID-27，而要抽取剧本全部对白、VO、OS，与全分镜视频提示词中的角色发声内容逐条对照，修正所有被改写、缩写、加戏或换词的台词。

用户给出改写版时，必须做“对比吸收”，不是原样覆盖，也不是只挑几句。先比较用户版和当前版在动作因果、POV 画面结果、情绪递进、空间方向、道具状态、上下镜头衔接上的差异；保留用户版更强的因果和画面证据，再把说明性词语翻译成可生成动作。当前案例：E1-S9-C2 用户把 `书包滑落` 改成 `姐姐跑起来后发现书包碍事，边跑边扯下肩带，把书包甩到土路上`，应吸收为动作链；但 `陷入震惊状态`、`疯狂跑`、`不知道到底是捡书包还是追姐姐` 要改成肩膀僵住、脚步乱、书包撞偏身体、视线在姐姐背影和地上书包之间迟疑。

转译规则：

```text
剧本语气 / 神态 → 表情来源 → 表情功能 → 表情占用时长 → 景别 / POV 替代表达 → 画面内容里的可见表演结果。
```

不要把“忍着哭”“压着火”这类抽象词原样丢进正式提示词后就结束。必须参考 `02_共享资产库/02_视觉语言资产/人物表演库/人物表演提示词规范.md` 和 `人物表情与肢体动作词典.md`，写成模型能生成的眼神、眉头、嘴角、嘴唇、下巴、呼吸、肩膀、手指、停顿、声音状态和身体距离。例如 `奶奶（忍着哭）` 要落成眼眶发红、内眉上抬、嘴角压住、吞咽、手指轻抖、说话中间短暂停顿；`父亲（压着火）` 要落成眉头压低、下颌绷紧、嘴唇压紧、声音低、拳头收紧、呼吸压住。

如果当前镜头是第一人称 POV、背影、远景、遮挡或角色不露脸，不能因为看不到脸就丢掉剧本神态标注。要把表情转译成 POV 可见 / 可听的替代表现：手部攥紧、指节发白、呼吸突然停住、声音发紧或压低、肩背僵住、衣角被攥皱、门缝里的侧影、玻璃 / 水面 / 金属反射里的眼神、脚步停顿或道具被握紧。注意：这条只适用于 POV、不露脸、背影、远景、遮挡或道具证据镜头；如果当前镜头本来能看见脸且主任务是表情，就优先写脸、眼神、嘴角、呼吸和肩颈，不用手部替代表情。

人物、场景或道具需要跨多个独立生成分镜保持同一个具体外观时，必须先判断是否有资产支撑。人物外观一致性优先依靠图片资产；文本资产只能固定类型、妆造和气质，不能保证同一张脸。

视频提示词阶段允许并且必须反向触发资产补充。前期视觉资产只是第一轮框架；当正式视频提示词写到具体镜头时，若发现某个场景、道具、动线、空间尺度或关键物件需要连续出现，或者本镜虽然能文字描述但下游生成风险高、空间关系模糊、年代容易跑偏，就不要硬写成“参考”糊过去。处理顺序：能作为一次性画面元素解决的，在 `【画面内容】` 里写细；需要跨镜头稳定或会影响剪辑连续性的，暂停并回到 `laohu_visual_assets` 补充资产，再同步分镜表和视频提示词引用。补充后必须告诉老胡新增资产编号、资产名、文件位置、服务镜头和它解决的生成风险。当前案例：E1-S9-C1 到 E1-S9-C3 的放学路连续承担肩带滑落、突发报丧、姐姐奔跑中甩落书包和小安追不上，`S4 放学路 / 村口` 应从单镜头参考升级为正式场景资产。

人物资产在视频提示词里要拆成“稳定身份参考”和“当前场景状态”。稳定身份参考优先用 `【形象参考@xx】` 调用人物设计资产图片，用 `【音色参考@xx】` 调用音频参考；当前状态包括本镜穿什么、是否睡着 / 刚醒 / 外出 / 上学 / 戴孝 / 躲在被窝、鞋是否在脚上、书包是在身上还是在床边 / 膝盖上，以及本镜声音是否哭腔、病弱、喊叫、压低、电话失真或 VO 回响。除非服装本身是品牌要求、校服制服、戏服、丧服、固定定装或连续性强依赖，否则不要把资产表里的默认服装机械复制到每条提示词。睡觉镜头写睡衣、秋衣、赤脚或被窝遮挡；起床镜头写从睡衣 / 秋衣过渡到外出服；车内和老家白天再写外出棉外套、裤鞋和书包；丧事段写素色衣服、孝布和仪式状态。

人物资产里的场景配件不能被机械继承。书包、雨伞、帽子、孝布、围裙、工具包、篮子、打火机、毛巾、药碗等如果只服务某个场景或动作，正式视频提示词必须按本镜状态重新声明它是否出现、在谁身上、在手里、在桌上还是完全不在画面内。资产参考图里出现书包，不等于这个角色在吃饭、包汤圆、睡觉、丧事、病床或结尾都背书包。当前案例：A5 姐姐在 E1-S6 包汤圆、E1-S7 饭桌里要写“在家里，不背书包”；E1-S9 放学路才写“背书包 / 报丧后奔跑中扯下肩带并甩落书包 / 小安捡起姐姐书包”。

POV 写法必须锚定具体人物资产。已经确认主观视角来自小安时，正式提示词要写 `小安第一人称 POV`、`小安视角`、`小安坐在后排的第一人称 POV`，不能只写 `儿童 POV`、`孩子视角`、`儿童低机位`。类别词只能作为补充说明，例如 `小安第一人称 POV，儿童身高低视线`。这样可以避免模型把镜头生成成第三人称儿童画面，或把 POV 主体误解成任意孩子。

`【画面内容】` 是观众眼前的镜头结果，不是剧情解释区。第三人称、第一人称、过肩、正反打、插入镜头和空镜都要写出当前真正可见 / 可听的结果；前景、中景、背景、视线方向、动作方向和声音来源只写本镜存在且承重的部分。

正式正文还必须逐句通过 `屏幕可观察性检查`：句子只能描述画面内可见的对象与变化、成片可听的声音，或观众能直接感到的景别、构图、屏幕方向、焦点、透视、地平线、遮挡和镜头运动结果。`她判断对手失衡`、`借对方拉力脱困`、`完整兑现主动权`、`镜头让观众理解她镇定` 都是内部因果或评价；改成 `对手右膝滑向坡下，双手中的链条随之松弛；她抬起左脚，身体从链线内侧穿过`。每轮初稿完成后，把每句当作已经生成的视频复述：陌生观众能否在屏幕上指出这句话对应的证据；不能就重写。

摄影路径与正式画面分层处理。导演内部可以使用轨道、摇臂、机身、Dolly、Pan、Tilt、Zoom 推导，但正式 `【画面内容】` 不把观众看不见的设备当主语。错误：`机身沿右前方弧线靠近`。正确：`镜头保持在交战轴线右侧，沿她右前方弧线靠近；人物由全身扩大到胸部以上，背景刺客逐渐虚化，焦点落到剑身、双手和眼睛。`画外事件只有通过声音、光影、影子、反射、飞入物、遮挡变化或画内人物反应留下证据后，才能写进本镜。

正式模型正文不能写角色心理解释、潜台词或未说出口的具体词。小说 / 剧本可以写 `像把没事两个字吞回去`、`想替对方找理由`、`像想解释或反驳`，但视频模型会把 `没事`、`理由`、`解释`、`反驳`、`话` 这类词当成可发声内容、字幕或画面文字。正式 `【画面内容】` 只能写屏幕证据：嘴唇微张又合上、喉咙吞咽、呼吸停半拍、眼眶水光、嘴角硬撑、下巴绷住、肩线塌下、没有发出任何声音。当前案例：《30秒钟带你体验谈恋爱》VID-09 从 `像把没事两个字吞回去` 改成 `嘴唇微微张开又合上，没有发出任何声音，脸上显出十分委屈却还在强撑的状态`。

正式视频提示词要优先使用“镜头主语”的导演语言。`【画面内容】` 不是小说旁白，尽量用 `镜头中出现...`、`镜头固定在...`、`镜头推进到...`、`镜头摇移到...`、`镜头下压到...`、`镜头抬起后...`、`镜头被...遮满`、`镜头从...掠过`、`镜头停在...`、`镜头后方传来...` 这类可执行摄影句式。尤其是 POV、遮挡转场、动作转场、推拉摇移、插入特写和复杂调度镜头，必须让“镜头”成为动作承载者，而不是只写“视线看到 / 画面呈现 / 小安觉得”。这样模型更容易理解这是拍摄结果，不会把文学叙事补成第三人称人物。

错误写法：`视线停在爷爷遗像上，视线慢慢低下，蒲团纹理越来越清楚。`  
正确写法：`镜头固定在爷爷黑白遗像照片上；亲戚提醒后，镜头缓慢下压，蒲团粗布纹理从画面下方推近并逐渐占满整个镜头。`

错误写法：`转场后回到同一张遗像桌方向的画面。`  
正确写法：`转场后镜头仍是满屏蒲团纹理；随后镜头缓慢抬起，遗像桌、旧墙、白布和蒲团前沿重新进入同一位置。`

正式视频提示词代码块里禁止写作者意图、观众理解目标、防误读说明或生成流程解释。`让观众懂`、`表现孩子不冷漠`、`避免误读成马上去世`、`禁止把小安拍成冷漠`、`镜头停顿足够让观众看见忍哭`、`发给模型时模型不知道上下文` 这类句子不是画面，而是作者解释或流程解释；只能放在分镜表、连接检查、自检或复盘里。进入 `【基础设定】`、`【场景状态与氛围画质】`、`【画面内容】` 时，必须翻译成屏幕证据，或直接补全本条提示词所需信息：人物做了什么、物件怎样压近、脚步怎样停、呼吸怎样乱、眼睛和手指怎样变化、衣服或视线高度怎样标记时间。当前案例：E1-S9-C3 不写 `画面让观众懂孩子不懂，禁止把小安拍成冷漠`，应写 `两个书包压在胸前，短脚步追几步后停住，镜头后方只有急促呼吸和短短喊声，视线茫然停在姐姐跑远的转弯处`。如果担心单条提示词缺上下文，不写 `模型不知道上下文`，而是把角色身份、场景、道具数量、动作起点和声音状态写完整。

画面内容不能泄露作者上帝视角。写提示词前必须区分：作者知道什么、角色知道什么、观众此刻能看见什么、模型应该生成什么。隐藏在物体内部、角色心里、未来剧情、尚未揭晓身份或后续承诺里的信息，不能提前写成当前可见画面。当前案例：硬币已经被包进汤圆后，E1-S6-C4 下锅转场只能写完整白汤圆、糯米皮、水汽和勺子，不能写可见硬币、露馅或“藏硬币的汤圆混在其中”。如果需要保留剧情信息，只能写 `内部不可见`、`外观完整`、`观众此刻只能看见白汤圆`。

资产名和资产行也不能携带错误主视觉锚。模型会把资产名、资产行和参考图里的高权重名词当成最终画面目标；如果资产名叫 `硬币汤圆`，资产行又写 `小面值硬币`，即使后面写 `内部不可见`，模型仍可能把硬币贴到成品汤圆表面。正确做法是把当前可见外观和隐藏 / 揭露物分开调用：成品汤圆写 `P4 元宵完整白汤圆：连续完整白糯米皮，表面只有糯米水光和轻微手搓纹理`；硬币写 `P10 元宵小面值硬币：只在包入前、吃出后、爷爷递出时可见`。当前镜头如果只看见完整白汤圆，基础设定和画面内容都不要把硬币写成汤圆外观的一部分。

正式写 `【画面内容】` 前先解决观众最终看见什么、主要感到什么、这个画面为什么成立。画面来源、观众站位、镜头关系、空间层次、视线方向、动作方向和剪辑停点是候选判断项；只选择当前镜头真正需要的部分。判断完成后，把结果写成可见画面，不在正式提示词里暴露内部标签。

通用写法：第三人称客观镜头可以写人物完整身体、站位和表情；严格 POV 要写眼前遮挡物、身体局部、其他人物局部和视线运动；过肩镜头要写谁的肩背虚化在前景、谁在中景、视线越过哪条肩线；正反打要写左右关系和相对视线；插入镜头要写道具占画面的位置、手或光如何进入。禁止把剧情摘要直接塞进 `【画面内容】`，例如只写“父亲责备孩子”“两人争执”“主角听到消息后震惊”；必须把它转成屏幕结果，例如父亲下颌绷紧、孩子眼前的书包带晃动、碗沿反光停住、声音从画外压下来。

严格 POV 必须先写清“画面呈现视点主体眼前所见的画面结果”，而不是写“镜头等同眼睛位置”。`眼睛位置` 是物理摆位，会诱导模型去想一台摄影机贴在眼睛上，甚至生成眼睛、脸部边缘或第三人称低机位；`眼前所见` 是屏幕结果，会把模型注意力拉回观众真正看见的画面。正确写法是 `小安第一人称 POV，画面呈现小安眼前所见，视线高度约 6-7 岁儿童低视线`、`男主第一人称 POV，画面呈现男主趴桌时看见的桌面、前排背影和试卷靠近过程`。这类句子里的角色名用于说明画面来自谁的感知结果，不是把角色作为画面里的被拍对象。写完来源后，后续画面内容仍要写眼前可见结果和身体感：肩膀被推则画面轻微摇晃，趴桌呼吸则低位画面微抖，试卷放到桌面则纸张靠近画面、油印字逐渐清晰，叹气从画面后方响起。

严格 POV 不只贴 `POV` 标签，但也不套全字段公式。不可省略的是画面来源：正式提示词先用具体人物说明 `小安第一人称 POV，画面呈现小安眼前所见`；再从身体局部、近眼遮挡、呼吸 / 步伐造成的画面运动、视线高度、头部转动后的屏幕变化、镜头后方声音、互动对象朝镜头动作中选择足以证明来源的证据。环境光影、焦段、景深、画幅和介质只有改变观看结果时才补充。

POV 前景锚点是高效证据之一，不是每镜必填。小手、袖口、膝盖、握住的道具、方向盘、被沿、眼镜边框等可以证明身体位置；如果它会遮住主情绪证据或破坏本镜纯净凝视，可以不用，改由呼吸 / 步伐造成的画面变化、近眼边缘遮挡、镜头后方声音或互动对象直视并朝镜头动作来证明来源。

POV 稳定方式从身体状态、运动方式、观看任务和主情绪共同推导。平稳、呼吸微动、短步轻晃、短促颠簸和短暂虚焦都是候选；治愈、紧张、儿童或病弱不自动绑定某一种效果。被选中的晃动必须有身体原因并保留关键落点。

POV 头部 / 视线运动必须写成眼前画面变化：低头看下方蒲团纹理、抬头看遗像桌、缓慢转向门口、向左环顾街边、被人推一下导致画面轻晃、伸手向前触碰物件、缓步向前使地面和前方主体靠近。不要写 `小安转头 / 小安抬头 / 小安停住` 作为外部动作摘要，要写 `镜头从门框甩向窗边并停住`、`画面缓慢抬到父亲下巴和手里的外套`、`两只小手伸向画面前方`。

POV 光学质感从角色能看见多少、注意什么、身体如何运动和主情绪是否需要失真反推。焦段与景深不负责证明 POV，也不固定为某组“人眼等效”参数；广角、长焦、深景深、浅景深或短暂失焦都可以使用，但必须产生当前角色感知所需的空间、注意力或失真结果。

外部 POV 公式里的“负面词收尾”不能照搬进本项目正式代码块。正式模型正文优先写正向画面；如果需要边界，只写抽象质量边界，不把当前镜头不该出现的具体对象反复写进模型正文。具体跑偏对象、风险和不该出现的剧情物，放到提示词外自检、回传字段或失败经验里。

严格 POV 不能把 `正面 / 背面 / 侧面 / 正面构图` 这类资产视角词松散接在 POV 主体后面。资产设计阶段可以写人物正面、侧面、背面，因为那是在做外部制作参考；正式视频提示词里的第一人称画面不是拍摄 POV 主体这个人，而是呈现 POV 主体眼前所见。如果写 `小安第一人称 POV 低视线正面`，模型可能把“正面”理解成小安的正面，于是生成小安的脸或身体，第一人称就失败。正确做法是把方向绑定到画面对象或空间锚点：`小安第一人称 POV，面向遗像桌方向的低视线构图`、`视线停在爷爷遗像上`、`画面朝向车前排和挡风玻璃方向`、`视线沿放学路家方向追向姐姐背影`。一句话：POV 里不写“视点主体的正面”，只写“视线朝向哪个物件 / 哪个空间方向”。

严格 POV 还必须做互动视线检查。只要画面里的其他角色正在和 POV 主体说话、递物、牵手、触碰、安慰、责备或观察，正式提示词要写清他们的视线、手和身体方向与镜头发生关系：看向镜头、朝镜头低头、手伸向镜头前方、物件递到镜头前、身体压近镜头。不要只写 `奶奶蹲低摸袖口`、`爷爷笑着说小安来喽`、`父亲递外套`，要写成 `奶奶蹲到镜头高度，眼睛看向镜头，手伸到画面前方摸袖口`、`爷爷视线对准镜头，朝镜头笑着招呼`、`父亲把外套递到镜头前方，外套边缘压近画面`。这能防止模型生成画面里另一个小孩，让角色看向那个小孩。

严格 POV 不能用群体外部关系词和第三人称动作摘要。`姐弟俩`、`小安和姐姐`、`村民看到姐弟俩`、`小安抱书包追姐姐` 这类句子会把视点主体重新放进画面，让模型生成旁观镜头。POV 写法要把关系翻译成眼前可见结果：前方姐姐背影、迎面村民的旧外套 / 锄头 / 视线、画面下方袖口和书包带、地上书包、两只小手伸进画面、书包抱起后遮挡半个视野、呼吸从镜头后方响起。当前案例：E1-S9-C2 不写 `村民看到姐弟俩`，写 `村民从左前方走近，视线朝镜头和前方姐姐扫过来`；E1-S9-C3 不写 `小安弯腰把姐姐书包抱起来`，写 `视线压到地上书包，画面下方两只小手伸出去，书包被抱起后挡住半个画面`。

主观镜头必须做“视点主体语法检查”。

通用规则：这里的视点主体可以是小安、父亲、爷爷、主角、观众、第二人称里的“你”，也可以是任意角色或生物。只要镜头被定义为第一人称、主观视角或某人所见，`【画面内容】` 就不能把这个视点主体当成一个被外部摄影机观察的人来写，也不能用“镜头等同眼睛位置”“摄影机绑定眼睛位置”“机位在某人眼睛上”这类物理机位描述替代画面结果。画面主语优先是眼前、画面、视线、光、遮挡物、手、袖口、脚尖、胸前衣料、门框、窗框、道具、其他人物局部和声音来源。

错误写法：`视点主体 + 躲 / 看 / 听到 / 停住 / 皱眉 / 转头 / 站起来 / 表情怎样`。例如 `小安躲在被子后面`、`父亲看见门口的人后皱眉`、`主角听到声音后停住`、`你转头看向窗外`。这些句子会让模型去拍视点主体本身，或者生成一个旁观者看着视点主体动作的镜头。

正确写法：把视点主体动作转译成感官结果和画面变化。`揉眼` 写成“手擦过画面边缘，画面短暂虚焦”；`往后缩` 写成“前景遮挡物抬高，画面被遮住一部分，声音变闷”；`盯住对方` 写成“视线停在对方胸口、下巴、手或道具上”；`突然停住` 写成“画面静住，呼吸声断半拍，手指僵在前景”；`转头` 写成“画面从门框甩向窗边并停住”。不要写 `镜头等同小安眼睛位置`，要写 `画面呈现小安眼前所见`；不要写 `机位高度等同男主趴桌视点`，要写 `画面呈现男主趴桌时看见的低位桌面、前排背影和试卷靠近过程`。

当前案例：小安床上 POV 不写 `小安躲在被子后面，小安听到后停住`。正确写成：`眼前先是朦胧的天花板和被窝边缘，两只穿浅色睡衣袖口的小手从画面下方伸出来，抓住被沿往上拉，棉被遮住画面下半部；门口冷光从被沿上方照进来，一个穿深色夹克的中年男人局部身影进入画面。` 如果镜头需要表现视点主体的脸部表情，应改成 `贴近视点主体的旁观低机位`、`近主观肩后镜头` 或 `第三人称近景`，并重新写清前景、中景和背景。

正反打、过肩和内外打必须写清空间关系。正反打要先确定轴线和左右关系，例如小安在画面右侧、父亲在画面左侧；反打时两人视线方向相对，不让两个人都看向同一边。过肩镜头要写清谁的肩背在前景、谁在中景、谁看向哪里。内打外 / 外打内要写清摄影机在门内、门外、车内、窗外还是桌子哪一侧。所有这些都要落成画面里的前景遮挡、中景动作、背景空间证据和视线方向。

`【画面内容】` 应优先写当前镜头能看见、能听见、能感到的正向结果。严格 POV 中，镜头不是“拍某个视点主体”，而是“这个视点主体眼前的世界如何变化”：遮挡物怎样进入画面、手或道具怎样进入眼前、光怎样照进来、其他人物局部怎样压近、物件怎样盖住镜头、声音怎样从画面外或遮挡物后方传来。其他镜头也一样：客观镜头写观众在旁边看见的人物完整调度；过肩写肩背前景和对方表情；正反打写相对视线；空镜写空间、物件、光影和声音如何承载情绪。边界判断放在提示词外自检；正式代码块里写“画面出现什么”。如果确实需要边界，只写抽象质量边界，不把当前镜头不该出现的具体对象写进模型正文。

多人、多物、复杂空间或存在交互的镜头，正式写 `【画面内容】` 前必须先建立“场景关系图”；单主体静态表情、单物特写和简单空镜只锁定主体、观看位置与必要空间锚点。关系图不是正式字段，只解决当前实际存在的位置、遮挡、视线、接触和运动关系，不为填表强加前景 / 中景 / 背景或门窗桌墙。错误写法：`女生拍男生肩膀，男生吓一跳，拉着走。` 正确写法：`镜头中男生站在画面中间偏左，女生从画面右后方绕到他背后，右手从男生右肩后方轻拍肩头；男生右肩向上一缩，身体向画面左前方小幅后撤，嘴型停住，女生随后拉住他的手腕往画面右侧带走。`

凡是画面里出现交互，必须说明交互方式、接触点、作用力大小轻重、方向和可见结果。交互包括人物和人物、人物和物品、物品和物品之间的触碰、递接、牵拉、推开、拍打、扶住、压住、拖动、碰撞、遮挡、承重、滚动、折叠、反弹、碎裂、晃动和变形。不要只写 `推 / 拉 / 拍 / 撞 / 拿 / 放 / 坏了`，要写哪只手或哪个物体接触哪里，力度是轻拍、突然一拽、双手用力、缓慢托住还是短促撞上，力从画面哪一侧指向哪一侧，受力后肩膀、手腕、碗、凳子、木轮、布料、液体、影子或镜头发生什么变化。轻微作用力也要可见：轻拍导致肩膀一缩，碗沿汤水晃一下；较重作用力要写承接边界：后退半步、脚跟撞凳、手撑地、物件滚到墙脚。

凡是有运动，必须写清运动方向、路径和终点，并让运镜配合观众看懂。人物移动、道具滑动、手伸向某物、镜头推进 / 后拉 / 横摇 / 下压 / 升镜，都要写从哪里开始、沿什么路径、经过哪些前景 / 中景 / 背景、往哪里结束，屏幕左 / 右 / 前 / 后的稳定参照物是什么。镜头运动要承担展示关系的职责：推镜用于让接触点和表情变清楚，拉镜用于露出人物和物品的空间关系，摇镜用于从一个对象扫到另一个对象，升镜用于从局部关系揭示整体布局。不能只写 `镜头跟随` 或 `镜头拉远`，要写它跟谁、拉到什么范围、最终让观众看见哪些人物和物品的位置关系。

局部光影承担主情绪、动作可读性或空间变化时，才进入场景关系判断，并只写关键光源、方向、受光对象和可见结果；不要求同时补高光、阴影、反光、轮廓和丁达尔。错误写法：`温馨光影，画面很有氛围。` 正确写法：`女生靠近男生背后时短暂挡住右侧窗光，男生脸侧亮面暗了一下，让被打断的节奏更明显。`

面向观众且承担视觉记忆的镜头，应设计“审美停点 / 情绪停点”：暂停后仍能把主情绪传清的画面瞬间。它不要求同时拥有前中后景、留白、完整色彩层级、复杂光影和材质细节；只选择能承重的要素。功能型插入镜头、动作连接镜头和信息证据镜头不强制壁纸帧，只需在任务完成处形成清楚、可剪辑的停点。不能为了截图价值破坏本镜情绪或动作节奏。

壁纸帧优先从剧情本身长出来，不靠无关滤镜和漂亮空镜硬凑。家庭纪实镜头可以是门框包住父亲递外套的剪影、饭桌暖灯下手和碗形成的三角构图、蒲团粗布纹理与遗像玻璃反光的冷灰停点、院子里木车和纸灰在傍晚光里的留白；喜剧镜头可以是女生从男生背后探出嫌弃脸、男生被拍肩后嘴型卡住的表情停点。错误写法：`画面温馨好看，有电影感。` 正确写法：`镜头轻轻后拉后停住，男生在画面中间偏左，女生站在他右后侧半步，右侧窗光勾出两人肩线，背景木门和墙面虚化成暖黄块面，画面左上留出一块安静空白，像一张生活喜剧海报。`

构图、光影、色彩以及后续所有审美模块，都不能被当成封闭词表。老胡给出的三分构图、黄金一小时、莫兰迪、青橙、胶片棕调等都是启发样例，不是固定菜单。正式写提示词时要先判断本镜的剧情情绪、时代背景、空间材质、人物肤色、道具颜色、光源类型、壁纸用途和剪辑连续性，再选择或组合合适的审美方案。正确做法是从底层目的扩展同类可能，例如构图可以继续扩展到层叠构图、纵深透视、色块构图、剪影构图；光影可以扩展到火光主光、雪地反光、霓虹湿地反射；色彩可以扩展到黑白灰单色、褪色老照片、煤油灯暖褐、山城雾灰绿等。不要机械照抄用户列举词，也不要把未列出的有效搭配排除掉。

构图承担主情绪或信息引导时，才选择明确构图结构并写成主体落点、视线方向和空间关系。三分、黄金分割、中心对称、框架、引导线、对角线、留白、前景框或三角关系都是候选，不要求每镜点名专业术语；只写 `构图好看` 仍然无效。

写构图时先定视觉落点，再按需要选择导引线或块面压掉无关信息。点、线、面是开放控制杆，不是三项必填：简单特写可以只有明确的点，极简空镜可以主要靠面，动作镜头可以靠运动线。只要选用，就要说明它怎样把注意力和主情绪收拢到同一目标。

透视和灭点只有在承担空间压迫、尺度、方向或视觉重心时才展开。单点、两点、三点和画外灭点没有固定情绪含义，必须结合人物处境和空间结果判断；不需要纵深信息的脸部特写不为展示摄影知识硬写灭点。

点的写法要回答“观众第一眼看哪里”。主体居中、偏置、靠边或被部分遮挡都会改变画面平衡与信息范围，但不自动等于稳定、呼吸或孤独。干扰很多时，从面积、亮度、清晰度、颜色、运动或声音中选择足够的主次差，不要求全部加强。

线的写法要回答“视线从哪里来、经过哪里、停在哪里”。主体在线条起点、途中或终点会改变观看顺序，但实际情绪由人物处境、速度、构图密度和声音决定。斜线、曲线、水平线、垂直线和 S 形线首先改变方向感与节奏，不固定对应冲击、温柔、稳定或庄重。

面的写法要回答“用哪块空间压住杂乱”。当背景信息多、颜色杂或主体不突出时，用大面积暗部、天空、海面、墙面、虚化绿植、雾气或石墙形成干净块面，让主体只占一小块但更醒目。正确写法：`画面左侧三分之二被深绿色虚化树影压成干净暗面，右侧三分线留出柔金亮面承接人物侧脸`。不要把面写成空泛的 `背景虚化`，要写它占画面比例、颜色 / 明暗、压掉什么杂质、如何托出主体。

审美停点可以使用信息留白，但必须写清遮蔽比例和读点。可见读点通常是眼睛、嘴角、唇峰、鼻梁、下颌线、耳坠、项链、锁骨、手指或道具边缘；遮蔽物可以是发丝、树影、窗帘、门框、玻璃反光、帽檐、暗部、烟雾或前景花枝。不要只写 `神秘感`，要写 `遮住哪里、露出哪里、光勾出哪里、观众靠哪个局部补全人物`。如果本镜核心是表情爆点，局部遮蔽只能短暂出现，停点必须回到清楚表情。

留白、平衡和边角清洁只在它们加强主情绪、主体识别或剪辑用途时写入。稳定不是唯一正确状态：恐慌、眩晕和失控可以有意破坏平衡，但必须是情绪选择而不是生成事故。

画幅比例先服从发布平台、主体形态、空间方向和裁切需求。16:9、21:9、3:4、9:16 和方形只提供不同边界，不规定必须留白、全身、均衡、中心或对称；同一画幅可以拥挤、偏置、极简或失衡。只有镜头承担封面或壁纸职责时才额外检查裁切与标题空间。

光影承担主情绪、主体塑形或动作可读性时，按需从时段、方向、软硬、明暗层级、反光和材质反应中选择承重项。自然光如果已经足够准确，可以只写来源和关键受光结果，不强制主光、辅光、轮廓光全部出现。

时段光线承重时要具体到真实来源、方向和受光结果。黄金时刻、日出、蓝调、正午硬光、阴天漫射、雨后天光、窗光、门缝光、火光和旧灯泡都是候选；没有一种天然更有壁纸感或更适合生活戏。`白天自然光` 若已足够说明非承重背景可以保留，只有光影承担主情绪或塑形时才继续展开。

需要光型分层时，先确定哪一层真正塑造主体或主情绪，再补必要的暗部可读性与分离关系。单一硬光、剪影、近无辅光或平光也可以成立，只要它是有意选择并且不会损害本镜需要看清的证据；不能为了凑层数添加无来源高亮和装饰反光。

动态视频里的光影必须稳定。AI 常会为了“有变化”让光源乱闪、主光位置跳变、阴影方向前后矛盾。正式提示词要写清关键镜头内光源不跳变，例如 `全程保持同一扇窗的侧逆光`、`镜头后拉时光源方向不变，人物移动只短暂遮住脸侧亮面`、`火光可以轻微跳动，但主光仍来自火盆下方，背景暗部保持低对比层次`。如果一条镜头抽帧后光影破碎，通常不是模型单独问题，而是提示词没有锁定光源、阴影和反光关系。

色彩承担主情绪、身份识别或连续性时，按需选择主色、辅助色、点缀色、饱和度、明度、环境反光或分级。不是每镜都需要完整色彩体系；单色、近无色或自然综合色同样可以成立，只要情绪方向清楚。

色彩母体按人物处境、真实光源、场景材质和主情绪选择，不按丧事、病床、饭桌或放学路套固定色谱。冷灰、暖黄、黑白、高饱和、多色冲突和自然综合色都可以成立；要说明颜色落在什么对象上、怎样分配注意力，以及为何不会把主情绪带偏。

色彩还要写出色彩透视。近景可以更暖、更清晰、更有肤色血色；远景可以更冷、更低饱和、更轻微雾化；前景点缀色可以小面积抢眼，背景主色负责收敛。提示词要写 `近景人物肤色暖白清透，远景山海偏冷灰蓝并降低饱和度，海面反光把冷色轻轻带到脸侧暗部`，不要只写 `清新蓝绿色调`。影调也要写出影调透视：高调、低调、硬调、软调、亮部、半暗面和暗部如何排列出空间深度；动态范围不是全部保留才高级，必要时可以牺牲局部暗部或高光细节，让主体和情绪更集中。

色彩要有清楚权重和过渡，但不固定为 `1 个主色 + 1 个辅助色 + 1 个点缀色`，也不默认低饱和等于高级。单色、综合色或有意冲突的多色体系都可以使用；真正要避免的是多个高权重颜色无目的地争抢主情绪和注意力。环境反光和色彩渐变只在真实存在并承担统一职责时写入。

色彩滤镜和分级要服务统一，而不是廉价套滤镜。可以写富士胶片色调、柯达金 200 暖调、电影 LUT 调色、轻微暗角、胶片低饱和、低对比度色彩分级、暗部偏冷高光偏暖、整体褪色老 DV 统一色偏等；但必须绑定画面结果：暗部是什么颜色，高光是什么颜色，肤色是否自然，墙面和衣料是否被同一环境色包住。动态镜头中同一场景色彩分级要保持一致，不能一会儿高饱和、一会儿冷灰、一会儿现代广告色。

如果作品建立了色彩风格资产，`【基础设定】` 引用 `【@C1 色卡名】`，`【场景状态与氛围画质】` 用一句色卡锚定句压缩全段主辅色、肤色基线、暗部倾向和高饱和点缀边界；正式投喂正文不能只写“调用色卡”。

颜色映射必须跟随对象实际出现的连续画面段落写进 `【画面内容】`，把四组色卡落到真实可见对象：整体光线、主角服装部位、肤色、发色、墙面 / 屋顶 / 地面 / 门窗、关键道具、雾气 / 烟雾 / 空气透视 / 暗部 / 阴影 / 高光分别调用哪些 HEX。切换到新空间时，再沿切换桥梁补充新出现对象的颜色，不按镜头编号单独重启色彩说明。

色卡使用要遵守 `母色卡不变，阶段变体受控变化`。同一场景和同一段连续镜头不要每条随机换色；情绪变化也不要靠完全换一套颜色来硬转场，而是从母色卡里调整明度、对比、暗部冷暖、点缀色面积、环境反光和阴影重量。当前案例：海边恋爱短片可以用 `C1 清新海边母色卡`，前半段蓝绿更清透、肤色更明亮，后半段仍是同一海面和树影体系，只降低明度、扩大冷灰暗部和负空间，让美景变得不再轻盈。

颜色映射不能为了完整而硬填本镜没有出现的资产。没有出镜的道具、服装部位、墙面或烟雾不要写进正式代码块；但只要它出现在画面里并影响观感，就必须绑定色卡 HEX，不能让模型自动改成另一套高饱和色调。

景深与空间层次承担主情绪、空间因果或注意力控制时，按需选择前景遮挡、中景主体、远景环境、焦段、焦点或空气透视。深景深、平面化和无前景也可以是有意选择，不强制前中后景齐全。

焦段从视野范围、摄影机距离、透视夸张 / 压缩、主体占比、背景信息量和主情绪反推，不与人像、POV、亲密或疏离固定绑定。35mm、50mm、85mm、135mm、微距、准广角和长焦都只是物理选择；写入时说明它怎样改变脸部比例、空间距离和环境可读性。

景深控制要和剧情信息匹配。人物情绪、手部道具和遗物停点可以使用极致浅景深、主体清晰锐利、背景柔和散景；群像、仪式、空间关系和动作因果需要中等景深或深景深，不能为了好看把关键信息虚掉。前景虚化要服务遮挡和层次，例如 `画面左侧门框虚化成暗边，中景爷爷手里的布巾清晰，远景饭桌灯泡柔成暖黄光斑`；不要让前景虚化遮住关键动作，也不要让焦点在镜头中随机漂移。

动态镜头只有在焦点承担注意力迁移、证据可读或连续性时才写对焦过程。焦点可以稳定锁定、主动转移、短暂失焦或保持深景深；关键是变化有触发并服务主情绪。需要转焦时写清从哪里到哪里、何时锁住；不承重时不为专业完整强加焦点动画。

画质和材质先保证主体、动作证据与情绪证据可读。只有材质承担身份、触感或剧情时才展开纹理；运动模糊、颗粒和边缘锐度按情绪与用途控制，不为“高清”机械堆微细节。

材质词必须落到具体物件，不能空堆。哑光柔和质感适合旧墙、棉衣、孝布和纸房子；磨砂低反光适合旧瓷、旧木、玻璃柜台边缘和年代道具；丝绒柔和肌理适合少量衣料或暗部质感；金属细腻拉丝、旧金属磨损和克制反光适合硬币、旧钥匙、锅沿和工具；水雾朦胧质感适合灶房水汽、雨后空气、火盆烟气和蓝调时刻；细腻胶片颗粒或老式 DV 轻微频闪噪点必须受控，服务年代记忆，不破坏主体边缘和材质细节。

截图用镜头必须控制运动模糊和画面洁净度。动作镜头可以有少量方向性模糊来表现速度，但审美停点要极低运动模糊、主体边缘稳定、关键手部和道具清楚；不能让大面积动态拖影、AI 多余虚影、边缘崩坏、肢体扭曲、杂点脏污、压缩糊块、随机文字或水印毁掉截图。正式提示词要写成正向画面结果，例如 `木轮转动后逐渐慢下来，镜头停点极低运动模糊，轮辐边缘和粗糙木轴纹理清晰`，而不是只写 `高清好看`。

氛围环境元素只有在加强主情绪、空间真实或动作反馈时才出现。雾、花瓣、烟尘、光斑和微粒不是质量标配；没有来源或不承担情绪的环境装饰直接删除。

氛围元素必须有来源、有密度、有方向。薄雾来自清晨、雨后、山城湿气、火盆烟气或灶房水汽；光斑来自窗光、旧灯泡、逆光、玻璃反射或水面波光；漂浮碎屑来自纸灰、落叶、糯米粉尘、木屑、火星或窗边灰尘；水面波纹来自雨滴、风、脚步或碗汤晃动。写法要落到画面结果，例如 `旧灯泡斜光照出窗边落尘微光，尘粒只在光柱里慢慢漂，不遮住奶奶的手`，而不是只写 `氛围感很强`。

氛围元素要服务情绪和题材，不能抢戏。家庭纪实和老式 DV 优先轻柔烟尘、窗边落尘、灶房水汽、旧灯泡光晕、纸灰和落叶；丧事和病床适合冷灰薄雾、压低的烟气、火盆纸灰和低密度浮尘；放学路适合雨后水汽、枯草微动、土路尘灰和远处山城薄雾；浪漫或风格化镜头才考虑漂浮花瓣、轻纱透光和明显镜头光斑。氛围元素密度要克制，不能把人物、动作、台词、道具状态和 POV 视线遮掉，也不能让画面变成超现实舞台特效。

镜头运动先服从主情绪和观看任务。稳定、微动、手持、甩镜、旋转或失衡都可以成立；只需写清被选运动的路径、强度和落点，并防止非意图性的漂移与模糊。

运镜速度服务观看意图和主情绪，不以截图停点为唯一标准。固定、慢推拉、低幅摇移、稳定跟拍、快速变焦、连续旋转、甩镜和颠簸都没有固定题材映射；需要读表情、证据或剪辑接口时给清楚落点，纯运动冲击和主观失控可以连续运动，只要关键因果仍可读。

需要观众读表情、事实证据、动作结果或剪辑接口时，镜头要给足可读停留；停留时长由识别、情绪进入和剪辑需要倒推，不固定为 1-2 秒。纯运动冲击、主观眩晕和连续追逐可以一路运动，但关键因果不能被无意模糊。若抽帧全糊或主体漂移，先判断这是有意情绪结果还是生成失控，再决定是否增加稳定约束。

镜头语言动词必须具体。推镜头要写推进对象和停点；拉镜头要写从哪个特写拉到哪个空间关系；摇镜头要写从左到右还是从右到左、经过哪些前景和中景；移镜头要写沿门框、桌沿、车窗、路面还是人物运动方向；下压和抬起要写压到什么材质、抬起后什么物件重新入画；遮挡要写哪种材质遮满镜头、遮挡持续多久、遮挡后的相似近景如何接起。不要只写 `镜头移动`、`镜头切换`、`镜头转场` 这类空泛词。

正式写 `【画面内容】` 前检查景别、机位、运镜和光学质感四类控制杆，但不把它们当四项必填。景别决定容纳多少信息，机位改变尺度、距离和力量关系，运镜改变观看路径，光学质感改变焦点、空间与介质。固定镜头不硬写运镜，简单特写不硬补焦段和前中后景；正式正文只写能加强主情绪、理解、生成稳定或剪辑连续的选择。

景别从观看任务倒推：它决定观众同时读到多少空间、动作、关系、表情或局部证据，不与孤独、亲密、庄重等情绪固定绑定。一个镜头如果承担过多互相争抢的任务，优先删减、拆镜头或写清景别变化。

机位角度必须服务主情绪和视角关系，但没有固定映射。平视、俯拍、仰拍、斜侧和正侧要结合人物处境、距离、尺度与空间结果判断；同一俯拍可以是脆弱、秩序或冷静观察。正反打、过肩、门缝和车内机位存在时，写清必要轴线与遮挡。严格 POV 不能用机位高度替代画面来源，必须写成 `画面呈现某人眼前所见`。

运镜必须写路径、方向、速度、停点和屏幕结果。固定镜头要写构图中哪些对象保持不变；水平摇镜要写左摇 / 右摇、起点、经过物和停点；横移要写屏幕方向与前后景视差；推镜要写主体从什么景别扩大到哪个表情或物件；拉镜要写从哪个局部露出什么环境；升镜 / 降镜要写画面高度变化与最终所见；环绕要写围绕谁、转动角度、背景横移和主体清晰度；跟拍要写跟谁、屏幕方向和路径边界；甩镜要写触发声音、方向残影和清楚落点。不要只写 `镜头移动`、`镜头切换`、`氛围感运镜`，也不要让设备名替代画面变化。

专业运镜术语必须先区分物理机制：Dolly / Track / Tracking Dolly 是机身整体移动；Pan / Tilt 是机身不动、镜头原地转动；Zoom 是焦段变化；Crane 是大幅高低升降；Jib 是小幅近距离升降；Handheld / Bumpy / Breathing Shake / Soft Stabilize 是稳定方式；Orbit / Arc / Match Move 是镜头和主体运动关系；Pass Through / Digital Dolly Through / Time-lapse Dolly / Spiral Dolly / Falling Dolly / Ascend & Dive 是创意或特效运动。正式提示词不能只写术语名，必须写路径、方向、速度、停点、主体关系和情绪任务。

希区柯克变焦 / Vertigo Shot 不是普通推拉。使用时必须同时写 `机身向前推进 + 光学变焦拉远`，并写清 `主体大小基本保持不变，背景空间拉伸畸变`，用于窒息、恐慌、崩溃、对峙或绝望。缺少其中任何一项，模型容易只生成普通推镜、普通变焦或背景随机变形。

光学质感与作品介质和主情绪一致，但没有题材固定套餐。浅景深、深景深、遮挡、光晕、微距、DV、胶片、鱼眼或宽幅都要说明其物理变化与观看职责；90 年代家庭回忆采用 DV 或暖黄色偏只是当前案例候选，不自动覆盖同题材作品。

镜头语言与情绪没有固定映射。平视、慢推、手持、拉远、仰拍、固定机位和深浅景深都只是候选；先确定具体处境和主情绪，再判断它们会让距离、力量、稳定性和信息怎样变化。当前案例：E1-S10-C2 丧事叩首选择固定低视线、镜头下压、蒲团纹理遮挡和冷灰白布，是因为这些手段加强仪式压迫与失去，不是因为“庄重”必然对应固定机位。

通用 AI 视频分层在本项目中只作为开放问题库，不作为正式字段，也不逐层检查齐全。正式视频提示词仍只保留 `【基础设定】`、`【场景状态与氛围画质】`、`【画面内容】` 三块；从镜头、主体、环境、光影色彩、光学和输出规格中选择本镜承重层。

分层职责如下：镜头语言层写景别、机位角度、运镜方式、镜头速度和确定时长；主体叙事层写人物 / 生物 / 物体、外貌穿搭、动作、神态和细微情绪；环境布景层写地点、空间结构、陈设、道具、前景遮挡、中景动作和远景背景；光影色彩层写光源方向、光线软硬、主色调、冷暖关系、光晕、丁达尔和阴影层次；镜头光学质感写焦段、人眼等效 / 广角 / 定焦、景深、散景、暗角、颗粒、畸变控制、胶片 / DV 介质；画幅帧率画质写横屏 / 竖屏、16:9 / 9:16 / 2.39:1、分辨率、帧率、稳定度和细节清晰度。

落入三段模板时，`【基础设定】` 只列实际调用素材和一句声音策略；`【场景状态与氛围画质】` 只写跨全部镜头成立的主风格、摄影介质和宏观色彩基线；`【画面内容】` 按镜头承接景别、机位、运镜、主体表演、环境、本镜光影、HEX 色彩落点、材质、声音、切换和停点。

极简、标准、复杂和氛围公式只作为开放问题库，不按片长或题材自动套用。详细度由主情绪、观看任务、输入资产和生成风险决定：简单镜头只写主体、变化、观看位置和结束状态也可以；复杂镜头按需补空间、受力、光色、声音、材质和连续摄影机路径。外部公式里的“负面规避词结尾”不作为正式正文层级。

遮挡式时间跳切本质上是遮挡转场，必须写清遮挡前、满屏遮挡转场点、转场后的相似遮挡和抬头揭示结果。凡是低头叩首、闭眼、火光铺满、袖口遮镜、门框压暗、被子盖住、纸灰飞起等动作承担时间省略时，不能只写 `切到 / 变成 / 跳到 / 换成`。正式提示词要写：遮挡前眼前是什么；什么材质以什么方式遮满画面；声音如何被遮挡或改变；哪个满屏遮挡近景形成转场点；转场后如何从相似近景继续动作；抬起 / 移开 / 火光退去后，哪些可见物件变了。匹配遮挡转场要谨慎控制变化量：如果目标是制造“同一构图忽然变了”的效果，场景、构图、桌椅、墙面、光源和主要空间锚点要尽量不变，只变化核心对象。当前案例：E1-S10-C2 不写 `袖口、供品、白布、视线高度都变化`，要写 `低头前同一遗像桌前是爷爷遗像，白色孝布遮住画面上沿一点；视线低下看蒲团纹理，蒲团纹理满屏形成遮挡转场；抬头后旧墙、白布、桌面、蒲团位置不变，只有桌中央黑白遗像从爷爷换成奶奶`。

旧话 VO 可以视觉化为二次曝光 / 三重曝光记忆层。凡是亲人遗言、承诺、叮嘱、后悔或旧话回响与火光、纸灰、玻璃反光、水面、旧物、窗帘、烟雾等媒介同场出现时，不要只写 `VO 回响`。先判断是否需要让说话人的形象进入画面：需要时，正式提示词要写清现实层是什么、曝光层叠在哪个区域、透明度和色彩主次、嘴形或动作如何与 VO 对位，以及现实层哪些物件仍然清楚。二次曝光是 `现实层 + 讲话人记忆影像`；三重曝光是 `现实前景 + 情绪媒介 / 前一仪式画面 + 讲话人记忆影像`。当前案例：E1-S10-C4 是火盆纸钱现实层 + 奶奶半透明二次曝光；E1-S10-C6 是纸房燃烧现实层 + 爷爷奶奶火光二次曝光；E1-S11-C2 是 P1/P2 两辆完整木车 + P11 半成品木马车架现实层，叠加爷爷半透明记忆层二次曝光，让小安触摸 P11 悬空后轮和爷爷承诺 VO 对位。曝光人物要像旧 DV 记忆压在现实上，不能写成恐怖鬼影，也不能遮住现实主物。

伏笔道具和病弱提示不能像标签一样插入画面，必须从生活动作链里长出来。正式提示词要先建立人物正在做什么、在哪里、身体怎么停住，再让伏笔打断或改变这件日常事，最后用人物反应自然回到主线。错误写法：`插入药碗，爷爷咳嗽，爷爷推木车出来`。正确写法：`小安坐在老家堂屋门口屋檐下、门槛内侧的小板凳，爷爷蹲在门槛外半步逗他说话，咳意突然上来时立刻偏头避开孩子并抬袖遮嘴；奶奶听见后从身后堂屋里端药出来，催他把药喝了；爷爷故作轻松，伸手牵起镜头前的小手去墙角看木马车`。

病弱状态必须落成可见 / 可听证据链。凡是病床、输液、受伤、虚弱、临终前、刚摔倒后被照护等镜头，不能只写 `病弱 / 虚弱 / 躺床 / 气息略虚 / 轻描淡写`。正式提示词要同时写脸色、唇色、眼皮、额汗、呼吸、说话音量、断句、停顿、动作幅度、手部力量、床单或被角反应，以及药碗、输液管、胶布、照护者表情等外部证据。错误写法：`爷爷躺床上但保持安慰孩子的笑，气息比平时虚`。正确写法：`爷爷半靠旧枕头，脸色偏白泛灰，唇色浅，眼皮沉，额角有细汗；看见镜头后只牵动嘴角，声音低、沙、短，中间轻喘停顿；没输液的手从被沿挪出一点又停住。` 当前案例：E1-S8-C2 必须避免红润脸色和中气十足的声音，让病弱由画面和声音共同证明。

病床触碰动作必须做床侧、输液侧和可达性排练。凡是躺床、输液、虚弱或被照护的人要牵手、摸头、拍手、递物、擦泪或安慰孩子，正式提示词前先判断：孩子站在床哪一侧；输液针扎在哪只手；输液管从哪里走；哪只手靠近床沿；另一只手是否在被子远侧、被身体压住或不可达；病人翻身、抬臂、伸手会不会太费力。不能为了表达亲情，就让病人突然翻身、抬远侧手或跨过身体摸孩子。当前案例：E1-S8-C3 小安站在靠输液手这一侧，想碰爷爷手背胶布又缩回；爷爷不翻身、不抬另一只远侧手，只把床沿附近的输液手小幅度转动，指尖反手轻碰孩子的手，输液管轻轻晃一下。

生活动作必须通过真实行为排练。凡是写咳嗽、打喷嚏、擦伤、端药、递物、牵手、抱起、摔倒、点火、推车、坐下、跨坐、追逐等动作，不能只写动作名，要写人真实会怎么动、怎么避让、怎么受力、怎么影响镜头。尤其当动作会影响孩子、老人、病人或亲密关系时，要符合身体本能和关系礼貌：老人咳嗽会偏头、抬手或袖口遮嘴，不会正对孩子 / 镜头咳；端药要写碗的位置、液体晃动和手部稳定；点火要写风、挡风、火苗和手指反应。错误写法：`爷爷蹲在面前，突然剧烈咳嗽几下`。正确写法：`爷爷蹲在门槛外半步，咳意上来时立刻把脸偏向画面左侧避开镜头和孩子，抬起袖口挡住嘴，咳声闷在袖口里，另一只手撑住膝盖，身体微微转开`。

操作型生活场景必须补齐物料清单。包汤圆、包饺子、做饭、缝衣服、修东西、擦伤口、洗脸、端药、点纸房、收拾行李这类镜头，不能只写“正在包 / 正在修 / 正在做”。正式提示词要先列出真实操作需要的工具、材料、半成品、成品和工作区，再写动作链。桌面、案板、灶台、工具台不能空；如果桌上只有一点点东西，模型会生成摆拍空桌或无法完成操作的画面。当前案例：包汤圆桌面至少要有糯米粉盆、半揉好的糯米团、馅料碗、硬币小碗、已搓好的白汤圆、撒粉区、旧瓷碗和奶奶正在操作的手。

歧义动作必须写清工具、接触方式和顺序。凡是 `加一点`、`取一点`、`放进去`、`抹上去`、`处理一下`、`弄好`、`包起来`、`擦一下`、`倒一点`、`递过去`、`推过去` 这类动作，现实里可能由手、勺子、筷子、夹子、布、棉签、碗、刷子、刀具或其他工具完成时，正式提示词必须写明：哪只手拿什么工具，工具从哪里取材料，工具先碰什么、后碰什么，材料如何被放下 / 压平 / 抹开 / 包住 / 擦掉，工具最后放回哪里，手是否还直接接触材料。食物、药物、伤口、胶水、颜料、火、尖锐工具、儿童和老人相关动作尤其要做卫生 / 安全 / 礼貌排练。当前案例：E1-S6-C2 不能只写 `加一点黑芝麻馅` 或 `用黑芝麻馅盖住硬币`，要写 `右手拿起黑芝麻馅碗边的小木勺，用勺尖舀起一小团馅，勺背轻轻压在硬币上方盖住反光；小木勺放回碗边后，手指只接触白糯米皮并捏合封口`，防止模型生成奶奶用手抓馅。

包裹类、揉捏类、修补类和烹饪类动作必须写材料变形链。凡是画面里出现面皮、馅料、硬币、布料、伤口、木件、纸房子、火柴、汤水等会发生形态或可见性变化的物件，不能只写 `放入`、`加上`、`包好`、`揉圆`、`修好`、`点燃`、`洗干净`。正式提示词要写动作前形态、接触方式、受力变化、边缘如何合拢或分开、内部信息何时隐藏、最终可见结果。当前案例：E1-S6-C2 写硬币汤圆时，要写奶奶左手托压扁糯米皮、右手把硬币平放进浅窝、黑芝麻馅盖住硬币反光、糯米皮边缘往中间抬起并捏褶封口、两掌滚圆；封好后硬币和馅料内部不可见，只剩完整白汤圆。

工具劳动动作必须写工作面、工具、材料、受力和收尾位置。凡是劈柴、锯木、刨木、钉钉、锤打、磨刀、铲土、挑水、洗衣、磨粮等动作，不能只写 `正在劈 / 正在锯 / 正在修`。正式提示词要写清工作发生在哪个稳定工作面上，材料初始状态是什么，工具由哪只手或双手怎样握住，力沿什么方向作用，材料是否卡住、裂开、弯折、溅水或掉屑，失败或重复动作如何继续，成品 / 废料最后放到哪里。当前案例：E1-S6-C3 父亲劈柴不是在柴堆上砍，而是在院子边旧木墩前，把一截短柴竖在木墩上，双手握斧顺木纹劈下；斧刃卡住后连木带斧抬起，再把柴底往木墩上一磕，裂开后第二下分成两半，最后把两半柴放到木墩旁边柴垛上。

儿童使用家具 / 垫脚物也必须做可达性和受力排练。孩子搬、拖、踩小板凳时，要写清是用手抓住凳面或凳边拖动，脚只是随后踩上去；不要只写“小板凳被拖动”让模型误解成脚推、凳子自己滑或镜头向前走。正确写法：`两只小手扣住小板凳凳面两侧，把板凳拖到案桌前；一只小手扶住桌沿，鞋尖踩上凳面，画面升高一截`。

移动动作必须写清方向和边界。凡是滑行、奔跑、追逐、推车、摔倒、冲撞、车辆行驶、人物走位、镜头穿越等移动类画面，不能只写“向前”“滑下”“冲过去”。必须明确：从什么具体起点出发，沿哪条路径或哪条空间线移动，往哪个具体终点去，屏幕左 / 右 / 前 / 后的稳定参照物是什么，正常路径中哪些区域保持通畅，碰撞或摔倒发生在什么合理边界。障碍物不能凭空放在路中央，除非剧情明确就是路中央障碍；生活场景里的碰撞更常见于墙脚、路边石、门槛、桌角、坡底边缘、水槽边、木料堆旁等空间边界。错误写法：`木车从小坡滑下，撞到一块石头。` 正确写法：`木车从坡顶沿坡面中线滑向坡底缓冲区，旧院墙始终在画面左侧，水槽 / 木料堆在画面右侧；试玩孩子控制不好，车头偏向画面左侧旧墙根，撞到坡底左侧贴墙压边石 / 墙脚，路中央保持通畅。`

儿童 POV 与成人尺度道具必须做身高 / 可达性排练。只要画面涉及柜台、桌子、灶台、电话、货架、窗台、车门、床沿、水缸、锅、碗柜、工具、门锁等成人尺度物件，正式提示词前必须先判断儿童身高、视线高度、手臂长度、抓握力量和可操作范围。孩子够不到或操作不了的内容，要改成成人手递下、成人代操作、孩子站在矮凳上、只看到物件局部、通过玻璃 / 反光 / 遮挡看见模糊轮廓，不能让孩子像成年人一样直接平视、拿取、拨号、挂断或俯视桌面。严格 POV 中要写孩子眼前能看见的结果：柜台上沿挡住视线、玻璃反光、主机在高处成模糊黑影、电话线从上方垂下、成人手从上方进入画面。错误写法：`小安趴在柜台边，黑色老式座机、卷曲电话线和硬币占画面中心，听筒被小手放回座机。` 正确写法：`小安第一人称 POV，画面低于玻璃柜台上沿；座机主机在柜台上方只是一团模糊黑影，成人手把听筒从高处递到画面前，卷曲电话线从上方垂下来；通话结束成人手接回听筒，高处传来咔哒挂断声。`

场景描述在存在歧义、走位、交互或连续性风险时，用最少的必要空间锚点消歧。`门口` 可以具体到 `老家堂屋门口屋檐下、门槛内侧`；摄影机侧、主体侧、前中后景、门窗桌墙和光源只在承担动作或主情绪时增加，不为完整全部写入。

多人群像和围桌场面必须先做座位图 / 站位图。凡是饭桌、会议桌、课堂、灵堂仪式、院子围观、家庭合照、群体争执等多人同框镜头，不能只写 `众人围坐`、`家人围在桌边`、`群像环绕`。正式提示词要先确定视点位置、桌子或场地朝向、每个人在画面左 / 右 / 前 / 后 / 近旁 / 远侧的固定位置，再让台词、视线、递物、推搡和冲突沿这个空间关系发生。当前案例：E1-S7-C1 小安坐饭桌近侧中间，爷爷坐小安右手边、画面右前方近旁，姐姐在左侧，奶奶在对面中间，父亲在对面偏右；这样爷爷后面从右前方伸手安慰、小安从下方推向右前方、爷爷向右后方柴火边失衡，空间因果才成立。

冲突动作必须补齐前置动机、靠近路径和身体受力。凡是推开、打断、抢夺、摔倒、撞倒、拉扯、抱住、躲开等动作，不能只写冲突结果。正式提示词要先写被推 / 被撞 / 被抢的人为什么靠近，如何从原位置移动到主角身边，手或道具伸向哪里，主角为什么在这个时刻反应，推力作用到身体哪个部位，后退或摔倒撞到什么合理边界。当前案例：E1-S7-C3 不是爷爷坐在原位被推倒，而是爷爷撑桌起身、从右侧桌边绕到小安身旁、弯腰拿小布巾擦眼泪，小安推开贴近脸前的手腕和胳膊，爷爷后退半步撞到右侧小木凳后跌坐柴火边。

冲突动作改稿必须优先做因果重构，而不是只给结果加形容词。看到 `推开 / 撞倒 / 拉扯 / 抢过 / 摔倒 / 躲开` 这类结果词时，先把旧句拆成六个问题：谁为什么靠近；从哪里走来；手或道具伸向哪里；视点主体为什么在这一刻反应；推力或拉力作用到哪里；后果被什么真实物体接住。然后再写正式画面。错误改法是把 `小安推开爷爷` 扩成 `小安用力推开爷爷，爷爷痛苦跌倒`；正确改法是新增前置安慰动作和可见受力链：`爷爷撑桌起身，从右侧桌边绕到小安身旁，拿小布巾靠近镜头想擦眼泪；两只小手推开贴近脸前的手腕和胳膊；爷爷弯腰重心在前，后退半步撞到右侧小木凳，手撑地跌坐到柴火边。`

年代戏、回忆戏和家庭生活戏必须做“时代物件 / 通信条件检查”。道具会暴露故事年代、家庭条件、城乡差异和人物生活方式。凡是出现手机、电话手表、智能设备、电脑、汽车、厨房、电器、支付方式、照明、交通工具、医疗器械、校服和玩具等时代敏感物件，写入正式提示词前必须判断：故事年代是否存在；该家庭阶层和地域是否合理拥有；人物在当前场景是否能合理接触。如果自家没有条件拥有，优先寻找当时真实可达的公共替代方式，例如 90 年代普通孩子给农村爷爷打电话，更适合写成小卖部 / 传达室 / 公用电话亭里的老式座机、投币电话或柜台电话，而不是电话手表。

当前案例：`电话手表屏幕照亮小安手指` 是年代错位；应改成 `小卖部玻璃柜台边放着黑色老式座机，卷曲电话线垂在柜台上，旁边搪瓷小碟里有几枚硬币；两只小手抱住沉重听筒，爷爷声音带老式座机电流失真`。这不是简单换道具，而是让孩子主动跑去公共电话告状，让“爷爷记住孩子一句话”更可信、更有年代温度。

正式提示词生成前必须做角色 / 对象命名检查。每条提示词里参与交互的具体对象都要能被识别，不要只靠“大人”“他”“群仙”“神兽”“法器”等泛称让模型猜。

处理规则：

```text
如果剧本称呼是“大人” → 正式提示词内部明确为“主角（被称为‘大人’的 POV）”，再写主角不露脸、袖口、玉扳指、手势等可见证据。
如果是“群仙” → 当作群体画面元素或提示词资产规则，写清服饰体系、站位、动作和礼仪，不当作同一固定人物资产。
如果是“神兽” → 具体化为白鹿、云龙、青鸾等确定对象；只有需要复用和一致性锁定时才调用资产。
如果是一次性女仙、守门者、迎客仙人 → 写清当前镜头外观和动作，不暗示它们和其他镜头是同一人。
```

生产命名可以出现在提示词外的分镜表、资产表和文件说明里；正式投喂代码块里要用自然语言展开成视频模型能理解的具体画面。台词里的“大人”可以保留，但画面描述必须让模型知道“大人”对应的是镜头背后的主角，而不是画面中另一个人物。

资产进入正式提示词时按“描述预算”分配：

```text
提示词资产 → 主要展开到【基础设定】和【场景状态与氛围画质】。
图片资产 / 固定资产 → 如果会作为参考图、图生视频首帧或平台资产输入，主要在【画面内容】写本镜头交互。
未资产化元素 → 必须在【画面内容】里详细描述外观、材质、服饰、表情、结构、体量和光影。
```

不要在画面内容里重复长篇描摹已经由图片资产固定的本体外观。比如人物图片资产已经固定白衣、脸、发饰和服装花纹，画面内容应写袖口被风吹起、白衣如何被侧逆光勾边、人物如何抬手、衣料如何遮挡镜头、与道具或环境如何发生关系。

反过来，路人、功能人物、一次性建筑、单镜头道具、没有作为图片输入的“已登记资产”，都不能偷懒省略。没有图片兜底时，人物要写相貌、服装、发饰、首饰、表情和服装纹样；建筑要写风格、材质、体量、画面占比和空间位置；道具要写形状、材质、比例、反光、发声和使用方式。

未建立图片资产时，不要让同一个具体人物跨多个独立视频提示词反复出现。处理顺序：

```text
不要求一致 → 降级为单镜头画面元素。
同场连续动作且总时长不超过 15 秒 → 合并成一个分镜 / 一条提示词。
必须跨多条提示词保持一致 → 退回 laohu_visual_assets 建立图片资产。
```

同一场景、同一未资产化人物、连续动作不超过 15 秒时，优先合并。合并后用连续镜头叙事写清开场、动作发展、切换桥梁、继承状态和停点；正式模型正文不写镜头编号，总时长在平台参数中设置。

正式提示词的详细度主要落在 `【画面内容】`。不要让基础设定和氛围画质很长，而画面内容只剩剧情摘要；先写主情绪、主注意力、主体状态 / 变化和可见结果，再从环境、镜头、构图、光影、表演、同期声和转场中选择当前镜头真正承重的部分。

正式写镜头前先完成 `文戏 / 武戏情绪入场分流`。共同目标是在第一有效节拍让观众进入人物处境，但不使用同一种节奏手段：文戏先锁人物的关系目的、阻力与关系变化，用台词目的、潜台词、表情、停顿、距离、反应和声场承重；武戏先锁危险方向、力量关系与主角选择，用动作、速度、空间、受力、环境反馈和摄影机身体感承重。混合镜头逐节拍只选一个主导模式，另一模式服务它；不能让对白、打斗、运镜和奇观同权并列。

正式视频提示词先确定模型路由再计算字数：Seedance 2.0 单条不得超过 `4000` 字符，Seedance 2.5 单条不得超过 `5000` 字符；模型未明确或同一正文跨版本共用时按 `4000` 字符。计数范围只包括可直接投喂模型的单个 `text` 代码块正文，从 `【基础设定】` 到 `【画面内容】` 末尾；中文、英文、数字、标点、空格和换行均按一个 Unicode 字符计数，代码块外的资产、执行参数、故事板和验收表不计入。上限不是最低字数或凑字目标。复杂变化仍要在限额内保留启动、传播、接触、结构成形、材质转换、VFX、环境反馈和完成状态，不得压成“华丽变身”“激烈打斗”“产生巨大冲击”。超限时先删作者解释、重复外观、同义风格词、重复否定和无画面作用的说明，再合并不增加观看证据的句子；不得删掉身份、空间边界、站位、攻击来源、运动路径、接触点、受力结果、镜头承接、关键表演和声音因果。必要信息仍装不下时，减少非承重镜头 / 效果或拆分 `VID`，不得交付超限正文。

凡是箭、子弹、暗器、飞刀、刀气、车辆、奔马或高速人物穿过画面，必须建立投射物 / 高速运动空间闭环。按当前镜头需要依次确认：场景坐标与通行净空；摄影机位于主体哪一侧；主体屏幕运动方向；攻击或物体来源；飞行 / 运动轨迹；与主体最近距离；主体感知时点；主体避让方向；物体最终出画或撞击位置；环境受力反馈；动作结束后主体与摄影机状态。禁止用 `从侧面飞来`、`擦脸而过`、`钉进路旁竹身`、`人物迅速躲开` 代替空间调度。撞击目标不承担剧情时，不强求同框展示；让物体沿清楚轨迹出画，再以画外撞击声和画面边缘反馈证明落点，避免模型把障碍物移进道路或人物运动带。

两个以上因果参与者同时运动时，先在正文外建立 `多主体运动账本`，再把关键约束翻译进镜头：每个对象分别写世界起点、屏幕起点、朝向、速度向量、加减速、景深层、触发、路径、外力、接触 / 避让、与其他对象的相对顺序、终点和出画顺序；摄影机另写位置、速度、移动轴和是否越轴。共同运动体分离后先继承共同惯性，没有摩擦、碰撞、制动、转向、推进或地形依据，不允许反向、超越、瞬移或换层。镜头跟随某一主体时，必须区分世界坐标和屏幕相对运动，优先写正向屏幕结果，例如 `马头始终朝右、马尾朝左，从中右移到右缘先出画；人物减速后留在中左，二者横向间距持续扩大`。

复杂人体动作在正式正文前建立 `人体姿势变换账本`，并把关键相位翻译成模型能看见的身体变化：起始姿势和朝向、原支撑点、解除脚镫 / 握持 / 坐姿等约束、新承重点、肩胸骨盆和主要关节的动作顺序、重心轨迹、旋转轴、四肢越过道具 / 对手的净空路径、离开支撑时的轮廓、首次接触点、缓冲卸力和结束姿势。不要用 `帅气翻身、轻盈跃下、凌空旋转、狼狈摔倒` 代替姿势。写骑马侧翻下马时，必须明确双脚先脱镫、手掌按在可承重的鞍桥 / 鞍座、骨盆离鞍、跨鞍腿的弧线、身体向哪侧翻、哪只手先离开、哪只脚 / 髋 / 前臂 / 肩依次落地，以及滑行如何接入下一姿势。

重大位移或上一动作改变空间关系后，下一镜先重建主体、攻击来源、地面 / 道路边界和摄影机观看侧，再进入局部手腕、暗器或碰撞点。连续攻击逐次写清来源预动作、人物线索、身体换位 / 格挡、接触角度、改向 / 出画 / 撞击和边缘反馈。承重动作必须设计 `帅点捕捉`：危险逼近速度先建立，人物提前半拍占位，动作路径短而完整，接触瞬间让关键轮廓短暂清晰，投射物和环境余势继续运动，摄影机最终停在动作结果形成的有力量轮廓。高手感来自占位、角度、节奏和控制，不来自暗器自动弹飞或人物无因摆姿势。

正式编排动作前为主要交战者建立 `角色动作语法卡`：能力等级、距离偏好、起势线索、惯用攻击几何、常用防守 / 借位、场景利用、命中后的回收方式和明确不会使用的越级能力。动作语法卡不是封闭招式表，而是让本 skill 能持续推导同一人物的新动作。群战还要建立攻击者进入顺序：每名攻击者的世界方位、视线 / 声音线索、起势、攻击线和与前一名攻击者的关系必须成立；上一招造成的遮挡、失衡、空位、掉落物或反作用力至少有一项成为下一招条件。

动作语法卡同时标记角色的主要制胜介质：轻灵技巧、重型力量、远程控制、范围能力或地形生存，并写清相对能力差。势均力敌使用交换与反转；中度占优使用连续高速逐个击破；压倒性碾压使用极少动作或范围结果；弱势求生使用撤退、遮挡与代价。动作方法按体格、兵器、训练、能力、性格和目的推导，不按性别套模板。当前女侠是轻灵技巧型、中度压过杂兵，因此主要使用切角、擦身、卸力、借力、短腕动作与连续换位，不使用原地多武器角力，也不提前使用宗师级范围剑气。

动作提示词必须区分 `动作完整` 与 `动作观赏`。先完成来源、路径、接触、受力、结果和状态继承，再选择一个主决定性瞬间，明确摄影机从哪里能同时看清危险线、人物轮廓与结果证据。接触时可让摄影机位移短暂停住、焦点短暂稳定或主体边缘短暂变清，但画内高速对象和环境余势继续运动；不能把“帅”统一翻译成慢动作、定格、长时间 Pose 或满屏拖影。特效只服务速度与接触，主体可读性优先于光效密度。

如果目标明确是 `炫酷、激烈、精彩、高速群战、多人围攻`，动作完整之后必须另做战斗节奏设计，不能让完整因果退化成慢速动作讲解。内部先回答：全段是否实时高速；同时有几条攻击线；不同攻击组错开多少节拍；主角是否在上一招结果尚未落地时已进入下一招；远程武器、近战敌人、摄影机和环境反馈是否同时运动；哪个瞬间用高快门与跟踪焦点提清，哪个瞬间真的需要升格。正式正文用 `同时、紧接、尚未落地、余势未尽、沿空位补入、半拍之后、同一呼吸内` 等时间关系组织并发，不把每名敌人写成轮流上场。

高密度群战可以按攻击职责分组，不必为了控制而减少人数：

```text
远程组：飞镖、袖箭、飞刀、弓箭、飞剑等持续制造穿越画面的高速攻击线。
长兵器组：枪、棍、戟、长刀、链刃等从外圈封锁移动通道。
近身组：剑、刀、钩、双短刃等沿被改向或落空形成的空位贴身补入。
高位组：从竹梢、屋顶、坡面或空中落下，制造垂直压力。
```

各组必须重叠而非排队：远程武器仍在飞行，长兵器已经封路；女侠弹开长兵器时，近身组沿其身体遮挡进入；上一名敌人被撞飞尚未落地，高位组已经压下。主角动作余势连续，不恢复站姿。

重叠威胁进入决定性接触后，必须形成唯一可读的力量关系。串行接触写清双方、角度、脱离与结果；多人同时接触则写清各攻击来源、不同接触位置、主角支撑、合力方向、位移 / 形变、胜负与情绪结果，并只表达主角震开合击、敌方把主角压退，或主角受压后改角卸力中的一个主结果。轻灵角色可以短暂承受多人合力，但应迅速借力换位；没有这些证据时，才把两枪一刀拆成无空档串行接触。

重叠推进只表示压力不断，不表示所有攻击线同时抵达主角身体。写群战前建立交战面容量：结合空地宽度、主角与敌人的身体占位、长短兵器射程、挥舞净空、友军遮挡、视线和误伤，判断当前真正能进入接触的攻击者。其余敌人分配为封路、补位、换角、回收、远程瞄准、保护射手、因挡线暂缓、受伤退出等状态。画面可以出现十五人，但一个狭窄接触面只让有净空线的人出手；后排通过脚步、兵器起势和移动封锁形成下一拍压力。

多人包围先设计破围策略，再设计连招。普通写实高武角色没有护体屏障时，不能长期站在圆心抵挡全方向兵器。优先从阵形薄弱侧向外移动，贴近一名敌人形成身体遮挡，把长兵器引向彼此碰撞，或利用墙、竹林边界、坡面和窄道把圆形包围压成扇面 / 纵深追击。每次镜头切换都要更新：主角距离出口多远、身后是谁、哪些敌人被挡住、哪些攻击线刚获得净空。

每个动作镜头块结尾再做 `预示性承接`：先完成本镜结果，再让下一威胁以刀尖、影子、脚步、机关声、链响、视线或运动物中的一种提前进入，同时把摄影机方向交给这条线索；下一镜从同一线索的下一相位开始。动作匹配、方向匹配、视线匹配、声音提前进入和运动物遮挡都可使用。遮挡只负责隐藏切点，不能代替下一威胁预告；遮挡掠开后凭空出现新敌人必须退稿。

远程武器必须写射界。飞镖、箭、飞刀与飞剑从哪个高低层进入，近战友军何时切入它们的轨迹，射手为何提前发射、延迟、抬高弹道、换角度或停止当前一轮，都要通过画面动作体现。飞剑可以从上方建立独立垂直压力，但落点、改向和回收不能穿过地面友军。

攻击结果不能统一写 `撞击、火星、闷响`。按材质推导：金属刃口相撞产生短促高频脆响、少量火星和手腕反震；剑脊压木枪杆产生沉闷木震、弯曲和纤维开裂；铁棍或长戟砸湿地产生低频闷响、武器陷入和扇形外翻泥水；刀锋切竹先出现切口，再有竹纤维爆裂、竹身倾斜和延迟震落的竹叶；拳肘或肩撞躯干产生衣料摩擦、肌肉受击闷声、呼气中断和脚底滑移。示例是材质推导入口，不是固定音效菜单。

正式提示词动笔前建立三张连续性账本：

```text
状态账本：对象进入状态 → 触发 → 接触部位 → 操作路径 → 中间状态 → 结果状态 → 下一镜继承。
知觉账本：客观事件 → 人物当下可获得线索 → 身体反应开始 → 危险进入观众视野 → 接触 / 避让结果 → 人物更新判断。
观众信息账本：观众领先 / 同步 / 落后人物 → 该关系制造的焦虑、惊吓、误判或反转 → 何时重新校准空间。
```

状态变化不能由名词自动完成。`手放在刀附近`、`握住刀柄`、`横刀在手`、`门开了`、`车停下`、`伤口扩大` 都要回查中间动作是否实际发生。武器尤其要标明 `完整入鞘 / 顶开护手 / 部分出鞘 / 完全出鞘 / 回鞘 / 脱手落地`；拔刀、上膛、开门、下车、换装、点灯等能承担情绪与节奏的动作不能被省略成状态跳切。

人物只能依据当时能感知的线索作反应。高速箭矢、子弹和暗器优先写弓弦、机关、脚步、余光、反射、气流、震动或环境异动触发训练反射，再让危险进入画面；不得默认写成 `看清箭头后再躲`。观众代入时优先从角色附近的声场、呼吸、重心和有限视野进入，必要的客观大全景只负责建立或恢复空间。

速度设计按 `参照物 → 相对位移 → 材料响应 → 摄影机响应 → 声音响应 → 关键清晰点` 写。疾驰可以由近处竹竿反向掠过、中远景视差、马鬃衣摆被风压向后、水花后抛、蹄声密集、低机位摄影机低频震动共同证明；箭速可以由短促弓弦声、瞬间方向性模糊、近脸极短清晰轮廓和随后的画外撞击声证明。除非情绪与信息需要，不把高速物体写成持续可见的慢动作。

接触点提清与动作减速是两种不同控制。需要观众看清刀剑碰撞时，优先写 `人物和兵器仍保持实时高速，摄影机使用高快门感和跟踪对焦，让接触边缘在一瞬清晰；火星、水花和碎屑继续高速飞离`。谨慎使用 `摄影机停止、短暂停住、慢动作、定格`，这些词会直接降低整段节奏。只有主决定性瞬间确实需要延长知觉时间时，才写清哪一层短暂升格、其他层仍怎样运动，以及何时立即恢复实时高速。

高武、机甲、枪战、追逐、超能力与爆炸共用 `爆发动作链`，但发力介质按题材推导：`预载 / 蓄力 → 瞬时释放 → 高速位移或力量传播 → 极短接触 → 明确结果 → 余势进入下一动作`。人物写脚掌、腰胯、脊柱、肩肘与兵器；机甲写承重脚、关节锁止、伺服蓄压、推进器矢量和装甲惯性；枪械写预瞄、扳机、后坐、掩体与弹道；大型破坏写能量积聚、命中、结构应力与冲击传播。题材还可以继续扩展，判断不变：没有发力点、起终位置、反向环境响应、惯性 / 拖曳、声音时差与结果的“瞬移”只是跳帧。角色越强，预动作越小、路径越短、接触越轻、结果越大、控制越精确。

动作速度至少写出四种可感证据中的两种：`位移证据`，主体在极短时间跨过明确参照物；`发力证据`，支撑点、关节、推进器、武器或能量介质先承载后释放；`环境证据`，雨水、尘土、火焰、碎片、衣料或背景视差沿反方向响应；`摄影 / 声音证据`，摄影机短暂跟丢后甩镜重新捕获，或破风、冲击声迟于视觉爆发抵达。不能只写“咻地飞过、快速移动、动作很激烈”。

每个文戏情绪段或武戏动作组选择一至两个 `承重英雄帧`。文戏从关系变化、反应或沉默结果中形成；武戏从预载轮廓、决定性接触或结果控场中形成。连接帧允许方向性模糊、前景遮挡、甩镜、失衡、局部出画和不完整轮廓，摄影机也可以短暂追不上主角；英雄帧通过高快门感、焦点重新捕获、构图和光线短促提清。禁止为了帧帧像壁纸让角色一招一停、回正重摆，或把动作爆点统一改成长慢镜。

超常题材正式写镜头前再建两张账本：

```text
能力基线：世界允许的能力 → 角色等级 → 感知 / 预判 / 速度 / 力量 / 控制精度 → 普通人与高手差异 → 本镜允许的超常表现。
超常物理：来源与发力 → 能量 / 压力形成 → 传播介质和路径 → 先行环境征兆 → 接触点 → 材质分层响应 → 人物身体反应 → 声场 / 摄影机响应 → 余波和永久结果。
```

写实高武不是普通武打，也不是只加金光的法术表演。顶级高手的反应要来自更早读取预动作、声源、坐骑、气流和环境微变；动作更短、更准，重心与停点更稳。刀气、剑气和冲击波要让空气折射、雨珠、雾气、竹叶、衣料、皮肤风压、湿土、石块、竹根和回声逐层响应。大威力与高控制要同时出现：一寸出刀可以裂开数丈山道，但轨迹必须精确偏开人物，环境破坏必须沿明确接触线传播。

爆炸、坍塌、炮击、撞击和大规模能量事件必须在正文外建立 `事件传播账本`，再按观看任务选择承重阶段写进镜头：来源与发射方向、命中点与入射角、力量传播方向、首个承力结构、材料失效顺序、碎片大小分组与飞散锥、二次碰撞 / 连锁破坏、火焰 / 烟尘 / 压力波 / 遮挡变化、声音到达与回响、摄影机响应、永久终态。不能只写 `高楼爆炸，碎石四处飞散`；要说明哪一面外墙先受击，玻璃和混凝土分别向哪里离开，钢筋与楼板何时失效，主体向哪边倾斜，人物与摄影机位于碎片锥哪一侧。

视频创作输出必须按阶段产物与内部质量门推进：

```text
1. 整个内容的剧本输出文件：锁定剧情硬约束和观众体验目标。
2. 完整设计的分镜表格输出文件：完成导演镜头构思和代入检查。
3. 第一个分镜的视频提示词展示文件：作为内部写法与模型可执行性校准样本。
4. 所有分镜视频提示词结果输出文件：完成全片连续性自审后交付。
```

短闪回、插入记忆和单信息补充镜头要按信息点倒推时长。先问这条镜头到底承担几个信息点：愿望出现、拒绝、被带离、情绪停顿、转场锚点。若只有 2-3 个信息点，通常 5-7 秒足够；若有复杂动作链、多句关键对白、表情特写和转场留白，才考虑 8-12 秒。不能把常用 10-12 秒套到所有镜头上。短闪回应该像记忆刺点，短、准、带余味；拖长会稀释节奏，浪费生成时长和成本。

如果最终集中到一个主文件，提示词外的说明可以压缩，但正式提示词不能丢失本镜情绪承重项和生成必需信息。主体状态或动作结果通常要清楚；镜头路径、构图层次、光影、材质、表演、声音和片内转场按本镜职责选择，不要求每镜同时写满全部。

第一条视频提示词完成 → 作为内部写法校准样本；用户要求全片时继续全部分镜，不等待普通创意确认。
全部分镜提示词完成 → 交付实际生成执行单；真实生成由老胡执行，结果回传后进入复盘。

所有正式内容必须写入文件。对话里不要贴长篇剧本、完整分镜表或完整视频提示词集合，只给文件链接和阶段摘要；默认按最终目标继续，不为普通创意询问是否进入下一阶段。

分镜表、第一分镜视频提示词、全分镜视频提示词默认在同一个阶段文件上迭代更新，不自动新建 v1/v2/v3。只有老胡明确要求新增版本、另存一版、保留旧版或 A/B 两版时，才创建新版本文件。

视频提示词交付必须方便老胡直接复制。每条正式视频提示词本体必须单独放进 `text` 代码块；代码块里只放可直接投喂视频模型的 `【基础设定】`、`【场景状态与氛围画质】`、`【画面内容】` 三块。镜头编号、所属场次、镜头任务、表情来源、流程判断、资产判断、生成前检查、回传字段、说明文字和确认问题，都必须放在代码块外。

正式视频提示词必须严格按照 `02_共享资产库/01_模板库/视频模板/模板_视频提示词_基础设定氛围画面内容.md` 输出。剧本、分镜表、流程判断、前置判断、资产判断、生成前检查、回传字段和作者说明都是提示词外的评审材料，不得混入正式提示词正文。

正式提示词正文只允许使用以下三块：

```text
【基础设定】
【场景状态与氛围画质】
【画面内容】
```

不要在正式提示词里临时新增【前置判断】【负面约束】【生成前检查】【回传字段】【后期备注】等块。需要表达生成边界时，在 `【基础设定】` 增加一行少量抽象 `输出限制`；不能把当前案例的具体错误对象逐条写成禁令。
正式提示词内部服从三段式但重新分配权重：`【基础设定】` 只列实际调用素材、一句声音策略和必要的抽象输出限制；`【场景状态与氛围画质】` 先写开拍前的场景初始状态，再写 1-3 句跨全部镜头成立的主风格、摄影介质和宏观色彩基线；`【画面内容】` 用无编号镜头块承载主要导演调度。旧字段只能作为内部拆解，不能进入正式代码块。

正式视频提示词要用目标描述收束生成空间。给视频模型看的正文必须先写目标画面、目标材质、目标动作、目标风格、目标声音和最终屏幕结果。不能用排除句承担正向描述的职责；模型会先注意到被提到的对象。少量硬边界只用于抽象质量问题，例如动作僵硬、逻辑混乱、文字水印、比例畸形，并且不能引入当前镜头不该出现的具体视觉对象。风险判断、常见跑偏和不该出现的剧情物，写在提示词外的自检、回传字段或失败经验里。

正向收束不是把模型自由发挥压没，而是给模型一条稳定走廊：主体是谁、世界是什么质感、画面属于什么风格、动作朝什么方向发展要清楚；细节纹理、云雾流动、衣料细节、光影微变化可以保留模型自由发挥。VC 优化可以继续提升画面表达，但初稿必须已经完成正向收束。

正式提示词只能写给视频模型看的画面、声音、动作、镜头和质感。不要出现给作者、剪辑师或助手看的话，例如“分镜编号”“所属场次”“镜头任务”“本条是否独立完整”“复制本条”“前一个画面”“下一个镜头”“接 E1-S1-C2”“后期备注”“为下一条做准备”。如果需要做分镜衔接，必须把它改写成画面内可生成的转场行为。

全分镜视频提示词还必须做上下镜头连续性设计。每条正式提示词代码块仍独立完整，但写作前要在提示词外记录或内部判断：

```text
上一镜停点：
本镜起点：
视觉锚点 / 声音锚点：
视线方向 / 屏幕方向：
时间关系：连续 / 省略 / 闪回 / 跳切 / 仪式性压缩
情绪任务：延续 / 反转 / 升级 / 暂停
连接方式：动作接动作 / 视线接所见 / 声音桥 / 物件匹配 / 光线匹配 / 遮挡 / 硬切停点
```

正式正文里不要写这些字段名，但要把判断落实为画面：上一镜的木轮声可以延续到下一镜的坡道，袖口特写可以触发量衣服回忆，低头叩首可以在抬头时完成时间跳切。不能让全片变成 39 条孤立提示词。

如果老胡采用 15 秒以内多段视频拼接成一镜到底效果，A 条视频的尾帧可以作为 B 条视频的首帧参考。生成 B 时在 `【基础设定】` 写 `【首帧参考@VID-A尾帧】`；`【画面内容】` 用自然语言写镜头从同一景别、构图、光源方向、人物姿态、表情余韵和背景锚点继续，再进入新动作。不要写 `第0秒` 或逐秒时间码。

分镜表之后可以按需输出 `镜头预演板提示词`。它和视频提示词同源但服务对象不同：预演板给图片模型和人工审查构图，视频提示词给 Seedance 2。老胡明确只要视频提示词、镜头已经过构图验证或首测需要提速时，不强制生成预演板。

需要预演时，全分镜交付仍写成一体化视频执行单，每个 `VID` 依次放 `【镜头预演板提示词】` 与 `【Seedance 2 视频生成提示词】`，避免来回翻文件。预演板是可选的人审层，不是 Seedance 正式提示词的必选附件。

镜头预演板生成黑白 / 灰阶的低保真构图骨架图，不是最终电影画面或视频首帧。它锁构图、景别、机位、主体比例、站位、道具数量、空间锚点、视线、动线、切换点和留白，不锁真实人物脸、具体服装颜色、最终材质、最终光影和完整电影美术。

老胡明确要求“使用故事板生成并在提示词中引用”时，一个 `VID` 仍只生成一张故事板图片。先写一条完整的 `【故事板图片提示词】`，把镜头01到镜头N全部排进同一张横屏多格 / 多行故事板表格图；每格写关键画面、构图、景别 / 机位、运镜、切镜、空间锚点、动作趋势、主体比例与位置。正式 `【基础设定】` 只引用一次整张板，例如 `【故事板参考@SB01 故事板图片】`，不能把板内每格改写成 `SB01-01`、`SB01-02` 等多个外部参考。

故事板负责提供整条视频的镜头地图，稳定资产继续锁身份、结构、材质、Logo 和空间；正式 `【画面内容】` 必须补全各格之间的身体动作、道具状态、运镜、受力、环境、声音与明确切镜，最终输出仍是连续单幅视频画面。若用户明确要求多张独立画面，应将其命名为“关键帧参考图”，不能用该例外重写故事板定义。

故事板必须避免“过度具体导致视频模型照抄”。第 2 列的图应该像导演给摄影和美术看的构图草图，而不是完成度很高的房间 / 院子 / 街道线稿。空间锚点优先用文字标签和极简线条，不画完整室内布局、装饰物、床头、枕头、台灯、书桌、窗帘、花盆、墙画等非视觉中心细节。资产只用来校准空间方向和关键锚点，不用来复刻场景。

POV 故事板必须做物理朝向检查：视点主体是躺着、坐着、站着还是低头，身体朝向哪里，眼前真实能看见什么。不能把不可能同时看见的床头、枕头、门口和完整房间都塞进同一格。当前案例：小安躺在床上面向门口方向，故事板只画被沿 / 床尾方向线、小手或袖口锚点、远处门口方向框、视线箭头、右侧三分线和留白区；不要画完整床头、枕头、窗帘、台灯和书桌。

镜头预演板推荐表格列：`镜头 / 关键画面`、`线框构图`、`构图规则`、`景别 / 机位`、`空间锚点`、`引导线 / 动线路径`、`主体比例与位置`。从 `镜头01` 连续编号到实际需要的 `镜头N`，或使用动作节点命名，不写内部时间码。

`构图规则` 是故事板最重要的列之一，必须用专业电影构图术语写清“什么和什么形成什么构图 / 视觉重心 / 视线引导”。可用术语包括三分构图、黄金分割构图、中心对称构图、框架式构图、前景框构图、引导线构图、对角线构图、三角稳定构图、层叠构图、纵深透视构图、留白构图、负空间构图、低机位压迫构图、高机位俯看构图、圆形匹配构图、遮挡转场构图等。要写成 `门框两侧竖线和被沿弧线形成前景框构图，父亲剪影落在右侧三分线`，不要只写 `构图好看`。

故事板必须明确画面重点和视线流向。画面重点可以通过主体落点、构图线、前景框、道路 / 桌沿 / 门框引导线、对角线动势、三角关系、负空间、光源方向和明暗重心建立。即使故事板是黑白线稿，也要用标签标注 `主光方向`、`亮部重点` 或 `视觉重心`，说明观众视线先看哪里、再看哪里。

镜头预演板和视频提示词使用同一组关键画面节点。项目内部编号和预演板格号服务人工对齐，可以留在分镜表或预演板；正式视频模型正文只写 `低头前、遮挡掠过、抬头后、落刀声响起` 等可见 / 可听节点及其连续变化。两者内容不一致时回到分镜表重排。

连续一镜到底拼接时，故事板第 1 行必须承担首帧复用：从 `【首帧参考@VID-A尾帧】` 的构图和人物状态开始，画同一景别、同一主体比例、同一视线方向或同一身体余势；第 2 行以后才画本条的新变化。这样生成出的故事板不会把 B 条开头画成另一个机位，也不会让视频拼接时跳脸、跳景别或跳光源。

镜头预演板提示词必须单条自足可复制，但只画当前镜头需要验证的关系。参考资产、灰阶骨架、画幅框、构图线、简化剪影、空间标签、视线、动线、前景框、负空间和表格列都是候选；复杂调度多选，单主体或单物镜头少选。

表情驱动、情绪人像、开场钩子、脑内 VO 反应和关系变化类视频，故事板先判断主情绪证据主要在脸部微表情、身体距离、完整姿态还是环境关系。脸部证据承重时优先近景化；疏离、压迫、等待或关系距离承重时，中景、全景和远景也可能更准确。只画本镜承重证据，不让无关手部、鞋尖、裙摆、包带或完整场景抢镜。当前恋爱情绪短片可采用胸部以上构图，但不把该案例升级成所有情绪镜头的固定景别。

连续视频单元可以使用“锚点重叠”，但不能机械每条都重叠。只有连续动作、情绪承接、POV 视线接续、遮挡转场、遗物触摸、门框 / 火光 / 蒲团 / 木轮这类强连接需要时，下一条 `VID` 可复用上一条最后一个微分镜作为起点，例如 `VID-01：S1-C1-01 到 S1-C1-03`，`VID-02：S1-C1-03 到 S1-C1-05`。普通硬切、时间跳切、换场或闪回不强制重叠。重叠微分镜在故事板和视频提示词里都要保持同一构图、空间锚点和动作状态。

连续结尾、遗物回收和片名段要按整段动作链设计。凡是 2 条以上分镜共同完成父亲牵走、孩子停步、走向遗物、触摸旧物、回忆曝光、升镜出片名这类连续段，必须先统一空间位置、道具数量、道具状态和动作顺序，再拆成单条提示词。上一镜停在什么物件上，下一镜就从同一个物件或同一动作继续；如果第一镜已经需要观众看见 P11 半成品木马车架的悬空后轮，第二镜和第三镜不能再把触摸中心改成完整旧车或墙角随机木轮。当前案例：E1-S11-C1 父亲牵小安往大门走，院中 P1 旧完整木马车、P2 新完整木马车和 P11 半成品木马车架进入视线，P11 斜靠在旧木框 / 柴堆边且一只后轮悬空；E1-S11-C2 小安松开父亲，走到同一只悬空后轮前摸过轮缘、粗糙木轴和未完成坐板，爷爷二次曝光浮出；E1-S11-C3 从同一只悬空后轮继续拨动，枯叶 / 纸灰飞起后升镜拉高，院子全景稳定后出现片名。

片名、字幕和结束文字必须作为可见画面元素设计。正式提示词如果要生成文字，必须写清内容、出现时机、屏幕位置、大小、颜色、字体气质、边缘质感、停留时间和遮挡关系。不能只写 `片名出现`、`字幕出现`。例如结尾片名《不想长大》应在院子全景稳定后出现，放在画面上方留白处，暖白色、轻微手写笔触、老式 DV 毛边，横排居中，大小约占画面宽度三分之一，避开下方人物、两辆完整木车和 P11 半成品车架。

正式视频提示词初稿完成后，必须调用 `laohu_vibe_creating_prompt` 增加一次 Vibe Creating 优化，再输出给老胡。该项目 skill 会调用外部原文 skill：

```text
02_共享资产库/05_工具流程/外部优化Skill/vibe-creating-prompt/SKILL.md
```

执行方式：

```text
严格三段视频提示词初稿
→ 交给 laohu_vibe_creating_prompt，按 vibe-creating-prompt 判断是否适合 VC 优化
→ 只对画面表达、情绪体验、关键意象、视觉统一性和低价值技术噪声做优化
→ 把优化结果重新落回【基础设定】【场景状态与氛围画质】【画面内容】三块
→ 再写入第一个分镜展示文件或全部分镜提示词结果文件
```

VC 优化不能改动这些硬约束：

```text
三段模板结构。
确定总时长。
用户明确指定的台词、旁白、音乐、音效。
资产一致性要求。
已确认的镜头编号和分镜表。
空间、动作、表演与前后因果完整；在模型字数上限内优先压缩重复信息，不压掉必要因果。
不得出现作者说明、后期备注、前后镜头说明。
```

VC 优化不得改台词。Vibe Creating 只能优化画面体验、情绪氛围、动作质感和表达流畅度；遇到剧本台词、旁白、VO、字幕、声音触发句和用户明确指定句子，必须原文保留。若优化结果改了台词，回填时必须改回剧本原文。

如果 `laohu_vibe_creating_prompt` 默认输出“判断 / 执行动作 / 输出结果 / 补充说明”，这些只能作为内部优化记录或提示词外说明；正式投喂给视频模型的代码块里，只保留优化后的三段提示词正文，不把 VC 判断标签写进去。

`【基础设定】` 的职责：只列本条实际上传或绑定的参考素材，并用一句话写声音策略。它是素材清单，不是资产说明书：

```text
【@A1 人物】
【@S1 场景】
【@P1 道具】
【@C1 色卡】
【@V1 动作 / 音色 / 首帧参考】（只在本条实际使用时填写）
声音：只生成对白、同期动作音效和环境声，不生成 BGM。
```

`【基础设定】` 是本条实际投喂素材清单，不是固定资产说明书。没有实际上传 / 绑定的对象不写进基础设定；未资产化对象在对应镜头中详细描述。

资产行还必须经过“本镜实际使用”检查。资产引用不是给作者看的备注，而是给模型的召回指令；写入 `【@资产名】`、资产名称或高权重视觉名词，模型就会倾向于把它放进当前画面。每条正式提示词只调用本镜实际出镜、出声、VO、被触碰、发声、承载光影、提供空间结构或成为运动中心的资产。只是前后镜头重要、作者知道、剧情背景存在、下一镜才会出现、为了提醒自己而写的资产，都不能进入当前正式提示词。

执行检查：

```text
人物资产：本镜是否出镜、出声、VO 或被其他角色直接互动。
场景资产：本镜是否真的使用该空间结构、门窗、桌椅、墙角或运动路径。
道具资产：本镜是否可见、被触碰、发声、被递出、被破坏、被点燃、产生反光或作为视线停点。
若答案是否 → 不调用该资产，也不在氛围与画质或画面内容里提名。
```

当前案例：E1-S8-C1 是门缝医生画外音，只需要小安小手、父亲局部、白大褂衣角、旧药箱、门缝光和压低声音；P6 输液瓶虽然是下一镜病床的重要视觉证据，但本镜不看见它，所以不能引用 P6。E1-S8-C2 小安进屋后第一次看见输液瓶，才调用 P6。

人物资产行还要承担形象和音色的一致性锚点。凡是本条提示词里会出镜、说话、喊叫、VO 回响或画外音出现的人物，基础设定里优先写成 `角色名：【形象参考@A1 角色人物设计资产】【音色参考@V1 角色音频参考】稳定身份、本镜状态和本镜出镜 / 出声方式。` `【形象参考@xx】` 由老胡替换成人物设计资产图片，`【音色参考@xx】` 由老胡替换成音频参考。角色基础音色已经写在人物设计资产图片的音色文字说明区，并由音频参考承担，不要在每条视频提示词里重复长篇基础声线。当前镜头因为病弱、哭腔、喊叫、压低声音、电话失真、隔门变闷等发生的变化，必须在 `【画面内容】` 里写成当下声音状态，不能改掉人物常态音色。

视频生成提示词必须把本镜实际投喂的资产用起来。写每条提示词前判断人物、场景、道具、色卡、动作 / 音色和首帧是否真实上传或绑定；答案为是才写占位符。镜头预演板默认给人看，不自动写成 `【故事板参考@...】`。若需要模型参考构图，优先上传由预演板确认后得到的干净首帧 / 构图图。

关键发声镜头必须开音色例外。`【音色参考@xx】` 只保证大方向一致，不能替代本镜的听感设计；短视频开场钩子、口播第一句、人物第一次出声、重要 VO 回响、吵架爆点和情绪反转句，必须在 `【基础设定】` 的 `声音设定` 里用 1-3 句重写本镜声线、音区、共鸣、颗粒、收尾和语气，再在 `【画面内容】` 把停顿、气口、咬字、尾音、回响或距离感写进表演。开场要抓人时，女声可以设计为冷感磁性女中音 / 偏低女声，中低频到中频集中，胸腔共鸣稳定，轻微沙哑颗粒，近麦干声，咬字清楚利落，尾音短收；不甜、不夹、不软，不做主持播音腔。这个方向只适用于需要短视频钩子、冷笑挑衅或强记忆点的发声镜头，不自动覆盖所有温柔、伤心、崩溃或回忆段。

台词、旁白、画外音和脑内 VO 必须按“双层声音表演”写，不能只写抽象情绪，也不能只写机械参数。第一层先写情绪意图和说话态度：示好、试探、亲昵、期待、敷衍、心虚、防御、不耐烦、反推责备、轻蔑、愤怒、暴怒、切断、空洞残响等，让模型和配音者知道这句话是从什么关系状态里说出来的。第二层再写可听见的声音形态：音高 / 音区、响度 / 音量、语速 / 节奏、停顿 / 气口、重音位置、气息状态、咬字 / 吐字、软硬强弱、爆发力、距离感、混响和衰减。`温柔`、`生气`、`压迫`、`破碎` 这类词不能单独使用；`音量中等、语速收紧、音高压低` 这类参数也不能单独使用。错误写法：`男声音高压低，音量中等，语速收紧。` 正确写法：`男声带防御和心虚，急于把怀疑压回去；声音收紧发硬，音区偏低，音量不大但压迫感明显，重音压在“她”和“普通朋友”上，“可以吗”短促下压。`

情绪曲线型短片必须给主要 VO 设计阶段性声音表演。若一个角色的画外音是推动另一个角色表情变化的主触发器，每个关系阶段都要先写情绪态度，再写声音参数：初识是轻佻试探和克制示好；亲昵称呼是冒进试探和甜腻笑意；恋爱初期是稳定惦记和温柔黏人；热恋邀约是期待、紧张和怕被拒绝；平淡期是表面愧疚但敷衍抽离；猜忌期是心虚、防御和急于压住对方；争吵期是不耐烦、反推责备、烦躁爆发和推卸责任；攻击句是轻蔑、厌烦和刺伤自尊；决裂句是暴怒爆发、厌倦切断和彻底拒绝；余音是伤害后的空洞残响。当前案例：《30秒钟带你体验谈恋爱》正片的男声脑内 VO 是林栀表情变化的主要触发器，不能每条都写成普通年轻男声，也不能只堆音量、语速、重音、咬字；必须让每句声音都有明确情绪、态度、软硬、强弱、爆发和回响。

道具资产进入正式提示词时，必须写清“本镜数量 + 资产身份 + 同类边界 + 剧情时间状态”。资产不是一个类别词，而是一个唯一对象；如果只写 `木马车`、`药碗`、`纸房子`、`硬币汤圆` 这类类名，模型容易把它理解成一类物件并自动复制。正确写法要明确 `唯一一辆 P1 旧木马车`、`一只 P5 爷爷药碗`、`两辆木马车：P1 旧木马车和 P2 新木马车`。如果同类资产会在后续镜头出现，但本镜还没到它的剧情解锁点，也要写清 `本镜发生在碰撞冲突之前，剧情里只有这一辆 P1 旧木马车；P2 新木马车尚未被承诺、尚未制作、尚未出现，禁止出现第二辆木马车`。如果本镜确实需要多个同类物件，必须逐一列出编号、数量、位置、差异和各自剧情来源，不能用一个资产名同时代表多件物。

同类道具必须做剧情解锁检查。制作阶段提前设计了某个资产，不代表它已经存在于当前镜头的剧情世界。先判断：它在当前镜头之前是否已经被制造 / 获得；角色是否已经知道或看见它；它是当前实物、台词承诺、回忆对象还是未来兑现证据。当前案例：《不想长大》P1 是爷爷一开始已经给小安做好的第一辆旧木马车；P2 是发生碰撞、孩子哭诉之后，爷爷承诺“再做一个 / 一人一个”的未来兑现物，只能在结尾遗物回收段作为第二辆车出现。E1-S3-C2 到 E1-S5-C1 承诺出口之前，所有木马车画面都只能出现 P1。

道具状态变化必须写成可见损坏点或可验证功能结果。`坏了`、`坏掉的车`、`破了`、`旧了`、`修好了`、`不能用` 都是模糊状态词，不能单独进入正式提示词。写损坏时先判断是外观损坏还是内部 / 功能损坏：外观损坏要写具体可见部位，例如右前圆木轮半脱、轮轴松动外露、坐板裂缝、扶手断开、木片翘起；内部 / 功能损坏要写操作后的结果，例如推起来卡住不滚、轮子只晃不转、发出闷响、车身向一侧歪。写修好时也要写可见修补结果，例如补木片、木楔、重新固定的轮轴、轮子重新能转。错误写法：`旁边放着坏掉的木车`。正确写法：`旁边只靠着一辆 P1 旧木马车，右前圆木轮半脱离轮轴，轮轴松动外露，车身向右前方歪斜；爷爷轻推一下，右前轮卡住发出闷响，车身只晃了一下没有滚动。`

资产图片引用统一用中性占位符：

```text
非人物资产名：【@资产名】固定外观、材质、服饰、比例、表情规则、动作限制或使用规则。
人物名：【形象参考@人物设计资产】【音色参考@人物音频参考】稳定身份、本镜状态和本镜出镜 / 出声方式。
```

如果实际平台需要 `<node-asset>...</node-asset>` 这类格式，可以在导出时替换；项目规则中默认使用 `【@资产名】`。这个占位符只代表此处应插入或引用已经设计好的资产图片，不代表模型自动知道资产内容。若本次生成没有把资产图片一起投喂，仍要在提示词正文保留足够外观描述。

不要把只在当前镜头才发生的一次性动作写进基础设定；那些应进入 `【画面内容】`。

人物资产行推荐写成“双参考占位 + 本镜状态”。例如：`小安：【形象参考@A1 小安人物设计资产】【音色参考@V1 小安音频参考】6-7 岁重庆小男孩；本镜穿浅色儿童睡衣或薄棉秋衣，身体在被窝里，以小手、睡衣袖口、揉眼和刚醒呼吸表现身份。` 这样既调用了 A1 固定小安的形象和设计图，也调用了 V1 固定小安基础音色；当前镜头的哭腔、病弱、喊叫、压低声音、电话失真等声音表演仍写进 `【画面内容】`。

`【场景状态与氛围画质】` 的职责分成两步。第一步写视频开始前已经成立的场景状态：固定空间边界、人物和道具初始位置、天气、人群活动和现有破坏；第二步用 1-3 句锁定跨本条全部镜头都成立的主风格、摄影介质和宏观色彩基线。开场以后才发生的入场、玻璃破碎、天气突变、环境破坏和局部光色变化不提前写进第二段，而是进入对应镜头块。

宏观层按以下三个问题压缩，不要求保留字段标签，也不要求把每项写满：

```text
风格核心：题材类型、风格母体、真实程度、影像目标、情绪能量、生成边界。可写 Photirealism-真人实景拍摄、电影级质感、超写实、极致逼真、禁止动作迟钝僵硬、禁止逻辑混乱等稳定锚点。
视觉基调：画幅、摄影系统、镜头系统、机位方式、运动质感、拍摄临场感。可写变形宽荧幕电影质感、IMAX 胶片摄影机、Panavision C 系列镜头、手持拍摄、动态模糊、轻微手持抖动。
色彩与影调：时代 / 美术色彩、主辅色、对比关系、胶片 / 滤镜 / 颗粒、光源类型、高光与暗部处理、明暗过渡和材质光感。
```

三段不是同一种文体：`【基础设定】` 是素材与边界清单；`【场景状态与氛围画质】` 是开拍前事实加简短全局摄影基线；`【画面内容】` 是导演现场调度，承担表情过程、动作因果、局部光色、逐镜声音、转场和停点。

宏观画质规则优先使用中文摄影表达，不写大段英文关键词清单。少量跨全部镜头成立的器材或介质名可以保留，例如 `ARRI Alexa 35`、`35mm 胶片颗粒`、`LUT`。具体肤色、妆效、发质、衣料、材质和局部曝光跟随人物实际出现的镜头写进 `【画面内容】`。

情绪人像、恋爱短片、开场钩子和外景美人片仍要先做风格交集，但正式 `【场景状态与氛围画质】` 只输出收束后的宏观交集。肤色妆效、树影压面、海面反光、人物气色和具体胶片色落点进入对应镜头，不再全部堆在全局段。

视频提示词先把摄影指导层当作开放问题库：光影关系、光影运动、色温、主体细节、空间层次、时间天气空气、镜头参数、画面类型、情绪反差和质量边界中，哪些真正改变本镜主情绪、主注意力、物理可读性或连续性？只选择承重项。跨全部镜头成立的结果进入 `【场景状态与氛围画质】`，局部选择进入对应镜头；不承重的项目不写。

光影承担体积、分离、身份或情绪时，才写需要的亮暗、轮廓、反光和背景关系；剪影、平光、大片暗部或主体融入背景也可能是准确选择。使用动态光源时必须写出来源、运动原因、阴影怎样变化以及影响哪个主体，不能用随机闪烁冒充情绪。

光源色温没有固定情绪字典。先从时间、真实光源、场景材质和人物肤色确定物理基线，再判断暖、冷或冷暖并置怎样加强主情绪；暖光可以危险、虚假或窒息，冷光也可以清醒、宁静或治愈。当前《30秒钟带你体验谈恋爱》选择柔金侧逆光和蓝绿海面反光，是因为海边时间、人物肤色和“美景仍在而关系变冷”的情绪结构共同需要它，不升级成恋爱短片套餐。

主体细节承担身份、状态、动作因果或主情绪时，才从颜色、材质、纹理、反光、湿度、破损、瑕疵和边缘状态中选择必要证据，不要求组成完整细节束。表情主任务镜头优先保留脸部和胸部以上真正承重的细节；服装展示、全身动作、资产验证或道具证据镜头再展开相应部位。细节不能和主情绪、主动作争夺注意力。

镜头参数按屏幕结果自动选型：需要多少环境、相机离主体多远、透视要夸张还是压缩、哪些信息必须同时清楚。焦段、景深、对焦距离、主体到背景距离和散景只在承重时展开；情绪人像可以深景深，POV 可以长焦，群像也可以选择性浅焦，只要关键关系与主情绪仍然可读。

情绪反差点要变成可见画面，不写成口号。`温暖但是孤独` 要落实为暖光仍在但人物眼神空掉；`清新但是疼` 要落实为海天仍清透但留白扩大、树影压到脸侧、气色变淡；`奢华但是破败` 要落实为高级材质边缘破损；`干净但是危险` 要落实为清洁空间里的不安阴影、低频光源或异常静止。反差点用于增加观看理由，但必须服从全片统一风格。

画面风格必须按组合系统生成：

```text
画面风格 = 风格母体 + 画质介质 + 色彩影调 + 光影方式 + 构图 / 美术体系 + 题材气质 + 正向边界
```

可使用日系、胶片复古、港风 / 东方复古、欧美经典电影、赛博未来、暗黑犯罪、Ins 日常高级、童话梦幻、黑白单色、纪实原生、小众失真、动画手绘、季节人像等风格母体，但不能死板堆词。正式提示词里优先确定 1 个主风格核心，再选择 1 个摄影 / 介质锚点和 1 套色彩影调作为补充，并写清统一边界。

例：`东方仙侠写实电影风格为主，借 IMAX 70mm 史诗清晰度和高动态光影；白玉、青玉、金白天光构成美术体系，画面保持古典东方神域、真实宽幅电影、清贵礼制和可触摸玉石材质。`

`【场景状态与氛围画质】` 必须短而有效：先回答开拍前场景已经怎样，再回答全段属于什么影像母体、使用什么统一介质、主辅色与肤色保持什么关系。判断句是：描述“开拍前已经成立”的留在第二段；删除某句后如果只影响一个镜头，就把它移到该镜头块。

`【画面内容】` 的职责：把内部镜头节点写成一条连续观看过程。正式写作前先确定主情绪和动作观看方式，不预设镜头数量。连续跟拍 / 少量长镜头用于展示真实时间、空间、完整身法和持续控制；高强度多切用于展示攻击密度、速度、冲击、失衡和压迫；混合结构可以先建立空间，再以多个短镜头覆盖爆发动作，最后让结果和情绪落地。15 秒使用少量镜头或约 10 个镜头都可能正确，必须以成片效果反推。

完整动作单元按 `建立 / 来路 → 选择 → 接触 / 表演 → 结果 → 余势` 闭合，但一条链可以由一个镜头完成，也可以由多个镜头分别覆盖不同相位。每个短镜头只需承担一个清楚的新观看证据，不要求独自完成整条因果；切镜后必须进入同一动作的下一相位，并继承动作手、姿势、武器归属、运动方向、力量余势和声场。高频动作覆盖不是快闪蒙太奇，不能因镜头短就省略连续性。

连续长镜头适合连续时间、空间和情绪累积；高强度多切适合从多个观看相位制造速度、冲击和压迫；快闪蒙太奇适合时间压缩、平行信息、记忆碎片、危机倒计时和动作卡点。正式正文不显示编号。每个新镜头以 `[景别][运镜 / 转场]` 开始，并立即继承姿势、道具、余势、空间方向和声场。只有不增加观看价值的重复角度才合并；只有核心动作结果确实无法装入总时长时才拆成多条素材。

每个镜头块使用统一高信息密度语法：

```text
[景别][运镜 / 转场] 画面描述。
[VFX：额外视觉效果与可见结果]（按需）
[环境音：当前空间持续声场关键词]（按需）
[动作音：与本镜动作同步的声音关键词]（按需）
[台词：角色名（表演）：“确认原文”]（按需）
```

画面描述写谁在何处、以什么状态、因何触发、怎样行动、作用于什么、产生什么结果。VFX 放在画面描述之后，只承接能被看见的额外效果，不重复人物动作，不用特效替代物理反馈。环境音和动作音按镜头分别写，避免全段末尾一张声音清单让模型无法判断何时进入、何时退出；没有对应内容时省略，不写匿名 `[无]`。

台词后的表演采用两级密度。功能台词只需简短、准确，例如 `[台词：男孩（惊讶、小声）：“妈妈，这个是神吗？”]`；情绪承重台词必须写出能被镜头读到的眼神、面部、呼吸、视线、姿态、身体距离和发声变化，例如 `[台词：男孩（仍缩在母亲怀里，眼睛越过她肩头盯住白羊，呼吸尚乱，声音发轻，惊恐中第一次出现敬畏）：“妈妈，这个是神吗？”]`。表演密度由本镜情绪职责决定，不机械填满五官和肢体。

每个镜头头部都要拥有唯一主要情绪功能。先回答摄影机站在谁的感知位置、观众要共同经历什么，再选择景别、观看侧、距离、速度、方向、稳定性、焦点和停点。运镜与情绪不是固定情绪词典：同一推镜可能是亲近、发现或压迫；这里的一一对应是“本镜运镜只服务一个主要情绪任务”，不是“某种运镜永远等于某种情绪”。

`【画面内容】` 的质量标准要接近导演现场调度，而不是分镜摘要。先写主情绪、主注意力、主体状态 / 变化和可见结果；发生动作、接触或连锁反应时，再写实际需要的起点、路径、触发与结果。不要只写“发生爆炸”“众人惊慌”“神兽出现”，也不要为了完整让每次爆炸都同时出现冲击波、灰尘、衣料、镜头抖动和声音；只选择能证明本次尺度、影响和主情绪的反应。

舞蹈类视频提示词必须写出可排练的身体动作链，不能只写“起势、旋身、跃转、收势、水袖成圆”这类结果词，也不能把动作理解完全交给故事板。正式 `【画面内容】` 至少要交代脚位和重心、膝胯高度、胸腔和脊柱方向、肩肘腕的带动顺序、手指和袖口关系、水袖运行轨迹、头眼方向、呼吸和动作停点。水袖舞要特别写清：力从脚底和腰背发起，肩放松，肘带腕，腕带袖，袖面先滞后再追上身体，袖尾形成弧线、圆线、斜线或遮挡转场；脚下点水、换重心、碾转、撤步、探步、并步、落脚产生的水纹和同期声也要写出来。错误写法：`她旋身，双袖形成大圆，画面很美。` 正确写法：`右脚脚尖先点进浅水，左脚承重，膝盖微屈，腰背带动胸腔向左打开；右肩不耸，右肘先向外送，手腕最后翻出，右袖滞后一拍后从膝侧追到头顶，袖尾扫出从左下到右上的月弧。`

舞蹈、剑舞、武打、卡点动作和音乐切片素材在老胡明确需要后期切片时，要设计若干可切节点，但不是每个爆点都必须停成完整壁纸。节点可以承担人物识别、动作线条、道具 / 衣料轨迹、受力、环境反应或结尾封面中的一种主职责；只选择能加强本段主能量的主体落点、构图、光影、色彩、材质或模糊控制，不要求前中后景、留白和完整光色体系同时出现。

数字人舞蹈宣传片先确定要观众记住人物本人、动作线条、空间奇观还是某种主情绪。人物识别承重时可优先中近景、半身、膝上或七分身；完整跳跃、足下动作、群体队形、孤独感或空间尺度承重时，全景和远景可能更准确。当前《泠月·云袖照影》适合中近景主导，是因为目标是记住数字人本人，不升级成所有舞蹈宣传片的固定景别。时长按动作与情绪预演倒推；默认只写同期声，不主动加入 BGM。

当老胡明确要求 `15 秒卡点舞蹈`、`短视频冲击力` 或炫酷动作运镜时，先确定观众要记住人物、动作线、节奏冲击还是空间奇观，再设计开场识别、动作升级和结束落点。近景、半身、全身、推拉、甩镜、横移、环绕、低位上摇、袖面遮挡和匹配停点都是候选，不套固定镜头套餐；只有真正增加识别、力量或节奏的镜头才保留。默认只生成可供外部歌曲剪辑的视觉卡点与同期声，不生成 BGM。

人物情绪开场不能只写 `笑一下 / 伤心 / 生气 / 不屑`。凡是镜头任务主要靠人物表情和声音带观众入戏，`【画面内容】` 必须写出表情的肌肉路径和节奏：眼神先怎样扫过镜头，眼睑、眉峰、单侧嘴角、鼻翼、下巴、呼吸和停顿怎样变化，笑意是先出现、压住、扩大、冷掉还是断掉；肢体上只让肩颈、脸侧发丝、耳坠、项链吊坠和胸部以上衣料边缘跟着情绪轻动。短视频开场可以写不屑轻笑、单侧嘴角上扬、眼神停半拍、气口短促、说完后笑意收住，不能只写普通清冷微笑；表情主任务镜头不要用手指、包带、裙摆、腰间系带、鞋尖和脚步证明情绪。

情绪人像只有在皮肤、妆效、曝光、服装首饰或环境运动承担主注意力、身份识别或主情绪时，才定义对应正向状态。肤色、气色、妆效和纹理由地域、年龄、职业、年代、健康与人物此刻处境决定；冷白、暖肤、深肤、晒痕、雀斑、皱纹、无妆、年代妆、柔雾、油润或汗湿都可以正确。林栀案例可使用冷白偏中性、清透裸妆和柔雾奶油肌，但不扩展为美女默认模板。被选中的发丝、首饰、衣料和环境运动要指向脸部表演或角色身份；低位服装和脚步只在它们承担本镜任务时出现。

当一条视频提示词内部包含多个镜头或连续动作段落时，用以下自然导演语言组织：

```text
[中景→近景][连续手持后退转侧移] 同一镜头内写完整摄影机路径、主体动作和屏幕变化，只出现一次镜头头部。
[近景][硬切·正面急推] 前一镜动作形成停点后进入新机位，正文立即继承人物与道具状态。
[低机位中景][衣袖遮挡转场·侧后跟拍] 前景衣袖覆盖画面后进入新机位，正文立即继承姿势、余势、空间方向和声场。
[特写][动作匹配转场·固定机位] 用相同动作方向或形状匹配进入新注意力目标。
```

总时长写在平台参数或代码块外执行信息中；正式模型正文不写 `[0-3秒]`、`第0秒`、`动作段1（0-1.5秒）`。

动作密度检查：

```text
主体动作：是否有清楚起势、过程、结果。
镜头动作：是否写清机位、视角、推进 / 跟随 / 环绕 / 甩动 / 固定等方式。
空间关系：前景、中景、背景、主体和追赶 / 逼近 / 远离关系是否明确。
因果反应：动作是否带来发光、破碎、震动、烟尘、衣料摆动、表情变化或环境响应。
同期声：声音是否由画面动作产生，而不是泛泛写氛围音。
冲击结果：爆炸、冲击波、摔落、遮挡、强光、失焦、画面抖动等结果是否写出来。
```

复杂场面控制不能被动作密度检查替代。高密度群战、多兵器、多主体追逐、爆炸连锁和复合运镜允许保留复杂内容，但写作前必须先把全部事件放进同一套同步控制图：

```text
场景链：固定场地边界、通行净空、前中后景锚点和不会临时搬动的环境结构。
摄影机链：从哪个位置开始，沿什么真实路径移动，保持哪一侧观看，何时因什么条件跨轴，最后停在哪里。
人物链：每个人从哪里、朝哪里、以什么姿势开始；每次接触后停成什么姿势，怎样直接进入下一动作。
道具链：每件关键兵器 / 道具只有一个明确归属和数量；握持、方向、接触、脱手、损坏、飞行、落点和后续状态连续继承。
事件链：上一招形成的受力、失衡、遮挡、空位、余势、破坏或声响，怎样成为下一招的真实触发和空间条件。
```

五条链必须在每个决定性接触点汇合。复杂不是把多条精彩句子并排，而是多个参与者共享同一个时间、空间和结果。正式正文每推进一个动作段，先继承前一段仍然成立的关键状态，再写发生变化的部分；不能让人物恢复默认站姿、让武器恢复完整、让敌人换到未建立的位置，或借衣袖、水幕、烟尘和甩镜把摄影机任意传送到另一侧。

收到复杂生成失败反馈时，先做控制歧义诊断：同一对象是否出现多个位置 / 归属，摄影机是否无物理路径换侧，遮挡后是否重置场景，攻击来源是否提前建立，结束姿势能否进入下一招，道具损坏 / 脱手 / 落地是否继续继承。不要先把内容削成单人、单招或固定镜头；只有控制图已经闭合而平台仍反复失败，或老胡明确要求取舍时，才拆分素材或减少事件。

当前镜头的局部光影只有在承担主情绪、主体塑形、动作可读性或连续性时才展开，并嵌入 `【画面内容】`，不单独列成必填字段。写入时落到真实来源、方向、受光对象和可见结果；不承担职责时沿用全段光线基线即可。

画面内容不写内部时间戳。用镜头数量、动作数量、动作先后、切换触发、声音桥和停止画面控制节奏；总时长由 Seedance 平台参数设置。

转场写法用画面行为表达，不写场外说明。常用方式：

```text
危机型开头转场：倒计时、即将断电、即将碰撞、即将插入、即将爆开、即将击中镜头、即将揭晓等未闭合动作，在结果兑现前一瞬切入正文。
遮挡转场：袖口、云雾、仙旗、人物身体或巨门掠过镜头并短暂遮满画面。
明暗转场：画面被金白强光吞没、云影压暗、门内白光铺满后再收束。
运动转场：镜头被裂隙吸入、快速前推穿过云层、甩过飞檐后落到新主体。
匹配转场：上一镜的圆形仙印、裂隙、龙眼、浮灯与下一镜相似形状或光源衔接。
动作转场：拂袖横扫、仙旗掠过、法器展开、巨门开启等大动作覆盖画面边缘。
硬切准备：镜头结束在稳定构图、清晰动作停点或声音收束上，方便直接硬切。
```

不要每个镜头都使用同一种黑场或白场。转场要服务当前镜头内容：奇观镜头可用高亮/吸入，人物礼仪镜头可用动作停点或遮挡，宏大场景可用运镜方向和形状匹配。

危机型转场要写得像真实可拍的动作链。手机倒计时要写屏幕数字、剩余电量、充电头位置、接口距离和黑屏切点；卡车 / 车辆逼近要写道路宽度、左右边界、车灯和车身从远到近的速度变化、风压和尘土、撞上前一瞬用灯光或车身暗影压满画面；打铁花要写铁水抛起、击打、火花方向、火星密度、火花如何铺满镜头以及火星退去后的正文主体；棒球撞镜要写投球路径、击球瞬间、球体沿镜头轴线放大、皮革缝线短暂清晰、撞镜一瞬的震动 / 失焦和下一帧揭示。不要把 `危险`、`紧张`、`强冲击` 当成结果，必须让观众看见导致紧张的物理过程。

### 商业卖点的画面编译

商业广告进入视频提示词前，必须已经有一个可执行商业简报。对每个承重卖点，先写内部编译链：`用户处境 → 问题触发 → 产品结构 / 功能参与 → 接触与受力 → 可见 / 可听结果 → 用户利益 → 文案命名`。正式 `【画面内容】` 只写观众能看见、听见的部分，但链条任一中段缺失都不得出稿。

画面证据要直接落到产品上：透气要看见网孔、弯折与空气结果；稳定要看见接触点、支撑结构、身体轴线和脱离结果；回弹要看见材料压缩、形变恢复和人物加速；抓地要看见鞋底分区接触、水 / 尘排开和运动轨迹不打滑。不用粒子线、发光数据、漂浮标签和泛化科技 VFX 替代真实证据，除非该作品本身就是风格化科幻广告。

旁白、口播、屏幕文字和品牌句必须与画面证据按意义同步。文案可以在证据出现前制造期待，也可以在证据出现后给结论，但不得同时讲 A 卖点而画面只展示 B 卖点。老胡未给文案时，继承编剧模块主动设计的精确文案；没有这一层且它对商业目标承重时，不得把“无人声、只保留同期声”当成默认高级选择。

## 内置质量校准视角

以下视角只用于提高分镜和视频提示词质量，不改变输出结构，不在正式提示词中新增专家分析或作者说明。

| 视角 | 内部校准方式 |
|---|---|
| Akira Kurosawa | 分镜要有天气、尘雾、旗帜、衣袖、群体运动等动态层次，让画面不是静态设定图。运动方向要清楚，剪辑点要有力。 |
| Saul Bass | 每个镜头只抓一个强视觉概念：形状、遮挡、符号、动作或构图。提示词要减少无关堆砌，让模型知道第一眼该生成什么。 |
| Harold Michelson | 分镜先解决画面来源和空间关系：观众最终看见什么，主体在哪里，画面从哪里开始、怎样移动、停在哪里。宏大场景也要有可执行的屏幕结果。 |
| Hayao Miyazaki | 奇观必须有生活感和近景锚点：风吹衣角、手触玉栏、云气掠过脸、法器微震。不要全是远景大场面。 |
| Ridley Scott | 世界观要通过材质、烟雾、光源、机械/建筑细节和人物调度显出来，不靠解释性文字。 |
| Roger Deakins | 光线要有来源和方向，构图服务情绪。不要为了高级感使用无法生成或互相冲突的光影词。 |

## 分镜宏观表

如果老胡只是要看全局，用简表，不展开完整提示词：

| 编号 | 所属场次 | 时长 | 镜头任务 | 表情细化 | 表情来源 | 表情功能 | 表情占用时长 | 简要内容 |

| E1-S1-C1 | 第1集 1-1 | 12 秒 |  | 是 / 否 | 剧本括号 / OS / 动作描述 / VO 回响 / 无 | 核心任务 / 辅助状态 / 不需要 |  |  |

规则：

- 编号使用 `E1-S1-C1`。
- 插入用 `E1-S1-C5A`。
- 总时长用确定值。
- 表情需要细化时，必须先给表情留时间，并写清表情来源。来源优先从剧本里的语气 / 神态括号、OS、VO 状态、动作描述和插入镜头里提取。
- 每个镜头只承担一个主任务：进入、揭示、反应、动作、转场或记忆点。不要让一个短镜头同时承担过多信息。
- 宏大场景、人物近景、道具特写、POV 运动和转场镜头要形成节奏变化；不要整片都是远景奇观。
- 如果用户同时要求“分镜表 + 第一条提示词展示”，且剧本已确认，可以在同一轮写两个文件；但仍不能跳过第一条展示直接写全部提示词。

正式生成前还要为每个 `VID` 做一次 `剪辑接口编译`。这不是强行增加镜头，而是先判断这条生成结果作为素材时，哪里可以安全进入、哪里可以裁切、哪里能把某种可匹配属性交给下一条：

```text
素材主任务：必须保住的表演 / 动作 / 卖点 / 奇观。
推荐入点：稳定起始状态；可接收的动作、视点、图形、声音或语义属性。
内部可切节点：动作相位、视线 / 焦点落点、遮挡满屏、光色峰值、重音、台词停顿或结果停点。
推荐出点：准备交出的主要匹配属性与辅助属性。
干净把手：核心事件前后可安全保留的稳定画面 / 声音余量。
不建议裁切：未完成接触、未知落点、表演尚未兑现、半句台词、未完成声音尾韵。
后期依赖：无 / 抠像 / 蒙版 / 屏幕替换 / 绿幕 / 变速 / 叠化 / 关键帧。
```

选择接口按 `主情绪与故事 → 节奏 → 观众视点 / 注意力 → 运动与空间 → 图形 → 声音 / 语义` 校准。一次切换通常只需一条主要匹配通道和一条辅助通道，不把所有转场机制塞进同一素材。一镜到底情绪表演只保留不破坏表演累积的头尾把手；动作、舞蹈、MV 和快节奏广告按动作相位或节拍增加节点；产品广告优先把产品细节、手部交互、卖点结果、品牌英雄帧和声音重音设计成可剪节点。

接口规划写在正式代码块外；进入模型正文时必须翻译为观众可见 / 可听的结果。`推荐出点：遮挡` 应编译为 `红色衣料从左向右掠过并完整覆盖画面，褶皱与摩擦声保持清楚`；`声音先行` 应编译为 `门后女声先进入当前声场，人物听见后转头，镜头仍停在当前房间`。禁止把 `剪这里、入点、出点、J-cut、L-cut、后期抠像` 写进三段正文。

## 失败分支

```text
没有剧本来源 → 先形成单场次剧本，不直接写视频提示词。
具体人物跨多条提示词但没有图片资产 → 合并到 15 秒以内，或退回视觉资产阶段。
画面内容过多 → 拆镜头；每条提示词只保留一个主任务。
只有远景奇观 → 增加近景锚点、身体感、人物反应、道具或材质特写。

```

## 自检

- 是否完成视频画面内容四核：主体与注意力目标、动作与表演、效果系统、节奏与时长是否形成一条观看因果链，而不是四类词语拼盘。
- 每个镜头是否只有一个主注意力目标；景别、焦点、运动、明暗色彩、导引线和声音是否共同指向它；注意力迁移是否有动作、视线、焦点、声音或切镜触发。
- 每个情绪节拍是否只有一个主情绪目标；是否分别回答主注意力目标、主观看任务和主情绪目标；如果发生情绪转折，是否写清起点情绪、触发、变化证据和终点情绪。
- 运镜内部是否按 `观看意图 → 摄影机物理路径 → 屏幕变化 → 情绪倾向 → 停点` 推导；正式正文是否只写可感的方向、轨迹、速度、稳定度、主体 / 背景 / 焦点 / 地平线变化和最终构图，没有用机身或设备叙事代替画面。
- 是否避免把运镜情绪写成固定字典；推、拉、摇、移、手持、FPV、横滚、希区柯克变焦是否结合当前主体、速度、焦点、声音和上下文选择。
- 焦点、环境、光色、速度和声音效果是否各有来源、变化过程、可见 / 可听结果和情绪职责；画外声音是否建立了镜头之外的空间。
- 时长是否覆盖主体识别、动作完成、情绪建立、效果展开和停点余量；内容过载时是否加时长、删次要效果、减镜头或拆素材，而不是压缩到观众来不及感受。
- 是否把生成结果按可剪辑素材设计，并在代码块外给出推荐入点、内部节点、推荐出点、匹配属性、干净把手和不建议裁切点；接口数量是否由内容决定而非固定模板。
- 每个计划接口是否形成 `出镜证据 → 可读边界 → 入镜证据`；切点两侧是否有可选择的稳定画面 / 声音范围，而非偶然一帧。
- 是否优先守住主情绪、故事和节奏，再选择注意力、运动、图形、遮挡、声音或语义通道；是否避免为做转场牺牲人物选择、卖点证据或动作因果。
- 正式三段正文是否只写观众可见 / 可听结果，没有出现 `入点、出点、剪辑接口、方便裁切、J-cut、L-cut、后期抠像` 等作者说明。
- 是否按图生视频 / 文生视频 / 实际资产引用调整描述预算；输入已经固定的外观是否避免重复，模型没有看见的主体和场景是否写足。
- 如果是首尾帧双端锚定模式，是否明确引用 `【首帧参考@图1】` 和 `【尾帧参考@图2】`；是否完成必须保持、必须改变、共同桥梁和最大断裂点分析；中间状态链、摄影机路径、尾帧召回、减速收束和落帧是否完整。
- 是否在基础设定声明只生成对白、动作声、衣料声、道具声和环境声，不生成 BGM；每个镜头实际出现的环境音和动作音是否分别写入本镜括号，只有老胡明确要求时才改变。

- 是否有单场次剧本来源。
- 是否已经读取并应用 `高质量AI视频提示词开发计划.md`；涉及图片参考、首帧、封面、治愈系画面或音乐卡点镜头时，是否也应用 `高质量AI图片开发计划.md`。
- 是否通过低信息密度退稿：正式提示词是否没有只靠 `治愈、唯美、电影感、高级、真实、清新、自然、氛围好、光影好、情绪饱满` 等泛词承重；这些词是否已经展开成镜头、表演、声音、光影、色彩、空间、材质、时间和剪辑停点。
- 写作前九项导演判断是否已经落地：镜头任务、镜头关系、表演变化、声音表演、光影系统、色彩系统、空间层次、材质细节、剪辑连续是否至少覆盖本镜承重项。
- 正式扩写前是否已有成立的导演镜头构思：事件节拍、决定性瞬间、动作 / 调度几何、摄影机观看位置、画内证据和光影落点是否互相支持；如果只有概括剧情和普通景别，是否退回分镜候选竞争。
- 去掉风格、材质、雨雾、颗粒和画质描述后，镜头骨架是否仍能看出故事、主情绪和观看力量；是否避免用提示词长度掩盖镜头构思贫弱。
- 是否完成视频时间关系链判断：起点状态、触发事件、动作路径、表演变化、镜头路径、光影变化、声音进入和退出、峰值停点、尾帧接续是否互相咬住；是否避免只写单帧美而缺少时间秩序。
- 音乐卡点、治愈系画面、氛围空镜和转场素材是否也写清画幅、景别、机位、运镜、主体落点、前中后景、光源方向、色彩影调、材质细节、环境运动、卡点停点和可接续尾帧，没有降级成漂亮画面短句。
- 是否按“剧本 → 导演镜头构思 → 分镜表 → 第一个分镜提示词内部校准 → 全部分镜提示词”的内部质量门推进。
- 是否把正式内容写入文件，并在聊天中给具体文件链接和阶段摘要，不为普通创意询问下一阶段。

## 证据尺寸、角色审美与举例边界

- 正式画面先列本条必须被观众看清的证据，再按证据尺寸分配景别。指尖装置、按钮接触、文字和甲片接缝需要微距 / 特写；口型、眼神和气质变化需要面部近景 / 特写；完整穿搭、动作路径、铠甲覆盖、翼数和英雄姿态需要全身中远景 / 全景。
- 一镜到底不等于固定使用一个中景。连续镜头可以升降、推拉、环绕并依次跨过腿部特写、腰部微距、面部近景和全身景别；每次移动都要由人物动作或新证据触发，焦点、背景透视和空间方向连续。
- 角色所属道具必须延续角色与服装的审美系统。写动作前先检查道具尺度、重量、佩戴 / 握持位置、材质、色彩和操作姿态是否符合角色身份与身体工学；不允许功能正确但造型违和的装置破坏人物气质。
- 强风格化变身必须把过程拆成可见结构完成节拍：传播来源、覆盖顺序、单个部件成形、接缝锁定、材质硬化、光声反馈、环境倒影或受力结果。华丽不是粒子更多，而是观众能看清每一层如何完成并等待下一层。
- 变身、换装、损坏、修复和形态升级先建立互斥状态账本。正式提示词写清 `只继承的人物身份`、`上一状态逐区消失`、`新状态逐区覆盖` 和 `完成后禁止残留`；不能为了连续性把日常短裙、丝袜、鞋履或首饰保留在完整战斗形态上，也不能靠白闪让旧状态无因消失。
- 用户说“比如”“类似”“可以理解成”“之后可能”时，先判断它是在解释动机、功能或气质，还是确认画面事实。未确认出现的怪兽、敌人、品牌、招式和场景不得自动加入；可以用声音、光、影、风压或画内反应表达已确认的危机感。

当前案例：TEST-007 用 50mm 连续物理路径从变身前丝袜高跟腿部特写进入 18mm 腰扣微距，再上升到台词面部近景，随后后退环绕看丝袜、短裙与高跟鞋逐区被全覆盖腿甲、护髋和稳定战靴替换，最后落到六翼低机位定姿；完成形态不残留平民服装，也不把用户用于说明变身动机的怪兽放进画面。
