# 视频提示词核心

## 能力定位

把剧本场次、分镜或视频创意推进成可生成、可诊断、可剪辑的完整视频提示词。

这个 skill 合并原先的视频基础设定、氛围画质、人物表演、画面内容和提示词组装。它不是拼接器，而是视频导演说明书：先判断剧本来源和镜头任务，再设计表演与时长，最后输出完整三层提示词。

优先读取：

- `02_共享资产库/00_核心规则手册.md`

## 能力加厚纪律

每条正式视频提示词必须按独立生成请求处理，包含完整的【基础设定】【氛围与画质】【画面内容】三部分。AI 视频平台不会读取上一条分镜、全片设定或项目上下文，所以正式投喂正文不能写“沿用全片”“参考上文”来替代实际内容。

前两部分可以从同一作品的规则中复用内容，但输出到正式提示词时必须逐条完整重写。基础设定和氛围画质是全片统一层，不是当前镜头剧情说明；当前分镜才发生的动作、事件、局部声音和一次性视觉变化，写进 `【画面内容】`。

视频提示词不能跳过剧本来源。即使老胡没有直接说“写剧本”，也要先形成或引用单场次剧本。

人物表情不是最后补词。分镜宏观表阶段必须判断表情是否需要细化、是否占用时长；需要时先设计表演，再写画面内容。

人物、场景或道具需要跨多个独立生成分镜保持同一个具体外观时，必须先判断是否有资产支撑。人物外观一致性优先依靠图片资产；文本资产只能固定类型、妆造和气质，不能保证同一张脸。

未建立图片资产时，不要让同一个具体人物跨多个独立视频提示词反复出现。处理顺序：

```text
不要求一致 → 降级为单镜头画面元素。
同场连续动作且总时长不超过 15 秒 → 合并成一个分镜 / 一条提示词。
必须跨多条提示词保持一致 → 退回 laohu_visual_assets 建立图片资产。
```

同一场景、同一未资产化人物、连续动作不超过 15 秒时，优先合并。合并后在 `【画面内容】` 用确定时间段写清楚 `第0秒-第2秒`、`第2秒-第5秒`，但镜头总时长必须仍是确定值。

正式提示词的详细度主要落在 `【画面内容】`。不要只让基础设定和氛围画质很长，而画面内容只有一两句。每条执行稿都要写清楚主体动作、环境变化、镜头路径、构图层次、表情占用、同期声和片内转场。

单条正式视频提示词正文必须控制在 2000 字以内。基础设定写全片稳定规则，氛围与画质写全片统一审美，画面内容写当前分镜执行细节。不要为了显得完整而输出需要老胡二次删减的长稿。

视频创作输出必须按确认门推进：

```text
1. 整个内容的剧本输出文件，等待确认。
2. 完整设计的分镜表格输出文件，等待确认。
3. 第一个分镜的视频提示词展示文件，等待确认。
4. 所有分镜视频提示词结果输出文件，等待确认或交付。
```

除非老胡明确要求一次性全部输出，否则不能越过当前确认门。尤其不能在剧本尚未确认时直接输出全部分镜提示词。

STOP/CHECKPOINT：

```text
剧本输出文件完成 → 停，等老胡确认后再做分镜表。
分镜表格输出文件完成 → 停，等老胡确认后再写第一条视频提示词展示。
第一条视频提示词展示文件完成 → 停，等老胡确认后再写全部分镜提示词。
全部分镜提示词结果文件完成 → 停，等老胡制作视频并回传结果后再复盘。
```

所有正式内容必须写入文件。对话里不要贴长篇剧本、完整分镜表或完整视频提示词集合，只给文件链接、阶段摘要和是否进入下一阶段的确认问题。

分镜表、第一分镜视频提示词、全分镜视频提示词默认在同一个阶段文件上迭代更新，不自动新建 v1/v2/v3。只有老胡明确要求新增版本、另存一版、保留旧版或 A/B 两版时，才创建新版本文件。

正式视频提示词必须严格按照 `02_共享资产库/01_模板库/视频模板/模板_视频提示词_基础设定氛围画面内容.md` 输出。剧本、分镜表、流程判断、前置判断、资产判断、生成前检查、回传字段和作者说明都是提示词外的评审材料，不得混入正式提示词正文。

正式提示词正文只允许使用以下三块：

```text
【基础设定】
【氛围与画质】
【画面内容】
```

不要在正式提示词里临时新增【前置判断】【负面约束】【生成前检查】【回传字段】【后期备注】等块。需要表达禁止项时，写进模板字段 `全局禁止` 或 `禁止方向`。

正式提示词只能写给视频模型看的画面、声音、动作、镜头和质感。不要出现给作者、剪辑师或助手看的话，例如“分镜编号”“所属场次”“镜头任务”“本条是否独立完整”“复制本条”“前一个画面”“下一个镜头”“接 E1-S1-C2”“后期备注”“为下一条做准备”。如果需要做分镜衔接，必须把它改写成画面内可生成的转场行为。

`【基础设定】` 的职责：写全片通用的世界观、稳定角色类别、生物 / 人群规则、建筑场景、道具规则、声音总规则和全局禁止。例如仙侠题材里的仙人服饰体系、东方中式古建筑、白玉宫阙、云海、神兽礼仪、不要配乐只保留同期声。

`【氛围与画质】` 的职责：写全片统一的风格核心、视觉基调、色彩影调、画面质感、镜头语言倾向和禁止方向。它用于保证后期拼接时 C1、C2、C3 像同一条视频，不是当前镜头的局部氛围说明。

`【画面内容】` 的职责：写当前分镜的确定时长、景别 / 构图、专业运镜、具体画面动作、人物表演、关键声音和片内转场。运镜写镜头如何运动，不要把“拂袖横扫”“巨门打开”这类画面动作写成运镜。声音细节写进画面内容中，说明声音从什么动作或物体产生。

画面内容不默认逐秒拆死。短镜头可以用自然语言写整体画面效果；只有关键节点必须精确控制时，才写确定时间点，例如“约第2秒裂隙亮起”“第6秒台词出口”。

转场写法用画面行为表达，不写场外说明。常用方式：

```text
遮挡转场：袖口、云雾、仙旗、人物身体或巨门掠过镜头并短暂遮满画面。
明暗转场：画面被金白强光吞没、云影压暗、门内白光铺满后再收束。
运动转场：镜头被裂隙吸入、快速前推穿过云层、甩过飞檐后落到新主体。
匹配转场：上一镜的圆形仙印、裂隙、龙眼、浮灯与下一镜相似形状或光源衔接。
动作转场：拂袖横扫、仙旗掠过、法器展开、巨门开启等大动作覆盖画面边缘。
硬切准备：镜头结束在稳定构图、清晰动作停点或声音收束上，方便直接硬切。
```

不要每个镜头都使用同一种黑场或白场。转场要服务当前镜头内容：奇观镜头可用高亮/吸入，人物礼仪镜头可用动作停点或遮挡，宏大场景可用运镜方向和形状匹配。

## 内置质量校准视角

以下视角只用于提高分镜和视频提示词质量，不改变输出结构，不在正式提示词中新增专家分析或作者说明。

| 视角 | 内部校准方式 |
|---|---|
| Akira Kurosawa | 分镜要有天气、尘雾、旗帜、衣袖、群体运动等动态层次，让画面不是静态设定图。运动方向要清楚，剪辑点要有力。 |
| Saul Bass | 每个镜头只抓一个强视觉概念：形状、遮挡、符号、动作或构图。提示词要减少无关堆砌，让模型知道第一眼该生成什么。 |
| Harold Michelson | 分镜先解决空间和镜头位置：观众在哪里，主体在哪里，镜头从哪里进、到哪里停。宏大场景也要有可执行机位。 |
| Hayao Miyazaki | 奇观必须有生活感和近景锚点：风吹衣角、手触玉栏、云气掠过脸、法器微震。不要全是远景大场面。 |
| Ridley Scott | 世界观要通过材质、烟雾、光源、机械/建筑细节和人物调度显出来，不靠解释性文字。 |
| Roger Deakins | 光线要有来源和方向，构图服务情绪。不要为了高级感使用无法生成或互相冲突的光影词。 |
| Emmanuel Lubezki | 长镜头或 POV 镜头要让镜头和身体感绑定：移动、停顿、转头、穿越、被光吞没，都要让观众感觉自己在场。 |
| Vittorio Storaro / 张艺谋 | 色彩要有情绪功能和主次层级。仙界可以金白、青玉、朱红点睛，但不能每个镜头都无差别铺满同一种颜色。 |
| 胡金铨 / 徐克 / 程小东 / 袁和平 | 仙侠运镜要结合身法、袖势、飞檐、云层、法器、门阙和空间纵深。动作写进画面内容，镜头运动写进运镜。 |
| Runway Academy / OpenAI 提示工程 | 正式提示词要清晰、具体、无矛盾，聚焦主体、场景、运动、镜头、风格和限制；不要把流程判断、引用编号或上下文依赖写进投喂正文。 |

使用这些视角时只优化三个结果：分镜任务更清楚，画面内容更可生成，镜头之间更可剪辑。

POV 横屏镜头硬检查：

```text
必须有第一人称身体感：袖口、手势、门槛、云雾、法器、光压、前景遮挡或被吸入的运动。
必须写清镜头路径：从哪里开始，怎样移动，经过什么前景 / 中景 / 远景，在哪里停住。
必须区分动作和运镜：拂袖、开门、法器展开是画面动作；推进、环绕、穿越、甩镜、俯冲、后撤是运镜。
必须有景别变化：横屏奇观镜头也要安排近景锚点、中景人物 / 动作、远景空间尺度。
必须有可剪辑停点：动作完成、光线收束、镜头停稳、遮挡铺满或声音收住。
```

## 能力边界

可以产出：

- 单场次视频提示词。
- 多镜头分镜概览表。
- 人物表演与表情时间点。
- 基础设定、氛围与画质、画面内容。
- 参考素材职责和负面约束。
- 生成前检查和回传字段。

不负责：

- 自动调用高成本视频生成。
- 替代图片资产固定。角色/场景不稳时，应回到 `laohu_visual_assets`。
- 生成后复盘。结果回来后交给 `laohu_generation_review`。

## 分镜宏观表

如果老胡只是要看全局，用简表，不展开完整提示词：

| 编号 | 所属场次 | 时长 | 镜头任务 | 表情细化 | 表情占用时长 | 简要内容 |
|---|---|---:|---|---|---:|---|
| E1-S1-C1 | 第1集 1-1 | 12 秒 |  | 是 / 否 |  |  |

规则：

- 编号使用 `E1-S1-C1`。
- 插入用 `E1-S1-C5A`。
- 总时长用确定值。
- 表情需要细化时，必须先给表情留时间。
- 每个镜头只承担一个主任务：进入、揭示、反应、动作、转场或记忆点。不要让一个短镜头同时承担过多信息。
- 宏大场景、人物近景、道具特写、POV 运动和转场镜头要形成节奏变化；不要整片都是远景奇观。
- 如果用户同时要求“分镜表 + 第一条提示词展示”，且剧本已确认，可以在同一轮写两个文件；但仍不能跳过第一条展示直接写全部提示词。

## 失败分支

```text
没有剧本来源 → 先形成单场次剧本，不直接写视频提示词。
具体人物跨多条提示词但没有图片资产 → 合并到 15 秒以内，或退回视觉资产阶段。
画面内容过多 → 拆镜头；每条提示词只保留一个主任务。
只有远景奇观 → 增加近景锚点、身体感、人物反应、道具或材质特写。
运镜和动作混淆 → 动作写进画面内容，镜头移动写进运镜。
提示词超过 2000 字 → 压缩解释性描述，保留可见主体、动作、镜头、声音和限制。
```

## 自检

- 是否有单场次剧本来源。
- 是否按“剧本 → 分镜表 → 第一个分镜提示词 → 全部分镜提示词”的确认门推进。
- 是否把正式内容写入文件，并在聊天中只给文件链接和下一阶段确认问题。
- 是否默认更新同一个输出文件，没有自动制造 v1/v2/v3。
- 是否使用 `E1-S1-C1` 编号。
- 总时长是否是确定值。
- 是否区分概览稿和执行稿。
- 是否包含基础设定、氛围与画质、画面内容三部分。
- 正式视频提示词是否严格按模板字段输出，没有混入剧本、分镜说明、流程判断、前置判断、生成前检查、后期备注或回传字段。
- 正式提示词是否不超过 2000 字。
- 正式提示词是否没有 `分镜编号`、`所属场次`、`镜头任务` 这类作者字段。
- 基础设定和氛围画质是否是全片统一层，而不是当前分镜画面内容的重复描述。
- 正式提示词是否独立完整，没有用“沿用全片”“参考上文”替代基础设定或氛围画质。
- 正式提示词是否只写视频模型能生成的内容，没有出现“复制本条”“前一个镜头”“下一个镜头”“接某编号”等场外说明。
- 前两部分是否根据当前分镜必要时局部调整，并在当前提示词内完整写出。
- 跨分镜复用的具体人物是否有图片资产；没有图片资产时是否已经合并到 15 秒以内同场镜头，或降级为单镜头画面元素。
- 画面内容是否达到执行稿详细度，而不是只写一句镜头概括；时间点是否只在关键节点使用，没有逐秒硬拆死。
- 运镜是否写的是镜头运动路径、速度、停点和视角变化，而不是把人物动作误写成运镜。
- 画面内容是否有主体、空间、材质、动作、声音、表演或环境运动的可见细节。
- 宏大镜头是否有近景锚点或沉浸视角，特写镜头是否给了足够时间让表情、材质或动作被看见。
- 如果需要衔接，是否已经写成画面内转场行为，而不是后期备注。
- 涉及人物时是否判断表情细化和占用时长。
- 是否完整可复制，不需要老胡再拼装。
- 是否输出回传字段，方便生成复盘。

## 反例黑名单

- 不要在正式提示词代码块里写分镜编号、所属场次、镜头任务、生成前检查、回传字段或后期备注。
- 不要写“沿用全片”“参考上文”“接上一镜”来替代完整提示词。
- 不要新增【前置判断】【负面约束】【作者说明】等正式提示词块。
- 不要写模糊总时长，例如 `10-12 秒`。
- 不要把每个短镜头逐秒控制死；只在关键节点写确定时间点。
- 不要把拂袖、开门、冲击波、巨兽转头这类画面动作写成运镜。
- 不要让横屏 POV 只剩空中航拍；必须有身体感、前景锚点或视角受力。
- 不要每个镜头都黑场 / 白场转场，转场必须服务当前画面。
