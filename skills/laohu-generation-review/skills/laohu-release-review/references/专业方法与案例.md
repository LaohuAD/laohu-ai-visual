# 发布复盘：专业方法与案例

## 当前专业决策

曝光→点击→观看→行动是不同分母的阶段；混杂因素是发布时间、受众、分发来源等同时改变的条件。一次改标题后CTR上升不能单独证明标题因果，因为平台可能换了观看人群。

先确定商业/观众目的→登记平台、窗口、样本、分母与来源→拆入口与兑现→对照真实封面/前段/关键流失时点→形成有限假设→写最小可验证变化与保护项。仅在有真实发布证据且已明确要求时做实验建议，不将A/B设为每次生产门。

### 同一材料候选比较

候选A：同一CTR上升：直接宣布新标题获所有用户喜欢。

候选B：先分流量来源与受众变化，再比同口径CTR和观看兑现，只提出证据支持的入口假设。

取舍：后者保护分母与混杂条件，前者把相关变成因果。

适用与反例：没有数据只做内容制作诊断；不默认每次生产都做实验，不假造完播和转化。

### 编译或返修结果示例

“若推荐流点击偏低但搜索流稳定，先检查缩略图在推荐流是否能区分主体与标题；只调整入口可读性，保留正片。结论写‘值得验证的入口假设’，不写‘用户不喜欢这类内容’。”

### 返回合同

返回平台窗口/分母/来源、漏斗断点、混杂解释与最小验证假设；指出本次改变哪个决定、原有哪项事实不能动、从哪个状态开始以及下一负责人如何验收。输入缺口影响因果时停止专业深化，带证据返回；不把下游修词当作上游事实已存在。

## 发布复盘

发布后先继承导演阐述的目的与传播假设，再按漏斗定位。记录目标观众、分发条件、样本范围与真实流失位置；相关信号只提出待验证原因，不能自动归因。治愈看陪伴与关系缓解，审美短片看感知和重看，知识内容看理解、复述与使用，商业内容按已确认目标看信任和行动；不把完播或互动单一指标当作所有作品的成功标准。

| 卡点 | 典型信号 | 优先回流 |
|---|---|---|
| 曝光低 | 平台给量少、初始互动弱 | 选题、发布时间、账号定位 |
| 点击低 | 有曝光但播放少 | 封面、标题、第一眼钩子 |
| 前 3 秒流失 | 快速划走 | 先查受众是否匹配与开头承诺是否可辨，再查画面、第一句或必要变化 |
| 中段流失 | 平均观看低、看不懂 | 剧本结构、分镜节奏、信息密度 |
| 完播低 | 后半段掉完 | 按流失位置核对观看承诺、理解成本、节奏与兑现时机；不自动补反转 |
| 互动低 | 看完但不评论点赞 | 先确认互动是否为作品目的，再查情感回应、实用回报或表达入口；不自动加争议 |
| 制作吐槽集中 | 画面、声音、字幕、变脸被反复提 | 对应回到资产、提示词或剪辑 |

下面是按目的选用的传播假设库，不是通用扣分清单。只读取与当前主推进力和已有症状相符的条目：争议、喜剧、痛点只在作品明确依靠它们时检查；低冲突、克制、留白或没有成长出口本身不扣分。每个采用的假设写清支持证据、反例和最低成本复验；无证据时记待验证。

短视频流量表达复盘：

```text
表达是否太顺：观点是否只是正确、平稳、无反差。
表达是否太安全：是否没有任何可评论、可争论、可转述的偏离点。
表达是否太理性：是否只在证明逻辑正确，缺少感性反应、关系感和让观众卷入的情绪入口。
是否只突出优点：人物、品牌、产品或观点是否只被赞美，缺少可被接受的缺点、边界和共同敌人。
是否被选择性忽视：表达是否太熟悉、太平滑、太像正确套话，缺少能打断惯性注意的轻微跑调点。
风格是否被讨好磨平：是否想让所有人都喜欢，导致立场、语气、角色缺点和视觉记忆点都不锋利。
是否直接采用第一反应：标题、钩子、金句、主物象、风格核心、结尾余味句是否没有经过 3-5 个方向候选竞争。
是否同题材可替换：这句话、这个标题、这个风格句或这个视觉概念是否能换到任何同类作品里仍然成立。
是否关系命名过泛：是否只写遗憾、释怀、温柔、治愈、破碎、成长、热血、英姿飒爽，没有说清具体关系压力或人物处境。
是否留白空心：是否只写神秘、余味、含蓄、意境，而没有动作、物象、空间块面、遮蔽比例、声音停顿或尾帧停点托住。
喜剧是否缺席：是否能加入狠词怂态度、言不由衷、经典借用、自嘲或错位表达。
浅深比例是否失衡：是否全是浅内容抓眼球，缺少能留下铁粉的深内容；或全是深内容，缺少轻快入口。
争议是否服务主题：争议必须让观点更鲜明，不能只是制造噪声。
是否疑似卖惨：困难是否只在索取同情，缺少和解、励志、行动或成长出口。
故事杠杆是否缺失：是否没有大脑墙、痛点杠杆、金句钉、共鸣网或利他金，导致内容正确但无法穿透、记住、扩散或转化。
痛点是否太弱：是否没有唤起真实损失、风险、错失、不甘或难受，导致观众只是在旁观而不是参与。
金句是否像个体宣言：广告语、口播金句或品牌表达是否只是正确话，缺少明确立场、反常识角度和替某类人发声的力量。
```

曝光和互动都弱时，先区分分发样本、受众匹配、点击入口与内容兑现；只有证据指向表达断点才回到 `laohu-script-writer`，不能以“选题不差”的主观判断排除其他原因。

## 研究依据与验证边界

YouTube说明CTR受流量来源/展示场景影响，留存图的峰谷可辅助寻找重复观看、跳过和流失。[CTR FAQ](https://support.google.com/youtube/answer/7628154?hl=en)、[Audience retention](https://support.google.com/youtube/answer/9314415?hl=en)。平台定义仅适用其统计口径；峰值也可能是困惑重看，不能直接认定受欢迎。

本页的项目编译链与原创例子是本地方法设计；专业资料不证明生成模型一定遵从，也不证明观众效果已经发生。平台控制每次实际执行前重新核验。
