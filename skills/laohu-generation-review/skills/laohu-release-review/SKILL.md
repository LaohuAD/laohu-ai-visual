# 老胡发布复盘

## 灵魂：数字先说明发生了什么，原因需要条件和证据。

发布数据必须连同分母与观察条件理解。区分曝光、点击、观看与兑现，流量来源改变时保留混杂解释，不把相关当因果。

## 筋骨：先把判断接到输入与结果

本专业接收当前作品任务、上游锁定事实和允许改变范围；先核对是否存在“已有发布数据或明确用户反馈，需要判断入口、观看兑现或行动转化”的缺口，已成立部分直接继承。先确定商业/观众目的→登记平台、窗口、样本、分母与来源→拆入口与兑现→对照真实封面/前段/关键流失时点→形成有限假设→写最小可验证变化与保护项。仅在有真实发布证据且已明确要求时做实验建议，不将A/B设为每次生产门。

## 血肉：让候选产生可见或可听差异

曝光→点击→观看→行动是不同分母的阶段；混杂因素是发布时间、受众、分发来源等同时改变的条件。一次改标题后CTR上升不能单独证明标题因果，因为平台可能换了观看人群。

同一材料下比较“同一CTR上升：直接宣布新标题获所有用户喜欢。”与“先分流量来源与受众变化，再比同口径CTR和观看兑现，只提出证据支持的入口假设。”。后者保护分母与混杂条件，前者把相关变成因果。专业方法、完整案例、例外和失败修复见[专业方法与案例](references/专业方法与案例.md)，只读取本次缺口对应章节。

## 表皮：交出可复验的专业结果

返回平台窗口/分母/来源、漏斗断点、混杂解释与最小验证假设。写明胜出理由、已保护事实、未证实假设和下游必须继承项。没有数据只做内容制作诊断；不默认每次生产都做实验，不假造完播和转化。

## 调用与返回

可由[父入口](../../SKILL.md)或其他实际负责人按缺口CONSULT，也可接受明确点名的独立任务。CONSULT结果返回实际调用者，不一律返回所属父入口。直接专业请求只要求本次判断必要的目的、材料、约束和事实；这些已经足够时直接执行，不强制先有完整父合同、导演阐述或整部剧本。只有缺口会改变当前因果或已锁事实时，才以证据RETURN最早负责人。不得改写源剧本、冻结文字、资产身份或已确认时间。整部作品仍由实际作品负责人整合，本子不以“已阅读”或格式齐全冒充已完成作品。

仅在明确复盘或真实问题已路由时执行；没有实物只给文本/口述初判，不虚构模型原因、听试或观众效果，不为正常生产强制A/B。返修最多三个动作，须注明执行负责人。
