# 视频评审：专业方法与案例

## 当前专业决策

首个失配帧是实际状态首次偏离已定因果/身份/空间的时间点；状态等式是A真实结束与B真实起点的必要相容关系。后续所有漂移可能源于同一坏首帧，所以不平均修所有词。

正常速度首看→标实际时间码→关键帧核对身份/动作/空间/来源→核对实际绑定/入口→必要时单变量实验。适合生成视频、跨批次连续失败；反例是挑一帧好图证明整条稳定、尚无实物就说模型吞动作、同时改五个变量后宣称找到根因。

### 同一材料候选比较

候选A：同一跨批次信封漂移：同时改五条提示词、首帧和模型。

候选B：先比A真实末态与B首态，核对B实际绑定，再只改变最可能错误的一项并记录保护项。

取舍：后者能检验根因，前者只产新候选无法证明哪项有效。

适用与反例：没有真实结果不宣布模型遗忘；正常生成不强制A/B或多模型比赛。

### 编译或返修结果示例

“若A真实末尾仍握信封，B首帧却已放在桌上，先核对B绑定；不能只把正文‘保持连续’换成‘空间稳定’。修复应让B从握持状态进入第一项新变化。”

### 返回合同

返回实际首失配时点、绑定/输入排查、状态等式与限定实验建议；指出本次改变哪个决定、原有哪项事实不能动、从哪个状态开始以及下一负责人如何验收。输入缺口影响因果时停止专业深化，带证据返回；不把下游修词当作上游事实已存在。

## 完整专业方法


## 特殊链路

跨批次必须对照 A 最后有效机位、真实参考截取、B 正式提示词和 B 第一个有效画面。把计划结束状态改为 A 的真实结束状态，并核对两端是否复述了同一份交接载体，再检查：

```text
A 真实结束状态：
B 起点状态：
状态等式：通过 / 不通过。
B 是否从下一相位开始：
参考是否只含一个有效机位：
允许生成 B / 改截取 / 改 B / 返修 A：
```

`提示词不是唯一变量`。当正文已经明确站位、起点、触发和下一相位，而同一问题仍重复出现时，先`停止同义词重写`：不再把“保持站位”轮换成“锁定位置、空间一致、人物不变”，而是检查目标入口、实际输入、GEO切片、参考职责、首帧阻挡、状态帧 / 尾部视频、参考强度、生成模式和随机性。只有发现正文缺少可见控制时才回视频 Skill 改词。

跨批次的参考先过`连续性把手质量门`：

```text
接续类型是否选对：空间 / 表演 / 动作 / 艺术 / 因果声音 / 场景重置。
把手是否只含一个连续有效机位，没有硬切前后的冲突画面。
人物、服装、道具、空间与光影是否属于A的真实正确结果。
把手是否比稳定资产新增了正确的站位、破坏、运动相位或表演余韵。
B是否声明只继承哪些属性，并从第一项新变化开始。
结论：可用 / 改截取 / 改用终帧+稳定资产 / 返回A / 场景重置不引用。
```

需要继续试验时建立`单一变量实验账本`，其目的不是强制正常生产做A/B，而是在已有真实失败且原因不明时减少无效付费生成：

```text
固定基线：模型 / 入口 / 模式 / 参数 / 提示词 / 资产 / GEO / 首帧 / 把手 / 随机种子（若可用）。
本轮唯一变化：尾部视频长度 / 终帧 / 首帧阻挡 / 某一参考职责或权重 / 某一局部提示词控制 / 入口模式中的一项。
假设：为什么这一个变量可能造成当前可见失败。
通过标准：哪项人物、空间、动作、表演或声音结果必须改善；哪些已成立部分必须保持。
结果与证据：成功 / 失败 / 混合；样本与日期。
下一步：保留 / 撤回 / 再测另一变量 / 证据不足停止。
```

同一轮同时改提示词、参考、构图、参数和入口，无法证明哪个机制有效。偶然一条成功也不自动变成长期规则；先作为当前作品证据，达到能力进化门槛后再交`laohu-capability-evolution`。

真实尾帧或抽帧在进入下一批次前执行状态帧质量门：

```text
人物身份与脸部：同一人，五官、发型和阶段形体没有漂移，手脸无畸形。
服装与道具：当前W/M和关键道具结构、颜色、数量、左右与状态正确。
空间与锚点：稳定场景拓扑、主空间锚点、入口和固定构件没有漂移。
画面质量：没有错误文字、随机物、运动模糊、异常曝光、严重压缩或不可解释遮挡。
状态价值：破坏、站位、临时光影、摄影方向和结束相位确实比稳定资产提供更多有效连续信息。
结论：可作为临时状态帧 / 需改截取 / 返修A / 返回稳定资产重建。
```

通过不等于升级资产。只连接一个相邻批次时作为临时参考，并与稳定人物、服装、道具和场景资产共同形成双参考；同一状态跨多个批次或反复调用时，交回 `laohu-visual-assets` 整理成正式场景状态资产。任何明显错误不得因“保持连续”继续向下传播。

首尾帧模式按端点输入、不变量、变化量、中间状态、摄影机路径、尾帧召回与收束定位。动作 / 奇观按运动方向、速度、接触、材料响应和永久结果定位。商业内容把视听质量与转化质量分开，额外检查需求命中、核心承诺、卖点证据、文案同步、品牌与行动。


## 诊断箴言

最后坏掉的地方，不一定是最先出错的地方。

本节 仅在明确复盘或诊断路由时读取，不作为正常生产固定步骤。用户未要求比较、没有真实结果或总控没有识别到待诊断问题时，不自动安排A/B、盲测、多模型对比或固定复盘。

生成结果是整条链路共同作用的表象。先找第一个可见断点，再沿输入、资产、镜头与模型执行逐层排除；上游事实没有成立时，不把下游表现归咎于模型。

最小归因顺序：

```text
作品意图是否清楚
→ 上游事实与状态是否完整
→ 实际绑定资产是否正确
→ 提示词是否把因果编译成可见变化
→ 模型是否在清楚约束下仍偏离
```

提示词只是链路中的一个变量。正文已经可执行、同一失败却在多轮“加强、保持、锁定、一致”改写后不变时，停止近义词优化，转查实际入口、模式、参数、输入职责、首帧、GEO切片、连续性把手和模型随机性。对跨批次站位漂移，先检查尾部参考是否只有一个有效机位、是否包含正确人物与锚点、是否比稳定资产提供了有效状态，以及B是否从下一相位开始；把手未过门时，继续润色B正文不会修复错误输入。

只有真实失败需要归因时才做单变量实验。冻结其余条件，一轮只替换尾部视频、终帧、首帧阻挡、一个参考职责 / 权重、一个入口模式或一项局部提示词控制，并记录假设、通过标准、保护项、结果和证据日期。多项同时变化只能生成新候选，不能生成机制结论。

每次归因都要同时写：证据、最早负责人、需要保护的成功点、最小返修和通过标准。

当输入是图片、视频、提示词或模型生成结果时读取；以真实结果找到第一个断点，不把所有问题归因于模型。


## 生成诊断


## 局部遵从但整体僵硬

`人物连续性` 只对跨场次、跨集、续集、长篇或明确要求固定人设的作品评分；一次性匿名人物记 `N/A`。0 分：人物在不同场景中脸、声音、价值、关系方式、动作身份或选择阈值像不同人，或预期差只有一次怪异效果；1 分：身份基本稳定，但人格基线、条件化行为、当前状态与弧光账本没有分层，或反差有记忆入口却缺少人物因果 / 他人反应 / 剧情后果；2 分：不可漂移身份、人格基线、当前状态和弧光变化分开维护，人物在不同处境下通过可识别的判断与策略保持连续，预期差先建立预期再产生有意义违背，并在关系、能力、选择或代价中兑现。弧光不要求人物变得更好，只要求变化有事件证据、阈值和新基线；旧习惯可以残留。

`镜头构思强度` 用来区分“镜头骨架普通”和“提示词执行不够精细”。0 分：只有概括剧情、普通站姿或常见正面中景，冲击力主要靠服装、滤镜、雨雾、颗粒和电影感词支撑；1 分：事件瞬间或机位已有方向，但动作几何、画内证据、主情绪可读性或生成可行性仍有明显缺口；2 分：剧情任务、决定性瞬间、人物 / 道具调度、摄影机观看位置、画内证据和光影落点形成同一画面因果，去掉颜色与材质仍能从黑白剪影读出镜头力量。若此项为 0，优先退回分镜构思，不先修提示词措辞。

`动作与表演` 0 分：承担本镜任务的动作跳变，情绪只有标签；1 分：动作基本完成，但关键触发、路径、受力、反应或情绪证据不足；2 分：与本镜任务有关的动作因果和表演证据清楚。简单抬眼、静止等待和单一手势不因缺少完整受力链扣分。

`效果系统` 0 分：只出现推镜、爆炸、冷色调、慢动作等名词，屏幕变化混乱；1 分：部分效果成立，但摄影机路径、焦点、环境、光色、速度或声音有一层失控；2 分：观看意图、摄影机物理路径、屏幕变化、情绪倾向和停点一致，各效果都有来源与结果。

`节奏与时长` 0 分：动作或情绪没建立就切走，或长时间没有变化；1 分：主体和动作可读，但效果、情绪或停点偏赶 / 偏拖；2 分：时长覆盖主体识别、动作完成、情绪建立、效果展开和停点 / 切换余量，快慢反差服务观看。

`音乐-画面融合` 只在成片存在音乐时评分；没有音乐记 `N/A`。0 分：只有个别动作偶然撞上鼓点，主要镜头、转场和图形变化与音乐段落各自运行，或所有镜头机械每拍一切；1 分：主要重拍和部分转场同步，但中段视觉短语缺少音乐驱动、拍前蓄势或拍后余波；2 分：音乐段落与宏观视觉阶段对应，每个主要视觉短语至少有一个决定性完成态与强拍、乐句边界、长音或休止建立关系，弱拍承载连续小运动，留白与故意切分有明确作用并能重新合拍。复盘时记录真实声音瞬态与视觉完成帧的偏差，不能只看提示词意图判满分。

`动作速度与能力` 只对武戏、追逐、机甲、枪战、超能力和大型破坏评分。0 分：只写高速、瞬移、激烈或巨大，人物仍按普通速度排招，或位移像跳帧；1 分：已有部分位移、环境或摄影机速度证据，但预载、瞬时释放、落点、接触结果、余势或角色等级差仍不完整；2 分：爆发动作链形成 `预载 / 蓄力 → 瞬时释放 → 高速位移或力量传播 → 极短接触 → 明确结果 → 余势继续`，并通过位移、发力、环境、摄影 / 声音中的必要证据让观众身体上感到速度；高手的预动作更小、路径更短、结果更大、控制更精确。

`镜头策略与动作覆盖` 评分多镜头视频。0 分：镜头数量来自固定模板，长镜头内部空洞，或快速切镜只是重复同一动作、重置姿势和制造混乱，没有把目标情绪传给观众；1 分：大体选择了连续跟拍、高强度多切或混合结构，但部分切换没有新增观看证据，动作相位或状态继承不清；2 分：镜头策略与主情绪一致，少量镜头能持续展示完整身法与空间控制，或多个短镜头能连续覆盖同一动作的来路、接触、脚步、受力、反应和结果。评分不按镜头多少扣分，15 秒约 10 镜与少量长镜头都按实际激烈程度、动作可读性、连续性和可用素材判断。

`屏幕可观察性` 评分正式模型正文。0 分：主要依赖小说因果、角色内心、导演评价或设备运动，模型必须猜最后画面；1 分：主体动作可见，但部分力量原因、镜头结果或画外信息仍未转译；2 分：每个实义句都能在成片中找到可见、可听或可直接感知的对应证据，内部因果已编译为动作、受力、位移、材质、焦点、透视和声音变化。重点排查 `她判断 / 她确认 / 借力 / 失去支撑 / 夺回主动 / 传达镇定` 等解释句，以及 `机身、摄影设备、轨道到达某点` 等幕后设备叙事；画外事件必须有声音、光影、反射、飞入物或画内反应作为入口。

`多主体运动连续性` 只在两个以上因果参与者同时运动、分离、追逐、承重或碰撞时评分。0 分：出现无因倒退、超车、瞬移、换层、出画颠倒或摄影机越轴；1 分：各自路径大致成立，但共同惯性、相对顺序、速度变化原因或摄影机关系不稳；2 分：世界 / 屏幕方向、朝向、速度、外力、相对顺序、终点和出画顺序连续可信。单主体静态镜头记 `N/A`。

`人体姿势变换连续性` 只对骑乘上下、跳跃落地、翻滚摔倒、复杂武打、舞蹈或身体与道具强交互评分。0 分：动作名直接跳到结果，肢体穿模或姿势突然替换；1 分：主要轮廓可读，但支撑转换、关节链、重心 / 旋转轴、四肢净空或落地卸力缺关键相位；2 分：关键姿势相位形成连续不同轮廓，身体几何、受力与下一动作入口可信。简单抬手、走路和静态表演记 `N/A`。

`事件传播连续性` 只在爆炸、坍塌、炮击、撞击或大型能量破坏时评分。0 分：只有爆炸 / 飞溅 / 倒塌结果，材料和方向随机；1 分：命中与主要破坏成立，但材料失效、碎片落点、二次碰撞、烟火压力、声音或永久终态有明显断点；2 分：力量从来源到命中、结构、材料、碎片、声场、摄影机和残局形成可追踪传播。无复杂破坏镜头记 `N/A`。

`镜头运动职责` 用来判断运动是否服务主情绪和观看任务。0 分：运动没有目的，关键表情、动作因果或证据被漂移与模糊破坏。1 分：运动方向成立，但速度、稳定度、焦点或停留时间与内容不匹配。2 分：稳定、持续运动、失衡或模糊都是有意选择；需要读表情、证据或剪辑接口时给足可读停留，纯运动冲击则保留连续性。复盘先判断问题是意图错误还是生成失控，不以“每帧可截图”作为所有镜头的统一标准。

## 研究依据与验证边界

Adobe动画原则提供时间/重量/重叠等观察维度；项目本地已积累真实状态帧、把手与绑定实验合同。[动画原则](https://www.adobe.com/creativecloud/animation/discover/principles-of-animation.html)。不把这些维度当作AI模型原因的直接证据。

本页的项目编译链与原创例子是本地方法设计；专业资料不证明生成模型一定遵从，也不证明观众效果已经发生。平台控制每次实际执行前重新核验。

## 局部协作

- [视频参考与资产绑定](../../../../laohu-video-prompt/skills/laohu-video-references/SKILL.md)：只在“真实参考、起终帧、GEO、资产属性主控或连续性把手冲突”时CONSULT，带本次事实与保护项，返回像素回执、入口职责、属性仲裁、GEO切片、首变与状态把手。
- [视频提示词编译](../../../../laohu-video-prompt/skills/laohu-video-compilation/SKILL.md)：只在“专业决定成立但正式正文有字段污染、路径含混、长度问题或请求不闭合”时CONSULT，带本次事实与保护项，返回封闭请求、三段式正文候选、源映射、字符/结构回执及VC前交接。
- [成片评审](../../laohu-edit-review/SKILL.md)：只在“已有剪辑或成片的事件理解、等待兑现、切点或导出质量待诊断”时CONSULT，带本次事实与保护项，返回首看记录、实际接口卡、剪点/声画证据、交付QC与优先返修。
