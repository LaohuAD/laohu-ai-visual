# 成片评审：专业方法与案例

## 当前专业决策

第一次观看重放暂时不借剧本补答案；事件连续性是观众能重建人物目标、动作和状态；交付QC是实际文件能否满足格式/音画/字幕/终端要求。剪辑中每镜都美并不保证连起来能懂。

按实际播放顺序记录知道/等待/答案时点→找第一次无法重建的切点→分别只看/只听辅助定位→恢复声画确认→测导出技术项→最多三个高收益返修。适合剪辑版本或成片；反例是用作者说明填补省略、把挑错者主观感受冒充受众研究结果。

### 同一材料候选比较

候选A：同一道具易手断点：在复盘里解释“他应该接过了”。

候选B：检查实际take有无接触相位，有则调整切点，无则返视频补缺失相位。

取舍：后者用真实素材解决理解，前者用说明掩盖成片断裂。

适用与反例：不以挑错者感觉冒充受众研究；可发布等级不等于授权对外发布。

### 编译或返修结果示例

“若实际剪点在道具离手前，下一镜已经易手，先检查其他take是否含接触相位；有素材则调整切点，无素材才返视频补拍，避免整段重做。”

### 返回合同

返回首看记录、实际接口卡、剪点/声画证据、交付QC与优先返修；指出本次改变哪个决定、原有哪项事实不能动、从哪个状态开始以及下一负责人如何验收。输入缺口影响因果时停止专业深化，带证据返回；不把下游修词当作上游事实已存在。

悬念、寻找、误判、揭示、倒计时或知识问题承重时，再按第一次观看标记三种失配：`问题提出过晚`——观众在关键过程开始后仍不知道该等什么；`回答过早`——证据、预期或人物反应尚未形成，答案已经被镜头、台词或声音泄露；`等待过期`——观众已经读懂证据并完成判断，画面仍靠重复动作、多角度或空停顿拖延。三者必须落到真实时间点和声画证据，不能只写“节奏不好”。

找到第一个断点：预测断裂、注意力误导、情绪对齐丢失、信息过早 / 过晚、事件边界模糊、动作因果断裂、资产走样或连续性断裂。后面的缺点可能只是连锁后果，不要平均返修所有层。

逐镜头检查：

```text
计划接口：提示词阶段原定的入点 / 内部节点 / 出点与匹配属性。
实际可用入点：真实时间码、稳定状态、可接收属性、前置干净把手。
实际可用内部节点：真实时间码、节点类型、可读帧范围、两侧状态。
实际可用出点：真实时间码、交出属性、尾部干净把手。
不建议裁切区间：未完成动作 / 台词 / 情绪 / 声音 / 变形或构图漂移的真实时间码。
可匹配素材标签：动作方向 / 屏幕位置 / 观众视点 / 视线 / 形状 / 构图 / 景别 / 角度 / 明暗 / 色彩 / 遮挡 / 声音 / 台词 / 语义。
计划与实际偏差：成功 / 部分成功 / 失败；失败发生在提示词设计、模型执行还是素材本身不适合。
相邻单元合同：A 已完成结果、A 真实结束状态、B 计划开始状态、必须不变、允许变化、主 / 辅匹配属性、B 第一项新动作 / 声音。
状态等式：`A 真实结束状态 = B 计划开始状态` 是否成立；B 是否从下一相位开始而非重演。
二次绑定结论：允许生成 B / 改截取 / 改用终帧或构图参考 / 修改 B 开场 / 返修 A。
动作连续：
人物目的与动作一致性：台词、选择和道具操作同向 / 有因反向 / 无意冲突；依据是什么。
承重道具状态：身份与数量 / A镜位置与支撑 / 控制者与接触 / 路径与受力 / B镜位置与支撑 / 是否悬空、瞬移、易手或消失。
省略重建：切点省略了什么；观众凭什么补齐；省略中是否藏有新的选择、障碍、物体状态或关系转折。
视线连续：
角色外观：
光影色调：
声音：是否继承人物基础声线；当前镜头声音状态是否服务剧情；是否出现跨镜头换音色、声音抢戏或声音与空间不匹配。

转场是否必要：
```

验收时逐帧或按最小可用时间精度查看实际成片，不能沿用提示词里的计划位置虚构时间码。一个可用接口必须同时满足：交接属性清楚、附近没有身份 / 道具 / 空间错误、切点前后留有选择余量、裁掉前后内容后剩余段落仍成立。只有单帧碰巧相似但前后漂移、动作未完成或声音被截断，不能判为可用接口。

连续性按观众事件理解验收，不按“两个画面看起来像”验收。把声音关掉先看一遍，再只听声音看一遍，最后恢复声画：逐镜复述人物正在争取什么、手里控制什么、上一个动作造成了什么、下一镜从哪一相位继续。若人物端起物体后切镜，必须在真实素材中找到离开原支撑、跨切载体和新支撑证据；中间路程可以省，控制权变化、决定改变、受阻或最终落点不能省。需要作者口头补充“她应该是把盘放进厨房了”，即判为接口失败。

台词与行动表面冲突时先查原剧本与前后节拍：若冲突来自真实两难或潜台词，实际画面必须给出两端目的和转折触发；若只有一句话和一个相反动作，且人物、对手、道具与后续都不承认这个矛盾，判为无意逻辑错误。最早断点可能在剧本，也可能在视频提示词未把已成立因果编译成可见证据，不能一律归咎模型。

对 J-cut / L-cut 不只看有没有声音跨画面，还要看声音是否有明确声源、是否在正确声场中进入 / 延续、是否提前泄露不该知道的信息、是否抢走关键表演。对抠像、撕纸、绿幕、屏幕替换和手势蒙版，检查轮廓是否干净、遮挡是否完整、运动是否可跟踪、替换平面是否稳定；这些条件不成立时标记为后期高成本，不把它算成可直接使用。

最终为每条生成素材输出实际接口卡：

```text
素材编号：
可用片段：起止时间码 + 内容职责
最佳入点：
最佳出点：
备用内部节点：
可匹配标签：
所需后期处理：
不建议使用区间：
剪辑接口兑现度：0 / 1 / 2
```

成片等级：

```text
A：可发布。
B：小修后可发布。
C：可做内部样片，不建议发布。
D：需要返修核心镜头。
```

返修动作最多 3 个，避免把所有问题混成一团。

STOP/CHECKPOINT：

```text
证据不足 → 停，先补原提示词、生成结果、分镜、剧本或发布数据。
生成诊断完成 → 证据足够时直接选择最多 3 个高收益动作并将修正合同HANDOFF给对应生成编译负责人形成下一版提示词；不为普通创意返修等待确认。
剪辑验收完成 → 按作品目标直接给出保留 / 删除 / 返修优先级；真实删除源素材或发布前再由老胡验收。
发布复盘完成 → 可复用经验直接反哺共享资产、封面、标题或课程化规则，并记录改动。
```

## 局部遵从但整体僵硬

`口播-B-roll 语义匹配` 判断辅助画面是否承担了当前话语节拍真正需要的视觉职能。0 分：按关键词或句号机械换画面，出现通用键盘、城市航拍、实验室、股票屏幕或漂亮空镜，画面没有新增对象、关系、过程、尺度或结果；1 分：多数节拍大致对应，但个别画面只重复名词、切入过早 / 退出过晚，或遮住讲解者的限定、反例和结论；2 分：口播按命题、机制、证据、反差和结论形成可读节拍，每段 B-roll 有明确视觉职能、完成点和退出接口，A-roll / 旁白连续且结论能够回收。评分不按 B-roll 数量、切镜频率或画风丰富度。

`B-roll 证据等级与事实边界` 判断画面是否诚实承担自己的证明能力。0 分：用 AI 生成的实验室、新闻现场、股票界面、专家人物、历史重建、随机数字或产品演示冒充真实记录、统计、研究结论或性能证据；1 分：事实、示意、插图和氛围大致可分，但来源、时间、范围或“示意 / 模拟”标识仍可能误导；2 分：直接证据可核验，可标注示意明确为解释模型，代表性插图只承担例子，纯氛围只承担情绪，数字、专名、Logo、UI 和结论使用可靠原始素材或确定性后期排版。视觉真实感和电影质感不能提高证据等级。

`讲解信息负荷` 判断口播、画面、字幕、音乐、动作音和转场是否把有限注意力用于同一学习任务。0 分：多个通道同时引入不同新信息，字幕逐字重复口播，持续动效与密集音效遮住关键词，观众不知道先看还是先听；1 分：主次基本成立，但局部仍有冗余文字、过量装饰、无意义微动作声或识别时间不足；2 分：口播保持最高可懂度，画面与声音互补而不重复，复杂关系经过分段、信号和删冗余处理，主证据出现时有稳定识别与理解时间。评分不要求所有内容都极简，也不按字幕、图形或转场数量机械扣分。

`景别证据与切换` 评分所有多镜头叙事。0 分：景别不匹配证据尺寸，或同一主体在相近轴线、构图和动作相位下只做微小景别变化，形成误切 / 跳切；1 分：单镜信息大致可读，但切换没有明显新增证据，或近景后没有重建空间结果；2 分：远景 / 全景、全景 / 中远景、中景 / 中近景、近景 / 特写分别承担空间几何、完整动作、关系重心、接触 / 表情等适合自身容量的证据；切换通过跨景别、约 30 度机位变化、动作相位、构图或信息目标中的至少一项形成有意义差异，并继承方向和状态。跨一级景别与 30 度只作经验，不机械评分。

`镜头预示性承接` 用来判断切换是否在观众脑中自然连续。0 分：遮挡或换景后新敌人、新武器和新方向凭空出现；1 分：姿势和方向继承，但下一威胁没有提前线索，切换仍像换任务；2 分：上一镜尾部完成结果的同时，以刀尖、影子、视线、声音或运动物提前引入下一威胁和摄影机方向，下一镜从同一线索的下一相位开始。静态独立镜头或明确断裂性硬切可记 `N/A`。

`影像母体一致性` 只对一组镜头、连续视频、系列资产或明确要求统一电影视觉的内容评分；单张中性资产和不要求统一视觉系统的功能图记 `N/A`。0 分：只写电影感、导演感、胶片或宽画幅词，镜头之间的摄影机权限、空间压力、光色来源、成像限制和事件状态彼此漂移，或每张都像完整海报；1 分：有部分共享影像条件，但不变量没有明确承重，变化项偶尔改写了观看位置、空间关系或事件逻辑；2 分：少数可观察不变量稳定贯穿，人物 / 空间 / 事件 / 色板 / 媒介等可变槽有意变化，电影感即使删去风格词仍能从机位、构图、光色来源、成像限制和不可交换的镜头顺序中读出来。21:9、颗粒、浅景深、低饱和和特殊光学不自动加分，不按不变量数量机械评分。

`镜头顺序不可交换性` 只评多镜头叙事。0 分：任意调换镜头仍不改变信息、等待、情绪或人物状态，只是一组漂亮截图；1 分：部分镜头有推进，仍有重复展示；2 分：每次切换都增加证据、改变关系、兑现动作结果、建立等待或承接余波，顺序被打乱会明确破坏观看逻辑。独立单镜头记 `N/A`。

## 局部协作

- [剪辑](../../../../laohu-video-prompt/skills/laohu-editing/SKILL.md)：只在“切点没有信息贡献、事件相位断裂、省略不可重建或素材把手不清”时CONSULT，带本次事实与保护项，返回切点理由、出入相位、匹配载体、素材把手和不可裁切区。
- [声画关系](../../../../laohu-video-prompt/skills/laohu-audiovisual/SKILL.md)：只在“声画同步、预置、声音桥、口播证据或音乐完成点不清”时CONSULT，带本次事实与保护项，返回声画事件、信息权限、主从、相对窗口及跨切声音合同。
- [音频评审](../../laohu-audio-review/SKILL.md)：只在“已有音频的漏词、发音、身份、表演、声场或技术异常待诊断”时CONSULT，带本次事实与保护项，返回实际文件/时点、文本对照、声线演法/声场/技术分层诊断。
