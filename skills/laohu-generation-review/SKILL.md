# 复盘验收核心

## 能力定位

把真实结果和真实反馈转成下一轮可执行动作。

这个 skill 合并生成结果诊断、剪辑成片验收和发布复盘。它不只回答“哪里不好”，而是判断问题处在作品链路哪一层：剧本、视觉资产、视频提示词、生成结果、剪辑成片、封面标题、发布漏斗或课程化回流。
## 能力加厚纪律

复盘不是评价好看不好看，而是把结果变成可执行返修和可复用经验。

必须区分：

- 生成问题：角色变脸、动作乱、表情失控、风格跑偏、声音冲突、模型限制。
- 剪辑问题：主线不清、入点出点断裂、动作/视线/色调/声音接不上、字幕遮挡。
- 发布问题：曝光、点击、前 3 秒、中段、完播、互动、评论和课程化反馈。

复盘必须沿导演链路回查，不只问“哪里不好”。每次生成、剪辑或发布失败，先判断：

```text
是灵感价值不够？
是故事引擎弱？
是节奏密度不够？
是文戏表演没写透？
是武戏动作没受力？
是镜头切换没任务？
是画面美学没停点？
是资产没锁住？
是视频提示词不够可执行？
是剪辑没有节奏变化？
是标题封面没有承接反转？
```

动作或奇观镜头还要单独回查两类系统性失真。`多主体运动失真` 检查人物、坐骑、车辆、群像、投射物与摄影机的世界方向、屏幕方向、朝向、速度变化、相对顺序和出画顺序，识别无因倒退、超车、瞬移、换层和越轴。`事件传播失真` 检查爆炸、炮击、坍塌、撞击或能量攻击的命中点、传播方向、承力结构、材料失效、碎片飞散锥、二次碰撞、烟火压力、声音、摄影机响应和永久终态。先判断是上游没写清，还是模型在清楚约束下仍失控。

人物动作看似完成但像直接跳变时，单独回查 `人体姿势变换失真`：动作名称是否被真正展开，约束是否先解除，手脚支撑点是否可接触，肩胸骨盆和主要关节是否按顺序变化，重心与旋转轴是否连续，四肢是否越过道具 / 对手而不穿模，首次落地与卸力是否符合受力，结束姿势是否能接下一动作。姿势链完整但生成仍简化，才归为模型动作遵循问题。

输出返修时最多给 3 个优先动作。不要把所有问题堆给下一轮；每个优先动作都要指向明确上游层：价值脑洞、剧本、分镜、视觉资产、视频提示词、剪辑、封面标题或发布策略。

首尾帧模式必须单独诊断，不能只归类为普通图生视频或转场失败。按 `端点输入 → 不变量 / 变化量 → 中间变换链 → 摄影机路径 → 尾帧召回 → 尾帧收束` 回查：首帧漂移，先检查首帧参考和开场是否重复改变构图；人物、产品或关键道具中途变形，检查不变量是否明确、参考是否冲突；过程突然跳变，检查触发、共同桥梁和中间状态是否缺失；画面很炫但看不懂，检查运镜是否压过主变换；尾帧未落准，检查尾帧元素是否出现太晚、结尾是否缺减速和构图校正。双端锚点是输入硬目标，不把概率模型一次偏差说成绝对规则失效；至少结合原提示词、首尾图和生成结果再定因。

跨 `VID` 连续失败也要单独定因，不能只归类为人物不一致或转场不流畅。按 `连续性路由 → A 交接点 → 实际参考截取 → 世界状态 / 屏幕投影 → B 开场提示 → 模型执行` 六层回查：直接连续却没有使用尾部动态参考，先查输入策略；同场重建仍上传带强运动的尾部视频，先查参考类型；参考片段同时包含硬切前后两个机位，先查截取；A 停在未完成接触、半空未知落点或未兑现破坏，先回到分镜边界；B 复演 A，检查基础设定是否没有限定参考职责、画面内容是否从旧动作而非新动作开始；人物画面左右改变但世界位置正确，检查是否属于有意重新建立机位，不能误判为世界状态错误。

复盘时至少对照 A 最后有效机位、实际上传的参考片段、B 正式三段提示词和 B 成片首个有效画面。分别记录：人物 / 道具 / 伤势 / 破坏是否继承，场景锚点和世界位置是否正确，屏幕方向、观看侧和运动余势是否连续，B 是否出现动作重播，参考是否把上一条错误状态放大。只有这些输入与提示都清楚而模型仍漂移，才归为模型执行偏差；否则先回到对应的剧本边界、分镜、截取或视频提示词层修正。

复盘不只在 B 失败后追责，还承担 A 生成后的 `二次绑定门`。先读取上游的相邻单元交接合同，逐帧确认 A 真正完成了什么、最后有效机位停在什么人物姿势、道具位置、动作相位、空间方向和声场；再把计划中的 `A 结束状态` 改成真实状态，检查它是否仍能与 B 开始状态相等。只有 `A 结束状态 = B 开始状态`、主匹配属性可读、参考片段只有一个机位、B 第一动作确为下一相位时，才标记 `允许生成 B`。否则给出最小修复：改截取范围、退化为终帧 / 构图参考、改 B 开场，或返修 A；不能因为 A 已经花钱生成，就继续花钱放大错误。

该门适用于任何作品，不只跨 `VID` 打斗或当前案例。相邻剧本节拍、分镜、场次和上下集若在成片中发生状态冲突，也要回到同一合同定位第一个断点：是上游结果没成立、交接记录错了、下游重演 / 跳相位、参考绑定错了，还是模型在清楚约束下仍漂移。剪辑接口兑现得漂亮也不能掩盖状态错误；连续性先通过，接口才有使用价值。

成功结果也要提炼可复用规则；失败结果默认有训练价值，要保存原提示词、结果描述、原因判断、修正提示词和下次避免规则。证据不足时输出暂定诊断，不编造平台数据或不存在的素材。

归档、复盘、生成结果诊断和发布复盘必须写入文件。对话里只给复盘文件链接、关键结论摘要和下一步阶段建议。

复盘和归档文件默认在同一个当前文件上更新，不自动新建 v1/v2/v3。只有老胡明确要求新增版本或保留旧版时，才另存版本。

### 商业转化链诊断

对电商、TVC、品牌或获客作品，视听质量与转化质量必须分开评估。画面漂亮、人物一致、动作完成，不代表观众已经理解为什么要买。额外评分以下五项，不适用的非商业作品记 `N/A`：

```text
需求命中：目标人群能否在开场处境中认出自己的问题或欲望。
核心承诺：看完后能否只用一句话说出这个产品带来的主要好处。
卖点证明：每个承重卖点是否有场景、产品机制、接触 / 受力和可见 / 可听结果，而不只是口播宣称。
文案同步：钩子、卖点句和行动句是否与当时画面证据同向，是否准确可信。
品牌与行动：观众是否知道这是什么产品、属于谁、下一步应该做什么。
```

` 卖点证明 ` 为 0 分时，不先改配乐、转场、滤镜和特效。先回查编剧是否选错卖点，资产是否没有承载证据的结构与场景，视频提示词是否只拍了结果没拍产品如何产生结果。真实产品出现无证据数字、疗效、认证、绝对化词或竞品对比时，同时判定为声称越界，不因文案有冲击力而放行。
## 能力边界

可以产出：

- 图片 / 视频生成结果诊断。
- 多镜头剪辑可行性和成片验收。
- 发布漏斗与评论反馈复盘。
- 成功 / 半成功 / 失败判断。
- A/B/C/D 等级。
- 失败类型、原因定位和上游返修路线。
- 下一版修正提示词。
- 首尾帧模式的端点兼容性、中间变换链和尾帧落准诊断。
- 最多 3 个优先返修动作。
- 案例入库草稿和共享资产反哺建议。

不负责：

- 自动调用高成本视频生成接口。
- 自动操作剪辑软件或平台后台。
- 伪造缺失数据。
- 替代最终审美选择。
## 输入判断

先判断当前反馈类型：

```text
反馈类型：图片生成 / 视频生成 / 封面生成 / 剪辑成片 / 发布数据 / 用户主观反馈 / 成功案例 / 失败案例
所属作品：
当前阶段：
原提示词或版本位置：
模型路由：Seedance 2.0 / Seedance 2.5 / 其他 / 未明确
正式提示词字符数 / 路由上限：
结果位置或结果描述：
用户最不满意的地方：
下一步意图：
证据完整度：完整 / 部分 / 口述初判
```

缺失信息写“缺”。如果证据不足，先给“基于现有描述的初步诊断”。

`正式提示词字符数` 必须来自 `skills/laohu-video-prompt/scripts/count_video_prompt_chars.sh` 的最终实测输出，并确认统计发生在最后一次正文修改之后。只有人工估算、旧版本数字或没有命令证据时填写 `未验证`，不能把它当成已确认事实进入生成失败诊断。

### 首次观看重放

评分和归因前，先把成片当成第一次看，不要从作者意图倒推“这里本来想表达什么”。按实际播放顺序逐节拍记录：

```text
我此刻实际知道什么，而不是剧本希望我知道什么。
我暂时相信什么；这是不是作品有意建立的判断。
我正在问什么；作品是否给了继续等待的理由。
我预测下一步是什么；后续是兑现、升级还是有依据地推翻。
我的眼睛 / 耳朵第一时间落在哪里；是否被错误背景、特效或声音抢走。
我与谁情绪对齐；目标、代价、空间和身体感是否足够。
切镜后我是否知道人物、道具、方向和事件仍处于什么状态。
```

定位 `第一个断点`，而不是先列所有缺点。断点优先分为：预测断裂、注意力误导、情绪对齐丢失、信息过早 / 过晚、事件边界模糊、动作或连续性断裂。后面的困惑可能只是第一个断点的连锁后果；返修应先回到最早失效的剧本节拍、资产证据、分镜选择、提示词编译或模型执行层。

如果作者看得懂、陌生观众看不懂，不能用“剧情里已经写了”判成功；如果陌生观众产生了不同但有证据支持、且更有吸引力的理解，先判断它是可保留的新价值还是破坏核心事实的误读。
## 复盘路由

主体先判断证据类型和第一个断点，再读取对应分支：

| 当前证据 | 读取 | 要解决的问题 |
|---|---|---|
| 图片、视频、原提示词或生成失败 | `references/01_图片与视频生成诊断.md` | 问题出在剧本、资产、提示词、模型还是具体生成失控 |
| 素材时间码、拼接、剪辑版本或连续性 | `references/02_剪辑连续性与素材接口验收.md` | 哪些片段可用、怎样连接、哪里必须返修 |
| 封面、标题、发布数据、完播或评论 | `references/03_封面与发布漏斗复盘.md` | 卡点位于点击、开头、中段、完播、互动还是制作 |
| 结论依赖外部资料或专业校准 | `references/00_资料来源与专业校准.md` | 结论依据和适用边界是否成立 |

可以按证据链顺序读取多个分支，但不把生成、剪辑、封面和发布四套检查强加给同一个局部问题。正式报告、最多三个返修动作、回流判断和反例边界属于主体的通用责任，不通过 Reference 延迟加载。

## 原流程导航

下列内容只用于定位原有阶段，不新增、删减或重排任何复盘步骤：

```text
读取真实结果和原输入
→ 判断证据是否足够
→ 重放首次观看并定位第一个断点
→ 进入对应生成、剪辑、封面或发布分支
→ 保护已经成立的部分
→ 给出最多三个高收益返修动作
→ 回到原有上游 Skill 或进入经验回流
```

本次拆分不改变原有 A/B/C/D 等级、文件位置、返修数量、回流路径和发布漏斗。

## 自检

- 是否先判断反馈类型，而不是直接改词。
- 是否保留或引用原提示词、素材或发布数据。
- 是否没有虚构缺失证据。
- 是否明确生成、剪辑、发布分别哪里出问题。
- 如果验收封面，是否先按实际发布尺寸做一秒识别与 10%-15% 缩略图检查；是否核对实际第一落点、双引号文字、标题引流、内容承诺和 `3:4 / 4:3 / 16:9` 自适应，而不是只评价大图好不好看。
- 封面是否因固定坐标在某一画幅失衡；参考图是否越权锁死背景、服装、版式或第三方识别；问题是否正确路由到 `laohu-script-writer`、`laohu-visual-assets` 或 `laohu-cover-design`。
- 是否先排查剧本、资产、分镜和提示词，再判断是否是模型限制。
- 是否只统计单个正式 `text` 代码块，并按 Seedance 2.0 `≤4000`、Seedance 2.5 `≤5000`、模型未明确或跨版本共用 `≤4000` 验收；超限时是否先回到提示词层压缩或拆分，而不是把不可提交归因于模型生成失败。
- 图片或视频用了资产时，是否分别检查 `资产审美适配、资产视觉记忆 / 传播潜力、资产制作可用性`；是否避免因多视图稳定就忽略设计普通，也避免因单张形象图漂亮就忽略换角度崩坏。道具是否有主结构 / 辅助视图与底部细节带，场景是否有左上四机位、右上鸟瞰和底部固定构件细节带；所有局部是否能回指同一结构与材质账本。
- 是否检查总览与局部的父子证据链：底部每项 Logo、文字、纹样、配饰、孔位、接口或固定构件，是否已经在上方完整视图中明确载体、宏观位置、朝向和数量；局部是否只提高观察精度；能否完成 `局部向上找唯一来源 + 总览识别点向下找放大证据`。
- 使用故事板作为视频输入时，是否遵守“一条提示词、一张图片、内部多分镜”；镜头01到镜头N是否都在同一张故事板表格图中，视频提示词是否只引用整张板一次；是否误把每格拆成独立故事板资产；正式提示词是否仍完整描述格间动作、运镜、物理、声音和切镜，最终成片是否避免显示故事板表格、格线、编号和说明文字。
- 如果结果看起来不想看、不想买、不像该题材或各资产不像同一世界，是否先回到 `laohu-visual-assets` 重做类型、受众、审美命题、设计语法和记忆点，而不是用运镜、VFX、滤镜或更复杂提示词补救。
- 如果流量低，是否检查表达反差、喜剧手法、争议钩子和浅深内容比例。
- 如果内容正确但传播弱，是否检查大脑墙、痛点杠杆、金句钉、共鸣网和利他金是否缺失。
- 如果转化弱，是否检查痛点是否真实、具体、可感知，并且是否给出行动出口。
- 如果金句弱，是否检查它是否像个体宣言，是否只是复述安全共识。
- 如果表达像 AI 默认答案、鸡汤、模板或说明文，是否检查高价值位置有没有直接采用第一反应；是否做过候选竞争、平均值淘汰、同题材可替换性、关系准确性、体裁成品性和留白检验。
- 如果表达像正确废话，是否检查它是否太理性、太赞美、太突出优点，缺少感性入口、可接受缺点和共同敌人。
- 如果内容没人注意，是否检查它是否太熟悉、太平滑、太讨好所有人，缺少风格边界和轻微跑调点。
- 如果内容涉及苦难、低谷或困难，是否检查它是走向和解 / 励志，还是停在卖惨。
- 是否先复述这张图 / 这条视频本来要让观众感到什么，再判断失败是目的不清、证据冲突，还是具体生成失控。
- 是否只检查与本镜目的有关的控制杆：注意力、构图、光线、色彩、焦点、空间、材质、表演、运动、声音、资产或连续性；不把整张专业清单强加给每个结果。
- “没有美感 / 没有壁纸帧”是否只用于本来承担视觉记忆的镜头，并回查它的主情绪、视觉落点和停点，而不是默认补前中后景、留白、色卡和复杂布光。
- “构图不好 / 画面乱”是否回查关键主体、关系距离、动作方向和干扰信息；是否允许中心、偏置、拥挤、失衡、满构图或平面化在有意时成立。
- 是否检查视线从哪里进入、落到哪个决定性信息、从哪里离开；摄影机是否有可信实体位置；每镜是否只有一个主要构图决定、一个主故事线索和按需一个辅助线索。
- 是否把每帧都做得同样锐利、昂贵、完整和高信息量；连接镜头是否允许普通、遮挡、失焦、未完成表演、未回应者、空位或现场继续运转。
- 特殊机位、鱼眼、镜面、反射、百叶影、水波光、车灯扫动和异常曝光是否有物理来源并改变叙事压力；没有动机时是否删除而非保留为装饰。
- 全片 / 阶段是否只选择一个主成像基底，每段是否只有一个主要不完美来源；色彩是否有物理色源和变化动机，而不是滤镜随机漂移。
- 多镜头是否做过顺序打乱测试；若换序后观众信息、等待、情绪和人物状态不变，是否已重构、合并或删除重复镜头。
- “光影潦草 / 平灰”是否先判断平光或灰调是不是目标；不是目标时，再检查真实光源、方向、可读性、材质反应和连续性，不默认补主辅轮廓光。
- “颜色乱 / 廉价”是否检查高权重颜色是否争抢主情绪和身份；不默认低饱和、两种主色或主辅点缀结构才高级。
- “景深失效 / 空间扁平 / 焦点乱”是否区分有意平面化与失控；只在空间承重时检查必要的焦点、遮挡、尺度、透视和空气关系。
- “糊 / 质感假 / 画面脏”是否按交付用途判断必须看清什么、允许模糊什么，而不是统一追求锐利、洁净和可放大壁纸。
- “人物皮肤油 / 脸像塑料 / 高光糊脸”是否先检查人物身份和目标肤质，再检查光源面积、曝光、反光、底妆、纹理与介质；不把冷白、裸妆和柔雾奶油肌套给所有角色。
- “画面死板 / 没氛围”是否先判断静止与干净是否正是主情绪；确需环境变化时，再检查天气、空气、微粒、光学点缀或背景运动的来源和贡献。
- “镜头一直晃 / 主体一直漂 / 运镜破坏美感”是否检查运动的观看职责、身体原因、关键可读点和剪辑接口；不强制每帧稳定或可截图。
- “动作不帅 / 没有高手感 / 不刺激”是否先区分动作物理是否完整、角色动作语法是否有身份、攻击来路是否可读、速度是否有逼近与结果反差、摄影机是否抓住决定性瞬间；不能只补慢动作、火花、拖影、摇晃或人物 Pose。
- 群战是否检查每名攻击者的方位、起势和进入顺序，以及上一招造成的遮挡、失衡、空位、掉落物或反作用力是否成为下一招条件；不能把依次排队攻击误判成模型随机性。
- 决定性瞬间是否符合段落主任务：动作段检查控制与接触，压迫段检查空间与最小反应，关系 / 情绪段检查证据被认出或人物控制破裂；不要求所有段落都用武打停帧。
- “镜头切换生硬 / 三个镜头像三条视频 / 人物每段重新起势”是否回查每个独立机位有没有新的 `[景别][运镜 / 转场]` 头部，第二括号是否写清硬切或软切机制；每次切换是否有前一画面的触发桥梁，摄影机和焦点是否沿桥梁变化，新画面是否继承姿势、道具、余势、空间方向和声场。只删除编号或只增加括号但不补承接关系仍然不合格。
- “声音出现时机乱 / 音效和动作对不上 / 台词表演太平”是否回查环境音、动作音和台词是否逐镜归属；情绪承重台词是否有与镜头可读范围相匹配的眼神、面部、呼吸、视线、姿态、距离和声线证据。
- “演员会哭会怒但不像在演戏”是否回查人物目的、保护策略、精确触发、可见 / 可听变化、禁止提前反应和结束状态；是否把整段情绪从第一帧一次性端出。
- 复杂表演是否内部反查八维，并检查脸、目光、呼吸、声音、身体和关系距离的异步变化；是否出现台词尚未触发，眼泪、退缩、笑意、音量或身体姿势已经提前泄露后续情绪。
- 上一节拍结束状态是否成为下一节拍开始状态；是否出现说完一句就表情复位、泪痕消失、呼吸恢复、身体距离重置或对手漏接反应。
- 使用 FACS / AU 时是否先有人话动作、少量承重编码和动态强度过程；是否避免情绪公式、编码堆叠、远景滥用及 A-E / 0-5 混写。
- 是否把“仙侠不对味”拆成礼仪、身法、空间纵深、奇观节奏和东方视觉语法问题。
- 是否给出最多 3 个优先动作。
- 是否说明回到 `laohu-script-writer`、`laohu-visual-assets`、`laohu-video-prompt`、`laohu-cover-design` 或本 skill。
- 是否输出下一版修正提示词或明确为什么暂时不能写。
- 是否给出入库和反哺位置。

## 反例黑名单

- 不要在缺原提示词、缺结果、缺分镜或缺数据时写确定结论。
- 不要把所有问题都归为模型限制。
- 不要只说“画面不好看”，必须拆成光、色、构图、动作、材质、表演、资产或剪辑问题。
- 不要一次给超过 3 个优先返修动作。
- 不要未保留原提示词就覆盖式复盘。
- 不要把单次作品问题自动升级成全局规则；必须判断是否可复用。
- 不要伪造发布数据、评论反馈、平台原因或用户反应。
- 不要把流量差只归因于平台限流；先检查选题、开头、表达反差、评论钩子和作品承诺。
- 不要为了争议牺牲底层价值；无意义冒犯只会制造噪声。
- 不要把惨当成人设长期售卖；苦难内容必须转向和解、励志、行动或成长。
- 不要只输出正确观点；缺少痛点、金句、共鸣关系和观众收益的内容很难形成传播杠杆。
- 不要用虚假焦虑制造转化；痛点必须来自真实风险或真实难受，并且给观众解决路径。
- 不要把广告语和口播金句写成普通正确话；缺少个体宣言感的金句很难穿透。
- 不要把借用偏见写成歧视或恶意标签；它只能指真实偏好、隐秘不满和未被说透的立场。
- 不要把借用缺点写成羞辱或廉价自黑；缺点必须服务个性、关系、共同敌人或成长动力。
- 不要把所有词句、观点和视觉都磨得平滑顺和；过于熟悉和平均的内容会被选择性忽视。
