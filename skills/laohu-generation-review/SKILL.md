# 老胡生成与发布复盘

## 复盘箴言

复盘不是给失败起名字，是找到最早走错的那一步。

成片最后暴露的问题，未必发生在最后一环。复盘先看真实结果，再沿生产链向上追到第一个断点；保护已经成立的部分，只把返修送回最早负责人。

本能力仅在明确复盘或诊断路由时调用，不作为正常生产固定步骤。只有老胡明确要求复盘、比较或诊断，或总控收到真实图片、视频、剪辑、封面、发布数据与明确可见问题后把任务路由到这里，才执行本 Skill。正常生成完成后不自动要求A/B、盲测、多模型对比或复盘；没有真实结果时也不为了流程完整伪造诊断。


## 任务整合与权威输入

接收真实图片/视频/音频/剪辑/发布数据及对应原稿、实际绑定和已确认目标；先区分完整证据、部分证据与口述初判。正常生产不自动执行本入口，不强制A/B、盲测、多模型比较。

主责保留证据分级、首断点归因、最早负责人RETURN、保护项、最多三个返修动作、素材反馈权限和能力进化回流；专业评审不在报告里擅自重写原作品。

## 按真实缺口调用

先确定本次承重结果，再按下表只调用必要专业；每次CONSULT记录输入、保护项、提取机制、被改变的决定和成品落点。CONSULT结果返回实际调用者。直接点名的局部专业请求只需当前判断所必需的事实，不强制先建立完整父合同或整部作品。已确认选择不重开，没有缺口不全量读取。混合事件按阶段拆专业判断；由本入口负责的整部作品最终只有本入口整合一份交付。

| 缺口 | 子能力 | 必须返回 |
|---|---|---|
| 已有真实图片的身份、结构、参考转译、注意力或像素质量待诊断 | [图片评审](skills/laohu-image-review/SKILL.md) | 实际观察、证据尺度、首断点、保护项与返修负责人 |
| 已有生成视频的动作、身份、空间、声画或批次连续性待诊断 | [视频评审](skills/laohu-video-review/SKILL.md) | 实际首失配时点、绑定/输入排查、状态等式与限定实验建议 |
| 已有音频的漏词、发音、身份、表演、声场或技术异常待诊断 | [音频评审](skills/laohu-audio-review/SKILL.md) | 实际文件/时点、文本对照、声线演法/声场/技术分层诊断 |
| 已有剪辑或成片的事件理解、等待兑现、切点或导出质量待诊断 | [成片评审](skills/laohu-edit-review/SKILL.md) | 首看记录、实际接口卡、剪点/声画证据、交付QC与优先返修 |
| 已有发布数据或明确用户反馈，需要判断入口、观看兑现或行动转化 | [发布复盘](skills/laohu-release-review/SKILL.md) | 平台窗口/分母/来源、漏斗断点、混杂解释与最小验证假设 |

## 接力与返回

CONSULT不转移当前作品主责。源故事/台词/空间因果不足返回编剧；造型和视觉系统错误返回对应设计；实际资产/绑定错误返回资产负责人。歌曲事实与全曲时间返回MV导演。需要跨专业语言判断时CONSULT laohu-language-mode，不用换写法掩盖内容缺口。专业子能力不得自行覆盖其他节点权威。

完整输入字段、状态账本、跨节点交接、硬边界和验收门使用[交接与验收合同](references/交接与验收.md)。合同是本入口的责任边界，专业方法已交由对应子能力。

## 最终验收与交付

按实际证据定位最早断点，检查计划与结果是否混写；返修动作对应文件/专业负责人及通过标准。机制证据不足只记录假设；已确认可复用经验才HANDOFF能力进化，执行完成回总控。不擅自发布、删除源素材或改变素材库级状态。

只报告真实进度。设计通过、待生成、已生成、已听试/已查看、已选定分别记录；文件存在不等于验收通过。作品主Markdown更新后由既有交付流程生成HTML并更新作品交付中心；内部规则不生成作品HTML。
