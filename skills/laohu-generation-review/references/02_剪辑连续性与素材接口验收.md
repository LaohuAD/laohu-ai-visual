# 剪辑、连续性与素材接口验收



当输入是生成素材、剪辑版本、多镜头拼接或时间码反馈时读取。



## 剪辑验收

当已有多个视频、图片、音频、字幕或成片版本时，先判断能不能剪成作品：

```text
开头钩子：
信息递进：
情绪递进：
结尾记忆点：
观众看完要知道什么：
```

逐镜头检查：

```text
计划接口：提示词阶段原定的入点 / 内部节点 / 出点与匹配属性。
实际可用入点：真实时间码、稳定状态、可接收属性、前置干净把手。
实际可用内部节点：真实时间码、节点类型、可读帧范围、两侧状态。
实际可用出点：真实时间码、交出属性、尾部干净把手。
不建议裁切区间：未完成动作 / 台词 / 情绪 / 声音 / 变形或构图漂移的真实时间码。
可匹配素材标签：动作方向 / 屏幕位置 / 观众视点 / 视线 / 形状 / 构图 / 景别 / 角度 / 明暗 / 色彩 / 遮挡 / 声音 / 台词 / 语义。
计划与实际偏差：成功 / 部分成功 / 失败；失败发生在提示词设计、模型执行还是素材本身不适合。
相邻单元合同：A 已完成结果、A 真实结束状态、B 计划开始状态、必须不变、允许变化、主 / 辅匹配属性、B 第一项新动作 / 声音。
状态等式：`A 真实结束状态 = B 计划开始状态` 是否成立；B 是否从下一相位开始而非重演。
二次绑定结论：允许生成 B / 改截取 / 改用终帧或构图参考 / 修改 B 开场 / 返修 A。
动作连续：
视线连续：
角色外观：
光影色调：
声音：是否继承人物基础声线；当前镜头声音状态是否服务剧情；是否出现跨镜头换音色、声音抢戏或声音与空间不匹配。
字幕：
转场是否必要：
```

验收时逐帧或按最小可用时间精度查看实际成片，不能沿用提示词里的计划位置虚构时间码。一个可用接口必须同时满足：交接属性清楚、附近没有身份 / 道具 / 空间错误、切点前后留有选择余量、裁掉前后内容后剩余段落仍成立。只有单帧碰巧相似但前后漂移、动作未完成或声音被截断，不能判为可用接口。

对 J-cut / L-cut 不只看有没有声音跨画面，还要看声音是否有明确声源、是否在正确声场中进入 / 延续、是否提前泄露不该知道的信息、是否抢走关键表演。对抠像、撕纸、绿幕、屏幕替换和手势蒙版，检查轮廓是否干净、遮挡是否完整、运动是否可跟踪、替换平面是否稳定；这些条件不成立时标记为后期高成本，不把它算成可直接使用。

最终为每条生成素材输出实际接口卡：

```text
素材编号：
可用片段：起止时间码 + 内容职责
最佳入点：
最佳出点：
备用内部节点：
可匹配标签：
所需后期处理：
不建议使用区间：
剪辑接口兑现度：0 / 1 / 2
```

成片等级：

```text
A：可发布。
B：小修后可发布。
C：可做内部样片，不建议发布。
D：需要返修核心镜头。
```

返修动作最多 3 个，避免把所有问题混成一团。

STOP/CHECKPOINT：

```text
证据不足 → 停，先补原提示词、生成结果、分镜、剧本或发布数据。
生成诊断完成 → 证据足够时直接选择最多 3 个高收益动作并写下一版修正提示词；不为普通创意返修等待确认。
剪辑验收完成 → 按作品目标直接给出保留 / 删除 / 返修优先级；真实删除源素材或发布前再由老胡验收。
发布复盘完成 → 可复用经验直接反哺共享资产、封面、标题或课程化规则，并记录改动。
```
