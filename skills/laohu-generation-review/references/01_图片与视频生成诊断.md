视频结果先按四核诊断，不先用“模型不行”概括：

```text
主注意力目标：观众是否明确知道这一刻该看脸、手、道具、接触点、环境变化还是画外声音引起的反应；焦点、运动、光色和声音是否共同指向它。
动作与表演：主体是否从起始状态经过触发、路径、接触 / 受力、可见结果和反应到达结束状态；情绪是否由表情、呼吸、肢体、距离和声音证明。

节奏与时长：主体是否来得及被识别，动作是否完成，情绪是否建立，效果是否展开，切镜和停点是否有余量。
```

以下三项只对知识口播、财经讲解、观点视频、教程旁白、画外解说或明显以 B-roll 辅助讲解的内容评分；纯剧情、纯音乐 MV 和无讲解功能的视觉片记 `N/A`。

`口播-B-roll 语义匹配` 判断辅助画面是否承担了当前话语节拍真正需要的视觉职能。0 分：按关键词或句号机械换画面，出现通用键盘、城市航拍、实验室、股票屏幕或漂亮空镜，画面没有新增对象、关系、过程、尺度或结果；1 分：多数节拍大致对应，但个别画面只重复名词、切入过早 / 退出过晚，或遮住讲解者的限定、反例和结论；2 分：口播按命题、机制、证据、反差和结论形成可读节拍，每段 B-roll 有明确视觉职能、完成点和退出接口，A-roll / 旁白连续且结论能够回收。评分不按 B-roll 数量、切镜频率或画风丰富度。

`B-roll 证据等级与事实边界` 判断画面是否诚实承担自己的证明能力。0 分：用 AI 生成的实验室、新闻现场、股票界面、专家人物、历史重建、随机数字或产品演示冒充真实记录、统计、研究结论或性能证据；1 分：事实、示意、插图和氛围大致可分，但来源、时间、范围或“示意 / 模拟”标识仍可能误导；2 分：直接证据可核验，可标注示意明确为解释模型，代表性插图只承担例子，纯氛围只承担情绪，数字、专名、Logo、UI 和结论使用可靠原始素材或确定性后期排版。视觉真实感和电影质感不能提高证据等级。

`讲解信息负荷` 判断口播、画面、字幕、音乐、动作音和转场是否把有限注意力用于同一学习任务。0 分：多个通道同时引入不同新信息，字幕逐字重复口播，持续动效与密集音效遮住关键词，观众不知道先看还是先听；1 分：主次基本成立，但局部仍有冗余文字、过量装饰、无意义微动作声或识别时间不足；2 分：口播保持最高可懂度，画面与声音互补而不重复，复杂关系经过分段、信号和删冗余处理，主证据出现时有稳定识别与理解时间。评分不要求所有内容都极简，也不按字幕、图形或转场数量机械扣分。

图片资产与使用了图片参考的视频还要单独评三项；纯文本生成且没有稳定资产职责时可记 `N/A`。

`资产审美适配` 判断设计是否兑现作品类型、受众、资产职责和作品承诺。0 分：类型错位，直接使用默认模板，主要靠滤镜、粒子、黑金、粉色圆角或其他俗套冒充设计；1 分：方向基本成立，但受众、设计语法或第一眼欲望不够准确；2 分：选角 / 造型、轮廓比例、CMF、空间语法和情绪承诺同向，观众一眼相信它属于这类作品。此项为 0 时先回 `laohu-visual-assets` 重做美术定位，不先修视频运镜或特效。

`资产视觉记忆 / 传播潜力` 判断关键资产是否拥有可被观众复述、截图辨认或用于封面传播的识别关系。0 分：同题材任意资产都可替换，只有通用漂亮；1 分：已有识别细节，但远看轮廓、近看细节或作品归属仍弱；2 分：至少有一个服务功能与世界观的轮廓、比例、材质、配色、造型或空间记忆点，并能在主视觉和后续视频中被继承。记忆点不等于堆奇观或故意怪异。

`人物连续性` 只对跨场次、跨集、续集、长篇或明确要求固定人设的作品评分；一次性匿名人物记 `N/A`。0 分：人物在不同场景中脸、声音、价值、关系方式、动作身份或选择阈值像不同人，或预期差只有一次怪异效果；1 分：身份基本稳定，但人格基线、条件化行为、当前状态与弧光账本没有分层，或反差有记忆入口却缺少人物因果 / 他人反应 / 剧情后果；2 分：不可漂移身份、人格基线、当前状态和弧光变化分开维护，人物在不同处境下通过可识别的判断与策略保持连续，预期差先建立预期再产生有意义违背，并在关系、能力、选择或代价中兑现。弧光不要求人物变得更好，只要求变化有事件证据、阈值和新基线；旧习惯可以残留。

`资产制作可用性` 判断美术设计能否被稳定生产。0 分：单张形象图漂亮但换角度崩坏，结构 / 比例 / 材质矛盾；道具只用平均四宫格，缺少下游会拍到的材质、Logo、文字、纹样、接缝和功能细节；场景只有几张相似广角，没有鸟瞰总平面与固定构件细节；或底部局部出现了上方总览从未定位的 Logo、文字、配饰、接口和固定构件。1 分：主要身份和结构可用，但局部角度、细节来源、操作关系、空间总平面或世界统一性不稳，部分细节只能猜测来源。2 分：形象资产证明吸引力；道具设计板以主结构 / 辅助视图和细节带证明同一物件，场景设计板以四机位、鸟瞰和固定构件细节带证明同一空间；每个局部都能回指上方唯一来源视图、位置、朝向和数量，上方承重识别点也有对应放大证据，动作、接触、材质和下游调用边界清楚。

`主注意力目标` 0 分：脸、背景奇观、道具、运镜和声音同时争抢，观众不知道看哪里；1 分：主体大致明确，但焦点、构图或声音偶尔把注意力拉走；2 分：每镜一个主目标，景别、焦点、运动、光色、导引线和声音共同指向它，迁移触发清楚。

`镜头构思强度` 用来区分“镜头骨架普通”和“提示词执行不够精细”。0 分：只有概括剧情、普通站姿或常见正面中景，冲击力主要靠服装、滤镜、雨雾、颗粒和电影感词支撑；1 分：事件瞬间或机位已有方向，但动作几何、画内证据、主情绪可读性或生成可行性仍有明显缺口；2 分：剧情任务、决定性瞬间、人物 / 道具调度、摄影机观看位置、画内证据和光影落点形成同一画面因果，去掉颜色与材质仍能从黑白剪影读出镜头力量。若此项为 0，优先退回分镜构思，不先修提示词措辞。

`观众代入强度` 与主情绪可读性分开评分。0 分：观众能看见人物在害怕、悲伤或快乐，却不知道人物为什么在乎，也没有共享信息、空间压力、身体感受、时间过程或选择后果，只在外部观察表演；1 分：目标风险和部分感官 / 信息关系成立，但观众进入角色的过程断裂或过快；2 分：段落从目标与代价出发，通过本段承重的信息、空间、身体、时间和选择路径让观众与人物共同经历，并在需要时拉开留下余波。不要求六项齐全，也不要求全程 POV、特写或手持。

`情绪入场` 先按文戏 / 武戏分流再评分。0 分：开场只有背景说明、漂亮摆拍、普通走位或无差别动作，观众迟迟不知道人物在关系中想得到什么，或危险与力量从哪里逼来；1 分：主情绪和处境可以识别，但第一有效节拍出现偏晚，前段存在无职责铺垫；2 分：文戏第一有效节拍即建立关系目的与阻力，或武戏第一有效节拍即建立危险方向、力量差与人物选择，后续镜头沿同一体验持续加压。这里的“快”不等于统一快剪，长镜头只要从开场就在增加关系或力量压力同样得满分。

`动作与表演` 0 分：承担本镜任务的动作跳变，情绪只有标签；1 分：动作基本完成，但关键触发、路径、受力、反应或情绪证据不足；2 分：与本镜任务有关的动作因果和表演证据清楚。简单抬眼、静止等待和单一手势不因缺少完整受力链扣分。

`演员临场感` 只对叙事性人物图片、首帧、封面或人物镜头评分；中性人物资产、定装展示和纯时尚摆姿任务记 `N/A`。0 分：人物只有气质词、持械动作或摄影姿势，像在配合摄影师摆拍；1 分：主情绪和事件大致存在，但事件压力、生理反应、行为选择、对手 / 环境反馈或景别可读性缺一处关键证据；2 分：观众能看见具体压力如何进入、人物身体如何响应、人物选择如何暴露态度，以及对手或环境如何为此作证。静止可以得满分，但必须是面对压力后的主动不动。

`人物现场活性` 只对观众成品人像、人物形象图、封面主体、叙事首帧和生活方式 B-roll 英雄帧评分；中性设计板、证件式身份校准、纯服装拆解和无人物画面记 `N/A`。它不重复评“演得对不对”，而评静态画面是否像从真实时间中截取。0 分：人物、摄影机和环境彼此独立，所有元素处于完整摆拍状态，生命感只靠大笑、伸手、高饱和、强逆光或滤镜；1 分：当前事件大致成立，但前后帧、摄影机关系、环境回声、受控不完整或材质分区缺一项承重证据；2 分：人物身份与事件清楚，身体 / 视线 / 道具 / 环境至少一项能推断前后瞬间，摄影机的信息权限有动机，人物与环境互相影响，皮肤、发丝、衣料、湿润和局部光学效果符合来源与材质。普通照片升级若改变人物、表情、动作、服装、道具、事件或场景类型，本项不得超过 0 分，并退回 `laohu-visual-assets`。

`效果系统` 0 分：只出现推镜、爆炸、冷色调、慢动作等名词，屏幕变化混乱；1 分：部分效果成立，但摄影机路径、焦点、环境、光色、速度或声音有一层失控；2 分：观看意图、摄影机物理路径、屏幕变化、情绪倾向和停点一致，各效果都有来源与结果。

`节奏与时长` 0 分：动作或情绪没建立就切走，或长时间没有变化；1 分：主体和动作可读，但效果、情绪或停点偏赶 / 偏拖；2 分：时长覆盖主体识别、动作完成、情绪建立、效果展开和停点 / 切换余量，快慢反差服务观看。

`音乐-画面融合` 只在成片存在音乐时评分；没有音乐记 `N/A`。0 分：只有个别动作偶然撞上鼓点，主要镜头、转场和图形变化与音乐段落各自运行，或所有镜头机械每拍一切；1 分：主要重拍和部分转场同步，但中段视觉短语缺少音乐驱动、拍前蓄势或拍后余波；2 分：音乐段落与宏观视觉阶段对应，每个主要视觉短语至少有一个决定性完成态与强拍、乐句边界、长音或休止建立关系，弱拍承载连续小运动，留白与故意切分有明确作用并能重新合拍。复盘时记录真实声音瞬态与视觉完成帧的偏差，不能只看提示词意图判满分。

`情绪目标混乱` 要与注意力和任务分开诊断。注意力集中、任务完成，情绪仍然可能杂乱：镜头只拍一个人、只完成拔刀，但雨雾、暖光、表演、音乐和运镜可能分别传达孤独、希望、危险、浪漫和展示感。0 分：观众说不出唯一主感受；1 分：镜头主情绪大致存在，但部分证据冲突；2 分：一个情绪节拍一个主情绪，所有主要证据同向，辅助余味退后；转折镜头有起点、触发、变化和终点。复盘时先分别问“看哪里、完成什么、感到什么”，不要只修构图或删动作。

`壁纸帧 / 审美停点` 只对承担人物第一眼、情绪峰值、段落记忆、封面候选或传播视觉职责的镜头评分；功能镜头、动作连接和证据插入镜头记 `N/A`。0 分：应该形成记忆点却没有清楚主情绪和视觉落点；1 分：情绪方向成立，但停点不稳或承重关系不够清楚；2 分：暂停后仍能准确传达本镜主情绪，所需的主体、姿态、构图、光色或材质中至少一种关系有记忆性。前中后景、留白、色卡和复杂光影都不是满分必需项。

动作场面的审美停点还要检查是否使用 `承重英雄帧 + 连续连接帧`。每个动作组有一至两个由蓄势、接触或结果自然形成的英雄帧即可；连接帧允许遮挡、甩镜、失衡、局部出画和方向性模糊。若人物为了截图每招停稳、回正、摆 Pose，`动作速度与能力` 和 `壁纸帧 / 审美停点` 都不能得满分。

`节奏密度` 用来判断内容是否持续给观众新的观看理由。0 分：只有开头和结尾，中段空转，镜头切换没有任务；1 分：有推进但信息点、冲突点或情绪点间隔不稳；2 分：15 秒、30 秒、60 秒或 1-3 分钟体量都有匹配的信息推进、冲突推进、情绪推进或动作爆点。复盘时如果老胡说“拖、散、看不下去”，不要只改运镜，要回查节奏网格。

`文戏表演` 只对文戏与关系反应镜头评分。0 分：台词像主题总结，表演只有抽象情绪词，人物不知道这一刻想从对方那里得到什么；1 分：人物目的和台词大致成立，但潜台词、触发、停顿、距离或反应证据不足；2 分：人物目的可执行，观众能从被选中的台词、潜台词、表情、停顿、距离或反应中准确读出关系变化，不要求所有通道同时出现。

`表演控制` 只对存在复杂情绪转折、长镜头、多人对手戏或明确反应时序的镜头评分，普通功能台词记 `N/A`。0 分：第一帧就同时端出愤怒、悲伤、眼泪和崩溃，或触发前提前完成反应，台词结束后瞬间复位；1 分：起点、触发和终点大致可读，但保护策略、强度过程、禁止提前反应、跨通道时序或静止余波缺一项承重控制；2 分：表演从人物目的和保护策略出发，被具体台词 / 重词 / 动作 / 声音 / 视线 / 信息触发，脸、目光、呼吸、声音、身体或距离按需要异步经历出现、增强、峰值和减弱，未承重通道没有抢先泄露后续情绪，禁止反应没有提前，结尾状态能被下一节拍继承。

复盘复杂表演时，内部必须反查八维：`时间段、人物目的、情绪变化与保护策略、精确触发、面部动作与可选 AU、目光身体与关系距离、声音呼吸与停顿、结束状态与静止反应`。这不是按八个标题或 AU 数量评分，而是检查每个会影响结果的维度是否已有可见 / 可听证据、是否在正确时刻变化、是否被下一节拍继承。某维不适用或本节拍不变化可省略；若承重维度在内部设计中缺失，不能因正式提示词短而判为合理压缩。

若提示词使用 FACS / AU，复盘只检查它是否辅助自然语言动作，不按编码数量评分。只写 AU 串、把 AU 当情绪公式、混用 FACS A-E 与工具 0-5、在多人远景或遮挡画面强行精细控制，都判为提示词设计问题；自然语言已经清楚而模型仍未执行，才记录为模型遵循偏差。

`武戏受力` 只对武戏、碰撞和复杂动作镜头评分。0 分：只有炫酷词，关键动作飘、乱或因果不清；1 分：动作路径可读，但本镜承重的起势、发力、受力、反应或爆点仍有缺口；2 分：观众能看清力量从哪里来、经过什么路径、造成什么结果。不是每个动作都必须同时展示起势、发力、受力、反应、爆点和停帧。

`时间动力与速度曲线` 在速度、停顿、反应窗口、快切、慢动作、转场运动、动态图形或声画节奏承重时评分；普通静态展示记 `N/A`。0 分：只感到全程同速或随机忽快忽慢，人物、摄影机、切镜、VFX 和声音互相争抢，关键动作与信息不可读；1 分：已有局部快慢对比或完成点，但主速度承载者、参照物、加减速、相位、停点或跨镜连续性有缺口；2 分：动作速度、摄影机速度、切镜速度、信息速度和声音速度主次明确，蓄势、启动、加速、峰值、接触、余波与停点按任务成立，快段仍看清方向与结果，慢段仍推进等待或情绪，跨镜保持方向、速度级别和相位。评分不按切镜数量、BPM、慢动作时长或速度形容词多少。

`动作速度与能力` 只对武戏、追逐、机甲、枪战、超能力和大型破坏评分。0 分：只写高速、瞬移、激烈或巨大，人物仍按普通速度排招，或位移像跳帧；1 分：已有部分位移、环境或摄影机速度证据，但预载、瞬时释放、落点、接触结果、余势或角色等级差仍不完整；2 分：爆发动作链形成 `预载 / 蓄力 → 瞬时释放 → 高速位移或力量传播 → 极短接触 → 明确结果 → 余势继续`，并通过位移、发力、环境、摄影 / 声音中的必要证据让观众身体上感到速度；高手的预动作更小、路径更短、结果更大、控制更精确。

`接触与力量可读性` 只对武戏、碰撞和强交互评分。0 分：多把武器聚成一团，没有清楚支撑、合力方向、位移、胜负或情绪结果；1 分：主要接触可辨，但力量关系、脱离或结果仍含糊；2 分：威胁可以并发，串行接触的双方、角度、脱离与结果清楚；一对多接触则明确攻击来源、不同接触位置、主角支撑、合力方向、位移 / 形变以及主角震开、被压退或改角脱困的唯一结果。不能因武器数量机械扣分。

`景别证据与切换` 评分所有多镜头叙事。0 分：景别不匹配证据尺寸，或同一主体在相近轴线、构图和动作相位下只做微小景别变化，形成误切 / 跳切；1 分：单镜信息大致可读，但切换没有明显新增证据，或近景后没有重建空间结果；2 分：远景 / 全景、全景 / 中远景、中景 / 中近景、近景 / 特写分别承担空间几何、完整动作、关系重心、接触 / 表情等适合自身容量的证据；切换通过跨景别、约 30 度机位变化、动作相位、构图或信息目标中的至少一项形成有意义差异，并继承方向和状态。跨一级景别与 30 度只作经验，不机械评分。

`镜头策略与动作覆盖` 评分多镜头视频。0 分：镜头数量来自固定模板，长镜头内部空洞，或快速切镜只是重复同一动作、重置姿势和制造混乱，没有把目标情绪传给观众；1 分：大体选择了连续跟拍、高强度多切或混合结构，但部分切换没有新增观看证据，动作相位或状态继承不清；2 分：镜头策略与主情绪一致，少量镜头能持续展示完整身法与空间控制，或多个短镜头能连续覆盖同一动作的来路、接触、脚步、受力、反应和结果。评分不按镜头多少扣分，15 秒约 10 镜与少量长镜头都按实际激烈程度、动作可读性、连续性和可用素材判断。

`屏幕可观察性` 评分正式模型正文。0 分：主要依赖小说因果、角色内心、导演评价或设备运动，模型必须猜最后画面；1 分：主体动作可见，但部分力量原因、镜头结果或画外信息仍未转译；2 分：每个实义句都能在成片中找到可见、可听或可直接感知的对应证据，内部因果已编译为动作、受力、位移、材质、焦点、透视和声音变化。重点排查 `她判断 / 她确认 / 借力 / 失去支撑 / 夺回主动 / 传达镇定` 等解释句，以及 `机身、摄影设备、轨道到达某点` 等幕后设备叙事；画外事件必须有声音、光影、反射、飞入物或画内反应作为入口。

`镜头预示性承接` 用来判断切换是否在观众脑中自然连续。0 分：遮挡或换景后新敌人、新武器和新方向凭空出现；1 分：姿势和方向继承，但下一威胁没有提前线索，切换仍像换任务；2 分：上一镜尾部完成结果的同时，以刀尖、影子、视线、声音或运动物提前引入下一威胁和摄影机方向，下一镜从同一线索的下一相位开始。静态独立镜头或明确断裂性硬切可记 `N/A`。

`多主体运动连续性` 只在两个以上因果参与者同时运动、分离、追逐、承重或碰撞时评分。0 分：出现无因倒退、超车、瞬移、换层、出画颠倒或摄影机越轴；1 分：各自路径大致成立，但共同惯性、相对顺序、速度变化原因或摄影机关系不稳；2 分：世界 / 屏幕方向、朝向、速度、外力、相对顺序、终点和出画顺序连续可信。单主体静态镜头记 `N/A`。

`人体姿势变换连续性` 只对骑乘上下、跳跃落地、翻滚摔倒、复杂武打、舞蹈或身体与道具强交互评分。0 分：动作名直接跳到结果，肢体穿模或姿势突然替换；1 分：主要轮廓可读，但支撑转换、关节链、重心 / 旋转轴、四肢净空或落地卸力缺关键相位；2 分：关键姿势相位形成连续不同轮廓，身体几何、受力与下一动作入口可信。简单抬手、走路和静态表演记 `N/A`。

`事件传播连续性` 只在爆炸、坍塌、炮击、撞击或大型能量破坏时评分。0 分：只有爆炸 / 飞溅 / 倒塌结果，材料和方向随机；1 分：命中与主要破坏成立，但材料失效、碎片落点、二次碰撞、烟火压力、声音或永久终态有明显断点；2 分：力量从来源到命中、结构、材料、碎片、声场、摄影机和残局形成可追踪传播。无复杂破坏镜头记 `N/A`。

`构图逻辑` 用来判断画面骨架是否把注意力和主情绪组织清楚。0 分：主体位置与画面关系随机，观众不知道看哪里或关键动作被遮挡；1 分：视觉落点大致成立，但稳定性、关系距离、运动方向或画幅适配仍有干扰；2 分：所选择的中心、偏置、对称、不对称、引导、框景、留白、拥挤、平面化或失衡结构准确服务本镜目的。三分法、黄金分割、引导线和留白只是候选，故意压迫、失衡、满构图或事实特写也可以得满分。

`影像母体一致性` 只对一组镜头、连续视频、系列资产或明确要求统一电影视觉的内容评分；单张中性资产和不要求统一视觉系统的功能图记 `N/A`。0 分：只写电影感、导演感、胶片或宽画幅词，镜头之间的摄影机权限、空间压力、光色来源、成像限制和事件状态彼此漂移，或每张都像完整海报；1 分：有部分共享影像条件，但不变量没有明确承重，变化项偶尔改写了观看位置、空间关系或事件逻辑；2 分：少数可观察不变量稳定贯穿，人物 / 空间 / 事件 / 色板 / 媒介等可变槽有意变化，电影感即使删去风格词仍能从机位、构图、光色来源、成像限制和不可交换的镜头顺序中读出来。21:9、颗粒、浅景深、低饱和和特殊光学不自动加分，不按不变量数量机械评分。

构图复盘要区分 `受控不工整` 与生成错误。人物贴边、头顶空间偏多、低地平线、窗框裁切、半完成动作和局部遮挡，如果有可信机位、明确关系压力并保住决定性证据，可以得满分；随机裁头、眼神被挡、产品结构缺失、动作接触不可读或画幅适配失败仍然是错误。不能因为画面不符合标准平衡就自动判差，也不能用“实验感”替模型事故开脱。

`视线流量` 判断观众的眼睛是否被有意接送。0 分：入口、决定性信息和出口互相冲突，视线在无关高亮、装饰或背景间乱跳；1 分：第一落点明确，但中间引导、余韵或下一镜交接偏弱；2 分：视线从明确入口进入，经眼神、动作、线条、明暗、遮挡、焦点或声音到达决定性信息，再由边缘、空位、反射、失焦区或动作趋势自然交给下一镜。单一事实特写可以很短，不因没有复杂路线扣分。

`摄影机位置动机` 判断镜头是否像真实空间中有人在正确位置观看。0 分：鱼眼、俯拍、隔窗、镜面、贴地或异常角度没有空间依据，只为炫技；1 分：位置物理上可行，但与信息关系和主情绪联系较弱；2 分：机位既能在场景中成立，又准确决定观众与人物的距离、信息权限和关系压力。纯动画 / 超现实作品也要有世界内部的观看逻辑。

`信息主次与选择性不完整` 判断画面是否知道什么该清楚、什么该退让。0 分：人物、道具、背景、特效和细节同等抢眼，或每帧都被做成完整海报；1 分：主线索可读，但辅助线索与背景仍过满；2 分：每镜一个主故事线索、按需一个辅助线索，其余内容可以普通、暗、软、遮挡、失焦或留空，决定性镜头与连接镜头拥有不同视觉预算。资产设计板因结构校准职责不按此项要求故意遮挡。

`特殊光学 / 光线动机` 判断鱼眼、镜面、反射、百叶影、水波光、车灯扫动、异常曝光等手段是否改变叙事。0 分：效果只作装饰或抢走主体；1 分：气氛成立但与信息、关系或身体感联系不够；2 分：特殊手段有明确物理来源，并改变危险、距离、认知、力量或情绪压力。没有特殊效果的普通镜头可记 `N/A`，不因克制扣分。

`成像基底与不完美一致性` 判断作品是否只有一个清楚的主介质，以及不完美是否有来源。0 分：35mm、VHS、监控、柔焦和现代数字锐度无因混用，或把生成事故当风格；1 分：主基底成立，但局部颗粒、色散、噪声、拖影或清晰度漂移；2 分：主成像基底稳定，阶段切换有剧情 / 设备动机，每段主要不完美来源单一且服务画面。中性资产设计板以结构校准为准。

`镜头顺序不可交换性` 只评多镜头叙事。0 分：任意调换镜头仍不改变信息、等待、情绪或人物状态，只是一组漂亮截图；1 分：部分镜头有推进，仍有重复展示；2 分：每次切换都增加证据、改变关系、兑现动作结果、建立等待或承接余波，顺序被打乱会明确破坏观看逻辑。独立单镜头记 `N/A`。

`情绪重心` 用来判断图片是否只有视觉焦点，没有情绪主心骨。0 分：视觉焦点清楚，但直视、拔刀、雨雾、暖光、日出、浪漫或时尚展示等信号各说各话，观众不知道该感到什么；1 分：有主情绪词，但人物处境、态度或部分视觉证据仍互相冲突；2 分：主情绪命题清楚写出主体面对什么、如何回应，观众第一情绪唯一，眼神、姿态、动作、景别、光影、色彩和环境都指向它，辅助余味只在第二眼出现。复盘时如果老胡说“什么都想传达但没有重心”，先区分视觉焦点和情绪重心，不要只通过放大人物或提高对比度修构图。

`透视与视觉重心` 只在空间尺度、纵深、运动路径或环境压力承重时评分。0 分：透视关系妨碍主体识别或动作理解；1 分：空间方向大致成立，但灭点、尺度或运动关系不稳；2 分：线性透视、空气透视、平面化、压缩空间或有意畸变中的任一种都准确服务镜头目的。近实远虚、近暖远冷和明确灭点是候选，不是统一满分标准。

`光影体系` 判断光是否完成本镜职责，而不是是否层数够多。0 分：光源无因、方向跳变，或关键情绪与动作证据被照坏；1 分：光线基线成立，但主体塑形、证据可读性或连续性有偏差；2 分：单一自然光、平光、剪影、硬光、近无辅光或多层布光中的任一种都能准确服务主情绪、主体识别和连续性。只有问题确实来自光线时，才回查时段、来源、方向、软硬、暗部和材质反应。

`色彩体系` 判断颜色是否服从主情绪、身份与连续性。0 分：颜色无目的争抢注意力或跨镜漂移；1 分：方向大致成立，但关键对象、明度、饱和度或连续性有干扰；2 分：单色、黑白、综合色、低饱和或有意高饱和冲突中的任一种都层级清楚，并准确加强本镜目的。主辅点缀色、低饱和和不超过两种主色都不是固定满分答案。

`影调透视与色彩透视` 判断明暗、冷暖、饱和度和动态范围是否把主体与空间关系组织清楚。0 分：这些关系无意混杂，主情绪或主体被吞掉；1 分：总体方向成立但局部层级不稳；2 分：高调、低调、硬调、软调、近暖远冷、近冷远暖、纯黑剪影或整体平光中的选择有明确作用。暗部可以无细节，画面也可以有意灰、褪色或油润，只要这是目标而不是失控。

`景深与空间层次` 判断焦点和空间信息是否与观看任务匹配。0 分：关键主体失焦、空间因果不明或随机漂焦；1 分：焦点大致正确，但虚实、遮挡或空间可读性仍不稳；2 分：浅景深、深景深、全平面清晰、无前景或完整前中后景中的任一种都让观众准确读到所需信息。只有纵深承担任务时才要求空间层次，不以三层齐全作为满分条件。

`画质与材质质感` 按交付用途和主注意力评分。0 分：需要看清的脸、证据、产品或接触点崩坏，或介质效果变成生成事故；1 分：关键内容可读，但锐度、纹理、模糊或颗粒仍影响目的；2 分：需要看清的细节准确可读，需要模糊、粗粝、低清、DV 噪点、梦境失焦或运动拖影的部分也符合意图。不要求每镜都洁净锐利、微细节丰富或可放大做壁纸。

`氛围环境元素` 只在天气、空气、微粒、光学点缀或背景运动承担主情绪和空间真实感时评分；干净静止环境可记 `N/A` 或得满分。0 分：元素无来源、遮挡主体或把情绪带偏；1 分：来源大致成立但方向、密度或节奏不稳；2 分：被选中的环境元素有真实来源，并准确加强主情绪，不以元素数量判断质量。

`镜头运动职责` 用来判断运动是否服务主情绪和观看任务。0 分：运动没有目的，关键表情、动作因果或证据被漂移与模糊破坏。1 分：运动方向成立，但速度、稳定度、焦点或停留时间与内容不匹配。2 分：稳定、持续运动、失衡或模糊都是有意选择；需要读表情、证据或剪辑接口时给足可读停留，纯运动冲击则保留连续性。复盘先判断问题是意图错误还是生成失控，不以“每帧可截图”作为所有镜头的统一标准。

声音适配不能只判断有没有配乐、同期声是否抢戏，还要判断人物声线一致性。凡是跨镜头说话、喊叫、VO 回响或画外音出现的人物，都要检查他是否继承了资产表 / 基础设定里的基础声线；病弱、哭腔、压低声音、隔门闷声、电话失真、VO 回响等只能作为当前镜头声音状态变化，不能让同一人物换成另一种音色。

诊断顺序：

```text
灵感价值和传播入口是否清楚
→ 故事引擎是否清楚
→ 节奏密度是否匹配体量
→ 文戏 / 武戏主任务是否写透
→ 镜头切换是否有任务
→ 剧本任务是否清楚
→ 资产设计是否抬高而不是压低视频审美上限
→ 资产一致性是否足够
→ 分镜机位和运动是否可执行
→ 正式提示词是否独立完整且没有场外说明
→ 生成结果是否偏离提示词
→ 偏离是否属于模型限制、随机性或素材不足
```

常见失败路由：

| 问题 | 回到 |
|---|---|
| 剧情目标、人物动机、开头钩子不清 | `laohu-script-writer` |
| 结构稳定但资产普通、丑、没有购买 / 观看欲望或不属于题材 | `laohu-visual-assets`，先重做类型、受众、审美命题、设计语法与记忆点，不先修视频运镜 |
| 角色、场景、道具、风格、封面或图片参考不稳 | `laohu-visual-assets` |
| 基础设定、氛围画质、表情、分镜内容或完整视频提示词问题 | `laohu-video-prompt` |
| 单段生成结果需要修正 | `laohu-generation-review` |

修正提示词必须说明：

```text
保留：
删除：
强化：
放松：
新增质量边界：
下一版修正提示词：
```

高频返修 playbook：

| 失败类型 | 保留 | 删除 | 强化 | 回到哪个 Skill |
|---|---|---|---|---|
| C1/C2 人物变脸或接不上 | 可用动作、可用构图、可用光影 | 跨提示词复用同一未资产化人物 | 图片资产、一条 15 秒内合并提示词、明确入点出点 | `laohu-visual-assets` 或 `laohu-video-prompt` |
| 画面美但不像本题材 | 可用画质、主体位置、镜头节奏 | 泛化仙气、无来源光、素材库拼贴感 | 世界观视觉语法、建筑材质、服饰礼仪、色彩层级、文本资产 | `laohu-visual-assets` |
| 仙侠动作假、飘、乱 | 可用动作意图、可用转场点 | 无受力飞行、乱飘衣袖、无起止点动作 | 身法逻辑、起势/发力/收势、空间纵深、遮挡转场、同期声 | `laohu-video-prompt` |
| 多主体倒退、超车或换位 | 可用动作意图、可用单体姿态 | 各对象孤立的 `向前 / 跑开` | 世界 / 屏幕坐标、共同惯性、朝向、相对顺序、摄影机速度与出画顺序 | `laohu-video-prompt` |
| 人物直接跳姿势或动作像普通跳下 | 可用动作目的、可用终点姿态 | 只写翻身、旋转、跃下、摔倒 | 约束解除、支撑点、肩胸骨盆、关节链、重心 / 旋转轴、四肢净空与卸力顺序 | `laohu-video-prompt` |
| 动作物理完整但不刺激、不像高手 | 可用空间、动作结果、资产状态 | 平均速度、通用连招、攻击者依次上前、无观看爆点 | 角色动作语法、攻击来路、逼近加速、提前占位、接触瞬间短暂清晰、结果高速余势和决定性瞬间 | `laohu-video-prompt` |
| 多镜头内容都正确但切换生硬、人物像被重置 | 可用单段动作、可用局部构图 | 缺少新的 `[景别][运镜 / 转场]` 边界，或只换行 / 只换机位，没有转场机制和状态继承 | 为每个独立机位补方括号镜头头部，把硬切 / 遮挡 / 甩镜 / 匹配机制写进第二括号；用动作、视线、焦点、声音或运动方向触发，并继承姿势、道具、余势、空间与声场 | `laohu-video-prompt` |
| 画面有声但声场混乱、音效出现时机错误 | 全局声音策略大致正确 | 只在提示词末尾列总声音词表，或标签没有对应正文触发、声源视角和动作相位 | 在各镜正文先写声画触发与结果，再用同一事件 ID 的 `[环境音：]`、`[动作音：]`、`[音乐：]`补充；复盘时检查同步点、预置声、声音桥、静音恢复和声源距离 | `laohu-video-prompt` |
| 特效很多但主体动作不清、VFX抢戏 | 风格和奇观方向可保留 | 主体动作、物理反馈和额外特效混成一句，模型把粒子 / 光带当成主要事件 | 先写主体动作与可见物理结果，再用独立 `[VFX：]` 只写额外视觉效果，并检查它是否加强本镜唯一主情绪 | `laohu-video-prompt` |
| 爆炸坍塌随机乱飞 | 可用命中概念、可用规模感 | 泛化爆炸、统一碎片、无方向烟尘 | 命中点、入射角、材料失效顺序、碎片飞散锥、二次碰撞和永久终态 | `laohu-video-prompt` |
| 宏大但无沉浸感 | 可用大景、空间尺度 | 连续远景航拍、无前景主体 | POV 身体感、近景锚点、手部/袖口/法器/门槛、镜头停点 | `laohu-video-prompt` |
| 诊断准但改法泛 | 已识别的问题类别 | 一次列太多返修方向 | 最多 3 个优先动作，每个动作对应一个上游文件或 Skill | `laohu-generation-review` |
