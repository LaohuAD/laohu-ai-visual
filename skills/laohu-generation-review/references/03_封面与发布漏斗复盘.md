# 封面与发布漏斗复盘



当输入是封面成图、标题表现、发布数据、完播、互动或评论反馈时读取。



## 封面验收

封面按传播画面单独验收，不能只沿用普通图片的“好看、清晰、人物一致”。先以实际发布尺寸观看，再回到大图检查文字和参考继承：

```text
一秒识别：第一次看到时，能否立刻认出主体、主标题和唯一观看承诺。
缩略图可读：缩到原图 10%-15% 后，主轮廓、标题字形和情绪关系是否仍成立。
第一视觉落点：眼睛实际先落在标题、预定主符号或二者共同关系上，还是被背景、装饰、人物服装或次级文字抢走。
日常版式基线：没有系列母版或内容破格证据时，标题是否以完整横排组位于上方约三分之一，主体视觉重量是否围绕画布中轴稳定；偏离是否真的比基线更强。
边界距离：标题、脸、眼睛、产品结构和决定性轮廓是否退出画布外圈缓冲区；是否把底边、顶边或侧边剩余空间当成塞字位置。
摄影机视角：人物近景是否保持可信平视或轻微仰视；超广角、斜切、偏心和贴边裁切是否有内容关系支撑，而不是用畸变冒充PV冲击力。
文字准确：所有中文双引号锁定文字是否逐字一致，标点、大小写、顺序、断行和字形是否完整。
标题引流：人物视线、表情、姿势、手势、道具、环境线条、明暗和色彩是否把注意力送向标题，而不是各自争抢。
画面承诺：封面制造的问题、欲望、冲突或结果是否能在正片中兑现，避免只赢点击却伤害观看信任。
比例自适应：同一条提示词在 `3:4 / 4:3 / 16:9` 中是否保持身份、标题原文、主层级和主关系，同时允许人物侧别、标题方位、断行和留白自动变化。
坐标僵化：是否因固定左上 / 右上、百分比坐标或绝对范围，导致某一画幅拥挤、遮脸、失衡或标题溢出。
参考职责：主体参考是否只锁主体，构图参考是否只提供图文关系，风格参考是否只提供综合色与材质；是否错误继承了参考图的背景、服装、版式、第三方文字或品牌。
文化海报 / KV：原始 / 传统资料、当代二创、商业案例、版式参考和来源不确定材料是否分层；文化事实是否能回到来源；文化元素是否被转译成构图、材料、尺度、字体或留白关系，而不是堆图腾、景点和传统纹样；未知经文、完整宗教图像、核心符号、法器、仪式和不明文字是否已隔离或核验；版式参考是否只借方法，没有复制坐标、原文案和独特组合。
原创与品牌：是否保持老胡品牌锚点、正确调用 `【Logo参考@老胡Logo】`，同时没有近似复刻第三方版式、片名系统或商业识别。
```

问题按首个断点回流：标题本身不成立或承诺与正片不一致，回 `laohu-script-writer`；人物、产品、场景或 Logo 参考不干净，回 `laohu-visual-assets`；主符号、视觉流量、图文关系、文字层级或比例适配失败，回 `laohu-cover-design`。如果提示词、资产和职责都清楚而模型仍持续错字或排版失控，才启用无字底图加后期排版的失败备用路线。

## 发布复盘

发布后按漏斗定位：

| 卡点 | 典型信号 | 优先回流 |
|---|---|---|
| 曝光低 | 平台给量少、初始互动弱 | 选题、发布时间、账号定位 |
| 点击低 | 有曝光但播放少 | 封面、标题、第一眼钩子 |
| 前 3 秒流失 | 快速划走 | 开头画面、第一句、冲突呈现 |
| 中段流失 | 平均观看低、看不懂 | 剧本结构、分镜节奏、信息密度 |
| 完播低 | 后半段掉完 | 悬念递进、结尾反转、镜头删减 |
| 互动低 | 看完但不评论点赞 | 情绪峰值、观点表达、评论引导 |
| 制作吐槽集中 | 画面、声音、字幕、变脸被反复提 | 对应回到资产、提示词或剪辑 |

短视频流量表达复盘：

```text
表达是否太顺：观点是否只是正确、平稳、无反差。
表达是否太安全：是否没有任何可评论、可争论、可转述的偏离点。
表达是否太理性：是否只在证明逻辑正确，缺少感性反应、关系感和让观众卷入的情绪入口。
是否只突出优点：人物、品牌、产品或观点是否只被赞美，缺少可被接受的缺点、边界和共同敌人。
是否被选择性忽视：表达是否太熟悉、太平滑、太像正确套话，缺少能打断惯性注意的轻微跑调点。
风格是否被讨好磨平：是否想让所有人都喜欢，导致立场、语气、角色缺点和视觉记忆点都不锋利。
是否直接采用第一反应：标题、钩子、金句、主物象、风格核心、结尾余味句是否没有经过 3-5 个方向候选竞争。
是否同题材可替换：这句话、这个标题、这个风格句或这个视觉概念是否能换到任何同类作品里仍然成立。
是否关系命名过泛：是否只写遗憾、释怀、温柔、治愈、破碎、成长、热血、英姿飒爽，没有说清具体关系压力或人物处境。
是否留白空心：是否只写神秘、余味、含蓄、意境，而没有动作、物象、空间块面、遮蔽比例、声音停顿或尾帧停点托住。
喜剧是否缺席：是否能加入狠词怂态度、言不由衷、经典借用、自嘲或错位表达。
浅深比例是否失衡：是否全是浅内容抓眼球，缺少能留下铁粉的深内容；或全是深内容，缺少轻快入口。
争议是否服务主题：争议必须让观点更鲜明，不能只是制造噪声。
是否疑似卖惨：困难是否只在索取同情，缺少和解、励志、行动或成长出口。
故事杠杆是否缺失：是否没有大脑墙、痛点杠杆、金句钉、共鸣网或利他金，导致内容正确但无法穿透、记住、扩散或转化。
痛点是否太弱：是否没有唤起真实损失、风险、错失、不甘或难受，导致观众只是在旁观而不是参与。
金句是否像个体宣言：广告语、口播金句或品牌表达是否只是正确话，缺少明确立场、反常识角度和替某类人发声的力量。
```

如果曝光和互动都弱，但选题本身不差，优先回到 `laohu-script-writer` 检查表达方式，而不是只改封面标题。
