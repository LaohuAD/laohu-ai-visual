## 内置质量校准视角

以下视角只用于提高诊断质量，不改变复盘输出结构，不在正式交付里新增专家分析栏目。

| 视角 | 内部校准方式 |
|---|---|
| Robert McKee / John Truby | 如果观众“不知道在看什么”，优先检查剧本目标、阻力、代价和人物选择，而不是只修提示词词藻。 |
| Blake Snyder / Dan Harmon | 如果开头弱或中段散，检查前 3 秒类型承诺、钩子、节拍推进和最小故事循环。 |
| Akira Kurosawa / Saul Bass | 如果镜头不成立，检查视觉任务、主体运动、构图概念和剪辑停点是否清楚。 |
| Roger Deakins / Emmanuel Lubezki / Vittorio Storaro | 如果画面廉价或不统一，检查光源方向、镜头身体感、色彩层级和画质描述是否冲突。 |
| Ralph McQuarrie / Syd Mead / Doug Chiang | 如果角色、场景或道具不稳定，检查资产是否真的锁住轮廓、材质、结构、比例和世界观语法。 |
| 胡金铨 / 徐克 / 程小东 / 袁和平 | 如果仙侠动作假、飘、乱，检查身法逻辑、空间纵深、礼仪节奏、动作起止点和可见受力。 |
| Runway Academy / OpenAI 提示工程 | 如果生成偏离，检查提示词是否独立完整、具体、无场外说明、无上下文依赖、无互相矛盾指令。 |

复盘时不要把所有问题都归为“模型不行”。先判断上游是否给了模型可执行的信息；只有剧本、资产、分镜和提示词都清楚后，才把剩余问题归为模型能力限制或随机性。

如果老胡反馈“像 AI、太普通、太安全、太顺、像鸡汤、像模板、像说明文、没有文学感、没有记忆点”，默认先进入反模型众数倾向诊断。不要只看某一句是否通顺，要回查高价值位置是否直接采用了第一反应：标题、开场钩子、主物象、核心台词、评论引导、风格核心、转场机制、结尾余味句、封面帧。复盘要判断它是不是同题材可替换、关系命名不准、体裁成品性不足或留白没有可见证据。

证据不足时先停在初判，不要硬写完整复盘：

```text
缺原提示词 → 只能判断表面症状，先让老胡补原提示词或当前提示词文件。
缺生成结果 → 只能基于口述做初步诊断，不写确定结论。
缺分镜 / 剧本 → 先判断是否是上游任务不清，不直接改视频提示词。
缺发布数据 → 只做内容和制作复盘，不编造曝光、点击、完播或互动原因。
```
