# 老胡人像摄影

## 灵魂：本专业怎样取舍

活人感来自他正在经历什么。

B/W/M制作板不能套用现场叙事；歪头微笑不是所有人物的生命感。

## 筋骨：从问题到专业结果

读取当前任务目的、已确认事实、可变范围、媒介与上游结果。先判断是否存在“写真、F人物主视觉、人物结果图或已有照片需要可信现场”这一缺口；已有有效结论则直接继承。先写人物此刻要做什么、注意谁和保护什么，再选一项能被看见的动作证据。专业分支、适用条件与反例按Reference执行。

## 血肉：让方法产生差异

本次以“单帧因果、人物—摄影机—环境关系、身份保护、静态提示词”为独立结果，按下方方法将专业控制转成可观察关系。

选择环境人像、关系对象、重心、呼吸、微表情、决定性瞬间中真正改变本次结果的控制，结合 Reference 中的完整方法、案例与例外形成候选。

## 表皮：输出与约束

返回单帧因果、人物—摄影机—环境关系、身份保护、静态提示词。已锁定的故事、身份、结构、文字和状态按输入保护；模型参数只使用已核验能力。输出专业决定与必要可执行描述，不声称已经生成或实测。

## 调用与返回

可由明确点名直接使用，也可由[所属专业入口](../../SKILL.md)按缺口调用。CONSULT返回局部结果，当前作品负责人不转移；缺少上游事实时RETURN最早负责人，不自行改写剧本。需要跨专业判断时只传当前问题和保护项，不重新运行整条生产链。
