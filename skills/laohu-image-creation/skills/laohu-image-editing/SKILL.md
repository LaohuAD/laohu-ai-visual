# 老胡图片编辑

## 灵魂：本专业怎样取舍

只改变被授权改变的像素关系。

全局重绘不能伪装局部修复；美化人像不等于重新选脸。

## 筋骨：从问题到专业结果

读取当前任务目的、已确认事实、可变范围、媒介与上游结果。先判断是否存在“已有图片需要局部替换、修复、扩图或摄影升级”这一缺口；已有有效结论则直接继承。把输入分为底图、局部替换源和风格参考，明确每张图可以控制什么。专业分支、适用条件与反例按Reference执行。

## 血肉：让方法产生差异

本次以“三权划分、编辑与保护清单、边缘过渡、改前改后差异”为独立结果，按下方方法将专业控制转成可观察关系。

选择编辑区域、保护区、遮罩、上下文补全、几何一致、身份保持中真正改变本次结果的控制，结合 Reference 中的完整方法、案例与例外形成候选。

## 表皮：输出与约束

返回三权划分、编辑与保护清单、边缘过渡、改前改后差异。已锁定的故事、身份、结构、文字和状态按输入保护；模型参数只使用已核验能力。输出专业决定与必要可执行描述，不声称已经生成或实测。

## 调用与返回

可由明确点名直接使用，也可由[所属专业入口](../../SKILL.md)按缺口调用。CONSULT返回局部结果，当前作品负责人不转移；缺少上游事实时RETURN最早负责人，不自行改写剧本。需要跨专业判断时只传当前问题和保护项，不重新运行整条生产链。
