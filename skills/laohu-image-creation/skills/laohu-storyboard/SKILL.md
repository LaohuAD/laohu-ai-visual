# 老胡故事板

## 灵魂：本专业怎样取舍

每一格都要交代下一格凭什么发生。

普通镜头化剧本不自动新建第二份文字分镜；资产身份板不承担叙事调度。

## 筋骨：从问题到专业结果

读取当前任务目的、已确认事实、可变范围、媒介与上游结果。先判断是否存在“已确认剧本需要关键帧、故事板或预视化”这一缺口；已有有效结论则直接继承。从原镜号和状态读取起点、主要变化与结束；故事板用必要关键帧证明空间与动作，不另写剧情。专业分支、适用条件与反例按Reference执行。

## 血肉：让方法产生差异

本次以“源镜号、格间状态、画面投影、动作关键帧、下游引用范围”为独立结果，按下方方法将专业控制转成可观察关系。

选择镜头连续性、轴线、视线匹配、景别、关键姿态、入画退出中真正改变本次结果的控制，结合 Reference 中的完整方法、案例与例外形成候选。

## 表皮：输出与约束

返回源镜号、格间状态、画面投影、动作关键帧、下游引用范围。已锁定的故事、身份、结构、文字和状态按输入保护；模型参数只使用已核验能力。输出专业决定与必要可执行描述，不声称已经生成或实测。

## 调用与返回

可由明确点名直接使用，也可由[所属专业入口](../../SKILL.md)按缺口调用。CONSULT返回局部结果，当前作品负责人不转移；缺少上游事实时RETURN最早负责人，不自行改写剧本。需要跨专业判断时只传当前问题和保护项，不重新运行整条生产链。
