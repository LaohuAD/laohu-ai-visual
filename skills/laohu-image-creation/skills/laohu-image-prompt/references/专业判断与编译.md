# 图片提示词编译的判断与编译

## 专业判断

先确定一个任务和一项主证据，再按对象—关系—光材—保护项编译。把属性贴回明确对象，区分世界位置和画面位置；风格召回和摄影控制分别承担职责。

长文本优先删除同义赞美与作者解释，不删独特结构和负面边界。制作板写足每格职责；结果图只截一个能被观看的瞬间。模型专有语法需核验后适配。

## 术语怎样进入选择

本专业使用：属性绑定、注意力层级、空间关系、参考职责、约束冲突。选择术语时必须同时指出它控制的对象、产生的可见差异和失败条件；不能把整组术语并列塞进提示词。

禁止把专业设计重新概括成电影感、精致、高清；默认输出文本不代表实际生成。

## 从机制到可执行描述

下例仅在对象和关系已经由输入确认时成立；换题后继承判断方法，不能借用示例中的人物、物品或事件。

> 先写门内人物与门外空位的关系，再写门框阴影怎样保护脸部身份；不列无关镜头参数。

先比较这种处理与一项合理替代：如果替代方案更清楚地保护本次主结果，就采用替代，不为展示技法保留原案。只有一个被锁定的有效方案时，比较未锁定变量，不重开用户已确认的设计。

## 验收与修复

逐项检查输出中的对象和因果是否对应权威输入；术语能否变成可观察关系；有没有两个控制相互抵消。发现问题先改产生问题的选择，再改表达。对真实图像的判断必须读取实际结果；只有文本时只验设计与可执行性。

最终返回：独立可复制正文、参考绑定、画幅与必要保护项。附本次采用、舍弃的关键选择及原因；未确定条件明确保留，不用推测补成事实。

## 专项深化与同素材比较

编译把专业判断转成单张可见图像，不重新设计内容。链路：判定成品/规格板/编辑外壳→引用职责→熟悉对象母型+本案变化→第一注意力与主证据→摄影和光色材质→保护文字与结构→检查每项属性是否改变像素或排除具体错误。例：同一F，不把服装背面内部工程塞入肖像正文；完整结构交W。制作板不能为套写真三段式丢固定画框。

精确数据任务同时保护数值、轴线与数据标记几何；按[信息设计](../../../../laohu-art-direction/skills/laohu-information-design/SKILL.md)将承载量值的层交确定性制作。不得以模型生成柱形后仅贴正确数字冒充正确图表。
