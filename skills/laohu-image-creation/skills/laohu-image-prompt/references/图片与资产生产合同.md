### 图片提示词的因果顺序

观众成品图按 `主体 → 场景 → 时间 → 主情绪 → 摄影位置 → 光色 → 材质 → 可见结果` 推导；制作资产按 `身份 / 结构职责 → 必须看清的视角 → 比例与材质 → 中性展示 → 下游一致性` 推导。

上游提供叙事灯光合同时，观众成品图先形成`静态受光证据`：当前光源与方向、相对面积 / 软硬和衰减、人物脸身或关键物的明暗边界、轮廓与眼神光、背景层级、材料和空气响应，以及必须显露 / 允许隐藏的信息。`参考帧灯光职责`只提供已确认的观看关系；资产层不得反推精确灯位、灯具功率和后期链路，也不得把参考帧整段提示词复制到不同人物和空间。

B / W / M / S / A / G等制作资产默认以`中性校准`和结构可读为先，除非叙事灯光本身就是必须校准的稳定属性，否则`不强加叙事光态`。中性展示可以有清楚主光、补光、眼神光和材料反应，但不能为了氛围吞掉脸、侧背面、参数、服装结构和空间拓扑。

正式编译图片提示词前，必须先建立一次内部`注意力合同`：唯一生成任务、主注意力、主证据、支撑证据、主动退让和3—6项不可丢锚点。它不是第四段，也不原样投喂模型；它负责让人物、服装、妆造、场景、风格和摄影共同证明同一个结果。若无法指出唯一主结果，或同一张图同时把脸部微妆、完整全身、服装内里和宏大环境都列为最高优先级，先分配证据尺寸、派生其他资产或返回上游，不继续堆描述。

注意力合同不能只判断“写没写”。正式首稿可先形成完整母稿，或先确定关键画面再补全同一专业合同；随后按共享注意力Reference的0—3级强度门建立内部`视觉主导合同`：承重维度必须达到3级，用足以辨认的画面证据把第一视觉落点抬到最高；单一机制可以成立，并明确第二眼、第三眼与竞争元素怎样退让。脚本通过只说明没有明显缺项，不说明画面已经高质量；资产层必须继续判断焦点是否真实主导、有效信息是否高占比、每项光影 / 构图 / 服装 / 场景信息是否共同证明唯一结果。

注意力合同之后执行正式编译顺序：`完整设计读取 → 必须锁定 / 方向引导 / 模型补全 → 选择性编译门 → 当前结果身份的外部结构 → 反向审稿`。设计库不是投喂清单，完整判断不等于完整投喂。视觉资产不得以“完整继承”为理由，把人物、服装、妆造、美术、场景和摄影正文全文拼接。先保住身份、题材、关系、主轮廓、主光关系和1—2项`非默认人物记忆点`；已被方向覆盖的次级局部留作`生成开放空间`。

稳定生产直接继承已经确认的美术风格设计交接包、`结果图成像合同`、人物、服装、妆造和布景设计，只编译当前画面发生了什么。复盘不是默认步骤：只有用户明确要求复盘、已有真实结果需要诊断，或当前输入出现无法由既有权威裁决的冲突时，才路由`laohu-generation-review`；不在每次生成后自动安排A/B测试、盲测或固定复盘。

所有正式图片正文都必须通过`镜头可执行语言`闸门；用于连续自然语言成像时，也称`镜头可执行的画面叙述`。题材、媒介、身份和成熟风格母型可以作为先验召回保留；正文主体必须写模型能成像和验收的对象、位置、关系、状态、材料、光线、构图与结果；人物心理、观众感受和设计原因留在内部工作卡，翻译成可见证据后才能进入代码块。所有含人物的结果图还要形成`单帧因果`：`过去痕迹 / 当前关系响应 / 下一趋势`；不依赖固定时间词，而由重心、眼线、接触、受力、惯性、环境余波和摄影机位置证明。结果写真、人物主视觉、封面主体和叙事首帧使用单帧分支，以关系对象、未完成动作和足以辨认结果的脸、身、衣发、道具或环境通道（单一通道可以成立）共同证明一个结果；制作资产只继承可执行语言闸门，不为生命感强行增加剧情动作。

人物结果图继续分静态与动态两支：静态关系帧证明人物正在回应谁、动作为什么未完成；动态动作帧必须额外写清支撑点、力量来源、单一发力路径、接触点、受影响对象、受力结果和余势。两支都必须建立第一眼 / 第二眼 / 第三眼和主动退让；不得把“挥剑、奔跑、推柱、衣袍飞扬”当成动态充分证据。

图片正文同时完成`已知母型 → 当前原创变化 → 可见证据`编译。人物、服装、材料和场景先使用模型训练中稳定的高频类别，再追加形状、位置、表面、受光与状态；世界观专有词必须紧跟视觉翻译。风格名称可以保留，但一个结果只设一个主锚点；其他名称必须明确只负责某一项构图、色彩、光影、材料、空间或运动机制，不能同权决定整张图。任何将被交给模型产生图片结果的提示词，包括草图、快速试验和候选图，都必须读取`02_共享资产库/05_工具流程/视觉生成模型注意力与提示词编译参考.md`，完整执行注意力合同和镜头可执行语言编译并留下调用回执。任务简单时可以缩短正文和回执，但不能跳过唯一任务、主注意力、主证据、支撑证据、主动退让与不可丢锚点中的任何判断。

#### 结果写真与制作资产使用不同外壳

`结果图写真`指一个人物、场景、道具、产品或其他对象已经设计成立后，被摄影机拍成的一张最终结果照片；F人物主视觉图属于这一类。它不是所有图片的统一模板。三段职责必须成立，标题可以显式或融合：

```text
【基础设定】图片类型、用途、表现媒介、原创对象、身份 / 功能、必须继承的参考。
【氛围与画质】著名导演、作品、艺术家、摄影传统、艺术流派或时代影像风格名称；可迁移的视觉机制；色彩、光线、材料、空气与成像介质。
【画面内容与构图】对象的完整具体设计、姿态 / 状态、环境、摄影机高度与方向、焦段 / 透视、主体占比、第一落点、前中远景、留白和裁切安全。
```

三段不是为了排版整齐，而是防止身份、审美先验和摄影实现互相吞没。正式模型正文可以保留三行标题，也可以把三段内化为一段连续、具象的画面叙述；验收看职责是否齐全且共同指向一个结果，不检查标题字样。名称锚点和`结果图成像合同`必须来自`laohu-art-direction`，并与当前可迁移机制一起出现；资产层不能只写`电影感、精修、东方、高级`，也不能临时另选导演或作品。

B / W / M / S / A / G等制作资产保留自己的专业框架，不机械改写成三段式。共同内核仍然进入它们：身份或结构职责决定展示什么；风格锚点转译后的色彩、材料与光线决定怎样展示；构图、主次和观看重点决定信息怎样被读到。例如W仍是平铺 / 人台 / 细节拆解板，S仍是多机位与鸟瞰结构板，B仍是固定三列校准板。`制作资产保留自己的专业框架`，不等于放弃审美，而是把同一灵魂与筋骨编译成该资产真正需要的版式。

普通制作资产不强制读取参考图形式转译 Reference。只有上游已经确认形式转译卡，且其中某个关系会改变资产的识别、材料、光影、色彩或观看重点时，才消费这一部分；不得重做候选，也不得把 B / W / M / S / A 变成极简 Zine、上下分栏、双色、点阵或抽象面板。制作资产的结构证据、依赖、固定画框和下游调用优先级不因风格转译而退让。

中性展示不等于中性设计。制作板可以使用普通背景和均匀光，但人物选角、产品轮廓、服装造型、材质配色和世界观必须先成立。

抽象词要解压成可见关系：

- “电影感”落到观看位置、构图、光源、色彩、材质和成像介质。
- “治愈、危险、孤独”落到处境、表情、身体、空间和环境证据。
- “特写”落到裁切、主体占比、角度、焦点和可见细节。
- “高级”落到比例、接缝、材料、留白、层级与真实使用情境。

每条可复制提示词单独放入 `text` 代码块。代码块先正向描述要出现的结果；具体不该出现的人、物和剧情风险放在代码块外，避免反向召回。需要手动绑定的内容用 `【……参考@……】` 显性标注，并在同一句写清职责。
