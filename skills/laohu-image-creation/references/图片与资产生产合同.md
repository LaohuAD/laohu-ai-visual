#### F人物主视觉图：B / W / M的共同成图源

旧行为场景中的`B / W / M的共同成品源`只作为兼容检索词保留；当前语义是共同成图源，不代表F已经提供全部侧背面、鞋履、内里和身体参数。

主要人物需要跨多集稳定复现时，先让擅长人物审美和完整角色实现的模型生成`F人物主视觉图`。F先是一张面向人观看的角色定调成图：它要让观众从一个正在发生的可感瞬间中，同时认出人物的脸、身体倾向、服装、妆发、气质、色彩和成像世界。它先供人工比较和选择，选中后再成为B / W / M的共同反向拆解源图。F本身不按稳定资产验收，不直接进入视频，也不代替B / W / M；它在三项拆解通过人工验收前始终保留。

主要人物进入F前必须已经有`服装方向已确认`记录：记录胜出候选、保留与删去项、允许专业补全范围和重新开启条件。若服装Skill状态仍为`待服装方向确认`，本Skill只能返回确认节点，或按老胡明确要求编译标记为`候选试验`且不进入稳定链的测试图；不得自行合并候选、根据模型随机美图替老胡选美，也不得先建正式F再倒推胜出服装。`服装方向确认`决定穿什么，`F人工选定`决定哪一张完整角色成图最准确地实现已确认设计，两道确认不能互相代替。

F的依赖为`美术风格设计交接包＋人物写真设计正文＋服装设计正文＋妆造补充正文＋成品图画面框架`。画面默认走人物主视觉或影视剧照逻辑：先确定人物此刻想要什么、正对谁或什么作出反应，再让重心、视线、衣发、道具、空间、光影和摄影机位置共同证明这一瞬间。根据主证据选择头肩、半身、七分身或全身；不为后续拆解强制正面、直视镜头、头脚完整、所有结构同时清楚或安全边距。人物主视觉成图的正文内部必须完成`基础设定 → 氛围与画质 → 画面内容与构图`三段职责，标题可以显式，也可以融合进连续的画面叙述；不得为展示格式打断同一瞬间的因果和观看流。视觉资产只把美术方向和三份专业正文接入成品图框架，不重新决定题材、选角、服装或妆发。

同编号反向拆解合同为：`F → B`提取可见脸身与比例证据，不可见侧背面和数值由人物设计正文定向补全；`F＋服装设计正文 → W`提取可见穿搭效果，再补足被遮挡的背面、内里、鞋履和拆分结构；`F＋B＋W＋妆造补充正文 → M`提取可见妆发与穿着关系，再补足侧背面。每项补全都是待人工选定的制作推定，不得冒充F已经可见的事实。W只有在资产板包含上身展示时才引用B作为体型承托；纯平铺拆解不强制引用B。F不直接进入首帧、封面和视频，视频只引用经过拆解和验收的B、阶段素体、W与M。

没有人物设计授权时，F不能借“更好看”重新选角。没有服装方向确认记录与服装设计正文时，F不能用模型默认服装代替专业设计；没有妆造补充正文时，写真可以先呈现已经确认的可见妆造，但M不得把侧背面猜测包装成确定设计。若专业人像模型改变核心骨相、年龄、文化身份、服装设计或人物第一印象，返回对应专业负责人，不能让漂亮结果倒改上游母版。

### 单张成品图

资产回答以后还能不能认出来，成品图回答这一眼值不值得停下来。

一旦判定为单张成品图，停止建立资产总表、规格板、跨请求依赖和中性展示；进入当前图片的观看设计。提示词不能从“主体 + 风格 + 画质”直接拼接，先形成内部成品图工作卡：

```text
观看结果：目标观众看见后主要感到、相信、记住或想做什么。
决定性瞬间：为什么偏偏截取这一刻，而不是前后任何一刻。
主关系：人物与人物、人物与物件、主体与空间，哪条关系在承重。
前后帧：前一瞬留下什么，后一瞬正往哪里去。
摄影机关系：观众为什么站在这个距离、角度和信息位置。
环境回声：空间怎样作用于主体，主体又给空间留下什么变化。
第一落点与视线出口：先看哪里，最后停在哪里。
主动退让：哪些背景、装饰、肢体边缘或光效可以暗、软、挡、空。
记忆证据：去掉“高级、电影感、氛围感”等总结词后，哪项可见关系仍使它属于本图。
```

只有开放设计尚未确定决定性瞬间，或用户明确要求候选比较时，才竞争真正改变观看位置、关系压力、空间作用或第一落点的构思；只换服装、色板、天气、镜头型号和滤镜不算不同方案。已经确认方向的稳定生产直接继承，不把A/B比较变成每张图的固定成本。

所有含人物的结果图，包括人物主视觉、写真、人像、封面主体、叙事首帧、生活方式英雄帧和已有照片升级，必须读取 [references / 06_人物生命感与现场摄影关系](../skills/laohu-portrait/references/06_人物生命感与现场摄影关系.md)，不是等画面失败后才补读。F也走这条成图路线：它不必复制某一场正式剧情，但必须设计一个与人物稳定气质同源的当下目的、关系对象和未完成状态，让脸、身体、服装、妆发、环境和摄影机共同构成一个活着的角色答案。没有人物的氛围图、概念图和奇观静帧也要保留决定性瞬间、摄影机权限、空间第二力量、光色来源和余韵；按对象再读取场景或风格 Reference。

成品图提示词按 `当前人物 / 主体状态与事件 → 摄影机观看关系 → 身体 / 物件 / 空间的承重变化 → 环境回应 → 光色与材质来源 → 局部光学反应 → 当前停点` 编译。若静态图里所有对象都处于最完整、最正面、最稳定的展示状态，优先判定为制作图或摆拍，不用“抓拍感、生命力、电影感”替它辩护。
