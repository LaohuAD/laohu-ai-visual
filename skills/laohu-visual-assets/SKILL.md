# 老胡视觉资产

## 资产箴言

一张图负责惊艳，一套资产负责不走样。

资产不是画面里出现过的名词，也不是一张漂亮图片的别名。它是跨生成请求仍要保持同一个身份、结构、空间、材质、关系或状态的生产基准。

文件名帮助生产，真实像素决定画面是什么。正式图片只有在观众实际看见的内容与任务一致时，才获得下游调用资格。

## 输入与责任

本 Skill 读取已确认剧本、场次、镜头任务、`MV导演交接包`中的`MV分镜资产任务`、美术风格设计交接包、人物连续性、人物设计交接包、服装设计交接包、场景与布景设计交接包、当前资产与真实生成结果，回答五个问题：

1. 什么必须保持同一个。
2. 什么只服务当前镜头，不值得资产化。
3. 这些资产怎样先设计、再生成、再组合。
4. 下游怎样引用，才能只继承该继承的部分。
5. 如果结果只为当前这一眼成立，怎样把人物、摄影机、环境和决定性瞬间组织成真正的成品图。

本项目默认只交付资产定义或成品图设计、图片提示词、生成顺序、验收和调用说明，不直接生成图片。只有真实图片已经由老胡生成并确认，才能标为可调用资产或已完成成品图。

若`美术风格设计交接包`已经包含胜出形式转译卡，本 Skill只消费参考职责、具体保真不变量、来源关系和形式结果，再把它们编译进正确图片外壳；不得重做候选、另选艺术命题或把外部样片表面当成新方向。没有参考分析、艺术转译或来源关系任务时，不强制读取参考图形式转译 Reference，也不伪造形式转译卡。

歌曲型作品中，MV 导演负责歌曲事实、导演命题、创作段落、声画关系、表演策略、制作时间线和每个单元为何需要图片；本 Skill 只把已经确认的`MV分镜资产任务`编译成图片提示词与参考职责。按单元选择最低充分模式：`单帧`锁定决定性起点或表演状态，`首尾帧`分别锁定承重起点与完成态，`多关键状态`只用于多个不可合并的视觉阈值。不得把固定格数、固定时长或某个平台的输入方式写成通用规则，也不得为了方便生图重切歌曲结构。

## 资产关系

### 先判断资产，后决定图片

候选对象先回答：

```text
复用范围：会出现在哪些独立镜头、场次、集数或作品。
叙事职责：它证明身份、关系、卖点、世界规则还是空间方向。
失真代价：走样后观众会不会认错、出戏、误解或无法剪接。
正文替代：只靠当前视频提示词能否稳定说清。
下游调用：哪一个具体环节会怎样引用它。
```

只有“它出现过”，没有失真代价和下游调用，就不建资产。删掉它仍不影响身份、空间、剧情锚点和连续性，就降级为镜头画面元素、单张成品图或临时参考图。

最低可行资产优先于资产齐全。资产越多，生成成本、引用冲突和维护成本越高；少一个会失控才保留，不为目录整齐建立成套图片。

“最低可行”只限制资产数量，不降低单项设计质量。少做一张，是为了把预算集中到真正承重的资产；留下来的每一项仍要经过设计竞争、人物 / 产品 / 世界关系校准和下游压力测试。数量精简不能成为轮廓普通、材质敷衍、人物平均、构图模板化的理由。

### 三类结果

| 结果 | 用途 | 必要内容 |
|---|---|---|
| 稳定资产 | 跨请求保持身份、结构、空间、材质或关系 | 编号、固定项、可变项、依赖、提示词、验收、下游调用 |
| 成品图 | 当前观看、发布或人工定调，如人物主视觉、封面主体、首帧、海报、氛围图 | 当次观看结果、决定性瞬间和提示词；可被人工选为后续源图，但不因此变成稳定资产 |
| 临时参考图 | 只为一个镜头、构图、测试或下一项正式资产的生成服务 | 清楚标记唯一消费者和失效时点；不得继续向消费者的下游传播 |

资产图片可以很美，但它首先要换角度仍是同一个对象；成品图可以只为这一眼成立。两者的验收不能混用。

#### 请求类型路由

图片提示词不是同一个“主体 + 风格 + 画质”模板。先问这张图下一步要控制什么，再选择外壳；同一作品可同时需要多种路由，但每张图只能有一个主要任务：

| 路由 | 主要用途 | 必须证明 | 不能越权 |
|---|---|---|---|
| 身份母版 | 跨请求稳定人物、群像或生物身份 | 脸身拓扑、比例、稳定辨识和允许阶段变化的边界 | 不自动决定剧情站位、摄影构图和瞬时表演 |
| 地点拓扑 | 稳定场景结构与行动关系 | 入口、固定锚点、方向距离、路径、遮挡、功能区和可变状态 | 不把一次性人物站位或临时光影冻结成空间本体 |
| 道具结构 | 稳定关键物件、产品、武器或可操作部件 | 轮廓比例、材料、连接、活动件、操作面、握持 / 使用方向 | 不用漂亮产品照代替真实操作与受力证据 |
| 局部受控编辑 | 在已确认图片上只改变一个明确区域或属性 | 变化区的新结果、保护区的不变证据、输入图 / 遮罩职责 | 不借局部修改重做整张图或顺手美化其他区域 |
| 叙事首帧 | 为视频建立一个正在发生的起点 | 人物关系、世界与屏幕站位、动作预备态、首个异常、阻挡和下一变化 | 不退化成中性资产板，也不把尚未发生的结果提前画完 |

#### STY风格定调图：强风格动画的共同视觉源

当逐段载体合同把当前段落明确委派为 `AI_VIDEO_FULL`，且作品需要编辑拼贴、纸媒动画、强风格 MG、系列知识动画，或用户明确要求“先看风格选项，再定视觉母板，最后做逐段分镜图和图生视频”时，先建立 `STY风格定调图`。本分支只接收明确委派的 `AI_VIDEO_FULL` 段落；`REMOTION_OVERLAY` 不进入 `STY → VMB → KF`，录屏和证据段也不因共享色彩、字体或纸艺风格而转成全屏生成资产。它和 F 人物主视觉图承担同一种上游作用：先让人类用真实画面判断整体方向是否成立，再让下游拆分；但 STY 只控制作品级视觉语法，不控制人物身份、具体段落内容和逐镜构图。

```text
同一内容基准：选择一条能同时暴露信息层级、媒介、色彩、边缘、构图和运动潜力的代表性关系。
候选竞稿：按美术风格设计交接包真实生成3—5张机制不同的定调图；候选可以沿平面剪贴、浅浮雕、微缩纸景、档案混合媒介等空间机制展开，不能只换色、纸纹、滤镜或镜像。
参考转译：用户给出样图时，先拆出空间深度、纸张结构、边缘与接缝、摄影观看位置、图文层级和可运动部件；候选至少保护其中真正承重的机制，不得把“有纸纹”误当成“像参考”。
人工定案：胜出图登记为STY01；未定案候选保持STY-A / B / C，不进入稳定调用链。
视觉母板：用户选定STY后建立`VMB01`，把胜出图编译成可跨段复用的静态语法与运动语法；未完成VMB时不批量生成KF。
静态语法：锁定媒介、空间深度、色彩角色、形状 / 边缘、纸张厚度与接缝、纹理、信息层级、版式密度、镜头观看位置和安全区。
运动语法：锁定允许的入场、退出、替换、翻页、滑轨、层间视差、纸带推进、停顿与手工定格节奏；同时写清哪些元素必须保持静止、一次只允许几个视觉动作争夺注意力。
标题文字策略：编辑型知识动画不得因担心文字崩坏而默认做成无字画面。`AIGC、快、多个方案、学习规律`这类承担主重心、节拍或概念命名的标题级大字，允许并应当先让图片模型参与定调；完整字幕、解释长句、数值和必须逐字正确的正文仍交给Remotion等确定性工具。正式KF可保留带大字版本；若文字实测崩坏、视频入口容易扭字或后期需要替换，再为同一构图补一张`P0无字底板`，不能反过来用无字底板取消标题设计。
不得继承：候选图的具体主体、文字、Logo、图标、人物、卡片坐标和完整布局。
逐段拆分：按已确认脚本节拍生成KF01—KFn；每张KF先是一张静止也能解释本段主关系的最终解释帧，再为视频保留动作起点、路径和停点。

KnowledgeVisualContract 空间化：不把脚本里的题材名换成若干图标。先把 `entities → initialState → interaction → stateChanges → resultState`编译成“知识拓扑”，再把这条因果链编译成“空间拓扑”：哪些是语义物件组，谁作用于谁，力、信息或材料沿哪条作用路径移动，哪个状态需要由 KF-A / KF-B 或多关键状态分开承担。`labelPlan`只保留少量中文大标签，就近标明身份、动作、结果或边界；不生成长句、密集小字、随机英文或生产占位符。`cameraPurpose`只能用来显露层级、穿过遮挡、跟随作用路径或完成焦点交接，不得为炫技改变知识关系。正式 KF 必须通过静音理解检查：关掉旁白后，仍能辨认核心对象、作用顺序和结果；若只能看出“这是 AI / 金融 / 医学”而看不出关系，返回重编。

强风格知识动画还要在既有图片提示词栏目内部通过`结构化信息密度与运动可供性门`。信息密度不是随机多塞图标，而是把本段唯一知识关系物理化为有层级的语义对象、过程站、路径、机关和空间结果：主承重装置之外，应按实际复杂度保留足以解释关系的对象组、2—4个不可跳步的状态节点、至少一条可追踪路径，以及门、轨道、转盘、传送带、分类槽或验证关卡中的必要物理因果；前中后景和摄影机通道只在帮助观众看懂同一关系时成立。若KF退化为“稀疏四卡片围中心标签”，只能支持同时飞入或简单汇聚，且没有对象之间的连续作用，必须返回内容设计重构；不得用无职责装饰、随机图标或全体发光漂移冒充高密度。

这里的密度指关系密度、状态密度和可追踪路径密度，不是对象数量。一个对象通过三次可见状态变化完整证明因果，比十个同时漂浮的图标信息更密。

正式编译前可在内部建立`运动可供性判断`，逐一核对真实对象的初态位置、允许动作、路径、作用对象、触发后状态、最终落点和摄影机看见过程的方式；它只用于完善现有风格、画面内容、构图和参考职责，不新增对外交付模板。复杂过程不得让一张完成态图片同时冒充起点和终点：按入口与因果阈值选择单帧、`KF-A起始状态＋KF-B结果状态`或多关键状态，并为每张图片声明起始帧、终点帧或构图参考职责。

#### AI叠层兼容预判

当 `AI_VIDEO_FULL` 后续可能承接 Remotion 的章节进度、证据标签、解释卡、结论大字或桥接提示时，KF 不能只回答“这一镜如何独立好看”，还要预判“后期信息从哪里进入而不破坏知识关系”。这项预判只描述 AI 画面给后期留下的空间与风险，不负责设计 Remotion 组件，也不替最终合成做蒙版决定。

每张承重 KF 在现有交接中补充：

```text
AI叠层兼容预判：可兼容 / 有条件兼容 / 本镜禁止叠加。
视觉锚点：本镜必须完整看见的主体、作用路径、结果装置及其运动轨迹。
稳定负空间：在一段可读时间内，主体、镜头和光线都不会侵入的区域；没有就明确写“无”。
禁入区域：人物脸手、核心标签、主因果路径、结果停点以及镜头即将穿过的区域。
亮度分布：按起始 / 过程 / 结果写暗、亮、混合或快速变化，不能只给全镜平均值。
运动负荷：按阶段写低 / 中 / 高，并指出运动来自摄影机、主体还是前景遮挡。
可交接时刻：哪个知识状态完成后，画面可以把第一注意力让给后期叠层。
```

稳定负空间不是为了把画面做空，也不能牺牲主知识结构去预留“万能右侧空位”。已有深色背景与高亮 Remotion 自然形成足够对比时，可以建议后期不加衬底；背景复杂或明暗快速变化时，只指出风险与可用区域。最终采用无衬底、局部底板、区域压暗还是全幅压暗，必须由后期对真实生成视频逐帧复核，资产层只做预测。

视频交接：图生视频绑定VMB01负责成像世界与动作边界，KF负责本段对象、关系和构图；人物身份、产品结构和场景拓扑仍由各自资产负责，视频正文主要展开运动、触发、镜头、声音与结束状态。
```

风格候选图属于面向人定调的成品图；人工选定后，STY01 先被编译为VMB01，再成为全局参考资产。选中不是把整张图片冻结：下游必须使用`参考职责合同`隔离样本残留，尤其不得复制外部品牌、字体、原文字、Logo 和精确版式。风格图只证明“想选择哪一种观看方式”，视觉母板证明“这种方式如何稳定复用”，逐段 KF 才证明“这一段画什么”；三者不能互相替代。这条分权简称 `STY＋VMB＋KF`：STY负责用户定案，VMB守统一静态与运动语法，KF守当前段落的内容关系与构图。

#### 正式图片像素验收门

STY、VMB、KF 或其他真实图片不能凭文件名、提示词、生成任务名称或项目状态自动通过。登记为正式资产、正式成品图或正式视频参考前，必须打开实际文件完成`正式图片像素验收单`：

```text
资产编号与绝对路径：
验证状态：正式候选 / 草图 / 未验收。
目标语义：这张图按上游任务应当让观众看见和理解什么。
真实像素语义：不看文件名，只根据实际画面复述主体、关系、流程和结论。
目标语言与实际文字：目标受众语言；画面实际出现的标题、标签、英文、乱码或占位。
第一视觉重点：缩小前后首先读到什么，它是否服务目标语义。
手机可读性：按目标发布尺寸缩小后，承重标题、关系和对象是否仍能辨认。
生产编号 / 占位文字泄漏：是否出现内部编号、临时英文、样本原字、Logo或模型伪字。
文件身份一致性：文件名、资产表职责与真实像素语义是否同一段、同一对象、同一状态。
正式视频参考资格：通过 / 返修 / 仅作草图；明确唯一消费者和失效时点。
```

`目标语义`与`真实像素语义`不一致，或文件名与真实内容不一致时，直接失败并停止登记；不得通过改表述把错图解释成正确文件。KF04 与 KF05 一类内容对调必须在这里被拦截，二者都不能继续下发 VID。

正式观众画面禁止出现仅供生产定位的`KFxx / STYxx / VMBxx`等内部编号。目标受众为中文时，`AIGC`、`AI`等内容本身需要的英文缩写可以保留；`SOFTWARE`、`MODEL`、模板标题等英文临时占位只有在它们本来就是确认内容时才允许。生产编号、英文临时占位、乱码、样本原字或未确认标签一旦成为第一视觉重点，正式验收失败。

草图允许保留生产编号或临时占位，但必须隔离为`草图 / 未验收`，登记唯一用途和失效时点，不能下发视频、封面或发布链。风格方向可用不等于知识终帧可用；STY只验风格职责，VMB验跨段语法，KF验当前段落知识关系，三者分别打开真实图片验收，不能互相背书。

这道门只在风格仍未确认且真实视觉选择会影响整批下游时生效。已有经人工确认的VMB、已有系列母版、用户锁定完整风格，或普通写实镜头只需继承既有作品成像合同时，直接进入稳定生产，不为流程整齐重复竞稿。若只有一张用户选中的风格图但缺少可执行母板，先编译VMB，不重复竞稿。

身份母版、地点拓扑和道具结构属于稳定资产分支；叙事首帧属于镜头状态或成品图分支；局部编辑属于已有图片的变更分支。先分流再调用人物、服装、场景、道具、摄影和注意力 Reference，避免让一个漂亮参考图同时控制身份、构图、空间和动作。

#### 局部受控编辑合同

局部编辑先建立`变化区 / 保护区`，再写目标结果。默认执行`单一变量编辑`：一次只改变一个主变量，例如徽章、发色、袖长、墙面破损或天空状态；若多个变化互相依赖，拆成可验收步骤，只有必须同时改变才能成立时才合并。

```text
输入图片与验证状态：
编辑目的：
变化区：位置 / 边界 / 旧状态 → 新轮廓 / 材质 / 颜色 / 连接 / 光影响应。
保护区：身份、发型、姿态、服装其他结构、场景、构图、镜头、光线中本次未授权变化的具体项。
输入职责 / 界面参数 / 提示词正文：输入图守整体基准；遮罩或局部选择守像素位置；强度、画幅等由真实界面参数负责；正文只写目标区域的新可见结果和必要的邻接响应。
验收：变化是否发生；保护区是否漂移；是否引入新对象、文字、边缘断裂或光影不一致。
```

保护区是内部与验收合同，不把一长串“不要改变脸、不要换场景”塞进模型正文。正式正文正向描述编辑后的唯一目标及其与邻接衣料、皮肤、墙面或光线的真实连接；没有遮罩能力时，先标记入口控制风险，不能用更长的文字假装拥有像素级定位。

#### F人物主视觉图：B / W / M的共同成图源

旧行为场景中的`B / W / M的共同成品源`只作为兼容检索词保留；当前语义是共同成图源，不代表F已经提供全部侧背面、鞋履、内里和身体参数。

主要人物需要跨多集稳定复现时，先让擅长人物审美和完整角色实现的模型生成`F人物主视觉图`。F先是一张面向人观看的角色定调成图：它要让观众从一个正在发生的可感瞬间中，同时认出人物的脸、身体倾向、服装、妆发、气质、色彩和成像世界。它先供人工比较和选择，选中后再成为B / W / M的共同反向拆解源图。F本身不按稳定资产验收，不直接进入视频，也不代替B / W / M；它在三项拆解通过人工验收前始终保留。

主要人物进入F前必须已经有`服装方向已确认`记录：记录胜出候选、保留与删去项、允许专业补全范围和重新开启条件。若服装Skill状态仍为`待服装方向确认`，本Skill只能返回确认节点，或按老胡明确要求编译标记为`候选试验`且不进入稳定链的测试图；不得自行合并候选、根据模型随机美图替老胡选美，也不得先建正式F再倒推胜出服装。`服装方向确认`决定穿什么，`F人工选定`决定哪一张完整角色成图最准确地实现已确认设计，两道确认不能互相代替。

F的依赖为`美术风格设计交接包＋人物写真设计正文＋服装设计正文＋妆造补充正文＋成品图画面框架`。画面默认走人物主视觉或影视剧照逻辑：先确定人物此刻想要什么、正对谁或什么作出反应，再让重心、视线、衣发、道具、空间、光影和摄影机位置共同证明这一瞬间。根据主证据选择头肩、半身、七分身或全身；不为后续拆解强制正面、直视镜头、头脚完整、所有结构同时清楚或安全边距。人物主视觉成图的正文内部必须完成`基础设定 → 氛围与画质 → 画面内容与构图`三段职责，标题可以显式，也可以融合进连续的画面叙述；不得为展示格式打断同一瞬间的因果和观看流。视觉资产只把美术方向和三份专业正文接入成品图框架，不重新决定题材、选角、服装或妆发。

同编号反向拆解合同为：`F → B`提取可见脸身与比例证据，不可见侧背面和数值由人物设计正文定向补全；`F＋服装设计正文 → W`提取可见穿搭效果，再补足被遮挡的背面、内里、鞋履和拆分结构；`F＋B＋W＋妆造补充正文 → M`提取可见妆发与穿着关系，再补足侧背面。每项补全都是待人工选定的制作推定，不得冒充F已经可见的事实。W只有在资产板包含上身展示时才引用B作为体型承托；纯平铺拆解不强制引用B。F不直接进入首帧、封面和视频，视频只引用经过拆解和验收的B、阶段素体、W与M。

没有人物设计授权时，F不能借“更好看”重新选角。没有服装方向确认记录与服装设计正文时，F不能用模型默认服装代替专业设计；没有妆造补充正文时，写真可以先呈现已经确认的可见妆造，但M不得把侧背面猜测包装成确定设计。若专业人像模型改变核心骨相、年龄、文化身份、服装设计或人物第一印象，返回对应专业负责人，不能让漂亮结果倒改上游母版。

### 单张成品图

资产回答以后还能不能认出来，成品图回答这一眼值不值得停下来。

一旦判定为单张成品图，停止建立资产总表、规格板、跨请求依赖和中性展示；进入当前图片的观看设计。提示词不能从“主体 + 风格 + 画质”直接拼接，先形成内部成品图工作卡：

```text
观看结果：目标观众看见后主要感到、相信、记住或想做什么。
决定性瞬间：为什么偏偏截取这一刻，而不是前后任何一刻。
主关系：人物与人物、人物与物件、主体与空间，哪条关系在承重。
前后帧：前一瞬留下什么，后一瞬正往哪里去。
摄影机关系：观众为什么站在这个距离、角度和信息位置。
环境回声：空间怎样作用于主体，主体又给空间留下什么变化。
第一落点与视线出口：先看哪里，最后停在哪里。
主动退让：哪些背景、装饰、肢体边缘或光效可以暗、软、挡、空。
记忆证据：去掉“高级、电影感、氛围感”等总结词后，哪项可见关系仍使它属于本图。
```

只有开放设计尚未确定决定性瞬间，或用户明确要求候选比较时，才竞争真正改变观看位置、关系压力、空间作用或第一落点的构思；只换服装、色板、天气、镜头型号和滤镜不算不同方案。已经确认方向的稳定生产直接继承，不把A/B比较变成每张图的固定成本。

所有含人物的结果图，包括人物主视觉、写真、人像、封面主体、叙事首帧、生活方式英雄帧和已有照片升级，必须读取 `references/06_人物生命感与现场摄影关系.md`，不是等画面失败后才补读。F也走这条成图路线：它不必复制某一场正式剧情，但必须设计一个与人物稳定气质同源的当下目的、关系对象和未完成状态，让脸、身体、服装、妆发、环境和摄影机共同构成一个活着的角色答案。没有人物的氛围图、概念图和奇观静帧也要保留决定性瞬间、摄影机权限、空间第二力量、光色来源和余韵；按对象再读取场景或风格 Reference。

成品图提示词按 `当前人物 / 主体状态与事件 → 摄影机观看关系 → 身体 / 物件 / 空间的承重变化 → 环境回应 → 光色与材质来源 → 局部光学反应 → 当前停点` 编译。若静态图里所有对象都处于最完整、最正面、最稳定的展示状态，优先判定为制作图或摆拍，不用“抓拍感、生命力、电影感”替它辩护。

### 依赖顺序

资产不能作为人物、道具、场景、风格四张孤立清单。写提示词前建立无环依赖图：

```text
全局锚点：固定 Logo、世界材质、色彩关系、主成像基底。
独立锚点：人物身份、关键物品、空置基础场景。
组合结果：最终造型、穿戴关系、布置后场景、人物与产品 / 坐骑 / 车辆关系。
镜头状态：首帧、尾帧、故事板和具体动作状态。

群像身份图与叙事调度图分权：正面集体合照只负责成员身份、五官、发型与身高体型差；复杂多人正片另用镜头首帧、故事板或clay render负责世界位置、屏幕层次、姿势、运动路径和摄影机轴线。身份校准图不能越权成为默认叙事站位。
```

这不是固定四级目录。根据项目风险裁剪，但下游资产必须排在全部上游之后。出现循环引用时拆清职责，不能靠调整排版掩盖。

每条依赖写清：

```text
下游资产：
上游参考：
上游只负责：身份 / 结构 / 材质 / 比例 / 空间 / 色彩 / 佩戴关系中的具体项。
禁止继承：背景、临时表情、一次性动作、无关服装或构图。
生成前置：上游图片是否真实存在并已验收。
变更传播：上游变化后哪些下游必须重验。
```

#### 上游变更失效门

资产一旦被下游引用，就不能把“上游文件已经改了”误当成“下游已经自动更新”。任何会改变身份、阶段体型、疾病 / 伤势、服装、妆造、道具结构、场景拓扑、锚点、材质或色彩的上游修改，都先做反向依赖审计：列出直接消费者与传递消费者，逐项判断改动影响哪些字段、哪些图片提示词、哪些M / 首帧 / 故事板 / VID / 封面和哪些已生成素材。

受到影响的消费者立即标记为`待重编译 / 待重验`；旧图片、旧视频和旧抽帧只保留为历史证据，不能继续代表当前资产状态。每个消费者只能以两种方式关闭：正文和绑定职责已经同步修改并重新验收；或明确证明本次上游变化不进入该消费者的可见范围，并记录理由。只改资产表、不更新消费者，或只改一个被用户指出的VID而未枚举同资产的其他调用，均不得标记阶段完成。

反向依赖回执至少包含：`变更资产与字段 → 直接 / 传递消费者 → 每个消费者的处理动作 → 已生成结果是否失效 → 复验结果`。组合资产还要重新仲裁属性权威：同一人物的身份、阶段脸身、疾病肤色、服装、妆发和瞬时表演各自只允许一个主负责人；下游参考可以补充其他属性，不得把上游已经确定的阶段状态重新平均回健康母版或默认状态。

### 全画面闭合

图片标题写“丈夫资产”，不代表画面里只会出现丈夫。写提示词前盘点所有可能被模型画出的可识别对象：人物、关系人、服装、穿戴物、手持物、Logo、屏幕、倒影、家具和背景人物。

每个对象只选一种处理：

- 已有确认图片：显式引用并限定职责。
- 尚无图片但必须出现：从同一规范词账本复现身份、数量、位置、颜色、材质和状态。
- 本图不需要出现：通过构图、画外方向、遮挡或空场让它不进入画面。

不能写一句关系动作，让模型自由补出一个错误的人，再把错误继续传给下游。

#### 引用也要闭合

全画面引用闭合不只检查“有没有参考图”，还要检查每张参考只控制什么。凡是画面中可识别对象由参考资产承担，必须同时写清：实际绑定文件、身份 / 结构 / 材质 / 比例 / 空间 / 色彩中的职责、禁止继承的背景与瞬时状态、当前剧情时间状态，以及它是否已经真实生成并验收。上游尚未生成、只存在文字定义时，不得在下游提示词里伪装成已绑定图片。

每张参考使用同一个`参考职责合同`：

```text
绑定对象 / 主职责 / 次职责（可选） / 必须保留 / 允许改变 / 不得继承 / 失效时点 / 验证状态。
```

每张图只设一个主要职责。身份参考不自动继承构图、背景与瞬时状态；结构参考不继承占位色、编号和示意文字；风格参考与版式参考不继承原主体、品牌、原文字和精确组合；辅助插入不能反过来接管整张图。必须保留、允许改变和不得继承互相冲突时，先返回美术方向澄清，不把矛盾交给模型平均。

交给具体图片或 VID 时，不转发整个资产库，而是形成`激活参考候选`：只列当前请求真实可能绑定、能降低承重失真的少数参考，并逐项写主职责、不得继承、验证状态和与其他参考的属性仲裁。候选不是已绑定；下游根据目标入口可接收类型、参考数量、构图权重和当前镜头任务再次裁决，最终只有实际上传 / 调用的项目进入`【基础设定】`。未生成占位、与本镜无关的角色场景服装、重复控制同一属性的参考不得进入运行上下文。

组合画面需要的关系人、穿戴物、手持物、布置结果和倒影，不能因为主体资产已经存在就自动视为闭合。每一个会被模型补画的对象都要么有确认参考，要么有同一规范词账本，要么通过构图明确不出现。

### 状态不能混成身份

稳定身份、持续阶段和瞬时表演分开：

```text
稳定身份：脸、体型、永久结构、固定空间和不随剧情变化的锚点。
持续阶段：会跨多个独立片段保持的服装、伤势、污染、变身或破坏状态。
瞬时表演：眼神、呼吸、动作受力、哭笑、抬手、摔落和本镜光影。
```

持续阶段是否做图片由复用与失真代价决定；瞬时表演交给分镜和视频提示词。互斥状态不画进同一资产，让模型自己融合。

### 故事时间账本与换装判断

人物跨越多日、季节、成长、增减重、治疗、受伤恢复或身份阶段时，先按真实故事时间建立 `故事时间账本`，再按剧本和剪辑顺序调用。剧本先写学校、后插入医院回忆，不代表学校发生在初诊之前；如果不先还原真实时间，身体、服装和伤病会被错误地按文档顺序继承。

账本只登记会改变资产或镜头状态的事实：

```text
故事阶段 / 与上一阶段的时间距离：
年龄、身高与人物阶段状态：
持续身体变化、伤病或污染：
场景功能与季节天气：
当前最终造型与服装尺码：
哪些镜头属于必须连续的同一天 / 同一行动：
允许变化 / 必须不变 / 变化证据：
```

`人物阶段状态` 用于同一身份在多个独立片段中持续存在、且仅靠正文容易漂移的体型、年龄段、康复期、伤病期或形态阶段。它引用同一身份，只固定该阶段的脸部软组织、身体轮廓、比例、体态和运动限制，不固定戏服、最终发型、妆容、剧情表情和场景。它在图片职责上就是阶段素体资产：完整继承B的校准板信息结构，而不是另做一张普通身体三视图。身份资产不锁最终服装，也不把某一阶段体重冒充永久身份。

换装判断只看三项：故事时间是否跨越到合理换衣节点；地点和活动功能是否需要不同穿着；相邻镜头是否属于必须保持的直接连续。跨日、跨季节、学校到家庭或医院复检通常需要重新判断；同一天从诊室走到回家路通常保持同一套。禁止为了资产丰富每场必换，也禁止为了省资产让角色数月一直穿同一件衣服。

时间账本一旦跨季节，季节不能只留在表格里。每个W先写`适用时间戳`和`环境热条件`，明确T阶段、具体天数或直接连续关系，以及室内外、昼夜、空调、活动量与职业 / 医疗环境；再把季节证据传给W与M：层数、覆盖面积、面料克重与表面、袖裤长度、鞋袜和穿法至少有三项共同变化。身体阶段只决定版型、尺码和松量；季节阶段决定层数、覆盖和材料性能；人物身份决定设计语言；场景动作决定开合与活动余量。四类原因不得互相替代。室内空调、职业制服或医疗要求允许保留长裤与薄外层，但必须在`环境热条件`中说明其功能，不能让厚卫衣、抓绒或保暖外套无理由跨入盛夏。若同一W跨两个非连续时间点复用，必须逐一列出时间戳，并证明机构规范、恒温环境和人物状态足以让服装结构保持不变。

## 美术与提示词

### 先选设计，再锁一致

稳定只能保护设计，不能把普通设计变高级。没有参考图时，先围绕当次作品竞争 3—5 个真正不同的方向；差异落在受众承诺、轮廓比例、形状语言、材质、配色、选角、空间语法或视觉记忆点，不只是换滤镜。

选择前建立：

```text
作品类型与观看情境：
目标受众为什么愿意靠近、相信、购买或记住：
资产在故事或商业表达中的职责：
第一眼感受或欲望：
形状、比例、材质、色彩、妆造与空间怎样同向：
一个远看可认、近看可记的视觉记忆点：
同类最常见的平均答案，以及本案为什么不取：
```

这组判断是资产美术指导门。它必须在批量写提示词和锁一致性之前完成：先比较已确认人物设计、产品轮廓、形状语言、材质、配色、空间和记忆点怎样共同服务作品承诺，再选定一套方案。只得到“高级、电影感、统一风格”或若干互不冲突的形容词，说明设计尚未成立；此时不能进入资产批量生产。人物选角和身体化尚未确认时，不在本门临时补选，先返回`laohu-character-design`。

材料不靠稀奇取胜，也不靠私人专属自动深刻。选材看承载力：它能否说明人物、功能、世界规则或公共经验；换成同类平均材料后，关系和结果是否变弱。宏大环境可以有公共尺度，小物件可以有亲密证据，两者按作品用意选择，不预设大小。

### 图片提示词的因果顺序

观众成品图按 `主体 → 场景 → 时间 → 主情绪 → 摄影位置 → 光色 → 材质 → 可见结果` 推导；制作资产按 `身份 / 结构职责 → 必须看清的视角 → 比例与材质 → 中性展示 → 下游一致性` 推导。

上游提供叙事灯光合同时，观众成品图先形成`静态受光证据`：当前光源与方向、相对面积 / 软硬和衰减、人物脸身或关键物的明暗边界、轮廓与眼神光、背景层级、材料和空气响应，以及必须显露 / 允许隐藏的信息。`参考帧灯光职责`只提供已确认的观看关系；资产层不得反推精确灯位、灯具功率和后期链路，也不得把参考帧整段提示词复制到不同人物和空间。

B / W / M / S / A / G等制作资产默认以`中性校准`和结构可读为先，除非叙事灯光本身就是必须校准的稳定属性，否则`不强加叙事光态`。中性展示可以有清楚主光、补光、眼神光和材料反应，但不能为了氛围吞掉脸、侧背面、参数、服装结构和空间拓扑。

正式编译图片提示词前，必须先建立一次内部`注意力合同`：唯一生成任务、主注意力、主证据、支撑证据、主动退让和3—6项不可丢锚点。它不是第四段，也不原样投喂模型；它负责让人物、服装、妆造、场景、风格和摄影共同证明同一个结果。若无法指出唯一主结果，或同一张图同时把脸部微妆、完整全身、服装内里和宏大环境都列为最高优先级，先分配证据尺寸、派生其他资产或返回上游，不继续堆描述。

注意力合同不能只判断“写没写”。正式首稿先形成高密度母稿，再按共享注意力Reference的0—3级强度门建立内部`视觉主导合同`：承重维度必须达到3级，至少用两种彼此独立的画面机制把第一视觉落点抬到最高，并明确第二眼、第三眼与竞争元素怎样退让。脚本通过只说明没有明显缺项，不说明画面已经高质量；资产层必须继续判断焦点是否真实主导、有效信息是否高占比、每项光影 / 构图 / 服装 / 场景信息是否共同证明唯一结果。

注意力合同之后执行正式编译顺序：`完整设计读取 → 必须锁定 / 方向引导 / 模型补全 → 选择性编译门 → 当前结果身份的外部结构 → 反向审稿`。设计库不是投喂清单，完整判断不等于完整投喂。视觉资产不得以“完整继承”为理由，把人物、服装、妆造、美术、场景和摄影正文全文拼接。先保住身份、题材、关系、主轮廓、主光关系和1—2项`非默认人物记忆点`；已被方向覆盖的次级局部留作`生成开放空间`。

稳定生产直接继承已经确认的美术风格设计交接包、`结果图成像合同`、人物、服装、妆造和布景设计，只编译当前画面发生了什么。复盘不是默认步骤：只有用户明确要求复盘、已有真实结果需要诊断，或当前输入出现无法由既有权威裁决的冲突时，才路由`laohu-generation-review`；不在每次生成后自动安排A/B测试、盲测或固定复盘。

所有正式图片正文都必须通过`镜头可执行语言`闸门；用于连续自然语言成像时，也称`镜头可执行的画面叙述`。题材、媒介、身份和成熟风格母型可以作为先验召回保留；正文主体必须写模型能成像和验收的对象、位置、关系、状态、材料、光线、构图与结果；人物心理、观众感受和设计原因留在内部工作卡，翻译成可见证据后才能进入代码块。所有含人物的结果图还要形成`单帧因果`：`过去痕迹 / 当前关系响应 / 下一趋势`；不依赖固定时间词，而由重心、眼线、接触、受力、惯性、环境余波和摄影机位置证明。结果写真、人物主视觉、封面主体和叙事首帧使用单帧分支，以关系对象、未完成动作和2—4个脸身衣发道具环境通道共同证明一个结果；制作资产只继承可执行语言闸门，不为生命感强行增加剧情动作。

人物结果图继续分静态与动态两支：静态关系帧证明人物正在回应谁、动作为什么未完成；动态动作帧必须额外写清支撑点、力量来源、单一发力路径、接触点、受影响对象、受力结果和余势。两支都必须建立第一眼 / 第二眼 / 第三眼和主动退让；不得把“挥剑、奔跑、推柱、衣袍飞扬”当成动态充分证据。

图片正文同时完成`已知母型 → 当前原创变化 → 可见证据`编译。人物、服装、材料和场景先使用模型训练中稳定的高频类别，再追加形状、位置、表面、受光与状态；世界观专有词必须紧跟视觉翻译。风格名称可以保留，但一个结果只设一个主锚点；其他名称必须明确只负责某一项构图、色彩、光影、材料、空间或运动机制，不能同权决定整张图。任何将被交给模型产生图片结果的提示词，包括草图、快速试验和候选图，都必须读取`02_共享资产库/05_工具流程/视觉生成模型注意力与提示词编译参考.md`，完整执行注意力合同和镜头可执行语言编译并留下调用回执。任务简单时可以缩短正文和回执，但不能跳过唯一任务、主注意力、主证据、支撑证据、主动退让与不可丢锚点中的任何判断。

#### 结果写真与制作资产使用不同外壳

`结果图写真`指一个人物、场景、道具、产品或其他对象已经设计成立后，被摄影机拍成的一张最终结果照片；F人物主视觉图属于这一类。它不是所有图片的统一模板。三段职责必须成立，标题可以显式或融合：

```text
【基础设定】图片类型、用途、表现媒介、原创对象、身份 / 功能、必须继承的参考。
【氛围与画质】著名导演、作品、艺术家、摄影传统、艺术流派或时代影像风格名称；可迁移的视觉机制；色彩、光线、材料、空气与成像介质。
【画面内容与构图】对象的完整具体设计、姿态 / 状态、环境、摄影机高度与方向、焦段 / 透视、主体占比、第一落点、前中远景、留白和裁切安全。
```

三段不是为了排版整齐，而是防止身份、审美先验和摄影实现互相吞没。正式模型正文可以保留三行标题，也可以把三段内化为一段连续、具象的画面叙述；验收看职责是否齐全且共同指向一个结果，不检查标题字样。名称锚点和`结果图成像合同`必须来自`laohu-art-direction`，并与当前可迁移机制一起出现；资产层不能只写`电影感、精修、东方、高级`，也不能临时另选导演或作品。

B / W / M / S / A / G等制作资产保留自己的专业框架，不机械改写成三段式。共同内核仍然进入它们：身份或结构职责决定展示什么；风格锚点转译后的色彩、材料与光线决定怎样展示；构图、主次和观看重点决定信息怎样被读到。例如W仍是平铺 / 人台 / 细节拆解板，S仍是多机位与鸟瞰结构板，B仍是固定三列校准板。`制作资产保留自己的专业框架`，不等于放弃审美，而是把同一灵魂与筋骨编译成该资产真正需要的版式。

普通制作资产不强制读取参考图形式转译 Reference。只有上游已经确认形式转译卡，且其中某个关系会改变资产的识别、材料、光影、色彩或观看重点时，才消费这一部分；不得重做候选，也不得把 B / W / M / S / A 变成极简 Zine、上下分栏、双色、点阵或抽象面板。制作资产的结构证据、依赖、固定画框和下游调用优先级不因风格转译而退让。

中性展示不等于中性设计。制作板可以使用普通背景和均匀光，但人物选角、产品轮廓、服装造型、材质配色和世界观必须先成立。

抽象词要解压成可见关系：

- “电影感”落到观看位置、构图、光源、色彩、材质和成像介质。
- “治愈、危险、孤独”落到处境、表情、身体、空间和环境证据。
- “特写”落到裁切、主体占比、角度、焦点和可见细节。
- “高级”落到比例、接缝、材料、留白、层级与真实使用情境。

每条可复制提示词单独放入 `text` 代码块。代码块先正向描述要出现的结果；具体不该出现的人、物和剧情风险放在代码块外，避免反向召回。需要手动绑定的内容用 `【……参考@……】` 显性标注，并在同一句写清职责。

### 人物、场景与物品

#### 美术方向调用门

视觉资产不负责从零决定作品题材风格。新作品、混合题材、系列首批F / W / S，或真实生成结果在`去标签测试 / 去背景测试 / 相邻替换测试`中落入其他题材时，先调用`laohu-art-direction`取得包含`风格先验与美术锚点`的`美术风格设计交接包`。视觉资产随后只做三件事：把已确认的题材视觉证据和名称锚点所承载的可迁移机制接入正确资产框架；检查模型是否兑现；把偏差按最早负责人回流。

若交接包本身缺少主辅类型、视觉证据矩阵或相邻类型边界，返回美术风格设计；若交接包正确而人物、服装或场景专业正文没有兑现，返回对应专业Skill；若两者都正确而图片仍漂移，才留在本 Skill修正引用、权重、提示词编译或模型适配。不得在资产代码块末尾临时追加“仙气、未来感、电影感、高级”等词掩盖上游缺口。

#### 人物设计调用门

B / 阶段素体 / M / G资产编译不再兼任完整原创人物设计。出现主要人物或关键配角首建、多人同脸同体型、人物只有年龄性格和发型清单、第一印象承担反转、稳定动作语言不清，或同一人物需要跨真人写实、2D、3D与AI保持身份时，先调用`laohu-character-design`，取得`人物设计交接包`后再继续。

三种入口分开：

- 完整原创：人物设计包必须含人物核心事实、3—5个脸身姿动真正不同的候选、第一印象—真实人格合同、自动胜出与淘汰理由、群像差异和媒介母版。
- 锁定身份：只继承用户有权使用且证据真实可见的脸身事实；不可见角度、背面身体、身高和围度不得写成零改动还原，按`推定制作信息 / 高风险缺口`分离。
- 一次性远景群众：不逐人建立人物母版或B；仍需留下年龄、体量、姿态、动作能量和密度范围的轻量群体合同，不能只写“一群弟子”。

视觉资产负责把人物设计、服装设计与妆造正文整合成F人物写真母图，再把人工确认的F反向编译为可生成、可复用、可验收的B、W、M、阶段素体与G，并把`交给道具 / 装备资产`的人体尺度、握持穿戴、重量重心、动作语言和高风险点传给角色所属物分支。它不得重新选择骨相、身体比例、服装本体、妆造方向、第一印象、稳定动作语言、媒介锚点或人物—物件关系。只有资产编译或真实生成暴露身份不稳定、服装结构不闭合、妆造侧背面无法成立、群像同质、跨媒介回归失败或人体工学冲突时，携带证据返回对应专业负责人。

#### 服装设计调用门

W / M资产编译不再兼任完整原创服装设计。出现主要人物首套服装、世界 / 阵营衣橱、角色弧线换装，或现有服装合理但平庸、全员同袍换色、只靠腰饰区分时，先调用`laohu-costume-design`，取得`服装设计交接包`后再继续。

三种入口分开：

- 完整原创：设计包必须含世界服饰宪法、人物服装命题、3—5个真正候选、自动胜出与淘汰理由、固定项和可变项。
- 已确认设计：用户明确锁定且有权使用时，不重新设计，只登记设计锁定清单、允许补全的制作信息和禁止新增项；会改变可见或运动轮廓的是`高风险缺口`，先请求补充参考或确认，不影响锁定外观的工程补全标为`推定制作信息`。
- 一次性背景群众：可以不建个人W / M；若等级或阵营承重，只接收轻量群像衣橱语法，写入群像资产或镜头正文。

视觉资产负责把胜出服装设计正文、写真母图和固定拆解框架组合成可生成、可复用、可验收的W，再把F、B、W和妆造补充正文组合成M；不得重新发明、概括或补写轮廓、比例、结构、材料关系、文化来路和妆造方向。只有资产编译暴露出无法制作、无法活动、无法引用或生成模型稳定失败时，携带证据返回对应专业负责人。

人物资产按职责建立，不把普通服装当成可以跳过的空白，也不把制作板字段当成人物设计理由：

- 专业人像模型与规格板模型能力明显分化，或主要人物需要长期跨镜复现：先建立包含完整人物、服装和妆造的F人物写真母图，人工确认后再拆同编号B / W / M；F不直接进入视频。
- 身份需要跨请求稳定：建立人物素体或身份校准资产。
- 同一身份存在可复用的体型、年龄段、康复、伤病或形态阶段：按需建立人物阶段状态资产，仍由同一身份上游控制，并使用完整阶段素体板。
- 只要角色的最终穿着会进入人物资产、故事板或视频，所有最终服装先建立W；普通、朴素和一次性服装也不能直接跳进M或视频正文。只有没有被资产化的一次性背景群众，才允许在群像或镜头正文中统一描述服装。
- 每套最终造型建立M；它引用F、身份、当前阶段状态、已确认W和人物设计交付的妆造补充正文，形成当前发型、妆容、装饰与完整穿着结果。
- 手、脚、义肢或局部只有承担身份 / 产品操作且反复出现时才补局部参考。

B素体必须逐项继承胜出`人物设计交接包`，按需引用同编号F，只把已确认的脸身关系编译成制作板，不因模板需要重新选角。它把脸部身份与身体校准分开控制，并严格复刻同一套16:9固定三列网格，不允许模型按人物、性别或文字多少重新排版。左栏约占画面宽度36%并贯穿整高，只放正面头部大特写，负责全板唯一清晰人脸以及五官、骨相、肤色、发际线、发质和永久面部特征；中栏约占45%并横向三等分，依次放左前方45度、正面、背面三张同尺度身体，使用同一具完全无头发的无五官校准头模，只负责身体轮廓和参数。三张头模从额顶、颞侧、耳后到枕骨均为连续、同色、哑光校准头模表面，只保留头颅与耳廓体块，不生成真实或模糊五官、头发、发际线、眉毛、睫毛、胡须、眼镜和头饰。三具身体统一穿纯白、不透明、哑光、中等克重校准服：立领前拉链长袖校准上衣、全长校准裤和白袜；领口、肩缝、袖口、前拉链、腰头、侧缝与裤脚必须清楚可见，衣料与肤色有清楚色差，贴合身体但保留2—4cm活动松量，除头颈与双手外不露出皮肤。身体轮廓由服装外轮廓、受力和参数共同证明，不使用肤色紧身衣、身体涂装、无缝人台表皮或近似裸体的表达。右栏约占19%并贯穿整高，是固定文字标注区，标题固定右上，年龄 / 身高 / 体重固定在标题下方，围度与长度按固定纵坐标向下排列，说明固定右下。中栏只允许在正面与背面身体之间出现一个头身比短标；其余参数只能位于右栏，不能改成底部横栏、左下参数栏、分格表格或紧贴人物的自由文字堆。关键围度使用白色圆点落在正面身体的解剖位置，以不交叉的水平细白引线连接右栏对应文字。

B的身体参数标注至少覆盖年龄、身高、体重、头身比、骨性肩宽、胸围、腰围、臀围、颈围、上臂围、大腿围、小腿围、肩点至腕、髋点至地和基础体态；开放设计的原创角色使用人物设计已经胜出的明确设计值，不声称真人测量。锁定真人缺少测量或全身证据时，不能为填满B而虚构数值，应先隔离推定制作信息和高风险缺口。三张身体从头模顶到脚底完整出现，共用同一地面线、头顶线、身体尺度、站姿、校准服、背景、光向和阴影方向。标题、正文、单位、引线、圆点和右下说明使用统一白色无衬线字体与固定字号层级；下游禁止继承注释文字、灰底、校准服和假人头模。

阶段素体资产必须逐项继承B的固定三列网格、36% / 45% / 19%栏宽、整高关系、三身体等分、纯白不透明校准服、右上标题、右栏参数纵坐标、水平引线、右下说明、字体层级和地面线，不能只写“版式与B一致”后让模型自由解释。中栏仍为同一具完全无头发的无五官校准头模所承载的左前方45度、正面、背面身体，头模表面连续、同色、哑光，只保留头颅与耳廓体块；校准服沿用立领前拉链长袖上衣、全长校准裤、白袜、清楚结构缝线和2—4cm活动松量，只允许身体轮廓与阶段数据变化。右栏用同一参数顺序显示当前完整值，完整参数与阶段增量同时保留，一句可见形体变化压缩为右下说明，不新增底栏或左下信息格。所有相邻阶段保持裁切、站姿、头顶线、地面线、光线、背景、字体、注释纵坐标和身体尺度一致，变化只能发生在阶段脸软组织、身体轮廓与对应数字。

左栏阶段脸必须把 `永久身份锚点` 与 `阶段可变区` 分开写，这套分离控制才叫阶段脸受控变化。永久身份只锁眼鼻口耳、发际线及其相互位置，不把整张脸型、脸颊厚度、下颌缘、颏下轮廓或颈部宽度一起锁死；阶段可变区明确列出本次允许改变的颧颊软组织、外侧脸颊轮廓、下颌缘显露度、颏下轮廓与颈部视觉宽度。每个阶段都要有无需上一张图也能执行的 `绝对目标`，再用已真实生成并验收的相邻阶段图强化连续性；`更饱满、进一步柔化、最明显、自然一些` 不能单独承担变化。绝对目标优先使用分级、相对母版的轮廓比例、平面由内收到平直到凸起、下颌缘可见范围、颏下弧线和对应颈围等可观察几何。阶段验收必须做 `剪影级差`：遮住五官后，相邻脸部外轮廓仍能按阶段顺序辨认；若身体变化成立而脸部级差失败，只返修左栏脸部或先生成同裁切的多阶段脸部校准条，不重做已经合格的身体与版式。校准条属于临时比较参考，只有跨任务复用并通过验收后才升级为正式资产。

W服装资产必须同时取得已经确认的F写真母图与`服装设计正文`。视觉资产只在正文前添加“把参考写真中已经成立的服装转换成服装资产拆解图”的固定框架，再接入平铺、正背、单品、材料和细节展示要求；不再重写身份、轮廓、材料、配色、工艺和穿法。纯平铺W不引用B；需要完整上身效果时才引用B或当前阶段素体作为承托体型。人物身体参数不得进入W，不在W画面重复身高、体重、三围、头身比或身体参数板；W可以标注成衣尺寸、规格和活动松量，但标注对象必须是服装。

身份、季节、人物化锚点和阶段变化由服装设计正文落实成具体服装结果。W代码块不得再出现`身份场景活动推导、当前阶段适配、材料必须清楚、平均答案回避`等要求模型代做设计的元语言；需要追溯的设计分析留在代码块外，模型正文只写已经决定的服装和资产展示结果。

W使用16:9固定服装视觉规格板，图片信息为主、名词短标签为辅。服装设计交接包已经完成`服装主件结构判断`，视觉资产据此选择框架，不再裁决。夹克、内搭、上衣、下装等可以独立穿脱并各自承担结构时，属于可拆套装；连衣裙、连体服、长袍等由一件从上身延续到下摆的连续主件主导时，属于连续主件。

`可拆套装分件拆解板`使用固定2行×2列四象限，四区边界、基线和标题位置统一：左上`上装拆解`，以无头无脸上半身服装承托架展示严格正面与严格背面，放大衣领、肩线、门襟、袖口、口袋、内里和接缝；右上`下装拆解`，以下半身服装承托架展示严格正面与严格背面，放大裤腰 / 裙腰、口袋、裆部或裙片、侧缝、裤脚 / 裙摆和内侧结构；左下`配件与鞋履`，逐件展示袜、鞋、腰带、手套、口罩或其他本套穿戴物，并补鞋底、扣合与接触面；右下`材质与活动余量`，以材质微距、局部受力和中性活动承托示意证明主次面料、里布、针脚、弹性、垂坠、抬臂、坐姿、屈膝或剧情所需松量。每个主件至少有完整正面、完整背面和一项关键内侧证据；存在外套＋内搭、多层裙或其他叠穿时，上装或下装区必须保留一张`叠穿关系`小图，证明穿着顺序、开合边界和内外层露出比例。可拆模式不再用两个全身成套人台占据画面，也不把全部细节压成十二个同尺寸小格。

`连续主件完整展示板`只用于不可拆分的单一连续主件。它保留左侧约三分之一的严格正面与严格背面全身服装承托人台，证明从肩线 / 领口到腰线、裆部或裙摆的连续轮廓、垂坠、长度和正背关系；右侧约三分之二固定4列×3行共12个近似正方形细节格，第一排以整件正面、整件背面、内里 / 展开和主要配件建立整体证据，第二排拆领口、扣合、袖口、腰线或下摆，第三排拆主次面料、里布、鞋底 / 接触面、活动余量或特殊工艺。承托人台必须光滑裸头、完全无头发、无五官，不呈现人物身份和身体参数。

两种模式都以局部摄影、展开平铺、技术线稿和材质微距互证，并让所有细节可回指到同一主件。画面文字只使用上装拆解、下装拆解、配件与鞋履、材质与活动余量、正面、背面、衣领、门襟、袖口、裤腰、面料、里布、鞋带、鞋底、叠穿关系等大号名词性标题；不使用小字号解释段落、参数墙或人物尺寸表。成衣规格继续作为设计与验收依据，只有尺寸本身承担区分时才允许一个清楚的大号成衣规格标记。`复杂度只改变设计密度`：它只改变已选模式内部的证据数量、细节深度和工艺精度，不决定是否建立W，也不允许把华丽服装写成更多形容词。禁止把人物素体板、普通商品正背图、自由拼贴或长篇文字说明当成完整W。W不加入最终发型、妆容、表情和剧情动作；这些组合结果交给M。

M取得F写真母图、B或当前阶段素体、W和人物设计交付的`妆造补充正文`，使用16:9受控定妆设计板反向拆出妆容、发型、发饰和最终穿着关系。视觉上保持2行×3列，实际必须组织成左前方45度、正面、背面三列纵向组合，不是六张彼此独立的人物照片。每列上排是放大的头部与必要肩颈特写，负责五官、最终发型、妆面、肤质、眉眼唇腮、发饰、胡须、耳饰、头饰、眼镜、伤妆和其他头部细节；每列下排必须是同角度的`无头穿着身体`，从颈部根部或肩线以下至鞋底，人体头颅完整位于下部画框之外。上部特写向下覆盖下部原本的头颅位置，覆盖接缝藏在颈肩交界或服装领口附近，使上部头部成为同列身体的唯一对应头部。上下同列角度、身份、阶段体型、身体中轴、服装穿着关系、背景、光向和色彩基线一致。M不重新定义身高、体重、骨架、永久身份或服装工程。

妆造记忆锚点、穿着方式、阶段变化和克制边界必须已经被`妆造补充正文`落实成具体的眉眼、肤面、唇色、发缝、发束、发饰位置和穿着结果；视觉资产不能只写抽象字段，也不能自行发明。W负责衣服本体，M负责把写真中已经成立的妆发与W穿回同一主体，两者不能重复设计。

“根据真实事迹改编”、沿用真实姓名或题材来自新闻，只能证明故事来源，不能自动推出真人相貌复刻。只有老胡明确要求还原具体真人，并且提供了有权使用、足以锁定身份的参考资料时，才建立真人相貌参考链；否则依据剧本职责原创选角，锁年龄、骨相、发型、体态和关系证据，同时避免声称“真人复刻”或“相貌还原”。

正式复用场景进入S场景资产之前，必须继承已经确认的`场景与布景设计交接包`；空间叙事命题、候选竞争、人物—空间关系、布景陈设和制作策略由`laohu-set-design`负责，视觉资产只把胜出设计编译成可复用的场景资产、物品资产、图片提示词与调用合同，不得重新设计。用户已经锁定完整场景时执行零设计改动编译；一次性环境只承担气氛且不需要稳定拓扑时，保留为场景画面元素或单镜头参考图，不强制建立正式场景资产。若缺的是“为什么这样设计”，返回场景设计；若设计已成立但多视图走样、锚点漂移、版式或生成失败，留在本 Skill。

场景先判断是有边界空间还是宏大环境。每个正式场景至少定义一个可跨机位识别、可供语言定位的空间锚点，并写清锚点与入口、行动区、固定光源、相邻面、关键家具和人物路径的距离与方向；必要时补一个次锚点。柱、门洞、固定柜体、楼梯平台和房梁优先，可移动家具只有长期固定且承担定位时才可用。`锚点视觉指纹`必须可核对：尺寸 / 截面、材料、朝向、连接方式和少量位置明确的磨痕、缺口、色差、接口或接缝。多视图只允许摄影机坐标和朝向变化，锚点不得移动、旋转、镜像、换材质、改指纹或被复制；鸟瞰必须能反推出各机位。前者还要证明入口、方向、相邻面、尺度、固定构件和可拍路径；后者要证明总拓扑、接近过程、人尺度、门槛与内部关系。现实公共空间还要执行`功能密度与社会经济校准`：按人物经济条件、场所等级和真实流程决定面积、共享设施、固定设备与生活物，不能把普通公立医院、学校或工薪家庭做成空房、豪华单间或样板间。漂亮空镜不能替代空间资产。

物品先锁主轮廓、比例、材料、功能、接触区、活动件、文字 / Logo 和磨损逻辑。纸张、屏幕、证件、包装和仪表先裁决观众是否必须读取：需要读取就准确设计版式、文字、显示安全区和保持时间；不需要读取就固定无印刷背面、边缘、折痕、纤维、受力和湿痕，印刷面始终背离镜头，不生成半可读伪字。只有跨角度、被操作、进入特写或承担主视觉时才需要多视图；正式道具资产采用中性偏灰摄影棚，按风险展示左前方45度、正面、侧面、背面和功能特写。简单一次性道具写进视频正文。

> 道具一旦被人拿起，就不再只是造型，而是动作因果的一部分。

凡关键物品会被端、拿、递、放、开合、倾倒、破坏或跨镜继承，资产阶段必须向视频阶段交付`道具操作合同`：人物为何选它而不是相邻物、谁拥有或控制它、起点由什么承托、允许怎样接触与发力、活动件怎样运动、经过什么路径、最后落在何处并由什么继续承托。道具的造型资产只固定身份与物性，剧情中的即时位置和控制权由镜头状态承接；不能用一张中性资产图替代动作状态，也不能只写“端走、放下”而省掉离开原承托、控制权变化与新落点。一次性道具可以不建正式资产，但这份操作合同仍必须进入视频提示词。

跨VID继承真实破坏、人物站位或临时光影时使用双参考合同：稳定人物、场景、服装与道具资产只负责身份、拓扑、材质和空间锚点；通过生成复盘验收的状态帧只负责当前破坏、站位、临时光影、摄影方向和瞬时状态。状态帧只服务一个相邻单元时是临时参考；持续跨多个VID或反复调用时才升级为场景状态资产。禁止让状态帧单独替代稳定资产，也禁止把未验收尾帧登记成正式资产。

商业资产还要证明卖点：产品结构、人物用法、场景条件和镜头角度必须共同提供可见证据。只拍高级静物不能证明抓地、防水、轻量、服务效率或使用利益。

## Reference 路由

- 稳定资产先完成依赖顺序、状态分层和全画面闭合，再读取对应 Reference。

## 资产验收与交接

### 单张成品图交付

成品图不混入资产总表，单独交付：

```text
【成品图判断】
图片用途 / 目标观众 / 观看结果 / 决定性瞬间 / 选中方案及舍弃理由。

【画面关系】
主关系 / 摄影机关系 / 环境回声 / 第一落点 / 视线出口 / 主动退让。

【可复制图片提示词】
一个 text 代码块，只放图片模型需要的正向可见结果。

【生成与验收】
身份和事实硬锁 / 允许变化 / 第一眼结果 / 前后帧 / 材质与光源 / 失败返修方向。
```

成品图合格不等于可升级为稳定资产。只有后续出现跨请求复用、明确失真代价和下游调用，才重新进入资产判定。

### 资产总表

多资产作品默认维护一个 `视觉资产总表`，按依赖顺序从上到下即可执行：

```text
【资产目的与最低集合】
作品承诺：
最低可行资产：
降级为画面元素 / 成品图 / 临时参考的对象与理由：

【资产依赖与生成队列】
编号 / 名称 / 职责 / 上游 / 固定项 / 可变项 / 禁止继承 / 阻塞状态。

【规范词账本】
对象 / 唯一标准描述 / 允许省略 / 不得漂移。

【可复制图片提示词】
每个资产一段独立正文，按拓扑顺序排列。

【图片生成与验收】
小批量数量 / 选择标准 / 失败类型 / 返修或降级。

【下游调用】
每个资产由哪个 VID、首帧、封面或组合结果调用，只负责什么。
```

结果保存到当前作品 `03_视觉资产/文本/` 的阶段主文件。实际图片由老胡回传后登记到 `03_视觉资产/图片/`。

### 验收

- 这是稳定资产、单张成品图还是临时参考，是否分类正确。
- 单张成品图是否真的按当前观看结果组织，而不是套用资产板、棚拍校准或通用“高级感”提示词。
- 每个资产是否有复用范围、叙事职责、失真代价和下游调用。
- 是否已经删到最低可行资产，未把剧本名词逐项建图。
- 依赖图是否无环，提示词是否按依赖顺序排列。
- 画面中每个可识别对象是否引用闭合、文本闭合或明确不出现。
- 稳定身份、持续阶段和瞬时表演是否没有混成一张图。
- 去掉滤镜、氛围和漂亮形容词后，设计本体是否仍成立。
- 实际图片去掉题名、身份说明和常见背景捷径后是否仍符合美术风格设计交接包；若失败，是否已返回最早负责人而非由资产层重做风格。
- 形象图是否有第一眼吸引，制作图是否能换角度保持同一个对象。
- 材料与意象是否承担作品用意和公共经验，而不是为了“专属”挑小物件。
- 代码块是否只有模型要看到的正向画面，引用是否显性且职责清楚。
- 是否能指出唯一生成任务、主注意力和主证据；人物、服装、妆造、场景、风格与摄影是否同向，专有词是否已有模型可执行的视觉翻译。
- 承重维度是否达到3级主导而不只是出现；第一眼是否至少由两种独立机制共同抬高，第二眼、第三眼与竞争元素是否明确退让。
- 正式首稿是否先形成高密度母稿；压缩是否只删除低价值、重复与可补全信息，没有把承重焦点、动态力量链、声画因果或结果停点压掉。
- 实际图片是否经过身份、结构、材质、用途和下游可用性验收；未生成时是否仍标为占位。
- 正式图片是否已经打开真实文件并完成像素验收单；目标语义、真实像素语义、目标语言、第一视觉重点、手机可读性和文件身份是否一致。
- 正式观众画面是否没有生产编号、英文临时占位、乱码、样本原字或模型伪字；草图是否保持隔离且没有下发视频。
- 下游是否知道该继承什么、该重新设计什么，不需要重新猜。
- 底线是否只负责稳定、闭合和可调用；成品图或承重资产是否另行通过巅峰门，证明主视觉、人物化设计、空间记忆或产品证据已经达到本任务当前最强候选。
- 是否比较过真正不同的设计方向；胜出方案是否因作品关系和观众结果取胜，而不是因为信息更多、特效更满或规则打勾更多。
