# 视觉资产核心

## 能力定位

把剧本、分场、单镜头或世界观设定拆成后续图片生成、视频生成、封面发布和剪辑需要的视觉资产。

这个 skill 合并原先的风格导演、图片资产提示词、图片生成交接和图片验收。它既负责判断“为了让作品能连续生成、能测试、能发布，需要准备哪些视觉资产”，也负责在没有现成参考时完成这些资产的美术定位与原创设计。稳定不是给普通设计兜底；资产本体必须先符合题材、受众、情绪和传播承诺，再被做成可复用参考。最终封面策略、标题视觉焦点、图文排版和带字图片提示词交给 `laohu-cover-design`。

本 skill 的“创建资产”只指创建文本资产定义、图片资产提示词、编号、用途、验收标准和下游占位符，不直接生成图片文件。即使资产是后续视频生成的必需输入，也只能交付可复制的提示词和执行说明，等待老胡自行生成并回传；回传前不得写“已创建图片”“已生成资产”或虚构本地素材路径。文字分镜同理，不得擅自生成分镜图或故事板图片。

## 资产请求判断门

用户说“生成资产 / 创建资产 / 做人物资产、场景资产、道具资产、服装资产或风格资产”时，默认进入资产包流程；不能把这句话简化成“生成一张好看的图片”。本 skill 先判断结果类型，再决定图片形态：

```text
可复用资产：需要跨镜头、跨场次、跨作品保持身份、结构、空间、材质、色彩、关系或状态的生产基准。
单张成品图：只服务当前一次观看或发布，例如海报、封面、氛围图、成品人像、首帧或故事板。
临时参考图：只服务当前镜头或当前测试，不承担长期一致性；必须在文件中标为“单镜头参考图”或“临时参考图”，不能混入正式资产表。
```

### 资产最小化门

建立图片资产前先做资产预算，不按剧本名词逐项建图。对象满足以下任一条件才进入正式资产表：跨两个及以上有独立生成风险的镜头 / 场次反复出现；承担人物身份、身体阶段或固定空间连续性；是关键剧情锚点；或轮廓、结构、材质、文字一旦漂移就会直接破坏观看。只在同一段连续动作中重复、只出现一次、只是背景填充、正文能够稳定写清或不值得观众注意的对象，直接进入视频提示词。

人物素体和持续身体阶段按身份与结构需要建立；服装、发型、妆容、口罩、床单、病床和普通生活物件不自动资产化。服装 / 妆造只有在跨独立片段仍需锁定、承担人物识别或本身是视觉重点时才建立；如果只需要锁一套最终外观，可以合并成一张最终造型资产，不强制拆成W服装资产和M妆造资产。连续镜头拆成多个生成片段，不单独构成高复用证据；优先使用尾帧交接和视频正文描述。

每个候选资产登记前写清：`复用位置 / 叙事职责 / 失真代价 / 正文是否可稳定描述 / 不建图时的替代写法`。若只能回答“它在镜头里出现过”，就不建资产。正式资产数量以最低可行集合为准，删掉一个资产后若身份、空间、剧情锚点和跨镜连续性仍能稳定成立，就删掉它。

### 资产包最小合同

判定为可复用资产后，交付物至少包含：

1. 资产编号、名称、类型和服务范围。
2. 资产用途、上游依赖、生成顺序和当前阻塞项。
3. 必须固定的身份 / 结构 / 材质 / 空间 / 关系 / 状态。
4. 允许变化项、禁止继承项和与其他资产的引用职责。
5. 可复制图片提示词，以及该提示词要生成的具体资产形态。
6. 验收标准、登记条件和下游调用句。

图片提示词只是资产包的一部分。资产图片生成并验收之前，不能把资产写成“已生成”；一张漂亮的环境图、人物海报或产品广告图即使质量很高，也不能自动替代设计资产、四机位场景板、多角度道具板、人物身份校准或组合关系资产。资产表必须登记“这张图固定什么、不能固定什么、后续谁引用它”，否则只能归类为单张图片或临时参考。

### 结果类型路由

先按用户动词和用途路由，不按“图片”二字猜测：

| 用户意图 | 正确交付 | 禁止误交付 |
|---|---|---|
| 生成人物资产 | 先建立人物素体；按复用与失真风险可选补身体阶段、最终造型或服装拆解 | 默认强制生成B/W/M三件套，或只有一张漂亮人物海报 |
| 生成场景资产 | 先分有边界空间与宏大环境；按需同编号交付场景形象资产和设计资产，锁总拓扑、主视角、路线、尺度、固定锚点、构件材质、光源与可拍摄区域 | 只有一张漂亮空镜，或让城市 / 巨构机械套室内四机位 |
| 生成道具 / 产品资产 | 物品形象资产；跨角度、操作或特写时同编号补物品设计资产 | 只有一张产品广告图 |
| 生成人物服装资产 | 仅当服装跨独立片段复用、结构重要或需要独立给多人复用时，拆解头部穿戴、上半身、下半身、足部及材质结构；否则写进最终造型或视频提示词 | 每套普通衣服都拆一张，或把发型、脸妆混入不必要的服装拆解板 |
| 生成风格资产 | 色彩、材质、成像基底、光影和适用边界的文本规则，必要时补色卡图片 | 一张风格海报或抽象氛围图 |
| 生成封面 / 海报 / 首帧 / 氛围图 | 单张图片提示词，按该图片的发布或镜头用途设计 | 把单张图登记成长期资产 |

如果用户只说“做一张图”但没有说明是资产还是成品，内部先根据后续是否需要复用、一致性和引用判断；不会改变成本、范围或输出数量时，默认按最低风险的单张图片处理，并在结果中标明“非稳定资产”。只有确认需要跨镜头或跨作品复用时，才升级为资产包。人物素体、身体阶段、服装、妆造和最终造型按需选取，不默认分别编号；同一人物新增造型时先复用原素体，只有造型本身值得反复锁定才新增图片资产。

### 资产与漂亮图片的质量分界

资产验收问的是“能不能稳定复用”，不是“这一张看起来是否惊艳”。每次交付前必须回答：

- 这张图 / 这组图固定了哪个唯一对象或空间，是否混入了不该固定的剧情瞬间？
- 下游模型拿它做参考时，能否从不同角度、不同景别或不同动作继续识别同一对象？
- 上游引用是否已经真实生成并验收，还是只有文本占位符？
- 资产表是否写清固定项、允许变化项、禁止继承项和下游调用方式？
- 如果删掉“好看、高级、电影感、氛围感”等形容词，资产的身份、结构和用途是否仍然成立？

任何一个答案是否定，先把结果降级为“单张图片 / 临时参考图”，或者补齐资产包，不得用审美质量掩盖资产职责缺失。

画幅采用参数与正文分离：内部在用户未指定时按 `16:9` 做构图预算，实际比例交给生成平台设置；可复制图片提示词只写主体位置、相对占比、留白、视线、分区职责和裁切安全，不写比例数字、横屏、竖屏、横版或竖版。用户明确指定其他比例时，要重新设计构图关系，不能只换数字。只有用户要求正文携带比例或平台没有独立比例设置时例外。

用于测评、教程和公开发布的商业视觉资产默认全部原创虚构。品牌名、产品包装、车标、店招、服装标识和界面文字只从 `老胡 / laohu / 老胡用AI赚钱` 发展，产品按 `老胡 + 中文品类` 或 `laohu + 英文品类` 命名。老胡已有固定 `laohu` Logo 图片，需要 Logo 时只调用 `【Logo参考@老胡Logo】`，不建立 Logo 设计资产或 Logo 生成提示词，不描摹、重画、重着色、材质化、改字形或改比例；资产提示词只设计产品、包装和版式，并写清现有 Logo 的载体与位置。既不能套用真实品牌的标识和标志性设计，也不能只把真实品牌名替换成“老胡”而保留其完整外形；产品几何、配色关系和文案仍要原创建立。没有合理品牌载体的画面不强加悬浮 Logo。

综合模型测评、公开商业样片或行业测试中的真人模特，先判断是否承担跨镜头身份、固定穿戴、产品操作或局部连续性。具体可识别模特需要稳定身份时建立人物素体形象资产；固定穿搭、最终造型或手脚局部只有在确实反复出现、承担识别或失真代价高时才补充对应资产，不默认生成服装与妆造成套资产。手模、脚模或身体局部承担关键商品交互时，只补实际承重的素体或局部参考，不能让多个模型随机生成不同的身份。匿名背景人群只需群像人物资产，或直接由场景提示词描述。性别不影响测试目标时，单人优先成年女性；多人以女性作为主要视觉和关键动作承担者，再穿插成年男性；题目明确指定性别、家庭身份或人口结构时按测试要求执行。
## 输入

- 完整短片剧本。
- 分场剧本。
- 单镜头剧本。
- 角色或世界观设定。
## 能力加厚纪律

本 skill 生成任何图片资产、封面、首帧、人物形象图、人物设计图、场景图、道具图、色卡图、故事板相关图片提示词前，必须先读取并吸收 `高质量AI图片开发计划.md`。该文档不是背景资料，而是图片提示词的审美与信息密度硬门。输出如果只停留在“治愈、好看、高级、电影感、真实、清新、漂亮、有氛围”这类低密度词，必须退回重写，不能交付给老胡。

高质量图片提示词必须先把目标画面圈准，再写漂亮。上游先执行图片四锚点：

```text
主体明确：第一视觉信息是谁 / 是什么，观众先看哪里，继续看能读到什么身份、动作或材质证据。
场景承托：主体属于什么空间，空间怎样提供尺度、动作条件、引导线、遮挡、反射、留白和故事证据。
时间定光：年代、季节、时刻和事件时间怎样决定自然光、环境状态、服装器物和行为。
风格定情绪：表现介质、类型语言、情绪氛围、参考母体、摄影和后期怎样把事实组织成统一观看方式。
```

四锚点不是四个词槽。必须按 `主体 → 场景 → 时间 → 风格 → 摄影构图 → 光影色彩 → 材质细节 → 情绪结果` 的因果顺序推导。时间的执行链为 `年代 / 季节 / 时刻 → 太阳高度与可用光源 → 方向和色温 → 阴影长度与软硬 → 空气、能见度和表面反射`；人工光源仍需单独说明来源、方向、光质、颜色、落点和反射。

当图片资产的光影、反射、透射、折射、散射、动态光或材质高光承担主要识别 / 美学结果时，必须读取 `02_共享资产库/02_视觉语言资产/画面风格库/画面氛围与画质规范.md` 的“光照事件链与传播路径”。资产提示词按 `光源 → 路径 / 介质 → 光的变化 → 落点材质 → 可见结果` 线性描述；验收时再反向检查结果是否清楚、来源能否解释、路径是否闭合、材质是否匹配、背景是否衬托主体。不能只写“电影光、柔光、丁达尔”，也不能为静态资产误加无职责的动态扫光。

四锚点之后、扩写细节之前，必须做主情绪唯一性判断：先写一句 `情绪命题 = 主体处境 + 主体态度`，再确定观众第一下感受到的主情绪，并列出承重的视觉证据与需要退让的辅助余味。视觉焦点解决看哪里，主情绪解决为什么被这一眼打动。`英姿飒爽` 是人物气质，不足以说明当前时刻；`强敌逼近，她知道危险但一步不退` 才能推导出临敌不退的镇定，以及稳定眼神、压低重心、克制刀势、冷硬主光和收敛背景。不得把孤冷、希望、危险、时尚展示和浪漫氛围以同等权重塞进同一张图。

构图、光影、时间、姿态、场景、色彩、焦段和材质等专业字段不是必填清单。每增加一项都要回答它如何让主情绪更准确或更强：能加强主情绪就保留，不能加强主情绪就省略，削弱主情绪或引出另一种并列感受就否决、替换或降权。禁止为了显得专业、详细或字数充足而填满全部字段。

观众成品图与制作参考资产必须分流。观众成品图、封面、首帧和人物形象图采用情绪优先；人物设计图、服装拆解、道具多角度和场景结构图采用功能优先，以中性展示基准锁身份、结构、比例、材质和空间关系。中性的是背景、机位、姿态和校准光，不是人物选角、产品轮廓、服装造型、材质配色或世界观设计。制作资产不强行加入戏剧姿态、复杂光影和多重情绪，但必须与形象资产属于同一个高质量设计，并避免错误锚点污染下游情绪。

所有列表都按开放属性空间理解。人物、生物、物品、自然、建筑、天气、年代、时刻、介质、类型、氛围、焦段等例子只用于引导 AI 继续发现相关属性，不构成封闭词库。先问“这个维度在当前画面承担什么作用”，再选择会改变身份、空间、物理、情绪、可信度或用途的信息。没有作用的字段不必机械填满；用户未列出但会决定画面的属性必须主动补充。

当用户只给 `女武侠美女`、`治愈系美女`、`做一个好看的画面` 等模糊方向时，不能只为场景、时间和风格抽签。先保留用户不可改变的主体、用途和剧情事实，再内部生成 3-5 个镜头构思候选；每个候选必须写清 `具体事件压力 / 关系状态 → 决定性瞬间 → 人物与道具动作几何 → 摄影机观看位置与透视 → 画内证据 → 光影落点 → 主情绪可见结果`。候选之间至少改变其中一项关键因果，不能只是把青石门换成竹林、把白天换成雨夜、把冷光换成暖光。选择剧情准确、情绪直接、画面骨架有辨识度且可生成的一组，再扩写正式提示词。自动补全不是随机拼词，也不是把多个候选同时塞进正文。

镜头构思和提示词细化必须分开评审。先把画面降到黑白剪影或线稿级关系，检查动作线、主体位置、摄影机高度、倾斜方向、敌我距离和第一视觉是否已经有冲击力；如果骨架普通，不允许靠皮肤、服装、胶片颗粒、雨雾和复杂布光把它包装成“高级”。只有镜头骨架成立后，才补时间、场景、风格、材质、肤色和画质。

正式提示词必须通过抽象词具象化门：

```text
景别：写裁切边界、主体占比、观看角度、焦点落点和可见细节，不只写特写 / 近景。
构图：写主体位置、面积、导引线、框景、前中后景和留白职责，不只写三分法 / 黄金分割。
光影：写光源、方向、光质、颜色、受光部位、阴影和材质反射，不只写电影光 / 丁达尔效应。
情绪：写表情肌肉、眼神、呼吸、手势、重心、人与环境关系和色彩空间证据，不只写孤独 / 治愈 / 危险。
风格：写介质、类型、构图、色彩、光影、空间、材质和后期特征，不只写电影感 / 某某风。
```

例如 `极度悲伤但压抑的人物特写` 应继续展开为：画面裁到额头与锁骨之间，脸占画面约三分之二，3/4 侧脸，焦点落在湿润但未落泪的眼睛；下颌轻微收紧，嘴角保持平直，呼吸停在胸口，手指压住衣领边缘，冷灰窗光只照亮半张脸，另一半保留有纹理的暗部。这里的情绪总结由可见事实托住。

每条可复制图片提示词先落实用途与主体，再从其余开放维度中选择承重项：

```text
用途层：这张图是人物素体形象资产、人物服装资产、人物妆造设计资产、场景资产、道具资产、色彩风格资产、封面、首帧还是临时参考图。
主体层：第一视觉主体是谁 / 是什么，主体占画面多少，观众第一眼看哪里。
构图层：主体落点怎样成立；点、线、面、导引线、留白和边角控制按需要选择。
人物写真摆姿层：人物与镜头、道具或环境建立什么关系；景别机位、身体朝向、头颈、眼神、手部、重心、接触点和服装发丝反应按主情绪选择。
时间层：年代、季节、时刻和事件时间是什么，它们如何改变自然光、天气、服装器物和环境状态。
光影层：由时间和真实光源推导基线；主光、辅光、轮廓、反光、高光和暗部只选择承重关系。
色彩层：色彩承重时选择对象色、肤色、光源色、暗部、饱和度、明度和分级，不固定主辅点缀结构。
透视层：空间承重时选择灭点、近大远小、虚实、色彩透视、前中后景或空气透视；平面化也可以成立。
影调层：高调 / 中间调 / 低调、硬调 / 软调、影调透视、动态范围取舍、纯黑纯白比例和灰度洁净度如何决定张力、写实度和通透感。
后期质感层：胶片颗粒、黑柔 / 白柔、高光光晕、褪色曲线、暗部冷暖和数码锐度控制如何落到具体材质上。
材质层：皮肤、发丝、衣料、首饰、金属、玻璃、木、纸、水汽、雾、胶片颗粒等哪些细节承担真实感。
一致性层：参考图职责、资产编号、造型账本、左右手方向、道具数量、空间结构和允许变化项。
下游层：这张图后续如何服务视频参考、首帧、角色一致性、封面截图、剪辑拼接或风格统一。
```

写提示词时必须让每个词有画面职责。名词确定对象，形容词限定状态，动词确定关系，专业词缩小生成范围。低密度写法是 `清新治愈的女生海边照片，电影感，高级，光影好`；高密度写法先定她为何放松、观众第一眼感到什么，再只写承重关系。例如让栏杆、海面留白和侧逆光共同表现“疲惫后终于允许自己松开”，肤色与妆效则保持这个角色自己的身份基准；冷白柔雾只在角色设定确实如此时使用。

本 skill 对“美”的工作定义：美不是漂亮元素堆叠，而是被选中的主体、构图、光影、色彩、空间、姿态、材质和情绪关系有清楚秩序。写图片提示词前先问观众第一眼看哪里、主要感到什么，再从导引线、主体反差、人物交互、光线塑形、色彩、空间层次、材质和留白中选择承重项。简单特写、平面化构图、单色、无留白或单一自然光都可以成立；真正不能交付的是主情绪不清、关键关系缺失或专业手段互相打架。

高质量图片不是词越多越好，而是承重维度越准确越好。正式可复制正文里禁止把多个大词堆成风格拼盘；先确定风格母体和用途，再从画质介质、色彩影调、构图关系、材质状态中选择能让该风格落地的部分。被选中的维度必须落到具体画面，未承担职责的维度不补齐。

全片或阶段的风格资产不能只交一组 HEX 与泛化气氛词，还要交接三项底层决定：`色彩命题` 说明颜色属于哪些人物 / 道具 / 空间、由什么光源或材料产生、何时移动 / 消退 / 反转；`主成像基底` 只选一种主介质，说明它怎样影响清晰度、动态范围、色彩与运动；`主要不完美来源` 每段按需要只选一种，例如雨湿反射、荧光灯制度脏感、雾玻璃、视频噪声或晒褪织物。它们是开放选择，不是固定套餐，也不能把 35mm、16mm、VHS、监控噪声和现代数字锐度同时堆进一条风格资产。

叙事首帧、场景气氛图和封面参考要建立信息主次：一个主故事线索、一个辅助线索，其余细节可以暗、软、遮挡、失焦、普通或留空。资产设计板本身例外，它的职责是把结构、Logo、材质、颜色和位置校准清楚，不为了电影感故意加入脏污、遮挡或戏剧性失焦；正式画面再根据作品需要调用选择性不完整。视觉资产交接必须明确哪些细节是身份硬锚点，哪些只是当前画面的介质或不完美效果，防止下游把一次性脏感永久焊在资产本体上。

引用知名电影、摄影、绘画或设计作品时，作品名只作为模型认知里的风格母体，不作为最终描述。必须继续拆出当前任务真正调用的构图、色彩、光影、空间、动作气质、材质和成像介质。例如参考《卧虎藏龙》时，可按当前镜头选择竹林纵深、克制青绿、东方留白、轻盈但有受力的动作线和写实武侠摄影；不得默认复制作品人物、剧情或某个标志性镜头。

画面情绪不能只写成 `光影好、构图好、色彩舒服`。透视、纵深、线性节奏、影调、色彩透视和柔化介质都是开放控制杆，不是同一张图的必填层。先确定哪个关系真正让观众感到目标情绪，再把它写成可见结果；例如“疲惫后终于放松”可以由身体重心、呼吸、海面空间和清晨漫射光承重，不必同时补单点透视、黑柔、低饱和和冷白肤色。

人物写真、环境人物成品图、封面、首帧和美女治愈系画面不能只写脸、衣服、肤色和光影，还要建立人物与镜头、道具或环境的关系。景别机位、身体朝向、头颈、眼神、手部任务、重心腿线、环境接触和服装发丝反应都是开放控制杆，只选择能表达角色处境与主情绪的部分。安静证件式凝视可以只靠眼神、肩线和呼吸成立；全身时尚动作可以展开重心、腿线和衣料；持刀女侠则优先刀、手腕、重心和视线。目的不是把每个人都摆成同一种 S 型写真，而是避免“漂亮人物无意义站桩”。

叙事性人物图必须从“摆姿”升级为“表演”。执行公式是 `演员临场感 = 具体事件压力 + 可见生理反应 + 带态度的行为选择 + 对手 / 环境反馈`。这四项是开放判断方向，不是固定字段；实际提示词只保留能闭合本镜因果的证据。静止必须是人物面对压力后主动选择不动，不能只写身体侧立、手持武器、眼神凌厉和气质清冷。景别按承重证据选择：微表情承重时靠近，身体与空间关系承重时拉开，两者同时承重时用近景或中近景，并把前景威胁、关系距离或环境反馈纳入同一构图。

观众成品人像、环境人物成品图、叙事首帧、封面主体和生活方式 B-roll 还要通过 `人物现场感门`：静态画面至少留下一项可推断前一瞬与后一瞬的身体、视线、道具或环境证据；摄影机的位置、距离和遮挡要像事件中的观看者；人物选择要改变环境，环境也要反作用于皮肤、发丝、衣料、呼吸或动作。普通照片升级先锁人物身份、年龄、表情方向、主要姿势 / 动作、服装、道具、事件和场景类型，只开放裁切、观看距离、光线、景深、色彩层级、背景退让和局部材质；改变硬锁即属于重新创作。生命感不等于大笑、伸手、近距离、高饱和或强逆光。需要细化原图升级、前后帧、现场关系、受控不完整、皮肤湿润分区或局部光学效果时，读取 `references/06_人物生命感与现场摄影关系.md`。

人物写真摆姿只适用于时尚展示、定装宣传、妆造展示等本来就需要面对摄影机的任务，并且必须服务角色气质与画面用途，不服务低俗凝视。可以写肩颈线条、背部轮廓、腰线、腿部线条、姿态张力、衣料贴合和裙摆展开，但不要把画面重心放到私密身体部位或过度暴露。叙事镜头不得套用展示型 S 形、回眸、拨发、手搭裙侧等默认写真动作；它必须优先写事件触发、人物反应和有态度的行动。

图片资产、封面、首帧、色彩风格资产和人物成品图也要反模型众数倾向。模型默认会生成同题材最常见的漂亮脸、漂亮滤镜、通用治愈图、通用电影感和平均构图；这些图可能不丑，但没有作品身份。高价值视觉位置不能接受第一版，包括人物第一眼气质、封面主体符号、首帧视觉钩子、色卡母风格、主构图、主物象和风格核心句。内部先给 3-5 个方向不同的候选：不同风格母体、色彩系统、构图落点、信息留白方式、材质锚点或封面符号；再淘汰同题材可替换、网红平均脸、泛写真、泛海报、泛电影感和只靠漂亮词承重的方案。胜出方案必须能回答：这张图为什么只能属于这个角色、这个作品、这个场景或这个发布任务。

本 skill 不只是从剧本里抽名词，而要把剧本翻译成可生成资产体系。每个角色、场景、道具和镜头任务都要先判断它到底是“可复用资产”，还是“单次画面元素”。只有需要跨独立镜头 / 场次复用，或承担身份、空间、关键剧情、高失真结构中的至少一项，才进入资产表；低价值的一次性元素必须由视频提示词闭合。

读取到 `相邻单元交接合同` 时，视觉资产模块必须做 `剧情状态映射`，不能只交一张中性人物图或道具图就宣称连续性已经解决。先把合同中的变化分成三类：`稳定身份 / 结构状态` 由常规人物、场景、道具资产锁定；`持续可见阶段` 如体重阶段、年龄形态、换装、伤势、污渍、损坏、开合、天气和永久破坏，只有在跨镜头反复出现且失真代价足够高时才建立独立图片资产，互斥阶段必须一阶段一资产，否则用视频正文文字锁定；`瞬时表演状态` 如眼泪将落未落、眉心收紧、吞咽、呼吸改变、手指刚松开和人物落地卸力，只进入分镜、首尾帧或视频正文，不创建状态图片资产。每项都写清从哪一单元开始生效、持续到哪里、由什么事件触发改变。

资产不能越权修复错误剧情。若合同里 A 已经把衣服撕裂、道具交给另一人、门彻底撞坏或场景起火，B 的资产调用必须继承该结果；若 A 与 B 对同一状态互相矛盾，先退回编剧 / 分镜修正，不能同时做两套图让视频模型猜。反过来，换机位或换景别只改变屏幕投影时，不要误建一个“新人物 / 新场景资产”。一次性出现、只需一笔带过或没有高识别 / 高失真风险的对象，直接由视频提示词描述，不得为了让资产表完整而单独建图。

视觉资产模块不能只继承剧本名词，还要为观众代入补世界的触感和人物生活痕迹：服装磨损、道具使用痕迹、空间出口、危险距离、材质声响、可触碰表面和光源位置都可以成为下游感官证据。已经明确的身份与世界观必须锁定；未明确的视觉创意由本模块主动选择，并把哪些固定、哪些留给分镜自由发挥写清。资产不能为了稳定把所有表情、动作和光影锁死，导致下游无法根据情绪重新创作。

会参与运动或受力的资产不能只固定外观，还要提供 `动态行为边界`：默认正向与左右朝向、可动关节 / 轮轴 / 门轴、承重点、速度或步态特征、受力后允许怎样变形、与人物的比例、上下左右关系，以及常用进入 / 离开方向。坐骑资产要锁马头与马尾方向、四肢步态、鞍具固定点和骑手下马侧；车辆要锁车头、车尾、轮向与制动方式；建筑或飞船资产要锁主要承力结构和不同材质层。资产只提供稳定物理身份，具体路径、速度与碰撞仍由分镜和视频提示词决定。

资产拆解前先做确定性命名审计。剧本里的观众称呼、生产命名和资产编号可以不同，但必须能映射。不要把“大人”“群仙”“神兽”“女仙”“宫殿”“法器”这类泛称直接搬进资产表当固定资产名。

正确处理：

```text
剧本显示称呼：大人
生产命名：主角
资产命名：A1 主角袖口与玉扳指
资产类型：图片资产，固定 POV 身份锚点
```

```text
群仙 → 不是人物图片资产；可作为群体画面元素，或沉淀为“群仙礼仪规则”提示词资产。
神兽 → 不是固定资产；白鹿、云龙、青鸾这类具体对象才进入资产判定。
女仙 → 如果只献礼一次，是一次性功能人物；若后续反复出现或作为封面主体，才命名并升级为角色资产。
```

命名审计的目的不是给所有元素起名字，而是防止下游独立生成时模型不知道“谁是谁”。只有确定的对象才可以固定；泛称只能作为类别规则、群体描述或单镜头画面元素。

当老胡说“再做一个 / 补一个 / 重新做一个”资产时，先判断这是新增资产、修正已有资产，还是补同类但不同地点 / 不同剧情阶段的资产，不能凭相似名词直接覆盖旧资产。`卧室`、`房间`、`院子`、`桌子`、`车`、`电话` 这类泛称必须绑定服务场次和生产命名后再编辑。例如《不想长大》里 `小安城市卧室` 和 `老家爷爷卧房` 是两个不同场景资产：前者服务开场醒来，后者服务门缝医生、病床输液和爷爷解释长大；用户补“乡下爷爷家的卧室”时应新增 / 调整 `S9 老家爷爷卧房`，不能覆盖 `S3 小安城市卧室`。

资产可以在视频提示词阶段反向补充。前期视觉资产只是第一轮框架，不等于后续禁止新增资产。正式视频提示词写细以后，如果发现某个场景、道具、动线、空间尺度或关键物件已经被多个镜头调用，或者只靠文字仍然容易模糊、错位、现代化、数量错误、方向不清，就要回到视觉资产文件补充对应资产。补充时必须说明资产编号、资产名、服务镜头、固定内容、可复制图片提示词、保存命名和验收标准，并同步更新分镜表和视频提示词引用。当前案例：`S4 放学路 / 村口` 原本只是单镜头参考，但 E1-S9-C1 到 E1-S9-C3 连续使用同一条放学路承载肩带滑落、村民报丧、姐姐跑远和小安抱书包追不上，因此应升级为正式场景四视图资产。

一次性出现的路人角色、单次奇观、单镜头场景、一次性时空裂隙和只服务某个镜头的画面，不默认叫资产。它们应进入镜头画面元素、单镜头参考图、临时生成素材或分镜提示词内容。

短视频开头的危机型转场机制也要先判断是否资产化。手机倒计时界面、固定充电头、系列统一的关机黑屏、固定车辆 / 道路困局、打铁花火花铺屏、棒球撞镜、门板压暗、镜头裂纹等，如果只是单条视频的一次性开头，归为单镜头画面元素或临时参考图；如果会作为账号栏目包装、系列开头、固定转场识别符、反复使用的视觉锚点，就升级为视觉资产或文本资产。资产化时要固定的不只是物体长相，还包括：危机机制、倒计时 / 逼近规则、屏幕铺满材料、切点、色彩风格、声音锚点和正文揭示方式。

视觉资产内部必须区分两种资产：

```text
图片资产：用图片固定具体形象和一致性。
文本资产 / 提示词资产：用文字固定氛围、妆造、环境、风格和世界观视觉规则。
色彩风格资产：用图片色卡 + 文本规则固定全片或阶段的色彩系统。
```

如果对象需要保持同一个脸、同一套服装、同一件道具或同一个空间，优先考虑图片资产。如果对象不需要固定为同一张图，但其风格、妆造、服饰、环境气质或材质规则需要被后续镜头继承，优先做文本资产 / 提示词资产。

提示词资产不是低级资产。基础设定、氛围与画质、人物妆造、服饰体系、场景大类规则、色彩材质、声音气质和世界观视觉规则，都可以成为跨镜头复用的提示词资产。后续生成正式视频提示词时，不能只写“调用提示词资产 A1”，必须把 A1 的具体规则展开到正式提示词正文中。

色卡可以升级为色彩风格资产，但它不是人物服装资产或人物妆造设计资产里的局部色值说明。局部配色只校对这个角色的服装、肤色、首饰和细节；全片色彩风格资产要控制整支作品的色调连续性。建立色彩风格资产时，必须按四组输出：人物组、道具组、场景组、氛围与过渡组。人物组写肤色、发色、妆容、服装不同部位、首饰和可见皮肤高光；道具组写关键道具名称、材质部位和 HEX；场景组写墙面、屋顶、地面、门窗、天空、水面、植被和固定建筑结构；氛围与过渡组写整体光线、雾气、烟雾、空气透视、远近层次、暗部、阴影、高光、转场铺屏和胶片 / LUT 分级。色块建议标十六进制 RGB，例如 `#DDEAF0`，但必须同时写颜色职责、使用比例和禁止偏移方向。

色卡资产不能只输出一张漂亮色条图。资产总表里每个 `C` 系列色卡必须同时提供：

```text
色卡图片提示词：生成四组分区色卡图，人物组 / 道具组 / 场景组 / 氛围与过渡组清楚分栏，每个色块有 HEX 和用途短标签。
文字规则：每个 HEX 落到哪些人物部位、道具部位、场景结构和氛围过渡；哪些颜色只能小面积出现；肤色和发色不能偏向什么色相；暗部和阴影如何保持细节。
视频调用句：请将【@C1 色卡名】作为本段视频的主色彩锚定，所有画面颜色必须严格服从这套色彩系统，不要自动改来换色调，不生成与色卡无关的高饱和颜色。
颜色映射模板：整体光线、主角服装、主角肤色与发色、场景结构、关键道具、氛围与过渡逐项填写 HEX。
```

同一作品默认先做一个全片母色卡，再按剧情情绪派生阶段变体。母色卡负责剪辑统一和世界一致；阶段变体负责情绪推进，例如恋爱前半段清新透亮，分手后半段仍继承同一海天蓝绿，但降低明度、扩大冷灰暗部、让树影和负空间变重。不要每个分镜随机换色卡，也不要所有分镜完全死用同一色卡。资产表里可用 `C` 系列编号，例如 `C1 全片母色卡`、`C1-A 心动期色卡变体`、`C1-B 失落期色卡变体`。

图片资产必须继续判断子类型。任何需要跨镜头稳定的重要人物、动物、卡通角色、拟人主体或其他主角级主体，先建立最低必要的身份资产，再按复用与失真风险选择身体阶段、服装、妆造或最终造型；以下统一用“人物”概括：

```text
人物素体形象资产：固定角色本体的脸 / 头型、五官、年龄或形态阶段、肤色 / 毛色 / 表面基质、身高体重设计值、身体比例、体态和辨识特征。版式为左侧大尺寸头部正面特写，右侧左45度、正面、背面三张完整全身视图，并附人物属性说明区；人类角色穿纯白简单衣裤，使用摄影棚中性灰背景和均匀校准光。
人物服装资产：仅在服装跨独立片段复用、结构需要校准、承担人物识别或需要给多人复用时，固定可拆卸服装和穿戴物。按头部穿戴、上半身、下半身、足部四区展示完整总览，并对版型、衣层、纹样、材质、颜色、接缝、扣合、悬挂、穿戴顺序、活动余量和局部装饰做特写与文字说明；普通一次性衣服直接写入视频提示词。
人物妆造 / 最终造型资产：在同一套发型、妆容和服装结果跨独立片段复用或必须锁定最终外观时使用，可直接引用素体并合并服装结果，不默认要求先建服装资产。它不是把人物放在灰底上做静态合成，而是受控的定妆摄影资产：必须让眉形、睫毛分离度、虹膜眼神光、眼睑色彩、腮红过渡、唇形与唇面高光在真实摄影光下可读，同时让背景明度、色相和景深衬托妆面而不吞掉脸。版式与素体呼应：左侧头部正面特写，右侧左45度、正面、背面三张全身视图；四个视图共用同一套摄影棚背景层次、主光方向、肤色基线和造型，不把复杂叙事场景混进资产。
人物连续性圣经：重要人物跨场次、跨集、换装或由多个模型反复生成时，必须从编剧阶段继承该文本生产资产。它固定不可漂移身份、人格基线、条件化行为签名、关系模式、声音 / 表演基线和弧光账本，但不是第四张人物图片资产。视觉资产只提取其中可见的身份锚点、代表性基准体态和观众第一印象接口；勇敢、善良、强势、危险、可信等人格结论必须留给行为与选择证明，不能写进素体图片正文让模型用刻板脸谱代替人物。
群像人物资产：固定一类背景人群的年龄层、服装年代、体态差异、站位密度、表情范围和群体气质，不锁每个具体人物的三资产链。
场景图片资产：同一个固定空间按需交付场景形象资产和场景设计资产。场景形象资产用单张主视角锁第一眼空间轮廓、尺度体验、主光色、地标关系和世界气质；场景设计资产锁结构 / 总拓扑、入口、路线、固定锚点、光源、可运动与可拍摄区域、构件材质细节。
场景扩展分区设计板：有边界空间使用左上正面 / 左侧 / 右侧 / 反向四机位、右上鸟瞰总平面和底部固定构件细节带；城市、山谷、宫城、工厂、洞窟世界、太空设施等宏大环境改用建立视角、接近路径、门槛揭示、内部人尺度区中的三至四个职责视图 + 总拓扑 / 轴测区 + 细节带，不机械原地旋转四次。两类版式都必须让主视图、总图与细节双向追溯。
物品形象资产：同一件关键商品 / 道具的单张成品图，固定第一眼观感、商业呈现、主视角材质和识别特征。
物品设计资产：同一件物品的扩展分区设计板，上部用三至五个有职责的主结构 / 辅助视图固定正反内外、顶部底部和左右关系，底部细节带固定材质、表面处理、Logo、文字、纹样、接缝、孔位、活动件、接口、接触区和关键功能结构。
色彩风格资产：全片或阶段的分区色卡图 + 文本规则，固定人物组、道具组、场景组、氛围与过渡组的 HEX 色值、使用比例、落点、禁止偏移方向、饱和度、明度、对比度和统一分级。
```

人物属性说明区按对象真实结构选择，不机械套人类三围。成人真人 / 写实角色可按需要记录：角色编号与名称、年龄或形态阶段、性别表达、身高、体重设计值、头身比、肩宽、胸围、腰围、臀围、躯干与腿长比例、臂展、手脚尺寸、惯用侧、基础体态、肤色、眼色、发色 / 发质、辨识特征、永久身体状态与动作限制。儿童、老人、动物、卡通、机甲或非人主体改用真正决定轮廓和动作的参数，例如体长、肩高、四肢比例、尾长、耳角翼尺寸、关节范围或变形边界。仅凭照片无法确认的体重、三围和尺寸必须标为“角色设计值 / 待确认”，不得冒充真实测量。

人物服装资产与道具资产按剧情功能分界：帽冠、簪饰、耳饰、项链、腰佩、盔甲、鞋履等主要承担穿搭识别且持续佩戴时属于服装资产；同一物件会被摘下、拿取、交换、使用、触发机关、揭示信息或推动剧情时，升级为独立道具资产，并由人物妆造设计资产按当前佩戴状态引用。发型、面部妆容、胡须、假发造型、临时纹身 / 身体彩绘、伤妆和疤痕妆属于人物妆造设计资产，不属于人物服装资产。

按需资产链可写成 `人物素体形象资产 → 持续身体阶段 → 可选服装资产 / 最终造型资产`。增加第二套造型时先复用同一素体，只有新造型跨独立片段复用或失真代价高才新增图片资产。服装需要适配头型、肩宽、腰臀或鞋码时，可引用素体的结构职责；最终造型资产可直接引用素体并写入服装结果。参考图职责必须显性写出，不能让人物参考图顺带锁死原图的现代发型、服装、妆容、姿势、背景和光线。

低保真故事板不属于图片资产。它是分镜表之后生成的线框故事板表格图提示词，用来锁构图、景别、机位、主体比例、站位、道具数量、空间锚点、引导线、动线路径、留白区和参考强度。它不调用具体资产图，不复刻角色脸、服装、材质、颜色和最终光影；人物只用火柴人或简化剪影，道具只用几何块，场景只用线框空间和文字标签。若某张图要表现真实人物外观、固定场景材质或道具细节，它就不是低保真故事板，而应回到人物 / 场景 / 道具图片资产或第一帧参考图判断。

故事板是按当前 `VID` 生成的临时分镜参考，不属于稳定人物 / 场景 / 道具资产。它默认只交付一条图片提示词并生成一张多分镜故事板表格图，镜头01到镜头N共同位于这一张图中；每格只承担自己的关键画面、构图、景别 / 机位、运镜、切镜、空间锚点、动作趋势、主体比例和位置。不能把每格拆成独立图片并分别编号为多个故事板资产。若老胡明确要求视频直接引用故事板，整张板使用一个稳定编号，例如 `SB02`；只有明确要求独立关键帧参考图时才输出多张图片，并改用“关键帧参考图”命名。

关键商品 / 道具若既承担主视觉，又会跨角度、被人物操作、穿戴、拆装、运动或进入特写，才在同一资产编号下按需交付物品形象提示词和 / 或物品设计提示词。两套图都登记为同一编号，不拆成 A3-1、A3-2。简单一次性道具、没有主视觉任务且正文能够稳定描述的物件不建图片资产；直接把形状、材质、比例和使用方式写入视频提示词。

测评人物资产必须作为被测模型共同输入，而不是只写在资产表里。先共同输入已经人工确认的人物素体；只有测试目标涉及固定穿戴、外观连续或产品操作，才补充服装或最终造型资产。不要为了形式统一给每个测试人物强行补齐B/W/M。人物资产不混入待测商品、产品 Logo 或具体剧情动作，商品与人物在视频提示词中组合。

资产唯一性原则：一个图片资产只能固定一个确定对象。人物素体只固定一个角色本体；人物服装资产只固定一套可穿戴系统；人物妆造设计资产只固定同一角色穿同一套服装后的一个最终造型；物品资产只固定一件道具或一组同类状态明确的同一物；场景资产只固定一个空间。不要把一个镜头里的场景、桌子、碗、汤圆、硬币、人物手部和动作同时写进同一个资产。这样的图已经是分镜图、首帧图或视频提示词参考，不是可复用资产。多个元素都需要稳定时，拆成多个单一资产，再在分镜、视频提示词或第一帧参考图里组合调用。

互斥可见状态必须拆资产。凡是一个物件在剧情中存在“外部完整状态”和“内部揭露状态”，或“可见阶段”和“隐藏阶段”，不要把两个状态写成同一张资产图的共同特征。否则模型会把互斥状态混合在最终画面里。错误写法：`P4 元宵硬币汤圆` 同时展示完整白汤圆、剖面黑芝麻馅、硬币贴近汤圆皮。正确写法：`P4 元宵完整白汤圆` 只固定连续白糯米皮和完整圆形外观；`P10 元宵小面值硬币` 单独固定硬币，只有包入前、吃出后或爷爷递出时组合调用。

所有图片资产、封面、首帧和生图提示词的可复制正文都必须遵守“出现什么描述什么”。模型只看输入文本本身；如果在硬币资产代码块里写“汤圆”，即使前面有“不出现”或“禁止”，也会把汤圆变成候选视觉元素。正确做法：代码块里只写当前目标画面的主体、形状、材质、比例、纹理、光线、背景和清晰度；混用风险、剧情上下文和不该出现的对象写在代码块外的 `不能继承`、验收标准或失败经验里。当前案例：硬币资产代码块只写硬币尺寸、边缘、磨损、清洁度、金属反光、背景和光线；完整白汤圆资产代码块只写白糯米皮、完整圆形、水光和手搓纹理。

资产类型不能只按剧本里出现的名词判断，要先判断“失真来源”。如果生成问题来自年代环境、店铺类型、货架陈列、空间尺度、灯光、地砖、墙面、入口、公共设施或场景空间语法，应优先做场景资产；如果问题来自某个物品本体的轮廓、材质、尺寸、结构、磨损、开启方式或特写细节，才做道具 / 物品资产。比如“商场拒买玩具”这场戏里，真正需要固定的是 90 年代末到 2000 年代初普通商场玩具货架区、荧光灯、浅色地砖、货架和包装陈列，因此应做 `S7 商场玩具货架区` 场景资产，而不是把问题误判成 `玩具车` 道具资产。场景资产只固定空间和陈列规则，人物手部、父亲牵走、孩子撒赖和剧情动作写入分镜或视频提示词。

人物图片资产按需分为以下正式类型。艺术照、环境人像、封面角色图和叙事首帧仍可创作，但属于成品图或临时参考，不替代已选择的生产资产：

1. `人物素体形象资产` 固定角色本体。左侧为大尺寸头部正面特写，锁脸 / 头型、五官、肤色或表面基质和永久辨识点；右侧依次为左45度、正面、背面三张完整全身图，锁身高、体重设计值、头身比、肩宽、胸腰臀、腿身比、臂展、手脚尺寸、惯用侧、体态与动作限制。人类使用纯白简单衣裤、中性灰摄影棚和均匀校准光，不加入戏服、首饰、浓妆、剧情表情和场景气氛。仅凭照片无法确认的数据标为“角色设计值 / 待确认”。动物、卡通、机甲和非人主体改用体长、肩高、四肢、尾耳角翼、关节范围或变形边界等真正承重参数。
2. `人物服装资产` 可选，固定不承担剧情操作的可拆卸穿戴系统。只有服装跨独立片段复用、结构重要或需要独立给多人复用时，按头部穿戴、上半身、下半身、足部四区给总览和局部特写；普通一次性衣服直接写入视频提示词。发型、面部妆容、胡须造型、伤妆、临时纹身和身体彩绘不进入服装资产。持续佩戴的簪、耳饰、腰佩和面具可归服装；会被摘取、交换、使用、触发机关或揭示信息的同一物件升级为独立道具资产。
3. `人物妆造 / 最终造型资产` 可选，固定跨独立片段复用的最终上身结果。它可直接引用素体并合并服装结果，再加入发型、眉眼唇腮妆容、胡须 / 假发、临时纹身 / 身体彩绘、伤妆、疤痕妆、义体表面和其他最终可见造型。版式与素体一致：左侧头部正面特写，右侧左45度、正面、背面三张完整全身图；只补简短造型说明，不重复整套身体属性。

人物资产按需生成。服装资产可以引用素体的头型、肩宽、腰臀、鞋码等结构职责做适配，但不能把随机模特的脸写入服装设计；最终造型资产可以直接引用素体并包含服装结果。增加第二套造型时复用同一素体，只在该造型确实值得跨片段锁定时新增图片资产。

人物穿搭仍要服务角色、场景、动作和观众反应，但审美判断必须落在正确层：服装资产负责版型、材料、颜色、穿法和活动机制；妆造设计资产负责服装如何贴合该角色的肩颈、胸腰、腿部比例，以及发型、妆容与最终轮廓如何共同成立。不能用 `好看的裙子、精致首饰、漂亮穿搭` 承重，必须写出可见结构和身体适配结果。

已建立的人物造型资产共用一份造型账本和细节来源映射。素体中的永久特征不能在最终造型板漂移；若同时建立服装资产，服装资产每个局部必须能回到四区总览，最终造型中的穿戴物必须与它一致；若未建立服装资产，则由最终造型或视频正文承担服装说明。人物自己的左45度必须按人物朝向标注，不按画面左右误判。

POV、背影、遮挡、低视线、只露手或袖口都是视频阶段的观看策略，不是强制新增资产的理由。主角级 POV先保证身份锚点足够稳定；若手、脚、义肢或身体局部承担跨镜头身份识别、商品操作或关键动作，可另加小面积局部补充参考，否则由视频正文描述。

人物声音属于音频资产或角色声音设定，不强制写进人物图片板。存在指定音色时另建 `【音色参考@V1】`；视频提示词在本镜正文描述哭腔、喊叫、压低、电话失真等声音状态，不用视觉图片承担音色一致性。

人物、服装、物品和场景设计板在写分区正文前，必须先执行一次 `细节反推总览`：

1. 列出准备进入局部细节区的每一项内容，包括 Logo、文字、纹样、配饰、材质节点、接缝、孔位、活动件、接口、固定构件和磨损。
2. 为每项指定唯一来源：它在上方哪个主视图 / 三视图 / 四机位 / 鸟瞰中出现，属于对象哪个部位或场景哪个坐标，朝向哪里，数量多少，基准状态是什么。
3. 回写总览视图，让该细节的载体、宏观位置、方向、数量和颜色块在完整对象上先成立。总览不要求看清微小字形和纹理，但必须让人知道细节安装在哪里、属于哪一面。
4. 再写局部模块。局部只提高观察尺度，补充字形、印刷、纹理、层级、装配、材质和磨损，不新增总览中不存在的设计。
5. 完稿后双向追溯：从每个细节向上找到唯一来源，再从每个承重识别点向下找到对应放大模块。无法追溯时先改总览视角、位置描述或资产状态，不让模型猜。

错误写法：上方鞋子后跟只有一条无字红色提环，底部突然出现写有“老胡”的红色提环特写。正确写法：上方后跟正视图先明确红色提环位于跟腱开口上方、正面带有小号“老胡”文字；底部再放大同一提环，展示织纹、印刷和根部加固。该判断同样适用于人物耳饰、衣服刺绣、产品 Logo、场景标识、门窗节点和机械接口。

已选择的人物图片资产必须使用不同且稳定的资产编号，并在依赖表中显性记录关系。推荐按职责前缀登记：

```text
B01：人物素体形象资产。
W01：可选的人物服装资产。
M01：可选的人物妆造 / 最终造型资产，可直接引用B01并包含服装结果。
```

编号前缀可以服从现有作品规范，但名称和职责不能缩写成模糊的“人物资产 A1”。助手不负责实际图片合成，但要负责规划、命名、提示词、生成顺序和引用关系；只有老胡实际生成并确认后，才把对应图片登记为可调用资产。

如果剧本信息不够，要补“暂定视觉假设”和“必须回问或待定字段”；如果资产过多，要先选首轮验证最小资产，而不是一次铺满全片。

首轮验证最小资产规则：

```text
短片 / 首测 / 单条视频验证 → 只保留会跨镜头复用、会影响一致性或会作为封面 / 第一帧的资产。
一次性人物 → 降级为画面元素或单镜头参考图。
一次性奇观 → 降级为画面元素、氛围参考或文本资产的一部分。
反复继承的风格、服饰、建筑、材质、色彩、礼仪 → 优先做文本资产 / 提示词资产。
```

风格、资产图片提示词、生成交接和图片验收归在本 skill 内处理；本 skill 只准备封面实际需要调用的人物、场景、道具、Logo、色卡和干净截图参考。

视觉资产、资产图片提示词、封面资产交接和图片验收结论都必须写入文件。对话里只给文件链接、当前阶段摘要和是否确认进入下一阶段。除非老胡明确要求粘贴全文，不要在聊天中直接输出长提示词集合。

多资产作品默认输出 `视觉资产总表`，不要只输出单一人物资产文件。只要同一作品里同时存在人物、场景、道具、色卡 / 色彩风格资产中的两类以上，文件名和标题必须体现“资产总表”，并在同一文件里集中放置所有资产账本、下游调用建议和 `可复制图片提示词：` 代码块。色卡不能只写文本规则，必须作为 `C` 系列色彩风格资产提供可复制色卡图片提示词；场景不能被人物资产挤掉，必须按 `S` 系列先判断有边界空间或宏大环境，再提供对应的场景设计资产提示词，必要时补场景形象资产。这样下游视频提示词才能一次性读取 A / S / P / C 资产，不需要在多个资产文件之间找引用。

资产图片提示词、封面资产交接和图片验收文件默认在同一个阶段文件上迭代，不自动新建 v1/v2/v3。只有老胡明确要求新增版本、另存一版或 A/B 两版时，才创建新版本文件。

图片提示词交付必须方便老胡直接复制。每个资产可以在代码块外写用途、服务场次、必须锁定、允许变化、不能继承、是否可作为视频参考图；但真正要复制到图片模型里的正文必须单独放进 `text` 代码块，并使用标题 `可复制图片提示词：`。代码块里只放模型投喂内容，先正向描述要出现的画面结果；边界优先写成 `质量边界`，只描述抽象质量要求，例如画面干净、比例自然、身份清楚、材质真实、无文字水印。不要把当前画面不该出现的具体对象写进代码块当排除项，也不要把用途说明、资产编号解释、生成执行单、命名规则、回传字段、验收标准等放进代码块。

凡是图片提示词、资产提示词、封面提示词、故事板提示词或生成执行单里需要老胡手动上传、替换、绑定、参考或调用的外部内容，都用中文全角中括号 `【】` 显性标注。稳定资产写 `【@资产名】`，人物分别写 `【素体参考@B01 人物素体形象资产】`、`【服装参考@W01 人物服装资产】`、`【妆造参考@M01 人物妆造设计资产】`，人物音色写 `【音色参考@V1 角色音频参考】`，临时参考图写 `【参考图1：用途】`、`【参考图2：用途】`。不要裸写 `参考图 1`、`参考图片 2`、`见上图`、`使用图片一`；正确写法是 `【参考图1：女主肖像】用于固定脸、年龄感、体态和真实自然感；【参考图2：服装穿搭】用于固定版型、层次、颜色、材质和配饰方向`。这能让老胡复制前快速找到所有需要上传的参考项，也能避免参考关系被模型当成普通说明弱化。

图片模型代码块里的引号只保留给画面里真实需要出现的文字，不用来做强调、解释、概念命名或歧义消除。因为生图模型容易把引号里的内容当成画面文字画出来，导致资产图出现多余标注。正确写法是 `标签文字为：左手、右手`、`标题文字为：音色说明`、`正文文字为：儿童清亮偏细，重庆口音，语速快，情绪外露`；不要写 `标注“人物自己的左手”`、`标题为“音色说明”`、`所谓“高级感”` 这类强调式引号。需要解释标签为什么这样写，放在代码块外的人类说明里。

### 商业资产的卖点证明责任

商业作品中，资产不只要好看和稳定，还要能让后续镜头证明卖点。拆产品、人物和场景前，读取商业简报中的 `核心承诺、支撑卖点、使用场景和相信证据`，建立卖点到资产的映射：

```text
卖点 → 承担它的真实结构 / 材料 / 服务触点
→ 哪个角度、动作、接触或环境能让它可见
→ 形象资产如何制造欲望
→ 设计 / 多视图资产如何锁定证据
→ 人物的身份、体态和使用方式如何增加可信度
→ 场景的路面、光线、尺度、水、风、尘、反射或声场如何提供测试条件
```

例如跑鞋要证明湿地抓地，鞋底设计资产必须锁定可追踪的抓地分区和排水路径，场景资产必须有真实湿润弯道、排水边界和足够运动净空，人物资产必须是能以可信姿态完成转弯的跑者。只把鞋拍成高级静物，或只写“科技感场景”，都没有为卖点提供证据。

- 场景资产表。
- 道具资产表。
- 风格与连续性表。
- 镜头任务表。
- 图片生成任务表。
- 视频生成准备表。
- 2-3 个视觉风格方向和主风格建议。
- 人物素体形象资产、按需的人物服装资产、按需的人物妆造 / 最终造型资产、群像人物资产、场景扩展分区设计板、物品扩展分区设计板、道具、第一帧、参考图、网格图提示词。人物艺术照、环境人像、首帧和封面主体图按成品职责管理，不混入人物基础资产。
- 人物素体形象资产使用左侧头部正面特写 + 右侧左45度 / 正面 / 背面全身 + 属性说明区；人物妆造设计资产使用同样四视图，方便逐项对照身份是否漂移。

- 当用户同时提供“人物参考图 + 服装参考图”时，要把两者分工写清：人物图负责脸、身形、年龄感、体态和基础气质；服装图负责版型、层次、颜色、穿着方式和身份识别元素。不要把它们混写成一条抽象的“角色图”。
- 这类人物提示词建议按服装层级顺序写清，例如“内 / 中 / 外 / 腰 / 下 / 足”或“上衣 / 外搭 / 裤装 / 鞋 / 配饰”，这样模型更容易稳定理解服装结构，而不是只记住一个笼统的风格词。
- 人物素体形象资产与人物妆造设计资产默认只使用中性校准表情，不做大笑、哭泣、惊讶、崩溃等多格情绪表情；复杂表演留给分镜和视频提示词，逐镜头写眼神焦点、眼睑、眉心、嘴角、下颌、呼吸、吞咽、手部和身体停顿。
- 图片生成执行单和小批量测试计划。
- 图片候选 A/B/C/D 验收、命名归档和回流建议。
- 封面所需人物、产品、场景、道具、Logo、色卡和视频截图参考的准备与职责说明。
- 资产优先级和生成顺序建议。

不直接产出：

- 视频最终提示词：交给 `laohu-video-prompt`。
- 生成后整体复盘：交给 `laohu-generation-review`。
## 拆解协议

### 1. 先判断作品资产需求

```text
作品体量：
是否多镜头：
是否多角色：
是否需要角色连续出镜：
是否需要固定场景：
是否有关键道具：
是否需要封面：
后期是否拼接：
```

识别需要建立的资产后，先完成内部 `资产审美定位卡`，再写任何图片提示词。它是思考过程，不要求机械完整抄进正式资产总表；正式交付只保留会影响生成、选图和下游继承的结论。

```text
作品类型与媒介：这是高端 TVC、可爱 IP、治愈短片、写实武侠、东方玄幻、科幻工业、生活纪录还是其他具体类型；真人、动画、摄影、概念设计或混合介质分别承担什么。
目标受众与观看情境：谁会看、在什么平台和尺寸看、他们希望靠近什么、相信什么、购买什么或记住什么。
资产职责：它要承担选角、商品欲望、角色身份、世界观入口、空间沉浸、动作功能、封面传播还是跨镜头稳定。
审美命题：观众第一眼应该产生什么明确感受或欲望；这个感受如何兑现作品承诺。
设计语法：形状语言、轮廓比例、CMF（颜色 / 材料 / 表面处理）、服装妆造、空间结构、光色与时代地域语法怎样同向。
视觉记忆点：远看可识别的轮廓、近看可记住的细节或只能属于本作品的关系是什么。
类型俗套否决：同类最常见的默认脸、默认配色、默认材质、默认布景和默认滤镜是什么；本案为什么不能直接采用。
形象 / 设计双证据：形象图怎样证明它值得被看、被喜欢或被购买；多视图怎样证明它换角度、去掉氛围包装后仍然成立。
下游继承：哪些设计事实必须进入视频、封面和剪辑，哪些摄影氛围只属于形象图，不能错误锁死。
```

没有参考图时，内部至少竞争 3 个真正不同的原创方向，差异必须落在受众承诺、轮廓比例、材质、配色、选角、空间或记忆点上，不能只是更换滤镜。选择最符合题材、最能抬高成片上限且可稳定生成的一案。参考图存在时，先拆 `硬锚点 / 可重新设计项 / 禁止继承项`；参考图质量不高或与目标冲突时，只继承必要事实，不继承普通审美。

### 资产依赖图与组合生成

完成资产判定后、写任何图片提示词前，必须把会发生佩戴、持有、摆放、容纳、同框、同一光色或状态继承的资产画成有向无环依赖图。不要把人物、道具、场景、风格当作四套孤立清单，也不要把所有东西提前塞进一张混合资产。

默认层级：

```text
L0 全局锚点：C 色彩风格、固定 Logo、世界材质与主成像基底。
L1 独立锚点：人物身份 / 素体、服装与穿戴物、关键道具、空置基础场景。
L2 组合资产：人物定装与佩戴状态、已布置场景、人物与坐骑 / 产品 / 车辆的稳定组合。
L3 镜头状态：故事板、首帧、尾帧、关键帧，负责具体站位、构图、动作起点和瞬时状态。
```

根据实际风险裁剪层级。单场不换装人物可以把人物身份和主场定装放在同一编号的两套提示词里，但人物设计图必须引用已确认形象图，穿戴物已经单独资产化时还必须引用对应 P 资产；固定场景中的电脑、店招、设备、家具或产品已经资产化时，场景状态图必须显式引用，不能再靠相似文字重画一次。

### 资产总表必须按拓扑顺序交付

依赖图不是只放在文件前面的说明图。完成依赖判断后，先把全部待生成图片资产做拓扑排序，再按该顺序输出资产总览、每一条可复制图片提示词和生成执行单。执行者应当能够从第一条提示词开始一直向下生成，不需要先读到 A1，才发现 A1 引用了写在几十行之后的 P3、S1 或 C1。

排序检查按依赖边逐条执行：`上游提示词位置 < 下游提示词位置`。人物形象和人物设计共用一个 A 编号时，形象提示词先出现，引用形象图的设计提示词紧随其后或位于所有自身上游之后；组合人物、已布置场景、关系图、故事板和首尾帧继续排在其全部组成资产之后。外部已确认参考图可以作为队列起点，但要明确标注为外部输入。若存在互相引用，说明依赖图有环，必须拆成身份锚点、物品 / 场景锚点和组合资产，禁止只改标题顺序。

为每条依赖建立下面的执行账本：

```text
下游资产：
上游参考：
引用强度：硬参考 / 风格参考 / 情境或尺度参考
上游只负责：身份 / 结构 / 比例 / CMF / Logo / 空间 / 光色 / 佩戴 / 接触关系中的具体项
禁止继承：背景 / 临时表情 / 一次性动作 / 非目标服装 / 构图 / 污损 / 其他对象
生成前置门：上游图片是否已由老胡生成并确认
变更传播：上游变化后哪些下游必须重验
```

提示词的第一句直接声明引用职责，例如：

```text
【素体参考@B01 林楠人物素体形象资产】只固定脸、年龄、体型与基础体态；【服装参考@W01 林楠人物服装资产】只固定服装与持续穿戴物；【妆造参考@M01 林楠人物妆造设计资产】只固定最终发型、妆容与穿着结果；【物品参考@P5 单耳耳麦】只固定左耳佩戴方向、结构、颜色和线材；【场景参考@S1 家庭餐客厅】只固定空间、人物站位尺度与真实光源；【色彩参考@C1 色彩风格资产】只固定全片色彩关系与数字电影基底。不继承参考图中的临时表情、一次性动作和无关陈设。
```

只有已经真实生成并验收的上游图片才能作为硬参考。资产表中的占位符可以提前写好，但执行单必须把未确认下游标记为阻塞；不得在上游未生成时声称已经完成引用。上游发生换图、换色、改尺寸、改结构、改 Logo 或改空间后，沿依赖图重验所有受影响组合资产。

禁止循环硬引用。人物与穿戴物互相依赖时，先固定人物身份或用中性人台固定穿戴物，再建立人物组合资产；人物与场景都需要彼此时，先分别确认，再建立 L2/L3 组合结果。循环说明职责没有拆清，不能用更多提示词文字掩盖。

### 全画面引用闭合与关系资产

每张资产图在写提示词前都要做一次全画面盘点，不能只看资产标题里的主语。列出模型可能画出的主角、配角、关系人物、服装、穿戴物、手持物、桌面物、Logo / 文字、倒影、屏幕内容、固定家具和背景人物，并为每项选择：

```text
引用闭合：已有确认图片时显式绑定资产，写清它只负责什么，并让文字与图片一致。
文本闭合：当前没有可用图片资产时，从统一规范词账本逐项复现身份、服装、数量、位置、颜色、材质、左右、状态和职责；重复对象标记为当前仅文本锁定。
画面排除：通过单人构图、空场、画外方向、留白或遮挡边界让对象不进入可见画面。
```

重复角色或关键物品没有图片来源时，不能让模型猜。错误示例是 A1 丈夫形象图写“看向妻子”，画面又会带到妻子，却不引用 A2、也不从规范词账本完整写出妻子的砖红主场定装；模型补成白衣妻子后，这张 A1 就会向下游传播错误。正确处理有三种：A2 图片已确认就显式引用 A2；A2 图片尚未生成但妻子需要入画，就逐项复现 A2 的标准身份、砖红#9B493F上衣、暖灰#77716B长裤、发型、左耳 P5、屏幕侧和清晰度；妻子不需要可见时才保持画外。A1/A2 都确认后，再建立 A3 夫妻关系组合资产进一步锁脸和关系。

关系组合资产需要锁定：

```text
全部可识别人物及其身份参考
每个人的固定定装、发型、左右方向和所属物
屏幕左 / 右、站 / 坐、高差、基础距离和视线关系
共同场景、固定陈设、光源和人物与场景的尺度
允许逐镜变化的表情、手势和距离
禁止提前写入的甩卡、落泪、损坏等瞬时状态
```

同一状态必须从 `规范词账本` 复现，不得自由换同义词。人物服装、道具材质、Logo、场景材料和左右方向首次锁定后，记录唯一标准描述；后续可以按景别删掉看不见的次级细节，但颜色、HEX、材质、版型、数量、左右和归属不得变化。参考图片与文字说明不一致时先阻塞并修正，不允许模型在两套冲突信息中自行猜测。

### 观众认知证据资产

资产不是脱离故事的漂亮设定，也不只负责跨镜头一致。读取剧本交接包里的 `观众认知状态`、视角分层和关键节拍后，检查每个承重资产怎样参与叙事：

```text
身份识别：观众靠哪个轮廓、穿着、动作习惯、声音载体或所属物认出它。
叙事证据：它证明人物关系、危险、职业、谎言、代价、产品卖点或世界规则的哪个事实。
注意力落点：它第一次进入画面时，哪个局部最先被看见；近看与远看分别读到什么。
信息控制：它应该立即说明什么，暂时隐藏什么，何时才允许暴露关键细节。
母题承载：是否有反复出现并随剧情改变意义的颜色、纹样、物件、空间构件或材质状态。
视角适配：主角、对手、客观空间和 POV 位置分别能看到资产的哪些面；不能依赖永远不会进入镜头的设计。
状态变化：破损、污染、消耗、开启、变形、归还、失去或重新命名怎样成为观众认知更新的可见证据。
```

不是每项都要创建新资产。一次性信息只写成镜头元素；只有需要跨镜头稳定、反复回收或影响理解的证据才资产化。不得为了让资产表显得完整，把所有母题和小道具升级成图片资产。

资产判定必须先回答：

```text
剧本显示称呼：
生产命名：
是否只是抽象泛称：
如果是泛称，是否需要具体化为单一对象：
是否会反复出现：
出现范围：单镜头 / 多镜头 / 多场次 / 多集 / 跨作品
是否需要一致性锁定：
资产类型：图片资产 / 文本资产 / 提示词资产 / 非资产画面元素
图片资产子类型：人物素体 / 人物定装 / 服装妆造 / 组合形象 / 场景多角度 / 物品多角度 / 第一帧
资产编号：
组合关系：例如 A3 = A1 + A2
如果不锁定，会不会影响理解、剪辑或后续生成：
如果只出现一次，是否降级为画面元素或临时参考图：
```

如果角色要跨镜头出现，角色资产优先级高于单镜头画面。如果角色只是一次性路人或功能性角色，不默认做角色资产，只在镜头画面内容里描述。

资产最小化门：建立图片资产前必须同时回答 `复用范围 / 叙事重要性 / 失真代价 / 视频正文能否稳定描述` 四项。默认至少满足“跨两个独立镜头或段落反复出现”或“虽然只出现一次但承担核心身份、关键剧情或极高失真风险”之一；只出现一次、只是背景填充、只需一笔带过或模型能按正文稳定生成的对象，降级为视频画面元素或临时参考图。重复出现但不影响身份、空间、剪辑或理解的低价值物件，也不自动资产化。

高频样例：

```text
迎客仙人只在开头出现一次 → 非角色图片资产；写成角色画面元素或单镜头参考图。
迎客仙人的白金道袍、玉冠、仙风道骨礼仪 → 可作为仙界迎宾人物妆造文本资产。
九界仙宫不是同一个固定宫殿反复进入 → 非场景图片资产；写成仙界建筑 / 云海 / 白玉青玉材质文本资产。
同一座主殿会多次进入并多角度拍摄 → 场景图片资产，做四机位 + 鸟瞰 + 固定构件细节带的扩展分区设计板。
同一个主角跨多个镜头出现且要同一张脸 → 人物图片资产，不可靠纯文字固定。
```

STOP/CHECKPOINT：

```text
资产判定表完成 → 内部按复用、一致性和成本判断保留或降级，并记录理由。
图片资产提示词完成 → 未发生真实生成成本时继续进入分镜；需要老胡实际上传或付费生成时交付明确执行单。
图片候选验收完成 → 按身份稳定、用途和下游代入价值选择胜出图；老胡明确要人工挑选时再停。
封面资产交接完成 → 把可用人物、产品、场景、道具、色卡、Logo 与成片截图的锁定 / 允许变化职责交给 `laohu-cover-design`；本 Skill 不写最终封面提示词。
```

## 判断规则

- 不只列漂亮画面，要列推动故事的画面。
- 不把所有出现过的东西都叫资产；先判断是否复用、是否需要一致性锁定。
- 低保真故事板不是资产，不进入角色 / 场景 / 道具资产表；它只作为分镜参考图提示词，保存到 `04_分镜/文本/`。
- 故事板也不升级为稳定资产；它是按当前 `VID` 或测试路线生成的一张临时多分镜参考图。需要直接投喂时整张板只引用一次，板内镜头格不分别建立外部引用。
- 一次性角色、一次性奇观、单镜头场景优先归为画面元素或临时参考图。
- 图片资产用于固定具体形象；文本资产 / 提示词资产用于固定氛围、妆造、环境、风格和世界观视觉规则。
- 关键资产必须有可识别轮廓、功能逻辑、材质规则、色彩层级和下游调用方式。
- 场景和道具必须能解释入口、尺度、光源、运动路径或使用方式，避免只有气氛没有结构。
- 同一作品的角色、建筑、服饰、法器和神兽要共享世界观设计语法，避免像不同素材库拼贴。
- 角色资产优先稳定：脸、发型、服装、年龄、气质。
- 重要人物是否继承人物连续性圣经，并把不可漂移身份、人格基线、当前状态和弧光变化分开；是否没有把人物圣经或表演状态误做成第四张人物图片资产。
- 人物素体是否只锁可见身份、身体关系、永久锚点与中性基准体态；是否没有用眼型、唇形、肤色、身材或光影直接证明勇敢、善良、强势、危险或可信。
- 是否为重要人物只选择少量高价值识别锚点，并通过正脸、左45度、背面、黑白轮廓、去服装 / 去装饰和跨妆造检查确认仍可识别；是否避免同时堆叠异色瞳、精灵耳、挑染、泪痣、纹身和多件饰品。
- 人物第一印象若服务剧情，是否明确它由哪些可见 / 可听线索建立；预期差若由编剧确认，视觉资产是否只负责建立前置预期，没有擅自把违背与剧情解释画进中性身份板。
- 主角色人物素体形象资产和人物妆造设计资产优先稳定身份与最终造型；持续可见的身体阶段按阶段拆成独立图片，复杂表情、情绪和动作状态由视频提示词负责，不用表情网格或状态图替代表演。
- 场景资产优先统一：空间、光影、色调、时代感。
- 固定场景若需要多角度拍摄，先分有边界空间与宏大环境：前者用四机位 + 鸟瞰 + 细节带，后者用职责视角 + 总拓扑 + 细节带；所有区域必须能互相证明是同一个空间。
- 道具资产必须说明故事功能。
- 镜头任务必须是动作或信息变化，不写“氛围感”。
- 动作镜头不要把构图锁死到无法运动。
- 情绪镜头必须预留近景或特写，并交给表演时间轴处理。
- 多镜头拼接必须写入点、出点、声音和色调连续性。

## 反例黑名单

- 不要把所有名词都列成资产。
- 不要把只出现一次的迎宾人物、守门者、群众、云雾、裂隙、远景奇观做成长期资产。
- 不要只做一张漂亮场景图就称为固定场景资产；固定场景必须能支持多角度和运动路径。
- 不要把图片资产和文本资产混成一栏，导致后续不知道靠图片固定还是靠提示词继承。
- 不要为首轮测试一次性铺满所有角色、场景、道具，先保留最小可验证资产。
- 不要让参考图带偏主体；人物资产背景要简单，场景资产才允许背景成为主体。
- 不要把没有故事功能的道具升级为关键道具资产。

## 自检

输出前检查：

- 是否已经读取并应用 `高质量AI图片开发计划.md`，而不是只沿用旧模板或凭感觉写图。
- 是否在提示词前完成类型、受众、资产职责、审美命题、设计语法、视觉记忆点、类型俗套和下游继承判断；正式文件是否只保留有执行价值的结论，没有机械输出一张空表。
- 角色所属道具、首饰、武器、设备和铠甲是否先通过角色归属审美、身体工学与造型系统检查，而不是先做通用功能装置再塞给角色。
- 强风格化变身、法术、机甲、奇幻装备或跨形态角色是否先判断并建立必要的色卡 / 风格资产；人物、装备、场景和 VFX 是否属于同一套文化母题、材质和颜色系统。
- 是否把用户用于解释功能或动机的例子误做成画面资产；没有被确认要出现的怪物、敌人、品牌、武器或场景是否已经排除。
- 同一人物存在互斥状态时，是否明确区分身份继承与服装继承；最终状态是否还残留上一状态的裙装、丝袜、鞋履、首饰、武器、损坏或材质；风格板是否错误地把两套状态合并在同一人物上。
- 是否读取相邻单元交接合同并完成剧情状态映射；稳定身份、持续可见阶段和瞬时表演是否由正确参考类型承担；是否把互斥阶段合在一张图，是否把表情做成资产，是否把换机位误建成新资产，或让伤势、损坏、持物、天气和永久结果在 B 中无因复原。
- 无参考图时是否主动竞争 3-5 个原创美术方向并选出最符合作品承诺的一案；有参考图时是否拆清硬锚点、开放项和禁止继承项，没有把参考图的普通审美一起锁死。
- 人物是否先完成正确选角与造型再谈身份稳定；产品 / 道具是否有目标人群、价格感或使用情境、功能逻辑、轮廓比例、CMF 和识别细节；场景是否有类型空间语法与一个可复述的空间记忆锚点。
- 是否把中性背景、正交视角和均匀光误当成中性设计；去掉形象图的氛围、滤镜和戏剧光以后，人物造型、产品轮廓、场景结构和材质配色是否仍然成立。
- 形象资产是否证明第一眼吸引与作品承诺，设计资产是否证明同一设计换角度仍然成立；是否出现形象图漂亮但多视图崩坏，或多视图稳定但本体普通。
- 单个资产即使漂亮，是否与同作品人物、道具、场景共享形状、材质、色彩和时代地域语法；是否存在各自好看却不像同一个世界的问题。
- 是否完成图片四锚点：主体是否明确、场景是否承托、时间是否定光、风格是否定情绪；四项是否形成同一个因果完整的世界，而不是关键词拼盘。
- 是否通过主情绪唯一性检查：情绪命题是否写清主体处境和态度；观众第一情绪是否只有一个；眼神、姿态、动作、构图、光影、色彩和环境证据是否指向它；辅助余味是否主动退让。
- 模糊需求是否先完成 3-5 个镜头构思候选，而不是只生成场景、时间和风格候选；胜出方案是否有清楚的决定性瞬间、动作几何、摄影机位置、画内证据和光影落点。
- 去掉服装纹理、肤色、滤镜、雨雾和画质词后，黑白剪影级镜头骨架是否仍有辨识度和冲击力；如果没有，是否退回镜头构思而不是继续堆细节。
- 叙事性人物图是否通过演员临场感检查：具体事件压力是否已经进入画面；是否有符合人物控制程度的生理反应；人物是否做出带态度的行为选择；对手、道具或环境是否反馈这个选择；静止是否为主动不动，而不是站桩摆拍。
- 观众成品人像是否留下可推断前后帧的状态；摄影机位置是否有事件或关系动机；人物与环境是否互相留下影响；普通照片升级是否锁住人物、表情、动作、服装、道具、事件和场景类型，没有把摄影升级偷换成重新创作。
- 光学效果是否有来源、局部作用区、画面交互和衰减；皮肤、发丝、衣料、金属、玻璃和水是否按干湿状态与材质分区响应，没有用全脸油亮、全图色散或统一逆光冒充生命感。
- 情绪证据与景别是否匹配：承担主情绪的眼神、嘴角、呼吸、手势、身体控制或空间压力是否达到观众可读尺寸；是否因为景别太远丢失微表情，或因为景别太近丢失临敌关系。
- 时间是否写清年代 / 季节 / 时刻中真正必要的层级，并继续推导太阳高度或环境光、方向、色温、阴影、空气和表面反射；人工光源是否另有真实来源。
- 所有示例是否按开放属性空间使用；是否根据当前题材补出了用户没有列出但会改变身份、空间、物理、情绪或用途的属性。
- 是否完成抽象词具象化：特写有没有裁切边界和焦点落点，构图有没有位置和导引关系，光影有没有来源与受光结果，情绪有没有表情、姿态和环境证据。
- 是否先做了美学总判断：第一眼落点、视线导引、主体与环境接触、人物姿态线条、光线塑形、色彩统一、空间层次、材质触感、取舍和留白是否共同服务同一画面目标。
- 图片提示词是否过了有效信息检查：用途和主体必须清楚；观众成品图是否只保留主情绪承重项，制作资产是否只保留身份与一致性必需项；是否删除为了完整而填写的构图、光影、色彩或材质字段。
- 是否存在低密度词独自承重，例如 `好看、高级、治愈、电影感、真实、漂亮、精致、氛围感、清新`；如果有，是否已展开成主体落点、光源方向、色彩分级、材质细节和构图关系。
- 当用户明确参考的是视频直出或未经后期调色的关键帧时，是否通过 `原生直出成像门`：实际光源、曝光层级、皮肤漫反射与局部高光、背景明度 / 冷暖分离、景深和边缘响应是否都能在生成图片本身成立，而不是依赖 LUT、磨皮或后期提亮。
- 需要把人物放进具体治愈场景时，是否区分 `B / 按需W或M` 的通用资产与 `最终造型 + 色卡 + 场景` 生成的成品人像 / 首帧参考；是否没有把一次性背景光、散景和叙事姿态永久焊进人物基础资产。
- 是否给观众眼睛找到了第一视觉落点：主体是否通过面积、亮度、清晰度、颜色、反差、位置或运动成为第一眼。
- 人物写真、人物成品图、封面、首帧和美女治愈系画面是否写清镜头互动层：景别机位、身体朝向、头颈角度、眼神关系、手部任务、重心腿线、环境接触和服装发丝反应是否共同成立；是否避免只写漂亮脸、衣服和光影。
- 导引线和块面是否在承担视觉引导或主情绪；没有承担时是否省略，而不是为了展示构图知识强行加入。
- 被选中的摄影控制杆是否真正加强主情绪；透视、影调、色彩、空气介质或滤镜没有职责时是否不写。
- 是否形成风格交集，而不是风格词堆叠：主风格母体、画质介质、色彩影调、构图关系、材质状态和用途边界是否互相限定。
- 人物第一眼气质、封面主体符号、首帧视觉钩子、色卡母风格、主构图和风格核心句是否经过反众数审美否决；是否避免直接采用第一版漂亮平均脸、泛写真、泛海报、泛电影感或通用治愈图。
- 是否每个资产都服务具体场次或镜头。
- 是否把只出现一次的角色、场景或奇观误列为资产。
- 是否给出资产 / 画面元素 / 临时参考图的分类理由。
- 是否区分图片资产和文本资产 / 提示词资产。
- 是否遵守资产唯一性原则：一个资产只固定一个人物、一个道具、一个场景或一套服装 / 妆造；是否把混合元素拆成多个单一资产，而不是写成分镜图。
- 是否把低保真故事板和图片资产分开：故事板只锁构图、景别、站位、比例、空间锚点、引导线、动线和留白，不锁具体外观、颜色、材质和最终光影。
- 是否先判断失真来源再决定资产类型：年代环境、陈列方式、空间语法和灯光跑偏时做场景资产；物品本体形状、材质和特写跑偏时做道具资产。
- 群众、同学、邻家孩子、亲戚、村民等是否先判断为画面元素、群像人物资产或主角色资产；是否避免把跑龙套群像误拆成多个固定主配角，也避免完全不固定导致时代感和服装气质漂移。
- 是否存在“漂亮但没用”的资产。
- 关键资产远看是否能识别身份、功能和世界观归属。
- 会运动或受力的坐骑、车辆、机器、门窗、建筑与飞船资产是否写清默认朝向、可动结构、承重点、步态 / 轮向 / 开合方式、材料层和动态行为边界，没有只锁漂亮外观。
- 场景资产是否有入口、尺度、光源、运动路径和多角度复用价值。
- 场景资产是否先完成空间分流：有边界空间包含左上正面 / 左侧 / 右侧 / 反向四机位、右上高位鸟瞰 / 斜俯视总平面和底部固定构件材质细节带；宏大环境包含有职责的建立 / 接近 / 门槛揭示 / 内部人尺度视图、总拓扑 / 轴测区和底部细节带；所有区域的空间逻辑、关键结构位置、光源和视角关系是否一致；是否避免把宏大环境硬写成室内四机位、把鸟瞰写成无布局价值的漂亮广角、把可移动道具混进场景细节带。
- 物品扩展分区设计板是否根据下游风险安排三至五个主结构 / 辅助视图，并在底部细节带锁定材质、表面处理、Logo、固定文字、纹样、接缝、孔位、活动件、接口、接触区和功能结构；每项细节是否能回到主视图，是否避免平均四宫格和互斥状态混图。
- 是否建立 `细节来源映射`：每个局部模块能否指出唯一的上方来源视图、宏观位置、朝向、数量和基准状态；上方是否先出现了该 Logo、文字、纹样、配饰、结构或固定构件；局部是否只放大澄清而没有第一次发明设计；是否完成细节向上、总览向下的双向追溯。
- 桌面、案板、操作台、祭祀桌、手工台等核心动作空间，是否先区分“空间资产”和“道具 / 家具资产”；是否避免把空间、道具、人物手部和动作混成一个资产。
- 色彩和材质是否形成统一体系，而不是每个资产各自好看。
- 已选择的人物资产是否共用同一份造型账本：素体永久特征、已建立的服装结构与最终造型结果能否双向追溯，是否出现随机饰品、换鞋、脸型漂移或体型漂移；未建立的服装 / 妆造是否已经由视频提示词明确，而不是被检查项强行补成图片资产。
- 人物素体形象资产是否使用左侧头部正面特写 + 右侧左45度 / 正面 / 背面全身 + 属性说明区，并以纯白简单衣裤、中性灰背景和均匀校准光排除服装与环境干扰。
- 人物服装资产是否把头部穿戴、上半身、下半身、足部的总览、材质、结构、穿法和局部细节写全；是否把发型、脸妆或剧情道具误塞进服装资产。
- 人物妆造设计资产是否同时引用正确素体与服装，并只补最终发型、妆容、伤妆 / 彩绘和上身适配结果，没有重复整套服装拆解或改变角色本体。
- 角色是否有可复用参考图策略。
- POV 主体是否已经建立完整人物资产，包含身高、比例、左手特写、右手特写、服装、鞋、背影和视线高度，而不是只做局部身份锚点。
- 会说话、VO 或画外音的角色是否把指定音色记录为独立 `【音色参考@xx】`，没有把音色说明强塞进人物图片板。
- 场景光影是否能跨镜头统一。
- 道具是否有故事功能。
- 镜头任务是否能生成、能诊断、能剪辑。
- 风格是否已经收敛成一个主方向。
- 风格是否有边界，是否避免为了讨好所有人而被磨平。
- 是否设计了一个服务作品承诺的轻微跑调点，降低选择性忽视风险。
- 图片提示词是否写清用途、锁定、允许变化、不能继承和质量边界。
- 图片提示词是否把可复制投喂正文单独放进代码块，且代码块外没有需要老胡手动拼进去的提示词片段。
- 多资产作品是否输出为 `视觉资产总表`，而不是误命名成单一人物资产文件；人物、场景、道具、色卡 / 色彩风格资产是否都在同一资产总表中有可复制提示词。
- 色卡 / 色彩风格资产是否提供了可复制色卡图片提示词和四组文字规则；是否包含人物组、道具组、场景组、氛围与过渡组；是否提供视频调用句和颜色映射模板，而不是只写一排色块或抽象文字色彩规则。
- 图片模型代码块里是否只在真实画面文字处使用文字指令，是否避免用引号做强调；左手 / 右手、音色说明等标签是否写成标签文字为、标题文字为、正文文字为，而不是把长解释放进画面标签。
- 图片生成是否有小批量执行单。
- 图片验收是否有 A/B/C/D 和回流路径。
- 是否向 `laohu-cover-design` 交接了封面参考的锁定项与允许变化项，而不是越权完成最终封面。
- 是否标出失败风险和生成优先级。
- 是否输出视觉资产交接包，方便图片、风格和视频设定继承。
