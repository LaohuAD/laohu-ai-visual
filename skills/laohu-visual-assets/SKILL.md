# 老胡视觉资产

## 资产箴言

一张图负责惊艳，一套资产负责不走样。

资产不是画面里出现过的名词，也不是一张漂亮图片的别名。它是跨生成请求仍要保持同一个身份、结构、空间、材质、关系或状态的生产基准。

## 输入与责任

本 Skill 读取已确认剧本、场次、镜头任务、人物连续性、当前资产与真实生成结果，回答四个问题：

1. 什么必须保持同一个。
2. 什么只服务当前镜头，不值得资产化。
3. 这些资产怎样先设计、再生成、再组合。
4. 下游怎样引用，才能只继承该继承的部分。

本项目默认只交付资产定义、图片提示词、生成顺序、验收和调用说明，不直接生成图片。只有真实图片已经由老胡生成并确认，才能标为可调用资产。

## 资产关系

### 先判断资产，后决定图片

候选对象先回答：

```text
复用范围：会出现在哪些独立镜头、场次、集数或作品。
叙事职责：它证明身份、关系、卖点、世界规则还是空间方向。
失真代价：走样后观众会不会认错、出戏、误解或无法剪接。
正文替代：只靠当前视频提示词能否稳定说清。
下游调用：哪一个具体环节会怎样引用它。
```

只有“它出现过”，没有失真代价和下游调用，就不建资产。删掉它仍不影响身份、空间、剧情锚点和连续性，就降级为镜头画面元素、单张成品图或临时参考图。

最低可行资产优先于资产齐全。资产越多，生成成本、引用冲突和维护成本越高；少一个会失控才保留，不为目录整齐建立成套图片。

### 三类结果

| 结果 | 用途 | 必要内容 |
|---|---|---|
| 稳定资产 | 跨请求保持身份、结构、空间、材质或关系 | 编号、固定项、可变项、依赖、提示词、验收、下游调用 |
| 单张成品图 | 当前观看或发布，如人像、首帧、海报、氛围图 | 当次画面目标和提示词，不进入稳定资产表 |
| 临时参考图 | 只为一个镜头、构图或测试服务 | 清楚标记使用范围和失效时点 |

资产图片可以很美，但它首先要换角度仍是同一个对象；成品图可以只为这一眼成立。两者的验收不能混用。

### 依赖顺序

资产不能作为人物、道具、场景、风格四张孤立清单。写提示词前建立无环依赖图：

```text
全局锚点：固定 Logo、世界材质、色彩关系、主成像基底。
独立锚点：人物身份、关键物品、空置基础场景。
组合结果：最终造型、穿戴关系、布置后场景、人物与产品 / 坐骑 / 车辆关系。
镜头状态：首帧、尾帧、故事板和具体动作状态。
```

这不是固定四级目录。根据项目风险裁剪，但下游资产必须排在全部上游之后。出现循环引用时拆清职责，不能靠调整排版掩盖。

每条依赖写清：

```text
下游资产：
上游参考：
上游只负责：身份 / 结构 / 材质 / 比例 / 空间 / 色彩 / 佩戴关系中的具体项。
禁止继承：背景、临时表情、一次性动作、无关服装或构图。
生成前置：上游图片是否真实存在并已验收。
变更传播：上游变化后哪些下游必须重验。
```

### 全画面闭合

图片标题写“丈夫资产”，不代表画面里只会出现丈夫。写提示词前盘点所有可能被模型画出的可识别对象：人物、关系人、服装、穿戴物、手持物、Logo、屏幕、倒影、家具和背景人物。

每个对象只选一种处理：

- 已有确认图片：显式引用并限定职责。
- 尚无图片但必须出现：从同一规范词账本复现身份、数量、位置、颜色、材质和状态。
- 本图不需要出现：通过构图、画外方向、遮挡或空场让它不进入画面。

不能写一句关系动作，让模型自由补出一个错误的人，再把错误继续传给下游。

#### 引用也要闭合

全画面引用闭合不只检查“有没有参考图”，还要检查每张参考只控制什么。凡是画面中可识别对象由参考资产承担，必须同时写清：实际绑定文件、身份 / 结构 / 材质 / 比例 / 空间 / 色彩中的职责、禁止继承的背景与瞬时状态、当前剧情时间状态，以及它是否已经真实生成并验收。上游尚未生成、只存在文字定义时，不得在下游提示词里伪装成已绑定图片。

组合画面需要的关系人、穿戴物、手持物、布置结果和倒影，不能因为主体资产已经存在就自动视为闭合。每一个会被模型补画的对象都要么有确认参考，要么有同一规范词账本，要么通过构图明确不出现。

### 状态不能混成身份

稳定身份、持续阶段和瞬时表演分开：

```text
稳定身份：脸、体型、永久结构、固定空间和不随剧情变化的锚点。
持续阶段：会跨多个独立片段保持的服装、伤势、污染、变身或破坏状态。
瞬时表演：眼神、呼吸、动作受力、哭笑、抬手、摔落和本镜光影。
```

持续阶段是否做图片由复用与失真代价决定；瞬时表演交给分镜和视频提示词。互斥状态不画进同一资产，让模型自己融合。

### 故事时间账本与换装判断

人物跨越多日、季节、成长、增减重、治疗、受伤恢复或身份阶段时，先按真实故事时间建立 `故事时间账本`，再按剧本和剪辑顺序调用。剧本先写学校、后插入医院回忆，不代表学校发生在初诊之前；如果不先还原真实时间，身体、服装和伤病会被错误地按文档顺序继承。

账本只登记会改变资产或镜头状态的事实：

```text
故事阶段 / 与上一阶段的时间距离：
年龄、身高与人物阶段状态：
持续身体变化、伤病或污染：
场景功能与季节天气：
当前最终造型与服装尺码：
哪些镜头属于必须连续的同一天 / 同一行动：
允许变化 / 必须不变 / 变化证据：
```

`人物阶段状态` 用于同一身份在多个独立片段中持续存在、且仅靠正文容易漂移的体型、年龄段、康复期、伤病期或形态阶段。它引用同一身份，只固定该阶段的脸部软组织、身体轮廓、比例、体态和运动限制，不固定戏服、最终发型、妆容、剧情表情和场景。它在图片职责上就是阶段素体资产：完整继承B的校准板信息结构，而不是另做一张普通身体三视图。身份资产不锁最终服装，也不把某一阶段体重冒充永久身份。

换装判断只看三项：故事时间是否跨越到合理换衣节点；地点和活动功能是否需要不同穿着；相邻镜头是否属于必须保持的直接连续。跨日、跨季节、学校到家庭或医院复检通常需要重新判断；同一天从诊室走到回家路通常保持同一套。禁止为了资产丰富每场必换，也禁止为了省资产让角色数月一直穿同一件衣服。

时间账本一旦跨季节，季节不能只留在表格里。每个阶段必须把季节证据传给W与M：层数、覆盖面积、面料克重与表面、袖裤长度、鞋袜和穿法至少有三项共同变化。身体阶段只决定版型、尺码和松量；季节阶段决定层数、覆盖和材料性能；人物身份决定设计语言；场景动作决定开合与活动余量。四类原因不得互相替代。室内空调、职业制服或医疗要求允许保留长裤与薄外层，但必须说明其功能，不能让厚卫衣、抓绒或保暖外套无理由跨入盛夏。

## 美术与提示词

### 先选设计，再锁一致

稳定只能保护设计，不能把普通设计变高级。没有参考图时，先围绕当次作品竞争 3—5 个真正不同的方向；差异落在受众承诺、轮廓比例、形状语言、材质、配色、选角、空间语法或视觉记忆点，不只是换滤镜。

选择前建立：

```text
作品类型与观看情境：
目标受众为什么愿意靠近、相信、购买或记住：
资产在故事或商业表达中的职责：
第一眼感受或欲望：
形状、比例、材质、色彩、妆造与空间怎样同向：
一个远看可认、近看可记的视觉记忆点：
同类最常见的平均答案，以及本案为什么不取：
```

这组判断是资产美术指导门。它必须在批量写提示词和锁一致性之前完成：先比较轮廓、比例、形状语言、材质、配色、选角、空间和记忆点怎样共同服务作品承诺，再选定一套方案。只得到“高级、电影感、统一风格”或若干互不冲突的形容词，说明设计尚未成立；此时不能进入资产批量生产。

材料不靠稀奇取胜，也不靠私人专属自动深刻。选材看承载力：它能否说明人物、功能、世界规则或公共经验；换成同类平均材料后，关系和结果是否变弱。宏大环境可以有公共尺度，小物件可以有亲密证据，两者按作品用意选择，不预设大小。

### 图片提示词的因果顺序

观众成品图按 `主体 → 场景 → 时间 → 主情绪 → 摄影位置 → 光色 → 材质 → 可见结果` 推导；制作资产按 `身份 / 结构职责 → 必须看清的视角 → 比例与材质 → 中性展示 → 下游一致性` 推导。

中性展示不等于中性设计。制作板可以使用普通背景和均匀光，但人物选角、产品轮廓、服装造型、材质配色和世界观必须先成立。

抽象词要解压成可见关系：

- “电影感”落到观看位置、构图、光源、色彩、材质和成像介质。
- “治愈、危险、孤独”落到处境、表情、身体、空间和环境证据。
- “特写”落到裁切、主体占比、角度、焦点和可见细节。
- “高级”落到比例、接缝、材料、留白、层级与真实使用情境。

每条可复制提示词单独放入 `text` 代码块。代码块先正向描述要出现的结果；具体不该出现的人、物和剧情风险放在代码块外，避免反向召回。需要手动绑定的内容用 `【……参考@……】` 显性标注，并在同一句写清职责。

### 人物、场景与物品

人物资产按职责建立，不把普通服装当成可以跳过的空白：

- 身份需要跨请求稳定：建立人物素体或身份校准资产。
- 同一身份存在可复用的体型、年龄段、康复、伤病或形态阶段：按需建立人物阶段状态资产，仍由同一身份上游控制，并使用完整阶段素体板。
- 只要角色的最终穿着会进入人物资产、故事板或视频，所有最终服装先建立W；普通、朴素和一次性服装也不能直接跳进M或视频正文。只有没有被资产化的一次性背景群众，才允许在群像或镜头正文中统一描述服装。
- 每套最终造型建立M；它引用身份、当前阶段状态和已确认W，形成当前发型、妆容、装饰与完整穿着结果。
- 手、脚、义肢或局部只有承担身份 / 产品操作且反复出现时才补局部参考。

B素体必须把脸部身份与身体校准分开控制，并严格复刻同一套16:9固定三列网格，不允许模型按人物、性别或文字多少重新排版。左栏约占画面宽度36%并贯穿整高，只放正面头部大特写，负责全板唯一清晰人脸以及五官、骨相、肤色、发际线、发质和永久面部特征；中栏约占45%并横向三等分，依次放左前方45度、正面、背面三张同尺度身体，使用同一具光滑裸头、完全无头发的无五官假人头模，只负责身体轮廓和参数。三张头模从额顶、颞侧、耳后到枕骨均为连续、同色、哑光人台表面，只保留头颅与耳廓体块，不生成真实或模糊五官、头发、发际线、眉毛、睫毛、胡须、眼镜和头饰；右栏约占19%并贯穿整高，是固定文字标注区，标题固定右上，年龄 / 身高 / 体重固定在标题下方，围度与长度按固定纵坐标向下排列，说明固定右下。中栏只允许在正面与背面身体之间出现一个头身比短标；其余参数只能位于右栏，不能改成底部横栏、左下参数栏、分格表格或紧贴人物的自由文字堆。关键围度使用白色圆点落在正面身体的解剖位置，以不交叉的水平细白引线连接右栏对应文字。

B的身体参数标注至少覆盖年龄、身高、体重、头身比、骨性肩宽、胸围、腰围、臀围、颈围、上臂围、大腿围、小腿围、肩点至腕、髋点至地和基础体态；原创角色使用明确设计值，不声称真人测量。三张身体从头模顶到脚底完整出现，共用同一地面线、头顶线、身体尺度、站姿、校准服、背景、光向和阴影方向。标题、正文、单位、引线、圆点和右下说明使用统一白色无衬线字体与固定字号层级；下游禁止继承注释文字、灰底、校准服和假人头模。

阶段素体资产必须逐项继承B的固定三列网格、36% / 45% / 19%栏宽、整高关系、三身体等分、右上标题、右栏参数纵坐标、水平引线、右下说明、字体层级和地面线，不能只写“版式与B一致”后让模型自由解释。中栏仍为同一具光滑裸头、完全无头发的无五官假人头模所承载的左前方45度、正面、背面身体，头模表面连续、同色、哑光，只保留头颅与耳廓体块；右栏用同一参数顺序显示当前完整值，完整参数与阶段增量同时保留，一句可见形体变化压缩为右下说明，不新增底栏或左下信息格。所有相邻阶段保持裁切、站姿、头顶线、地面线、光线、背景、字体、注释纵坐标和身体尺度一致，变化只能发生在阶段脸软组织、身体轮廓与对应数字。

左栏阶段脸必须把 `永久身份锚点` 与 `阶段可变区` 分开写，这套分离控制才叫阶段脸受控变化。永久身份只锁眼鼻口耳、发际线及其相互位置，不把整张脸型、脸颊厚度、下颌缘、颏下轮廓或颈部宽度一起锁死；阶段可变区明确列出本次允许改变的颧颊软组织、外侧脸颊轮廓、下颌缘显露度、颏下轮廓与颈部视觉宽度。每个阶段都要有无需上一张图也能执行的 `绝对目标`，再用已真实生成并验收的相邻阶段图强化连续性；`更饱满、进一步柔化、最明显、自然一些` 不能单独承担变化。绝对目标优先使用分级、相对母版的轮廓比例、平面由内收到平直到凸起、下颌缘可见范围、颏下弧线和对应颈围等可观察几何。阶段验收必须做 `剪影级差`：遮住五官后，相邻脸部外轮廓仍能按阶段顺序辨认；若身体变化成立而脸部级差失败，只返修左栏脸部或先生成同裁切的多阶段脸部校准条，不重做已经合格的身体与版式。校准条属于临时比较参考，只有跨任务复用并通过验收后才升级为正式资产。

W服装资产必须先做身份场景活动推导：角色是谁、处在什么场景、要做什么、年龄与阶层、季节与当前身体怎样共同决定服装轮廓、比例、材料、配色、工艺、穿法和活动余量。B或当前阶段素体只作为后台版型与尺码输入，用于推导衣长、肩宽、胸腰松量、袖长、裤长、鞋码和动作余量；人物身体参数不得进入W，不在W画面重复身高、体重、三围、头身比、身体参数板或全身人物三视图。W可以标注成衣尺寸、规格和活动松量，但标注对象必须是服装。

W在进入制作板之前还必须建立人物化设计卡。它从剧本中的选择、关系压力和社会位置，推导一个中远景可读的主要锚点与最多一个近景辅助锚点；锚点优先落在轮廓比例、色彩关系、材料行为、结构和穿法，不把性格形容词直接翻译成颜色或图案。每条W明确写出`季节阶段`、`人物化设计锚点`、从上一套保留的`连续继承`、本阶段因季节 / 场景 / 身体产生的`阶段替换`，以及`平均答案回避`。普通服装也要完成这一步；人物化不等于华丽化，删掉装饰后人物关系更准确时应保留克制方案。

W使用16:9固定服装视觉规格板，图片信息为主、名词短标签为辅。写版式前必须先做`服装主件结构判断`，不是让所有服装套同一张板：判断这套资产由几个独立主件构成、哪个主件决定整体轮廓、拆开以后哪些正背面与隐藏结构会丢失。鞋袜和普通配饰不单独决定模式；夹克、内搭、上衣、下装等可以独立穿脱并各自承担结构时，属于可拆套装；连衣裙、连体服、长袍等由一件从上身延续到下摆的连续主件主导时，属于连续主件。

`可拆套装分件拆解板`使用固定2行×2列四象限，四区边界、基线和标题位置统一：左上`上装拆解`，以无头无脸上半身服装承托架展示严格正面与严格背面，放大衣领、肩线、门襟、袖口、口袋、内里和接缝；右上`下装拆解`，以下半身服装承托架展示严格正面与严格背面，放大裤腰 / 裙腰、口袋、裆部或裙片、侧缝、裤脚 / 裙摆和内侧结构；左下`配件与鞋履`，逐件展示袜、鞋、腰带、手套、口罩或其他本套穿戴物，并补鞋底、扣合与接触面；右下`材质与活动余量`，以材质微距、局部受力和中性活动承托示意证明主次面料、里布、针脚、弹性、垂坠、抬臂、坐姿、屈膝或剧情所需松量。每个主件至少有完整正面、完整背面和一项关键内侧证据；存在外套＋内搭、多层裙或其他叠穿时，上装或下装区必须保留一张`叠穿关系`小图，证明穿着顺序、开合边界和内外层露出比例。可拆模式不再用两个全身成套人台占据画面，也不把全部细节压成十二个同尺寸小格。

`连续主件完整展示板`只用于不可拆分的单一连续主件。它保留左侧约三分之一的严格正面与严格背面全身服装承托人台，证明从肩线 / 领口到腰线、裆部或裙摆的连续轮廓、垂坠、长度和正背关系；右侧约三分之二固定4列×3行共12个近似正方形细节格，第一排以整件正面、整件背面、内里 / 展开和主要配件建立整体证据，第二排拆领口、扣合、袖口、腰线或下摆，第三排拆主次面料、里布、鞋底 / 接触面、活动余量或特殊工艺。承托人台必须光滑裸头、完全无头发、无五官，不呈现人物身份和身体参数。

两种模式都以局部摄影、展开平铺、技术线稿和材质微距互证，并让所有细节可回指到同一主件。画面文字只使用上装拆解、下装拆解、配件与鞋履、材质与活动余量、正面、背面、衣领、门襟、袖口、裤腰、面料、里布、鞋带、鞋底、叠穿关系等大号名词性标题；不使用小字号解释段落、参数墙或人物尺寸表。成衣规格继续作为设计与验收依据，只有尺寸本身承担区分时才允许一个清楚的大号成衣规格标记。`复杂度只改变设计密度`：它只改变已选模式内部的证据数量、细节深度和工艺精度，不决定是否建立W，也不允许把华丽服装写成更多形容词。禁止把人物素体板、普通商品正背图、自由拼贴或长篇文字说明当成完整W。W不加入最终发型、妆容、表情和剧情动作；这些组合结果交给M。

M妆造使用16:9受控定妆设计板，视觉上保持2行×3列，实际必须组织成左前方45度、正面、背面三列纵向组合，不是六张彼此独立的人物照片。每列上排是放大的头部与必要肩颈特写，负责五官、最终发型、妆面、肤质、眉眼唇腮、发饰、胡须、耳饰、头饰、眼镜、伤妆和其他头部细节；上排通常约占高度三分之一，妆发细节承重时可以适度加高，只要下部仍能从颈根完整展示到鞋底。每列下排必须是同角度的`无头穿着身体`：从颈部根部或肩线以下至鞋底，画框最高可见点固定为左前方45度和正面的锁骨、双肩峰，背面的后领中心与肩线，人体头颅完整位于下部画框之外。上部特写向下覆盖下部原本的头颅位置，覆盖接缝藏在颈肩交界或服装领口附近，使上部头部成为同列身体的唯一对应头部；下部不再生成第二个远景脸、头发或完整全身肖像。上下同列角度、身份、阶段体型、身体中轴、服装穿着关系、背景、光向和色彩基线一致。M组合B、当前人物阶段状态、W和当前妆发装饰，只确认最终上身结果，不重新定义身高、体重、骨架、永久身份或服装工程。它还负责纹身、身体彩绘、疤痕妆、义体表面与配饰主次怎样共同形成身份和气质。B、人物阶段状态、W和M的详细提示词合同读取人物Reference与图片模板，不得退回每张全身图都带远景五官、六张独立人物照片、普通三视图阶段板、无W妆造或旧四视图妆造板。

M进入固定版式前必须写清`妆造记忆锚点`、`穿着方式`、相对上一阶段的妆发 / 穿法变化和克制边界。妆造记忆点只能来自发型轮廓、发缝、眼镜、胡须、妆面结构、饰品或衣服真实穿法中承重的一至两项；不靠多件装饰抢戏，也不把`更疲惫、更自然、更精致`当终态。W负责衣服本体，M负责它怎样被这个人物穿成当前状态，两者不能重复设计。

“根据真实事迹改编”、沿用真实姓名或题材来自新闻，只能证明故事来源，不能自动推出真人相貌复刻。只有老胡明确要求还原具体真人，并且提供了有权使用、足以锁定身份的参考资料时，才建立真人相貌参考链；否则依据剧本职责原创选角，锁年龄、骨相、发型、体态和关系证据，同时避免声称“真人复刻”或“相貌还原”。

场景先判断是有边界空间还是宏大环境。每个正式场景至少定义一个可跨机位识别、可供语言定位的空间锚点，并写清锚点与入口、行动区、固定光源、相邻面、关键家具和人物路径的距离与方向；必要时补一个次锚点。柱、门洞、固定柜体、楼梯平台和房梁优先，可移动家具只有长期固定且承担定位时才可用。前者还要证明入口、方向、相邻面、尺度、固定构件和可拍路径；后者要证明总拓扑、接近过程、人尺度、门槛与内部关系。漂亮空镜不能替代空间资产。

物品先锁主轮廓、比例、材料、功能、接触区、活动件、文字 / Logo 和磨损逻辑。只有跨角度、被操作、进入特写或承担主视觉时才需要多视图；正式道具资产采用中性偏灰摄影棚，按风险展示左前方45度、正面、侧面、背面和功能特写。简单一次性道具写进视频正文。

跨VID继承真实破坏、人物站位或临时光影时使用双参考合同：稳定人物、场景、服装与道具资产只负责身份、拓扑、材质和空间锚点；通过生成复盘验收的状态帧只负责当前破坏、站位、临时光影、摄影方向和瞬时状态。状态帧只服务一个相邻单元时是临时参考；持续跨多个VID或反复调用时才升级为场景状态资产。禁止让状态帧单独替代稳定资产，也禁止把未验收尾帧登记成正式资产。

商业资产还要证明卖点：产品结构、人物用法、场景条件和镜头角度必须共同提供可见证据。只拍高级静物不能证明抓地、防水、轻量、服务效率或使用利益。

### 验收

- 这是稳定资产、单张成品图还是临时参考，是否分类正确。
- 每个资产是否有复用范围、叙事职责、失真代价和下游调用。
- 是否已经删到最低可行资产，未把剧本名词逐项建图。
- 依赖图是否无环，提示词是否按依赖顺序排列。
- 画面中每个可识别对象是否引用闭合、文本闭合或明确不出现。
- 稳定身份、持续阶段和瞬时表演是否没有混成一张图。
- 去掉滤镜、氛围和漂亮形容词后，设计本体是否仍成立。
- 形象图是否有第一眼吸引，制作图是否能换角度保持同一个对象。
- 材料与意象是否承担作品用意和公共经验，而不是为了“专属”挑小物件。
- 代码块是否只有模型要看到的正向画面，引用是否显性且职责清楚。
- 实际图片是否经过身份、结构、材质、用途和下游可用性验收；未生成时是否仍标为占位。
- 下游是否知道该继承什么、该重新设计什么，不需要重新猜。
