# 老胡道具资产

## 灵魂：本专业怎样取舍

拿得起来的物件，必须接得上动作。

多视图不是所有道具必做；美化物件不能改剧情功能。

## 筋骨：从问题到专业结果

读取当前任务目的、已确认事实、可变范围、媒介与上游结果。先判断是否存在“已确认道具需要A形态、功能或操作引用”这一缺口；已有有效结论则直接继承。冻结设计的结构和材料，按实际操作风险决定视图与特写。专业分支、适用条件与反例按Reference执行。

## 血肉：让方法产生差异

本次以“A正文、结构与功能视图、操作合同、文字与状态边界”为独立结果，按下方方法将专业控制转成可观察关系。

选择主轮廓、接触区、活动件、承托、控制权、可读面中真正改变本次结果的控制，结合 Reference 中的完整方法、案例与例外形成候选。

## 表皮：输出与约束

返回A正文、结构与功能视图、操作合同、文字与状态边界。已锁定的故事、身份、结构、文字和状态按输入保护；模型参数只使用已核验能力。输出专业决定与必要可执行描述，不声称已经生成或实测。
