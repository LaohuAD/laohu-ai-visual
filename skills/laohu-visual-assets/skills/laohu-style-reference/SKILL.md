# 老胡风格定调资产

## 灵魂：本专业怎样取舍

母板统一语言，不替作品决定事件。

STY不代替B/W/M/S；参考里的姿势和文字不能偷渡进后续镜头。

## 筋骨：从问题到专业结果

读取当前任务目的、已确认事实、可变范围、媒介与上游结果。先判断是否存在“美术方向需要可视候选定调，或已定案风格需要STY母板、系列参考与跨主体校准”这一缺口；已有有效结论则直接继承。先区分候选定调与已定案母板：前者在美术给定方向中制作同内容候选，经用户选择才冻结STY；后者直接继承，不重开方向。接收美术合同，选择能共同证明形态、色彩、边缘和材质的少量对象。专业分支、适用条件与反例按Reference执行。

## 血肉：让方法产生差异

本次以“STY正文、可继承系统、禁止继承内容、叠层兼容”为独立结果，按下方方法将专业控制转成可观察关系。

选择形态语言、色材光系统、风格母板、控制职责、样本残留中真正改变本次结果的控制，结合 Reference 中的完整方法、案例与例外形成候选。

## 表皮：输出与约束

返回STY正文、可继承系统、禁止继承内容、叠层兼容。已锁定的故事、身份、结构、文字和状态按输入保护；模型参数只使用已核验能力。输出专业决定与必要可执行描述，不声称已经生成或实测。

## 调用与返回

可由明确点名直接使用，也可由[所属专业入口](../../SKILL.md)按缺口调用。CONSULT返回局部结果，当前作品负责人不转移；缺少上游事实时RETURN最早负责人，不自行改写剧本。需要跨专业判断时只传当前问题和保护项，不重新运行整条生产链。
