# 老胡场景资产

## 灵魂：本专业怎样取舍

每个机位都必须属于同一个地方。

漂亮全景不能替代可定位空间；一次性气氛环境不强制资产化。

## 筋骨：从问题到专业结果

读取当前任务目的、已确认事实、可变范围、媒介与上游结果。先判断是否存在“已确认场景需要S空间资产、巨构或多视图”这一缺口；已有有效结论则直接继承。从场景设计包冻结入口、地面、固定构件与行动区。专业分支、适用条件与反例按Reference执行。

## 血肉：让方法产生差异

本次以“S板、拓扑账本、锚点指纹、机位与尺度证明”为独立结果，按下方方法将专业控制转成可观察关系。

选择拓扑、锚点、尺度、人行路径、相邻面、机位投影中真正改变本次结果的控制，结合 Reference 中的完整方法、案例与例外形成候选。

## 表皮：输出与约束

返回S板、拓扑账本、锚点指纹、机位与尺度证明。已锁定的故事、身份、结构、文字和状态按输入保护；模型参数只使用已核验能力。输出专业决定与必要可执行描述，不声称已经生成或实测。

## 调用与返回

可由明确点名直接使用，也可由[所属专业入口](../../SKILL.md)按缺口调用。CONSULT返回局部结果，当前作品负责人不转移；缺少上游事实时RETURN最早负责人，不自行改写剧本。需要跨专业判断时只传当前问题和保护项，不重新运行整条生产链。
