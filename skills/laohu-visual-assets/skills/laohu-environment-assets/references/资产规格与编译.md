# 资产规格与编译



正式复用场景进入S场景资产之前，必须继承已经确认的`场景与布景设计交接包`；空间叙事命题、候选竞争、人物—空间关系、布景陈设和制作策略由`laohu-set-design`负责，视觉资产只把胜出设计编译成可复用的场景资产、物品资产、图片提示词与调用合同，不得重新设计。用户已经锁定完整场景时执行零设计改动编译；一次性环境只承担气氛且不需要稳定拓扑时，保留为场景画面元素或单镜头参考图，不强制建立正式场景资产。若缺的是“为什么这样设计”，返回场景设计；若设计已成立但多视图走样、锚点漂移、版式或生成失败，留在本 Skill。

场景先判断是有边界空间还是宏大环境。每个正式场景至少定义一个可跨机位识别、可供语言定位的空间锚点，并写清锚点与入口、行动区、固定光源、相邻面、关键家具和人物路径的距离与方向；必要时补一个次锚点。柱、门洞、固定柜体、楼梯平台和房梁优先，可移动家具只有长期固定且承担定位时才可用。`锚点视觉指纹`必须可核对：尺寸 / 截面、材料、朝向、连接方式和少量位置明确的磨痕、缺口、色差、接口或接缝。多视图只允许摄影机坐标和朝向变化，锚点不得移动、旋转、镜像、换材质、改指纹或被复制；鸟瞰必须能反推出各机位。前者还要证明入口、方向、相邻面、尺度、固定构件和可拍路径；后者要证明总拓扑、接近过程、人尺度、门槛与内部关系。现实公共空间还要执行`功能密度与社会经济校准`：按人物经济条件、场所等级和真实流程决定面积、共享设施、固定设备与生活物，不能把普通公立医院、学校或工薪家庭做成空房、豪华单间或样板间。漂亮空镜不能替代空间资产。



场景资产图写法：

```text
扩展分区场景设计板：左上 2×2 为正面、左侧、右侧和反向四机位，右上为较大的高位鸟瞰 / 斜俯视总平面，底部为固定构件、材质、颜色、连接、磨损和空间记忆锚点细节带；先指定一个跨机位不移动的主空间锚点，必要时补次锚点，标明它与入口、行动区、固定光源、关键家具和人物路径的方向与距离；所有区域保持同一结构、光源、锚点名称和位置账本。
局部操作空间要先拆资产：空间本身做局部场景资产，桌子 / 案板 / 碗 / 汤圆 / 硬币等可移动物单独做物品资产。场景资产只锁空间结构、入口、光源和动线；物品资产只锁物品本体；手部进入方向和人物站位属于分镜或视频提示词。
```
