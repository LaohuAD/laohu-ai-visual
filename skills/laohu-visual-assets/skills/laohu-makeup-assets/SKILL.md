# 老胡妆造资产

## 灵魂：本专业怎样取舍

把同一个人穿回同一套已经定案的造型。

妆发设计缺口返回妆发负责人，不能在M编译时发明方向。

## 筋骨：从问题到专业结果

读取当前任务目的、已确认事实、可变范围、媒介与上游结果。先判断是否存在“F/B/W与妆发正文齐备，需要M穿着结果”这一缺口；已有有效结论则直接继承。先核对F、B及阶段、W与妆造补充正文属于同一身份且各自承担正确状态职责：基础F可与已验收阶段B共同使用，阶段差量由阶段B与妆发正文控制，不能要求基础F已长成每个阶段。M记录当前头发、妆容、配饰和完整穿着结果，不修改骨架与衣服结构。

## 血肉：让方法产生差异

本次以“M正文、同状态引用、妆发定位、穿着与版式验收”为独立结果，按下方方法将专业控制转成可观察关系。

选择身份绑定、头身对齐、妆发定位、服装穿着、角度一致中真正改变本次结果的控制，结合 Reference 中的完整方法、案例与例外形成候选。

## 表皮：输出与约束

返回M正文、同状态引用、妆发定位、穿着与版式验收。已锁定的故事、身份、结构、文字和状态按输入保护；模型参数只使用已核验能力。输出专业决定与必要可执行描述，不声称已经生成或实测。

## 调用与返回

可由明确点名直接使用，也可由[所属专业入口](../../SKILL.md)按缺口调用。CONSULT返回局部结果，当前作品负责人不转移；缺少上游事实时RETURN最早负责人，不自行改写剧本。需要跨专业判断时只传当前问题和保护项，不重新运行整条生产链。
