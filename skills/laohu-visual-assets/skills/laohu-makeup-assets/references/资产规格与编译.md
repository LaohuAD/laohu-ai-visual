# 资产规格与编译



M取得F写真母图、B或当前阶段素体、W和由妆发设计维护、可经人物入口整合交付的`妆造补充正文`，使用16:9受控定妆设计板反向拆出妆容、发型、发饰和最终穿着关系。视觉上保持2行×3列，实际必须组织成左前方45度、正面、背面三列纵向组合，不是六张彼此独立的人物照片。每列上排是放大的头部与必要肩颈特写，负责五官、最终发型、妆面、肤质、眉眼唇腮、发饰、胡须、耳饰、头饰、眼镜、伤妆和其他头部细节；每列下排必须是同角度的`无头穿着身体`，从颈部根部或肩线以下至鞋底，人体头颅完整位于下部画框之外。上部特写向下覆盖下部原本的头颅位置，覆盖接缝藏在颈肩交界或服装领口附近，使上部头部成为同列身体的唯一对应头部。上下同列角度、身份、阶段体型、身体中轴、服装穿着关系、背景、光向和色彩基线一致。M不重新定义身高、体重、骨架、永久身份或服装工程。

妆造记忆锚点、穿着方式、阶段变化和克制边界必须已经被`妆造补充正文`落实成具体的眉眼、肤面、唇色、发缝、发束、发饰位置和穿着结果；视觉资产不能只写抽象字段，也不能自行发明。W负责衣服本体，M负责把写真中已经成立的妆发与W穿回同一主体，两者不能重复设计。



人物妆造设计资产：显式引用人物素体、当前人物阶段素体与W服装资产。16:9画面视觉上保持2行×3列，实际写成左前方45度、正面、背面三列纵向组合，而不是六张独立人物照片。每列上排是放大的头部及必要肩颈特写，通常约占三分之一并可按妆发细节适度加高；每列下排是同角度的无头穿着身体，从颈部根部或肩线以下至鞋底，画框最高可见点只落在锁骨、肩峰、后领中心或肩线，人体头颅完整位于下部画框之外。上部特写向下覆盖下部原本的头颅位置，覆盖接缝藏在颈肩交界或服装领口，使上部头部成为同列身体的唯一对应头部。三列共同锁定当前最终发型、发饰、妆面、肤质、胡须、耳饰、头饰、眼镜、纹身、身体彩绘 / 伤妆、疤痕妆、义体表面和服装穿回同一人物后的气质结果；上下同列的身份、阶段体型、服装穿着关系、身体中轴、背景、光向与色彩一致。M是受控定妆摄影资产，必须补背景与妆面之间的明度 / 色相对比、主光与补光方向、眼神光、睫毛分离度、腮红过渡、唇部高光、发丝边缘和服装轮廓；不重复身体工程参数，不重新发明W的服装结构。


- 人物妆造设计资产：引用F写真母图、已经确认的B或当前阶段素体、W及妆发设计维护、可经人物入口整合的`妆造补充正文`。F提供已经成立的脸、妆容、发型、发饰、人物气质与光影质感；B提供脸身和体型；W提供服装正背结构；妆造补充正文明确写真没有展示清楚的眉眼、肤面、唇色、发缝、侧背发束和发饰位置。视觉资产只把四类输入放进16:9三列纵向定妆板，不自行设计妆发，不重复身体工程参数，也不重新设计W。
