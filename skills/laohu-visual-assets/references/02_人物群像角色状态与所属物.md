# 人物、群像、角色状态与所属物



当人物身份、群像、服装状态、人物设计板、角色所属物或跨镜一致性承重时读取。



### 2. 角色资产拆解

角色资产不是人物介绍，而是生成稳定性说明：

```text
角色名：
故事功能：
固定外观：
发型和服装：
年龄和气质：
表情基准：
关键情绪变化：
需要图片资产：
一致性风险：
```

只有角色会跨镜头、跨场次或跨集复用时，才进入角色资产表。一次性迎宾、路人、群众、守门者等功能角色，除非需要后续反复出现或作为封面主体，否则只写成“角色画面元素”。

### 2.1 人物连续性接口

人物资产不能只回答“长什么样”，也不能越权替编剧回答“她是什么样的人”。重要人物先读取 `人物连续性圣经`，再按职责拆分：

```text
不可漂移身份 → 进入人物素体形象资产与基础音色接口。
跨多个独立片段持续存在的体型、年龄、康复、伤病或形态阶段 → 按复用和失真代价进入人物阶段状态资产。
服装与最终妆造 → 进入人物服装资产和人物妆造设计资产。
人格基线与条件化行为签名 → 交给剧本、分镜、表演和声音，不写进中性资产图。
当前状态 → 进入本场状态账本、故事板、首帧或视频提示词，不污染永久资产。
弧光变化 → 只有跨过明确剧情阈值后才更新新基线；换装、伤妆和表情变化不自动等于成长。
```

人物连续性圣经是文本生产资产，不要求机械增加图片。人物阶段状态资产只在持续身体变化确实跨请求复用且失真代价高时建立，可以沿用作品自己的阶段编号；它不改变 B / W / M 的职责，也不能把瞬时表演升级成永久资产。视觉资产文件只记录连续性圣经与图片的接口：哪些身份锚点必须被看见，哪些阶段变化必须可见，哪些第一印象线索可由视觉建立，哪些人格结论必须留给后续行为证明。

### 2.2 识别锚点与第一印象

人物辨识度按层级设计：

```text
身份级锚点：脸型、骨相、眉眼鼻唇关系、发际线与发质、头身比、基础身体比例、永久标记。
轮廓级锚点：当前发型整体外轮廓、颈肩关系、体态、步态、服装大轮廓；其中发型整理与服装仍可随最终造型变化。
局部主锚点：一个近看最容易记住、且跨妆造仍成立的特征。
辅助锚点：按需最多一个，不与主锚点争夺。
状态性变化：妆容、伤势、污渍、服装、饰品、持物和光影，不登记为永久身份。
```

高辨识不等于特征数量多。先寻找相对于平均脸、平均轮廓真正不同的关系，再做适度强化；强化到损失真实感、审美和跨角度稳定时立即回退。至少做四项内部测试：`去色后轮廓是否可认 / 去掉服装与饰品后脸和身体是否可认 / 正脸与左45度是否仍是同一人 / 更换妆造后主锚点是否仍在`。只有靠发色、耳饰或单件服装才能认出的角色，身份资产尚未成立。

外貌线索可以设计 `观众第一印象`，但不能在资产文件里把印象写成人格事实。正确写法是：`上挑但不过度锐利的眼裂、稳定直视、颈肩打开，观众可能先读到主动和控制感；真实人格由人物圣经与剧情行为证明。` 错误写法是：`她眼尾上扬，所以她强势、自信、绝不退缩。` 第一印象属于观众预期层，可能正确，也可以被剧情有意推翻。

### 2.3 预期差的视觉职责

编剧确认使用预期差后，视觉资产只承担“让前置预期清楚可读”的部分。例如粗犷体格、胡茬、宽肩、厚重工作服可以让观众预期低沉粗粝的声线；真正出现的纤细偏高声线、人物原因、他人反应和剧情后果由声音、表演与剧本承担。不得为了把反差一次画完，在人物素体上同时堆入与身份无关的夸张表情、台词文字、声波图标和剧情说明。

预期差也可以跨其他通道：精致外貌与粗粝劳动方式、弱小体格与极强空间控制、威严身份与私下笨拙亲密、冷硬服装与极轻柔操作。选择哪一种取决于故事功能；不默认外貌必须和人格相反。视觉端检查：前置预期是否明确但不过度脸谱化；是否保留真实人物空间；是否避免用性别、年龄、地域、职业、体型、残障或声线特征本身制造羞辱。

需要多镜头复用时，先按“复用次数、身份承重、结构易漂移、失真代价”判断最小必要资产，不统一建立三件套：

- 人物素体形象资产：16:9中性灰摄影棚校准板使用不可变的三列网格。左栏约36%宽并占满整高，只放正面头部大特写和全板唯一清晰人脸；中栏约45%宽并三等分，依次为左前方45度、正面、背面三张同尺度身体，使用同一具光滑裸头、完全无头发的无五官假人头模和贴体不暴露的中性校准服。三张头模从额顶、颞侧、耳后到枕骨均为连续、同色、哑光人台表面，只保留头颅和耳廓体块，不保留真实发型、发际线或任何头部装饰；右栏约19%宽并占满整高，标题固定右上、基础信息紧随其下、围度与长度使用固定纵坐标、说明固定右下。除中栏正面与背面之间的头身比短标外，参数文字只允许进入右栏；关键围度以正面身体上的白色圆点和不交叉水平细白引线连接右栏文字，不建立底部横栏、左下参数格或自由浮动标签。参数至少写年龄、身高、体重、头身比、骨性肩宽、胸围、腰围、臀围、颈围、上臂围、大腿围、小腿围、肩点至腕、髋点至地、基础体态和永久身体特征；原创角色使用设计值。下游禁止继承注释文字、灰底、校准服、假人头模和中性站姿。
- 人物阶段素体资产：显式引用同一人物素体，固定跨多个独立片段持续存在的体型、年龄段、康复、伤病或形态阶段。它逐项沿用B的16:9固定三列网格、36% / 45% / 19%栏宽、三身体等分、右上标题、右栏参数纵坐标、水平引线、右下说明、字体层级、头顶线和地面线；不能改成普通三视图，也不能换文字区位置。左栏阶段脸分开写 `永久身份锚点` 与 `阶段可变区`：眼鼻口耳、发际线及其相互位置负责同一人，颧颊软组织、外侧脸颊、下颌缘显露度、颏下轮廓和颈部视觉宽度负责当前阶段；身份锁不得把后组同时冻结。每阶段同时写独立可执行的 `绝对目标` 与按需的相邻阶段比较，使用软组织分级、相对母版轮廓比例、面部平面凹凸、下颌缘可见范围、颏下弧线和颈围等屏幕证据，不用“更、进一步、最、自然”替代目标。中栏仍为同一具光滑裸头、完全无头发的无五官假人头模所承载的左前方45度、正面、背面身体，头模表面连续、同色、哑光；右栏按同一顺序记录当前完整参数，阶段增量与一句可见形体变化进入右下说明。相邻阶段只替换阶段脸、身体轮廓、当前数字和右下阶段说明，其他版式、裁切、站姿、光线、背景和身体尺度全部冻结。并排验收时遮住五官做 `剪影级差`，相邻外轮廓仍须按顺序可辨。它不固定戏服、最终发型、妆容、剧情表情和场景。
- 人物服装资产：所有最终服装都先单独形成W，普通、朴素和一次性服装也不跳过。身份、阶层、年龄、当前形体、场景、活动和季节是设计输入，先据此推导服装版型、层次、材质、颜色、纹样、接缝、扣合、穿法、规格和活动余量；人物素体只在后台提供尺码约束，人物身体参数不得进入W画面。W先做服装主件结构判断，再选择两种16:9固定服装视觉规格板之一：上衣、下装、外套、内搭等多个独立主件组成的套装使用`可拆套装分件拆解板`，固定2行×2列四象限，分别为上装拆解、下装拆解、配件与鞋履、材质与活动余量；上装用无头无脸上半身服装承托架展示严格正背面，下装用下半身服装承托架展示严格正背面，多层穿着另留叠穿关系图。连衣裙、连体服、长袍等由不可拆分的单一连续主件主导时使用`连续主件完整展示板`，左侧约三分之一为无五官全身承托人台的严格正背面，右侧约三分之二为4列×3行十二格，证明连续轮廓、内里、结构、材质、鞋履与活动余量。两种模式都以局部摄影、展开平铺、技术线稿和材质微距为主，文字只保留大号名词性标题；普通与复杂服装都保留完整正背、隐藏结构、材料工艺和动作适配，复杂度只增加已选模式内部的证据密度，不改变模式判断。
- 人物妆造设计资产：引用已经确认的素体、当前人物阶段素体与W，固定当前发型整理、发饰、面部妆容、胡须 / 假发、头饰 / 耳饰、眼镜、伤妆、纹身 / 身体彩绘、疤痕妆、义体表面及服装穿回同一主体后的最终结果。16:9画面视觉上保持2行×3列，实际组织成左前方45度、正面、背面三列纵向组合。每列上部是放大的头部与必要肩颈特写，通常约占三分之一，按妆发细节可读性适度调整；每列下部是同角度的无头穿着身体，从颈部根部或肩线以下到鞋底，最高只出现锁骨、肩峰、后领中心和肩线，人体头颅完整位于下部画框之外。上部特写覆盖下部原本的头颅位置，覆盖接缝藏在颈肩交界或服装领口，使上部成为下部身体的唯一对应头部；六个区域不得退化为六张独立人物照片。M采用受控定妆摄影关系，不是B的中性灰平光图：背景明度 / 色相衬托肤色、发色、妆面和服装轮廓，主光照出眼睑、睫毛、虹膜眼神光、鼻梁和唇面高光，补光保留暗侧结构，上下同列共享身份、阶段体型、服装穿着关系、光向和色彩基线。它不重复身体工程参数，也不重新设计W的服装结构。
- 表情组、动作起点参考图或角色一致性网格图只能作为辅助或临时参考，不能替代已经选定的正式资产职责。

生成顺序按依赖关系执行：先有 `人物素体形象资产`，存在持续形体变化时再建立 `人物阶段素体资产`；随后为每套最终服装建立W，最后由M组合当前B / 阶段素体、W和妆发装饰。M不得绕过W直接发明服装。未被资产化的一次性背景群众仍可由群像或视频正文统一描述，不为每个路人建立个人资产。B左侧唯一清晰人脸可以使用便于识别发际线和发质的中性整理，但右侧无五官身体图不保留真实发型；最终发型由M或当前镜头状态负责。

### 2.4 长时间跨度的造型链

先把剧本还原成真实故事时间，再建立 `时间阶段 → 身体阶段 → 场景功能 → 最终造型` 链。换装由跨日 / 跨季节、活动功能和直接连续性共同裁决；剧本段落换了不等于必须换装，段落没换也不等于几个月都穿同一套。长时增重、衰老、康复或伤病恶化必须用至少两个可辨阶段证明变化过程，不能让起点资产直接跳到终点，也不能只靠字幕说明。

例：初诊后直接步行回家属于同一天，保持同一套外出服；数周后的学校场景改为校服；跨季节的长期增重段用尺码、材质和层次变化证明时间；复检与结尾清晨分别按医院外出和家居功能建立最终造型。即使某套衣服只用一次，只要该角色进入正式人物造型链，也先建立W；校服等多人共用服装可以由多个M复用同一W。一次性背景群众不进入个人造型链时，服装才留在群像或视频正文。

如果角色是 POV 主体，仍按正常人物资产判断：只在主角、跨镜头出现，或手、袖口、肩背承担稳定身份 / 关键操作时建立对应图片资产；人物素体可锁完整身体、身高比例、肩宽、手脚尺度、侧面和背面，服装或最终造型资产按需补充。视频阶段再把已确认的信息转成 POV 手部、袖口、肩背、低视线、反射里的身份锚点，并只调用本镜实际存在的 `【素体参考@Bxx】`、`【服装参考@Wxx】` 或 `【妆造 / 最终造型参考@Mxx】`。

群像人物资产不是主角色资产。它用于稳定“这一群人像什么人”，不用于锁定“每个人是谁”。当跑龙套群众会在连续镜头里围观、起哄、参与轻冲突或提供时代生活气，并且纯文字容易生成成现代人、偶像化人群或气质错误的人群时，可以新增 `G` 系列群像资产。群像资产可以使用场景合照式参考图：一群人站在对应环境里，展示年龄层、服装、发型、站位密度和表情范围。禁止把群像资产写成多个 A 系列主配角；禁止要求每个群众固定姓名、固定脸和完整三视图；具体谁伸手、谁跑动、谁说台词仍写在分镜或视频提示词里。

## 角色所属物与强风格资产路由

当道具、首饰、武器、设备、服装或铠甲属于某个具体角色时，先做角色归属审美检查，再写功能结构：

1. 从角色身份、性别表达、年龄、身材、服装轮廓、动作方式、世界观和情绪职责推导物品应有的尺度、重量、形状、材质、颜色、佩戴 / 握持位置与装饰语言。
2. 检查物品是否像角色会主动选择、长期携带并愿意纳入造型的东西。功能清楚但让角色显得违和、笨重、廉价、幼态或被物品吞没，直接退回重设。
3. 女性、小体量或技巧型角色不等于所有物品必须可爱小巧；真正判断依据是角色设定、身体工学和本场气质。若需求明确强调精致、性感、轻盈或珠宝感，就禁止无依据扩大为战术手柄、厚重机械块和男性化装备。
4. 服装展示身材时，使用贴合剪裁、腰线、露肩 / 露腿边界、明暗分区、冷暖反差、材质透光和轮廓光证明曲线；不能靠全身黑隐藏结构，也不能把“性感”偷换成暴露胸口、腹部或髋部。
5. 强风格化变身、法术、机甲、奇幻装备和跨形态角色先决定是否建立色卡 / 风格资产。建立后按人物、装备、场景、VFX 四组锁定写实比例、文化母题、HEX、材质和禁区，所有后续资产共同继承。
6. 用户的类比和剧情举例不是默认资产清单。只有明确要求在画面出现、需要跨镜稳定或承担下游输入的对象才资产化。
7. 同一人物有日常 / 战斗、变身前 / 变身后、完好 / 损坏等互斥状态时，先建立 `状态 → 继承身份 → 必须替换 → 最终禁止残留` 账本。身份参考只继承脸、年龄、身材、肤色、发型和稳定体态；服装、鞋履、首饰和装备必须按状态单独声明。风格板将互斥状态分区，不制作一个人物同时穿两套服装的综合色彩图。

当前案例：TEST-007 先建立 A27 半写实东方科幻玄幻色卡，再让 A22 的香槟白、酒红和烟黑御姐穿搭推导右腰 18mm 珠宝式 A23 曜莲星扣；A24 只继承 A22 的身份，不继承上衣、短裙、丝袜、腰链或细高跟，完成形态改为护髋、全覆盖腿甲和稳定战靴；A27 将变身前后分区，场景不生成用户只用于解释动机的怪兽。

## 研究校准与边界

- 人脸识别、表情和面部言语信息不能混成同一件事；人物素体优先锁身份，不用情绪表情替代脸部结构。参考 Bruce 与 Young（1986，DOI `10.1111/j.2044-8295.1986.tb02199.x`）。
- 发型对陌生人脸识别有明显帮助，但不能成为唯一身份来源；跨发型或被遮挡时仍要靠脸部关系和身体锚点稳定。参考 Toseeb 等（2012，DOI `10.1371/journal.pone.0034144`）。
- 适度强化偏离平均脸的特征可以提高辨识，过度夸张会损失真实感与身份准确。参考 Lee 等（2000，DOI `10.1111/1467-9280.00274`）与 Valentine、Lewis、Hills（2016，DOI `10.1080/17470218.2014.990392`）。
- 面孔会触发快速的可信度与支配感判断，但这些判断未必准确，因此视觉资产可以设计第一印象，不能把它冒充真实性格。参考 Oosterhof 与 Todorov（2008，DOI `10.1073/pnas.0805664105`）。
