# 人物、群像、角色状态与所属物



当人物身份、群像、服装状态、人物设计板、角色所属物或跨镜一致性承重时读取。



### 2. 角色资产拆解

角色资产不是人物介绍，而是生成稳定性说明：

```text
角色名：
故事功能：
固定外观：
发型和服装：
年龄和气质：
表情基准：
关键情绪变化：
需要图片资产：
一致性风险：
```

只有角色会跨镜头、跨场次或跨集复用时，才进入角色资产表。一次性迎宾、路人、群众、守门者等功能角色，除非需要后续反复出现或作为封面主体，否则只写成“角色画面元素”。

### 2.1 人物连续性接口

人物资产不能只回答“长什么样”，也不能越权替编剧回答“她是什么样的人”。重要人物先读取 `人物连续性圣经`，再按职责拆分：

```text
不可漂移身份 → 进入人物素体形象资产与基础音色接口。
服装与最终妆造 → 进入人物服装资产和人物妆造设计资产。
人格基线与条件化行为签名 → 交给剧本、分镜、表演和声音，不写进中性资产图。
当前状态 → 进入本场状态账本、故事板、首帧或视频提示词，不污染永久资产。
弧光变化 → 只有跨过明确剧情阈值后才更新新基线；换装、伤妆和表情变化不自动等于成长。
```

人物连续性圣经是文本生产资产，不增加 B / W / M 之外的第四张图片资产。视觉资产文件只记录它与图片的接口：哪些身份锚点必须被看见，哪些第一印象线索可由视觉建立，哪些人格结论必须留给后续行为证明。

### 2.2 识别锚点与第一印象

人物辨识度按层级设计：

```text
身份级锚点：脸型、骨相、眉眼鼻唇关系、头身比、身体比例、永久标记。
轮廓级锚点：发型整体外轮廓、颈肩关系、体态、步态、服装大轮廓。
局部主锚点：一个近看最容易记住、且跨妆造仍成立的特征。
辅助锚点：按需最多一个，不与主锚点争夺。
状态性变化：妆容、伤势、污渍、服装、饰品、持物和光影，不登记为永久身份。
```

高辨识不等于特征数量多。先寻找相对于平均脸、平均轮廓真正不同的关系，再做适度强化；强化到损失真实感、审美和跨角度稳定时立即回退。至少做四项内部测试：`去色后轮廓是否可认 / 去掉服装与饰品后脸和身体是否可认 / 正脸与左45度是否仍是同一人 / 更换妆造后主锚点是否仍在`。只有靠发色、耳饰或单件服装才能认出的角色，身份资产尚未成立。

外貌线索可以设计 `观众第一印象`，但不能在资产文件里把印象写成人格事实。正确写法是：`上挑但不过度锐利的眼裂、稳定直视、颈肩打开，观众可能先读到主动和控制感；真实人格由人物圣经与剧情行为证明。` 错误写法是：`她眼尾上扬，所以她强势、自信、绝不退缩。` 第一印象属于观众预期层，可能正确，也可以被剧情有意推翻。

### 2.3 预期差的视觉职责

编剧确认使用预期差后，视觉资产只承担“让前置预期清楚可读”的部分。例如粗犷体格、胡茬、宽肩、厚重工作服可以让观众预期低沉粗粝的声线；真正出现的纤细偏高声线、人物原因、他人反应和剧情后果由声音、表演与剧本承担。不得为了把反差一次画完，在人物素体上同时堆入与身份无关的夸张表情、台词文字、声波图标和剧情说明。

预期差也可以跨其他通道：精致外貌与粗粝劳动方式、弱小体格与极强空间控制、威严身份与私下笨拙亲密、冷硬服装与极轻柔操作。选择哪一种取决于故事功能；不默认外貌必须和人格相反。视觉端检查：前置预期是否明确但不过度脸谱化；是否保留真实人物空间；是否避免用性别、年龄、地域、职业、体型、残障或声线特征本身制造羞辱。

需要多镜头复用时，先按“复用次数、身份承重、结构易漂移、失真代价”判断最小必要资产，不统一建立三件套：

- 人物素体形象资产：中性灰摄影棚校准板，左侧头部正面特写，右侧左45度 / 正面 / 背面全身三视图，固定脸型、五官、身材、身高、基础体态和永久辨识特征；人类使用白衣白裤或中性简单衣裤。
- 人物服装资产：单独固定头部穿戴、上半身、下半身和足部的服装系统，写清版型、层次、材质、颜色、纹样、接缝、扣合、穿法和活动余量；不固定脸、发型和面部妆容。
- 人物妆造设计资产：引用已经确认的素体与服装，固定发型、面部妆容、胡须 / 假发、伤妆、身体彩绘和服装穿回同一主体后的最终结果；版式为左侧头部正面特写，右侧左45度 / 正面 / 背面全身三视图。M采用受控定妆摄影关系，不是中性灰平光图：背景明度 / 色相要衬托肤色与妆面，主光照出眼睑、睫毛、虹膜眼神光、鼻梁和唇面高光，补光保留暗侧结构，四视图共享同一光向和色彩基线。
- 表情组、动作起点参考图或角色一致性网格图只能作为辅助或临时参考，不能替代已经选定的正式资产职责。

生成顺序按依赖关系执行：通常先有 `人物素体形象资产`，再按需建立 `人物服装资产` 或 `人物妆造 / 最终造型资产`；M可以直接引用B并写入最终服装结果，不要求先建立W。如果角色只在一个场景出现且不承担跨镜头身份一致性，直接用视频提示词描述，不建立人物图片资产。

如果角色是 POV 主体，仍按正常人物资产判断：只在主角、跨镜头出现，或手、袖口、肩背承担稳定身份 / 关键操作时建立对应图片资产；人物素体可锁完整身体、身高比例、肩宽、手脚尺度、侧面和背面，服装或最终造型资产按需补充。视频阶段再把已确认的信息转成 POV 手部、袖口、肩背、低视线、反射里的身份锚点，并只调用本镜实际存在的 `【素体参考@Bxx】`、`【服装参考@Wxx】` 或 `【妆造 / 最终造型参考@Mxx】`。

群像人物资产不是主角色资产。它用于稳定“这一群人像什么人”，不用于锁定“每个人是谁”。当跑龙套群众会在连续镜头里围观、起哄、参与轻冲突或提供时代生活气，并且纯文字容易生成成现代人、偶像化人群或气质错误的人群时，可以新增 `G` 系列群像资产。群像资产可以使用场景合照式参考图：一群人站在对应环境里，展示年龄层、服装、发型、站位密度和表情范围。禁止把群像资产写成多个 A 系列主配角；禁止要求每个群众固定姓名、固定脸和完整三视图；具体谁伸手、谁跑动、谁说台词仍写在分镜或视频提示词里。

## 角色所属物与强风格资产路由

当道具、首饰、武器、设备、服装或铠甲属于某个具体角色时，先做角色归属审美检查，再写功能结构：

1. 从角色身份、性别表达、年龄、身材、服装轮廓、动作方式、世界观和情绪职责推导物品应有的尺度、重量、形状、材质、颜色、佩戴 / 握持位置与装饰语言。
2. 检查物品是否像角色会主动选择、长期携带并愿意纳入造型的东西。功能清楚但让角色显得违和、笨重、廉价、幼态或被物品吞没，直接退回重设。
3. 女性、小体量或技巧型角色不等于所有物品必须可爱小巧；真正判断依据是角色设定、身体工学和本场气质。若需求明确强调精致、性感、轻盈或珠宝感，就禁止无依据扩大为战术手柄、厚重机械块和男性化装备。
4. 服装展示身材时，使用贴合剪裁、腰线、露肩 / 露腿边界、明暗分区、冷暖反差、材质透光和轮廓光证明曲线；不能靠全身黑隐藏结构，也不能把“性感”偷换成暴露胸口、腹部或髋部。
5. 强风格化变身、法术、机甲、奇幻装备和跨形态角色先决定是否建立色卡 / 风格资产。建立后按人物、装备、场景、VFX 四组锁定写实比例、文化母题、HEX、材质和禁区，所有后续资产共同继承。
6. 用户的类比和剧情举例不是默认资产清单。只有明确要求在画面出现、需要跨镜稳定或承担下游输入的对象才资产化。
7. 同一人物有日常 / 战斗、变身前 / 变身后、完好 / 损坏等互斥状态时，先建立 `状态 → 继承身份 → 必须替换 → 最终禁止残留` 账本。身份参考只继承脸、年龄、身材、肤色、发型和稳定体态；服装、鞋履、首饰和装备必须按状态单独声明。风格板将互斥状态分区，不制作一个人物同时穿两套服装的综合色彩图。

当前案例：TEST-007 先建立 A27 半写实东方科幻玄幻色卡，再让 A22 的香槟白、酒红和烟黑御姐穿搭推导右腰 18mm 珠宝式 A23 曜莲星扣；A24 只继承 A22 的身份，不继承上衣、短裙、丝袜、腰链或细高跟，完成形态改为护髋、全覆盖腿甲和稳定战靴；A27 将变身前后分区，场景不生成用户只用于解释动机的怪兽。

## 研究校准与边界

- 人脸识别、表情和面部言语信息不能混成同一件事；人物素体优先锁身份，不用情绪表情替代脸部结构。参考 Bruce 与 Young（1986，DOI `10.1111/j.2044-8295.1986.tb02199.x`）。
- 发型对陌生人脸识别有明显帮助，但不能成为唯一身份来源；跨发型或被遮挡时仍要靠脸部关系和身体锚点稳定。参考 Toseeb 等（2012，DOI `10.1371/journal.pone.0034144`）。
- 适度强化偏离平均脸的特征可以提高辨识，过度夸张会损失真实感与身份准确。参考 Lee 等（2000，DOI `10.1111/1467-9280.00274`）与 Valentine、Lewis、Hills（2016，DOI `10.1080/17470218.2014.990392`）。
- 面孔会触发快速的可信度与支配感判断，但这些判断未必准确，因此视觉资产可以设计第一印象，不能把它冒充真实性格。参考 Oosterhof 与 Todorov（2008，DOI `10.1073/pnas.0805664105`）。
