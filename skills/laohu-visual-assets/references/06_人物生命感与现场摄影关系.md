# 人物生命感与现场摄影关系

当任务是观众成品人像、封面主体、叙事首帧、生活方式 B-roll 英雄帧，或需要在不改人物与事件的前提下升级普通照片时读取。B人物素体形象资产、按需建立的W人物服装资产和M人物妆造 / 最终造型资产属于制作参考，不调用本文件的现场叙事摄影规则；完成当前任务实际选择的制作参考后，再按需做成品人像。纯时尚摆姿只有在作品要求现场叙事或人物状态连续时调用。

这项能力解决的是“人物是否像正处在一段生活或事件里”，不是规定某一种漂亮人像风格。它与主体中的 `演员临场感` 分工如下：演员临场感检查事件压力、身体反应和行为选择是否成立；本 Reference 继续检查静态画面是否留下前后帧、摄影机是否真正进入关系、环境是否回应人物，以及皮肤、发丝、潮湿与光学效果是否服从真实材质。

## 一、核心机制

人物生命感由五项因果共同产生：

```text
具体人物状态
→ 正在发生的事件或关系
→ 摄影机以有动机的位置介入
→ 人物与环境互相留下影响
→ 光线、皮肤、发丝、衣料和空气按自身材质响应
```

画面不需要五项平均用力。承重的是人物安静表情时，动作可以很小；承重的是奔跑、争执或风雨时，环境响应可以更强。真正的不变量是：每个被写进提示词的摄影、美术和光学手段，都能回到人物此刻的处境，而不是独立制造“高级感”。

`生命感` 不等于大笑、伸手、奔跑、近距离、高饱和、强逆光、老人戴墨镜、儿童拿风车，也不等于每张脸都直视镜头。人物可以疲惫、迟疑、平静、冷淡、衰老、狼狈或主动静止；只要观众能推断这一刻从哪里来、正发生什么、还会往哪里去，画面就有时间和生活。

## 二、两种工作模式

### 2.1 普通照片摄影升级

升级的目标是让原图的观看关系更准确，不是借“美学提升”重新选角、换戏或编造生活。动手前先建立两栏：

```text
硬锁：人物身份、年龄层、可识别脸部关系、原有表情方向、主要姿势或动作、服装与关键配饰、主要道具、正在发生的事件、场景类型。
开放：裁切、观看距离、摄影机高度与侧别、前景侵入、曝光、光比、景深、色彩层级、背景退让、局部材质和有来源的光学效果。
```

原图本身存在技术事故时，可以修复模糊、曝光、杂乱背景、肢体边缘和材质，但不能把修复偷换成改脸、改年龄、改表情、改动作、改服装或改事件。任何硬锁发生变化，都应明确标记为“重新创作”，不能继续称为原图升级。

原图信息不足时，先减少新增设定，不靠模型猜一套更漂亮的人生。无法确认衣服纹样、手中物件或背景地点时，使用保守、兼容原图的描述；不能为了画面丰富凭空增加品牌、职业、亲属关系或剧情道具。

### 2.2 原创人物人像

原创人像先确定人物是谁，再确定这张图截取哪一个不可替换的时刻：

```text
前一瞬：刚发生什么，留下哪一项可见痕迹。
当前瞬间：人物正面对什么，并选择怎样回应。
后一瞬：身体、视线、道具、环境或光线正朝哪里继续。
摄影机关系：摄影机为什么能站在这里，人物是否意识到它。
环境回声：空间怎样被人物影响，又怎样反过来作用于人物。
```

不要求把五项作为标题输出。它们是内部检查，正式提示词仍写成连续自然语言，并只保留当前画面可见、可推断的承重证据。

## 三、前后帧可推断性

静态图的时间感来自未完成状态，不来自把“动态感”写进形容词。至少让一项证据同时指向过去与未来：

- 身体：重心尚未完全落稳、肩颈刚从用力中松开、呼吸正在回落、手指刚离开物体或即将握紧。
- 视线：目光正在追随画外对象、刚从某处移回、或停在一个将触发下一动作的位置。
- 衣料与发丝：保持人物上一动作或环境风向留下的惯性，不作为无来源飘带。
- 道具：杯中水面仍有细波、门仍在回摆、纸张一角刚被按住、刀鞘与手的接触处仍有受力。
- 环境：脚边水花、扬尘、植物回弹、窗帘位移、光斑移动、蒸汽消散或人群视线继续证明事件。

安静人物同样可以有前后帧。老人坐在窗边不需要强行挥手或大笑；杯口蒸汽正在变薄、手掌刚从杯壁离开、眼睛仍停在窗外刚经过的人影，就足以建立时间。若所有元素都处于最完整、最稳定、最正面的展示状态，画面通常会退化成摆拍或图库照。

## 四、人物、摄影机与环境三方闭环

三方关系各自回答一个问题：

```text
人物：他正在回应什么，选择做什么或选择不做什么。
摄影机：观众站在哪里，为什么能获得这个距离、角度和信息权限。
环境：人物的动作怎样改变空间，空间又怎样改变人物的身体、衣料、皮肤、声音或情绪证据。
```

摄影机不是隐形参数。贴近会让呼吸、皮肤和迟疑变得可读，也可能形成冒犯或亲密；隔着门框、车窗、人群或前景观看，会改变观众的信息权限；略低机位、侧后跟随、人物主动贴近镜头，都必须有事件或关系动机。异常焦段、鱼眼、旋焦和贴脸透视只有在它们准确改变人物与观众的距离时才使用。

环境不能只是题材壁纸。风要改变发丝、衣角、呼吸或尘雾；水要改变皮肤、布料、反光和动作阻力；人群要通过让路、回头、挤压或忽视回应人物；室内光要来自窗、灯、屏幕或反射面并落到相应材质。若人物删掉后背景仍是完整风景海报，或背景删掉后人物仍是同一套通用姿势，人物与环境通常没有真正发生关系。

## 五、受控不完整

裁切、遮挡、轻微失焦、运动模糊、透视变形、边缘曝光溢出和不平衡构图都可以制造在场感，但必须先锁定决定性证据：

```text
必须保住：人物识别、承重表情、动作接触点、关键道具或产品结构、主情绪所需的身体关系。
允许退让：无关背景、非承重肢体边缘、次要装饰、重复信息和不承担身份的空间细节。
```

受控不完整的判断标准不是“不工整就高级”，而是缺掉的内容是否让观众更靠近决定性瞬间。窗框压住画面边缘可以成立，随机挡住眼睛不成立；奔跑时鞋尖局部出画可以成立，产品使用图把按钮和接触方式裁掉不成立；浅景深让背景人群退让可以成立，让人物两只眼睛都失焦不成立。

## 六、光线、光学效果与材质分区

### 6.1 光学效果四步门

焦散、色散、旋焦、柔光、漏光、鬼影、玻璃折射、水面反射和边缘光晕写入前依次回答：

```text
来源：由哪一种光源、介质或镜头条件产生。
区域：只作用在哪个边缘、前景、玻璃、水面、发丝或背景。
交互：它怎样改变人物、空间或信息，而不是盖一层滤镜。
衰减：离开来源后怎样减弱，不扩散到整张图。
```

每张图不默认需要光学效果。需要时优先选择一个主要效果，其他效果只在物理上共存且不争抢人物时出现。色散通常只在高反差边缘、透明介质或画面边缘局部可见；水波焦散只落在能被反射或折射照到的皮肤、墙面或衣料；旋焦只改变背景运动组织，不能把人物五官一起扭曲。无法说明来源和区域的效果直接删除。

### 6.2 皮肤与湿润状态

干燥皮肤以真实微纹理、柔润哑光或缎面漫反射为基线，高光只在额头、鼻梁、下眼睑、唇部、颧骨或受光转折等局部出现，并随年龄、妆效、环境和角色身份变化。禁止用全脸同亮度高光证明“生命感”，那会把皮肤生成成油膜、蜡像或塑料。

湿润场景要写清水从哪里来、落在哪里、怎样聚成水滴或薄水膜、沿什么方向流动、哪些区域被衣料或头发吸收，以及高光如何只在湿润表面增强。雨水、汗、水下和刚洗脸是不同状态；不能用同一套满脸油亮、湿发贴脸和镜面反射覆盖所有场景。

发丝按发根、发束、边缘碎发和环境作用分区。干发可以蓬松或成束，湿发会局部黏连、增重并降低飞散幅度；逆光只勾亮朝向光源的边缘，不把整圈头发均匀描白。衣料、金属、玻璃和皮肤也必须各自保持不同的反射宽度、粗糙度和受光响应。

### 6.3 治愈人像与原生直出关系

治愈人像不是低饱和、暖色、白皮、浅景深和圆形散景的固定套餐。它首先是一种低攻击性的观看关系：人物不被硬光、过强对比、拥挤背景或夸张表演逼迫，观众能在眼神、呼吸、皮肤、发丝和环境余韵中停留。具体色板、肤色、光比和焦段仍由人物身份、场景、时间和主情绪决定。

当参考结果未经后期调色却已经成立时，按 `光源 → 曝光 → 皮肤与材质反射 → 背景分离 → 景深成像` 反推，不把美感归因于 LUT。至少锁定：主光来源、方向、面积和软硬；人物脸部相对背景的曝光关系；暗侧是否保留眼睛、鼻翼、嘴角与下颌；眼神光、鼻梁和唇面高光是否与主光一致；背景靠什么明度、冷暖或清晰度差托住人物；虚化区域是否仍保留能解释空间和光源的色块。

近景人物可以采用大面积柔和侧前光塑造额头、眼睑、鼻梁、唇峰和下颌，再由较弱环境反光托住暗侧；侧后方较亮窗面、灯面或反射区可以分开发丝和肩颈。关键不是把脸照得最白，而是保住从亮面到半暗面的连续过渡、虹膜中的单一稳定眼神光、嘴唇的湿润缎光、皮肤局部微高光与毛孔基线。背景散景只承担空间和色彩平衡，不随机铺满光斑，也不比眼睛和嘴唇更亮、更锐或更饱和。

图片或首帧提示词先写最终可见的现场光色，不写 `后期提亮、后期磨皮、后期增加电影 LUT` 作为必要条件。可以使用胶片、镜头或色彩科学作为成像参考，但必须继续展开它对高光衰减、暗部色彩、肤色保护、边缘柔化和颗粒的实际影响。删除介质名称后，光源、曝光、肤质、背景分离和景深仍然成立，才说明这张图不是靠风格名碰运气。

## 七、色彩与人物差异

色彩不固定为“一主色、一对比色、一肤色”，也不默认高饱和或高对比。先判断人物与空间靠明度、冷暖、饱和度、材质、清晰度还是局部颜色差异分离，再把颜色落到具体物体和光源。高饱和可以服务节庆、青春、眩晕或商业冲击；低饱和、黑白、综合色和平光也可以承载强生命感。

人物差异不能只靠换衣服和发型。至少从年龄与生活痕迹、职业或身份、骨相比例、眉眼嘴的走势、皮肤状态、常态表情气质、重心习惯、手部动作和面对镜头的方式中选择承重差异。儿童、老人、劳动者、潮流青年和职业角色都不能被压成同一张年轻商业脸；也不能把年龄和身份简化成皱纹、墨镜、晒黑或固定道具。

批量人像要改变人物处境与主导机制，不机械规定每张必须换七项。相邻图片如果只是同一近距离大笑、同一伸手动作和同一强逆光换了服装，仍然属于同一张图的表面变体。

## 八、提示词编译

内部先完成以下判断，再编译成自然语言，不把字段名原样塞进正式提示词：

```text
人物身份与当前状态
正在发生的事件
前一瞬留下的证据
当前行为选择
后一瞬的运动或注意趋势
摄影机位置、距离与关系动机
环境对人物的作用和人物对环境的影响
光源与材质响应
必要的局部光学效果
身份 / 事件硬锁与允许摄影升级项
```

正式描述遵循 `人物状态与事件 → 摄影机观看关系 → 身体 / 视线 / 道具动作 → 环境响应 → 光线与材质 → 局部效果 → 当前停点`。这不是要求写长，而是保证每项专业词都能改变画面。提示词已经清楚时不要追加“充满生命力、抓拍感、高级、电影感”；这些总结词不能代替前面的证据。

## 九、失败修复

| 失败表现 | 根因 | 修复 |
|---|---|---|
| 人漂亮但像站桩模特 | 没有具体事件和前后帧 | 增加一项未完成动作或关系触发，并让环境保留结果 |
| 人物动作很多却显得假忙 | 多个动作没有同一目的 | 只保留一个当前行为选择，让其他身体和环境证据服务它 |
| 画面像商业棚拍，不像真实现场 | 摄影机、人物和环境彼此独立 | 改写摄影机信息权限，并让人物与空间发生接触或互相改变 |
| 为了抓拍感随机裁头、挡脸、失焦 | 把生成事故误当受控不完整 | 先列决定性证据，再只牺牲非承重区域 |
| 全图都有色散、漏光或水波纹 | 光学效果没有来源与区域 | 补来源、作用区和衰减；不能闭合就删除 |
| 皮肤过亮、油腻、塑料 | 没有区分干湿区域和反射宽度 | 恢复哑光 / 缎面基线，只保留局部高光；湿润另写水的来源与路径 |
| 普通照片升级后换了人、表情或故事 | 未建立硬锁与开放项 | 恢复身份、动作、服装、事件和场景类型，只优化摄影字段 |
| 一组人物同脸换装 | 人物差异只写服饰 | 重做骨相、五官走势、年龄状态、动作习惯和镜头关系 |
| 每张都是大笑、伸手、逆光、高饱和 | 把样片表面当底层机制 | 改变人物处境、情绪温度、观看距离和环境关系，不再复用同一动作模板 |

## 十、迁移测试

规则写完后至少用以下互异任务做内部迁移，不要求实际生成图片：

| 任务 | 应成立的机制 | 不应被强制加入 |
|---|---|---|
| 儿童奔跑人像 | 前后帧、重心、衣料与地面反馈清楚 | 固定风车、大笑、强逆光 |
| 老年人物安静状态 | 微小动作、视线与时间痕迹成立 | 墨镜、夸张皱纹、商业摆姿 |
| 咖啡馆普通照片升级 | 人物、服装、动作和地点类型硬锁，只重做观看关系 | 换脸、换衣、另编剧情 |
| 文戏首帧 | 关系压力、摄影机信息权限与环境反馈闭合 | 只靠近景和眼泪制造情绪 |
| 产品使用人物图 | 人物状态、接触方式和产品结构都可读 | 为了抓拍遮挡产品证据 |

若一条规则只有在高饱和、近距离、强阳光、东亚年轻脸或特定道具下成立，它还没有完成机制抽象，不能进入本项目默认能力。

## 十一、反复制边界

外部人像项目只用于校准人物状态、摄影关系、材质和失败诊断。不得复制其固定人物、服装、道具、场景组合、完整提示词、镜头比例、示例顺序和标志性表面效果；不得默认东亚面孔、老人墨镜、儿童风车、花市伸手、逆光大笑、高饱和或每张图加入色散。外部仓库未提供根目录许可证文件，本项目只保留独立提炼后的通用机制和批判性边界，不收录长段原文或模板。
