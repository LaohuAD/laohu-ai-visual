# 资产状态与接续参考

基础资产准备后交[视频分段规划](../../laohu-video-segmentation/SKILL.md)。卡片按原文写开始状态→变化→结束状态，普通拆装、湿污、破损不强制补状态图；基础身份与结构不重新设计。后续P需要保持时先登记需求，视频交付选择文字、成片取帧或预制图，并在本段提示词上方说明准备时机。

状态图只定义计划目标，真实结果核对后才可接续；未生成/未验收保持原状态。取帧不得提前登记成已有文件，预制图也不证明视频已经到达目标。音色身份和当场演法分开，已设计音色不冒充实际音频。

## 4.1 破坏状态与状态帧升级

视频真实生成的某一帧可以承载当前破坏、人物位置、临时光影和摄影方向，但它同时可能带入畸形手脸、错误服装、漂移结构、随机文字、运动模糊和偶然曝光。任何尾帧或抽帧先作为临时状态帧，不自动成为场景资产。

跨批次使用双参考合同：

```text
稳定场景资产：只负责原始空间拓扑、材料、固定构件与空间锚点。
稳定人物 / 服装 / 道具资产：只负责身份、结构与当前确认造型。
已验收状态帧：只负责当前破坏、站位、临时光影、摄影方向和画面相位。
禁止继承：状态帧里的畸变、错误文字、随机物、错误服装和空间漂移。
```

状态帧通过 `laohu-generation-review` 的状态帧质量门后，才可连接下一个批次。只连接一个相邻单元时保持临时参考；同一破坏状态跨多个批次、跨场次或反复调用时，才升级为正式场景状态资产，并重新整理干净的锚点、拓扑和破坏账本。状态帧不能单独替代稳定场景资产，也不能因“更连续”而强行继承明显错误。



## 首尾帧与下游运动的相容复验

实际图像进入视频前，把首帧、尾帧分别与正文首句运动及结束状态相对照：真实机位、景别、视轴、可见对象、遮挡与路径是否支持该运动起点和停点。宽景中对象已可见，不等于它们必须同时运动或同时成为第一焦点；可从外部宽景小幅推近已可见结构再回原宽景，不能为了FPV穿行虚构不可见的内部通道。仅作 style / 风格参考的图不锁对象、机位或构图，首尾帧职责则必须与真实像素相容。

不相容时向视频负责人返回合法入口或局部运动调整建议；确实需要不同视角或起始状态才补图，不能用更强文字覆盖真实图片。源或消费者变更按核心合约的依赖复验规则及 `scripts/validate_delivery_dependencies.py` 执行；工具只发现变更，专业负责人判断它是否影响引用，不另造记录表。


跨批次继承真实破坏、人物站位或临时光影时使用双参考合同：稳定人物、场景、服装与道具资产只负责身份、拓扑、材质和空间锚点；通过生成复盘验收的状态帧只负责当前破坏、站位、临时光影、摄影方向和瞬时状态。状态帧只服务一个相邻单元时是临时参考；持续跨多个批次或反复调用时才升级为场景状态资产。禁止让状态帧单独替代稳定资产，也禁止把未验收尾帧登记成正式资产。



```text
表情规则：B人物素体形象资产与M人物妆造设计资产只写中性常见表情，不写多格情绪表情；情绪表演交给视频提示词逐镜头调度。
```



常见非资产包括：一次性路人、单镜头奇观、不会回到的场景、只出现一次的入口裂隙、只用于当下画面的云雾光效。它们可以写图片提示词，但文件中必须标注为“单镜头参考图”或“画面元素提示词”，不要混进资产表。
