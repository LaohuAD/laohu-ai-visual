# 图片生成验收与封面资产交接



当图片提示词已经完成，并且用户明确要求安排生成顺序、验收已经回传的真实候选、诊断失败结果或向封面阶段交接资产时读取。正常图片提示词完成后不自动进入本 Reference，不自动要求多模型对比、A/B 实验或固定复盘。



### 8. 图片生成与验收

图片提示词准备好后，输出生成执行单：

```text
提示词版本：
目标模型：
建议数量：
保存位置：
命名规则：
生成后回传字段：
```

已有真实候选并明确进入资产验收时，按 A/B/C/D 质量等级验收。这里的 A/B/C/D 是结果等级，不是要求额外生成四组候选，也不是 A/B 实验：

```text
A：可直接进入视频参考。
B：小修可用。
C：只保留为参考，不进入视频。
D：失败，进入失败复盘。
```

验收不能只看好看，也不能只看一致性。候选图必须同时通过两道门：`审美门` 检查类型与受众适配、第一眼吸引、设计语言、视觉记忆和作品归属；`制作门` 检查身份、结构、比例、材质、多角度一致性、可运动性和参考污染。任一道不通过都不能进入 A 级视频参考；结构稳定但普通、好看但换角度崩坏、单独漂亮但不属于同一世界，都要回到资产设计而不是让视频提示词补救。

观众成品人像、人物形象图、封面主体、叙事首帧和生活方式 B-roll 英雄帧再过 `现场生命感门`：人物状态能否推断前后瞬间，摄影机是否有可信观看关系，环境是否回应人物，皮肤、发丝、衣料、湿润和局部光学效果是否按来源与材质成立。普通照片升级另查身份与事件硬锁；换脸、换年龄、换表情、换主要动作、换服装、换关键道具或另编场景，即使更漂亮也不能评 A。中性设计板、证件式校准和纯结构拆解记 `N/A`，不强行制造抓拍感。

### 9. 封面与海报

本 Skill 不再创作最终封面，只向 `laohu-cover-design` 交接可用参考：


## 首尾帧与下游运动的相容复验

实际图像进入视频前，把首帧、尾帧分别与正文首句运动及结束状态相对照：真实机位、景别、视轴、可见对象、遮挡与路径是否支持该运动起点和停点。宽景中对象已可见，不等于它们必须同时运动或同时成为第一焦点；可从外部宽景小幅推近已可见结构再回原宽景，不能为了FPV穿行虚构不可见的内部通道。仅作 style / 风格参考的图不锁对象、机位或构图，首尾帧职责则必须与真实像素相容。

不相容时向视频负责人返回合法入口或局部运动调整建议；确实需要不同视角或起始状态才补图，不能用更强文字覆盖真实图片。源或消费者变更按核心合约的依赖复验规则及 `scripts/validate_delivery_dependencies.py` 执行；工具只发现变更，专业负责人判断它是否影响引用，不另造记录表。
