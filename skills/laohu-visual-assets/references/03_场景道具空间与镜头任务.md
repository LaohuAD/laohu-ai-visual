# 场景、道具、空间与镜头任务

当已取得`场景与布景设计交接包`或锁定场景参考，需要把固定场景、多角度空间、宏大环境、巨构空间、道具结构、动态物理或镜头任务编译成稳定资产时读取。

本 Reference 负责证明已确认设计怎样不走样，不重新决定空间为何存在、哪套人物—空间关系胜出、布景为何这样陈设。缺少这些上游判断时返回`laohu-set-design`；不得用四机位、鸟瞰和漂亮S板反向冒充原创场景设计已经完成。

## 1. 场景资产基础拆解

场景资产要锁住空间、光影和剪辑连续性：

```text
场景名：
服务场次：
空间结构：
时间和天气：
主光方向：
色彩影调：
可运动空间：
需要图片资产：
不允许变化：
```

只有场景会被多次进入、多角度拍摄、跨场次复用或作为系列长期空间时，才进入场景资产表。一次性远景、一次性时空裂隙、单次天宫大景，默认先归入“场景画面元素 / 氛围参考 / 单镜头参考图”。

场景图片资产不要只做一张单视角漂亮图，也不要用四张等大图平均消耗画幅。先判断空间尺度：房间、店铺、院落、走廊、单一街角等可被一个局部总平面完整解释的空间，使用“有边界空间设计板”；城市、宫城、巨型工业区、山谷、洞窟世界、太空设施、海底聚落、巨兽驮城等无法靠四个原地旋转机位解释的环境，使用“宏大环境设计板”。两者都要有总拓扑与细节来源，但视图职责不同。

### 1.1 空间锚点与语言坐标

每个正式场景先选一个主空间锚点，必要时补一个次锚点。锚点不是“画面里最漂亮的东西”，而是跨机位仍存在、位置不易变化、能被人物接近或绕行、能让提示词说明距离与方向的空间构件。柱、门洞、固定柜体、楼梯平台、房梁、固定操作台等优先；沙发、桌子和车辆只有在布局长期固定并承担定位时才可选。

```text
主空间锚点：唯一名称、形状、材料、尺寸和不可移动位置。
次空间锚点：只在主锚点不足以消除方向歧义时增加。
入口关系：从哪个入口看见锚点，锚点位于入口哪一侧、多远。
行动区关系：站位、座位、操作区、可绕行侧和不可通行侧。
固定光源关系：光源在锚点哪一侧，投影向哪里延伸。
语言坐标句：距主锚点约多少、位于哪一方向、人物如何到达。
```

所有机位、鸟瞰和视频正文都使用同一锚点名称。正确调用是“人物站在主锚点方柱左侧约两米，面向诊室门洞”；错误调用是“人物在房间左边”，因为摄影机反打后画面左右会改变。锚点提供空间坐标，不替代人物动作、摄影机路径和当前状态。

锚点不能只是一类物品名称，必须具有可跨视角核对的视觉指纹：固定尺寸、截面或轮廓、材料、朝向、连接方式，以及一至三处位置明确的磨痕、缺口、色差、接口或接缝。先定义原点与“前方”，再定义各指纹朝向；所有机位只改变摄影机坐标和朝向，锚点本体不得移动、旋转、镜像、换材质、改变指纹位置或被复制成第二个。鸟瞰图必须能反推出每幅机位，任意两幅视图都能用同一视觉指纹证明它们围绕的是同一个锚点。

现实场景还要经过“功能密度与社会经济校准”。从人物收入、场所等级、公共/私人属性、年代和实际流程推导面积、床位数、家具数量、共享设施、生活物与磨损；不能用“干净”把公立诊室简化成一桌一椅，也不能把普通家庭病人默认放进昂贵单人病房。功能密度的目标是让场所能真实运作，不是堆杂物：每件物品要能回答谁使用、放在哪里、是否固定、会不会阻挡动线。涉及医院、学校、交通和其他现实公共空间时，优先核验现行权威标准或官方资料，再把必要事实写成空间关系。

## 2. 有边界空间设计板

有边界固定场景优先做扩展分区设计板：上部约三分之二为结构区，左侧约三分之二放 2×2 四机位，右侧约三分之一放一张高位鸟瞰 / 斜俯视总平面；底部约三分之一放固定构件、材质、颜色、表面处理和空间记忆锚点的横向细节带。

左上四机位不是四张不同气氛图，而是同一个空间围绕正面视角旋转出来的制作参考：

```text
正面视角：定义场景主入口、主构图、主要物件和纵深。
左侧视角：以正面视角向左转动 90 度，展示左侧墙面、动线和物件侧面。
右侧视角：以正面视角向右转动 90 度，展示右侧墙面、动线和物件侧面。
正面反打图：从正面视角对面看回去，展示反向空间、入口回看和人物可站位。
```

四个视角必须保持同一场景布局一致，视角逻辑正确，物体空间逻辑正确，入口、窗户、固定家具、墙角、灶台、柴火堆等关键结构能互相对应。右上鸟瞰必须能反推出四个机位的位置、朝向、入口、出口和人物动线；底部每个细节必须能在四机位或鸟瞰中找到所属结构。判断标准是：任取四机位、鸟瞰和细节带中的两个区域，都能证明它们属于同一个空间，而不是相似风格素材拼贴。

左上四机位不能写成“功能拼图”。错误写法是：格 1 饭桌、格 2 灶台、格 3 遗像桌、格 4 另一个反打空间；这会让模型生成四个相似房间，而不是同一个房间的不同方位。正确写法必须先定义一个正面视角，再说明左侧视角、右侧视角和反打图都从这个正面视角旋转而来，并让右上鸟瞰复核位置；底部细节只拆固定建筑构件和材质，不把可移动剧情道具混进去。

当核心动作发生在桌面、案板、操作台、灶台边、祭祀桌、手工台等局部空间时，先判断要固定的是空间还是物。灶房一角、门窗、墙面、光源和动线属于局部场景；桌子、案板、碗、汤圆、硬币、药碗、针线篮属于道具或家具资产。局部场景资产不能把人物手部、具体道具和动作一起塞进去；物品特写只负责材质和细节；多个资产如何摆放、谁的手从哪里进入、动作如何发生，交给分镜图、视频提示词或视频第一帧参考图处理。

当单镜头里出现“某个物品 + 某个空间”时，先问本次测试到底哪里容易跑偏：如果跑偏的是年代感、场所类型、货架 / 柜台 / 餐桌 / 教室 / 小卖部 / 商场这些空间组织方式，做场景资产；如果跑偏的是木马车、药碗、硬币汤圆、玩具车本体等具体物，做道具资产。错误写法：因为镜头里有玩具，就新增 `P10 玩具车`。正确写法：因为闪回会生成成现代玩具店，所以新增 `S7 商场玩具货架区`，用四视图固定同一个普通商场玩具过道。

## 3. 宏大环境与巨构场景资产

### 3.1 主机制与适用边界

宏大环境的观众承诺不是“看见很多东西”，而是“相信这里比人物巨大、比单镜头更深，并且能够进入、移动、继续拍摄”。它可以服务仙侠宫城，也可以服务未来都市、巨型工厂、太空港、灾后城市、天然洞窟、海底遗迹、雪山基地或现实大型公共空间；颜色、地域、年代、建筑风格和超现实程度全部是可变槽。

只有该环境会被多镜头、多区域、多场次使用，或其世界拓扑、尺度和建筑语法需要稳定继承时，才升级为正式场景资产。一次性奇观远景仍按单镜头参考图或场景画面元素处理，不能因为画面宏大就自动建资产。

宏大场景按同一 `S` 编号分成两个可选交付职责：

```text
场景形象资产：单张主视角成品图，锁第一眼轮廓、观众尺度体验、主光色、地标关系和世界气质；负责“为什么想进入这里”。
宏大环境设计资产：扩展分区设计板，锁总拓扑、地貌 / 建筑群、分区、路线、门槛、固定锚点、环境系统和细节来源；负责“这里怎样真实存在并被继续拍摄”。
```

作品只需要稳定空间、没有传播级主视觉任务时，可以只做设计资产；宏大场景既承担视觉钩子又会跨镜复用时，同编号同时交付两者。形象资产不能替代设计资产，设计板也不能假装已经证明了最终镜头的震撼感。

### 3.2 先建拓扑账本，再写漂亮画面

```text
世界边界：场景可见 / 不可见的范围，天空、地平线、地下、悬空、水下或封闭边界。
地貌与主质量：山体、岩层、城市体块、巨型机械、建筑群或自然主形的数量、相对高度和轮廓。
功能分区：核心地标、居住 / 仪式 / 工业 / 交通 / 防御 / 服务区域及其主次。
连接网络：道路、桥、轨道、阶梯、水系、廊道、升降、飞行航线和人流怎样连接分区。
门槛与揭示：观众从哪里进入，先被什么遮挡，经过何处才看到主地标。
垂直层级：地表、地下、台地、塔层、空中、云上或水下层怎样互相到达。
固定锚点：跨机位必须保留的天际线缺口、巨门、塔、桥、树、瀑布、烟囱、月台或地貌切口。
环境系统：主光、天气、雾、云、水、风、烟尘、植被、交通、人流与能源从哪里来，沿什么路径变化。
拍摄能力：建立镜头、接近镜头、门槛揭示、内部行动、反打和撤离分别在哪里完成。
```

不要求每个场景逐项写满；只保留决定世界可读性、镜头复用和连续性的关系。建筑数量可以变化，但主地标、拓扑关系、路线方向和固定锚点不能在不同视图中互换位置。

### 3.3 尺度必须被证明，不能只被宣称

`巨大、史诗、无边、万丈、震撼` 不是尺度证据。按当前场景从以下机制中选择两至四项形成互证：

```text
已知尺寸锚：人、门窗、车辆、树木、路宽、灯具、桥跨、船舶、脚手架或重复构件提供观众熟悉的尺寸。
嵌套尺度链：人物 < 门 / 车辆 < 单体建筑 < 建筑群 / 地貌；至少两级中间量，避免人物与巨物之间没有可读关系。
透视与遮挡：近处对象遮挡远处同类，轮廓与间距随距离递减，入口、道路或桥梁把视线送向主地标。
重复梯度：窗、柱、灯、层台、道路节点或人群密度沿纵深缩小，证明距离而不是装饰表面。
空气与清晰度：远处降低对比、饱和度与细节，近处保留纹理；雾层可以分段揭示高度，但不能把结构全部糊掉。
局部不可见：顶部、底部或中段被画框、云层、山体或建筑遮住，使观众感到对象超出单帧，而不是为了偷懒缺信息。
运动与时间：视频中用人物行走、车辆通过、云影扫过、声音延迟、升降过程或摄影机视差证明距离和体量。
```

尺度锚必须与巨构处于可解释的同一空间关系，并在透视、受光和遮挡上成立。前景放一个巨大人物、远处放一座建筑，可能只是在利用透视错觉；默认古装美女背影、飞鸟或同一种小人也会把所有项目做成同一张概念图。锚点应由题材与功能决定，人物不是必填。

### 3.4 空间观看语法

传统绘画中的高远、深远、平远可以转译为三种跨题材空间任务，但不能固化成中式画风：

```text
垂直压迫：从低处沿高度链向上读，适合证明塔、山、巨机和竖向城市；不等于一律超广角仰拍。
层层深入：通过门、桥、峡谷、街道、廊道和遮挡连续窥见更深空间，适合证明路线与未知区域。
横向展开：平视或高位让地平线、天际线、河谷、舰队或城市带横向延展，适合证明广度与区域关系。
```

镜头按观众任务选择：建立视角交代主轮廓与尺度；接近视角让道路或桥梁把观众带向地标；门槛揭示让遮挡在正确位置打开；内部人尺度视角证明世界可居住、可操作；构件特写证明宏观轮廓由可信材料和结构组成。不是每个资产都固定五张图，缺哪种证据才补哪种视角。

广角会扩大视野并夸张前后距离，长焦会压缩纵深，低机位可能放大高度，高位可能揭示布局；它们没有固定情绪。设计板的正交 / 轴测 / 鸟瞰用于证明拓扑，场景形象图的透视机位用于证明观看体验，不能用一张俯瞰图同时冒充两种职责。

### 3.5 宏大环境扩展分区设计板

宏大环境不使用“正面、左转90度、右转90度、原地反打”的室内四机位模板。建议版式仍保持 `主视图区 / 总拓扑区 / 细节带`，但主视图区改为有职责的空间证据：

```text
上部左侧主视图区：从建立视角、接近路径、门槛揭示、内部人尺度区中选择三至四个；每个视图标明它在总拓扑中的机位和朝向。
上部右侧总拓扑区：高位鸟瞰、轴测或分层总图，明确世界边界、主质量、分区、连接网络、垂直层级、入口出口和固定锚点。
底部细节带：只放大主视图与总拓扑已经出现的结构模块、材料、接缝、道路 / 桥梁节点、标识载体、光源、排水 / 通风 / 能源或环境交界。
```

所有视图共用同一份地貌、天际线、主地标、路线、材质、光源与天气账本。总拓扑能反推主视图所在位置，主视图能看见总拓扑里的固定锚点，细节能回到唯一来源区域。若模型无法在一张板中稳定承载全部信息，先做总拓扑与主地标，再按区域拆 `S01-A / S01-B` 子区；子区继承母场景，不另造相似世界。

### 3.6 建筑与环境语法

宏大不等于构件越多越好。先建立一套可重复但有层级的场景语法：

```text
主轮廓语法：最远处仍能识别的天际线、主形比例和一个视觉统治者。
次级质量语法：两至四种辅助体块怎样围绕、服从或对抗主形。
结构 / 功能语法：建筑、机械、地貌为什么能承重、通行、排水、供能、防御或举行仪式。
模块语法：窗、柱、桥、轨道、屋面、塔节、岩层、植被或机械单元怎样重复并随尺度变化。
材料与老化语法：材料怎样连接、受力、积水、磨损、反射、长苔、积雪或留下使用痕迹。
文化与时代语法：只有可追溯事实进入硬锁；商业案例和幻想二创只提供构图方法，不能证明建筑史实。
```

真实构件颗粒可以提高可信度，但不能把某一传统、地域或软件词汇当作所有巨构的通用答案。中式历史建筑、宗教空间、少数民族建筑或文化遗产需要核验来源、时代、结构与使用语境；不明构件和符号标记待核验，不用“高级东方”掩盖事实缺口。

### 3.7 疏密、留白与破格

宏大场景需要主次，不需要全画面同密度。先确定一个主地标、一个主要尺度关系和一条进入路径，再决定哪里密、哪里普通、哪里留空。云海、天空、水面、荒原、暗部和雾区可以承担负空间，让轮廓与尺度更清楚；不能把留白机械固定为某个百分比。

反重力、巨型器物、共生建筑、异常天体、倒悬水流或结构错位都只是“世界异常”的候选。只有当它能改变世界规则、路线、受力或观众承诺时才加入，并写清它如何存在；不强制每张图有一处破格，也不固定占画面15%。若异常只是一件漂亮装饰，它进入风格可变槽，不进入场景硬结构。

### 3.8 提示词编译与验收

正式场景提示词按因果顺序压缩：

```text
世界与功能前提
→ 地貌 / 主质量与总拓扑
→ 主地标、次级质量和连接网络
→ 观众进入位置、机位与尺度证明
→ 前中后景或垂直层级怎样展开
→ 建筑 / 环境语法、材料与固定锚点
→ 时间、天气、光源与空气如何作用
→ 人流、交通、水、风、云、烟或机械怎样提供时间证据
→ 镜头最终看见的空间结果
```

最低质量门：

- 删除 `宏大、史诗、震撼、仙境、电影感` 后，画面是否仍能通过尺度链、拓扑、透视、遮挡和材质成立。
- 形象资产是否形成一个清楚主轮廓、尺度体验与进入诱因，而不是平均铺满所有建筑。
- 设计资产是否能回答“从哪里进、怎样走、哪里转向、哪些区域相连、哪些固定锚点跨镜保留”。
- 人物、车辆、飞鸟、窗格、道路等尺度锚是否与主场景处于可信空间，而不是贴图式装饰。
- 建筑群是否共享结构、模块、材料、时代和世界规则，还是不同素材库拼贴。
- 远景是否保留必要轮廓，中景是否证明路线，近景是否证明材质；空气透视没有把关键结构全部吞掉。
- 动态环境是否有来源、路径、速度与作用对象，并能给视频留下运动方向和声音空间。
- 设计板的每个主视图是否能在总拓扑找到机位，细节是否能向上找到唯一来源。

常见失败与最小修复：

| 失败 | 根因 | 最小修复 |
|---|---|---|
| 巨构像桌面模型 | 只有“大”字，没有中间尺度 | 补已知尺寸锚与至少两级尺度链，增加道路 / 门窗 / 重复构件梯度 |
| 画面很满却不震撼 | 所有体块同权重 | 只留一个主地标，降低次级质量对比，恢复天空 / 水面 / 暗部负空间 |
| 四张图像四个世界 | 只统一风格，没有拓扑 | 先锁总拓扑、天际线缺口、路线和固定锚点，再标每个机位坐标 |
| 只有鸟瞰，没有代入 | 设计图替代了观看体验 | 补接近路径或门槛揭示视角，让观众从地面尺度进入 |
| 只有人物背影才显大 | 比例尺模板化 | 换成题材真实锚点，并用遮挡、重复梯度、空气层次或运动时间共同证明 |
| 建筑像随机贴图 | 没有结构与模块语法 | 锁主轮廓、次级体块、连接方式、重复模块和材料老化规则 |
| 奇观不可拍、不可走 | 只设计表面，没有路径 | 补入口、连接网络、垂直交通、行动净空和镜头可进入区域 |
| 所谓东方巨构变成符号堆砌 | 把文化标签当结构事实 | 核验来源与时代，只保留可证明构件，幻想变化放到世界规则层 |

## 4. 道具资产拆解

道具必须有故事功能：

```text
道具：
第一次出现：
推动什么信息：
人物为什么选择它，而不是相邻的其他物品：
谁拥有 / 控制 / 争夺它：
开场位置、朝向、容量与支撑面：
允许怎样拿取、递交、移动、放置或破坏：
可信落点与下一状态：
材质和尺寸：
特写需求：
是否影响人物动作：
后续视频用途：
```

道具设计同时服务物理可信与叙事选择。桌上有什么，由人物数量、家庭或场所条件、时段、用途和生活习惯决定；镜头重点操作什么，由人物目的和场次转折决定。家庭饭桌可以有主菜、配菜、汤饭与餐具形成生活可信，但只有真正改变人物选择、身体代价或关系控制权的那一件进入承重近景。不能因为剧情只写一盘肉，就让整桌像尚未开饭；也不能为了“丰盛”平均展示所有菜，冲淡承重道具。

临时剧情道具不必全部升级为稳定资产，但必须给下游可执行的状态合同。凡是被人物拿起、递交、争夺、隐藏、消耗、破坏或跨镜继承的物品，至少交接身份、数量、开场支撑、控制者、可握 / 可托位置、移动净空、可信目的地与结束支撑。道具结构图能证明“它是什么”，不能替视频提示词决定“人物为什么现在碰它、怎样把它从这里移到那里”。

正式道具资产采用中性偏灰摄影棚和稳定基准线，按结构风险展示左前方45度、正面、侧面、背面及必要的顶部、底部、开启、握持、接触或文字特写。多视图固定同一件物品的轮廓、比例、材料、颜色、接缝、活动件、文字 / Logo、磨损和使用方向；特写只能放大主视图已经存在的部位。仅在当前镜头一次出现、不会跨角度或被操作的简单物品继续留在视频正文。

纸张、屏幕、包装、证件和仪表在建资产前先选择唯一可读性分支。若观众必须读取正面，资产和后期共同负责真实版式、准确文字、显示安全区与镜头保持时间；若剧情只需要“这是一份报告/票据”而不让观众读，摄影机只看无印刷背面、边缘、折痕、纤维、受力弯曲和湿痕，印刷面贴桌、朝角色或背离镜头。禁止生成半可读伪字、镜像字、透出的表格块或一张纸同时承担多份不同报告。视频正文必须继承同一分支，不能资产用背面、镜头又突然正面特写。

## 4.1 破坏状态与状态帧升级

视频真实生成的某一帧可以承载当前破坏、人物位置、临时光影和摄影方向，但它同时可能带入畸形手脸、错误服装、漂移结构、随机文字、运动模糊和偶然曝光。任何尾帧或抽帧先作为临时状态帧，不自动成为场景资产。

跨VID使用双参考合同：

```text
稳定场景资产：只负责原始空间拓扑、材料、固定构件与空间锚点。
稳定人物 / 服装 / 道具资产：只负责身份、结构与当前确认造型。
已验收状态帧：只负责当前破坏、站位、临时光影、摄影方向和画面相位。
禁止继承：状态帧里的畸变、错误文字、随机物、错误服装和空间漂移。
```

状态帧通过 `laohu-generation-review` 的状态帧质量门后，才可连接下一个VID。只连接一个相邻单元时保持临时参考；同一破坏状态跨多个VID、跨场次或反复调用时，才升级为正式场景状态资产，并重新整理干净的锚点、拓扑和破坏账本。状态帧不能单独替代稳定场景资产，也不能因“更连续”而强行继承明显错误。

## 5. 镜头任务拆解

镜头任务必须写成动作或信息变化：

```text
主角发现异常。
观众第一次看见关键道具。
两人的关系距离发生变化。
角色试图隐藏情绪但失败。
```

禁止写：

```text
表现高级感。
营造氛围。
展示人物悲伤。
```

必须输出四张表：

1. 角色资产表。
2. 群像人物资产表。
3. 场景资产表。
4. 道具资产表。
5. 镜头任务表。

每个资产都要说明服务哪一场戏或哪个镜头。

## 6. 外部方法校准与反复制边界

本分支审计 `irenerachel/celestial-architect-skill` 提交 `81c589573b69fdec0119368b03e4b6c9efeb58f4` 的 `README.md`、Skill 包、四个 Reference 和四张公开样片。仓库未声明许可证，因此只独立吸收可由摄影、空间设计和项目样片共同验证的机制：真实结构颗粒、尺度链、垂直 / 深入 / 横展三类空间组织、总图与体验视角分责、疏密层级、世界异常与结构语法。不得复制其长段原文、完整提示词、固定三组输出、人物设定、构件清单或白玉京风格配方。

外部项目的 `白玉、朱柱、金瓦、云海、古装美女背影、暖金自然光、钴蓝线框、固定密均疏三组、每图必有异象 / 破格` 全部属于垂直产品的可变槽，不进入本项目通用默认。传统“三远”只被转译成垂直压迫、层层深入和横向展开三种空间任务，不把古典理论名称强塞进现代、科幻、现实或其他文化题材的模型正文。

理论校准：Yale Film Analysis Guide 的 Cinematography 条目说明镜头尺度会改变人物与环境关系，低 / 高机位会改变观看关系，广角夸张前后距离而长焦压缩纵深；Blender 官方 Cameras 文档区分透视与正交投影，并说明焦距 / 视场角控制进入画面的空间范围。它们支持“先选观看与空间任务，再选机位和投影”，不证明低机位、广角、雾、人物背影或任何固定画风天然更高级。
