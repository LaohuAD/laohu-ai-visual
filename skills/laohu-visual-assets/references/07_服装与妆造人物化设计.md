# 服装设计包到W/M资产编译

本 Reference 只在服装原创决定已经由 `laohu-costume-design` 完成，且人物主视觉图已经由人工确认，或用户提供了有权使用的完整角色成图与服装设计正文后读取。它负责把角色成图反向拆成W服装与M妆造资产，不再从零发明人物服装或妆发。

## 一、入口合同

可靠输入必须能同时回答“成品看起来是什么”和“不可见结构怎样补足”：

```text
服装方向确认记录：主要人物已经完成人工定案，或任务属于合法AI自动定案 / 锁定设计；记录胜出编号、保留删去项、允许补全和重开条件。
人物主视觉图：已经人工确认的角色成图，包含可见的脸身、服装、妆发、人物关系与整体质感；不可见的背面、内里、鞋履和侧面妆发由专业正文与制作板补足。
服装正文：服装设计Skill交付的模型可用描述、色卡、主件模式与不可见结构补充。
妆造正文：人物设计Skill交付的模型可用妆容、发型、发饰与侧背面补充。
B / 阶段素体：只在W需要上身承托或M组合完整人物时提供脸身与体型。
```

缺少可靠输入时停止编译：主要人物仍为`待服装方向确认`时先返回确认节点；缺服装正文返回`laohu-costume-design`；缺妆造正文返回`laohu-character-design`；缺少会改变人物、世界或版权边界的事实返回总控。不得让视觉资产根据一张未经确认的漂亮图、旧提示词或抽象分析自行补设计。服装方向确认决定设计，F人工选定决定成图实现，两者不能互相代替。

## 二、W服装资产

W回答：写真中这套衣服拆开以后由什么组成，正背面、内里、材料和配饰怎样稳定复现。它继承写真与服装正文，不重新选择轮廓、比例、主件结构、材料关系、色彩秩序和文化来路。

正式W提示词只由三段组成：

```text
1. 参考引用：同编号F写真母图；含上身展示时再引用B或阶段素体。
2. 资产转换框架：把写真中的服装转换成平铺 / 承托拆解板，规定正背、单品、材料、鞋履、配饰和细节区域。
3. 服装设计正文：直接接入上游已经决定的服装、色卡与不可见结构补充。
```

纯平铺W不引用B。只有框架包含完整上身效果时，才引用B或当前阶段素体作为体型承托；人物身高、体重、三围、头身比和五官不得进入W画面，成衣规格只能标注服装。

制作板模式直接继承服装设计交接包的主件判断：可独立穿脱的主件使用`可拆套装分件拆解板`；从上身连续到下摆、拆开会丢失整体关系的主件使用`连续主件完整展示板`。视觉资产不能再次判断或借框架修改设计。

## 三、已确认设计的零改动编译

用户明确锁定设计时，不生成3—5个新方案，也不借“人物化、结构优化、巅峰门”修改服装本体。编译前后对照：

```text
必须相同：主轮廓、比例、长度、领与门襟、层次、主次材料、色彩面积、图案位置、装饰数量和关键穿法。
允许补全：参考未展示但制作与活动必需的背面、内里、接缝、扣合、鞋底、材料微距和活动余量。
禁止新增：改变身份、阶层、文化来源、时代、阵营或视觉记忆的结构和装饰。
```

补全信息与可见参考冲突时，以确认参考为准并标记缺口，不能悄悄改成更易生成的设计。背面、内里、扣合或活动余量的补全只要会改变正侧面可见轮廓、运动轮廓、装饰数量、层次露出、关键穿法，或新增任何在背面可见的后开衩、结构线、接缝节奏和装饰，就属于高风险缺口：停止猜测并请求补充参考或确认；不会影响锁定外观的纯工程补全可以暂定，但必须标记为`推定制作信息`，不能冒充参考已展示事实。

## 四、季节与阶段编译

设计包给出衣橱关系，W把它落实为当前节点的绝对终态。身体阶段决定版型、尺码和松量；季节环境决定层数、覆盖与材料性能；人物身份决定设计语言；场景动作决定开合与活动余量，四类原因不能互相替代。

春夏跨度至少从层数、覆盖面积、面料克重与表面、袖裤长度、鞋袜和穿法中共同改变三项。室内恒温、职业制服、医疗或修炼防护允许保留覆盖，但必须写入环境热条件。生成正文只写本节点应出现的正向终态，不把被排除的冬装名词重新召回。

## 五、M妆造设计资产

M回答：写真里已经成立的完整造型，怎样拆成可在左前45度、正面和背面稳定复现的妆容、发型、发饰与穿着关系。

```text
参考引用：F写真母图 / B或阶段素体 / W服装资产。
妆造补充正文：眉形、眼妆、睫毛、肤面、腮红、唇色、发型轮廓、发缝、侧背发束、发饰位置和穿着方式的具体终态。
资产转换框架：左前45度、正面、背面三列；上部头肩妆发特写，下部同角度无头穿着身体。
```

M不重新定义W的领口、口袋、材料、版型和色彩关系，也不靠妆造遮住阶段素体已经确认的身体变化。写真负责整体答案，B负责脸身，W负责衣服，妆造补充正文负责写真没有展示清楚的侧背结构，视觉资产只负责组合。

M使用 `laohu-visual-assets/SKILL.md` 的16:9受控定妆设计板：左前方45度、正面、背面三列纵向组合；每列上排是唯一对应的头部与肩颈特写，下排是从颈根 / 肩线到鞋底的无头穿着身体，头颅完整位于下部画框之外，覆盖接缝落在颈肩或领口附近。

## 六、编译拒绝门

- 没有服装设计交接包或确认参考，却直接批量写主要人物W。
- 主要人物仍待服装方向确认，却先生成正式F，或用F的随机漂亮结果替代服装定案。
- 视觉资产重新发明胜出设计，或把淘汰候选混进W。
- 已确认设计在“补背面、补活动余量”过程中改变主轮廓、配色或装饰。
- W写最终妆发、表情和剧情动作，M重新设计服装工程。
- 季节只换颜色或短袖，厚重材料与盛夏状态并存却没有功能解释。
- 普通、朴素服装被当作无需W，或为了证明人物化擅自增加徽章、补丁和象征物。
- 一次性不可识别背景群众被机械拆成个人B / W / M；反过来，等级承重群像又没有远景可读的服装语法。
- 制作板格式完整就宣布设计优秀；格式只通过底线门，服装胜出结论以设计交接包为准。

## 七、交回设计负责人的条件

只有出现以下证据才返回 `laohu-costume-design`：胜出结构无法完成关键动作；材料行为与世界条件冲突；多人并排后剪影同质；真实生图持续证明记忆锚点在目标镜头距离不可读。纯版式、引用、文字伪影、视角丢失、细节格和单次生成崩坏留在视觉资产修复。
