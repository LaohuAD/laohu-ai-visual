# 服装与妆造人物化设计

当服装虽然合理却过于普通、人物之间只有职业差异、长时间跨度只换尺码不换季节，或妆造只是把衣服穿回人物而没有形成记忆点时读取。本 Reference 负责把剧本中的身份、选择、关系、时间和动作，编译成服装与妆发的可见设计；它不替代 W / M 的固定制作板格式，也不把人格判断写回素体。

## 一、证据与适用边界

以下是可以进入项目的专业共识：

- 影视服装的首要任务是服务叙事并建立可信人物；色彩、纹理和轮廓都是角色信息，而不是独立装饰。伦敦艺术大学的电影服装研究将服装设计概括为把剧本中的人物落实为可信的银幕人物，并以色彩、纹理和轮廓共同填充画面。[UAL：Reel People—Character, Cinema & Costume Design](https://ualresearchonline.arts.ac.uk/id/eprint/7871/)
- 服装及其变化会向观众传递人物的性格、态度、地位和旅程；差异可以由轮廓的高、方、窄、厚以及颜色和质感建立，不必依赖奢华或奇装异服。[RSC：Richard II Teacher Pack](https://cdn2.rsc.org.uk/sitefinity/education-pdfs/teacher-packs/edu-richardii-teacherpack-2013-3.pdf?sfvrsn=2)
- 服装设计不是先画造型再补材料。高质量服装需要同时判断身体结构、功能、轮廓、线条、材料与施工方式；这些变量彼此作用。[Cornell：Fiber Science & Apparel Design 课程目录](https://courses.cornell.edu/courses/fsad/)
- 面料不是颜色贴图。面料的物理属性会决定服装怎样贴合、撑起、垂坠、伸展和随身体运动，因此材料必须以可见行为进入设计。[Museum at FIT：Fabric in Fashion](https://exhibitions.fitnyc.edu/fabric-in-fashion/)
- 热舒适同时受环境、活动与服装隔热影响；夏季设计不能只写短袖，还要处理层数、覆盖、空气层、面料重量和湿热交换。[Cornell Ergonomics：Thermal Comfort](https://www.ergo.human.cornell.edu/studentdownloads/DEA3500notes/Thermal/thcomnotes1.html)
- 妆发的主要目的同样是创造人物，并与服装、导演、摄影和故事环境共同工作；细小且连续的变化可以比夸张造型更可信。[Academy：Costumes & Makeup Activities Guide](https://www.oscars.org/sites/oscars/files/costumes_and_makeup_activites_guide.pdf)；[BAFTA Film Sessions：Make-Up & Hair](https://www.bafta.org/media-centre/press-releases/bafta-film-sessions-2022-make-up-hair/)

这些来源能支撑“服装与妆发应共同服务人物、身体、动作、材料和时间”的机制，不能替项目决定某个人必须穿什么颜色，也不能把舞台、秀场或历史服装的固定外形照搬进当代纪实短片。

## 二、从剧本到人物化设计

先建立人物化设计卡，再写 W 或 M：

```text
剧本证据：人物做过什么选择，承受什么关系压力，处于什么社会位置。
外部身份：年龄、职业、阶层、地区、机构规范和家庭购买能力。
身体与动作：当前阶段体型、活动、坐卧、抬臂、奔跑、搀扶、出汗与穿脱要求。
时间环境：故事日、季节阶段、室内外、温湿度逻辑和直接连续关系。
公众形象 / 私下状态：人物想给别人看见什么，独处时又怎样穿。
轮廓动词：收、撑、垂、包、开、贴、叠、拖、提中的一至两个，不用抽象气质词代替。
比例决定：肩线、腰线、衣长、袖长、裤长、露肤和上下装面积怎样组织。
色彩关系：主色、近似色、对比点和明度秩序；不是只列三个色名。
材料行为：挺 / 垂、干 / 润、细 / 粗、透 / 密、轻 / 重、伸展 / 回弹、吸湿 / 快干怎样被镜头看见。
结构与工艺：领口、门襟、口袋、接缝、包边、里布、扣合和磨损怎样服务身份与动作。
主要记忆锚点：一个远看可认的轮廓、比例或色彩关系。
辅助记忆锚点：一个近看可记的结构、穿法、妆发或饰品；没有必要时不增加。
阶段保留 / 阶段替换：什么跨造型不变，什么因时间、场景和人物弧线变化。
平均答案：同类人物最容易被写成什么；本案为什么不取。
```

人物化不是把性格形容词翻译成图案。`勇敢 → 红衣服`、`温柔 → 粉色`、`医生 → 白大褂加眼镜`都只是类型捷径。正确做法是从行为证据推导可见关系：一个长期照料别人的人，可能更需要易卷袖、深口袋、耐洗材料和迅速穿脱；一个习惯克制的人，记忆点可以落在重复的窄边、扣合秩序或固定色彩关系，而不是夸张装饰。

## 三、角色记忆系统

### 3.1 一个主锚点、一个辅锚点

主要记忆锚点必须在中远景仍可读，优先从以下位置选择一项：

- 轮廓：短而有支撑、窄长下垂、上宽下直、开放前襟、固定腰线。
- 比例：特定衣长、袖长、裤脚位置、上短下长或内外层露出比例。
- 色彩关系：深色主体加固定暖点、低饱和同色层次、冷外层包住暖内层。
- 材料关系：硬壳包软内层、挺括外轮廓配磨软接触面、粗纹理和细密包边并置。

辅助记忆锚点只在近景补充一项：固定形状的拉链头、反复出现的窄色压线、旧纽扣、袖口穿法、发缝、眼镜、胡须边界、发饰或一个有因果的修补痕迹。两个锚点都必须能说明人物或使用历史；去掉后人物没有变弱，就不要加。

### 3.2 连续不是每套一模一样

连续锚点可以跨服装迁移，但表现形式要随场景变化。例如同一名儿童的暖赭色细节点，在外出服上可以是拉链织带，在家居服上可以是侧缝套结，在校服不能私改时则退到鞋带结、穿法或发型；不能为了“统一”破坏学校、医院或职业规范。

造型变化至少改动两个相互支持的维度，才能让观众读到阶段：`层数 + 面料重量`、`轮廓松量 + 袖长`、`发型秩序 + 衣服穿法`。只换颜色容易变成同一套衣服的重染，只换配饰容易变成贴纸式记忆点。

## 四、春到夏的90天造型链

季节变化先写进故事时间账本，再传到 W 与 M。以下是适用于当代生活题材的叙事分段，不是固定气象标准：

| 阶段 | 服装证据 | 材料与结构 | 妆发与穿法 |
|---|---|---|---|
| 初春 | 两层或可拆外层，手腕与脚踝覆盖较多 | 轻薄防风棉锦、细针织、较密平纹；保留空气层 | 发型较完整，外层开合能应对昼夜温差 |
| 暮春 | 外层可以脱去，单层长袖与短袖并存 | 中轻克重棉、珠地、薄斜纹；袖口可卷、前襟可开 | 袖口、领口和鞋袜开始减量 |
| 初夏 | 以单层短袖为主，裤装缩短或变轻 | 薄针织、细平纹、泡泡纱或轻量混纺；腋下、背部和腰腹留空气通道 | 发型减少厚重造型，穿法允许散热但仍符合身份 |
| 盛夏 | 最少必要层数和覆盖，室内空调场景按实际补一件轻层 | 低克重、透气、吸湿或快干，减少厚里布和大面积黏肤 | 汗湿、贴发和素颜只能作为镜头状态，M锁可持续的夏季整理基线 |

春夏跨度不能用花朵、绿色、阳光或短袖单独证明。至少同时改变：`层数 / 覆盖面积 / 面料克重 / 表面纹理 / 袖裤长度 / 鞋袜 / 穿法`中的三项。室内医院可以因空调保留长裤或薄外层，但必须是轻量、可穿脱的夏季系统，不能继续使用抓绒、厚卫衣和保暖长外套。

进入可复制图片提示词时，只写本阶段应当出现的正向季节终态，例如“单层短袖、膝上薄短裤、赤足、低克重透气棉、腋下与腰腹保留空气通道”。冬季衣物名称、转凉、取消保暖等排除性说明只留在设计判断和验收表，不进入生图正文；否则模型可能把被排除的名词仍当成视觉候选。

长时身体变化和季节变化同时发生时，先拆变量：身体阶段决定版型、尺码和松量；季节阶段决定层数、覆盖和材料性能；人物身份决定设计语言；场景动作决定开合与活动余量。不能让“胖了所以穿短袖”或“夏天所以换大码”替代因果。

## 五、W与M的职责分界

### W服装资产

W回答：这套衣服本身是什么，为什么属于这个人物和阶段，怎样制造，怎样活动。每条 W 在固定制作板合同之外必须明确：

```text
季节阶段：初春 / 暮春 / 初夏 / 盛夏，以及室内外关系。
人物化设计锚点：主锚点、辅锚点及其剧本依据。
连续继承：从上一套保留什么关系。
阶段替换：因季节、场景、身体或剧情替换什么。
平均答案回避：本套怎样避免成为任何同龄 / 同职业人物都能穿的默认套装。
```

W可以设计服装自身的尺寸、衣长、松量、鞋码与结构参数，但不显示人物身高、体重和三围；不写最终发型、妆面、表情和剧情动作。

### M妆造设计资产

M回答：同一个人把已确认 W 穿上后，怎样通过妆发、穿法、配饰和身体表面形成当前气质。每条 M 必须明确：

```text
妆造记忆锚点：发型 / 发缝 / 眼镜 / 胡须 / 妆面 / 饰品中真正承重的一至两项。
穿着方式：扣到哪里、卷不卷袖、衣摆怎样处理、鞋带和裤脚怎样落位。
阶段变化：本阶段相对上一阶段增加、减少或松动什么。
克制边界：哪些细节必须保持真实生活尺度，不抢走表演。
```

M不重新发明 W 的领口、口袋、材料和版型，也不靠妆造遮住阶段素体已经确认的身体变化。纪实人物不等于完全不设计；设计可以细，但必须像人物自己长期形成的选择，而不是造型师临时贴上去的符号。

## 六、普通、复杂与华丽服装

普通服装的难点不是细节少，而是每个决定容易落入默认值。普通服装也要比较至少三个方向，例如：`规整压线的克制感 / 洗软层叠的生活感 / 功能口袋与可卷袖的照料感`，再根据剧本选择，不把“白T、蓝裤、运动鞋”当完整设计。

复杂或华丽服装不靠形容词密度证明高级。先建立轮廓和比例秩序，再决定主次材料、工艺焦点和视觉休息区；一个主焦点之外的装饰必须服从层级。W制作板需要用正背面、内里、结构拆解、材料微距和活动余量证明复杂性，不用长篇文字解释“精美、贵气、高端”。

## 七、生成前拒绝门

出现以下任一情况，退回人物化设计卡，不进入批量生图：

- 把角色名换成同年龄、同职业的另一个人，整套描述仍完全成立。
- 只有颜色名和单品名，没有轮廓、比例、材料行为、结构和穿法。
- 人物记忆点只能在文字解释中成立，远景与近景都没有对应视觉证据。
- 为了有记忆点堆入两个以上抢眼装饰，或把贫困、肥胖、疾病和职业做成脸谱。
- 春夏跨度只换短袖或色彩，厚卫衣、抓绒、保暖外套和盛夏状态同时存在且没有空调 / 医疗功能解释。
- W写妆发和表情，M重新设计服装结构，B或阶段素体承担戏服。
- 妆发变化只写更疲惫、更自然、更精致，没有发丝、发缝、轮廓、光泽、肤质或穿法终态。

验收时做两个盲测：遮住标题，看四名主要人物能否只凭轮廓、色彩关系与妆发主锚点区分；把同一人物各阶段并排，看锚点是否仍是同一个人、季节和状态是否单向推进。两项都失败，说明设计仍停在“合理描述”，没有成为可用资产。
