# 风格决策与图片提示词

## 选材箴言

材料不论大小，只问能不能承重。

钥匙、杯子、旧衣和门把手并不因为私人就天然深刻；城市、山河、战争和星空也不因为宏大就天然空泛。材料的价值来自三层关系：它是否准确承接当前人物与用意，是否在画面中产生可见后果，是否能从个体经验照见更多人的公共经验。

正式选择前比较：

```text
关系承载：换掉它以后，人物关系、功能或主题是否明显变弱。
典型性：它既有当前作品的身份，又能让陌生观众凭公共经验读懂。
视觉潜力：它能否形成轮廓、尺度、动作、空间、材质或光色上的可见关系。
生成代价：模型是否能稳定生成，它是否会引出错误联想或无关细节。
```

“非它不可”不是要求每次都找一个专属小物件，而是要求材料与当前任务的关系不可随意替换。宏大用意可以选择公共尺度和集体意象，也可以用一个具体入口进入；小用意也可以借宏大环境放大。先定承载关系，再决定材料尺度，不能让“具体”把作品写小，也不能让“宏大”把人物写空。



当任务需要选择美术方向、建立作品视觉语法、竞争原创方案或编写图片提示词时读取。



### 6. 风格决策

当风格不明确或图片 / 视频 / 封面风格冲突时，给 2-3 个方向：

```text
风格方向：
适合原因：
生成风险：
角色资产继承：
场景资产继承：
视频提示词继承：
封面继承：
推荐主风格：
```

如果用户已经给定唯一且不冲突的风格，不强行展开多个方向。

风格不是讨好所有人，而是建立可识别的选择。做视觉方向时必须判断：

```text
这套视觉最想抓住哪类观众。
它主动放弃哪种审美期待。
观众已经熟悉到会忽视的同类画面是什么。
这套视觉的轻微跑调点是什么：形状、色彩、材质、构图、人物缺点、道具、光影、镜头节奏或封面第一眼符号。
跑调点是否服务世界观和作品承诺，而不是无意义怪异。
```

如果视觉方向过于平滑、平均、熟悉、模板化，即使画面漂亮，也要标记为“选择性忽视风险”。首轮测试时至少保留一个不讨好所有人的风格记忆点。

风格决策之后还要落到具体资产，不能用风格词代替设计。人物先判断选角、脸部辨识、身形体态、妆发、服装版型和角色身份；产品 / 道具先判断目标人群、价格感或使用情境、功能结构、轮廓比例、CMF 和握持 / 运动方式；场景先判断世界观空间语法、尺度、入口、动线、材质、陈设密度、光源逻辑和记忆锚点。`可爱` 不自动等于粉色圆角，`高端` 不自动等于黑金玻璃，`治愈` 不自动等于奶油暖光，`玄幻` 不自动等于蓝紫粒子。类型只规定作品要兑现的感受，不替系统完成设计。

### 7. 图片提示词

图片不是单张好看图，而是视频上游资产。每张图片提示词必须写：

```text
图片用途：
服务场次 / 镜头：
必须锁定：
允许变化：
不能继承：
可复制图片提示词：
是否可作为视频参考图：
```

`可复制图片提示词：` 后必须紧跟一个 `text` 代码块。代码块内只写可直接粘贴到图片模型的正文，例如画幅、主体、构图、光影、材质、风格和抽象质量边界。代码块外写给人看的说明，代码块内写给模型看的内容；跑偏对象和不能混用的资产写在代码块外。

图片模型代码块里禁止用引号做强调。只有画面上确实要出现的文字，才允许以文字指令写入正文，并优先使用 `标签文字为：...`、`标题文字为：...`、`正文文字为：...` 这种无引号写法。手部、表情、服装、构图、气质、风格等说明都不要加引号；否则模型可能把引号内容生成到图片上。

常见资产包括人物素体形象、按需的人物服装 / 最终造型、场景结构、关键道具、视频第一帧和封面底图。主角色不要默认输出多格表情组或角色一致性情绪网格图，除非老胡明确要求做表情测试；即便要做，也必须写成“测试参考”，不能替代已经选定的正式资产职责。

人物资产图写法：

```text
人物素体形象资产：中性灰摄影棚校准板，左侧头部正面大特写；右侧左45度、正面、背面三张全身视图；属性区锁定脸型、五官、身高、体重设计值、身体比例、基础体态和永久辨识特征，衣着只用白衣白裤或中性简单衣裤。
人物服装资产：四区服装拆解板，依次展示头部穿戴、上半身、下半身、足部的总览与局部特写，锁定版型、层次、材质、颜色、纹样、接缝、扣合、穿法和活动余量；不写发型和面部妆容。
人物妆造设计资产：显式引用人物素体与人物服装，左侧头部正面大特写，右侧左45度、正面、背面三张全身视图，锁定最终发型、妆容、身体彩绘 / 伤妆和服装穿回同一人物后的结果；M是受控定妆摄影资产，必须补背景与妆面之间的明度 / 色相对比、主光与补光方向、眼神光、睫毛分离度、腮红过渡、唇部高光、发丝边缘和服装轮廓，不得继续套用B的灰底平光校准。
表情规则：B人物素体形象资产与M人物妆造设计资产只写中性常见表情，不写多格情绪表情；情绪表演交给视频提示词逐镜头调度。
```

场景资产图写法：

```text
扩展分区场景设计板：左上 2×2 为正面、左侧、右侧和反向四机位，右上为较大的高位鸟瞰 / 斜俯视总平面，底部为固定构件、材质、颜色、连接、磨损和空间记忆锚点细节带；所有区域保持同一结构、光源和位置账本。
局部操作空间要先拆资产：空间本身做局部场景资产，桌子 / 案板 / 碗 / 汤圆 / 硬币等可移动物单独做物品资产。场景资产只锁空间结构、入口、光源和动线；物品资产只锁物品本体；手部进入方向和人物站位属于分镜或视频提示词。
```

物品资产图写法：

```text
同一件物品多角度展示，背景简洁，重点固定轮廓、比例、材质、纹理、磨损和可特写细节。
```

常见非资产包括：一次性路人、单镜头奇观、不会回到的场景、只出现一次的入口裂隙、只用于当下画面的云雾光效。它们可以写图片提示词，但文件中必须标注为“单镜头参考图”或“画面元素提示词”，不要混进资产表。
