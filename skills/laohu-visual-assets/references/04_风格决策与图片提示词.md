# 风格决策与图片提示词

## 选材箴言

材料不论大小，只问能不能承重。

钥匙、杯子、旧衣和门把手并不因为私人就天然深刻；城市、山河、战争和星空也不因为宏大就天然空泛。材料的价值来自三层关系：它是否准确承接当前人物与用意，是否在画面中产生可见后果，是否能从个体经验照见更多人的公共经验。

正式选择前比较：

```text
关系承载：换掉它以后，人物关系、功能或主题是否明显变弱。
典型性：它既有当前作品的身份，又能让陌生观众凭公共经验读懂。
视觉潜力：它能否形成轮廓、尺度、动作、空间、材质或光色上的可见关系。
生成代价：模型是否能稳定生成，它是否会引出错误联想或无关细节。
```

“非它不可”不是要求每次都找一个专属小物件，而是要求材料与当前任务的关系不可随意替换。宏大用意可以选择公共尺度和集体意象，也可以用一个具体入口进入；小用意也可以借宏大环境放大。先定承载关系，再决定材料尺度，不能让“具体”把作品写小，也不能让“宏大”把人物写空。



当任务需要把已经确认的美术风格设计交接包编译进图片提示词、检查图片是否兑现题材视觉证据，或处理单张成品图的当次画面风格时读取。作品级美术方向、题材边界和跨部门视觉语法由`laohu-art-direction`负责，本Reference不再从零重做。

## 图片任务先按控制对象分流

同一种图片模型可以完成身份、地点、道具、局部修改和叙事首帧，但五类任务需要的证据不同。正式提示词之前先决定本图唯一主要职责：

```text
身份母版：让同一人物跨角度仍可认；锁脸身拓扑、比例、稳定辨识，瞬时表演与剧情构图退让。
地点拓扑：让人物能在空间中行动；锁入口、固定锚点、方向距离、路径、遮挡和功能区，一次性站位退让。
道具结构：让物件能被操作与复现；锁轮廓、材料、连接、活动件、操作面和使用方向，广告式漂亮反光退让。
局部受控编辑：只改变已确认图中的授权区域或属性；变化区清楚，保护区可复验，整图重设计退让。
叙事首帧：让下一段视频从一个已经有压力的状态开始；锁关系阻挡、站位、视线、动作预备态、首个异常和下一变化，规格板完整展示退让。
```

模型熟悉的母型、风格和摄影语言必须服从当前任务。身份母版可以中性，叙事首帧可以遮挡和裁切；地点图要读清空间，不能只靠氛围；道具图要能解释怎样握、开、穿、装、触发，不能只拍一个英雄角度。

### 局部编辑的三权分离

局部编辑把控制分给三个位置：

```text
输入职责：已确认原图提供整体身份、构图、纹理、光线和未编辑区域基准；其他参考只提供新部件或新材料的指定属性。
界面参数：遮罩 / 选区负责像素位置与边界，编辑强度、画幅和参考权重由当前真实入口承担。
提示词正文：正向写变化区最终应看见什么，以及它怎样与邻接材料、皮肤、衣料或光线连接。
```

先列`变化区 / 保护区`，默认一次只改一个主变量。保护区要具体到可验收事实，例如同一骨相、发际线、肩线、姿态、外套裁片、背景柱位和主光方向；它不靠正文里的否定词长清单来保护。新徽章替换旧徽章时，正文写新徽章的轮廓、尺度、金属、位置、别针连接和反光如何贴合衣料；旧徽章只存在于代码块外的变更记录，不让模型再次召回。

没有遮罩、选区或可靠局部编辑能力时，明确标记整图漂移风险。可以先生成部件资产、建立合成说明或改用确定性工具；不能把“保持其他完全一致”当成已经获得像素锁定。



### 6. 美术方向继承与当次画面选择

存在`美术风格设计交接包`时，先提取本图片实际看得见的部分：主辅类型、承重证据通道、形态 / 色彩 / 材料 / 光影规则、相邻类型风险、保持与允许变化。资产层不重新给作品选择另一套方向。

当单张成品图只需在既有作品风格内选择观看方式时，可以比较2—3个当次画面方向：

```text
当次画面方向：
适合原因：
生成风险：
继承的美术方向：
本图承重证据：
允许变化：
推荐画面方向：
```

如果美术方向已经锁定且当前图片不承担新的观看竞争，不强行展开多个方向。若风格本身不明确、跨部门冲突或真实图片落入相邻类型，返回`laohu-art-direction`，不得在本Reference继续推导作品级风格。

风格不是讨好所有人，而是建立可识别的选择。做视觉方向时必须判断：

```text
这套视觉最想抓住哪类观众。
它主动放弃哪种审美期待。
观众已经熟悉到会忽视的同类画面是什么。
这套视觉的轻微跑调点是什么：形状、色彩、材质、构图、人物缺点、道具、光影、镜头节奏或封面第一眼符号。
跑调点是否服务世界观和作品承诺，而不是无意义怪异。
```

如果视觉方向过于平滑、平均、熟悉、模板化，即使画面漂亮，也要标记为“选择性忽视风险”。首轮测试时至少保留一个不讨好所有人的风格记忆点。

风格决策之后还要落到具体资产，不能用风格词代替设计。人物先判断选角、脸部辨识、身形体态、妆发、服装版型和角色身份；产品 / 道具先判断目标人群、价格感或使用情境、功能结构、轮廓比例、CMF 和握持 / 运动方式；场景先判断世界观空间语法、尺度、入口、动线、材质、陈设密度、光源逻辑和记忆锚点。`可爱` 不自动等于粉色圆角，`高端` 不自动等于黑金玻璃，`治愈` 不自动等于奶油暖光，`玄幻` 不自动等于蓝紫粒子。类型只规定作品要兑现的感受，不替系统完成设计。

#### 形式转译卡的条件性消费

只有`laohu-art-direction`已经交付胜出形式转译卡时，本 Reference才消费它；不得在资产层重新分析参考集合、重做语义最小集或另选候选。先读取`参考职责合同`中的必须保留、允许改变、不得继承和样本残留，再按结果身份编译：

- `结果图 / 编辑主视觉`：把胜出关系放进现有基础设定、氛围与画质、画面内容与构图；先写主注意力和主证据，再写支撑形式。质量、线、负形、节奏、裁切、重叠、比例、文字与再生产方式必须变成模型能画出的相对位置、尺度、边缘、密度和层级，不能把`语义最小集、关系不变量、形式转译卡`这些内部词原样投喂模型。
- `制作资产`：只继承会改变识别、材料、光影、色彩或观看重点的共同内核。B / W / M / S / A继续使用固定专业画框和结构证据，不套海报版式，不为纸感、点阵、双色、撕纸或留白牺牲身份、比例、侧背面、材料和拓扑。

形式卡与专业设计冲突时，专业对象事实和固定结构由对应人物、服装、场景负责人裁决；形式卡只能组织观看，不能改写对象本体。形式卡与注意力合同冲突时，先保住唯一生成任务和主证据，再缩减支撑形式，不能把全部形式动作平权塞进正文。

### 7. 图片提示词

先判断当前图属于哪一种结果身份：

- `结果图写真`：人物、场景、道具、产品或其他对象已经设计成立后，被摄影机拍成一张最终结果照片。F人物主视觉图属于这一类。正文内部完成`基础设定 → 氛围与画质 → 画面内容与构图`三段职责，标题可以显式，也可以融合进连续画面叙述。
- `制作资产`：为了固定身份、结构、侧背面、材料、参数或空间拓扑而制作的B / W / M / S / A / G规格板。制作资产保留自己的专业框架，不机械套三段式标题。
- `叙事成品图`：首帧、封面、剧情写真或英雄帧，按人物—摄影机—环境和决定性瞬间组织；如果它同时是一个完成对象的正式写真，可以使用结果图三段式，否则按叙事工作卡编译。

三类图的共同内核一致：对象是谁 / 有什么用途，属于什么成熟美术分布，观众先看哪里，摄影机怎样观看，光色材料怎样证明，最后哪些可见证据必须成立。差别只是外部版式服务不同任务。

写正文前先建立内部注意力合同：`唯一生成任务 / 主注意力 / 主证据 / 支撑证据 / 主动退让 / 3—6项不可丢锚点`。三段式只是承接结果的外壳，不会自动产生权重；所有内容都必须从同一灵魂向下编译。需要判断模型母型、专有词视觉翻译、属性绑定、单帧证据尺寸、摄影参数和多参考职责时，读取`02_共享资产库/05_工具流程/视觉生成模型注意力与提示词编译参考.md`。

结果图写真必须完成下列职责，但标题不是质量门：

```text
【基础设定】图片类型、用途、媒介、原创对象、身份 / 功能、引用关系。
【氛围与画质】一个主名称锚点及其召回职责；按需一个机制锚点，只负责一项构图 / 色彩 / 光影 / 材料 / 运动机制；文化根系怎样转成当前形态、色域或材料；当前光色、空气与成像基底。
【画面内容与构图】先写模型熟悉的对象 / 服装 / 场景母型，再写当前原创变化；从整体轮廓到主证据，再到支撑细节；姿态或状态；环境；摄影机高度、方向、距离、焦段与景深结果；主体占比、第一落点、前中远景、留白、裁切与安全边距。
```

著名名称是高密度召回锚点，但只有美术风格交接已经选定时才进入正式正文；可迁移机制负责说明它在本图承担什么，当前原创对象负责内容归属。多个名称不得同权覆盖整张图：主锚点决定第一眼审美世界，机制锚点只补一个通道，文化根系只提供形态、色域或材料来源。若删除某个名称不会改变当前主证据，就不把它塞进模型正文。正式生成还要继承`laohu-art-direction`交付的`结果图成像合同`，不再临场重选胶片、调色、肤色、光型和颗粒。

稳定生产直接继承已确认的美术、人物、服装、妆造、布景与成像合同；只有未决方向或用户明确要求候选时才做构思比较。复盘不是默认步骤，真实结果诊断只在用户明确要求或总控路由到`laohu-generation-review`时发生。

图片不是单张好看图，而是视频上游资产。每张图片提示词必须写：

```text
图片用途：
服务场次 / 镜头：
必须锁定：
允许变化：
不能继承：
可复制图片提示词：
是否可作为视频参考图：
```

若使用参考图或形式转译卡，代码块前还要检查：每张参考职责是否单一且绑定明确；必须保留、允许改变、不得继承是否互不冲突；每个承重形式是否能回指来源事实；样本残留是否已隔离；主注意力是否被多个风格词挤掉；像素、Logo、精确文字或几何保真是否已经转入确定性工具或如实降级。检查结论留在代码块外，代码块只写模型要生成的正向可见结果。

`可复制图片提示词：` 后必须紧跟一个 `text` 代码块。代码块内只写可直接粘贴到图片模型的正文，例如画幅、主体、构图、光影、材质、风格和抽象质量边界。代码块外写给人看的说明，代码块内写给模型看的内容；跑偏对象和不能混用的资产写在代码块外。

图片模型代码块里禁止用引号做强调。只有画面上确实要出现的文字，才允许以文字指令写入正文，并优先使用 `标签文字为：...`、`标题文字为：...`、`正文文字为：...` 这种无引号写法。手部、表情、服装、构图、气质、风格等说明都不要加引号；否则模型可能把引号内容生成到图片上。

常见资产包括人物素体形象、按需的人物服装 / 最终造型、场景结构、关键道具、视频第一帧和封面底图。主角色不要默认输出多格表情组或角色一致性情绪网格图，除非老胡明确要求做表情测试；即便要做，也必须写成“测试参考”，不能替代已经选定的正式资产职责。

人物资产图写法：

```text
F人物主视觉图：使用擅长人物审美与角色塑造的模型，把人物设计正文、服装设计正文和妆造补充正文编译成一张有当下目的、关系对象和未完成状态的角色成图。三段职责必须成立，标题可以显式或融合；正式正文优先保持连续的镜头可执行画面叙述。氛围与画质接入美术风格设计交接包已经确认的名称锚点、可迁移机制与结果图成像合同；画面内容与构图明确人物正在做什么、看向谁、摄影机站在哪里、主证据需要多大、环境怎样参与而不抢人。景别可以是头肩、半身、七分身或全身，不为拆解强制完整身体和裁切安全。它是供人类判断人物是否真正成立的角色主视觉，不是技术规格板。人工确认后，同编号B从F反推可见脸身并用人物正文补齐参数，同编号W从F和服装设计正文反推服装结构，同编号M从F、B、W和妆造补充正文还原最终造型。F不直接进入首帧、封面或视频。

F的编译合同只承接：角色母型与第一眼气质；一个关系瞬间或人物状态；少数脸身、服装、妆发锚点；一个摄影观看方式；一个统一题材先验。服装只锁可识别母型、整体轮廓、主色关系、主要材料行为和一个人物化结构记忆点；脸部只锁稳定身份关系与本次表情方向。不可见背面、内里、鞋履工程、纹样排列和次级配件归入模型补全，或由下游B / W / M结合专业正文处理。
人物素体形象资产：按需显式引用同编号F，且只继承五官比例、骨相、年龄感、肤色、发际线、自然发质和稳定辨识特征，不继承写真背景、服装、光影、构图、妆容和具体表情。16:9中性灰摄影棚固定三列网格校准板，不允许自由排版。左栏约36%宽、整高，只放正面头部大特写和唯一清晰人脸；中栏约45%宽、三等分，依次放左前方45度、正面、背面三张同尺度身体，全部使用同一具完全无头发的无五官校准头模，额顶、颞侧、耳后至枕骨为连续同色哑光校准头模表面，只保留头颅与耳廓体块。三具身体统一穿纯白、不透明、哑光、中等克重校准服：立领前拉链长袖校准上衣、全长校准裤和白袜；领口、肩缝、袖口、前拉链、腰头、侧缝与裤脚清楚，贴合身体但保留2—4cm活动松量，除头颈与双手外不露出皮肤，衣料与肤色有清楚色差。右栏约19%宽、整高，标题固定右上、基础信息位于标题下、围度与长度按固定纵坐标排列、说明固定右下。中栏只保留一个头身比短标，其余参数文字只在右栏；关键围度从正面身体的白色圆点以不交叉水平细白引线连接右栏文字。参数写年龄、身高、体重设计值、头身比、骨性肩宽、胸围、腰围、臀围、颈围、上臂围、大腿围、小腿围、肩点至腕、髋点至地、基础体态与永久身体特征；禁止底部参数栏、左下参数栏、分格表和自由浮动标签。下游禁止继承注释文字和制作板外观。
人物阶段素体资产：显式引用同一人物素体并逐项继承B的16:9固定三列网格、36% / 45% / 19%栏宽、三身体等分、纯白不透明校准服、右上标题、右栏参数纵坐标、水平引线、右下说明、字体层级、头顶线与地面线。左栏阶段脸把同一人的 `永久身份锚点` 与当前 `阶段可变区` 分开；每阶段给出单独可执行的绝对目标，再用已验收相邻图补连续关系。绝对目标写软组织等级、外轮廓比例、颧下平面凹凸、下颌缘可见范围、颏下弧线和颈部视觉宽度等可见几何，不让悬空比较词或抽象质量词承担变化。中栏仍使用同一具完全无头发的无五官校准头模展示左前方45度、正面、背面身体，并继续穿立领前拉链长袖校准上衣、全长校准裤和白袜，保留清楚结构缝线与2—4cm活动松量；右栏按固定顺序记录当前完整参数，阶段增量与一句可见形体变化进入右下说明。多阶段只允许替换阶段脸、身体轮廓、数字和阶段说明，其他版式、裁切、站姿、光线、背景与身体尺度冻结并排验收；遮住五官后仍要形成单调连续的剪影级差。
```

场景资产图写法：

```text
扩展分区场景设计板：左上 2×2 为正面、左侧、右侧和反向四机位，右上为较大的高位鸟瞰 / 斜俯视总平面，底部为固定构件、材质、颜色、连接、磨损和空间记忆锚点细节带；先指定一个跨机位不移动的主空间锚点，必要时补次锚点，标明它与入口、行动区、固定光源、关键家具和人物路径的方向与距离；所有区域保持同一结构、光源、锚点名称和位置账本。
局部操作空间要先拆资产：空间本身做局部场景资产，桌子 / 案板 / 碗 / 汤圆 / 硬币等可移动物单独做物品资产。场景资产只锁空间结构、入口、光源和动线；物品资产只锁物品本体；手部进入方向和人物站位属于分镜或视频提示词。
```

物品资产图写法：

```text
同一件物品在中性偏灰摄影棚多角度展示，按风险包含左前方45度、正面、侧面、背面和功能特写，重点固定轮廓、比例、材质、纹理、接触区、活动件、文字 / Logo、磨损、使用方向和可特写细节。
```

常见非资产包括：一次性路人、单镜头奇观、不会回到的场景、只出现一次的入口裂隙、只用于当下画面的云雾光效。它们可以写图片提示词，但文件中必须标注为“单镜头参考图”或“画面元素提示词”，不要混进资产表。
