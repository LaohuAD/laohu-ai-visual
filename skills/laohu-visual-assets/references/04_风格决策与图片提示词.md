# 风格决策与图片提示词

## 选材箴言

材料不论大小，只问能不能承重。

钥匙、杯子、旧衣和门把手并不因为私人就天然深刻；城市、山河、战争和星空也不因为宏大就天然空泛。材料的价值来自三层关系：它是否准确承接当前人物与用意，是否在画面中产生可见后果，是否能从个体经验照见更多人的公共经验。

正式选择前比较：

```text
关系承载：换掉它以后，人物关系、功能或主题是否明显变弱。
典型性：它既有当前作品的身份，又能让陌生观众凭公共经验读懂。
视觉潜力：它能否形成轮廓、尺度、动作、空间、材质或光色上的可见关系。
生成代价：模型是否能稳定生成，它是否会引出错误联想或无关细节。
```

“非它不可”不是要求每次都找一个专属小物件，而是要求材料与当前任务的关系不可随意替换。宏大用意可以选择公共尺度和集体意象，也可以用一个具体入口进入；小用意也可以借宏大环境放大。先定承载关系，再决定材料尺度，不能让“具体”把作品写小，也不能让“宏大”把人物写空。



当任务需要选择美术方向、建立作品视觉语法、竞争原创方案或编写图片提示词时读取。



### 6. 风格决策

当风格不明确或图片 / 视频 / 封面风格冲突时，给 2-3 个方向：

```text
风格方向：
适合原因：
生成风险：
角色资产继承：
场景资产继承：
视频提示词继承：
封面继承：
推荐主风格：
```

如果用户已经给定唯一且不冲突的风格，不强行展开多个方向。

风格不是讨好所有人，而是建立可识别的选择。做视觉方向时必须判断：

```text
这套视觉最想抓住哪类观众。
它主动放弃哪种审美期待。
观众已经熟悉到会忽视的同类画面是什么。
这套视觉的轻微跑调点是什么：形状、色彩、材质、构图、人物缺点、道具、光影、镜头节奏或封面第一眼符号。
跑调点是否服务世界观和作品承诺，而不是无意义怪异。
```

如果视觉方向过于平滑、平均、熟悉、模板化，即使画面漂亮，也要标记为“选择性忽视风险”。首轮测试时至少保留一个不讨好所有人的风格记忆点。

风格决策之后还要落到具体资产，不能用风格词代替设计。人物先判断选角、脸部辨识、身形体态、妆发、服装版型和角色身份；产品 / 道具先判断目标人群、价格感或使用情境、功能结构、轮廓比例、CMF 和握持 / 运动方式；场景先判断世界观空间语法、尺度、入口、动线、材质、陈设密度、光源逻辑和记忆锚点。`可爱` 不自动等于粉色圆角，`高端` 不自动等于黑金玻璃，`治愈` 不自动等于奶油暖光，`玄幻` 不自动等于蓝紫粒子。类型只规定作品要兑现的感受，不替系统完成设计。

### 7. 图片提示词

图片不是单张好看图，而是视频上游资产。每张图片提示词必须写：

```text
图片用途：
服务场次 / 镜头：
必须锁定：
允许变化：
不能继承：
可复制图片提示词：
是否可作为视频参考图：
```

`可复制图片提示词：` 后必须紧跟一个 `text` 代码块。代码块内只写可直接粘贴到图片模型的正文，例如画幅、主体、构图、光影、材质、风格和抽象质量边界。代码块外写给人看的说明，代码块内写给模型看的内容；跑偏对象和不能混用的资产写在代码块外。

图片模型代码块里禁止用引号做强调。只有画面上确实要出现的文字，才允许以文字指令写入正文，并优先使用 `标签文字为：...`、`标题文字为：...`、`正文文字为：...` 这种无引号写法。手部、表情、服装、构图、气质、风格等说明都不要加引号；否则模型可能把引号内容生成到图片上。

常见资产包括人物素体形象、按需的人物服装 / 最终造型、场景结构、关键道具、视频第一帧和封面底图。主角色不要默认输出多格表情组或角色一致性情绪网格图，除非老胡明确要求做表情测试；即便要做，也必须写成“测试参考”，不能替代已经选定的正式资产职责。

人物资产图写法：

```text
人物素体形象资产：16:9中性灰摄影棚固定三列网格校准板，不允许自由排版。左栏约36%宽、整高，只放正面头部大特写和唯一清晰人脸；中栏约45%宽、三等分，依次放左前方45度、正面、背面三张同尺度身体，全部使用同一具光滑裸头、完全无头发的无五官假人头模，额顶、颞侧、耳后至枕骨为连续同色哑光人台表面，只保留头颅与耳廓体块；右栏约19%宽、整高，标题固定右上、基础信息位于标题下、围度与长度按固定纵坐标排列、说明固定右下。中栏只保留一个头身比短标，其余参数文字只在右栏；关键围度从正面身体的白色圆点以不交叉水平细白引线连接右栏文字。参数写年龄、身高、体重设计值、头身比、骨性肩宽、胸围、腰围、臀围、颈围、上臂围、大腿围、小腿围、肩点至腕、髋点至地、基础体态与永久身体特征；禁止底部参数栏、左下参数栏、分格表和自由浮动标签。下游禁止继承注释文字和制作板外观。
人物阶段素体资产：显式引用同一人物素体并逐项继承B的16:9固定三列网格、36% / 45% / 19%栏宽、三身体等分、右上标题、右栏参数纵坐标、水平引线、右下说明、字体层级、头顶线与地面线。左栏阶段脸把同一人的 `永久身份锚点` 与当前 `阶段可变区` 分开；每阶段给出单独可执行的绝对目标，再用已验收相邻图补连续关系。绝对目标写软组织等级、外轮廓比例、颧下平面凹凸、下颌缘可见范围、颏下弧线和颈部视觉宽度等可见几何，不让悬空比较词或抽象质量词承担变化。中栏仍使用同一具光滑裸头、完全无头发的无五官假人头模展示左前方45度、正面、背面身体，头模表面连续同色；右栏按固定顺序记录当前完整参数，阶段增量与一句可见形体变化进入右下说明。多阶段只允许替换阶段脸、身体轮廓、数字和阶段说明，其他版式、裁切、站姿、光线、背景与身体尺度冻结并排验收；遮住五官后仍要形成单调连续的剪影级差。
人物服装资产：所有最终服装都先建立W。先写身份场景活动推导，B或当前阶段素体只在后台提供版型、尺码与活动限制，人物身体参数不得进入W画面；随后做服装主件结构判断。多个可独立识别与穿脱的上装、下装、外层和内搭使用`可拆套装分件拆解板`：16:9固定2行×2列四象限，上装拆解区用无头无脸上半身服装承托架给出严格正背面及领口、门襟、袖口、内里， 下装拆解区用下半身服装承托架给出严格正背面及裤腰 / 裙腰、口袋、侧缝、裤脚 / 裙摆，配件与鞋履区逐件展示穿戴物及鞋底，材质与活动余量区用材质微距和中性局部活动承托证明面料、工艺与松量；外套＋内搭等多层结构必须增加叠穿关系小图。不可拆分的单一连续主件使用`连续主件完整展示板`：左侧约三分之一为光滑裸头、完全无头发的无五官全身承托人台严格正背面，右侧约三分之二为4列×3行十二格，证明从领口到下摆的连续轮廓、内里、隐藏结构、材料、鞋履与活动余量。两种模式都以图片信息为主，只写大号名词性标题；不使用小字号解释段落、人物参数墙、自由拼贴或最终妆发，复杂度只提高当前模式内可回指的视觉证据密度。
人物妆造设计资产：显式引用人物素体、当前人物阶段素体与W服装资产。16:9画面视觉上保持2行×3列，实际写成左前方45度、正面、背面三列纵向组合，而不是六张独立人物照片。每列上排是放大的头部及必要肩颈特写，通常约占三分之一并可按妆发细节适度加高；每列下排是同角度的无头穿着身体，从颈部根部或肩线以下至鞋底，画框最高可见点只落在锁骨、肩峰、后领中心或肩线，人体头颅完整位于下部画框之外。上部特写向下覆盖下部原本的头颅位置，覆盖接缝藏在颈肩交界或服装领口，使上部头部成为同列身体的唯一对应头部。三列共同锁定当前最终发型、发饰、妆面、肤质、胡须、耳饰、头饰、眼镜、纹身、身体彩绘 / 伤妆、疤痕妆、义体表面和服装穿回同一人物后的气质结果；上下同列的身份、阶段体型、服装穿着关系、身体中轴、背景、光向与色彩一致。M是受控定妆摄影资产，必须补背景与妆面之间的明度 / 色相对比、主光与补光方向、眼神光、睫毛分离度、腮红过渡、唇部高光、发丝边缘和服装轮廓；不重复身体工程参数，不重新发明W的服装结构。
表情规则：B人物素体形象资产与M人物妆造设计资产只写中性常见表情，不写多格情绪表情；情绪表演交给视频提示词逐镜头调度。
```

场景资产图写法：

```text
扩展分区场景设计板：左上 2×2 为正面、左侧、右侧和反向四机位，右上为较大的高位鸟瞰 / 斜俯视总平面，底部为固定构件、材质、颜色、连接、磨损和空间记忆锚点细节带；先指定一个跨机位不移动的主空间锚点，必要时补次锚点，标明它与入口、行动区、固定光源、关键家具和人物路径的方向与距离；所有区域保持同一结构、光源、锚点名称和位置账本。
局部操作空间要先拆资产：空间本身做局部场景资产，桌子 / 案板 / 碗 / 汤圆 / 硬币等可移动物单独做物品资产。场景资产只锁空间结构、入口、光源和动线；物品资产只锁物品本体；手部进入方向和人物站位属于分镜或视频提示词。
```

物品资产图写法：

```text
同一件物品在中性偏灰摄影棚多角度展示，按风险包含左前方45度、正面、侧面、背面和功能特写，重点固定轮廓、比例、材质、纹理、接触区、活动件、文字 / Logo、磨损、使用方向和可特写细节。
```

常见非资产包括：一次性路人、单镜头奇观、不会回到的场景、只出现一次的入口裂隙、只用于当下画面的云雾光效。它们可以写图片提示词，但文件中必须标注为“单镜头参考图”或“画面元素提示词”，不要混进资产表。
