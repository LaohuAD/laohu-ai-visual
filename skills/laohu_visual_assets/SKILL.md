# 视觉资产核心

## 能力定位

把剧本、分场、单镜头或世界观设定拆成后续图片生成、视频生成、封面发布和剪辑需要的视觉资产。

这个 skill 合并原先的风格导演、图片资产提示词、图片生成交接、图片验收和封面提示词。它不负责把画面写漂亮，而是负责判断“为了让作品能连续生成、能测试、能发布，需要准备哪些视觉资产”。

## 能力加厚纪律

本 skill 不只是从剧本里抽名词，而要把剧本翻译成可生成资产体系。每个角色、场景、道具和镜头任务都要先判断它到底是“可复用资产”，还是“单次画面元素”。只有需要跨镜头、跨场次、跨集或跨作品复用，或者需要锁定外观、空间、材质、比例、色彩和连续性的内容，才进入资产表。

资产拆解前先做确定性命名审计。剧本里的观众称呼、生产命名和资产编号可以不同，但必须能映射。不要把“大人”“群仙”“神兽”“女仙”“宫殿”“法器”这类泛称直接搬进资产表当固定资产名。

正确处理：

```text
剧本显示称呼：大人
生产命名：主角
资产命名：A1 主角袖口与玉扳指
资产类型：图片资产，固定 POV 身份锚点
```

```text
群仙 → 不是人物图片资产；可作为群体画面元素，或沉淀为“群仙礼仪规则”提示词资产。
神兽 → 不是固定资产；白鹿、云龙、青鸾这类具体对象才进入资产判定。
女仙 → 如果只献礼一次，是一次性功能人物；若后续反复出现或作为封面主体，才命名并升级为角色资产。
```

命名审计的目的不是给所有元素起名字，而是防止下游独立生成时模型不知道“谁是谁”。只有确定的对象才可以固定；泛称只能作为类别规则、群体描述或单镜头画面元素。

当老胡说“再做一个 / 补一个 / 重新做一个”资产时，先判断这是新增资产、修正已有资产，还是补同类但不同地点 / 不同剧情阶段的资产，不能凭相似名词直接覆盖旧资产。`卧室`、`房间`、`院子`、`桌子`、`车`、`电话` 这类泛称必须绑定服务场次和生产命名后再编辑。例如《不想长大》里 `小安城市卧室` 和 `老家爷爷卧房` 是两个不同场景资产：前者服务开场醒来，后者服务门缝医生、病床输液和爷爷解释长大；用户补“乡下爷爷家的卧室”时应新增 / 调整 `S9 老家爷爷卧房`，不能覆盖 `S3 小安城市卧室`。

资产可以在视频提示词阶段反向补充。前期视觉资产只是第一轮框架，不等于后续禁止新增资产。正式视频提示词写细以后，如果发现某个场景、道具、动线、空间尺度或关键物件已经被多个镜头调用，或者只靠文字仍然容易模糊、错位、现代化、数量错误、方向不清，就要回到视觉资产文件补充对应资产。补充时必须说明资产编号、资产名、服务镜头、固定内容、可复制图片提示词、保存命名和验收标准，并同步更新分镜表和视频提示词引用。当前案例：`S4 放学路 / 村口` 原本只是单镜头参考，但 E1-S9-C1 到 E1-S9-C3 连续使用同一条放学路承载肩带滑落、村民报丧、姐姐跑远和小安抱书包追不上，因此应升级为正式场景四视图资产。

一次性出现的路人角色、单次奇观、单镜头场景、一次性时空裂隙和只服务某个镜头的画面，不默认叫资产。它们应进入镜头画面元素、单镜头参考图、临时生成素材或分镜提示词内容。

视觉资产内部必须区分两种资产：

```text
图片资产：用图片固定具体形象和一致性。
文本资产 / 提示词资产：用文字固定氛围、妆造、环境、风格和世界观视觉规则。
色彩风格资产：用图片色卡 + 文本规则固定全片或阶段的色彩系统。
```

如果对象需要保持同一个脸、同一套服装、同一件道具或同一个空间，优先考虑图片资产。如果对象不需要固定为同一张图，但其风格、妆造、服饰、环境气质或材质规则需要被后续镜头继承，优先做文本资产 / 提示词资产。

提示词资产不是低级资产。基础设定、氛围与画质、人物妆造、服饰体系、场景大类规则、色彩材质、声音气质和世界观视觉规则，都可以成为跨镜头复用的提示词资产。后续生成正式视频提示词时，不能只写“调用提示词资产 A1”，必须把 A1 的具体规则展开到正式提示词正文中。

色卡可以升级为色彩风格资产，但它不是人物设计资产里的小色值卡。人物设计资产里的配色板只校对这个角色的服装、肤色、首饰和局部细节；全片色彩风格资产要控制整支作品的色调连续性。建立色彩风格资产时，至少写清主色、辅助色、点缀色、肤色倾向、光源色、暗部倾向、环境反光、饱和度、明度、对比度、胶片 / LUT 分级、适用场景和情绪阶段变体。色块建议标十六进制 RGB，例如 `#DDEAF0`，但必须同时写颜色职责：它落在海面、天空、墙面、衣料、皮肤高光、暗部、道具还是字幕留白。

同一作品默认先做一个全片母色卡，再按剧情情绪派生阶段变体。母色卡负责剪辑统一和世界一致；阶段变体负责情绪推进，例如恋爱前半段清新透亮，分手后半段仍继承同一海天蓝绿，但降低明度、扩大冷灰暗部、让树影和负空间变重。不要每个分镜随机换色卡，也不要所有分镜完全死用同一色卡。资产表里可用 `C` 系列编号，例如 `C1 全片母色卡`、`C1-A 心动期色卡变体`、`C1-B 失落期色卡变体`。

图片资产必须继续判断子类型：

```text
人物形象资产：单张正面 / 半正面艺术照，用环境、光影、姿态、服装材质和画面叙事拉满角色气质，先确定这个人的第一眼感觉。
人物素体资产：固定脸、身材、年龄、发型、基础体态。通常白衣 / 中性服装，简洁灰白背景。
人物设计资产：白底或简洁背景的制作参考图，使用三视图、面部特写、左手特写、右手特写、配色板、局部细节、比例照和音色文字说明区，锁定五官、比例、服装穿搭、手部参考、声音基础设定和可复用细节。
群像人物资产：固定一类跑龙套人群的年龄层、服装年代、体态差异、站位密度、表情范围和群体气质，不固定每个具体人的脸和身份。适合邻家孩子、同学、亲戚、村民、围观群众等需要稳定时代感和群体真实感、但不需要逐个定脸的角色群。
人物定装资产：同一个人物穿固定服装、发饰、妆容后的完整形象。
服装 / 妆造资产：单独固定服装、发饰、妆容、配饰、盔甲，供后续叠加到人物素体。
组合形象资产：人物素体资产 + 服装 / 妆造资产组合后的新形象资产。
场景图片资产：同一个固定空间的三宫格 / 四宫格 / 多角度视图，锁定结构、入口、主视角、反向视角、光源和可运动路径。
场景四视图设定图：以同一个场景为主体，输出正面视角、左侧视角、右侧视角、正面反打图，用视角旋转关系锁定空间布局和物体对应位置。
物品图片资产：同一件物品的多角度和材质细节，背景尽量简单。
色彩风格资产：全片或阶段的横向色卡图 + 文本规则，固定主色、辅色、点缀色、肤色、光源色、暗部倾向、环境反光、饱和度、明度、对比度和统一分级。
```

低保真故事板不属于图片资产。它是分镜表之后生成的线框故事板表格图提示词，用来锁构图、景别、机位、主体比例、站位、道具数量、空间锚点、引导线、动线路径、留白区和参考强度。它不调用具体资产图，不复刻角色脸、服装、材质、颜色和最终光影；人物只用火柴人或简化剪影，道具只用几何块，场景只用线框空间和文字标签。若某张图要表现真实人物外观、固定场景材质或道具细节，它就不是低保真故事板，而应回到人物 / 场景 / 道具图片资产或第一帧参考图判断。

资产唯一性原则：一个图片资产只能固定一个确定对象。人物资产只固定一个人物；物品资产只固定一件道具或一组同类状态明确的同一物；场景资产只固定一个空间；服装 / 妆造资产只固定一套可穿戴规则。不要把一个镜头里的场景、桌子、碗、汤圆、硬币、人物手部和动作同时写进同一个资产。这样的图已经是分镜图、首帧图或视频提示词参考，不是可复用资产。多个元素都需要稳定时，拆成多个单一资产，再在分镜、视频提示词或第一帧参考图里组合调用。

互斥可见状态必须拆资产。凡是一个物件在剧情中存在“外部完整状态”和“内部揭露状态”，或“可见阶段”和“隐藏阶段”，不要把两个状态写成同一张资产图的共同特征。否则模型会把互斥状态混合在最终画面里。错误写法：`P4 元宵硬币汤圆` 同时展示完整白汤圆、剖面黑芝麻馅、硬币贴近汤圆皮。正确写法：`P4 元宵完整白汤圆` 只固定连续白糯米皮和完整圆形外观；`P10 元宵小面值硬币` 单独固定硬币，只有包入前、吃出后或爷爷递出时组合调用。

所有图片资产、封面、首帧和生图提示词的可复制正文都必须遵守“出现什么描述什么”。模型只看输入文本本身；如果在硬币资产代码块里写“汤圆”，即使前面有“不出现”或“禁止”，也会把汤圆变成候选视觉元素。正确做法：代码块里只写当前目标画面的主体、形状、材质、比例、纹理、光线、背景和清晰度；混用风险、剧情上下文和不该出现的对象写在代码块外的 `不能继承`、验收标准或失败经验里。当前案例：硬币资产代码块只写硬币尺寸、边缘、磨损、清洁度、金属反光、背景和光线；完整白汤圆资产代码块只写白糯米皮、完整圆形、水光和手搓纹理。

资产类型不能只按剧本里出现的名词判断，要先判断“失真来源”。如果生成问题来自年代环境、店铺类型、货架陈列、空间尺度、灯光、地砖、墙面、入口、公共设施或场景空间语法，应优先做场景资产；如果问题来自某个物品本体的轮廓、材质、尺寸、结构、磨损、开启方式或特写细节，才做道具 / 物品资产。比如“商场拒买玩具”这场戏里，真正需要固定的是 90 年代末到 2000 年代初普通商场玩具货架区、荧光灯、浅色地砖、货架和包装陈列，因此应做 `S7 商场玩具货架区` 场景资产，而不是把问题误判成 `玩具车` 道具资产。场景资产只固定空间和陈列规则，人物手部、父亲牵走、孩子撒赖和剧情动作写入分镜或视频提示词。

人物资产必须区分“形象资产”和“设计资产”。形象资产不是三视图，它是一张光影、氛围、环境和人物气质拉满的正面或半正面艺术照，用来确定角色的第一眼魅力、风格母体和情绪方向。设计资产才是三视图 / 特写 / 配色板 / 局部细节 / 比例照，用来锁定五官、身材、衣服穿搭和后续生成的一致性。

人物定装资产必须服务角色魅力、场景光影和观众情绪，不只是把衣服写得“好看”。设计主角或重要角色穿搭时，先判断观众需要对这个人产生什么第一眼反应，例如心疼、不平、向往、压迫、信任、危险、亲近；再选择服装版型、材质、层次、首饰、鞋、发型和妆容。穿搭要和固定场景的色彩、光源、风、雨、材质和动作相互配合：海边可以用月白、雾蓝灰、珍珠、银饰和轻薄面料接住海风与侧逆光；老家怀旧场景要避免现代潮牌和过度精致；仙侠礼制场景要让衣袖、发冠、腰封和材质服务身份与动作。错误写法是只写 `好看的裙子、精致首饰、漂亮穿搭`，模型会生成普通写真或廉价网红感。正确写法是 `月白丝缎长裙 + 雾蓝灰轻薄外搭 + 珍珠 / 银色细首饰`，并说明它为什么适合场景、角色气质和观众反应。当前案例：林栀的定装必须让观众产生“这么好看的女孩也会被这样对待”的疼惜和不平，所以固定清冷温柔的海边高级定装，不用朴素 T 恤牛仔裤，也不走红毯礼服或甜宠公主风。

人物形象资产可以用信息留白强化第一眼吸引力。形象资产不是必须把脸、身材、服装和环境一次性全部交代完；当目标是神秘、清冷、危险、暧昧、不可接近或高级氛围时，可以设计半张侧脸、发丝遮眼、只露嘴唇和下颌、背影回头、门框 / 窗帘 / 树影局部遮挡、只拍手和首饰等局部遮蔽。使用时必须保留身份锚点：脸型轮廓、鼻梁、唇峰、耳坠、项链、锁骨、手型、发型或服装材质至少有一组清楚可读；不能遮到角色无法识别。设计资产阶段仍要完整锁定正面、侧面、背面、脸部和身体比例；局部遮蔽只属于形象资产、封面、首帧或视频镜头策略，不能替代完整人物设计资产。

人物定装还必须写清“衣服如何穿在这个身体上”。服装参考图只提供服装方向，不等于直接复制参考图里衣服和模特身材的关系。主角服装提示词要描述身材基础和版型机制：肩线是否收住肩颈，胸口是否有自然省道 / 弧度 / 支撑，腰侧是否收束，高腰线是否明确，裙腰或裤腰从哪里展开，面料是贴合、垂坠、挺括还是轻薄，哪里允许随风动，哪里必须稳住比例。错误写法是只写 `深灰无袖上衣、长裙、腰间系带`，模型容易生成松垮罩衫、胸前塌陷、腰线消失或直筒麻袋。正确写法是 `深灰无袖垫肩上衣按人物身形修身合体，肩线利落，胸前有轻微立体省道和柔和弧度，腰侧自然收住；浅灰系带压出高腰线和细腰比例；高腰长裙从细腰处展开`。同时要写边界：修身但不紧绷，漂亮但不过度暴露，不做网红紧身性感和夸张丰胸。当前案例：林栀的【参考图2：冷灰水墨定装穿搭】必须从“衣服长什么样”升级为“衣服衬出林栀肩颈、胸腰比例和高腰长裙比例”。

服装参考不能只继承单品名称，还要继承穿法逻辑、视觉重心和比例关系。腰间系带、披肩、外套绑腰、腰封、领巾、围巾、链条、裙摆开衩这类细节，如果参考图里是偏侧、斜绕、松弛、轻薄或作为比例修饰，就不能机械居中成正面大结、毛巾、围裙或厚重遮挡布。鞋履也不是脚下随便补一个款式，必须和人物身份、场景、服装、首饰、脚背露肤、腿部线条和动作需求统一：写清鞋头形状、闭口 / 露趾、浅口 / 深口、踝带、跟高、材质、颜色和气质。当前案例：林栀腰间浅灰条纹层必须偏侧斜绕、扁平贴腰、布尾轻薄同侧垂落；鞋履从露趾凉鞋改为珍珠白冰银尖头浅口踝带低跟单鞋，闭口细尖头、浅口露脚背、纤细踝带和低细跟服务清冷文艺气质。

人物设计资产必须建立同一份造型账本。三视图、面部特写、手部特写、局部细节、配色板和比例照不能各自生成一套配饰、鞋履和标签。写提示词前要列清固定定装清单：上衣、下装、腰部结构、包、发饰、耳饰、项链、鞋履、手腕是否佩戴饰品；每个分区只能继承这份清单。发圈如果设定为发间配饰，就只能出现在头发或发髻上，不能在左右手特写里变成两个手环；鞋履如果是精致低跟鞋，就不能在局部细节里变成拖鞋、运动凉鞋或标签错位。局部细节模块必须一物一标，标签和图像物件一一对应。当前案例：林栀 A1 的深灰发圈只属于发间，左右手腕保持干净；鞋履固定为珍珠白冰银尖头浅口踝带低跟单鞋，用来完成清冷文艺海边定装。

人物设计资产的三视图必须展示角色在当前年龄段和身份里的高光体态，不是普通站姿记录。主角和重要角色要写清：脊柱自然拉直、胸腔舒展、肩背打开、肩胛稳定、颈线拉长、下巴微收、腰背挺住、重心稳定、站姿自信。禁止含胸驼背、圆肩、缩脖、头颈前伸、塌腰和没精神的被动站姿。身材魅力要服务角色气质，写成自然饱满胸型、胸腰比例、肩颈锁骨和挺拔体态，不写低俗凝视；如果确实需要更明确的身材目标，可以写“约 C 罩杯轮廓、自然饱满但不夸张、漂亮但不过度暴露”。当前案例：林栀资产必须让三视图看起来像她 24 岁最好的状态，而不是松散地站在那里。

左右手参考必须按人物自身左右和解剖方向校准，不能只放两张相似手照。写提示词时要明确人物自己的左手 / 人物自己的右手，不要按图片左右误标；画面里的标签只写左手、右手，不写林栀自己的左手、林栀自己的右手这类长标签。若手背朝镜头、指尖向下，人物自己的左手拇指应在画面右侧，人物自己的右手拇指应在画面左侧；若手掌朝镜头，左右关系与手背参考相反。左右手应来自同一人物、同一年龄、同一肤色和同一手部比例，但拇指方向必须相反，不能生成成同一只手。当前案例：林栀 A1 的手部参考区必须用中文标签分别标注左手和右手，并写清拇指方向。

POV 主体也必须按正常人物资产设计。第一人称、背影、遮挡、低视线、只露手或只露袖口，都是下游镜头表达方式，不是资产阶段的豁免。只要 POV 主体是主角、跨镜头反复出现或承担观众代入，就要先建立完整人物资产，锁定年龄、身高、头身比、上下身比例、肩宽、左手大小、右手大小、脚步尺度、默认日常穿着、可变服装状态、书包 / 鞋等身份道具和背面 / 侧面 / 正面关系。后续视频可以控制他少露脸，但资产本身必须告诉模型“这是谁的身体”，否则左右手、袖口、视线高度、成人与儿童比例都会失控。

POV 主体资产不能在视频阶段被泛称替代。资产表里如果确定了 `A1 小安儿童人物资产`，下游视频提示词必须写 `小安第一人称 POV` 或 `小安视角`，再补充儿童低视线、小手、袖口、呼吸等表现；不能只写 `儿童 POV`。资产阶段要在备注里提示：`儿童` 是类型特征，`小安` 才是可调用主体。

人物资产要区分“默认参考服装”和“本镜真实穿着”。设计资产可以用某套干净日常服锁定比例、袖口、鞋和书包，但这不代表角色在睡觉、洗漱、病床、丧事、换衣或回忆里都穿这一套。除非服装是品牌、校服制服、固定戏服、丧服或定装资产，否则视频阶段必须按场景重写当前服装状态。资产表里应补 `可变项`：日常外套、睡衣 / 秋衣、学生外套、孝布 / 素衣、是否背书包、是否穿鞋等；并说明哪些必须固定、哪些允许随场景变化。

人物资产还必须区分稳定身份、固定定装、场景配件和动作道具。稳定身份是脸、身高、年龄、体态、发型、基础气质和声线；固定定装是明确要持续穿的服装；场景配件是只在特定场景出现的书包、雨伞、帽子、孝布、围裙、工具包、篮子等；动作道具是当前动作临时使用的打火机、勺子、毛巾、药碗、锄头等。不要把场景配件写进人物设计资产的全身三视图当常驻外观。需要记录配件时，把它放在局部细节区、状态模块或单独道具 / 服装资产里，并写清适用场景。当前案例：A5 姐姐的书包只属于放学路 / 报丧场景，不能成为元宵包汤圆、饭桌、丧事和结尾镜头里的常驻外观。

人物设计资产必须增加左右手制作参考。左手特写和右手特写分别独立成模块，不能只写“手部特写”。手部模块要展示手背 / 手掌或至少一个清楚角度，说明手指长度、指节、指甲、肤色、年龄感、手部肉感、常见袖口连接方式和可作为 POV 前景锚点的识别点。第一人称、递物、牵手、触摸道具、拨动木轮、擦眼泪等镜头经常只靠手建立身份，如果左右手不固定，视频会出现成人手、错手、比例漂移和年龄感丢失。

人物设计资产还要把基础音色做成图片上的文字说明区。只要角色会跨镜头说话、VO 回响或画外音出现，设计资产图里必须有清晰中文短句，写出音色、音线、年龄感、地域口音、语速和常态情绪。例如小安写 `音色说明：儿童清亮偏细，重庆口音，语速快，情绪外露`；父亲写 `音色说明：低沉克制，短句重庆话，压着火，尾音重`；爷爷写 `音色说明：温和沙哑，带笑，重庆老人口音，气息略虚`；奶奶写 `音色说明：温软絮叨，鼻音轻，重庆老人口音，忍哭时发颤`。如果已有音频参考，要在资产表记录对应的 `音色参考` 编号，供视频提示词用 `【音色参考@xx】` 调用。

视频提示词阶段的人物调用不再重复长篇基础声线。人物交接给 `laohu_video_prompt` 时，要提供双参考占位建议：`角色名：【形象参考@A1 角色人物设计资产】【音色参考@V1 角色音频参考】稳定身份和本镜状态。` 形象参考由老胡替换成人物设计资产图片，音色参考由老胡替换成音频参考；本镜的哭腔、病弱、喊叫、压低、隔门闷声、电话失真和 VO 回响仍由视频提示词写在 `【画面内容】`。

人物图片资产推荐按生产链输出：

```text
先做人物形象资产：环境内艺术照，展示气质和光影氛围。
如果会换衣服，再做人物素体资产：白色素衣 / 中性服装，简洁背景，锁脸和身材。
再做服装 / 妆造资产：单独锁服装版型、层次、材质、颜色、纹样和配饰。
最后做组合设计资产：把素体和服装组合成穿对应衣服的白底设计资产图。
```

人物设计资产推荐 16:9 横幅扩展分区制作参考图，并且必须按信息优先级分配画幅：主视觉区放正面 + 侧面 + 背面三视图，脸部区放一张大尺寸纯头部 / 脸部特写，右侧或主辅助区放摄影棚真实人像状态区；身高和身体节点比例标注应合并进三视图，不再单独占一个和三视图重复的全身比例图。手部参考、色值卡、局部细节和音色文字说明是辅助校对信息，面积要小而清楚，不能抢走三视图、脸和摄影棚真实人像状态区的主画幅。背景应简洁，避免强场景色干扰人物；摄影棚真实人像状态区使用中性灰或极简灰背景，专门校准真实光影下的脸部皮肤、妆容、表情、肩颈姿态、首饰受光和上半身服装状态。场景资产不要求简洁背景，因为场景本身就是主体；物品资产则应尽量使用简单背景，突出形状、材质和比例。

人物设计资产的脸部特写必须是真正的头部特写，用来固定五官、眼神、鼻梁、嘴唇、皮肤质感、妆容、发际线和脸型轮廓，不要拆成两张面部 / 颈肩半身图。左右手特写必须存在，但应是小面积手模级模块，展示手指修长程度、指节、甲床、肤色、袖口连接和左右解剖方向；不要把手部放成比脸还大的主模块。配色板只做紧凑色值卡，优先标注十六进制 RGB 色值，不写大块颜色名称。厘米身高和身体节点比例线要并入三视图，用厘米高度线标注脚底、脚踝、膝盖、髋部、腰线、胸线、肩线、颈根、下巴和头顶，不能用 1、2、3、7.5 这种抽象头身刻度，也不要额外生成一个和三视图内容一模一样的比例图区。右侧摄影棚真实人像状态区应是胸部以上中近景摄影照片感参考，人物占区域高度约 70%，中性灰背景，柔和主光、轻微侧逆轮廓光和明暗层次，用来测试人物在真实摄影光影下是否仍然好看、皮肤是否清透、底妆是否服帖、首饰和上半身服装是否成立。当前案例：林栀 A1 的版式要把过大的左右手和配色板缩为辅助模块，把面部区合并成一张大尺寸纯头部特写，把厘米比例标注并入三视图，并把右侧重复比例图改成摄影棚真实人像状态区。

人物设计资产本身会反向影响后续视频肤色。只要人物资产会作为视频参考图、图生视频首帧、角色一致性图或后续分镜参考，资产图里的肤色、底妆和脸部高光就是下游视频的强锚点；如果资产图本身偏黄、偏油、大片高光或厚粉，视频提示词里再写白皙清透也会被参考图拉回去。因此美女角色、情绪人像、开场钩子角色和壁纸帧主角的人物设计资产，必须在资产提示词本体先正向锁住肤色妆效：冷白偏中性的白皙肤色、白皙通透、肤色匀净、清透裸妆、轻薄服帖底妆、柔雾奶油肌、柔雾哑光带内透光肤感、低饱和裸杏腮红、低饱和玫瑰豆沙唇；再补细微毛孔、皮肤微纹理、自然漫反射、柔和次表面透光、高光过渡柔和、细腻 35mm 胶片颗粒。参考图如果带黄色室内光、油亮妆效或过曝美颜，只能继承脸型和五官，不继承偏黄光源和油亮肤感。摄影棚真实人像状态区要把这套肤色妆效放进真实光影里验证：脸部亮面柔和，脸侧半暗面保留皮肤细节，眼神、鼻梁小范围、唇峰、脸侧轮廓、发丝和首饰有克制柔光。当前案例：林栀 A1 必须让三视图、脸部特写、手部参考和摄影棚真实人像状态区都统一为冷白偏中性、白皙通透、柔雾奶油肌，不能让 A1 资产先变黄变油后再靠视频提示词补救。

人物设计资产的局部细节区不是装饰拼贴区，而是造型账本的校对区。每个细节模块都要来自主视觉三视图已经出现或明确设定的同一套服装 / 配饰 / 鞋履；不要额外发明新饰品，不要把一个配件复制到多个身体部位，不要让标签贴错物件。鞋履、发饰、手部、包、首饰等模块必须分别命名清楚，并和三视图、比例照一致。

人物形象资产和人物设计资产必须分开输出。形象资产负责第一眼气质、环境、光影、姿态、服装材质和叙事瞬间；设计资产负责白底 / 简洁背景的多角度制作参考。禁止用“左侧脸部近景 + 右侧三视图”的旧版混合图同时冒充形象资产和设计资产，因为它既没有情绪场景，也没有完整四区制作标准。

形象资产提示词和设计资产提示词属于同一个人物资产编号下的两个生成入口，不拆成两个资产编号。例如小安仍然是 `A1`，可以输出 `A1 小安人物形象资产提示词` 和 `A1 小安人物设计资产提示词`，但后续视频提示词只调用最终选定的 `A1`。禁止写成 `A1-1`、`A1-2` 这种会让下游误以为是两个资产的编号。

当人物资产需要更完整的制作参考时，可以升级为四区结构：

```text
主视觉区（上方）：正面 + 侧面 + 背面三个核心视角，展示整体身形、服饰搭配和标志性特征。
补充信息区（左侧）：面部特写 + 配色板，补足脸部正立、颈部垂直、下颌线水平、头顶到下巴处于画面垂直中轴上的标准。
局部细节区（底部）：配饰、点缀、关键身份识别元素的小模块拆解。
比例照（右侧）：全身比例照，必要时加入比例参考物或身高对比。
```

这不是所有角色都强制做满，但凡是会跨镜头复用、需要导演确认、或服装和身形比例要严格一致的人物，优先按这个分区组织，而不是只做一张普通三视图。

资产编号必须稳定记录：

```text
A1：人物素体资产。
A2：服装 / 妆造资产。
A3：A1 穿着 A2 后形成的组合形象资产。
```

助手不负责实际图片合成，但要负责规划、命名和记录组合关系。后续如果老胡生成了 A3 图片，资产表要把 A3 登记为可调用图片资产。

如果剧本信息不够，要补“暂定视觉假设”和“必须回问或待定字段”；如果资产过多，要先选首轮验证最小资产，而不是一次铺满全片。

首轮验证最小资产规则：

```text
短片 / 首测 / 单条视频验证 → 只保留会跨镜头复用、会影响一致性或会作为封面 / 第一帧的资产。
一次性人物 → 降级为画面元素或单镜头参考图。
一次性奇观 → 降级为画面元素、氛围参考或文本资产的一部分。
反复继承的风格、服饰、建筑、材质、色彩、礼仪 → 优先做文本资产 / 提示词资产。
```

风格、图片提示词、生成交接、图片验收、封面都归在本 skill 内处理。不要为了同一个作品在多个零散 skill 之间跳来跳去。

视觉资产、资产图片提示词、封面提示词和图片验收结论都必须写入文件。对话里只给文件链接、当前阶段摘要和是否确认进入下一阶段。除非老胡明确要求粘贴全文，不要在聊天中直接输出长提示词集合。

资产图片提示词、封面提示词和图片验收文件默认在同一个阶段文件上迭代，不自动新建 v1/v2/v3。只有老胡明确要求新增版本、另存一版或 A/B 两版时，才创建新版本文件。

图片提示词交付必须方便老胡直接复制。每个资产可以在代码块外写用途、服务场次、必须锁定、允许变化、不能继承、是否可作为视频参考图；但真正要复制到图片模型里的正文必须单独放进 `text` 代码块，并使用标题 `可复制图片提示词：`。代码块里只放模型投喂内容，先正向描述要出现的画面结果；边界优先写成 `质量边界`，只描述抽象质量要求，例如画面干净、比例自然、身份清楚、材质真实、无文字水印。不要把当前画面不该出现的具体对象写进代码块当排除项，也不要把用途说明、资产编号解释、生成执行单、命名规则、回传字段、验收标准等放进代码块。

凡是图片提示词、资产提示词、封面提示词、故事板提示词或生成执行单里需要老胡手动上传、替换、绑定、参考或调用的外部内容，都用中文全角中括号 `【】` 显性标注。稳定资产写 `【@资产名】`，人物形象写 `【形象参考@A1 角色人物设计资产】`，人物音色写 `【音色参考@V1 角色音频参考】`，临时参考图写 `【参考图1：用途】`、`【参考图2：用途】`。不要裸写 `参考图 1`、`参考图片 2`、`见上图`、`使用图片一`；正确写法是 `【参考图1：女主肖像】用于固定脸、年龄感、体态和真实自然感；【参考图2：服装穿搭】用于固定版型、层次、颜色、材质和配饰方向`。这能让老胡复制前快速找到所有需要上传的参考项，也能避免参考关系被模型当成普通说明弱化。

图片模型代码块里的引号只保留给画面里真实需要出现的文字，不用来做强调、解释、概念命名或歧义消除。因为生图模型容易把引号里的内容当成画面文字画出来，导致资产图出现多余标注。正确写法是 `标签文字为：左手、右手`、`标题文字为：音色说明`、`正文文字为：儿童清亮偏细，重庆口音，语速快，情绪外露`；不要写 `标注“人物自己的左手”`、`标题为“音色说明”`、`所谓“高级感”` 这类强调式引号。需要解释标签为什么这样写，放在代码块外的人类说明里。

## 内置质量校准视角

以下视角只用于提高资产设计质量，不改变输出结构，不在正式文件里新增专家分析栏目。

| 视角 | 内部校准方式 |
|---|---|
| Ralph McQuarrie | 关键资产先看大轮廓和第一眼识别度：远看能不能认出身份、阵营、时代和功能。不要只堆纹样。 |
| Syd Mead | 场景和道具要有功能逻辑：它为什么长这样，人在里面如何移动，光源、入口、尺度和材质是否自洽。 |
| Moebius | 奇幻世界要有陌生感和留白，不要把画面塞满同一种符号。仙界奇观要有呼吸空间和视觉节奏。 |
| Doug Chiang / Iain McCaig | 角色、服装、建筑、道具要属于同一个世界观设计语法；形状语言、材质体系和色彩层级要能互相继承。 |
| Feng Zhu | 资产不是漂亮插画，而是生产设计。每个资产都要明确可复用角度、生成用途、失败风险和下游调用方式。 |
| 张艺谋 / Christopher Doyle | 东方视觉要注意色彩仪式感、人物与空间的关系、主色和点睛色。不要让全片变成单一金白或单一蓝紫。 |
| 胡金铨 / 徐克 / 程小东 | 仙侠资产要同时服务礼仪、身法和空间调度：衣袖、法器、门、桥、旗、云层都可以成为动作和转场工具。 |

资产设计时优先问：这个东西是否真的会复用，是否能锁定一致性，是否能帮助视频生成和剪辑。不能因为名字好听就升级成资产。

## 能力边界

可以产出：

- 角色资产表。
- 场景资产表。
- 道具资产表。
- 风格与连续性表。
- 镜头任务表。
- 图片生成任务表。
- 视频生成准备表。
- 2-3 个视觉风格方向和主风格建议。
- 角色形象资产、素体资产、服装 / 妆造资产、设计资产、组合形象资产、三视图、场景四视图设定图、道具、第一帧、参考图、网格图提示词。表情组只在老胡明确要求表情测试时输出，不作为主角色人物设计资产的默认组成。
- 人物形象资产提示词可以写成“电影级正面艺术照 / 半正面肖像”：画面要有具体环境、光源方向、冷暖对比、服装材质、姿态、眼神、构图和叙事氛围，用来先立住角色气质。
- 人物形象资产可以使用局部遮蔽和信息留白，但必须服务第一眼气质，不替代完整设计资产。适合写半张侧脸、发丝遮住一只眼、窗帘 / 门框 / 树影形成前景遮挡、只露嘴唇下颌和耳坠、背影回头一点点；同时要保留脸型轮廓、鼻梁、唇峰、首饰、手型、发型或服装材质等身份锚点。
- 人物设计资产图可以按“主视觉区 + 补充信息区 + 左右手特写区 + 局部细节区 + 比例照 + 音色文字说明区”来组织，尤其适合需要校服、制服、明确身高比例、脸部正立标准、手部参考、声音基础设定和配色板的人物。
- 当用户同时提供“人物参考图 + 服装参考图”时，要把两者分工写清：人物图负责脸、身形、年龄感、体态和基础气质；服装图负责版型、层次、颜色、穿着方式和身份识别元素。不要把它们混写成一条抽象的“角色图”。
- 这类人物提示词建议按服装层级顺序写清，例如“内 / 中 / 外 / 腰 / 下 / 足”或“上衣 / 外搭 / 裤装 / 鞋 / 配饰”，这样模型更容易稳定理解服装结构，而不是只记住一个笼统的风格词。
- 主角色人物设计资产默认只固定中性常见表情：正脸自然、脸部肌肉放松、嘴唇自然闭合或轻微放松、眼神正常，不做大笑、哭泣、惊讶、崩溃等多格情绪表情。原因是资产提示词里的表情词通常过于概括，模型会按夸张符号生成，导致脸部肌肉不真实、表情浮夸、后续视频被错误表情锁死。恋爱、悲伤、愤怒、怀疑、崩溃这类情绪表演应留给分镜和视频提示词，逐镜头写清眼神焦点、眼睑、眉心、嘴角、下颌、呼吸、吞咽、手部和身体停顿。
- 图片生成执行单和小批量测试计划。
- 图片候选 A/B/C/D 验收、命名归档和回流建议。
- 封面、海报、标题图和视频截图二创封面提示词。
- 资产优先级和生成顺序建议。

不直接产出：

- 视频最终提示词：交给 `laohu_video_prompt`。
- 生成后整体复盘：交给 `laohu_generation_review`。

## 拆解协议

### 1. 先判断作品资产需求

```text
作品体量：
是否多镜头：
是否多角色：
是否需要角色连续出镜：
是否需要固定场景：
是否有关键道具：
是否需要封面：
后期是否拼接：
```

资产判定必须先回答：

```text
剧本显示称呼：
生产命名：
是否只是抽象泛称：
如果是泛称，是否需要具体化为单一对象：
是否会反复出现：
出现范围：单镜头 / 多镜头 / 多场次 / 多集 / 跨作品
是否需要一致性锁定：
资产类型：图片资产 / 文本资产 / 提示词资产 / 非资产画面元素
图片资产子类型：人物素体 / 人物定装 / 服装妆造 / 组合形象 / 场景多角度 / 物品多角度 / 第一帧
资产编号：
组合关系：例如 A3 = A1 + A2
如果不锁定，会不会影响理解、剪辑或后续生成：
如果只出现一次，是否降级为画面元素或临时参考图：
```

如果角色要跨镜头出现，角色资产优先级高于单镜头画面。如果角色只是一次性路人或功能性角色，不默认做角色资产，只在镜头画面内容里描述。

高频样例：

```text
迎客仙人只在开头出现一次 → 非角色图片资产；写成角色画面元素或单镜头参考图。
迎客仙人的白金道袍、玉冠、仙风道骨礼仪 → 可作为仙界迎宾人物妆造文本资产。
九界仙宫不是同一个固定宫殿反复进入 → 非场景图片资产；写成仙界建筑 / 云海 / 白玉青玉材质文本资产。
同一座主殿会多次进入并多角度拍摄 → 场景图片资产，做三宫格 / 四宫格多角度。
同一个主角跨多个镜头出现且要同一张脸 → 人物图片资产，不可靠纯文字固定。
```

STOP/CHECKPOINT：

```text
资产判定表完成 → 停，等老胡确认哪些资产需要保留或降级。
图片资产提示词完成 → 停，等老胡确认后再进入图片生成或分镜。
图片候选验收完成 → 停，等老胡确认采用哪张图作为资产。
封面方向完成 → 停，等老胡确认后再写封面提示词或生成封面。
```

### 2. 角色资产拆解

角色资产不是人物介绍，而是生成稳定性说明：

```text
角色名：
故事功能：
固定外观：
发型和服装：
年龄和气质：
表情基准：
关键情绪变化：
需要图片资产：
一致性风险：
```

只有角色会跨镜头、跨场次或跨集复用时，才进入角色资产表。一次性迎宾、路人、群众、守门者等功能角色，除非需要后续反复出现或作为封面主体，否则只写成“角色画面元素”。

需要多镜头复用时，优先建议：

- 人物形象资产：环境内电影级正面 / 半正面艺术照，固定第一眼气质、光影和主视觉感觉。
- 人物设计资产：白底 / 简洁背景四区制作参考图，固定五官、身材比例、服装、局部细节和比例照。
- 人物素体资产：白衣 / 中性服装、简洁背景，固定脸、身材、发型和基础体态。
- 服装 / 妆造资产：单独固定服装版型、层次、材质、颜色、纹样和配饰。
- 组合形象资产：人物素体穿上指定服装后的新形象，仍按形象资产和设计资产分开输出。
- 表情组、动作起点参考图或角色一致性网格图。

如果角色长期复用且会换装，先做人物形象资产，再做人物素体资产、服装 / 妆造资产，最后登记组合形象资产，并为组合结果输出人物形象资产和人物设计资产。若角色只在一个场景里出现且不换装，也应至少区分形象资产和设计资产，不要用单张旧版三视图混合图替代两者。

如果角色是 POV 主体，仍按正常人物资产处理：人物形象资产可少用正脸做宣传，但人物设计资产必须包含完整儿童 / 成人身体、身高比例、左手特写、右手特写、服装、鞋、背影、侧面、视线高度参考和音色文字说明区。视频阶段再把这些信息转成 POV 手部、袖口、肩背、低视线、反射里的身份锚点和 `【形象参考@xx】【音色参考@xx】` 调用。

群像人物资产不是主角色资产。它用于稳定“这一群人像什么人”，不用于锁定“每个人是谁”。当跑龙套群众会在连续镜头里围观、起哄、参与轻冲突或提供时代生活气，并且纯文字容易生成成现代人、偶像化人群或气质错误的人群时，可以新增 `G` 系列群像资产。群像资产可以使用场景合照式参考图：一群人站在对应环境里，展示年龄层、服装、发型、站位密度和表情范围。禁止把群像资产写成多个 A 系列主配角；禁止要求每个群众固定姓名、固定脸和完整三视图；具体谁伸手、谁跑动、谁说台词仍写在分镜或视频提示词里。

### 3. 场景资产拆解

场景资产要锁住空间、光影和剪辑连续性：

```text
场景名：
服务场次：
空间结构：
时间和天气：
主光方向：
色彩影调：
可运动空间：
需要图片资产：
不允许变化：
```

只有场景会被多次进入、多角度拍摄、跨场次复用或作为系列长期空间时，才进入场景资产表。一次性远景、一次性时空裂隙、单次天宫大景，默认先归入“场景画面元素 / 氛围参考 / 单镜头参考图”。

场景图片资产不要只做一张单视角漂亮图。固定场景资产优先做三宫格 / 四宫格 / 多角度：主入口、主视角、侧视角、反向视角、局部细节或可运动路径，确保后续分镜能从不同角度进入同一个空间。

当固定场景会多次进入、需要多机位拍摄、或后续分镜可能出现正反打和左右侧视角时，优先做场景四视图设定图。四视图不是四张不同气氛图，而是同一个空间围绕正面视角旋转出来的制作参考：

```text
正面视角：定义场景主入口、主构图、主要物件和纵深。
左侧视角：以正面视角向左转动 90 度，展示左侧墙面、动线和物件侧面。
右侧视角：以正面视角向右转动 90 度，展示右侧墙面、动线和物件侧面。
正面反打图：从正面视角对面看回去，展示反向空间、入口回看和人物可站位。
```

四个视角必须保持同一场景布局一致，视角逻辑正确，物体空间逻辑正确，入口、窗户、桌椅、墙角、灶台、柴火堆等关键物件在四视图中能互相对应。判断标准是：看任意两张图，都能反推出它们属于同一个空间的不同方向，而不是四个相似风格的房间。

四视图不能写成“功能拼图”。错误写法是：格 1 饭桌、格 2 灶台、格 3 遗像桌、格 4 另一个反打空间；这会让模型生成四个相似房间，而不是同一个房间的不同方位。正确写法必须先定义一个正面视角，再说明左侧视角、右侧视角和反打图都从这个正面视角旋转而来，关键物件在四格里能对上位置。

当核心动作发生在桌面、案板、操作台、灶台边、祭祀桌、手工台等局部空间时，先判断要固定的是空间还是物。灶房一角、门窗、墙面、光源和动线属于局部场景；桌子、案板、碗、汤圆、硬币、药碗、针线篮属于道具或家具资产。局部场景资产不能把人物手部、具体道具和动作一起塞进去；物品特写只负责材质和细节；多个资产如何摆放、谁的手从哪里进入、动作如何发生，交给分镜图、视频提示词或视频第一帧参考图处理。

当单镜头里出现“某个物品 + 某个空间”时，先问本次测试到底哪里容易跑偏：如果跑偏的是年代感、场所类型、货架 / 柜台 / 餐桌 / 教室 / 小卖部 / 商场这些空间组织方式，做场景资产；如果跑偏的是木马车、药碗、硬币汤圆、玩具车本体等具体物，做道具资产。错误写法：因为镜头里有玩具，就新增 `P10 玩具车`。正确写法：因为闪回会生成成现代玩具店，所以新增 `S7 商场玩具货架区`，用四视图固定同一个普通商场玩具过道。

### 4. 道具资产拆解

道具必须有故事功能：

```text
道具：
第一次出现：
推动什么信息：
材质和尺寸：
特写需求：
是否影响人物动作：
后续视频用途：
```

### 5. 镜头任务拆解

镜头任务必须写成动作或信息变化：

```text
主角发现异常。
观众第一次看见关键道具。
两人的关系距离发生变化。
角色试图隐藏情绪但失败。
```

禁止写：

```text
表现高级感。
营造氛围。
展示人物悲伤。
```

必须输出四张表：

1. 角色资产表。
2. 群像人物资产表。
3. 场景资产表。
4. 道具资产表。
5. 镜头任务表。

每个资产都要说明服务哪一场戏或哪个镜头。

### 6. 风格决策

当风格不明确或图片 / 视频 / 封面风格冲突时，给 2-3 个方向：

```text
风格方向：
适合原因：
生成风险：
角色资产继承：
场景资产继承：
视频提示词继承：
封面继承：
推荐主风格：
```

如果用户已经给定唯一且不冲突的风格，不强行展开多个方向。

风格不是讨好所有人，而是建立可识别的选择。做视觉方向时必须判断：

```text
这套视觉最想抓住哪类观众。
它主动放弃哪种审美期待。
观众已经熟悉到会忽视的同类画面是什么。
这套视觉的轻微跑调点是什么：形状、色彩、材质、构图、人物缺点、道具、光影、镜头节奏或封面第一眼符号。
跑调点是否服务世界观和作品承诺，而不是无意义怪异。
```

如果视觉方向过于平滑、平均、熟悉、模板化，即使画面漂亮，也要标记为“选择性忽视风险”。首轮测试时至少保留一个不讨好所有人的风格记忆点。

### 7. 图片提示词

图片不是单张好看图，而是视频上游资产。每张图片提示词必须写：

```text
图片用途：
服务场次 / 镜头：
必须锁定：
允许变化：
不能继承：
可复制图片提示词：
是否可作为视频参考图：
```

`可复制图片提示词：` 后必须紧跟一个 `text` 代码块。代码块内只写可直接粘贴到图片模型的正文，例如画幅、主体、构图、光影、材质、风格和抽象质量边界。代码块外写给人看的说明，代码块内写给模型看的内容；跑偏对象和不能混用的资产写在代码块外。

图片模型代码块里禁止用引号做强调。只有画面上确实要出现的文字，才允许以文字指令写入正文，并优先使用 `标签文字为：...`、`标题文字为：...`、`正文文字为：...` 这种无引号写法。手部、表情、服装、构图、气质、风格等说明都不要加引号；否则模型可能把引号内容生成到图片上。

常见资产包括角色定妆、三视图、场景氛围图、道具图、视频第一帧和封面底图。主角色不要默认输出多格表情组或角色一致性情绪网格图，除非老胡明确要求做表情测试；即便要做，也必须写成“测试参考”，不能替代人物设计资产。

人物资产图写法：

```text
人物形象资产：16:9 电影级正面 / 半正面艺术照，写清具体环境、人物姿态、服装材质、眼神、光源方向、照亮部位、阴影结果、色彩影调和叙事瞬间。
人物设计资产：16:9 白底 / 简洁灰白背景扩展分区制作参考图，主视觉区为正面 + 侧面 + 背面，补充信息区为面部正立特写 + 配色板 + 音色文字说明区，手部参考区为左手特写 + 右手特写，局部细节区为配饰 / 袖口 / 鞋 / 书包 / 识别点，比例照锁定身高和头身比。
表情规则：人物设计资产只写中性常见表情，不写多格情绪表情；情绪表演交给视频提示词逐镜头调度。
```

场景资产图写法：

```text
四视图设定图或三宫格 / 四宫格多角度，同一个固定空间，不同视角保持同一结构和光源。四视图优先包含正面视角、左侧视角、右侧视角、正面反打图，并保证物体空间逻辑和对应位置一致。
局部操作空间要先拆资产：空间本身做局部场景资产，桌子 / 案板 / 碗 / 汤圆 / 硬币等可移动物单独做物品资产。场景资产只锁空间结构、入口、光源和动线；物品资产只锁物品本体；手部进入方向和人物站位属于分镜或视频提示词。
```

物品资产图写法：

```text
同一件物品多角度展示，背景简洁，重点固定轮廓、比例、材质、纹理、磨损和可特写细节。
```

常见非资产包括：一次性路人、单镜头奇观、不会回到的场景、只出现一次的入口裂隙、只用于当下画面的云雾光效。它们可以写图片提示词，但文件中必须标注为“单镜头参考图”或“画面元素提示词”，不要混进资产表。

### 8. 图片生成与验收

```text

建议数量：
保存位置：

```

候选图回来后按 A/B/C/D 验收：

```text
A：可直接进入视频参考。

```

验收重点不是好看，而是角色一致性、场景连续性、第一帧可运动性、参考图是否会带偏。

## 判断规则

- 不只列漂亮画面，要列推动故事的画面。
- 不把所有出现过的东西都叫资产；先判断是否复用、是否需要一致性锁定。
- 低保真故事板不是资产，不进入角色 / 场景 / 道具资产表；它只作为分镜参考图提示词，保存到 `04_分镜/文本/`。
- 一次性角色、一次性奇观、单镜头场景优先归为画面元素或临时参考图。
- 图片资产用于固定具体形象；文本资产 / 提示词资产用于固定氛围、妆造、环境、风格和世界观视觉规则。
- 关键资产必须有可识别轮廓、功能逻辑、材质规则、色彩层级和下游调用方式。
- 场景和道具必须能解释入口、尺度、光源、运动路径或使用方式，避免只有气氛没有结构。
- 同一作品的角色、建筑、服饰、法器和神兽要共享世界观设计语法，避免像不同素材库拼贴。
- 角色资产优先稳定：脸、发型、服装、年龄、气质。
- 主角色人物设计资产优先稳定身份和制作细节，不用粗略多格表情锁情绪；表情复杂度由视频提示词负责。
- 场景资产优先统一：空间、光影、色调、时代感。
- 固定场景若需要多角度拍摄，优先做场景四视图设定图；四个视角必须能互相证明是同一个空间。
- 道具资产必须说明故事功能。
- 镜头任务必须是动作或信息变化，不写“氛围感”。
- 动作镜头不要把构图锁死到无法运动。
- 情绪镜头必须预留近景或特写，并交给表演时间轴处理。
- 多镜头拼接必须写入点、出点、声音和色调连续性。

## 反例黑名单

- 不要把所有名词都列成资产。
- 不要把只出现一次的迎宾人物、守门者、群众、云雾、裂隙、远景奇观做成长期资产。
- 不要只做一张漂亮场景图就称为固定场景资产；固定场景必须能支持多角度和运动路径。
- 不要把图片资产和文本资产混成一栏，导致后续不知道靠图片固定还是靠提示词继承。
- 不要为首轮测试一次性铺满所有角色、场景、道具，先保留最小可验证资产。
- 不要让参考图带偏主体；人物资产背景要简单，场景资产才允许背景成为主体。
- 不要把没有故事功能的道具升级为关键道具资产。

## 自检

输出前检查：

- 是否每个资产都服务具体场次或镜头。
- 是否把只出现一次的角色、场景或奇观误列为资产。
- 是否给出资产 / 画面元素 / 临时参考图的分类理由。
- 是否区分图片资产和文本资产 / 提示词资产。
- 是否遵守资产唯一性原则：一个资产只固定一个人物、一个道具、一个场景或一套服装 / 妆造；是否把混合元素拆成多个单一资产，而不是写成分镜图。
- 是否把低保真故事板和图片资产分开：故事板只锁构图、景别、站位、比例、空间锚点、引导线、动线和留白，不锁具体外观、颜色、材质和最终光影。
- 是否先判断失真来源再决定资产类型：年代环境、陈列方式、空间语法和灯光跑偏时做场景资产；物品本体形状、材质和特写跑偏时做道具资产。
- 群众、同学、邻家孩子、亲戚、村民等是否先判断为画面元素、群像人物资产或主角色资产；是否避免把跑龙套群像误拆成多个固定主配角，也避免完全不固定导致时代感和服装气质漂移。
- 是否存在“漂亮但没用”的资产。
- 关键资产远看是否能识别身份、功能和世界观归属。
- 场景资产是否有入口、尺度、光源、运动路径和多角度复用价值。
- 场景四视图是否包含正面视角、左侧视角、右侧视角、正面反打图，且物体空间逻辑、关键物件位置和视角旋转关系一致；是否避免把四格写成功能拼图或四个相似房间。
- 桌面、案板、操作台、祭祀桌、手工台等核心动作空间，是否先区分“空间资产”和“道具 / 家具资产”；是否避免把空间、道具、人物手部和动作混成一个资产。
- 色彩和材质是否形成统一体系，而不是每个资产各自好看。
- 人物设计资产是否建立同一份造型账本：三视图、手部特写、局部细节、配色板和比例照里的服装、发饰、首饰、包、鞋履、腕饰状态是否一致；局部细节标签是否和物件一一对应。
- 人物设计资产是否避免右侧比例图和左侧三视图重复：身高和身体节点厘米标注是否已经合并到三视图；右侧是否改为摄影棚真实人像状态区，用胸部以上中近景、中性灰背景、柔和主光、侧逆轮廓光和明暗层次校准脸部皮肤、妆容、姿态、首饰和上半身服装。
- 人物设计资产是否先锁住资产本体的肤色妆效：如果该资产会作为视频参考图，三视图、脸部特写和手部模块是否统一为冷白偏中性、白皙通透、肤色匀净、清透裸妆、轻薄服帖底妆、柔雾奶油肌、柔雾哑光带内透光肤感；是否避免继承参考图里的偏黄光源、油亮肤感、大片高光、厚粉网红妆和塑料磨皮。
- 角色是否有可复用参考图策略。
- POV 主体是否已经建立完整人物资产，包含身高、比例、左手特写、右手特写、服装、鞋、背影和视线高度，而不是只做局部身份锚点。
- 人物设计资产是否已经包含清晰的音色文字说明区；会说话、VO 或画外音的角色是否记录了可供视频提示词调用的 `【音色参考@xx】`。
- 场景光影是否能跨镜头统一。
- 道具是否有故事功能。
- 镜头任务是否能生成、能诊断、能剪辑。
- 风格是否已经收敛成一个主方向。
- 风格是否有边界，是否避免为了讨好所有人而被磨平。
- 是否设计了一个服务作品承诺的轻微跑调点，降低选择性忽视风险。
- 图片提示词是否写清用途、锁定、允许变化、不能继承和质量边界。
- 图片提示词是否把可复制投喂正文单独放进代码块，且代码块外没有需要老胡手动拼进去的提示词片段。
- 图片模型代码块里是否只在真实画面文字处使用文字指令，是否避免用引号做强调；左手 / 右手、音色说明等标签是否写成标签文字为、标题文字为、正文文字为，而不是把长解释放进画面标签。
- 图片生成是否有小批量执行单。
- 图片验收是否有 A/B/C/D 和回流路径。
- 封面是否检查标题、主体和缩略图可读性。
- 是否标出失败风险和生成优先级。
- 是否输出视觉资产交接包，方便图片、风格和视频设定继承。
