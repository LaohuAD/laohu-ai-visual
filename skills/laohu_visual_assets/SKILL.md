# 视觉资产核心

## 能力定位

把剧本、分场、单镜头或世界观设定拆成后续图片生成、视频生成、封面发布和剪辑需要的视觉资产。

这个 skill 合并原先的风格导演、图片资产提示词、图片生成交接、图片验收和封面提示词。它不负责把画面写漂亮，而是负责判断“为了让作品能连续生成、能测试、能发布，需要准备哪些视觉资产”。

## 能力加厚纪律

本 skill 不只是从剧本里抽名词，而要把剧本翻译成可生成资产体系。每个角色、场景、道具和镜头任务都要先判断它到底是“可复用资产”，还是“单次画面元素”。只有需要跨镜头、跨场次、跨集或跨作品复用，或者需要锁定外观、空间、材质、比例、色彩和连续性的内容，才进入资产表。

一次性出现的路人角色、单次奇观、单镜头场景、一次性时空裂隙和只服务某个镜头的画面，不默认叫资产。它们应进入镜头画面元素、单镜头参考图、临时生成素材或分镜提示词内容。

视觉资产内部必须区分两种资产：

```text
图片资产：用图片固定具体形象和一致性。
文本资产 / 提示词资产：用文字固定氛围、妆造、环境、风格和世界观视觉规则。
```

如果对象需要保持同一个脸、同一套服装、同一件道具或同一个空间，优先考虑图片资产。如果对象不需要固定为同一张图，但其风格、妆造、服饰、环境气质或材质规则需要被后续镜头继承，优先做文本资产 / 提示词资产。

提示词资产不是低级资产。基础设定、氛围与画质、人物妆造、服饰体系、场景大类规则、色彩材质、声音气质和世界观视觉规则，都可以成为跨镜头复用的提示词资产。后续生成正式视频提示词时，不能只写“调用提示词资产 A1”，必须把 A1 的具体规则展开到正式提示词正文中。

图片资产必须继续判断子类型：

```text
人物素体资产：固定脸、身材、年龄、发型、基础体态。通常白衣 / 中性服装，简洁灰白背景。
人物定装资产：同一个人物穿固定服装、发饰、妆容后的完整形象。
服装 / 妆造资产：单独固定服装、发饰、妆容、配饰、盔甲，供后续叠加到人物素体。
组合形象资产：人物素体资产 + 服装 / 妆造资产组合后的新形象资产。
场景图片资产：同一个固定空间的三宫格 / 四宫格 / 多角度视图，锁定结构、入口、主视角、反向视角、光源和可运动路径。
物品图片资产：同一件物品的多角度和材质细节，背景尽量简单。
```

人物图片资产推荐 16:9 横幅：左侧放脸部特写 / 表情参考，右侧放全身三视图或多角度视图。背景应简洁，避免强场景色干扰人物。场景资产不要求简洁背景，因为场景本身就是主体；物品资产则应尽量使用简单背景，突出形状、材质和比例。

资产编号必须稳定记录：

```text
A1：人物素体资产。
A2：服装 / 妆造资产。
A3：A1 穿着 A2 后形成的组合形象资产。
```

助手不负责实际图片合成，但要负责规划、命名和记录组合关系。后续如果老胡生成了 A3 图片，资产表要把 A3 登记为可调用图片资产。

如果剧本信息不够，要补“暂定视觉假设”和“必须回问或待定字段”；如果资产过多，要先选首轮验证最小资产，而不是一次铺满全片。

首轮验证最小资产规则：

```text
短片 / 首测 / 单条视频验证 → 只保留会跨镜头复用、会影响一致性或会作为封面 / 第一帧的资产。
一次性人物 → 降级为画面元素或单镜头参考图。
一次性奇观 → 降级为画面元素、氛围参考或文本资产的一部分。
反复继承的风格、服饰、建筑、材质、色彩、礼仪 → 优先做文本资产 / 提示词资产。
```

风格、图片提示词、生成交接、图片验收、封面都归在本 skill 内处理。不要为了同一个作品在多个零散 skill 之间跳来跳去。

视觉资产、资产图片提示词、封面提示词和图片验收结论都必须写入文件。对话里只给文件链接、当前阶段摘要和是否确认进入下一阶段。除非老胡明确要求粘贴全文，不要在聊天中直接输出长提示词集合。

资产图片提示词、封面提示词和图片验收文件默认在同一个阶段文件上迭代，不自动新建 v1/v2/v3。只有老胡明确要求新增版本、另存一版或 A/B 两版时，才创建新版本文件。

## 内置质量校准视角

以下视角只用于提高资产设计质量，不改变输出结构，不在正式文件里新增专家分析栏目。

| 视角 | 内部校准方式 |
|---|---|
| Ralph McQuarrie | 关键资产先看大轮廓和第一眼识别度：远看能不能认出身份、阵营、时代和功能。不要只堆纹样。 |
| Syd Mead | 场景和道具要有功能逻辑：它为什么长这样，人在里面如何移动，光源、入口、尺度和材质是否自洽。 |
| Moebius | 奇幻世界要有陌生感和留白，不要把画面塞满同一种符号。仙界奇观要有呼吸空间和视觉节奏。 |
| Doug Chiang / Iain McCaig | 角色、服装、建筑、道具要属于同一个世界观设计语法；形状语言、材质体系和色彩层级要能互相继承。 |
| Feng Zhu | 资产不是漂亮插画，而是生产设计。每个资产都要明确可复用角度、生成用途、失败风险和下游调用方式。 |
| 张艺谋 / Christopher Doyle | 东方视觉要注意色彩仪式感、人物与空间的关系、主色和点睛色。不要让全片变成单一金白或单一蓝紫。 |
| 胡金铨 / 徐克 / 程小东 | 仙侠资产要同时服务礼仪、身法和空间调度：衣袖、法器、门、桥、旗、云层都可以成为动作和转场工具。 |

资产设计时优先问：这个东西是否真的会复用，是否能锁定一致性，是否能帮助视频生成和剪辑。不能因为名字好听就升级成资产。

## 拆解协议

### 1. 先判断作品资产需求

```text
作品体量：
是否多镜头：
是否多角色：
是否需要角色连续出镜：
是否需要固定场景：
是否有关键道具：
是否需要封面：
后期是否拼接：
```

资产判定必须先回答：

```text
是否会反复出现：
出现范围：单镜头 / 多镜头 / 多场次 / 多集 / 跨作品
是否需要一致性锁定：
资产类型：图片资产 / 文本资产 / 提示词资产 / 非资产画面元素
图片资产子类型：人物素体 / 人物定装 / 服装妆造 / 组合形象 / 场景多角度 / 物品多角度 / 第一帧
资产编号：
组合关系：例如 A3 = A1 + A2
如果不锁定，会不会影响理解、剪辑或后续生成：
如果只出现一次，是否降级为画面元素或临时参考图：
```

如果角色要跨镜头出现，角色资产优先级高于单镜头画面。如果角色只是一次性路人或功能性角色，不默认做角色资产，只在镜头画面内容里描述。

高频样例：

```text
迎客仙人只在开头出现一次 → 非角色图片资产；写成角色画面元素或单镜头参考图。
迎客仙人的白金道袍、玉冠、仙风道骨礼仪 → 可作为仙界迎宾人物妆造文本资产。
九界仙宫不是同一个固定宫殿反复进入 → 非场景图片资产；写成仙界建筑 / 云海 / 白玉青玉材质文本资产。
同一座主殿会多次进入并多角度拍摄 → 场景图片资产，做三宫格 / 四宫格多角度。
同一个主角跨多个镜头出现且要同一张脸 → 人物图片资产，不可靠纯文字固定。
```

STOP/CHECKPOINT：

```text
资产判定表完成 → 停，等老胡确认哪些资产需要保留或降级。
图片资产提示词完成 → 停，等老胡确认后再进入图片生成或分镜。
图片候选验收完成 → 停，等老胡确认采用哪张图作为资产。
封面方向完成 → 停，等老胡确认后再写封面提示词或生成封面。
```

### 2. 角色资产拆解

角色资产不是人物介绍，而是生成稳定性说明：

```text
角色名：
故事功能：
固定外观：
发型和服装：
年龄和气质：
表情基准：
关键情绪变化：
需要图片资产：
一致性风险：
```

只有角色会跨镜头、跨场次或跨集复用时，才进入角色资产表。一次性迎宾、路人、群众、守门者等功能角色，除非需要后续反复出现或作为封面主体，否则只写成“角色画面元素”。

需要多镜头复用时，优先建议：

- 人物素体资产：白衣 / 中性服装、简洁背景，固定脸、身材、发型和基础体态。
- 人物定装资产：该角色穿固定服装的三视图和表情特写。
- 2x2 或 3x3 角色一致性网格图。
- 表情组。
- 动作起点参考图。

如果角色长期复用且会换装，先做人物素体资产，再做服装 / 妆造资产，最后登记组合形象资产。若角色只在一个场景里出现且不换装，可以直接做人物定装资产。

### 3. 场景资产拆解

场景资产要锁住空间、光影和剪辑连续性：

```text
场景名：
服务场次：
空间结构：
时间和天气：
主光方向：
色彩影调：
可运动空间：
需要图片资产：
不允许变化：
```

只有场景会被多次进入、多角度拍摄、跨场次复用或作为系列长期空间时，才进入场景资产表。一次性远景、一次性时空裂隙、单次天宫大景，默认先归入“场景画面元素 / 氛围参考 / 单镜头参考图”。

场景图片资产不要只做一张单视角漂亮图。固定场景资产优先做三宫格 / 四宫格 / 多角度：主入口、主视角、侧视角、反向视角、局部细节或可运动路径，确保后续分镜能从不同角度进入同一个空间。

### 4. 道具资产拆解

道具必须有故事功能：

```text
道具：
第一次出现：
推动什么信息：
材质和尺寸：
特写需求：
是否影响人物动作：
后续视频用途：
```

### 5. 镜头任务拆解

镜头任务必须写成动作或信息变化：

```text
主角发现异常。
观众第一次看见关键道具。
两人的关系距离发生变化。
角色试图隐藏情绪但失败。
```

禁止写：

```text
表现高级感。
营造氛围。
展示人物悲伤。
```

必须输出四张表：

1. 角色资产表。
2. 场景资产表。
3. 道具资产表。
4. 镜头任务表。

每个资产都要说明服务哪一场戏或哪个镜头。

### 6. 风格决策

当风格不明确或图片 / 视频 / 封面风格冲突时，给 2-3 个方向：

```text
风格方向：
适合原因：
生成风险：
角色资产继承：
场景资产继承：
视频提示词继承：
封面继承：
推荐主风格：
```

如果用户已经给定唯一且不冲突的风格，不强行展开多个方向。

风格不是讨好所有人，而是建立可识别的选择。做视觉方向时必须判断：

```text
这套视觉最想抓住哪类观众。
它主动放弃哪种审美期待。
观众已经熟悉到会忽视的同类画面是什么。
这套视觉的轻微跑调点是什么：形状、色彩、材质、构图、人物缺点、道具、光影、镜头节奏或封面第一眼符号。
跑调点是否服务世界观和作品承诺，而不是无意义怪异。
```

如果视觉方向过于平滑、平均、熟悉、模板化，即使画面漂亮，也要标记为“选择性忽视风险”。首轮测试时至少保留一个不讨好所有人的风格记忆点。

### 7. 图片提示词

图片不是单张好看图，而是视频上游资产。每张图片提示词必须写：

```text
图片用途：
服务场次 / 镜头：
必须锁定：
允许变化：
不能继承：
画面提示词：
负面约束：
是否可作为视频参考图：
```

常见资产包括角色定妆、三视图、表情组、角色一致性网格图、场景氛围图、道具图、视频第一帧和封面底图。

人物资产图写法：

```text
16:9 横幅构图。左侧为人物脸部特写 / 表情参考；右侧为全身三视图或多角度视图。背景为简洁灰 / 白，避免强场景、强色彩或复杂道具干扰人物识别。
```

场景资产图写法：

```text
三宫格 / 四宫格多角度，同一个固定空间，不同视角保持同一结构和光源。包含主入口、主视角、侧视角、反向视角或关键局部。
```

物品资产图写法：

```text
同一件物品多角度展示，背景简洁，重点固定轮廓、比例、材质、纹理、磨损和可特写细节。
```

常见非资产包括：一次性路人、单镜头奇观、不会回到的场景、只出现一次的入口裂隙、只用于当下画面的云雾光效。它们可以写图片提示词，但文件中必须标注为“单镜头参考图”或“画面元素提示词”，不要混进资产表。

### 8. 图片生成与验收

图片提示词准备好后，输出生成执行单：

```text
提示词版本：
目标模型：
建议数量：
保存位置：
命名规则：
生成后回传字段：
```

候选图回来后按 A/B/C/D 验收：

```text
A：可直接进入视频参考。
B：小修可用。
C：只保留为参考，不进入视频。
D：失败，进入失败复盘。
```

验收重点不是好看，而是角色一致性、场景连续性、第一帧可运动性、参考图是否会带偏。

### 9. 封面与海报

封面服务点击和发布，不是普通剧照。必须判断：

```text
平台：
第一眼钩子：
主体冲击力：
标题文字：
标题位置：
字体气质：
手机端缩略图可读性：
是否与视频内容承诺一致：
```

```text

| 资产名 | 固定什么规则 | 适用范围 | 继承方式 | 禁止偏移 |

【全局连续性表】
| 项目 | 统一规则 | 禁止变化 |

【角色资产表】
```

## 判断规则

- 不只列漂亮画面，要列推动故事的画面。
- 不把所有出现过的东西都叫资产；先判断是否复用、是否需要一致性锁定。
- 一次性角色、一次性奇观、单镜头场景优先归为画面元素或临时参考图。
- 图片资产用于固定具体形象；文本资产 / 提示词资产用于固定氛围、妆造、环境、风格和世界观视觉规则。
- 关键资产必须有可识别轮廓、功能逻辑、材质规则、色彩层级和下游调用方式。
- 场景和道具必须能解释入口、尺度、光源、运动路径或使用方式，避免只有气氛没有结构。
- 同一作品的角色、建筑、服饰、法器和神兽要共享世界观设计语法，避免像不同素材库拼贴。
- 角色资产优先稳定：脸、发型、服装、年龄、气质。
- 场景资产优先统一：空间、光影、色调、时代感。
- 道具资产必须说明故事功能。
- 镜头任务必须是动作或信息变化，不写“氛围感”。
- 动作镜头不要把构图锁死到无法运动。
- 情绪镜头必须预留近景或特写，并交给表演时间轴处理。
- 多镜头拼接必须写入点、出点、声音和色调连续性。

## 反例黑名单

- 不要把所有名词都列成资产。
- 不要把只出现一次的迎宾人物、守门者、群众、云雾、裂隙、远景奇观做成长期资产。
- 不要只做一张漂亮场景图就称为固定场景资产；固定场景必须能支持多角度和运动路径。
- 不要把图片资产和文本资产混成一栏，导致后续不知道靠图片固定还是靠提示词继承。
- 不要为首轮测试一次性铺满所有角色、场景、道具，先保留最小可验证资产。
- 不要让参考图带偏主体；人物资产背景要简单，场景资产才允许背景成为主体。
- 不要把没有故事功能的道具升级为关键道具资产。

## 自检

输出前检查：

- 是否每个资产都服务具体场次或镜头。
- 是否把只出现一次的角色、场景或奇观误列为资产。
- 是否给出资产 / 画面元素 / 临时参考图的分类理由。
- 是否区分图片资产和文本资产 / 提示词资产。
- 是否存在“漂亮但没用”的资产。
- 关键资产远看是否能识别身份、功能和世界观归属。
- 场景资产是否有入口、尺度、光源、运动路径和多角度复用价值。
- 色彩和材质是否形成统一体系，而不是每个资产各自好看。
- 角色是否有可复用参考图策略。
- 场景光影是否能跨镜头统一。
- 道具是否有故事功能。
- 镜头任务是否能生成、能诊断、能剪辑。
- 风格是否已经收敛成一个主方向。
- 风格是否有边界，是否避免为了讨好所有人而被磨平。
- 是否设计了一个服务作品承诺的轻微跑调点，降低选择性忽视风险。
- 图片提示词是否写清用途、锁定、允许变化和负面约束。
- 图片生成是否有小批量执行单。
- 图片验收是否有 A/B/C/D 和回流路径。
- 封面是否检查标题、主体和缩略图可读性。
- 是否标出失败风险和生成优先级。
- 是否输出视觉资产交接包，方便图片、风格和视频设定继承。
