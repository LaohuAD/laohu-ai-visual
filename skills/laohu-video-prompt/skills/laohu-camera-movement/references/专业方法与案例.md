# 运镜：专业方法与案例

## 当前专业决策

推轨改变摄影机位置；变焦改变视角范围；摇摄主要改变视轴；拉焦改变清晰平面。四者引发的视差、遮挡、主体占比和注意力变化不同，所以“推近焦点”不能同时代替四套控制。摄影机路线应由观众需要获得的新证据倒推。

先写起点观看侧、主体与锚点，再比较固定观看、机身位移、视轴转动、焦平面迁移；只保留能新增信息的一种主机制，写经过何物、何时露出目标、最终构图。适合揭示遮挡后关系、追随路线、表现距离压力；反例是已经充分清楚的微表情近景却机械环绕，或以变焦声称穿过门洞。

### 同一材料候选比较

候选A：同一桌侧钥匙揭示：环绕人物一周，最后切钥匙特写。

候选B：沿桌缘小幅横移，让杯缘先挡后露钥匙；停在钥匙和人物眼线同框处。

取舍：后者沿一次真实观看路径揭示原有对象；前者新增无必要空间和切点。

适用与反例：固定近景已有充分表演证据时保持摄影机稳定，不为“高级”添加运动。

### 编译或返修结果示例

“摄影机保持桌侧高度，沿桌缘向右平移；近处水杯先遮住他的手，杯缘滑开后露出压在纸下的钥匙，移动停在钥匙与他垂下的眼线同时可见的位置。”前提是钥匙与动作已获源剧本授权。

### 返回合同

返回摄影机起点—路径—停点、屏幕结果与焦平面合同；指出本次改变哪个决定、原有哪项事实不能动、从哪个状态开始以及下一负责人如何验收。输入缺口影响因果时停止专业深化，带证据返回；不把下游修词当作上游事实已存在。

## 完整专业方法


## 摄影机注意力合同

当且仅当当前单元是纸拼贴／分层纸雕／3D纸艺机关类知识讲解 `AI_VIDEO_FULL`，上游真实KF存在可追踪轨道、纸带、门洞、层间通道或明确输入—处理—结果空间时，正式提示词必须先在内部建立`摄影机注意力合同`。它不是第四个输出区块，而是编译进`【画面内容】`的一组因果字段：

```text
起始位置与朝向：摄影机从哪一个真实空间锚点开始，面对哪条已存在路径。
cameraRoute：沿哪些真实轨道、纸带、数据流、门洞或层间通道连续前进；起点、节点和终点可追踪。
revealOrder：按 KnowledgeVisualContract.semanticAnchors 的什么顺序揭示语义节点，哪些信息此时仍不得成为第一焦点。
attentionTarget：每一步唯一第一焦点是什么；上一焦点完成什么可见变化后才移交。
movementPurpose：为什么此时移动、移动揭示哪条知识关系；只写“酷、沉浸、电影感”视为缺失。
transitionOccluder：用哪一个真实前景纸层、门、轨道护栏、装置外壳或近景物件完成连续遮挡和焦点交接。
speedCurve：进入、接近、跨越、减速、停稳的速度变化；不能全程同速或持续高速。
focusTransfer：焦平面、构图主次和注意力怎样从已理解状态移到新状态。
readabilityDwell：已有准确标签、数字、问号、对勾或结论结果需要多少稳定阅读时间；移动中的文字不承担解释。
finalPayoff：摄影机最终抵达什么结果，哪条输入—处理—结果关系仍能回看，结果停点持续多久。
semanticAnchorBinding：逐条写 spokenCue → visualEvent → 知识状态；每次移动都绑定一条真实语义锚点。
```

每一步移动必须能回答：去哪里，为什么现在揭示，揭示了哪条关系或作用路径，绑定哪一条`spokenCue → visualEvent`，并给下一步留下什么知识状态。答不出任一项，删除该移动或退回重编译。固定正面把四张卡始终同权摆满、只靠翻牌／发光轮流点名，或FPV只写高速穿越、环绕、俯冲而未绑定语义锚点，都不能通过。

适用范围不能外溢：FPV式连续穿越是强纵深纸艺知识场景的候选手法，不是全项目质量等级。普通人物对话、一般转场、平面编辑拼贴、没有可追踪因果通道的解释或任何移动会伤害表演、文字与关系理解的内容，保留固定摄影机或更克制的合适机位；运动不能伤害理解，也不得为套用FPV新造参考图中不存在的轨道、门和机关。


## 摄影机与屏幕变化

运镜术语不能独自承重。先写摄影机在现实或虚拟空间怎样移动，再写观众屏幕上发生什么：主体大小、角度、遮挡、焦点、方向、背景视差和最终构图如何变化。

复杂镜头先用方头概览景别演变、机位、摄影机路线、动态构图和节奏，再由正文沿同一条因果顺序展开。方头只负责导航，不能替正文省略路径；正文只负责执行，不另起一套与方头不同的机位和构图。

复杂方头里的景别演变和组合运镜仍然服从镜头原子：它们只能沿一条不中断的摄影机路径观察同一主要内容。方头的景别栏、机位栏或正文中只要写出两个靠切镜连接的观察位置，这就已经是两个镜头；把“硬切”写进同一镜头正文，属于结构失败，不能进入VC。

真人和三维空间使用实体 / 虚拟摄影机；MG、UI、二维动画和字幕动效优先写视窗、图层、遮罩、版式和焦点迁移。固定镜头可以成立，但要写清观看边界和画内变化，不为“高级”强造运动。

景别是证据边界。特写不能同时证明远处空间，中远景不能靠几像素脸部承担微表情。需要跨尺度时写清切近、拉远、视窗缩放、遮罩展开或版式重排。

多人场面先做两层空间排演，再写摄影机：世界层记录每个人相对固定锚点、桌椅、门窗或道具的方位、距离、朝向、进入路径和接触对象；屏幕层记录当前机位下每个人落在画面左中右、前中后景、谁遮挡谁、视线越过什么以及运动方向。换机位只能改变屏幕投影，不能改写世界位置。若同一人物在相邻镜头从左后方无过程地变成正前方，或群体从包围关系变成并排合照，空间排演即判失败。

人物素体、群像合照和服装资产主要锁身份、比例与造型，不自动拥有叙事构图权。参考图若是正面并排校准照，而正片需要侧后包围、前后遮挡或复杂走位，必须把“身份参考”和“调度参考”分开：身份图只负责谁是谁；另用镜头首帧、故事板、简模 / clay render 或已验收视频片段负责机位、空间结构、动作路径和阻挡关系。不能只靠一句“仅参考身份”抵消一张强构图图片对模型的影响。

后文才揭示的观察者、控制者或亲密关系可以在前文留下可回看的摄影证据，但必须先建立`关系视点合同`：视点是角色主观、受限第三人称还是中性观察；真实`观察者位置`在哪里；人物与摄影机之间的`视线通道`是否成立；`遮挡来源`是哪扇门、哪块家具、帘边或人群；当时谁知道什么；后文用什么动作、位置或声音验证这层关系。`主观镜头必须属于`一个当时真实存在且能看见该画面的角色；否则只能写成受限观察构图，不得暗示虚构的偷窥者。遮挡本身不等于偷窥，它还可能只负责纵深、隐藏剪辑点或限制信息；若没有人物关系和空间证据，不为悬疑机械增加黑色虚化前景。


## 先选择观察系统，不强造运镜

不同媒介使用不同的观察语法：

```text
真人实拍 / 空间表演：使用实体摄影机，写机位、轴线、景别、焦点、遮挡和空间视差。
三维动画 / 合成奇观：使用虚拟摄影机，仍写空间路径，但同时说明尺度、层级、材质和合成对象的相对运动。
二维动画 / MG / UI / 字幕动效：优先写视窗、版式、图层、遮罩、缩放、平移、重排和焦点迁移，不把图形位移伪装成真人摄影机运动。
静态机位 / 定帧构图：明确机位和构图保持不动，再写人物表演、产品状态、光影、声音或图形内部怎样改变。
```

运镜是改变观看关系的手段，不是动态内容的硬指标。固定机位中的一次吸气、一次视线回避、产品指示灯由红转绿、柱状图在同一坐标系内重新排序，都可以构成完整事件。只有摄影机、视窗或构图焦点真的发生变化时才描述其路径；不运动时写清固定边界与画内变化，不能为了显得高级强行推拉摇移。


## 连续长镜头与切镜路线

`单一长镜头`有真实用途：它可以保住空间路线、动作因果、表演累积和现场时间，减少独立生成单元之间的身份与状态重建。但它也会把人物漂移、后半段遗忘、复杂调度和错误不可剪切地绑在一起。是否使用长镜头，不按“高级 / 不高级”判断，而按承重结果判断：

```text
若切开会损失实时压力、表演累积、空间路线或一次不可替代的动作完成感
→ 优先连续长镜头，并设计可恢复的内部停点。

若每次观看位置变化都要新增信息，或入口在长时生成中持续丢动作 / 漂身份
→ 使用片内切镜或拆批，并为每个切点建立共同载体与状态合同。
```

长镜头正文不能只写“一镜到底”。它要写摄影机起点、可行路线、人物与锚点的相对运动、遮挡如何临时发生、何处改变景别或焦平面、主要兑现在哪里完成、最后怎样稳定。即使选择长镜头，也要在动作完成、构图暂稳、声音收束或遮挡出现的位置埋入可裁切停点，避免一次局部失败拖垮整段。


## FOV、焦段与可见结果

`FOV`与焦段表的价值，是约束“这一刻能同时读到多少空间、距离被怎样感知、前后景关系怎样变形”，不是给每镜机械分配一个数字。先决定可见结果，再按目标入口能力选择是否写数值：

| 目标结果 | 画面证据 | 可选光学方向 |
|---|---|---|
| 读清多人、入口、桌椅和破坏状态的拓扑 | 人物与锚点同时入画，遮挡可读，边缘不过度拉伸 | 较宽视场 / 广角至中广角；空间很小时谨慎控制边缘畸变 |
| 压缩人物距离、制造窥视或围困 | 前后人物看似更接近，背景尺度被压平 | 较窄视场 / 中长焦 |
| 保留脸部关系同时看见手与道具 | 面部比例自然，上半身与接触点同画 | 标准至中焦 |
| 主观逼近、速度与边缘张力 | 近物快速扩张、背景视差明显 | 近距离广角，但必须接受和管理形变 |

正文优先写主体占比、边缘形变、空间压缩、背景视差、可见锚点和最终构图。只有目标系统稳定理解具体焦段 / FOV 且数值会改变结果时才追加参数；数值与可见描述冲突时，以重新设计镜头为先，不能靠堆两个相反焦段补救。


## 8K、IMAX与成像召回锚点

`8K`、`IMAX`、`large-format`等词可能在部分模型中召回高清细节、大画幅摄影、宽动态范围或特定商业电影语料，因此不能因为它们是常见词就全盘删除；但它们也不能证明入口会输出真实 8K，更不能替代分辨率参数、空间构图、动态范围、镜头反应和材质证据。

只在以下条件同时成立时，把它们作为`成像召回锚点`：目标入口的实测结果显示该词确实改善承重画面；它与作品结果图成像合同同向；界面参数已经承担真实输出规格；正文仍写清可见结果，例如大画幅空间层次、高光不过曝、暗部保留关系、皮肤与材料的细节尺度。若加入后只变得过锐、塑料、假HDR或抢走人物注意力，移除召回词，保留真正起作用的光线、动态范围、纹理与镜头条件。


## 电影视觉母体转译

本分支只在用户明确要求电影感、电影正片感、导演 / 摄影参考、影像风格、宽银幕叙事，或生成结果出现“漂亮但像海报 / CG / 游戏截图”时启用。它不是新的题材分类，也不因为画面里有剧情就自动加载。主 Reference 仍由观众承诺和主导机制决定；本分支只把影像审美翻译成可观察、可生成、可验收的镜头条件。


## 影像母体不是风格词

“电影感、史诗、克制、真实、导演感、胶片质感”都不能直接作为完成条件。先把本段影像母体拆成一组不变量，再决定哪些内容可以变化：

```text
观众承诺：观众要进入什么观看位置、感到什么关系压力或时间状态。
摄影机权限：摄影机为什么在这里，它能看见什么，又被什么遮住或限制。
空间语法：人物、建筑、道具、留白、轴线和前中后景怎样共同施压。
视线流量：视线从哪里进入，被什么放慢 / 阻断，落到哪个决定性信息，最后从哪里离开。
光色来源：颜色和明暗来自哪盏灯、哪种天气、哪件服装、哪种材料或哪片反射。
成像基底：本段像由什么摄影介质捕获，清晰度、动态范围和边缘响应有什么限制。
时间证据：本镜留下什么前后帧线索，事件如何推进，结尾留下什么未完成状态。
```

从中锁定少数真正承重的不变量，不设固定数量，也不为填表把每项都写进正文；人物、地点、道具、色板、焦段、媒介和动作可以作为可变槽，但不能让可变项破坏摄影机权限、空间关系、光色来源或事件状态。如果所谓母体只剩颜色、颗粒、宽画幅或浅景深，说明它仍是表面滤镜，必须退回关系、空间与事件层重做。


## 不变量与可变槽

内部先建立一张简短的影像母体卡：

```text
主观看任务：这一段最先让观众看见什么。
主空间压力：人物被谁 / 什么限制，或谁在控制观看权限。
主构图机制：只选一个主要压力，如被观察、被困住、关系疏离、权力不对等或心理失衡。
主色彩命题：颜色从哪里来，它怎样改变事件判断。
成像与缺陷：只选一个主要成像基底和一个主要不完美来源。
序列变化：每个镜头新增什么信息、关系、尺度、证据或后果。
余韵出口：最后停在人物、动作、物件、空间、声音或缺席的哪个状态。
```

正式提示词只把会改变生成结果的部分写进去：全局不变量进入 `【场景状态与氛围画质】`，本镜变化进入 `【画面内容】`，内部判断表不直接投喂模型。一个镜头只保留一个主画面内容、一个主构图决定、一个主故事线索和按需一个从属线索；普通、暗、软、遮挡或留空的信息不是缺陷，而是给决定性信息让位的选择。只有特殊机位、特殊光学或特殊光线改变信息权限、关系压力或身体感时才使用，不能用来装饰“电影感”。


## 镜头原子：一镜一事

镜头原子以一次不中断的摄影机观看为边界，不以一段剧情、一组因果或一个时间区间为边界。每个镜头先用一句话命名唯一内容，例如`右前轮主动压入水坑`、`后视镜里老人受损，司机看见后发笑`、`老人看见前方泥沟`。若“再切到”等连接实际断开的观察位置，则已包含多个镜头；“然后又看”若只是同一连续时空中的拉焦或揭示，应检查整体目的与连续路径，不能只按连词拆镜。

逐镜只保留：当前看什么、开场构图是什么、对象发生哪一项主变化、摄影机怎样连续观察、结束构图留下什么。人物可以在同一镜头内完成一个连续动作的相位变化，摄影机也可以推、拉、摇、移或改变焦点，多个信息节拍可以随运镜顺序揭示，只要共同服务一个整体观看目的，时空与观察路径连续。泥水由车轮升起并扑满镜头属于同一物理事件；水坑低机位同时看见车内手转方向盘、路边菜筐、老人全身和司机表情，则是不可成立的观察位置拼盘。

实际插入特写、客观转主观的切换、正反打、车内切车外、局部切全景，以及硬切、软切、时间跳跃或不连续机位，必须新开段内C编号。新人物反应、后视镜或车轮成为焦点、从局部揭示全景，若在同一连续路径内发生则不自动拆镜。新镜头方头承担真实转场，上一镜正文只写到自身结束构图；同一P内C连续编号，P边界不由运镜专业改写。信息节拍的清楚与观看连续性共同决定质量，不按镜头数量判密度。


## 电影化提示词的正向编译

出现“电影感”需求时按以下顺序写，不先堆电影术语：

```text
关系压力 / 观众位置
→ 真实摄影机位置与信息权限
→ 视线入口、阻断、落点和出口
→ 人物 / 道具 / 空间的一个可见事件
→ 光色与材质的画内来源
→ 成像限制与局部光学反应
→ 停点、余波和下一镜状态
```

“真实电影剧照、史诗、沉浸、大片质感、胶片感”只能作为内部检查标签，不能代替上述内容。正文必须让模型看见摄影机位置、主体状态、空间参照、动作结果和停点；对视频而言，还必须让画面在运动中发生可观察变化。宽画幅只是生成参数或内部构图条件，不能自动带来横向关系，也不能让本项目默认进入三联拼接模式。


## 电影感失败的根因修复

| 失败结果 | 根因 | 最小修复 |
|---|---|---|
| 像海报或游戏概念图 | 没有事件状态，只有完整漂亮的主体与风格词 | 加一个可推断前后帧的选择、阻力、缺席或环境后果，减少装饰细节 |
| 像普通电视剧截图 | 摄影机只在记录人物说话，没有观看压力 | 给机位一个空间限制，并让构图承担关系距离、信息差或权力差 |
| 像滤镜套图 | 颜色、颗粒、光晕没有画内来源 | 指定颜色来自实景对象 / 光源，保留单一成像基底和局部缺陷 |
| 像空洞风景照 | 空间没有第二叙事力量 | 加入人物选择、观察者、制度痕迹、等待对象、异常物件或正在改变的环境 |
| 三个镜头可以随意换序 | 每镜只是同主题的审美变体 | 为每镜指定唯一新增信息或后果，并做顺序打乱测试 |
| 参考图换人后仍像原图 | 同时继承构图、配色、人物关系和道具组合 | 只抽取一个维度，其余改写为原创的空间、事件、色彩和角色关系 |


## 迁移与边界测试

影像母体卡通过以下测试才算抽象有效：把人物换成物件 / 符号，换掉色板，改成 MV、广告、动作、文戏或文化视觉任务，摄影机权限、空间压力、视线流量和事件停点仍然能重新编译。若规则只能依赖 21:9、三联结构、某位导演、某种胶片或某个样片的独特道具，它只是表面模板，应退回当前作品的一次性机制卡。

三联图、21:9、胶片颗粒、特定导演 DNA、宽银幕光晕和“两个稳定镜头加一个特殊镜头”都只能作为外部案例中的候选方案，不能升级为项目默认。是否使用它们，必须由当前作品的主导机制、实际画幅、人物 / 空间证据、剪辑接口和模型可生成性共同决定。


## 2. 景别或信息尺度是证据边界

真人与三维空间使用景别，二维动画、MG、UI 和字幕动效使用信息尺度；两者都不是装饰标签，而是规定观众这一刻能同时看见多少信息：

| 景别 | 主要职责 | 能够承重的证据 |
|---|---|---|
| 特写 / 局部特写 | 单一局部证据 | 眼睛、嘴唇、拇指、刀镡、刀刃接触、按钮、裂纹 |
| 中近景 | 表情与上半身关系 | 脸、手、胸背、武器局部、对手距离 |
| 中景 | 身体动作与方向 | 站姿、步行、拔刀前准备、人物和背景的相对运动 |
| 中远景 / 较宽画面 | 空间与路线证据 | 全身位移、人物与城市 / 敌群 / 巨物的关系 |

如果正文需要跨越景别，必须写出变化机制：`镜头从刀柄特写沿刀锋方向拉远至中近景`、`镜头绕过肩线并后撤，人物全身和背景轨道同时进入画面`。不能让同一个景别凭空拥有互相不可见的信息。

二维内容对应三种常用信息尺度：`总览` 证明整体结构、坐标系和各组关系；`分组焦点` 证明一组对象之间的比较、顺序或因果；`单点细节` 证明一个数字、标签、节点或局部变化。信息尺度切换必须写出视窗缩放、图层前后移、遮罩展开、版式重排或焦点迁移，不能让一个单点细节画面同时承担完整系统关系，也不能边高速重排边要求观众读完全部文字。


## 3. 观察路径必须改变屏幕，静止必须有意

每次实体摄影机、虚拟摄影机、二维视窗或构图焦点发生运动时，至少明确五项中的四项，关键转场全部明确五项：

```text
起点：摄影机当前看什么、在主体哪一侧、处于什么距离。
路径：机身整体移动、原地摇 / 俯仰、环绕、升降、穿越或焦点迁移。
方向：向左 / 右、前进 / 后退、上移 / 下移、顺时针 / 逆时针，以及主体屏幕方向。
速度：匀速、缓入、突然加速、峰值、硬制动、回弹或减速；写相对谁变化。
停点：最终停在什么景别、构图、对象、焦点或可裁切状态。
屏幕结果：主体大小、角度、遮挡、背景视差、焦点和位置如何改变。
```

“镜头上移”不是完整描述。完整描述应让模型知道镜头上移时沿谁上移、经过什么、最后看见什么：

```text
贴着女刀客的靴面向右上方旋转上移，沿左腰带出斜穿画面的深海蓝黑刀鞘；镜头继续绕过刀鞘口，右上缺口圆环护手贴近前景，随后停在她冷静的右眼特写。
```

专业术语可以出现，但必须紧跟可见结果。`Dolly / Track` 指机身整体移动；`Pan / Tilt` 指机位基本不动的转动；`Zoom` 指焦段变化。不能只堆“旋转推进、电影感、炫酷运镜”。

焦点不等于摄影机位置。`Rack focus / 受控拉焦`只改变镜头内部的焦平面，可以在摄影机完全固定时把观众注意从近前景送到后景；`Tilt / 俯仰`才是摄影机原位改变视轴，`Pedestal / 升降`才是机身整体上下移动。正式拉焦写法至少包含：

```text
摄影机状态：固定或运动，构图是否改变。
起始层：近 / 中 / 远景中的哪个对象先清晰，另一个对象怎样柔焦。
触发：哪次接触、下沉、抬眼、台词重词或声音开始迁移。
方向与速度：由近到远或由远到近，平稳、突然或分段。
停点：最终锁在哪个具体部位，前一对象成为怎样的柔焦遮挡。
```

错误：`焦点从手抬到她失守的眼神`。这把机身运动、焦平面和抽象情绪混为一体。正确：`摄影机固定在人物正面中近景；近前景手掌先清晰、后景双眼柔焦。手指失去力量开始下沉时，构图不动，焦平面由近向远平稳后移，最终锁住虹膜与下眼睑积泪，手掌转为柔焦前景遮挡。`

二维图形没有真实景深、地面轴线或镜头视差时，不机械套用这些术语。改写为可见的版式动作，例如：`主标题保持画面中心不动，三组数据卡沿同一水平基线从右侧依次进入；第二组放大并前移到视觉第一层，其余两组降低明度退到两侧`。固定机位则写明 `摄影机保持平视中近景不动`，随后只描述画内表演和状态变化。


## 3A. 镜头宏观合同与正文唯一执行主轨

镜头方头不是为了缩短正文，而是让读者和模型先知道这一镜将沿什么摄影与构图路线完成。它形成`镜头宏观合同`；紧随其后的自然语言正文是`正文唯一执行主轨`。二者是概览与展开的关系，不是两份并行分镜。

简单镜头沿用紧凑方头：

```text
【C01｜固定中近景｜平视侧面｜固定机位】
```

复杂连续镜头按需扩展：

```text
【C01｜景别：中景→近景→全景｜机位：左下低位→右前方平视｜摄影机路线：向右横移并旋转上摇→绕过肩线→后撤拉远停稳｜构图：起始→决定性→结束｜节奏：辨认停顿→移动加速→结果停稳】
```

方头只保留五类宏观决定：景别怎样演变；摄影机从什么机位和视角出发；连续路径或切换机制；构图怎样重组；节奏在哪些相位加速、减速或停住。`概览不能新增事件`：正文没有人物后退、门关闭、哭声或光线熄灭，方头和补充轨都不能先写出来。方头中的每一项必须能在正文中定位到具体起点、触发、变化和停点；正文也不能悄悄换成另一条机位、方向或结束构图。


## 摄影机路径闭合

连续镜头可以组合横移、摇镜、俯仰、升降、环绕、推进、后撤、变焦和拉焦，但必须形成同一条物理可达路线：

```text
起始机位与朝向
→ 什么动作 / 声音触发摄影机移动
→ 机身或视轴怎样变化，经过哪个空间锚点
→ 速度、稳定性、景别与焦平面怎样改变
→ 主体和背景在屏幕上怎样重排
→ 最终机位、景别、焦点和可裁切停点
```

只有主要画面内容、机位、朝向和时间连续时才保留一个镜头方头。摄影机无过程穿墙、瞬间越轴、从人物左侧跳到右侧、焦段变化却被写成机身后退，或前一位置无法抵达后一位置，都说明路径断裂；注意力可以从人物移向物件、反应或全景结果，只要摄影机路径、时间和共同观看目的持续成立；实际插入切镜、反打剪切或时空跳跃才另开编号。此时重新设计可达路线，或新开编号镜头并写共同载体和转场。


## 动态构图不是一张静态摆位表

构图先借用静态图片的清楚关系，但视频必须沿`起始构图 → 决定性构图 → 结束构图`检查三个状态：

```text
起始构图：开场的世界位置、屏幕位置、前中后景、遮挡、负空间、视线轴、焦平面和第一落点。
决定性构图：主要动作、台词重词、接触、揭示或光色峰值到来时，谁占据第一视觉，哪些对象退让或被遮挡。
结束构图：摄影机停在哪里，人物与关键物最终落在什么屏幕关系，哪一项状态可以被裁切或交给下一镜。
```

`世界位置`说明人物和物体相对门、桌、墙、道路和其他人的真实方位；`屏幕位置`说明它们在当前机位下落在左中右、上中下和前中后景的投影。摄影机移动可以改变屏幕位置，不能无因改写世界位置。前景、中景、背景、虚化、角落坐标和负空间只在承担遮挡、尺度、焦点、运动参照或后期接口时写；不要求每镜都有三层，也不把所有人物锁成像素坐标。

方头只概括构图变化，例如`人物由右下被门框挤压→接触时进入中央亮区→结尾退到左侧暗部`；正文必须说明门框、摄影机、人物动作和光线如何共同造成这次重构。静态构图说清以后，时间变化才有参照；但只写开场站位、没有决定性与结束状态，仍不足以控制复杂镜头。


## 关系视点必须有主人和空间

后文确认“有人一直在场”“另一个人早已控制空间”或“亲密关系并非表面所见”时，前文可以通过观看位置留下第二次观看才会增义的证据；但先建立`关系视点合同`：

```text
视点性质：角色主观 / 受限第三人称 / 中性观察。
观察者位置：当时真实位于哪里，身体高度、朝向和藏身条件是什么。
视线通道：从该位置经过哪些门缝、家具、人群或反射面，能看到什么、看不到什么。
遮挡来源：前景轮廓属于哪个真实物体，为什么会进入画框并随摄影机产生何种视差。
信息权限：观察者、被观察者和观众分别知道什么，最低危险证据是什么。
后文验证：哪个位置、动作、声音、反射或物件状态证明前面的观看关系没有撒谎。
```

`主观镜头必须属于`一个在该时刻真实存在、处于可达位置并能沿这条视线看见画面的角色。角色身份可以暂不揭示，但镜头不能从密闭墙内、不可到达高度或后来才出现的人物眼睛里观看。需要限制信息但没有具体观察者时，写`受限观察构图`：摄影机借门框、柜角、帘边或反射只开放部分信息，却不把它冒充某人的眼睛。

`遮挡本身不等于偷窥`。前景虚化也可能只负责纵深、尺度、危险边界或隐藏切点；只有观察者存在、关系动机、空间位置、视线通道和后续验证共同成立时，它才承担窥视关系。若场景里没有观察者，不能为了“悬疑感”机械加黑色前景；若当下危险本身尚未被观众理解，也不能把人物、行动对象和必要空间全部遮掉，只保留作者知道的答案。

关系前置不能改写事件事实。后文揭示只允许重新解释前文已经出现的遮挡、声音、视线或物件状态，不允许倒灌一个前镜不存在的人、脚步或呼吸。有效的关系视点让旧证据获得第二层意义；无依据的窥视角度只是视觉口头禅。


## 节奏概览与声音轨迹

`节奏概览`写动作和摄影机的相位，不写完整逐秒表：`定住辨认→迟疑→后撤加速→撞墙硬停`。具体动作在正文展开；数字只用于局部相对时长，如反应延迟、动作完成窗口、减速区和结果最低保持。把`向左看1秒、向右看1秒、抬头1秒、后退3秒`首尾拼满整镜，仍是伪装的绝对时间轴，也容易把自然表演写成机械动作清单。

声音先在正文成为触发、反馈或结果，再在对应补充轨写`声音轨迹`：

```text
声源与进入点 → 方向 / 距离变化 → 响度和频率感觉 → 遮挡与混响 → 峰值 → 衰减 / 余响 / 静音
```

抽象情绪箭头不能代替声学变化。`紧张→恐惧→痛哭`应先在人物动作和表演中成立；可听写法是`办公室空调保持低频底噪→门合上后走廊高频被削弱→人物后退脚步的短回声逐次靠近→哭声在近场破出并压过底噪→停点只剩断续吸气和远处风机`。补充轨仍须使用正文已经出现的同名事件 ID，不能新增正文没有的门、脚步、哭声或音乐。

简单固定机位不机械填满以上栏目。构图不变时只写它保持什么，声音不承重时省略声音轨迹，动作自然完成时不补数字；复杂度由观看任务和生成风险决定，不由模板字段数量决定。


## 4. 运动必须有空间参照

人物向右前方、左后方或画外移动时，必须让观众看到至少一种空间证据：

- 中景或更宽画面保留脚步、身体重心和地面参照。
- 背景向相反方向滑动，前景遮挡产生不同速度的视差。
- 地面网格、道路、管道、楼群、栏杆或光带向后掠过。
- 衣料、发丝、尘土、水花或影子产生与运动方向一致的延迟反馈。
- 摄影机与主体同速、慢于主体或绕行时，分别写清主体稳定、背景失跟或相对位移结果。

```text
错误：她保持向右前方前进，镜头切近拇指拔刀。
正确：侧面中景与女刀客同速向右跟拍，脚下骨白网格和身后的楼群持续向左后退；她进入画面右侧后，镜头才沿左腰快速切近到刀柄特写。
```

特写可以展示局部动作，但不能同时证明观众无法看到的全身路线。需要两种证据时，先用中景完成空间动作，再通过明确的切近或镜头路径进入局部特写。


## 分层纸雕的摄影机注意力专法

只有 B 类分层纸雕知识场景已经存在可追踪的知识路径与真实空间通道时，才考虑FPV式连续穿越或一镜到底。摄影机不是在纸世界里参观，而是把观众送到下一个尚未理解的关系：从样本端沿纸带进入提炼装置，从人工长链穿门到AI分流，从候选出口经过核验槽抵达人的选择台。路线本身必须重现知识拓扑，不能只证明场景有纵深。


## 一条路线怎样成立

1. 从一个真实起点开始，朝向真实路径；不能从无来源的空中机位突然俯冲。
2. 按`semanticAnchors`顺序接近节点。节点只有在摄影机接近、经过、绕到或被上一节点沿路径触发后，才成为第一焦点。
3. 上一节点必须留下可回看的新状态，例如轨道点亮、门打开、槽位填入、齿轮停止、问号变为核验结果；摄影机沿这个结果继续，而不是瞬移到下一展台。
4. 用真实前景纸层、纸门、轨道护栏、齿轮边缘或装置外壳做短遮挡，遮挡前后保持方向和空间连续；遮挡用于焦点交接，不用于掩盖无因跳转。
5. 普通通道可以中速通过，接近承重标签、数字、问号／对勾和结果时必须减速、稳定、阅读后再走；最后结论留出独立停点。

一条合格路线逐步回答：摄影机去哪里，为什么现在去，此处揭示哪条关系或作用路径，绑定哪句口播，焦点从谁交给谁，观众已经知道了什么。答不出来的运动删掉。


## 拒绝条件

- 固定正面把四张卡或四个舱室从开场到结尾同时摆满，只靠翻牌、发光和放大轮流点名。
- FPV只有高速穿越、无目的环绕、俯冲、升降或甩镜，没有语义锚点和知识状态。
- 摄影机、全部机关、标签和背景同时高速运动，导致观众不知道当前该看哪里。
- 文字在高速移动或浅景深虚化中承担解释；随机英文、伪中文和密集小字填充纸面。
- 路线瞬移、反复折返、随机旋转，或为了穿越新造参考图不存在的门、洞、轨道和通道。

这项专法不适用于所有纸拼贴。编辑纸拼贴、平面关系图、普通转场、人物表演或没有连续因果通道的内容，摄影机可以固定或克制移动；只要移动会降低静音理解、标签可读性或人物关系，就不使用FPV。


## 摄影机速度与屏幕速度


## 先决定摄影机和主体的速度关系

- 摄影机慢于主体：主体逼近画边或短暂出框，制造失跟、危险和不可控。
- 摄影机与主体同速：主体相对稳定，背景高速滑动，便于看清表演并感到环境速度。
- 摄影机快于主体：越过、超前或回看，强调主导、发现前方威胁或重新构图。
- 摄影机与主体反向：屏幕相对速度叠加，冲击强，但必须留清晰接触或方向锚点。
- 摄影机先静后动：动作先撕开稳定画面，摄影机随后被迫响应，力量更明显。
- 摄影机先动主体后动：观众先被拉向目标，适合预示、邀请或陷阱。

不能把“人物快”自动翻译成“摄影机也快”。主体、摄影机、焦点和切镜最好只让一至两个成为主速度源。


## 景别与屏幕位移

- 近景 / 特写中，同样的真实位移会占据更大屏幕比例，速度感和冲击更强，但完整动作路径更难读。
- 较宽景别能保留起点、落点和对手距离，适合证明动作几何；它不一定显慢，近前景掠过和明显视差仍可制造高速。
- 近距离广角运动容易产生强透视与前后景视差，适合冲刺、穿越和空间膨胀；必须控制边缘变形和主体清晰度。
- 长焦会压缩纵深，适合让追逐距离显得黏着、让横向运动扫过画面或制造难以逃脱的压迫；不要把焦段当固定速度按钮。


## 运镜速度词必须落到屏幕结果

弱写法：`快速推镜、疯狂甩镜、动感环绕。`

强写法：`机身从她右后方迅速贴近，肩部由画面中部扩大到占据右侧前景，背景灯带向左拉出强视差；刀刃接触前摄影机停止推进，保持落点清晰。`


## 触发条件与观众承诺

用于第一人称 POV、街头采访、手机 UGC、纪录感跟拍、连续行走、路线追踪和“一镜到底”社交互动。观众应相信摄影机真实存在于空间中，人物会对它的位置、距离和行动作出反应。


## 连续路线机制

先画空间路线：起点、关键地标、门槛、转弯、遮挡、终点。相机跟随人物路线，距离、步速、视线、手势和相对高差改变社交关系；环境视差、脚步声、光线变化和重复地标证明连续空间。

路线进度可以由重复地标、材料变化、光区、门洞、楼层或工具状态作为进度时钟。重复必须发生变化，不能只是同一背景循环。

一镜到底不等于摄影机永远匀速跟随。可以停住让人物离开、被遮挡后重新发现、绕到侧面、落后再追上，但机身路径必须可实现，空间不能瞬移。


## 严格 POV

严格 POV 不只贴标签，也不套全字段公式。必须写具体人物的眼高、画面呈现其眼前所见、身体边缘证据、视线方向和声音来源，只选择足以证明来源的证据。

严格 POV 不能用群体外部关系词，例如“姐弟俩”“村民看到姐弟俩”；改成画面下方两只小手、前方姐姐背影、路边村民视线越过镜头看向 POV 主体。

严格 POV 不能把 `正面 / 背面 / 侧面 / 正面构图` 接在 POV 主体后面。写“面向遗像桌方向的低视线”“视线停在爷爷遗像上”，把方向绑定到画面对象。

POV 中手部出现必须符合肩宽、视野下缘、持物和动作可达性；不能为证明第一人称让双手一直悬在画面中央。


## 街访与纪实互动

街访先建立真实社会目标：拦停、征得同意、提问、等待、追问、离开。人物不会从第一帧就正对镜头念完整答案；先有视线确认、步速变化、身体转向、短暂停顿和环境干扰。

相机距离决定关系：远处观察保留陌生感，中距离同行建立信任，近距离停住形成压力。手势、目光和身体朝向必须回应摄影机或采访者的实际位置。

UGC 的不完美只选一个主要来源，例如手持微抖、自动曝光迟滞、对焦短暂寻找或手机麦克风近讲失真；不要把所有“真实感缺陷”叠在一起。


## 记忆、记录与二次曝光

固定取景器记录适合让同一构图中的人物、季节或物件状态变化；机位和画框是时间证据。旧话 VO 可以视觉化为二次曝光 / 三重曝光记忆层，但要区分现实层与曝光层。

例如 `E1-S11-C2` 可让 `P11 半成品木马车架` 保持现实层，爷爷半透明记忆层二次曝光只承担动作回声；不能让记忆层变成同等实体并与现实物体碰撞。


## 遮挡与时间跳切

遮挡式时间跳切本质上是遮挡转场。前一对象形成满屏遮挡转场点，后一个时间从相同遮挡边缘退出；旧墙、白布、桌面、蒲团位置不变，只有桌中央黑白遗像从爷爷换成奶奶，观众才能判断时间跳跃而非换场。

纪实路线中的遮挡可以由行人、车辆、门框、衣物或墙角完成，但遮挡前后运动方向、机位高度和背景锚点要连续。


## 三段式编译

- `【基础设定】`只承接总时长、生成方式、实际绑定资产职责和一句全条声音策略。本机制还需保护的内容为：摄影设备 / 生成方式、人物与场景资产、路线图、声音策略和是否严格 POV。
- `【场景状态与氛围画质】`：全段真实成像基底、天气、时间、曝光和主要不完美来源。
- `【画面内容】`：摄影机实体路径、人物对相机反应、地标推进、视差、声音距离和终点状态。
这些内容按职责分别进入代码块外交接、开拍前全局状态或对应镜头变化；不把逐镜动作、身份命题、色卡、作者解释或禁止词表塞入基础设定。冻结台词、标题、Logo与音乐原文保持，具体出现位置由本镜声画事件承接。


## 惊艳点设计

纪实类的惊艳来自“意外但可信”：背景异常先被人物反应或手机录像证明；一个陌生互动在路线中逐渐变成同行；固定画框中时间造成不可逆变化。不要用无来源大特效破坏在场感。


## 可剪辑接口

优先提供自然遮挡、脚步重音、转头甩镜、视线接所见、同方向进出画、环境声 J cut 和人物回答 L cut。连续路线可保留 0.5-1 秒纯环境或稳定地标作为剪辑缓冲。


## 失败修复

- POV 变第三人称：删外部关系描述，补眼高、视野边缘和所见方向。
- 一镜到底像漂浮无人机：补脚步、加减速、避障、视差和人物回应。
- 街访像摆拍：增加征得注意、思考停顿、环境打断和不完整回答。
- 时间跳切像换场：锁相同机位、固定陈设和一个明确状态变化。
- 手持太晃看不清：只保留一种可控不完美，承重信息处短暂停稳。


## 迁移测试与反复制边界

机制应能迁移到街访、旅行跟拍、第一人称救援、家庭记录和固定机位记忆。不得复制外部受访者、地点、问答、路线和具体异常事件。
