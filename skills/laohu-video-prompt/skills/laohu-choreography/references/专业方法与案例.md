# 舞蹈编排：专业方法与案例

## 当前专业决策

动作母题是可辨识且可变奏的短动作组合；齐舞是同一相位同步进行；卡农是同一短语错时进入；队形关系包括方向、层次、距离和接力。重复先建立可辨认规律，变奏才让观众读出关系变化，而非只觉得四肢忙碌。

继承真实歌曲时间与已定表演策略→选一个身体发起部位与重心短语→写脚下支撑及移动范围→安排齐舞/错相/对位→选完整轮廓可读的镜位→回到可接续终姿。适合独舞、群舞、舞蹈型MV；反例是每拍切镜遮掉短语、把每人随机动作叫群舞、用新编舞改变歌曲段落。

### 同一材料候选比较

候选A：同一三人舞段：每人自由旋转，每个鼓点切近景。

候选B：领舞踏实右脚后胸廓转向、双臂展开；后排依次错后一拍，最终同向停重心。

取舍：后者保留可辨母题和群体关系，前者无法比较相位且剪掉脚下支撑。

适用与反例：节拍只继承真实音轨；没有拍点证据不捏造精确时间，身体障碍不得被切镜掩盖。

### 编译或返修结果示例

“领舞右脚踏实后以胸廓带动转向，双臂沿肩高展开；后排两人依次晚一个拍位完成同一短语，三人最终面向画面左侧，重心停在外侧脚。拍位来自已确认音轨。”

### 返回合同

返回动作短语、脚下支撑、队形/相位、拍位与终姿合同；指出本次改变哪个决定、原有哪项事实不能动、从哪个状态开始以及下一负责人如何验收。输入缺口影响因果时停止专业深化，带证据返回；不把下游修词当作上游事实已存在。

## 完整专业方法

### 动作短语与队形的专业编排

短语先回答身体哪部分发起、重心去哪、支撑怎样转换、轨迹在哪里终止。把“转身、甩手、跳跃”写成短语时，至少确认朝向、脚下支撑、活动平面与结束姿态；每一个动作名都不是自动可执行的身体路径。上游角色有伤势、服装体积、长袖、道具或空间净空限制时，先将限制带入身体排演，不让镜头切掉不可达部分。

母题发展一次只改变主要关系：同样伸臂短语可以改变高度、方向、幅度、速度、重复次数或参与人数；改变后必须仍可追认原短语。若动作、方向、节拍和队形同时全换，就已经是新短语，需要新建立而不是声称“变奏”。齐舞用相同相位表现共同性；卡农用错时进入让同一动作沿队伍传递；对位允许不同短语共存，但要分清谁是注意力主项。

先沿已确认音轨划分乐句功能，选真正承重的拍位、延音或休止作为进入/完成条件。动作可以跨拍，不把每拍都强行切成新动作；重拍可能是落脚、停住或对方加入，而非永远腾空峰值。听到的节拍与实际身体触地需要分开描述。沒有真实音轨时只交相对短语，不编造时间码。

镜头必须保住短语：脚下转换承重则选择能见支撑的景别；手部母题承重可切近，但保留上一个镜头给出的方向与重心。只拍脸不能证明群舞齐度；密集快切也不能证明整段动作可连续执行。返回短语起点、动作路径、群体相位、结束姿态与必要拍位，让动画负责形体连续、运镜负责观看，MV导演继续掌握全曲结构。


## 表演型 MV

舞蹈、演唱、动作姿态或人物与镜头互动承担节奏。先锁动作短语、重心方向、手脚路径、朝向和结束姿势，再让摄影机、文字和灯光响应动作结果。群舞必须有领舞与群体相位关系；口型同步、身体表演和镜头互动分开控制。


## MV、舞蹈与角色 PV

音乐提供宏观速度骨架，角色动作、摄影机、VFX 和切镜不必每拍同速。主动作落决定性完成点，次级粒子和 UI 放到弱拍。系列角色保持同一音乐速度与段落能量，人物差异由动作曲线、材质响应、标志性停点和同期音色体现。
