# 老胡表演

## 灵魂：先让人物试着得到什么，再让表情暴露失败。

情绪由行动策略与失控过程显现。先判人物想影响谁、怎样影响、在哪里受到阻力，再安排表情和身体通道；动机不足返回编剧。

## 筋骨：先把判断接到输入与结果

本专业接收当前作品任务、上游锁定事实和允许改变范围；先核对是否存在“人物表演只有情绪标签，或听者反应、说话权、身体泄露顺序不清”的缺口，已成立部分直接继承。继承人物基线→当场目的→阻力→保护动作→精确触发→一项主通道先变、另一项随后泄露→话后选择。适用于对白、沉默、听者反应、对镜头关系；反例是机械为每句话补眼泪/握拳，或在远景要求细小肌肉承重。内容动机缺失必须退编剧，不能用演技猜剧情。

## 血肉：让候选产生可见或可听差异

行动目标是人物想让对方发生什么变化；策略是他当前怎样尝试；节拍是触发后策略或关系发生改变的段落。可执行的“留住他”会改变眼线、说话权和距离；只给“很悲伤”可能让模型从第一帧哭满，破坏触发。

同一材料下比较“同一递杯事件：她从开场就落泪，手、眼、肩同时颤抖。”与“她先保持递杯，听到人名后手停住，眼线不退，下一口气接不上，最后收回杯。”。强候选保留目的、触发及失去控制的过程；弱候选提前演完终态。专业方法、完整案例、例外和失败修复见[专业方法与案例](references/专业方法与案例.md)，只读取本次缺口对应章节。

## 表皮：交出可复验的专业结果

返回处境与行动策略、触发词、通道先后、听者反应和终态。写明胜出理由、已保护事实、未证实假设和下游必须继承项。若源剧本未交代人名为何刺痛她，返回编剧，不能由表演编造往事。

## 调用与返回

可由[父入口](../../SKILL.md)或其他实际负责人按缺口CONSULT，也可接受明确点名的独立任务。CONSULT结果返回实际调用者，不一律返回所属父入口。直接专业请求只要求本次判断必要的目的、材料、约束和事实；这些已经足够时直接执行，不强制先有完整父合同、导演阐述或整部剧本。只有缺口会改变当前因果或已锁事实时，才以证据RETURN最早负责人。不得改写源剧本、冻结文字、资产身份或已确认时间。整部作品仍由实际作品负责人整合，本子不以“已阅读”或格式齐全冒充已完成作品。

正式提示词继承E-S-P原文范围与分段执行卡，在每P内建C01、C02摄影镜头，保留三个一级区块。自然连贯的导演句承担动作与声画执行，不把分析标签写进模型正文；VC由父级实际调用并复验。
