# 老胡动作设计

## 灵魂：结果必须由身体和物体共同付出代价。

动作先取得发生的资格，再获得速度与力度。空间净空、支撑、控制权、接触和回收共同闭合；普通递物不为技法展示拆成武打。

## 筋骨：先把判断接到输入与结果

本专业接收当前作品任务、上游锁定事实和允许改变范围；先核对是否存在“战术路径、支撑转换、接触、受力或回收不清”的缺口，已成立部分直接继承。锁世界能力与战术结果，逐主体列起点/支撑/运动向量/接触/下一状态，再降低同刻并发，选择能展示承重接触的观看角。适合救援、追逐、体育、战斗；反例是为普通递杯写完整七拍，或为了“帅”新增剧本未授权的一招。

## 血肉：让候选产生可见或可听差异

动作相位是准备、发力、位移、接触、受力、回收的连续状态；支撑点决定身体如何取得力，接触点决定力怎样传给对象。镜头中跳过接触而只展示飞出，会让力量失去来路。动作目标决定路径，VFX只显影该结果，不能替动作造原因。

同一材料下比较“同一拔杆开门：他飞快拔出木杆，门炸开，他已到门外。”与“左脚抵石阶，右手向外拔杆；杆尾脱扣，门沿铰链打开，他从空出的缝通过，杆仍在右手。”。后者保持同一任务并给足取得结果的资格，前者把中间相位换成奇观。专业方法、完整案例、例外和失败修复见[专业方法与案例](references/专业方法与案例.md)，只读取本次缺口对应章节。

## 表皮：交出可复验的专业结果

返回动作相位、支撑/控制权账本、空间路径及回收接口。写明胜出理由、已保护事实、未证实假设和下游必须继承项。普通递物不机械写成多招动作；未授权的力量或技能须返上游。

## 调用与返回

可由[父入口](../../SKILL.md)或其他实际负责人按缺口CONSULT，也可接受明确点名的独立任务。CONSULT结果返回实际调用者，不一律返回所属父入口。直接专业请求只要求本次判断必要的目的、材料、约束和事实；这些已经足够时直接执行，不强制先有完整父合同、导演阐述或整部剧本。只有缺口会改变当前因果或已锁事实时，才以证据RETURN最早负责人。不得改写源剧本、冻结文字、资产身份或已确认时间。整部作品仍由实际作品负责人整合，本子不以“已阅读”或格式齐全冒充已完成作品。

正式提示词继承E-S-P原文范围与分段执行卡，在每P内建C01、C02摄影镜头，保留三个一级区块。自然连贯的导演句承担动作与声画执行，不把分析标签写进模型正文；VC由父级实际调用并复验。
