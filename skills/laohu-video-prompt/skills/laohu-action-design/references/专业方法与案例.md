# 动作设计：专业方法与案例

## 当前专业决策

动作相位是准备、发力、位移、接触、受力、回收的连续状态；支撑点决定身体如何取得力，接触点决定力怎样传给对象。镜头中跳过接触而只展示飞出，会让力量失去来路。动作目标决定路径，VFX只显影该结果，不能替动作造原因。

锁世界能力与战术结果，逐主体列起点/支撑/运动向量/接触/下一状态，再降低同刻并发，选择能展示承重接触的观看角。适合救援、追逐、体育、战斗；反例是为普通递杯写完整七拍，或为了“帅”新增剧本未授权的一招。

### 同一材料候选比较

候选A：同一拔杆开门：他飞快拔出木杆，门炸开，他已到门外。

候选B：左脚抵石阶，右手向外拔杆；杆尾脱扣，门沿铰链打开，他从空出的缝通过，杆仍在右手。

取舍：后者保持同一任务并给足取得结果的资格，前者把中间相位换成奇观。

适用与反例：普通递物不机械写成多招动作；未授权的力量或技能须返上游。

### 编译或返修结果示例

“他先以左脚抵住石阶，右手将已经松动的木杆向外拉；杆尾脱离门扣，门沿原铰链向内打开，他借门扇空出的缝侧身通过，木杆仍握在右手。”

### 返回合同

返回动作相位、支撑/控制权账本、空间路径及回收接口；指出本次改变哪个决定、原有哪项事实不能动、从哪个状态开始以及下一负责人如何验收。输入缺口影响因果时停止专业深化，带证据返回；不把下游修词当作上游事实已存在。

## 完整专业方法


## 道具状态账本

只登记被拿取、递交、隐藏、破坏、消费、争夺或跨镜继承的承重物品；背景陈设不机械入账。

```text
道具身份与叙事职责：
镜前位置 / 朝向 / 容量 / 支撑面：
谁以哪只手或身体部位接触，接触点与受力怎样成立：
离开原位的触发、提起方式、承重反馈与运动方向：
经过的空间锚点 / 可省略路程：
镜后落点、朝向、容量、支撑面与谁仍控制它：
下一镜继承的状态：
```

人物拿起盘、杯、文件、工具或武器时，物体必须从一个真实支撑转移到另一个真实支撑，重量要通过手腕、手指、躯干、液面、衣料或接触声留下反馈。端起后无落点、离手后仍悬空、换镜后数量或控制者改变，都属于状态断裂。


## 5. 动作必须闭合因果

所有关键动作按以下句法组织：

```text
主体 / 物体 + 起始位置 + 接触部位 + 发力或运动方向 + 受力变化 + 屏幕结果 + 收束状态
```

```text
女刀客左拇指压住刀柄前方的圆环护手，右手沿刀柄向后抽出刀身；冷白刀刃从左腰刀鞘口斜向右上方滑出，刀锋经过镜头前方时，刃面反光由左下向右上扩展并遮住画面；斩击完成后，右手停在身体右后方，刀锋斜向上，余光沿画面右上方衰减。
```

不能从“手碰刀”直接跳到“刀已经在空中”，也不能从“拔刀”直接跳到“画面被刀光填满”。模型需要知道刀光由刀刃反射产生、沿哪条路径扩展、何时遮挡画面、遮挡退开后留下什么。


## 人物、物体与剪辑的连续因果

镜头连续性不是让背景、衣服和人物脸看起来一样，而是让观众始终能回答：谁正在为了什么做事，手中的物体处于什么状态，这一镜的结果为什么会成为下一镜的条件。


## 2. 道具不是布景名词，而是状态机

凡是被人物操作并承担剧情的物体，内部建立状态：

```text
身份 / 数量 / 容量
→ 所在空间、相对锚点、朝向与支撑面
→ 控制者、接触部位与受力方向
→ 离开原位、运动路径与重量反馈
→ 新位置、朝向、支撑面、容量与控制者
```

盘子从桌面被端起时，先由盘底脱离桌面和手腕承重证明离开；移动时液面、汤汁、肩肘、步幅或瓷器轻响证明重量；结束时盘底必须接触明确台面、柜层或另一双手，并在人物松手前稳定。物体被遮挡后可以暂时看不见，不能在没有放置、递交、掉落、吃完或破坏的情况下消失。人物转身离开前若已经把盘放回桌面，下一镜必须继承“盘在桌上、人物空手”；不能让模型因为上一镜出现过端盘，就把盘继续带进厨房。

食物、家具和生活物还要经过叙事与现实双校准：家庭收入、用餐人数、场次时间和人物饮食目的决定菜量与组合；主剧情道具决定哪一道菜获得近景、被谁控制和怎样移动。配菜可以建立生活真实，但不能抢走承重食物的动作权；承重食物也不能因为要突出就让整张餐桌失去基本生活可信度。


## 动作相位与速度曲线


## 七相位动作链

复杂动作按需检查：`蓄势 → 启动 → 加速 → 峰值 → 接触 → 余波 → 停点`。

- 蓄势：给方向、目标、重心和能量来源；不一定长，但必须可读。
- 启动：动作真正离开静止的第一变化，负责消除“突然瞬移”。
- 加速：位移间距扩大，身体、衣发、道具与背景开始出现速度差。
- 峰值：最快阶段，只保留观众必须识别的轮廓、方向和主动作。
- 接触：动作与目标发生同帧或明确先后关系，是声音和 VFX 的同步点。
- 余波：反冲、拖尾、碎片、烟尘、衣发和摄影机响应继续完成力量证明。
- 停点：主体、结果或构图获得最低可读保持，给剪辑和观众反应窗口。

不是每个简单动作都把七项写进正文。只有高速、复杂接触、慢动作、多人动作或生成容易乱序时才展开；一般动作把相邻相位合并成自然语言即可。


## 常用速度曲线

| 速度曲线 | 可见运动 | 适合情绪 / 任务 | 提示词写法 |
|---|---|---|---|
| 匀速 | 位移间距稳定 | 冷静、机械、不可阻挡、流程展示 | `保持恒定速度横穿画面，不加速、不摇摆` |
| 缓入 / ease-in | 从静止逐渐加速 | 靠近、觉醒、压迫积累、巨大物启动 | `先几乎静止，随后连续加速，背景视差逐步扩大` |
| 缓出 / ease-out | 高速后逐渐减速 | 抵达、揭示、英雄定帧、产品停稳 | `接近目标后平滑减速，最终无回弹地锁定构图` |
| 缓入缓出 | 两端慢、中段快 | 自然移动、顺滑转场、图形形变 | `起步与收尾都平缓，中段快速完成主要位移` |
| 突发阶跃 | 无明显渐变地突然提速 | 惊吓、抢攻、故障、决断 | `短暂停住后突然爆发，第一步即跨过大半距离` |
| 硬制动 | 高速瞬间停住 | 控制力、阻挡、危险逼停 | `高速逼近后在接触线前骤停，衣摆与尘粒继续前冲` |
| 超调回弹 | 越过目标后回摆 | 弹性、喜剧、UI、轻质物 | `越过锁定位置少许，再一次回弹后稳定` |
| 阶梯式脉冲 | 多次短促加速，中间有停顿 | 连击、机械启动、信息升级、音乐重音 | `每次重音只完成一次位移，间隙短暂停住保持轮廓` |
| 速度渐变 / speed ramp | 实时与快慢速连续转换 | 关键技巧、主观时间、动作强调 | `接近接触前逐渐降速以看清落点，接触完成后迅速恢复实时速度` |

技术术语必须配可见结果。只写 `ease-in、speed ramp、time remapping` 不够；模型需要知道何时开始变化、哪一段最快、何时恢复、画面中什么证明速度改变。


## 动作、打斗与追逐

先锁空间和攻击线，再使用 `短蓄势 → 高速越距 → 清晰接触 → 结果停点`。连击不要求每次都切镜；同一动作组内可让两三次快速交换形成密度，再用一次明显慢下来的预判、失手或对峙重新建立方向。强敌登场常通过主角原有速度突然无效、被迫制动或第一次失跟来证明，不只靠更大爆炸。


## 触发条件与观众承诺

用于近身交手、兵器战、群战、追逐、救援、体育、机甲战和超常力量。观众必须看清谁从哪里发力、沿什么路径运动、在哪里接触、谁受力、造成什么结果，并在清楚的基础上感到快、重、险和帅。


## 动作设计总链

`战术目的 → 力量来源 → 起势 → 运动路径 → 接触点 → 受力方向 → 环境反馈 → 回收 / 下一招机会`。上一招造成的遮挡、失衡、空位、掉落物或反作用力必须成为下一招条件，不能把招式做成互不相干的展示。

正式编译前先核验上游`动作因果交接合同`：世界能力基线、起始条件、战术目的、发力来源、能力触发、运动路径、环境交互、接触点、受力结果和镜尾把手。若上游只给“追上、闪现、踢飞、撞穿、楼塌”等结果，却没有人物取得结果的资格，退回编剧补因果，不由视频提示词暗自补故事。合同成立后，才把同一因果扩成相位、速度、坑洞尺寸、裂纹形态、碎片、烟尘、材质和光照等模型可执行颗粒。`剧本锁因果，提示词扩颗粒`。

每个主要角色建立角色动作语法卡：能力等级、距离偏好、起势线索、攻击几何、防守 / 借位、场景利用、回收方式。动作气质来自决策和几何，不来自反复写“凌厉、优雅、迅猛”。


## 镜头结构选择

不预设镜头数量。15 秒使用少量镜头或约 10 个镜头都可能正确。连续跟拍 / 少量长镜头适合证明完整技巧和空间连续；高强度多切适合并列不同攻击几何和反应尺度；混合结构通常用较远景建立空间、近景捕捉接触、英雄帧停住决定性结果。

高频动作覆盖不是快闪蒙太奇。每次切换必须回答新的问题：攻击来自哪里、身体怎样避让、接触发生在哪、环境如何受力、谁获得下一步主动权。

镜头节奏按贡献选择短切、长镜头、特写进、跟踪镜头、甩镜。文戏动作要让关键台词在关系中产生可见 / 可听后果；武戏必须交代力量来源、运动路径、接触点、动作结果。


## 力量与多点接触

复杂碰撞先建立唯一可读的力量关系。多敌同时攻击时，分别写各攻击来源、不同接触位置、主角支撑点和合力方向；用较远景别交代攻击几何，再用约 30 度偏轴近景看清接触，不要所有力量在正侧面压成一条线。

机甲写承重脚、关节锁止、伺服蓄压、躯干传力、武器反冲和地面反馈；不能只有灯光亮起和手臂摆姿。大体量角色移动要先让脚底、关节、地面和空气承担重量。

文戏 / 武戏情绪入场分流：战斗开场可以直接兑现危险，但仍要明确主角处于压制、试探、掌控或反攻哪个状态。动作速度选取足以证明本次承重结果的可感证据；不机械凑四种，也不能删掉速度参照和关键接触；决定性节拍留下承重英雄帧，不让全部高速模糊。


## 速度证据

速度设计按 `参照物、相对位移、材料响应、摄影机响应、声音响应、关键清晰点` 编译。可见证据例如近处竹竿反向掠过、马鬃衣摆被风压向后、水花后抛；声音以箭速撕裂空气的尖啸先到、撞击低频后到。高速中至少让接触瞬间的关键轮廓短暂清晰。

“快”不能只靠快切。镜头要提前半拍占位，让危险逼近速度可读；帅点捕捉发生在起势完整、接触清楚或结果突然静止的帧。


## 空间闭环

投射物 / 高速运动空间闭环必须写：场景坐标与通行净空、摄影机位于主体哪一侧、主体屏幕运动方向、攻击或物体来源、主体避让方向、最终出画或撞击位置、环境受力反馈。

下一镜先重建主体、攻击来源、地面 / 道路边界和摄影机观看侧，再继续新动作。若换轴，必须通过正面中性镜头、绕行镜头或明确运动完成换轴。

多主体运动账本写世界起点、屏幕起点、朝向、速度向量、相对顺序、出画顺序。世界坐标正确但屏幕方向错误，仍会造成越轴和追逐关系倒置。


## 人体姿势与工具相位

复杂姿势不能瞬移。人体姿势变换账本按可见承重点拆解，例如翻身下马：双脚先脱镫，手掌按在可承重的鞍桥 / 鞍座，骨盆离鞍，再写哪只脚、髋、前臂、肩依次落地。

兵器状态使用明确相位：完整入鞘、顶开护手、部分出鞘、完全出鞘、回鞘、脱手落地。上一镜只顶开护手，下一镜不能已经完成挥砍。

## 冷静高密度延迟收尾

静止建立 → 连续密集交换 → 一次决定性干预 → 短暂假稳定 → 延迟不可逆结果。适合高手碾压、剑切巨物、反击和强者“后果晚到”。假稳定必须短，延迟结果必须由前面接触因果造成。


## 非对称力量破局

先让观众相信阻力巨大，再用杠杆、角度、支点、速度差或材料弱点改写力量关系。主角不是凭空更强，而是更准确地使用空间和力。


## 接力式动作链

一个工具、信物、目标或追逐对象贯穿多个空间；每段都改变它的持有者、速度、危险或用途。它是连续因果，不是同主题蒙太奇。


## 三段式编译

- `【基础设定】`只承接总时长、生成方式、实际绑定资产职责和一句全条声音策略。本机制还需保护的内容为：能力基线、角色动作语法、武器 / 载具资产、轴线与声音总策略。
- `【场景状态与氛围画质】`：地面边界、天气介质、主光、尺度与整体危险状态。
- `【画面内容】`：逐动作写路径、接触、受力、结果、镜头占位、声音和下一招机会。
这些内容按职责分别进入代码块外交接、开拍前全局状态或对应镜头变化；不把逐镜动作、身份命题、色卡、作者解释或禁止词表塞入基础设定。冻结台词、标题、Logo与音乐原文保持，具体出现位置由本镜声画事件承接。


## 失败修复

- 只有光效没有战斗：删形容词，补目标、路径、接触与结果。
- 每招都切镜：保留至少一个完整动作单元证明技巧。
- 很快但不重：增加承重脚、反冲、材料失效和低频声音。
- 群战混乱：降低同刻并发，分层安排近中远攻击来源。
- 环境全毁但主角不受影响：补防守路径、距离衰减和控制证据。
- 冲突动作突然发生：补前置动机、靠近路径、身体受力和回收姿态。


## 迁移测试与反复制边界

同一机制应能迁移到剑战、机甲、跑酷、球赛、救援和追车。只继承力量几何、状态链和结果节奏；不复制外部案例角色、武器、场景、招式顺序和特效表面。

## 研究依据与验证边界

新加坡IMDA行业技能框架明确影视打斗编排需要把真实武技转换为可重复的屏幕动作，并保持视觉可信。[Media skills framework](https://www.imda.gov.sg/-/media/imda/files/how-we-can-help/media-manpower-plan/skills-framework-for-media-2024.pdf)。本项目只取动作可读性与职业边界，不提供实拍危险动作操作教程。

本页的项目编译链与原创例子是本地方法设计；专业资料不证明生成模型一定遵从，也不证明观众效果已经发生。平台控制每次实际执行前重新核验。

## 局部协作

- [动画](../../laohu-animation/SKILL.md)：只在“形体运动僵硬、时间间距、关键姿态、重叠或定格物性不清”时CONSULT，带本次事实与保护项，返回关键姿态、时距曲线、体积/关节不变量、重叠和循环接口。
- [视觉特效 VFX](../../laohu-vfx/SKILL.md)：只在“异常变化缺来源、传播、材质交互、尺度或永久结果”时CONSULT，带本次事实与保护项，返回主机制、源/传播/交互/收束、结构终态与声音接口。
- [运镜](../../laohu-camera-movement/SKILL.md)：只在“观看路线、视差、遮挡揭示或焦点迁移不清”时CONSULT，带本次事实与保护项，返回摄影机起点—路径—停点、屏幕结果与焦平面合同。
