# 声画关系：专业方法与案例

## 当前专业决策

同步是声画同一事件相位匹配；声音预置是在图像揭示前提供可听证据；声音桥延续跨切的空间或情绪。先听见会改变观众预测，因此时点不是单纯后期装饰。

建立可听源→人物是否听见→观众此刻允许知道什么→相位/进入窗口→画面揭示→残留关系。选择一条主声画关系，其他轨退让。适合对白反应、画外危险、MV卡点、知识口播；反例是悬念揭晓前用明显音效泄底、每个UI/脚步/切镜同拍抢重音、把旁白改成角色开口。

### 同一材料候选比较

候选A：同一门后敲击：先给门后人的辨识声，再让角色寻找是谁。

候选B：保留未揭晓声源的两次轻敲，角色抬眼后才切门把手，第二次余响跨切。

取舍：后者保护信息权限并用声音牵引观察，前者可能提前泄露答案。

适用与反例：主观听点必须已获导演授权；不可把旁白误成画内人物开口，不更换最终歌曲。

### 编译或返修结果示例

“画面仍停在关着的门，门后先传来两次已授权的轻敲；人物抬眼后才切向门把手，第二次敲击的短余响越过切点。”

### 返回合同

返回声画事件、信息权限、主从、相对窗口及跨切声音合同；指出本次改变哪个决定、原有哪项事实不能动、从哪个状态开始以及下一负责人如何验收。输入缺口影响因果时停止专业深化，带证据返回；不把下游修词当作上游事实已存在。

## 完整专业方法


## 动作、表演与声音

```text
写作声音：由 laohu-script-writer 提供；人物注意什么、怎样解释、想用语言改变谁、冻结台词与话后行动。
可听声音身份：由人物母版 / 已确认音色证据提供；稳定音区、音色、共鸣、咬字、常态语速与呼吸支撑。
已生成音频资产：由`laohu-audio-design`提供；只有真实存在并已听试的 VOICE / DUB / AMB / SFX / MUS 才可绑定，其事件相位、入出点和不可重生成项必须继承。
条件化行为签名：由人物母版提供；在何种压力和关系下通常采用什么判断与策略，哪些动作槽可随空间和道具变化。
当前场次表演：由视频父入口 编译；本镜目的、保护策略、精确触发、足以辨认本次变化的承重通道（单一通道可以成立）、台词中的声线变化、对手反馈与结束状态。
```

需要新建或重新生成旁白、对白、环境声、动作声或连续音乐时，先交`laohu-audio-design`形成音频设计交接包；视频父入口 只把其事件与镜头起点、触发、变化和结束状态对齐，不重新设计音色或把文本合同当成已生成音频。

文戏先写人物此刻想让对方做什么，哪一个词、动作、声音或信息触发表演变化，再写眼神、面部、呼吸、身体、距离和声线中的承重证据。不能从第一帧就把高潮反应全部端出来。

文戏承重动作按 `目的 → 动作策略 → 接触或关键词 → 身体异步反应 → 对手反馈 → 关系停点` 编译。脸不是唯一表演器官：按当前任务选择眼线、眼睑与眉、口唇与下颌、呼吸、颈肩、手指、躯干重心、步幅、道具受力和声线中的必要通道；每个通道都要有触发和变化方向。信息密度来自这些相互因果的控制，不来自把“痛苦、电影感、克制、真实”反复换词。

正文是完整视听事件主轨。`【VFX】`、`【环境音】`、`【动作音】` 和 `【音乐 / 节拍】` 可以作为紧跟当前镜头的校准轨；台词不得拆成 `【台词】`、`【对白】` 或角色清单等独立轨道。已冻结台词必须嵌入说话人物所在的镜头正文，与开口前动作、说话对象、眼线、口型、气口、重音、音量、身体变化、听者同步反应和说完后的停点写成同一条连续事件。关键事件必须先在正文发生，标签只补来源、方向、材质、时点和衰减；没有正文触发的孤儿标签删除。


## 上游边界

当输入是一首完整歌曲、歌词、音频时间轴或歌曲创作背景时，先由`laohu-mv-director`建立`MV导演交接包`。本节 只解决已经确认生产单元内部怎样形成动态图形、表演、母题、镜头与三段式视频提示词，不重新决定整首歌的导演命题、段落结构、口型分配或生产单元边界。没有该交接包时，可以为单条概念 PV 提供局部方法；不得假装已经完成整首 MV 设计。


## 音乐与视觉短语

先建立前奏、段落进入、重拍、节奏加速、留白、高潮和尾奏。每个声音事件只承担一个主变化：动作落点、版面重排、母题变形、标题出现或镜头冲量。辅变化只证明主变化。

卡点不等于每拍切镜。可以让视觉变化在重拍前蓄势、重拍时完成、重拍后停住；也可以让一个长音维持连续变形，在鼓点上突然锁定。至少形成两个以上视觉短语：第一遍建立规律，第二遍产生变体或升级，结尾才有回收感。

正式设计先建立 `音乐-画面节拍合同`。段落层让人物出场、世界异常、威胁揭示、高潮和标题回收分别落在不同音乐功能；拍点层把动作接触、转场闭合、版面翻转、母题变形、光色反转和文字形成分配给强拍、弱拍、细分拍、长音或休止；事件层写清拍前准备、同步完成与拍后余波。每个主要视觉短语必须有一项决定性画面事件被音乐驱动，中段不能只剩“背景音乐继续”。

同步密度要有层级：大变化只占承重强拍或乐句边界，小变化可以跟随弱拍与细分拍，连续推镜和形变可以跨越多个拍点，留白允许画面先停或声音先到。故意抢拍、拖拍与切分音可以制造不安或惊喜，但先让观众听懂规律，再明确哪一次偏离、哪一次重新合拍。若所有切镜、脚步、UI 与粒子都抢同一强拍，减少次要同步，只保留主事件。

固定歌曲需要精确同步时调用音乐参考；普通原创氛围音乐不机械建立音频资产。声音设计要与视觉材料绑定：纸裂对应撕裂、金属瞬态对应硬边符号、低频对应尺度压迫、扫描声对应 UI 进入、钟声对应时间母题，而不是所有切换都使用同一种 whoosh。


## 组合成员系列出场

同一女团、乐队、战队、阵营或角色组合拆成多条成员出场视频时，先建立 `主音乐骨架合同`：固定同一速度、拍号、鼓组、Bass 律动、主和声 / 主旋律走向、核心乐器、女声或人声职责、重拍位置和段落能量。不同成员的身份差异优先由动作音、材质音、武器音、VFX 瞬态和视觉母题表达，不能让第二条改编曲、第三条加速、第四条突然进入另一个副歌来冒充角色差异。纯文生视频只能逼近同一音乐结构；要求旋律、音色和演奏完全一致时，必须使用同一音频参考或后期统一音轨。

系列还要过 `成员视觉能级对齐`。第一条可用成片一旦建立了观众期待，后续每条至少要达到同级的五段奇观链：`立即发生的入场力量 → 摄影机被动作迫使改变 → 成员标志动作或标志物完成身份揭示 → 环境 / 图形空间产生可见结果 → 英雄停点或下一条交接`。五段是能级审稿维度，不要求固定五个镜头；一镜可以承担多段，多镜也可以共同完成一段。比较的是冲击、身份、因果和记忆点，不是特效数量。

成员之间应当 `同能级、不同机制`。主唱可以用声压、呼吸与麦克风改变空间；舞担可以用重心、脚步、旋转和丝带切开版面；中心成员可以用召集、棱镜和其他成员母题完成终局合流。不能只是把第一条换颜色照抄，也不能让第一名拥有完整入场动作、运镜追击、环境破坏和英雄停点，后续成员却只站立、摆姿势、生成道具或在普通 UI 前唱跳。最终成员可以因承担组合回收而高于单人平均值，但不能用终局合流掩盖自身出场事件不足。

写完系列后建立简短能级账本，逐条比较：首拍是否立即有事件；摄影机是否真正响应人物；标志动作是否不可互换；VFX 是否改变环境而不只是贴图；是否有一个可记住的峰值；是否保留稳定转场接口；主音乐骨架是否完全一致。若某一条只能用“漂亮、流畅、特效多”说明优势，却说不出人物造成了什么空间结果，就退回重做出场方式。


## 6. VFX 和声音必须有来源

特效不是作者加上的装饰层，而是画内事件的可见 / 可听结果。写特效时回答：

```text
来源是什么 → 在哪里形成 → 沿什么路径传播 → 接触什么 → 造成什么变化 → 余波怎样停住
```

声音至少写清声源、材质、方向、距离、进入时点和衰减。刀光来自刀刃，波纹来自脚底受力，警报带来自监视环缺口，碎片来自被斩开的图形；不能让特效从画面外凭空出现。

错误：极白冷光切满画面。

正确：刀刃从刀鞘口斜向右上方滑出，刃面反光沿刀路由左下向右上扩展；白光在刀锋穿过猩红警报带时才扩大成遮挡，遮挡边缘保留红带裂口的锯齿轮廓。


## 7. 正文主轨与声画补充轨

`【画面内容】` 内部可以拆成两层，但两层不是两个互相独立的剧本：

```text
正文主轨：什么时候发生、什么触发、画面 / 声音发生什么可感变化、动作如何进入下一状态。
声画补充轨：VFX、环境音、动作音、音乐 / 节拍的材质、方向、声场、强弱、相位、持续和校准细节。
```

正文主轨必须先把事件写出来。标签只补充已经在正文出现的事件，不得独自新增关键动作、特效、声音、人物或节拍。模型不一定把 `【VFX】`、`【动作音】` 当作稳定的结构化字段；如果关键触发只写在标签里，模型可能只生成一个“漂亮结果”，却丢掉结果的来源和发生时点。

推荐使用事件 ID 把正文和补充轨绑定：

```text
女刀客的黑色战斗靴重重踩进骨白网格；脚跟压实的瞬间，受力点向外弹出冷青缺口圆环波纹【VFX-A1】。靴底硬响与网格低沉回声在落脚点同时出现【动作音-A1】；第一记强拍在脚跟锁定时落下【音乐-A1】。
【VFX-A1】波纹从脚跟接触点向外扩散，外圈保持右上缺口，冷青亮度由中心向外衰减。
【动作音-A1】硬质靴底撞击骨白网格，近距离、短促、低频有重量；网格受压回声向画面后方衰减。
【音乐-A1】脚跟落地前留出极短预拍，强拍与脚跟完全压实同步，拍后保留半拍余波。
```

正文中的事件 ID 不是给模型看的新对象，而是让作者、剪辑者和复盘者可以逐项回查。最终投喂时可以保留标签；如果目标模型对标签敏感，则保留标签名称但删掉不改变生成结果的解释性句子，不能删掉正文中的触发、结果和同步关系。


## 三项绑定规则

1. **存在性绑定**：每个 `【VFX-X】`、`【环境音-X】`、`【动作音-X】`、`【音乐-X】` 必须在前面的正文中找到同名事件 ID和可见 / 可听触发。
2. **时序绑定**：正文先写触发，再写结果，再写标签细节；标签不能把结果提前、延后或改成另一个动作。
3. **属性绑定**：标签可以补充材质、声源方向、距离、频率感觉、动态范围、音乐拍点、衰减和余波，但不能改变正文的主体、位置、运动方向、颜色母题、接触对象或结束状态。


## 四类补充轨职责

| 标签 | 正文必须先写 | 标签补充什么 |
|---|---|---|
| `【VFX-X】` | 触发动作、生成位置、可见变化 | 传播路径、轮廓、材质、亮度、遮挡、峰值、衰减、跨镜继承 |
| `【环境音-X】` | 空间中正在发生的声场变化 | 声源位置、方向、距离、空间大小、混响、遮挡、远近变化 |
| `【动作音-X】` | 谁与什么接触 / 移动 / 破坏 | 材质、力度、音头、持续、余响、与动作相位的同步 |
| `【音乐-X】` | 哪个画面事件与音乐进入、停顿或完成同步 | 段落职责、拍前蓄势、强拍 / 弱拍 / 长音、拍后余波、抢拍或拖拍关系 |

环境音与动作音不能只写“有声音”。环境音维持空间，动作音证明接触；音乐提供时间骨架，三者的职责不能互相替代。一个脚步既可以产生动作音，也可以被低频音乐包住，但标签要分别说明它们怎样叠加，不能把所有声音都写成“节奏感强”。


## 正文与标签的压缩边界

当正文已经写出“脚跟压实的瞬间产生冷青波纹”，标签只补波纹的轮廓、方向和衰减，不再重复整句动作；当标签补充了刀刃擦鸣，正文仍要写刀刃何时经过什么对象，不能让音效成为唯一动作线索。正文承载事件因果，标签承载调音和特效校准；二者重复到可以互相替换时，说明层级没有分开。


## 声画理论的迁移原则

这套双层结构吸收影视声音设计中的 `spotting`（为事件确定声音进入点）、同步声 / 拟音的接触证据、环境声的空间连续、非画内音乐的段落组织、声音桥和声画反差等原则。它们共同说明：声音不是画面后面的一张清单，而是对画面事件的时间和空间定位；但也不能让模型正文被完整音频工程表淹没。先在画面主轨中建立因果锚点，再在补充轨中做声音和 VFX 校准，才能同时服务生成、阅读、剪辑和复盘。


## 声画质量加厚


## 1. 建立声画事件账本

复杂镜头在正文外先登记最小事件账本，不新增模型正文层级：

```text
事件 ID：VFX-A1 / 动作音-A1 / 环境音-A1 / 音乐-A1
画面触发：谁在什么位置对什么对象做了什么
可见结果：对象的形状、位置、颜色、材质或焦点怎样变化
声音结果：声源、方向、距离、材质、进入点和衰减
音乐关系：拍前蓄势、同步完成点、拍后余波或故意错位
下一状态：动作余势、声场余韵、画面载体和下一镜第一变化
```

每个事件只登记真正改变画面、声音、节奏或连续性的内容。事件账本用于查错，不把“事件 ID、触发、结果”全部原样复制进正文；正文和标签只保留执行所需的最小信息。


## 2. 声源视角必须和摄影机一致

环境音和动作音除了“是什么声音”，还要判断它从哪里被听见：

- 画内近距离：声音清晰、音头明确，适合脚步、刀刃、手指接触和产品操作。
- 画外同场：声音方向明确，但声源暂时不入画，适合威胁、警报、来车和下一镜预示。
- 远处空间：高频衰减、混响更长、方向更宽，适合城市、机器群、人群和天气。
- 主观听觉：可以低通、压缩、抽空或只留下心跳 / 呼吸，但必须由人物状态或摄影机视角触发。

声音视角不能和画面距离矛盾：局部接触特写却配远处空旷回声，会削弱受力；远景城市却把单个脚步做成贴耳近麦，除非这是明确的主观听觉变化。


## 3. 同步、预置和声音桥

声音与画面有三种常用关系：

```text
同步：接触、爆裂、标题锁定与声音完成点同落。
预置：下一镜的警报、脚步、低频或呼吸先进入，画面随后揭示声源。
声音桥：上一镜的摩擦、余响、长音或环境底噪跨过切点，帮助下一镜继承空间 / 动作相位。
```

预置和声音桥不能用来掩盖画面断因。若声音先出现，正文必须写它来自画外或上一状态；若声音跨镜保留，下一镜必须说明声场如何继续、变化或衰减。音乐存在时，声音桥可以维持乐句连续，但动作音仍要在真实接触点完成。


## 4. 声音优先级与静音

一个镜头最多保留一至两个主声画事件。混音优先级按本镜任务决定：对白 / 关键表演 > 决定性接触音 > 关键环境警报 > 音乐细节；纯动作镜头则优先决定性接触音和动作方向，音乐与环境为其让位。不要把脚步、衣料、城市、电流、警报、金属、低频、音乐和粒子全部写成同等重要。

静音或抽空半拍也是事件，必须写清被抽掉什么、由哪个动作触发、持续到哪个完成点，以及下一声音如何回来。`突然安静` 不够，改成 `刀锋接触前，脚步和城市电流同时抽空，只留一口吸气；红带裂开时金属撞击和鼓点同时回来`。


## 5. 声画冲突审查

逐镜检查以下冲突：画面接触已完成而声音仍在预备；声音已经爆发而画面尚未发力；近景动作配远景声场；音乐强拍切断了必须完整读完的动作；环境音盖住决定性结果；下一镜继承了声音却换了空间、方向或材质。发现冲突时先修事件相位，再修词语，不用“更有氛围”掩盖时序错误。


## 声音语法

同期纸张音效是材料真实性和节奏提示，不是装饰音效包：

- 滑入对应纸片摩擦和方向。
- 弹入对应短促轻响。
- 压平对应低而短的纸面轻敲。
- 翻页、抽拉、转盘、铰链各有不同摩擦长度和瞬态。
- 锁定后留短暂安静，让关系被看懂。

声音层级默认是关键口播 / 旁白优先，其次知识承重纸张音效，最后才是 BGM。纯 B-roll 可只保留纸张音效；有旁白时压低纸声但保留动作触感；BGM 不得覆盖纸机关完成的重音。


## 音乐、声音与速度

音乐存在时，速度设计必须接入全段音乐-画面合同；音乐 BPM 不等于画面切镜速度。一个动作可以跨多个拍完成，一次强拍也可以只负责接触或构图锁定。

按 `拍前蓄势 → 拍上完成 → 拍后余波` 写视觉事件包络：

- 强拍 / 乐句边界：动作接触、方向反转、转场闭合、标题形成、VFX 峰值。
- 弱拍 / 细分拍：脚步、连续小位移、UI 刷新、粒子跟随。
- 长音：持续推镜、慢速形变、空间展开、角色抬头。
- 休止 / 抽空：停住、蓄力、反派出现、情绪保护层破裂。

允许抢拍、拖拍、切分和故意失拍，但必须说明重新合拍的视觉完成点。动作音优先落在真实接触，低频余响负责延长重量，吸气、衣料、机械预响和声音先行可以预告动作启动。没有音乐时，声音可用强弱、疏密和停顿建立节奏，但材质、空间传播和因果真实优先。


## 机制

本节 解决的是：知识博主、财经讲解、观点口播、教程旁白或知识型短视频中，什么时候保留主讲人，什么时候切入 B-roll，B-roll 应该证明什么，以及如何让辅助画面帮助理解而不是抢走认知焦点。

它不是一套固定的“素材风格”，也不是“每句话配一张图”的剪辑模板。它把口播编译成一条可检查的声画关系：

```text
口播命题
→ 观众此刻要解决的问题
→ 本节拍的视觉职能
→ 证据等级与素材来源
→ 画面如何进入、证明、停留和退出
→ 主讲人 / 旁白如何连续
→ 下一节拍继承什么
```


## 触发条件与边界

出现以下任一情况时读取：

- 用户提供口播、旁白或知识文案，并要求配 B-roll、辅助画面、知识讲解画面、财经讲解画面或自媒体讲解视频。
- 画面需要在主讲人、实拍 / 素材、图表、示意图、AI 生成画面、屏幕录制、纸艺、MG 或多图蒙太奇之间切换。
- 生成结果出现漂亮空镜、泛化人物在实验室 / 办公室里摆动、画面与口播只是关键词对应、事实没有证据或画面信息压过口播。

不在以下情况中强行调用：

- 纯文戏或人物关系镜头，B-roll 只是遮挡表演缺口；主用 `laohu-performance`。
- 产品利益需要真实操作与物理证明；主用 `laohu-video-compilation`，本节只补口播与 B-roll 的语义接口。
- 纯数据 / 图形推导；主用 `laohu-motion-design`。
- 明确要求纸拼贴、纸雕或纸艺知识风格；主用 `laohu-motion-design`。
- 音乐、歌词和视觉排版由音乐主导；主用 `laohu-motion-design`。

本节 可以作为口播结构的主要编译层，再选择一个视觉实现 Reference。视觉实现是“怎么呈现”，不是“口播在证明什么”：

```text
真人 / 素材 / 屏幕录制 / 纪实证据：事实、使用过程、现场和来源。
MG / 图表 / 2.5D：数字、关系、机制、流程和抽象结构。
纸拼贴 / 纸艺：隐喻、层级、组装、材料和触觉记忆。
多图蒙太奇：已有参考图的语义排序、裁切、运动和转场。
手绘 / 动画 / 3D：难以实拍的过程、尺度、结构或世界模型。
```


## 一、先判断 A-roll 还是 B-roll

不要把 B-roll 当作“主讲人说话时的漂亮填充”。先判断观众此刻最需要哪种信息：

| 观众任务 | 首选画面 | 原因 |
|---|---|---|
| 信任讲解者的立场、经历、判断或情绪 | A-roll 主讲人 | 脸、目光、语气和关系感本身就是信息 |
| 看见具体物件、现场、操作或结果 | B-roll 证据画面 | 口播命名事实，画面提供可检查对象 |
| 理解抽象因果、数据、流程或对比 | B-roll 图形 / 示意 | 画面承担结构关系，避免主讲人只用口头描述 |
| 感受尺度、氛围、风险或生活处境 | B-roll 体验 / 情境 | 画面让观众获得身体和环境线索，但不能冒充事实证据 |
| 记住章节、核心词或结论 | A-roll 回收 + 少量标题 / 图形 | 让观点落回讲解者与观众关系，不让标题卡取代内容 |

推荐的混合路线是：`A-roll 建立可信关系 → B-roll 证明 / 展开 → A-roll 回收判断、限定或行动`。不是每段都必须回到 A-roll；如果整条片由画外口播承载，也要保留声音连续、视觉证据和结论停点。


## 二、口播语义节拍拆解

不要按标点、每 2 秒或每句话机械切换。先把口播拆成能够改变观众认知的最小节拍：

```text
命题：这段要观众相信什么？
对象：观众要看见谁 / 什么？
机制：为什么会这样，或怎样发生？
证据：观众凭什么相信？
反差：原有误解在哪里被改写？
结论：观众要记住、判断或行动什么？
```

一句话可能只有一个节拍，也可能包含 `命题 → 机制 → 结论`。一条 15 秒口播通常只承载少数节拍；若拆出很多节拍，优先删减口播、延长时长、拆成多条或降低画面复杂度，不用快闪把所有内容塞进去。

每个节拍建立一行 `B-roll 节拍卡`：

```text
口播原文 / 时间承重：必须逐字保留的声音。
观众问题：此刻观众还不知道什么。
视觉职能：直观呈现 / 事实证据 / 机制解释 / 对比尺度 / 情境体验 / 章节导航 / 情绪余波。
证据等级：直接证据 / 可标注示意 / 代表性插图 / 纯氛围。
画面承重对象：本节拍第一眼必须看见什么。
进入触发：哪一个词、重音、声音先行、动作或图形状态让 B-roll 进入。
完成点：观众何时已经看懂本节拍，不再继续堆信息。
退出接口：回到 A-roll、进入下一图形、动作匹配、遮挡、声音桥或干净停点。
```

这张卡放在提示词代码块外，供导演和剪辑检查；模型正文只编译真正影响画面、声音和时序的结果。


## 三、证据等级与事实边界

B-roll 的“看起来像”不等于“证明了”。每条知识口播先区分事实、推论、例子和情绪表达：

| 等级 | 用途 | 可否支撑事实声称 |
|---|---|---|
| 直接证据 | 原始图表、真实屏幕录制、实际物件、可核验文件、真实演示或明确来源影像 | 可以，前提是来源、时间和范围准确 |
| 可标注示意 | 图表重绘、流程动画、结构剖面、比例示意、模拟实验 | 可以解释机制；必须标注“示意 / 模拟”，不能伪装成实测记录 |
| 代表性插图 | 用原创人物、场景或物件表现一种典型情境 | 只能说明例子或场景，不足以证明统计、因果或历史事实 |
| 纯氛围 | 情绪、质感、生活细节、抽象风景、节奏画面 | 不能支撑事实；只能承载情绪、段落缓冲或注意力重置 |

当口播包含数字、排名、历史事件、产品性能、医学 / 财经结论、真实人物或“研究表明”时，优先使用直接证据；没有来源就降级为“假设 / 示意 / 虚构案例”，不能用 AI 生成的实验室、股票屏幕、新闻画面或专家人物替代证据。真实数据和精确文字优先使用原始素材或后期排版，不能要求视频模型凭空重绘。

每个 B-roll 画面还要标记：`事实画面 / 示意画面 / 代表性插图 / 氛围画面`。如果观众不容易区分，必须在口播、字幕、画面标签或发布说明中做最小澄清；不能用电影质感掩盖证据等级。


## 四、画面与口播的分工

好的 B-roll 不只是重复口播名词，而是让两个通道各自承担不同信息：

```text
口播优先说：为什么、立场、限定条件、抽象关系、判断和人的声音。
画面优先证明：谁 / 什么、在哪里、怎样变化、尺度、材料、过程、对比和结果。
字幕只锁定：必要的专名、数字、关键词、结论或可核验原文。
声音优先提供：空间连续、接触证据、章节重音和口播之外的时间线索。
```

禁止以下低效组合：

- 口播已经逐字解释一个概念，画面再用同一句大字重复一遍，却没有新增结构。
- 口播讲机制，画面只放通用人物点头、键盘、城市航拍、实验室蓝光或股票跳动。
- 画面出现与口播同名但事实不相干的物件，制造“看似对应”的错觉。
- 口播正在说限定条件、反例或风险时，B-roll 仍停留在夸张成功结果。
- 一次加入图表、人物、字幕、装饰、音效和复杂转场，让观众不知道先看哪一个。

画面可以不与每个词同步，但必须与本节拍的认知任务同步。抽象句可用机制图或有因果的视觉隐喻；具体句优先展示对象和结果；情绪句可以留在 A-roll 或使用体验画面，不能把氛围误写成证据。


## 六、视觉实现路由

先由证据职能选择媒介，再由审美选择风格：

| 主要任务 | 推荐实现 | 主要 Reference |
|---|---|---|
| 真实人物、现场、操作、采访补画面 | 实拍 / 纪实 / POV / 资产化人物 | `laohu-camera-movement`，必要时 `laohu-performance` |
| 数据、流程、比较、结构 | MG、图表、2.5D、屏幕录制 | `laohu-motion-design` |
| 抽象观点、情绪、社会关系 | 纸拼贴、手绘、原创情境、符号蒙太奇 | `laohu-motion-design` / `laohu-camera-movement` |
| 多张已有图片的语义剪辑 | 图片证据卡、裁切、景深、匹配转场 | 本节 + 当前图片参考能力 |
| 难以实拍的尺度、内部结构、历史重建 | 3D、动画、合成示意 | `laohu-vfx` / `laohu-video-compilation` |
| 章节标题、核心词、结论回收 | 少量标题 / MG / A-roll 回收 | `laohu-motion-design` / `laohu-motion-design` |

“知识讲解”不是自动等于 MG，“B-roll”也不是自动等于多图蒙太奇。主导机制决定主要 Reference；本节负责保证口播、证据和剪辑关系不散。


## 七、声音、音乐与认知负荷

讲解型 B-roll 默认让口播保持最高可懂度：

- 口播是主时间轴，B-roll 动作音和环境声只在不遮挡关键词、重音和气口时进入。
- 音乐负责段落能量，不为每个 B-roll 微动作配置撞击声；关键转折、图形完成、证据落版才需要同步。
- 画面、字幕、口播同时承载新信息时，减少非必要纹理、装饰、复杂背景和持续运动；“有趣”不能成为认知噪声。
- 复杂知识先分段，再用箭头、颜色、局部放大、轮廓或明暗做信号；信号只指向主证据，不用全画面高亮。
- 画面和口播互补时可同时使用视觉 / 听觉通道；如果两者都在念同一大段文字，会把视觉通道浪费在重复阅读上。

这些判断对应多媒体学习中的 `signaling / segmenting / weeding / matching modality`，以及双编码理论的文字 / 图像双通道，但它们是设计依据，不是要求每条片都加入箭头、分段、双通道或提问。


## 八、15 秒与 30 秒的信息预算

不设固定镜头数、固定状态数或固定 B-roll 比例。先按观众能否识别、理解和记住分配预算：

- 15 秒：通常只承载一个主命题、一个反差或机制、一个结论；B-roll 最好只完成少数高价值证据。
- 30 秒：可以加入基准 → 变化 → 解释 → 结论，或一个事实、一个示意和一个反例。
- 60 秒以上：可以形成 A-roll 开场 / 中间解释 / 结尾回收，但每个段落仍需有独立的语义节拍卡。

如果所有节拍都在高速切换，观众只能记住运动而记不住知识；如果所有 B-roll 都是慢空镜，口播没有被证明。调整节奏时同时看信息速度、画面识别速度、口播速度和声音竞争，不以切镜数量代替节奏。


## 九、三段式编译


## `【基础设定】`

写口播 / 旁白是否为主时间轴、实际引用的图片 / 屏幕 / 人物 / 图表资产、事实与示意的边界、主讲人声线、画面风格和本条唯一主命题。不把整段口播复制进提示词；锁定台词时逐字保留。


## `【场景状态与氛围画质】`

写全条统一的 A-roll / B-roll 世界、摄影或图形媒介、主色彩、光线、声音底床和信息层级。删除一句如果只影响一个节拍，就把它移入对应镜头块。


## `【画面内容】`

每个 B-roll 节拍写清：当前可见事实、视觉职能、口播触发、画面主体、运动 / 图形变化、证据完成点、退出接口和必要声音。正文不写“这里解释知识”“让观众理解”，而写屏幕真正发生的可见事件。


## 十、质量门与失败修复


## P0 硬失败

- 画面与口播语义相反、把插图伪装成直接证据，或用 AI 生成画面冒充真实记录。
- 数字、专名、Logo、UI、研究结论或产品数据由模型随机重绘且没有确定素材。
- 每句话机械切 B-roll，A-roll 的人物目的、限定、反例或结论被遮掉。
- B-roll 只提供关键词画面，没有可见对象、过程、关系、尺度或结果。
- 画面、字幕、音乐、动作和特效同时争夺第一视觉落点，口播无法听清。
- 多图只变成等大缩略图墙，或转场载体结束后残留在下一画面。
- B-roll 切入和退出没有语义完成点、声音桥或下一节拍接口。


## 失败修复

| 结果问题 | 根因 | 修复顺序 |
|---|---|---|
| 看着热闹但没学到 | 画面没有视觉职能，只有氛围和特效 | 回到口播节拍卡，给每段补一个对象、机制或结果 |
| 画面总是泛化 | 口播命题没有证据等级和具体场景 | 区分直接证据、示意、插图、氛围，锁定可核验对象 |
| 观众听不清 | B-roll、字幕、音乐和动作音同权重 | 保留口播最高层级，删冗余字幕和微动作音 |
| 画面像幻灯片 | 图片没有主次、运动和退出接口 | 每节拍选一个主运动，保留稳定识别点，用匹配载体交接 |
| 字幕与画面重复 | 画面没有新增结构 | 让口播说“为什么”，画面表现“怎样 / 结果”，删整句重复文字 |
| B-roll 盖住核心观点 | 没有 A-roll 回收合同 | 在限定、反例、个人判断和 CTA 前后回到主讲人或保留清晰声线 |


## 十一、迁移测试与反复制边界

机制至少要迁移到：财经数据解释、历史事实讲解、科技原理、生活方式建议、情绪观点、产品知识和纯旁白短片。再把真人素材换成 MG、纸拼贴、3D、手绘、多图参考或屏幕录制；仍然要能执行 `口播命题 → 视觉职能 → 证据等级 → 进入 / 完成 / 退出 → A-roll / 声音接口`。

不得复制外部包的固定模块名、H3 六段式、默认 16:9、默认霓虹色、固定中文文字主平面、固定 8 种文字动效、固定五阶段、固定 4–6 次转场或任何示例中的品牌、文案、图片组合。只吸收 B-roll 路由、图片证据卡、语义排序、主次层级、清洁落版和模块化实现思维。

- Mayer, R. E., & Moreno, R. (2003). *Nine Ways to Reduce Cognitive Load in Multimedia Learning*. Educational Psychologist, 38(1), 43–52. `https://doi.org/10.1207/S15326985EP3801_6`
- Clark, J. M., & Paivio, A. (1991). *Dual Coding Theory and Education*. Educational Psychology Review, 3, 149–210. `https://doi.org/10.1007/BF01320076`
- Guo, P. J., Kim, J., & Rubin, R. (2014). *How Video Production Affects Student Engagement: An Empirical Study of MOOC Videos*. ACM L@S, 41–50. `https://doi.org/10.1145/2556325.2566239`
- Fiorella, L., & Mayer, R. E. (2018). *What Works and Doesn’t Work with Instructional Video*. Computers in Human Behavior, 89, 465–470. `https://doi.org/10.1016/j.chb.2018.07.015`

这些研究支持的是认知负荷、信号、分段、删冗余、双通道、讲解者参与感和视频分段等设计判断；它们不直接证明某种 B-roll 画风、转场数量或平台提示词格式。理论只能校准“为什么这样安排可能更容易理解”，实际质量仍需用成片的观看、复述、事实准确和剪辑可用性复盘验证。

## 研究依据与验证边界

Adobe定义J-cut为下一段声音先于画面进入，L-cut为上一段声音延伸进下一画面。[J/L cuts](https://helpx.adobe.com/premiere/desktop/edit-projects/trim-clips/perform-j-cuts-and-l-cuts.html)。同步、预置、声音桥在本地用信息权限判断，不自动等于优质。

本页的项目编译链与原创例子是本地方法设计；专业资料不证明生成模型一定遵从，也不证明观众效果已经发生。平台控制每次实际执行前重新核验。
