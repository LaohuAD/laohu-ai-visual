# 视频提示词编译：专业方法与案例

## 当前专业决策

封闭请求指当前模型一次请求所需事实已在实际输入中闭合；控制密度是能改变输出的必要约束覆盖，不是字符越多越好；降级是把不受支持的控制如实转为方向性要求。过度约束可能互相抵消，缺起点又会迫使模型猜。

收齐各子专业差异→保护冻结文本→按控制对象/起点/变化/路径/终态写连续导演句→放入父级三段式→检查一个方头是否藏了硬切→实测字符与结构→交父级实际VC及终验。适合专业方案已经成立的最终编译；反例是为了字符数删掉主因果，或编译时重写人物决定。

### 同一材料候选比较

候选A：同一信封交接：用“情绪复杂、保持连续、电影感”补满长度。

候选B：逐句写唯一信封从谁手中到谁手中，握住后才松手，固定桌侧观看，结束位置明确。

取舍：后者覆盖必要控制而无同义重复；字数更多并不能替代控制权变化。

适用与反例：本子不独立放行；冻结文字不改，完成首稿后仍回父级实际执行VC与最终复验。

### 编译或返修结果示例

“【画面内容】他伸手接住已经递出的信封，手指合拢后对方才松手；摄影机固定在桌侧，信封从画面右侧进入他胸前，最终停在双手可见的位置。”正式全稿仍需父级另两段与源镜号映射。

### 返回合同

返回封闭请求、三段式正文候选、源映射、字符/结构回执及VC前交接；指出本次改变哪个决定、原有哪项事实不能动、从哪个状态开始以及下一负责人如何验收。输入缺口影响因果时停止专业深化，带证据返回；不把下游修词当作上游事实已存在。

## 图片与视频共用一个成像内核

图片与视频不是两套互不相干的提示词。它们都要先让一个对象、关系和观看重点在画面中成立，再由构图、光色、材质、人物表演、环境和摄影共同证明同一个结果。区别在于：图片把因果压缩进一个决定性瞬间；视频把同一因果沿时间展开。两者三段同构但不等职：结果图的三段职责可以融合成自然画面叙述，正式视频仍保留显式三段和逐镜方头，以管理跨帧状态、声音和剪辑接口。

视频内部先建立`稳定层—变化层—结果层`，再写三段式：

```text
稳定层：人物身份、关系位置、服装妆造、空间拓扑、作品结果图成像合同、开拍前光色和承重道具状态。
变化层：唯一主变化承载者、精确触发、动作 / 表演 / 摄影机 / 环境 / 声音的因果响应和阻力。
结果层：决定性可见 / 可听结果、即时影响、余韵停点和下一单元可以继承的结束状态。
```

稳定层不是重复静态资产全文，变化层不是把所有对象都动起来，结果层也不是另加一个同权高潮。`【基础设定】`只声明生成合同与参考职责；`【场景状态与氛围画质】`只承接稳定层；`【画面内容】`让变化层抵达结果层。图生视频的输入图决定高权重起点，不替代人物动机、触发、时间传播和结束状态；文生视频没有输入图托底，才用最低充分的静态描述建立起点。

进入时间线前先过`静态成立门`：把开场暂时看成一张图，观众能否立即认出主体、关系对象、空间方向、第一视觉落点和作品成像世界；构图、光线、清晰度、前后景和人物姿态是否共同服务本段唯一任务。静态门只保证时间零点可读，不要求每一帧都是壁纸。连接相位允许遮挡、失焦、运动模糊、身体局部出画和不对称；视觉预算集中在开场识别、决定性瞬间和结果余韵。

随后建立`视觉注意力轨迹`：

```text
第一落点 → 哪个动作 / 台词 / 声音触发迁移 → 注意力经过什么对象或屏幕变化 → 决定性落点 → 余韵停点
```

构图引导线、主体面积与反差、光影变化、焦平面、人物眼线、摄影机路径、运动方向和声音只能按这条轨迹分工，不能分别争夺焦点。一个镜头有多个对象时，不把眼睛、手、衣摆、背景奇观和特效写成同权清单；用触发顺序让观众一次看见一件真正承重的事。

进入逐镜正文前，必须执行`镜头原子检查`。每个编号只回答五件事，答案共同围绕同一个主要画面内容：

```text
主画面内容：这个镜头唯一要看的对象、动作或反应是什么。
开场构图：摄影机从哪里，以什么景别看见它。
唯一主变化：这个对象在本镜从什么状态变成什么状态。
连续摄影机路径：固定，或从开场机位物理可达的一条连续移动。
结束构图：变化完成后画面停在哪里，并交出什么状态。
```

镜头身份以摄影机观看与时间的连续性为边界，信息节拍与生成批次分别判断。同一连续时空中，蓄势、接触、反应、拉焦或逐步揭示可以按序提供多个信息节拍，共同服务一个整体观看目的；注意对象换人、获得新信息或局部动作形成结果，都不单独触发拆镜。实际硬切、软切、正反打、插入镜头、时间跳跃，或摄影机无法连续抵达的观察位置必须新建段内C镜号；一个连续揭示不能靠事后声称“一镜到底”掩盖机位跳变。每个E-S-P内可有多个C，不改变原文次序，不再重组生成边界。转场只写在新镜头方头，表示它怎样从上一镜进入，不能埋在旧镜正文里。

连续长镜头需要`整体观看目的统一 + 同一连续时空 + 摄影机路径物理闭合 + 全程没有片内切镜`。变化景别、焦点或构图时，写清观察路径、焦点交接和阅读停留；复杂度不能超过本次输入与模型的可执行条件。路径不成立则拆镜，信息过载但路径成立则先减少竞争任务、延长必要窗口或重编批次，不能只因新信息出现就切碎连续观看。

人物不是运动物体。人物视频的生命感来自`当下目的与关系对象 → 为实现目的选择的动作策略 → 精确触发 → 足以辨认本次变化的承重通道响应（单一通道可以成立，多通道时异步）响应 → 对方或环境反馈 → 未完全消散的结束状态`。跑、回头、微笑、落泪和挥剑都只是外层动作；没有人物正在争取、保护、试探或抵抗的东西，动作越完整越像演示。眼神、面部、呼吸、手部、重心、衣发、道具、距离和声线只选择本次承重通道，禁止为了“活人感”让全身同时表演。

内部完整设计后，视频正文同样执行`必须锁定 / 方向引导 / 模型补全`：

- `必须锁定`：身份与关系、唯一主变化、关键空间方向、精确触发、承重接触、主要结果、结束状态和相邻单元接口。
- `方向引导`：动作能量、摄影机观看方式、材料运动、环境响应、声音功能和作品级成像变体；规定范围，不逐帧微操。
- `模型补全`：不承重的自然步态细节、次级衣褶发丝、背景随机微动、纹样排列和已经被输入图可靠锁定的静态外观。

完整判断不等于完整投喂。每增加一项精确动作、表情、光影、运镜、特效或声音控制，都要说明它在时间因果和注意力轨迹中承担什么；不能回答就降为方向引导或交给模型补全。官方视频模型指南普遍把主体、动作、场景、风格、摄影机、构图、氛围和声音作为可组合控制，并区分输入图提供的静态条件与文本负责的运动进程；这支持按职责选择，而不支持把所有字段一次填满。


## 先定观众得到什么，再定模型收到什么

提示词能把字段填满，作品却可能没有要害。正式分镜和三段式之前，先完成一张内部导演工作卡：

```text
观众结果：看完这段，主要感到、相信、理解或记住什么。
主要兑现：全段所有铺垫最后共同推到的唯一可见 / 可听结果。
次要兑现（可选）：最多一项，明确它如何放大主要兑现而不分流。
人物动力：人物为什么非做不可，正在保护什么或抵抗什么。
主关系压力：谁 / 什么正在改变谁，压力如何递进。
首个可见异常：最早哪项屏幕或声音证据让观众进入事件。
主视觉命题：哪一种空间、动作、表演、物件或光色关系承载本段。
决定性瞬间：全段哪一刻不能被别的漂亮镜头替代。
峰值与代价：效果怎样到顶，人物、环境、产品或关系因此留下什么结果。
余韵出口：结束后还留在观众心里的画面、动作、声音或缺席是什么。
主动放弃：哪些好看的镜头、特效、信息和支线不服务本段，明确不争夺预算。
```

这张卡不是正式提示词的第四段，也不向视频模型泄露作者解释。它负责决定候选胜负、Reference 路由、镜头预算和声画主次。人物、摄影机、环境、道具、VFX和声音只有三种合法身份：为主要兑现蓄势、在准确触发后兑现它，或证明它留下的结果。无法归入三者的漂亮画面不进入本段。若卡片只能写出“震撼、电影感、感人、节奏快”，或者同时列出两项不能分主从的高潮，说明灵魂仍未成立；不能靠三段式继续生产。


## 先有镜头

上游只有“人物悲伤、女侠御敌、产品高级、画面震撼”等概念时，先在分镜层竞争 3—5 个镜头构思。候选至少改变决定性瞬间、动作几何、观看位置、可见证据或结束状态；只换地点、天气和滤镜不算新镜头。

提示词编译前先完成一次戏剧带入，不允许从字段模板直接开写。用一句内部工作句回答：`人物此刻为什么非做不可 → 他用什么行为保护目标或抵抗处境 → 谁或什么怎样施压 → 观众最先看见哪一个异常证据 → 本镜结束后关系发生什么变化`。这句话不一定原样进入正式正文，但它必须控制动作强度、演员调度、摄影机位置和声音优先级。若把人物名与台词换掉后仍可套在任何剧情上，说明还没有吃透本场；返回剧本和上下游状态重新推演。

自媒体剧情短片的开场先检查“首个可见异常”：前几秒应让新观众看见与核心矛盾直接相关的动作、结果、关系侵犯或未解问题，而不是先展示环境和日常礼貌动作。钩子必须兑现正片，不靠无关爆炸、哭喊或随机快切。先从故事真正的异常中选择最有屏幕冲击力的证据，再决定特写、横移、急停、遮挡或声音突入。后续镜头仍要让异常获得原因、代价与关系结果，不能只有开头刺激。

胜出镜头先写内部五问：

```text
主注意力：观众第一眼看哪里。
主观看任务：观众在等哪个变化或结果。
主情绪：观众主要经历什么。
决定性证据：哪一个动作、接触、反应、声音或环境结果证明它成立。
停点：哪一帧最值得保留、裁切或交给下一镜。
```

五问必须能回扣导演工作卡。局部镜头很漂亮却没有推进观众结果、主关系压力或决定性瞬间时，降级为连接镜头、缩短或删除；不能因为已写得具体就保留。

每次将提示词交给模型产生视频结果前，都必须完整建立模型注意力合同：本镜唯一主变化、主注意力、主变化承载者、支撑响应、主动稳定层、不可丢结束状态，以及共享Reference要求的唯一任务、主证据、主动退让和不可丢锚点。人物、摄影机、环境、VFX和声音不能同时成为同权主变化；若都必须发生，按触发顺序形成因果。成片、草稿、试验片和候选片提示词都必须读取`02_共享资产库/05_工具流程/视觉生成模型注意力与提示词编译参考.md`并执行`镜头可执行语言`：模型正文只保留先验召回和可见 / 可听控制，把导演阐述翻译成对象、关系、动作、光线、声音和终态；人物表演按起点、精确触发、足以辨认本次变化的承重通道变化（单一通道可以成立，多通道时异步）、主要结果、即时影响和余韵编译。任务简单时可以缩短正文与回执，但不能降低注意力合同的判断完整度；多主体、多参考、复杂属性绑定和长时序只增加控制密度，不获得另一套可跳过的流程。


## 镜头方头与正文执行分权

每个镜头先建立`镜头宏观合同`，再写正文。方头是这一镜的摄影与构图概览，正文是`正文唯一执行主轨`：方头承诺的景别、机位、路径、构图和节奏必须在正文中逐步兑现；正文没有发生的动作、声音、特效和台词不得只靠方头或补充轨新增。

正式叙事作品进入视频父入口时，读取E-S-P分段执行卡及原文来源映射，再建立段内C摄影合同。景别、运镜、机位与构图由本阶段设计；事件顺序、冻结台词、世界位置、道具控制权、人物关系及结果不得改写。P边界不适配返回分段，剧情不足返回编剧。

```text
简单镜头：
【C01｜固定中近景｜平视侧面｜固定机位】

复杂连续镜头：
【C01｜景别：中景→近景→全景｜机位：左下低位→人物右前方平视｜摄影机路线：向右横移并旋转上摇→绕过肩线→后撤拉远停稳｜构图：起始→决定性→结束｜节奏：辨认停顿→移动加速→结果停稳】
```

方头不是关键词清单。依据P卡建立C方头：景别决定证据尺度，运镜决定基础观察变化，机位 / 视轴决定观看侧，构图决定开镜投影和必要重构；四项互相矛盾时在视频阶段重做摄影；若根因是剧情世界关系矛盾才返回编剧。复杂镜头再执行`摄影机路径闭合`：写清起始位置与朝向、触发、连续路径、经过的空间锚点、速度与稳定变化、焦点或景别迁移、最终机位和停点。横移、摇镜、升降、环绕、后撤和变焦可以组合，但组合动作必须在同一物理路径上连续发生；观察位置瞬间跳变、越过不可通过空间、切换到另一侧轴线或无法由前一位置到达时，必须新开镜头并写转场。

构图不是只列左下角、右上角和前中后景，而是建立`动态构图`。复杂镜头至少检查`起始构图 → 决定性构图 → 结束构图`：人物与承重物的世界位置不变或有因变化，屏幕位置、前中后景、遮挡、负空间、视线轴、焦平面和第一注意力随摄影机路径重新组织。只写本镜承重对象；没有前景、背景虚化或固定角落职责时，不为格式强加。

`节奏概览`只概括相位，例如`停住辨认→迟疑→后撤加速→撞墙硬停`。正文再用动作完成、反应延迟、速度变化和结果保持展开；只有确实需要控制的完成窗口、触发延迟和停点使用`局部相对时长`，不把每次转头、抬眼和脚步排成逐秒时间轴。

声音和VFX先在正文事件中出现，再用同名`事件 ID`补充。`声音轨迹`写可听属性怎样变化：声源、方向、距离、响度、频率感觉、遮挡、混响、进入、峰值和衰减；`紧张→恐惧→痛哭`属于人物情绪概览，不是可执行声音轨迹。方头、正文和补充轨发生冲突时，以重新编译正文为先，不能让三个位置各自讲一遍不同的镜头。

简单镜头保持紧凑。固定机位、单一构图和单一反应已经足够时，只写观看边界、触发、画内变化和结束停点，`不机械填满`复杂路径、动态构图三检查点、组合运镜、声音轨迹和逐动作时长。


## 人物、道具与剪辑必须共享一条因果

> 镜头可以跳，因果不能断；动作可以省，状态必须接得住。

逐镜具体不等于整段连贯。凡是人物选择、台词、关键道具操作或内部切镜承重，正式正文前必须完成以下内部编译；简单动作可以一两句完成，复杂文戏和跨空间操作不得跳过。


## 时间因果链

上游叙事灯光合同包含时间变化时，把它编译成`灯光变化事件`，而不是在氛围段追加静态光型词：

```text
起始光态：人物、关键物、背景与空气当前怎样受光，哪些信息可见或被隐藏。
触发：门窗开合、人物遮挡、车灯扫入、屏幕 / 实用灯启停、火焰变化、停电、法术或剧情异常由什么事件引发。
传播过程：光或阴影怎样沿空间移动，先后改变谁，材料、烟尘、反射和人物动作怎样响应。
结束光态：新的明暗、轮廓、信息权限和空间关系稳定在哪里，为下一镜留下什么。
```

只写“灯光变暗、气氛紧张”不算变化；只替换顶光、侧光、逆光等`光型标签`也不算叙事。没有变化时继承静态光态，不为每镜强造开灯、扫光和闪烁。视频只编译当前事件，不重新决定作品级光源动机。

每个批次都必须先建立一条不可换序的时间因果主线；时间线不等于逐秒时间码，它管理的是哪一个状态必须先成立，哪一个触发才能让变化发生，主要兑现何时到顶，以及它留下什么不可撤回的结果。先在内部写清：

```text
动机 / 初始压力
→ 铺垫与早期证据
→ 精确触发
→ 变化传播与阻力
→ 主要兑现
→ 即时影响
→ 余韵 / 下一状态
```

再让每个镜头只承担其中一个主要功能：蓄压、加压、触发、兑现或结果余韵。单镜只有在同一主体、同一主要画面内容和同一连续摄影机路径内，才可随一个未中断动作跨两个相邻功能；一旦需要插入物、反应、主观视角、反打、全景结果或片内切镜，就拆成新编号。不能让每镜同时追求完整起承转合。局部再按实际需要从下列链条取材，不把它当字段清单：

```text
起点状态
→ 触发事件
→ 主体动作或表演变化
→ 摄影机 / 视窗路径
→ 屏幕变化
→ 接触、声音或 VFX 结果
→ 余波
→ 结束状态与下一相位
```

每句话必须改变像素、运动、声音、情绪证据、身份稳定、物理因果、剪辑接口或结束状态。删除后没有可感知差异的解释、重复和气氛词不进入正文。

顺序打乱测试是完成门：如果镜头换序后主要兑现的力量、理解和结果基本不变，说明它们只是一组同题材美图，时间因果尚未成立。


## 时长反推与相对时长约束

单元总时长不按“单人表演、多人对白、动作镜头”等类型套固定秒数，也不按剧本文字量直接换算。先完成内部节拍排演，再按以下真实需要相加并取能够让观众读懂的最短充分时长：

```text
主体与空间识别
+ 动作完整完成
+ 情绪从起点经过触发到终点的中间变化
+ 完整台词、气口、停顿与听者反应
+ 摄影机路径和屏幕重构
+ 结果停点与剪辑把手
```

剧本篇幅只能提示其中包含多少动作、关系和情绪阈值，不能把字数机械折算成秒数。镜头任务完成就进入下一状态；承重表演尚未完成就增加时长、删次要效果或调整单元分配，不能为了平均镜长压掉过程。

总时长作为平台参数写在 `【基础设定】`。`【画面内容】` 保留连续编号镜头方头，镜头编号只标顺序，不绑定逐秒时间码。默认禁止 `0—2秒、2—5秒、片内14.2—15秒` 这类绝对起止区间；只有动作完成速度、触发后延迟、反应窗口或结果最低保持无法靠自然语言稳定控制时，才在对应镜头正文中使用少量相对时长约束，例如 `两秒内完成吞咽`、`听到关键词后约0.4秒才移开目光`、`数字稳定后至少保持0.8秒`。这些数字描述局部关系，不组成从零排到总时长的时间轴。`局部相对时长`只服务动作速度、触发延迟、反应窗口和停点保持；同一提示词不得把所有局部数字首尾拼成一条伪装的绝对时间线。


## 最低充分控制密度

不设机械最低字数，不等于允许短概要交付。正式首稿可先写`高密度导演母稿`，也可先确定关键场面再专业补全：把唯一主要兑现、逐镜起点、观看位置、视觉层级、人物目的、精确触发、动作 / 表演、光影环境、声音 / VFX来源、结果与剪辑接口全部闭合，再压缩为模型正文。关键场面或短概要可以作为探索起点，不能作为正式完成稿；两种路径都不得以“字段已经出现、没有明显报错”提前停止。每条正式提示词都存在由剧情、时长、人物数量、镜头数量、台词承重、空间调度、动作复杂度和连续性风险共同决定的“最低充分控制线”：在这条线以下，模型仍需要猜谁看谁、怎样说、怎样动、从哪里拍、何时反应或最后停在哪里，正文就没有完成。

质量验收使用0—3级强度，而不是有 / 无：0级缺失，1级点名但模型仍猜，2级可执行但主次偏弱，3级由足以辨认的声画证据形成主导并让竞争信息退让（单一机制可以成立）。每个承重节拍的主要兑现、决定性落点和结束状态必须达到3级；辅助节拍达到2级即可。脚本只拦0—1级结构错误，巅峰门继续判断实际声画是否达到主导。

复杂单元先做承重节拍覆盖检查。每个承重节拍至少闭合当前真正相关的控制通道：

```text
屏幕起点与空间坐标
人物当前目的与动作策略
触发词 / 接触 / 声音
说话者的开口前动作、台词中的声线与身体变化、说完后的停点
听者在准确触发后的眼神、呼吸、面部、手部、躯干或距离变化
摄影机起点、路径、焦平面、屏幕结果和切点
道具与环境受力、声源、光线或空气反馈
结束状态、静止余波和下一镜接口
```

不是每个节拍机械填满全部通道；功能性动作可以短，15—30秒多人文戏、复杂调度、长对白和高成本一次生成必须先做完整覆盖表，再把没有改变生成结果的字段名和重复说明压掉。若仍存在以下任一问题，禁止以“简洁”“信息密度高”或“没有最低字数”为理由交付：

- 台词脱离说话者表演或听者反应，删除台词标签后人物只剩站着念词。
- 同一镜头写了多人，却没有各自世界位置、屏幕层次、注意对象和动作路径。
- 情绪只用形容词概括，没有触发后的可见变化顺序。
- 摄影术语没有起点、路径、焦平面或最终屏幕结果。
- 声音、道具、光影或环境本应承担因果，却只剩背景名词。
- 单元后半段、对白重词、反应窗口或结束停点仍由模型自行补全。

字符上限是可用控制容量，不是必须填满的成绩；但只要还有高价值、非重复、能改变像素、动作、声音、表演、空间或剪辑接口的控制信息没有写入，就不得因为正文已经达到一两千字符而停止。压缩只能删除作者解释、同义反复、无来源氛围词和低权重装饰，不能删除承重控制通道。

最低充分控制线之后必须再过语言模式的[有效信息与冗余裁决](../../../../laohu-language-mode/references/05_有效信息与冗余裁决.md)。必要信息保护门保证起点、触发、人物目的、空间锚点、动作与摄影机路径、表演、声音、物理结果、结束状态和镜间接口没有被压缩掉；边际作用门再逐项确认它确实改变时间中的像素、动作、声音、表演、空间、物理或剪辑结果。只重复审美同义词、作者意图或已经由更强控制证明的内容才合并或删除。若缺口来自剧本、资产、声音或导演取舍，返回原负责人，不用提示词第一次发明。

音乐承重时先建 `音乐段落 → 主视觉事件 → 拍前蓄势 → 同步完成点 → 拍后余波`。卡点是事件完成态与音乐事件对齐，不是每一拍都切镜。

多批次叙事成片默认把整体配乐从视频生成请求中分离：每个批次只生成对白、环境声和动作声，成片音乐另做一条连续音频资产，并按整片时间结构设计。这样替换、缩短或重排镜头时不会在批次边界硬断音乐。只有某个画面动作必须与确定音乐事件精确同步时，才允许本批写入音乐关系，而且相邻批次必须共同绑定同一条已存在音频参考、明确连续入点与出点；禁止让各批次各自生成相似但彼此无关的音乐。


## 控制语言闸门

每条承重句落笔前先还原为 `控制对象 → 本次实际基准 / 起点 → 变化维度 → 方向、幅度或路径 → 可见 / 可听终态`。正式提示词不新增这五个字段，而是把它们压进连续导演句。相对词必须指向本次真实绑定的参考或本镜已经写清的起点；即使存在参考，也要补一个当前请求独立可执行的绝对目标。`轻微、自然、缓慢、更明显、进一步、最`后面若没有屏幕参照、变化路径和终态，只是作者愿望，必须重写。

不可变项和可变项分开控制。同一人物可锁眼鼻口耳的身份拓扑，同时允许脸颊软组织变化；同一场景可锁柱、门、桌的拓扑，同时允许人物、临时道具和光影变化。不得用“保持同一张脸 / 保持场景一致”吞掉本镜真正需要改变的区域。具体排除指令改写为正向唯一结果：声音轨列出唯一成分，画面列出唯一人物与物件，单镜写清连续路径；真实时间状态中的`尚未、仍未、没有抽走`可以保留。

Seedance 2.5或其他高成本视频在投喂前逐句检查：删除作者解释和悬空比较，确认每个弱词能回答“什么对象、相对什么、改多少 / 多快、最后看见或听见什么”，再运行结构与字符脚本。机械脚本只拦截明确的负向生成命令和作者解释，不以禁词表代替语义判断。

正式代码块不是给老胡看的创作说明，也不是剧情分析。`戏剧任务、表演任务、人物调度目标、观众应该感到、这一镜证明、不是……而是……`只允许出现在代码块外的内部导演卡；进入模型正文时必须翻译成摄影机和画内事实。翻译至少落到其中一项：人物的世界位置与屏幕位置、身体动作路径、接触与受力结果、眼线和呼吸变化、摄影机起点与停点、焦平面迁移、环境响应、可定位的声音或明确结束状态。若一句话只能解释“为什么这样拍”，却不能让模型画出下一帧，它不得进入正式提示词。


## 目标与执行时点

本 reference 是正式导演母稿的充分度、压缩与质检门。允许完整母稿法与“关键场面→专业补全”法，短概要和关键场面仅是探索起点；正式交付合同相同。先让导演工作卡、Reference机制、承重节拍、逐镜声画和序列关系完整成立；再阻止作者解释、同义重复和低权重装饰进入模型正文。不能先写没有主次、无限堆字段的超限长稿，也不能把探索稿的省略当作正式稿的充分度；创作中允许改写、删并和重排，最终不能删去承重接口。高质量首稿的顺序是：承重控制全部到位 → 0—3级强度审查 → 删除低价值信息 → 字符与结构校验 → VC提纯。

执行顺序：先确定决定性成片结果与承重节拍，展开产生该结果所需的身份、起点、触发、动作、摄影机、视觉层级、VFX、声音、情绪证据、转场和停点；确认承重项都进入具体镜头且达到3级主导后，再删除不改变结果的表达；随后完成三段格式、连续性、字符数和逐镜字段机械校验。全部通过后，必须交给 VC 做第二轮提纯或零改动判断。


## 句子准入与压缩顺序

一句话写出前先问：它独立或与相邻句群共同控制像素、声音、节奏、身份、物理、情绪或剪辑接口中的哪一项？气氛与生活节奏可累计，不要求每分句新增结果；整组仍无作用才删除。一个事实只放一个位置；全局不变量不在逐镜复述，资产已锁静态外观不在动作段复述，动作结果不再用情绪结论重复解释。

先删：

1. 作者意图、审稿解释、流程说明。
2. 同义风格词和重复氛围词。
3. 已被图片资产完整锁定的静态外观。
4. 不改变屏幕结果的摄影参数。
5. 没有来源、没有反馈作用的雾、尘、光斑、粒子。
6. 重复否定和具体排除对象。
7. 同一状态被不同句式重复描述的内容。

后合并：共同全局条件上移到前两段；连续动作合并为一条因果链；同一声音的声源、方向和衰减合并；同一资产只引用一次。

绝不先删：人物身份、剧情锁定台词、空间边界、动作起点、运动路径、接触点、受力结果、触发表演、禁止提前反应、尾帧状态、跨 `批次` 交接和剪辑接口。


## 泛化弱词审稿

`小、轻、低、微微、一点、稍微、淡淡、有点、慢慢、柔和、自然、高级、舒服、压住、收紧` 不是禁词，但必须落到可生成维度：对象是什么，变化在幅度、速度、音量、亮度、饱和度、距离、力度还是压力，观众具体看见或听见什么。不能让一个弱词同时代替动作、情绪和画质。

每个承重控制句用五问复核：控制谁或什么；从哪个本次可见 / 可听起点开始；允许改变哪个维度；沿什么方向、幅度、速度或物理路径变化；最后停在哪个可见 / 可听状态。比较级、最高级和`继续 / 进一步`必须指向本次真实绑定参考或当前镜头已写明的起点，同时补当前请求独立可执行的绝对终态。没有实际参照的`更、最、进一步`删除或改写；只有质量判断、没有屏幕证据的`自然、明显、高级、流畅`不能进入承重位置。

先分开不可变项与可变项，再检查是否互相冲突。锁人物身份时只锁本镜不允许漂移的身份拓扑，不用整张脸型吞掉表情、软组织或伤妆变化；锁场景时只锁固定结构，不吞掉动作造成的临时状态。出现`保持完全一致`同时又要求同一部位变化时，缩小锁定范围并明确变化区。


## 三段式污染检查


## 基础设定

只保留总时长、画幅、生成方式、实际绑定资产、声音总策略和全条硬连续性。不放剧情解释、逐镜动作和未上传参考。


## 场景状态与氛围画质

控制在 1-3 句，只写跨全部镜头成立的场景初始状态、成像基底、宏观色彩、整体光源和空气状态。删除某句后如果只影响一个镜头，把它下移到对应镜头。


## 画面内容

只写随时间变化的屏幕事件。镜头主语优先使用导演语言：`镜头中出现、镜头固定在、镜头推进到、镜头摇移到、镜头下压到、镜头抬起后、镜头被某物遮满、镜头从某处掠过、镜头停在`。不把小说心理和观众解释混入正文。


## 高频失败与修复

| 失败现象 | 根因 | 修复动作 |
|---|---|---|
| 内容很多但画面普通 | 没有单一承重机制 | 删除装饰，指定一个不可替代的决定性变化及其结果 |
| 特效覆盖主体 | 特效无来源、无阶段、无受力 | 绑定来源，分出现 / 增强 / 峰值 / 消退，让环境证明尺度 |
| 动作像摆姿 | 只写姿势，不写目标和力 | 补准备、发力、接触、受力、回收 |
| 快切像废片拼接 | 镜头只换角度，不换信息 | 每次切换必须增加攻击几何、产品证据、情绪反应或尺度 |
| 情绪一步到顶 | 触发与保护层缺失 | 写起点保护策略、精确触发、通道异步变化和禁止提前反应 |
| 长视频后半段忘指令 | 事件过多、全局重复 | 上移不变量，减少并行主体，每节拍只写变化量和结束状态 |
| 空间穿帮 | 没有屏幕侧和路径 | 建坐标、站位、运动方向、入画 / 出画与下一镜重建 |
| 资产越用越乱 | 图片职责未限定 | 写每张参考只锁什么，当前剧情状态覆盖旧配件状态 |
| 上游阶段资产已改，视频仍恢复旧脸 / 健康状态 | 只改资产定义，未失效全部消费者；多张参考争夺同一属性；反向排除词与自动肤色归一化重新召回旧状态 | 反向枚举全部消费者并重编译；为脸身阶段、肤色、服装和妆发指定唯一主参考；在每个可见镜头用轮廓、色度、承托和动作能力重申状态，并让固定白平衡与相对色度差同向证明 |
| 声音没有层次 | 只写“震撼音效” | 写声源、距离、方向、材料、瞬态、余响和退出方式 |
| 镜头不能剪 | 无入口 / 出口锚点 | 补动作、遮挡、视线、声音、形状、光色或方向匹配 |
| 画面内容变成逐秒时间轴 | 把内部节拍表直接投喂模型 | 保留连续镜头方头，删除绝对起止区间；只在局部动作、延迟、反应或保持确需控制时写相对时长 |
| 基础设定和场景状态混杂剧情 | 三段职责没有分开 | 基础设定只留总时长、生成方式、真实资产职责与声音总策略；第二段只留开拍前且跨全条成立的事实；变化全部回到对应镜头 |


## 连续性账本

对复杂镜头按需建立：

- `状态账本：对象进入状态 → 当前状态 → 退出状态`。
- `知觉账本：客观事件 → 谁先看见 / 听见 → 谁后反应`。
- `观众信息账本：观众领先、同步或落后于人物`。
- 道具相位必须具体，例如 `完整入鞘 / 顶开护手 / 部分出鞘 / 完全出鞘 / 回鞘 / 脱手落地`。
- 多主体运动账本写 `世界起点 / 屏幕起点 / 朝向 / 速度向量 / 相对顺序 / 出画顺序`，同时检查世界坐标和屏幕相对运动。
- 事件传播账本写 `命中点与入射角 / 材料失效顺序 / 碎片大小分组与飞散锥 / 永久终态`。

核心词、道具状态和空间压力必须共同继承。`凭什么` 不能被 `为什么` 替换；银行卡已经甩到对方桌边，下一镜不能仍被原持有者按住；脸部正反打和逼近 / 后退要服务同一空间压力。


## 正向收束检查

代码块先写目标画面。禁止用“不要出现某人、不要穿丝袜、不要切镜、不生成BGM”等具体排除句代替正面状态；改成“战斗铠甲从腰部至足部连续闭合”“画面只有确认角色”“单一连续镜头跟随人物完成动作”“声音轨仅由对白、同期动作声和环境声组成”。`泪尚未落、手仍未伸出、门没有打开`属于开拍前或触发前的世界状态，可以保留；它们描述当前事实，不是让模型想象被排除对象。抽象质量边界可以写比例自然、动作连贯、无文字水印。


## 长度与信息预算

- 先读取目标平台、具体入口、模型版本、生成模式和核验日期对应的`目标入口能力合同`。品牌名相同不代表网页端、移动端、API、T2V、I2V、首尾帧或多参考模式拥有同一长度边界。
- 只有官方文档、真实入口报错或可复现实测才能把字符数升级为硬门；记录计数口径、样本日期、超限表现和长提示词后段遵循度。
- 没有上述证据时标记`入口长度兼容性未验证`。保留结构闭合的高密度导演母稿，字符统计只报告信息规模，不回退到跨模型4000或默认10000字符。
- 外部案例的长提示词只能证明“该案例在当时某入口可被提交或使用”，不能自动成为本项目的新上限，也不能证明越长越好。

字符只统计单个正式 `text` 代码块，不设置机械最低字数，但首稿必须达到由时长、人物、台词、动作、调度和连续性风险决定的最低充分控制密度。若仍有承重表演、空间、声画来源、摄影机或结束状态需要模型猜测，继续补足；不能把“不凑上限”偷换成一两千字符提前停止。已证实超限时，先把能由输入资产、参考职责和界面参数承担的信息移出正文，再删同义解释与低权重装饰；仍超限才减少不承担主承诺的镜头、效果或支线，或拆成独立 `批次`。若删除一句仍不改变像素、声音、表演、身份、物理或剪辑接口，就删掉；未知上限也不能成为保留口水化解释的借口。


## 最终反向审稿

把提示词当成别人写的，逐句问：

1. 模型能看见或听见这句话吗？
2. 它改变了哪一个时间状态？
3. 它与前后动作是否物理兼容？
4. 它是否重复资产已锁信息？
5. 它是否抢走主注意力？
6. 它是否提供新的剪辑价值？
7. 如果删除，结果会不会变化？

第 1 项为否、且不是必要全局约束，删除；第 7 项为否，优先删除。最后运行同类问题全局扫描、字符数检查和状态等式检查。

这轮反向审稿必须发生在首稿交给 VC 之前。除错别字外，VC 收到的稿件若仍有三段缺失、镜头头部缺失、逐镜声画归属错误、明显重复、作者解释、字符超限或相邻状态冲突，应判定为上游编译失败并退回 `laohu-video-prompt`，不能把修基本功记成 VC 质量提升。


## 证据尺寸、角色审美与举例边界

提示词精度服从屏幕证据尺寸：远景不写毛孔级表情，极近特写不靠全身动作证明情绪。角色审美服从身份、任务和状态，不能把某个案例的冷白肤色、丝袜、高跟鞋、妆容或铠甲当成跨题材默认。规则中的人物名、道具名和镜头只是解释机制的例子，迁移时必须重新创作。

## 机制

本节 解决的不是某一种题材，而是视频提示词的文字组织问题：把“我想让模型做一个很有画面感的镜头”编译成模型能够按顺序执行的可见事件链。

编译前先定义本段唯一主要兑现，按需最多保留一项明确从属的次要兑现。所有镜头和声画信息先分配为蓄压、加压、触发、兑现或结果余韵；无法回答自己怎样推进主要兑现的画面，即使单看漂亮也不进入正文。

核心链条是：

```text
动机与当前画面可见事实
→ 摄影机从哪里看、沿什么路径运动
→ 主体与物体从什么状态开始
→ 谁接触谁、怎样发力、沿什么方向变化
→ 画面在运动过程中具体改变什么
→ VFX / 声音由哪个画内事件产生
→ 主要兑现在哪个可见 / 可听结果中到顶
→ 画面在什么影响与余韵中停住或交给下一镜
```

它借鉴连续性剪辑、动作匹配、屏幕方向、视线匹配、180 度轴线、景别分工、事件因果和视觉注意力管理的共同原则，但不把理论名词直接当成提示词。理论只用于内部判断，正文只留下模型能看见、听见和执行的结果。


## 先继承剧本镜号，再深化执行

普通叙事读取完整E-S原文和P卡的表演、世界位置、道具控制权、情绪触发及起止状态，再建立C摄影及原文来源映射；不把P卡重写成另一份剧本。

```text
单一来源：E01-S01-C03 → E01-S01-P01 / 镜头01
拆镜：E01-S01-C04 → E01-S01-P01 / 镜头02A、镜头02B
并镜：E01-S01-C05 + E01-S01-C06 → E01-S01-B02 / 镜头01—02
```

拆镜、并镜或改用组合运镜可以改变执行形式，不能改写剧情。景别、基础运镜和构图可按模型能力与屏幕证据调整；实际出画人物、事件顺序、冻结台词、关键道具控制权、关系结果和结束状态不得改动。一旦发现不改这些事实就无法成立，返回编剧，不在视频提示词中偷换。

MV、强媒介知识动画、故事板图像 / 预视化或老胡明确要求专业分镜资产时，可继续经过条件性 SHOT 阶段；此分支是专业资产需求，不是普通叙事作品的重复步骤。


## 跨媒介定位

本节 是“画面内容的通用编译层”，不是动作片模板。它统一解决四个跨题材问题：画面从哪里开始、观众通过什么观察系统接收变化、事件如何产生可见 / 可听结果、下一状态如何继承。观察系统可以是实体摄影机、三维虚拟摄影机、二维视窗、版式焦点或固定构图；它不替代当前作品的主导机制、资产规则、表演规则、商业证据、图形信息逻辑或模型适配。

正式编译分三层：

```text
第一层：主导机制决定“这一镜为什么成立”。
第二层：媒介物理决定“这个结果能以什么方式出现”。
第三层：本节 决定“怎样选择摄影机 / 视窗 / 构图路径，并把变化写成连续、可观察、可生成的镜头语言”。
```

同一个“触发 → 变化 → 结果”在不同内容中不是同一种动作：刀锋接触是物理受力，台词重词是关系触发，按钮点击是产品机制，图形节点连接是信息推导，音乐强拍是时间触发，角色剪影变化是视觉母题触发。先选对触发类型，再使用统一的镜头路径、屏幕变化和停点语法。


## 跨媒介适配矩阵

| 内容类型 | 本镜主导因果 | 正文必须证明 | 标签 / 辅助层重点 | 常见误套 |
|---|---|---|---|---|
| 文戏 / 对手戏 | 处境 → 人物目的 → 触发 → 可见反应 → 关系状态 | 视线、呼吸、距离、打断、沉默、动作选择和对手反馈 | 台词节拍、表演八维、声线、环境压力 | 用动作片的受力词替代关系变化 |
| 动作 / 战斗 / 追逐 | 蓄势 → 释放 → 位移 → 接触 → 受力结果 → 余势 | 攻击来源、运动路径、接触点、速度参照、环境反馈和结束姿态 | 动作音、冲击 VFX、速度曲线、卡点 | 只写“快速、激烈、爆炸、炫酷” |
| 广告 / TVC / 产品 PV | 用户处境 → 问题 → 产品机制 → 可见证据 → 用户利益 → 品牌出口 | 产品如何参与问题、物理结果如何证明卖点、利益如何被画面兑现 | 口播、卖点文字、产品音、品牌音乐、CTA | 用漂亮运镜代替卖点证明 |
| 动画 / 角色 PV / MV | 视觉钩子 → 姿态 / 动作签名 → 形状或母题变化 → 节拍完成 → 下一视觉状态 | 轮廓、色彩、运动向量、构图重心、角色身份和音乐完成点 | VFX、图形折页、标题、音乐段落、匹配转场 | 把每个画面写成孤立海报或机械每拍切镜 |

| 特效 / 世界变化 / 巨物奇观 | 稳定锚点 → 触发 → 传播 → 尺度 / 材质响应 → 不可逆结果 | 来源、传播介质、受影响对象、环境反馈和残局 | VFX 阶段、低频、冲击、光色反转、停点 | 只写“能量爆发、世界被改变” |

适配矩阵不是新的题材分类，也不是每行都要同时加载。先根据观众承诺和主导机制选择一个主要 Reference，再用本节把它编译成镜头正文；混合内容按主要节拍切换适配分支，不能把所有行的术语堆进一条提示词。


## 适配后的通用句法

```text
主导机制的触发者 / 触发物 + 当前空间与状态
→ 摄影机 / 视窗 / 构图焦点的观看位置、路径和屏幕变化
→ 触发如何改变主体、关系、产品、图形或环境
→ 可见 / 可听证据怎样出现、传播和达到峰值
→ 观众此刻得到的关系 / 信息 / 卖点 / 奇观结果
→ 停点与下一状态
```

句法里的每个承重变化还要通过五项控制检查：对象、本次起点、变化维度、方向 / 幅度 / 路径、可见 / 可听终态。比较词只在起点或实际参考已经进入本次请求时成立；即使参考存在，终态也要能独立描述。不可变身份、结构与空间锚点要和可变表情、软组织、动作、破坏或光色分开，避免“保持一致”把本镜真正要发生的变化一起冻结。

“接触”在动作片中可以是刀刃撞上警报带，在文戏中可以是重词击中对方的防御，在广告中可以是手指按下产品按钮，在 MG 中可以是数据节点连接，在 MV 中可以是图形轮廓与音乐强拍对齐。不要把动作片的“发力”机械套到所有类型，但任何类型都必须能回答：什么触发了变化，变化怎样被看见或听见，结果如何改变下一状态。


## 触发条件

出现任一信号时读取本节：

- 画面正文出现“第一帧已经发生动作”“这里揭示身份”“让观众看到”“完成登场”等作者解释，却没有直接写画面。
- 一个镜头头部写特写，正文却突然同时出现全身移动、城市全貌、手部细节和眼睛特写。
- 写了“镜头切到”“镜头上移”“快速推进”却没有起点、路径、方向、速度变化、停点和屏幕结果。
- 写人物向某方向移动，却没有景别、地面参照、背景反向位移或视差证据。
- 写拔刀、爆炸、能量、刀光、烟雾或光效，却没有说明来源、接触点、传播方向和结果。
- 写“无缝衔接”“自然转场”“保持一致”，却没有说明两个镜头共同继承的轮廓、颜色、材质、位置、运动相位和声音。
- 用“不出现第二次拔刀”“不要让人物哭”“不是另一个镜头”等否定句控制具体动作。
- 使用模型不稳定的生僻术语、抽象情绪结论或小说式跳接，导致主体关系需要模型猜测。
- 生成结果出现突然换景、人物瞬移、武器状态跳变、镜头方向反转或特效凭空出现。

静态单对象展示可以不加载本节；凡是需要镜头运动、主体动作、画面转化、VFX、声音、音乐卡点、卖点证明、表演转折或跨镜衔接的动态内容，默认把本节 作为编译层使用，即使首稿还没有暴露明显错误。


## 不变量


## 1. 先写看见的画面

每个镜头第一句必须直接回答：画面现在看见谁、什么物体、位于哪里、处于什么状态、正在发生什么。不得先写作者对镜头的解释。

```text
错误：第一帧已经发生动作。
正确：女刀客的黑色战斗靴重重踩进骨白网格，脚跟压出一圈冷青波纹。
```

“第一帧”“这一镜”“此处揭示”“让观众理解”可以作为代码块外的导演说明，不能替代模型正文中的人物、物体、动作和结果。`完成亮相`、`完成转场`可以作为动作链收束句，但前面必须已经把形成这个结果的画面写完整。


## 9. 正向描述，不召回禁止对象

具体负面句会把不想要的对象再次提供给模型。不要写“不要第二次拔刀”，改写为当前真实状态：

```text
刀锋已经完全出鞘，右手停在身体右后方，刀尖斜向上，余光沿刀路衰减。
```

排除句只保留在代码块外的验收边界，或用于抽象质量问题（文字水印、解剖畸形、画面破碎）。模型正文只描述目标画面，不描述作者担心什么。


## 10. 语言要像“镜头化小说”

好的画面内容兼具小说的视觉连续性和分镜的执行纪律：句子有空间、有动作、有质感和画面感，但每个意象都附着在镜头正在观察的对象上。推荐使用“对象 + 动作 + 结果”的连续句，不使用主题总结、作者自评或抽象旁白。

```text
对象：女刀客的黑色战斗靴。
动作：重重踩进骨白网格。
结果：脚跟压出冷青缺口圆环波纹，摄影机沿波纹上移并带出刀鞘。
```

可以写“冷白刀光像一条被拉直的线”，但必须紧接它从哪里来、遮住什么、如何进入下一画面。比喻是材质和形状的辅助，不是动作因果的替代品。


## 推荐镜头块

正式三段式中的 `【画面内容】` 使用以下结构；字段不是机械填空，只有本镜承重的行才保留：

```text
【C01｜景别或景别演变｜机位 / 视角｜摄影机路径 / 转场｜按需构图状态｜按需节奏概览】
当前画面：直接写主体、物体、空间位置和起始状态。
观察路径：按媒介写摄影机、虚拟摄影机、二维视窗或构图焦点的起点、方向、速度变化、经过对象、屏幕变化和停点；固定构图则写不动的边界。
动态构图：复杂镜头写起始、决定性和结束构图怎样通过同一摄影机路径重组；简单镜头省略。
动作因果：写主体接触、发力、位移、结果和结束状态。
【VFX】写画内来源、传播路径、材质反馈和收束状态。
【环境音】写声源、方向、距离和环境变化。
【动作音】写具体接触、材质和余响。
【音乐 / 节拍】有音乐时写拍前蓄势、同步完成点和拍后余波。
```

如果一个段落需要从人物中景切到刀柄插入特写，必须另开镜头块。摄影机沿可见、物理可达的连续路径推近刀柄，或固定机位从人物拉焦到刀柄时，只要时间连续、各信息节拍服务同一整体观看目的，就可留在同一镜头，并写清哪些对象离开画面、哪些对象进入画面及焦点交接。新获得刀柄信息不单独构成切镜。不能用“确实是一镜到底”作为事后解释把多个镜头重新装回一个编号。


## 镜头组织原则


## 先分配证据，再写句子

写每个镜头前，内部先确定：

```text
主注意力：观众第一眼看哪里？
主观看任务：观众等待什么变化？
主空间证据：观众如何知道人物在移动、受压或接触？
主结果：本镜结束后哪一项状态不可逆？
停点 / 交接：在哪个可见状态切走或交给下一镜？
```

一个镜头通常只保留一个主注意力目标。要同时表现眼睛、马尾、右手、城市和反派时，不是把名词都塞进同一段，而是安排明确的连续镜头路径与焦点交接，让注意力有触发顺序；若需要切换画面，则另开段内C镜号，保持P来源不变。


## 运动和切镜的速度关系

速度写法要绑定参照物：人物相对背景、摄影机相对人物、刀光相对刀锋、切镜相对音乐拍点。`快速、炫酷、激烈、电影感` 只能做总结，不能替代路径。

高能动作至少保留 `蓄势 / 启动 → 加速 → 接触 → 结果 → 余势 / 停点` 中真正承重的阶段。快负责越距和接触，慢负责预读和力量积累，硬停负责让结果被看见；持续快切会抹掉空间，必须用一处减速、遮挡或静止帧重新建立可读性。


## 画面句与解释句检查

把正文中的每句单独拿出来问：删除它后，模型生成的像素、运动、声音、节奏、身份、物理结果或剪辑接口会不会改变？不会改变，就是解释句、重复句或空泛形容词，应删除或改成可见动作。

高风险解释词包括：`第一帧已经、这一镜、这里揭示、让观众、为了表现、完成了、不要出现、不再、无缝、自然地、电影感、炫酷地、强烈地`。这些词不是绝对禁用；只有它们后面紧跟可观察对象、路径和结果时才保留，例如“遮挡退开后完成身份亮相”可以作为动作链收束，但不能单独构成画面描述。


## 失败修复表

| 失败表现 | 根因 | 最小修复 |
|---|---|---|
| 开头写“已经发生动作” | 作者在解释剪辑点，没有写首个画面 | 直接写主体、物体、位置、动作和即时结果 |
| 画面突然从脸跳到全身 | 景别职责混用 | 明确拉远 / 环绕 / 切镜，并补空间证据 |
| MG 同时要求读全局、分组和单个数字 | 信息尺度混用 | 按总览、分组焦点、单点细节分配证据，并写清视窗或版式切换 |
| 人物移动像瞬移 | 没有背景参照或动作相位 | 改为中景跟拍，补地面、背景反向位移和重心 |
| 特效凭空出现 | 缺少来源和传播路径 | 写触发者、接触点、路径、遮挡和余波 |
| 两条视频接不上 | 只写“同一个”没有视觉指纹 | A / B 双端重复轮廓、颜色、材质、位置、相位和声音 |
| 模型增加禁写动作 | 否定句召回了对象 | 删除否定句，改写动作完成后的正面状态 |
| 描述像名词清单 | 缺少观看顺序 | 用摄影机路径把对象按进入、离开和焦点迁移串起来 |
| 文字很美但画面不执行 | 比喻替代了因果 | 每个比喻后补来源、方向、接触和屏幕结果 |
| MG / UI 像在虚拟摄影棚乱飞 | 把二维版式变化误写成实体运镜 | 改写为视窗、图层、遮罩、缩放、重排和焦点迁移 |
| 每个镜头都在推拉摇移 | 把运镜当成高级感本身 | 固定机位或视窗边界，只保留真正改变观看关系的运动 |
| 黑色前景很多却只有廉价悬疑感 | 没有真实观察者、关系动机、视线通道或后文验证 | 建立关系视点合同；没有观察者时改成诚实的受限观察构图，或删除无职责遮挡 |


## 迁移测试

入库或修改后至少检查以下题材：

1. 武打：把“刀光”替换成拳头、车辆或投射物，仍能写出起势、接触、结果和空间参照。
2. 文戏：把“斩击”替换成递手机、逼近一步或回头，仍能保持景别和运镜的因果。
3. 广告：把“攻击结果”替换成产品参与、卖点证据和用户利益，仍能说明触发、可见证明、停点和声音。
4. MG / UI：去掉实体摄影机后，仍能用视窗、图层、版式重排和焦点迁移说明信息怎样成立。
5. 形态变化：把人物替换成纸片、界面图形或巨大生物，镜头语法仍成立，不依赖题材专有词。

如果规则只能指导“女刀客踩网格、拔刀、刀光遮挡”这一案例，而无法指导上述替换，它仍停留在案例复述，应继续抽象。


## 反复制边界

本节 继承的是画面组织机制：可见事件链、景别证据边界、镜头路径、动作因果、正向描述、共同载体转场和声音来源。不得继承任何外部案例的角色、品牌、台词、具体道具、镜头顺序、颜色组合或标志性特效。当前女刀客的靴子、刀镡、缺口圆环和警报带只作为局部示例，不是固定模板。

## 触发条件与观众承诺

用于电商广告、产品短片、品牌片、宣传 PV、门店获客和功能演示。观众承诺不是“产品很漂亮”，而是快速理解它解决什么、怎样起作用、凭什么相信、下一步做什么。

本节的主机制是商业证据。若作品主要依靠角色剪影、二维版面、标题序列和抽象图形世界建立 IP 气质，没有产品问题、功能参与和利益证明，本节不能因名称里有“PV”就被选为主要 reference。


## 商业证据状态机

先锁商业简报：目标人群、购买矛盾、一个核心承诺、2-4 个支撑卖点、每个卖点的可见证据、品牌记忆和行动出口。

商业卖点的画面编译遵循：`用户处境 → 问题触发 → 产品结构 / 功能参与 → 接触与受力 → 可见 / 可听结果 → 用户利益`。功能名、参数和口播不能代替结果。

每个信息状态只回答一个产品问题：

1. 结果先行：它能带来什么。
2. 操作证明：真实怎样使用。
3. 机制证明：为什么有效。
4. 最大反差：前后或内外差异。
5. 广度证明：不同场景仍成立。
6. 品牌与行动：观众记住谁、做什么。

不是每条广告都填满六步；按购买阻力选择最低充分证据。


## 产品真实性与资产锁定

建立产品锁：尺寸比例、材料、开合结构、按钮、接口、文字、Logo 位置、颜色和使用方向。真实产品未提供性能、价格、成分、疗效或认证时不得编造；原创测试产品可明确设计功能，但结构、卖点和画面物理必须一致。

需要 Logo 时调用 `【Logo参考@老胡Logo】`。不得因品牌片需要“高级”就重设计 Logo、金属化 Logo 或生成近似字标。


## 产品证明机制族


## 第一人称测试

用手部、视线和身体反馈让观众替代性体验产品；必须看见操作起点、触感、结果和使用后的行为改变。POV 不等于只拍两只手。


## 结构剖面与双系统汇合

外部操作和内部机制在同一时间线推进，最后在一个结果点汇合。剖面不能成为无关的技术炫技；每个内部运动都要解释一个外部结果。


## 极简产品广告

极简不等于空白背景加旋转。每镜只保留一个材料、结构或使用证据，通过光线移动、接触、开合和声音建立质感。产品身份必须始终可读。


## 品牌世界展开

由产品的一条结构线、颜色、材料或动作生长出世界，再回收成产品 / Logo。展开与回收必须共享几何或材料，不能只是任意场景蒙太奇。


## 镜头与信息层级

开场优先首帧兑现需求、异常结果或触感，不先做无信息空镜。特写进适合把局部证据变成问题，再逐步揭示产品整体和使用场景。

产品镜头每次只承担一个主证据：表面材料、结构动作、用户结果或品牌记忆。多个卖点并列时，用状态变化串联，不让字幕、产品、人物和背景同时争夺第一落点。


## 声音

产品声音要证明材料与机械：卡扣瞬态、织物摩擦、液体流动、磁吸贴合、马达频率、空间余响。BGM 只组织节奏，不覆盖关键操作声。口播命名画面已证明的利益，不在画面没证明时夸大。


## 三段式编译

- `【基础设定】`只承接总时长、生成方式、实际绑定资产职责和一句全条声音策略。本机制还需保护的内容为：产品、人物、Logo、场景和音色资产，商业承诺及不可编造边界放代码块外。
- `【场景状态与氛围画质】`：统一品牌成像、材料基线、主辅色和全局空间。
- `【画面内容】`：每镜按问题、产品介入、物理结果、用户利益和品牌停点编译。
这些内容按职责分别进入代码块外交接、开拍前全局状态或对应镜头变化；不把逐镜动作、身份命题、色卡、作者解释或禁止词表塞入基础设定。冻结台词、标题、Logo与音乐原文保持，具体出现位置由本镜声画事件承接。


## 惊艳点设计

广告惊艳来自“证据的表达方式”，不是脱离产品的特效。优先竞争：结果先于原因、微观机制与宏观使用同构、一个动作跨场景接力、材料变化形成可读品牌符号、产品解决问题后空间行为整体改变。


## 剪辑接口

每个卖点状态提供清楚入口和出口：按钮按下、产品遮满镜头、同形结构、同方向手势、机械重音或声音先行。结尾品牌帧保持短暂稳定，Logo 和 CTA 可读，不让粒子在最后一帧继续改形。


## 失败修复

- 漂亮但不知道卖什么：恢复用户问题和可见结果。
- 参数很多但不可信：把一个参数改成接触或对比证据。
- 产品变形：减少运镜与特效并发，重申结构锁。
- 品牌片像通用模板：从产品真实结构、动作和材料寻找视觉母题。
- CTA 突然出现：让前一结果自然腾出信息空间或通过同形回收进入品牌帧。


## 迁移测试与反复制边界

同一证据状态机应能迁移到家电、软件、服饰、饮料、汽车和服务。不得复制外部案例产品外形、品牌、广告语、镜头顺序和独特包装；只继承“每个状态回答不同购买问题”的机制。

## 触发条件与能力边界

当作品成败明显取决于速度变化、力量释放、动作可读性、镜头快慢对比、连续快切、慢动作、速度渐变、追逐压迫、文戏停顿、动态图形节拍或跨 `批次` 运动衔接时，读取本节。它是跨题材的辅助 reference，不是动作片专属分类；主任务仍由 `01-07` 中最适配的题材 reference 负责。

以下情况不必读取：普通人物走路、单一稳定推镜、没有速度设计任务的静态展示，或现有题材 reference 已经足够说明一项简单动作。不能因为画面中“有运动”就加载本节，也不能为了显得专业给每镜增加速度术语。

本节解决的是时间动力学：怎样让观众感到蓄力、冲出、撞上、失重、拖拽、迟疑、窒息、释放和余波。它不替代动作因果、人物目的、空间调度、音乐合同或生成后剪辑。


## 第一性原理


## 速度不是一个快慢形容词

观众感到的速度不是由一句“节奏很快”决定，而是多个独立时间层共同作用：

`事件变化率 → 信息进入率 → 动作位移与加速度 → 摄影机位移 → 屏幕内相对运动 → 镜头持续时间 → 转场完成速度 → 声音瞬态与密度 → 时间重映射与运动模糊`

正式判断至少区分：`动作速度 / 摄影机速度 / 切镜速度 / 信息速度 / 声音速度`。它们可以同向，也可以互相对抗。人物可以高速奔跑但摄影机稳定跟随；镜头可以不切却因近景横穿和强视差显得极快；画面可以连续快切但每个镜头内部几乎静止；音乐可以很快而角色故意慢半拍。

因此，“快”必须回答：

1. 谁或什么在快：人物、物体、摄影机、切镜、图形、信息还是声音。
2. 相对谁显得快：背景、敌人、镜头、重拍、观众预期或前一节拍。
3. 从什么状态变快：静止、匀速、迟疑、蓄力、缓慢靠近或上一镜余波。
4. 快到哪里结束：接触、越过、构图锁定、停住、反弹、出画或进入下一动作相位。
5. 观众必须看清什么：起因、路径、接触点、结果、表情变化或空间关系。


## 力度主要来自速度变化

匀速运动可以显得流畅，却不天然有力量。力量感通常来自加速度、突然制动、方向改变、质量反馈和余波：

- 静止后的突然启动，强调决断和爆发。
- 缓慢蓄势后的高速释放，强调力量储存。
- 高速运动的硬停，强调控制、阻挡或碰撞。
- 接触后的反冲、拖尾、衣发延迟和环境响应，证明惯性真的存在。
- 结果晚于接触短暂出现，可以制造“力量穿过去以后才爆开”的延迟冲击。

所以，速度提示词优先写“变化过程”，而不是只写峰值速度。


## 对比才让速度可感

持续快会让观众适应，持续慢会让刺激失效。真正可感的速度来自相邻节拍的差值：`停 → 动`、`慢 → 快`、`密 → 空`、`连击 → 静止`、`顺滑 → 断裂`、`跟随 → 失跟`。

“快中有慢、慢中有快”不是平均混合，而是让不同速度承担不同职责：慢负责预读、蓄力、悬念、情绪暴露和结果停点；快负责越过防御、压缩距离、完成接触和释放能量。没有慢，快失去参照；没有停点，结果没有重量。


## 可读性是速度成立的前提

观众必须先知道谁要做什么、动作从哪里来、撞到哪里，才会把高速变化理解成能力；否则只会看到模糊和混乱。高速动作最少保住三类证据中的两类：

- 预备证据：眼神锁定、重心压低、刀尖后撤、车身偏转、图形开始聚合。
- 接触证据：刀刃与物体同帧接触、拳脚落点、轮胎抓地、图形边缘闭合、按钮被按下。
- 结果证据：对手位移、材质破裂、空间翻转、角色停姿、标题锁定、声音余响。

速度越高，越不能同时让主体、摄影机、背景、VFX 和剪辑全部无差别加速。先选一个主速度承载者，其余层负责衬托或校正可读性。


## 九层速度账本

| 层级 | 控制对象 | 主要问题 | 常用可见证据 |
|---|---|---|---|
| 故事速度 | 事件与目标 | 局势多久发生一次不可逆变化 | 新威胁、新选择、新结果 |
| 信息速度 | 观众认知 | 单位时间进入多少新信息 | 揭示顺序、字幕量、证据停点 |
| 表演速度 | 眼神、呼吸、台词、身体 | 人物反应多快、哪里迟疑 | 抢话、停顿、吸气、目光延迟 |
| 动作速度 | 人物与物体 | 位移多快、怎样加减速 | 重心、轨迹、接触、反冲 |
| 摄影机速度 | 机身、镜头与焦点 | 观众被怎样带动或甩开 | 视差、主体尺寸、地平线、失跟 |
| 切镜速度 | 镜头持续与更换 | 何时切、切后更新什么 | 动作匹配、反应切、闪切、长持 |
| 转场速度 | 遮挡、光色、图形与 VFX | A 如何变成 B | 铺满、穿越、闭合、裂开、消退 |
| 声音速度 | 音乐、台词、动作音、环境音 | 何时预告、完成和衰减 | 强拍、瞬态、停顿、混响尾 |
| 播放速度 | 实时、慢动作、快动作、停格 | 时间是否被扩张或压缩 | 速度渐变、抽帧感、运动模糊 |

内部先找承重层，不机械填写九层。普通镜头通常只需要一至三层；速度主导的复杂镜头才建立完整账本。若多个层级同时变化，写清主次：例如 `人物爆发加速为主，摄影机先稳定锁住接触，再被冲击带出短促后撤；切镜不跟着乱跳。`


## 速度与情绪功能

| 情绪 / 观众感受 | 主要速度结构 | 不宜默认使用 |
|---|---|---|
| 爆发、愤怒 | 压住或短停 → 突然加速 → 短促硬停 | 全程大喊、全程手持乱晃 |
| 力量、重量 | 较慢启动 → 持续加速 → 重接触 → 长余波 | 轻飘的瞬移、接触即消失 |
| 技巧、敏捷 | 极短预备 → 清晰高速路径 → 精准停点 | 过长慢动作遮盖真实速度 |
| 压迫、威胁 | 对手或镜头稳定缓慢逼近 → 局部突然加速 | 从第一帧就疯狂快切 |
| 恐惧、惊吓 | 低变化率建立预期 → 破坏规律的瞬时事件 → 静默余震 | 均匀密集的惊吓点 |
| 悲伤、羞耻 | 反应延迟、动作变慢、呼吸不规则、镜头多停半拍 | 所有动作机械慢速化 |
| 亲密、犹豫 | 细小移动、缓慢靠近、目光与台词之间错半拍 | 摄影机频繁抢人物反应 |
| 权威、冷酷 | 节制匀速、最少无效动作、精准制动 | 为显强而高速挥舞 |
| 喜剧 | 明确预备 → 超出预期的延迟或抢拍 → 干净反应停点 | 没有反应镜头的连续快动作 |
| 崇高、巨物感 | 大尺度缓入、局部先动、全体后动、长衰减 | 巨物像轻物一样瞬间启停 |
| 混乱、失控 | 局部速度与方向冲突，但周期性给空间重置点 | 所有层同时随机变化 |

情绪映射不是固定公式。缓慢推镜可以是亲密、威胁或发现；关键看它相对人物、空间、声音和前一节拍做了什么。


## 相对时长约束


## 节奏概览只给相位，不替正文排满时间

复杂镜头可以在方头中加入一条短`节奏概览`，用箭头标出真正改变动作、摄影机或注意力的相位，例如：

```text
停住辨认 → 迟疑 → 后撤加速 → 撞墙硬停 → 结果保持
```

它只帮助读者先看懂整镜的快慢骨架，不能成为第二份动作正文。人物为何停、从哪里后退、摄影机怎样跟随、脚步与墙面怎样反馈、最终表演和构图如何停止，仍由镜头正文按因果展开。方头概览和正文出现不同顺序、不同终点或不同速度关系时，先重编译，不能让模型自行取舍。

相对时间只补模型容易抢拍或拖延的局部：动作完成窗口、触发后延迟、反应窗口、减速区和结果最低保持。`向左看1秒→向右看1秒→抬头1秒→后退3秒`若首尾覆盖整镜，虽然没有写绝对起止区间，仍然是伪装时间轴；除非每个数字都直接决定承重结果，否则改为自然动作顺序和速度曲线。简单反应、自然走路和固定镜头不机械增加节奏概览或数字。

相对时长约束只控制局部动作关系，默认禁止 `0-1秒、1-2秒` 或 `【片内14.2-15.0秒】` 等绝对起止区间。只在自然语言无法稳定表达局部速度关系时，使用可随总片长伸缩的写法：

1. 动作完成速度：`从顶镡到刃光切屏控制在0.2秒内。`
2. 触发后延迟：`刀锋接触后0.1秒内，警报带先保持完整，再沿接触点断开。`
3. 反应窗口：`听到关键词后停顿约0.4秒，她的目光才从对方移开。`
4. 结果最低保持：`标题与人物构图形成后稳定保持至少0.8秒。`

一个复杂镜头通常只保留 `1-3` 个真正承重的数字。需要更多精确秒数时，优先拆镜、删动作、增加总时长或绑定真实音频时间码。数字只约束局部关系，不替代动作链，也不伪装成生成后的真实剪辑点。


## 按题材选择速度结构


## 产品广告与品牌片

产品操作优先让机制可见：打开、按压、喷出、吸附、折叠、锁定都要保留接触和结果。高级感不等于全片慢动作；可以用克制缓入建立材质，再在功能发生时短促加速，最后缓出停稳。卖点文字和 Logo 必须得到独立可读停点。


## 恐怖、悬疑与奇观揭示

用低变化率建立观众预测，再由一次违反规律的速度变化触发惊吓或揭示。巨物通常局部先动、整体后动；镜头可以先缓慢靠近，让尺度参照逐步出现，再用短促异常事件打断。全程慢不等于悬疑，全程快也不等于危险。


## 三段式编译


## `【基础设定】`

只写跨镜稳定的时间制度：总体节奏曲线、是否以实时速度为基线、固定音乐或音频参考、特殊的抽帧 / 顺滑运动观感。不要在这里堆每个动作的速度。


## `【场景状态与氛围画质】`

写影响整场速度知觉的环境参照：近前景掠过物、雨雪风尘方向、稳定或失衡地平线、空间纵深、光源闪动、运动模糊基线。环境必须帮助观众读速度，不作为无来源装饰。


## `【画面内容】`

在编号镜头内按需编译：

`速度意图 → 主速度承载者与参照物 → 起点状态 → 速度曲线 / 动作相位 → 摄影机响应 → 接触与结果 → 声音完成点 → 可读停点 → 禁止提前或禁止失控的反应`

这是一条内部因果链，不是九栏固定模板。正文只保留决定成片的部分。

弱写法：

`【镜头】节奏很快，人物高速打斗，镜头快速切换，炫酷慢动作，音乐卡点。`

强写法：

`【C01｜中近景｜侧后低机位｜静止后突进】她先压低重心，刀鞘保持不动；右手启动后在极短距离内连续加速，刀锋沿单一斜线上挑。摄影机先锁住刀刃与金属棍的接触点，碰撞完成时才被冲击带出短促后撤；火星沿受力方向喷开，对手手腕后折并退出画面。她在下一次呼吸前骤停，刀尖保持清晰，衣摆晚半相位扫过腿侧后衰减。金属撞击落在强拍完成点，低频余响延续到停点。`


## 高频失败与修复

| 失败 | 根因 | 修复 |
|---|---|---|
| 全程都写快速、激烈、炫酷 | 没有速度参照和曲线 | 增加蓄势、制动、停点，只让承重层提速 |
| 人物快、摄影机快、VFX 快、切镜也快 | 多层争夺注意力 | 选一个主速度承载者，其余层稳定或延迟响应 |
| 快切很多但不精彩 | 每镜没有新结果 | 按攻击线、策略或信息变化删并镜头 |
| 寻找或追查换了很多角度却不紧张 | 重复动作没有信息增量 | 保留真正改变范围、策略、风险或答案的证据，其余同镜加速、合并或省略 |
| 重点段已经读懂仍长时间停留 | 把重要等同于慢，把停顿等同于悬念 | 以证据可辨认、预期形成和反应完成划定可读等待窗口，窗口到期即更新或切走 |
| 慢动作很多但没有力量 | 慢放扩张了无关过程 | 只扩张接触、技巧、表情或代价，随后恢复实时 |
| 巨物轻飘、人物瞬移 | 缺少启动、惯性和参照物 | 写局部先动、加速、环境传震与长余波 |
| 高速动作看不清 | 没有预备和结果证据 | 保住起点方向、接触点和停姿；减少同步特效 |
| 速度词与物理矛盾 | 只追求情绪形容词 | 按质量、材质、力向、摩擦和连接方式重写 |
| 音乐快就每拍切镜 | 把 BPM 当剪辑命令 | 强拍留给主完成点，连续运动跨拍，弱拍承载小变化 |
| 跨批次 转场忽快忽慢 | 只匹配形状，未匹配相位 | A 尾和 B 头镜像写方向、速度级别、加减速趋势与相位 |
| 精确时间码锁死片长 | 把导演时间线当模型正文 | 改为动作完成、触发延迟和最低保持的相对约束 |
| 运动模糊吞掉主体 | 把模糊当速度本身 | 保持主轮廓和接触点清晰，只在运动方向保留适量拖影 |
| 速度变化很多却无情绪 | 速度没有戏剧任务 | 每次变化绑定威胁、选择、力量、关系或信息结果 |


## 速度自审合同

初稿后逐镜检查：

1. 本镜真正承重的是哪一层速度，是否写成了泛泛的“快 / 慢”。
2. 相对参照物是否存在；删掉前后对比后，观众还能感到速度变化吗。
3. 蓄势、启动、加速、峰值、接触、余波、停点中，承重相位是否完整且顺序正确。
4. 人物、摄影机、切镜、VFX 和声音是否同时争抢速度；谁应该稳定。
5. 高速段是否仍能读出方向、接触和结果；慢速段是否仍在推进等待或情绪。
6. 质量、尺度、材质、衣发和环境是否给出惯性证据。
7. 切点是否由动作、反应或信息完成决定，而不是为了数量和均匀时长。
8. 相对时长数字是否只用于局部承重点；是否出现锁死片长的绝对起止区间。
9. 有音乐时，速度曲线是否接入段落、强弱拍、休止和决定性完成点。
10. A 尾与 B 头是否继承运动方向、屏幕速度、加减速趋势、动作相位和声音余韵。
11. 是否存在最低可读停点和后期可裁切把手。
12. 删除每个速度形容词后，剩余动作、屏幕变化和声音关系是否仍能让模型看见速度。


## 迁移测试与反复制边界

用以下变化测试规则是否真正可复用：

- 把女刀客替换为厨师翻锅、运动员扣杀、机械臂装配，七相位和主速度承载者仍成立。
- 把战斗替换为夫妻争吵，速度转为抢话、停顿、逼近、呼吸和反应窗口，规则仍成立。
- 把真人替换为图表、Logo、纸片或产品零件，速度曲线、完成点和可读停点仍成立。
- 把音乐删除，动作音和环境音仍能按接触、传播和衰减组织事件节奏。
- 把总片长从 15 秒改为 30 秒，局部相对时长仍成立，绝对起止区间不会锁死结构。
- 把 A、B 两段独立生成，交接载体的方向、速度级别、趋势和相位仍能被双方提示词独立召回。

不得复制外部案例的具体角色、武器、镜头顺序、音乐、精确时长和标志性速度渐变。吸收的是：速度分层、动作相位、对比、可读性、物理惯性、声画完成点和跨镜连续性。


## 理论来源与使用边界

- [Yale Film Analysis Guide: Editing](https://filmanalysis.yale.edu/editing/)：节奏由声音、镜头序列和镜内运动的速率与规律共同形成；镜头持续时间、长镜头、重叠剪辑与快慢节奏都能改变时间体验。
- [Yale Film Analysis Guide: Cinematography](https://filmanalysis.yale.edu/cinematography/)：摄影机运动、跟随、重构图、景别和慢动作会改变观看位置、注意力与运动感。
- Ollie Johnston 与 Frank Thomas，《The Illusion of Life》：预备动作、缓入缓出、跟随与重叠动作、Timing 用于建立重量、物理、情绪和人物性格。这里吸收原理，不照搬手绘动画工作流。
- Harold Whitaker 与 John Halas，《Timing for Animation》：动作所占帧数与间距决定速度、重量和表演节奏。正式提示词优先翻译成可见相位，不要求模型理解动画师帧表。
- John Lasseter, “Principles of Traditional Animation Applied to 3D Computer Animation”, SIGGRAPH 1987：传统 Timing、Anticipation、Follow Through 等原则可迁移到计算机动画，但仍需服务清晰表演。
- [RED: Shutter Angles & Creative Control](https://www.red.com/red-101/shutter-angle-tutorial)：快门角度影响运动模糊；更小角度更清晰断续，更大角度更柔顺拖影。生成模型未必精确执行参数，因此自然语言画面结果优先。
- [NVIDIA GPU Gems 3: Motion Blur](https://developer.nvidia.com/gpugems/gpugems3/part-iv-image-effects/chapter-27-motion-blur-post-processing-effect)：运动模糊能增强速度感并平滑低帧率运动，但它是视觉效果，不替代真实动作路径。
- Michel Chion，《Audio-Vision》；Jones 与 Boltz 的动态注意理论；Vroomen 与 de Gelder 的时间腹语研究：声音瞬态和规律会改变观众对视觉事件时点的注意和判断。这里用于设计同步完成点，不声称纯文生音乐能做到采样级同步。
- Karen Pearlman，《Cutting Rhythms》：剪辑节奏同时来自身体、事件和情绪，不等于平均镜头时长或切镜数量。

理论提供因果判断，不是固定速度表。具体动作多快、停多久、是否慢放，最终由观众任务、人物状态、物理尺度、模型能力和生成复盘共同决定。

## 机制卡写法

每次吸收新案例，内部建立一张机制卡：

```text
机制：观众体验由哪条因果链产生。
不变量：删除、换序或模糊后会失败的 3-7 个锚点。
可变槽：允许原创替换的主体、空间、材质、动作、摄影、声音。
三段式编译：哪些进入基础设定，哪些进入全局氛围，哪些逐镜变化。
失败修复：失败现象 → 根因 → 最小修复。
迁移测试：至少换两个题材，机制能否继续工作。
反复制边界：哪些独特表达绝不继承。
```


## 重点密度判断

提示词重点不是“重要词多写几遍”，而是形成少数高权重因果：

- 每条只设一个观众承诺。
- 每个镜头只完成一个新的状态变化或证据。
- 每个奇观只有一个主物理机制，辅效只证明它。
- 每个动作写到结果，不在接触前结束。
- 每个镜头给出可保存停点，不让模型平均分配注意力。
- 全局不变量上移，逐镜只写变化量。
- 每个镜头直接从可见画面开始；景别、运镜、动作和屏幕结果必须互相证明，不能让模型替作者补空间因果。

凡是删掉后不改变身份、空间、运动、情绪、声音、光影、结果或剪辑的句子，都是口水话候选。

`skills/laohu-video-prompt/skills/laohu-video-compilation/references/专业方法与案例.md` 的最低迁移检查：把一个镜头中的人物、武器、材质和题材全部替换，仍能按照“谁在什么位置做什么、摄影机怎么观察、画面怎么变、结果怎么交接”重新生成，而不是只能复述原案例的动作名词。


## 迁移测试

机制入库前至少通过：

1. 换人物和地点仍成立。
2. 换视觉材质仍成立。
3. 换 9:16 与 16:9 后主因果仍可读。
4. 换图生视频与文生视频后只改变描述预算，不改变事件逻辑。
5. 删除外部案例专有名词后，仍能独立指导创作。

若只能在原案例的镜头顺序、材质和文案中成立，它不是机制，只是案例复述。
