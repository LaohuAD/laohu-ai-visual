# 老胡视频提示词

## 镜头箴言

画面会动不等于镜头成立；变化有因，时间才有力量。

镜头不是段落容器，而是一次连续观看。一镜一事，切镜就是边界；信息密度来自相邻镜头不断交出新证据，不来自把多个观看任务塞进同一个编号。

视频提示词不是形容词长文，也不是第一次发明故事。它把已经成立的镜头编译成模型能执行的起点状态、触发、屏幕变化、声画结果和结束状态。

对普通叙事作品，完整剧本是内容母版，基础资产是身份与设计真源，E-S-P分段执行卡规定本次内容范围、讲戏、时间与接续；本Skill在每个P内部建立C01、C02……摄影镜头，决定景别、机位、构图、运镜与切点。不得改写剧情、冻结台词、世界位置、控制权和信息揭示顺序。

## 任务整合与权威输入

接收完整剧本及原文来源映射、[分段执行卡](../laohu-video-segmentation/SKILL.md)、资产/音色目录、真实参考与目标入口合同；MV另接MV导演交接包与最终音频时间证据。一P对应一条视频提示词，不自行合并P或重新分批；时长/负荷不适配时RETURN分段修订P及来源映射。历史B/VID只作兼容。

编译前读取[交接与验收合同](references/交接与验收.md)；设计摄影时读取[镜头空间与连续性](references/镜头空间与连续性.md)。视频负责世界位置到摄影画面的投影、画框入出、切点、动作相位与声画实现，内容不足返回编剧，不把尚未决定摄影误判为剧情缺失。

## 按真实缺口调用

先确定本次承重结果，再按下表只调用必要专业；每次CONSULT记录输入、保护项、提取机制、被改变的决定和成品落点。CONSULT结果返回实际调用者。直接点名的局部专业请求只需当前判断所必需的事实，不强制先建立完整父合同或整部作品。已确认选择不重开，没有缺口不全量读取。混合事件按阶段拆专业判断；由本入口负责的整部作品最终只有本入口整合一份交付。

| 缺口 | 子能力 | 必须返回 |
|---|---|---|
| 观看路线、视差、遮挡揭示或焦点迁移不清 | [运镜](skills/laohu-camera-movement/SKILL.md) | 摄影机起点—路径—停点、屏幕结果与焦平面合同 |
| 人物表演只有情绪标签，或听者反应、说话权、身体泄露顺序不清 | [表演](skills/laohu-performance/SKILL.md) | 处境与行动策略、触发词、通道先后、听者反应和终态 |
| 战术路径、支撑转换、接触、受力或回收不清 | [动作设计](skills/laohu-action-design/SKILL.md) | 动作相位、支撑/控制权账本、空间路径及回收接口 |
| 形体运动僵硬、时间间距、关键姿态、重叠或定格物性不清 | [动画](skills/laohu-animation/SKILL.md) | 关键姿态、时距曲线、体积/关节不变量、重叠和循环接口 |
| 舞蹈短语、重心、母题发展、群体相位或队形关系不清 | [舞蹈编排](skills/laohu-choreography/SKILL.md) | 动作短语、脚下支撑、队形/相位、拍位与终姿合同 |
| 图形变化不能证明信息、母题难追认、阅读停留或图层关系不清 | [动态图形设计](skills/laohu-motion-design/SKILL.md) | 信息不变量、图层/遮罩、状态转换、阅读停点与退出接口 |
| 异常变化缺来源、传播、材质交互、尺度或永久结果 | [视觉特效 VFX](skills/laohu-vfx/SKILL.md) | 主机制、源/传播/交互/收束、结构终态与声音接口 |
| 切点没有信息贡献、事件相位断裂、省略不可重建或素材把手不清 | [剪辑](skills/laohu-editing/SKILL.md) | 切点理由、出入相位、匹配载体、素材把手和不可裁切区 |
| 声画同步、预置、声音桥、口播证据或音乐完成点不清 | [声画关系](skills/laohu-audiovisual/SKILL.md) | 声画事件、信息权限、主从、相对窗口及跨切声音合同 |
| 真实参考、起终帧、GEO、资产属性主控或连续性把手冲突 | [视频参考与资产绑定](skills/laohu-video-references/SKILL.md) | 像素回执、入口职责、属性仲裁、GEO切片、首变与状态把手 |
| 专业决定成立但正式正文有字段污染、路径含混、长度问题或请求不闭合 | [视频提示词编译](skills/laohu-video-compilation/SKILL.md) | 封闭请求、三段式正文候选、源映射、字符/结构回执及VC前交接 |

## 接力与返回

CONSULT不转移当前作品主责。源故事/台词/空间因果不足返回编剧；造型和视觉系统错误返回对应设计；实际资产/绑定错误返回资产负责人。歌曲事实与全曲时间返回MV导演。需要跨专业语言判断时CONSULT laohu-language-mode，不用换写法掩盖内容缺口。专业子能力不得自行覆盖其他节点权威。

完整输入字段、状态账本、跨节点交接、硬边界和验收门使用[交接与验收合同](references/交接与验收.md)。合同是本入口的责任边界，专业方法已交由对应子能力。

## 最终验收与交付

每条先过基线与字符/结构检查，再实际调用laohu-vibe-creating-prompt；零改动也保留调用记录。VC返回后复验源P与段内C、冻结台词、参考职责、空间/动作/声画、三段式与字符，最后比较巅峰门并交付。修改正文后重新检查，不把“计划调用VC”写成已完成。

只报告真实进度。设计通过、待生成、已生成、已听试/已查看、已选定分别记录；文件存在不等于验收通过。作品主Markdown更新后由既有交付流程生成HTML并更新作品交付中心；内部规则不生成作品HTML。

父级正式格式唯一：`【基础设定】→【场景状态与氛围画质】→【画面内容】`；第三段先有时间因果主线，再有连续编号C01、C02镜头方头。台词直接嵌入说话者所在镜头，逐字锁定；默认不用绝对起止时间轴，只在承重处保留局部相对约束。执行本目录已有 `scripts/validate_video_prompt_structure.sh` 与 `scripts/count_video_prompt_chars.sh`；只有已核验上限才传限制值。
