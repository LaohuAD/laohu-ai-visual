# 老胡视频提示词

## 镜头箴言

画面会动不等于镜头成立；变化有因，时间才有力量。

视频提示词不是形容词长文，也不是第一次发明故事。它把已经成立的镜头编译成模型能执行的起点状态、触发、屏幕变化、声画结果和结束状态。

## 输入与责任

启动时只读取当前作品真正相关的：项目总览、已确认剧本、`MV导演交接包`、分镜或镜头任务、资产总表、相邻单元交接合同、已有生成结果和目标模型。

最低输入：

```text
镜头为什么存在：主观看任务与主情绪。
本段唯一主要兑现：最后哪个可见 / 可听结果必须成立。
可选次要兑现：最多一项，它怎样服务而不竞争主要兑现。
起点状态：开拍前人物、道具、空间、声音已经怎样。
触发事件：什么让状态开始改变。
确定时长与目标模型：
目标入口能力合同：具体平台 / 入口 / 版本 / 模式，以及已验证的时长、输入、长度和参数边界。
生成方式：文生 / 图生 / 首尾帧 / 视频参考。
实际可绑定资产：
真实参考图调用合同：每张实际图片的绝对路径、正式像素验收状态、入口模式、可见对象、固定与可动边界、禁止新生对象、首个变化和最终结果。
GEO 运行时切片：当前镜头真正需要的空间锚点、站位、轴线、路径、遮挡和可变状态。
激活参考职责：本次实际绑定的每份输入分别只负责什么，不负责什么。
作品结果图成像合同及本段阶段变体：
上一个单元的真实结束状态：
本单元结束后要交给谁：
```

缺的是剧情因果、说话权或人物选择，退回 `laohu-script-writer`；缺的是身份、结构、空间或产品参考，退回 `laohu-visual-assets`。提示词不能用更长的文字掩盖上游缺口。

### 真实参考图调用合同

正式图生视频、首尾帧或多参考提示词编译前，必须打开每一张真实参考图；文件名、资产表、提示词和上游“已完成”状态都不能代替像素检查。逐条记录：

```text
绝对路径与正式像素验收回执：
入口模式：起始帧 / 终点帧 / 构图参考 / 风格参考 / 视频参考；不能只写“参考图生视频”。
本条目标语义：当前 VID 必须表达的对象关系与结束结论。
真实可见对象：不看文件名，根据像素列出人物、装置、卡片、文字、路径、前中后景和已成立状态。
固定对象：输入图已经正确且本条不得漂移的身份、构图、空间、材质、文字或关系。
可动对象：本条允许进入、退出、翻转、移动、变形、发光或被选择的实际对象及边界。
禁止新生对象：输入图没有、上游也未委派，不得由模型补出的承重人物、卡片、文字、装置或结果。
首个变化：从真实输入状态开始发生的第一项可见 / 可听变化。
最终结果：动画停止时必须留下的独立可验收画面，以及它与下一单元的关系。
```

随后执行`参考图语义一致性门`：当前 VID 的目标语义必须与真实像素语义、入口模式和允许运动范围相容。语义不一致则拒绝绑定，返回 `laohu-visual-assets` 纠正图片身份、登记或重新验收；不得靠正文重新描述另一张不存在的正确图片，也不得交换文件名后继续使用未经复验的图。标记为草图、未验收、含生产编号或临时占位的图片不能进入正式提示词。

VMB只以风格参考进入时，不接管当前段落对象和构图；KF作为起始帧或构图参考时，必须按它真实可见的对象写运动。输入图已经是结果终帧，却要求“从空白开始逐项生成”时，只有入口真实支持终点参考或另有合格起始帧才成立；否则先改入口模式或补参考，不能让同一图片同时冒充起点和终点。

只有逐段载体合同把当前单元明确委派为 `AI_VIDEO_FULL`，且它采用强风格、系列化或关键帧驱动的知识动画时，才检查 `STY＋VMB＋KF` 前置门。若用户已经指定“风格选项 → 视觉母板 → 逐段分镜参考图 → 图生视频”的生产方式，或同一批全屏生成镜头必须依靠编辑拼贴、纸媒、手绘、定格等强媒介保持统一，则正式视频提示词必须取得：已人工选定并真实存在的 `STY` 风格参考、由该选择编译出的 `VMB` 静态与运动语法、当前单元已验收的 `KF` 关键帧 / 分镜参考图，以及三者互不越权的参考职责。缺任一项时返回 `laohu-art-direction / laohu-visual-assets`，项目保持 `ASSET` 或 `SHOT`；可以保留运动设想草稿，但不得完成 VC、登记为 `PROMPT` 或用于正式生成。`REMOTION_OVERLAY`、录屏与证据段不因共享风格进入本门。已有系列 VMB 与逐段 KF 均成立时不重复竞稿。

对纸质拼贴、剪纸、档案混合媒介和定格感动画，视频正文必须先交付`动画编排链`，再编译模型语言：

```text
起始空态：画面最初保留什么底板、背景或单一锚点，不能把最终信息提前摆满。
首个触发：哪一个词、声音或动作让第一个纸片 / 图片 / 路径进入。
逐步建立：元素分别从哪个屏幕方向、纸层、槽口或画外进入，以滑入、贴合、翻页、弹出、替换、展开或层间视差中的哪一种方式运动。
因果兑现：前一个元素的到达、碰撞、连接或选择怎样触发下一个变化，避免多个物件同时乱动。
结果停点：本段最终解释帧怎样与KF一致，哪些元素停止、降低亮度、退出或留给下一段继续使用。
```

若上游有 `KnowledgeVisualContract`，不新建另一套模板，而是把它编译进上述链条：`initialState` 进入起始空态，`interaction + stateChanges` 进入屏幕变化与因果兑现，`resultState + viewerInference` 进入结果停点和结束状态。`semanticAnchors`中每一个 `spokenCue → visualEvent` 都要落成可见触发，并保持前一状态是后一状态的条件；不得把整段口播只对齐到一张完成态图。`labelPlan`只写已通过图片像素验收的中文大标签，长句和必须逐字准确的解释留给确定性后期。

摄影机职责只有四类合法用途：显露层级，跟随作用路径，从输入交接到结果，或把注意力从已理解状态送到新状态。如果删掉运镜不影响知识状态变化的理解，优先固定摄影机；立体深度与运镜不是质量等级。本 Skill 只生成并复核文本提示词，完成 VC 后交给用户手动生成；不调用视频生成接口，也不自动调用媒体生成接口。

### 摄影机注意力合同

当且仅当当前单元是纸拼贴／分层纸雕／3D纸艺机关类知识讲解 `AI_VIDEO_FULL`，上游真实KF存在可追踪轨道、纸带、门洞、层间通道或明确输入—处理—结果空间时，正式提示词必须先在内部建立`摄影机注意力合同`。它不是第四个输出区块，而是编译进`【画面内容】`的一组因果字段：

```text
起始位置与朝向：摄影机从哪一个真实空间锚点开始，面对哪条已存在路径。
cameraRoute：沿哪些真实轨道、纸带、数据流、门洞或层间通道连续前进；起点、节点和终点可追踪。
revealOrder：按 KnowledgeVisualContract.semanticAnchors 的什么顺序揭示语义节点，哪些信息此时仍不得成为第一焦点。
attentionTarget：每一步唯一第一焦点是什么；上一焦点完成什么可见变化后才移交。
movementPurpose：为什么此时移动、移动揭示哪条知识关系；只写“酷、沉浸、电影感”视为缺失。
transitionOccluder：用哪一个真实前景纸层、门、轨道护栏、装置外壳或近景物件完成连续遮挡和焦点交接。
speedCurve：进入、接近、跨越、减速、停稳的速度变化；不能全程同速或持续高速。
focusTransfer：焦平面、构图主次和注意力怎样从已理解状态移到新状态。
readabilityDwell：已有准确标签、数字、问号、对勾或结论结果需要多少稳定阅读时间；移动中的文字不承担解释。
finalPayoff：摄影机最终抵达什么结果，哪条输入—处理—结果关系仍能回看，结果停点持续多久。
semanticAnchorBinding：逐条写 spokenCue → visualEvent → 知识状态；每次移动都绑定一条真实语义锚点。
```

每一步移动必须能回答：去哪里，为什么现在揭示，揭示了哪条关系或作用路径，绑定哪一条`spokenCue → visualEvent`，并给下一步留下什么知识状态。答不出任一项，删除该移动或退回重编译。固定正面把四张卡始终同权摆满、只靠翻牌／发光轮流点名，或FPV只写高速穿越、环绕、俯冲而未绑定语义锚点，都不能通过。

适用范围不能外溢：FPV式连续穿越是强纵深纸艺知识场景的候选手法，不是全项目质量等级。普通人物对话、一般转场、平面编辑拼贴、没有可追踪因果通道的解释或任何移动会伤害表演、文字与关系理解的内容，保留固定摄影机或更克制的合适机位；运动不能伤害理解，也不得为套用FPV新造参考图中不存在的轨道、门和机关。

#### AIOverlayCompatibilityContract

只要本条 `AI_VIDEO_FULL` 可能在成片中承接 Remotion 信息层，正式视频交接必须在代码块外附一份 `AIOverlayCompatibilityContract`。它把 KF 的静态预判编译成随摄影机与对象变化的时间合同，供老胡画面讲解选择叠层位置、持续状态和最低充分对比方式：

```text
visualAnchor：本镜必须持续保护的视觉锚点、作用路径与结果停点。
protectedRegions：按画面区域或运动轨迹描述不可覆盖对象；不能只写“不要挡主体”。
stableNegativeSpace：可叠加区域＋成立的相位 / 时间段；空间随运镜消失时必须写结束条件。
luminanceProfile：起始 / 过程 / 结果的暗、亮、混合或动态变化。
motionLoad：各相位的低 / 中 / 高运动负荷及来源。
forbiddenOverlayWindows：AI画面正在揭示关键关系、快速穿越或兑现奇观时，禁止新增解释层的窗口。
attentionHandoff：哪个 `spokenCue → visualEvent → 知识状态` 完成后，第一注意力从AI画面交给叠层；叠层结束后交回哪里。
suggestedContrastMode：NONE / LOCAL_BACKPLATE / REGIONAL_SCRIM / FULL_SCRIM，以及基于预期画面的理由。
```

`suggestedContrastMode`只是生成前建议，不是最终合成裁决。深色宿主画面与高亮叠层已满足可读性时应建议 `NONE`；只有局部冲突时优先局部底板或区域压暗，不能因为“出现 Remotion”就默认铺满灰黑蒙版。生成结果由用户手动取得后，后期必须依据真实像素、字幕、脸手、源界面和视觉锚点重新验证，并可覆盖本建议。

AI视频与Remotion可以在同一时间段共存，但必须分工：AI视频承担空间、物理因果、奇观或沉浸路线；Remotion承担准确文字、章节状态、证据指示或跨载体连续语义。同一瞬间只能有一个第一焦点。若二者都在推出新结论、同时高速运动或同时抢中心位置，先用`禁止叠加窗口`（forbiddenOverlayWindows）与`注意力交接`（attentionHandoff）错开，不用加重蒙版掩盖职责冲突。建议不等于最终合成裁决。

平面图片也可以有立体感：运动可以来自纸片层级、统一软影、边缘翘曲、轻微视差和定格步进，不得为了“动起来”擅自把平面拼贴改造成光滑3D模型。每个时刻只保留一个主动作，最多一个从属反馈；镜头运动不能代替对象变化。

当上游KF属于强纵深纸艺、机关流程或结构化知识动画时，继续使用现有真实参考图合同、动画编排链和正式三段式，不新增平行模板。先在内部消费上游`运动可供性判断`：只有真实像素中已经存在且登记为可动的对象、门、轨道、转盘、传送带、分类槽、验证关卡和前中后景通道，才能进入顺序动作；提示词不得凭文字新造输入图中没有的承重机关。每组动作必须由上一组留下的新状态触发，按因果顺序分批激活，不能把高信息密度误写成所有对象同时漂移、发光或弹出。

摄影机只选择一条完整可读、服务因果揭示的路线，例如沿真实轨道推进、穿过层叠纸景、围绕主装置小幅转向、俯视进入真实分类槽，或从人工长链横移到AI分支；先写它经过哪些真实遮挡与空间锚点，再按摄影机注意力合同写揭示顺序、焦点交接、速度曲线、阅读停留和最终兑现。节点只有在摄影机接近、经过、绕到或由上一状态沿路径触发后，才能成为第一焦点；大标签出现时摄影机必须减速、稳定并给出可读停留。禁止同一镜头为了热闹叠加环绕、俯冲、变焦和甩镜，禁止瞬移、随机高速旋转、所有节点开场同时显露，也禁止用运镜掩盖对象没有发生因果变化。若复杂过程只有结果KF而正文要求从空态搭建，先返回视觉资产补合格起始／中间状态，不让一张完成态同时承担起点和终点。

歌曲型作品还要先检查`MV导演交接包`。缺的是歌曲事实、导演命题、声画关系、表演 / 对口型策略、创作段落或生产单元边界，退回`laohu-mv-director`；这些已经成立时，本 Skill 必须继承最终音频时间证据、音乐与歌词触发、单元边界、分镜资产模式和相邻声音接口，只负责把当前单元编译成模型可执行的运动、表演、声音、状态变化与三段式正文。不得重新解释整首歌、按模型方便改写歌曲结构，或把一个生成单元冒充成成片中的一个固定剪辑镜头。

## 时空编译

### 图片与视频共用一个成像内核

图片与视频不是两套互不相干的提示词。它们都要先让一个对象、关系和观看重点在画面中成立，再由构图、光色、材质、人物表演、环境和摄影共同证明同一个结果。区别在于：图片把因果压缩进一个决定性瞬间；视频把同一因果沿时间展开。两者三段同构但不等职：结果图的三段职责可以融合成自然画面叙述，正式视频仍保留显式三段和逐镜方头，以管理跨帧状态、声音和剪辑接口。

视频内部先建立`稳定层—变化层—结果层`，再写三段式：

```text
稳定层：人物身份、关系位置、服装妆造、空间拓扑、作品结果图成像合同、开拍前光色和承重道具状态。
变化层：唯一主变化承载者、精确触发、动作 / 表演 / 摄影机 / 环境 / 声音的因果响应和阻力。
结果层：决定性可见 / 可听结果、即时影响、余韵停点和下一单元可以继承的结束状态。
```

稳定层不是重复静态资产全文，变化层不是把所有对象都动起来，结果层也不是另加一个同权高潮。`【基础设定】`只声明生成合同与参考职责；`【场景状态与氛围画质】`只承接稳定层；`【画面内容】`让变化层抵达结果层。图生视频的输入图决定高权重起点，不替代人物动机、触发、时间传播和结束状态；文生视频没有输入图托底，才用最低充分的静态描述建立起点。

进入时间线前先过`静态成立门`：把开场暂时看成一张图，观众能否立即认出主体、关系对象、空间方向、第一视觉落点和作品成像世界；构图、光线、清晰度、前后景和人物姿态是否共同服务本段唯一任务。静态门只保证时间零点可读，不要求每一帧都是壁纸。连接相位允许遮挡、失焦、运动模糊、身体局部出画和不对称；视觉预算集中在开场识别、决定性瞬间和结果余韵。

随后建立`视觉注意力轨迹`：

```text
第一落点 → 哪个动作 / 台词 / 声音触发迁移 → 注意力经过什么对象或屏幕变化 → 决定性落点 → 余韵停点
```

构图引导线、主体面积与反差、光影变化、焦平面、人物眼线、摄影机路径、运动方向和声音只能按这条轨迹分工，不能分别争夺焦点。一个镜头有多个对象时，不把眼睛、手、衣摆、背景奇观和特效写成同权清单；用触发顺序让观众一次看见一件真正承重的事。

人物不是运动物体。人物视频的生命感来自`当下目的与关系对象 → 为实现目的选择的动作策略 → 精确触发 → 2—4个承重通道异步响应 → 对方或环境反馈 → 未完全消散的结束状态`。跑、回头、微笑、落泪和挥剑都只是外层动作；没有人物正在争取、保护、试探或抵抗的东西，动作越完整越像演示。眼神、面部、呼吸、手部、重心、衣发、道具、距离和声线只选择本次承重通道，禁止为了“活人感”让全身同时表演。

内部完整设计后，视频正文同样执行`必须锁定 / 方向引导 / 模型补全`：

- `必须锁定`：身份与关系、唯一主变化、关键空间方向、精确触发、承重接触、主要结果、结束状态和相邻单元接口。
- `方向引导`：动作能量、摄影机观看方式、材料运动、环境响应、声音功能和作品级成像变体；规定范围，不逐帧微操。
- `模型补全`：不承重的自然步态细节、次级衣褶发丝、背景随机微动、纹样排列和已经被输入图可靠锁定的静态外观。

完整判断不等于完整投喂。每增加一项精确动作、表情、光影、运镜、特效或声音控制，都要说明它在时间因果和注意力轨迹中承担什么；不能回答就降为方向引导或交给模型补全。官方视频模型指南普遍把主体、动作、场景、风格、摄影机、构图、氛围和声音作为可组合控制，并区分输入图提供的静态条件与文本负责的运动进程；这支持按职责选择，而不支持把所有字段一次填满。

### 先定观众得到什么，再定模型收到什么

提示词能把字段填满，作品却可能没有要害。正式分镜和三段式之前，先完成一张内部导演工作卡：

```text
观众结果：看完这段，主要感到、相信、理解或记住什么。
主要兑现：全段所有铺垫最后共同推到的唯一可见 / 可听结果。
次要兑现（可选）：最多一项，明确它如何放大主要兑现而不分流。
人物动力：人物为什么非做不可，正在保护什么或抵抗什么。
主关系压力：谁 / 什么正在改变谁，压力如何递进。
首个可见异常：最早哪项屏幕或声音证据让观众进入事件。
主视觉命题：哪一种空间、动作、表演、物件或光色关系承载本段。
决定性瞬间：全段哪一刻不能被别的漂亮镜头替代。
峰值与代价：效果怎样到顶，人物、环境、产品或关系因此留下什么结果。
余韵出口：结束后还留在观众心里的画面、动作、声音或缺席是什么。
主动放弃：哪些好看的镜头、特效、信息和支线不服务本段，明确不争夺预算。
```

这张卡不是正式提示词的第四段，也不向视频模型泄露作者解释。它负责决定候选胜负、Reference 路由、镜头预算和声画主次。人物、摄影机、环境、道具、VFX和声音只有三种合法身份：为主要兑现蓄势、在准确触发后兑现它，或证明它留下的结果。无法归入三者的漂亮画面不进入本段。若卡片只能写出“震撼、电影感、感人、节奏快”，或者同时列出两项不能分主从的高潮，说明灵魂仍未成立；不能靠三段式继续生产。

#### 期待驱动节奏

悬念、寻找、误判、揭示、关系反转、倒计时、问题解决或知识解释承担观看牵引时，节奏不能只跟随抽象情绪或动作速度；先继承编剧的`观众问题—答案交接`，再建立内部`观众问题—声画兑现表`：

```text
节拍与当前观众问题：
进入本拍前已经知道 / 暂时相信：
本拍处理：建立 / 加压 / 延迟 / 部分回答 / 回答 / 改写。
新增证据与信息增量：它让观众多知道、改信或改等什么。
声画兑现：由哪个动作、构图、焦点、遮挡、声音或停点交付。
可读等待窗口：证据从何时足以被辨认，到反应或认知更新何时完成。
下一问题：是否由当前答案、代价或后果自然产生；没有则不强造。
```

`期待驱动节奏`不是把全片改成连续提问，`情绪不是唯一节拍器`。没有具体观众问题的氛围、观察、歌舞和克制表演，仍由身体、音乐、空间与材料的可读变化组织节奏。问题承重时，没有新增证据、风险、关系或判断变化的重复动作优先压缩、合并或省略；镜头角度只有改变信息权限、空间关系、人物视点或证据可读性时才新增，不能靠多角度重复同一动作制造紧张。

快慢由信息与表演共同裁决。快用于越过观众已经读懂且不再改变判断的过程；慢用于让关键证据达到辨认阈值、让观众形成预期、读到人物反应或承受答案到来的前一刻。证据尚未可读就切走是抢答；证据、预期和反应都已完成却继续拖延是等待过期。所谓重点不自动获得慢镜头，短促中断、实时动作或突然静音也能成为决定性节拍。以上表格只存在于代码块外的导演判断，正式提示词必须翻译为可见 / 可听事件。

### 先有镜头

上游只有“人物悲伤、女侠御敌、产品高级、画面震撼”等概念时，先在分镜层竞争 3—5 个镜头构思。候选至少改变决定性瞬间、动作几何、观看位置、可见证据或结束状态；只换地点、天气和滤镜不算新镜头。

提示词编译前先完成一次戏剧带入，不允许从字段模板直接开写。用一句内部工作句回答：`人物此刻为什么非做不可 → 他用什么行为保护目标或抵抗处境 → 谁或什么怎样施压 → 观众最先看见哪一个异常证据 → 本镜结束后关系发生什么变化`。这句话不一定原样进入正式正文，但它必须控制动作强度、演员调度、摄影机位置和声音优先级。若把人物名与台词换掉后仍可套在任何剧情上，说明还没有吃透本场；返回剧本和上下游状态重新推演。

自媒体剧情短片的开场先检查“首个可见异常”：前几秒应让新观众看见与核心矛盾直接相关的动作、结果、关系侵犯或未解问题，而不是先展示环境和日常礼貌动作。钩子必须兑现正片，不靠无关爆炸、哭喊或随机快切。先从故事真正的异常中选择最有屏幕冲击力的证据，再决定特写、横移、急停、遮挡或声音突入。后续镜头仍要让异常获得原因、代价与关系结果，不能只有开头刺激。

胜出镜头先写内部五问：

```text
主注意力：观众第一眼看哪里。
主观看任务：观众在等哪个变化或结果。
主情绪：观众主要经历什么。
决定性证据：哪一个动作、接触、反应、声音或环境结果证明它成立。
停点：哪一帧最值得保留、裁切或交给下一镜。
```

五问必须能回扣导演工作卡。局部镜头很漂亮却没有推进观众结果、主关系压力或决定性瞬间时，降级为连接镜头、缩短或删除；不能因为已写得具体就保留。

每次将提示词交给模型产生视频结果前，都必须完整建立模型注意力合同：本镜唯一主变化、主注意力、主变化承载者、支撑响应、主动稳定层、不可丢结束状态，以及共享Reference要求的唯一任务、主证据、主动退让和不可丢锚点。人物、摄影机、环境、VFX和声音不能同时成为同权主变化；若都必须发生，按触发顺序形成因果。成片、草稿、试验片和候选片提示词都必须读取`02_共享资产库/05_工具流程/视觉生成模型注意力与提示词编译参考.md`并执行`镜头可执行语言`：模型正文只保留先验召回和可见 / 可听控制，把导演阐述翻译成对象、关系、动作、光线、声音和终态；人物表演按起点、精确触发、2—4个承重通道异步变化、主要结果、即时影响和余韵编译。任务简单时可以缩短正文与回执，但不能降低注意力合同的判断完整度；多主体、多参考、复杂属性绑定和长时序只增加控制密度，不获得另一套可跳过的流程。

#### 镜头方头与正文执行分权

每个镜头先建立`镜头宏观合同`，再写正文。方头是这一镜的摄影与构图概览，正文是`正文唯一执行主轨`：方头承诺的景别、机位、路径、构图和节奏必须在正文中逐步兑现；正文没有发生的动作、声音、特效和台词不得只靠方头或补充轨新增。

```text
简单镜头：
【镜头01｜固定中近景｜平视侧面｜固定机位】

复杂连续镜头：
【镜头01｜景别：中景→近景→全景｜机位：左下低位→人物右前方平视｜摄影机路线：向右横移并旋转上摇→绕过肩线→后撤拉远停稳｜构图：起始→决定性→结束｜节奏：辨认停顿→移动加速→结果停稳】
```

方头不是关键词清单。复杂镜头执行`摄影机路径闭合`：写清起始位置与朝向、触发、连续路径、经过的空间锚点、速度与稳定变化、焦点或景别迁移、最终机位和停点。横移、摇镜、升降、环绕、后撤和变焦可以组合，但组合动作必须在同一物理路径上连续发生；观察位置瞬间跳变、越过不可通过空间、切换到另一侧轴线或无法由前一位置到达时，必须新开镜头并写转场。

构图不是只列左下角、右上角和前中后景，而是建立`动态构图`。复杂镜头至少检查`起始构图 → 决定性构图 → 结束构图`：人物与承重物的世界位置不变或有因变化，屏幕位置、前中后景、遮挡、负空间、视线轴、焦平面和第一注意力随摄影机路径重新组织。只写本镜承重对象；没有前景、背景虚化或固定角落职责时，不为格式强加。

`节奏概览`只概括相位，例如`停住辨认→迟疑→后撤加速→撞墙硬停`。正文再用动作完成、反应延迟、速度变化和结果保持展开；只有确实需要控制的完成窗口、触发延迟和停点使用`局部相对时长`，不把每次转头、抬眼和脚步排成逐秒时间轴。

声音和VFX先在正文事件中出现，再用同名`事件 ID`补充。`声音轨迹`写可听属性怎样变化：声源、方向、距离、响度、频率感觉、遮挡、混响、进入、峰值和衰减；`紧张→恐惧→痛哭`属于人物情绪概览，不是可执行声音轨迹。方头、正文和补充轨发生冲突时，以重新编译正文为先，不能让三个位置各自讲一遍不同的镜头。

简单镜头保持紧凑。固定机位、单一构图和单一反应已经足够时，只写观看边界、触发、画内变化和结束停点，`不机械填满`复杂路径、动态构图三检查点、组合运镜、声音轨迹和逐动作时长。

### 人物、道具与剪辑必须共享一条因果

> 镜头可以跳，因果不能断；动作可以省，状态必须接得住。

逐镜具体不等于整段连贯。凡是人物选择、台词、关键道具操作或内部切镜承重，正式正文前必须完成以下内部编译；简单动作可以一两句完成，复杂文戏和跨空间操作不得跳过。

#### 人物动机—行动校准

```text
人物此刻要什么 / 同时怕失去什么：
他为什么选择这个动作而不是附近更容易的动作：
这件物品在本场代表、诱发或阻挡什么：
动作造成什么即时身体、关系或环境结果：
台词与动作关系：一致 / 有意相反 / 无意冲突。
观众在动作当下先怎样理解，后续哪项证据确认或改写理解：
```

台词与动作一致时，让二者互相证明；表面相反时，只能有两种结果：人物正处在真实两难、伪装、犹豫或失控中，并且镜头能给出保护动作、迟疑、受力、对手反应或后续选择作为证据；否则就是上游错误，退回 `laohu-script-writer`。不能把无意矛盾解释成潜台词，也不能因为动作来自原稿就停止判断。

#### 道具状态账本

只登记被拿取、递交、隐藏、破坏、消费、争夺或跨镜继承的承重物品；背景陈设不机械入账。

```text
道具身份与叙事职责：
镜前位置 / 朝向 / 容量 / 支撑面：
谁以哪只手或身体部位接触，接触点与受力怎样成立：
离开原位的触发、提起方式、承重反馈与运动方向：
经过的空间锚点 / 可省略路程：
镜后落点、朝向、容量、支撑面与谁仍控制它：
下一镜继承的状态：
```

人物拿起盘、杯、文件、工具或武器时，物体必须从一个真实支撑转移到另一个真实支撑，重量要通过手腕、手指、躯干、液面、衣料或接触声留下反馈。端起后无落点、离手后仍悬空、换镜后数量或控制者改变，都属于状态断裂。

#### 剪辑承接合同

每个内部切点在写正文前回答：

```text
A镜已经完成什么，最后可见 / 可听证据是什么：
跨切载体：动作相位 / 视线 / 屏幕方向 / 物体 / 形状 / 遮挡 / 声音 / 因果结果：
B镜第一项证据怎样接住它，并新增什么：
切点省略了哪段时间或路程：
省略期间是否出现新的选择、障碍、人物、物体状态或不可逆结果：
观众凭哪些已见事实可以重建被省略部分：
```

`省略成立门`：只有动作目标已经确定、主体与物体身份没有改变、运动方向或目的地能够推断、后镜明确显示结果，且被省略段不包含新的决定、阻力或状态转折时，才允许省略中间过程。否则必须增加连接镜头、声音桥、动作匹配、空间建立或结果特写。所谓“观众会脑补”只能是验收结论，不能代替这些证据。

复杂单元再做一次状态链朗读：只读每镜最后一句和下一镜第一句。如果人物目的、手中物、屏幕方向、空间位置、声音来源或关系状态有任何一项无法连续复述，先修剪辑合同，再修华丽镜头。

内部校准完成后必须进入正式描述。两镜以上共同完成同一人物选择、道具操作或连续动作时，在`【画面内容】`开头先写一至三句`连续动作主线`：用画内事实说清同一人物、同一物体、不可交换的动作顺序、关键控制权变化和最终状态，再由编号镜头逐步展开。它不是第四个一级区块，不写主题、观众感受和作者解释，也不使用内部字段名；它的作用是让模型先看见整段事件，再理解每个镜头怎样完成事件。

例如不要只把“端盘、台词、夹回、离开”散落到四个镜头里；应先明确：`全段围绕同一盘菜连续发生：母亲先把菜夹入孩子碗中；看见孩子吞咽失败后才端起盘子阻止；孩子说完话从她仍端着的同一盘中夹回一块；母亲把盘子放稳在原餐桌后松手，空手起身走向阳台。` 随后各镜只展开当前相位的机位、表演、接触、声音和停点。总述与逐镜正文有任一状态冲突，整条提示词不得交付。

本 Skill 默认面向当前可用的强生成模型，不替生成模型预先降级。不得因为猜测模型“可能理解不了”，就删掉人物关系、动作因果、镜头调度、物理路径或决定性画面；描述端的责任，是把最佳导演方案写得清楚、完整、无冲突、可执行。平台字符上限只是法度：需要压缩时先删同义解释和低权重装饰，不能压缩承重因果。

### 时间因果链

上游叙事灯光合同包含时间变化时，把它编译成`灯光变化事件`，而不是在氛围段追加静态光型词：

```text
起始光态：人物、关键物、背景与空气当前怎样受光，哪些信息可见或被隐藏。
触发：门窗开合、人物遮挡、车灯扫入、屏幕 / 实用灯启停、火焰变化、停电、法术或剧情异常由什么事件引发。
传播过程：光或阴影怎样沿空间移动，先后改变谁，材料、烟尘、反射和人物动作怎样响应。
结束光态：新的明暗、轮廓、信息权限和空间关系稳定在哪里，为下一镜留下什么。
```

只写“灯光变暗、气氛紧张”不算变化；只替换顶光、侧光、逆光等`光型标签`也不算叙事。没有变化时继承静态光态，不为每镜强造开灯、扫光和闪烁。视频只编译当前事件，不重新决定作品级光源动机。

每个VID都必须先建立一条不可换序的时间因果主线；时间线不等于逐秒时间码，它管理的是哪一个状态必须先成立，哪一个触发才能让变化发生，主要兑现何时到顶，以及它留下什么不可撤回的结果。先在内部写清：

```text
动机 / 初始压力
→ 铺垫与早期证据
→ 精确触发
→ 变化传播与阻力
→ 主要兑现
→ 即时影响
→ 余韵 / 下一状态
```

再让每个镜头只承担其中一个主要功能：蓄压、加压、触发、兑现或结果余韵。单镜可在连续动作中跨两个相邻功能，但不能每镜都同时追求完整起承转合。局部再按实际需要从下列链条取材，不把它当字段清单：

```text
起点状态
→ 触发事件
→ 主体动作或表演变化
→ 摄影机 / 视窗路径
→ 屏幕变化
→ 接触、声音或 VFX 结果
→ 余波
→ 结束状态与下一相位
```

每句话必须改变像素、运动、声音、情绪证据、身份稳定、物理因果、剪辑接口或结束状态。删除后没有可感知差异的解释、重复和气氛词不进入正文。

顺序打乱测试是完成门：如果镜头换序后主要兑现的力量、理解和结果基本不变，说明它们只是一组同题材美图，时间因果尚未成立。

### 先定生成单元，再在单元内分镜

`VID` 是一次交给模型生成的完整视听段落，`镜头` 是这个段落内部的观看位置和切换语法；两者不得混为同一级。不能因为出现新的台词、新的情绪节拍或新的机位，就机械新建一个 `VID`。

先按目标模型的单次可用时长、字符上限和长叙事能力，把剧本节拍聚合成生成单元：

```text
同一连续事件 / 同一场景簇
+ 主要人物与资产可以在一次请求中稳定调用
+ 前一镜结果自然成为后一镜条件
+ 完整对白、动作、反应和转场在模型单次上限内能够讲完
→ 优先合并为一个 VID，在【画面内容】内使用多个连续镜头
```

场景簇允许在同一叙事段落里经过少量地点切换，例如“食堂受辱后继续吃 → 操场独行 → 教室独坐”，前提是它们共同完成一个不可拆的故事判断，并通过动作匹配、遮挡、视线、声音桥、光色或形状继承形成连续观看经验。模型支持的 30 秒不是必须填满的配额，但也不能继续沿用旧模型的 5 秒、10 秒或 15 秒惯性，把本可一次讲完的段落拆碎。

只有出现以下任一情况才拆成多个 `VID`：总时长超过当前入口单次硬上限；正式正文超过字符上限且删去非承重信息后仍无法执行；两段需要互相冲突的首帧、参考角色或世界状态；前一结果必须经过真实生成验收后才能确定后一段起点；或真实测试已经证明该模型在此类组合中持续丢失承重动作。拆分点必须落在已完成结果上，不落在未完成接触、半句台词或未知落点中间。

单元聚合完成后再分镜。每个内部切点必须回答：前一画面交出什么可见 / 可听属性，后一画面怎样接收它，并新增什么信息、关系、动作结果或情绪压力。只写“切到”“转场到”而没有共同载体，不算完成导演编译。

多个 `VID` 属于同一成片时，先建立序列推进账本，再分别写正文：

```text
VID / 本段观众情绪或认知相位 / 新增的唯一结果
起点状态 / 结束状态 / 下一段第一项新变化
继承的动作、形状、光色、声音或视线载体
本段决定性瞬间 / 峰值 / 余韵
相邻单元为什么不能换序
```

每个 VID 不能各自从零追求“完整、震撼、电影感”。前一段负责蓄压，后一段才能释放；前一段已经完成释放，后一段就必须承担代价、余波或新的关系变化。打乱顺序后力量不变，说明它们仍是几条平行提示词，不是一段作品。

### 时长反推与相对时长约束

单元总时长不按“单人表演、多人对白、动作镜头”等类型套固定秒数，也不按剧本文字量直接换算。先完成内部节拍排演，再按以下真实需要相加并取能够让观众读懂的最短充分时长：

```text
主体与空间识别
+ 动作完整完成
+ 情绪从起点经过触发到终点的中间变化
+ 完整台词、气口、停顿与听者反应
+ 摄影机路径和屏幕重构
+ 结果停点与剪辑把手
```

剧本篇幅只能提示其中包含多少动作、关系和情绪阈值，不能把字数机械折算成秒数。镜头任务完成就进入下一状态；承重表演尚未完成就增加时长、删次要效果或调整单元分配，不能为了平均镜长压掉过程。

总时长作为平台参数写在 `【基础设定】`。`【画面内容】` 保留连续编号镜头方头，镜头编号只标顺序，不绑定逐秒时间码。默认禁止 `0—2秒、2—5秒、片内14.2—15秒` 这类绝对起止区间；只有动作完成速度、触发后延迟、反应窗口或结果最低保持无法靠自然语言稳定控制时，才在对应镜头正文中使用少量相对时长约束，例如 `两秒内完成吞咽`、`听到关键词后约0.4秒才移开目光`、`数字稳定后至少保持0.8秒`。这些数字描述局部关系，不组成从零排到总时长的时间轴。`局部相对时长`只服务动作速度、触发延迟、反应窗口和停点保持；同一提示词不得把所有局部数字首尾拼成一条伪装的绝对时间线。

### 摄影机与屏幕变化

运镜术语不能独自承重。先写摄影机在现实或虚拟空间怎样移动，再写观众屏幕上发生什么：主体大小、角度、遮挡、焦点、方向、背景视差和最终构图如何变化。

复杂镜头先用方头概览景别演变、机位、摄影机路线、动态构图和节奏，再由正文沿同一条因果顺序展开。方头只负责导航，不能替正文省略路径；正文只负责执行，不另起一套与方头不同的机位和构图。

真人和三维空间使用实体 / 虚拟摄影机；MG、UI、二维动画和字幕动效优先写视窗、图层、遮罩、版式和焦点迁移。固定镜头可以成立，但要写清观看边界和画内变化，不为“高级”强造运动。

景别是证据边界。特写不能同时证明远处空间，中远景不能靠几像素脸部承担微表情。需要跨尺度时写清切近、拉远、视窗缩放、遮罩展开或版式重排。

多人场面先做两层空间排演，再写摄影机：世界层记录每个人相对固定锚点、桌椅、门窗或道具的方位、距离、朝向、进入路径和接触对象；屏幕层记录当前机位下每个人落在画面左中右、前中后景、谁遮挡谁、视线越过什么以及运动方向。换机位只能改变屏幕投影，不能改写世界位置。若同一人物在相邻镜头从左后方无过程地变成正前方，或群体从包围关系变成并排合照，空间排演即判失败。

人物素体、群像合照和服装资产主要锁身份、比例与造型，不自动拥有叙事构图权。参考图若是正面并排校准照，而正片需要侧后包围、前后遮挡或复杂走位，必须把“身份参考”和“调度参考”分开：身份图只负责谁是谁；另用镜头首帧、故事板、简模 / clay render 或已验收视频片段负责机位、空间结构、动作路径和阻挡关系。不能只靠一句“仅参考身份”抵消一张强构图图片对模型的影响。

后文才揭示的观察者、控制者或亲密关系可以在前文留下可回看的摄影证据，但必须先建立`关系视点合同`：视点是角色主观、受限第三人称还是中性观察；真实`观察者位置`在哪里；人物与摄影机之间的`视线通道`是否成立；`遮挡来源`是哪扇门、哪块家具、帘边或人群；当时谁知道什么；后文用什么动作、位置或声音验证这层关系。`主观镜头必须属于`一个当时真实存在且能看见该画面的角色；否则只能写成受限观察构图，不得暗示虚构的偷窥者。遮挡本身不等于偷窥，它还可能只负责纵深、隐藏剪辑点或限制信息；若没有人物关系和空间证据，不为悬疑机械增加黑色虚化前景。

#### 当前镜头封闭编译

每个 VID 在调用模型前都要能脱离整部剧本独立执行。把上游世界与场景资料裁成当前请求的 `GEO 运行时切片`，只保留本镜会进入画面或决定运动的固定锚点、人物站位、观看侧、轴线、入口出口、动作路径、遮挡层级、承重道具、当前破坏与光影状态；再为本次真正上传的素材声明`激活参考职责`。未绑定的母版、未进入画面的房间和仅供作者理解的设定不进入正文。

首帧不是一张漂亮人物合照，而是事件的起始阻挡。`首帧阻挡`必须让人物与锚点在世界位置、屏幕左中右、前中后景、朝向、视线对象、遮挡关系和动作预备态上能够同时成立；人物身份参考与叙事构图冲突时，调度首帧负责位置和构图，身份 / 服装 / 场景资产只守各自属性。当前请求需独立写清：

```text
本镜唯一任务与主要兑现：
GEO 运行时切片：
激活参考职责：参考名 → 只锁属性 → 不接管属性。
首帧阻挡：世界位置 / 屏幕层次 / 朝向眼线 / 遮挡 / 动作预备态。
触发与下一相位：
结束状态与连续性把手：
```

这份内部合同是`当前镜头封闭编译`，不是正式提示词的第四段。它的作用是把长篇设定编译成一次请求真正可用的条件，避免模型在多参考之间自行决定谁控制脸、服装、位置、动作和光线。

#### 资产变更接管与多参考仲裁

正式编译前把资产表中的`变更传播`反向展开到全部VID。人物阶段状态、疾病 / 伤势、服装、妆造、道具、场景锚点或色彩一旦修改，所有直接和传递消费者先标记为`待重编译`，逐条更新绑定职责、基础设定、跨镜不变量、逐镜可见证据和验收门；已有生成视频只作为旧状态证据，不得因文件仍存在继续进入剪辑。没有完成全消费者审计时，不能只修用户点名的镜头后宣称问题解决。

同一人物绑定多张参考时先做属性仲裁，只允许一个主参考控制同一属性。例如阶段素体主控脸部软组织、身体轮廓、疾病肤色和动作能力，妆造参考只能补发型、妆面、服装穿法与饰品；健康身份母版只锁眼鼻口耳等永久拓扑，不能借妆造或默认人像美化回填阶段可变区。正式`【基础设定】`必须写清主从关系，不能让两张参考同时“锁病容、锁体型、锁肤色”。

凡体重、年龄、病程、伤势、污染或变形承担剧情证据，不能只在基础设定远距声明一次。每个真正看得到该状态的镜头都要根据证据尺寸重申当前承重结果：近景写轮廓平面、色度、皮肤 / 毛发和局部动作能力；中景写颈肩、衣料支撑、肢体承托与姿态；远景写轮廓、移动方式与环境交互。光源、白平衡、曝光、肤色保护、美颜和参考优先级必须与状态同向；若“自然光、真实肤色、温暖肤色、自动曝光”等全局词会把承重状态归一化，就改成固定白平衡、相对人物色度差、可见明暗平面和唯一终态。具体排除对象不进入模型正文，避免反向召回被排除的健康脸、旧服装或旧空间。

摄影机运动与焦平面迁移是两套控制，不能混写。`横移 / 推轨 / 升降 / 摇摄 / 俯仰`描述机身或视轴怎样改变；`受控拉焦 / 焦点转移`描述构图可以不变时，清晰平面怎样沿景深从一个对象移动到另一个对象。承重拉焦必须写清：摄影机是否固定、近前景与后景各是谁、起始焦平面、触发动作、迁移方向、结束焦平面、最终清晰对象和前一对象怎样转为柔焦。禁止用“焦点抬到眼神、镜头跟焦到情绪、焦点扫向某人”替代这些可见参数；只有摄影机确实上移时才写“抬升”。

### 动作、表演与声音

动作闭合为 `准备 / 蓄势 → 发力 → 接触 → 结果 → 余波 / 回收`。简单动作自然概括；复杂人体、工具、打斗、爆炸和变身只展开决定生成成败的支撑、路径、接触、受力、材料响应和终态。

人物表演进入镜头前先做四权分离，不能把所有信息压成一个“人物设定”或一个情绪形容词：

```text
写作声音：由 laohu-script-writer 提供；人物注意什么、怎样解释、想用语言改变谁、冻结台词与话后行动。
可听声音身份：由人物母版 / 已确认音色证据提供；稳定音区、音色、共鸣、咬字、常态语速与呼吸支撑。
条件化行为签名：由人物母版提供；在何种压力和关系下通常采用什么判断与策略，哪些动作槽可随空间和道具变化。
当前场次表演：由本 Skill 编译；本镜目的、保护策略、精确触发、2—4个承重通道、台词中的声线变化、对手反馈与结束状态。
```

四者必须相容但不得互相替代。写作声音不能证明演员的音色；可听声音身份不能决定每句都用同一情绪；条件化行为签名不能机械复制招牌动作；当前场次表演不能为了更戏剧化改写冻结台词、人物价值或稳定身份。若只有外貌和性格词，没有前三项可靠输入，按缺口返回编剧 / 人物设计或标记待声音选角，不能在视频正文中伪造稳定人物事实。

直接对镜表演还要先建立`镜头关系对象合同`，至少记录`最终观众、戏内关系对象、允许强度、无害结果`：公开发布给谁看，与人物在戏里把镜头当成谁，是两层关系。最终观众决定理解门槛和平台边界；镜头所代表的戏内对象决定称呼、礼貌程度、攻击性、眼线、关系距离和身体动作。镜头代表亲密搭档时，观众只是旁观者，不能因作品公开发布就把私下质问编译成面向陌生人的礼貌口播。已确认的直白台词继续冻结；无害分寸由软质舞台道具、非接触动作、明确停手、滑稽物性和无伤害终态承担，不能靠擅自把台词改客气来承担。只有剧情明确让人物面对陌生人、正式对象或故意表演克制时，才调用相应公开模式。

文戏先写人物此刻想让对方做什么，哪一个词、动作、声音或信息触发表演变化，再写眼神、面部、呼吸、身体、距离和声线中的承重证据。不能从第一帧就把高潮反应全部端出来。

多人冲突必须分别写每个人的即时目的和注意力对象，不能把群众写成“站着嘲笑”、把台词写成干读。至少说明：谁在争夺谁的注意、谁通过同伴反应获得强化、谁侵入了谁的距离或道具、说话前后的眼线与身体朝向、听者如何抵抗或改变动作。环境交互只写能证明冲突的结果，例如饭粒随急促进食散落、桌沿因身体前压承重、饭盒被敲后滑动、旁观者笑声向某个方向聚集；不为热闹随机增加飞散物。

文戏承重动作按 `目的 → 动作策略 → 接触或关键词 → 身体异步反应 → 对手反馈 → 关系停点` 编译。脸不是唯一表演器官：按当前任务选择眼线、眼睑与眉、口唇与下颌、呼吸、颈肩、手指、躯干重心、步幅、道具受力和声线中的必要通道；每个通道都要有触发和变化方向。信息密度来自这些相互因果的控制，不来自把“痛苦、电影感、克制、真实”反复换词。

整片目标时长不能反向压扁承重表演。先保证每个关键单元完成触发、反应、对手反馈和停点；若总时长超出目标，优先压缩重复建立、环境展示、同义反应或蒙太奇次数，再重新分配单元，不得删除让人物选择成立的中间过程。

正文是完整视听事件主轨。`【VFX】`、`【环境音】`、`【动作音】` 和 `【音乐 / 节拍】` 可以作为紧跟当前镜头的校准轨；台词不得拆成 `【台词】`、`【对白】` 或角色清单等独立轨道。已冻结台词必须嵌入说话人物所在的镜头正文，与开口前动作、说话对象、眼线、口型、气口、重音、音量、身体变化、听者同步反应和说完后的停点写成同一条连续事件。关键事件必须先在正文发生，标签只补来源、方向、材质、时点和衰减；没有正文触发的孤儿标签删除。

### 最低充分控制密度

不设机械最低字数，不等于允许短概要交付。正式首稿必须先写成`高密度导演母稿`：把唯一主要兑现、逐镜起点、观看位置、视觉层级、人物目的、精确触发、动作 / 表演、光影环境、声音 / VFX来源、结果与剪辑接口全部闭合，再压缩为模型正文。不能从短概要开始，以“字段已经出现、没有明显报错”提前停止。每条正式提示词都存在由剧情、时长、人物数量、镜头数量、台词承重、空间调度、动作复杂度和连续性风险共同决定的“最低充分控制线”：在这条线以下，模型仍需要猜谁看谁、怎样说、怎样动、从哪里拍、何时反应或最后停在哪里，正文就没有完成。

质量验收使用0—3级强度，而不是有 / 无：0级缺失，1级点名但模型仍猜，2级可执行但主次偏弱，3级由至少两种独立声画机制形成主导并让竞争信息退让。每个承重节拍的主要兑现、决定性落点和结束状态必须达到3级；辅助节拍达到2级即可。脚本只拦0—1级结构错误，巅峰门继续判断实际声画是否达到主导。

复杂单元先做承重节拍覆盖检查。每个承重节拍至少闭合当前真正相关的控制通道：

```text
屏幕起点与空间坐标
人物当前目的与动作策略
触发词 / 接触 / 声音
说话者的开口前动作、台词中的声线与身体变化、说完后的停点
听者在准确触发后的眼神、呼吸、面部、手部、躯干或距离变化
摄影机起点、路径、焦平面、屏幕结果和切点
道具与环境受力、声源、光线或空气反馈
结束状态、静止余波和下一镜接口
```

不是每个节拍机械填满全部通道；功能性动作可以短，15—30秒多人文戏、复杂调度、长对白和高成本一次生成必须先做完整覆盖表，再把没有改变生成结果的字段名和重复说明压掉。若仍存在以下任一问题，禁止以“简洁”“信息密度高”或“没有最低字数”为理由交付：

- 台词脱离说话者表演或听者反应，删除台词标签后人物只剩站着念词。
- 同一镜头写了多人，却没有各自世界位置、屏幕层次、注意对象和动作路径。
- 情绪只用形容词概括，没有触发后的可见变化顺序。
- 摄影术语没有起点、路径、焦平面或最终屏幕结果。
- 声音、道具、光影或环境本应承担因果，却只剩背景名词。
- 单元后半段、对白重词、反应窗口或结束停点仍由模型自行补全。

字符上限是可用控制容量，不是必须填满的成绩；但只要还有高价值、非重复、能改变像素、动作、声音、表演、空间或剪辑接口的控制信息没有写入，就不得因为正文已经达到一两千字符而停止。压缩只能删除作者解释、同义反复、无来源氛围词和低权重装饰，不能删除承重控制通道。

音乐承重时先建 `音乐段落 → 主视觉事件 → 拍前蓄势 → 同步完成点 → 拍后余波`。卡点是事件完成态与音乐事件对齐，不是每一拍都切镜。

多 VID 叙事成片默认把整体配乐从视频生成单元中分离：每个 VID 只生成对白、环境声和动作声，成片音乐另做一条连续音频资产，并按整片时间结构设计。这样替换、缩短或重排镜头时不会在单元边界硬断音乐。只有某个画面动作必须与确定音乐事件精确同步时，才允许单元写入音乐关系，而且相邻单元必须共同绑定同一条已存在音频参考、明确连续入点与出点；禁止让各 VID 各自生成相似但彼此无关的音乐。

### 相邻单元

跨镜头、场次或 VID 不先问“怎样无缝”，先选择`接续类型`。每一对相邻 VID 必须选择一种主策略，也可以声明场景重置；不能把“所有结尾拉成广角”或“所有地方做遮挡转场”当成默认答案。

| 接续类型 | 适用判断 | 连续性把手 |
|---|---|---|
| 空间连续 | 同场景、多人物、入口 / 桌椅 / 破坏状态和观看侧决定下一动作 | A 末端约 1—3 秒的有效中远景 / 较宽画面或其他能读清拓扑的稳定片段；入口不支持视频参考时，退化为合格终帧 + 稳定资产 |
| 表演连续 | 文戏、对口型、近景反应，身体与声音相位比空间全貌更承重 | 呼吸、眼线、颈肩、手中物、距离、屏幕方向、声线余韵和`条件化行为签名`；不为交代全景破坏承重表演 |
| 动作连续 | 追逐、打斗、舞蹈、物件操作需要继承速度与受力 | 动作相位、重心、运动向量、接触状态、摄影方向、动作声或运动余势 |
| 艺术转场 | MV、广告、概念片或跨空间段落追求意义 / 节奏关联，不要求物理地点连续 | 动作、轮廓、形状、颜色、材质、光线或声音的`共同载体`；A 种下，B 从下一相位接收并增加意义 |
| 因果 / 声音桥 | B 展示 A 的后果、画外事件或另一个空间的响应 | A 的决定性声源、台词尾音、物体结果或因果问题；B 先接住再揭示新空间 |
| 场景重置 | 时间、地点、主体或视觉制度有意跳变，上一状态不应继承 | 明确断开旧 GEO，只继承剧情事实、人物长期身份或音乐结构；不用错误状态帧制造伪连续 |

把手不是正片必须保留的剧情镜头，而是生成与剪辑之间的保险区。空间高风险时，A 最后一个`有效机位`应在人物完成当前动作后稳定读出人物、固定锚点、站位、观看侧、临时破坏和运动余势；它可以是广角、中远景或较宽画面，不等于越广越好。经验上可预留约 1—3 秒，但必须按入口能力、动作速度和镜头可读性调整，并在交接卡标记`预计裁剪区`。若这段含两个硬切机位、人物畸形、空间漂移或错误服装，它就不是可用把手。

文戏的`表演连续`优先保护情绪尚未消散的身体和声音状态。A 可停在母亲压住哭腔后的短呼吸、仍看向孩子的眼线、握住杯子的手和肩颈回落；B 从孩子听见重词后的迟疑开始。`条件化行为签名`只继承该人物在当前压力下稳定可见的反应倾向，例如先收紧下颌再移开眼线、说到重词时气息变窄；它不是抽象的“悲伤、克制”，也不要求 A 后拉成大全景。

`艺术转场`只继承作品希望观众感到的动作、形状、光线或声音关系，不继承不该延续的地点。相似动作转场必须写 A 的动作相位、轮廓与光线如何到达出点，B 如何从同一共同载体的下一相位开始，并立即增加新人物、新空间或新意义；只写“炫酷转场、无缝衔接”不成立。

选定类型后再比较：

```text
A / B 接续类型：
A 已完成结果：
A 真实结束状态：
B 起点状态：
必须不变 / 允许变化：
B 第一项新变化：
下一相位：
主匹配属性 / 连续性把手：
预计裁剪区：
```

直接连续必须满足 `A 真实结束状态 = B 起点状态`。B 从下一相位开始，不重演 A 已完成动作。计划尾帧不能冒充真实尾帧；A 实际生成后由 `laohu-generation-review` 二次绑定，再决定 B 使用尾帧、视频尾部还是稳定资产。

当B需要继承A真实生成出的破坏、站位、临时光影或摄影方向时，使用双参考合同，不能在“稳定资产”和“状态帧”之间二选一：稳定人物、服装、道具与场景资产负责身份、结构、材质、空间拓扑和锚点；通过 `laohu-generation-review` 状态帧质量门的抽帧或有效尾部视频只负责当前破坏、人物站位、临时光影、摄影方向和结束相位。正文明确每张参考只控制什么、禁止继承什么。状态帧或尾部片段有畸形手脸、错误服装、空间漂移、错误文字、随机物、运动模糊、曝光问题或包含两个互相冲突的机位时，不得为了连续强行绑定，退回稳定资产建立干净起点。

状态帧只连接一个相邻VID时是临时参考；同一状态跨多个VID、跨场次或反复调用时，返回 `laohu-visual-assets` 整理为正式场景状态资产。任何状态帧都不能单独替代稳定资产，真实尾帧也不能因被截取就自动获得资产身份。

首尾帧双端锚定时，两端都是输入目标。写清必须保持、必须改变、共同桥梁、中间状态和尾帧召回；不能只描述两张图，让模型自己跳变。

## Reference 路由

正式提示词必须留下内部 `Reference 调用回执`：本轮读取的文件、提取的机制、被它改变的导演 / 镜头决定、变化进入哪段提示词，以及为什么到这里可以停止。只写“已阅读”或摘抄摘要不算调用；无法定位到实际改变时，先修路由和中间结果，不能直接进入 VC。

先读取 `references/00_调用路由与机制提炼.md`，按观众承诺、主导机制、空间语法、时间语法、证据方式和媒介物理，判定 `完全适配 / 组合适配 / 能力缺口`。

- 完全适配：一个主要题材 Reference。
- 组合适配：一个主要题材 Reference，最多一个辅助 Reference。
- 能力缺口：建立当前作品机制卡，不为有文件可用而强套。

动态内容默认读取 `references/10_画面内容镜头叙事语法.md` 完成跨媒介镜头编译。其余按主导机制选择：

任何将被交给模型产生视频结果的提示词都必须读取`02_共享资产库/05_工具流程/视觉生成模型注意力与提示词编译参考.md`，完整执行注意力合同、镜头可执行语言与时序分支。多主体、多参考、图生视频、复杂属性绑定、专有概念视觉翻译或空间与时间竞争只会增加需要绑定和仲裁的对象，不改变这项基础完成条件。图生视频由输入图负责主体、构图、色彩、光线和风格，正文优先写动作、环境运动、摄影机、方向、速度、触发和停点；只有引入新元素或改动起始图时才重述对应静态外观。

同一作品、同一连续阶段必须继承`laohu-art-direction`交付的`结果图成像合同`。视频Skill不凭“电影感、古偶唯美、港风”等短标签重新猜风格，也不临时改选导演、作品、介质或调色；它只把合同中当前镜头真正可见的成像基底、色彩肤色、主光影调、空间构图和表面光学编译进`【场景状态与氛围画质】`。剧情阶段、记录媒介、观看者或世界规则改变时，使用美术交接包已经定义的阶段变体和返回条件。

若美术交接还包含叙事灯光合同，静态部分只继承当前可见受光关系；动态部分必须进入`灯光变化事件`的起始光态、触发、传播过程和结束光态。参考帧只负责已确认的光影关系，不负责虚构实际灯位；同一光型随人物、空间、材料和摄影条件变化时，不沿用固定情绪结论。

`02_共享资产库/02_视觉语言资产/画面风格库/画面氛围与画质规范.md`由`laohu-art-direction`负责消化成作品合同，视频Skill不绕过合同重新组合风格母版。合同缺失、只剩短标签或当前阶段没有合法变体时，退回美术方向补齐；不能为了赶写视频直接从共享风格库另选一套画质。

凡人物表演承重，同时读取`02_共享资产库/02_视觉语言资产/人物表演库/人物表演提示词规范.md`；需要寻找可见的脸、目光、呼吸、身体、关系距离或声音候选时，按需读取同目录`人物表情与肢体动作词典.md`。八维在内部完整判断，正式正文只保留人物目的、精确触发、2—4个承重通道、禁止提前反应和结束状态；不得把词典整行投喂或让所有身体通道同时表演。

对白、同期声、动作接触声、空间声场、声音桥、画外触发或原生音频承担因果时，读取`02_共享资产库/02_视觉语言资产/声音与同期声库/声音提示词规范.md`。它只负责声源、方向、距离、材质、声画相位、混响、遮挡和衰减；不能用声音标签新增正文没有发生的事件，也不能让配乐、对白、环境声和动作声同时成为主注意力。

正式成稿使用`02_共享资产库/01_模板库/视频模板/模板_视频提示词_基础设定氛围画面内容.md`作为版式与交付表面，不把模板中的全部候选字段机械填满；本Skill与当前题材Reference决定内容，模板只承接三段、逐镜方头、补充声画轨和代码块外接口。镜头方案已经成立但缺少准确摄影词汇时，可以按需查询`02_共享资产库/02_视觉语言资产/镜头语言库/镜头语言词典.md`，只选择能改变观看位置、空间关系、注意力轨迹或停点的一项词汇，并把术语翻译成摄影机路径与屏幕结果。

共享库中的开发计划、历史编号规范、导演总控流程和生成后评分表不进入每条提示词的默认运行上下文：计划文件只保存建设历史；编号与状态规则由当前Skill和核心合约承接；导演总控由`laohu-ai-visual`路由；真实结果评分由`laohu-generation-review`负责。文件存在不等于全部读取，只有能改变本次决定且职责不冲突的知识才进入调用回执。

Reference 提供机制、不变量、可变槽、失败修复和迁移测试，不提供可复制的外部案例表面。人物、品牌、台词、镜头顺序和标志性特效必须重新设计。

## 三段式成稿

正式投喂代码块只有三个一级区块：

```text
【基础设定】
只写总时长、生成方式、实际绑定资产的职责和一句全条声音策略。未真实绑定的资产不能写成已存在；逐镜动作、剧情解释、场景光色和作者验收不进入本段。

【场景状态与氛围画质】
只写开拍前已经成立、且跨本条全部镜头有效的空间边界、人物与道具初始状态、主成像基底、宏观光色和空气关系。开拍后才发生的入场、落泪、破坏、天气变化和局部灯光变化进入对应镜头，不能提前写成初始状态。

【画面内容】
每个VID先写一至三句时间因果主线，只包含动机或初始压力、不可交换的触发和变化顺序、主要兑现、即时影响与余韵。简单事件可压缩成一句，但不得省略；它只写画内可见 / 可听事实，不写主题和作者解释。
【镜头01｜景别或景别演变｜机位 / 视角｜固定机位、连续摄影机路径或转场｜复杂镜头按需续写构图与节奏栏】
从可见画面开始，依次写触发、主体与环境变化、摄影机路径、屏幕结果、声画事件、停点和结束状态。
按需紧跟【VFX】【环境音】【动作音】【音乐 / 节拍】；台词直接嵌入当前镜头正文，并与说话者表演、听者反应和摄影机变化连续书写。
```

每个新镜头使用连续编号的中文方头。镜头边界由动作、遮挡、视线、焦点、声音、光色峰值或运动方向建立，不能只靠编号切开。

代码块外保留：

```text
观众问题—声画兑现：悬念、寻找、误判、揭示、倒计时或知识问题承重时填写；不承重时省略。
镜头 / VID 编号与任务：
实际绑定资产：
相邻单元交接：
素材剪辑接口卡：推荐入点 / 内部节点 / 出点 / 匹配属性 / 干净把手 / 不建议裁切点。
字符实测：
生成风险与回传字段：
```

### 控制语言闸门

每条承重句落笔前先还原为 `控制对象 → 本次实际基准 / 起点 → 变化维度 → 方向、幅度或路径 → 可见 / 可听终态`。正式提示词不新增这五个字段，而是把它们压进连续导演句。相对词必须指向本次真实绑定的参考或本镜已经写清的起点；即使存在参考，也要补一个当前请求独立可执行的绝对目标。`轻微、自然、缓慢、更明显、进一步、最`后面若没有屏幕参照、变化路径和终态，只是作者愿望，必须重写。

不可变项和可变项分开控制。同一人物可锁眼鼻口耳的身份拓扑，同时允许脸颊软组织变化；同一场景可锁柱、门、桌的拓扑，同时允许人物、临时道具和光影变化。不得用“保持同一张脸 / 保持场景一致”吞掉本镜真正需要改变的区域。具体排除指令改写为正向唯一结果：声音轨列出唯一成分，画面列出唯一人物与物件，单镜写清连续路径；真实时间状态中的`尚未、仍未、没有抽走`可以保留。

Seedance 2.5或其他高成本视频在投喂前逐句检查：删除作者解释和悬空比较，确认每个弱词能回答“什么对象、相对什么、改多少 / 多快、最后看见或听见什么”，再运行结构与字符脚本。机械脚本只拦截明确的负向生成命令和作者解释，不以禁词表代替语义判断。

正式代码块不是给老胡看的创作说明，也不是剧情分析。`戏剧任务、表演任务、人物调度目标、观众应该感到、这一镜证明、不是……而是……`只允许出现在代码块外的内部导演卡；进入模型正文时必须翻译成摄影机和画内事实。翻译至少落到其中一项：人物的世界位置与屏幕位置、身体动作路径、接触与受力结果、眼线和呼吸变化、摄影机起点与停点、焦平面迁移、环境响应、可定位的声音或明确结束状态。若一句话只能解释“为什么这样拍”，却不能让模型画出下一帧，它不得进入正式提示词。

### 硬规格

- 单条时长由剧情、表演、动作、对白、摄影机和停点反推；目标入口已经核验的可用时长仍是硬边界。启用长时路线时单独验收后半段遗忘与漂移。
- 正式编译前读取`02_共享资产库/03_模型适配/通用规范/多模型AI视频提示词通用规范.md`中的`目标入口能力合同`。平台名称、模型名称、网页 / 移动 / API、T2V / I2V / 首尾帧 / 多参考等模式不能互相代替证据。
- 只有官方文档、真实入口报错或可复现实测才能建立字符硬上限。未获得证据时标记`入口长度兼容性未验证`，字符脚本只报告实测长度，不按跨模型 4000 或默认 10000 裁切。
- 不设置机械最低字数，但必须通过“最低充分控制密度”语义门。字符数由有效控制信息自然产生，上限不是扩写目标；也不能把“不凑上限”偷换成提前停止，导致对白表演、空间调度、动作因果、声画来源或结束接口缺失。禁止为了接近上限增加同义反复、作者解释和低权重装饰。
- 画幅用于内部构图和平台参数；模型正文默认写主体占比、裁切、留白和运动路径，不机械重复比例数字。
- 台词、旁白、字幕和固定音乐原文一经确认，不擅改。

任何正文改动后重新实测字符。未知上限只统计：

```bash
bash skills/laohu-video-prompt/scripts/count_video_prompt_chars.sh "提示词文件.md"
```

能力合同已经证实上限时才追加 `--limit N`；脚本没有在最后一次改稿后运行，只能标记“字符数未验证”。正式交付还要运行结构检查，拒绝三段缺失、镜头方头缺失和绝对时间轴污染；结构检查默认不制造长度上限。

## 生成前验收

### 底线门：首稿可执行

- 上游镜头是否已经成立，提示词没有承担第一次发明故事。
- 每镜是否只有一个主观看任务和一个主情绪。
- 期待承重时，是否继承观众问题—答案交接并完成声画兑现表；每次快慢、切角、遮挡和停点是否改变信息、风险、关系或判断，且内部作者解释没有进入模型代码块。
- 起点状态、触发、路径、屏幕变化、结果和结束状态是否闭合。
- 人物动机、台词、动作与道具选择是否共享同一条因果；表面矛盾是否有意且有可见证据，否则是否退回上游。
- 承重道具是否通过状态账本锁定起点、接触、承重、路径、落点、支撑和下一镜状态，没有悬空、瞬移、易手或数量漂移。
- 每个切点是否有剪辑承接合同；省略是否通过省略成立门，而不是靠“自然衔接”或观众替作者补因果。
- 两镜以上共同完成同一动作时，连续动作主线是否已经进入正式`【画面内容】`，并与逐镜状态逐项一致。
- 摄影机物理路径是否真的产生正文所写屏幕变化。
- 动作、表演、VFX 和声音是否有画内来源与正确时点。
- 冻结台词是否嵌入镜头正文，并同时写清开口前动作、说话对象、重音 / 气口 / 口型、说话中的身体变化、听者准确反应与说完后的停点；是否完全没有独立 `【台词】` 轨。
- 直接对镜时是否写清`镜头关系对象合同`；人物的称呼、礼貌程度、攻击性、眼线、距离和动作强度是否服从戏内对象，而非笼统服从公开观众；无害边界是否落在道具、接触、停手和结果上，而没有削弱冻结台词。
- 复杂单元是否通过最低充分控制密度检查；是否仍有承重人物、空间、表演、摄影机、环境或后半段状态需要模型猜测。
- 首稿是否先形成高密度导演母稿；是否因为“已经有镜头编号 / 台词 / 音效”而在强度仅1—2级时提前停止。
- 每个承重节拍的主要兑现、决定性视觉落点和结果停点是否达到3级主导；构图、焦点、光色、动作、声音和VFX是否至少两项同向证明，竞争信息是否退让。
- 所谓重点是否通过当前观众问题与信息增量证明；是否既没有在证据可读前抢答，也没有在预期和反应完成后继续拖成等待过期。
- 实际绑定资产是否真实存在，本镜未用资产是否删除。
- 图生、首尾帧和多参考任务是否已打开真实图片并完成真实参考图调用合同；路径、入口模式、真实可见对象、固定对象、可动对象、禁止新生对象、首个变化与最终结果是否齐全。
- 参考图是否通过语义一致性门；文件名与真实像素不一致、草图未验收或内部编号 / 临时占位泄漏时，是否已经拒绝绑定并返回视觉资产。
- A 与 B 状态是否相等，B 是否从下一相位开始。
- 代码块是否只有模型需要的内容，没有作者意图和后期解释。
- 承重句是否具备实际基准、变化维度、方向 / 幅度 / 路径和可见 / 可听终态；不可变项是否吞掉了可变项。
- 具体排除是否已经改写为正向唯一结果；真实时间状态是否被正确保留。
- 字符、格式、时长和命名是否通过机械检查。

首稿未通过，留在本 Skill 修复，不能交给 VC 收拾基础错误。

### VC 交接

VC 指外部 Skill `vibe-creating-prompt`，本项目只通过本地适配入口 `laohu-vibe-creating-prompt` 调用它，不直接调用外部原文。首稿合格后交给该适配入口：

```text
不可删不变量：
允许重排 / 压缩：
最值得增强的观众效果：
资产和相邻状态合同：
字符预算：
```

所有通过首稿门的视频提示词都必须交给 VC；不能因题材偏功能、原稿已经成熟、预计改动很小或时间紧而跳过。VC 可以在实际读取和判断后零改动放行，但必须留下调用记录与比较结论。

VC 完成后重新回到本 Skill，检查三段式、镜头编号、状态、接口和字符实测，再写入当前作品 `05_视频/文本/` 的阶段主文件。外部原文、便携副本或二者一致性失效时，保留已经通过首稿门的版本作为排障与恢复材料，同时标记“VC 链路失败”；未实际完成 VC 的稿件不得进入正式写入和付费生成。

### 巅峰门：正式提示词值得生成

底线门与 VC 都完成后，视频 Skill 仍对最终作品效果负责，不能只复查格式。正式写入前检查：

```text
主胜负手：本段最不可替代的情绪、关系、视觉、声音或卖点结果是什么。
候选比较：决定性瞬间、观看位置、构图、运镜、表演、声画和停点中，哪些方向被比较并淘汰。
序列推进：每个镜头 / VID 新增什么，换序或删除后是否明显失去力量。
导演连续性：人物目的怎样穿过镜头，道具状态怎样交接，省略怎样被观众无负担地重建；是否仍有逐镜成立、合看断裂之处。
峰值兑现：前面的蓄压是否在可见 / 可听结果中真正到顶，而不是靠形容词宣布高潮。
专业协同：构图、运镜、表演、动作、VFX、光色、音乐和环境声是否共同托住主胜负手；不承重的维度是否主动退让。
质量强度：主胜负手是否达到3级主导；不是统计规则有没有，而是判断它是否足够强、有效信息占比是否足够高、删掉任何承重句是否会明显削弱结果。
Reference 生效：调用回执能否指出机制改变了哪个决定并落到哪处成品。
VC 生效：有改动时为什么更强；零改动时为什么原稿已经优于可行改法。
已知上限：是否仍存在一个具体、可实施且预计明显更强的方案没有处理。
```

最后一项为是，返回对应的导演选择、镜头编译或 VC 环节继续改；不能以字符已满、三段齐全或时间已花费为理由停止。极致不要求每个维度最大：承重的是静止、留白、沉默或固定机位时，强行增加运动和特效反而判为降级。
