# 速度、节奏与时间动力设计

## 触发条件与能力边界

当作品成败明显取决于速度变化、力量释放、动作可读性、镜头快慢对比、连续快切、慢动作、速度渐变、追逐压迫、文戏停顿、动态图形节拍或跨 `VID` 运动衔接时，读取本文件。它是跨题材的辅助 reference，不是动作片专属分类；主任务仍由 `01-07` 中最适配的题材 reference 负责。

以下情况不必读取：普通人物走路、单一稳定推镜、没有速度设计任务的静态展示，或现有题材 reference 已经足够说明一项简单动作。不能因为画面中“有运动”就加载本文件，也不能为了显得专业给每镜增加速度术语。

本文件解决的是时间动力学：怎样让观众感到蓄力、冲出、撞上、失重、拖拽、迟疑、窒息、释放和余波。它不替代动作因果、人物目的、空间调度、音乐合同或生成后剪辑。

## 第一性原理

### 速度不是一个快慢形容词

观众感到的速度不是由一句“节奏很快”决定，而是多个独立时间层共同作用：

`事件变化率 → 信息进入率 → 动作位移与加速度 → 摄影机位移 → 屏幕内相对运动 → 镜头持续时间 → 转场完成速度 → 声音瞬态与密度 → 时间重映射与运动模糊`

正式判断至少区分：`动作速度 / 摄影机速度 / 切镜速度 / 信息速度 / 声音速度`。它们可以同向，也可以互相对抗。人物可以高速奔跑但摄影机稳定跟随；镜头可以不切却因近景横穿和强视差显得极快；画面可以连续快切但每个镜头内部几乎静止；音乐可以很快而角色故意慢半拍。

因此，“快”必须回答：

1. 谁或什么在快：人物、物体、摄影机、切镜、图形、信息还是声音。
2. 相对谁显得快：背景、敌人、镜头、重拍、观众预期或前一节拍。
3. 从什么状态变快：静止、匀速、迟疑、蓄力、缓慢靠近或上一镜余波。
4. 快到哪里结束：接触、越过、构图锁定、停住、反弹、出画或进入下一动作相位。
5. 观众必须看清什么：起因、路径、接触点、结果、表情变化或空间关系。

### 力度主要来自速度变化

匀速运动可以显得流畅，却不天然有力量。力量感通常来自加速度、突然制动、方向改变、质量反馈和余波：

- 静止后的突然启动，强调决断和爆发。
- 缓慢蓄势后的高速释放，强调力量储存。
- 高速运动的硬停，强调控制、阻挡或碰撞。
- 接触后的反冲、拖尾、衣发延迟和环境响应，证明惯性真的存在。
- 结果晚于接触短暂出现，可以制造“力量穿过去以后才爆开”的延迟冲击。

所以，速度提示词优先写“变化过程”，而不是只写峰值速度。

### 节奏不是切镜频率

电影节奏由声音、镜头序列和镜内运动的速率与规律共同形成。长镜头可以因人物、摄影机、焦点和空间持续变化而紧张快速；短镜头也可以因内容静止、变化重复而显得迟缓。切得快只能提高画面更换率，不能自动提高戏剧推进率。

每次提速必须至少推进一项：危险更近、关系更紧、力量升级、信息翻转、空间改变、目标接近或情绪保护层破裂。没有状态变化的快切只是视觉噪声。

### 对比才让速度可感

持续快会让观众适应，持续慢会让刺激失效。真正可感的速度来自相邻节拍的差值：`停 → 动`、`慢 → 快`、`密 → 空`、`连击 → 静止`、`顺滑 → 断裂`、`跟随 → 失跟`。

“快中有慢、慢中有快”不是平均混合，而是让不同速度承担不同职责：慢负责预读、蓄力、悬念、情绪暴露和结果停点；快负责越过防御、压缩距离、完成接触和释放能量。没有慢，快失去参照；没有停点，结果没有重量。

### 可读性是速度成立的前提

观众必须先知道谁要做什么、动作从哪里来、撞到哪里，才会把高速变化理解成能力；否则只会看到模糊和混乱。高速动作最少保住三类证据中的两类：

- 预备证据：眼神锁定、重心压低、刀尖后撤、车身偏转、图形开始聚合。
- 接触证据：刀刃与物体同帧接触、拳脚落点、轮胎抓地、图形边缘闭合、按钮被按下。
- 结果证据：对手位移、材质破裂、空间翻转、角色停姿、标题锁定、声音余响。

速度越高，越不能同时让主体、摄影机、背景、VFX 和剪辑全部无差别加速。先选一个主速度承载者，其余层负责衬托或校正可读性。

## 九层速度账本

| 层级 | 控制对象 | 主要问题 | 常用可见证据 |
|---|---|---|---|
| 故事速度 | 事件与目标 | 局势多久发生一次不可逆变化 | 新威胁、新选择、新结果 |
| 信息速度 | 观众认知 | 单位时间进入多少新信息 | 揭示顺序、字幕量、证据停点 |
| 表演速度 | 眼神、呼吸、台词、身体 | 人物反应多快、哪里迟疑 | 抢话、停顿、吸气、目光延迟 |
| 动作速度 | 人物与物体 | 位移多快、怎样加减速 | 重心、轨迹、接触、反冲 |
| 摄影机速度 | 机身、镜头与焦点 | 观众被怎样带动或甩开 | 视差、主体尺寸、地平线、失跟 |
| 切镜速度 | 镜头持续与更换 | 何时切、切后更新什么 | 动作匹配、反应切、闪切、长持 |
| 转场速度 | 遮挡、光色、图形与 VFX | A 如何变成 B | 铺满、穿越、闭合、裂开、消退 |
| 声音速度 | 音乐、台词、动作音、环境音 | 何时预告、完成和衰减 | 强拍、瞬态、停顿、混响尾 |
| 播放速度 | 实时、慢动作、快动作、停格 | 时间是否被扩张或压缩 | 速度渐变、抽帧感、运动模糊 |

内部先找承重层，不机械填写九层。普通镜头通常只需要一至三层；速度主导的复杂镜头才建立完整账本。若多个层级同时变化，写清主次：例如 `人物爆发加速为主，摄影机先稳定锁住接触，再被冲击带出短促后撤；切镜不跟着乱跳。`

## 动作相位与速度曲线

### 七相位动作链

复杂动作按需检查：`蓄势 → 启动 → 加速 → 峰值 → 接触 → 余波 → 停点`。

- 蓄势：给方向、目标、重心和能量来源；不一定长，但必须可读。
- 启动：动作真正离开静止的第一变化，负责消除“突然瞬移”。
- 加速：位移间距扩大，身体、衣发、道具与背景开始出现速度差。
- 峰值：最快阶段，只保留观众必须识别的轮廓、方向和主动作。
- 接触：动作与目标发生同帧或明确先后关系，是声音和 VFX 的同步点。
- 余波：反冲、拖尾、碎片、烟尘、衣发和摄影机响应继续完成力量证明。
- 停点：主体、结果或构图获得最低可读保持，给剪辑和观众反应窗口。

不是每个简单动作都把七项写进正文。只有高速、复杂接触、慢动作、多人动作或生成容易乱序时才展开；一般动作把相邻相位合并成自然语言即可。

### 常用速度曲线

| 速度曲线 | 可见运动 | 适合情绪 / 任务 | 提示词写法 |
|---|---|---|---|
| 匀速 | 位移间距稳定 | 冷静、机械、不可阻挡、流程展示 | `保持恒定速度横穿画面，不加速、不摇摆` |
| 缓入 / ease-in | 从静止逐渐加速 | 靠近、觉醒、压迫积累、巨大物启动 | `先几乎静止，随后连续加速，背景视差逐步扩大` |
| 缓出 / ease-out | 高速后逐渐减速 | 抵达、揭示、英雄定帧、产品停稳 | `接近目标后平滑减速，最终无回弹地锁定构图` |
| 缓入缓出 | 两端慢、中段快 | 自然移动、顺滑转场、图形形变 | `起步与收尾都平缓，中段快速完成主要位移` |
| 突发阶跃 | 无明显渐变地突然提速 | 惊吓、抢攻、故障、决断 | `短暂停住后突然爆发，第一步即跨过大半距离` |
| 硬制动 | 高速瞬间停住 | 控制力、阻挡、危险逼停 | `高速逼近后在接触线前骤停，衣摆与尘粒继续前冲` |
| 超调回弹 | 越过目标后回摆 | 弹性、喜剧、UI、轻质物 | `越过锁定位置少许，再一次回弹后稳定` |
| 阶梯式脉冲 | 多次短促加速，中间有停顿 | 连击、机械启动、信息升级、音乐重音 | `每次重音只完成一次位移，间隙短暂停住保持轮廓` |
| 速度渐变 / speed ramp | 实时与快慢速连续转换 | 关键技巧、主观时间、动作强调 | `接近接触前逐渐降速以看清落点，接触完成后迅速恢复实时速度` |

技术术语必须配可见结果。只写 `ease-in、speed ramp、time remapping` 不够；模型需要知道何时开始变化、哪一段最快、何时恢复、画面中什么证明速度改变。

## 速度与情绪功能

| 情绪 / 观众感受 | 主要速度结构 | 不宜默认使用 |
|---|---|---|
| 爆发、愤怒 | 压住或短停 → 突然加速 → 短促硬停 | 全程大喊、全程手持乱晃 |
| 力量、重量 | 较慢启动 → 持续加速 → 重接触 → 长余波 | 轻飘的瞬移、接触即消失 |
| 技巧、敏捷 | 极短预备 → 清晰高速路径 → 精准停点 | 过长慢动作遮盖真实速度 |
| 压迫、威胁 | 对手或镜头稳定缓慢逼近 → 局部突然加速 | 从第一帧就疯狂快切 |
| 恐惧、惊吓 | 低变化率建立预期 → 破坏规律的瞬时事件 → 静默余震 | 均匀密集的惊吓点 |
| 悲伤、羞耻 | 反应延迟、动作变慢、呼吸不规则、镜头多停半拍 | 所有动作机械慢速化 |
| 亲密、犹豫 | 细小移动、缓慢靠近、目光与台词之间错半拍 | 摄影机频繁抢人物反应 |
| 权威、冷酷 | 节制匀速、最少无效动作、精准制动 | 为显强而高速挥舞 |
| 喜剧 | 明确预备 → 超出预期的延迟或抢拍 → 干净反应停点 | 没有反应镜头的连续快动作 |
| 崇高、巨物感 | 大尺度缓入、局部先动、全体后动、长衰减 | 巨物像轻物一样瞬间启停 |
| 混乱、失控 | 局部速度与方向冲突，但周期性给空间重置点 | 所有层同时随机变化 |

情绪映射不是固定公式。缓慢推镜可以是亲密、威胁或发现；关键看它相对人物、空间、声音和前一节拍做了什么。

## 人物、物体与材质速度

### 质量与尺度

- 轻小物体通常启动快、方向变化快、停稳快；但屏幕占比小，必须用背景参照、拖尾或结果放大可读性。
- 重物和巨物通常启动更慢、制动更长、局部先动整体后动；接触后环境传震、结构形变和低频声延长重量感。
- 高手不等于动作全快。高手常通过更早预判、更少多余动作、更短路径和更精准停点显得快。
- 疲惫、受伤或犹豫不只是“慢”；还会出现启动失败、速度不均、局部代偿、动作中断和恢复时间变长。

### 重叠动作与拖拽

躯干、手臂、衣摆、长发、武器穗、烟尘和碎片不应同一帧同时启动或停止。主动作先发，附属部分延迟跟上；主体停住后，附属部分继续越过再衰减。延迟量由材质、长度、连接方式和速度决定。

错误：`她高速转身，头发和长衣摆同时完全静止。`

正确：`肩胯先完成转身，长发与衣摆晚半相位甩过身体；她停住后，发梢再摆回一次才衰减。`

### 接触速度与结果延迟

高速接触必须明确先后：`接近 → 接触 → 材质响应 → 环境响应 → 声音衰减`。可以故意让结果延迟，但不能让爆炸、破裂或飞出发生在接触之前，除非剧情明确是远程能量或预触发机制。

## 摄影机速度与屏幕速度

### 先决定摄影机和主体的速度关系

- 摄影机慢于主体：主体逼近画边或短暂出框，制造失跟、危险和不可控。
- 摄影机与主体同速：主体相对稳定，背景高速滑动，便于看清表演并感到环境速度。
- 摄影机快于主体：越过、超前或回看，强调主导、发现前方威胁或重新构图。
- 摄影机与主体反向：屏幕相对速度叠加，冲击强，但必须留清晰接触或方向锚点。
- 摄影机先静后动：动作先撕开稳定画面，摄影机随后被迫响应，力量更明显。
- 摄影机先动主体后动：观众先被拉向目标，适合预示、邀请或陷阱。

不能把“人物快”自动翻译成“摄影机也快”。主体、摄影机、焦点和切镜最好只让一至两个成为主速度源。

### 景别与屏幕位移

- 近景 / 特写中，同样的真实位移会占据更大屏幕比例，速度感和冲击更强，但完整动作路径更难读。
- 较宽景别能保留起点、落点和对手距离，适合证明动作几何；它不一定显慢，近前景掠过和明显视差仍可制造高速。
- 近距离广角运动容易产生强透视与前后景视差，适合冲刺、穿越和空间膨胀；必须控制边缘变形和主体清晰度。
- 长焦会压缩纵深，适合让追逐距离显得黏着、让横向运动扫过画面或制造难以逃脱的压迫；不要把焦段当固定速度按钮。

### 运镜速度词必须落到屏幕结果

弱写法：`快速推镜、疯狂甩镜、动感环绕。`

强写法：`机身从她右后方迅速贴近，肩部由画面中部扩大到占据右侧前景，背景灯带向左拉出强视差；刀刃接触前摄影机停止推进，保持落点清晰。`

## 切镜、镜头时长与信息速度

### 切点由事件决定

优先在以下位置切镜：

- 动作意图已读懂、结果尚未出现时，切向目标或反应。
- 动作穿过画面边缘、遮挡面或光色峰值时，借运动完成转场。
- 接触完成点切向结果，让声音瞬态把两镜粘合。
- 人物听到触发词后，不立刻切走，保留最低反应窗口再进入特写。
- 高速段结束时用较长停点，让观众读取代价和新局势。

不能按固定镜头数或固定秒数机械切。镜头持续多久，取决于观众需要多久完成“识别 → 预测 → 等待 → 确认”；一旦本镜任务完成且下一状态已经出现，继续停留才是拖沓。

### 快切的正确用途

快切适合压缩过程、并列证据、制造攻击密度、呈现记忆碎片或在音乐重音上升级状态。每一切至少改变景别证据、受力结果、空间位置、人物策略或信息层级。连续几镜若只换角度而结果不变，删镜比继续提速更有效。

动作片的高速度常用 `可读建立镜 → 短促爆发镜组 → 结果停点`；文戏可用 `稳定对峙 → 触发词后的微反应切近 → 沉默长持`；MG 可用 `连续组装 → 关键数字停住 → 下一关系快速重排`。这些是机制关系，不是固定镜头配额。

### 信息速度不能超过识别速度

画面同时出现新角色、新道具、新字幕、新空间和新动作时，即使每项都清楚，总体仍可能过载。速度设计先保住主观看任务：高速阶段减少新概念，复杂概念阶段减少无关运动。标题、数字、产品卖点和关键表情都需要最低可读停点，不能边高速变形边要求观众完整阅读。

### 期待驱动节奏：问题什么时候到期

剧情、悬念、寻找、误判、揭示、倒计时或知识问题承重时，节奏的基本单位不是镜头秒数，而是观众正在等待的状态何时获得有效更新。先从编剧的观众信息账本接收问题与答案边界，再建立`观众问题—声画兑现表`：

```text
当前问题与提出它的可见 / 可听证据
观众已经知道、暂时相信和仍不知道什么
本拍处理：建立 / 加压 / 延迟 / 部分回答 / 回答 / 改写
信息增量：新增证据改变了哪项判断、风险或下一等待
声画分配：动作、机位、焦点、遮挡、声音与停点各承担什么
可读等待窗口：证据达到辨认阈值 → 观众形成预期 → 反应或答案完成更新
下一问题是否由当前答案、代价或后果产生
```

同一人连续翻找、奔跑、敲门或浏览资料，可以用速度上升证明焦躁或压力，但`重复信息不因多角度获得新价值`。只有新角度改变观察权限、空间范围、人物策略、关系位置或暴露新证据时才保留；否则在同一镜内加速、用动作匹配压缩，或直接省略到下一项有效变化。剪得快不等于故事走得快，镜头没变也不等于节奏慢。

`可读等待窗口`没有固定秒数。开始点是观众已经能够辨认承重对象或异常、足以提出问题；结束点是预期、人物反应或认知更新已成立。结束前切走会让答案没有证据，结束后持续停留却没有新的压力会让等待过期。答案也不必一次给完：部分回答可以把原问题扩大或改写，但新问题必须由当前结果因果地产生，不能靠随机人影、巨响或新秘密替换旧承诺。

`情绪不是唯一节拍器`。情绪是人物处境、信息权限、身体表演、动作速度、声音和观看等待共同形成的结果；它不能单独决定所有重点都慢放、所有焦虑都快切。重点可以用实时速度、短促中断、突然静音或一次硬停成立；低烈度观察、歌舞和氛围段没有具体问题时，继续按身体、音乐、空间和材料的可读变化组织，不强造悬念问答。

## 转场与跨 VID 的速度连续性

匹配转场除了几何、颜色和材质，还必须继承运动方向、屏幕速度和动作相位。A 尾与 B 头分别完整复述同一份交接载体指纹：

`轮廓 / 内部结构 / 画面位置与占比 / 材质 / 颜色 / 受光 / 运动方向 / 屏幕速度 / 当前相位 / 拖尾与遮挡边界 / 同步声音 / 稳定把手`

若 A 尾是“圆盘顺时针高速旋转并正在减速”，B 头不能从静止或反向加速开始。B 先恢复共同状态，再新增第一项变化。跨 `VID` 不追求数学上完全相同的速度数值，而要保证观众可感的方向、快慢级别、加减速趋势和相位连续。

转场速度按任务选择：

- 高速擦镜：共同遮挡面快速铺满，适合隐藏空间切换。
- 缓慢形变：共同轮廓逐步重组，适合概念关联和高级感。
- 硬切接惯性：A 出画与 B 入画方向一致，接续运动冲量。
- 突然停住后切：先制造静止标点，再切向新空间，适合强调结果。
- 声音先行：B 的声音提前进入，画面仍在 A 的减速余波中，适合叙事推进。

## 时间重映射、慢动作与运动模糊

### 实时速度

默认优先实时速度，因为它最能保留表演、物理和真实能力。若动作在实时下无法读清，先考虑改变景别、简化动作、增加预备或结果停点，再考虑慢动作。

### 慢动作

慢动作适合扩张一个真实承重点：看清技巧、看见微表情、延长危险等待、展示材质形变或让主观时间失真。它不等于高级感，也不自动增加力量；若从起步到结束全部慢放，爆发差值会消失。

写法要说明：从哪个事件开始降速、慢下来后观众看什么、哪个事件恢复实时。例：`刀锋接近玻璃前逐渐降速，只展开刃口与玻璃接触、裂纹起始和她眼神不动；裂纹完成第一圈扩散后立刻恢复实时，整面玻璃高速崩开。`

### 快动作与时间压缩

快动作适合压缩重复劳动、时间流逝、路线推进、机械装配或喜剧失衡。关键因果和人物选择不能一起被压掉；压缩段前后必须有清楚起点和结果。

### 速度渐变

速度渐变必须有戏剧理由：进入主观感知、突出接触、从回忆回到现实、在音乐抽空处拉长动作，或在重拍恢复实时。禁止为“炫酷”在每个动作中无规律快慢切换。

### 运动模糊与快门观感

运动模糊是速度证据，也是可读性成本：

- 自然适量的方向性模糊让连续运动流畅，并增强位移感。
- 较少模糊、边缘更清晰会产生硬朗、断续、战地或惊慌的抽帧感，适合短促高速动作。
- 较多模糊会让运动更柔顺或更眩晕，但可能吞掉脸、武器边缘和接触点。

正式提示词优先描述画面结果，如 `刀身边缘保持可识别，只在运动方向出现短拖影`，而不是默认写快门角度。只有模型明确支持摄影参数且参数承担结果时，再使用较小快门角度获得清晰断续运动、较大快门角度获得更连续拖影等技术表达；不能把参数当成稳定生成保证。

## 相对时长约束

### 节奏概览只给相位，不替正文排满时间

复杂镜头可以在方头中加入一条短`节奏概览`，用箭头标出真正改变动作、摄影机或注意力的相位，例如：

```text
停住辨认 → 迟疑 → 后撤加速 → 撞墙硬停 → 结果保持
```

它只帮助读者先看懂整镜的快慢骨架，不能成为第二份动作正文。人物为何停、从哪里后退、摄影机怎样跟随、脚步与墙面怎样反馈、最终表演和构图如何停止，仍由镜头正文按因果展开。方头概览和正文出现不同顺序、不同终点或不同速度关系时，先重编译，不能让模型自行取舍。

相对时间只补模型容易抢拍或拖延的局部：动作完成窗口、触发后延迟、反应窗口、减速区和结果最低保持。`向左看1秒→向右看1秒→抬头1秒→后退3秒`若首尾覆盖整镜，虽然没有写绝对起止区间，仍然是伪装时间轴；除非每个数字都直接决定承重结果，否则改为自然动作顺序和速度曲线。简单反应、自然走路和固定镜头不机械增加节奏概览或数字。

相对时长约束只控制局部动作关系，默认禁止 `0-1秒、1-2秒` 或 `【片内14.2-15.0秒】` 等绝对起止区间。只在自然语言无法稳定表达局部速度关系时，使用可随总片长伸缩的写法：

1. 动作完成速度：`从顶镡到刃光切屏控制在0.2秒内。`
2. 触发后延迟：`刀锋接触后0.1秒内，警报带先保持完整，再沿接触点断开。`
3. 反应窗口：`听到关键词后停顿约0.4秒，她的目光才从对方移开。`
4. 结果最低保持：`标题与人物构图形成后稳定保持至少0.8秒。`

一个复杂镜头通常只保留 `1-3` 个真正承重的数字。需要更多精确秒数时，优先拆镜、删动作、增加总时长或绑定真实音频时间码。数字只约束局部关系，不替代动作链，也不伪装成生成后的真实剪辑点。

## 音乐、声音与速度

音乐存在时，速度设计必须接入全段音乐-画面合同；音乐 BPM 不等于画面切镜速度。一个动作可以跨多个拍完成，一次强拍也可以只负责接触或构图锁定。

按 `拍前蓄势 → 拍上完成 → 拍后余波` 写视觉事件包络：

- 强拍 / 乐句边界：动作接触、方向反转、转场闭合、标题形成、VFX 峰值。
- 弱拍 / 细分拍：脚步、连续小位移、UI 刷新、粒子跟随。
- 长音：持续推镜、慢速形变、空间展开、角色抬头。
- 休止 / 抽空：停住、蓄力、反派出现、情绪保护层破裂。

允许抢拍、拖拍、切分和故意失拍，但必须说明重新合拍的视觉完成点。动作音优先落在真实接触，低频余响负责延长重量，吸气、衣料、机械预响和声音先行可以预告动作启动。没有音乐时，声音可用强弱、疏密和停顿建立节奏，但材质、空间传播和因果真实优先。

## 按题材选择速度结构

### 动作、打斗与追逐

先锁空间和攻击线，再使用 `短蓄势 → 高速越距 → 清晰接触 → 结果停点`。连击不要求每次都切镜；同一动作组内可让两三次快速交换形成密度，再用一次明显慢下来的预判、失手或对峙重新建立方向。强敌登场常通过主角原有速度突然无效、被迫制动或第一次失跟来证明，不只靠更大爆炸。

### 文戏与情绪表演

速度主要在语速、抢话、停顿、呼吸、目光延迟、身体逼近和摄影机反应中。触发词前禁止提前出现峰值表情；关键台词后不要立刻切镜，让反应完成。爆发可以语速加快，但最痛的一句也可能突然变慢、音量下降；判断依据是人物在攻击、掩盖、求证还是终于承认。

### MV、舞蹈与角色 PV

音乐提供宏观速度骨架，角色动作、摄影机、VFX 和切镜不必每拍同速。主动作落决定性完成点，次级粒子和 UI 放到弱拍。系列角色保持同一音乐速度与段落能量，人物差异由动作曲线、材质响应、标志性停点和同期音色体现。

### 产品广告与品牌片

产品操作优先让机制可见：打开、按压、喷出、吸附、折叠、锁定都要保留接触和结果。高级感不等于全片慢动作；可以用克制缓入建立材质，再在功能发生时短促加速，最后缓出停稳。卖点文字和 Logo 必须得到独立可读停点。

### MG、图表与知识解释

速度服从理解：一个关系完成后再引入下一关系。重复元素可快速组装，关键数字、因果箭头和结论需要停住。图形加速应对应增长、扩散、竞争或失控等概念，不能只为热闹让所有元素弹跳。

### 恐怖、悬疑与奇观揭示

用低变化率建立观众预测，再由一次违反规律的速度变化触发惊吓或揭示。巨物通常局部先动、整体后动；镜头可以先缓慢靠近，让尺度参照逐步出现，再用短促异常事件打断。全程慢不等于悬疑，全程快也不等于危险。

## 三段式编译

### `【基础设定】`

只写跨镜稳定的时间制度：总体节奏曲线、是否以实时速度为基线、固定音乐或音频参考、特殊的抽帧 / 顺滑运动观感。不要在这里堆每个动作的速度。

### `【场景状态与氛围画质】`

写影响整场速度知觉的环境参照：近前景掠过物、雨雪风尘方向、稳定或失衡地平线、空间纵深、光源闪动、运动模糊基线。环境必须帮助观众读速度，不作为无来源装饰。

### `【画面内容】`

在编号镜头内按需编译：

`速度意图 → 主速度承载者与参照物 → 起点状态 → 速度曲线 / 动作相位 → 摄影机响应 → 接触与结果 → 声音完成点 → 可读停点 → 禁止提前或禁止失控的反应`

这是一条内部因果链，不是九栏固定模板。正文只保留决定成片的部分。

弱写法：

`【镜头】节奏很快，人物高速打斗，镜头快速切换，炫酷慢动作，音乐卡点。`

强写法：

`【镜头｜中近景｜侧后低机位｜静止后突进】她先压低重心，刀鞘保持不动；右手启动后在极短距离内连续加速，刀锋沿单一斜线上挑。摄影机先锁住刀刃与金属棍的接触点，碰撞完成时才被冲击带出短促后撤；火星沿受力方向喷开，对手手腕后折并退出画面。她在下一次呼吸前骤停，刀尖保持清晰，衣摆晚半相位扫过腿侧后衰减。金属撞击落在强拍完成点，低频余响延续到停点。`

## 高频失败与修复

| 失败 | 根因 | 修复 |
|---|---|---|
| 全程都写快速、激烈、炫酷 | 没有速度参照和曲线 | 增加蓄势、制动、停点，只让承重层提速 |
| 人物快、摄影机快、VFX 快、切镜也快 | 多层争夺注意力 | 选一个主速度承载者，其余层稳定或延迟响应 |
| 快切很多但不精彩 | 每镜没有新结果 | 按攻击线、策略或信息变化删并镜头 |
| 寻找或追查换了很多角度却不紧张 | 重复动作没有信息增量 | 保留真正改变范围、策略、风险或答案的证据，其余同镜加速、合并或省略 |
| 重点段已经读懂仍长时间停留 | 把重要等同于慢，把停顿等同于悬念 | 以证据可辨认、预期形成和反应完成划定可读等待窗口，窗口到期即更新或切走 |
| 慢动作很多但没有力量 | 慢放扩张了无关过程 | 只扩张接触、技巧、表情或代价，随后恢复实时 |
| 巨物轻飘、人物瞬移 | 缺少启动、惯性和参照物 | 写局部先动、加速、环境传震与长余波 |
| 高速动作看不清 | 没有预备和结果证据 | 保住起点方向、接触点和停姿；减少同步特效 |
| 速度词与物理矛盾 | 只追求情绪形容词 | 按质量、材质、力向、摩擦和连接方式重写 |
| 音乐快就每拍切镜 | 把 BPM 当剪辑命令 | 强拍留给主完成点，连续运动跨拍，弱拍承载小变化 |
| 跨 VID 转场忽快忽慢 | 只匹配形状，未匹配相位 | A 尾和 B 头镜像写方向、速度级别、加减速趋势与相位 |
| 精确时间码锁死片长 | 把导演时间线当模型正文 | 改为动作完成、触发延迟和最低保持的相对约束 |
| 运动模糊吞掉主体 | 把模糊当速度本身 | 保持主轮廓和接触点清晰，只在运动方向保留适量拖影 |
| 速度变化很多却无情绪 | 速度没有戏剧任务 | 每次变化绑定威胁、选择、力量、关系或信息结果 |

## 速度自审合同

初稿后逐镜检查：

1. 本镜真正承重的是哪一层速度，是否写成了泛泛的“快 / 慢”。
2. 相对参照物是否存在；删掉前后对比后，观众还能感到速度变化吗。
3. 蓄势、启动、加速、峰值、接触、余波、停点中，承重相位是否完整且顺序正确。
4. 人物、摄影机、切镜、VFX 和声音是否同时争抢速度；谁应该稳定。
5. 高速段是否仍能读出方向、接触和结果；慢速段是否仍在推进等待或情绪。
6. 质量、尺度、材质、衣发和环境是否给出惯性证据。
7. 切点是否由动作、反应或信息完成决定，而不是为了数量和均匀时长。
8. 相对时长数字是否只用于局部承重点；是否出现锁死片长的绝对起止区间。
9. 有音乐时，速度曲线是否接入段落、强弱拍、休止和决定性完成点。
10. A 尾与 B 头是否继承运动方向、屏幕速度、加减速趋势、动作相位和声音余韵。
11. 是否存在最低可读停点和后期可裁切把手。
12. 删除每个速度形容词后，剩余动作、屏幕变化和声音关系是否仍能让模型看见速度。

## 迁移测试与反复制边界

用以下变化测试规则是否真正可复用：

- 把女刀客替换为厨师翻锅、运动员扣杀、机械臂装配，七相位和主速度承载者仍成立。
- 把战斗替换为夫妻争吵，速度转为抢话、停顿、逼近、呼吸和反应窗口，规则仍成立。
- 把真人替换为图表、Logo、纸片或产品零件，速度曲线、完成点和可读停点仍成立。
- 把音乐删除，动作音和环境音仍能按接触、传播和衰减组织事件节奏。
- 把总片长从 15 秒改为 30 秒，局部相对时长仍成立，绝对起止区间不会锁死结构。
- 把 A、B 两段独立生成，交接载体的方向、速度级别、趋势和相位仍能被双方提示词独立召回。

不得复制外部案例的具体角色、武器、镜头顺序、音乐、精确时长和标志性速度渐变。吸收的是：速度分层、动作相位、对比、可读性、物理惯性、声画完成点和跨镜连续性。

## 理论来源与使用边界

- [Yale Film Analysis Guide: Editing](https://filmanalysis.yale.edu/editing/)：节奏由声音、镜头序列和镜内运动的速率与规律共同形成；镜头持续时间、长镜头、重叠剪辑与快慢节奏都能改变时间体验。
- [Yale Film Analysis Guide: Cinematography](https://filmanalysis.yale.edu/cinematography/)：摄影机运动、跟随、重构图、景别和慢动作会改变观看位置、注意力与运动感。
- Ollie Johnston 与 Frank Thomas，《The Illusion of Life》：预备动作、缓入缓出、跟随与重叠动作、Timing 用于建立重量、物理、情绪和人物性格。这里吸收原理，不照搬手绘动画工作流。
- Harold Whitaker 与 John Halas，《Timing for Animation》：动作所占帧数与间距决定速度、重量和表演节奏。正式提示词优先翻译成可见相位，不要求模型理解动画师帧表。
- John Lasseter, “Principles of Traditional Animation Applied to 3D Computer Animation”, SIGGRAPH 1987：传统 Timing、Anticipation、Follow Through 等原则可迁移到计算机动画，但仍需服务清晰表演。
- [RED: Shutter Angles & Creative Control](https://www.red.com/red-101/shutter-angle-tutorial)：快门角度影响运动模糊；更小角度更清晰断续，更大角度更柔顺拖影。生成模型未必精确执行参数，因此自然语言画面结果优先。
- [NVIDIA GPU Gems 3: Motion Blur](https://developer.nvidia.com/gpugems/gpugems3/part-iv-image-effects/chapter-27-motion-blur-post-processing-effect)：运动模糊能增强速度感并平滑低帧率运动，但它是视觉效果，不替代真实动作路径。
- Michel Chion，《Audio-Vision》；Jones 与 Boltz 的动态注意理论；Vroomen 与 de Gelder 的时间腹语研究：声音瞬态和规律会改变观众对视觉事件时点的注意和判断。这里用于设计同步完成点，不声称纯文生音乐能做到采样级同步。
- Karen Pearlman，《Cutting Rhythms》：剪辑节奏同时来自身体、事件和情绪，不等于平均镜头时长或切镜数量。

理论提供因果判断，不是固定速度表。具体动作多快、停多久、是否慢放，最终由观众任务、人物状态、物理尺度、模型能力和生成复盘共同决定。
