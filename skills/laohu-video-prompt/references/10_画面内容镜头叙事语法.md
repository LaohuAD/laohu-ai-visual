# 画面内容镜头叙事语法

## 机制

本 Reference 解决的不是某一种题材，而是视频提示词的文字组织问题：把“我想让模型做一个很有画面感的镜头”编译成模型能够按顺序执行的可见事件链。

核心链条是：

```text
当前画面可见事实
→ 摄影机从哪里看、沿什么路径运动
→ 主体与物体从什么状态开始
→ 谁接触谁、怎样发力、沿什么方向变化
→ 画面在运动过程中具体改变什么
→ VFX / 声音由哪个画内事件产生
→ 画面在哪个状态停住或交给下一镜
```

它借鉴连续性剪辑、动作匹配、屏幕方向、视线匹配、180 度轴线、景别分工、事件因果和视觉注意力管理的共同原则，但不把理论名词直接当成提示词。理论只用于内部判断，正文只留下模型能看见、听见和执行的结果。

## 跨媒介定位

本 Reference 是“画面内容的通用编译层”，不是动作片模板。它统一解决四个跨题材问题：画面从哪里开始、观众通过什么观察系统接收变化、事件如何产生可见 / 可听结果、下一状态如何继承。观察系统可以是实体摄影机、三维虚拟摄影机、二维视窗、版式焦点或固定构图；它不替代当前作品的主导机制、资产规则、表演规则、商业证据、图形信息逻辑或模型适配。

正式编译分三层：

```text
第一层：主导机制决定“这一镜为什么成立”。
第二层：媒介物理决定“这个结果能以什么方式出现”。
第三层：本 Reference 决定“怎样选择摄影机 / 视窗 / 构图路径，并把变化写成连续、可观察、可生成的镜头语言”。
```

同一个“触发 → 变化 → 结果”在不同内容中不是同一种动作：刀锋接触是物理受力，台词重词是关系触发，按钮点击是产品机制，图形节点连接是信息推导，音乐强拍是时间触发，角色剪影变化是视觉母题触发。先选对触发类型，再使用统一的镜头路径、屏幕变化和停点语法。

### 跨媒介适配矩阵

| 内容类型 | 本镜主导因果 | 正文必须证明 | 标签 / 辅助层重点 | 常见误套 |
|---|---|---|---|---|
| 文戏 / 对手戏 | 处境 → 人物目的 → 触发 → 可见反应 → 关系状态 | 视线、呼吸、距离、打断、沉默、动作选择和对手反馈 | 台词节拍、表演八维、声线、环境压力 | 用动作片的受力词替代关系变化 |
| 动作 / 战斗 / 追逐 | 蓄势 → 释放 → 位移 → 接触 → 受力结果 → 余势 | 攻击来源、运动路径、接触点、速度参照、环境反馈和结束姿态 | 动作音、冲击 VFX、速度曲线、卡点 | 只写“快速、激烈、爆炸、炫酷” |
| 广告 / TVC / 产品 PV | 用户处境 → 问题 → 产品机制 → 可见证据 → 用户利益 → 品牌出口 | 产品如何参与问题、物理结果如何证明卖点、利益如何被画面兑现 | 口播、卖点文字、产品音、品牌音乐、CTA | 用漂亮运镜代替卖点证明 |
| 动画 / 角色 PV / MV | 视觉钩子 → 姿态 / 动作签名 → 形状或母题变化 → 节拍完成 → 下一视觉状态 | 轮廓、色彩、运动向量、构图重心、角色身份和音乐完成点 | VFX、图形折页、标题、音乐段落、匹配转场 | 把每个画面写成孤立海报或机械每拍切镜 |
| MG / 信息图 / 科普动画 | 输入对象 / 数据 → 图形规则 → 顺序传播 → 对比或结论 | 数值关系、图形映射、变形步骤、标签层级和结论停点 | 图形声音、旁白、字幕、节拍和 UI 状态 | 只写“图表出现、数据上升、动画流畅” |
| 特效 / 世界变化 / 巨物奇观 | 稳定锚点 → 触发 → 传播 → 尺度 / 材质响应 → 不可逆结果 | 来源、传播介质、受影响对象、环境反馈和残局 | VFX 阶段、低频、冲击、光色反转、停点 | 只写“能量爆发、世界被改变” |
| 纪实 / POV / UGC / 连续路线 | 摄影机视点 → 可行路线 → 现场反馈 → 视线 / 声音引导 → 下一位置 | 视点主体、身体可达性、路线、声源、遮挡和真实反应 | 手持稳定、环境底噪、画外声、连续运动 | 把外部摄影机写成主观视点，或跳过路线 |

适配矩阵不是新的题材分类，也不是每行都要同时加载。先根据观众承诺和主导机制选择一个主要 Reference，再用本文件把它编译成镜头正文；混合内容按主要节拍切换适配分支，不能把所有行的术语堆进一条提示词。

### 适配后的通用句法

```text
主导机制的触发者 / 触发物 + 当前空间与状态
→ 摄影机 / 视窗 / 构图焦点的观看位置、路径和屏幕变化
→ 触发如何改变主体、关系、产品、图形或环境
→ 可见 / 可听证据怎样出现、传播和达到峰值
→ 观众此刻得到的关系 / 信息 / 卖点 / 奇观结果
→ 停点与下一状态
```

句法里的每个承重变化还要通过五项控制检查：对象、本次起点、变化维度、方向 / 幅度 / 路径、可见 / 可听终态。比较词只在起点或实际参考已经进入本次请求时成立；即使参考存在，终态也要能独立描述。不可变身份、结构与空间锚点要和可变表情、软组织、动作、破坏或光色分开，避免“保持一致”把本镜真正要发生的变化一起冻结。

“接触”在动作片中可以是刀刃撞上警报带，在文戏中可以是重词击中对方的防御，在广告中可以是手指按下产品按钮，在 MG 中可以是数据节点连接，在 MV 中可以是图形轮廓与音乐强拍对齐。不要把动作片的“发力”机械套到所有类型，但任何类型都必须能回答：什么触发了变化，变化怎样被看见或听见，结果如何改变下一状态。

### 先选择观察系统，不强造运镜

不同媒介使用不同的观察语法：

```text
真人实拍 / 空间表演：使用实体摄影机，写机位、轴线、景别、焦点、遮挡和空间视差。
三维动画 / 合成奇观：使用虚拟摄影机，仍写空间路径，但同时说明尺度、层级、材质和合成对象的相对运动。
二维动画 / MG / UI / 字幕动效：优先写视窗、版式、图层、遮罩、缩放、平移、重排和焦点迁移，不把图形位移伪装成真人摄影机运动。
静态机位 / 定帧构图：明确机位和构图保持不动，再写人物表演、产品状态、光影、声音或图形内部怎样改变。
```

运镜是改变观看关系的手段，不是动态内容的硬指标。固定机位中的一次吸气、一次视线回避、产品指示灯由红转绿、柱状图在同一坐标系内重新排序，都可以构成完整事件。只有摄影机、视窗或构图焦点真的发生变化时才描述其路径；不运动时写清固定边界与画内变化，不能为了显得高级强行推拉摇移。

## 电影视觉母体转译

本分支只在用户明确要求电影感、电影正片感、导演 / 摄影参考、影像风格、宽银幕叙事，或生成结果出现“漂亮但像海报 / CG / 游戏截图”时启用。它不是新的题材分类，也不因为画面里有剧情就自动加载。主 Reference 仍由观众承诺和主导机制决定；本分支只把影像审美翻译成可观察、可生成、可验收的镜头条件。

### 影像母体不是风格词

“电影感、史诗、克制、真实、导演感、胶片质感”都不能直接作为完成条件。先把本段影像母体拆成一组不变量，再决定哪些内容可以变化：

```text
观众承诺：观众要进入什么观看位置、感到什么关系压力或时间状态。
摄影机权限：摄影机为什么在这里，它能看见什么，又被什么遮住或限制。
空间语法：人物、建筑、道具、留白、轴线和前中后景怎样共同施压。
视线流量：视线从哪里进入，被什么放慢 / 阻断，落到哪个决定性信息，最后从哪里离开。
光色来源：颜色和明暗来自哪盏灯、哪种天气、哪件服装、哪种材料或哪片反射。
成像基底：本段像由什么摄影介质捕获，清晰度、动态范围和边缘响应有什么限制。
时间证据：本镜留下什么前后帧线索，事件如何推进，结尾留下什么未完成状态。
```

从中锁定少数真正承重的不变量，不设固定数量，也不为填表把每项都写进正文；人物、地点、道具、色板、焦段、媒介和动作可以作为可变槽，但不能让可变项破坏摄影机权限、空间关系、光色来源或事件状态。如果所谓母体只剩颜色、颗粒、宽画幅或浅景深，说明它仍是表面滤镜，必须退回关系、空间与事件层重做。

### 不变量与可变槽

内部先建立一张简短的影像母体卡：

```text
主观看任务：这一段最先让观众看见什么。
主空间压力：人物被谁 / 什么限制，或谁在控制观看权限。
主构图机制：只选一个主要压力，如被观察、被困住、关系疏离、权力不对等或心理失衡。
主色彩命题：颜色从哪里来，它怎样改变事件判断。
成像与缺陷：只选一个主要成像基底和一个主要不完美来源。
序列变化：每个镜头新增什么信息、关系、尺度、证据或后果。
余韵出口：最后停在人物、动作、物件、空间、声音或缺席的哪个状态。
```

正式提示词只把会改变生成结果的部分写进去：全局不变量进入 `【场景状态与氛围画质】`，本镜变化进入 `【画面内容】`，内部判断表不直接投喂模型。一个镜头通常只保留一个主构图决定、一个主故事线索和按需一个辅助线索；普通、暗、软、遮挡或留空的信息不是缺陷，而是给决定性信息让位的选择。只有特殊机位、特殊光学或特殊光线改变信息权限、关系压力或身体感时才使用，不能用来装饰“电影感”。

### 电影化提示词的正向编译

出现“电影感”需求时按以下顺序写，不先堆电影术语：

```text
关系压力 / 观众位置
→ 真实摄影机位置与信息权限
→ 视线入口、阻断、落点和出口
→ 人物 / 道具 / 空间的一个可见事件
→ 光色与材质的画内来源
→ 成像限制与局部光学反应
→ 停点、余波和下一镜状态
```

“真实电影剧照、史诗、沉浸、大片质感、胶片感”只能作为内部检查标签，不能代替上述内容。正文必须让模型看见摄影机位置、主体状态、空间参照、动作结果和停点；对视频而言，还必须让画面在运动中发生可观察变化。宽画幅只是生成参数或内部构图条件，不能自动带来横向关系，也不能让本项目默认进入三联拼接模式。

### 电影感失败的根因修复

| 失败结果 | 根因 | 最小修复 |
|---|---|---|
| 像海报或游戏概念图 | 没有事件状态，只有完整漂亮的主体与风格词 | 加一个可推断前后帧的选择、阻力、缺席或环境后果，减少装饰细节 |
| 像普通电视剧截图 | 摄影机只在记录人物说话，没有观看压力 | 给机位一个空间限制，并让构图承担关系距离、信息差或权力差 |
| 像滤镜套图 | 颜色、颗粒、光晕没有画内来源 | 指定颜色来自实景对象 / 光源，保留单一成像基底和局部缺陷 |
| 像空洞风景照 | 空间没有第二叙事力量 | 加入人物选择、观察者、制度痕迹、等待对象、异常物件或正在改变的环境 |
| 三个镜头可以随意换序 | 每镜只是同主题的审美变体 | 为每镜指定唯一新增信息或后果，并做顺序打乱测试 |
| 参考图换人后仍像原图 | 同时继承构图、配色、人物关系和道具组合 | 只抽取一个维度，其余改写为原创的空间、事件、色彩和角色关系 |

### 迁移与边界测试

影像母体卡通过以下测试才算抽象有效：把人物换成物件 / 符号，换掉色板，改成 MV、广告、动作、文戏或文化视觉任务，摄影机权限、空间压力、视线流量和事件停点仍然能重新编译。若规则只能依赖 21:9、三联结构、某位导演、某种胶片或某个样片的独特道具，它只是表面模板，应退回当前作品的一次性机制卡。

三联图、21:9、胶片颗粒、特定导演 DNA、宽银幕光晕和“两个稳定镜头加一个特殊镜头”都只能作为外部案例中的候选方案，不能升级为项目默认。是否使用它们，必须由当前作品的主导机制、实际画幅、人物 / 空间证据、剪辑接口和模型可生成性共同决定。

## 触发条件

出现任一信号时读取本文件：

- 画面正文出现“第一帧已经发生动作”“这里揭示身份”“让观众看到”“完成登场”等作者解释，却没有直接写画面。
- 一个镜头头部写特写，正文却突然同时出现全身移动、城市全貌、手部细节和眼睛特写。
- 写了“镜头切到”“镜头上移”“快速推进”却没有起点、路径、方向、速度变化、停点和屏幕结果。
- 写人物向某方向移动，却没有景别、地面参照、背景反向位移或视差证据。
- 写拔刀、爆炸、能量、刀光、烟雾或光效，却没有说明来源、接触点、传播方向和结果。
- 写“无缝衔接”“自然转场”“保持一致”，却没有说明两个镜头共同继承的轮廓、颜色、材质、位置、运动相位和声音。
- 用“不出现第二次拔刀”“不要让人物哭”“不是另一个镜头”等否定句控制具体动作。
- 使用模型不稳定的生僻术语、抽象情绪结论或小说式跳接，导致主体关系需要模型猜测。
- 生成结果出现突然换景、人物瞬移、武器状态跳变、镜头方向反转或特效凭空出现。

静态单对象展示可以不加载本 Reference；凡是需要镜头运动、主体动作、画面转化、VFX、声音、音乐卡点、卖点证明、表演转折或跨镜衔接的动态内容，默认把本 Reference 作为编译层使用，即使首稿还没有暴露明显错误。

## 不变量

### 1. 先写看见的画面

每个镜头第一句必须直接回答：画面现在看见谁、什么物体、位于哪里、处于什么状态、正在发生什么。不得先写作者对镜头的解释。

```text
错误：第一帧已经发生动作。
正确：女刀客的黑色战斗靴重重踩进骨白网格，脚跟压出一圈冷青波纹。
```

“第一帧”“这一镜”“此处揭示”“让观众理解”可以作为代码块外的导演说明，不能替代模型正文中的人物、物体、动作和结果。`完成亮相`、`完成转场`可以作为动作链收束句，但前面必须已经把形成这个结果的画面写完整。

### 2. 景别或信息尺度是证据边界

真人与三维空间使用景别，二维动画、MG、UI 和字幕动效使用信息尺度；两者都不是装饰标签，而是规定观众这一刻能同时看见多少信息：

| 景别 | 主要职责 | 能够承重的证据 |
|---|---|---|
| 特写 / 局部特写 | 单一局部证据 | 眼睛、嘴唇、拇指、刀镡、刀刃接触、按钮、裂纹 |
| 中近景 | 表情与上半身关系 | 脸、手、胸背、武器局部、对手距离 |
| 中景 | 身体动作与方向 | 站姿、步行、拔刀前准备、人物和背景的相对运动 |
| 中远景 / 较宽画面 | 空间与路线证据 | 全身位移、人物与城市 / 敌群 / 巨物的关系 |

如果正文需要跨越景别，必须写出变化机制：`镜头从刀柄特写沿刀锋方向拉远至中近景`、`镜头绕过肩线并后撤，人物全身和背景轨道同时进入画面`。不能让同一个景别凭空拥有互相不可见的信息。

二维内容对应三种常用信息尺度：`总览` 证明整体结构、坐标系和各组关系；`分组焦点` 证明一组对象之间的比较、顺序或因果；`单点细节` 证明一个数字、标签、节点或局部变化。信息尺度切换必须写出视窗缩放、图层前后移、遮罩展开、版式重排或焦点迁移，不能让一个单点细节画面同时承担完整系统关系，也不能边高速重排边要求观众读完全部文字。

### 3. 观察路径必须改变屏幕，静止必须有意

每次实体摄影机、虚拟摄影机、二维视窗或构图焦点发生运动时，至少明确五项中的四项，关键转场全部明确五项：

```text
起点：摄影机当前看什么、在主体哪一侧、处于什么距离。
路径：机身整体移动、原地摇 / 俯仰、环绕、升降、穿越或焦点迁移。
方向：向左 / 右、前进 / 后退、上移 / 下移、顺时针 / 逆时针，以及主体屏幕方向。
速度：匀速、缓入、突然加速、峰值、硬制动、回弹或减速；写相对谁变化。
停点：最终停在什么景别、构图、对象、焦点或可裁切状态。
屏幕结果：主体大小、角度、遮挡、背景视差、焦点和位置如何改变。
```

“镜头上移”不是完整描述。完整描述应让模型知道镜头上移时沿谁上移、经过什么、最后看见什么：

```text
贴着女刀客的靴面向右上方旋转上移，沿左腰带出斜穿画面的深海蓝黑刀鞘；镜头继续绕过刀鞘口，右上缺口圆环护手贴近前景，随后停在她冷静的右眼特写。
```

专业术语可以出现，但必须紧跟可见结果。`Dolly / Track` 指机身整体移动；`Pan / Tilt` 指机位基本不动的转动；`Zoom` 指焦段变化。不能只堆“旋转推进、电影感、炫酷运镜”。

二维图形没有真实景深、地面轴线或镜头视差时，不机械套用这些术语。改写为可见的版式动作，例如：`主标题保持画面中心不动，三组数据卡沿同一水平基线从右侧依次进入；第二组放大并前移到视觉第一层，其余两组降低明度退到两侧`。固定机位则写明 `摄影机保持平视中近景不动`，随后只描述画内表演和状态变化。

### 4. 运动必须有空间参照

人物向右前方、左后方或画外移动时，必须让观众看到至少一种空间证据：

- 中景或更宽画面保留脚步、身体重心和地面参照。
- 背景向相反方向滑动，前景遮挡产生不同速度的视差。
- 地面网格、道路、管道、楼群、栏杆或光带向后掠过。
- 衣料、发丝、尘土、水花或影子产生与运动方向一致的延迟反馈。
- 摄影机与主体同速、慢于主体或绕行时，分别写清主体稳定、背景失跟或相对位移结果。

```text
错误：她保持向右前方前进，镜头切近拇指拔刀。
正确：侧面中景与女刀客同速向右跟拍，脚下骨白网格和身后的楼群持续向左后退；她进入画面右侧后，镜头才沿左腰快速切近到刀柄特写。
```

特写可以展示局部动作，但不能同时证明观众无法看到的全身路线。需要两种证据时，先用中景完成空间动作，再通过明确的切近或镜头路径进入局部特写。

### 5. 动作必须闭合因果

所有关键动作按以下句法组织：

```text
主体 / 物体 + 起始位置 + 接触部位 + 发力或运动方向 + 受力变化 + 屏幕结果 + 收束状态
```

```text
女刀客左拇指压住刀柄前方的圆环护手，右手沿刀柄向后抽出刀身；冷白刀刃从左腰刀鞘口斜向右上方滑出，刀锋经过镜头前方时，刃面反光由左下向右上扩展并遮住画面；斩击完成后，右手停在身体右后方，刀锋斜向上，余光沿画面右上方衰减。
```

不能从“手碰刀”直接跳到“刀已经在空中”，也不能从“拔刀”直接跳到“画面被刀光填满”。模型需要知道刀光由刀刃反射产生、沿哪条路径扩展、何时遮挡画面、遮挡退开后留下什么。

### 6. VFX 和声音必须有来源

特效不是作者加上的装饰层，而是画内事件的可见 / 可听结果。写特效时回答：

```text
来源是什么 → 在哪里形成 → 沿什么路径传播 → 接触什么 → 造成什么变化 → 余波怎样停住
```

声音至少写清声源、材质、方向、距离、进入时点和衰减。刀光来自刀刃，波纹来自脚底受力，警报带来自监视环缺口，碎片来自被斩开的图形；不能让特效从画面外凭空出现。

错误：极白冷光切满画面。

正确：刀刃从刀鞘口斜向右上方滑出，刃面反光沿刀路由左下向右上扩展；白光在刀锋穿过猩红警报带时才扩大成遮挡，遮挡边缘保留红带裂口的锯齿轮廓。

### 7. 正文主轨与声画补充轨

`【画面内容】` 内部可以拆成两层，但两层不是两个互相独立的剧本：

```text
正文主轨：什么时候发生、什么触发、画面 / 声音发生什么可感变化、动作如何进入下一状态。
声画补充轨：VFX、环境音、动作音、音乐 / 节拍的材质、方向、声场、强弱、相位、持续和校准细节。
```

正文主轨必须先把事件写出来。标签只补充已经在正文出现的事件，不得独自新增关键动作、特效、声音、人物或节拍。模型不一定把 `【VFX】`、`【动作音】` 当作稳定的结构化字段；如果关键触发只写在标签里，模型可能只生成一个“漂亮结果”，却丢掉结果的来源和发生时点。

推荐使用事件 ID 把正文和补充轨绑定：

```text
女刀客的黑色战斗靴重重踩进骨白网格；脚跟压实的瞬间，受力点向外弹出冷青缺口圆环波纹【VFX-A1】。靴底硬响与网格低沉回声在落脚点同时出现【动作音-A1】；第一记强拍在脚跟锁定时落下【音乐-A1】。
【VFX-A1】波纹从脚跟接触点向外扩散，外圈保持右上缺口，冷青亮度由中心向外衰减。
【动作音-A1】硬质靴底撞击骨白网格，近距离、短促、低频有重量；网格受压回声向画面后方衰减。
【音乐-A1】脚跟落地前留出极短预拍，强拍与脚跟完全压实同步，拍后保留半拍余波。
```

正文中的事件 ID 不是给模型看的新对象，而是让作者、剪辑者和复盘者可以逐项回查。最终投喂时可以保留标签；如果目标模型对标签敏感，则保留标签名称但删掉不改变生成结果的解释性句子，不能删掉正文中的触发、结果和同步关系。

#### 三项绑定规则

1. **存在性绑定**：每个 `【VFX-X】`、`【环境音-X】`、`【动作音-X】`、`【音乐-X】` 必须在前面的正文中找到同名事件 ID和可见 / 可听触发。
2. **时序绑定**：正文先写触发，再写结果，再写标签细节；标签不能把结果提前、延后或改成另一个动作。
3. **属性绑定**：标签可以补充材质、声源方向、距离、频率感觉、动态范围、音乐拍点、衰减和余波，但不能改变正文的主体、位置、运动方向、颜色母题、接触对象或结束状态。

#### 四类补充轨职责

| 标签 | 正文必须先写 | 标签补充什么 |
|---|---|---|
| `【VFX-X】` | 触发动作、生成位置、可见变化 | 传播路径、轮廓、材质、亮度、遮挡、峰值、衰减、跨镜继承 |
| `【环境音-X】` | 空间中正在发生的声场变化 | 声源位置、方向、距离、空间大小、混响、遮挡、远近变化 |
| `【动作音-X】` | 谁与什么接触 / 移动 / 破坏 | 材质、力度、音头、持续、余响、与动作相位的同步 |
| `【音乐-X】` | 哪个画面事件与音乐进入、停顿或完成同步 | 段落职责、拍前蓄势、强拍 / 弱拍 / 长音、拍后余波、抢拍或拖拍关系 |

环境音与动作音不能只写“有声音”。环境音维持空间，动作音证明接触；音乐提供时间骨架，三者的职责不能互相替代。一个脚步既可以产生动作音，也可以被低频音乐包住，但标签要分别说明它们怎样叠加，不能把所有声音都写成“节奏感强”。

#### 正文与标签的压缩边界

当正文已经写出“脚跟压实的瞬间产生冷青波纹”，标签只补波纹的轮廓、方向和衰减，不再重复整句动作；当标签补充了刀刃擦鸣，正文仍要写刀刃何时经过什么对象，不能让音效成为唯一动作线索。正文承载事件因果，标签承载调音和特效校准；二者重复到可以互相替换时，说明层级没有分开。

#### 声画理论的迁移原则

这套双层结构吸收影视声音设计中的 `spotting`（为事件确定声音进入点）、同步声 / 拟音的接触证据、环境声的空间连续、非画内音乐的段落组织、声音桥和声画反差等原则。它们共同说明：声音不是画面后面的一张清单，而是对画面事件的时间和空间定位；但也不能让模型正文被完整音频工程表淹没。先在画面主轨中建立因果锚点，再在补充轨中做声音和 VFX 校准，才能同时服务生成、阅读、剪辑和复盘。

### 声画质量加厚

#### 1. 建立声画事件账本

复杂镜头在正文外先登记最小事件账本，不新增模型正文层级：

```text
事件 ID：VFX-A1 / 动作音-A1 / 环境音-A1 / 音乐-A1
画面触发：谁在什么位置对什么对象做了什么
可见结果：对象的形状、位置、颜色、材质或焦点怎样变化
声音结果：声源、方向、距离、材质、进入点和衰减
音乐关系：拍前蓄势、同步完成点、拍后余波或故意错位
下一状态：动作余势、声场余韵、画面载体和下一镜第一变化
```

每个事件只登记真正改变画面、声音、节奏或连续性的内容。事件账本用于查错，不把“事件 ID、触发、结果”全部原样复制进正文；正文和标签只保留执行所需的最小信息。

#### 2. 声源视角必须和摄影机一致

环境音和动作音除了“是什么声音”，还要判断它从哪里被听见：

- 画内近距离：声音清晰、音头明确，适合脚步、刀刃、手指接触和产品操作。
- 画外同场：声音方向明确，但声源暂时不入画，适合威胁、警报、来车和下一镜预示。
- 远处空间：高频衰减、混响更长、方向更宽，适合城市、机器群、人群和天气。
- 主观听觉：可以低通、压缩、抽空或只留下心跳 / 呼吸，但必须由人物状态或摄影机视角触发。

声音视角不能和画面距离矛盾：局部接触特写却配远处空旷回声，会削弱受力；远景城市却把单个脚步做成贴耳近麦，除非这是明确的主观听觉变化。

#### 3. 同步、预置和声音桥

声音与画面有三种常用关系：

```text
同步：接触、爆裂、标题锁定与声音完成点同落。
预置：下一镜的警报、脚步、低频或呼吸先进入，画面随后揭示声源。
声音桥：上一镜的摩擦、余响、长音或环境底噪跨过切点，帮助下一镜继承空间 / 动作相位。
```

预置和声音桥不能用来掩盖画面断因。若声音先出现，正文必须写它来自画外或上一状态；若声音跨镜保留，下一镜必须说明声场如何继续、变化或衰减。音乐存在时，声音桥可以维持乐句连续，但动作音仍要在真实接触点完成。

#### 4. 声音优先级与静音

一个镜头最多保留一至两个主声画事件。混音优先级按本镜任务决定：对白 / 关键表演 > 决定性接触音 > 关键环境警报 > 音乐细节；纯动作镜头则优先决定性接触音和动作方向，音乐与环境为其让位。不要把脚步、衣料、城市、电流、警报、金属、低频、音乐和粒子全部写成同等重要。

静音或抽空半拍也是事件，必须写清被抽掉什么、由哪个动作触发、持续到哪个完成点，以及下一声音如何回来。`突然安静` 不够，改成 `刀锋接触前，脚步和城市电流同时抽空，只留一口吸气；红带裂开时金属撞击和鼓点同时回来`。

#### 5. 声画冲突审查

逐镜检查以下冲突：画面接触已完成而声音仍在预备；声音已经爆发而画面尚未发力；近景动作配远景声场；音乐强拍切断了必须完整读完的动作；环境音盖住决定性结果；下一镜继承了声音却换了空间、方向或材质。发现冲突时先修事件相位，再修词语，不用“更有氛围”掩盖时序错误。

### 8. 转场是共同载体的状态继承

相邻独立生成镜头不能只写“无缝衔接”。必须建立共同载体视觉指纹：

```text
载体名称 / 几何轮廓 / 内部结构 / 画面位置与占比
颜色层级 / 材质与纹理 / 光源和反射
运动方向 / 速度 / 动作相位 / 遮挡边界
同步声音 / VFX 阶段 / 下一镜第一变化
```

A 尾部和 B 开头都要独立写出同一指纹。A 以它遮挡或离场，B 从同一轮廓、颜色、材质、位置和运动相位重新开始，再只增加一个新变化。不能用“继续上一镜的圆环”“同一个刀光”代替跨请求的可执行描述。

### 9. 正向描述，不召回禁止对象

具体负面句会把不想要的对象再次提供给模型。不要写“不要第二次拔刀”，改写为当前真实状态：

```text
刀锋已经完全出鞘，右手停在身体右后方，刀尖斜向上，余光沿刀路衰减。
```

排除句只保留在代码块外的验收边界，或用于抽象质量问题（文字水印、解剖畸形、画面破碎）。模型正文只描述目标画面，不描述作者担心什么。

### 10. 语言要像“镜头化小说”

好的画面内容兼具小说的视觉连续性和分镜的执行纪律：句子有空间、有动作、有质感和画面感，但每个意象都附着在镜头正在观察的对象上。推荐使用“对象 + 动作 + 结果”的连续句，不使用主题总结、作者自评或抽象旁白。

```text
对象：女刀客的黑色战斗靴。
动作：重重踩进骨白网格。
结果：脚跟压出冷青缺口圆环波纹，摄影机沿波纹上移并带出刀鞘。
```

可以写“冷白刀光像一条被拉直的线”，但必须紧接它从哪里来、遮住什么、如何进入下一画面。比喻是材质和形状的辅助，不是动作因果的替代品。

## 推荐镜头块

正式三段式中的 `【画面内容】` 使用以下结构；字段不是机械填空，只有本镜承重的行才保留：

```text
【镜头01｜中景 / 特写｜机位、视窗或构图焦点｜观察路径 / 转场方式】
当前画面：直接写主体、物体、空间位置和起始状态。
观察路径：按媒介写摄影机、虚拟摄影机、二维视窗或构图焦点的起点、方向、速度变化、经过对象、屏幕变化和停点；固定构图则写不动的边界。
动作因果：写主体接触、发力、位移、结果和结束状态。
【VFX】写画内来源、传播路径、材质反馈和收束状态。
【环境音】写声源、方向、距离和环境变化。
【动作音】写具体接触、材质和余响。
【音乐 / 节拍】有音乐时写拍前蓄势、同步完成点和拍后余波。
```

如果一个段落需要从中景切到刀柄特写，必须另开镜头块；如果确实是一镜到底，则在同一块里写清镜头如何从中景切近、何时焦点迁移、哪些对象离开画面、哪些对象进入画面。

## 镜头组织原则

### 先分配证据，再写句子

写每个镜头前，内部先确定：

```text
主注意力：观众第一眼看哪里？
主观看任务：观众等待什么变化？
主空间证据：观众如何知道人物在移动、受压或接触？
主结果：本镜结束后哪一项状态不可逆？
停点 / 交接：在哪个可见状态切走或交给下一镜？
```

一个镜头通常只保留一个主注意力目标。要同时表现眼睛、马尾、右手、城市和反派时，不是把名词都塞进同一段，而是安排明确的镜头路径或片内切换，让注意力有触发顺序。

### 运动和切镜的速度关系

速度写法要绑定参照物：人物相对背景、摄影机相对人物、刀光相对刀锋、切镜相对音乐拍点。`快速、炫酷、激烈、电影感` 只能做总结，不能替代路径。

高能动作至少保留 `蓄势 / 启动 → 加速 → 接触 → 结果 → 余势 / 停点` 中真正承重的阶段。快负责越距和接触，慢负责预读和力量积累，硬停负责让结果被看见；持续快切会抹掉空间，必须用一处减速、遮挡或静止帧重新建立可读性。

### 画面句与解释句检查

把正文中的每句单独拿出来问：删除它后，模型生成的像素、运动、声音、节奏、身份、物理结果或剪辑接口会不会改变？不会改变，就是解释句、重复句或空泛形容词，应删除或改成可见动作。

高风险解释词包括：`第一帧已经、这一镜、这里揭示、让观众、为了表现、完成了、不要出现、不再、无缝、自然地、电影感、炫酷地、强烈地`。这些词不是绝对禁用；只有它们后面紧跟可观察对象、路径和结果时才保留，例如“遮挡退开后完成身份亮相”可以作为动作链收束，但不能单独构成画面描述。

## 失败修复表

| 失败表现 | 根因 | 最小修复 |
|---|---|---|
| 开头写“已经发生动作” | 作者在解释剪辑点，没有写首个画面 | 直接写主体、物体、位置、动作和即时结果 |
| 画面突然从脸跳到全身 | 景别职责混用 | 明确拉远 / 环绕 / 切镜，并补空间证据 |
| MG 同时要求读全局、分组和单个数字 | 信息尺度混用 | 按总览、分组焦点、单点细节分配证据，并写清视窗或版式切换 |
| 人物移动像瞬移 | 没有背景参照或动作相位 | 改为中景跟拍，补地面、背景反向位移和重心 |
| 特效凭空出现 | 缺少来源和传播路径 | 写触发者、接触点、路径、遮挡和余波 |
| 两条视频接不上 | 只写“同一个”没有视觉指纹 | A / B 双端重复轮廓、颜色、材质、位置、相位和声音 |
| 模型增加禁写动作 | 否定句召回了对象 | 删除否定句，改写动作完成后的正面状态 |
| 描述像名词清单 | 缺少观看顺序 | 用摄影机路径把对象按进入、离开和焦点迁移串起来 |
| 文字很美但画面不执行 | 比喻替代了因果 | 每个比喻后补来源、方向、接触和屏幕结果 |
| MG / UI 像在虚拟摄影棚乱飞 | 把二维版式变化误写成实体运镜 | 改写为视窗、图层、遮罩、缩放、重排和焦点迁移 |
| 每个镜头都在推拉摇移 | 把运镜当成高级感本身 | 固定机位或视窗边界，只保留真正改变观看关系的运动 |

## 迁移测试

入库或修改后至少检查以下题材：

1. 武打：把“刀光”替换成拳头、车辆或投射物，仍能写出起势、接触、结果和空间参照。
2. 文戏：把“斩击”替换成递手机、逼近一步或回头，仍能保持景别和运镜的因果。
3. 广告：把“攻击结果”替换成产品参与、卖点证据和用户利益，仍能说明触发、可见证明、停点和声音。
4. MG / UI：去掉实体摄影机后，仍能用视窗、图层、版式重排和焦点迁移说明信息怎样成立。
5. 形态变化：把人物替换成纸片、界面图形或巨大生物，镜头语法仍成立，不依赖题材专有词。

如果规则只能指导“女刀客踩网格、拔刀、刀光遮挡”这一案例，而无法指导上述替换，它仍停留在案例复述，应继续抽象。

## 反复制边界

本 Reference 继承的是画面组织机制：可见事件链、景别证据边界、镜头路径、动作因果、正向描述、共同载体转场和声音来源。不得继承任何外部案例的角色、品牌、台词、具体道具、镜头顺序、颜色组合或标志性特效。当前女刀客的靴子、刀镡、缺口圆环和警报带只作为局部示例，不是固定模板。
