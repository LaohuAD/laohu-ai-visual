# MV、概念 PV 与动态图形蒙太奇

## 上游边界

当输入是一首完整歌曲、歌词、音频时间轴或歌曲创作背景时，先由`laohu-mv-director`建立`MV导演交接包`。本 Reference 只解决已经确认生产单元内部怎样形成动态图形、表演、母题、镜头与三段式视频提示词，不重新决定整首歌的导演命题、段落结构、口型分配或生产单元边界。没有该交接包时，可以为单条概念 PV 提供局部方法；不得假装已经完成整首 MV 设计。

## 触发条件与观众承诺

用于 MV、舞蹈、演唱、角色 / IP 概念 PV、游戏视觉短片、动画 OP、动态标题序列、符号拼贴、动态图形海报、节奏剪辑、歌词字效和空间文字。主任务是让观众在音乐或声音组织的时间里记住作品的情绪气质、角色身份、世界观或视觉识别，而不是讲懂知识、证明产品或完成连续剧情。

画面可以由人物、物件、雕像、建筑、符号、文字、UI 或 Logo 承担锚点。是否有人物不是分类条件；真正的共同机制是：统一音轨推动视觉母题反复出现、变形、遮挡、拆解、重排和回收，整个画面像一张不断重新设计的动态海报。

## 核心状态机

先锁一个身份命题：观众最终要记住谁、什么世界、什么情绪或什么作品。再建立：

```text
音乐 / 声音结构
→ 主视觉锚点与重复母题
→ 扁平二维或浅层 2.5D 版面
→ 节拍触发的图形状态转换
→ 母题回声与视觉升级
→ 标题、角色、Logo 或核心符号回收
```

每次转换必须改变构图关系、视觉身份或信息状态，不能只是随机闪屏。角色轮廓、十字架、钟盘、月相、城市管线、刀形色块、HUD 圆环或文字都可以成为母题；母题应保留可识别的几何、方向、色彩职责或声音对应关系，才能在变形后被观众认出。

## 四种主要模式

每条作品只选择一个主要模式，最多借用一个辅助模式；不能为了“丰富”把四种模式平均堆满。

### 表演型 MV

舞蹈、演唱、动作姿态或人物与镜头互动承担节奏。先锁动作短语、重心方向、手脚路径、朝向和结束姿势，再让摄影机、文字和灯光响应动作结果。群舞必须有领舞与群体相位关系；口型同步、身体表演和镜头互动分开控制。

### 角色与 IP 概念 PV

角色或生物是稳定身份锚点，城市、UI、武器、时间符号、阵营图形和标题围绕其轮廓持续拆解重组。角色不必始终完整露出，但发型、剪影、服装结构、标志物和色彩职责至少保留两个稳定识别点。角色动作服务身份揭示，不强行发展成连续打斗或写实场景叙事。

当任务是用十几秒概括一个更大的故事，不把有限时长误用成动作集锦。先建立 `角色出场 → 世界规则或异常 → 一次标志行动 → 未来冲突碎片 → 对手 / 代价预示 → 角色或作品身份回收` 的宏观叙事链，再让武器动作、遮挡、图形变形和匹配剪辑负责跨阶段过渡。每段只给观众一块可拼接的故事证据，不解释完整前因后果；一次斩击既能证明能力、切开警报色块、引出敌方符号并生成下一张动态海报，比连续多招只证明“会打”更适合宣传 PV。对手可以只以眼睛、手、影子、徽记或控制痕迹出现，预示其存在，不必在短时长内完成正面对决。

### 符号与物件视觉蒙太奇

雕像、十字架、钟表、花、月相、建筑、器物和抽象图形共同建立主题。先确定核心符号及其关系，再用尺度反转、对称破坏、负形嵌套、拼贴遮挡和重复回声制造意义；不能把无关符号只按“看起来神秘”随机堆叠。

### 排版、UI 与标题序列

动态文字、HUD、扫描框、网格、刻度、编号、图标和几何框架承担主要节奏。非承重小字可以作为抽象纹理，不要求真实可读；作品名、角色名、核心短句和 Logo 必须形成、保持、退出分相位，留出稳定阅读停点。空间文字需要真实影响遮挡、路径或构图，不能只是贴在画面表面。

## 动态海报空间

默认把空间理解为二维版面或浅层 2.5D 层栈，不按真实摄影棚或完整三维城市组织。先锁背景层、主锚点层、母题层、文字 / UI 层和前景遮挡层，再决定哪些层可平移、旋转、翻面、缩放、折叠或产生视差。

转场本身负责生成下一张构图，可使用同形匹配、轮廓遮挡、负形切割、黑白反相、色块擦除、纸裂、硬切、短促故障、图形折解和版面翻转。每次转场都要有明确完成态，禁止无意义淡入淡出、随机火焰擦除和没有落点的连续 Glitch。

限制色板不是固定蓝黑红，而是为颜色分配职责：主身份色、结构色、背景色和危险 / 反转色。新增颜色必须对应事件或身份变化，不能为了热闹持续扩色。

## 音乐与视觉短语

先建立前奏、段落进入、重拍、节奏加速、留白、高潮和尾奏。每个声音事件只承担一个主变化：动作落点、版面重排、母题变形、标题出现或镜头冲量。辅变化只证明主变化。

卡点不等于每拍切镜。可以让视觉变化在重拍前蓄势、重拍时完成、重拍后停住；也可以让一个长音维持连续变形，在鼓点上突然锁定。至少形成两个以上视觉短语：第一遍建立规律，第二遍产生变体或升级，结尾才有回收感。

正式设计先建立 `音乐-画面节拍合同`。段落层让人物出场、世界异常、威胁揭示、高潮和标题回收分别落在不同音乐功能；拍点层把动作接触、转场闭合、版面翻转、母题变形、光色反转和文字形成分配给强拍、弱拍、细分拍、长音或休止；事件层写清拍前准备、同步完成与拍后余波。每个主要视觉短语必须有一项决定性画面事件被音乐驱动，中段不能只剩“背景音乐继续”。

同步密度要有层级：大变化只占承重强拍或乐句边界，小变化可以跟随弱拍与细分拍，连续推镜和形变可以跨越多个拍点，留白允许画面先停或声音先到。故意抢拍、拖拍与切分音可以制造不安或惊喜，但先让观众听懂规律，再明确哪一次偏离、哪一次重新合拍。若所有切镜、脚步、UI 与粒子都抢同一强拍，减少次要同步，只保留主事件。

固定歌曲需要精确同步时调用音乐参考；普通原创氛围音乐不机械建立音频资产。声音设计要与视觉材料绑定：纸裂对应撕裂、金属瞬态对应硬边符号、低频对应尺度压迫、扫描声对应 UI 进入、钟声对应时间母题，而不是所有切换都使用同一种 whoosh。

## 组合成员系列出场

同一女团、乐队、战队、阵营或角色组合拆成多条成员出场视频时，先建立 `主音乐骨架合同`：固定同一速度、拍号、鼓组、Bass 律动、主和声 / 主旋律走向、核心乐器、女声或人声职责、重拍位置和段落能量。不同成员的身份差异优先由动作音、材质音、武器音、VFX 瞬态和视觉母题表达，不能让第二条改编曲、第三条加速、第四条突然进入另一个副歌来冒充角色差异。纯文生视频只能逼近同一音乐结构；要求旋律、音色和演奏完全一致时，必须使用同一音频参考或后期统一音轨。

系列还要过 `成员视觉能级对齐`。第一条可用成片一旦建立了观众期待，后续每条至少要达到同级的五段奇观链：`立即发生的入场力量 → 摄影机被动作迫使改变 → 成员标志动作或标志物完成身份揭示 → 环境 / 图形空间产生可见结果 → 英雄停点或下一条交接`。五段是能级审稿维度，不要求固定五个镜头；一镜可以承担多段，多镜也可以共同完成一段。比较的是冲击、身份、因果和记忆点，不是特效数量。

成员之间应当 `同能级、不同机制`。主唱可以用声压、呼吸与麦克风改变空间；舞担可以用重心、脚步、旋转和丝带切开版面；中心成员可以用召集、棱镜和其他成员母题完成终局合流。不能只是把第一条换颜色照抄，也不能让第一名拥有完整入场动作、运镜追击、环境破坏和英雄停点，后续成员却只站立、摆姿势、生成道具或在普通 UI 前唱跳。最终成员可以因承担组合回收而高于单人平均值，但不能用终局合流掩盖自身出场事件不足。

写完系列后建立简短能级账本，逐条比较：首拍是否立即有事件；摄影机是否真正响应人物；标志动作是否不可互换；VFX 是否改变环境而不只是贴图；是否有一个可记住的峰值；是否保留稳定转场接口；主音乐骨架是否完全一致。若某一条只能用“漂亮、流畅、特效多”说明优势，却说不出人物造成了什么空间结果，就退回重做出场方式。

## 镜头与版面运动

真实摄影机运动只在它能强化视觉身份时使用。平面正交推拉、沿缝隙推进、图层间视差、低角度仰拍和短促旋转都必须改变锚点的尺度、遮挡或关系；不能为了电影感把扁平图形世界拍成普通写实 3D 场景。

每个状态保留一个第一视觉落点。人物、文字、符号和背景同时存在时，明确谁先被看到，其他信息通过明暗、尺寸、清晰度、遮挡或延迟进入降级。承重画面应留下海报式停点，既能作为剪辑接口，也能单独保存为宣传静帧。

## 三段式编译

- `【基础设定】`：音乐 / 音色参考、作品身份命题、人物 / 物件 / Logo 资产、锁定标题、主视觉母题、色彩职责和禁止出现内容。
- `【场景状态与氛围画质】`：统一二维 / 2.5D 版面空间、图层关系、线条与材质、主辅色、图形阴影、故障强度和声音质感。
- `【画面内容】`：按视觉短语写锚点起始状态、触发声音、母题变形路径、版面重排、镜头或图层运动、完成构图、阅读停点和结尾回收。

正式正文不机械罗列每一拍时间码；复杂同步可以在正文外建立 beat-event plan，再把真正承重的节拍、停顿和完成态编译进提示词。

## 惊艳点设计

惊艳来自同一个视觉母题跨状态改变身份，而不是同时堆十种特效。例如人物披风负形变成城市阴影，钟盘刻度展开为 HUD，十字架横梁切成标题框架，舞者手臂轨迹成为文字笔画，月相缩成瞳孔高光，最后再回收到作品标题。前后状态必须共享轮廓、方向、节奏或语义，观众才能感到“原来如此”，而不是随机变形。

## 可剪辑接口

提供重拍停点、海报式完整构图、满屏色块、轮廓遮满、黑场 / 白场、同形母题、同方向擦除和纯声音桥。J cut 可让下一段音乐、钟声、祷告或机械声提前进入；L cut 可让上一段余响拖过新构图。作品标题和角色身份帧不得在尚未稳定时结束。

## 失败修复

- 像模板拼贴：减少装饰符号，只保留能证明身份命题的重复母题。
- 卡点机械：把变化组织成视觉短语，让建立、变体、升级和回收跨多个节拍发生。
- 画面很满但记不住：固定一个主锚点和 2-4 个母题，其他元素降级。
- 角色不断变脸变装：锁剪影、发型、服装结构、标志物和色彩职责，不要求每次完整露出。
- 字看不清：区分纹理字与承重文字，延长承重文字保持相位并降低背景运动。
- 平面风格变成廉价三维：恢复图层层栈、正交关系、硬边阴影和有限视差。
- Glitch 失控：只在身份切换、信息受扰或重拍断裂时短促使用，完成后立即恢复清楚构图。
- 音乐与画面各做各的：建立唯一声音时间轴和每个声音事件的唯一主变化。

## 迁移测试与反复制边界

机制应能迁移到舞曲 MV、古风演唱、游戏角色 PV、原创 OC 介绍、哥特符号短片、动画 OP、赛事视觉片、时尚概念片和标题序列。把人物换成物件、蓝色换成红色、游戏换成音乐或文化主题后，核心状态机仍应成立。

不得复制外部歌曲、歌词、角色、品牌、Logo、独特符号组合、文字内容、镜头顺序、精确时长和标志性特效皮肤。只继承音乐时间轴、视觉母题、动态海报空间、图形状态机和身份回收等底层机制。
