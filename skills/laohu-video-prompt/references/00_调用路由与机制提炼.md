# 调用路由与机制提炼

## 路由箴言

题材是外衣，机制才是骨头。

同样是广告，可能靠产品证明、人物关系、速度对比或图形解释成立；同样是国风，可能是文戏、动作、奇观、文化事实或纯视觉节拍。Reference 按“作品为什么会有效”选择，不按名词和风格标签配对。

## 用途

本文件负责把用户需求路由到最少的专业 Reference，并把当前需要吸收的案例拆成可迁移机制，而不是复制其表面形式。外部仓库的审计历史保存在研究记录中，不进入日常路由上下文。

## 路由算法

### 内容指纹

路由前先生成六轴内容指纹：`观众承诺 / 主导机制 / 空间语法 / 时间语法 / 证据方式 / 媒介物理`。

- 观众承诺：观众看完必须相信、感到或记住什么。
- 主导机制：效果由表演触发、力量接触、产品证明、节拍同步、图形推导、世界变化还是摄影机在场产生。
- 空间语法：真实三维空间、扁平二维版面、浅层 2.5D、分层舞台、严格 POV 或不断重组的图形空间。
- 时间语法：连续动作、触发后渐变、节拍事件、停格组装、状态机、拆解重组或快速标题序列。
- 证据方式：人物反应、接触结果、产品输出、数据关系、环境尺度、图形形变、文字 / UI 或声音连续。
- 媒介物理：真人摄影、赛璐璐、纸片、三维材质、动态图形、界面元素或多媒介混合怎样限制运动。

`10_画面内容镜头叙事语法.md` 是跨媒介的通用编译层。凡是需要镜头运动、主体动作、画面转化、VFX、声音、音乐卡点、卖点证明、表演转折或跨镜衔接的动态内容，默认使用它；静态单对象展示可以省略。它不决定主导机制，只负责把主导机制翻译成 `当前画面 → 摄影机路径 → 触发变化 → 可见 / 可听证据 → 停点 / 下一状态`。

选择主导机制时执行跨媒介适配：文戏优先检查人物目的、触发台词、反应和关系状态；动作优先检查蓄势、位移、接触和受力结果；广告优先检查用户问题、产品参与、卖点证据和利益兑现；动画 / PV / MV 优先检查轮廓、色彩、运动向量、视觉母题和音乐完成点；MG / 科普优先检查数据或对象的图形映射、变形规则和结论停点；特效奇观优先检查来源、传播、尺度、材质反馈和残局；POV / 纪实优先检查视点、路线、声源和现场反馈。这个适配层不创建新的题材分类，也不要求把所有专业词汇写进正文。

### 三类判定

1. `完全适配`：一个现有 reference 的机制与不变量覆盖主导机制，风格差异只需写进可变槽。
2. `组合适配`：一个主要 reference 覆盖主导机制，最多一个辅助 reference 只补声音、字效、局部特效、表演、速度节奏或剪辑接口。
3. `能力缺口`：现有 reference 只能覆盖局部，或套用后会把作品改成另一种空间、时间、证据或媒介逻辑。

禁止把局部覆盖提升为主要 reference，也禁止用两个辅助 reference 拼出虚假的主路由。没有匹配时不读取题材 reference，先写当前作品一次性机制卡。

### 缺口提案

能力缺口提案固定说明：内容主机制；最接近的现有 reference 能覆盖什么、缺什么；不新增时如何用一次性机制卡完成当前作品；建议的新 reference 名称、适用范围、核心不变量、与旧分类的边界、预计复用场景和维护成本。建议的新 reference 永久创建前必须得到老胡确认。

仅视觉风格变化不创建新分类；只有机制、空间语法、时间语法、证据方式或媒介物理形成可复用的新规律，才提出升格。

新分类名称必须使用稳定的观众任务和主导机制，不能使用单个案例的角色、颜色、题材、道具、软件或特效皮肤命名。提案先通过跨样本抽象测试：把人物换成物件或符号、把色板换掉、把游戏换成 MV / 文化 / 时尚主题后，核心状态机是否仍成立；再通过邻近边界测试：知识解释、产品证明、连续叙事或真实动作为什么不能被这个新分类误吸收。若第二、第三个同类案例暴露更高层共性，优先升级已有 reference 的内部机制分支，不为每种视觉锚点另建小类。

### 当前能力导航

先问“这一段最需要观众相信什么”，再检查是否存在主要 reference：

1. 相信人物此刻真的被某句话击中：`01`。
2. 相信力量、速度、接触和结果真的发生：`02`。
3. 相信产品解决问题并值得行动：`03`。
4. 相信音乐 / 声音、表演、视觉母题、文字和版面重排共同建立作品身份：`04`。
5. 相信抽象知识由可见图形机制推导出来：`05`。
6. 相信抽象知识由纸片物件、层级和组装顺序变成可触摸模型：`05A`。
7. 相信知识口播中的事实、机制、反差和结论被恰当的辅助画面证明，而且讲解者没有被辅助画面抢走：`05B`。
8. 相信不可能变化有阶段、有尺度、有不可逆结果：`06`。
9. 相信摄影机真实在场、路线连续、互动未摆拍：`07`。

`05B` 解决的是口播语义与证据编排，不负责固定画风。先把口播拆成命题、对象、机制、证据、反差和结论，再为每个节拍确定 `视觉职能 → 证据等级 → 进入 / 完成 / 退出 → A-roll / 声音接口`；随后只按主要证据职能选择最多一个实现层：数据与机制用 `05`，纸质隐喻与组装用 `05A`，真实现场与人物操作用 `07`，标题 / 音乐排版用 `04`。不能把所有 B-roll 都路由成 MG、多图蒙太奇或纸艺，也不能用两个局部视觉模块拼成虚假的完整适配。

速度与节奏执行横向判定：如果作品成败取决于谁在快、如何加减速、哪里蓄势与制动、动作和摄影机怎样错速、快切如何保持可读、跨镜运动怎样接相位，或文戏反应窗口怎样变化，主 reference 仍按上面八类选择，并把 `09_速度节奏与时间动力设计.md` 作为唯一辅助 reference。普通走路、单一推镜和不承重的背景运动不读取 `09`；不能因为题材是动作片或音乐存在就自动加载。

画面文字组织执行另一条独立的编译判定：如果正文出现作者解释、景别混用、镜头路径与屏幕变化脱节、人物移动缺少空间参照、VFX 没有来源、转场没有共同载体或句子像名词清单，读取 `10_画面内容镜头叙事语法.md`。它是跨题材的表达与镜头叙事层，不是新的题材主类，也不替代主要 reference；它不占用题材辅助名额。触发后必须先修复“可见画面 → 镜头路径 → 动作因果 → 屏幕结果 → 声音 / VFX 来源 → 停点 / 交接”，再进行压缩、风格增强或速度优化。

当用户要求电影感、电影正片感、导演 / 摄影参考、宽银幕叙事，或结果像海报、CG、游戏截图、滤镜套图时，在上述编译层中启用 `10_画面内容镜头叙事语法.md` 的“电影视觉母体转译”分支。它负责提取观众承诺、摄影机权限、空间压力、视线流量、光色来源、成像基底和时间证据的不变量，再把人物、地点、色板、媒介和动作作为可变槽；它不是独立题材 Reference，不强制 21:9、三联拼接、胶片颗粒或某位导演风格。删除“电影感”一词后，如果提示词仍保留机位、空间、事件、光色来源、成像限制和停点，才算完成转译。

混合任务按节拍拆，不按题材标签全加载。例如女武神“变身后战斗”：变身段主用 `06`，交手段主用 `02`；产品 PV 含三维机械剖面：全片主用 `03`，机制解释节拍辅用 `05`；知识博主讲财经趋势：全片先用 `05B` 确定哪些话需要事实图表、哪些只需情境插图，再按主要证据职能辅用 `05`，不能因为画面里有人和图表就同时加载 `07 / 05 / 04`。

## 机制卡写法

每次吸收新案例，内部建立一张机制卡：

```text
机制：观众体验由哪条因果链产生。
不变量：删除、换序或模糊后会失败的 3-7 个锚点。
可变槽：允许原创替换的主体、空间、材质、动作、摄影、声音。
三段式编译：哪些进入基础设定，哪些进入全局氛围，哪些逐镜变化。
失败修复：失败现象 → 根因 → 最小修复。
迁移测试：至少换两个题材，机制能否继续工作。
反复制边界：哪些独特表达绝不继承。
```

## 重点密度判断

提示词重点不是“重要词多写几遍”，而是形成少数高权重因果：

- 每条只设一个观众承诺。
- 每个镜头只完成一个新的状态变化或证据。
- 每个奇观只有一个主物理机制，辅效只证明它。
- 每个动作写到结果，不在接触前结束。
- 每个镜头给出可保存停点，不让模型平均分配注意力。
- 全局不变量上移，逐镜只写变化量。
- 每个镜头直接从可见画面开始；景别、运镜、动作和屏幕结果必须互相证明，不能让模型替作者补空间因果。

凡是删掉后不改变身份、空间、运动、情绪、声音、光影、结果或剪辑的句子，都是口水话候选。

`10_画面内容镜头叙事语法.md` 的最低迁移检查：把一个镜头中的人物、武器、材质和题材全部替换，仍能按照“谁在什么位置做什么、摄影机怎么观察、画面怎么变、结果怎么交接”重新生成，而不是只能复述原案例的动作名词。

## 迁移测试

机制入库前至少通过：

1. 换人物和地点仍成立。
2. 换视觉材质仍成立。
3. 换 9:16 与 16:9 后主因果仍可读。
4. 换图生视频与文生视频后只改变描述预算，不改变事件逻辑。
5. 删除外部案例专有名词后，仍能独立指导创作。

若只能在原案例的镜头顺序、材质和文案中成立，它不是机制，只是案例复述。
