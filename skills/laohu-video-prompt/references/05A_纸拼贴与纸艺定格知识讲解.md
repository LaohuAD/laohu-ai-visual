# 纸拼贴与纸艺定格知识讲解

## 触发条件与能力边界

用于把一句观点、一个知识点、一个因果过程或一组短口播转成纸拼贴 B-roll、纸艺定格科普、视觉隐喻讲解和知识型短片。它解决的是“抽象关系如何变成可触摸、可组装、可记住的物理模型”，不是给普通 MG 贴纸纹。

本文件只负责纸媒介专法。数据图表、一般 MG、三维解释和手绘真人融合的共同规则继续读取 `05_MG动态图形科普与混合媒介动画.md`；纸拼贴任务以本文件为主要 reference，必要时再把 `05` 作为辅助。

## 为什么这种方法有效

纸拼贴把知识关系外化为位置、层级、连接、遮挡、展开和装配，观众不必只靠语言在工作记忆中维持抽象关系。它的有效性来自四个可解释机制：

- `信号提示`：颜色、暖白描边、箭头、层级和运动顺序指出当前应该看哪里。
- `分段`：每个节拍只建立一个新关系，观众先看懂再进入下一步。
- `空间邻近`：标签、箭头和被解释对象保持邻近，减少来回搜索；不需要精确文字时优先让物件关系自己说明。
- `认知负荷控制`：只保留承担意义的物件组和材质证据，删除与知识无关的装饰、旧纸噪声和同时动作。

这些原则与 Mayer、Moreno 2003 年关于多媒体学习认知负荷的研究方向一致（`Nine Ways to Reduce Cognitive Load in Multimedia Learning`，DOI `10.1207/s15326985ep3801_6`），但“纸拼贴知识编译器”是本项目结合影视生成形成的工程方法，不冒充论文直接验证过的固定公式。

## 两种媒介模式

编辑纸拼贴与分层纸雕是两种媒介模式，不能混成同一套模糊“纸艺风”。先根据知识关系选择模式，再定构图和运镜。

### A. 编辑纸拼贴

适合观点、文学主题、社会关系、对比、情绪化知识和口播 B-roll。核心视觉是大色场、黑白半调照片剪影、选择性彩色卡纸、暖白边线、柔和纸影和 3-6 个大语义物件组。

空间以平面或浅 2.5D 层叠为主，摄影机通常稳定；运动来自纸片逐组出现、滑入、弹入、压平和锁定。它像一张编辑插画被现场组装，不做无意义大环绕、平滑数字缩放或复杂三维飞行。

### B. 分层纸雕剧场

适合结构、流程、尺度、生态、天文、机械和可分层知识。场景是 4-7 个真实纸平面组成的微缩剧场：前景遮挡、中景核心模型、背景环境、远景底板，层间有可见厚度、真实投影和视差。

运动来自滑轨、抽拉片、铰钉、关节、转盘、翻页、立体弹出和层间分离；摄影机可以缓推、横移、微距观察或轻俯视，但必须像在拍真实搭建的纸舞台。

### 模式选择

- 关系主要靠并置、对照、象征和编辑构图表达：选 A。
- 关系主要靠层级、因果、内部结构、路径和机械运动表达：选 B。
- 同一短片可以先 A 提出观点、再 B 解释机制，但切换必须由同一纸片、颜色或几何完成；不能每个镜头随机换纸艺类型。

## 知识到画面的编译器

每个知识段先在内部形成同一条链：`核心命题 → 动作动词 → 视觉隐喻 → 3-6 个语义物件组 → 最终解释帧 → 组装顺序 → 同期纸张音效 → 记忆停点`。

### 1. 核心命题

只写观众看完这一段必须记住的一句话。若一句里包含两个独立因果、三个并列结论或多个时间尺度，先拆段。

### 2. 动作动词

从知识中提取真正的关系动词，例如连接、分裂、泄漏、累积、压缩、筛选、替代、循环、放大、遮蔽、汇合、反转。动词决定纸片怎样运动，避免先选“翻页、弹入”等效果再硬套内容。

### 3. 视觉隐喻

视觉隐喻必须保留原知识的因果结构，而不是只保留题材名。`信息被层层筛选` 可以变成多层纸筛网；`成本被不断转嫁` 可以变成同一重物沿纸轨逐级推给下一个角色。若隐喻需要长文字解释才能成立，退回竞争 3-5 个新方向。

### 4. 语义物件组

默认使用 3-6 个大而易读的语义物件组。一个“组”可以含同类小件，但只承担一个语义职责：主体、阻力、路径、结果、尺度或反证。不要把 20 个碎纸片误当成信息丰富。

### 5. 关系拓扑

先画最终帧中的关系：谁在中心、谁连接谁、箭头指向哪里、什么被遮挡、哪个层级最高、哪里留下文字安全区。只有位置、层级、方向和颜色都承担意义时，观众才可能无旁白读懂。

## 结果帧先行

先设计最终解释帧，再倒推每个物件怎样进入。最终帧不是漂亮海报，而是这一知识段完整成立时的“关系证明图”。

结果帧先行的原因：

1. 防止动画过程很热闹，最后却没有清楚结论。
2. 让所有进入动作都有确定落点，不会漂浮或随机堆叠。
3. 为图生视频提供可靠尾帧 / 故事板锚点。
4. 给后期留下稳定可读的结论帧和剪辑出口。

倒推顺序：`最终关系 → 最后一个必要证据 → 它依赖的前一关系 → 起始空色场 / 基础纸层`。若某个物件在最终帧中没有语义职责，也没有承担转场，删除。

## 停格组装语法

单个语义物件组使用可读的触感相位：`出现或纸片滑动 → 弹入 / 移至目标 → 轻微回弹 → 压平 → 暂停 → 锁定`。多个组按知识因果依次装配，不整体淡入，不同时飞散。

### 编辑纸拼贴组装

从与最终帧一致的干净主色纸场开始。先入基础关系或大轮廓，再入主体与阻力，最后入箭头、结果和强调片。摄影机保持稳定，让纸片动作承担叙事。

### 分层纸雕组装

先建立舞台底板和深度层，再让滑轨、转盘、抽拉层或立体书机构逐级改变关系。前中后景运动速度不同，形成真实视差；每次机关完成后短暂停住，让观众确认新状态。

运动幅度服从纸片物理：短距离分段移动、关节绕铆钉旋转、滑片沿轨道平移、纸层沿折线展开。避免液态融化、弹性橡胶形变和没有机械来源的丝滑 CG 运动。

## 文字、数字与口播

“不用文字也能理解”是隐喻质量测试，不是所有知识片的禁字令。执行三档策略：

1. 关系能由物件和动作证明：不加文字。
2. 专有名词、关键数字或类别必须准确：只保留最少文字，用中文双引号锁定，放在稳定纸卡层并留出阅读停点。
3. 复杂论证必须靠长句：画面只证明结构，完整解释交给既有口播 / 旁白；不得把整段口播烧成画面文字。

用户已有口播时保留原文，把纸拼贴作为同步或错位补充证据，不擅自新增旁白。没有口播时，根据任务决定纯视觉、字幕或旁白，不继承官方示例“默认无旁白”的产品设定。

## 色彩、材质与构图

色彩按角色职责设计：基底色建立统一，主体色锁主命题，强调色只标记变化或反证。项目不固定颜色与语义的对应关系；橙色不天然等于紧迫，墨绿不天然等于认知，必须由当前题材、色卡和上下文决定。

编辑纸拼贴可使用半调照片剪影、干净未涂布纸纤维、细微撕边、层叠接缝、暖白描边和软纸影。分层纸雕要强调卡纸厚度、折痕、切边、铆钉、滑轨、层间间距与真实投影。

纸张要有触感但不能喧宾夺主。过旧、过脏、泛黄、重皱和随机污渍会增加视觉噪声；除非知识主题需要历史档案感，否则保持干净可读。

不继承官方示例默认的 16:9、4 秒和固定色彩语义。画幅服从平台，时长服从知识可读时间，色彩服从本作品色卡与信息职责。

## 声音语法

同期纸张音效是材料真实性和节奏提示，不是装饰音效包：

- 滑入对应纸片摩擦和方向。
- 弹入对应短促轻响。
- 压平对应低而短的纸面轻敲。
- 翻页、抽拉、转盘、铰链各有不同摩擦长度和瞬态。
- 锁定后留短暂安静，让关系被看懂。

声音层级默认是关键口播 / 旁白优先，其次知识承重纸张音效，最后才是 BGM。纯 B-roll 可只保留纸张音效；有旁白时压低纸声但保留动作触感；BGM 不得覆盖纸机关完成的重音。

## 三段式编译

- `【基础设定】`：画幅、确定时长、生成方式、实际静帧 / 色卡 / 角色资产、媒介模式、文字与声音策略。
- `【场景状态与氛围画质】`：统一纸材、主色场、成像基底、层间投影、镜头稳定度和批次连续性。
- `【画面内容】`：从起始纸场到最终解释帧，逐语义物件组写进入相位、空间落点、知识变化、同期音效、保持时间和结束状态。

若使用图生视频，已确认静帧负责最终关系与材质，正文重点写倒序组装如何到达该帧；若文生视频，必须补齐语义物件组、关系拓扑、纸材结构和最终构图。

## 可剪辑接口

每个知识段至少提供：干净起始纸场、一个满屏纸片 / 翻页遮挡点、机关完成重音、最终解释帧稳定停点。相邻段可用同色纸场、同一纸片、同形箭头、翻页、抽拉或纸声 J cut 连接。

最终帧应稳定到足以阅读，不在最后一刻继续新增物件；需要循环时，让最后一个纸片动作反向触发基础色场恢复，但不能破坏结论帧的可读停留。

## 质量门与失败修复

- 隐喻必须在去掉标题后仍能说明核心关系；否则重做动作动词和视觉隐喻。
- 画面过碎：减到 3-6 个语义物件组，扩大主关系。
- 像普通 MG 贴纸纹：选择 A 或 B 模式，并让纸材结构真正限制动作。
- 像平滑数字图层：恢复出现、回弹、压平、暂停、锁定的停格相位。
- 最终画面没有结论：先重做最终解释帧，再倒推组装。
- 文字太多：把关系交还给物件和动作，只锁专名与数字。
- 纸雕没有空间：补 4-7 层、层间投影、前景遮挡和视差。
- 音效热闹：只保留与真实纸片接触同步的声音，并在结论处制动。
- 色彩像套模板：按当前信息职责和色卡重分配，不使用固定颜色语义表。

## 迁移测试与反复制边界

同一方法应能迁移到 AI 工作流、金融传导、生态循环、人体结构、历史观点和文学主题。迁移时保留“动词、语义物件组、最终解释帧、触感组装和记忆停点”，重新设计隐喻、纸片、颜色、构图、文字和声音。

不得复制 MiniMax 官方案例的固定半调人物、色板、场景、物件组合、逐段顺序、英文风格签名和完整提示词；官方仓库本轮未发现根目录许可证文件，因此只独立改写底层机制和质量判断，不搬运长文本。
