# 段内摄影与空间连续性

接收P执行卡后读取。人物世界位置、叙事观看限制与事件次序来自剧本，摄影机、画框入口和切镜由视频负责人建立；若摄影无法实现既定事件，返回具体缺口，不改戏。C仅在每个P内连续编号；剧本不要求镜号方头。

## 画面关系与观看位置

正式剧本先建立空间，再描述画面。它不默认写精确设备坐标，却必须让三层关系同时成立：

```text
世界层：人物、道具和固定锚点在场景中的真实方位、距离、朝向、进入路径与接触关系。
摄影机层：摄影机位于人物关系轴线的哪一侧，视轴朝向哪里，景别允许看见多大范围；固定还是沿哪一条连续方向变化。
画面层：在这个观看位置下，谁落在画面左中右、前中后景，谁遮挡谁，眼线和运动方向如何投影。
```

“老胡站在圆台右侧”是世界位置，不自动等于“老胡位于画面右后方”；只有摄影机观看侧与视轴确定后，世界位置才能投影成画面位置。换机位可以改变左右与前后景投影，不能无过程地改写人物在世界中的真实站位。

空间验收顺序固定为：`世界位置 → 摄影机观看侧 / 视轴 → 画面左中右与前中后景`。任一箭头无法解释，镜头仍未闭合。

这套三层空间用于真人、实拍与三维空间。二维动画、MG、UI和字幕动效没有真实世界站位时，用`信息拓扑 → 视窗 / 版式观看范围 → 屏幕层级与焦点`完成同一职责：一个单点细节画面不能同时证明完整系统关系，视窗缩放、遮罩展开、图层前后移或版式重排可以在同一连续动画内承担有先后的信息节拍；实际切换画面或时空不连续才新建镜号。不能为了统一术语，给二维内容强造摄影机和地面轴线。

视频负责人为每个复杂多人镜头写正文前先形成`镜头继承合同`：

```text
本镜唯一主观看任务：观众只等待哪一项变化。
开镜状态：开拍时已经成立的人物、道具、光线、声音与动作预备态。
世界位置：每个承重对象相对门、圆台、桌、墙、道路等固定锚点在哪里。
摄影机观看侧与视轴：从人物关系轴线哪一侧、朝哪个方向看；是否固定。
开镜画面投影：实际入画者、画面左中右、前中后景、身体朝向、视线与遮挡。
允许的连续变化：人物怎样走、转、靠近、离开或进入画框；摄影机若移动，沿什么连续方向改变观看关系。
镜尾状态：谁仍在画内、停在哪里、持有什么、朝向哪里，空间 / 身体 / 道具 / 声音发生了什么不可逆变化。
下镜第一项新变化：下一镜从哪个新证据或下一动作相位开始。
```

合同用于视频分镜与执行，不要求把字段表机械贴进每个简单镜头。正文仍以自然、可见的动作语言承接；只有会影响读者理解、资产设计、段内编译或视频执行的事实才显式写出。

每镜根据需要写清：

- `实际出画 / 画外`：谁在画面里，谁只有声音。
- `世界位置`：人物或道具相对固定场景锚点在哪里，不因换机位自动变化。
- `摄影机观看侧 / 视轴`：从关系轴线哪一侧、朝什么方向观看；只写足以消除投影歧义的粗粒度关系。
- `画面位置`：在当前观看侧下，人物或道具处于左、中、右和前、中、后景的哪一层。
- `身体朝向`：正面、侧身、背对、转向某人或某物。
- `视线对象`：看向谁、监视器、遥控器、灯或画外的哪个方向。
- `遮挡`：谁挡住谁，门框、肩膀、监视器或其他物件限制了什么信息。
- `关系距离`：人物之间隔着什么，能否直接触碰，谁向谁靠近或退开。
- `入画 / 退出`：新出现的人物原本在哪里，从哪个画框边缘沿哪条世界路径进入；退出时去向哪里。
- `关系变化`：本镜结束时出画、持物、距离、朝向、视线或空间状态与开始相比发生了什么变化。

双人或多人动作段落建立人物指代锚点：每个新动作段第一次出现人物时先写具体名称；同一人物连续行动时才用“她／他”；叙述主体切换、段落重开、遮挡改变或第三人加入时，重新写具体名称。正文不能让一个没有明确先行词的“他／她”承担递交、攻击、受力、看向或退让等承重动作。

不必写“摄影机高1.4米、离圆台2.7米”这类无叙事价值的设备数值；但不能只靠“左前景 / 右后景”假定机位已经成立。方头至少写清摄影机在人物关系轴线哪一侧、朝哪里看，再用构图栏检查画面投影是否与世界站位一致。例如：`【C01｜双人中景｜运镜：固定镜头｜机位：圆台南侧，朝北看向双人横轴｜构图：Luna左前景、老胡右后景，监视器居中｜约5秒】`。POV、过肩、俯拍、仰拍、门口限制视角或反射视角写在机位栏；身体朝向、视线、进入路径和动作后的新状态留在正文。

方头既不能少到让读者进入正文后才发现观看方向，也不能长成完整视频提示词。简单镜头每栏用一个短语；复杂长镜头的机位栏只写起点观看侧，运镜栏写连续方向，构图栏用`起始 → 决定性 → 结束`概括主重构。若观察位置无法从起点连续到达终点，必须新建镜号。

### 固定镜头、人物入画与景别证据边界

`固定镜头`只表示摄影机位置、视轴和构图边界不变，不表示演员不能移动。固定镜头中人物可以进入、退出、转身或靠近，但正文必须选择一种成立方式：

- 人物从开镜起已经可见：在开镜构图中先写明他处于哪个画面层级。
- 人物由画外进入：写明他原本在什么世界位置，从画框哪一侧沿什么路径进入，进入后停在哪里。
- 人物始终不入画：使用 O.S.，只让声音和画内人物反应承担关系。

固定近景先说“主持人的脸占据画面中心”，随后直接说“助手位于画面右后方”，却没有声明助手开镜已在后景、从右侧入画或构图怎样变化，这不是省略，而是空间合同断裂。最小修复通常是保持助手 O.S.，把他的露面放到新双人镜头；只有开镜就设计成可读的双人纵深构图时，才可同镜保留。

景别是证据边界，不是装饰名称：

- 特写 / 近景主要证明单一局部、脸部和有限上半身关系，不能同时证明远处完整空间与全身结果。
- 中景主要证明身体动作、人物距离和局部环境锚点。
- 中远景 / 全景主要证明完整位移、多人拓扑、破坏范围和人物与环境的关系。

同一镜头需要跨尺度时，必须由基础运镜和正文共同证明是一次连续可达的推近、后拉、横移、环绕或焦点迁移；新尺度可以揭示下一信息节拍，仍保留连续镜号；实际剪切或无连续可达路径时另建镜号，不能用“近景转全景”掩盖跳跃。

## 单镜号边界

单镜号的参考时长由表演节拍和完整动作决定；历史十五秒只作旧任务参考，不是通用上限。它必须满足：

- 只有一个主要画面内容和一项主变化；剧情上属于同一段，不等于视觉上属于同一镜。
- 至少有一个可被拍到的开始状态和结束状态。
- 台词、旁白、同期声不能和画面互相抢。
- 情绪变化要能被脸、手、呼吸、视线或身体距离看见。
- 世界位置、摄影机观看侧 / 视轴和画面投影必须同时成立。
- 固定镜头中新人物入画必须有起始位置、画框入口和连续路径；开镜已在画内则先声明。
- 实际插入画面、主客观切换、正反打、硬切、软切、时间跳跃或无法连续到达的观看位置需要新建镜号。新的反应、拉焦或逐步揭示若仍服务同一整体观看目的，且摄影机观看连续可达，保留同一镜号；两个互相争夺的主要观看任务先调整主次或拆镜，不能仅因注意对象改变就拆镜。

摄影镜头常见类型：

| 类型 | 适用 |
|---|---|
| 动作起点镜头 | 人物开始移动、伸手、转身、发现异常 |
| 情绪反应镜头 | 角色听到信息后的表情和身体变化 |
| 道具信息镜头 | 关键道具被看见、触碰或揭示 |
| 关系变化镜头 | 两个人靠近、远离、对峙、沉默 |
| 结尾钩子镜头 | 留下悬念、反转或最后一帧记忆点 |
