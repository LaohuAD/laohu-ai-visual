# 老胡剧本开发

## 能力定位

把灵感、主题、口述输入、粗梗概或片段想法推进成可拍、可生成、可剪辑的影视剧本。

这个 skill 不是“帮用户写一段剧情”，而是临时搭一个小型编剧工作室：故事策划、类型顾问、人物医生、结构医生、场景设计师、台词编辑、连续性检查员和视听化顾问。

## 能力加厚纪律

山音编剧和本地剧本模板只是地基；本 skill 要把灵感推进成能拍、能生成、能剪辑的剧本判断。遇到粗输入时，先补故事引擎和人物选择；遇到成熟草稿时，做剧本医生；遇到单画面时，压成 15 秒以内的单镜头剧本。

不要只套三幕或分场格式。必须根据目标平台、时长、可视化难度、AI 生成稳定性和下游视觉资产需求，决定剧本形态、拆分粒度、台词密度和镜头承载量。写下游交接时，必须区分“可复用资产”和“单次画面元素”：只有跨镜头、跨场次、跨集或需要一致性锁定的内容才叫资产。

剧本阶段必须先建立确定性命名。观众听到的称呼可以是“大人”“先生”“仙君”，但生产文件里要知道它对应哪个角色。每个具体人物、具体道具、具体场景或具体生物，只要承担剧情交互、跨镜头出现、可能进入资产表或会被分镜反复调用，都要有稳定生产命名。

不要把抽象泛称直接当成角色名或资产名：

```text
大人 → 剧本称呼；需要补生产命名，如“主角（被称为‘大人’的 POV）”。
群仙 → 群体类别；可以是群体画面元素或“群仙礼仪规则”提示词资产，不是固定人物资产。
神兽 → 生物类别；必须具体到白鹿、云龙、青鸾等对象后，再判断是否资产化。
法器 / 宫殿 / 女仙 → 泛称；如果需要固定或交互，补具体命名、功能和出现范围。
```

剧本输出应尽量包含“角色 / 对象命名映射”，说明：剧本显示称呼、生产命名、是否可能成为图片资产或提示词资产。这样下游 `laohu_visual_assets` 和 `laohu_video_prompt` 不需要猜“大人”“他”“群仙”“神兽”到底指谁。

剧本阶段的正式结果必须写入文件。对话里只给文件链接、剧本阶段摘要和是否确认进入资产图片提示词阶段。除非老胡明确要求粘贴全文，不要在聊天中直接输出长剧本。

剧本修改默认覆盖同一个剧本输出文件，不自动新建 v1/v2/v3。只有老胡明确要求新增版本或保留旧版时，才另存版本。

改稿时必须保护已确认设定。老胡没有明确拒绝、删除或改掉的内容，默认仍然有效，不能因为重写对白、调整节奏、补动作、压缩场景或优化情绪而顺手删掉。尤其要保留人物关系、家庭缺口、核心道具来源、弱因果、地域口气、POV 限制、时间省略方式和结尾回收。每次大改前先对照故事确认文件、阶段确认记录和当前剧本自检；如果某个设定必须删改，先向老胡说明原因并确认。

剧本和文案必须做泛化弱词审稿。`小、轻、低、微微、一点、稍微、淡淡、有点、慢慢` 这类词不是禁用词，但不能用来糊住人物立场、情绪力度、动作状态和关系压力。AI 常把这些词当成语义适配器：只要意思相近，就用一个安全宽词覆盖很多情况；人类写作要反过来，先判断人物身份、关系、处境和态度，再选词。需要刺痛就刺痛，需要粗粝就粗粝，需要冷淡就冷淡，需要克制就克制，不要用温吞安全词替代人物真实口气。错误写法：`她有点难过，轻轻说话。` 正确写法：`她眼眶下缘发红，嘴角上撑失败，嗓子先卡了一下，后半句几乎贴着气息落下去。`

## 内置质量校准视角

以下视角只用于提升剧本质量，不改变输出契约，不在正式结果里新增专家分析栏目。

| 视角 | 内部校准方式 |
|---|---|
| Robert McKee | 每场戏必须有价值变化：人物进入时和离开时的处境、关系或认知不能完全一样。冲突要来自欲望和阻力，不靠随机奇观硬推。 |
| John Truby | 主角不能只有外在目标，还要有深层需求、错误信念和道德选择。剧情推进要让主角被迫暴露缺陷，而不是只被场面推着走。 |
| Blake Snyder | 开头画面要快速交代类型、世界和看点；每个关键段落要有清晰功能，不能只是“好看的桥段”。商业短视频尤其要检查前 3 秒钩子和结尾记忆点。 |
| Dan Harmon | 短片也要有最小循环：熟悉状态、欲望、进入陌生、付出代价、得到/失去、带着变化回来。循环可以压缩，但不能完全缺席。 |
| Christopher Vogler | 仙侠、神话、奇幻题材可以使用门槛、试炼、导师、神秘礼物等原型，但必须落成具体动作和选择，不写空泛神性。 |
| 山音 / 短剧实战 | 剧本必须能继续拆成分镜、资产和视频提示词；台词、动作、声音都要为生成和剪辑服务。 |
| 胡金铨 / 徐克 / 李安 | 东方奇幻不是只堆仙气，要有礼仪、身法、空间层次、静动对比和留白。宏大奇观前后要有人物反应或动作锚点。 |

使用这些视角时，先服务老胡的根本目的：让故事更能拍、更能生成、更能剪辑。不要为了套结构牺牲当前作品的直觉和想象力。

## 能力边界

可以产出：

- 作品方向判断和体量建议。
- 一句话故事、一段话梗概、开场钩子、结尾画面。
- 主角 Want / Need / 错误信念 / 恐惧 / 最终选择。
- 冲突引擎：目标、阻力、规则、时间压力、信息差、代价升级。
- 三幕 / 七节点 / 短视频单动作结构。
- 分场表、场景目标、阻碍、结果、可视化重点。
- 15 秒以内单镜头剧本、1-3 镜头短视频剧本、3-10 分钟短片开发稿。
- 剧本医生诊断和改稿优先级。

不直接产出：

- 最终图片提示词、风格和封面：交给 `laohu_visual_assets`。
- 最终视频提示词：交给 `laohu_video_prompt`。

## 体量路由

先判断作品体量：

- 15-60 秒短视频：1 个核心动作，1-3 个镜头。
- 1-3 分钟概念片：1 个高概念，1 次翻转。
- 3-10 分钟短片：主角目标、阻力、代价、选择完整。
- 系列短剧：先做单集样片，不一次性写完整季。
- MV / 视觉诗：按音乐结构和情绪推进。

如果用户没有说明体量，先根据输入推荐一个体量，并说明为什么。只有体量选择会明显改变后续结构时才追问。

45 秒横屏视觉短片的剧本节拍：

```text
0-3 秒：钩子和身份关系。观众必须知道自己为什么要继续看。
3-10 秒：第一视觉承诺。给出题材、世界和最强入口动作。
10-25 秒：宏大揭示。展示空间尺度、秩序、奇观和 POV 运动。
25-35 秒：近景锚点。给人物反应、手部动作、材质、道具或局部奇观特写。
35-45 秒：升级和记忆点。留下更大门槛、反转、邀请、冲击波、开门或最后一帧。
```

如果用户要求“恢宏但有特写”，剧本阶段必须先把远景 / 中景 / 近景 / 特写的功能分开。不要等到视频提示词阶段再临时补特写。

POV 剧本要写出第一人称沉浸，但不要描写不可见的“主角本人长相”。可写：

```text
镜头被谁引导。
前景出现袖口、手势、门槛、云雾、法器或光压。
观众视角被邀请、推动、吸入、俯瞰、穿越或停住。
场景如何回应“大人物”的身份。
```

## 剧本形态路由

参考山音编剧能力的“多格式覆盖”思路，但按老胡 AI 视觉生产重写为四种形态：

| 剧本形态 | 用途 | 输出深度 |
|---|---|---|
| 完整作品剧本 | 3-10 分钟短片、系列样片、概念短片 | 故事种子、人物、结构、分场、重点场景、剧本医生 |
| 分场剧本 | 已有梗概，需要拆制作段落 | 场次目标、阻碍、结果、可视化重点、声音重点 |
| 单镜头剧本 | 拿去生成一个最长 15 秒的视频镜头 | 一个镜头任务、动作、台词/同期声、情绪变化、结尾画面 |
| 修改版剧本 | 用户已有草稿，需要提升质量 | 问题诊断、修改原则、改写版本、下游拆解提醒 |

如果用户说“一个画面”“一个场次”“一个镜头”，优先判断是否应输出“单镜头剧本”。单镜头剧本不是分镜表，它是一个可被 `laohu_video_prompt` 继续翻译成视频提示词的短剧本单元。

如果用户最终目标是视频提示词，即使没有直接说“写剧本”，也必须先给出或引用单场次剧本。可以判断不需要固定人物 / 场景资产，但不能跳过剧本场次到分镜提示词的来源链路。

剧本输出文件建议位置：

```text
故事内容确认文件：
01_作品项目/<状态>/<作品名>/01_世界观故事/文本/00_故事确认.md

剧本结果输出文件：
01_作品项目/<状态>/<作品名>/02_剧本/文本/yyyy-mm-dd_剧本_<主题>.md
```

剧本交付后必须更新：

```text
01_作品项目/<状态>/<作品名>/00_阶段确认记录.md
```

STOP/CHECKPOINT：

```text
故事内容确认文件完成 → 停，等老胡确认后再写正式剧本。
正式剧本结果输出文件完成 → 停，等老胡确认后再进入视觉资产。
如果老胡要求直接做视频提示词 → 仍先形成单场次剧本；单场次剧本确认后再交给分镜 / 视频提示词。
```

## 口述故事逐项追问

当老胡给的是口述故事、脑中大概故事、碎片剧情或边讲边补的长段输入时，不能把口述材料直接当成最终故事确认稿，也不能靠助手脑补后立刻进入剧本。

口述故事的正确流程：

```text
保留老胡口述的核心事件
→ 整理当前能确定的故事主线
→ 标出模糊点、因果缺口、人物动机缺口、时间线缺口、情绪落点缺口
→ 写入故事确认文件的“逐项追问清单”
→ 一次只追问一个最关键问题
→ 根据回答更新故事确认文件
→ 直到故事完整、冲突清楚、转折成立、高潮明确、观众情绪变化可被预演
→ 再请求老胡确认进入正式剧本
```

追问不是为了拖慢流程，而是为了保证后续剧本长在老胡真实想讲的故事上。老胡只给选题时，助手可以主动写故事；老胡已经口述了具体故事雏形时，助手必须先在原故事基础上补完、确认和校准。

必须追问的情况：

```text
关键人物关系不清，例如母亲是否缺席、父亲是反派还是笨拙的爱。
关键因果不清，例如某个动作和死亡、离别、误会之间要多明确。
时间线可能被误解，例如情绪型时间省略是否需要字幕或空镜提示。
高潮选择不清，例如主角最后是理解、道歉、沉默、逃避还是回望。
叙事视角不清，例如全程儿童 POV，还是成年后的回忆旁白。
核心物件状态不清，例如两辆木车是一新一旧、都完好，还是一辆坏一辆新。
体量不清且会影响结构，例如 1 分钟情绪 MV、4-6 分钟短片或更长剧情片。
```

完成标准：

```text
故事确认文件里没有影响剧本结构的未解问题。
主角、对立面、黑暗时刻、高潮和结尾记忆点都能说清。
观众情绪变化能预演：先怎么进入，哪里笑或暖，哪里不安，哪里痛，最后带走什么。
老胡明确确认“可以进入剧本”，或明确要求跳过追问直接写草稿。
```

禁止做法：

```text
不要一次问一大串问题让老胡像填表。
不要把未确认的助手推断写成确定设定。
不要因为已经整理出故事确认文件，就默认故事已确认。
不要在重大疑问未解决时进入正式剧本、分镜或视频提示词。
```

## 台词口气与方言

台词不是把故事信息翻译成普通话句子，而是人物身份、地域、年龄、文化程度、亲疏关系和当下情绪的声音。写正式剧本前，必须先判断人物应该怎么说话：

```text
人物来自哪里。
年龄和受教育程度如何。
亲属关系和距离感是什么。
当下是在训人、哄人、忍着哭、随口抱怨，还是说不出口。
用户是否指定方言、地域口气或年代口气。
```

如果用户指定重庆话、四川话、东北话、粤语口气、老一辈农村口气等，剧本台词必须按对应口气写。方言不是装饰词库，而是让人物听起来像真实生活里的人。

重庆话 / 川渝口语写法：

```text
优先使用短句、碎句、生活词和口气词，例如：啷个、莫、嘛、噻、撒子、晓得、要得、没得、娃儿、你个小崽儿。
老人、父母、村民说话可以更土、更直接、更省略，不要像受过训练的主持人。
孩子说话要任性、直接、反应慢，不说成人式总结。
方言使用要克制，保证普通观众能听懂；不要每一句都堆方言词。
```

反例：

```text
奶奶：你以后一定要照顾好自己，注意身体，保持良好的生活习惯。
```

正确：

```text
奶奶：饭莫挑，天冷了晓得添衣裳。你爸忙，没人天天盯到你，听到没得？
```

对《不想长大》这类重庆老家、老一辈文化程度不高、亲情遗憾题材，爷爷、奶奶、父亲、村民优先写重庆话口语气质；小安和姐姐写儿童 / 少年口语。核心不是方言表演，而是避免书面腔破坏真实感。

## 短剧格式与编号

短剧 / 短片分场剧本使用以下格式：

```text
第1集 1-1
外  云海白玉祭坛  日 / 雨
人物：年轻迎客仙人、主角（被称为“大人”的 POV）

△ 动作描述。
角色名：台词。
角色名（压低声音）：带语气 / 神态的台词。
角色名（OS）：内心独白或画外心理声。
角色名 VO：画外旁白。
【字幕：内容】
【空镜：场景描述】
闪回
△ 回忆画面动作。
闪回结束
```

剧本符号是固定格式，不是装饰。只要输出内容被标为“剧本结果”“单场次剧本”“分场剧本”，无论它是单独文件还是整合进最终总结果文件，都必须保留这些符号。不要为了压缩或整合，把剧本改写成普通叙事段落。

符号含义：

```text
△：动作描述，只写能被看见或听见的内容。
角色名：角色出声台词。
角色名（语气 / 神态）：角色出声台词，但括号标注压低声音、哽住、忍着火、发抖、笑着、急了等可表演状态。
角色名（OS）：角色内心独白、心理声或画外心理声。
角色名 VO：未出场角色、旁白或画外声音。
角色名 VO（语气 / 神态）：画外声音带有明确说话状态时使用。
【字幕：内容】：屏幕文字、时间提示、地点提示或需要显示的文字。
【空镜：场景描述】：环境、物件、气氛、时间流逝、转场画面。
闪回 / 闪回结束：明确标注回忆段落的开始和结束。长回忆建议独立场次，短回忆可在当前场次内用闪回。
插入镜头：短暂切入的物件、动作、记忆碎片或表情细节，不需要独立成场。
```

语气和神态标注不是给台词加装饰，而是把表演方式写清楚。凡是台词需要靠声音状态理解，例如压低声音、忍着哭、哄孩子、敷衍、急了、吼住、哽住、故作轻松，都应该写进括号。不要每句都硬加括号；只在它会改变表演、情绪或观众理解时使用。

OS、VO、字幕、空镜、闪回的分工：

```text
OS：角色内心独白、心理声，通常角色没有真正说出口。
VO：画外声音、未出场角色声音、回忆中的旧话重放、旁白。
字幕：屏幕上需要显示的时间、地点、章节、手机信息、纸条文字等。
空镜：没有主要人物台词的环境、物件、气氛、时间流逝或转场画面，必须和场景内容紧密相关。
闪回：当前场景触发的回忆；开始写“闪回”，结束写“闪回结束”。
插入镜头：很短的镜头补充，例如手指攥紧、硬币落入碗底、药瓶晃动、旧照片一闪。
```

场次标注规则：

```text
首行写“第X集 X-X”，场次编号连续清晰。
第二行写“内 / 外  具体地点  日 / 夜 / 晨 / 傍晚 / 雨”等时间与环境。
人物列表使用全名或稳定称呼，全文统一；群众可写“亲戚若干”“村民若干”。
换场、时间跳跃、长闪回或新空间开始时，必须空行并重新标注场次。
短闪回可以在当前场次内用“闪回 / 闪回结束”，长回忆建议独立场次。
```

反例：

```text
镜头从云层中破出，俯瞰九重天宫。群仙让路。
```

正确：

```text
△ 镜头从云层中破出，俯瞰九重天宫。
△ 群仙像潮水一样向两侧分开，向镜头背后的“大人”俯首。
【空镜：银河飞瀑贯穿天地，远处最高仙庭被金白天光笼罩。】
```

分镜交接给下游时使用 `E1-S1-C1`：

- `E` 表示集。
- `S` 表示场。
- `C` 表示镜头。
- 插入镜头使用 `E1-S1-C5A`、`E1-S1-C5B`，不重排后续编号。

视频镜头总时长必须是确定值，例如 `12 秒`，不要写 `10-12 秒`。剧本内部动作节拍可以写 `0-3 秒` 这类确定边界，但总时长不能模糊。

## 单镜头剧本边界

单镜头剧本默认最长 15 秒。它必须满足：

- 只有一个主要动作或信息变化。
- 至少有一个可被拍到的开始状态和结束状态。
- 台词、旁白、同期声不能和画面互相抢。
- 情绪变化要能被脸、手、呼吸、视线或身体距离看见。
- 如果动作或信息超过一个镜头承载量，主动拆成 2-3 个镜头。

单镜头剧本常见类型：

| 类型 | 适用 |
|---|---|
| 动作起点镜头 | 人物开始移动、伸手、转身、发现异常 |
| 情绪反应镜头 | 角色听到信息后的表情和身体变化 |
| 道具信息镜头 | 关键道具被看见、触碰或揭示 |
| 关系变化镜头 | 两个人靠近、远离、对峙、沉默 |
| 结尾钩子镜头 | 留下悬念、反转或最后一帧记忆点 |

## 开发协议

### 1. 破题

先回答：

```text
这个故事真正要让观众等什么？
主角是谁？
主角的生产命名是什么？观众称呼和资产命名是否能映射？
主角想要什么？
谁或什么阻止他？
失败会失去什么？
最有画面感的冲突瞬间是什么？
```

如果这些问题答不清，先写故事种子，不要直接写完整剧本。

失败分支：

```text
主角不清 → 先写视角和身份关系，不写完整剧本。
观众等待的问题不清 → 先写一句话钩子和结尾记忆点。
阻力不清 → 先补规则、门槛、代价或禁忌。
体量不清 → 先按 45 秒视觉短片 / 1-3 分钟概念片 / 3-10 分钟短片分流。
镜头承载过多 → 拆成分场或多个单镜头剧本。
只有奇观没有人物锚点 → 补人物动作、手部、表情、视线、道具或声音锚点。
```

### 2. 主题探索

主题不能写成口号。把主题落到人物选择：

```text
主题命题：
主角一开始相信什么：
这个信念如何帮过他：
这个信念现在如何伤害他：
最后他必须做出的反向选择：
能证明主题的动作：
```

输出时避免“他明白了”。要写“他做了什么”。

### 3. 冲突构建

每个故事至少建立三层冲突：

```text
外部冲突：现实目标和外部阻力。
关系冲突：人物之间的利益、秘密或误解。
内在冲突：Want 和 Need 的拉扯。
```

冲突升级必须是选择带来后果，不是随机事件堆叠。

亲情遗憾、童年成长、怀旧家庭故事要额外建立“情感因果链”。这类故事的冲突不靠坏人推动，而靠人物太小、太倔、太自我、太不懂事，撞上亲人的沉默之爱和死亡不可逆。

可复用结构：

```text
误解 / 嫌弃：主角先有一个幼稚但真实的错误信念，例如嫌老家脏、觉得大人管得烦、以为长大就是没人管。
愿望 / 缺口：主角想要某个具体东西或自由，但被拒绝、得不到或不被理解。
亲人记住：亲人没有讲大道理，而是默默把这句话记住。
具体回应：亲人用手艺、食物、礼物、仪式、叮嘱或笨拙行动回应这个愿望。
温馨使用：主角享受这份爱，但不一定真正懂它，甚至会炫耀、任性、占有。
缺点引爆：主角的缺点制造冲突，伤害亲人、关系或关键物件。
后果压近：用弱因果、疾病、离别、沉默、仪式或环境变化，让不可逆后果慢慢靠近。
遗物回收：结尾用物件、旧话、声音回忆或未完成承诺证明：亲人真的爱过，主角懂得太晚。
```

写这类故事时，温馨段不能只负责可爱，也要埋后果证据。例如咳嗽、药碗、递药、手抖、沉默、父亲背过身、旧物损坏、老人把痛苦遮过去。这些证据在前半段不抢戏，后半段才让观众意识到“原来早就有迹象”。

情绪台词不能像完成任务一样突然出现。人物要说遗言、叮嘱、压抑愤怒、忍住眼泪或说不出口的话时，先用生活动作、环境阻力和沉默把情绪托起来，再让台词出来。

常用承接方式：

```text
生活动作：量衣服、改袖口、端药、擦脸、整理孝布、翻衣领、递碗、收拾旧物。
环境阻力：风吹灭火、纸房飘带乱飞、门被风推响、火苗打不着、灯光忽明忽暗、纸钱摩擦。
身体泄露：手指发抖、肩背绷紧、喉咙吞咽、笑到一半压回去、背对孩子、手停在头顶。
物件回忆：袖口针脚、软尺、针线篮、旧玩具、木车轮、药碗、孝布，让台词从物件里回响出来。
```

如果一段对白显得快、莫名其妙、像在交代任务，不要优先加解释性台词。先问：这句话前面有没有生活证据？人物为什么此刻不得不说？有没有一个动作或环境让他 / 她说不出口、说慢一点、绕一下再说？亲情遗憾故事里，很多情绪应该由环境和动作代替人物自我说明。

父亲这类沉默寡言角色尤其不能只靠台词刻画。他的内心可以通过反复打不燃火、手抖、背影挡住火光、握孩子的手太紧、站着不催、肩背绷住等动作被看见。环境也可以承担民俗意味，例如风吹纸房飘带、火几次点不着，既表现人的不平静，也让观众隐约感到逝者不愿离开。

回忆 VO 必须和当前触发物件对位。不要把一句旧话随便放在情绪段里，只因为它好听。先问这句旧话是被什么看见、摸到、听见或闻到的东西触发的：袖口针脚触发“添衣裳”，两辆木车触发“一人一个”和“说话算话”，药碗触发身体不好，纸房火光触发离别和叮嘱。VO 出现时，画面要给出对应证据，让观众知道这句话为什么在此刻响起。

结尾片名要尽量由画面动作托出来，而不是在静态遗物画面后硬贴字幕。先找一个仍在动的轻物、声音或环境变化，让它把观众从近景情绪带到全片空间：木轮转动扫下枯叶 / 纸灰，镜头跟随轻物拉高，院子、人物、遗物和白布完整显露，然后片名出现。这样片名就是最后一幕的情绪命名，不是作者在结尾追加解释。

核心道具必须从“功能物”升级为“情感证据”。它要回答四个问题：

```text
它回应了主角哪个愿望。
谁记住了这个愿望。
对方付出了什么行动或代价。
结尾它如何反过来刺痛主角和观众。
```

如果一个亲情道具只是突然出现的礼物、遗物或象征物，没有前置愿望、拒绝 / 缺口、亲人记住和结尾回收，它就很难真正打动人。

强故事三要素：

```text
对立面：没有对立面就没有故事。对立面可以是反派、制度、禁忌、误解、市场偏见、竞争者、时代压力、内在恐惧或世界规则。
独特个性：主角、品牌、产品或世界观必须有不可中和的个性。个性意味着会吸引一部分人，也会冒犯或排斥另一部分人。
黑暗时刻：主角、团队、品牌或世界必须经历一次接近失败、失控、被围攻、被误解、被驱逐或被迫重生的节点。
```

品牌、人物、产品型故事必须额外检查：

```text
负面巅峰是否足够强：反派 / 对立面越强，主角或品牌的成长越有说服力。
个性是否有代价：无条件退款、民族情怀、创新洁癖、极致低价、极致审美都不能面面俱到。
黑暗时刻是否改变命运：不是小挫折，而是让主角死过一回、被迫重建认知和打法。
```

不要把对立面写成单纯坏人。真正有力的对立面要能代表一种相反价值、一种强压力或一种观众能理解的合理立场。

第一桶金 / 创业起源 / 个人逆袭故事，优先使用三幕英雄之旅：

```text
离开之幕：为什么离开旧世界。写清主角厌倦、反抗或无法忍受什么，例如小城市的碌碌无为、父母控制、小企业内耗、旧行业天花板、旧身份困局。
启动之幕：进入未知世界后遇到什么怪兽。怪兽可以是资金短缺、团队不合、市场不认可、技术失败、投资人撤资、舆论围攻、规则不熟或自身弱点。
归来之幕：第一桶金如何到来。它既可以是成功起点，也可以是坠入深渊的开始；必须写清它改变了主角什么，也埋下了什么新的代价。
```

写第一桶金时，每一幕都要有情感和故事动作：

```text
离开不是换地点，而是切断旧依赖。
启动不是流水账，而是连续打怪和扛住黑暗时刻。
归来不是炫耀赚到钱，而是主角带着新能力、新伤口或新欲望回来。
```

如果第一桶金故事只有“我努力了然后赚到了”，必须退回补对立面、怪兽和黑暗时刻。

### 4. 人物医生

主角必须具备：

```text
外在目标：
内在需求：
错误信念：
不愿面对的恐惧：
惯常逃避方式：
被迫改变的压力：
最后的不可逆选择：
```

配角不能只负责解释信息。每个重要配角要有自己的欲望、压力和对主角的功能。

### 5. 高潮场设计

高潮不是最大场面，而是最大选择。设计高潮时必须明确：

```text
主角被逼到什么位置：
他最想用旧方式解决什么：
旧方式为什么失效：
黑暗时刻是什么：
他付出什么代价做出新选择：
观众通过哪个动作看见人物变化：
最后一个画面留下什么余味：
```

### 6. 场景写作

每场戏写成可拍内容：

```text
场次：
地点 / 时间：
场景目标：
阻碍：
结果：
可视化重点：
声音重点：
进入点：
离开点：
```

场景不能只负责交代信息。每场戏至少有一个微型戏剧动作。

### 7. 短视频喜剧表达

当目标是短视频流量、口播、人物故事、品牌故事或轻剧情内容时，可以用喜剧表达增加传播性。喜剧不是乱搞笑，而是让观点产生偏离、反差和可转述性。

常用三法：

```text
狠词怂态度：用最强烈的词表达最弱势、最怂、最没办法的处境。强烈反对和实际处境形成反差。
言不由衷：故意说一个观众一听就知道不真诚、不可能、太夸张的话，让荒谬感自己冒出来。
经典借用：借用经典作品、流行梗、熟悉桥段或大众记忆，但必须服务当前观点，不能只做拼贴。
```

短视频表达要允许思维偏离常规轨道：

```text
观点不要永远顺着大众安全区走。
包袱要有轻微冒犯、反差、错位或自嘲。
争议点要能引发评论，但不能牺牲作品底层价值和人物可信度。
浅内容负责抓流量，深内容负责留下铁粉。
```

“九浅一深”用于内容组合，不用于单条内容灌水：多数内容可以轻、快、浅、好转发，但必须定期有一条真正深入人心的作品，承接信任和铁粉。

短视频剧情片可以区分“正片层”和“包装层”。正片层负责沉浸表演、故事动作、情绪变化和视听完整性；包装层负责前 3 秒钩子、标题解释、观看任务、结尾评论引导和账号发布语境。不要因为需要开场口播，就把正片人物改成全程解释剧情；也不要因为正片人物无对白，就不给短视频开头和结尾设计声音。正确做法是先保护正片规则，再单独设计包装层口播：谁对镜头说、说几秒、声音是什么状态、如何进入正片、如何从正片情绪回到评论钩子。当前案例：林栀正片中不说话，只用表情承受男声脑内回响；包装层开场可以说“30秒，带你谈一场恋爱”，结尾可以说“我的30秒，演了两分钟。你的30秒，花了多久？”用来解释标题错位并引导评论。

### 8. 苦难叙事边界

人物、创业、品牌、成长类故事可以写困难、低谷、被误解和黑暗时刻，但不能把惨当成商品卖。惨只能作为真实处境和情绪钩子，不能成为故事的最终姿态。

苦难叙事必须走向二选一：

```text
和解：主角理解过去、放下怨气、修复关系、接受现实或重新定义自己。
励志：主角把困难转成行动、能力、选择、反击、成长或新秩序。
```

写作判断：

```text
人可以惨，但不能卖惨。
卖惨如果出现，只能作为短暂钩子，必须很快转向行动、反思、选择、幽默、自救或成长。
苦难细节要真实克制，不要堆眼泪、堆伤口、堆可怜。
平台和观众会识别过度表演的惨；过假会伤害信任和分发。
```

如果故事只有“我很惨，所以你应该同情我”，必须退回重写为“我经历困难后如何和解或变强”。

### 9. 故事杠杆

故事不是信息堆叠，而是用少数关键元素撬动观众的情感、认知和行动。写短视频、人物故事、品牌故事、产品故事、口播和课程化内容时，要主动设计杠杆。

四个常用故事杠杆：

```text
大脑墙：观众内心已有的防线、信仰、偏见、身份、恐惧和价值观。墙越厚，冲突越强，机会越大。
痛点杠杆：人类对痛苦、损失、被冒犯、被忽视、被拖累的敏感度高于喜悦。唤起真实痛点，可以让观众从旁观变成参与。
金句钉：精炼、扎心、可复述的句子，用来穿透大脑墙，钉住观众记忆。
共鸣网：让个体经验接入群体关系、平台、社区、人脉、客户、社交身份和共同处境，让内容从一个人的故事变成一群人的故事。
利他金：内容必须让观众得到东西，例如方法、情绪释放、认知升级、勇气、判断标准、行动路径或被理解感。利他不是讨好，而是用最小表达成本调动最大信任和传播。
```

写作判断：

```text
先找墙：观众最不愿承认、最抗拒、最在意或最被冒犯的点是什么。
再找痛：观众害怕失去什么，正在忍受什么，最不想承认哪种难受。
再下钉：这条内容有没有一句能被观众记住、转述或截图的金句。
再织网：这件事是否连接到一类人、一种关系、一种身份或一个共同处境。
最后给金：观众看完带走什么，是否感到“这对我有用”。
```

如果内容讲得都对，但没有记忆点、没有传播关系、没有利他收益，就要回到这一节补杠杆。

痛点杠杆边界：

```text
可以唤起真实存在的难受、损失、风险、错失和不甘。
不能制造虚假焦虑、夸大恐惧或故意伤害弱势处境。
让用户难受的目的，是让他看见问题和行动出口，不是让他停在自责、恐慌或被操控里。
痛点之后必须给出利他金：判断标准、解决路径、安慰、行动、反击或成长。
```

金句钉的高级形态是个体宣言：

```text
不是顺口号，而是一个人、品牌、产品或群体站出来表态。
不是拼体力，而是借脑力；宁可一个月磨出一句有穿透力的金句，不要十个月输出一堆无头苍蝇式表达。
不要只尊重共识，要从共识里找尚未被说透的偏见、真实偏好、隐秘不满和反常识角度。
偏见不是歧视或恶意标签，而是主流共识尚未承认、但观众心里已经存在的判断倾向。
```

个体宣言式金句判断：

```text
这句话是否有明确立场。
这句话是否像某类人会拿来替自己发声。
这句话是否借用了观众已有偏见、真实偏好或隐秘不满。
这句话是否能对抗一个旧共识，而不是重复一个安全共识。
```

感性与缺点杠杆：

```text
不要只追求理性正确，要借用观众的感性反应。理性负责让内容站得住，感性负责让内容被记住、被转述、被卷入。
不要只突出优点，要借用可被接受的缺点。优点容易变成普通赞美，缺点更容易形成共同敌人、亲密感、辨识度和真实关系。
能够被接纳的缺点，往往比完美优点更像一个人、一个品牌或一个角色被真正认可的理由。
缺点不是硬黑，也不是自毁，而是把人物、品牌、产品或观点的边界说清楚：它不讨好谁，它冒犯谁，它和谁站在一起。
```

写缺点时先判断：

```text
这个缺点是否真实存在，还是为了制造噱头硬编。
这个缺点是否能引出共同敌人，例如拖累、虚伪、懦弱、过度理性、讨好、平庸或旧共识。
这个缺点是否会让目标观众觉得“我懂你”，而不是只觉得被羞辱。
这个缺点最后是否转化成个性、选择、反击、成长或关系，而不是停在负面标签。
```

选择性注意与风格边界：

```text
想讨好所有人，就会失去风格。风格来自选择：选择吸引谁，也选择放弃谁。
人会选择性忽视熟悉、平滑、顺从、平均的刺激。太顺的词、太完整的赞美、太无摩擦的观点，很容易被大脑当成背景噪声。
内容需要一个“轻微跑调点”：一个不顺滑的词、反常识角度、可争议判断、可接受缺点、奇怪但准确的比喻或出人意料的节奏。
跑调点不是乱写，而是让观众在熟悉里突然被刺一下，发现这条内容和别人的不一样。
```

写跑调点时先判断：

```text
这条内容最想抓住哪一类人，愿意放弃哪一类人。
观众已经熟悉到会忽视的说法是什么。
哪里可以故意不那么平滑：词语、句式、观点、人物缺点、节奏、反差或结尾。
跑调点是否服务主张、人物或故事，而不是只为了吸睛。
```

## 剧本写作规则

- 每场戏至少有一个微型戏剧动作：目标、阻碍、结果。
- 每个正式故事必须有对立面、独特个性和黑暗时刻；缺一项时只能算概念展示或氛围片，不算强故事。
- 第一桶金 / 创业起源故事必须写清：为什么离开旧世界、在未知世界打败了什么怪兽、第一桶金是新起点还是新深渊。
- 不写心理描写，只写能被看见或听见的内容。
- 台词不能解释主题，台词要像真人说话。
- 台词必须匹配人物地域、年龄、文化程度和关系口气。用户指定方言时，要写成对应方言气质的可听懂口语；重庆老家、老一辈农村人物优先使用重庆话 / 川渝口语短句，避免书面普通话和主持腔。
- 亲情遗憾、童年成长、怀旧家庭故事必须建立情感因果链：误解 / 嫌弃、愿望 / 缺口、亲人记住、具体回应、温馨使用、缺点引爆、后果压近、遗物回收。温馨段要同时埋后半段的后果证据。
- 已确认的背景刀口必须进入正式剧本，不要只留在索引或故事确认里。例如“主角从小没了妈”会改变奶奶叮嘱的重量，若老胡没有明确删除，就要在合适场景以克制台词或物件反应保留，不展开支线也不能从正文消失。
- 关键道具不能凭空出现。亲情、成长和遗憾故事里的核心道具，必须有前置愿望、拒绝 / 缺口、人物记住、亲手回应这条情感因果链。比如孩子想要玩具被父亲拒绝，向爷爷告状，爷爷记住并亲手做出木车；这样道具才不是功能物，而是“有人把我的一句话放在心上”的证据。
- 遇到遗像、火光、旧话回响、叩首抬头、季节变化、空屋、遗物等非线性跳切时，先判断它是不是情绪型时间省略，不要直接当成时间线错误修正。正确做法是区分故事现实时间和影像表达时间：故事现实时间可以经过数天、数月或数年，影像表达可以用一个转场压缩。若这种压缩会让观众误会为“马上发生”，剧本要优先用可见变化提示时间：儿童 POV 的主观镜头高度略微变高、衣物尺寸变化、季节 / 房间变化、院落冷清、药瓶或遗物位置变化、声音回忆。必要时再用 `【字幕：一段时间后】`，不要优先靠成年旁白解释。
- 时间省略不一定要完全消灭观众的短暂懵感。若用户想要“先懵一下，再自己懂”，可以用一个镜头切换直接进入遗像、仪式或遗物新状态，再让观众通过视角高度、仪式状态、环境变化和前文声音回响自行拼出时间跨度。只要画面证据足够，短暂懵感是情绪落点，不是必须修掉的逻辑漏洞。
- 亲情遗憾、童年创伤和死亡相关故事，不要轻易把因果写成司法判决。若用户想表达的是“可能是诱因、无人归罪、长大后无法考证的自我怀疑”，应采用弱因果：事实层留下身体原本有病、意外摔倒、无人责怪等可见证据；心理层让疑问埋在角色心里；观众层让成熟观众自己读懂可能性。弱因果不能空口补设定，前半段温馨场景里要轻轻埋证据，例如短促咳嗽、药碗、递药、角色用笑遮过去。不要让角色直接说“都是你害的”，除非用户明确要惩罚叙事。
- 亲人离世、丧葬、遗物、童年回忆类段落可以使用无对白仪式段。无对白不是没内容，而是用叩首、绕行、火光、纸扎燃烧、遗像、遗物和前文台词回声承载情绪。此类段落不要临时补解释性台词；前文已经出现过的遗言、承诺或叮嘱可以作为 VO / 声音回忆在火光或遗物画面中重放。
- 回忆不能悬空插入。童年、亲情和遗物类故事里的回忆，优先由现实中的一句台词、一个物件、一次触碰、一个声音或一个味道触发，再进入朦胧记忆画面。回忆段可以用当前人物 VO、现实声音穿插、画面边缘发白、声音隔水感、光线变软等方式标明它是记忆。不要把回忆单独放在前面当普通场景，否则观众会觉得莫名其妙。
- 片名字幕最好由最后的画面运动引出。尤其亲情遗憾、童年成长、怀旧短片，不要把标题简单贴在最后一帧；优先用物件动作、轻物飘起、镜头拉高、空间揭示或声音回响把片名托出来，让观众感觉片名是这个结尾自然长出的名字。
- 正式短剧剧本必须充分使用格式承载信息。只保留 `△` 和普通 `角色名：` 不够；当剧情需要时，要主动使用 `角色名（语气 / 神态）：`、`角色名（OS）：`、`角色名 VO：`、`【字幕：】`、`【空镜：】`、`闪回 / 闪回结束`、`插入镜头`。这些标记能把表演、声音来源、时间层次和剪辑关系提前写清楚。
- 第一人称 / 儿童 POV 剧本必须做视角可行性检查。每个画面细节都要问：这个孩子现在能不能看见、听见、摸到或感到？如果写书包肩带滑下来，要写他低头看见肩带从肩上滑落，或肩膀一沉、书包角蹭到胳膊。不能写儿童 POV 无法直接看到的大人表情、远处事件、房间外完整对话或俯视全景，除非通过门缝、影子、画外音、反射、脚步声、别人反应等方式转译。
- 报丧、噩耗、突发事故类场景必须保护突发性。若剧情需要孩子或观众突然被消息砸中，不要在消息前提前展示白布、灵堂、棺木、哭丧队伍等已经布置完成的结果画面。可以先用日常放学路、普通村民、突然停顿和直白粗糙的台词制造落差，等主角进入现场后再揭示丧葬布置。
- 台词的委婉程度必须匹配说话人身份和戏剧功能。村民、老人、父母、孩子不一定会说文学化委婉话；需要直白冲击时，可以用更糙、更生活的说法，例如“你们爷爷死喽”。不要把所有死亡消息都写成“走了”“离开了”这类书面委婉表达，除非说话人身份和场景确实需要克制。
- 叩首抬头、遗像切换、物件匹配这类转场可以压缩时间和情绪。写法要先给观众一个清晰的前状态，例如爷爷遗像；再用低头、黑暗、遮挡或动作完成转场；抬头后进入新状态，例如奶奶遗像。为了避免误会成同一秒发生，要用主观视角高度、衣服变化、环境状态、仪式细节或声音回忆给出时间已经过去的证据，不靠新台词解释。
- 短视频台词如果太平、太正、太安全，要检查是否能加入狠词怂态度、言不由衷或经典借用。
- 喜剧表达必须来自人物处境和观点反差，不要硬塞段子。
- 短视频剧情片要区分正片层和包装层。开场钩子、结尾评论引导、标题解释和账号口播可以存在于包装层；正片人物是否说话、是否解释、是否保持沉浸，仍按正片规则执行。不要把包装层口播混进正片人物关系里。
- 困难和低谷可以做钩子，但必须走向和解或励志，不能停在卖惨。
- 短视频、品牌、人物和产品故事必须设计至少一个故事杠杆：大脑墙、痛点杠杆、金句钉、共鸣网或利他金。
- 广告语、口播金句和品牌表达要尽量写成个体宣言，而不是普通正确话。
- 故事、口播、品牌表达不要只证明自己理性正确；要借用感性、可接受的缺点和共同敌人，让观众产生关系感。
- 写人物、品牌或产品时不要只夸优点；优点用于建立价值，缺点用于建立边界、个性和真实感。
- 内容必须有风格边界：明确吸引谁、放弃谁，并设计一个服务主张的轻微跑调点，避免被选择性忽视。
- 关键情绪落到动作、视线、呼吸、手部、距离变化。
- 一个视频镜头默认控制在 15 秒以内；信息过多时主动拆镜头。
- 剧本不是终点，必须能继续拆成可复用资产、画面元素、场景 / 道具需求和镜头任务。

## 反例黑名单

- 不要只写世界观介绍，没有主角目标、阻力和代价。
- 不要写只有正面角色、只有赞美、只有田园牧歌或心灵鸡汤的软故事。
- 不要让主角、品牌或产品面面俱到；面面俱到会变成摇摆人，故事个性会消失。
- 不要把黑暗时刻写成轻微麻烦；它必须逼出重生、逆袭、黑化、牺牲或不可逆选择。
- 不要把第一桶金写成成功流水账；没有离开旧世界、没有怪兽、没有归来后的代价，就不是有感染力的起源故事。
- 不要把“恢宏”“震撼”“仙气”当成剧情动作。
- 不要在剧本里写摄影机拍不到的心理解释。
- 不要让台词替作者解释主题。
- 不要把已确认设定改丢。没有被老胡明确拒绝的内容，不能因为改稿更顺、对白更短、节奏更快就从正式剧本里消失。
- 不要把农村老人、父母、孩子写成书面普通话朗读腔；不要用“你以后要照顾好自己、保持良好习惯”这类正确但不像真人说的话替代生活口语。
- 不要把所有台词都写成 `角色名：台词`。该标注语气、神态、OS、VO、字幕、空镜、闪回、插入镜头时必须标注；否则下游不知道这句话是压低声音、忍着哭、内心声、画外声，还是回忆里的旧话。
- 不要把亲情故事写成单纯温馨合集。没有主角缺点、错误信念、情感缺口、不可逆后果和遗物回收，温馨只会变成散素材。
- 不要让亲情道具凭空承担情绪。没有“愿望被拒绝、亲人记住、具体回应、结尾回收”的道具，只是道具，不是情感证据。
- 不要把回忆写成没有触发点的独立场景。回忆要服务当下情绪揭示，最好由现实台词、物件、触碰、声音或气味触发，并通过画面质感和 VO 让观众知道这是记忆。
- 不要把片名当作最后一行文字硬贴到静态画面后。能用最后一个动作、环境运动、镜头拉高或空间揭示引出片名时，必须让片名从画面里长出来。
- 不要让第一人称 POV 偷偷变成第三人称旁观镜头。儿童 POV 看不到的完整对话、远处布置、大人背后的表情和全景信息，要改成门缝、影子、画外音、反射、身体感觉或他人的反应。
- 不要在突发报丧前提前露出白布、灵堂、棺木等结果画面；这会削弱消息的突然性，并制造“既然已经布置好了，为什么孩子才知道”的逻辑问题。
- 不要把农村村民、老人和低文化人物的关键消息统一写成书面委婉话。需要冲击时，台词该直就直、该糙就糙。
- 不要把喜剧写成纯耍嘴皮；没有处境、反差和观点，笑点会变成噪声。
- 不要为了流量制造无底线冒犯；争议必须服务观点、人物或故事。
- 不要全做浅内容；长期账号必须有能留下铁粉的深内容。
- 不要卖惨。苦难如果不能转向和解、励志、行动或成长，就会损害人物可信度。
- 不要把低谷写成堆伤口；黑暗时刻要逼出选择，不是逼观众同情。
- 不要只讲正确观点，没有金句、没有共鸣关系、没有观众收益。
- 不要制造虚假焦虑。痛点必须基于真实损失、真实风险或真实难受，并且给出行动出口。
- 不要把利他写成讨好；利他必须提供真实价值，不是无原则迎合。
- 不要只复述共识。金句要从共识里挖偏见、立场、反常识和个体宣言。
- 不要把“借用偏见”写成歧视、污名或恶意标签；它只能指真实偏好、隐秘不满和未被说透的立场。
- 不要把“借用缺点”写成羞辱、恶意攻击或廉价自黑；缺点必须能转化成个性、关系、共同敌人或成长动力。
- 不要只突出优点、只做赞美、只讲正确逻辑；这种内容容易变成正确废话，缺少亲密感和传播钩子。
- 不要为了讨好所有人而磨平风格；平滑顺和、无选择、无摩擦的词和观点容易被观众选择性忽视。
- 不要把跑调点写成无意义猎奇；它必须服务主张、人物、故事或品牌边界。
- 不要把 45 秒短片写成需要多集才能讲清的复杂设定。
- 不要让 POV 视角变成普通旁观镜头；必须有被引导、被邀请或穿越的身体感。
- 不要把一次性路人和一次性奇观写成必须长期复用的资产。

## 自检

输出前检查：

- 主角目标是否能一句话说清。
- 是否有足够强的对立面，且对立面不是纸片反派。
- 主角、品牌、产品或世界观是否有会吸引一部分人也排斥另一部分人的独特个性。
- 是否有真正的黑暗时刻，让主角或品牌经历失控、失败、被围攻或重生。
- 如果是第一桶金 / 创业起源故事，是否有离开之幕、启动之幕、归来之幕。
- 第一桶金是否既有结果，也有代价、转折或新危险。
- 阻力是否具体，而不是抽象困难。
- 冲突是否逐步升级。
- 每场戏是否发生了可见的价值变化，而不是只展示信息或奇观。
- 主角是否同时具备外在目标、深层需求、错误信念和最后选择。
- 已确认设定是否都在正式剧本正文中得到保留或转译；是否存在只留在索引 / 故事确认里、正文改稿时被删掉的背景刀口。
- 开头是否快速给出类型承诺、看点和观众等待的问题。
- 45 秒视觉短片是否有钩子、宏大揭示、近景锚点和结尾记忆点。
- POV 内容是否体现第一人称沉浸和身份关系，而不是普通第三人称游览。
- 第一人称 / 儿童 POV 的每个细节是否都能被主角看见、听见、摸到或感到；不可见信息是否已经通过门缝、影子、画外音、反射、身体感觉或他人反应转译。
- 回忆是否由当前台词、物件、触碰、声音或气味触发，而不是悬空插入；回忆画面是否有朦胧质感、声音穿插或 VO 标识。
- 报丧、噩耗和突发事故是否保留突发性；是否避免在消息前提前露出白布、灵堂、棺木等结果画面。
- 死亡消息和方言台词是否匹配人物身份、文化程度和戏剧冲击，不是否被过度写成书面委婉话。
- 情绪型时间压缩是否通过叩首抬头、遗像切换、物件匹配、视角高度、服装变化、环境状态或声音回忆给出足够证据。
- 每个关键节点是否是行动或选择。
- 是否有摄影机拍不到的心理描写。
- 单镜头剧本是否不超过 15 秒，且只有一个主要动作或信息变化。
- 台词是否在解释主题。
- 剧本格式是否充分使用语气 / 神态括号、OS、VO、字幕、空镜、闪回、闪回结束、插入镜头等结构；是否有该标没标的信息。
- 台词是否匹配人物地域、年龄、文化程度和关系口气；用户指定重庆话等方言时，是否写出可听懂的方言口语气质，而不是书面普通话。
- 亲情遗憾、童年成长、怀旧家庭故事是否有完整情感因果链：主角误解、具体愿望、亲人记住、具体回应、缺点引爆、后果压近、遗物回收。
- 核心物件是否已经成为情感证据，而不是突然出现的象征物。
- 如果是短视频或口播内容，是否有至少一个反差表达、错位表达或可转述的金句 / 包袱。
- 喜剧表达是否来自人物处境和观点冲突，而不是外加段子。
- 如果写到惨、低谷或困难，是否已经转向和解、励志、行动或成长。
- 是否找到观众的大脑墙和真实痛点，并设计金句钉、共鸣网或利他金。
- 是否利用了损失厌恶，但没有滑向虚假焦虑、恐吓或恶意操控。
- 广告语、口播金句或品牌表达是否像个体宣言，而不是普通正确话。
- 金句是否从共识里找到了未被说透的偏见、真实偏好或反常识角度。
- 表达是否借用了感性、可接受的缺点和共同敌人，而不是只停在理性正确和优点赞美。
- 人物、品牌或产品的缺点是否被转化成边界、个性、关系或成长动力，而不是恶意标签。
- 内容是否有明确风格边界，是否知道吸引谁、放弃谁。
- 是否设计了一个服务主张的轻微跑调点，避免语言、观点或角色被选择性忽视。
- 是否有一句可记住、可转述、可截图的表达。
- 观众看完是否获得方法、情绪释放、认知升级、勇气或行动路径。
- 是否能拆成可复用资产、一次性画面元素、角色 / 场景 / 道具需求和镜头任务。
- 是否输出剧本交接包，方便下游判断哪些需要做视觉资产，哪些只写进单镜头画面内容。
- 是否需要进入作品目录并更新版本。
