# 证据吸收与根因判断

只在反馈需要升级、外部资料需要吸收、规则原因不清或平台事实需要核验时读取。它负责回答“凭什么改、问题最早发生在哪里”，不替四层编译和文件迁移作决定。

## 一、先分清输入是什么

| 输入 | 能证明什么 | 不能自动证明什么 |
|---|---|---|
| 老胡明确反馈 | 真实需求、体验和个人偏好存在 | 普遍因果、所有题材都应如此 |
| 单次作品结果 | 这次输入、模型和流程产生了该结果 | 某条规则一定正确或错误 |
| 多次同类结果 | 问题可能稳定复现 | 原因只来自当前怀疑的变量 |
| 发布数据 | 某个完整包装在当时取得结果 | 单个标题、句子或镜头独立造成结果 |
| 外部高水平作品 | 一种经过选择的成品和结果 | 作者全部判断过程、方法普遍适用 |
| 相邻水平对照 | 结果差异和可比较取舍 | 差异一定由唯一因素造成 |
| 论文、官方文档、平台说明 | 特定范围内的事实、机制或硬边界 | 能直接决定老胡的审美与项目结构 |
| 外部 Skill 或仓库 | 一套明确方法、接口或经验组织 | 可以抹掉来源、照搬包装或冒充本地原创 |

先记录输入的原貌和来源，再写推论。事实、推论、偏好和决定不能混成一句“已经证明”。

## 二、反馈怎样成为能力证据

### 一次反馈先照见问题

把反馈拆成：

```text
老胡指出的可见问题
→ 他真正希望改变的结果
→ 当前规则原本怎样判断
→ 哪个执行结果与判断不一致
→ 这是偶发执行错误，还是规则本身缺口
```

反馈只修当前结果时，交给业务 Skill；反馈暴露重复出现的判断缺失、路由错误、方法缺口或硬接口问题时，才进入长期进化。

### 多次验证才立成尺度

长期升级至少寻找一种补强证据：相邻场景重复出现；高水平与普通结果在同一任务上有稳定取舍差异；平台事实已经核验；旧规则与多个现有能力发生冲突；反例证明现有原则范围过大。

证据尚不足但风险较低时记为 OBSERVE，并写清下一次需要观察的变量。不能用“以后可能有用”把假设塞进每次加载的 Skill。

## 三、外部知识怎样吸收

### 先找高下之别，再提炼取舍之因

不要在平庸答案中总结平均做法。选取已经被可靠结果、长期实践或正式作品证明的高水平选择，再找同一任务、相邻水平的普通选择进行对照：

```text
双方在解决同一个什么问题
→ 高水平选择取了什么、舍了什么
→ 普通选择取了什么、舍了什么
→ 哪项差异真正改变结果
→ 差异依赖哪些条件
→ 换题材或媒介后什么仍然成立
```

高水平不等于名气。作品、方法和证据必须与当前细分任务同构；名人观点只能提供校准视角，不能替代可验证因果。

### 拆机制，不搬外壳

吸收外部 Skill、仓库或案例时分成五类：

| 内容 | 处理 |
|---|---|
| 可独立验证的底层机制 | 改写成项目领域判断，并记录适用条件 |
| 平台、模型和接口事实 | 核验时效后进入法度或脚本 |
| 固定格式、命名和工作流包装 | 只有解决本项目真实接口时才保留 |
| 人物、品牌、独特措辞和镜头顺序 | 不复制，除非拥有权利且任务明确要求 |
| 外部运行时 Skill | 登记原文、镜像、本地适配、调用者、返回者和失效处理 |

外部来源不知道作者、网址或许可时明确写缺失，不猜测补齐。研究记录不能因为日常不加载就被删除；它可以降级为证据来源，但不能伪装成本地原创。

## 四、找到第一个能力断点

问题最后出现在哪里，不等于最早在哪里发生。按下列顺序回溯：

```text
真实结果哪里开始偏离目标
→ 当时由哪个阶段负责
→ 该阶段收到的上游事实是否已经错误
→ 当前 Skill 有规则但没执行，还是根本没有判断
→ Reference 是否有内容但不可达
→ 规则是否正确却缺少技法或法度
→ 机械检查能否更早拦截
```

四类断点必须分开：

- 判断断点：不知道什么值得选择，可能影响灵魂。
- 关系断点：负责人、先后、状态或交接错误，可能影响筋骨。
- 方法断点：知道方向却不会处理具体材料，可能影响血肉。
- 接口断点：结果不能被工具或下游使用，可能影响表皮。

一个问题可以包含多个断点，但先修最早且能解释后续症状的断点。不能从最后一句不好看，直接推导出整套原则需要重写。

## 五、反例与替代解释

提出改动假设后至少问：

1. 有没有旧场景在现有规则下表现很好？
2. 问题是否来自输入不足、执行遗漏、模型随机性或外部限制？
3. 同一结果能否由更小改动解决？
4. 新规则换到相邻题材会不会造成新的平均化？
5. 如果删除这条新规则，下一次行为是否真的会不同？

无法排除替代解释时，缩小适用范围或进入 OBSERVE。反例不是为了机械反对，而是防止把偶然当规律。

## 六、证据包

交给四层重编译前形成：

```text
来源与可追溯位置：
事实：
推论：
偏好或价值取舍：
当前结果与预期结果：
高水平与相邻水平对照：
第一个能力断点：
唯一规则负责人候选：
反例与替代解释：
证据充分度：足够更新 / 只够观察 / 应当否决。
```

证据包不能回答“改哪一层”时，不进入永久写回。
